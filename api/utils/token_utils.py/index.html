    token_utils.py

    Source: utils/token_utils.py

    Technical Overview

    utils/token_utils.py provides the token counting, prompt sizing, context window headroom budgeting, and dynamic token ratio calibration infrastructure for the codebase knowledge generation pipeline. Large language models (LLMs) across different vendors employ disparate tokenization schemes (such as Byte-Pair Encoding variants like cl100k_base, SentencePiece, or custom gemini/claude tokenizers). Because running vendor-specific tokenizers locally for every candidate prompt is computationally expensive or impossible without network round-trips, this module uses a fast local baseline (tiktoken's cl100k_base) paired with an adaptive calibration system that dynamically scales raw token counts to match the active model's billed token counts.

    The architecture decouples raw token counting from model-specific token budgeting. Raw counts are computed using tiktoken with an in-memory, thread-safe LRU-style cache (OrderedDict) keyed by string length and content hash to eliminate redundant processing across execution phases. If tiktoken fails to load or environment constraints prevent downloading encoding files, the system falls back to a deterministic byte-ratio estimator (UTF-8 bytes / 3), which deliberately over-counts source code rather than under-counting multi-byte non-English scripts. The dynamic calibration engine observes provider-reported token usage across requests, applying an Exponential Moving Average (EMA) with size weighting to adjust the token multiplier. This learned ratio is persisted to disk in llm_token_calibration.json, ensuring subsequent workflow runs immediately benefit from calibrated headroom estimates.

    Prompt budgeting logic computes the maximum safe prompt size that guarantees adequate headroom for model responses, chain-of-thought thinking tokens, and estimation uncertainty. Providers such as Anthropic and OpenRouter enforce shared context windows where prompt and completion tokens share the total limit, whereas Google Gemini maintains separated input and output quotas. The budgeting engine queries provider capabilities to reserve output space and scales down the uncertainty reserve from 5% to 2% once the active model's ratio is verified through real usage data.

    resolve_max_tokens()

    Visibility: Public

    Signature: def resolve_max_tokens(shared):

    Description: Resolves the maximum context token window for the active workflow step. It inspects the shared workflow dictionary for an explicit "max_tokens" override; if absent, it queries utils.llm_config.resolve_llm_settings() and utils.llm_config.get_model_context_length() to determine the context window size configured for the active model endpoint and API key.

    Parameters:

    • shared (dict): Shared pipeline state dictionary, optionally containing a "max_tokens" override.

    Returns:

    • int: Maximum context window length in tokens.

    Example:

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from the active provider."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    _, model_name, endpoint, api_key = resolve_llm_settings()
    max_tokens_val = get_model_context_length(endpoint, model_name, api_key)
    emit_raw("DEBUG", f"resolve_max_tokens | resolved max_tokens={max_tokens_val:,}", dest="LOG")
    return max_tokens_val

    The function prioritizes manual user configuration supplied via the shared state map. When an explicit limit is not configured, it triggers dynamic discovery via resolve_llm_settings(), resolving the provider, canonical model identifier, endpoint URL, and credentials. It delegates to get_model_context_length() to query static tables or remote provider catalog endpoints before outputting a debug trace via emit_raw().

    input_token_budget()

    Visibility: Public

    Signature: def input_token_budget(max_tokens: int, thinking_level: str | None = None) -> int:

    Description: Calculates the maximum number of tokens permissible for input prompts such that sufficient headroom remains in the context window for completions, internal reasoning (thinking) budgets, safety margins, and estimation variance.

    Parameters:

    • max_tokens (int): Total context window limit for the active model.
    • thinking_level (str | None, optional): Configured reasoning effort level ("minimal", "low", "medium", "high", or "max"). Defaults to None.

    Returns:

    • int: Maximum allowable input token count.

    Example:

    def input_token_budget(max_tokens: int, thinking_level: str | None = None) -> int:
    planned = context_output_reserve(thinking_level)
    if planned is not None:
        reserve = planned + CONTEXT_MARGIN
    else:
        reserve = min(max(int(max_tokens * 0.05), MIN_OUTPUT_RESERVE), MAX_OUTPUT_RESERVE)
    reserve += int(max_tokens * (ESTIMATE_RESERVE_CALIBRATED if ratio_is_calibrated() else ESTIMATE_RESERVE_UNCALIBRATED))
    return max(max_tokens - reserve, max_tokens // 2)

    The function computes reserved capacity based on provider-specific architectural constraints. When context_output_reserve() returns a concrete value (used for providers like Anthropic and OpenRouter where output and reasoning tokens consume shared context), the budget reserves that amount plus a fixed CONTEXT_MARGIN. For other providers without explicit output sizing, it clamps a 5% reserve between MIN_OUTPUT_RESERVE (8,192 tokens) and MAX_OUTPUT_RESERVE (64,000 tokens). An additional percentage reserve (2% if calibrated, 5% if uncalibrated) accounts for estimation error, with a lower floor guaranteeing at least half the context window remains available.

    count_tokens_raw()

    Visibility: Public

    Signature: def count_tokens_raw(text: str) -> int:

    Description: Measures raw token counts using the standard tiktoken cl100k_base vocabulary without applying model-specific ratio scaling. Results are cached in an internal memory memo.

    Parameters:

    • text (str): Input string to tokenize.

    Returns:

    • int: Unscaled raw token count.

    Example:

    def count_tokens_raw(text: str) -> int:
    """tiktoken cl100k_base token count (no model calibration). Memoized by content."""
    if not text:
        return 0
    if len(text) < MEMO_MIN_CHARS:
        return _encode_count(text)
    key = (len(text), hash(text))
    cached = _memo_get(key)
    if cached is not None:
        return cached
    count = _encode_count(text)
    _memo_put(key, count)
    return count

    The function provides fast-path handling for empty strings and short snippets beneath MEMO_MIN_CHARS (256 characters) by directly invoking _encode_count(). For larger texts, it computes a composite key consisting of string length and Python's built-in string hash, which is cached on the string object itself. It inspects _memo to return cached counts in $O(1)$ time, delegating to tokenization and updating the cache only on initial evaluation.

    count_tokens_raw_many()

    Visibility: Public

    Signature: def count_tokens_raw_many(texts: list[str]) -> list[int]:

    Description: Computes raw cl100k_base token counts for a collection of strings in parallel, bypassing the memo for uncached entries to leverage multi-threaded batch encoding.

    Phase 1: Cache Inspection & Batch Partitioning

        counts = [0] * len(texts)
    pending = []
    for i, text in enumerate(texts):
        if not text:
            continue
        key = (len(text), hash(text)) if len(text) >= MEMO_MIN_CHARS else None
        cached = _memo_get(key) if key else None
        if cached is not None:
            counts[i] = cached
        else:
            pending.append((i, text, key))

    This initial phase initializes the fixed-size results array and identifies items already present in the memory memo. Inputs that exceed MEMO_MIN_CHARS are evaluated against _memo_get(). Items missing from the cache or shorter than the memo minimum are registered in pending as (index, text, key) tuples for bulk execution.

    Phase 2: Parallel Batch Tokenization & Fallback

        enc = _get_encoding()
    if pending and enc is not None:
        encoded = enc.encode_ordinary_batch([text for _, text, _ in pending], num_threads=min(8, os.cpu_count() or 1))
        results = [len(tokens) for tokens in encoded]
    else:
        results = [_fallback_count(text) for _, text, _ in pending]

    When pending items exist and tiktoken is operational, the function calls encode_ordinary_batch() across multiple worker threads, bounding CPU concurrency between 1 and 8 threads. If the encoding fails to load or environment errors occur, it falls back to synchronous computation via _fallback_count() for each pending text.

    Phase 3: Result Assembly & Cache Insertion

        for (i, _text, key), count in zip(pending, results, strict=True):
        counts[i] = count
        if key:
            _memo_put(key, count)
    return counts

    In the final phase, token counts from the batch encoder are mapped back to their original array offsets in counts. If a pending entry has an associated cache key, its calculated count is stored in the memo via _memo_put() to optimize subsequent pipeline steps.

    Parameters:

    • texts (list[str]): List of input strings to count.

    Returns:

    • list[int]: Sequence of raw token counts matching the input ordering.

    token_ratio()

    Visibility: Public

    Signature: def token_ratio() -> float:

    Description: Retrieves the active token ratio multiplier that maps raw cl100k_base counts to estimated tokens for the currently configured provider and model.

    Returns:

    • float: Effective token scaling multiplier.

    Example:

    def token_ratio() -> float:
    """Multiplier from raw tiktoken counts to the active model's tokenizer (static prior, calibrated)."""
    provider, _model, key = _active_key()
    return _effective(_static_ratio(provider, key), _load_calibration().get(key))

    The function resolves the active provider and model key, retrieves the baseline static prior via _static_ratio(), loads calibration records from disk or memory via _load_calibration(), and evaluates the effective ratio using _effective().

    ratio_is_calibrated()

    Visibility: Public

    Signature: def ratio_is_calibrated() -> bool:

    Description: Determines whether the active provider and model have accumulated sufficient empirical usage data to be considered fully calibrated.

    Returns:

    • bool: True if minimum observation counts and raw token thresholds have been satisfied; False otherwise.

    Example:

    def ratio_is_calibrated() -> bool:
    """True once enough real usage (samples and measured text) has been observed for the active
    provider+model, in this or earlier runs."""
    provider, _model, key = _active_key()
    entry = _valid_entry(_static_ratio(provider, key), _load_calibration().get(key))
    return bool(entry) and _can_lower(entry)

    The function verifies that a calibration record exists, has not drifted from its static prior, and satisfies the criteria enforced by _can_lower(): at least CALIBRATION_MIN_SAMPLES_TO_LOWER (3) requests and at least CALIBRATION_MIN_RAW_TO_LOWER (150,000) raw tokens.

    describe_token_ratio()

    Visibility: Public

    Signature: def describe_token_ratio() -> str:

    Description: Produces a human-readable description of the token ratio configuration for logging and UI startup displays, distinguishing between static priors and calibrated states.

    Returns:

    • str: Formatted string indicating the active ratio, calibration status, and sample count.

    Example:

    def describe_token_ratio() -> str:
    """'1.55 (static)' or '1.61 (calibrated from 12 calls; static 1.55)' for the startup display."""
    provider, _model, key = _active_key()
    static = _static_ratio(provider, key)
    entry = _valid_entry(static, _load_calibration().get(key))
    effective = _effective(static, entry)
    if not entry:
        return get("CFG_TOKEN_RATIO_STATIC", ratio=f"{static:.2f}")
    return get("CFG_TOKEN_RATIO_CALIBRATED", ratio=f"{effective:.2f}", samples=entry["n"], static=f"{static:.2f}")

    The function checks whether a valid calibration entry exists for the active model. If no entry exists or calibration has drifted, it formats the localized string template CFG_TOKEN_RATIO_STATIC. Otherwise, it returns CFG_TOKEN_RATIO_CALIBRATED containing the effective ratio, the number of observed samples, and the baseline prior.

    observe_prompt_tokens()

    Visibility: Public

    Signature: def observe_prompt_tokens(provider: str, model: str, raw_tokens: int, billed_tokens: int, served_model: str | None = None) -> None:

    Description: Ingests actual provider-reported prompt token metrics following an LLM API call to update the model's calibration ratio.

    Phase 1: Pre-validation & Guard Clauses

        if not calibration_enabled() or raw_tokens < CALIBRATION_MIN_RAW or billed_tokens <= 0:
        return
    if _get_encoding() is None:
        return
    model_id = _model_id(provider, model)
    served = _model_id(provider, served_model or "")
    if served and not (served.startswith(model_id) or model_id.startswith(served)):
        return
    if provider == "OPENROUTER" and ":online" in model_id:
        return
    ratio = billed_tokens / raw_tokens
    if not OBSERVED_RATIO_BOUNDS[0] <= ratio <= OBSERVED_RATIO_BOUNDS[1]:
        return

    This phase filters out requests where ratio calibration would introduce distortion. Requests smaller than CALIBRATION_MIN_RAW (2,000 tokens) are ignored because fixed prompt formatting tokens skew the multiplier. Calls using fallback byte counters, requests redirected to discordant models, OpenRouter :online routes that append search results in transit, and observed ratios falling outside OBSERVED_RATIO_BOUNDS (0.5 to 3.0) are discarded.

    Phase 2: EMA Calculation & Thread-Safe State Mutation

        key = _key(provider, model)
    static = _static_ratio(provider, key)
    weight = min(raw_tokens / CALIBRATION_FULL_WEIGHT_RAW, 1.0)
    with _calibration_lock:
        calibration = _load_calibration()
        entry = _valid_entry(static, calibration.get(key))
        before = _effective(static, entry)
        if entry is None:
            entry = calibration[key] = {"ema": ratio, "n": 0, "raw": 0, "w": 0.0}
        seen = entry.get("w", 0.0)
        if seen < 1.0:
            entry["ema"] = (entry["ema"] * seen + ratio * weight) / (seen + weight)
        else:
            alpha = CALIBRATION_EMA_WEIGHT * weight
            entry["ema"] = (1 - alpha) * entry["ema"] + alpha * ratio
        entry["w"] = seen + weight
        entry["n"] += 1
        entry["raw"] += raw_tokens
        entry["prior"] = static
        after = _effective(static, entry)
        _save_calibration()

    Under lock protection, the sample is integrated into the calibration history. Prompts contribute weight proportionally up to CALIBRATION_FULL_WEIGHT_RAW (50,000 tokens). Until cumulative observed weight reaches 1.0, the EMA behaves as a size-weighted arithmetic mean; beyond 1.0, an Exponential Moving Average with weight factor $\alpha = 0.35 \times \text{weight}$ is applied. The entry updates sample counts and raw totals before writing changes to disk via _save_calibration().

    Phase 3: Telemetry & Event Dispatch

        emit_raw(
        "DEBUG",
        f"TOKEN RATIO | key={key} | observed={ratio:.3f} | ema={entry['ema']:.3f} | samples={entry['n']} | effective {before:.3f} -> {after:.3f}",
        dest="LOG",
    )
    if abs(after - before) / before >= 0.02:
        emit("TOKEN_RATIO_UPDATED", model=model, before=f"{before:.2f}", after=f"{after:.2f}", observed=f"{ratio:.2f}", samples=entry["n"])

    Telemetry events are emitted following state updates. A granular record is written to the log file via emit_raw(). If the effective ratio shifts by 2% or more relative to its prior value, a public TOKEN_RATIO_UPDATED notification is emitted to console output.

    Parameters:

    • provider (str): Target provider identifier (e.g., "ANTHROPIC", "GEMINI").
    • model (str): Configured model identifier.
    • raw_tokens (int): Unscaled tiktoken count for the prompt.
    • billed_tokens (int): Actual prompt tokens reported by the provider.
    • served_model (str | None, optional): Actual model identifier returned in the provider response payload. Defaults to None.

    count_tokens()

    Visibility: Public

    Signature: def count_tokens(text: str) -> int:

    Description: Estimates the token footprint of a text string for the currently active provider and model by multiplying its raw cl100k_base count by the active token_ratio().

    Parameters:

    • text (str): Input string to evaluate.

    Returns:

    • int: Scaled token estimate.

    Example:

    def count_tokens(text: str) -> int:
    """Estimate tokens for the active model: raw tiktoken count x token_ratio()."""
    raw = count_tokens_raw(text)
    if not raw:
        return 0
    ratio = token_ratio()
    return int(raw * ratio) if ratio != 1.0 else raw

    The function computes the raw token count via count_tokens_raw(), retrieves the active ratio multiplier via token_ratio(), and returns the product cast to an integer.

    Phase 2: Breakdown Formatting & Suffix Construction

        # Build token usage breakdown suffix for stdout display
    suffix = ""

    # Single-line, parseable record in the log file

    )

    In this final phase, the function dispatches formatted telemetry through emit() using the localized key TOKEN_ANALYTICS for interactive terminal display. Simultaneously, it writes a structured, single-line log record via emit_raw() tagged with DEBUG to the persistent log sink.

    emit_step_usage()

    Visibility: Public

    Signature: def emit_step_usage(key: str, step: str, usage: dict) -> None:

    Description: Emits a formatted usage line for a specific execution step or subtotal summary, comparing estimated token usage against billed usage and calculating percentage deviation.

    Parameters:

    • key (str): Localized string template key (e.g., "LLM_USAGE_STEP", "LLM_STEP_SUBTOTAL").
    • step (str): Workflow step label.

    Example:

    def emit_step_usage(key: str, step: str, usage: dict) -> None:
    """Emit one per-step usage row (LLM_USAGE_STEP / LLM_STEP_SUBTOTAL) from llm_common.get_step_summary()."""
    estimate = usage.get("estimated_input", 0)
    billed = usage.get("input", 0)
    deviation = f"{(billed - estimate) / estimate:+.0%}" if estimate and usage.get("calls") else get("CFG_VALUE_UNKNOWN")
    emit(
        key,
        step=step,
        calls=f"{usage.get('calls', 0):,}",
        cache_hits=f"{usage.get('cache_hits', 0):,}",
        input=f"{billed:,}",
        estimate=f"{estimate:,}",
        deviation=deviation,
        output=f"{usage.get('output', 0):,}",
        thinking=f"{usage.get('thinking', 0):,}",
        cost=format_cost(usage),
    )

    The function extracts token metrics and calculates estimation variance as (billed - estimate) / estimate. It populates formatted string arguments—including call counts, cache hits, input tokens, thinking tokens, output tokens, and formatted costs—and delegates rendering to emit().

    format_cost()

    Visibility: Public

    Signature: def format_cost(usage: dict) -> str:

    Description: Formats accumulated monetary cost for a usage dictionary into a currency string, applying 4 decimal places for sub-cent values and annotating unpriced calls.

    Parameters:

    • usage (dict): Ledger usage metrics dictionary containing "cost", "calls", and "unpriced_calls".

    Returns:

    • str: Formatted cost string (e.g., "$1.23", "$0.0041", ">= $1.23 (2 calls unpriced)", or unknown indicator).

    Example:

    def format_cost(usage: dict) -> str:
    """'$1.23', '$0.0041' (sub-cent costs keep 4 decimals), '>= $1.23 (2 calls unpriced)' or n/a."""
    cost = usage.get("cost", 0.0)
    amount = f"${cost:.4f}" if 0 < cost < 0.01 else f"${cost:.2f}"
    unpriced = usage.get("unpriced_calls", 0)
    priced = usage.get("calls", 0) - unpriced
    if not unpriced:
        return amount
    if priced <= 0:
        return get("CFG_VALUE_UNKNOWN")
    return get("LLM_USAGE_COST_PARTIAL", cost=amount, unpriced=unpriced)

    The function rounds costs below $0.01 to four decimal places and other values to two decimal places. If calls occurred without pricing metadata, it checks whether any calls were priced; if none were priced, it returns the unknown placeholder via get("CFG_VALUE_UNKNOWN"), otherwise returning LLM_USAGE_COST_PARTIAL.

    _fallback_count()

    Visibility: Private

    Signature: def _fallback_count(text: str) -> int:

    Description: Provides a deterministic fallback token estimate based on UTF-8 byte length when tiktoken is unavailable.

    Parameters:

    • text (str): Input string to evaluate.

    Returns:

    • int: Estimated token count calculated as $\lceil \text{bytes} / 3 \rceil$.

    Example:

    def _fallback_count(text: str) -> int:
    # Conservative when tiktoken is unavailable: UTF-8 bytes/3 over-counts code (~4.3 chars/token)
    # instead of under-counting non-English text as chars/4 would (~2.5 chars/token for Vietnamese).
    return -(-len(text.encode("utf-8", "surrogatepass")) // 3)

    The function computes the ceiling division of UTF-8 byte length divided by 3 using -(-len // 3). The surrogatepass error handler ensures malformed lone surrogates do not raise decoding exceptions. Using a ratio of 3 bytes per token over-estimates English code without dangerously under-estimating multi-byte international text (such as Vietnamese or CJK scripts).

    _memo_put()

    Visibility: Private

    Signature: def _memo_put(key, value: int) -> None:

    Description: Thread-safe insertion of a calculated token count into _memo, evicting the oldest entries when capacity exceeds MEMO_MAX_ENTRIES.

    Parameters:

    • key (tuple[int, int]): Composite lookup key (length, hash).
    • value (int): Token count to cache.

    Example:

    def _memo_put(key, value: int) -> None:
    with _memo_lock:
        _memo[key] = value
        _memo.move_to_end(key)
        while len(_memo) > MEMO_MAX_ENTRIES:
            _memo.popitem(last=False)

    The helper acquires _memo_lock, assigns the value, positions it at the end of the OrderedDict, and evicts the least-recently used items from the beginning (last=False) until total cache entries stay within MEMO_MAX_ENTRIES (4,096).

    Description: Validates that a calibration record is usable and has not drifted from the current static prior.

    _effective()

    Visibility: Private

    Signature: def _effective(static: float, entry: dict | None) -> float:

    Description: Calculates the effective runtime token multiplier by applying headroom and boundary clamps to the learned EMA ratio.

    Parameters:

    • static (float): Static baseline token ratio prior.
    • entry (dict | None): Calibration entry dictionary.

    Returns:

    • float: Clamped effective token multiplier.

    Example:

    def _effective(static: float, entry: dict | None) -> float:

    if not entry:

    low, high = CALIBRATION_RANGE
    learned = min(max(entry["ema"] * CALIBRATION_HEADROOM, static * low), static * high)
    return learned if _can_lower(entry) else max(static, learned)

    The function clamps the learned ratio (ema * 1.03) within CALIBRATION_RANGE (0.75× to 1.5× the static prior). If _can_lower() returns false, the function returns max(static, learned), ensuring ratios can only increase until sufficient usage data is gathered.

    Data Structures

    Calibration File Schema

    Top-level schema stored on disk in llm_token_calibration.json:

    Field Type Description
    version int Schema version indicator (currently 1).
    counter str Base tokenizer vocabulary against which raw counts are measured (must equal "cl100k_base").
    entries dict[str, CalibrationEntry] Mapping from composite provider/model keys to their empirical calibration records.

    Calibration Entry

    Dictionary tracking empirical token ratio metrics for a specific provider and model:

    Field Type Description
    ema float Size-weighted Exponential Moving Average of observed token ratios.
    n int Total number of API response samples incorporated into this entry.
    raw int Cumulative raw cl100k_base prompt tokens measured across all samples.
    w float Accumulated weight units (capped at 1.0 during initial arithmetic averaging).
    prior float (Optional) The baseline static ratio active when the entry was recorded; used for drift detection.

    Example structure extracted from runtime execution:

  "counter": "cl100k_base",
  "entries": {
    "ANTHROPIC|claude-3-7-sonnet-20250219": {
      "ema": 1.284,
      "n": 14,
      "prior": 1.25,
      "raw": 348200,
      "w": 7.964
    }
  }
}

    Field Type Description

    Error Handling

    The module implements defensive, fault-tolerant patterns to avoid disrupting the documentation pipeline on tokenization or calibration failures:

    • Tokenizer Loading Failures: In _get_encoding(), exceptions raised by tiktoken.get_encoding("cl100k_base") are trapped and recorded via _encoding_failed = True. A single localized warning (WARN_TIKTOKEN_UNAVAILABLE) is emitted, and subsequent calls fall back to _fallback_count() without additional network retry delays.
    • Malformed Calibration Persistence: When reading llm_token_calibration.json, _load_calibration() catches FileNotFoundError silently, as well as OSError, ValueError, TypeError, and AttributeError. If the baseline counter in the file differs from CALIBRATION_COUNTER, a ValueError is raised internally and caught, logging a warning and falling back to default static priors.
    • Atomic File Updates: In _save_calibration(), data is written to a temporary file (.tmp) before replacing the target via os.replace(), preventing corrupt partial writes if the process is interrupted.
    • Ratio Outlier Rejection: In observe_prompt_tokens(), ratios outside OBSERVED_RATIO_BOUNDS (0.5 to 3.0), prompts below CALIBRATION_MIN_RAW (2,000 tokens), and responses from divergent fallback models are discarded to protect calibration state from skewed metrics.
