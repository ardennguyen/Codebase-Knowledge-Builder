    llm_anthropic.py

    Source: utils/llm_anthropic.py

    Technical Overview

    Following the internationalization and string localization workflows established in i18n.py, llm_anthropic.py serves as the native Anthropic integration driver within the codebase synthesis pipeline. It isolates all Claude-specific protocol details, API communications, and response parsers so that the upstream dispatcher call_llm.py remains vendor-agnostic. The module interfaces with the official anthropic Python SDK, handling token sizing, context window enforcement, adaptive thinking configurations, prompt caching, server-side refusal fallbacks, and real-time streaming to prevent transport timeouts during generation.

    The module provides streaming execution for single-turn requests across modern Claude model families (including Claude Opus 5.5, Fable, Mythos, Sonnet, and legacy Haiku models). Because modern reasoning models can generate up to 128,000 output tokens including internal chain-of-thought blocks, every generation is processed as an HTTP stream. The engine dynamically calculates available context space by checking local models or querying the Anthropic Models API, clamping planned output tokens to avoid overflow errors while leaving sufficient margin for complex prompts.

    A key operational feature of this driver is its layered resilience architecture. When interacting with safety classifiers or models subject to refusal boundaries, the driver injects Anthropic beta fallback headers to request automated server-side rerouting. If beta headers are rejected with an HTTP 400 Bad Request, the system disables fallback parameters for the remainder of the execution run and retries natively. Furthermore, when generation cuts short due to output token boundaries, the driver escalates token allocation to the maximum available context window ceiling and executes a one-time automated retry before wrapping any remaining truncated text in a specialized container.

    Public API

    call_anthropic()

    Visibility: Public
    Signature: def call_anthropic(prompt: str, thinking_level: str | None = None) -> str:

    Description: Sends a single-turn prompt to the resolved Anthropic Claude model via streaming and returns the completed text response. Under the hood, it tokenizes the prompt, scales it according to the codebase tokenizer ratio, calculates context boundaries, configures adaptive or budget-based reasoning, attaches server-side fallback betas, and initiates a streamed request. If the response stops because output tokens exceeded the initial budget, the function automatically retries once at the context window ceiling. It logs token usage and costs, emits diagnostics, raises exceptions on refusal, and returns either raw text or a TruncatedResponse.

    Parameters: * prompt (str): The raw text prompt destined for the model. * thinking_level (str | None, optional): Desired reasoning effort level (e.g., "low", "medium", "high", "xhigh", "max", or None). Defaults to None.

    Returns: * str: The decoded response text extracted from the message content blocks. If truncation occurred after the retry attempt, returns an instance of TruncatedResponse (which is a subclass of str).

    Raises: * LLMRefusalError: If the model declined the prompt due to content safety classifications (stop_reason == "refusal"). * anthropic.APIError: If SDK communication fails and cannot be handled by internal fallbacks.

    Phase 1: Configuration and Token Budget Resolution

        from utils.llm_config import get_token_ratio
    from utils.token_utils import count_tokens_raw

    model = get_model()
    effort = normalize_effort(model, thinking_level)
    raw_tokens = count_tokens_raw(prompt)  # tokenize once; the scaled estimate drives the budget
    max_tokens, ceiling = _resolve_max_tokens(int(raw_tokens * get_token_ratio()), model, effort)
    params, betas = _build_request(prompt, model, effort, max_tokens)
    emit_raw(
        "DEBUG",
        f"Anthropic request | model={model} | effort={effort or 'default'} | max_tokens={max_tokens:,} | "
        f"fallbacks={'on' if betas else 'off'} | prompt_cache={'on' if 'cache_control' in params else 'off'}",
        dest="LOG",
    )
    The initial phase resolves the active model identifier and normalizes the desired reasoning effort string. The input prompt is tokenized using count_tokens_raw() to establish a raw baseline token count, which is then multiplied by get_token_ratio() to account for token density differences between tiktoken and Anthropic tokenizers. With this scaled token count, _resolve_max_tokens() calculates the planned max_tokens allocation alongside the maximum absolute context ceiling. Finally, _build_request() formats the complete API payload dictionary and associated beta headers, logging the planned configuration to the debug stream.

    Phase 2: Primary Execution and Truncation Retry Escalation

        start = time.time()
    message = _send(params, betas)

    if message.stop_reason == "max_tokens" and max_tokens < ceiling:
        # Thinking + reply outgrew the budget: retry once at the largest budget that fits.
        emit("WARN_ANTHROPIC_TRUNCATED_RETRY", max_tokens=f"{max_tokens:,}", cap=f"{ceiling:,}")
        _record_usage(message, raw_tokens, effort, time.time() - start)
        params, betas = _build_request(prompt, model, effort, ceiling)
        start = time.time()
        message = _send(params, betas)

    _record_usage(message, raw_tokens, effort, time.time() - start)
    if is_debug():
        _log_thinking(message)
    The execution phase dispatches the request through _send() to initiate streaming. If generation terminates prematurely with stop_reason == "max_tokens" and the initial allocation was less than the contextual ceiling, the driver recognizes that reasoning and reply tokens exceeded the planned budget. It logs a warning, records intermediate billing metrics for the aborted attempt, rebuilds the request parameters with max_tokens expanded to the context ceiling, and executes a one-time retry. Upon receiving the final message, execution duration is logged and reasoning thoughts are recorded if debug logging is enabled.

    Phase 3: Telemetry, Refusal Handling, and Response Packaging

        if _served_by_fallback(message) and message.stop_reason != "refusal":
        count_event("ANTHROPIC", "fallbacks")
        emit("WARN_ANTHROPIC_FALLBACK_SERVED", model=model, served_by=getattr(message, "model", "unknown"))

    if message.stop_reason == "refusal":
        count_event("ANTHROPIC", "refusals")
        details = getattr(message, "stop_details", None)
        category = getattr(details, "category", None) if details else None
        emit("WARN_ANTHROPIC_REFUSAL", model=model, category=category or "unknown")
        raise LLMRefusalError(model, category, provider="ANTHROPIC")

    text = _extract_text(message)
    if message.stop_reason in _TRUNCATION_STOPS:
        count_event("ANTHROPIC", "truncations")
        emit("WARN_ANTHROPIC_TRUNCATED", max_tokens=f"{params['max_tokens']:,}")
        return TruncatedResponse(text)
    if not text:
        emit_raw("WARNING", f"Anthropic response contained no text blocks (stop_reason={message.stop_reason})", dest="LOG")
    return text
    The final phase inspects response metadata. If the message was fulfilled by an alternative server-side fallback model rather than the primary target, a fallback event is recorded and reported. If the stop reason indicates a safety refusal, refusal counters increment, refusal categories are extracted from stop_details, and an LLMRefusalError is raised to signal non-retryable rejection to upstream nodes. If the message was truncated even after retrying at the ceiling limit, a truncation counter increments and the text is returned as a TruncatedResponse instance, preventing upstream caching layers from storing incomplete outputs.

    get_model_limits()

    Visibility: Public
    Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Determines the maximum input context window and maximum allowable output tokens for a given model. It queries an in-memory memoization cache _model_limits_cache to avoid repeated remote network roundtrips. On a cache miss, it contacts the Anthropic Models API via _get_client().models.retrieve(model) to read remote limits. If the API lookup encounters an anthropic.APIError (e.g., during offline operation or permission limitations), it logs a warning and falls back to pre-configured bounds from _MODEL_LIMITS or _DEFAULT_LIMITS.

    Parameters: * model (str): The model identifier string whose limits are requested.

    Returns: * tuple[int, int]: A two-element tuple consisting of (context_window, max_output_tokens).

    Raises: * None (API errors are trapped internally and resolved using offline fallbacks).

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def get_model_limits(model: str) -> tuple[int, int]:
    """Return (context_window, max_output_tokens) from the Models API, with offline fallback."""
    if model in _model_limits_cache:
        return _model_limits_cache[model]
    fallback = next((v for k, v in _MODEL_LIMITS.items() if model.startswith(k)), _DEFAULT_LIMITS)
    try:
        info = _get_client().models.retrieve(model)
        limits = (getattr(info, "max_input_tokens", None) or fallback[0], getattr(info, "max_tokens", None) or fallback[1])
        emit_raw("DEBUG", f"Anthropic Models API | model={model} | context={limits[0]:,} | max_output={limits[1]:,}", dest="LOG")
    except anthropic.APIError as e:
        emit("WARN_ANTHROPIC_MODEL_LOOKUP", model=model, error=str(e))
        limits = fallback
    _model_limits_cache[model] = limits
    return limits
    The function combines API-driven limit discovery with defensive offline resilience. By caching limits in the module-level dictionary _model_limits_cache, it ensures that the overhead of querying the Anthropic Models API occurs at most once per model ID per process execution. When the network is unavailable or the credentials lack permission to call the Models endpoint, the system seamlessly applies predefined defaults (such as 200,000 / 64,000 tokens for Haiku 4.5 or 1,000,000 / 128,000 tokens as the global default).

    Visibility: Private
    Signature: def _get_client() -> anthropic.Anthropic:

    Description: Lazily initializes and returns the shared singleton instance of anthropic.Anthropic. The client is configured with max_retries=3 to handle transient network issues (HTTP 408, 409, 429, and 5xx) with exponential backoff beneath the orchestration layer.

    Parameters: * None.

    Returns: * anthropic.Anthropic: The initialized Anthropic client singleton.

    Raises: * anthropic.AnthropicError: If client instantiation fails due to missing or invalid credentials.

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def _get_client():
    global _client
    if _client is None:
        # SDK resolves credentials (ANTHROPIC_API_KEY / AUTH_TOKEN / ant profile) and
        # ANTHROPIC_BASE_URL itself. SDK retries 408/409/429/5xx with backoff;

The underlying SDK manages authentication token discovery across environment variables and profile stores, while the retry policy guarantees localized resilience against transient provider throttling.

    _fallback_config()

    Visibility: Private
    Signature: def _fallback_config(model: str) -> tuple[list[str], dict]:

    Description: Evaluates the ANTHROPIC_FALLBACKS environment variable and returns the appropriate beta header list and extra_body payload dictionary for server-side refusal fallbacks. If fallbacks have been globally disabled for the run (due to prior 400 Bad Request rejections) or explicitly set to "off", it returns empty structures.

    Parameters: * model (str): The model identifier string.

    Returns: * tuple[list[str], dict]: A tuple of (betas, extra_body). For default fallbacks, returns ([_FALLBACK_DEFAULT_BETA], {"fallbacks": "default"}). For custom model lists, returns ([_FALLBACK_LIST_BETA], {"fallbacks": [{"model": m}, ...]}).

    Raises: * None.

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def _fallback_config(model: str) -> tuple[list[str], dict]:
    """Return (betas, extra_body) for server-side refusal fallbacks, or empty when disabled."""
    setting = (os.getenv("ANTHROPIC_FALLBACKS") or "default").strip()
    if _fallbacks_disabled or setting.lower() == "off":
        return [], {}
    if setting.lower() == "default":
        if not _matches(model, _FALLBACK_PREFIXES):
            return [], {}
        return [_FALLBACK_DEFAULT_BETA], {"fallbacks": "default"}
    targets = [m.strip() for m in setting.split(",") if m.strip()]
    return [_FALLBACK_LIST_BETA], {"fallbacks": [{"model": m} for m in targets]}
    This helper structures server-side safety fallback configurations. When models encounter policy classifiers (such as Claude Opus 5.x and Fable 5.x), enabling Anthropic's fallback beta directs the Anthropic edge proxy to automatically redirect queries to secondary models rather than returning terminal refusal errors.

    _build_request()

    Parameters: * prompt (str): The input user prompt text. * model (str): The target model ID. * effort (str | None): The normalized thinking effort level. * max_tokens (int): Maximum allowed output tokens.

    Returns: * tuple[dict, list[str]]: A tuple containing (params, betas) where params is the request keyword arguments dictionary and betas is a list of active Anthropic beta feature strings.

    Raises: * None.

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def _build_request(prompt: str, model: str, effort: str | None, max_tokens: int) -> tuple[dict, list[str]]:
    params = {
        "model": model,
        "max_tokens": max_tokens,
        "messages": [{"role": "user", "content": prompt}],
    }
    if uses_adaptive_thinking(model):
        if effort or _matches(model, _THINKING_BY_DEFAULT_PREFIXES):
            thinking = {"type": "adaptive"}
            if is_debug():
                # Readable reasoning summaries go to the log file (never to stdout).
                thinking["display"] = "summarized"
            params["thinking"] = thinking
        if effort:
            params["output_config"] = {"effort": effort}
    elif effort:
        budget = min(_BUDGET_BY_LEVEL[effort], max_tokens - 1_024)
        if budget >= 1_024:
            params["thinking"] = {"type": "enabled", "budget_tokens": budget}

    if (os.getenv("ANTHROPIC_PROMPT_CACHE") or "off").strip().lower() == "on":
        params["cache_control"] = {"type": "ephemeral"}

    betas, extra_body = _fallback_config(model)
    if extra_body:
        params["extra_body"] = extra_body
    return params, betas
    This function isolates API parameter assembly across diverse Claude generations. For adaptive models, it configures thinking: {"type": "adaptive"} along with output_config: {"effort": effort}, enabling debug summaries if debug logging is enabled. For pre-adaptive models, it translates effort levels to explicit budget_tokens, ensuring token margins remain valid (budget >= 1024).

    _resolve_max_tokens()

    Visibility: Private
    Signature: def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:

    Description: Computes the optimal planned max_tokens budget and the absolute ceiling allowed by context limits and configuration overrides. It retrieves model limits via get_model_limits(), calculates available context room after subtracting prompt tokens and safety margins (ANTHROPIC_CONTEXT_MARGIN), and clamps output budgets to prevent context window overflow.

    Parameters: * prompt_tokens (int): Estimated prompt token count (scaled by token multiplier). * model (str): Target model identifier string. * effort (str | None): Normalized thinking effort level.

    Returns: * tuple[int, int]: A tuple of (wanted, ceiling) representing the allocated budget and the maximum context ceiling.

    Raises: * None.

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:
    context_window, output_cap = get_model_limits(model)
    cap = anthropic_output_cap()
    wanted = anthropic_planned_output(model, effort)  # same value input_token_budget reserved

    room = max(context_window - prompt_tokens - ANTHROPIC_CONTEXT_MARGIN, 4_096)
    ceiling = min(output_cap, room, cap) if cap else min(output_cap, room)
    if ceiling < wanted:
        # Small shortfalls (template overhead on a budget-packed prompt) are expected; only report real cuts.
        if ceiling < wanted * 0.9:
            emit("WARN_ANTHROPIC_OUTPUT_CLAMPED", wanted=f"{wanted:,}", available=f"{ceiling:,}")
        wanted = ceiling
    return wanted, ceiling
    The allocation algorithm balances token capacity across generation requirements. It reserves headroom defined by ANTHROPIC_CONTEXT_MARGIN to ensure prompt expansion or internal reasoning tokens do not trigger API context window errors. If the available room falls significantly short of the requested budget (ceiling < wanted * 0.9), it issues a warning before clamping the allocation.

    _stream_message()

    Visibility: Private
    Signature: def _stream_message(params: dict, betas: list[str]):

    Description: Invokes either client.beta.messages.stream() (if beta headers are provided) or standard client.messages.stream() using context managers, returning the final accumulated message object upon stream completion.

    Parameters: * params (dict): Keyword arguments passed directly to the Anthropic Messages streaming endpoint. * betas (list[str]): List of Anthropic beta feature strings.

    Returns: * anthropic.types.Message: The fully accumulated message object returned by stream.get_final_message().

    Raises: * anthropic.APIError: If network failure or API validation errors occur during streaming.

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def _stream_message(params: dict, betas: list[str]):
    client = _get_client()
    if betas:
        with client.beta.messages.stream(betas=betas, **params) as stream:
            return stream.get_final_message()
    with client.messages.stream(**params) as stream:
        return stream.get_final_message()
    By encapsulating streaming transport within context managers, this helper ensures that HTTP stream connections are cleanly consumed and terminated without socket leaks. Streaming prevents standard HTTP connection timeouts on generations that produce tens of thousands of reasoning and content tokens.

    _fallback_rejected()

    Visibility: Private
    Signature: def _fallback_rejected(error_text: str, params: dict) -> bool:

    Description: Determines whether an HTTP 400 Bad Request error from Anthropic was specifically caused by the refusal fallback feature itself (e.g., unsupported beta header, or accounts where default fallbacks are unavailable), rather than an invalid prompt or schema error.

    Parameters: * error_text (str): The error message text from the caught BadRequestError. * params (dict): The parameter dictionary used in the rejected request.

    Returns: * bool: True if the error indicates that server-side fallback headers caused the rejection; otherwise False.

    Raises: * None.

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def _fallback_rejected(error_text: str, params: dict) -> bool:
    """True when a 400 rejects the fallback feature itself (beta header not enabled, or
    `fallbacks: "default"` unsupported for this model/account) — not a user config error."""
    text = error_text.lower()
    if "anthropic-beta" in text and "server-side-fallback" in text:
        return True
    return params.get("extra_body", {}).get("fallbacks") == "default" and "fallbacks" in text
    This heuristic inspects error payloads to distinguish between genuine user configuration issues and server-side beta compatibility limitations. It searches for specific signatures indicating that beta fallback routing is not provisioned for the current API tier or model.

    _send()

    Visibility: Private
    Signature: def _send(params: dict, betas: list[str]):

    Description: Executes a streamed request via _stream_message(). If a BadRequestError occurs and _fallback_rejected() confirms that server-side fallbacks caused the failure, it permanently sets _fallbacks_disabled = True, logs a warning, removes fallback configurations from the payload, and retries the request without fallback headers.

    Parameters: * params (dict): Request parameter dictionary. * betas (list[str]): Active beta header list.

    Returns: * anthropic.types.Message: The completed response message.

    Raises: * anthropic.BadRequestError: If the 400 error is unrelated to fallback feature rejection. * anthropic.APIError: For other unrecoverable API errors.

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def _send(params: dict, betas: list[str]):
    """Send one streamed request; disable fallbacks for the run if the feature is unavailable."""
    global _fallbacks_disabled
    try:
        return _stream_message(params, betas)
    except anthropic.BadRequestError as e:
        if "extra_body" in params and _fallback_rejected(str(e), params):
            _fallbacks_disabled = True
            emit("WARN_ANTHROPIC_FALLBACK_DISABLED", error=str(e))
            retry_params = {k: v for k, v in params.items() if k != "extra_body"}
            return _stream_message(retry_params, [])
        raise
    This function implements an automated recovery loop. When an account or model rejects fallback headers, modifying the module global _fallbacks_disabled ensures that subsequent requests throughout the process skip fallback negotiation entirely, preventing repetitive failed calls.

    _price()

    Visibility: Private
    Signature: def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:

    Description: Calculates the estimated USD cost of an API call based on token consumption metrics and prefix-matched pricing rates from _PRICING. Cache write operations are billed at 1.25× the base input token price.

    Parameters: * model (str): Model identifier used to match pricing tiers. * tokens_in (int): Count of non-cached input tokens. * tokens_out (int): Count of generated output tokens. * cache_read (int): Count of input tokens read from prompt cache. * cache_write (int): Count of input tokens written to prompt cache.

    Returns: * float | None: Total estimated cost in USD, or None if the model does not match any prefix in _PRICING.

    Raises: * None.

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:
    price = next((_PRICING[k] for k in sorted(_PRICING, key=len, reverse=True) if (model or "").startswith(k)), None)
    if price is None:
        return None
    p_in, p_out, p_read = price
    return (tokens_in * p_in + tokens_out * p_out + cache_read * p_read + cache_write * p_in * 1.25) / 1_000_000
    Pricing calculations sort model prefixes by descending string length to ensure specific versions (such as claude-fable-5-1) match before broader family prefixes (claude-fable-5). Costs are calculated on a per-million token basis, incorporating cached read discounts and write surcharges.

    _message_cost()

    Visibility: Private
    Signature: def _message_cost(message, served_model: str) -> float | None:

    Description: Calculates the estimated USD cost of an entire message response. When server-side fallbacks occur, it processes per-attempt usage records stored in usage.iterations, billing each attempt at its corresponding model's rate while skipping attempts declined before output generation. For un-iterated responses, it bills according to the served model's rates.

    Parameters: * message (Any): The Anthropic message object. * served_model (str): The model ID that served the final response.

    Returns: * float | None: Aggregated USD cost, or None if any consumed model's pricing rates are unrecognized.

    Raises: * None.

    Example: 

    # Sourced directly from utils/llm_anthropic.py
def _message_cost(message, served_model: str) -> float | None:
    iterations = getattr(message.usage, "iterations", None) or []
    if iterations:
        total, known = 0.0, True
        for entry in iterations:
            tokens_in, tokens_out, cache_read, cache_write = _tokens(entry)
            if tokens_out == 0:
                continue  # declined before any output (primary or fallback attempt): not billed
            cost = _price(getattr(entry, "model", None) or served_model, tokens_in, tokens_out, cache_read, cache_write)
            known = known and cost is not None
            total += cost or 0.0
        return total if known else None
    if message.stop_reason == "refusal" and not _extract_text(message):
        return 0.0  # declined before any output: not billed
    return _price(served_model, *_tokens(message.usage))
    This calculation accurately accounts for costs in multi-model fallback sequences. When Anthropic routes a request through multiple candidate models before completing, top-level usage covers only the final attempt, while usage.iterations tracks all intermediate executions. Declined requests that yielded zero output tokens are excluded from billing calculations.

    Model Context Limits Schema (_MODEL_LIMITS, _DEFAULT_LIMITS)

    Defines offline token limit fallback configurations when the Models API cannot be reached. Represented as a tuple[int, int] corresponding to (context_window, max_output_tokens).

    Identifier Context Window Max Output Tokens Description
    "claude-haiku-4-5" 200,000 64,000 Hardcoded fallback for the Haiku 4.5 family.
    _DEFAULT_LIMITS 1,000,000 128,000 Global default fallback applied to modern Claude architectures.

    Parameter Field Type Description

    Error Handling

    The module provides defensive exception handling and recovery workflows across API interactions:

    • Remote Models API Failures (anthropic.APIError): When checking model context limits in get_model_limits(), network or authentication errors are caught. The driver logs WARN_ANTHROPIC_MODEL_LOOKUP and falls back to offline boundaries from _MODEL_LIMITS or _DEFAULT_LIMITS without crashing.
    • Server-Side Fallback Feature Rejection (anthropic.BadRequestError): When Anthropic's API returns an HTTP 400 rejecting fallback beta headers (detected via _fallback_rejected()), the module isolates the failure. It sets _fallbacks_disabled = True, logs WARN_ANTHROPIC_FALLBACK_DISABLED, strips extra_body and beta headers from the parameters, and immediately retries the request natively.
    • Context Budget Shortfalls & Output Clamping: In _resolve_max_tokens(), if available context room is below 90% of the planned output allocation (ceiling < wanted * 0.9), the module issues WARN_ANTHROPIC_OUTPUT_CLAMPED and clamps output tokens to the context boundary.
    • Premature Token Truncation Retry Escalation: In call_anthropic(), when a response ends with stop_reason == "max_tokens" and max_tokens < ceiling, the driver issues WARN_ANTHROPIC_TRUNCATED_RETRY, records the intermediate attempt's metrics, recalculates parameters using the context ceiling, and executes a one-time retry.
    • Terminal Truncation Handling (_TRUNCATION_STOPS): If a response terminates due to "max_tokens" or "model_context_window_exceeded" after retry escalation, the driver logs WARN_ANTHROPIC_TRUNCATED and returns the generated text wrapped in a TruncatedResponse instance. This prevents upstream caching layers in call_llm.py from storing incomplete output.
    • Safety Classifications and Refusals (stop_reason == "refusal"): When Claude refuses a prompt, the driver extracts classification categories from message.stop_details, increments failure counters via count_event(), issues WARN_ANTHROPIC_REFUSAL, and raises LLMRefusalError. This signals to call_llm.py and upstream workflow nodes that the request failed due to content boundaries and should not be retried.
