    llm_anthropic.py

    Source: utils/llm_anthropic.py

    Technical Overview

    utils/llm_anthropic.py is the dedicated native Anthropic (Claude) provider implementation within the LLM execution pipeline. Operating directly behind the central gateway in utils/call_llm.py, it encapsulates all Claude-specific API mechanisms, streaming lifecycles, prompt construction, adaptive reasoning configurations, and cost accounting. By isolating Anthropic-specific dependencies and protocols, the module allows the rest of the application to interact with language models through an abstract interface without forcing environments utilizing alternative providers to install the anthropic client SDK.

    The module is specifically tuned for modern Claude model families (including Claude 5 and 4.6+ series) while retaining backward compatibility for models requiring token-based budget configurations (such as Haiku 4.5). It natively implements adaptive thinking using the API's output_config.effort parameter, automatically enables optional ephemeral prompt caching, dynamically discovers context and output token boundaries via the Anthropic Models API, and coordinates server-side safety fallbacks (anthropic-beta headers) for models utilizing content classifiers. Every request is streamed to prevent HTTP timeout issues during extensive reasoning or generation cycles.

    Operational resilience and precision billing are central to the module's architecture. It implements dynamic token clamping that balances prompt size against model context windows, an automatic one-time retry mechanism that re-requests truncated completions at maximum permissible token ceilings, and a fallback disabling mechanism that gracefully recovers from rejected beta headers. Furthermore, the module tracks multi-iteration usage metrics generated by server-side fallbacks, observes runtime prompt token discrepancies for calibration against local tokenizers, and persists financial ledgers.

    get_model_limits()

    Visibility: Public

    Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Queries the Anthropic Models API via the client SDK to determine the authoritative input context window and maximum output tokens for a specified model. Results are stored in the module-level _model_limits_cache to avoid repeated remote API lookups during execution. If the API is unreachable or returns an anthropic.APIError, the function emits a warning and gracefully degrades to static offline definitions found in _MODEL_LIMITS or _DEFAULT_LIMITS.

    Parameters:

    • model (str): The model identifier being inspected.

    Returns:

    • tuple[int, int]: A two-element tuple containing (context_window, max_output_tokens).

    Raises:

    No exceptions raised externally; catches anthropic.APIError.

    Example:

    # Look up limits to calculate safe headroom for prompt and generation
context_window, output_cap = get_model_limits(model)
cap = anthropic_output_cap()
wanted = anthropic_planned_output(model, effort)

    The underlying implementation attempts remote retrieval, falling back to cached or hardcoded constants upon failure:

    def get_model_limits(model: str) -> tuple[int, int]:
    """Return (context_window, max_output_tokens) from the Models API, with offline fallback."""
    if model in _model_limits_cache:
        return _model_limits_cache[model]
    fallback = next((v for k, v in _MODEL_LIMITS.items() if model.startswith(k)), _DEFAULT_LIMITS)
    try:
        info = _get_client().models.retrieve(model)
        limits = (getattr(info, "max_input_tokens", None) or fallback[0], getattr(info, "max_tokens", None) or fallback[1])
        emit_raw("DEBUG", f"Anthropic Models API | model={model} | context={limits[0]:,} | max_output={limits[1]:,}", dest="LOG")
    except anthropic.APIError as e:
        emit("WARN_ANTHROPIC_MODEL_LOOKUP", model=model, error=str(e))
        limits = fallback
    _model_limits_cache[model] = limits
    return limits

    The method inspects the in-memory cache before initiating network communication. When invoking retrieve(), it safely inspects max_input_tokens and max_tokens attributes on the response object, falling back to preset boundaries if either property is null. Any unexpected API failure is logged via emit("WARN_ANTHROPIC_MODEL_LOOKUP"), ensuring execution continues unabated.

    def normalize_effort(model: str, level: str | None) -> str | None:
    """Map a thinking level to an effort value the model accepts (None = model default)."""
    effort = anthropic_effort(model, level)  # minimal → low; xhigh → high on the 4.6 family

    call_anthropic()

    Visibility: Public

    Signature: def call_anthropic(prompt: str, thinking_level: str | None = None) -> str:

    Description: The primary public inference entry point for executing Claude completions. Manages the full request lifecycle: resolves models and budgets, compiles request parameters and fallback beta headers, dispatches streaming completions, transparently retries output truncated by max_tokens, logs multi-iteration usage metrics, intercepts safety refusals, and extracts plain text from content blocks.

    Parameters:

    • prompt (str): The prompt payload to send to Claude.
    • thinking_level (str | None): Optional thinking intensity override (None uses model default).

    Returns:

    • str: The generated text response. If the response remains truncated after retry, returns a TruncatedResponse wrapper.

    Raises:

    • LLMRefusalError: Raised when Claude halts generation due to content safety policies (stop_reason == "refusal").

    Phase 1: Request Sizing and Payload Compilation

        model = get_model()
    effort = normalize_effort(model, thinking_level)
    raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
    max_tokens, ceiling = _resolve_max_tokens(int(raw_tokens * token_ratio()), model, effort)
    params, betas = _build_request(prompt, model, effort, max_tokens)
    emit_raw(
        "DEBUG",
        f"Anthropic request | model={model} | effort={effort or 'default'} | max_tokens={max_tokens:,} | "
        f"fallbacks={'on' if betas else 'off'} | prompt_cache={'on' if 'cache_control' in params else 'off'}",
        dest="LOG",
    )

    The invocation begins by resolving active model identifiers and normalizing reasoning effort. It retrieves the prompt's token footprint using count_tokens_raw() and scales it by the dynamic token_ratio() calibration multiplier. Using this estimated prompt size, _resolve_max_tokens() calculates the planned max_tokens allocation alongside an absolute context-safe ceiling. The method then passes these arguments into _build_request() to obtain the final message parameters and beta header arrays.

    Phase 2: Stream Execution and Dynamic Truncation Retry

        start = time.time()
    message = _send(params, betas)

    if message.stop_reason == "max_tokens" and max_tokens < ceiling:
        # Thinking + reply outgrew the budget: retry once at the largest budget that fits.
        emit("WARN_ANTHROPIC_TRUNCATED_RETRY", max_tokens=f"{max_tokens:,}", cap=f"{ceiling:,}")
        _record_usage(message, raw_tokens, effort, time.time() - start, model=model, observe=False)  # same prompt: observe once
        params, betas = _build_request(prompt, model, effort, ceiling)
        start = time.time()
        message = _send(params, betas)

    The request is dispatched over network transport via _send(), which streams the completion to avoid connection timeouts. If the model concludes processing with stop_reason == "max_tokens" and the initial max_tokens was smaller than the permissible ceiling, the system detects that thinking or response tokens exceeded planned budgets. It logs a warning, persists the partial usage to the ledger without triggering tokenizer re-calibration, re-builds the request allocating the maximum ceiling, and executes a single retry.

    Phase 3: Telemetry, Refusal Traps, and Text Extraction

        _record_usage(message, raw_tokens, effort, time.time() - start, model=model)
    if is_debug():
        _log_thinking(message)

    if _served_by_fallback(message) and message.stop_reason != "refusal":
        count_event("ANTHROPIC", "fallbacks")
        emit("WARN_ANTHROPIC_FALLBACK_SERVED", model=model, served_by=getattr(message, "model", "unknown"))

    if message.stop_reason == "refusal":
        count_event("ANTHROPIC", "refusals")
        details = getattr(message, "stop_details", None)
        category = getattr(details, "category", None) if details else None
        emit("WARN_ANTHROPIC_REFUSAL", model=model, category=category or "unknown")
        raise LLMRefusalError(model, category, provider="ANTHROPIC")

    text = _extract_text(message)
    if message.stop_reason in _TRUNCATION_STOPS:
        count_event("ANTHROPIC", "truncations")
        emit("WARN_ANTHROPIC_TRUNCATED", max_tokens=f"{params['max_tokens']:,}")
        return TruncatedResponse(text)
    if not text:
        emit_raw("WARNING", f"Anthropic response contained no text blocks (stop_reason={message.stop_reason})", dest="LOG")
    return text

    In the final phase, _record_usage() logs execution time, token metrics, and pricing across all attempts to the central ledger while passing the observed token ratio to calibration routines. If verbose debugging is enabled, _log_thinking() extracts and emits reasoning summaries to the log file. The method detects whether a server-side fallback model fulfilled the request, logs policy refusals before raising LLMRefusalError, and converts output truncated by context limits into a TruncatedResponse wrapper. If the response is valid, it concatenates and returns all text blocks.

    Visibility: Private

    _get_client()

    Visibility: Private

    Signature: def _get_client():

    Description: Lazily constructs and returns the thread-safe singleton anthropic.Anthropic client configured with a maximum retry threshold of 3 for transient network or status codes (408, 409, 429, 5xx).

    Parameters:

    None.

    Returns:

    def _get_client():
    global _client

    _fallback_config()

    Visibility: Private

    Signature: def _fallback_config(model: str) -> tuple[list[str], dict]:

    Description: Resolves the necessary anthropic-beta headers and extra_body payload parameters required to configure server-side refusal fallbacks. Checks the ANTHROPIC_FALLBACKS environment variable and the module's _fallbacks_disabled flag.

    Parameters:

    • model (str): Target model identifier string.

    Returns:

    • tuple[list[str], dict]: A pair containing a list of beta header strings and a dictionary of parameters to merge into the request's extra_body.

    Raises:

    No custom exceptions raised.

    Example:

    def _fallback_config(model: str) -> tuple[list[str], dict]:
    """Return (betas, extra_body) for server-side refusal fallbacks, or empty when disabled."""
    setting = (os.getenv("ANTHROPIC_FALLBACKS") or "default").strip()
    if _fallbacks_disabled or setting.lower() == "off":
        return [], {}
    if setting.lower() == "default":
        if not _matches(model, _FALLBACK_PREFIXES):
            return [], {}
        return [_FALLBACK_DEFAULT_BETA], {"fallbacks": "default"}
    targets = [m.strip() for m in setting.split(",") if m.strip()]
    return [_FALLBACK_LIST_BETA], {"fallbacks": [{"model": m} for m in targets]}

    When ANTHROPIC_FALLBACKS is set to "default", fallbacks are restricted to models with active classifiers defined in _FALLBACK_PREFIXES. An explicit comma-separated list enables fallbacks unconditionally for the designated secondary models using the server-side-fallback-2026-06-01 beta protocol.

    _build_request()

    Visibility: Private

    Signature: def _build_request(prompt: str, model: str, effort: str | None, max_tokens: int) -> tuple[dict, list[str]]:

    Description: Constructs the parameters dictionary and beta header list required by the Anthropic SDK message stream method. Configures adaptive thinking, output effort, budget tokens, top-level ephemeral prompt caching, and server-side fallback bodies.

    Parameters:

    • prompt (str): Text prompt content.
    • model (str): Anthropic model identifier.
    • effort (str | None): Normalized effort level string or None.
    • max_tokens (int): Maximum output tokens budget.

    Returns:

    • tuple[dict, list[str]]: A tuple containing the parameters dictionary (params) and a list of beta feature tags (betas).

    Raises:

    No custom exceptions raised.

    Example:

    def _build_request(prompt: str, model: str, effort: str | None, max_tokens: int) -> tuple[dict, list[str]]:
    params = {
        "model": model,
        "max_tokens": max_tokens,
        "messages": [{"role": "user", "content": prompt}],
    }
    if uses_adaptive_thinking(model):
        if effort or _matches(model, _THINKING_BY_DEFAULT_PREFIXES):
            thinking = {"type": "adaptive"}
            if is_debug():
                # Readable reasoning summaries go to the log file (never to stdout).
                thinking["display"] = "summarized"
            params["thinking"] = thinking
        if effort:
            params["output_config"] = {"effort": effort}
    elif effort:
        budget = min(_BUDGET_BY_LEVEL[effort], max_tokens - 1_024)
        if budget >= 1_024:
            params["thinking"] = {"type": "enabled", "budget_tokens": budget}

    if (os.getenv("ANTHROPIC_PROMPT_CACHE") or "off").strip().lower() == "on":
        params["cache_control"] = {"type": "ephemeral"}

    betas, extra_body = _fallback_config(model)
    if extra_body:
        params["extra_body"] = extra_body
    return params, betas

    The function handles multiple model generations: adaptive models receive an output_config dict and optional reasoning display settings, while older models compute an explicit budget_tokens threshold clamped between 1,024 and max_tokens - 1024. Ephemeral cache control is enabled if ANTHROPIC_PROMPT_CACHE=on.

    _resolve_max_tokens()

    Visibility: Private

    Signature: def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:

    Description: Computes the optimal generation token budget and maximum allowable token ceiling. Calculates remaining headroom inside the model's context window after subtracting prompt tokens and safety margins, and clamps output against hardware boundaries and optional configuration caps.

    Parameters:

    • prompt_tokens (int): Token count of the input prompt scaled by token ratio calibration.
    • model (str): Target model identifier string.
    • effort (str | None): Desired effort level for planned generation sizing.

    Returns:

    • tuple[int, int]: A tuple containing (wanted, ceiling), where wanted is the planned token budget and ceiling is the maximum allowable token limit that fits within the context window.

    Raises:

    No custom exceptions raised.

    Example:

    def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:
    """Return (max_tokens, ceiling): the planned budget and the largest budget allowed."""
    context_window, output_cap = get_model_limits(model)
    cap = anthropic_output_cap()
    wanted = anthropic_planned_output(model, effort)  # same value input_token_budget reserved

    room = max(context_window - prompt_tokens - ANTHROPIC_CONTEXT_MARGIN, 4_096)
    ceiling = min(output_cap, room, cap) if cap else min(output_cap, room)
    if ceiling < wanted:
        # Small shortfalls (template overhead on a budget-packed prompt) are expected; only report real cuts.
        if ceiling < wanted * 0.9:
            emit("WARN_ANTHROPIC_OUTPUT_CLAMPED", wanted=f"{wanted:,}", available=f"{ceiling:,}")
        wanted = ceiling
    return wanted, ceiling

    The calculation guarantees that room never falls below 4,096 tokens, ensuring space remains for generation even under tight context constraints. If available room forces a reduction of more than 10% below the planned output budget, it publishes a WARN_ANTHROPIC_OUTPUT_CLAMPED warning.

    _send()

    Visibility: Private

    Signature: def _send(params: dict, betas: list[str]):

    Description: High-level dispatch wrapper executing _stream_message(). If a BadRequestError indicates that server-side fallbacks are rejected by the API endpoint, it sets _fallbacks_disabled = True, logs a diagnostic warning, removes extra_body from parameters, and retries the stream without betas.

    Parameters:

    • params (dict): Parameters dictionary for the request.
    • betas (list[str]): Active beta feature flags.

    Returns:

    • anthropic.types.Message: The final accumulated API message.

    Raises:

    • anthropic.BadRequestError: Re-raised if the bad request was not caused by rejected fallback headers.
    • anthropic.APIError: Any other upstream API error.

    Example:

    def _send(params: dict, betas: list[str]):
    """Send one streamed request; disable fallbacks for the run if the feature is unavailable."""
    global _fallbacks_disabled
    try:
        return _stream_message(params, betas)
    except anthropic.BadRequestError as e:
        if "extra_body" in params and _fallback_rejected(str(e), params):
            _fallbacks_disabled = True
            emit("WARN_ANTHROPIC_FALLBACK_DISABLED", error=str(e))
            retry_params = {k: v for k, v in params.items() if k != "extra_body"}
            return _stream_message(retry_params, [])
        raise

    This helper guarantees self-healing execution: once a fallback feature rejection is detected, the run latch disables fallbacks globally to prevent redundant failing calls on subsequent requests.

    _price()

    Visibility: Private

    Signature: def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:

    Description: Calculates the monetary cost in USD for a given token breakdown based on longest-prefix matching against the _PRICING lookup table. Cache writes are billed at 1.25x the standard input token rate.

    Parameters:

    • model (str): Served model identifier.
    • tokens_in (int): Count of non-cached input tokens.
    • tokens_out (int): Count of generated output tokens.
    • cache_read (int): Count of tokens read from prompt cache.
    • cache_write (int): Count of tokens written to prompt cache.

    Returns:

    • float | None: Total cost in USD, or None if the model has no entry in _PRICING.

    Raises:

    No custom exceptions raised.

    Example:

    def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:
    price = next((_PRICING[k] for k in sorted(_PRICING, key=len, reverse=True) if (model or "").startswith(k)), None)
    if price is None:
        return None
    p_in, p_out, p_read = price
    return (tokens_in * p_in + tokens_out * p_out + cache_read * p_read + cache_write * p_in * 1.25) / 1_000_000

    Matches models using reverse length-sorted prefix matching so specific entries (e.g., claude-opus-5-5) take precedence over broader family prefixes (e.g., claude-opus-5).

    def _billed_entries(message) -> list:

    _billed_tokens()

    Visibility: Private

    Signature: def _billed_tokens(message) -> tuple[int, int, int, int, int]:

    Description: Computes the aggregated sum of tokens across all billed attempts. Combines base input, prompt cache reads, and prompt cache writes into total input.

    Parameters:

    • message: The Anthropic response Message object.

    Returns:

    • tuple[int, int, int, int, int]: A 5-tuple of (total_in, out, cache_read, cache_write, thinking) tokens.

    Raises:

    No custom exceptions raised.

    Example:

    def _billed_tokens(message) -> tuple[int, int, int, int, int]:
    """(total input incl. cache read/write, output, cache_read, cache_write, thinking) summed over the
    billed attempts (_billed_entries), so token totals match _message_cost."""
    total_in = out = cache_read = cache_write = thinking = 0
    for entry in _billed_entries(message):
        tokens_in, tokens_out, read, write = _tokens(entry)
        total_in += tokens_in + read + write
        out += tokens_out
        cache_read += read
        cache_write += write
        thinking += _thinking_tokens(entry)
    return total_in, out, cache_read, cache_write, thinking

    Ensures aggregated token values displayed in debug summaries match the financial accounting computed by _message_cost().

    _message_cost()

    Visibility: Private

    Signature: def _message_cost(message, served_model: str) -> float | None:

    Description: Calculates the estimated total USD cost of a message response. Handles both single-attempt usage and server-side fallback chains by pricing each attempt according to its specific model pricing tier.

    Parameters:

    • message: The Anthropic response Message object.
    • served_model (str): Default fallback model identifier string if an entry does not declare its own model.

    Returns:

    • float | None: Total computed cost in USD, or None if any participating model lacks pricing data.

    Raises:

    No custom exceptions raised.

    Example:

    def _message_cost(message, served_model: str) -> float | None:
    iterations = getattr(message.usage, "iterations", None) or []
    if iterations:
        total, known = 0.0, True
        for entry in iterations:
            tokens_in, tokens_out, cache_read, cache_write = _tokens(entry)
            if tokens_out == 0:
                continue  # declined before any output (primary or fallback attempt): not billed
            cost = _price(getattr(entry, "model", None) or served_model, tokens_in, tokens_out, cache_read, cache_write)
            known = known and cost is not None
            total += cost or 0.0
        return total if known else None
    if _declined_before_output(message):
        return 0.0  # declined before any output: not billed
    return _price(served_model, *_tokens(message.usage))

    Iterates over fallback attempts, verifying pricing for every model involved. If all participating models have established pricing definitions, it returns the sum of all individual costs.

    _record_usage()

    Visibility: Private

    Signature: def _record_usage(message, raw_prompt_tokens: int, effort: str | None, elapsed: float, model: str = "", observe: bool = True) -> None:

    Description: Records detailed usage statistics into the application ledger via utils.llm_common.record_usage(). Feeds observed token ratios into utils.token_utils.observe_prompt_tokens() for dynamic tokenizer calibration, and prints structured debug telemetry.

    Parameters:

    • message: The Anthropic response Message object.
    • raw_prompt_tokens (int): Input token count estimated prior to the call.
    • effort (str | None): Effort setting applied to the generation.
    • elapsed (float): Call duration in seconds.
    • model (str): Requested model string.
    • observe (bool): Whether to update tokenizer calibration with this request's observed token count. Default True.

    Returns:

    • None

    Raises:

    No custom exceptions raised.

    Example:

    def _record_usage(message, raw_prompt_tokens: int, effort: str | None, elapsed: float, model: str = "", observe: bool = True) -> None:
    from utils.token_utils import observe_prompt_tokens

    served_model = getattr(message, "model", "") or ""
    has_iterations = bool(getattr(message.usage, "iterations", None))
    entries = _billed_entries(message)
    if not entries:
        record_usage("ANTHROPIC", served_model, cost=0.0, measured=False)  # declined before any output: not billed
    # One ledger request per billed attempt (primary + fallback each billed at its own model's rate), so
    # request counts, per-request estimate deviation and the model list stay correct.
    for entry in entries:
        t_in, t_out, read, write = _tokens(entry)
        entry_model = (getattr(entry, "model", None) or served_model) if has_iterations else served_model
        record_usage(
            "ANTHROPIC",
            entry_model,
            input_tokens=t_in + read + write,
            output_tokens=t_out,
            thinking_tokens=_thinking_tokens(entry),
            cache_read=read,
            cache_write=write,
            cost=_price(entry_model, t_in, t_out, read, write) if has_iterations else _message_cost(message, served_model),
        )
    total_in, tokens_out, cache_read, cache_write, thinking = _billed_tokens(message)  # totals for the debug line
    cost = _message_cost(message, served_model)

    # Observed Claude/tiktoken ratio of the attempt that produced this message (top-level usage),
    # fed to the calibration unless another model (server-side fallback) served it.
    tokens_in, _, read, write = _tokens(message.usage)
    attempt_in = tokens_in + read + write
    ratio = attempt_in / raw_prompt_tokens if raw_prompt_tokens else 0.0
    if observe and model and not _served_by_fallback(message):
        observe_prompt_tokens("ANTHROPIC", model, raw_prompt_tokens, attempt_in, served_model=served_model)
    emit_raw(
        "DEBUG",
        f"ANTHROPIC USAGE | model={served_model} | effort={effort or 'default'} | stop={message.stop_reason} | "
        f"in={total_in:,} | out={tokens_out:,} | thinking={thinking:,} | cache_read={cache_read:,} | cache_write={cache_write:,} | "
        f"est_cost={'$' + format(cost, '.4f') if cost is not None else 'n/a'} | elapsed={elapsed:.1f}s | observed_token_ratio={ratio:.2f}",
        dest="BOTH",
    )

    The function splits usage logging across distinct entries in _billed_entries(). If fallbacks occurred, each model in the chain is accounted for at its own pricing rate. Calibration observation is conditionally suppressed if the response was fulfilled by a fallback model, preventing ratio pollution across differing tokenizers.

    Data Structures

    Model Pricing Table (_PRICING)

    Defines token pricing rates in USD per one million tokens. Matched against model names using longest-prefix evaluation.

    Field Index Name Type Description
    0 input_price float Cost per 1M non-cached input tokens.
    1 output_price float Cost per 1M generated output tokens.
    2 cache_read_price float Cost per 1M tokens read from prompt cache.

    Note: 5-minute cache writes are billed at input_price * 1.25.

    claude-opus-5 5.00 25.00 0.50 6.25
    claude-fable-5-1 10.00 50.00 0.25 12.50
    claude-fable-5 10.00 50.00 1.00 12.50
    claude-mythos-5-1 10.00 50.00 0.25 12.50
    claude-mythos-5 10.00 50.00 1.00 12.50

    Error Handling

    LLMRefusalError

    The module intercepts situations where Claude refuses a prompt due to safety policy classifications (stop_reason == "refusal"). It extracts classification metadata from message.stop_details.category and raises LLMRefusalError:

        if message.stop_reason == "refusal":
        count_event("ANTHROPIC", "refusals")
        details = getattr(message, "stop_details", None)
        category = getattr(details, "category", None) if details else None
        emit("WARN_ANTHROPIC_REFUSAL", model=model, category=category or "unknown")
        raise LLMRefusalError(model, category, provider="ANTHROPIC")

    Downstream callers in utils/call_llm.py treat LLMRefusalError as an unretryable failure and cache the refusal event to avoid repeated billing.

    Fallback Beta Incompatibility Recovery

    When server-side fallbacks are requested via anthropic-beta headers, older accounts or specific models may reject the beta header with an HTTP 400 BadRequestError. The _send() function intercepts this error, disables fallbacks globally, and retries the request transparently:

        except anthropic.BadRequestError as e:
        if "extra_body" in params and _fallback_rejected(str(e), params):
            _fallbacks_disabled = True
            emit("WARN_ANTHROPIC_FALLBACK_DISABLED", error=str(e))
            retry_params = {k: v for k, v in params.items() if k != "extra_body"}
            return _stream_message(retry_params, [])
        raise

    Context Boundary Truncation

    Truncation occurs when output terminates with stop_reason in ("max_tokens", "model_context_window_exceeded"). The module handles this in two stages:

    1. Dynamic Retry: If the initial max_tokens allocation was below the maximum permissible ceiling, it logs WARN_ANTHROPIC_TRUNCATED_RETRY and retries once allocating ceiling.
    2. Truncated Response Object: If generation remains truncated after the retry, it records the event, emits WARN_ANTHROPIC_TRUNCATED, and wraps the extracted text in a TruncatedResponse object:
        text = _extract_text(message)
    if message.stop_reason in _TRUNCATION_STOPS:
        count_event("ANTHROPIC", "truncations")
        emit("WARN_ANTHROPIC_TRUNCATED", max_tokens=f"{params['max_tokens']:,}")
        return TruncatedResponse(text)

    The TruncatedResponse return signals utils/call_llm.py that the output was prematurely severed, preventing it from being committed to the on-disk cache.
