    llm_anthropic.py

    Source: utils/llm_anthropic.py

    Following the internationalization and string management routines documented in i18n.py, the utils/llm_anthropic.py module serves as the native integration driver for Anthropic Claude models within the Codebase-Knowledge-Builder architecture. It encapsulates Claude-specific API transport, parameter normalization, thinking budget scheduling, prompt caching, server-side refusal fallbacks, and cost telemetry. By isolating provider-specific behaviors within this driver, higher-level orchestrators such as call_llm.py operate as thin dispatchers agnostic to transport nuances.

    Technical Overview

    The utils/llm_anthropic.py module establishes a robust client pipeline tuned for the Claude 5 model family (such as Sonnet 5, Opus 5.5, and Fable 5.1) while maintaining backward compatibility with Claude 4.6 and Haiku 4.5. Requests to the Anthropic Messages API are executed using streaming transport (messages.stream and beta.messages.stream), ensuring that substantial token budgets (up to 128K combined response and thinking tokens) do not terminate prematurely due to intermediate HTTP gateway timeouts. The driver automatically coordinates model capabilities, dynamically choosing between adaptive reasoning budgets for Claude 5 models and explicit budget_tokens ceilings for legacy architectures.

    The execution lifecycle integrates defensive token budgeting, proactive truncation mitigation, and resilient error recovery. Prior to request dispatch, prompt token counts are derived using tiktoken-scaled ratios and compared against context window ceilings retrieved either from the Anthropic Models API or from internal offline fallback tables. If a response exhausts its token allocation (stop_reason == "max_tokens"), the driver detects whether headroom remains under the context window and triggers a single automated retry at the maximal permissible output ceiling. If truncation persists, the payload is returned wrapped in a TruncatedResponse container, signaling upstream caches to bypass storage.

    The driver natively integrates server-side refusal fallbacks via Anthropic beta headers (server-side-fallback-2026-07-01 and server-side-fallback-2026-06-01), allowing safety classifier rejections on models like Opus 5.x and Fable 5.x to fail over seamlessly to secondary models. If an environment or account rejects the fallback header with an HTTP 400 BadRequestError, the module logs a warning, mutates runtime state to disable fallbacks for the remainder of the execution run, and retries the request without fallback parameters. Usage metrics—including input, output, cache-read, and cache-creation tokens—are parsed per call (and per fallback iteration) to record USD expenditures into centralized accounting facilities.

    Public API

    The public API consists of the functions and classes exposed for external consumption by call_llm.py and other orchestration modules. The module re-exports LLMRefusalError and TruncatedResponse from utils.llm_common in its __all__ list for backward compatibility.

    call_anthropic()

    Visibility: Public Signature: def call_anthropic(prompt: str, thinking_level: str | None = None) -> str:

    Description: The primary entry point for Anthropic Claude inference. Dispatches a single-turn prompt to the configured Anthropic model, manages streaming transport, dynamically resizes output allocations, handles truncation retries, monitors refusal events, records token usage, and returns either raw response text or a TruncatedResponse.

    The internal execution decomposes into distinct logical phases:

    Phase 1: Budget Sizing and Parameter Assembly

        from utils.llm_config import get_token_ratio
    from utils.token_utils import count_tokens_raw

    model = get_model()
    effort = normalize_effort(model, thinking_level)
    raw_tokens = count_tokens_raw(prompt)  # tokenize once; the scaled estimate drives the budget
    max_tokens, ceiling = _resolve_max_tokens(int(raw_tokens * get_token_ratio()), model, effort)
    params, betas = _build_request(prompt, model, effort, max_tokens)
    emit_raw(
        "DEBUG",
        f"Anthropic request | model={model} | effort={effort or 'default'} | max_tokens={max_tokens:,} | "
        f"fallbacks={'on' if betas else 'off'} | prompt_cache={'on' if 'cache_control' in params else 'off'}",
        dest="LOG",
    )
    The function identifies the active model from environment variables or defaults, normalizes reasoning effort strings, and calculates raw prompt token counts via count_tokens_raw(). Sizing logic computes both the planned output budget (max_tokens) and the hard ceiling permitted by the model's context window margin. Request payloads and beta headers are generated, activating ephemeral prompt caching and server-side fallback parameters if enabled.

    Phase 2: Stream Execution and Truncation Retry

        start = time.time()
    message = _send(params, betas)

    if message.stop_reason == "max_tokens" and max_tokens < ceiling:
        # Thinking + reply outgrew the budget: retry once at the largest budget that fits.
        emit("WARN_ANTHROPIC_TRUNCATED_RETRY", max_tokens=f"{max_tokens:,}", cap=f"{ceiling:,}")
        _record_usage(message, raw_tokens, effort, time.time() - start)
        params, betas = _build_request(prompt, model, effort, ceiling)
        start = time.time()
        message = _send(params, betas)
    The request is streamed to the Anthropic API via _send(). If the initial attempt cuts off prematurely (stop_reason == "max_tokens") and the initial allocation was strictly below the context ceiling, the intermediate usage is logged, a warning event is emitted, and a one-time retry is dispatched using the maximum available context ceiling.

    Phase 3: Telemetry, Refusal Trapping, and Payload Extraction

        _record_usage(message, raw_tokens, effort, time.time() - start)
    if is_debug():
        _log_thinking(message)

    if _served_by_fallback(message) and message.stop_reason != "refusal":
        count_event("ANTHROPIC", "fallbacks")
        emit("WARN_ANTHROPIC_FALLBACK_SERVED", model=model, served_by=getattr(message, "model", "unknown"))

    if message.stop_reason == "refusal":
        count_event("ANTHROPIC", "refusals")
        details = getattr(message, "stop_details", None)
        category = getattr(details, "category", None) if details else None
        emit("WARN_ANTHROPIC_REFUSAL", model=model, category=category or "unknown")
        raise LLMRefusalError(model, category, provider="ANTHROPIC")

    text = _extract_text(message)
    if message.stop_reason in _TRUNCATION_STOPS:
        count_event("ANTHROPIC", "truncations")
        emit("WARN_ANTHROPIC_TRUNCATED", max_tokens=f"{params['max_tokens']:,}")
        return TruncatedResponse(text)
    if not text:
        emit_raw("WARNING", f"Anthropic response contained no text blocks (stop_reason={message.stop_reason})", dest="LOG")
    return text
    Following message retrieval, token consumption and costs are recorded. If debug logging is enabled, intermediate reasoning thoughts are persisted to disk. The method evaluates whether server-side fallbacks fulfilled the prompt or whether a safety refusal occurred, raising an LLMRefusalError if rejected. If the stop reason indicates unresolvable truncation, the text is wrapped in TruncatedResponse to prevent disk caching; otherwise, clean string content is returned.

    Parameters: * prompt (str): The complete user prompt text to send to Claude. * thinking_level (str | None, optional): Desired reasoning effort level (low, medium, high, xhigh, max). Defaults to None.

    Returns: * str: Clean extracted text response or an instance of TruncatedResponse if the model exceeded limits.

    Raises: * LLMRefusalError: When Claude declines the request due to safety classification triggers (stop_reason == "refusal"). * anthropic.APIError: For fatal connection errors or invalid configurations unhandled by retry loops.

    get_model_limits()

    Visibility: Public Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Resolves the context window token limit and maximal output token limit for a given model string. Caches results in memory (_model_limits_cache). Queries the Anthropic Models API (client.models.retrieve()) dynamically, gracefully falling back to predefined local limits (_MODEL_LIMITS or _DEFAULT_LIMITS) if the network request fails or the endpoint is unreachable.

    Implementation: 

    def get_model_limits(model: str) -> tuple[int, int]:
    """Return (context_window, max_output_tokens) from the Models API, with offline fallback."""
    if model in _model_limits_cache:
        return _model_limits_cache[model]
    fallback = next((v for k, v in _MODEL_LIMITS.items() if model.startswith(k)), _DEFAULT_LIMITS)
    try:
        info = _get_client().models.retrieve(model)
        limits = (getattr(info, "max_input_tokens", None) or fallback[0], getattr(info, "max_tokens", None) or fallback[1])
        emit_raw("DEBUG", f"Anthropic Models API | model={model} | context={limits[0]:,} | max_output={limits[1]:,}", dest="LOG")
    except anthropic.APIError as e:
        emit("WARN_ANTHROPIC_MODEL_LOOKUP", model=model, error=str(e))
        limits = fallback
    _model_limits_cache[model] = limits
    return limits
    The method checks the _model_limits_cache dictionary using model as the lookup key. If absent, it determines a static offline tuple from _MODEL_LIMITS (matching model name prefixes) or defaults to (1_000_000, 128_000). It attempts dynamic resolution using _get_client().models.retrieve(model). Any anthropic.APIError encountered during resolution logs a WARN_ANTHROPIC_MODEL_LOOKUP warning event and assigns the static fallback tuple, writing the finalized bounds into _model_limits_cache.

    Parameters: * model (str): Anthropic model identifier string (e.g., "claude-sonnet-5", "claude-haiku-4-5").

    Returns: * tuple[int, int]: A 2-tuple of (context_window, max_output_tokens).

    Example:

cap = anthropic_output_cap()

    _fallback_config()

    Visibility: Private Signature: def _fallback_config(model: str) -> tuple[list[str], dict]:

    Description: Formulates beta header lists and extra_body payload mappings to activate server-side fallback routines on eligible models based on the ANTHROPIC_FALLBACKS environment variable.

    Implementation: 

    def _fallback_config(model: str) -> tuple[list[str], dict]:
    """Return (betas, extra_body) for server-side refusal fallbacks, or empty when disabled."""
    setting = (os.getenv("ANTHROPIC_FALLBACKS") or "default").strip()
    if _fallbacks_disabled or setting.lower() == "off":
        return [], {}
    if setting.lower() == "default":
        if not _matches(model, _FALLBACK_PREFIXES):
            return [], {}
        return [_FALLBACK_DEFAULT_BETA], {"fallbacks": "default"}
    targets = [m.strip() for m in setting.split(",") if m.strip()]
    return [_FALLBACK_LIST_BETA], {"fallbacks": [{"model": m} for m in targets]}
    The helper evaluates ANTHROPIC_FALLBACKS (defaulting to "default"). If fallbacks have been runtime-disabled via _fallbacks_disabled or explicitly set to "off", it returns empty containers. When configured to "default", it verifies whether the model matches _FALLBACK_PREFIXES (claude-opus-5, claude-fable-5), returning the beta header server-side-fallback-2026-07-01 and body {"fallbacks": "default"}. If given a custom comma-separated list of models, it returns header server-side-fallback-2026-06-01 and a structured list of target model objects.

    Parameters: * model (str): Target model name.

    Returns: * tuple[list[str], dict]: A 2-tuple containing a list of beta header flags and an extra_body parameter dictionary.

    _build_request()

    Visibility: Private Signature: def _build_request(prompt: str, model: str, effort: str | None, max_tokens: int) -> tuple[dict, list[str]]:

    Description: Builds the complete parameter dictionary and beta headers for the Anthropic Messages API, handling adaptive thinking, fixed budget tokens, prompt caching, and fallback configurations.

    Implementation: 

    def _build_request(prompt: str, model: str, effort: str | None, max_tokens: int) -> tuple[dict, list[str]]:
    params = {
        "model": model,
        "max_tokens": max_tokens,
        "messages": [{"role": "user", "content": prompt}],
    }
    if uses_adaptive_thinking(model):
        if effort or _matches(model, _THINKING_BY_DEFAULT_PREFIXES):
            thinking = {"type": "adaptive"}
            if is_debug():
                # Readable reasoning summaries go to the log file (never to stdout).
                thinking["display"] = "summarized"
            params["thinking"] = thinking
        if effort:
            params["output_config"] = {"effort": effort}
    elif effort:
        budget = min(_BUDGET_BY_LEVEL[effort], max_tokens - 1_024)
        if budget >= 1_024:
            params["thinking"] = {"type": "enabled", "budget_tokens": budget}

    if (os.getenv("ANTHROPIC_PROMPT_CACHE") or "off").strip().lower() == "on":
        params["cache_control"] = {"type": "ephemeral"}

    betas, extra_body = _fallback_config(model)
    if extra_body:
        params["extra_body"] = extra_body
    return params, betas
    Initializes the base dictionary with model, max_tokens, and the single user prompt message. If the model supports adaptive thinking, it injects thinking: {"type": "adaptive"} (adding "display": "summarized" when debug logging is enabled) and maps effort to output_config: {"effort": effort}. For legacy models with thinking enabled, it calculates an integer budget_tokens clamped to max_tokens - 1024. If ANTHROPIC_PROMPT_CACHE is enabled, it sets cache_control: {"type": "ephemeral"}. Finally, it attaches fallback headers and payload bodies from _fallback_config().

    Parameters: * prompt (str): The raw text prompt. * model (str): Target Anthropic model. * effort (str | None): Normalized effort level. * max_tokens (int): Sized output token budget.

    Returns: * tuple[dict, list[str]]: A 2-tuple containing the parameter dictionary passed to the SDK and the list of beta header strings.

    Example: 

    # Extracted from call_anthropic implementation

start = time.time()
message = _send(params, betas)

    _resolve_max_tokens()

    Visibility: Private Signature: def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:

    Description: Computes the optimal planned output token budget and the maximum context ceiling permissible for the model without exceeding context windows.

    Implementation: 

    def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:
    """Return (max_tokens, ceiling): the planned budget and the largest budget allowed.

    `prompt_tokens` comes from count_tokens() (already scaled by ANTHROPIC_TOKEN_RATIO).
    The ceiling respects the model output cap, the context window (prompt + output +
    ANTHROPIC_CONTEXT_MARGIN — the same margin input_token_budget reserves), and
    ANTHROPIC_MAX_OUTPUT_TOKENS when set.
    """
    context_window, output_cap = get_model_limits(model)
    cap = anthropic_output_cap()
    wanted = anthropic_planned_output(model, effort)  # same value input_token_budget reserved

    room = max(context_window - prompt_tokens - ANTHROPIC_CONTEXT_MARGIN, 4_096)
    ceiling = min(output_cap, room, cap) if cap else min(output_cap, room)
    if ceiling < wanted:
        # Small shortfalls (template overhead on a budget-packed prompt) are expected; only report real cuts.
        if ceiling < wanted * 0.9:
            emit("WARN_ANTHROPIC_OUTPUT_CLAMPED", wanted=f"{wanted:,}", available=f"{ceiling:,}")
        wanted = ceiling
    return wanted, ceiling
    The helper determines the context window and output capacity via get_model_limits(). It computes the remaining available space (room) after subtracting prompt tokens and safety margin (ANTHROPIC_CONTEXT_MARGIN). The hard ceiling is clamped by the model's physical output cap, available room, and any user cap defined by ANTHROPIC_MAX_OUTPUT_TOKENS. If ceiling falls below the planned output budget (wanted), the budget is clamped, emitting a WARN_ANTHROPIC_OUTPUT_CLAMPED warning if reduced by more than 10%.

    Parameters: * prompt_tokens (int): Tokenized length of the prompt, pre-scaled by token ratios. * model (str): Target model name. * effort (str | None): Normalized reasoning effort.

    Returns: * tuple[int, int]: A 2-tuple representing (max_tokens, ceiling).

    Example: 

    # Extracted from call_anthropic implementation

params, betas = _build_request(prompt, model, effort, max_tokens)

    _stream_message()

    Visibility: Private Signature: def _stream_message(params: dict, betas: list[str]) -> anthropic.types.Message:

    Description: Dispatches a streaming request over the Anthropic client and blocks until the stream completes, returning the finalized Message object.

    Implementation: 

    def _stream_message(params: dict, betas: list[str]):
    client = _get_client()
    if betas:
        with client.beta.messages.stream(betas=betas, **params) as stream:
            return stream.get_final_message()

    _price()

    Visibility: Private Signature: def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:

    Description: Calculates the estimated USD cost of an inference call based on token consumption, prompt cache read/write hits, and pricing tables matched via longest model prefix.

    Implementation: 

    def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:
    price = next((_PRICING[k] for k in sorted(_PRICING, key=len, reverse=True) if (model or "").startswith(k)), None)
    if price is None:
        return None
    p_in, p_out, p_read = price
    return (tokens_in * p_in + tokens_out * p_out + cache_read * p_read + cache_write * p_in * 1.25) / 1_000_000
    Matches model against keys in _PRICING sorted in descending order of length to ensure specialized sub-variants match before base models. Multiplies input, output, cache-read, and cache-creation tokens by their million-token rate (evaluating 5-minute cache writes at $1.25\times$ base input cost) and returns the total cost in USD. Returns None if the model has no entry in the pricing table.

    Parameters: * model (str): Served model name. * tokens_in (int): Count of non-cached prompt input tokens. * tokens_out (int): Count of generated output tokens. * cache_read (int): Count of tokens read from Anthropic prompt cache. * cache_write (int): Count of tokens written to Anthropic prompt cache.

    Returns: * float | None: Total USD expenditure, or None if unknown.

    _message_cost()

    Visibility: Private Signature: def _message_cost(message: anthropic.types.Message, served_model: str) -> float | None:

    Description: Calculates the comprehensive cost of a completed message, iterating through multiple fallback attempt blocks if present or zeroing out unbilled refusals.

    Implementation: 

    def _message_cost(message, served_model: str) -> float | None:
    """Estimated USD cost of one response. With server-side fallbacks, usage.iterations holds the
    per-attempt usage (each billed at its own model's rate; an attempt declined before any output is
    unbilled); top-level usage covers only the attempt that produced the returned message."""
    iterations = getattr(message.usage, "iterations", None) or []
    if iterations:
        total, known = 0.0, True
        for entry in iterations:
            tokens_in, tokens_out, cache_read, cache_write = _tokens(entry)
            if tokens_out == 0:
                continue  # declined before any output (primary or fallback attempt): not billed
            cost = _price(getattr(entry, "model", None) or served_model, tokens_in, tokens_out, cache_read, cache_write)
            known = known and cost is not None
            total += cost or 0.0
        return total if known else None
    if message.stop_reason == "refusal" and not _extract_text(message):
        return 0.0  # declined before any output: not billed
    return _price(served_model, *_tokens(message.usage))
    When server-side fallbacks are invoked, message.usage.iterations captures token metrics per attempt. The helper walks each iteration, skipping attempts that produced zero output tokens (which Anthropic does not bill), resolving prices based on each attempt's specific model rate. If iterations are absent and the model immediately refused without generating text, cost is evaluated as $0.00. Otherwise, top-level usage is computed via _price().

    Parameters: * message (anthropic.types.Message): The completed message object. * served_model (str): Identifier of the model that generated the final response.

    Returns: * float | None: Total cost in USD, or None if unknown.

    Example:

    "ANTHROPIC", served_model, input_tokens=tokens_in, output_tokens=tokens_out, cache_read=cache_read, cache_write=cache_write, cost=cost

    Error Handling

    The module provides defensive recovery mechanisms to manage safety refusals, token truncation, network timeouts, and rejected beta headers:

    1. Refusal Exception Escalation

    When Claude's internal safety classifiers decline to respond, the API assigns message.stop_reason = "refusal". The driver extracts the category string from message.stop_details (if present), logs a WARN_ANTHROPIC_REFUSAL warning, increments the provider refusal counter via count_event("ANTHROPIC", "refusals"), and raises an LLMRefusalError(model, category, provider="ANTHROPIC"). Upstream orchestrators in call_llm.py trap this error to memoize the failure in cache storage and prevent repeated billing.

    2. Output Budget Truncation and Retry Loop

    If a response stops with message.stop_reason == "max_tokens" and the initial max_tokens allocation was below the maximum context ceiling, the driver automatically attempts a recovery. It records the first attempt's token usage, emits WARN_ANTHROPIC_TRUNCATED_RETRY, rebuilds the request parameters with max_tokens = ceiling, and streams a second attempt. If the second attempt still terminates with a truncation stop reason ("max_tokens" or "model_context_window_exceeded"), it wraps the extracted text in a TruncatedResponse container. Upstream cache handlers check for isinstance(result, TruncatedResponse) to avoid caching truncated text.

    3. Server-Side Fallback Rejection Recovery

    Certain API accounts or models may reject server-side fallback configurations. When _send() encounters an anthropic.BadRequestError, it calls _fallback_rejected(str(e), params): 

        except anthropic.BadRequestError as e:
        if "extra_body" in params and _fallback_rejected(str(e), params):
            _fallbacks_disabled = True
            emit("WARN_ANTHROPIC_FALLBACK_DISABLED", error=str(e))
            retry_params = {k: v for k, v in params.items() if k != "extra_body"}
            return _stream_message(retry_params, [])
        raise
    If the error indicates that the fallback beta header or payload was rejected, _fallbacks_disabled is set to True to protect subsequent calls in the run. The current request is immediately retried without fallback parameters.

    4. Models API Fallback Protection

    During model limits resolution in get_model_limits(), network errors or permission boundaries can cause client.models.retrieve() to throw an anthropic.APIError. The module catches this error, emits WARN_ANTHROPIC_MODEL_LOOKUP, and falls back to static definitions in _MODEL_LIMITS or _DEFAULT_LIMITS, ensuring pipeline execution continues even when offline or behind restrictive firewalls.
