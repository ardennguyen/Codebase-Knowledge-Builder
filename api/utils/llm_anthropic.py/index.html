    llm_anthropic.py

    Source: utils/llm_anthropic.py

    Technical Overview

    The utils/llm_anthropic.py module serves as the native Anthropic Claude client integration layer for the Codebase Knowledge Builder pipeline. It encapsulates all Claude-specific request framing, configuration negotiation, response parsing, and error-recovery behaviors, allowing the higher-level dispatch layer in call_llm.py to remain provider-agnostic. By isolating the anthropic SDK dependency within this module, downstream execution environments that run alternative providers (such as Gemini or OpenRouter) can operate without installing the proprietary Anthropic client library.

    Architecturally, the module adapts to modern Claude capabilities across model families (including Claude 5, Claude 4.6, and Haiku 4.5). It natively implements adaptive thinking protocols, mapping user reasoning levels (low, medium, high, xhigh, max) to engine-compatible output configurations or token-budgeted thinking structures. To prevent HTTP connection timeouts under massive output budgets (up to 128,000 tokens), all network invocations are dispatched over streaming connections. Furthermore, the module handles safety refusal mitigations using Anthropic server-side fallback betas and executes automated single-step token budget expansion when responses are truncated by context ceilings.

    The module also acts as a precise cost accounting and token telemetry engine. It calculates financial expenditures using longest-prefix pricing rules that factor in prompt caching reads, five-minute cache writes, thinking token overheads, and per-iteration server-side fallback attempts. It feeds observed prompt token deviations back into the pipeline's runtime calibration engine, ensuring that token estimation multipliers remain synchronized with real API token counts throughout long documentation runs.

    get_model()

    Visibility: Public

    Signature: def get_model() -> str:

    Description: Resolves the active Anthropic model identifier. It inspects the ANTHROPIC_MODEL environment variable and falls back to the system default defined in DEFAULT_ANTHROPIC_MODEL (claude-sonnet-5).

    Parameters:

    None.

    Returns:

    • str: The target model name to be used for API requests.

    Raises:

    None.

    Example:

    model = get_model()
effort = normalize_effort(model, thinking_level)

    The function queries os.getenv("ANTHROPIC_MODEL") to allow runtime overrides from the environment. If the variable is unset or empty, it defaults cleanly to DEFAULT_ANTHROPIC_MODEL. This decoupling allows pipeline configurations to specify alternative Claude variants (such as claude-opus-5-5 or claude-haiku-4-5) without altering downstream code.

    if uses_adaptive_thinking(model):
    if effort or _matches(model, _THINKING_BY_DEFAULT_PREFIXES):

    get_model_limits()

    Visibility: Public

    Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Retrieves the context window and maximum output token capacity for a designated Claude model. It inspects an in-memory session cache, queries the Anthropic Models API via the SDK client if uncached, and falls back to offline default constants if the API endpoint cannot be reached or returns an error.

    Parameters:

    • model (str): The model identifier string.

    Returns:

    • tuple[int, int]: A 2-tuple containing (context_window, max_output_tokens).

    Raises:

    None. API exceptions are trapped internally, logged as warnings, and converted to offline fallback defaults.

    Example:

    # From _resolve_max_tokens implementation:
context_window, output_cap = get_model_limits(model)
cap = anthropic_output_cap()
wanted = anthropic_planned_output(model, effort)

    The function first consults _model_limits_cache to eliminate redundant network operations during sequential processing. If absent, it queries _get_client().models.retrieve(model). If the Models API returns successfully, it extracts max_input_tokens and max_tokens. In the event of an anthropic.APIError, it emits a WARN_ANTHROPIC_MODEL_LOOKUP event and extracts predefined bounds from _MODEL_LIMITS or _DEFAULT_LIMITS (1_000_000 context window, 128_000 max output tokens).

    Example:

    call_anthropic()

    Visibility: Public

    Signature: def call_anthropic(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches a single-turn prompt to the Anthropic API and returns the generated textual response. It handles token budget estimation, output clamping, streaming execution, server-side fallback detection, automatic truncation retries, cost accounting, and refusal error propagation.

    Parameters:

    • prompt (str): The prompt payload to send to Claude.
    • thinking_level (str | None, optional): The reasoning effort level requested by the caller ("low", "medium", "high", "xhigh", "max", or None). Defaults to None.

    Returns:

    • str: The generated text response. If the response was truncated by output token limits even after retry, an instance of TruncatedResponse (a subclass of str) is returned.

    Raises:

    • LLMRefusalError: Raised when the Anthropic safety classifiers decline the request (stop_reason == "refusal").

    Phase 1: Parameter Configuration and Token Budgeting

        model = get_model()
    effort = normalize_effort(model, thinking_level)
    raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
    max_tokens, ceiling = _resolve_max_tokens(int(raw_tokens * token_ratio()), model, effort)
    params, betas = _build_request(prompt, model, effort, max_tokens)
    emit_raw(
        "DEBUG",
        f"Anthropic request | model={model} | effort={effort or 'default'} | max_tokens={max_tokens:,} | "
        f"fallbacks={'on' if betas else 'off'} | prompt_cache={'on' if 'cache_control' in params else 'off'}",
        dest="LOG",
    )

    Phase 1 resolves the target model and normalizes the thinking effort level. It measures the input prompt tokens using count_tokens_raw and scales them by the runtime token ratio from token_utils. Using _resolve_max_tokens, it computes both the initial planned budget (max_tokens) and the upper hard limit (ceiling). Finally, _build_request frames the parameters dictionary and beta header list.

    Phase 2: Initial Streaming Request Dispatch

        start = time.time()
    message = _send(params, betas)

    Phase 2 initiates execution through _send. The invocation utilizes a streaming connection to prevent HTTP connection timeouts on massive context payloads. Network-level socket and transport errors are handled within the Anthropic client SDK, while beta-level 400 Bad Request rejections trigger internal fallback disabling and retries within _send.

    Phase 3: Dynamic Truncation Recovery

        if message.stop_reason == "max_tokens" and max_tokens < ceiling:
        # Thinking + reply outgrew the budget: retry once at the largest budget that fits.
        emit("WARN_ANTHROPIC_TRUNCATED_RETRY", max_tokens=f"{max_tokens:,}", cap=f"{ceiling:,}")
        _record_usage(message, raw_tokens, effort, time.time() - start, model=model, observe=False)  # same prompt: observe once
        params, betas = _build_request(prompt, model, effort, ceiling)
        start = time.time()
        message = _send(params, betas)

    Phase 3 evaluates whether the generation halted prematurely due to stop_reason == "max_tokens". If the planned max_tokens was clamped below the maximum possible ceiling, the system logs usage for the initial truncated attempt with observe=False and immediately retries the request with max_tokens expanded directly to ceiling.

    Phase 4: Usage Accounting and Telemetry Recording

        _record_usage(message, raw_tokens, effort, time.time() - start, model=model)
    if is_debug():
        _log_thinking(message)

    if _served_by_fallback(message) and message.stop_reason != "refusal":
        count_event("ANTHROPIC", "fallbacks")
        emit("WARN_ANTHROPIC_FALLBACK_SERVED", model=model, served_by=getattr(message, "model", "unknown"))

    Phase 4 records comprehensive accounting metrics for the finalized message via _record_usage. It captures input, output, cache-read, cache-creation, and thinking tokens across all attempt iterations. If debug mode is active, it logs the summarized reasoning chain. If the request was fulfilled by a fallback model, telemetry counters increment and an advisory warning emits.

    Phase 5: Refusal Verification and Text Extraction

        if message.stop_reason == "refusal":
        count_event("ANTHROPIC", "refusals")
        details = getattr(message, "stop_details", None)
        category = getattr(details, "category", None) if details else None
        emit("WARN_ANTHROPIC_REFUSAL", model=model, category=category or "unknown")
        raise LLMRefusalError(model, category, provider="ANTHROPIC")

    text = _extract_text(message)
    if message.stop_reason in _TRUNCATION_STOPS:
        count_event("ANTHROPIC", "truncations")
        emit("WARN_ANTHROPIC_TRUNCATED", max_tokens=f"{params['max_tokens']:,}")
        return TruncatedResponse(text)
    if not text:
        emit_raw("WARNING", f"Anthropic response contained no text blocks (stop_reason={message.stop_reason})", dest="LOG")
    return text

    Phase 5 examines the terminal status of the message. If safety classifiers triggered a refusal, it increments the refusal metrics, logs the refusal category, and raises an unretryable LLMRefusalError. If the response halted due to context exhaustion or token limits (_TRUNCATION_STOPS), it wraps the accumulated text in TruncatedResponse to prevent upstream caching. Otherwise, it extracts and returns the clean text response.

    Example:

    # Invocation pattern from utils/call_llm.py:
reply = call_anthropic(prompt, thinking_level=thinking_level)

    Signature: def _get_client():

    Description: Lazily initializes and returns the module-level singleton instance of anthropic.Anthropic.

    Parameters:

    None.

    Returns:

    • anthropic.Anthropic: The authenticated Anthropic client instance configured with max_retries=3.

    Raises:

    None.

    Example:

    def _get_client():
    global _client
    if _client is None:
        # SDK resolves credentials (ANTHROPIC_API_KEY / AUTH_TOKEN / ant profile) and

    This helper ensures that the Anthropic SDK client is instantiated only when an Anthropic model call is actually requested.     _fallback_config()

    Visibility: Private

    Signature: def _fallback_config(model: str) -> tuple[list[str], dict]:

    Description: Determines the server-side fallback configuration, including required beta headers and extra body payloads, based on model capabilities and environment settings.

    Parameters:

    • model (str): The primary model identifier string.

    Returns:

    • tuple[list[str], dict]: A 2-tuple containing a list of required beta headers and a dictionary containing the extra_body payload for the API request.

    Raises:

    None.

    Example:

    def _fallback_config(model: str) -> tuple[list[str], dict]:
    """Return (betas, extra_body) for server-side refusal fallbacks, or empty when disabled."""
    setting = (os.getenv("ANTHROPIC_FALLBACKS") or "default").strip()
    if _fallbacks_disabled or setting.lower() == "off":
        return [], {}
    if setting.lower() == "default":
        if not _matches(model, _FALLBACK_PREFIXES):
            return [], {}
        return [_FALLBACK_DEFAULT_BETA], {"fallbacks": "default"}
    targets = [m.strip() for m in setting.split(",") if m.strip()]
    return [_FALLBACK_LIST_BETA], {"fallbacks": [{"model": m} for m in targets]}

    The function reads the ANTHROPIC_FALLBACKS environment setting. If fallbacks are globally disabled (due to prior 400 errors) or set to "off", it returns empty structures. If set to "default", it activates _FALLBACK_DEFAULT_BETA exclusively for models in _FALLBACK_PREFIXES (Opus 5.x and Fable 5.x). If configured with an explicit comma-separated model list, it binds _FALLBACK_LIST_BETA and constructs an explicit fallback target array.

    _build_request()

    Visibility: Private

    Signature: def _build_request(prompt: str, model: str, effort: str | None, max_tokens: int) -> tuple[dict, list[str]]:

    Description: Assembles the parameter dictionary and beta header list required for the Anthropic messages API.

    Parameters:

    • prompt (str): The user prompt text.
    • model (str): The model name.
    • effort (str | None): The normalized reasoning effort level.
    • max_tokens (int): The maximum output token allocation.

    Returns:

    • tuple[dict, list[str]]: A 2-tuple of (params, betas) ready for request dispatch.

    Raises:

    None.

    Example:

    def _build_request(prompt: str, model: str, effort: str | None, max_tokens: int) -> tuple[dict, list[str]]:
    params = {
        "model": model,
        "max_tokens": max_tokens,
        "messages": [{"role": "user", "content": prompt}],
    }
    if uses_adaptive_thinking(model):
        if effort or _matches(model, _THINKING_BY_DEFAULT_PREFIXES):
            thinking = {"type": "adaptive"}
            if is_debug():
                # Readable reasoning summaries go to the log file (never to stdout).
                thinking["display"] = "summarized"
            params["thinking"] = thinking
        if effort:
            params["output_config"] = {"effort": effort}
    elif effort:
        budget = min(_BUDGET_BY_LEVEL[effort], max_tokens - 1_024)
        if budget >= 1_024:
            params["thinking"] = {"type": "enabled", "budget_tokens": budget}

    if (os.getenv("ANTHROPIC_PROMPT_CACHE") or "off").strip().lower() == "on":
        params["cache_control"] = {"type": "ephemeral"}

    betas, extra_body = _fallback_config(model)
    if extra_body:
        params["extra_body"] = extra_body
    return params, betas

    The function compiles the basic message payload and then injects reasoning configurations. For models using adaptive thinking, it injects {"type": "adaptive"} along with output_config.effort. For older models, it computes a fixed budget_tokens value using _BUDGET_BY_LEVEL. Furthermore, it appends ephemeral prompt caching headers if ANTHROPIC_PROMPT_CACHE is enabled and integrates fallback payloads generated by _fallback_config.

    _resolve_max_tokens()

    Visibility: Private

    Signature: def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:

    Description: Calculates the optimal planned max_tokens and the absolute available token ceiling given the context window, prompt length, and environment restrictions.

    Parameters:

    • prompt_tokens (int): The estimated input prompt token count.
    • model (str): The model identifier.
    • effort (str | None): The normalized effort level.

    Returns:

    • tuple[int, int]: A 2-tuple (wanted, ceiling) representing the requested token allocation and the maximum permissible token limit.

    Raises:

    None.

    Example:

    def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:
    """Return (max_tokens, ceiling): the planned budget and the largest budget allowed.

    `prompt_tokens` is the raw tiktoken count scaled by token_utils.token_ratio() (calibrated).
    The ceiling respects the model output cap, the context window (prompt + output +
    ANTHROPIC_CONTEXT_MARGIN — the same margin input_token_budget reserves), and
    ANTHROPIC_MAX_OUTPUT_TOKENS when set.
    """
    context_window, output_cap = get_model_limits(model)
    cap = anthropic_output_cap()
    wanted = anthropic_planned_output(model, effort)  # same value input_token_budget reserved

    room = max(context_window - prompt_tokens - ANTHROPIC_CONTEXT_MARGIN, 4_096)
    ceiling = min(output_cap, room, cap) if cap else min(output_cap, room)
    if ceiling < wanted:
        # Small shortfalls (template overhead on a budget-packed prompt) are expected; only report real cuts.
        if ceiling < wanted * 0.9:
            emit("WARN_ANTHROPIC_OUTPUT_CLAMPED", wanted=f"{wanted:,}", available=f"{ceiling:,}")
        wanted = ceiling
    return wanted, ceiling

    The function queries model limits and environment output caps (ANTHROPIC_MAX_OUTPUT_TOKENS). It determines available headroom by subtracting the prompt tokens and safety buffer (ANTHROPIC_CONTEXT_MARGIN) from the context window, enforcing a 4,096 token minimum. If the available ceiling truncates the desired budget by more than 10%, it emits WARN_ANTHROPIC_OUTPUT_CLAMPED to alert the user before clamping wanted to ceiling.

    _stream_message()

    Visibility: Private

    Signature: def _stream_message(params: dict, betas: list[str]):

    Description: Dispatches a streaming request through the Anthropic SDK and waits for stream completion to assemble the final message object.

    Parameters:

    • params (dict): The parameters payload for the messages API.
    • betas (list[str]): List of beta header strings required for experimental features.

    Returns:

    • anthropic.types.Message: The fully accumulated message object returned by stream.get_final_message().

    Raises:

    • anthropic.APIError: If the streaming request encounters network or API validation failures.

    Example:

    def _stream_message(params: dict, betas: list[str]):
    client = _get_client()
    if betas:
        with client.beta.messages.stream(betas=betas, **params) as stream:
            return stream.get_final_message()
    with client.messages.stream(**params) as stream:
        return stream.get_final_message()

    The function checks whether beta headers are present. If betas are supplied, it invokes client.beta.messages.stream(betas=betas, **params); otherwise, it executes client.messages.stream(**params). By using context manager streaming blocks and collecting the final message with get_final_message(), the pipeline prevents socket read timeouts even during protracted 128K generation cycles.

    _fallback_rejected()

    Visibility: Private

    Signature: def _fallback_rejected(error_text: str, params: dict) -> bool:

    Description: Analyzes an API 400 error string to verify if the failure was caused by server-side fallback incompatibility rather than malformed client parameters.

    Parameters:

    • error_text (str): The error message string returned by the API.
    • params (dict): The request parameters dictionary.

    Returns:

    • bool: True if the error reflects an unsupported or unpermitted fallback beta; otherwise False.

    Raises:

    None.

    Example:

    def _fallback_rejected(error_text: str, params: dict) -> bool:
    """True when a 400 rejects the fallback feature itself (beta header not enabled, or
    `fallbacks: "default"` unsupported for this model/account) — not a user config error."""
    text = error_text.lower()
    if "anthropic-beta" in text and "server-side-fallback" in text:
        return True
    return params.get("extra_body", {}).get("fallbacks") == "default" and "fallbacks" in text

    This helper inspects error details for specific phrases indicative of fallback beta permission or compatibility issues. If the error explicitly mentions server-side-fallback under anthropic-beta or references unsupported default fallbacks, the caller treats the failure as a provider capability mismatch rather than an application-level defect.

    _send()

    Visibility: Private

    Signature: def _send(params: dict, betas: list[str]):

    Description: Wraps message streaming with automatic fallback rejection recovery, disabling server-side fallbacks for the remainder of the execution run if rejected by the API.

    Parameters:

    • params (dict): The API parameters dictionary.
    • betas (list[str]): List of beta header strings.

    Returns:

    • anthropic.types.Message: The assembled response message object.

    Raises:

    • anthropic.BadRequestError: Re-raised if the 400 error is not related to fallback rejection.
    • anthropic.APIError: Any other network or API exception.

    Example:

    def _send(params: dict, betas: list[str]):
    """Send one streamed request; disable fallbacks for the run if the feature is unavailable."""
    global _fallbacks_disabled
    try:
        return _stream_message(params, betas)
    except anthropic.BadRequestError as e:
        if "extra_body" in params and _fallback_rejected(str(e), params):
            _fallbacks_disabled = True
            emit("WARN_ANTHROPIC_FALLBACK_DISABLED", error=str(e))
            retry_params = {k: v for k, v in params.items() if k != "extra_body"}
            return _stream_message(retry_params, [])
        raise

    The function executes _stream_message within a defensive try-except block. If an anthropic.BadRequestError occurs and _fallback_rejected evaluates to True, the function mutates the module-level _fallbacks_disabled flag to True, emits a WARN_ANTHROPIC_FALLBACK_DISABLED warning, strips extra_body from the parameter map, and retries the streaming request without beta headers.

    _price()

    Visibility: Private

    Signature: def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:

    Description: Calculates the monetary cost (in USD) for a given token usage breakdown based on model pricing tables.

    Parameters:

    • model (str): The model name or prefix.
    • tokens_in (int): Uncached input token count.
    • tokens_out (int): Output token count (including thinking tokens).
    • cache_read (int): Prompt cache read token count.
    • cache_write (int): Prompt cache creation token count.

    Returns:

    • float | None: The calculated cost in USD, or None if the model has no entry in _PRICING.

    Raises:

    None.

    Example:

    def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:
    price = next((_PRICING[k] for k in sorted(_PRICING, key=len, reverse=True) if (model or "").startswith(k)), None)
    if price is None:
        return None
    p_in, p_out, p_read = price
    return (tokens_in * p_in + tokens_out * p_out + cache_read * p_read + cache_write * p_in * 1.25) / 1_000_000

    The function matches the provided model name against _PRICING using longest-prefix matching. If matched, it extracts rates for input, output, and cache reads per million tokens. Cache creation writes are billed at 1.25x the standard input token rate. The components are summed and divided by 1,000,000 to produce the final USD cost figure.

    _billed_tokens()

    Visibility: Private

    Signature: def _billed_tokens(message) -> tuple[int, int, int, int, int]:

    Description: Aggregates token statistics across all billable attempts belonging to a message.

    Parameters:

    • message (anthropic.types.Message): The response message object.

    Returns:

    • tuple[int, int, int, int, int]: A 5-tuple representing (total_in, out, cache_read, cache_write, thinking) summed across all billable entries.

    Raises:

    None.

    Example:

    def _billed_tokens(message) -> tuple[int, int, int, int, int]:
    """(total input incl. cache read/write, output, cache_read, cache_write, thinking) summed over the
    billed attempts (_billed_entries), so token totals match _message_cost."""
    total_in = out = cache_read = cache_write = thinking = 0
    for entry in _billed_entries(message):
        tokens_in, tokens_out, read, write = _tokens(entry)
        total_in += tokens_in + read + write
        out += tokens_out
        cache_read += read
        cache_write += write
        thinking += _thinking_tokens(entry)
    return total_in, out, cache_read, cache_write, thinking

    The function iterates over _billed_entries(message) and sums uncached inputs, cache reads, cache writes, output tokens, and thinking tokens. Total input tokens include the sum of direct input, cache reads, and cache creations to reflect the true context volume evaluated across fallback attempts.

    _message_cost()

    Visibility: Private

    Signature: def _message_cost(message, served_model: str) -> float | None:

    Description: Estimates the total cost in USD for a response message, accounting for per-attempt fallback iterations at their respective model rates.

    Parameters:

    • message (anthropic.types.Message): The response message object.
    • served_model (str): The default model identifier that fulfilled the request.

    Returns:

    • float | None: Total cost in USD, or None if any participating model lacked pricing information.

    Raises:

    None.

    Example:

    def _message_cost(message, served_model: str) -> float | None:
    """Estimated USD cost of one response. With server-side fallbacks, usage.iterations holds the
    per-attempt usage (each billed at its own model's rate; an attempt declined before any output is
    unbilled); top-level usage covers only the attempt that produced the returned message."""
    iterations = getattr(message.usage, "iterations", None) or []
    if iterations:
        total, known = 0.0, True
        for entry in iterations:
            tokens_in, tokens_out, cache_read, cache_write = _tokens(entry)
            if tokens_out == 0:
                continue  # declined before any output (primary or fallback attempt): not billed
            cost = _price(getattr(entry, "model", None) or served_model, tokens_in, tokens_out, cache_read, cache_write)
            known = known and cost is not None
            total += cost or 0.0
        return total if known else None
    if _declined_before_output(message):
        return 0.0  # declined before any output: not billed
    return _price(served_model, *_tokens(message.usage))

    The function handles fallback billing dynamics where an initial attempt might run on Opus before cascading to Sonnet. It inspects message.usage.iterations, evaluating each non-zero output entry against the specific model that executed it. If any model price is unlisted in _PRICING, known switches to False and the function returns None. For single-attempt responses, it prices message.usage directly.

    _record_usage()

    Visibility: Private

    Signature: def _record_usage(message, raw_prompt_tokens: int, effort: str | None, elapsed: float, model: str = "", observe: bool = True) -> None:

    Description: Dispatches call usage metrics to the shared pipeline ledger and recalibrates the prompt token estimation multiplier.

    Parameters:

    • message (anthropic.types.Message): The response message object.
    • raw_prompt_tokens (int): Uncalibrated token count calculated prior to transmission.
    • effort (str | None): The reasoning effort level configured for the request.
    • elapsed (float): Latency in seconds.
    • model (str, optional): The requested model identifier. Defaults to "".
    • observe (bool, optional): Whether to report observed token counts to token_utils.observe_prompt_tokens. Defaults to True.

    Returns:

    None.

    Raises:

    None.

    Example:

    def _record_usage(message, raw_prompt_tokens: int, effort: str | None, elapsed: float, model: str = "", observe: bool = True) -> None:
    from utils.token_utils import observe_prompt_tokens

    served_model = getattr(message, "model", "") or ""
    has_iterations = bool(getattr(message.usage, "iterations", None))
    entries = _billed_entries(message)
    if not entries:
        record_usage("ANTHROPIC", served_model, cost=0.0, measured=False)  # declined before any output: not billed
    # One ledger request per billed attempt (primary + fallback each billed at its own model's rate), so
    # request counts, per-request estimate deviation and the model list stay correct.
    for entry in entries:
        t_in, t_out, read, write = _tokens(entry)
        entry_model = (getattr(entry, "model", None) or served_model) if has_iterations else served_model
        record_usage(
            "ANTHROPIC",
            entry_model,
            input_tokens=t_in + read + write,
            output_tokens=t_out,
            thinking_tokens=_thinking_tokens(entry),
            cache_read=read,
            cache_write=write,
            cost=_price(entry_model, t_in, t_out, read, write) if has_iterations else _message_cost(message, served_model),
        )
    total_in, tokens_out, cache_read, cache_write, thinking = _billed_tokens(message)  # totals for the debug line
    cost = _message_cost(message, served_model)

    # Observed Claude/tiktoken ratio of the attempt that produced this message (top-level usage),
    # fed to the calibration unless another model (server-side fallback) served it.
    tokens_in, _, read, write = _tokens(message.usage)
    attempt_in = tokens_in + read + write
    ratio = attempt_in / raw_prompt_tokens if raw_prompt_tokens else 0.0
    if observe and model and not _served_by_fallback(message):
        observe_prompt_tokens("ANTHROPIC", model, raw_prompt_tokens, attempt_in, served_model=served_model)
    emit_raw(
        "DEBUG",
        f"ANTHROPIC USAGE | model={served_model} | effort={effort or 'default'} | stop={message.stop_reason} | "
        f"in={total_in:,} | out={tokens_out:,} | thinking={thinking:,} | cache_read={cache_read:,} | cache_write={cache_write:,} | "
        f"est_cost={'$' + format(cost, '.4f') if cost is not None else 'n/a'} | elapsed={elapsed:.1f}s | observed_token_ratio={ratio:.2f}",
        dest="BOTH",
    )

    The function records granular usage into the shared system ledger via record_usage(). For server-side fallbacks, it records separate entries for each attempt so cost attribution and request metrics remain exact. Unless bypassed or served by a fallback model, it passes the observed token ratio to observe_prompt_tokens() to calibrate the dynamic multiplier against Claude's native BPE tokenizer. Finally, it outputs a formatted usage summary to the log.

    Error Handling

    Refusal Trapping and Propagation

    Anthropic models equipped with safety classifiers (such as Opus 5.x and Fable 5.x) may refuse a prompt rather than fulfill it. The module handles this deterministically:

    1. When server-side fallbacks are active (_FALLBACK_DEFAULT_BETA or _FALLBACK_LIST_BETA), the Anthropic infrastructure attempts to re-route refused prompts to alternative models.
    2. If all fallback models refuse or fallbacks are disabled, message.stop_reason returns "refusal".
    3. call_anthropic() catches this condition, extracts the refusal category from message.stop_details.category, records refusal metrics via count_event("ANTHROPIC", "refusals"), emits WARN_ANTHROPIC_REFUSAL, and raises LLMRefusalError(model, category, provider="ANTHROPIC").
    4. Refusals with zero output tokens are marked as unbilled in _declined_before_output(), ensuring accounting ledgers reflect $0.00 cost.

    Dynamic Truncation Recovery

    When generating exhaustive documentation chapters, responses may hit output token limits (stop_reason == "max_tokens"):

    • Single-Step Budget Retry: In call_anthropic(), if message.stop_reason == "max_tokens" and the initial budget max_tokens was smaller than the permissible ceiling, the module immediately logs the truncated attempt, updates parameter budgets to ceiling, and executes a single retry.
    • TruncatedResponse Fallback: If the retry still ends in a truncation condition (stop_reason in _TRUNCATION_STOPS), the module logs WARN_ANTHROPIC_TRUNCATED, records a truncation event via count_event, and returns the accumulated text wrapped inside TruncatedResponse(text). Downstream callers in call_llm.py inspect this type to ensure partial outputs are never committed to persistent caches.

    Server-Side Fallback Degrade

    When experimental server-side fallbacks are enabled via beta headers:

    • If an account or model rejects the fallback configuration with an HTTP 400 (BadRequestError), _send() invokes _fallback_rejected().
    • If verified as a fallback incompatibility, the module sets _fallbacks_disabled = True, logs WARN_ANTHROPIC_FALLBACK_DISABLED, strips the extra_body payload, and immediately re-executes the request as standard non-fallback streaming. All subsequent calls in the process lifetime inherit the disabled state.

    Models API Failures

    In get_model_limits(), network errors or permission issues encountered while querying client.models.retrieve() raise anthropic.APIError. The module intercepts this exception, logs WARN_ANTHROPIC_MODEL_LOOKUP, and seamlessly injects predefined limits from _MODEL_LIMITS or _DEFAULT_LIMITS, preventing network glitches during model metadata lookup from failing the pipeline.
