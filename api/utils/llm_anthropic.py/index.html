    llm_anthropic.py

    Source: utils/llm_anthropic.py

    Technical Overview

    The utils/llm_anthropic.py module implements the dedicated Anthropic Claude client adapter for the Codebase-Knowledge-Builder pipeline. While utils/call_llm.py acts as a vendor-agnostic dispatch facade, this module encapsulates all Anthropic-specific protocols, configuration quirks, context budgeting algorithms, and response processing. By isolating SDK dependencies and Claude-specific execution mechanics here, the broader codebase avoids direct coupling to the anthropic Python library, allowing runtime environments targeting alternative providers to omit the Anthropic SDK entirely.

    The adapter is engineered around the operational requirements of the Claude model family (primarily Claude 5 and 4.6+, alongside legacy support for Haiku 4.5). It natively configures adaptive thinking budgets, enforces strict token context limits using calibrated ratios, handles ephemeral prompt caching, and negotiates server-side refusal fallbacks via experimental Anthropic beta headers. Because long-running model generations and deep reasoning traces can trigger HTTP gateway timeouts, the module executes all chat completions using streamed HTTP transport via client.messages.stream, extracting the synthesized message aggregate only after transmission concludes.

    Furthermore, the module integrates directly with the pipeline's telemetry and caching contracts. It tracks multi-tier token usage across input tokens, output tokens, thinking budgets, and ephemeral cache read/write tiers, recording operational costs into the shared ledger. When requests encounter context exhaustion or safety refusals, it enforces specialized fail-soft protocols: output truncation triggers a one-time dynamic retry with expanded ceilings before yielding a TruncatedResponse, while classifier declinations are mapped directly to LLMRefusalError exceptions to prevent upstream caching.

    get_model_limits()

    Visibility: Public
    Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Retrieves the maximum context window capacity and maximum generation limit for a specified model. It queries the Anthropic Models API via the SDK client, caches the result in an in-memory dictionary, and falls back to hardcoded defaults if network or API errors occur.

    Parameters: * model (str): The model identifier string.

    Returns: * tuple[int, int]: A 2-tuple of (context_window, max_output_tokens).

    Raises: * Catches anthropic.APIError internally and falls back to static limits.

    Example: 

    def get_model_limits(model: str) -> tuple[int, int]:
    """Return (context_window, max_output_tokens) from the Models API, with offline fallback."""
    if model in _model_limits_cache:
        return _model_limits_cache[model]
    fallback = next((v for k, v in _MODEL_LIMITS.items() if model.startswith(k)), _DEFAULT_LIMITS)
    try:
        info = _get_client().models.retrieve(model)
        limits = (getattr(info, "max_input_tokens", None) or fallback[0], getattr(info, "max_tokens", None) or fallback[1])
        emit_raw("DEBUG", f"Anthropic Models API | model={model} | context={limits[0]:,} | max_output={limits[1]:,}", dest="LOG")
    except anthropic.APIError as e:
        emit("WARN_ANTHROPIC_MODEL_LOOKUP", model=model, error=str(e))
        limits = fallback
    _model_limits_cache[model] = limits
    return limits

    The function checks _model_limits_cache to eliminate redundant remote calls over the process lifetime. If the remote API endpoint is unreachable or returns an error, the function captures anthropic.APIError, emits a diagnostic warning via emit("WARN_ANTHROPIC_MODEL_LOOKUP", ...), and falls back to hardcoded prefix matches in _MODEL_LIMITS or the global default _DEFAULT_LIMITS (1_000_000, 128_000).

    def normalize_effort(model: str, level: str | None) -> str | None:

If an explicit non-empty level was supplied but failed validation, it logs a warning event containing the valid options before returning None.

    call_anthropic()

    Visibility: Public
    Signature: def call_anthropic(prompt: str, thinking_level: str | None = None) -> str:

    Description: The primary public interface for executing completions against the Anthropic API. It resolves model parameters, checks token margins, streams the generation, records telemetry, and validates stop criteria. The function operates across three distinct logical phases: Request Configuration and Sizing, Stream Execution and Truncation Retry, and Usage Accounting and Result Extraction.

    Phase 1: Request Configuration and Sizing

        model = get_model()
    effort = normalize_effort(model, thinking_level)
    raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
    max_tokens, ceiling = _resolve_max_tokens(int(raw_tokens * token_ratio()), model, effort)
    params, betas = _build_request(prompt, model, effort, max_tokens)
    emit_raw(
        "DEBUG",
        f"Anthropic request | model={model} | effort={effort or 'default'} | max_tokens={max_tokens:,} | "
        f"fallbacks={'on' if betas else 'off'} | prompt_cache={'on' if 'cache_control' in params else 'off'}",
        dest="LOG",
    )

    In this initial phase, the function determines the active model and normalized thinking effort. It estimates the prompt's raw token count via count_tokens_raw(prompt) and scales it using token_ratio() (calibrated against real Claude tokenizers). It then calls _resolve_max_tokens to calculate an output budget and hard ceiling, ensuring that the combined prompt, margin, and output fit inside the model context window. Finally, it constructs the Anthropic API parameter dictionary and beta header list.

    Phase 2: Stream Execution and Truncation Retry

        start = time.time()
    message = _send(params, betas)

    if message.stop_reason == "max_tokens" and max_tokens < ceiling:
        # Thinking + reply outgrew the budget: retry once at the largest budget that fits.
        emit("WARN_ANTHROPIC_TRUNCATED_RETRY", max_tokens=f"{max_tokens:,}", cap=f"{ceiling:,}")
        _record_usage(message, raw_tokens, effort, time.time() - start, model=model, observe=False)  # same prompt: observe once
        params, betas = _build_request(prompt, model, effort, ceiling)
        start = time.time()
        message = _send(params, betas)

    The second phase executes the streamed request via _send(). If the generation cuts off with a stop_reason of "max_tokens" and the initial budget was smaller than the allowable ceiling (max_tokens < ceiling), the function triggers an automated retry. It logs a warning, records usage for the partial first attempt without contaminating token calibration (observe=False), rebuilds the request parameters allocated to the absolute ceiling limit, and executes the stream a second time.

    Phase 3: Usage Accounting and Result Extraction

        _record_usage(message, raw_tokens, effort, time.time() - start, model=model)
    if is_debug():
        _log_thinking(message)

    if _served_by_fallback(message) and message.stop_reason != "refusal":
        count_event("ANTHROPIC", "fallbacks")
        emit("WARN_ANTHROPIC_FALLBACK_SERVED", model=model, served_by=getattr(message, "model", "unknown"))

    if message.stop_reason == "refusal":
        count_event("ANTHROPIC", "refusals")
        details = getattr(message, "stop_details", None)
        category = getattr(details, "category", None) if details else None
        emit("WARN_ANTHROPIC_REFUSAL", model=model, category=category or "unknown")
        raise LLMRefusalError(model, category, provider="ANTHROPIC")

    text = _extract_text(message)
    if message.stop_reason in _TRUNCATION_STOPS:
        count_event("ANTHROPIC", "truncations")
        emit("WARN_ANTHROPIC_TRUNCATED", max_tokens=f"{params['max_tokens']:,}")
        return TruncatedResponse(text)
    if not text:
        emit_raw("WARNING", f"Anthropic response contained no text blocks (stop_reason={message.stop_reason})", dest="LOG")
    return text

    In the final phase, the function registers the completed request metrics with the ledger via _record_usage. If debug logging is active, any reasoning blocks in the response are extracted and logged to disk. If the request was fulfilled by a fallback model, telemetry counters are updated. If the generation terminated due to safety classifier refusal, an LLMRefusalError is raised. Finally, it aggregates all text blocks; if the response remained truncated despite retries, it wraps the output in a TruncatedResponse to prevent persistent disk caching.

    Parameters: * prompt (str): The raw text prompt sent to Claude. * thinking_level (str | None, optional): Desired reasoning effort (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The synthesized output text, or a TruncatedResponse instance if generation was cut short by context limits.

    Raises: * LLMRefusalError: Raised when the Anthropic API refuses the prompt due to safety classifier policies (stop_reason == "refusal").

    Example: 

    # Real usage from call_llm.py delegating to call_anthropic
from utils.llm_anthropic import call_anthropic

response = call_anthropic("Identify architectural abstractions in this codebase.", thinking_level="high")

Module-level singletons _client, _model_limits_cache, and _fallbacks_disabled track the SDK client instance, cached model constraints, and runtime fallback flags across execution steps.

    _get_client()

    Visibility: Private
    Signature: def _get_client():

    Description: Lazily instantiates and returns the module-level Anthropic client singleton (_client), configuring internal retry handling for transient HTTP errors.

    Parameters: * None.

    Returns: * anthropic.Anthropic: The configured Anthropic SDK client instance.

    Raises: * No exceptions raised directly.

    Example: 

    def _get_client():
    global _client
    if _client is None:
        # SDK resolves credentials (ANTHROPIC_API_KEY / AUTH_TOKEN / ant profile) and
        # ANTHROPIC_BASE_URL itself. SDK retries 408/409/429/5xx with backoff;

    The helper relies on standard Anthropic SDK resolution order to locate authentication credentials (ANTHROPIC_API_KEY, ANTHROPIC_AUTH_TOKEN, or local ant auth login tokens). It configures max_retries=3 for transient gateway errors (HTTP 408, 409, 429, and 5xx), establishing a defensive baseline beneath upstream node retry logic.

    _fallback_config()

    Visibility: Private
    Signature: def _fallback_config(model: str) -> tuple[list[str], dict]:

    Description: Determines the appropriate Anthropic beta headers and extra_body payload required to activate server-side fallback routing based on environment settings and model eligibility.

    Parameters: * model (str): The model identifier.

    Returns: * tuple[list[str], dict]: A tuple of (betas, extra_body). If fallbacks are disabled or inapplicable, returns ([], {}).

    Raises: * No exceptions raised.

    Example: 

    def _fallback_config(model: str) -> tuple[list[str], dict]:
    """Return (betas, extra_body) for server-side refusal fallbacks, or empty when disabled."""
    setting = (os.getenv("ANTHROPIC_FALLBACKS") or "default").strip()
    if _fallbacks_disabled or setting.lower() == "off":
        return [], {}
    if setting.lower() == "default":
        if not _matches(model, _FALLBACK_PREFIXES):
            return [], {}
        return [_FALLBACK_DEFAULT_BETA], {"fallbacks": "default"}
    targets = [m.strip() for m in setting.split(",") if m.strip()]
    return [_FALLBACK_LIST_BETA], {"fallbacks": [{"model": m} for m in targets]}

    This function inspects ANTHROPIC_FALLBACKS. When set to "default", it checks whether the model matches _FALLBACK_PREFIXES (e.g., Opus 5.x, Fable 5.x) and assigns _FALLBACK_DEFAULT_BETA. If explicit target models are provided as a comma-delimited string, it maps them into a list structure using _FALLBACK_LIST_BETA. If fallbacks are disabled via runtime flags or set to "off", it returns empty structures.

    _build_request()

    Visibility: Private
    Signature: def _build_request(prompt: str, model: str, effort: str | None, max_tokens: int) -> tuple[dict, list[str]]:

    Description: Assembles the complete parameter payload dictionary and required beta header list for an Anthropic API call, configuring thinking profiles, ephemeral prompt caching, and fallback structures.

    Parameters: * prompt (str): The input prompt string. * model (str): The target model identifier. * effort (str | None): The normalized thinking effort setting. * max_tokens (int): The maximum output token allocation.

    Returns: * tuple[dict, list[str]]: A tuple containing the params dictionary and the list of betas headers.

    Raises: * No exceptions raised.

    Example: 

    def _build_request(prompt: str, model: str, effort: str | None, max_tokens: int) -> tuple[dict, list[str]]:
    params = {
        "model": model,
        "max_tokens": max_tokens,
        "messages": [{"role": "user", "content": prompt}],
    }
    if uses_adaptive_thinking(model):
        if effort or _matches(model, _THINKING_BY_DEFAULT_PREFIXES):
            thinking = {"type": "adaptive"}
            if is_debug():
                # Readable reasoning summaries go to the log file (never to stdout).
                thinking["display"] = "summarized"
            params["thinking"] = thinking
        if effort:
            params["output_config"] = {"effort": effort}
    elif effort:
        budget = min(_BUDGET_BY_LEVEL[effort], max_tokens - 1_024)
        if budget >= 1_024:
            params["thinking"] = {"type": "enabled", "budget_tokens": budget}

    if (os.getenv("ANTHROPIC_PROMPT_CACHE") or "off").strip().lower() == "on":
        params["cache_control"] = {"type": "ephemeral"}

    betas, extra_body = _fallback_config(model)
    if extra_body:
        params["extra_body"] = extra_body
    return params, betas

    The function handles variations in thinking across model generations. For models supporting adaptive thinking, it injects {"type": "adaptive"} along with output_config.effort. For legacy models, it calculates fixed budget_tokens from _BUDGET_BY_LEVEL. Additionally, it checks ANTHROPIC_PROMPT_CACHE to inject ephemeral cache control breakpoints and merges any fallback settings generated by _fallback_config().

    _resolve_max_tokens()

    Visibility: Private
    Signature: def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:

    Description: Calculates the requested output token budget alongside the maximum allowable ceiling that fits safely within the model's physical context window.

    Parameters: * prompt_tokens (int): Calibrated prompt token count. * model (str): Target model identifier. * effort (str | None): Normalized thinking effort level.

    Returns: * tuple[int, int]: A tuple of (wanted, ceiling). wanted is the planned token budget; ceiling is the upper limit allowed by context margins and configured caps.

    Raises: * No exceptions raised.

    Example: 

    def _resolve_max_tokens(prompt_tokens: int, model: str, effort: str | None) -> tuple[int, int]:
    context_window, output_cap = get_model_limits(model)
    cap = anthropic_output_cap()
    wanted = anthropic_planned_output(model, effort)  # same value input_token_budget reserved

    room = max(context_window - prompt_tokens - ANTHROPIC_CONTEXT_MARGIN, 4_096)
    ceiling = min(output_cap, room, cap) if cap else min(output_cap, room)
    if ceiling < wanted:
        # Small shortfalls (template overhead on a budget-packed prompt) are expected; only report real cuts.
        if ceiling < wanted * 0.9:
            emit("WARN_ANTHROPIC_OUTPUT_CLAMPED", wanted=f"{wanted:,}", available=f"{ceiling:,}")
        wanted = ceiling
    return wanted, ceiling

    The function computes the available context margin using ANTHROPIC_CONTEXT_MARGIN to ensure input prompts do not crowd out output headroom. If ceiling restricts the planned budget by more than 10% (ceiling < wanted * 0.9), it emits a diagnostic warning (WARN_ANTHROPIC_OUTPUT_CLAMPED) before clamping wanted to ceiling.

    _stream_message()

    Visibility: Private
    Signature: def _stream_message(params: dict, betas: list[str]):

    Description: Dispatches a streaming request through the Anthropic client and blocks until the stream completes, returning the aggregated final message object.

    Parameters: * params (dict): Keyword parameters for the Messages API. * betas (list[str]): List of beta feature headers.

    Returns: * anthropic.types.Message: The fully assembled final response message object.

    Raises: * anthropic.APIError: If the API request fails during transmission.

    Example: 

    def _stream_message(params: dict, betas: list[str]):
    client = _get_client()
    if betas:
        with client.beta.messages.stream(betas=betas, **params) as stream:
            return stream.get_final_message()
    with client.messages.stream(**params) as stream:
        return stream.get_final_message()

    By consuming responses through stream.get_final_message(), this function eliminates the risk of HTTP read timeouts on large reasoning models generating long thinking chains (which can exceed 64K to 128K tokens). If betas are active, it routes execution through the client.beta.messages.stream interface.

    _fallback_rejected()

    Visibility: Private
    Signature: def _fallback_rejected(error_text: str, params: dict) -> bool:

    Description: Inspects HTTP 400 Bad Request error messages to determine whether the rejection was caused by unsupported server-side fallback headers rather than invalid user parameters.

    Parameters: * error_text (str): The error message string returned by the Anthropic SDK. * params (dict): The request parameter dictionary that triggered the failure.

    Returns: * bool: True if the error reflects rejected beta fallback headers; False otherwise.

    Raises: * No exceptions raised.

    Example: 

    def _fallback_rejected(error_text: str, params: dict) -> bool:
    """True when a 400 rejects the fallback feature itself (beta header not enabled, or
    `fallbacks: "default"` unsupported for this model/account) — not a user config error."""
    text = error_text.lower()
    if "anthropic-beta" in text and "server-side-fallback" in text:
        return True
    return params.get("extra_body", {}).get("fallbacks") == "default" and "fallbacks" in text

    This verification helper inspects error payloads for occurrences of "anthropic-beta" and "server-side-fallback", or notifications indicating that "fallbacks": "default" is unsupported on the invoking account. This distinction allows the client to fall back gracefully instead of crashing on beta header rejections.

    _send()

    Visibility: Private
    Signature: def _send(params: dict, betas: list[str]):

    Description: Wraps message streaming with automatic fallback error recovery. If the API rejects fallback headers, it disables fallbacks globally for the rest of the run and immediately retries the request without them.

    Parameters: * params (dict): Request parameters. * betas (list[str]): Beta feature header strings.

    Returns: * anthropic.types.Message: The completed response message.

    Raises: * anthropic.BadRequestError: Re-raised if the 400 error is unrelated to fallback headers. * anthropic.APIError: On general API failures.

    Example: 

    def _send(params: dict, betas: list[str]):
    """Send one streamed request; disable fallbacks for the run if the feature is unavailable."""
    global _fallbacks_disabled
    try:
        return _stream_message(params, betas)
    except anthropic.BadRequestError as e:
        if "extra_body" in params and _fallback_rejected(str(e), params):
            _fallbacks_disabled = True
            emit("WARN_ANTHROPIC_FALLBACK_DISABLED", error=str(e))
            retry_params = {k: v for k, v in params.items() if k != "extra_body"}
            return _stream_message(retry_params, [])
        raise

    When an anthropic.BadRequestError is intercepted, _send invokes _fallback_rejected(). If verified, it sets the global flag _fallbacks_disabled = True, logs a warning (WARN_ANTHROPIC_FALLBACK_DISABLED), strips extra_body from the request parameters, clears the betas list, and dispatches an unadorned retry.

    _price()

    Visibility: Private
    Signature: def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:

    Description: Calculates the estimated USD cost of an API call using token counts and the pricing rates configured in _PRICING.

    Parameters: * model (str): The model identifier. * tokens_in (int): Count of non-cached input tokens. * tokens_out (int): Count of generated output tokens. * cache_read (int): Count of prompt tokens read from cache. * cache_write (int): Count of prompt tokens written to cache.

    Returns: * float | None: Total cost in USD, or None if the model does not match any prefix in _PRICING.

    Raises: * No exceptions raised.

    Example: 

    def _price(model: str, tokens_in: int, tokens_out: int, cache_read: int, cache_write: int) -> float | None:
    price = next((_PRICING[k] for k in sorted(_PRICING, key=len, reverse=True) if (model or "").startswith(k)), None)
    if price is None:
        return None
    p_in, p_out, p_read = price
    return (tokens_in * p_in + tokens_out * p_out + cache_read * p_read + cache_write * p_in * 1.25) / 1_000_000

    The matching algorithm sorts the keys of _PRICING by string length descending to ensure specific model versions (e.g., "claude-opus-5-5") match before broader base prefixes (e.g., "claude-opus-5"). Cache creation is billed at 1.25× the base input token rate, conforming to Anthropic's pricing structure for 5-minute ephemeral cache writes.

    _billed_entries()

    Visibility: Private
    Signature: def _billed_entries(message) -> list:

    Description: Identifies and returns all billable usage entries associated with a message response, accounting for server-side fallback attempts and unbilled early refusals.

    Parameters: * message: The Anthropic Message object.

    Returns: * list: A list of billable usage objects.

    Raises: * No exceptions raised.

    Example: 

    def _billed_entries(message) -> list:
    """Usage entries of the billed attempts: every usage.iterations entry with output (server-side
    fallbacks), else the top-level usage unless the request was declined before any output."""
    iterations = getattr(message.usage, "iterations", None) or []
    if iterations:
        return [entry for entry in iterations if (getattr(entry, "output_tokens", 0) or 0) > 0]
    return [] if _declined_before_output(message) else [message.usage]

    When server-side fallbacks occur, Anthropic returns per-attempt records in message.usage.iterations. This helper filters out attempts that produced zero output tokens (such as early refusals on the primary model) while retaining billable attempts. If iterations are absent, it returns the top-level usage object unless the request was declined before output.

    _billed_tokens()

    Visibility: Private
    Signature: def _billed_tokens(message) -> tuple[int, int, int, int, int]:

    Description: Computes the aggregated token totals across all billable attempts associated with a response.

    Parameters: * message: The Anthropic Message object.

    Returns: * tuple[int, int, int, int, int]: A 5-tuple containing (total_in, out, cache_read, cache_write, thinking).

    Raises: * No exceptions raised.

    Example: 

    def _billed_tokens(message) -> tuple[int, int, int, int, int]:
    """(total input incl. cache read/write, output, cache_read, cache_write, thinking) summed over the
    billed attempts (_billed_entries), so token totals match _message_cost."""
    total_in = out = cache_read = cache_write = thinking = 0
    for entry in _billed_entries(message):
        tokens_in, tokens_out, read, write = _tokens(entry)
        total_in += tokens_in + read + write
        out += tokens_out
        cache_read += read
        cache_write += write
        thinking += _thinking_tokens(entry)
    return total_in, out, cache_read, cache_write, thinking

    By summing tokens strictly across _billed_entries(message), this function ensures token counts match financial charges calculated by _message_cost. Non-cached input tokens, cache reads, and cache writes are combined to report the total input token footprint.

    _message_cost()

    Visibility: Private
    Signature: def _message_cost(message, served_model: str) -> float | None:

    Description: Calculates the overall USD cost of a response. When server-side fallbacks occur, it prices each attempt using its respective model rates.

    Parameters: * message: The Anthropic Message object. * served_model (str): The default model identifier that served the final message.

    Returns: * float | None: Total cost in USD, or None if pricing data is missing for any involved model.

    Raises: * No exceptions raised.

    Example: 

    def _message_cost(message, served_model: str) -> float | None:
    iterations = getattr(message.usage, "iterations", None) or []
    if iterations:
        total, known = 0.0, True
        for entry in iterations:
            tokens_in, tokens_out, cache_read, cache_write = _tokens(entry)
            if tokens_out == 0:
                continue  # declined before any output (primary or fallback attempt): not billed
            cost = _price(getattr(entry, "model", None) or served_model, tokens_in, tokens_out, cache_read, cache_write)
            known = known and cost is not None
            total += cost or 0.0
        return total if known else None
    if _declined_before_output(message):
        return 0.0  # declined before any output: not billed
    return _price(served_model, *_tokens(message.usage))

    This helper handles composite billing when server-side fallbacks switch models during a request. It iterates over message.usage.iterations, checks the model assigned to each attempt, skips unbilled early declinations, and accumulates charges using per-model rates.

    Data Structures

    The module defines and manipulates several internal data structures and configuration schemas.

    Pricing Rates Schema (_PRICING)

    Represents token pricing rates across supported Anthropic models. Keys are matched against the beginning of model name strings using longest-prefix matching.

    Field Index Tuple Type Name Description
    0 float input_cost_per_m Cost in USD per 1,000,000 standard input tokens.
    1 float output_cost_per_m Cost in USD per 1,000,000 generated output tokens.
    2 float cache_read_per_m Cost in USD per 1,000,000 tokens read from ephemeral cache.

    Note: Ephemeral cache creation (writes) is dynamically computed as input_cost_per_m * 1.25.

    Example mapping entry: 

    "claude-sonnet-5": (2.00, 10.00, 0.20)

    Model Limits Tuple

    Returned by get_model_limits() and cached within _model_limits_cache.

    Element Type Description
    context_window int Total physical context capacity (input + output headroom) in tokens.
    max_output int Maximum generation token cap supported by the model architecture.

    Example structure: 

    (1_000_000, 128_000)

    Anthropic Request Parameters (params)

    The dictionary constructed by _build_request() and dispatched to messages.stream.

    Key Type Description
    "model" str Model identifier string (e.g., "claude-sonnet-5").
    "max_tokens" int Allocated output ceiling for this request attempt.
    "messages" list[dict] Payload containing user input: [{"role": "user", "content": prompt}].
    "thinking" dict (optional) Thinking config ({"type": "adaptive"} or {"type": "enabled", "budget_tokens": int}).
    "output_config" dict (optional) Adaptive effort setting: {"effort": effort}.
    "cache_control" dict (optional) Set to {"type": "ephemeral"} when prompt caching is enabled.
    "extra_body" dict (optional) Fallback specifications passed via beta headers.

    Billed Tokens Breakdown

    The 5-tuple returned by _billed_tokens() summarizing token consumption across all billable attempts.

    Index Field Type Description
    0 total_in int Total input volume including regular input, cache reads, and cache writes.
    1 out int Total generated output tokens.
    2 cache_read int Subset of input tokens served from prompt cache.
    3 cache_write int Subset of input tokens written to prompt cache.
    4 thinking int Output tokens used for internal model reasoning.

    Error Handling

    The module implements defensive strategies to manage network errors, feature incompatibilities, safety refusals, and context exhaustion:

    • API Model Lookup Failures: In get_model_limits(), if _get_client().models.retrieve() fails due to an anthropic.APIError, the error is caught, logged via WARN_ANTHROPIC_MODEL_LOOKUP, and safely resolved using _MODEL_LIMITS or _DEFAULT_LIMITS (1_000_000, 128_000).
    • Beta Feature Rejection: If an account or model rejects fallback headers (server-side-fallback-*), the API responds with an HTTP 400 BadRequestError. The _send() helper catches this, invokes _fallback_rejected(), disables the feature globally for the run (_fallbacks_disabled = True), emits WARN_ANTHROPIC_FALLBACK_DISABLED, and retries without fallback headers.
    • Safety Classifier Refusals: If Claude's safety filters decline a prompt (message.stop_reason == "refusal"), the adapter logs WARN_ANTHROPIC_REFUSAL, updates refusal event counters via count_event(), and raises an LLMRefusalError. This prevents call_llm.py from caching the refusal and allows calling pipelines to handle the failure cleanly.
    • Context Window Truncation and Retry: When generation is cut off with a stop reason in _TRUNCATION_STOPS ("max_tokens" or "model_context_window_exceeded"), call_anthropic() checks if the initial budget was smaller than the available context ceiling. If headroom exists, it logs WARN_ANTHROPIC_TRUNCATED_RETRY and retries once using the full ceiling. If the response is still truncated, it wraps the output in a TruncatedResponse object, signaling upstream callers to avoid caching incomplete text.
