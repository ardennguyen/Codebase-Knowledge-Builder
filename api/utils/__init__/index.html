    utils.init

    File Path: utils/__init__.py

    Following the graph execution mechanisms established in nodes, the utils package provides specialized lower-level helper components that support file ingestion, token accounting, prompt assembly, and large language model execution.

    Technical Overview

    The utils/__init__.py file serves as the package initialization marker for the utils directory within the Codebase-Knowledge-Builder repository. In Python's package system, the presence of __init__.py marks the enclosing directory as a regular package rather than a namespace package, ensuring deterministic module resolution across diverse deployment environments and runtime configurations.

    By remaining empty, this file establishes a zero-overhead package boundary. It intentionally avoids eager re-exports or top-level symbol imports from its sibling utility modules. This architectural design yields several benefits: 1. Prevents Circular Dependencies: Submodules like utils.call_llm and utils.prompts can import shared dependencies without triggering circular initialization chains through __init__.py. 2. Eliminates Initialization Overhead: Downstream modules that require a single utility (such as utils.token_utils) do not pay the runtime or memory penalty of importing heavy third-party networking or crawling libraries (e.g., requests, google-genai). 3. Encourages Explicit Module Namespaces: Consumers must import submodules explicitly (for example, from utils.call_llm import call_llm or from utils.crawl_local_files import crawl_local_files), ensuring clear call sites and straightforward static analysis.

    Module-Level Definitions & Symbol Inventory

    # utils/__init__.py contains 0 bytes of code.

    The file defines no public or private classes, methods, functions, or package-level variables (__all__). All module features are accessed directly via individual submodule imports within the utils namespace:

    Submodule Module Path Responsibility Primary Entry Points
    call_llm utils/call_llm.py Interfaces with Google Gemini LLM via the google-genai SDK call_llm()
    crawl_github_files utils/crawl_github_files.py Crawls and fetches file contents from GitHub repositories crawl_github_files()
    crawl_local_files utils/crawl_local_files.py Recursively collects and filters local repository files crawl_local_files()
    prompts utils/prompts.py Contains system and user prompt templates for generation steps Prompt constants & template formatters
    token_utils utils/token_utils.py Computes token counts and enforces context window budget limits Token estimation & slicing functions
