    llm_openrouter.py

    Source: utils/llm_openrouter.py

    Technical Overview

    The llm_openrouter.py module implements the OpenRouter integration layer for the Codebase Knowledge Builder pipeline. It encapsulates request serialization, streaming network transport, Server-Sent Events (SSE) parsing, error classification, and multi-dimensional token and cost accounting. Designed around an OpenAI-compatible chat completions interface, the module dynamically adapts request schemas using OpenRouter's remote model catalog rather than relying on static, hardcoded provider configurations. This architecture allows the pipeline to interface seamlessly with upstream models from Anthropic, Google, Meta, and others through a single unified gateway.

    The module resolves key operational challenges in Large Language Model (LLM) communications. To support varying provider capabilities, it inspects catalog metadata to negotiate reasoning parameters—converting abstract pipeline thinking tiers into either categorical reasoning effort strings (reasoning.effort) or discrete token limits (reasoning.max_tokens), while automatically stripping sampling temperatures for models that disallow them. Transport reliability is maintained through streaming SSE connections that eliminate socket read timeouts during protracted generation cycles. Furthermore, an adaptive retry mechanism with exponential backoff handles transient network anomalies and upstream rate limits based on HTTP Retry-After headers.

    Response handling provides defensive stream decoding and deterministic error categorization. Incoming byte streams are split and decoded per line to prevent text corruption from Unicode line break characters like U+2028 or U+0085. Termination states are evaluated through upstream finish reasons: token limit exhaustion yields a non-cacheable TruncatedResponse, policy violations and content blocks trigger retryable or non-retryable LLMRefusalError exceptions, and incomplete or malformed streams raise standard runtime errors. Finally, billing metrics—including prompt tokens, output completion, reasoning tokens, prompt caching, and "Bring Your Own Key" (BYOK) upstream inference fees—are recorded into the global telemetry ledger and used to calibrate tokenizer ratios dynamically.

    build_payload()

    Visibility: Public

    Signature: def build_payload(prompt: str, model: str, level: str | None, prompt_tokens: int) -> tuple[dict, str]:

    Description: Compiles the complete OpenAI-compatible JSON request payload for OpenRouter. It resolves catalog-driven capabilities for the target model, calculates output token limits based on remaining context space, adapts reasoning configurations according to supported effort schemas, and conditionally applies temperature settings.

    Parameters:

    • prompt (str): The user prompt text to send to the model.
    • model (str): The model identifier string.
    • level (str | None): The requested abstract thinking level (e.g., "low", "medium", "high"), or None to omit reasoning.
    • prompt_tokens (int): The estimated prompt token length, used to clamp maximum completion tokens within the model's context window.

    Returns:

    • tuple[dict, str]: A 2-tuple containing:
      • dict: The serialized JSON request payload containing model, messages, stream, and optional max_tokens, reasoning, and temperature fields.
      • str: A human-readable diagnostic description of the applied reasoning configuration (e.g., "effort=high" or "reasoning.max_tokens=8192").

    Example:

    raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
payload, desc = build_payload(prompt, model, thinking_level, int(raw_tokens * token_ratio()))
headers = {"Content-Type": "application/json", **_attribution_headers()}

    The function constructs the standard messages array with a single user turn and forces stream: True. It queries helper functions _max_tokens(), _reasoning(), and _sends_temperature() to ensure that provider-incompatible parameters (such as sending temperatures to reasoning models) are omitted from the wire format.

    call_openrouter()

    Visibility: Public

    Signature: def call_openrouter(prompt: str, thinking_level: str | None = None) -> str:

    Description: Coordinates the complete single-turn prompt execution cycle against the OpenRouter completions endpoint. It handles environment validation, prompt token estimation, payload construction, streaming HTTP communication with bounded retries, SSE parsing, cost and token telemetry tracking, and upstream termination categorization.

    Parameters:

    • prompt (str): The prompt string to execute.
    • thinking_level (str | None, optional): The desired reasoning depth tier (e.g., "low", "medium", "high", "max"). Defaults to None.

    Returns:

    • str: The completion text generated by the model. If the response was truncated due to output token boundaries, an instance of TruncatedResponse (a str subclass) is returned instead.

    Raises:

    • ValueError: When the OPENROUTER_MODEL environment variable is missing or empty.
    • RuntimeError: When network requests fail after reaching maximum retry attempts, when streams terminate without a finish reason, or when an error chunk is returned by the upstream provider.
    • LLMRefusalError: When the upstream provider rejects the prompt or terminates the generation due to safety violations, moderation rules, or content filters.

    Phase 1: Context & Payload Preparation

        from utils.token_utils import count_tokens_raw, token_ratio

    model = get_model()
    if not model:
        raise ValueError("OPENROUTER_MODEL environment variable is required")
    api_key = os.getenv("OPENROUTER_API_KEY", "").strip()
    raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
    payload, desc = build_payload(prompt, model, thinking_level, int(raw_tokens * token_ratio()))
    headers = {"Content-Type": "application/json", **_attribution_headers()}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"
    max_tokens = payload.get("max_tokens")
    emit_raw(
        "DEBUG",
        f"OpenRouter request | model={model} | {desc} | max_tokens={f'{max_tokens:,}' if max_tokens else 'omitted'} | "
        f"temperature={payload.get('temperature', 'omitted')} | catalog={'yes' if openrouter_catalog() else 'no'} | "
        f"attribution={'on' if 'HTTP-Referer' in headers else 'off'}",
        dest="LOG",
    )

    In this initial phase, the function ensures the OPENROUTER_MODEL environment variable is defined and estimates token costs using token_utils.count_tokens_raw(). It scales the token count by the current runtime token_ratio() to derive accurate input reservations. The JSON payload is generated via build_payload(), and request headers are compiled with optional Bearer token authentication and app attribution metadata. Diagnostic logs capture parameter configurations, catalog availability, and header settings.

    Phase 2: HTTP Execution and Stream Initialization

        start = time.time()
    resp = _post(f"{openrouter_base_url()}/v1/chat/completions", headers, payload)
    generation_id = resp.headers.get("X-Generation-Id")

    The function captures the start timestamp and initiates a streaming HTTP POST request to the resolved completions endpoint via _post(). It extracts the X-Generation-Id header from the response stream, providing an OpenRouter generation identifier for subsequent debugging and log tracking.

    Phase 3: Stream Consumption and Metric Recording

        try:
        result = _consume(resp)
    except Exception:
        # An error chunk mid-stream ("Upstream idle timeout exceeded") still was a request: unmeasured, like a
        # dropped stream, so a failed attempt and its retry both show in the usage ledger
        record_usage("OPENROUTER", model, cost=None, measured=False)
        emit_raw("DEBUG", f"OPENROUTER USAGE | model={model} | stream error, no usage reported | generation_id={generation_id or 'n/a'}", dest="BOTH")
        raise
    _record(model, result, raw_tokens, desc, time.time() - start, generation_id)
    if is_debug() and result["reasoning"]:
        emit_raw("DEBUG", f"REASONING:\n{result['reasoning']}", dest="LOG")

    Stream consumption is delegated to _consume(), which processes incoming SSE data chunks into an aggregated dictionary. If an exception occurs during streaming (such as an upstream idle timeout or a dropped socket), an unmeasured usage event is recorded via record_usage() so failed attempts appear in the pipeline accounting ledger before re-raising the exception. Upon clean completion, _record() parses usage metrics, logs generation statistics, and registers prompt token counts to calibrate token conversion ratios. If debug mode is active, intermediate reasoning text is written to the diagnostic log stream.

    Phase 4: Response Evaluation, Refusals, and Truncation Handling

        finish, native = (result["finish"] or ""), (result["native"] or "")
    if finish == "error":
        raise RuntimeError(f"OpenRouter generation ended with an error (native_finish_reason={native or 'n/a'})")
    if finish == "content_filter" or result["refusal"] or native.lower() in _REFUSAL_NATIVE_REASONS:
        category = native or finish or "refusal"
        # Filters on sampled output (safety, recitation, content_filter) may pass on another attempt.
        retryable = not result["refusal"] and native.lower() not in _DETERMINISTIC_NATIVE_REASONS
        count_event("OPENROUTER", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="OpenRouter", model=model, category=category)
        raise LLMRefusalError(model, category, provider="OPENROUTER", retryable=retryable)
    if not finish:
        # No data at all, or the connection dropped mid-answer: never return a partial reply.
        raise RuntimeError(
            f"OpenRouter stream ended without a finish_reason after {result['events']} events ({len(result['text']):,} characters received)"
        )
    if finish == "length":
        count_event("OPENROUTER", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="OpenRouter", max_tokens=f"{max_tokens:,}" if max_tokens else "default")
        return TruncatedResponse(result["text"])
    if not result["text"]:
        emit_raw("WARNING", f"OpenRouter response contained no text (finish_reason={finish or 'n/a'})", dest="LOG")
    return result["text"]

    The concluding phase inspects both standard and native finish reasons. If a terminal error or policy refusal is detected, the function distinguishes between deterministic blocks (which short-circuit future attempts) and stochastic content filter blocks (marked retryable=True), raising an LLMRefusalError. If the connection terminated prematurely without providing a finish reason, a RuntimeError is raised to prevent partial data corruption. When finish == "length", the text is wrapped in a TruncatedResponse instance to signal token exhaustion and bypass downstream disk caching. Otherwise, the raw text content is returned.

    _reasoning()

    Visibility: Private

    Signature: def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:

    Description: Evaluates model catalog metadata to construct an appropriate reasoning configuration dictionary and human-readable diagnostic description.

    Parameters:

    • model (str): The model identifier.
    • info (dict | None): Catalog metadata dictionary for the model from openrouter_model_info().
    • level (str | None): The requested reasoning level string.
    • max_tokens (int | None, optional): The maximum token budget computed for the completion. Defaults to None.

    Returns:

    • tuple[dict | None, str]: A 2-tuple containing the reasoning payload dictionary (or None if disabled/unsupported) and a status description string.

    Example:

    def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:
    """(reasoning payload | None, description)."""
    if not level:
        return None, "default"
    level = level.lower()
    exclude = not is_debug()
    if info is None:
        # Catalog unavailable or model unknown: send the level; OpenRouter clamps server-side.
        return {"effort": level, "exclude": exclude}, f"effort={level} (unverified)"
    reasoning = info.get("reasoning")
    if not isinstance(reasoning, dict) and "reasoning" not in (info.get("supported_parameters") or []):
        if warn_once("openrouter_no_reasoning", model):
            emit("WARN_THINKING_NOT_SUPPORTED", model=model)
        return None, "unsupported"
    meta = reasoning if isinstance(reasoning, dict) else {}
    if "supported_efforts" not in meta and meta.get("supports_max_tokens"):
        # Budget-only model: an explicit thinking budget (OpenRouter's effort ratio of a large
        # max_tokens would over-spend). It must stay below max_tokens.
        budget = _REASONING_BUDGETS.get(level, _REASONING_BUDGETS["medium"])
        if max_tokens:
            budget = max(min(budget, max_tokens - 1_024), 1_024)
        return {"max_tokens": budget, "exclude": exclude}, f"reasoning.max_tokens={budget}"
    efforts = meta.get("supported_efforts")
    effort = level
    if efforts:
        effort = clamp_level(level, [e for e in efforts if e != "none"]) or level
        if effort != level and warn_once("openrouter_level", model, level):
            emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effort, model=model)
    return {"effort": effort, "exclude": exclude}, f"effort={effort}"

    The function checks whether the target model supports categorical efforts or explicit token budgets. For models supporting explicit budgets (supports_max_tokens), it calculates a budget from _REASONING_BUDGETS and ensures it does not exceed the total completion limit. For models supporting discrete effort lists, it invokes clamp_level() to prevent passing unsupported effort levels (such as "none" on mandatory reasoning architectures) that cause HTTP 400 errors.

    _max_tokens()

    Visibility: Private

    Signature: def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:

    Description: Calculates the maximum completion token limit for a request, clamping the planned output budget to the remaining context window after accounting for prompt tokens and context safety margins.

    Parameters:

    • model (str): The model identifier.
    • info (dict | None): Catalog metadata for the model.
    • level (str | None): The active thinking level.
    • prompt_tokens (int): Estimated number of tokens in the prompt.

    Returns:

    • int | None: Clamped token budget integer, or None if the model limits cannot be determined from the catalog.

    Example:

    def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:
    """Planned max_tokens clamped to the context left after the prompt; None = omit (unknown model)."""
    planned = openrouter_output_budget(model, level)
    context = ((info or {}).get("top_provider") or {}).get("context_length") or (info or {}).get("context_length")
    if planned and context:
        planned = min(planned, max(context - prompt_tokens - CONTEXT_MARGIN, 4_096))
    return planned

    The helper prevents prompt context overflow by evaluating top_provider.context_length or base context_length. It reserves a margin defined by CONTEXT_MARGIN while ensuring a baseline minimum output window of 4,096 tokens when context space allows.

    _refusal_category()

    Visibility: Private

    Signature: def _refusal_category(resp) -> str | None:

    Description: Inspects an HTTP 403 response to determine whether the status signifies an upstream moderation block, safety trigger, or content policy refusal.

    Parameters:

    • resp: The HTTP response object.

    Returns:

    • str | None: The identified refusal category string, or None if the 403 response does not represent a recognized policy refusal.

    Example:

    def _refusal_category(resp) -> str | None:
    """Category when an HTTP 403 is a moderation / guardrail / upstream refusal, else None."""
    if resp.status_code != 403:
        return None
    err = _error_body(resp)
    meta = err.get("metadata") or {}
    kind = str(err.get("type") or err.get("error_type") or meta.get("error_type") or "").lower()
    if kind in _REFUSAL_ERROR_TYPES:
        return kind
    if meta.get("reasons") or meta.get("flagged_input"):

        return ",".join(map(str, reasons)) if isinstance(reasons, list) else str(reasons)
    return None

    The function checks response error types against _REFUSAL_ERROR_TYPES and checks metadata dictionaries for moderation flags or specific trigger reason arrays, converting them into a comma-delimited classification string.

    _post()

    Visibility: Private

    Signature: def _post(url: str, headers: dict, payload: dict):

    Description: Dispatches an HTTP POST request with streaming enabled, managing automated retries with exponential backoff on transient network faults and rate limits.

    Parameters:

    • url (str): Target endpoint URL.
    • headers (dict): Request headers dictionary.
    • payload (dict): JSON request payload.

    Returns:

    • requests.Response: An open streaming response object.

    Raises:

    • LLMRefusalError: When an HTTP 403 response corresponds to a policy or moderation refusal.
    • RuntimeError: When requests fail repeatedly up to _MAX_ATTEMPTS, or when an unhandled HTTP 4xx/5xx error occurs.

    Example:

    def _post(url: str, headers: dict, payload: dict):
    """POST with bounded retries on transient failures; returns an open streaming response."""
    for attempt in range(1, _MAX_ATTEMPTS + 1):
        try:
            resp = requests.post(url, headers=headers, json=payload, stream=True, timeout=(15, _read_timeout()))
        except (requests.exceptions.ConnectionError, requests.exceptions.Timeout) as e:
            if attempt == _MAX_ATTEMPTS:
                raise RuntimeError(f"OpenRouter request failed after {attempt} attempts: {e}") from e
            time.sleep(2**attempt)
            continue
        if resp.status_code in _RETRYABLE_STATUS and attempt < _MAX_ATTEMPTS:
            wait = min(_retry_after(resp) or 2**attempt * 2, 60)
            emit_raw("WARNING", f"OpenRouter HTTP {resp.status_code}; retrying in {wait:.0f}s ({_error_detail(resp)})", dest="LOG")
            resp.close()
            time.sleep(wait)
            continue
        if resp.status_code >= 400:
            detail, category = _error_detail(resp), _refusal_category(resp)
            resp.close()
            if category:
                model = payload.get("model", "")
                count_event("OPENROUTER", "refusals")
                emit("WARN_LLM_REFUSAL", provider="OpenRouter", model=model, category=category)
                emit_raw("WARNING", f"OpenRouter HTTP 403 refusal: {detail}", dest="LOG")
                raise LLMRefusalError(model, category, provider="OPENROUTER")
            raise RuntimeError(f"OpenRouter HTTP {resp.status_code}: {detail}")
        return resp
    raise RuntimeError("OpenRouter request failed")  # unreachable

    This helper wraps requests.post() in a retry loop bounded by _MAX_ATTEMPTS. Socket connection errors and read timeouts sleep for 2**attempt seconds. HTTP status codes listed in _RETRYABLE_STATUS are retried honoring Retry-After headers (capped at 60 seconds). For unretryable HTTP 4xx/5xx status codes, the response stream is closed immediately, and specific 403 moderation errors are raised as LLMRefusalError.

    _consume()

    Visibility: Private

    Signature: def _consume(resp) -> dict:

    Description: Consumes and processes an open HTTP response stream, handling single JSON response bodies as well as Server-Sent Events (SSE) streams. It decodes byte lines individually to prevent Unicode character corruption, filters keep-alive comments, and accumulates output text, reasoning, finish flags, and usage data.

    Parameters:

    • resp: An open requests.Response streaming object.

    Returns:

    • dict: An aggregated result dictionary containing extracted text, reasoning traces, finish reasons, refusal strings, usage statistics, and event counts.

    Example:

    def _consume(resp) -> dict:
    """Parse the SSE stream: text, reasoning, finish / native finish reason, refusal, usage.

    Lines are split as bytes and decoded one by one: str.splitlines() (used by
    iter_lines(decode_unicode=True)) also breaks on U+2028 / U+0085, which JSON strings may contain raw.
    """
    out = {"text": [], "reasoning": [], "finish": None, "native": None, "refusal": None, "usage": None, "events": 0}
    try:
        if "application/json" in (resp.headers.get("Content-Type") or "").lower():
            # An OpenAI-compatible proxy that ignores stream=true answers with one JSON body.
            _apply_chunk(out, resp.json())
        else:
            for raw_line in resp.iter_lines():
                line = raw_line.decode("utf-8", errors="replace") if isinstance(raw_line, bytes) else raw_line
                if not line or line.startswith(":") or not line.startswith("data:"):
                    continue  # blank separators and ': OPENROUTER PROCESSING' keep-alives
                data = line[5:].strip()
                if data == "[DONE]":
                    break
                try:
                    chunk = json.loads(data)
                except ValueError:
                    continue
                _apply_chunk(out, chunk)
    finally:
        resp.close()
    out["text"] = "".join(out["text"])
    out["reasoning"] = "".join(out["reasoning"])
    return out

    The function checks for non-streamed application/json responses from incompatible proxies, folding them directly via _apply_chunk(). For standard SSE streams, it reads byte-by-byte using iter_lines(), explicitly avoiding decode_unicode=True to prevent standard Python line-splitting routines from breaking on characters like U+2028 or U+0085. It skips : OPENROUTER PROCESSING keep-alive comments, unpacks data: lines, breaks on [DONE], and ensures the underlying network socket is closed via a finally block.

    _apply_chunk()

    Visibility: Private

    Signature: def _apply_chunk(out: dict, chunk: dict) -> None:

    Description: Parses an individual stream chunk (or complete non-streamed JSON response) and updates the in-memory output accumulator dictionary in place.

    Parameters:

    • out (dict): The target accumulator dictionary populated by _consume().
    • chunk (dict): Parsed JSON object representing an SSE event or completion chunk.

    Returns:

    • None

    Raises:

    • RuntimeError: When an upstream error object is embedded within the SSE chunk or choice payload.

    Example:

    def _apply_chunk(out: dict, chunk: dict) -> None:
    """Fold one stream chunk (or a whole non-streamed completion) into the _consume result."""
    out["events"] += 1
    if chunk.get("error"):
        err = chunk["error"]
        raise RuntimeError(f"OpenRouter stream error: {err.get('message', err) if isinstance(err, dict) else err}")
    if chunk.get("usage"):
        out["usage"] = chunk["usage"]
    for choice in chunk.get("choices") or []:
        delta = choice.get("delta") or choice.get("message") or {}
        if delta.get("content"):
            out["text"].append(delta["content"])
        if delta.get("reasoning"):
            out["reasoning"].append(delta["reasoning"])
        if delta.get("refusal"):
            out["refusal"] = delta["refusal"]
        if choice.get("finish_reason"):
            out["finish"] = choice["finish_reason"]
        if choice.get("native_finish_reason"):
            out["native"] = choice["native_finish_reason"]
        if choice.get("error"):
            err = choice["error"]
            raise RuntimeError(f"OpenRouter upstream error: {err.get('message', err) if isinstance(err, dict) else err}")

    This helper increments event counters, intercepts embedded streaming errors, captures usage payloads, and appends text and reasoning fragments from delta or message objects. It also updates standard finish_reason and provider-specific native_finish_reason fields.

    _record()

    Visibility: Private

    Signature: def _record(model: str, result: dict, raw_prompt_tokens: int, desc: str, elapsed: float, generation_id: str | None) -> None:

    Description: Records execution usage metrics, cost figures, and prompt token counts into the global accounting ledger, handling BYOK cost calculations and token conversion ratio calibration.

    Parameters:

    • model (str): Target model identifier string.
    • result (dict): The accumulator result dictionary generated by _consume().
    • raw_prompt_tokens (int): Raw prompt token count calculated via local tokenizer.
    • desc (str): Diagnostic description string from payload assembly.
    • elapsed (float): Request execution duration in seconds.
    • generation_id (str | None): The X-Generation-Id returned by OpenRouter, or None.

    Returns:

    • None

    Example:

    def _record(model: str, result: dict, raw_prompt_tokens: int, desc: str, elapsed: float, generation_id: str | None) -> None:
    if not result["usage"]:
        # No usage chunk (dropped stream, or a proxy that omits usage): a request, but unmeasured.
        record_usage("OPENROUTER", model, cost=None, measured=False)
        emit_raw("DEBUG", f"OPENROUTER USAGE | model={model} | no usage reported | generation_id={generation_id or 'n/a'}", dest="BOTH")
        return
    usage = result["usage"]
    prompt = usage.get("prompt_tokens") or 0
    completion = usage.get("completion_tokens") or 0  # includes reasoning tokens
    reasoning_tokens = (usage.get("completion_tokens_details") or {}).get("reasoning_tokens") or 0
    details = usage.get("prompt_tokens_details") or {}
    cached = details.get("cached_tokens") or 0
    cache_write = details.get("cache_write_tokens") or 0
    cost = usage.get("cost")
    upstream = (usage.get("cost_details") or {}).get("upstream_inference_cost")
    if usage.get("is_byok") and isinstance(upstream, int | float):
        # BYOK: `cost` is only OpenRouter's fee; the provider bills upstream_inference_cost to your key.
        cost = (cost if isinstance(cost, int | float) else 0.0) + upstream
    record_usage(
        "OPENROUTER",
        model,
        input_tokens=prompt,
        output_tokens=completion,
        thinking_tokens=reasoning_tokens,
        cache_read=cached,
        cache_write=cache_write,
        cost=float(cost) if isinstance(cost, int | float) else None,
    )
    ratio = prompt / raw_prompt_tokens if raw_prompt_tokens else 0.0
    # usage counts come from the upstream model's own tokenizer (OpenRouter usage accounting), so they
    # calibrate like the native provider; observe_prompt_tokens skips ':online' routes (injected search
    # results) and implausible ratios (prompt rewritten in transit).
    from utils.token_utils import observe_prompt_tokens

    observe_prompt_tokens("OPENROUTER", model, raw_prompt_tokens, prompt)
    emit_raw(
        "DEBUG",
        f"OPENROUTER USAGE | model={model} | {desc} | finish={result['finish']} (native={result['native']}) | in={prompt:,} | out={completion:,} | "
        f"reasoning={reasoning_tokens:,} | cached={cached:,} | cost={'$' + format(cost, '.4f') if isinstance(cost, int | float) else 'n/a'} | "
        f"elapsed={elapsed:.1f}s | observed_token_ratio={ratio:.2f} | generation_id={generation_id or 'n/a'}",
        dest="BOTH",
    )

    If the upstream stream omitted usage information, the request is recorded as unmeasured. Otherwise, the helper unpacks prompt tokens, total completion tokens, reasoning tokens, and cache read/write statistics. When OpenRouter's is_byok flag is true, upstream inference fees are added to OpenRouter's routing fee to compute total financial expenditure. Billed token counts are submitted to token_utils.observe_prompt_tokens() to continuously calibrate runtime token ratios.

    Notable Error Patterns and Exceptions

    1. Transient HTTP Retries (_post): Status codes defined in _RETRYABLE_STATUS (408, 429, 502, 503, 524, 529) as well as requests.exceptions.ConnectionError and requests.exceptions.Timeout trigger up to 3 dispatch attempts. The sleep delay uses the HTTP Retry-After header value when present, falling back to exponential backoff (2**attempt * 2 seconds, capped at 60 seconds). If attempts are exhausted, a RuntimeError is raised.

    2. HTTP 403 Policy and Moderation Refusals: When an HTTP 403 status is returned, _refusal_category() inspects the error payload for moderation metadata. If matched against _REFUSAL_ERROR_TYPES, the module emits a warning and raises an LLMRefusalError(retryable=False), preventing subsequent workflow retries on prompts rejected by safety guardrails.

    3. Mid-Stream and Server-Sent Event Errors: If an SSE event chunk contains an error dictionary (e.g., an upstream idle timeout occurred while generating), _apply_chunk() immediately raises a RuntimeError. The failure is recorded in the usage tracker as an unmeasured request before propagating.

    4. Stream Connection Drop: If a stream closes without sending a terminal finish_reason, the module raises a RuntimeError. This ensures that truncated responses caused by severed network sockets are never treated as valid completions.

    5. Finish Reason Bifurcation (Refusal vs. Truncation):

    6. Stochastic and Deterministic Refusals: When finish == "content_filter", delta.refusal is populated, or native_finish_reason matches _REFUSAL_NATIVE_REASONS, the module raises LLMRefusalError. Refusals matching _DETERMINISTIC_NATIVE_REASONS are marked retryable=False. Transient safety or recitation triggers set retryable=True.
    7. Output Token Exhaustion: When finish == "length", an event counter is incremented, and the text is wrapped in a TruncatedResponse object. This subclass prevents downstream caching in utils.call_llm while allowing partial outputs to be inspected.
