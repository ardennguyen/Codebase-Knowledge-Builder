    llm_openrouter.py

    Source: utils/llm_openrouter.py

    Technical Overview

    The llm_openrouter.py module implements the OpenRouter provider client for the call_llm execution subsystem. It exposes a streaming, OpenAI-compatible chat completions interface configured dynamically through the OpenRouter remote catalog. By querying live catalog metadata rather than relying on static capability maps, the module dynamically normalizes reasoning effort tiers, output budgets, and sampling controls across diverse upstream model families (such as Anthropic Claude, Google Gemini, and Qwen).

    All generation requests operate over Server-Sent Events (SSE) streaming connections to prevent transport-layer read timeouts during protracted reasoning cycles. The network engine handles connection keep-alives (filtering : OPENROUTER PROCESSING SSE comments), executes bounded exponential backoff retries respecting HTTP Retry-After response headers, and detects transient gateway anomalies. Furthermore, it intercepts HTTP 403 moderation rejections and upstream refusal markers, distinguishes between deterministic content policy blocks and retryable output filters, and records multi-dimensional token usage and Bring-Your-Own-Key (BYOK) cost metrics.

    Example:

if not model:
    raise ValueError("OPENROUTER_MODEL environment variable is required")

    build_payload()

    Visibility: Public

    Signature: def build_payload(prompt: str, model: str, level: str | None, prompt_tokens: int) -> tuple[dict, str]:

    Description: Compiles the complete HTTP JSON body for an OpenRouter /v1/chat/completions request. It queries utils.llm_config.openrouter_model_info to retrieve catalog metadata, clamps the maximum output token limit to remaining context capacity, configures reasoning schemas (effort strings versus discrete token budgets), and selectively includes sampling temperature when supported.

    Parameters:

    • prompt (str): The full text of the user prompt to send to the model.
    • model (str): The OpenRouter model identifier (e.g., anthropic/claude-3.7-sonnet).
    • level (str | None): The requested thinking effort level (minimal, low, medium, high, xhigh, max, or None).
    • prompt_tokens (int): The estimated prompt token consumption used to calculate remaining context window headroom.

    Returns:

    • tuple[dict, str]: A 2-tuple containing the constructed dictionary payload ready for JSON serialization, and a short human-readable description of the applied reasoning configuration (e.g., effort=high or reasoning.max_tokens=8192).

    Raises:

    This function does not raise exceptions directly; fallback defaults are used if environment variables or catalog lookups fail.

    Example:

    def build_payload(prompt: str, model: str, level: str | None, prompt_tokens: int) -> tuple[dict, str]:
    info = openrouter_model_info(model)
    max_tokens = _max_tokens(model, info, level, prompt_tokens)
    reasoning, desc = _reasoning(model, info, level, max_tokens)
    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "stream": True,
    }
    if max_tokens:
        payload["max_tokens"] = max_tokens
    if reasoning is not None:
        payload["reasoning"] = reasoning
    if _sends_temperature(model, info, reasoning):
        try:
            payload["temperature"] = float(os.getenv("OPENROUTER_TEMPERATURE", "0.7"))
        except ValueError:
            payload["temperature"] = 0.7
    return payload, desc

    The implementation queries catalog capabilities to establish safe context limits and reasoning schemes. Output budgeting deducts prompt tokens and safety margins via _max_tokens(). Temperature sampling is evaluated through _sends_temperature() and safely defaults to 0.7 only when neither reasoning nor catalog restrictions forbid sampling parameters.

    call_openrouter()

    Visibility: Public

    Signature: def call_openrouter(prompt: str, thinking_level: str | None = None) -> str:

    Description: Executes a complete single-turn inference lifecycle against the OpenRouter completions endpoint. It counts raw prompt tokens, generates headers with optional attribution, dispatches an SSE-streamed POST request over a retry-capable transport layer, aggregates streaming chunks, records usage metrics, and evaluates completion finish reasons against refusal policies and token truncations.

    Parameters:

    • prompt (str): The complete prompt text to submit.
    • thinking_level (str | None, optional): The requested reasoning intensity tier. Defaults to None.

    Returns:

    • str: The decoded completion text returned by the model. Returns a TruncatedResponse instance if the model stopped due to reaching token length limits.

    Raises:

    • ValueError: Raised when the OPENROUTER_MODEL environment variable is missing or empty.
    • RuntimeError: Raised when the HTTP request fails across all retry attempts, if the stream returns an explicit error payload, or if the connection closes prematurely without a finish_reason.
    • LLMRefusalError: Raised when the model rejects the prompt via moderation filters, native refusal codes, or HTTP 403 guardrails.

    Phase 1: Configuration & Payload Preparation

        from utils.token_utils import count_tokens_raw, token_ratio

    model = get_model()
    if not model:
        raise ValueError("OPENROUTER_MODEL environment variable is required")
    api_key = os.getenv("OPENROUTER_API_KEY", "").strip()
    raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
    payload, desc = build_payload(prompt, model, thinking_level, int(raw_tokens * token_ratio()))
    headers = {"Content-Type": "application/json", **_attribution_headers()}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"
    max_tokens = payload.get("max_tokens")
    emit_raw(
        "DEBUG",
        f"OpenRouter request | model={model} | {desc} | max_tokens={f'{max_tokens:,}' if max_tokens else 'omitted'} | "
        f"temperature={payload.get('temperature', 'omitted')} | catalog={'yes' if openrouter_catalog() else 'no'} | "
        f"attribution={'on' if 'HTTP-Referer' in headers else 'off'}",
        dest="LOG",
    )

    The function verifies that OPENROUTER_MODEL is populated and determines baseline token counts using token_utils.count_tokens_raw(). It scales estimated prompt tokens with token_ratio() to establish token headroom for build_payload(). Optional attribution headers and bearer authentication are assembled, followed by debug emission detailing the planned request parameters.

    Phase 2: Network Transmission & Stream Ingestion

        start = time.time()
    resp = _post(f"{openrouter_base_url()}/v1/chat/completions", headers, payload)
    generation_id = resp.headers.get("X-Generation-Id")
    result = _consume(resp)
    _record(model, result, raw_tokens, desc, time.time() - start, generation_id)
    if is_debug() and result["reasoning"]:
        emit_raw("DEBUG", f"REASONING:\n{result['reasoning']}", dest="LOG")

    The client records the invocation start timestamp and sends the payload to {openrouter_base_url()}/v1/chat/completions using _post(). It extracts the X-Generation-Id header returned by OpenRouter for tracing. The SSE response stream is consumed into aggregated buffers via _consume(), usage metrics are logged via _record(), and any extracted internal reasoning trace is conditionally emitted if debug mode is active.

    Phase 3: Response Evaluation & Error Classification

        finish, native = (result["finish"] or ""), (result["native"] or "")
    if finish == "error":
        raise RuntimeError(f"OpenRouter generation ended with an error (native_finish_reason={native or 'n/a'})")
    if finish == "content_filter" or result["refusal"] or native.lower() in _REFUSAL_NATIVE_REASONS:
        category = native or finish or "refusal"
        # Filters on sampled output (safety, recitation, content_filter) may pass on another attempt.
        retryable = not result["refusal"] and native.lower() not in _DETERMINISTIC_NATIVE_REASONS
        count_event("OPENROUTER", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="OpenRouter", model=model, category=category)
        raise LLMRefusalError(model, category, provider="OPENROUTER", retryable=retryable)
    if not finish:
        # No data at all, or the connection dropped mid-answer: never return a partial reply.
        raise RuntimeError(
            f"OpenRouter stream ended without a finish_reason after {result['events']} events ({len(result['text']):,} characters received)"
        )
    if finish == "length":
        count_event("OPENROUTER", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="OpenRouter", max_tokens=f"{max_tokens:,}" if max_tokens else "default")
        return TruncatedResponse(result["text"])
    if not result["text"]:
        emit_raw("WARNING", f"OpenRouter response contained no text (finish_reason={finish or 'n/a'})", dest="LOG")
    return result["text"]

    The completion inspects both OpenRouter's generic finish reason and upstream native finish markers. Streams ending with error raise a RuntimeError. Refusals and content blocks trigger an LLMRefusalError, marked as non-retryable for deterministic input rejections or retryable for stochastic output safety filters. If a stream terminates without any finish_reason, a RuntimeError is raised to prevent partial data leakage. If the model hit token bounds (finish == "length"), the accumulated text is wrapped in a TruncatedResponse to prevent persistent disk caching.

    Internal Helpers

    _read_timeout()

    Visibility: Private

    Signature: def _read_timeout() -> float:

    Description: Parses the OPENROUTER_TIMEOUT_SECONDS environment variable to configure the socket read timeout during streaming response consumption. The returned value is clamped to a minimum duration of 30.0 seconds.

    Parameters:

    This function accepts no parameters.

    Returns:

    • float: The configured timeout in seconds, defaulting to 300.0 if unset or malformed.

    Raises:

    This function does not raise exceptions; invalid numeric inputs fall back to 300.0.

    Example:

    def _read_timeout() -> float:
    try:
        return max(float(os.getenv("OPENROUTER_TIMEOUT_SECONDS", "300")), 30.0)
    except ValueError:
        return 300.0

    The function reads the environment variable and attempts conversion to a float. If a user sets a value lower than 30.0, max() enforces the 30.0-second lower bound to account for slow multi-token streaming intervals.

    _reasoning()

    Visibility: Private

    Signature: def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:

    Description: Evaluates catalog capabilities to construct the reasoning sub-dictionary in the completions payload. It determines whether a model natively expects reasoning effort strings or discrete token budgets (supports_max_tokens). If a model specifies an allowed list of efforts, it invokes clamp_level to match supported tiers. Internal reasoning output text is excluded from transmission (exclude: True) unless debug mode is active.

    Parameters:

    • model (str): The identifier of the target model.
    • info (dict | None): The catalog dictionary retrieved from openrouter_model_info().
    • level (str | None): The requested reasoning intensity tier.
    • max_tokens (int | None, optional): The total completion budget used to ensure thinking budgets do not exceed generation limits. Defaults to None.

    Returns:

    • tuple[dict | None, str]: A tuple containing the reasoning configuration dictionary (or None if reasoning is unsupported or unrequested) and a descriptive log string.

    Raises:

    This function does not raise exceptions directly.

    Example:

    def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:
    """(reasoning payload | None, description)."""
    if not level:
        return None, "default"
    level = level.lower()
    exclude = not is_debug()
    if info is None:
        # Catalog unavailable or model unknown: send the level; OpenRouter clamps server-side.
        return {"effort": level, "exclude": exclude}, f"effort={level} (unverified)"
    reasoning = info.get("reasoning")
    if not isinstance(reasoning, dict) and "reasoning" not in (info.get("supported_parameters") or []):
        if warn_once("openrouter_no_reasoning", model):
            emit("WARN_THINKING_NOT_SUPPORTED", model=model)
        return None, "unsupported"
// ...

    The logic falls back to unverified effort passing if catalog data is missing. When metadata is present, it validates parameter support, falling back gracefully and logging a single warning if the model lacks reasoning capabilities. For budget-only models, it looks up values in _REASONING_BUDGETS and ensures the budget stays at least 1,024 tokens below max_tokens.

    _sends_temperature()

    Visibility: Private

    Signature: def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:

    Description: Determines whether the temperature parameter may safely be included in the request payload. It verifies that reasoning is not enabled, that the model family does not reject sampling parameters (via rejects_sampling_params()), and that catalog metadata explicitly lists temperature without enforcing mandatory reasoning.

    Parameters:

    • model (str): The model identifier.
    • info (dict | None): The catalog dictionary for the model.
    • reasoning (dict | None): The constructed reasoning payload dictionary, if any.

    Returns:

    • bool: True if temperature should be sent; otherwise False.

    Raises:

    This function does not raise exceptions.

    Example:

    def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:
    if reasoning is not None or rejects_sampling_params(model):
        return False
    if info is None:
        return True
    if "temperature" not in (info.get("supported_parameters") or []):
        return False
    meta = info.get("reasoning") if isinstance(info.get("reasoning"), dict) else {}
    return not (meta.get("mandatory") or meta.get("default_enabled"))

    The helper performs defensive checks against models with mandatory thinking (such as OpenAI o-series or Gemini 2.5/3.x variants) where explicit temperature settings cause HTTP 400 Bad Request errors. If catalog metadata is absent, it defaults to sending temperature unless the model is explicitly known to reject sampling parameters.

    _max_tokens()

    Visibility: Private

    Signature: def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:

    Description: Computes the output token budget allocated for a completion request. It references openrouter_output_budget and clamps the budget against the top provider's advertised context length, subtracting estimated prompt tokens and CONTEXT_MARGIN.

    Parameters:

    • model (str): The model identifier.
    • info (dict | None): The catalog entry for the model.
    • level (str | None): The requested reasoning intensity tier.
    • prompt_tokens (int): The estimated count of input prompt tokens.

    Returns:

    • int | None: The clamped maximum completion token budget, or None if the model is unlisted in the catalog.

    Raises:

    This function does not raise exceptions.

    Example:

    def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:
    """Planned max_tokens clamped to the context left after the prompt; None = omit (unknown model)."""
    planned = openrouter_output_budget(model, level)
    context = ((info or {}).get("top_provider") or {}).get("context_length") or (info or {}).get("context_length")
    if planned and context:
        planned = min(planned, max(context - prompt_tokens - CONTEXT_MARGIN, 4_096))
    return planned

    The helper verifies context boundaries by inspecting provider-specific context limits. If planned budgets threaten context exhaustion, the function clamps the allowance while preserving a baseline floor of 4,096 tokens.

    _refusal_category()

    Visibility: Private

    Signature: def _refusal_category(resp) -> str | None:

    Description: Classifies HTTP 403 Forbidden responses to determine if they represent upstream content moderation blocks or policy refusals.

    Parameters:

    • resp: A requests.Response instance.

    Returns:

    • str | None: The identified refusal category string (e.g., content_policy_violation), or None if the error does not indicate a moderation rejection.

    Raises:

    This function does not raise exceptions.

    Example:

    def _refusal_category(resp) -> str | None:
    """Category when an HTTP 403 is a moderation / guardrail / upstream refusal, else None."""
    if resp.status_code != 403:
        return None
    err = _error_body(resp)
    meta = err.get("metadata") or {}
    kind = str(err.get("type") or err.get("error_type") or meta.get("error_type") or "").lower()
    if kind in _REFUSAL_ERROR_TYPES:

    _post()

    Visibility: Private

    Signature: def _post(url: str, headers: dict, payload: dict):

    Description: Dispatches the HTTP POST request to OpenRouter with streaming enabled, executing bounded retries for transient HTTP errors and network timeouts.

    Parameters:

    • url (str): The target endpoint URL.
    • headers (dict): The HTTP headers including authorization and content types.
    • payload (dict): The JSON-serializable request payload.

    Returns:

    • requests.Response: An active streaming HTTP response object with open sockets.

    Raises:

    • RuntimeError: Raised when transient connection errors persist beyond _MAX_ATTEMPTS, or when a non-refusal HTTP status code >= 400 is received.
    • LLMRefusalError: Raised when an HTTP 403 response indicates an upstream moderation or policy rejection.

    Example:

    def _post(url: str, headers: dict, payload: dict):
    """POST with bounded retries on transient failures; returns an open streaming response."""
    for attempt in range(1, _MAX_ATTEMPTS + 1):
        try:
            resp = requests.post(url, headers=headers, json=payload, stream=True, timeout=(15, _read_timeout()))
        except (requests.exceptions.ConnectionError, requests.exceptions.Timeout) as e:
            if attempt == _MAX_ATTEMPTS:
                raise RuntimeError(f"OpenRouter request failed after {attempt} attempts: {e}") from e
            time.sleep(2**attempt)
            continue
        if resp.status_code in _RETRYABLE_STATUS and attempt < _MAX_ATTEMPTS:
            wait = min(_retry_after(resp) or 2**attempt * 2, 60)
            emit_raw("WARNING", f"OpenRouter HTTP {resp.status_code}; retrying in {wait:.0f}s ({_error_detail(resp)})", dest="LOG")
            resp.close()
            time.sleep(wait)
            continue
// ...

    The retry loop executes up to _MAX_ATTEMPTS (3) times. It traps connection drops and timeouts, applying exponential backoff (2**attempt). When receiving retryable status codes (such as 429 or 503), it respects Retry-After headers clamped to 60 seconds. Fatal 4xx/5xx errors are evaluated by _refusal_category(); rejections raise LLMRefusalError directly, whereas unexpected HTTP errors raise RuntimeError.

    _consume()

    Visibility: Private

    Signature: def _consume(resp) -> dict:

    Description: Reads and processes the incoming Server-Sent Events (SSE) data stream. It handles line decoding, discards comments and keep-alive heartbeats, terminates upon receiving [DONE], and accumulates message fragments into an aggregated dictionary.

    Parameters:

    • resp: The open requests.Response stream returned by _post().

    Returns:

    • dict: An aggregated output dictionary containing concatenated text, reasoning, finish states, and usage structures.

    Raises:

    • RuntimeError: Re-raised if _apply_chunk encounters an in-stream error event.

    Example:

    def _consume(resp) -> dict:
    """Parse the SSE stream: text, reasoning, finish / native finish reason, refusal, usage.

    Lines are split as bytes and decoded one by one: str.splitlines() (used by
    iter_lines(decode_unicode=True)) also breaks on U+2028 / U+0085, which JSON strings may contain raw.
    """
    out = {"text": [], "reasoning": [], "finish": None, "native": None, "refusal": None, "usage": None, "events": 0}
    try:
        if "application/json" in (resp.headers.get("Content-Type") or "").lower():
            # An OpenAI-compatible proxy that ignores stream=true answers with one JSON body.
            _apply_chunk(out, resp.json())
        else:
            for raw_line in resp.iter_lines():
                line = raw_line.decode("utf-8", errors="replace") if isinstance(raw_line, bytes) else raw_line
                if not line or line.startswith(":") or not line.startswith("data:"):
                    continue  # blank separators and ': OPENROUTER PROCESSING' keep-alives
                data = line[5:].strip()
                if data == "[DONE]":
                    break
                try:
                    chunk = json.loads(data)
                except ValueError:
                    continue
                _apply_chunk(out, chunk)
    finally:
        resp.close()
    out["text"] = "".join(out["text"])
    out["reasoning"] = "".join(out["reasoning"])
    return out

    The function uses byte-level iteration instead of unicode line splitting to avoid accidental breaks on Unicode line separators like U+2028 or U+0085 embedded in raw JSON. It filters SSE comments such as : OPENROUTER PROCESSING before parsing JSON data payloads. In non-streaming fallback scenarios (where an endpoint returns standard application/json), it ingests the single response payload directly. The response socket is guaranteed to close within a finally block.

    _apply_chunk()

    Visibility: Private

    Signature: def _apply_chunk(out: dict, chunk: dict) -> None:

    Description: Parses an individual SSE chunk or complete response payload and merges its content deltas, reasoning tokens, finish flags, and usage metadata into the accumulator dictionary.

    Parameters:

    • out (dict): The accumulator dictionary populated by _consume().
    • chunk (dict): The parsed JSON object representing a single SSE event or JSON response.

    Returns:

    • None: Mutates out in place.

    Raises:

    • RuntimeError: Raised if the chunk contains an error dictionary at the root or within the choice array.

    Example:

    def _apply_chunk(out: dict, chunk: dict) -> None:
    """Fold one stream chunk (or a whole non-streamed completion) into the _consume result."""
    out["events"] += 1
    if chunk.get("error"):
        err = chunk["error"]
        raise RuntimeError(f"OpenRouter stream error: {err.get('message', err) if isinstance(err, dict) else err}")
    if chunk.get("usage"):
        out["usage"] = chunk["usage"]
    for choice in chunk.get("choices") or []:
        delta = choice.get("delta") or choice.get("message") or {}
        if delta.get("content"):
            out["text"].append(delta["content"])
        if delta.get("reasoning"):
            out["reasoning"].append(delta["reasoning"])
        if delta.get("refusal"):
            out["refusal"] = delta["refusal"]
        if choice.get("finish_reason"):
            out["finish"] = choice["finish_reason"]
        if choice.get("native_finish_reason"):
            out["native"] = choice["native_finish_reason"]
        if choice.get("error"):
            err = choice["error"]
            raise RuntimeError(f"OpenRouter upstream error: {err.get('message', err) if isinstance(err, dict) else err}")

    The method increments the event counter and immediately inspects for error blocks emitted mid-stream by OpenRouter or upstream providers. It supports both streaming (delta) and non-streaming (message) choice payloads, appending text and reasoning fragments to list buffers for string concatenation upon stream completion.

    Error Handling

    The module differentiates between network-level failures, model refusals, and stream interruptions:

    • Transient Network & Gateway Errors: HTTP status codes in _RETRYABLE_STATUS (408, 429, 502, 503, 524, 529) and requests.exceptions.ConnectionError or Timeout exceptions are intercepted by _post(). It performs up to 3 attempts with exponential backoff (2**attempt), parsing any Retry-After header returned by the host. If errors persist beyond 3 attempts, a RuntimeError is raised.
    • Deterministic vs. Retryable Refusals: HTTP 403 errors bearing moderation error types and stream chunks containing refusal flags or _REFUSAL_NATIVE_REASONS trigger LLMRefusalError. If the reason belongs to _DETERMINISTIC_NATIVE_REASONS (refusal, prohibited_content, blocklist, spii) or has an explicit refusal payload, retryable is set to False to prevent downstream workflow loops from re-sending the prompt. If the stop was triggered by output-side sampling filters (content_filter, safety, recitation), retryable is set to True.
    • Token Budget Truncation: When a model stops due to context or budget exhaustion (finish == "length"), the output is wrapped in a TruncatedResponse(result["text"]) object. This notifies callers that the text is incomplete and prevents persistent caching.
    • Stream Interruptions & In-Stream Errors: If an SSE stream terminates without a finish_reason (indicating a dropped socket or proxy failure), or if an in-stream chunk provides an error dictionary, the module raises a RuntimeError so that the workflow node can catch and retry the generation.
