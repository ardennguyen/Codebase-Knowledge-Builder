    llm_openrouter.py

    Source: utils/llm_openrouter.py

    Technical Overview

    The utils/llm_openrouter.py module serves as the specialized OpenRouter client adapter for the Codebase-Knowledge-Builder pipeline. Acting as a vendor-specific transport layer beneath utils/call_llm.py, it translates generic prompt requests and reasoning requirements into OpenAI-compatible Server-Sent Events (SSE) streaming chat completions targeted at the OpenRouter gateway (/v1/chat/completions). Because OpenRouter multiplexes hundreds of disparate upstream LLM providers (including Anthropic Claude, Google Gemini, OpenAI, Meta Llama, and Qwen), the module avoids static, hardcoded parameter tables. Instead, it relies on dynamic catalog introspection via utils.llm_config.openrouter_model_info to negotiate reasoning effort tiers, output token reservations, sampling temperature support, and context boundary clamping.

    The adapter strictly mandates streamed HTTP transport to avoid intermediate read timeouts during extended reasoning phases while consuming SSE byte streams incrementally. It filters out gateway keep-alive ping lines (: OPENROUTER PROCESSING), handles OpenAI-compatible non-streaming proxy fallbacks, parses byte-oriented stream chunks to prevent Unicode line-break corruption, and tracks upstream metadata including completion deltas, reasoning traces, refusal flags, and granular token usage. Transient gateway errors (such as HTTP 408, 429, 502, 503, 524, and 529) are mitigated through bounded exponential backoff respecting upstream Retry-After response headers.

    System-level resilience and accounting are central to the module's operation. When generations terminate prematurely due to token budget exhaustion (finish_reason == "length"), the adapter wraps the output in a TruncatedResponse sentinel to prevent caching corrupted documents. For policy blocks, guardrails, and model refusals, it parses native provider codes and HTTP 403 metadata to distinguish deterministic rejections from retryable candidate filters, raising LLMRefusalError. Finally, usage telemetry reconciles native OpenRouter costs, Bring-Your-Own-Key (BYOK) upstream inference fees, and cache read/write distributions, piping empirical token counts into calibration routines to continuously refine prompt budget ratios.

    Description: Resolves and returns the configured OpenRouter model identifier from the environment. It inspects the OPENROUTER_MODEL variable, trimming whitespace to prevent routing and authentication errors caused by accidental formatting issues.

    build_payload()

    Visibility: Public
    Signature: def build_payload(prompt: str, model: str, level: str | None, prompt_tokens: int) -> tuple[dict, str]:

    Description: Constructs the complete OpenAI-compatible chat completion payload dictionary sent to OpenRouter's /v1/chat/completions endpoint. It queries model metadata from the catalog via openrouter_model_info(model) to determine appropriate token headroom, reasoning constraints, and sampling options.

    The function coordinates three distinct configuration pipelines: 1. _max_tokens() calculates the generation token limit by clamping the model's planned budget against the remaining context window after accounting for prompt tokens and safety margins. 2. _reasoning() constructs the model-appropriate thinking configuration dictionary (effort or max_tokens) based on catalog support flags. 3. _sends_temperature() determines whether the temperature parameter should be included (defaulting to 0.7 or the OPENROUTER_TEMPERATURE environment variable), omitting it for reasoning-enabled calls or models that reject sampling.

    Parameters: * prompt (str): The full text of the user prompt to send to the model. * model (str): The OpenRouter model identifier. * level (str | None): Desired reasoning effort level (e.g., "low", "medium", "high"), or None if disabled. * prompt_tokens (int): Estimated prompt token count scaled by the current token ratio.

    Returns: * tuple[dict, str]: A 2-tuple containing: * payload (dict): The JSON-serializable request payload including model, messages, stream: True, and optional conditional fields (max_tokens, reasoning, temperature). * desc (str): A human-readable diagnostic description of the effective reasoning and token budget configuration.

    Example: 

    # Real usage extracted from call_openrouter() in utils/llm_openrouter.py:
raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
payload, desc = build_payload(prompt, model, thinking_level, int(raw_tokens * token_ratio()))
headers = {"Content-Type": "application/json", **_attribution_headers()}

    call_openrouter()

    Visibility: Public
    Signature: def call_openrouter(prompt: str, thinking_level: str | None = None) -> str:

    Description: The primary public orchestrator for the OpenRouter integration. It executes single-turn chat completion requests through the OpenRouter gateway using Server-Sent Events (SSE) streaming transport. It calculates prompt token metrics, builds headers (including optional attribution and bearer authentication), dispatches requests with transient retry handling, consumes streaming text chunks, accounts for token and cost usage, and validates generation finish states.

    Phase 1: Pre-flight Verification and Payload Assembly

        from utils.token_utils import count_tokens_raw, token_ratio

    model = get_model()
    if not model:
        raise ValueError("OPENROUTER_MODEL environment variable is required")
    api_key = os.getenv("OPENROUTER_API_KEY", "").strip()
    raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
    payload, desc = build_payload(prompt, model, thinking_level, int(raw_tokens * token_ratio()))
    headers = {"Content-Type": "application/json", **_attribution_headers()}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"
    max_tokens = payload.get("max_tokens")
    emit_raw(
        "DEBUG",
        f"OpenRouter request | model={model} | {desc} | max_tokens={f'{max_tokens:,}' if max_tokens else 'omitted'} | "
        f"temperature={payload.get('temperature', 'omitted')} | catalog={'yes' if openrouter_catalog() else 'no'} | "
        f"attribution={'on' if 'HTTP-Referer' in headers else 'off'}",
        dest="LOG",
    )

    The function checks that OPENROUTER_MODEL is defined, raising a ValueError immediately if missing. It measures the raw prompt token length using count_tokens_raw(), scales it by the global token_ratio(), and calls build_payload() to generate the request payload. Optional Bearer authentication is injected if OPENROUTER_API_KEY is present in the environment (which is optional for custom non-OpenRouter proxies), and _attribution_headers() attaches optional app rankings metadata.

    Phase 2: Transport Dispatch and Stream Aggregation

        start = time.time()
    resp = _post(f"{openrouter_base_url()}/v1/chat/completions", headers, payload)
    generation_id = resp.headers.get("X-Generation-Id")
    result = _consume(resp)
    _record(model, result, raw_tokens, desc, time.time() - start, generation_id)
    if is_debug() and result["reasoning"]:
        emit_raw("DEBUG", f"REASONING:\n{result['reasoning']}", dest="LOG")

    The payload is dispatched via _post() to the resolved base URL ({openrouter_base_url()}/v1/chat/completions). The open HTTP stream response is passed directly into _consume(), which folds incoming SSE deltas into a cumulative result dictionary while filtering out keep-alive pings. Once the stream terminates, _record() reports the observed tokens, cache operations, and financial cost to the global ledger and calibration tables. If debug logging is enabled, the aggregated reasoning trace is written to the diagnostic logger.

    Phase 3: Termination Analysis and Error Routing

        finish, native = (result["finish"] or ""), (result["native"] or "")
    if finish == "error":
        raise RuntimeError(f"OpenRouter generation ended with an error (native_finish_reason={native or 'n/a'})")
    if finish == "content_filter" or result["refusal"] or native.lower() in _REFUSAL_NATIVE_REASONS:
        category = native or finish or "refusal"
        # Filters on sampled output (safety, recitation, content_filter) may pass on another attempt.
        retryable = not result["refusal"] and native.lower() not in _DETERMINISTIC_NATIVE_REASONS
        count_event("OPENROUTER", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="OpenRouter", model=model, category=category)
        raise LLMRefusalError(model, category, provider="OPENROUTER", retryable=retryable)
    if not finish:
        # No data at all, or the connection dropped mid-answer: never return a partial reply.
        raise RuntimeError(
            f"OpenRouter stream ended without a finish_reason after {result['events']} events ({len(result['text']):,} characters received)"
        )
    if finish == "length":
        count_event("OPENROUTER", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="OpenRouter", max_tokens=f"{max_tokens:,}" if max_tokens else "default")
        return TruncatedResponse(result["text"])
    if not result["text"]:
        emit_raw("WARNING", f"OpenRouter response contained no text (finish_reason={finish or 'n/a'})", dest="LOG")
    return result["text"]

    The function inspects finish_reason, native_finish_reason, and refusal attributes to classify the completion outcome: * An explicit "error" finish reason raises a RuntimeError. * Guardrail triggers, content policy violations, and model refusals are categorized. The function flags stochastic sampling filters (safety, recitation, content_filter) as retryable=True, while deterministic term blocks and refusals are marked non-retryable, raising an LLMRefusalError. * Dropped connections that terminate without a finish reason raise a RuntimeError to prevent upstream nodes from accepting partial text. * Output capped by token limits (finish == "length") is wrapped in a TruncatedResponse instance, preventing caching and signaling upstream orchestrators to resize token allocations. * Standard completions return the accumulated string.

    Parameters: * prompt (str): Prompt text sent to the language model. * thinking_level (str | None, optional): Categorical reasoning tier ("minimal", "low", "medium", "high", "xhigh", "max"). Defaults to None.

    Returns: * str: The completed textual generation. If output was cut off by output token limits, returns a TruncatedResponse (a str subclass with .truncated = True).

    Raises: * ValueError: If the OPENROUTER_MODEL environment variable is not defined or is blank. * LLMRefusalError: If the model, upstream safety filters, or moderation endpoints reject the prompt or generated content. * RuntimeError: If the HTTP request fails unrecoverably, if the gateway reports an error mid-stream, or if the connection closes without reporting a finish reason.

    Example: 

    # Real usage pattern calling call_openrouter from call_llm.py:
response = call_openrouter(prompt="Identify the architectural abstractions in this module.", thinking_level="medium")

    Module-Level Constants

    _RETRYABLE_STATUS

    • Signature: _RETRYABLE_STATUS = {408, 429, 502, 503, 524, 529}
    • Visibility: Private
    • Description: A set[int] defining the HTTP status codes eligible for automatic retry in _post(). It includes standard request timeouts (408), rate limits (429), bad gateways (502), service unavailability (503), Cloudflare gateway timeouts (524), and site overload conditions (529).

    _MAX_ATTEMPTS

    • Signature: _MAX_ATTEMPTS = 3
    • Visibility: Private
    • Description: Maximum number of HTTP request execution attempts before raising a fatal RuntimeError.

    _REFUSAL_NATIVE_REASONS

    • Signature: _REFUSAL_NATIVE_REASONS = {"refusal", "safety", "prohibited_content", "recitation", "blocklist", "spii", "content_filter"}
    • Visibility: Private
    • Description: A set[str] of upstream finish reasons reported by providers via OpenRouter's native_finish_reason field that map to safety blocks, moderation interventions, or policy refusals.

    _DETERMINISTIC_NATIVE_REASONS

    • Signature: _DETERMINISTIC_NATIVE_REASONS = {"refusal", "prohibited_content", "blocklist", "spii"}
    • Visibility: Private
    • Description: Subset of _REFUSAL_NATIVE_REASONS that represent static, deterministic policy violations (such as personally identifiable information blocks or explicit model refusals). When encountered, LLMRefusalError is raised with retryable=False to prevent identical network requests.

    _REFUSAL_ERROR_TYPES

    • Signature: _REFUSAL_ERROR_TYPES = {"refusal", "content_policy_violation", "moderation"}
    • Visibility: Private
    • Description: Error category identifiers found in OpenRouter HTTP 403 error payloads that indicate the request was rejected by moderation filters.

    _REASONING_BUDGETS

    • Signature: _REASONING_BUDGETS = {"minimal": 1_024, "low": 2_048, "medium": 8_192, "high": 16_384, "xhigh": 24_576, "max": 32_000}
    • Visibility: Private
    • Description: Explicit token allocation mapping used for reasoning-capable models that support reasoning.max_tokens but lack discrete supported_efforts tiers. Enforces an absolute minimum budget of 1,024 tokens.

    _APP_TITLE

    • Signature: _APP_TITLE = "Codebase Knowledge Builder"
    • Visibility: Private
    • Description: Identification string sent in X-OpenRouter-Title and X-Title attribution headers when the application opts into rankings tracking via OPENROUTER_APP_URL.

    _read_timeout()

    Visibility: Private
    Signature: def _read_timeout() -> float:

    Description: Resolves the per-chunk SSE read timeout threshold in seconds. It parses the OPENROUTER_TIMEOUT_SECONDS environment variable, enforcing a hard lower bound of 30.0 seconds to prevent premature drops during deep reasoning generations.

    def _read_timeout() -> float:
    try:
        return max(float(os.getenv("OPENROUTER_TIMEOUT_SECONDS", "300")), 30.0)
    except ValueError:
        return 300.0

    The function provides defensive fallback to 300.0 seconds if the environment variable contains an unparseable non-numeric string. By enforcing a 30-second minimum, it guarantees sufficient headroom between keep-alive pings and stream chunk delivery during prolonged thinking generation phases.

    Parameters: * None.

    Returns: * float: The configured read timeout threshold in seconds (clamped to $\ge 30.0$).

    Example: 

    # Real usage inside _post() in utils/llm_openrouter.py:
resp = requests.post(url, headers=headers, json=payload, stream=True, timeout=(15, _read_timeout()))

    _reasoning()

    Visibility: Private
    Signature: def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:

    Description: Synthesizes the OpenRouter reasoning payload block and diagnostic description for a given model and effort level. It determines whether the target model supports categorical effort tiers, explicit token budgets, or reasoning parameters at all.

    def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:
    """(reasoning payload | None, description)."""
    if not level:
        return None, "default"
    level = level.lower()
    exclude = not is_debug()
    if info is None:
        # Catalog unavailable or model unknown: send the level; OpenRouter clamps server-side.
        return {"effort": level, "exclude": exclude}, f"effort={level} (unverified)"
    reasoning = info.get("reasoning")
    if not isinstance(reasoning, dict) and "reasoning" not in (info.get("supported_parameters") or []):
        if warn_once("openrouter_no_reasoning", model):
            emit("WARN_THINKING_NOT_SUPPORTED", model=model)
        return None, "unsupported"
    meta = reasoning if isinstance(reasoning, dict) else {}
    if "supported_efforts" not in meta and meta.get("supports_max_tokens"):
        # Budget-only model: an explicit thinking budget (OpenRouter's effort ratio of a large
        # max_tokens would over-spend). It must stay below max_tokens.
        budget = _REASONING_BUDGETS.get(level, _REASONING_BUDGETS["medium"])
        if max_tokens:
            budget = max(min(budget, max_tokens - 1_024), 1_024)
        return {"max_tokens": budget, "exclude": exclude}, f"reasoning.max_tokens={budget}"
    efforts = meta.get("supported_efforts")
    effort = level
    if efforts:
        effort = clamp_level(level, [e for e in efforts if e != "none"]) or level
        if effort != level and warn_once("openrouter_level", model, level):
            emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effort, model=model)
    return {"effort": effort, "exclude": exclude}, f"effort={effort}"

    The function handles reasoning parameters across multiple catalog scenarios: * If no thinking level is requested, it returns (None, "default"). * If catalog metadata is unavailable (info is None), it forwards the raw requested effort tier to OpenRouter, relying on server-side clamping. * If the model's catalog metadata indicates reasoning is unsupported, it emits a warning (WARN_THINKING_NOT_SUPPORTED) and returns (None, "unsupported"). * If the model supports numeric token limits without categorical effort tiers (supports_max_tokens), it selects an integer budget from _REASONING_BUDGETS, clamping it so that at least 1,024 tokens remain allocated for output completion below max_tokens. * If the model defines supported_efforts, it calls clamp_level() to snap requested tiers to the closest supported upstream string (excluding "none" to avoid HTTP 400 errors on mandatory reasoning models). In all cases, exclude = not is_debug() ensures internal thinking traces are excluded from streamed chunks unless debugging is enabled.

    Parameters: * model (str): Target OpenRouter model identifier. * info (dict | None): Catalog metadata dictionary resolved from openrouter_model_info(). * level (str | None): Requested reasoning effort level string. * max_tokens (int | None, optional): Planned output token reservation used to clamp numeric reasoning budgets.

    Returns: * tuple[dict | None, str]: A 2-tuple containing the dictionary payload for payload["reasoning"] (or None), and a diagnostic label string.

    Example: 

    # Real usage inside build_payload() in utils/llm_openrouter.py:
reasoning, desc = _reasoning(model, info, level, max_tokens)

    _sends_temperature()

    Visibility: Private
    Signature: def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:

    Description: Evaluates whether the temperature sampling parameter is valid for the current request. It prevents API rejections from upstream providers that reject sampling parameters during reasoning.

    def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:
    if reasoning is not None or rejects_sampling_params(model):
        return False
    if info is None:
        return True
    if "temperature" not in (info.get("supported_parameters") or []):
        return False
    meta = info.get("reasoning") if isinstance(info.get("reasoning"), dict) else {}
    return not (meta.get("mandatory") or meta.get("default_enabled"))

    The helper disables temperature under four distinct conditions: 1. Active reasoning parameters are attached to the payload (reasoning is not None). 2. The model family belongs to an architecture that explicitly rejects sampling parameters according to rejects_sampling_params() (e.g., Anthropic Claude 3.7+ or Gemini 2.5/3.x reasoning modes). 3. The model catalog explicitly omits "temperature" from its supported_parameters list. 4. The model has mandatory or default-enabled reasoning enabled upstream (meta.get("mandatory") or meta.get("default_enabled")). If catalog data is unavailable, it defaults to True.

    Parameters: * model (str): Target model identifier string. * info (dict | None): Catalog metadata dictionary for the model. * reasoning (dict | None): The constructed reasoning payload dictionary, if any.

    Returns: * bool: True if temperature should be sent; otherwise False.

    Example: 

    # Real usage inside build_payload() in utils/llm_openrouter.py:
if _sends_temperature(model, info, reasoning):
    try:
        payload["temperature"] = float(os.getenv("OPENROUTER_TEMPERATURE", "0.7"))
    except ValueError:
        payload["temperature"] = 0.7

    _max_tokens()

    Visibility: Private
    Signature: def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:

    Description: Calculates the output token reservation limit (max_tokens), clamped to ensure generation headroom fits within the model's total context window.

    def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:
    """Planned max_tokens clamped to the context left after the prompt; None = omit (unknown model)."""
    planned = openrouter_output_budget(model, level)
    context = ((info or {}).get("top_provider") or {}).get("context_length") or (info or {}).get("context_length")
    if planned and context:
        planned = min(planned, max(context - prompt_tokens - CONTEXT_MARGIN, 4_096))
    return planned

    The function computes the initial budget via openrouter_output_budget(model, level). If total context limits are known from top_provider.context_length or the top-level context_length in the catalog, it clamps planned to not exceed context - prompt_tokens - CONTEXT_MARGIN, while guaranteeing at least a 4,096 token baseline. If the catalog does not know the model or its limits, it returns None so the provider's upstream defaults apply.

    Parameters: * model (str): The target model identifier string. * info (dict | None): Catalog dictionary resolved for the model. * level (str | None): Categorical reasoning effort string. * prompt_tokens (int): Token length of the input prompt.

    Returns: * int | None: Clamped integer output token limit, or None if the budget is omitted.

    Example: 

    # Real usage inside build_payload() in utils/llm_openrouter.py:
info = openrouter_model_info(model)
max_tokens = _max_tokens(model, info, level, prompt_tokens)

    _consume()

    Visibility: Private
    Signature: def _consume(resp) -> dict:

    Description: Parses an active SSE stream line-by-line, extracting completion text, reasoning traces, termination finish reasons, moderation refusals, and token usage statistics into an aggregated state dictionary.

    Phase 1: Stream Decoding and Event Filtering

        out = {"text": [], "reasoning": [], "finish": None, "native": None, "refusal": None, "usage": None, "events": 0}
    try:

        else:

    Error Handling

    HTTP Network and Transient Retry Logic

    HTTP interactions dispatched in _post() handle transient gateway and network failures by evaluating requests.exceptions.ConnectionError, requests.exceptions.Timeout, and status codes within _RETRYABLE_STATUS ({408, 429, 502, 503, 524, 529}). Execution retries are governed by the following rules: * Up to 3 execution attempts (_MAX_ATTEMPTS) are performed. * If a transient HTTP status is returned, the module parses the Retry-After header using _retry_after(). If absent, it falls back to exponential backoff ($2^{\text{attempt}} \times 2$), capped at 60 seconds. * Active response bodies are closed via resp.close() prior to backoff sleep intervals, preventing socket connection leaks. * Exhaustion of attempts or encounters with non-retryable status codes $\ge 400$ raise a RuntimeError containing parsed diagnostic text from _error_detail().

    Refusal and Moderation Classification

    The module distinguishes between deterministic policy violations and transient sampling blocks using LLMRefusalError: * HTTP 403 Responses: Evaluated via _refusal_category(). If error metadata indicates content policy rejections, moderation flags, or explicit refusals (_REFUSAL_ERROR_TYPES), the request raises LLMRefusalError(model, category, provider="OPENROUTER", retryable=False). * Stream-Level Refusals: Checked during finish state analysis in call_openrouter(). If finish_reason == "content_filter", delta.refusal is populated, or native_finish_reason matches _REFUSAL_NATIVE_REASONS: * If the condition is listed in _DETERMINISTIC_NATIVE_REASONS ({"refusal", "prohibited_content", "blocklist", "spii"}), it raises LLMRefusalError with retryable=False. * If caused by output sampling filters ("safety", "recitation", "content_filter"), the refusal is marked retryable=True because alternate temperature samples may pass upstream checks.

    Mid-Stream Failures and Truncation Guardrails

    Streaming responses can fail mid-transmission without raising low-level socket errors. The module handles these stream-level failure modes as follows: * Mid-Stream Errors: If an SSE chunk contains an "error" field (either at top-level or within choices), _apply_chunk() raises a RuntimeError immediately, aborting consumption. * Dropped Streams: If the stream terminates without providing a finish_reason (or delivers zero event chunks), call_openrouter() raises a RuntimeError, preventing downstream nodes from processing incomplete responses. * Token Budget Truncation: If the generation finishes with finish_reason == "length", the output is wrapped in a TruncatedResponse object. This notifies the caching layer in utils.call_llm not to persist incomplete data and signals upstream callers to resize context windows.
