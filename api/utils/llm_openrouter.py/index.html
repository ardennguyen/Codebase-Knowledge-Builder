    llm_openrouter.py

    Source: utils/llm_openrouter.py

    Technical Overview

    llm_openrouter.py implements the OpenRouter provider adapter for the call_llm dispatch layer in the Codebase-Knowledge-Builder architecture. It exposes an OpenAI-compatible chat completion client driven entirely by dynamic metadata retrieved from OpenRouter's remote model catalog (utils/llm_config.openrouter_model_info). By delegating model capabilities, context windows, parameter limits, and reasoning constraints to catalog inspection, the module natively supports diverse upstream model families (such as Anthropic Claude, Google Gemini, Qwen, and DeepSeek) without relying on brittle, hardcoded per-model logic within the adapter itself.

    The module operates over persistent HTTP streaming connections utilizing Server-Sent Events (SSE) via the requests library. Streaming execution prevents client-side read and gateway timeouts during long generation cycles and deep reasoning runs that may span several minutes. Incoming event streams are decoded line by line as raw bytes rather than standard Unicode string splits to prevent corrupted parsing when multi-byte sequences or raw Unicode line breaks (U+2028, U+0085) appear inside JSON payloads. Keep-alive SSE comment events (: OPENROUTER PROCESSING) are discarded automatically during iteration.

    Resilience is built directly into the transport and parsing layers. Network disconnections and transient HTTP response codes (408, 429, 502, 503, 524, 529) trigger bounded exponential backoff retries respecting upstream Retry-After headers. Non-transient status codes and upstream moderation stops are categorized into deterministic refusals or retryable policy filters, raising structured LLMRefusalError exceptions to halt or redirect pipeline nodes. Responses that exhaust output token capacities are encapsulated in TruncatedResponse instances to prevent incomplete generations from entering downstream disk caches, while full token, cache, and cost metrics are recorded to the system ledger.

    Public API

    get_model()

    Visibility: Public

    Signature: def get_model() -> str:

    Description: Retrieves the configured OpenRouter model identifier from the environment. Reads the OPENROUTER_MODEL environment variable, returning its stripped string value or an empty string if unset.

    Parameters:

    None.

    Returns:

    • str: The target model identifier string (e.g., "anthropic/claude-3.7-sonnet"), or "" if not defined.

    Example:

    # Extracted from utils/llm_openrouter.py: call_openrouter()
model = get_model()
if not model:
    raise ValueError("OPENROUTER_MODEL environment variable is required")

    The function performs a direct lookup of OPENROUTER_MODEL via os.getenv(). Because upstream orchestration logic depends on this name to query the catalog and compute context window limits, returning a sanitized string ensures downstream URLs and catalog lookups receive valid identifiers without leading or trailing whitespace.

    build_payload()

    Visibility: Public

    Signature: def build_payload(prompt: str, model: str, level: str | None, prompt_tokens: int) -> tuple[dict, str]:

    Description: Assembles the complete OpenAI-compatible JSON dictionary payload for an OpenRouter chat completion request, returning both the payload dictionary and a diagnostic human-readable description of the reasoning configuration.

    Parameters:

    • prompt (str): The raw text prompt submitted to the model.
    • model (str): The target model identifier.
    • level (str | None): The requested abstract thinking/reasoning effort level (e.g., "low", "medium", "high"), or None.
    • prompt_tokens (int): Estimated prompt token count used to compute available context headroom.

    Returns:

    • tuple[dict, str]: A 2-tuple containing:
      1. dict: The serialized JSON request payload containing model, messages, stream: True, and conditional fields (max_tokens, reasoning, temperature).
      2. str: A short human-readable string summarizing the reasoning parameters (e.g., "effort=medium" or "unsupported").

    Example:

    # Extracted from utils/llm_openrouter.py: build_payload() implementation
info = openrouter_model_info(model)
max_tokens = _max_tokens(model, info, level, prompt_tokens)
reasoning, desc = _reasoning(model, info, level, max_tokens)
payload = {
    "model": model,
    "messages": [{"role": "user", "content": prompt}],
    "stream": True,
}
if max_tokens:
    payload["max_tokens"] = max_tokens
if reasoning is not None:
    payload["reasoning"] = reasoning
if _sends_temperature(model, info, reasoning):
    try:
        payload["temperature"] = float(os.getenv("OPENROUTER_TEMPERATURE", "0.7"))
    except ValueError:
        payload["temperature"] = 0.7

    build_payload() serves as the central serialization pipeline for OpenRouter requests. It queries openrouter_model_info(model) to retrieve upstream architectural capabilities, calculates the safe max_tokens reserve via _max_tokens(), constructs reasoning constraints via _reasoning(), and determines temperature inclusion via _sends_temperature(). All requests enforce stream: True to ensure completions are returned through Server-Sent Events.

    call_openrouter()

    Visibility: Public

    Signature: def call_openrouter(prompt: str, thinking_level: str | None = None) -> str:

    Description: Orchestrates the full lifecycle of an OpenRouter model invocation. This includes pre-call token estimation, payload serialization, HTTP dispatch with bounded retries, SSE stream consumption, telemetry recording, and finish reason evaluation.

    Parameters:

    • prompt (str): The user or system prompt to send for completion.
    • thinking_level (str | None, optional): Desired reasoning effort level (e.g., "low", "medium", "high"). Defaults to None.

    Returns:

    • str: The generated completion text. If the generation was halted due to context length limits, an instance of TruncatedResponse (a str subclass) is returned.

    Raises:

    • ValueError: If the OPENROUTER_MODEL environment variable is not set.
    • RuntimeError: If the request fails after all retry attempts, if an SSE stream drops mid-generation without a finish reason, or if the stream yields an upstream error.
    • LLMRefusalError: If the model or OpenRouter content filters reject the prompt.

    Phase 1: Request Assembly and Validation

    model = get_model()
if not model:
    raise ValueError("OPENROUTER_MODEL environment variable is required")
api_key = os.getenv("OPENROUTER_API_KEY", "").strip()
raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
payload, desc = build_payload(prompt, model, thinking_level, int(raw_tokens * token_ratio()))
headers = {"Content-Type": "application/json", **_attribution_headers()}
if api_key:
    headers["Authorization"] = f"Bearer {api_key}"
max_tokens = payload.get("max_tokens")
emit_raw(
    "DEBUG",
    f"OpenRouter request | model={model} | {desc} | max_tokens={f'{max_tokens:,}' if max_tokens else 'omitted'} | "
    f"temperature={payload.get('temperature', 'omitted')} | catalog={'yes' if openrouter_catalog() else 'no'} | "
    f"attribution={'on' if 'HTTP-Referer' in headers else 'off'}",
    dest="LOG",
)

    In the first phase, call_openrouter() validates the presence of OPENROUTER_MODEL and loads credentials from OPENROUTER_API_KEY. Raw prompt tokens are obtained from count_tokens_raw() and scaled by token_ratio() to establish the prompt token baseline. The request dictionary is constructed using build_payload(), optional attribution headers are merged from _attribution_headers(), and debug telemetry is dispatched to log sinks.

    Phase 2: HTTP Execution and Stream Consumption

    start = time.time()
resp = _post(f"{openrouter_base_url()}/v1/chat/completions", headers, payload)
generation_id = resp.headers.get("X-Generation-Id")
try:
    result = _consume(resp)
except Exception:
    # An error chunk mid-stream ("Upstream idle timeout exceeded") still was a request: unmeasured, like a
    # dropped stream, so a failed attempt and its retry both show in the usage ledger
    record_usage("OPENROUTER", model, cost=None, measured=False)
    emit_raw("DEBUG", f"OPENROUTER USAGE | model={model} | stream error, no usage reported | generation_id={generation_id or 'n/a'}", dest="BOTH")
    raise
_record(model, result, raw_tokens, desc, time.time() - start, generation_id)
if is_debug() and result["reasoning"]:
    emit_raw("DEBUG", f"REASONING:\n{result['reasoning']}", dest="LOG")

    The second phase transmits the request via _post() to the completions endpoint resolved by openrouter_base_url(). The resulting streaming response is parsed by _consume(). If an exception occurs mid-stream (such as an idle timeout or dropped connection), the attempt is recorded in the global ledger as an unmeasured request via record_usage() before re-raising the error. Upon successful stream termination, _record() logs the billing and token metrics, and debug thinking traces are emitted if requested.

    Phase 3: Finish Reason Evaluation and Refusal Classification

    finish, native = (result["finish"] or ""), (result["native"] or "")
if finish == "error":
    raise RuntimeError(f"OpenRouter generation ended with an error (native_finish_reason={native or 'n/a'})")
if finish == "content_filter" or result["refusal"] or native.lower() in _REFUSAL_NATIVE_REASONS:
    category = native or finish or "refusal"
    # Filters on sampled output (safety, recitation, content_filter) may pass on another attempt.
    retryable = not result["refusal"] and native.lower() not in _DETERMINISTIC_NATIVE_REASONS
    count_event("OPENROUTER", "refusals")
    emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="OpenRouter", model=model, category=category)
    raise LLMRefusalError(model, category, provider="OPENROUTER", retryable=retryable)
if not finish:
    # No data at all, or the connection dropped mid-answer: never return a partial reply.
    raise RuntimeError(
        f"OpenRouter stream ended without a finish_reason after {result['events']} events ({len(result['text']):,} characters received)"
    )
if finish == "length":
    count_event("OPENROUTER", "truncations")
    emit("WARN_LLM_TRUNCATED", provider="OpenRouter", max_tokens=f"{max_tokens:,}" if max_tokens else "default")
    return TruncatedResponse(result["text"])
if not result["text"]:
    emit("LLM_EMPTY_REPLY", provider="OpenRouter", reason=finish or "n/a")
return result["text"]

    The final phase examines the stream termination flags (finish and native). If an error is flagged, execution halts. Content filters, native provider refusals, or explicit refusal attributes raise LLMRefusalError, with retryable set to True for output-dependent filters (e.g., recitation or safety) and False for deterministic blocks. A missing finish reason raises a RuntimeError to prevent partial responses from being processed. If the response finished due to context length exhaustion (finish == "length"), the accumulated text is wrapped in a TruncatedResponse to prevent disk caching; otherwise, the raw decoded text is returned.

    Internal Helpers

    _read_timeout()

    Visibility: Private

    Signature: def _read_timeout() -> float:

    Description: Determines the maximum permissible silence duration between Server-Sent Events chunks before timing out.

    Parameters:

    None.

    Returns:

    • float: The read timeout in seconds, bounded to a minimum of 30.0 seconds. Defaults to 300.0 seconds if OPENROUTER_TIMEOUT_SECONDS is unset or invalid.

    Example:

    # Extracted from utils/llm_openrouter.py: _read_timeout()
try:
    return max(float(os.getenv("OPENROUTER_TIMEOUT_SECONDS", "300")), 30.0)
except ValueError:
    return 300.0

    _read_timeout() parses the OPENROUTER_TIMEOUT_SECONDS environment variable to configure the socket read timeout for HTTP streaming. Long reasoning models frequently pause for dozens of seconds between emitting thought tokens and final output; enforcing a strict lower floor of 30.0 seconds prevents aggressive socket drops during intense thinking phases.

    _reasoning()

    Visibility: Private

    Signature: def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:

    Description: Constructs the OpenRouter-specific reasoning payload dictionary based on the requested thinking level, the catalog specifications for the model, and available output tokens.

    Parameters:

    • model (str): Target model identifier.
    • info (dict | None): The catalog entry dictionary returned by openrouter_model_info(), or None if unavailable.
    • level (str | None): Desired reasoning level (e.g., "minimal", "low", "medium", "high", "xhigh", "max").
    • max_tokens (int | None, optional): The allocated completion token budget. Defaults to None.

    Returns:

    • tuple[dict | None, str]: A tuple containing:
      1. dict | None: The dictionary payload to send under the "reasoning" key in the API request, or None if reasoning is unsupported or unrequested.
      2. str: A human-readable description for telemetry and logging.

    Example:

    # Extracted from utils/llm_openrouter.py: _reasoning()
if not level:
    return None, "default"
level = level.lower()
exclude = not is_debug()
if info is None:
    # Catalog unavailable or model unknown: send the level; OpenRouter clamps server-side.
    return {"effort": level, "exclude": exclude}, f"effort={level} (unverified)"
reasoning = info.get("reasoning")
if not isinstance(reasoning, dict) and "reasoning" not in (info.get("supported_parameters") or []):
    if warn_once("openrouter_no_reasoning", model):
        emit("WARN_THINKING_NOT_SUPPORTED", model=model)
    return None, "unsupported"
meta = reasoning if isinstance(reasoning, dict) else {}
if "supported_efforts" not in meta and meta.get("supports_max_tokens"):
    budget = _REASONING_BUDGETS.get(level, _REASONING_BUDGETS["medium"])
    if max_tokens:
        budget = max(min(budget, max_tokens - 1_024), 1_024)
    return {"max_tokens": budget, "exclude": exclude}, f"reasoning.max_tokens={budget}"
efforts = meta.get("supported_efforts")
effort = level
if efforts:
    effort = clamp_level(level, [e for e in efforts if e != "none"]) or level
    if effort != level and warn_once("openrouter_level", model, level):
        emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effort, model=model)
return {"effort": effort, "exclude": exclude}, f"effort={effort}"

    _reasoning() inspects the model catalog to negotiate thinking parameters. If a model only accepts explicit token budgets rather than effort strings (indicated by supports_max_tokens), it maps the level to _REASONING_BUDGETS and clamps the budget to remain below max_tokens - 1024. For models supporting effort levels, it utilizes clamp_level() to ensure the effort tier is supported upstream (excluding "none" to prevent HTTP 400 errors on reasoning-mandatory models). In all cases, exclude: True is set unless debugging is enabled, preventing verbose thinking tokens from cluttering the final response payload.

    _sends_temperature()

    Visibility: Private

    Signature: def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:

    Description: Evaluates whether an explicit temperature parameter should be included in the API request payload.

    Parameters:

    • model (str): Target model identifier.
    • info (dict | None): Catalog metadata for the model.
    • reasoning (dict | None): The constructed reasoning payload, or None.

    Returns:

    • bool: True if temperature is supported and safe to send; otherwise False.

    Example:

    # Extracted from utils/llm_openrouter.py: _sends_temperature()
if reasoning is not None or rejects_sampling_params(model):
    return False
if info is None:
    return True
if "temperature" not in (info.get("supported_parameters") or []):
    return False
meta = info.get("reasoning") if isinstance(info.get("reasoning"), dict) else {}
return not (meta.get("mandatory") or meta.get("default_enabled"))

    Modern reasoning models (such as Claude 4.7+, Gemini 3.x, and o1/o3 architectures) reject sampling parameters when reasoning is enabled. _sends_temperature() checks if reasoning is active or if rejects_sampling_params(model) flags the family. If catalog info exists, it validates that "temperature" is listed under supported_parameters and verifies that reasoning is neither mandatory nor default-enabled for the target architecture.

    _max_tokens()

    Visibility: Private

    Signature: def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:

    Description: Calculates the upper limit of generation tokens allowed for the request, bounded by catalog context limits and prompt token consumption.

    Parameters:

    • model (str): Target model identifier.
    • info (dict | None): Catalog metadata dictionary.
    • level (str | None): Requested reasoning effort level.
    • prompt_tokens (int): Count of prompt tokens.

    Returns:

    • int | None: The clamped maximum token count, or None if the model is unknown and limits should be deferred to upstream defaults.

    Example:

    # Extracted from utils/llm_openrouter.py: _max_tokens()
planned = openrouter_output_budget(model, level)
context = ((info or {}).get("top_provider") or {}).get("context_length") or (info or {}).get("context_length")
if planned and context:
    planned = min(planned, max(context - prompt_tokens - CONTEXT_MARGIN, 4_096))
return planned

    _max_tokens() coordinates with openrouter_output_budget() to establish a base output ceiling for the model family and effort tier. If the catalog provides the model's total context_length, the planned output is clamped so that planned <= context - prompt_tokens - CONTEXT_MARGIN, while guaranteeing a minimum working window of 4,096 tokens. If the model is absent from the catalog, None is returned to allow OpenRouter and the upstream host to apply default limits.

    Parameters:

    • resp (requests.Response): The HTTP response to evaluate.

    • str | None: A normalized refusal category string (e.g., "content_policy_violation", "moderation"), or None if the status code is not 403 or the error is unrelated to content moderation.

    # Extracted from utils/llm_openrouter.py: _refusal_category()
if resp.status_code != 403:
    return None

kind = str(err.get("type") or err.get("error_type") or meta.get("error_type") or "").lower()

    _post()

    Visibility: Private

    Signature: def _post(url: str, headers: dict, payload: dict):

    Description: Executes an HTTP POST request with streaming enabled, handling transient failures and rate limits via bounded exponential backoff retries.

    Parameters:

    • url (str): The target endpoint URL.
    • headers (dict): HTTP request headers.
    • payload (dict): JSON payload dictionary.

    Returns:

    • requests.Response: An open streaming HTTP response ready for SSE consumption.

    Raises:

    • LLMRefusalError: If an HTTP 403 response indicates content moderation or policy refusal.
    • RuntimeError: If network connection errors, timeouts, or non-retryable 4xx/5xx responses persist across _MAX_ATTEMPTS.

    Example:

    # Extracted from utils/llm_openrouter.py: _post()
for attempt in range(1, _MAX_ATTEMPTS + 1):
    try:
        resp = requests.post(url, headers=headers, json=payload, stream=True, timeout=(15, _read_timeout()))
    except (requests.exceptions.ConnectionError, requests.exceptions.Timeout) as e:
        if attempt == _MAX_ATTEMPTS:
            raise RuntimeError(f"OpenRouter request failed after {attempt} attempts: {e}") from e
        emit("LLM_HTTP_RETRY", provider="OpenRouter", attempt=attempt, attempts=_MAX_ATTEMPTS, error=brief(e), wait=2**attempt)
        time.sleep(2**attempt)
        continue
    if resp.status_code in _RETRYABLE_STATUS and attempt < _MAX_ATTEMPTS:
        wait = min(_retry_after(resp) or 2**attempt * 2, 60)
        error = f"HTTP {resp.status_code}: {_error_detail(resp)}"
        emit("LLM_HTTP_RETRY", provider="OpenRouter", attempt=attempt, attempts=_MAX_ATTEMPTS, error=brief(error), wait=f"{wait:.0f}")
        resp.close()
        time.sleep(wait)
        continue
    if resp.status_code >= 400:
        detail, category = _error_detail(resp), _refusal_category(resp)
        resp.close()
        if category:
            model = payload.get("model", "")
            count_event("OPENROUTER", "refusals")
            emit("WARN_LLM_REFUSAL", provider="OpenRouter", model=model, category=category)
            emit_raw("WARNING", f"OpenRouter HTTP 403 refusal: {detail}", dest="LOG")
            raise LLMRefusalError(model, category, provider="OPENROUTER")
        raise RuntimeError(f"OpenRouter HTTP {resp.status_code}: {detail}")
    return resp
raise RuntimeError("OpenRouter request failed")  # unreachable

    _post() wraps HTTP transport in an attempt loop bounded by _MAX_ATTEMPTS (3). Sockets enforce a connection timeout of 15 seconds and a read timeout determined by _read_timeout(). Network disconnections and retryable status codes (_RETRYABLE_STATUS) calculate wait times using exponential backoff or _retry_after(), capped at 60 seconds. Fatal HTTP errors are parsed for refusal classifications; if identified as a moderation rejection, an LLMRefusalError is raised immediately to halt redundant retries.

    _consume()

    Visibility: Private

    Signature: def _consume(resp) -> dict:

    Description: Parses the incoming HTTP response body into accumulated text, reasoning traces, finish reasons, and usage statistics, supporting both streaming SSE lines and single-chunk JSON responses.

    Parameters:

    • resp (requests.Response): The open streaming HTTP response.

    Returns:

    • dict: An accumulated result dictionary matching the Stream Aggregation Payload schema.

    Example:

    # Extracted from utils/llm_openrouter.py: _consume()
out = {"text": [], "reasoning": [], "finish": None, "native": None, "refusal": None, "usage": None, "events": 0}
try:
    if "application/json" in (resp.headers.get("Content-Type") or "").lower():
        # An OpenAI-compatible proxy that ignores stream=true answers with one JSON body.
        _apply_chunk(out, resp.json())
    else:
        for raw_line in resp.iter_lines():
            line = raw_line.decode("utf-8", errors="replace") if isinstance(raw_line, bytes) else raw_line
            if not line or line.startswith(":") or not line.startswith("data:"):
                continue  # blank separators and ': OPENROUTER PROCESSING' keep-alives
            data = line[5:].strip()
            if data == "[DONE]":
                break
            try:
                chunk = json.loads(data)
            except ValueError:
                continue
            _apply_chunk(out, chunk)
finally:
    resp.close()
out["text"] = "".join(out["text"])
out["reasoning"] = "".join(out["reasoning"])
return out

    _consume() handles the transport deserialization of streaming responses. Because certain proxies ignore stream=true and return single JSON bodies, it branches based on Content-Type. For SSE streams, it iterates over raw byte lines via iter_lines() to prevent Python's str.splitlines() from splitting on raw Unicode control characters (U+2028, U+0085). Comment lines prefixed with : (such as OpenRouter keep-alive pings) and empty delimiter lines are skipped, and JSON payload chunks are delegated to _apply_chunk().

    _apply_chunk()

    Visibility: Private

    Signature: def _apply_chunk(out: dict, chunk: dict) -> None:

    Description: Folds an individual SSE JSON chunk (or non-streamed completion response) into the in-progress stream accumulator dictionary.

    Parameters:

    • out (dict): The accumulator dictionary created by _consume().
    • chunk (dict): A deserialized JSON chunk from the API response.

    Returns:

    • None

    Raises:

    • RuntimeError: If the chunk contains an top-level or choice-level error message.

    Example:

    # Extracted from utils/llm_openrouter.py: _apply_chunk()
out["events"] += 1
if chunk.get("error"):
    err = chunk["error"]
    raise RuntimeError(f"OpenRouter stream error: {err.get('message', err) if isinstance(err, dict) else err}")
if chunk.get("usage"):
    out["usage"] = chunk["usage"]
for choice in chunk.get("choices") or []:
    delta = choice.get("delta") or choice.get("message") or {}
    if delta.get("content"):
        out["text"].append(delta["content"])
    if delta.get("reasoning"):
        out["reasoning"].append(delta["reasoning"])
    if delta.get("refusal"):
        out["refusal"] = delta["refusal"]
    if choice.get("finish_reason"):
        out["finish"] = choice["finish_reason"]
    if choice.get("native_finish_reason"):
        out["native"] = choice["native_finish_reason"]
    if choice.get("error"):
        err = choice["error"]
        raise RuntimeError(f"OpenRouter upstream error: {err.get('message', err) if isinstance(err, dict) else err}")

    _apply_chunk() increments the event counter and checks for mid-stream error envelopes emitted by upstream providers or proxies. It extracts text deltas, reasoning strings, and refusal messages from choice.delta or choice.message. It also captures termination signals (finish_reason and native_finish_reason) and records the terminal usage dictionary emitted in the final chunk of the stream.

    _record() handles the accounting lifecycle for OpenRouter completions. If an API proxy omits usage metadata, it records an unmeasured entry via record_usage(). When usage is available, it isolates standard completion tokens, reasoning tokens, prompt cache read/write tokens, and financial costs.     Error Handling

    The module provides defensive error classification and recovery routines across transport, parsing, and upstream provider boundaries:

    • HTTP Transport Retries: Network drops (ConnectionError), socket timeouts (Timeout), and transient HTTP status codes (408, 429, 502, 503, 524, 529) are caught within _post(). It performs up to 3 attempts with exponential backoff (2**attempt seconds). When an HTTP 429 response includes a valid Retry-After header, _retry_after() honors the server's requested delay up to a 60-second ceiling.
    • HTTP 403 Moderation Rejections: Upstream guardrails that reject prompts before generation begins are detected by _refusal_category(). Instead of raising a retryable network error, the response is categorized into an LLMRefusalError(retryable=False), logging the refusal event and aborting node retries immediately.
    • Stream Corruption and Disconnections: If an SSE connection drops mid-stream, _consume() exits its loop. In call_openrouter(), if finish is empty or missing, a RuntimeError is raised stating the number of events and characters received. Partial or fragmented responses are never returned.
    • Mid-Stream Provider Errors: When upstream providers fail during generation (e.g., idle timeouts), OpenRouter emits an SSE chunk with an error dictionary. _apply_chunk() detects this structure and raises a RuntimeError, causing the mid-stream attempt to be logged as unmeasured in record_usage() before escalating to the node retry runner.
    • Token Length Truncations: When generations terminate with finish == "length", the output is wrapped in a TruncatedResponse instance. This informs call_llm and downstream orchestrators that the completion was truncated, preventing the incomplete response from being written to the disk cache (llm_cache_v2.json).
    • Content Filter and Safety Stops: Terminations flagged with finish == "content_filter", an explicit refusal message, or native reasons matching _REFUSAL_NATIVE_REASONS raise LLMRefusalError. If the stop was caused by non-deterministic sampling filters (e.g., safety or recitation), retryable is set to True, permitting the caller to resubmit the prompt with alternative sampling seeds or lower temperatures.
