    llm_openrouter.py

    Source: utils/llm_openrouter.py

    Technical Overview

    utils/llm_openrouter.py provides the catalog-driven OpenRouter inference adapter for the centralized Large Language Model (LLM) execution pipeline in call_llm.py. Operating across OpenAI-compatible chat completion endpoints, the module dynamically interfaces with heterogeneous upstream model families (such as Anthropic Claude, Google Gemini, and Qwen) without relying on hardcoded parameter tables. Instead, it inspects dynamic metadata retrieved from the OpenRouter model catalog via utils.llm_config to govern reasoning effort parameters, output token ceilings, and sampling options at runtime.

    The module enforces Server-Sent Events (SSE) streaming for all completions to eliminate read timeouts during prolonged multi-turn reasoning phases, filtering out transient : OPENROUTER PROCESSING keep-alive comments. Network interactions are safeguarded by an exponential backoff retry loop with bounded attempts for transient HTTP status codes (such as rate limits and gateway timeouts) while respecting server-supplied Retry-After headers. In addition, the component manages opt-in application attribution headers, classifies guardrail blocks and safety refusals into retryable or non-retryable exceptions, returns truncation indicators when response ceilings are reached, and records multi-dimensional token counts and financial costs (including Bring Your Own Key / BYOK upstream fees) directly into the system's global usage ledger.

    Public API

    get_model()

    Visibility: Public

    Signature: def get_model() -> str:

    Description: Resolves and sanitizes the configured OpenRouter model identifier by inspecting the OPENROUTER_MODEL environment variable. Whitespace is stripped to ensure clean lookup strings for catalog queries and API payload generation.

    Parameters:

    • This function takes no arguments.

    Returns:

    • str: The target model name (e.g., "anthropic/claude-3.7-sonnet"), or an empty string if unset.

    Example:

    model = get_model()
if not model:
    raise ValueError("OPENROUTER_MODEL environment variable is required")

    The function provides safe fallback access to the primary configuration variable. Callers verify that the string is non-empty before initiating downstream payload preparation or authorization preflight checks.

    build_payload()

    Visibility: Public

    Signature: def build_payload(prompt: str, model: str, level: str | None, prompt_tokens: int) -> tuple[dict, str]:

    Description: Compiles the OpenAI-compatible JSON dictionary payload dispatched to the OpenRouter chat completions endpoint. It inspects catalog specifications via openrouter_model_info to adjust token limits, configure reasoning structures, and evaluate whether sampling parameters should be included.

    Parameters:

    • prompt (str): The raw input user prompt text.
    • model (str): The designated OpenRouter model identifier.
    • level (str | None): The desired thinking effort level ("minimal", "low", "medium", "high", "xhigh", "max", or None).
    • prompt_tokens (int): The estimated prompt token consumption used for context window margin calculations.

    Returns:

    • tuple[dict, str]: A 2-tuple where index 0 contains the completion request payload dictionary, and index 1 contains a human-readable telemetry description of the reasoning configuration.

    Example:

    info = openrouter_model_info(model)
max_tokens = _max_tokens(model, info, level, prompt_tokens)
reasoning, desc = _reasoning(model, info, level, max_tokens)
payload = {
    "model": model,
    "messages": [{"role": "user", "content": prompt}],
    "stream": True,
}
if max_tokens:
    payload["max_tokens"] = max_tokens
if reasoning is not None:
    payload["reasoning"] = reasoning
if _sends_temperature(model, info, reasoning):
    try:
        payload["temperature"] = float(os.getenv("OPENROUTER_TEMPERATURE", "0.7"))
    except ValueError:
        payload["temperature"] = 0.7

    build_payload() enforces stream mode ("stream": True) unconditionally to support progressive SSE reads. It dynamically attaches max_tokens, reasoning, and temperature fields based on catalog parameters, guarding against invalid API requests such as sending temperature to reasoning models or requesting thinking capabilities from models that do not support them.

    call_openrouter()

    Visibility: Public

    Signature: def call_openrouter(prompt: str, thinking_level: str | None = None) -> str:

    Description: The primary public inference coordinator for the OpenRouter provider. It resolves environment parameters, measures input tokens, compiles headers and payloads, handles streaming HTTP execution, logs diagnostic and reasoning metrics, records ledger usage, and translates termination indicators into completions, truncations, or refusal errors.

    Parameters:

    • prompt (str): The input prompt string dispatched for completion.
    • thinking_level (str | None): Optional reasoning effort level. Defaults to None.

    Returns:

    • str: The completed response text, or a TruncatedResponse instance if generation was cut off by token limits.

    Raises:

    • ValueError: If the OPENROUTER_MODEL environment variable is not defined or is empty.
    • RuntimeError: If network retries are exhausted, an upstream or streaming error occurs, the stream ends without a finish reason, or generation terminates with an error code.
    • LLMRefusalError: If the model or OpenRouter guardrail filters block the request.

    Phase 1: Environment and Token Validation

    from utils.token_utils import count_tokens_raw, token_ratio

model = get_model()
if not model:
    raise ValueError("OPENROUTER_MODEL environment variable is required")
api_key = os.getenv("OPENROUTER_API_KEY", "").strip()
raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
payload, desc = build_payload(prompt, model, thinking_level, int(raw_tokens * token_ratio()))
headers = {"Content-Type": "application/json", **_attribution_headers()}
if api_key:
    headers["Authorization"] = f"Bearer {api_key}"
max_tokens = payload.get("max_tokens")

    The initial phase validates that a target model is configured and reads the optional API key from OPENROUTER_API_KEY. It estimates prompt tokens by querying count_tokens_raw scaled by the current token_ratio(), then constructs the request payload and headers (including opt-in attribution metadata).

    Phase 2: Streaming Transport and Error Recovery

    start = time.time()
resp = _post(f"{openrouter_base_url()}/v1/chat/completions", headers, payload)
generation_id = resp.headers.get("X-Generation-Id")
try:
    result = _consume(resp)
except Exception:
    # An error chunk mid-stream ("Upstream idle timeout exceeded") still was a request: unmeasured, like a
    # dropped stream, so a failed attempt and its retry both show in the usage ledger
    record_usage("OPENROUTER", model, cost=None, measured=False)
    emit_raw("DEBUG", f"OPENROUTER USAGE | model={model} | stream error, no usage reported | generation_id={generation_id or 'n/a'}", dest="BOTH")
    raise

    The transport phase initiates the HTTP request via _post() against the configured base URL. If the SSE stream fails or drops unexpectedly during _consume(), the exception handler ensures the failed attempt is recorded in the usage ledger as an unmeasured request prior to re-raising the exception.

    Phase 3: Telemetry Accounting and Response Classification

    _record(model, result, raw_tokens, desc, time.time() - start, generation_id)
if is_debug() and result["reasoning"]:
    emit_raw("DEBUG", f"REASONING:\n{result['reasoning']}", dest="LOG")

finish, native = (result["finish"] or ""), (result["native"] or "")
if finish == "error":
    raise RuntimeError(f"OpenRouter generation ended with an error (native_finish_reason={native or 'n/a'})")
if finish == "content_filter" or result["refusal"] or native.lower() in _REFUSAL_NATIVE_REASONS:
    category = native or finish or "refusal"
    # Filters on sampled output (safety, recitation, content_filter) may pass on another attempt.
    retryable = not result["refusal"] and native.lower() not in _DETERMINISTIC_NATIVE_REASONS
    count_event("OPENROUTER", "refusals")
    emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="OpenRouter", model=model, category=category)
    raise LLMRefusalError(model, category, provider="OPENROUTER", retryable=retryable)
if not finish:
    # No data at all, or the connection dropped mid-answer: never return a partial reply.
    raise RuntimeError(
        f"OpenRouter stream ended without a finish_reason after {result['events']} events ({len(result['text']):,} characters received)"
    )
if finish == "length":
    count_event("OPENROUTER", "truncations")
    emit("WARN_LLM_TRUNCATED", provider="OpenRouter", max_tokens=f"{max_tokens:,}" if max_tokens else "default")
    return TruncatedResponse(result["text"])
if not result["text"]:
    emit_raw("WARNING", f"OpenRouter response contained no text (finish_reason={finish or 'n/a'})", dest="LOG")
return result["text"]

    The final phase commits detailed token usage and timing statistics via _record(). It evaluates the completion's finish_reason and native_finish_reason, distinguishing between non-retryable deterministic refusals and retryable sampling blocks (e.g., safety filters). If output is bounded by max tokens (finish == "length"), it wraps the text in a TruncatedResponse to prevent caching incomplete responses.

    Internal Helpers

    _RETRYABLE_STATUS

    Visibility: Private

    Definition: _RETRYABLE_STATUS = {408, 429, 502, 503, 524, 529}

    Set of HTTP response status codes considered transient errors eligible for automated retry in _post(). It covers request timeouts (408), rate limits (429), bad gateways (502), service unavailability (503), Cloudflare gateway timeouts (524), and site overload conditions (529).

    _MAX_ATTEMPTS

    Visibility: Private

    Definition: _MAX_ATTEMPTS = 3

    Maximum number of dispatch attempts allocated for a single request before treating a transport failure as fatal and raising a RuntimeError.

    _REFUSAL_NATIVE_REASONS

    Visibility: Private

    Definition: _REFUSAL_NATIVE_REASONS = {"refusal", "safety", "prohibited_content", "recitation", "blocklist", "spii", "content_filter"}

    String constants matching native finish reason tags emitted by various upstream models indicating that generation was halted due to content moderation, safety filtering, or policy violation.

    _DETERMINISTIC_NATIVE_REASONS

    Visibility: Private

    Definition: _DETERMINISTIC_NATIVE_REASONS = {"refusal", "prohibited_content", "blocklist", "spii"}

    Subset of _REFUSAL_NATIVE_REASONS representing deterministic policy violations that will repeat for identical input prompts. These cause LLMRefusalError to be marked with retryable=False.

    _REFUSAL_ERROR_TYPES

    Visibility: Private

    Definition: _REFUSAL_ERROR_TYPES = {"refusal", "content_policy_violation", "moderation"}

    Error classification keywords encountered within HTTP 403 error payloads that signify policy moderation blocks rather than authentication failures.

    _REASONING_BUDGETS

    Visibility: Private

    Definition: _REASONING_BUDGETS = {"minimal": 1_024, "low": 2_048, "medium": 8_192, "high": 16_384, "xhigh": 24_576, "max": 32_000}

    Explicit token allocation table mapping thinking levels to token counts for reasoning models that accept reasoning.max_tokens but lack native effort tiers.

    _APP_TITLE

    Visibility: Private

    Definition: _APP_TITLE = "Codebase Knowledge Builder"

    Application title string included in OpenRouter attribution headers (X-OpenRouter-Title and X-Title) when opt-in attribution is active.

    _read_timeout()

    Visibility: Private

    Signature: def _read_timeout() -> float:

    Description: Calculates the HTTP streaming read timeout threshold in seconds. It parses the OPENROUTER_TIMEOUT_SECONDS environment variable, enforcing a minimum lower bound of 30.0 seconds to prevent early drops during extended thinking phases.

    Parameters:

    • This function takes no arguments.

    Returns:

    • float: Read timeout duration in seconds (defaulting to 300.0).

    Example:

    def _read_timeout() -> float:
    try:
        return max(float(os.getenv("OPENROUTER_TIMEOUT_SECONDS", "300")), 30.0)
    except ValueError:
        return 300.0

    This helper wraps environment parsing in a ValueError guard. If invalid or non-numeric values are supplied in the environment, it safely falls back to the default duration of 300.0 seconds.

    _reasoning()

    Visibility: Private

    Signature: def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:

    Description: Constructs the "reasoning" configuration sub-dictionary for the request payload. Based on the model catalog metadata, it determines whether to send effort-based reasoning ("effort"), token budget-based reasoning ("max_tokens"), or omit reasoning entirely if unsupported.

    Parameters:

    • model (str): Target model identifier.
    • info (dict | None): Model catalog metadata returned by openrouter_model_info.
    • level (str | None): Desired thinking level string.
    • max_tokens (int | None): Planned maximum completion token limit. Defaults to None.

    Returns:

    • tuple[dict | None, str]: A tuple containing the reasoning configuration dictionary (or None if disabled/unsupported) and an audit description string.

    Example:

    def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:
    if not level:
        return None, "default"
    level = level.lower()
    exclude = not is_debug()
    if info is None:
        return {"effort": level, "exclude": exclude}, f"effort={level} (unverified)"
    reasoning = info.get("reasoning")
    if not isinstance(reasoning, dict) and "reasoning" not in (info.get("supported_parameters") or []):
        if warn_once("openrouter_no_reasoning", model):
            emit("WARN_THINKING_NOT_SUPPORTED", model=model)
        return None, "unsupported"
    meta = reasoning if isinstance(reasoning, dict) else {}
    if "supported_efforts" not in meta and meta.get("supports_max_tokens"):
        budget = _REASONING_BUDGETS.get(level, _REASONING_BUDGETS["medium"])
        if max_tokens:
            budget = max(min(budget, max_tokens - 1_024), 1_024)
        return {"max_tokens": budget, "exclude": exclude}, f"reasoning.max_tokens={budget}"
    efforts = meta.get("supported_efforts")
    effort = level
    if efforts:
        effort = clamp_level(level, [e for e in efforts if e != "none"]) or level
        if effort != level and warn_once("openrouter_level", model, level):
            emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effort, model=model)
    return {"effort": effort, "exclude": exclude}, f"effort={effort}"

    The function clamps requested effort levels using clamp_level() to prevent invalid configurations, explicitly filtering out 'none' which causes HTTP 400 errors on mandatory reasoning models. When operating in non-debug mode (not is_debug()), it injects "exclude": True to prevent raw thinking traces from appearing in final completions while still allowing token billing.

    _sends_temperature()

    Visibility: Private

    Signature: def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:

    Description: Determines whether the temperature parameter may be safely sent in the payload. Sampling parameters are suppressed if reasoning is active, if the model family rejects sampling, or if catalog metadata flags reasoning as mandatory or enabled by default.

    Parameters:

    • model (str): Target model identifier.
    • info (dict | None): Catalog metadata dictionary for the model.
    • reasoning (dict | None): Configured reasoning dictionary, if any.

    Returns:

    • bool: True if temperature should be included, False otherwise.

    Example:

    def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:
    if reasoning is not None or rejects_sampling_params(model):
        return False
    if info is None:
        return True
    if "temperature" not in (info.get("supported_parameters") or []):
        return False
    meta = info.get("reasoning") if isinstance(info.get("reasoning"), dict) else {}
    return not (meta.get("mandatory") or meta.get("default_enabled"))

    The function incorporates guard logic against sending sampling parameters to advanced reasoning models (such as Claude 3.7 Sonnet in thinking mode or Gemini 2.5/3.x series). It verifies compatibility against both catalog parameter declarations and family-level rules defined in rejects_sampling_params().

    _max_tokens()

    Visibility: Private

    Signature: def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:

    Description: Computes the output token budget for the request. It retrieves the planned budget from openrouter_output_budget and clamps it to ensure it does not exceed the remaining provider context window after subtracting prompt tokens and safety margins.

    Parameters:

    • model (str): Target model identifier.
    • info (dict | None): Catalog metadata for the model.
    • level (str | None): Thinking effort level.
    • prompt_tokens (int): Number of tokens consumed by the prompt.

    Returns:

    • int | None: Clamped output token limit, or None if the model or context window limits are unknown.

    Example:

    def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:
    planned = openrouter_output_budget(model, level)
    context = ((info or {}).get("top_provider") or {}).get("context_length") or (info or {}).get("context_length")
    if planned and context:
        planned = min(planned, max(context - prompt_tokens - CONTEXT_MARGIN, 4_096))
    return planned

    The calculation resolves context limits by prioritizing top_provider.context_length before falling back to top-level context_length. If remaining context is constrained, it clamps output to available headroom while enforcing a floor of 4,096 tokens.

    _error_detail()

    Visibility: Private

    Signature: def _error_detail(resp) -> str:

    Description: Formats an actionable error diagnostic message from an HTTP response by inspecting error bodies, metadata, raw provider messages, and text truncations.

    Parameters:

    • resp (requests.Response): The HTTP response object.

    Returns:

    • str: Human-readable error diagnostic string.

    def _error_detail(resp) -> str:
    err = _error_body(resp)

    _refusal_category()

    Visibility: Private

    Signature: def _refusal_category(resp) -> str | None:

    Description: Analyzes an HTTP 403 Forbidden response to determine if it represents a moderation, guardrail, or content policy refusal rather than a general permission or authentication failure.

    Parameters:

    • resp (requests.Response): The HTTP response object.

    Returns:

    • str | None: Refusal category identifier (e.g., "content_policy_violation", "moderation"), or None if the status code is not 403 or the error is unrelated to content moderation.

    Example:

    def _refusal_category(resp) -> str | None:
    if resp.status_code != 403:
        return None
    err = _error_body(resp)
    meta = err.get("metadata") or {}
    kind = str(err.get("type") or err.get("error_type") or meta.get("error_type") or "").lower()
    if kind in _REFUSAL_ERROR_TYPES:
        return kind
    if meta.get("reasons") or meta.get("flagged_input"):
        reasons = meta.get("reasons") or ["moderation"]
        return ",".join(map(str, reasons)) if isinstance(reasons, list) else str(reasons)
    return None

    The function checks both standard OpenRouter error type fields and nested metadata arrays (metadata.reasons). When flagged input reasons are detected, it joins them into a comma-delimited string to classify the refusal.

    _post()

    Visibility: Private

    Signature: def _post(url: str, headers: dict, payload: dict):

    Description: Dispatches the HTTP POST request to the completion endpoint with a streaming response connection. It encapsulates retry logic with exponential backoff for transient errors, handles connection failures, and translates HTTP 403 moderation blocks into LLMRefusalError.

    Parameters:

    • url (str): Target completions endpoint URL.
    • headers (dict): HTTP request headers.
    • payload (dict): Serialized JSON payload dictionary.

    Returns:

    • requests.Response: An open streaming response object.

    Raises:

    • LLMRefusalError: When an HTTP 403 response corresponds to a content moderation or policy refusal.
    • RuntimeError: When network connection retries are exhausted or a non-refusal HTTP error occurs.

    Connection Management and Transient Retry Loop

    for attempt in range(1, _MAX_ATTEMPTS + 1):
    try:
        resp = requests.post(url, headers=headers, json=payload, stream=True, timeout=(15, _read_timeout()))
    except (requests.exceptions.ConnectionError, requests.exceptions.Timeout) as e:
        if attempt == _MAX_ATTEMPTS:
            raise RuntimeError(f"OpenRouter request failed after {attempt} attempts: {e}") from e
        time.sleep(2**attempt)
        continue
    if resp.status_code in _RETRYABLE_STATUS and attempt < _MAX_ATTEMPTS:
        wait = min(_retry_after(resp) or 2**attempt * 2, 60)
        emit_raw("WARNING", f"OpenRouter HTTP {resp.status_code}; retrying in {wait:.0f}s ({_error_detail(resp)})", dest="LOG")
        resp.close()
        time.sleep(wait)
        continue

    The loop attempts up to _MAX_ATTEMPTS (3) dispatches. Network timeouts and dropped connections trigger exponential backoff pauses (2**attempt). When receiving a retryable status code (such as 429 or 503), it honors the Retry-After header capped at 60 seconds.

    _consume()

    Visibility: Private

    Signature: def _consume(resp) -> dict:

    Description: Parses the open response stream. It supports both standard Server-Sent Events (SSE) data streams and single-payload JSON bodies emitted by non-streaming OpenAI-compatible proxies.

    Parameters:

    • resp (requests.Response): Open streaming HTTP response.

    Returns:

    • dict: Accumulated output dictionary containing consolidated text, reasoning, finish states, and usage metrics.

    Example:

    def _consume(resp) -> dict:
    out = {"text": [], "reasoning": [], "finish": None, "native": None, "refusal": None, "usage": None, "events": 0}
    try:
        if "application/json" in (resp.headers.get("Content-Type") or "").lower():
            _apply_chunk(out, resp.json())
        else:
            for raw_line in resp.iter_lines():
                line = raw_line.decode("utf-8", errors="replace") if isinstance(raw_line, bytes) else raw_line
                if not line or line.startswith(":") or not line.startswith("data:"):
                    continue
                data = line[5:].strip()
                if data == "[DONE]":
                    break
                try:
                    chunk = json.loads(data)
                except ValueError:
                    continue
                _apply_chunk(out, chunk)
    finally:
        resp.close()
    out["text"] = "".join(out["text"])
    out["reasoning"] = "".join(out["reasoning"])
    return out

    The function processes stream lines as raw byte sequences decoded with errors="replace". This prevents decoding bugs with str.splitlines(), which breaks on Unicode line separators like U+2028 or U+0085 that may appear within raw JSON strings. It ignores comment lines (such as : OPENROUTER PROCESSING) and terminates when encountering the [DONE] SSE marker.

    _apply_chunk()

    Visibility: Private

    Signature: def _apply_chunk(out: dict, chunk: dict) -> None:

    Description: Updates the accumulator dictionary in _consume() by folding in content deltas, reasoning strings, refusal notices, finish reasons, and usage metrics from a single deserialized stream chunk.

    Parameters:

    • out (dict): The shared accumulator dictionary.
    • chunk (dict): Parsed JSON chunk from the SSE stream.

    Raises:

    • RuntimeError: If the chunk contains a top-level or choice-level error definition from OpenRouter or the upstream provider.

    Example:

    def _apply_chunk(out: dict, chunk: dict) -> None:
    out["events"] += 1
    if chunk.get("error"):
        err = chunk["error"]
        raise RuntimeError(f"OpenRouter stream error: {err.get('message', err) if isinstance(err, dict) else err}")
    if chunk.get("usage"):
        out["usage"] = chunk["usage"]
    for choice in chunk.get("choices") or []:
        delta = choice.get("delta") or choice.get("message") or {}
        if delta.get("content"):
            out["text"].append(delta["content"])
        if delta.get("reasoning"):
            out["reasoning"].append(delta["reasoning"])
        if delta.get("refusal"):
            out["refusal"] = delta["refusal"]
        if choice.get("finish_reason"):
            out["finish"] = choice["finish_reason"]
        if choice.get("native_finish_reason"):
            out["native"] = choice["native_finish_reason"]
        if choice.get("error"):
            err = choice["error"]
            raise RuntimeError(f"OpenRouter upstream error: {err.get('message', err) if isinstance(err, dict) else err}")

    _apply_chunk() checks for stream-level and choice-level error blocks (such as mid-stream upstream timeouts). It extracts content deltas across both streaming chunk formats (choice.delta) and non-streaming proxy formats (choice.message).

    Error Handling

    utils/llm_openrouter.py implements a multi-tiered error recovery and classification strategy to distinguish between transient network issues, content policy blocks, generation truncation, and fatal errors:

    • Transient HTTP Retries: Status codes defined in _RETRYABLE_STATUS (408, 429, 502, 503, 524, 529) trigger automated retries up to _MAX_ATTEMPTS (3). The wait time prioritizes the response's Retry-After header when available, falling back to exponential backoff (2**attempt * 2) bounded at 60 seconds.
    • HTTP 403 Refusal Classification: When an HTTP 403 Forbidden status is encountered, _refusal_category() inspects the response body and metadata. If classified as a content policy, guardrail, or moderation violation (matching _REFUSAL_ERROR_TYPES), it raises LLMRefusalError(model, category, provider="OPENROUTER") rather than a generic network exception.
    • Stream Disconnection and Mid-Stream Errors: If an SSE stream drops without providing a finish_reason, or if a chunk returns an explicit error payload, a RuntimeError is raised. The failure is recorded as an unmeasured attempt via record_usage() so that failed attempts are accounted for in the execution ledger.
    • Native Finish Reason Mapping: Upstream stop reasons in _REFUSAL_NATIVE_REASONS (refusal, safety, prohibited_content, recitation, blocklist, spii, content_filter) raise LLMRefusalError. Deterministic triggers in _DETERMINISTIC_NATIVE_REASONS mark the error as non-retryable (retryable=False), while probabilistic filters (such as recitation or content_filter) allow retries (retryable=True).
    • Length Truncation: When generation ends due to token limits (finish == "length"), output is wrapped in a TruncatedResponse instance. This signals downstream callers that output was cut off, preventing partial answers from being committed to persistent disk caches.
