    llm_openrouter.py

    Source: utils/llm_openrouter.py

    Following the vendor-specific driver implementation for Google Gemini in llm_gemini.py, this module provides a catalog-driven integration layer for OpenRouter's OpenAI-compatible API gateway. While llm_gemini.py and llm_anthropic.py interact directly with proprietary vendor SDKs, llm_openrouter.py acts as a polymorphic client capable of orchestrating requests across hundreds of upstream model architectures through a single standardized transport interface.

    Technical Overview

    The primary responsibility of llm_openrouter.py is to execute single-turn chat completions against the OpenRouter gateway without hardcoding model capabilities. Instead of maintaining static parameter lookup tables for each upstream provider, the module queries metadata dynamically from the OpenRouter model catalog via llm_config.py (openrouter_model_info). This metadata dictates reasoning parameters, token constraints, context boundaries, and parameter eligibility (such as temperature filtering) for any arbitrary model identifier at runtime.

    To maintain transport resilience during long-running generative passes and extended reasoning traces, all interactions are executed via Server-Sent Events (SSE) streaming using requests.post(..., stream=True). This architecture prevents transport-layer socket timeouts by continually consuming SSE events while discarding gateway-specific keep-alive pulses (: OPENROUTER PROCESSING). The module transparently manages transient network anomalies and upstream rate limiting using exponential backoff aligned with server-supplied Retry-After headers.

    The module standardizes downstream error handling by classifying diverse gateway responses into shared domain abstractions defined in llm_common.py. Generation outputs halted due to token ceilings are wrapped in TruncatedResponse to prevent corrupting local cache stores in call_llm.py. Upstream policy violations, moderation triggers, and safety guardrails are mapped to LLMRefusalError, explicitly differentiating between deterministic prompt rejections and transient sampling filter halts. Additionally, token telemetry and financial ledger entries—including Bring-Your-Own-Key (BYOK) upstream inference surcharges—are recorded into session analytics via record_usage.

    Description: Compiles the OpenAI-compatible JSON request payload tailored to the capabilities of the specified model.     Phase 1: Context Resolution & Token Sizing

It then delegates to _reasoning() to translate the abstract level string into vendor-specific reasoning structures. Finally, it initializes the baseline request dictionary with user messages and explicitly sets "stream": True to mandate Server-Sent Events from the gateway.

    Phase 2: Parameter Shaping & Temperature Policy

        if max_tokens:
        payload["max_tokens"] = max_tokens
    if reasoning is not None:
        payload["reasoning"] = reasoning
    if _sends_temperature(model, info, reasoning):

If structured reasoning was generated, the dictionary is attached under the "reasoning" key.     call_openrouter()

    Visibility: Public
    Signature: def call_openrouter(prompt: str, thinking_level: str | None = None) -> str:

    Description: Coordinates the complete single-turn inference lifecycle over the OpenRouter gateway. It validates local environment settings, estimates input token footprints, constructs the catalog-adapted payload, and dispatches the streaming HTTP request. Upon receiving the stream, it accumulates chunks, handles keep-alive pulses, records comprehensive token and billing usage metrics, evaluates termination conditions (distinguishing between length-based truncations, fatal safety blocks, and transient moderation flags), and returns the final synthesized output.

    Phase 1: Environment Validation & Token Analysis

        from utils.llm_config import get_token_ratio
    from utils.token_utils import count_tokens_raw

    model = get_model()
    if not model:
        raise ValueError("OPENROUTER_MODEL environment variable is required")
    api_key = os.getenv("OPENROUTER_API_KEY", "").strip()
    raw_tokens = count_tokens_raw(prompt)
    payload, desc = build_payload(prompt, model, thinking_level, int(raw_tokens * get_token_ratio()))
    headers = {"Content-Type": "application/json", **_attribution_headers()}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"
    max_tokens = payload.get("max_tokens")
    The execution begins by performing local lazy imports to avoid circular dependency chains with configuration and tokenizer modules. It inspects get_model(), raising a ValueError immediately if the target model string is undefined. It calculates raw prompt tokens via count_tokens_raw(prompt) and scales the estimate by get_token_ratio() to account for cross-tokenizer variance before assembling the request payload. Headers are initialized with application/json, optional attribution metadata from _attribution_headers(), and bearer token authorization if OPENROUTER_API_KEY is present.

    Phase 2: Diagnostics & HTTP Dispatch

        emit_raw(
        "DEBUG",
        f"OpenRouter request | model={model} | {desc} | max_tokens={f'{max_tokens:,}' if max_tokens else 'omitted'} | "
        f"temperature={payload.get('temperature', 'omitted')} | catalog={'yes' if openrouter_catalog() else 'no'} | "
        f"attribution={'on' if 'HTTP-Referer' in headers else 'off'}",
        dest="LOG",
    )

    start = time.time()
    resp = _post(f"{openrouter_base_url()}/v1/chat/completions", headers, payload)
    generation_id = resp.headers.get("X-Generation-Id")
    result = _consume(resp)
    Before network transport commences, detailed execution metadata is emitted to the diagnostic logger, tracing the resolved token caps, temperature values, and catalog availability. The system records the start timestamp and initiates the HTTP request via _post(), targeting /v1/chat/completions under the resolved base URL. Upon opening the HTTP socket, it extracts the gateway generation identifier (X-Generation-Id) from response headers and immediately streams the body through _consume(resp) to parse SSE lines into an in-memory aggregation dictionary.

    Phase 3: Telemetry Recording & Debug Trace

        _record(model, result, raw_tokens, desc, time.time() - start, generation_id)
    if is_debug() and result["reasoning"]:
        emit_raw("DEBUG", f"REASONING:\n{result['reasoning']}", dest="LOG")

    finish, native = (result["finish"] or ""), (result["native"] or "")
    if finish == "error":
        raise RuntimeError(f"OpenRouter generation ended with an error (native_finish_reason={native or 'n/a'})")
    Once the stream concludes, the execution elapsed time is computed, and _record() updates internal session ledgers with token counts, cache hits, and calculated financial costs. If runtime debugging is enabled via is_debug() and reasoning traces were gathered from upstream models, the thought trace is written to the diagnostic log stream. The method then checks whether the generation terminated with a finish status of "error", raising a RuntimeError immediately to alert upstream pipeline coordinators.

    Phase 4: Termination Analysis & Output Classification

        if finish == "content_filter" or result["refusal"] or native.lower() in _REFUSAL_NATIVE_REASONS:
        category = native or finish or "refusal"
        # Filters on sampled output (safety, recitation, content_filter) may pass on another attempt.
        retryable = not result["refusal"] and native.lower() not in _DETERMINISTIC_NATIVE_REASONS
        count_event("OPENROUTER", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="OpenRouter", model=model, category=category)
        raise LLMRefusalError(model, category, provider="OPENROUTER", retryable=retryable)
    if not finish:
        # No data at all, or the connection dropped mid-answer: never return a partial reply.
        raise RuntimeError(
            f"OpenRouter stream ended without a finish_reason after {result['events']} events ({len(result['text']):,} characters received)"
        )
    if finish == "length":
        count_event("OPENROUTER", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="OpenRouter", max_tokens=f"{max_tokens:,}" if max_tokens else "default")
        return TruncatedResponse(result["text"])
    if not result["text"]:
        emit_raw("WARNING", f"OpenRouter response contained no text (finish_reason={finish or 'n/a'})", dest="LOG")
    return result["text"]
    In the final evaluation phase, the termination metadata is verified against policy blocks and length exhaustion. If the stream encountered a content filter, an explicit refusal string, or a native safety flag, the method determines retryability: deterministic triggers (like prohibited_content or spii) raise non-retryable LLMRefusalError exceptions, whereas stochastic output filters raise retryable variants. If the stream terminated abruptly without a finish reason (signifying dropped TCP sockets), a RuntimeError prevents returning incomplete outputs. If execution halted due to "length", output is returned wrapped in a TruncatedResponse instance; otherwise, the accumulated plain text string is returned.

    Parameters: * prompt (str): The complete synthesized prompt text destined for model execution. * thinking_level (str | None, optional): Reasoning intensity level ("minimal", "low", "medium", "high", "xhigh", "max"). Defaults to None.

    Returns: * str: The model's complete generated completion string, or a TruncatedResponse subclass if execution hit token ceilings.

    Raises: * ValueError: Raised if OPENROUTER_MODEL is not defined in the process environment. * LLMRefusalError: Raised when upstream safety policies, moderation filters, or content blocks reject the prompt. * RuntimeError: Raised on non-retryable HTTP failures, gateway stream errors, or abruptly terminated connections.

    Internal Helpers

    _read_timeout()

    Visibility: Private
    Signature: def _read_timeout() -> float:

    Description: Resolves the maximum socket read timeout allowed between successive SSE streaming events. It inspects the OPENROUTER_TIMEOUT_SECONDS environment variable, defaulting to 300.0 seconds if unset or invalid. To avoid premature connection termination during deep reasoning pauses, the returned value is clamped to a lower boundary of 30.0 seconds.

    def _read_timeout() -> float:
    try:
        return max(float(os.getenv("OPENROUTER_TIMEOUT_SECONDS", "300")), 30.0)
    except ValueError:
        return 300.0

    The helper safely wraps the environment lookup inside a try-except block targeting ValueError. If a non-numeric string is provided, it falls back to the 300.0-second default. When a valid float is parsed, max(..., 30.0) prevents misconfigurations from setting dangerously low read timeouts that would abort valid model reasoning pauses.

    Parameters: * None.

    Returns: * float: The resolved timeout threshold in seconds (minimum 30.0).

    Raises: * None.

    _reasoning()

    Visibility: Private
    Signature: def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:

    Description: Assembles the "reasoning" configuration block based on the requested level and catalog capabilities. It inspects whether the model supports explicit effort tiers ("supported_efforts") or raw token allocations ("supports_max_tokens"). In the absence of catalog metadata, it constructs an unverified effort payload, relying on server-side clamping.

    Phase 1: Level Validation & Unverified Model Fallback

        if not level:
        return None, "default"
    level = level.lower()
    exclude = not is_debug()
    if info is None:
        # Catalog unavailable or model unknown: send the level; OpenRouter clamps server-side.
        return {"effort": level, "exclude": exclude}, f"effort={level} (unverified)"
    reasoning = info.get("reasoning")
    if not isinstance(reasoning, dict) and "reasoning" not in (info.get("supported_parameters") or []):
        if warn_once("openrouter_no_reasoning", model):
            emit("WARN_THINKING_NOT_SUPPORTED", model=model)
        return None, "unsupported"
    The method begins by returning early if no reasoning level was requested. It forces the level string to lowercase and determines the exclude flag: reasoning text is stripped from the completion unless is_debug() is active. If the model catalog is unavailable or the model is unrecognized, it generates an unverified effort payload. If catalog data is present but indicates that reasoning is unsupported by parameters or metadata, it issues a single warning via warn_once and returns None.

    Phase 2: Budget-Only Reasoning Configuration

        meta = reasoning if isinstance(reasoning, dict) else {}
    if "supported_efforts" not in meta and meta.get("supports_max_tokens"):
        # Budget-only model: an explicit thinking budget (OpenRouter's effort ratio of a large
        # max_tokens would over-spend). It must stay below max_tokens.
        budget = _REASONING_BUDGETS.get(level, _REASONING_BUDGETS["medium"])
        if max_tokens:
            budget = max(min(budget, max_tokens - 1_024), 1_024)
        return {"max_tokens": budget, "exclude": exclude}, f"reasoning.max_tokens={budget}"
    If the model metadata lacks supported_efforts but contains supports_max_tokens, the model requires an explicit numeric token budget rather than an abstract effort string. The helper resolves the budget against _REASONING_BUDGETS (defaulting to the "medium" allocation of 8,192 tokens). If an upper completion limit (max_tokens) is active, it constrains the thinking allocation to leave at least 1,024 completion tokens free, clamping the budget floor at 1,024 tokens.

    Phase 3: Effort Clamping & Unsupported Guard

        efforts = meta.get("supported_efforts")
    effort = level
    if efforts:
        effort = clamp_level(level, [e for e in efforts if e != "none"]) or level
        if effort != level and warn_once("openrouter_level", model, level):
            emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effort, model=model)
    return {"effort": effort, "exclude": exclude}, f"effort={effort}"
    When supported_efforts is defined, the helper extracts the allowed tiers, explicitly stripping "none" to prevent HTTP 400 validation rejections on architectures with mandatory reasoning. It leverages clamp_level() from thinking.py to locate the closest compatible tier. If clamping alters the requested intensity, a deduplicated warning is logged. The final dictionary contains the resolved effort and the exclusion flag.

    Parameters: * model (str): The OpenRouter model slug. * info (dict | None): The model catalog entry, or None if unknown. * level (str | None): The requested reasoning intensity. * max_tokens (int | None, optional): The calculated maximum generation ceiling. Defaults to None.

    Returns: * tuple[dict | None, str]: A 2-tuple containing: 1. dict | None: The serialized payload for the "reasoning" key, or None if unsupported. 2. str: Diagnostic description of the applied configuration.

    Raises: * None.

    _sends_temperature()

    Visibility: Private
    Signature: def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:

    Description: Determines whether the temperature parameter should be included in the request payload. Sampling parameters are suppressed if reasoning is active, if the model architecture belongs to a family that rejects sampling controls, or if catalog metadata flags temperature as unsupported or overridden by default reasoning.

    def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:
    if reasoning is not None or rejects_sampling_params(model):
        return False
    if info is None:
        return True
    if "temperature" not in (info.get("supported_parameters") or []):
        return False
    meta = info.get("reasoning") if isinstance(info.get("reasoning"), dict) else {}
    return not (meta.get("mandatory") or meta.get("default_enabled"))

    The function checks if reasoning is active or if rejects_sampling_params(model) (from llm_config.py) matches the model identifier, returning False immediately. If catalog information is unavailable, it permits temperature by default. If catalog metadata exists, it verifies that "temperature" is declared under supported_parameters, and confirms that reasoning is neither mandatory nor enabled by default on the upstream model.

    Parameters: * model (str): The target model identifier. * info (dict | None): The OpenRouter catalog metadata dictionary. * reasoning (dict | None): The active reasoning payload structure, if any.

    Returns: * bool: True if temperature should be sent; otherwise, False.

    Raises: * None.

    _max_tokens()

    Visibility: Private
    Signature: def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:

    Description: Computes the output token budget for the request, clamping planned reservations against residual context space. It queries openrouter_output_budget(model, level) and subtracts input prompt tokens and safety margins (CONTEXT_MARGIN) from the context window length reported by OpenRouter's catalog.

    def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:
    """Planned max_tokens clamped to the context left after the prompt; None = omit (unknown model)."""
    planned = openrouter_output_budget(model, level)
    context = ((info or {}).get("top_provider") or {}).get("context_length") or (info or {}).get("context_length")
    if planned and context:
        planned = min(planned, max(context - prompt_tokens - CONTEXT_MARGIN, 4_096))
    return planned

    The implementation first resolves the planned output budget via openrouter_output_budget(). It inspects catalog metadata, preferring top_provider.context_length before falling back to top-level context_length. If both a planned budget and a context ceiling exist, it clamps the planned allocation so it does not exceed the remaining capacity (context - prompt_tokens - CONTEXT_MARGIN), maintaining a guaranteed baseline floor of 4,096 tokens.

    Parameters: * model (str): The target model identifier. * info (dict | None): The catalog metadata dictionary. * level (str | None): The active reasoning intensity level. * prompt_tokens (int): Scaled token count of the prompt payload.

    Returns: * int | None: Clamped token ceiling, or None if the model or its limits are unrecognized.

    Raises: * None.

    def _attribution_headers() -> dict:

    _error_body()

    Visibility: Private

    Description: Safely deserializes the JSON error payload from a failed HTTP response, handling nested error dictionaries and malformed non-JSON error pages.

    _apply_chunk()

    Visibility: Private
    Signature: def _apply_chunk(out: dict, chunk: dict) -> None:

    Description: Updates the running stream accumulator dictionary with delta fragments extracted from a single SSE event or non-streamed response chunk.

    def _apply_chunk(out: dict, chunk: dict) -> None:
    """Fold one stream chunk (or a whole non-streamed completion) into the _consume result."""
    out["events"] += 1
    if chunk.get("error"):
        err = chunk["error"]
        raise RuntimeError(f"OpenRouter stream error: {err.get('message', err) if isinstance(err, dict) else err}")
    if chunk.get("usage"):
        out["usage"] = chunk["usage"]
    for choice in chunk.get("choices") or []:
        delta = choice.get("delta") or choice.get("message") or {}
        if delta.get("content"):
            out["text"].append(delta["content"])
        if delta.get("reasoning"):
            out["reasoning"].append(delta["reasoning"])
        if delta.get("refusal"):
            out["refusal"] = delta["refusal"]
        if choice.get("finish_reason"):
            out["finish"] = choice["finish_reason"]
        if choice.get("native_finish_reason"):
            out["native"] = choice["native_finish_reason"]
        if choice.get("error"):
            err = choice["error"]
            raise RuntimeError(f"OpenRouter upstream error: {err.get('message', err) if isinstance(err, dict) else err}")

    The function increments the event counter and checks for mid-stream error payloads, raising a RuntimeError immediately if one is detected. It records usage metadata when provided in the chunk. It then iterates through choices, extracting fragments from either delta (in streaming mode) or message (in non-streaming fallback mode), appending content and reasoning strings, and capturing refusal, finish_reason, and native_finish_reason attributes.

    Error Handling

    Transient HTTP Status Handling

    Network communication over OpenRouter is safeguarded against transient upstream disconnections and traffic spikes. The driver automatically intercepts status codes defined in _RETRYABLE_STATUS (408, 429, 502, 503, 524, 529): * Up to _MAX_ATTEMPTS (3) tries are performed. * Delays honor server-supplied Retry-After headers if present and parseable as floats. * In the absence of Retry-After, an exponential backoff formula ($2^{\text{attempt}} \times 2$) is evaluated, capped at 60.0 seconds.

    Policy Violations, Moderation & Refusal Classification

    The module differentiates between deterministic rejections and transient content moderation filters: * HTTP 403 Inspection: _refusal_category() inspects the error payload of HTTP 403 responses. If the error matches _REFUSAL_ERROR_TYPES ("refusal", "content_policy_violation", "moderation") or metadata flags, an LLMRefusalError(retryable=False) is raised. * Native Finish Reason Mapping: During stream analysis, _REFUSAL_NATIVE_REASONS ({"refusal", "safety", "prohibited_content", "recitation", "blocklist", "spii", "content_filter"}) are flagged as refusals. * Deterministic vs. Retryable: If the stop reason is contained in _DETERMINISTIC_NATIVE_REASONS ({"refusal", "prohibited_content", "blocklist", "spii"}), it indicates an unrecoverable policy failure. Conversely, stochastic generation filters (such as recitation or content_filter) raise LLMRefusalError(retryable=True), signaling upstream graph controllers in nodes.py that resampling with different parameters may succeed.

    Stream Integrity & Truncation Handling

    • Dropped Connections: If the SSE stream completes without delivering a finish_reason, the module assumes a socket disconnect occurred mid-generation. It raises a RuntimeError rather than returning a corrupt partial string.
    • Length Exhaustion: If finish == "length", generation stopped due to token budget depletion. The module wraps the accumulated text in TruncatedResponse(result["text"]) and increments truncation event counters via count_event(). The upstream cache engine in call_llm.py detects the TruncatedResponse type and bypasses disk persistence.
