    llm_openrouter.py

    Source: utils/llm_openrouter.py

    Following the provider execution harness established in llm_gemini.py for Google's Gemini models, llm_openrouter.py serves as the execution adapter and low-level transport client for OpenRouter's OpenAI-compatible completions API. Rather than relying on hardcoded static capabilities per model, this module dynamically consults the OpenRouter remote catalog via llm_config.py to inspect model constraints, reasoning mechanisms, output ceilings, and sampling options at runtime. This catalog-driven design allows the codebase knowledge builder to dispatch prompts across hundreds of upstream model architectures (including Anthropic Claude, Google Gemini, Meta Llama, and Qwen) through a single unified HTTP interface without vendor SDK bloat.

    The module manages the complete lifecycle of an OpenRouter chat completion request: prompt sizing, reasoning parameter adaptation, optional application attribution headers, resilient HTTP transport, Server-Sent Events (SSE) decoding, and fine-grained usage bookkeeping. Transport operations stream chunks over SSE to prevent read timeouts during prolonged chain-of-thought phases while filtering out OpenRouter keep-alive signals. The component intercepts and parses server-side error envelopes, classifying rate limits and gateway timeouts as retryable, mapping content moderations and policy rejections into structured refusal errors, and wrapping length-truncated generations into sentinels that safeguard downstream cache integrity.

    Public API

    get_model()

    Visibility: Public
    Signature: def get_model() -> str:

    Description: Resolves and sanitizes the configured OpenRouter model identifier from the runtime process environment. It reads the OPENROUTER_MODEL environment variable, strips extraneous leading and trailing whitespace, and returns the raw string identifier. If the variable is unset or contains only whitespace, an empty string is returned, which subsequently triggers configuration assertion failures in downstream dispatchers.

    Returns: * str: The sanitized model name (e.g., "anthropic/claude-3.7-sonnet", "google/gemini-2.5-pro"), or an empty string if unconfigured.

    Example: 

    model = get_model()
if not model:
    raise ValueError("OPENROUTER_MODEL environment variable is required")

    The function reads directly from the environment to allow dynamic overrides during execution runs. Calling components verify this return value prior to initiating HTTP connection attempts or token reservations.

    build_payload()

    Visibility: Public
    Signature: def build_payload(prompt: str, model: str, level: str | None, prompt_tokens: int) -> tuple[dict, str]:

    Description: Constructs the complete OpenAI-compatible chat completion payload dictionary tailored specifically to the upstream model's declared specifications in the OpenRouter catalog. The function resolves model capabilities via openrouter_model_info(), determines planned completion ceilings through _max_tokens(), calculates reasoning parameters through _reasoning(), and conditionally evaluates sampling parameters via _sends_temperature().

    The payload construction process executes across two distinct phases:

    Phase 1: Catalog & Token Limit Resolution

    info = openrouter_model_info(model)
max_tokens = _max_tokens(model, info, level, prompt_tokens)
reasoning, desc = _reasoning(model, info, level, max_tokens)
payload = {
    "model": model,
    "messages": [{"role": "user", "content": prompt}],
    "stream": True,
}
if max_tokens:
    payload["max_tokens"] = max_tokens
    In this phase, the function looks up the model's structural metadata in the local catalog. It calculates the output token limit by subtracting prompt tokens and safety margins from the context window, and configures thinking parameters according to provider requirements. The base payload dictionary is initialized with streaming explicitly enabled ("stream": True).

    Phase 2: Reasoning & Sampling Parameter Synthesis

    if reasoning is not None:
    payload["reasoning"] = reasoning
if _sends_temperature(model, info, reasoning):
    try:
        payload["temperature"] = float(os.getenv("OPENROUTER_TEMPERATURE", "0.7"))
    except ValueError:
        payload["temperature"] = 0.7
return payload, desc
    In this phase, reasoning parameters (either an effort category or an integer token budget) are attached if supported. The helper then checks whether temperature sampling is valid for this model family and thinking state; if permitted, it parses OPENROUTER_TEMPERATURE (defaulting to 0.7) and injects it into the request dictionary alongside a diagnostic configuration string.

    Parameters: * prompt (str): The complete input text prompt to be processed by the model. * model (str): The target OpenRouter model identifier. * level (str | None): The requested reasoning or thinking effort level (e.g., "low", "high", None). * prompt_tokens (int): The calibrated estimate of input prompt tokens used to enforce context ceiling constraints.

    Returns: * tuple[dict, str]: A 2-tuple containing: 1. dict: The serialized JSON payload ready for submission to /v1/chat/completions. 2. str: A human-readable diagnostic description of active reasoning parameters (e.g., "effort=high", "reasoning.max_tokens=8192", or "default").

    Example: 

    payload, desc = build_payload(
    prompt="Explain the AST architecture",
    model="anthropic/claude-3.7-sonnet",
    level="high",
    prompt_tokens=1542,
)

    call_openrouter()

    Visibility: Public
    Signature: def call_openrouter(prompt: str, thinking_level: str | None = None) -> str:

    Description: The primary entry point for executing single-turn prompts via the OpenRouter API. It orchestrates preflight validation, token calibration, payload construction, resilient network transport, SSE stream aggregation, usage accounting, and termination classification. The function enforces robust error checking, raising LLMRefusalError on provider moderation rejections or policy blocks, and returning TruncatedResponse instances when generations hit max token cutoffs.

    The execution workflow is structured into four distinct sequential phases:

    Phase 1: Environment & Token Preflight

    from utils.token_utils import count_tokens_raw, token_ratio

model = get_model()
if not model:
    raise ValueError("OPENROUTER_MODEL environment variable is required")
api_key = os.getenv("OPENROUTER_API_KEY", "").strip()
raw_tokens = count_tokens_raw(prompt)  # memoized: the node already counted this prompt
payload, desc = build_payload(prompt, model, thinking_level, int(raw_tokens * token_ratio()))
    The method begins by asserting the presence of OPENROUTER_MODEL. It counts raw tiktoken prompt tokens via count_tokens_raw() and scales them using token_ratio() to derive an accurate baseline for context-window clamping. It then builds the payload and extracts runtime metadata.

    Phase 2: Payload Assembly & Attribution Setup

    headers = {"Content-Type": "application/json", **_attribution_headers()}
if api_key:
    headers["Authorization"] = f"Bearer {api_key}"
max_tokens = payload.get("max_tokens")
emit_raw(
    "DEBUG",
    f"OpenRouter request | model={model} | {desc} | max_tokens={f'{max_tokens:,}' if max_tokens else 'omitted'} | "
    f"temperature={payload.get('temperature', 'omitted')} | catalog={'yes' if openrouter_catalog() else 'no'} | "
    f"attribution={'on' if 'HTTP-Referer' in headers else 'off'}",
    dest="LOG",
)
    Standard JSON headers are prepared alongside opt-in attribution headers generated by _attribution_headers(). If an API key is available, the Authorization bearer token header is set. Comprehensive debugging telemetry is logged before initiating network I/O.

    Phase 3: HTTP Streaming Execution & Event Consumption

    start = time.time()
resp = _post(f"{openrouter_base_url()}/v1/chat/completions", headers, payload)
generation_id = resp.headers.get("X-Generation-Id")
result = _consume(resp)
_record(model, result, raw_tokens, desc, time.time() - start, generation_id)
if is_debug() and result["reasoning"]:
    emit_raw("DEBUG", f"REASONING:\n{result['reasoning']}", dest="LOG")
    The request is dispatched through _post(), which manages transport retries and status validation. The active HTTP response is passed to _consume() to parse the SSE stream into text buffers, reasoning text, and metadata. _record() updates the central ledger, calculates token ratios, and logs latency metrics.

    Phase 4: Telemetry Recording & Response Classification

    finish, native = (result["finish"] or ""), (result["native"] or "")
if finish == "error":
    raise RuntimeError(f"OpenRouter generation ended with an error (native_finish_reason={native or 'n/a'})")
if finish == "content_filter" or result["refusal"] or native.lower() in _REFUSAL_NATIVE_REASONS:
    category = native or finish or "refusal"
    # Filters on sampled output (safety, recitation, content_filter) may pass on another attempt.
    retryable = not result["refusal"] and native.lower() not in _DETERMINISTIC_NATIVE_REASONS
    count_event("OPENROUTER", "refusals")
    emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="OpenRouter", model=model, category=category)
    raise LLMRefusalError(model, category, provider="OPENROUTER", retryable=retryable)
if not finish:
    # No data at all, or the connection dropped mid-answer: never return a partial reply.
    raise RuntimeError(
        f"OpenRouter stream ended without a finish_reason after {result['events']} events ({len(result['text']):,} characters received)"
    )
if finish == "length":
    count_event("OPENROUTER", "truncations")
    emit("WARN_LLM_TRUNCATED", provider="OpenRouter", max_tokens=f"{max_tokens:,}" if max_tokens else "default")
    return TruncatedResponse(result["text"])
if not result["text"]:
    emit_raw("WARNING", f"OpenRouter response contained no text (finish_reason={finish or 'n/a'})", dest="LOG")
return result["text"]
    The final phase evaluates completion status flags. Unrecoverable stream terminations or upstream failures raise RuntimeError. Policy blocks, guardrails, and model refusals trigger LLMRefusalError (flagged as retryable if caused by stochastic sampling filters like safety or recitation). Generations terminated due to context exhaustion return a TruncatedResponse instance to protect disk caches from poisoning.

    Parameters: * prompt (str): The complete text prompt dispatched to the model. * thinking_level (str | None, optional): The target reasoning effort level (e.g., "minimal", "low", "medium", "high", "max"). Defaults to None.

    Returns: * str: The accumulated completion text returned by the model. May be an instance of TruncatedResponse if cut off by token limits.

    Raises: * ValueError: If OPENROUTER_MODEL is missing or empty. * LLMRefusalError: If the model or gateway refuses the prompt due to policy violations, content filtering, or safety triggers. * RuntimeError: If network communication exhausts maximum retry attempts, an upstream stream error occurs, or the stream terminates prematurely without a valid finish_reason.

    Example: 

    from utils.llm_openrouter import call_openrouter

response = call_openrouter(
    prompt="Generate an architectural summary of utils/flow.py",
    thinking_level="medium",
)

    Internal Helpers

    _read_timeout()

    Visibility: Private
    Signature: def _read_timeout() -> float:

    Description: Resolves the HTTP read timeout duration for streaming connections. It parses the OPENROUTER_TIMEOUT_SECONDS environment variable, enforcing a minimum lower bound of 30.0 seconds to prevent premature disconnections during lengthy provider reasoning phases. If the variable is unset or contains non-numeric text, it defaults to 300.0 seconds.

    Returns: * float: The effective stream silence timeout in seconds (minimum 30.0).

    Example: 

    def _read_timeout() -> float:
    try:
        return max(float(os.getenv("OPENROUTER_TIMEOUT_SECONDS", "300")), 30.0)
    except ValueError:
        return 300.0

    The function handles string parsing defensively using a try-except ValueError block. It guarantees that connection handlers receive a valid floating-point deadline even under misconfigured deployment environments.

    _reasoning()

    Visibility: Private
    Signature: def _reasoning(model: str, info: dict | None, level: str | None, max_tokens: int | None = None) -> tuple[dict | None, str]:

    Description: Adapts abstract reasoning level requests into provider-specific parameter schemas supported by OpenRouter. It parses catalog metadata to determine whether the model accepts reasoning effort strings ("effort"), explicit integer token budgets ("max_tokens"), or rejects reasoning entirely.

    The helper executes across two distinct logical phases:

    Phase 1: Level Validation & Catalog Verification

    if not level:
    return None, "default"
level = level.lower()
exclude = not is_debug()
if info is None:
    # Catalog unavailable or model unknown: send the level; OpenRouter clamps server-side.
    return {"effort": level, "exclude": exclude}, f"effort={level} (unverified)"
reasoning = info.get("reasoning")
if not isinstance(reasoning, dict) and "reasoning" not in (info.get("supported_parameters") or []):
    if warn_once("openrouter_no_reasoning", model):
        emit("WARN_THINKING_NOT_SUPPORTED", model=model)
    return None, "unsupported"
    The phase verifies whether a level was requested. If the catalog is missing, it falls back to sending the unverified effort level. If the model catalog explicitly indicates that reasoning is unsupported, it logs a warning once via warn_once() and returns None.

    Phase 2: Budget-Only vs Effort-Based Parameter Assembly

    meta = reasoning if isinstance(reasoning, dict) else {}
if "supported_efforts" not in meta and meta.get("supports_max_tokens"):
    # Budget-only model: an explicit thinking budget (OpenRouter's effort ratio of a large
    # max_tokens would over-spend). It must stay below max_tokens.
    budget = _REASONING_BUDGETS.get(level, _REASONING_BUDGETS["medium"])
    if max_tokens:
        budget = max(min(budget, max_tokens - 1_024), 1_024)
    return {"max_tokens": budget, "exclude": exclude}, f"reasoning.max_tokens={budget}"
efforts = meta.get("supported_efforts")
effort = level
if efforts:
    effort = clamp_level(level, [e for e in efforts if e != "none"]) or level
    if effort != level and warn_once("openrouter_level", model, level):
        emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effort, model=model)
return {"effort": effort, "exclude": exclude}, f"effort={effort}"
    If the model only supports numeric token budgets (supports_max_tokens), the level is mapped to an integer budget via _REASONING_BUDGETS and clamped below max_tokens - 1024. Otherwise, effort strings are clamped against supported_efforts using clamp_level() (explicitly filtering out "none" to prevent HTTP 400 errors on mandatory-reasoning models).

    Parameters: * model (str): The target model identifier. * info (dict | None): The model catalog entry returned by openrouter_model_info(). * level (str | None): The requested reasoning effort level. * max_tokens (int | None, optional): The resolved generation output ceiling. Defaults to None.

    Returns: * tuple[dict | None, str]: A 2-tuple containing: 1. dict | None: The reasoning configuration dictionary (e.g., {"effort": "high", "exclude": True}) or None. 2. str: A description string for logging.

    Example: 

    reasoning, desc = _reasoning(
    model="anthropic/claude-3.7-sonnet",
    info={"reasoning": {"supported_efforts": ["low", "medium", "high"]}},
    level="high",
    max_tokens=16384,
)
# Returns: ({"effort": "high", "exclude": True}, "effort=high")

    _sends_temperature()

    Visibility: Private
    Signature: def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:

    Description: Determines whether the temperature parameter can safely be transmitted in the completion request. Many reasoning models (such as o1, o3, and newer Anthropic or Gemini architectures) reject sampling parameters when reasoning is enabled or mandatory. The helper disables temperature if reasoning is active, if the model family rejects sampling according to rejects_sampling_params(), if the catalog omits temperature from supported_parameters, or if reasoning is configured as mandatory or enabled by default.

    Parameters: * model (str): The model identifier. * info (dict | None): The model metadata dictionary from the catalog. * reasoning (dict | None): The resolved reasoning configuration payload.

    Returns: * bool: True if temperature should be included in the request payload; otherwise False.

    Example: 

    def _sends_temperature(model: str, info: dict | None, reasoning: dict | None) -> bool:
    if reasoning is not None or rejects_sampling_params(model):
        return False
    if info is None:
        return True
    if "temperature" not in (info.get("supported_parameters") or []):
        return False
    meta = info.get("reasoning") if isinstance(info.get("reasoning"), dict) else {}
    return not (meta.get("mandatory") or meta.get("default_enabled"))

    This gatekeeper protects API calls from immediate HTTP 400 rejection errors caused by sending invalid parameter combinations to reasoning-centric backends.

    _max_tokens()

    Visibility: Private
    Signature: def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:

    Description: Calculates the upper limit for completion tokens (max_tokens), ensuring that the requested generation budget does not exceed the remaining capacity of the model's total context window. It queries openrouter_output_budget() for the model family's default ceiling and retrieves context length limits from the catalog metadata. If both limits are known, it clamps the planned output budget to the remaining context space minus CONTEXT_MARGIN, enforcing an absolute floor of 4,096 tokens.

    Parameters: * model (str): The model identifier. * info (dict | None): The model catalog dictionary. * level (str | None): The active thinking effort level. * prompt_tokens (int): Calibrated input prompt token count.

    Returns: * int | None: The clamped maximum output tokens, or None if the model or its limits are unknown.

    Example: 

    def _max_tokens(model: str, info: dict | None, level: str | None, prompt_tokens: int) -> int | None:
    planned = openrouter_output_budget(model, level)
    context = ((info or {}).get("top_provider") or {}).get("context_length") or (info or {}).get("context_length")
    if planned and context:
        planned = min(planned, max(context - prompt_tokens - CONTEXT_MARGIN, 4_096))
    return planned

    If the catalog lacks context window data, the function returns the planned budget unmodified, leaving enforcement to OpenRouter's upstream defaults.

    _attribution_headers()

    Visibility: Private

Identification headers are strictly suppressed unless the operator explicitly sets the OPENROUTER_APP_URL environment variable. When present, the function populates HTTP-Referer, X-OpenRouter-Title, and legacy X-Title headers using the internal application identity string ("Codebase Knowledge Builder").

    Returns: * dict: A dictionary containing attribution headers if configured, or an empty dictionary if unset.

    Example: 

    def _attribution_headers() -> dict:
    url = os.getenv("OPENROUTER_APP_URL", "").strip()
    if not url:
        return {}
    return {"HTTP-Referer": url, "X-OpenRouter-Title": _APP_TITLE, "X-Title": _APP_TITLE}

    This opt-in design ensures zero external telemetry or application tracking occurs during standard, unconfigured CLI executions.

    _error_body()

    Visibility: Private
    Signature: def _error_body(resp: requests.Response) -> dict:

    Description: Safely extracts and unwraps the structured error payload from an HTTP error response. It attempts to parse the response body as JSON and resolves nested "error" keys common to OpenAI-compatible error payloads. If JSON parsing fails or the content is malformed, it gracefully returns an empty dictionary or wraps scalar messages into a standard {"message": str(err)} format.

    Parameters: * resp (requests.Response): The HTTP error response.

    Returns: * dict: A dictionary containing extracted error details, or an empty dictionary.

    Example: 

    def _error_body(resp) -> dict:
    try:
        body = resp.json()
    except ValueError:
        return {}
    err = body.get("error", body) if isinstance(body, dict) else body
    return err if isinstance(err, dict) else {"message": str(err)}

    This helper prevents uncaught JSON decoding exceptions from masking the underlying HTTP transport status codes.

    _error_detail()

    Visibility: Private
    Signature: def _error_detail(resp: requests.Response) -> str:

    Description: Synthesizes a human-readable diagnostic error string from an HTTP response. It inspects the parsed payload from _error_body(), retrieving primary error messages alongside underlying provider details (such as raw error output or upstream provider identifiers). If structured error fields cannot be found, it truncates the raw response text to 300 characters.

    Parameters: * resp (requests.Response): The HTTP response to inspect.

    Returns: * str: A formatted error description string suitable for log output.

    Example: 

    def _error_detail(resp) -> str:
    err = _error_body(resp)
    if not err:
        return resp.text[:300].strip()
    meta = err.get("metadata") or {}
    raw = meta.get("raw") or meta.get("provider_name") or ""
    return f"{err.get('message', err)}" + (f" ({raw})" if raw else "")

    By appending upstream provider diagnostics in parentheses, this function clarifies errors originating from specific underlying providers behind OpenRouter.

    _refusal_category()

    Visibility: Private
    Signature: def _refusal_category(resp: requests.Response) -> str | None:

    Description: Inspects an HTTP 403 Forbidden response to determine if it represents a policy violation, content moderation block, or guardrail refusal rather than an authentication failure. It checks error type identifiers against known refusal categories (_REFUSAL_ERROR_TYPES) and parses metadata reason arrays.

    Parameters: * resp (requests.Response): The HTTP response object.

    Returns: * str | None: The classified refusal category string (e.g., "content_policy_violation", "moderation", "safety"), or None if the response is not a moderation rejection.

    Example: 

    def _refusal_category(resp) -> str | None:
    if resp.status_code != 403:
        return None
    err = _error_body(resp)
    meta = err.get("metadata") or {}
    kind = str(err.get("type") or err.get("error_type") or meta.get("error_type") or "").lower()
    if kind in _REFUSAL_ERROR_TYPES:
        return kind
    if meta.get("reasons") or meta.get("flagged_input"):
        reasons = meta.get("reasons") or ["moderation"]
        return ",".join(map(str, reasons)) if isinstance(reasons, list) else str(reasons)
    return None

    This classification allows the orchestrator to differentiate permanent policy blocks from retryable network or auth errors.

    _post()

    Visibility: Private
    Signature: def _post(url: str, headers: dict, payload: dict) -> requests.Response:

    Description: Dispatches an HTTP POST request to the OpenRouter chat completions endpoint with bounded retry handling for transient errors. It configures connect and read timeouts, manages exponential backoffs, respects server-side Retry-After headers, and intercepts moderation refusals before surfacing fatal exceptions.

    The method operates in two distinct phases:

    Phase 1: Transient Retry Loop & Timeout Configuration

    Phase 2: Response Status Inspection & Refusal Trapping

    _apply_chunk()

    Visibility: Private
    Signature: def _apply_chunk(out: dict, chunk: dict) -> None:

    Description: Updates the running accumulator dictionary with data extracted from a single SSE event or completion chunk. It increments the total event count, raises exceptions on inline stream errors, stores token usage objects, and appends incoming content or reasoning deltas to their respective lists.

    Parameters: * out (dict): The target accumulator dictionary modified in-place. * chunk (dict): The parsed JSON chunk received over the wire.

    Raises: * RuntimeError: If the chunk or choice object contains an upstream error structure.

    Example:

        err = chunk["error"]
        raise RuntimeError(f"OpenRouter stream error: {err.get('message', err) if isinstance(err, dict) else err}")
    if chunk.get("usage"):
        out["usage"] = chunk["usage"]
    for choice in chunk.get("choices") or []:
        delta = choice.get("delta") or choice.get("message") or {}
        if delta.get("content"):
            out["text"].append(delta["content"])
        if delta.get("reasoning"):
            out["reasoning"].append(delta["reasoning"])
        if delta.get("refusal"):
            out["refusal"] = delta["refusal"]
        if choice.get("finish_reason"):
            out["finish"] = choice["finish_reason"]
        if choice.get("native_finish_reason"):
            out["native"] = choice["native_finish_reason"]
        if choice.get("error"):
            err = choice["error"]
            raise RuntimeError(f"OpenRouter upstream error: {err.get('message', err) if isinstance(err, dict) else err}")

    This helper abstracts schema differences between streaming delta payloads (choice["delta"]) and static completion payloads (choice["message"]).

    Notable Error Patterns and Resolution Rules

    1. Transient Network and Gateway Failures: Connection errors, socket read timeouts, and HTTP status codes defined in _RETRYABLE_STATUS (408, 429, 502, 503, 524, 529) do not immediately terminate execution. _post() executes up to 3 attempts. When a server returns a Retry-After header, the client pauses for the indicated duration (capped at 60 seconds); otherwise, it applies exponential backoff delays (2**attempt * 2).

    2. HTTP 403 Moderation Rejection vs Authentication Errors: Standard HTTP 403 Forbidden errors can signify either an invalid API key or an upstream content moderation rejection. _refusal_category() inspects the error payload's type and metadata.reasons fields. If flagged as a policy violation, moderation block, or guardrail refusal, it raises LLMRefusalError(retryable=False). Unmatched 403 responses raise a standard RuntimeError.

    3. Stream Disconnection and Incomplete Outputs: If an SSE stream terminates without emitting a final finish_reason (e.g., due to an interrupted connection or proxy termination), the module rejects the accumulated text buffer and raises a RuntimeError. This prevents partial completions from entering downstream processing stages.

    4. Stochastic vs. Deterministic Refusals: In call_openrouter(), completion refusals are bifurcated:

    5. Deterministic Refusals: Explicit model refusals or stops matching _DETERMINISTIC_NATIVE_REASONS ("refusal", "prohibited_content", "blocklist", "spii") raise LLMRefusalError(retryable=False). Upstream callers cache these refusals and avoid redundant retry attempts.

    6. Stochastic Refusals: Terminations triggered by candidate sampling filters ("content_filter", "safety", "recitation") raise LLMRefusalError(retryable=True), allowing the orchestrator to retry the prompt with different sampling conditions.

    7. Cache-Protection via Sentinel Types: When a generation terminates with finish_reason == "length", the function wraps the accumulated text in a TruncatedResponse instance (subclassed from str). Upstream caching layers in call_llm.py detect this sentinel type and bypass disk caching, preventing corrupted or cut-off outputs from persisting.
