    utils.crawl_github_files

    Original Source File Path: utils/crawl_github_files.py

    Technical documentation and API reference for the remote repository ingestion module utils.crawl_github_files. This module provides capabilities to inspect, filter, and fetch source files from remote GitHub repositories using either local Git SSH cloning into temporary directories or direct traversal via the GitHub REST API v3.

    Overview

    The utils.crawl_github_files module is responsible for extracting raw file trees and text contents from remote GitHub repositories. It serves as an entry point for repository ingestion within the Codebase-Knowledge-Builder architecture.

    Key Capabilities

    • Dual Retrieval Strategy:
    • SSH Clones (git@... or .git): Invokes Git via GitPython (git.Repo.clone_from) into a managed tempfile.TemporaryDirectory(), scanning files locally via os.walk().
    • GitHub REST API (https://github.com/...): Parses owner, repository, branch/commit references, and subpaths from standard web URLs, fetching tree hierarchies and file blobs recursively over HTTP.
    • Granular Filtering & Exclusion:
    • Path and filename glob matching via fnmatch using include_patterns and exclude_patterns.
    • Dynamic .gitignore parsing using pathspec (either by reading repository .gitignore directly or fetching it via the GitHub API).
    • Defensive Content Ingestion:
    • Automatic size enforcement (max_file_size, default 1 MB).
    • Binary and non-UTF-8 detection with fallback handling.
    • Rate-limit backoff handling against GitHub API 403/429 limits using X-RateLimit-Reset response headers.
    • Path Normalization: Supports root-relative or subtree-relative path transformations (use_relative_paths).

    Description:
    Main entry point for repository crawling. Analyzes the structure of repo_url to branch into either local temporary cloning (for SSH connections) or recursive REST API polling. It normalizes pattern lists, loads applicable .gitignore match specifications, manages console telemetry using ANSI terminal color codes, and compiles a comprehensive map of file paths to raw string contents alongside execution statistics.

    Parameters: * repo_url (str): Full URL of the repository (e.g., https://github.com/microsoft/autogen/tree/main/python or git@github.com:owner/repo.git). * token (str, optional): GitHub Personal Access Token (PAT) used for private repository authentication or raising rate limits from 60 to 5,000 requests per hour. Defaults to None. * max_file_size (int, optional): Upper size limit in bytes for downloaded files. Defaults to 1048576 (1 MB). * use_relative_paths (bool, optional): If True, strips the root subpath prefix from returned file dictionary keys. Defaults to False. * include_patterns (Union[str, Set[str]], optional): Glob pattern(s) specifying matching files to retain (e.g., {"*.py", "*.md"}). Defaults to None (all files allowed). * exclude_patterns (Union[str, Set[str]], optional): Glob pattern(s) specifying files or directories to ignore. Defaults to None.

    Returns: * Dict[str, Any]: A structured dictionary containing: * "files" (Dict[str, str]): Mapping of repository-relative (or subpath-relative) file paths to their decoded string content. * "stats" (Dict[str, Any]): Execution statistics including downloaded_count, skipped_count, skipped_files, base_path, include_patterns, exclude_patterns, and optional source descriptor.

    Raises: * ValueError: If the provided HTTP GitHub URL does not contain at least owner and repo path segments. * Exception: If GitHub API rate limits are exceeded and no token was supplied to authorize higher quotas.

    The function normalizes include/exclude filtering parameters into sets before checking whether the URL qualifies as an SSH target. For SSH connections, it clones the entire tree into an ephemeral directory created by tempfile.TemporaryDirectory(), compiles a PathSpec parser from .gitignore if present, walks the directory tree while skipping ignored folders in-place, and reads file contents using UTF-8-sig encoding.

    For HTTP URLs, crawl_github_files extracts the repository coordinates using urllib.parse.urlparse. If a specific tree ref or nested subdirectory path is provided (e.g., /tree/main/sub/dir), it verifies the ref against branch and git tree endpoints, then invokes the internal fetch_contents() closure to traverse GitHub's content endpoints.

    def should_include_file(
    file_path: str, 
    file_name: str, 
    gitignore_spec: Optional[pathspec.PathSpec] = None
) -> bool:

    Description:
    Applies multi-stage filtering against a given file. It verifies if the file name matches include_patterns (if defined), validates that the relative path is not blocked by repository .gitignore rules via pathspec, and verifies that the path does not match any entry in exclude_patterns.

    Parameters: * file_path (str): Relative path of the candidate file within the repository. * file_name (str): Base filename component of the candidate file. * gitignore_spec (Optional[pathspec.PathSpec]): Compiled PathSpec instance initialized with gitwildmatch rules from the repository's .gitignore. Defaults to None.

    Returns: * bool: True if the file satisfies all inclusion criteria and avoids all exclusions; False otherwise.

    Implementation Logic: 

        def should_include_file(file_path: str, file_name: str, gitignore_spec=None) -> bool:
        """Determine if a file should be included based on patterns"""
        # If no include patterns are specified, include all files
        if not include_patterns:
            include_file = True
        else:
            # Check if file matches any include pattern
            include_file = any(fnmatch.fnmatch(file_name, pattern) for pattern in include_patterns)

        # Check gitignore if provided
        if include_file and gitignore_spec:
            if gitignore_spec.match_file(file_path):
                return False

        # If exclude patterns are specified, check if file should be excluded
        if exclude_patterns and include_file:
            # Exclude if file matches any exclude pattern
            exclude_file = any(fnmatch.fnmatch(file_path, pattern) for pattern in exclude_patterns)
            return not exclude_file

        return include_file

    The filter performs short-circuit evaluation. If include_patterns is provided, the filename must match at least one pattern via fnmatch.fnmatch(). If valid, the relative file path is checked against the parsed gitignore_spec. If it passes gitignore validation, it is evaluated against exclude_patterns. Any positive match in exclude_patterns causes the function to return False.

    def fetch_branches(owner: str, repo: str) -> List[Dict[str, Any]]:

    Description:
    Queries the GitHub REST API endpoint (GET /repos/{owner}/{repo}/branches) to list all active branches in the repository. Used during URL parsing to match branch names containing forward slashes (e.g., feature/v1) against URL path components.

    Parameters: * owner (str): GitHub organization or user account name. * repo (str): GitHub repository name.

    Returns: * List[Dict[str, Any]]: List of branch dictionaries returned by the GitHub API. Returns an empty list ([]) if the request fails or returns an HTTP error.

    Raises: * Exception: When a rate-limit error (HTTP 403 or 429) occurs and no access token was configured.

    Implementation Logic: 

        def fetch_branches(owner: str, repo: str):
        """Get brancshes of the repository"""

        url = f"https://api.github.com/repos/{owner}/{repo}/branches"
        response = requests.get(url, headers=headers, timeout=(30, 30))

        if response.status_code in (403, 429) and not token:
            raise Exception("GitHub API rate limit exceeded. Please provide a GitHub token using --token or GITHUB_TOKEN env var.")

        if response.status_code == 404:
            if not token:
                print(f"Error 404: Repository not found or is private.\n"
                      f"If this is a private repository, please provide a valid GitHub token via the 'token' argument or set the GITHUB_TOKEN environment variable.")
            else:
                print(f"Error 404: Repository not found or insufficient permissions with the provided token.\n"
                      f"Please verify the repository exists and the token has access to this repository.")
            return []

        if response.status_code != 200:
            print(f"Error fetching the branches of {owner}/{repo}: {response.status_code} - {response.text}")
            return []

        return response.json()

    The function executes a GET request with a 30-second connect/read timeout. It validates the response status code, emitting diagnostic console messages for 404 responses depending on whether an authentication token was supplied. If rate limits are exceeded without a token, execution halts immediately with an explanatory exception.

    Implementation Logic: 

        def check_tree(owner: str, repo: str, tree: str):
        """Check the repository has the given tree"""

    def fetch_contents(path: str) -> None:

    Description:
    Recursively inspects directories and downloads files from GitHub's Contents API (GET /repos/{owner}/{repo}/contents/{path}). It handles rate-limit backoff, evaluates .gitignore and glob filters, ignores directories matching exclusions, downloads file contents using raw URLs or base64 decoding, and updates the shared files map and counter registries.

    Parameters: * path (str): Repository-relative subdirectory or file path to query.

    Returns: * None: Populates outer-scope data structures (files, api_counters, api_skipped_size, api_skipped_non_text) in place.

    Raises: * Exception: When an unauthenticated rate limit is triggered.

    Implementation Logic: 

        def fetch_contents(path):
        """Fetch contents of the repository at a specific path and commit"""
        url = f"https://api.github.com/repos/{owner}/{repo}/contents/{path}"

        response = requests.get(url, headers=headers, params=params, timeout=(30, 30))

        if response.status_code in (403, 429) and 'rate limit exceeded' in response.text.lower():

    When an authenticated rate-limit threshold (HTTP 403 or 429) is encountered, fetch_contents calculates sleep duration using the X-RateLimit-Reset header and sleeps before retrying the call. For each item returned in directory listings: * Directory (type == "dir"): Evaluates gitignore_spec and exclude_patterns. If excluded, skips recursion; otherwise, recurses down the tree. * File (type == "file"): Verifies size limits and include/exclude patterns. Downloads raw content via item["download_url"] or falls back to decoding base64 blobs from item["url"]. Decoded content is stored directly into the files dictionary.

    Usage Example

    The module includes an execution example under if __name__ == "__main__": demonstrating how to fetch Python and Markdown files from a GitHub repository:

    if __name__ == "__main__":
    # Get token from environment variable (recommended for private repos)
    github_token = os.environ.get("GITHUB_TOKEN")
    if not github_token:
        print("Warning: No GitHub token found in environment variable 'GITHUB_TOKEN'.\n"
              "Private repositories will not be accessible without a token.\n"
              "To access private repos, set the environment variable or pass the token explicitly.")

    repo_url = "https://github.com/pydantic/pydantic/tree/6c38dc93f40a47f4d1350adca9ec0d72502e223f/pydantic"

    # Example: Get Python and Markdown files, but exclude test files
    result = crawl_github_files(
        repo_url, 
        token=github_token,
        max_file_size=1 * 1024 * 1024,  # 1 MB in bytes
        use_relative_paths=True,  # Enable relative paths
        include_patterns={"*.py", "*.md"},  # Include Python and Markdown files
    )

    files = result["files"]
    stats = result["stats"]

    print(f"\nDownloaded {stats['downloaded_count']} files.")
    print(f"Skipped {stats['skipped_count']} files due to size limits or patterns.")
    print(f"Base path for relative paths: {stats['base_path']}")
    print(f"Include patterns: {stats['include_patterns']}")
    print(f"Exclude patterns: {stats['exclude_patterns']}")
