    utils.crawl_github_files

    File Path: utils/crawl_github_files.py

    Overview

    The utils.crawl_github_files module is responsible for ingesting source code and file trees from remote GitHub repositories. It serves as one of the underlying repository-fetching implementations called by the FetchRepo node in the computational flow.

    The module provides dual retrieval mechanisms: 1. Git SSH Cloning: For SSH URLs (git@... or URLs ending with .git), the module performs a temporary shallow repository clone using git.Repo.clone_from, scans the directory tree using os.walk, applies inclusion/exclusion filters along with .gitignore patterns via pathspec, and reads file contents directly with utf-8-sig encoding. 2. GitHub REST API Traversal: For standard HTTP/HTTPS URLs, the module parses the repository owner, repository name, branch or tree commit SHA, and subdirectories. It uses the GitHub REST API (/repos/{owner}/{repo}/contents/{path} and /git/trees/{tree}) to recursively traverse directories, handle rate-limit resets (403/429), parse remote .gitignore files, and fetch content via raw download URLs or base64 decoding.

    Both mechanisms enforce file size limits, filter files against glob patterns, skip binary/non-text files, and output ANSI-colored terminal summaries.

    crawl_github_files()

    Visibility: Public
    Signature: def crawl_github_files(repo_url: str, token: str = None, max_file_size: int = 1 * 1024 * 1024, use_relative_paths: bool = False, include_patterns: Union[str, Set[str]] = None, exclude_patterns: Union[str, Set[str]] = None) -> dict:

    Description:
    Crawls files from a specified GitHub repository URL at an optional branch, commit SHA, or subpath. Automatically selects between SSH repository cloning via GitPython and the GitHub REST API depending on the URL schema.

    Under the hood: - Normalizes include_patterns and exclude_patterns into sets. - If the URL starts with git@ or ends with .git: - Creates a temporary directory using tempfile.TemporaryDirectory. - Clones the repository using git.Repo.clone_from. - Parses .gitignore using pathspec.PathSpec.from_lines("gitwildmatch", ...) if present. - Recursively traverses the directory tree using os.walk, pruning excluded directories and filtering files via should_include_file. - Enforces max_file_size and reads contents using utf-8-sig. - If the URL is an HTTP/HTTPS GitHub URL: - Parses the URL components (owner, repo, optional branch/tree ref, and subdirectory path). - Fetches branches via fetch_branches or verifies trees via check_tree to resolve tree references and subdirectory paths. - Queries contents/.gitignore via the REST API to construct a pathspec matcher. - Recursively invokes fetch_contents to traverse the repository structure. - Handles API rate-limiting headers (X-RateLimit-Reset), pausing execution when limits are reached if a token is supplied. - Reads text contents via download_url HTTP requests or decodes base64 content payloads. - Prints a color-coded summary to standard output and returns a dictionary containing the path-to-content map and execution statistics.

    Parameters: * repo_url (str): Target GitHub repository URL (e.g., 'https://github.com/owner/repo/tree/main/subdir' or 'git@github.com:owner/repo.git'). * token (str | None, optional): GitHub personal access token for authenticating private repositories and raising API rate limits. Defaults to None. * max_file_size (int, optional): Maximum file size in bytes to read into memory. Defaults to 1048576 (1 MB). * use_relative_paths (bool, optional): If True, returns dictionary keys relative to the specified URL subdirectory rather than repository root. Defaults to False. * include_patterns (str | set[str] | None, optional): File pattern or set of glob patterns to include (e.g., {"*.py", "*.md"}). If None, all files are included. * exclude_patterns (str | set[str] | None, optional): File pattern or set of glob patterns to exclude (e.g., {"test/*", "*.png"}). If None, no patterns are excluded.

    Returns: * dict: A dictionary structured as: - "files" (dict[str, str]): Mapping of relative file paths to string file contents. - "stats" (dict[str, Any]): Metadata dictionary containing downloaded_count, skipped_count, skipped_files, base_path, include_patterns, exclude_patterns, and optionally source or error.

    Raises: * ValueError: If repo_url cannot be parsed into valid GitHub repository components (owner and repository name). * Exception: If GitHub API rate limits are exceeded without a token provided, or if git clone operations fail.

    Example: 

    from utils.crawl_github_files import crawl_github_files

result = crawl_github_files(
    repo_url="https://github.com/pydantic/pydantic/tree/main/pydantic",
    token="ghp_exampletoken12345",
    max_file_size=512 * 1024,
    use_relative_paths=True,
    include_patterns={"*.py"},
    exclude_patterns={"tests/*"}
)

files = result["files"]
print(f"Downloaded {len(files)} files.")

    should_include_file()

    Visibility: Private (Internal closure within crawl_github_files)
    Signature: def should_include_file(file_path: str, file_name: str, gitignore_spec: pathspec.PathSpec = None) -> bool:

    Description:
    Evaluates whether a given file matches the inclusion, exclusion, and .gitignore criteria. 1. Tests file_name against include_patterns using fnmatch.fnmatch. If include_patterns is empty, defaults to True. 2. If included and gitignore_spec is provided, tests file_path against gitignore_spec.match_file(file_path); returns False if matched. 3. If still included and exclude_patterns is defined, checks file_path against all exclusion patterns; returns False if matched.

    Parameters: * file_path (str): Relative path of the candidate file. * file_name (str): Base filename of the candidate file. * gitignore_spec (pathspec.PathSpec | None, optional): Compiled pathspec object representing .gitignore rules. Defaults to None.

    Returns: * bool: True if the file satisfies all filtering criteria and should be crawled; False otherwise.

    Raises: * None

    Example: 

    # Internal usage within crawl_github_files
is_valid = should_include_file("src/utils/math.py", "math.py", gitignore_spec=gitignore_spec)

    fetch_branches()

    Visibility: Private (Internal helper within crawl_github_files)
    Signature: def fetch_branches(owner: str, repo: str) -> list[dict]:

    Description:
    Queries the GitHub REST API endpoint GET /repos/{owner}/{repo}/branches to list all branches in the target repository. Validates response codes, raising an exception if unauthenticated rate limits are hit, logging 404 errors if the repository is private or not found, and returning the JSON array of branch metadata.

    Parameters: * owner (str): GitHub repository owner / organization. * repo (str): GitHub repository name.

    Returns: * list[dict]: List of branch dictionaries returned by GitHub API, or an empty list [] on failure.

    Raises: * Exception: If HTTP status code is 403 or 429 and no token was configured.

    Example: 

    # Internal usage within crawl_github_files
branches = fetch_branches("octocat", "Hello-World")
for b in branches:
    print(b["name"])

    Signature: def check_tree(owner: str, repo: str, tree: str) -> bool:

    Description:
    Queries GET /repos/{owner}/{repo}/git/trees/{tree} to determine if the given tree SHA or ref exists within the repository. Used to disambiguate whether a URL segment is a branch name or a Git tree SHA.

    Parameters: * owner (str): GitHub repository owner / organization. * repo (str): GitHub repository name. * tree (str): Tree SHA or reference to check.

    Returns: * bool: True if the API responds with HTTP 200, False otherwise.

    Raises: * Exception: If rate limits (403/429) are encountered without a token.

    Example: 

    # Internal usage within crawl_github_files
exists = check_tree("octocat", "Hello-World", "6dcb09b5b57875f334f61aebed695e2e4193db5e")

    fetch_contents()

    Visibility: Private (Internal recursive helper within crawl_github_files)
    Signature: def fetch_contents(path: str) -> None:

    Description:
    Recursively navigates the GitHub repository hierarchy using the REST API GET /repos/{owner}/{repo}/contents/{path}: - Appends the query parameter ref if a branch/commit is specified. - If rate-limited (403/429), reads X-RateLimit-Reset, sleeps until the quota resets, and retries the request. - Iterates over items returned in the directory listing: - Directories (dir): Checks gitignore_spec and exclude_patterns. If excluded, prints an ANSI exclusion log; otherwise, recursively calls fetch_contents(item["path"]). - Files (file): Checks patterns via should_include_file and enforces max_file_size. Downloads content using download_url or falls back to decoding base64 payloads from item["url"]. Updates the outer files dictionary and tracking counters.

    Parameters: * path (str): Repository directory path to inspect.

    Returns: * None (Updates the enclosing files dictionary and counter state in-place).

    Raises: * Exception: If GitHub API rate limits are hit without a configured token.

    Example: 

    # Internal invocation within crawl_github_files
fetch_contents("src/core")
