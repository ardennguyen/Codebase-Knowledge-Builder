    llm_config.py

    Source: utils/llm_config.py

    Technical Overview

    Following the foundational execution and telemetry contracts established in utils/llm_common.py, utils/llm_config.py acts as the centralized configuration, credential preflight, and model parameter resolution layer across all supported Large Language Model providers. The module was explicitly extracted from call_llm.py to break a circular import dependency between execution dispatching and tokenizer budgeting (call_llm ↔ token_utils). By consolidating provider settings, endpoint URLs, API keys, thinking budget profiles, context length querying, and token-ratio priors into a single source of truth, it provides a decoupled configuration foundation for downstream runtime systems.

    The module manages multi-provider interoperability across Anthropic Claude, Google Gemini, OpenRouter, and generic OpenAI-compatible gateways. It establishes deterministic parameter mappings for model capabilities, including adaptive thinking effort levels, token-ratio adjustments between tiktoken and Claude tokenizers, Vertex AI regional endpoint routing, and OpenRouter dynamic catalog inspection. To avoid runtime disruptions during heavy pipeline execution passes, utils/llm_config.py encapsulates early preflight authentication routines that validate local CLI credentials, Workload Identity Federation profiles, and SDK version compatibility before network requests are dispatched.

    anthropic_output_budget()

    Visibility: Public

    Signature: def anthropic_output_budget(thinking_level: str | None) -> int:

    Description: Resolves the planned output token allocation for adaptive Anthropic models based on the specified thinking level, applying the optional ceiling from anthropic_output_cap().

    Parameters:

    • thinking_level (str | None): The requested abstract thinking effort ("minimal", "low", "medium", "high", "xhigh", "max", or None).

    Returns:

    • int: Output token count allocated for the request.

    Example:

    def anthropic_output_budget(thinking_level: str | None) -> int:
    """Per-effort table value capped by ANTHROPIC_MAX_OUTPUT_TOKENS (adaptive models)."""
    level = thinking_level.lower() if thinking_level else None
    budget = ANTHROPIC_MAX_TOKENS_BY_EFFORT.get(level, ANTHROPIC_MAX_TOKENS_BY_EFFORT[None])
    cap = anthropic_output_cap()
    return min(budget, cap) if cap else budget

    The function normalizes the thinking level string to lowercase and retrieves the mapped value from ANTHROPIC_MAX_TOKENS_BY_EFFORT. If thinking_level is None or not present in the table, it falls back to the default effort budget (64,000 tokens). Finally, if ANTHROPIC_MAX_OUTPUT_TOKENS is defined, the budget is clamped to that ceiling.

    anthropic_effort()

    Visibility: Public

    Signature: def anthropic_effort(model: str, level: str | None) -> str | None:

    Description: Normalizes and validates an abstract thinking level string into a supported Claude API effort parameter, adjusting for family-specific capabilities.

    Parameters:

    • model (str): The name or identifier of the Anthropic model.
    • level (str | None): The desired thinking level string.

    Returns:

    • str | None: The validated effort string ("low", "medium", "high", "xhigh", "max"), or None if disabled/unsupported.

    Example:

    def anthropic_effort(model: str, level: str | None) -> str | None:
    """Thinking level → effort the model accepts: minimal → low, xhigh → high on the 4.6 family,
    unknown values → None (model default)."""
    if not level:
        return None
    level = level.lower()
    if level == "minimal":
        level = "low"
    if level not in ANTHROPIC_EFFORT_LEVELS:
        return None
    if level == "xhigh" and (model or "").lower().startswith(ANTHROPIC_NO_XHIGH_PREFIXES):
        return "high"
    return level

    The method standardizes input strings by converting them to lowercase and mapping "minimal" up to "low", as Anthropic APIs do not support a minimal tier. If the normalized value is not recognized in ANTHROPIC_EFFORT_LEVELS, None is returned so the provider uses its default behavior. For models belonging to ANTHROPIC_NO_XHIGH_PREFIXES (such as Opus 4.6 and Sonnet 4.6), the effort is clamped from "xhigh" down to "high".

    anthropic_planned_output()

    Visibility: Public

    Signature: def anthropic_planned_output(model: str, thinking_level: str | None) -> int:

    Description: Calculates the total planned output token reservation (max_tokens) for Anthropic requests. It differentiates between adaptive thinking models and legacy fixed-budget models before factoring in user-configured environment caps.

    Parameters:

    • model (str): Anthropic model identifier.
    • thinking_level (str | None): Target thinking effort level.

    Returns:

    • int: Total output token reservation planned for the API request.

    Example:

    def anthropic_planned_output(model: str, thinking_level: str | None) -> int:
    """Claude max_tokens the request will plan for (before the model/context ceiling): the per-effort
    table on adaptive models, budget_tokens + 16K on pre-adaptive ones (Haiku 4.5), capped by
    ANTHROPIC_MAX_OUTPUT_TOKENS. Shared by llm_anthropic and token_utils.input_token_budget."""
    effort = anthropic_effort(model, thinking_level)
    if (model or "").lower().startswith(ANTHROPIC_ADAPTIVE_PREFIXES):
        return anthropic_output_budget(effort)
    planned = ANTHROPIC_BUDGET_BY_LEVEL.get(effort, 0) + ANTHROPIC_BUDGET_REPLY_TOKENS
    cap = anthropic_output_cap()
    return min(planned, cap) if cap else planned

    If the model matches ANTHROPIC_ADAPTIVE_PREFIXES, the output budget is resolved directly via anthropic_output_budget(). For pre-adaptive architectures (such as Haiku 4.5), thinking budget tokens are explicitly looked up from ANTHROPIC_BUDGET_BY_LEVEL and added to ANTHROPIC_BUDGET_REPLY_TOKENS (16,000 tokens) to guarantee reply space. The computed total is clamped by anthropic_output_cap() if configured.

    gemini_thinking_mode()

    Visibility: Public

    Signature: def gemini_thinking_mode(model: str) -> tuple[str, object]:

    Description: Determines the thinking configuration mode and parameter constraints for a given Gemini model identifier.

    Parameters:

    • model (str): Gemini model identifier or full resource path.

    Returns:

    • tuple[str, object]: A mode tuple categorizing thinking behavior:
      • ("budget", (min, max, can_disable)) for legacy Gemini 2.5 models.
      • ("level", allowed_levels) for modern Gemini 3.x models.
      • ("none", None) for unmapped, non-Gemini, or non-text models.

    Example:

    def gemini_thinking_mode(model: str) -> tuple[str, object]:
    """('level', allowed_levels) for Gemini 3.x, ('budget', (min, max, can_disable)) for 2.5,
    ('none', None) for models without a thinking control the project maps."""
    name = gemini_model_id(model)
    for prefix, low, high, can_disable in GEMINI_BUDGET_RANGES:
        if name.startswith(prefix):
            return "budget", (low, high, can_disable)
    if not name.startswith("gemini-") or name.startswith(("gemini-1", "gemini-2")):
        return "none", None  # 1.x / 2.0, other 2.5 variants (image, live, TTS) and non-Gemini ids
    for prefix, levels in GEMINI_THINKING_LEVELS:
        if name.startswith(prefix):
            return "level", levels
    # Other 3.x ids, '-latest' aliases (gemini-flash-latest, gemini-pro-latest) and newer families:
    # the level set every documented 3.x model accepts (a model that rejects it is handled at runtime).
    return "level", GEMINI_3_DEFAULT_LEVELS

    The function normalizes the input model identifier using gemini_model_id() and iterates through GEMINI_BUDGET_RANGES to identify budget-based models. If the model represents an older family (Gemini 1.x, 2.0) or non-text variant, thinking controls are disabled via ("none", None). For 3.x models, it matches against GEMINI_THINKING_LEVELS or defaults to GEMINI_3_DEFAULT_LEVELS for latest aliases and future revisions.

    gemini_vertex_locations()

    Visibility: Public

    Signature: def gemini_vertex_locations(model: str) -> tuple | None:

    Description: Resolves the allowed Vertex AI deployment locations that serve a specific Gemini 3.x model.

    Parameters:

    • model (str): Gemini model identifier.

    Returns:

    • tuple | None: A tuple of valid region strings (e.g., ("global", "us", "eu")), or None if the model can be served from any regional endpoint.

    Example:

    def gemini_vertex_locations(model: str) -> tuple | None:
    """Vertex AI locations that serve a Gemini 3.x model (None = any, including regional endpoints)."""
    name = gemini_model_id(model)
    for prefix, locations in GEMINI_VERTEX_LOCATIONS:

If matched, the associated location tuple (or None for unconstrained regional serving) is returned. Unlisted 3.x models default to GEMINI_3_VERTEX_LOCATIONS (("global", "us", "eu")), while non-3.x models return None.

    gemini_output_budget()

    Visibility: Public

    Signature: def gemini_output_budget(thinking_level: str | None, output_limit: int | None = None) -> int:

    Description: Computes the planned Gemini max_output_tokens parameter based on effort level, model-specific boundaries, and environment caps.

    Parameters:

    • thinking_level (str | None): Desired thinking effort level.
    • output_limit (int | None): Optional hard model output limit (defaults to 65,536).

    Returns:

    • int: The resolved output token budget for the request.

    Example:

    def gemini_output_budget(thinking_level: str | None, output_limit: int | None = None) -> int:
    """Planned Gemini max_output_tokens: per-level table, capped by the model output limit and
    GEMINI_MAX_OUTPUT_TOKENS. Shared by llm_gemini (request) and token_utils (prompt budget)."""
    level = thinking_level.lower() if thinking_level else None
    budget = GEMINI_OUTPUT_TOKENS_BY_EFFORT.get(level, GEMINI_OUTPUT_TOKENS_BY_EFFORT[None])
    budget = min(budget, output_limit or GEMINI_DEFAULT_LIMITS[1])
    cap = _env_int("GEMINI_MAX_OUTPUT_TOKENS")
    return min(budget, cap) if cap else budget

    The function looks up the target effort in GEMINI_OUTPUT_TOKENS_BY_EFFORT, defaulting to 65,536 tokens if omitted. It clamps the budget against the provided output_limit or GEMINI_DEFAULT_LIMITS[1]. If the GEMINI_MAX_OUTPUT_TOKENS environment variable is defined and positive, it applies that ceiling.

        stored = sorted(glob.glob(os.path.join(_anthropic_config_dir(), "credentials", "*.json")))

            return True

        _emit_auth_help(ant_installed=False)
        return False

    # Run with the same environment the SDK will see; empty key variables are dropped so the
    # CLI reports the profile the SDK will actually use (the SDK treats empty as unset).
    env = {k: v for k, v in os.environ.items() if not (k in ("ANTHROPIC_API_KEY", "ANTHROPIC_AUTH_TOKEN") and not v.strip())}

    except (OSError, subprocess.SubprocessError) as e:
        emit("WARN_ANTHROPIC_AUTH_UNVERIFIED", error=str(e))
        return True

    output = f"{result.stdout}\n{result.stderr}"
    credential, workspace = parse_ant_auth_status(output)
    emit_raw("DEBUG", f"ant auth status | exit={result.returncode}\n{_redact(output).strip()}", dest="LOG")

        _emit_auth_help(ant_installed=True)
        return False

    if workspace:
        source += f" | {_ui('AUTH_SOURCE_WORKSPACE', workspace=workspace)}"
    emit("ANTHROPIC_AUTH_OK", source=source)
    return True

    _normalize_claude_id()

    Visibility: Private

    Signature: def _normalize_claude_id(model_name: str) -> str:

    Description: Normalizes heterogeneous Claude identifiers (such as AWS Bedrock resource paths or reversed version strings) into canonical family-first slugs.

    Parameters:

    • model_name (str): Raw model identifier or path.

    Returns:

    • str: Canonical normalized identifier (e.g., "claude-opus-4-7").

    Example:

    def _normalize_claude_id(model_name: str) -> str:
    """Gateway/cloud IDs → bare family-first Claude ID: 'anthropic/claude-opus-4.7',
    'bedrock/us.anthropic.claude-opus-4-7-v1:0' and the version-first alias
    'anthropic/claude-4.7-opus-20260416' all → 'claude-opus-4-7...'."""
    name = (model_name or "").lower().replace(".", "-")

        major, minor, family = match.groups()
        name = f"claude-{family}-{major}" + (f"-{minor}" if minor else "") + name[match.end() :]
    return name

    The function replaces periods with hyphens, extracts the substring starting at "claude-", and applies the _CLAUDE_VERSION_FIRST regex. If an identifier uses version-first ordering (e.g., claude-4.7-opus), it rewrites the token order to family-first (claude-opus-4-7).

    Error Handling

    The module implements defensive validation patterns to catch configuration and runtime issues before downstream inference runs:

    • OpenRouter Catalog Fetch Fault Tolerance: When querying {openrouter_base_url()}/v1/models, network exceptions (requests.RequestException), HTTP errors (raise_for_status()), or invalid JSON structures raise exceptions internally. openrouter_catalog() catches these errors, logs a warning via emit_raw, records the timestamp in _openrouter_last_failure, and surfaces a deduplicated warning via warn_once("openrouter_catalog_unavailable"). Calls during the 60-second _OPENROUTER_RETRY_COOLDOWN window return None immediately, preventing cascading startup timeouts.
    • SDK Version and Dependency Validation: check_gemini_config() and check_anthropic_auth() verify that required packages are installed and meet version constraints before execution begins. If google-genai is older than GEMINI_MIN_SDK (1.56.0), the pipeline halts and reports the installed vs. required version strings.
    • Environment Variable Type Safety: Numeric parsing helpers _env_int() and _ratio_from_env() handle malformed or non-numeric environment values safely. _ratio_from_env() catches ValueError, validates that the result is finite via math.isfinite(), and clamps it to TOKEN_RATIO_BOUNDS (0.5 to 3.0).
    • Subprocess Error Isolation: When invoking ant auth status to check Anthropic authentication profiles, subprocess execution is bounded by a 30-second timeout. Any OSError or subprocess.SubprocessError is captured and logged as WARN_ANTHROPIC_AUTH_UNVERIFIED, allowing pipeline execution to continue if credentials can be resolved through another mechanism.
