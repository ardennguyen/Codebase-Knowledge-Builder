    llm_config.py

    Source: utils/llm_config.py

    Technical Overview

    Following the pattern of runtime dependency decoupling established in i18n.py—which isolates localization data from output telemetry to avoid circular execution bottlenecks—llm_config.py resolves a foundational architectural circularity between prompt inference in call_llm.py and token measurement in token_utils.py. In earlier architectures, the token estimation pipeline required provider configurations and context window ceilings to budget prompt payloads, while the LLM execution client simultaneously imported token utility functions to audit prompt token consumption before dispatching network calls. By extracting model configuration, environment variable inspection, and context-window discovery into utils/llm_config.py, the system establishes an immutable, leaf-level source of truth that both operational modules can import without mutual entanglement.

    The module provides two core functional capabilities: provider identification and model context-length resolution. Provider resolution inspects standard runtime environment variables (LLM_PROVIDER, GEMINI_PROJECT_ID, and GEMINI_API_KEY) to determine whether inference must be routed to Google Gemini or an OpenAI-compatible REST endpoint (such as OpenRouter or Ollama). Context-length resolution dynamically evaluates model endpoints and model names to determine maximum token ceilings. It recognizes Google Gemini endpoints to provide a safe 1,000,000-token ceiling, and queries the OpenRouter REST catalog (https://openrouter.ai/api/v1/models) to retrieve model-specific limits, falling back to a deterministic 100,000-token default when queries fail or endpoints are omitted.

    To maintain minimal network latency during repetitive token accounting passes, the module implements an in-memory catalog cache (_openrouter_models_cache). When querying OpenRouter model metadata, it lazily executes a single remote GET request bounded by a 5-second timeout, subsequently serving all downstream lookups from memory. Error handling is structured for total resilience: all network failures and schema anomalies are caught internally, and localized diagnostic warnings are dispatched via lazy imports of output.py (emit and emit_raw), ensuring that context resolution never halts pipeline execution.

    Public API

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description: Evaluates environment variables to determine the active large language model provider. It first checks the explicit configuration variable LLM_PROVIDER. If LLM_PROVIDER is unset or empty, it evaluates Google Gemini credentials by checking for the presence of either GEMINI_PROJECT_ID or GEMINI_API_KEY. If either Gemini variable is detected, it returns "GEMINI" as the fallback provider. If no relevant environment variables are configured, it returns None.

    Parameters: * None.

    Returns: * str | None: The resolved provider identifier string (e.g., "GEMINI", "OPENROUTER", "OLLAMA"), or None if no inference provider can be determined from the runtime environment.

    Raises: * None. All variable lookups use non-throwing os.getenv() calls.

    Example: 

    # Extracted from utils/llm_config.py implementation
def get_llm_provider() -> str | None:
    """Determine the LLM provider from environment variables."""
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    return provider
    The implementation provides zero-configuration defaults for Google Gemini workflows. When deploying inside environments where LLM_PROVIDER has not been explicitly exported, developers can provide standard Gemini credentials (GEMINI_API_KEY or GEMINI_PROJECT_ID), and the application automatically routes downstream inference requests to the Gemini client. Downstream callers in call_llm.py use this return value to select between the Google GenAI SDK and generic OpenAI-compatible HTTP REST clients.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Resolves the maximum input context length (in tokens) for a given LLM model and API endpoint combination. It implements a multi-tiered evaluation pipeline that handles empty endpoints, detects Google Gemini inference URLs and model names, queries OpenRouter's live model catalog API, and falls back to a safe default of 100,000 tokens when endpoints cannot be queried or errors arise.

    Parameters: * endpoint_url (str): The base or complete HTTP/HTTPS URL of the model inference endpoint. * model_name (str): The model identifier string (e.g., "gemini-2.5-pro", "anthropic/claude-3.5-sonnet"). * api_key (str, optional): The API authentication key for remote requests. Defaults to "". (Note: Currently unused in the internal OpenRouter GET request as OpenRouter's catalog endpoint is public).

    Returns: * int: The maximum context window ceiling in tokens. Returns 1000000 for Gemini models, the integer context_length from OpenRouter's catalog for matched OpenRouter models, or 100000 as the baseline default limit.

    Raises: * None. All network failures, JSON decode errors, and key lookups are caught internally and logged via output.py.

    Phase 1: Parameter Validation and Gemini Endpoint Discrimination

        default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000
    This phase validates the input parameters and applies hardcoded heuristics for Google Gemini models. If endpoint_url is falsy or an empty string, the function immediately returns default_limit (100,000 tokens), preventing unnecessary downstream network operations. If the endpoint contains Google's official API host (generativelanguage.googleapis.com) or the model identifier contains the substring "gemini" (evaluated case-insensitively via .lower()), the function returns 1,000,000 tokens. This safely handles modern Gemini 1.5 and 2.x architectures, which natively support at least 1M tokens of context.

    Phase 2: Remote Model Catalog Query and Context Window Extraction

            if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    This phase executes when the endpoint indicates an OpenRouter gateway ("openrouter.ai" in endpoint_url). It dispatches an HTTP GET request to https://openrouter.ai/api/v1/models using a strict 5-second socket timeout to prevent blocking application execution during slow network conditions. Upon receiving an HTTP 200 response, it extracts the data list from the parsed JSON payload and iterates through the catalog entries. When an entry's id field matches model_name, it extracts and returns the context_length attribute, defaulting to 100,000 if the attribute is absent.

    Phase 3: Defensive Fallback and Telemetry Emission

        except Exception as e:
        from utils.output import emit

        emit("WARN_CONTEXT_LENGTH_FETCH", model=model_name, endpoint=endpoint_url, error=str(e))

    return default_limit
    The final phase encapsulates the entire discovery block within a generic except Exception handler. If any failure occurs—such as a requests.Timeout, connection refusal, malformed JSON response, or missing dictionary keys—the error is intercepted. The function lazily imports emit from utils.output to dispatch a localized warning event (WARN_CONTEXT_LENGTH_FETCH) containing the offending model, endpoint URL, and exception message string. Regardless of the failure mode, execution safely terminates by returning default_limit (100,000 tokens), guaranteeing that token budgeting calculations in token_utils.py always receive a valid integer.

    Example: 

    # Extracted from utils/llm_config.py implementation
def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        from utils.output import emit

        emit("WARN_CONTEXT_LENGTH_FETCH", model=model_name, endpoint=endpoint_url, error=str(e))

    return default_limit

    Internal Helpers

    _get_openrouter_model_info()

    Visibility: Private (Internal Helper)
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description: Fetches the complete metadata record for a specified model from the OpenRouter model catalog. To avoid saturating network bandwidth and incurring latency penalties across repeated calls, it utilizes the module-level global cache _openrouter_models_cache. If the cache has not been populated, it makes an HTTP GET request to https://openrouter.ai/api/v1/models with a 5-second timeout, parses the JSON payload, and populates the cache. If the network request fails, it emits a diagnostic warning to the application log stream and initializes the cache as an empty list. It then scans the cached models and returns the matching dictionary or None.

    Parameters: * model_id (str): The unique OpenRouter model identifier (e.g., "deepseek/deepseek-r1", "meta-llama/llama-3.3-70b-instruct").

    Returns: * dict | None: The dictionary containing the model's metadata specifications (e.g., id, name, context_length, pricing, architecture), or None if the model cannot be located in the catalog or the API query failed.

    Raises: * None. Exceptions during network transport or JSON parsing are caught, logged, and handled internally.

    Phase 1: Cache Validation and Remote Catalog Fetch

        global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception as e:
            from utils.output import emit_raw

            emit_raw("WARNING", f"Failed to fetch OpenRouter model info: {e}", dest="LOG")
            _openrouter_models_cache = []
    This phase checks whether the singleton cache _openrouter_models_cache is None. If uninitialized, it initiates an HTTP GET request to OpenRouter's public model catalog endpoint with a 5-second socket timeout. On receiving a successful response, it parses the response body as JSON and assigns the data list to _openrouter_models_cache. If an exception occurs (such as a DNS failure, HTTP 5xx error, or network timeout), it lazily imports emit_raw from utils.output, emits a warning directed strictly to the log destination (dest="LOG"), and sets _openrouter_models_cache = []. This ensures that subsequent invocations do not retry failing network calls repeatedly during the same process lifecycle.

    Phase 2: Catalog Search and Match Extraction

        return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)
    Once the cache is confirmed to be populated (either with model dictionaries or an empty list following a network error), this phase searches the catalog using a generator expression wrapped in next(). It iterates through each dictionary m in _openrouter_models_cache and evaluates whether the id key equals model_id. If a matching entry is found, next() immediately yields that dictionary; if the generator is exhausted without finding a match, it returns the fallback default None.

    Example: 

    # Extracted from utils/llm_config.py implementation
def _get_openrouter_model_info(model_id: str) -> dict | None:
    """Fetch info for a specific model from the OpenRouter model catalog."""
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception as e:
            from utils.output import emit_raw

            emit_raw("WARNING", f"Failed to fetch OpenRouter model info: {e}", dest="LOG")
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    OpenRouter Model Object Schema

    The dictionary structure returned by _get_openrouter_model_info() representing an entry in the OpenRouter model catalog.

    Field Type Description
    id str Unique model identifier string (e.g., "openai/gpt-4o").
    name str Human-readable display name of the model.
    context_length int Maximum context window size supported by the model in tokens.
    pricing dict Pricing rates for prompt and completion token consumption.
    architecture dict Metadata regarding modality, tokenizer, and reasoning support.
    top_provider dict Provider routing metadata, latency figures, and availability metrics.

    Context Length Ceiling Mapping

    The context length values resolved by get_model_context_length() based on endpoint characteristics and model names.

    Endpoint / Model Match Criteria Resolved Context Ceiling Evaluation Mechanism
    Empty / Falsy endpoint_url 100,000 tokens Immediate early return without network overhead.
    "generativelanguage.googleapis.com" in URL 1,000,000 tokens Static string membership heuristic.
    "gemini" in model_name.lower() 1,000,000 tokens Case-insensitive substring match.
    "openrouter.ai" in URL context_length from API Dynamic HTTP GET lookup via /api/v1/models.
    Unmatched endpoint / Network error 100,000 tokens Fallback default limit.

    The return values produced by get_llm_provider() based on active environment variables.

    Environment Configuration Returned Provider Resolution Rule
    LLM_PROVIDER="CUSTOM_NAME" "CUSTOM_NAME" Explicit provider definition takes precedence.
    LLM_PROVIDER="", GEMINI_PROJECT_ID set "GEMINI" Fallback to Gemini when Google Cloud project ID is present.

    Error Handling

    The module implements a strict defensive error-handling strategy designed to make configuration lookups infallible to upstream callers. Because context-length resolution occurs during token budgeting in token_utils.py and prompt execution in call_llm.py, an unhandled exception would crash the entire repository ingestion pipeline.

    Key error-handling mechanisms include:

    1. Defensive Network Timeouts: Both get_model_context_length and _get_openrouter_model_info configure timeout=5 on remote HTTP calls. If OpenRouter's API degrades or hangs, the socket connection is forcibly severed after 5 seconds, preventing execution deadlocks.
    2. Defensive JSON Extraction: Responses are traversed using safe accessor patterns (resp.json().get("data", []) and m.get("context_length", default_limit)), preventing KeyError exceptions when the upstream API changes its schema or returns an unexpected error payload.
    3. Lazy Diagnostic Logging: Logging utilities (emit and emit_raw) are imported lazily within except blocks (from utils.output import emit, emit_raw). This eliminates module-level circular imports between configuration utilities, logging engines, and downstream inference modules during Python's initialization phase.
    4. Deterministic Fallback Ceilings: In the event of any unhandled network error, connection drop, DNS resolution failure, or parsing exception, get_model_context_length logs the event via WARN_CONTEXT_LENGTH_FETCH and returns the deterministic fallback integer 100000.
    # Implementation pattern illustrating lazy telemetry and fallback ceilings
except Exception as e:
    from utils.output import emit

    emit("WARN_CONTEXT_LENGTH_FETCH", model=model_name, endpoint=endpoint_url, error=str(e))

return default_limit
