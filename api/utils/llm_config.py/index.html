    llm_config.py

    Source: utils/llm_config.py

    Following the foundational telemetry and state-tracking mechanisms defined in utils/llm_common.py, the utils/llm_config.py module establishes the centralized configuration, authentication preflight, and context-length resolution engine for the entire codebase.

    Technical Overview

    The utils/llm_config.py module acts as the authoritative source of truth for provider resolution, model identification, token budgeting, and environment preflight verification across the system. It was extracted from utils/call_llm.py to decouple the cyclic dependency loop previously binding call_llm and utils/token_utils.py. Upstream pipeline entry points—including main.py, utils/call_llm.py, and utils/token_utils.py—consume this module to resolve active provider configurations, query context window boundaries, and validate SDK credentials before initiating expensive pipeline traversals.

    The module manages multi-provider configuration mechanics for Anthropic Claude, Google Gemini (via both Vertex AI and Google AI Studio), and OpenRouter gateway endpoints. It normalizes provider-specific model strings, resolves API endpoints, sets default token margins, and harmonizes model-specific reasoning controls. Additionally, it contains the credential preflight engine that verifies SDK installations, parses local OAuth sessions, queries local credential directories, and checks Workload Identity Federation configs to guarantee early failure reporting prior to pipeline execution.

    Public API

    anthropic_output_cap()

    Visibility: Public
    Signature: def anthropic_output_cap() -> int | None:

    Description: Resolves the user-configured ceiling for Anthropic token generation by inspecting the ANTHROPIC_MAX_OUTPUT_TOKENS environment variable. It parses the numeric value using _env_int, returning None if the environment variable is not defined or is not a positive integer.

    Parameters: * None.

    Returns: * int | None: The parsed upper bound integer token count, or None if unset or invalid.

    Raises: * None.

    Example: 

    def anthropic_output_cap() -> int | None:
    """ANTHROPIC_MAX_OUTPUT_TOKENS as an int, or None when unset/invalid."""
    return _env_int("ANTHROPIC_MAX_OUTPUT_TOKENS")

    The function reads the environment through the internal helper _env_int, which strips whitespace and confirms the presence of positive numeric digits. This ensures that misconfigured strings (such as negative numbers or non-numeric characters) do not trigger runtime conversion errors in downstream token budgeting calculations. By returning None in the absence of an explicit cap, it allows adaptive and legacy models to default to their respective preset limits.

    anthropic_output_budget()

    Visibility: Public
    Signature: def anthropic_output_budget(thinking_level: str | None) -> int:

    Description: Calculates the target output token allocation for adaptive Claude models based on the requested thinking effort level. The value is looked up from ANTHROPIC_MAX_TOKENS_BY_EFFORT and clamped by anthropic_output_cap() if an explicit system ceiling is enforced.

    Parameters: * thinking_level (str | None): The requested thinking effort level (e.g., "low", "medium", "high", "xhigh", "max"), or None for default.

    Returns: * int: The computed output token budget clamped to the active system ceiling.

    Raises: * None.

    Example: 

    def anthropic_output_budget(thinking_level: str | None) -> int:
    """Per-effort table value capped by ANTHROPIC_MAX_OUTPUT_TOKENS (adaptive models)."""
    level = thinking_level.lower() if thinking_level else None
    budget = ANTHROPIC_MAX_TOKENS_BY_EFFORT.get(level, ANTHROPIC_MAX_TOKENS_BY_EFFORT[None])
    cap = anthropic_output_cap()
    return min(budget, cap) if cap else budget

    This function normalizes the input effort string to lowercase and retrieves the planned token count from ANTHROPIC_MAX_TOKENS_BY_EFFORT. If an unknown or empty effort level is passed, it falls back to the default None key entry (64_000 tokens). The resulting integer is then compared against anthropic_output_cap(), returning the lower of the two values to guarantee compliance with user-defined resource constraints.

    anthropic_effort()

    Visibility: Public
    Signature: def anthropic_effort(model: str, level: str | None) -> str | None:

    Description: Normalizes and validates the specified thinking level into an effort string supported by the target Anthropic model family. It maps unsupported low-tier values (e.g., "minimal") up to "low", downgrades "xhigh" to "high" for older Claude 4.6 models that predate extended thinking, and drops unrecognized levels to None.

    Parameters: * model (str): Target Anthropic model name or identifier. * level (str | None): Proposed thinking effort level.

    Returns: * str | None: The normalized effort string accepted by the Anthropic API, or None to adopt the model's default reasoning behavior.

    Raises: * None.

    Example: 

    def anthropic_effort(model: str, level: str | None) -> str | None:
    """Thinking level → effort the model accepts: minimal → low, xhigh → high on the 4.6 family,
    unknown values → None (model default)."""
    if not level:
        return None
    level = level.lower()
    if level == "minimal":
        level = "low"
    if level not in ANTHROPIC_EFFORT_LEVELS:
        return None
    if level == "xhigh" and (model or "").lower().startswith(ANTHROPIC_NO_XHIGH_PREFIXES):
        return "high"
    return level

    The normalization pipeline guarantees that model-specific API constraints are satisfied before dispatch. The Anthropic API does not offer a "minimal" effort category, so the function maps it directly to "low". Furthermore, because models matching ANTHROPIC_NO_XHIGH_PREFIXES (such as claude-opus-4-6 and claude-sonnet-4-6) reject the "xhigh" parameter with an HTTP 400 bad request, the function transparently steps down "xhigh" requests to "high" for those specific identifiers.

    anthropic_planned_output()

    Visibility: Public
    Signature: def anthropic_planned_output(model: str, thinking_level: str | None) -> int:

    Description: Computes the planned output token reservation for an Anthropic request before context window ceilings are applied. It routes adaptive models to anthropic_output_budget and pre-adaptive models (such as Claude Haiku 4.5) to a composite formula combining budget tokens with a fixed reply token allowance.

    Parameters: * model (str): The target Anthropic model identifier. * thinking_level (str | None): The requested reasoning effort string.

    Returns: * int: Total output tokens planned for the request, clamped by ANTHROPIC_MAX_OUTPUT_TOKENS.

    Raises: * None.

    Example: 

    def anthropic_planned_output(model: str, thinking_level: str | None) -> int:
    """Claude max_tokens the request will plan for (before the model/context ceiling): the per-effort
    table on adaptive models, budget_tokens + 16K on pre-adaptive ones (Haiku 4.5), capped by
    ANTHROPIC_MAX_OUTPUT_TOKENS. Shared by llm_anthropic and token_utils.input_token_budget."""
    effort = anthropic_effort(model, thinking_level)
    if (model or "").lower().startswith(ANTHROPIC_ADAPTIVE_PREFIXES):
        return anthropic_output_budget(effort)
    planned = ANTHROPIC_BUDGET_BY_LEVEL.get(effort, 0) + ANTHROPIC_BUDGET_REPLY_TOKENS
    cap = anthropic_output_cap()
    return min(planned, cap) if cap else planned

    The function identifies whether the model belongs to the modern adaptive thinking family via ANTHROPIC_ADAPTIVE_PREFIXES. For adaptive architectures, output allocations are derived from anthropic_output_budget(). For pre-adaptive variants, the function calculates the sum of the thinking budget from ANTHROPIC_BUDGET_BY_LEVEL and ANTHROPIC_BUDGET_REPLY_TOKENS (16_000), ensuring that the token planning phase leaves sufficient headroom for completion generation.

    gemini_thinking_mode()

    Visibility: Public
    Signature: def gemini_thinking_mode(model: str) -> tuple[str, object]:

    Description: Determines the reasoning mode and valid configuration boundaries supported by a specified Gemini model. Distinguishes between modern Gemini 3.x categorical levels, legacy Gemini 2.5 numeric budget ranges, and non-reasoning architectures.

    Parameters: * model (str): Target Gemini model name or path.

    Returns: * tuple[str, object]: A two-element tuple consisting of: 1. Mode identifier string: "level", "budget", or "none". 2. Specification payload: a tuple of allowed level strings for "level", a 3-tuple (min, max, can_disable) for "budget", or None for "none".

    Raises: * None.

    Example: 

    def gemini_thinking_mode(model: str) -> tuple[str, object]:
    """('level', allowed_levels) for Gemini 3.x, ('budget', (min, max, can_disable)) for 2.5,
    ('none', None) for models without a thinking control the project maps."""
    name = gemini_model_id(model)
    for prefix, low, high, can_disable in GEMINI_BUDGET_RANGES:
        if name.startswith(prefix):
            return "budget", (low, high, can_disable)
    if not name.startswith("gemini-") or name.startswith(("gemini-1", "gemini-2")):
        return "none", None  # 1.x / 2.0, other 2.5 variants (image, live, TTS) and non-Gemini ids
    for prefix, levels in GEMINI_THINKING_LEVELS:
        if name.startswith(prefix):
            return "level", levels
    # Other 3.x ids, '-latest' aliases (gemini-flash-latest, gemini-pro-latest) and newer families:
    # the level set every documented 3.x model accepts (a model that rejects it is handled at runtime).
    return "level", GEMINI_3_DEFAULT_LEVELS

    The function strips namespace prefixes using gemini_model_id() to extract the core model name. It matches the name against GEMINI_BUDGET_RANGES to determine if legacy budget-based reasoning applies. For non-reasoning legacy models (gemini-1*, gemini-2.0*), it returns ("none", None). For Gemini 3.x and modern variants, it checks GEMINI_THINKING_LEVELS using longest-prefix semantics, falling back to GEMINI_3_DEFAULT_LEVELS for unrecognized modern versions or rolling aliases.

    gemini_vertex_locations()

    Visibility: Public
    Signature: def gemini_vertex_locations(model: str) -> tuple | None:

    Description: Identifies the valid Google Cloud Vertex AI geographic regions serving a specific Gemini model.

    Parameters: * model (str): Target model name or identifier.

    Returns: * tuple | None: A tuple of allowed location strings (e.g., ("global", "us")), or None if the model is universally supported across regional endpoints.

    Raises: * None.

    Example: 

    def gemini_vertex_locations(model: str) -> tuple | None:
    """Vertex AI locations that serve a Gemini 3.x model (None = any, including regional endpoints)."""
    name = gemini_model_id(model)
    for prefix, locations in GEMINI_VERTEX_LOCATIONS:

If no specific prefix matches, it assigns GEMINI_3_VERTEX_LOCATIONS for any model beginning with "gemini-3", or returns None for unconstrained models.

    gemini_output_budget()

    Visibility: Public
    Signature: def gemini_output_budget(thinking_level: str | None, output_limit: int | None = None) -> int:

    Description: Resolves the planned output token allocation for Gemini models. Balances thinking level configurations against the model's hard maximum output limit and the GEMINI_MAX_OUTPUT_TOKENS environment variable.

    Parameters: * thinking_level (str | None): The requested reasoning effort string. * output_limit (int | None): The upper output token limit supported by the model, defaulting to GEMINI_DEFAULT_LIMITS[1] (65_536).

    Returns: * int: Planned token generation limit.

    Raises: * None.

    Example: 

    def gemini_output_budget(thinking_level: str | None, output_limit: int | None = None) -> int:
    """Planned Gemini max_output_tokens: per-level table, capped by the model output limit and
    GEMINI_MAX_OUTPUT_TOKENS. Shared by llm_gemini (request) and token_utils (prompt budget)."""
    level = thinking_level.lower() if thinking_level else None
    budget = GEMINI_OUTPUT_TOKENS_BY_EFFORT.get(level, GEMINI_OUTPUT_TOKENS_BY_EFFORT[None])
    budget = min(budget, output_limit or GEMINI_DEFAULT_LIMITS[1])
    cap = _env_int("GEMINI_MAX_OUTPUT_TOKENS")
    return min(budget, cap) if cap else budget

    The function queries GEMINI_OUTPUT_TOKENS_BY_EFFORT using the normalized thinking level. It clamps the value against the model's documented output capacity (defaulting to 65,536 tokens if omitted). Finally, it checks for an explicit override via GEMINI_MAX_OUTPUT_TOKENS, returning the most restrictive token ceiling.

    openrouter_output_budget()

    Visibility: Public
    Signature: def openrouter_output_budget(model: str, thinking_level: str | None) -> int | None:

    Description: Resolves the planned output token budget for models dispatched through OpenRouter. Fetches parameters from the cached OpenRouter model catalog, checks max_completion_tokens, and clamps the result using OPENROUTER_MAX_OUTPUT_TOKENS.

    Parameters: * model (str): Target OpenRouter model identifier or slug. * thinking_level (str | None): The requested reasoning intensity.

    Returns: * int | None: Planned output tokens, or None if the model cannot be identified in the catalog (signaling that max_tokens should be omitted from the request).

    Raises: * None.

    Example: 

    def openrouter_output_budget(model: str, thinking_level: str | None) -> int | None:
    """Planned OpenRouter max_tokens: shared per-effort table, capped by the catalog's
    top_provider.max_completion_tokens and OPENROUTER_MAX_OUTPUT_TOKENS. None when the model is not
    in the catalog (unknown limits, e.g. a non-OpenRouter proxy): max_tokens is then omitted."""
    info = openrouter_model_info(model)
    if info is None:
        return _env_int("OPENROUTER_MAX_OUTPUT_TOKENS")
    level = thinking_level.lower() if thinking_level else None
    budget = OUTPUT_TOKENS_BY_EFFORT.get(level, OUTPUT_TOKENS_BY_EFFORT[None])
    model_cap = (info.get("top_provider") or {}).get("max_completion_tokens")
    budget = min(budget, model_cap) if model_cap else min(budget, 32_000)
    cap = _env_int("OPENROUTER_MAX_OUTPUT_TOKENS")
    return min(budget, cap) if cap else budget

    The function looks up model metadata via openrouter_model_info(). If the catalog cannot be retrieved or does not contain the model, it returns the value of OPENROUTER_MAX_OUTPUT_TOKENS (which may be None). When catalog metadata is available, it compares the per-effort planned output against top_provider.max_completion_tokens (or a 32,000 token default) and the environment cap.

    context_output_reserve()

    Visibility: Public
    Signature: def context_output_reserve(thinking_level: str | None) -> int | None:

    Description: Calculates the number of output tokens that must be subtracted from the total context window to accommodate planned completions and reasoning tokens.

    Parameters: * thinking_level (str | None): The requested reasoning effort string.

    Returns: * int | None: Token count to reserve from shared context windows (Anthropic and OpenRouter), 0 for architectures with independent input/output buffers (Gemini), or None if unconfigured.

    Raises: * None.

    Example: 

    def context_output_reserve(thinking_level: str | None) -> int | None:
    """Output tokens that share the context window with the prompt, for the active provider.
    ANTHROPIC / OPENROUTER: the planned max_tokens (thinking included). GEMINI: 0 — Gemini's input and
    output limits are separate. None: the provider does not size output (5% reserve in token_utils)."""
    provider, model, _, _ = resolve_llm_settings()
    if provider == "ANTHROPIC":
        return anthropic_planned_output(model, thinking_level)
    if provider == "GEMINI":
        return 0
    if provider == "OPENROUTER":
        return openrouter_output_budget(model, thinking_level)
    return None

    Different LLM providers implement distinct context window architectures. Anthropic and OpenRouter share a single context window across input prompts and generated output (including reasoning tokens), requiring the prompt builder to subtract the planned output allocation from the total context limit. In contrast, Google Gemini manages input and output capacities independently, allowing this function to return 0 and make the entire context window available for input prompts.

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description: Evaluates environment variables to determine the active LLM provider. Gives precedence to LLM_PROVIDER, falls back to detecting Gemini credentials, and avoids auto-selecting Anthropic.

    Parameters: * None.

    Returns: * str | None: The normalized provider name in uppercase (e.g., "GEMINI", "ANTHROPIC", "OPENROUTER"), or None if no provider can be resolved.

    Raises: * None.

    Example: 

    def get_llm_provider() -> str | None:
    """Determine the LLM provider from environment variables.

    Explicit LLM_PROVIDER wins; otherwise Gemini credentials select GEMINI (legacy default).
    ANTHROPIC is never auto-selected: ANTHROPIC_API_KEY is often exported globally for other
    tools (e.g. Claude Code), and a silent switch to a paid Claude run would be surprising.
    """
    provider = os.getenv("LLM_PROVIDER")
    if provider:
        return provider.strip().upper()
    if os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY"):
        return "GEMINI"
    return None

    The function enforces safety invariants around automated provider selection. If LLM_PROVIDER is set explicitly, it is normalized to uppercase and returned. Otherwise, it detects GEMINI_PROJECT_ID or GEMINI_API_KEY to retain legacy backward compatibility. It explicitly avoids auto-selecting ANTHROPIC when ANTHROPIC_API_KEY is present in the environment, preventing unintentional billing on accounts where CLI tools (such as Claude Code) export credentials globally.

    def openrouter_model_info(model_id: str) -> dict | None:
    """Catalog entry for a model id: exact id, canonical_slug, routing-suffix variant
    (':nitro', ':floor', ...), dated canonical slug (e.g. 'anthropic/claude-4.6-opus' →
    'anthropic/claude-4.6-opus-20260205'), or a '~...-latest' alias's target."""
    catalog = openrouter_catalog()
    if not catalog or not model_id:
        return None
    wanted = model_id.strip()
    candidates = [wanted, *(wanted[: -len(suffix)] for suffix in _OPENROUTER_ROUTING_SUFFIXES if wanted.endswith(suffix))]
    for name in candidates:
        entry = next((m for m in catalog if m.get("id") == name or m.get("canonical_slug") == name), None)
        if entry is None:
            # Dated canonical slug only ('anthropic/claude-4.6-opus' → '…-20260205'): a looser prefix
            # match would map typos such as 'google/gemini-3.1-pro' onto a different model.
            dated = re.compile(re.escape(name) + r"-\d{8}")
            entry = next((m for m in catalog if dated.fullmatch(str(m.get("canonical_slug", "")))), None)
        if entry is not None:
            target = (entry.get("alias_target") or {}).get("slug")
            if target and target != entry.get("id"):
                return next((m for m in catalog if m.get("id") == target or m.get("canonical_slug") == target), entry)
            return entry
    return None

    The matching algorithm strips OpenRouter routing suffixes (such as :nitro or :thinking) to evaluate candidate names against id and canonical_slug fields. If an exact match is missing, it evaluates regular expressions against eight-digit dated snapshots (e.g., -20260205).     version = _installed_version("google-genai")
    if version is None:
        emit("ERROR_GEMINI_SDK_MISSING")
        return False
    if version < GEMINI_MIN_SDK:
        emit("ERROR_GEMINI_SDK_OUTDATED", version=".".join(map(str, version)), required=".".join(map(str, GEMINI_MIN_SDK)))
        return False

    retired = GEMINI_RETIRED_MODELS.get(gemini_model_id(model))
    if retired:
        replacement, aliased_on_ai_studio = retired
        if aliased_on_ai_studio and not os.getenv("GEMINI_PROJECT_ID"):
            emit("WARN_GEMINI_MODEL_RETIRED", model=model, replacement=replacement)
        else:
            emit("ERROR_GEMINI_MODEL_RETIRED", model=model, replacement=replacement)
            return False

    if os.getenv("GEMINI_PROJECT_ID"):
        location = gemini_location()
        allowed = gemini_vertex_locations(model)
        if allowed is not None and location.lower() not in allowed:
            emit("WARN_GEMINI_LOCATION", location=location, model=model, allowed=", ".join(allowed))
        try:
            import google.auth

            google.auth.default()
        except Exception as e:  # DefaultCredentialsError, or google-auth missing
            emit("ERROR_GEMINI_VERTEX_CREDENTIALS", error=str(e).splitlines()[0][:200])
            return False
        emit("LLM_AUTH_OK", provider="Gemini", source=_ui("AUTH_SOURCE_VERTEX", project=os.environ["GEMINI_PROJECT_ID"], location=location))
        return True
    if _env_set("GEMINI_API_KEY"):
        emit("LLM_AUTH_OK", provider="Gemini", source=_ui("AUTH_SOURCE_AI_STUDIO"))
        return True
    emit("ERROR_GEMINI_NO_CREDENTIALS")
    return False

    The function checks that google-genai is installed and meets the minimum version requirement (>= 1.56.0), which is necessary to support categorical thinking levels without Pydantic validation errors. It checks GEMINI_RETIRED_MODELS to block decommissioned identifiers, warns about unsupported Vertex AI regions, verifies Vertex Application Default Credentials via google.auth.default(), and validates AI Studio keys, emitting localized error codes for configuration failures.

    Error Handling

    The utils/llm_config.py module uses a fail-fast approach for environment and credential validation, preventing missing packages or invalid API configurations from causing errors mid-pipeline.

    SDK Installation and Version Checks

    • Anthropic SDK Verification: In check_anthropic_auth(), package availability is verified using importlib.util.find_spec rather than direct imports. Missing installations emit ERROR_ANTHROPIC_SDK_MISSING and halt execution.
    • Gemini SDK Versioning: check_gemini_config() validates that google-genai is installed and meets GEMINI_MIN_SDK (1.56.0). Older versions that reject categorical thinking parameters emit ERROR_GEMINI_SDK_OUTDATED and return False.

    Credential Preflight Engine

    • Conflicting Credentials: If both ANTHROPIC_API_KEY and ANTHROPIC_AUTH_TOKEN are detected, check_anthropic_auth() emits WARN_ANTHROPIC_KEY_AND_TOKEN to warn about precedence conflicts.
    • Subprocess Isolation: When calling ant auth status, subprocess exceptions (OSError, subprocess.SubprocessError) are caught gracefully, logging WARN_ANTHROPIC_AUTH_UNVERIFIED without crashing the process.
    • Vertex AI Credentials: check_gemini_config() tests Application Default Credentials via google.auth.default(). If credentials cannot be loaded, it extracts the error message and emits ERROR_GEMINI_VERTEX_CREDENTIALS.
    • Retired Models: Deprecated Gemini models listed in GEMINI_RETIRED_MODELS are blocked with ERROR_GEMINI_MODEL_RETIRED, unless running on Google AI Studio where legacy aliasing applies (WARN_GEMINI_MODEL_RETIRED).

    Network Resilience and Cooldown

    • OpenRouter Catalog Caching: Network errors during catalog retrieval are captured by openrouter_catalog(). The module logs WARN_OPENROUTER_CATALOG_UNAVAILABLE via warn_once() and sets a 60-second cooldown (_OPENROUTER_RETRY_COOLDOWN), preventing transient network failures from repeatedly blocking the pipeline.
    • Context Length Fallback: When context limits cannot be resolved over the network, get_model_context_length() emits WARN_CONTEXT_LENGTH_FETCH and falls back to a safe default of 100_000 tokens.
