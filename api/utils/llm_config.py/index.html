    llm_config.py

    Source: utils/llm_config.py

    Technical Overview

    Building upon the foundational accounting and error primitives established in utils.llm_common (doc: utils/llm_common.py.md), llm_config.py serves as the centralized configuration authority and provider resolution layer for the entire Codebase-Knowledge-Builder pipeline. The module was extracted from call_llm.py to eliminate circular dependency chains between inference execution and token budget estimation (utils.token_utils). It operates as the single source of truth for runtime provider detection, model endpoint construction, credential validation, context window boundaries, and tokenizer multiplication ratios.

    The module provides deterministic resolution of target LLM environments, supporting Anthropic Claude, Google Gemini (via AI Studio and Google Cloud Vertex AI), OpenRouter gateways, and custom OpenAI-compatible endpoints. It implements proactive authentication and configuration preflight checks (check_llm_auth()) before any file extraction or code graph analysis begins, preventing wasted execution cycles caused by misconfigured environment variables or missing software development kits (SDKs). Additionally, it manages model reasoning parameters, mapping symbolic effort levels (minimal to max) to provider-specific controls such as Claude adaptive thinking, Gemini thinking levels or token budgets, and OpenRouter reasoning configurations.

    To support prompt assembly and token budget calculation, llm_config.py manages static prior token ratios against tiktoken (cl100k), detects models that reject classical sampling parameters (such as temperature, top_p, and top_k), and caches remote model metadata from OpenRouter's /v1/models endpoint with failure cooldowns.

    anthropic_output_cap()

    Visibility: Public

    Signature: def anthropic_output_cap() -> int | None:

    Description: Retrieves the maximum allowed Anthropic completion tokens configured via environment variables. It parses the ANTHROPIC_MAX_OUTPUT_TOKENS environment variable into an integer using _env_int(). If the variable is unset, empty, non-numeric, or less than or equal to zero, the function returns None.

    Parameters:

    None.

    Returns:

    • int | None: The parsed positive token limit or None if invalid or unset.

    Example:

    def anthropic_output_cap() -> int | None:
    """ANTHROPIC_MAX_OUTPUT_TOKENS as an int, or None when unset/invalid."""
    return _env_int("ANTHROPIC_MAX_OUTPUT_TOKENS")

    The function provides an operational override mechanism for pipeline runs targeting Claude models. Downstream components consult this value to prevent requests from exceeding cost constraints or custom reverse-proxy output boundaries.

    anthropic_output_budget()

    Visibility: Public

    Signature: def anthropic_output_budget(thinking_level: str | None) -> int:

    Description: Calculates the output token budget for adaptive Anthropic models under a specified reasoning effort level. It queries the ANTHROPIC_MAX_TOKENS_BY_EFFORT table using the lowercased effort level (defaulting to the None effort tier if unspecified) and clamps the result against anthropic_output_cap() if an environment cap is defined.

    Parameters:

    • thinking_level (str | None): The target reasoning effort (minimal, low, medium, high, xhigh, max, or None).

    Returns:

    • int: Planned output token allocation for the request.

    Example:

    def anthropic_output_budget(thinking_level: str | None) -> int:
    """Per-effort table value capped by ANTHROPIC_MAX_OUTPUT_TOKENS (adaptive models)."""
    level = thinking_level.lower() if thinking_level else None
    budget = ANTHROPIC_MAX_TOKENS_BY_EFFORT.get(level, ANTHROPIC_MAX_TOKENS_BY_EFFORT[None])
    cap = anthropic_output_cap()
    return min(budget, cap) if cap else budget

    The function coordinates output token headroom between request creation in utils.llm_anthropic and prompt sizing calculations in utils.token_utils. By using matching numbers, prompts can be sized aggressively against context windows while guaranteeing that reasoning output tokens are preserved.

    anthropic_effort()

    Visibility: Public

    Signature: def anthropic_effort(model: str, level: str | None) -> str | None:

    Description: Translates a normalized pipeline thinking level into an effort string accepted by Anthropic's Messages API. It maps minimal to low, validates membership against ANTHROPIC_EFFORT_LEVELS, downgrades xhigh to high for Claude 4.6 family models (which predate the xhigh setting), and falls back to None for invalid or missing levels to allow the model's default reasoning behavior.

    Parameters:

    • model (str): Target model identifier (used for prefix family matching).
    • level (str | None): Desired pipeline reasoning level.

    Returns:

    • str | None: Validated Anthropic effort parameter (low, medium, high, xhigh, max) or None.

    Example:

    def anthropic_effort(model: str, level: str | None) -> str | None:
    """Thinking level → effort the model accepts: minimal → low, xhigh → high on the 4.6 family,
    unknown values → None (model default)."""
    if not level:
        return None
    level = level.lower()
    if level == "minimal":
        level = "low"
    if level not in ANTHROPIC_EFFORT_LEVELS:
        return None
    if level == "xhigh" and (model or "").lower().startswith(ANTHROPIC_NO_XHIGH_PREFIXES):
        return "high"
    return level

    This normalization handles discrepancies across Claude model generations. Newer adaptive models (Sonnet 5, Opus 5, Opus 4.7+) support distinct effort levels, while older intermediate architectures like Opus 4.6 or Sonnet 4.6 reject unsupported configurations with API-level 400 validation errors.

    anthropic_planned_output()

    Visibility: Public

    Signature: def anthropic_planned_output(model: str, thinking_level: str | None) -> int:

    Description: Computes the total max tokens allocation that the Anthropic request will request. For modern adaptive models (matching ANTHROPIC_ADAPTIVE_PREFIXES), it returns the value calculated by anthropic_output_budget(). For pre-adaptive models (such as Claude Haiku 4.5), it computes the sum of the level-specific reasoning budget (ANTHROPIC_BUDGET_BY_LEVEL) and the base reply allocation (ANTHROPIC_BUDGET_REPLY_TOKENS, 16,000 tokens), capping the total at anthropic_output_cap().

    Parameters:

    • model (str): Target Claude model identifier.
    • thinking_level (str | None): Configured pipeline reasoning effort.

    Returns:

    • int: Total output token ceiling planned for the inference cycle.

    Example:

    def anthropic_planned_output(model: str, thinking_level: str | None) -> int:
    """Claude max_tokens the request will plan for (before the model/context ceiling): the per-effort
    table on adaptive models, budget_tokens + 16K on pre-adaptive ones (Haiku 4.5), capped by
    ANTHROPIC_MAX_OUTPUT_TOKENS. Shared by llm_anthropic and token_utils.input_token_budget."""
    effort = anthropic_effort(model, thinking_level)
    if (model or "").lower().startswith(ANTHROPIC_ADAPTIVE_PREFIXES):
        return anthropic_output_budget(effort)
    planned = ANTHROPIC_BUDGET_BY_LEVEL.get(effort, 0) + ANTHROPIC_BUDGET_REPLY_TOKENS
    cap = anthropic_output_cap()
    return min(planned, cap) if cap else planned

    This dual-branch planning ensures backward compatibility with older thinking paradigms where thinking tokens were configured as an explicit sub-budget rather than an overall effort setting. Token budgeting components rely on this function to establish identical reservation values across inference calls and context packing.

    gemini_thinking_mode()

    Visibility: Public

    Signature: def gemini_thinking_mode(model: str) -> tuple[str, object]:

    Description: Determines the thinking configuration schema supported by a specific Google Gemini model. It evaluates stripped model identifiers against legacy budget ranges (GEMINI_BUDGET_RANGES), legacy architectural prefixes (gemini-1, gemini-2), and modern Gemini 3.x series configurations (GEMINI_THINKING_LEVELS).

    Parameters:

    • model (str): Raw or qualified Gemini model name.

    Returns:

    • tuple[str, object]: A two-element tuple consisting of:
      1. Mode tag: "budget", "level", or "none".
      2. Specification: For "budget", a tuple (low, high, can_disable); for "level", a tuple of valid strings; for "none", None.

    Example:

    def gemini_thinking_mode(model: str) -> tuple[str, object]:
    """('level', allowed_levels) for Gemini 3.x, ('budget', (min, max, can_disable)) for 2.5,
    ('none', None) for models without a thinking control the project maps."""
    name = gemini_model_id(model)
    for prefix, low, high, can_disable in GEMINI_BUDGET_RANGES:
        if name.startswith(prefix):
            return "budget", (low, high, can_disable)
    if not name.startswith("gemini-") or name.startswith(("gemini-1", "gemini-2")):
        return "none", None  # 1.x / 2.0, other 2.5 variants (image, live, TTS) and non-Gemini ids
    for prefix, levels in GEMINI_THINKING_LEVELS:
        if name.startswith(prefix):
            return "level", levels
    # Other 3.x ids, '-latest' aliases (gemini-flash-latest, gemini-pro-latest) and newer families:
    # the level set every documented 3.x model accepts (a model that rejects it is handled at runtime).
    return "level", GEMINI_3_DEFAULT_LEVELS

    Sending thinking_level to a Gemini 2.5 endpoint or thinking_budget to a Gemini 3.x endpoint triggers an HTTP 400 validation error in the Google GenAI SDK. This function enforces strict separation between numerical budget parameters and enumerated level parameters.

    gemini_output_budget()

    Visibility: Public

    Signature: def gemini_output_budget(thinking_level: str | None, output_limit: int | None = None) -> int:

    Description: Determines the maximum generation token limit (max_output_tokens) for Gemini requests. It looks up the per-level allowance in GEMINI_OUTPUT_TOKENS_BY_EFFORT, limits the result to the model's reported limit (or GEMINI_DEFAULT_LIMITS[1]), and applies the GEMINI_MAX_OUTPUT_TOKENS environment override if set.

    Parameters:

    • thinking_level (str | None): Desired pipeline reasoning level.
    • output_limit (int | None, optional): Known upper output limit for the specific model. Defaults to None.

    Returns:

    • int: Planned output token limit.

    Example:

    def gemini_output_budget(thinking_level: str | None, output_limit: int | None = None) -> int:
    """Planned Gemini max_output_tokens: per-level table, capped by the model output limit and
    GEMINI_MAX_OUTPUT_TOKENS. Shared by llm_gemini (request) and token_utils (prompt budget)."""
    level = thinking_level.lower() if thinking_level else None
    budget = GEMINI_OUTPUT_TOKENS_BY_EFFORT.get(level, GEMINI_OUTPUT_TOKENS_BY_EFFORT[None])
    budget = min(budget, output_limit or GEMINI_DEFAULT_LIMITS[1])
    cap = _env_int("GEMINI_MAX_OUTPUT_TOKENS")
    return min(budget, cap) if cap else budget

    Gemini models allocate thinking and response text from the same output ceiling (typically 65,536 tokens). This function enforces that requests allocate sufficient tokens to prevent reasoning traces from cutting off the final response.

    openrouter_output_budget()

    Visibility: Public

    Signature: def openrouter_output_budget(model: str, thinking_level: str | None) -> int | None:

    Description: Resolves the completion token ceiling for models accessed via OpenRouter. It fetches metadata via openrouter_model_info(). If the model is not found in the catalog, it falls back to OPENROUTER_MAX_OUTPUT_TOKENS or returns None. When catalog metadata is available, it retrieves the base budget from OUTPUT_TOKENS_BY_EFFORT, caps it against the provider's max_completion_tokens (or 32,000), and applies OPENROUTER_MAX_OUTPUT_TOKENS if defined.

    Parameters:

    • model (str): Target OpenRouter model identifier or alias.
    • thinking_level (str | None): Desired reasoning level.

    Returns:

    • int | None: Resolved token budget or None if the model's limits are unverified.

    Example:

    def openrouter_output_budget(model: str, thinking_level: str | None) -> int | None:
    """Planned OpenRouter max_tokens: shared per-effort table, capped by the catalog's
    top_provider.max_completion_tokens and OPENROUTER_MAX_OUTPUT_TOKENS. None when the model is not
    in the catalog (unknown limits, e.g. a non-OpenRouter proxy): max_tokens is then omitted."""
    info = openrouter_model_info(model)
    if info is None:
        return _env_int("OPENROUTER_MAX_OUTPUT_TOKENS")
    level = thinking_level.lower() if thinking_level else None
    budget = OUTPUT_TOKENS_BY_EFFORT.get(level, OUTPUT_TOKENS_BY_EFFORT[None])
    model_cap = (info.get("top_provider") or {}).get("max_completion_tokens")
    budget = min(budget, model_cap) if model_cap else min(budget, 32_000)
    cap = _env_int("OPENROUTER_MAX_OUTPUT_TOKENS")
    return min(budget, cap) if cap else budget

    This dynamic catalog-driven logic avoids hardcoding limits for thousands of upstream models hosted on OpenRouter. If an upstream model is unverified or running behind a proxy, returning None allows the provider to apply its own defaults.

    context_output_reserve()

    Visibility: Public

    Signature: def context_output_reserve(thinking_level: str | None) -> int | None:

    Description: Calculates how many output tokens share the context window with the input prompt, tailored to the active provider. For Anthropic and OpenRouter, output tokens share the window and require reserving the planned maximum output. For Gemini, input and output limits are managed independently, so the reserve is 0. For unmanaged providers, it returns None.

    Parameters:

    • thinking_level (str | None): Configured pipeline reasoning level.

    Returns:

    • int | None: Number of tokens to reserve from the context window, or None if unmanaged.

    Example:

    def context_output_reserve(thinking_level: str | None) -> int | None:
    """Output tokens that share the context window with the prompt, for the active provider.
    ANTHROPIC / OPENROUTER: the planned max_tokens (thinking included). GEMINI: 0 — Gemini's input and
    output limits are separate. None: the provider does not size output (5% reserve in token_utils)."""
    provider, model, _, _ = resolve_llm_settings()
    if provider == "ANTHROPIC":
        return anthropic_planned_output(model, thinking_level)
    if provider == "GEMINI":
        return 0
    if provider == "OPENROUTER":
        return openrouter_output_budget(model, thinking_level)
    return None

    Prompt budgeting logic in utils.token_utils uses this value to determine the maximum available prompt context. Subtracting this reserve prevents generation errors caused by prompts leaving insufficient room for output tokens.

    get_llm_provider()

    Visibility: Public

    Signature: def get_llm_provider() -> str | None:

    Description: Resolves the active provider name from the process environment. An explicit LLM_PROVIDER environment variable takes precedence. If omitted, the presence of GEMINI_PROJECT_ID or GEMINI_API_KEY falls back to GEMINI. Anthropic is intentionally never auto-selected without an explicit LLM_PROVIDER=ANTHROPIC configuration.

    Parameters:

    None.

    Returns:

    • str | None: The uppercase provider name ("GEMINI", "ANTHROPIC", "OPENROUTER", etc.) or None if unconfigured.

    Example:

    def get_llm_provider() -> str | None:
    """Determine the LLM provider from environment variables.

    Explicit LLM_PROVIDER wins; otherwise Gemini credentials select GEMINI (legacy default).
    ANTHROPIC is never auto-selected: ANTHROPIC_API_KEY is often exported globally for other
    tools (e.g. Claude Code), and a silent switch to a paid Claude run would be surprising.
    """
    provider = os.getenv("LLM_PROVIDER")
    if provider:
        return provider.strip().upper()
    if os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY"):
        return "GEMINI"
    return None

    The selective fallback behavior prevents accidental billable usage. Since developers frequently set ANTHROPIC_API_KEY globally for local developer tooling, requiring LLM_PROVIDER=ANTHROPIC ensures that Claude calls are explicitly opt-in.

    openrouter_model_info()

    Visibility: Public

    Signature: def openrouter_model_info(model_id: str) -> dict | None:

    Description: Searches the OpenRouter catalog for a model entry matching a given ID. The lookup handles routing suffixes (such as :nitro, :floor, :thinking), canonical slugs, dated slugs (e.g., matching anthropic/claude-4.6-opus to anthropic/claude-4.6-opus-20260205), and resolves alias_target references to underlying target models.

    Parameters:

    • model_id (str): Requested model name, slug, or aliased string.

    Returns:

    • dict | None: The matching catalog dictionary from OpenRouter, or None if not found or the catalog is unavailable.

    Example:

    def openrouter_model_info(model_id: str) -> dict | None:
    """Catalog entry for a model id: exact id, canonical_slug, routing-suffix variant
    (':nitro', ':floor', ...), dated canonical slug (e.g. 'anthropic/claude-4.6-opus' →
    'anthropic/claude-4.6-opus-20260205'), or a '~...-latest' alias's target."""
    catalog = openrouter_catalog()
    if not catalog or not model_id:
        return None
    wanted = model_id.strip()
    candidates = [wanted, *(wanted[: -len(suffix)] for suffix in _OPENROUTER_ROUTING_SUFFIXES if wanted.endswith(suffix))]
    for name in candidates:
        entry = next((m for m in catalog if m.get("id") == name or m.get("canonical_slug") == name), None)
        if entry is None:
            # Dated canonical slug only ('anthropic/claude-4.6-opus' → '…-20260205'): a looser prefix
            # match would map typos such as 'google/gemini-3.1-pro' onto a different model.
            dated = re.compile(re.escape(name) + r"-\d{8}")
            entry = next((m for m in catalog if dated.fullmatch(str(m.get("canonical_slug", "")))), None)
        if entry is not None:
            target = (entry.get("alias_target") or {}).get("slug")
            if target and target != entry.get("id"):
                return next((m for m in catalog if m.get("id") == target or m.get("canonical_slug") == target), entry)
            return entry
    return None

    This matching logic resolves varied model specifications to concrete catalog metadata, ensuring the pipeline correctly extracts context limits and parameter capabilities regardless of the naming style used.

    def parse_ant_auth_status(output: str) -> tuple[str | None, str | None]:
    """Return (active credential, active workspace) from `ant auth status` output.

    The command's exit code is not a health signal, so read its `(active)` rows instead:
        Credentials
          (active) * Profile (user_oauth) [via active_config]       sk-ant-oat01-EXA...
        Workspace
          (active) * Workspace                                      wrkspc_01... (Engineering)
    """
    section, credential, workspace = None, None, None
    for line in output.splitlines():
        if not line.strip():
            continue
        if not line[0].isspace():
            header = line.strip().lower()
            section = header if header in ("credentials", "workspace") else None
            continue

            workspace = workspace or text
        else:

    return credential, workspace

    check_anthropic_auth()

    Visibility: Public

    Signature: def check_anthropic_auth() -> bool:

    Description: Validates authentication credentials when LLM_PROVIDER=ANTHROPIC. The verification follows this sequence: 1. Verifies that the anthropic Python SDK is installed. 2. Checks for ANTHROPIC_API_KEY or ANTHROPIC_AUTH_TOKEN. 3. Checks for Workload Identity Federation configuration. 4.     None.

    Returns:

    • bool: True if valid credentials are confirmed or the provider is not Anthropic; False if unauthenticated.

    Example:

    def check_anthropic_auth() -> bool:
    """Preflight for LLM_PROVIDER=ANTHROPIC. Returns False (after printing instructions) when
    the run cannot authenticate; True otherwise, including for every other provider.

    Order: anthropic package installed → ANTHROPIC_API_KEY / ANTHROPIC_AUTH_TOKEN →
    Workload Identity Federation env vars → `ant auth status` (active login profile) →
    stored login files when the `ant` CLI is not installed.
    """
    from utils.output import emit, emit_raw

    if get_llm_provider() != "ANTHROPIC":
        return True
    if not _anthropic_sdk_installed():
        emit("ERROR_ANTHROPIC_SDK_MISSING")
        return False

    if _env_set("ANTHROPIC_API_KEY") and _env_set("ANTHROPIC_AUTH_TOKEN"):
        emit("WARN_ANTHROPIC_KEY_AND_TOKEN")
    if _env_set("ANTHROPIC_API_KEY"):
        emit("ANTHROPIC_AUTH_OK", source="ANTHROPIC_API_KEY")
        return True
    if _env_set("ANTHROPIC_AUTH_TOKEN"):
        emit("ANTHROPIC_AUTH_OK", source="ANTHROPIC_AUTH_TOKEN")
        return True
    if all(_env_set(v) for v in _FEDERATION_VARS) and (_env_set("ANTHROPIC_IDENTITY_TOKEN_FILE") or _env_set("ANTHROPIC_IDENTITY_TOKEN")):
        emit("ANTHROPIC_AUTH_OK", source="Workload Identity Federation")
        return True

    # No key: the SDK falls back to an `ant auth login` profile. Verify one is active.
    ant = shutil.which("ant")
    if not ant:
        stored = sorted(glob.glob(os.path.join(_anthropic_config_dir(), "credentials", "*.json")))
        if stored:
            emit("WARN_ANTHROPIC_ANT_MISSING_LOGIN_FOUND", path=stored[0])
            return True
        emit("ERROR_ANTHROPIC_NO_CREDENTIALS")
        _emit_auth_help(ant_installed=False)
        return False

    # Run with the same environment the SDK will see; empty key variables are dropped so the
    # CLI reports the profile the SDK will actually use (the SDK treats empty as unset).
    env = {k: v for k, v in os.environ.items() if not (k in ("ANTHROPIC_API_KEY", "ANTHROPIC_AUTH_TOKEN") and not v.strip())}
    try:
        result = subprocess.run([ant, "auth", "status"], capture_output=True, text=True, encoding="utf-8", errors="replace", timeout=30, env=env)
    except (OSError, subprocess.SubprocessError) as e:
        emit("WARN_ANTHROPIC_AUTH_UNVERIFIED", error=str(e))
        return True

    emit_raw("DEBUG", f"ant auth status | exit={result.returncode}\n{_redact(output).strip()}", dest="LOG")
    if not credential:
        emit("ERROR_ANTHROPIC_NOT_LOGGED_IN")
        details = _redact(output).strip()
        if details:
            emit_raw("INFO", "\n".join(f"    {line}" for line in details.splitlines()))
        _emit_auth_help(ant_installed=True)
        return False

    source = _ui("AUTH_SOURCE_ANT_LOGIN", credential=credential)
    if workspace:
        source += f" | {_ui('AUTH_SOURCE_WORKSPACE', workspace=workspace)}"
    emit("ANTHROPIC_AUTH_OK", source=source)
    return True

    model = os.getenv("OPENROUTER_MODEL", "").strip()
    if not model:
        emit("ERROR_OPENROUTER_NO_MODEL")
        return False
    if openrouter_catalog() and openrouter_model_info(model) is None:
        emit("WARN_OPENROUTER_MODEL_UNKNOWN", model=model)
    emit("LLM_AUTH_OK", provider="OpenRouter", source=f"OPENROUTER_API_KEY | {model} | {openrouter_base_url()}")
    return True

    This check allows third-party OpenAI-compatible reverse proxies to operate without an API key if the endpoint is not on openrouter.ai, while enforcing API key presence for the official service.

    _normalize_claude_id()

    Visibility: Private

    Signature: def _normalize_claude_id(model_name: str) -> str:

    Description: Normalizes Claude model identifiers across various cloud formats (e.g., Anthropic native, AWS Bedrock, OpenRouter slugs, version-first naming) into a consistent family-first format. It replaces dots with dashes, extracts substrings following claude-, and uses _CLAUDE_VERSION_FIRST to reorder patterns like claude-4-7-opus into claude-opus-4-7.

    Parameters:

    • model_name (str): The raw model name or routing string.

    Returns:

    • str: Standardized Claude identifier.

    Example:

    def _normalize_claude_id(model_name: str) -> str:
    """Gateway/cloud IDs → bare family-first Claude ID: 'anthropic/claude-opus-4.7',
    'bedrock/us.anthropic.claude-opus-4-7-v1:0' and the version-first alias
    'anthropic/claude-4.7-opus-20260416' all → 'claude-opus-4-7...'."""
    name = (model_name or "").lower().replace(".", "-")
    start = name.find("claude-")
    name = name[start:] if start >= 0 else name
    match = _CLAUDE_VERSION_FIRST.match(name)
    if match:
        major, minor, family = match.groups()
        name = f"claude-{family}-{major}" + (f"-{minor}" if minor else "") + name[match.end() :]
    return name

    This transformation normalizes varied model naming conventions across cloud providers (e.g., bedrock/us.anthropic.claude-opus-4-7-v1:0 vs claude-4.7-opus) so prefix matching against ANTHROPIC_ADAPTIVE_PREFIXES evaluates consistently.

    Error Handling

    The module implements defensive validation patterns to catch configuration problems during preflight checks, avoiding unhandled exceptions during inference:

    • Graceful Environment Coercion: Functions such as _env_int() and _ratio_from_env() catch ValueError internally and check for non-finite values (math.isfinite), falling back to safe defaults when variables contain invalid data.
    • Network Fault Resilience in OpenRouter Catalog: When fetching the OpenRouter catalog in openrouter_catalog(), network or JSON parsing failures trigger a 60-second cooldown (_OPENROUTER_RETRY_COOLDOWN). Failed responses are not cached, and transient errors are logged once via warn_once() rather than raising uncaught exceptions.
    • Subprocess Isolation: In check_anthropic_auth(), running ant auth status via subprocess.run() catches OSError and SubprocessError. If the execution fails or times out (30s), it logs a warning (WARN_ANTHROPIC_AUTH_UNVERIFIED) and allows execution to proceed to SDK-level authentication.
    • Dynamic Import Safety: Package presence checks like _anthropic_sdk_installed() and _installed_version() wrap importlib calls in defensive try/except blocks (ImportError, ValueError, PackageNotFoundError), allowing checks to run safely across diverse virtual environment setups.
