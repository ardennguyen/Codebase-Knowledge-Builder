    llm_config.py

    Source: utils/llm_config.py

    Following the vendor-neutral state management and telemetry primitives established in llm_common.py, llm_config.py acts as the single source of truth for runtime provider resolution, model capability negotiation, token ratio calibration, output budgeting, and preflight authentication checks across the entire system. It was extracted directly from call_llm.py to break a circular import dependency between execution dispatching and prompt budgeting in token_utils.py. Both inference drivers and context-sizing utilities now import settings and token limits from this module without reciprocal couplings.

    The module manages execution policies across three primary inference ecosystems: Anthropic Claude, Google Gemini, and OpenRouter. It resolves target provider environments, negotiates model-specific features—such as adaptive reasoning budgets versus explicit token limits, and flags models that reject standard sampling controls (e.g., temperature, top_p, top_k). It also provides tokenizer calibration multipliers to reconcile discrepancies between native BPE tokenizers and the cl100k_base encoding used by tiktoken, preventing context window overflow during high-density code analysis.

    In addition to static configuration resolution, the module implements lightweight credential preflights and runtime catalog discovery. It validates environment variables, SDK installations, Google Vertex AI Application Default Credentials (ADC), and Anthropic CLI (ant auth status) profiles before expensive graph traversal passes begin. For OpenRouter endpoints, it features an in-memory cached model catalog fetcher with automatic cooldown backoff to dynamically determine remote context windows and provider-specific parameter capabilities.

    anthropic_output_cap()

    Visibility: Public
    Signature: def anthropic_output_cap() -> int | None:

    Description: Retrieves the maximum output token limit configured for Anthropic models via the ANTHROPIC_MAX_OUTPUT_TOKENS environment variable. If the variable is unset, empty, non-numeric, or less than or equal to zero, it evaluates to None.

    Parameters: None.

    Returns: * int | None: An integer token cap if a valid positive integer is found in the environment; otherwise None.

    Raises: None.

    Example: 

    def anthropic_output_cap() -> int | None:
    """ANTHROPIC_MAX_OUTPUT_TOKENS as an int, or None when unset/invalid."""
    return _env_int("ANTHROPIC_MAX_OUTPUT_TOKENS")

    The function delegates string parsing and positive-integer validation to the internal helper _env_int. Downstream sizing workflows consume this value to enforce hard administrative output boundaries that override default thinking-level calculations.

    anthropic_output_budget()

    Visibility: Public
    Signature: def anthropic_output_budget(thinking_level: str | None) -> int:

    Description: Resolves the target output token budget for adaptive Anthropic models based on an abstract thinking effort level. It queries ANTHROPIC_MAX_TOKENS_BY_EFFORT, falling back to the unconfigured default if thinking_level is None or unrecognized, and clamps the resulting value using anthropic_output_cap().

    Parameters: * thinking_level (str | None): Desired reasoning level ("minimal", "low", "medium", "high", "xhigh", "max", or None).

    Returns: * int: Allocated token budget for the response, constrained by any administrative ceiling.

    Raises: None.

    Example: 

    def anthropic_output_budget(thinking_level: str | None) -> int:
    """Per-effort table value capped by ANTHROPIC_MAX_OUTPUT_TOKENS (adaptive models)."""
    level = thinking_level.lower() if thinking_level else None
    budget = ANTHROPIC_MAX_TOKENS_BY_EFFORT.get(level, ANTHROPIC_MAX_TOKENS_BY_EFFORT[None])
    cap = anthropic_output_cap()
    return min(budget, cap) if cap else budget

    This function ensures that adaptive thinking requests reserve adequate output headroom for both the generated thought blocks and the final response. When an administrative token cap is active via anthropic_output_cap(), min(budget, cap) guarantees the returned budget does not exceed organizational token constraints.

    anthropic_effort()

    Visibility: Public
    Signature: def anthropic_effort(model: str, level: str | None) -> str | None:

    Description: Normalizes an abstract reasoning level into a vendor-accepted output_config.effort parameter for Anthropic models. It maps "minimal" to "low", rejects values outside ANTHROPIC_EFFORT_LEVELS, and downgrades "xhigh" to "high" on legacy Claude 4.6 family architectures.

    Parameters: * model (str): Target Anthropic model identifier. * level (str | None): Input effort string.

    Returns: * str | None: Normalized effort string ("low", "medium", "high", "xhigh", "max"), or None if the input is empty or invalid.

    Raises: None.

    Example: 

    def anthropic_effort(model: str, level: str | None) -> str | None:
    """Thinking level → effort the model accepts: minimal → low, xhigh → high on the 4.6 family,
    unknown values → None (model default)."""
    if not level:
        return None
    level = level.lower()
    if level == "minimal":
        level = "low"
    if level not in ANTHROPIC_EFFORT_LEVELS:
        return None
    if level == "xhigh" and (model or "").lower().startswith(ANTHROPIC_NO_XHIGH_PREFIXES):
        return "high"
    return level

    This mapping guarantees API compatibility across model iterations. Because older models like Claude 4.6 throw runtime HTTP 400 errors when encountering "xhigh", the function evaluates prefix match tuples (ANTHROPIC_NO_XHIGH_PREFIXES) to downgrade the effort level before payload assembly occurs in llm_anthropic.py.

    anthropic_planned_output()

    Visibility: Public
    Signature: def anthropic_planned_output(model: str, thinking_level: str | None) -> int:

    Description: Calculates the total output token reservation (max_tokens) that must be planned for an Anthropic request prior to applying context window clamping. For modern adaptive models, it delegates to anthropic_output_budget. For pre-adaptive models (such as Claude Haiku 4.5), it adds a 16,000-token reply buffer (ANTHROPIC_BUDGET_REPLY_TOKENS) to the fixed budget table (ANTHROPIC_BUDGET_BY_LEVEL), capping the sum with anthropic_output_cap().

    Parameters: * model (str): The target Claude model identifier. * thinking_level (str | None): Desired thinking intensity level.

    Returns: * int: Total output token count to configure in the API payload.

    Raises: None.

    Example: 

    def anthropic_planned_output(model: str, thinking_level: str | None) -> int:
    """Claude max_tokens the request will plan for (before the model/context ceiling): the per-effort
    table on adaptive models, budget_tokens + 16K on pre-adaptive ones (Haiku 4.5), capped by
    ANTHROPIC_MAX_OUTPUT_TOKENS. Shared by llm_anthropic and token_utils.input_token_budget."""
    effort = anthropic_effort(model, thinking_level)
    if (model or "").lower().startswith(ANTHROPIC_ADAPTIVE_PREFIXES):
        return anthropic_output_budget(effort)
    planned = ANTHROPIC_BUDGET_BY_LEVEL.get(effort, 0) + ANTHROPIC_BUDGET_REPLY_TOKENS
    cap = anthropic_output_cap()
    return min(planned, cap) if cap else planned

    This function is shared between the prompt budget sizing engine in token_utils.py and the driver payload assembler in llm_anthropic.py. By using an identical calculation, the system ensures that input context packing leaves enough room for the model to emit its planned output tokens without truncating generation.

    gemini_thinking_mode()

    Visibility: Public
    Signature: def gemini_thinking_mode(model: str) -> tuple[str, object]:

    Description: Determines the thinking parameter strategy required by a Gemini model. It inspects normalized model IDs against known budget ranges (Gemini 2.5) and allowed categorical level sets (Gemini 3.x), returning a mode discriminator and its associated configuration tuple.

    Parameters: * model (str): Raw or normalized Gemini model identifier.

    Returns: * tuple[str, object]: A tuple indicating the parameter schema: * ("budget", (min_tokens, max_tokens, can_disable)) for Gemini 2.5. * ("level", allowed_levels_tuple) for Gemini 3.x. * ("none", None) for older architectures (Gemini 1.x, 2.0) or non-text variants.

    Raises: None.

    Example: 

    def gemini_thinking_mode(model: str) -> tuple[str, object]:
    """('level', allowed_levels) for Gemini 3.x, ('budget', (min, max, can_disable)) for 2.5,
    ('none', None) for models without a thinking control the project maps."""
    name = gemini_model_id(model)
    for prefix, low, high, can_disable in GEMINI_BUDGET_RANGES:
        if name.startswith(prefix):
            return "budget", (low, high, can_disable)
    if not name.startswith("gemini-") or name.startswith(("gemini-1", "gemini-2")):
        return "none", None  # 1.x / 2.0, other 2.5 variants (image, live, TTS) and non-Gemini ids
    for prefix, levels in GEMINI_THINKING_LEVELS:
        if name.startswith(prefix):
            return "level", levels
    # Other 3.x ids, '-latest' aliases (gemini-flash-latest, gemini-pro-latest) and newer families:
    # the level set every documented 3.x model accepts (a model that rejects it is handled at runtime).
    return "level", GEMINI_3_DEFAULT_LEVELS

    The returned configuration controls how llm_gemini.py structures its ThinkingConfig. Sending both thinking_level and thinking_budget simultaneously triggers an HTTP 400 error from the Google GenAI SDK, making this branch discriminator a critical protocol gatekeeper.

    gemini_model_id()

    Visibility: Public
    Signature: def gemini_model_id(model: str) -> str:

    Description: Strips Google resource hierarchy prefixes (such as models/ or publishers/google/models/) from an input model string, returning a lowercased bare model name.

    Parameters: * model (str): The model name or resource path.

    Returns: * str: Clean, lower-cased model identifier.

    Raises: None.

    Example: 

    def gemini_model_id(model: str) -> str:

    This helper standardizes identifiers across diverse source inputs, such as command-line flags, Vertex AI Model Garden paths, and Google AI Studio REST endpoints. Subsequent prefix matching logic relies entirely on this normalized representation.

    gemini_vertex_locations()

    Visibility: Public
    Signature: def gemini_vertex_locations(model: str) -> tuple | None:

    Description: Resolves the allowed Google Cloud Vertex AI geographic endpoint locations serving a specific Gemini model family using longest-prefix matching.

    Parameters: * model (str): Normalized or raw Gemini model identifier.

    Returns: * tuple | None: A tuple of valid region strings (e.g., ("global", "us")), or None if the model family is served by any regional endpoint.

    Raises: None.

    Example: 

    def gemini_vertex_locations(model: str) -> tuple | None:
    """Vertex AI locations that serve a Gemini 3.x model (None = any, including regional endpoints)."""
    name = gemini_model_id(model)
    for prefix, locations in GEMINI_VERTEX_LOCATIONS:
        if name.startswith(prefix):
            return locations
    return GEMINI_3_VERTEX_LOCATIONS if name.startswith("gemini-3") else None

    Because Gemini 3.x models are restricted to global and multi-region locations rather than traditional regional endpoints (e.g., us-central1), this function enables check_gemini_config() to emit early configuration warnings when an incompatible region is requested.

    gemini_output_budget()

    Visibility: Public
    Signature: def gemini_output_budget(thinking_level: str | None, output_limit: int | None = None) -> int:

    Description: Computes the planned max_output_tokens allocation for Gemini models. It references GEMINI_OUTPUT_TOKENS_BY_EFFORT, clamps the value against the model limit (defaulting to 65,536 tokens), and applies administrative overrides defined in GEMINI_MAX_OUTPUT_TOKENS.

    Parameters: * thinking_level (str | None): Desired thinking intensity level. * output_limit (int | None, optional): Known output token limit of the model. Defaults to GEMINI_DEFAULT_LIMITS[1].

    Returns: * int: Final output token limit to send to the Gemini driver.

    Raises: None.

    Example: 

    def gemini_output_budget(thinking_level: str | None, output_limit: int | None = None) -> int:
    """Planned Gemini max_output_tokens: per-level table, capped by the model output limit and
    GEMINI_MAX_OUTPUT_TOKENS. Shared by llm_gemini (request) and token_utils (prompt budget)."""
    level = thinking_level.lower() if thinking_level else None
    budget = GEMINI_OUTPUT_TOKENS_BY_EFFORT.get(level, GEMINI_OUTPUT_TOKENS_BY_EFFORT[None])
    budget = min(budget, output_limit or GEMINI_DEFAULT_LIMITS[1])
    cap = _env_int("GEMINI_MAX_OUTPUT_TOKENS")
    return min(budget, cap) if cap else budget

    This budget enforces balance between context and generation size. Because Gemini includes thinking tokens within the overall max_output_tokens payload quota, setting this allocation prevents premature truncation during long reasoning phases.

    openrouter_output_budget()

    Visibility: Public
    Signature: def openrouter_output_budget(model: str, thinking_level: str | None) -> int | None:

    Description: Resolves planned maximum output tokens for models invoked through OpenRouter. It looks up the model's catalog entry, inspects provider-specific parameters (top_provider.max_completion_tokens), clamps to effort defaults, and enforces OPENROUTER_MAX_OUTPUT_TOKENS.

    Parameters: * model (str): Target model name or identifier. * thinking_level (str | None): Reasoning effort level.

    Returns: * int | None: Resolved token cap, or None if the model is absent from the OpenRouter catalog (indicating limits cannot be verified, prompting callers to omit the parameter).

    Raises: None.

    Example: 

    def openrouter_output_budget(model: str, thinking_level: str | None) -> int | None:
    """Planned OpenRouter max_tokens: shared per-effort table, capped by the catalog's
    top_provider.max_completion_tokens and OPENROUTER_MAX_OUTPUT_TOKENS. None when the model is not
    in the catalog (unknown limits, e.g. a non-OpenRouter proxy): max_tokens is then omitted."""
    info = openrouter_model_info(model)
    if info is None:
        return _env_int("OPENROUTER_MAX_OUTPUT_TOKENS")
    level = thinking_level.lower() if thinking_level else None
    budget = OUTPUT_TOKENS_BY_EFFORT.get(level, OUTPUT_TOKENS_BY_EFFORT[None])
    model_cap = (info.get("top_provider") or {}).get("max_completion_tokens")
    budget = min(budget, model_cap) if model_cap else min(budget, 32_000)
    cap = _env_int("OPENROUTER_MAX_OUTPUT_TOKENS")
    return min(budget, cap) if cap else budget

    When targeting custom endpoints or non-catalog proxies that mirror the OpenRouter API, returning None allows the request assembler in call_llm.py to omit max_tokens entirely, preventing request rejections caused by invalid default caps.

    context_output_reserve()

    Visibility: Public
    Signature: def context_output_reserve(thinking_level: str | None) -> int | None:

    Description: Determines how many output tokens must be subtracted from the total context window to reserve space for model responses. For Anthropic and OpenRouter, output tokens share the context window with the prompt. For Gemini, output limits are separate from input context, so this returns 0.

    Parameters: * thinking_level (str | None): Reasoning level under evaluation.

    Returns: * int | None: Token count to subtract from the model context window, or None if the active provider does not define output sizing.

    Raises: None.

    Example: 

    def context_output_reserve(thinking_level: str | None) -> int | None:
    """Output tokens that share the context window with the prompt, for the active provider.
    ANTHROPIC / OPENROUTER: the planned max_tokens (thinking included). GEMINI: 0 — Gemini's input and
    output limits are separate. None: the provider does not size output (5% reserve in token_utils)."""
    provider, model, _, _ = resolve_llm_settings()
    if provider == "ANTHROPIC":
        return anthropic_planned_output(model, thinking_level)
    if provider == "GEMINI":
        return 0
    if provider == "OPENROUTER":
        return openrouter_output_budget(model, thinking_level)
    return None

    This abstraction allows token_utils.py to calculate repository ingestion budgets without embedding provider-specific context architecture rules. Returning None prompts upstream callers to fall back to a defensive default (e.g., reserving 5% of the total context window).

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description: Evaluates environment variables to determine the active LLM provider. Explicit declarations in LLM_PROVIDER take precedence. If unset, the presence of GEMINI_PROJECT_ID or GEMINI_API_KEY defaults the run to "GEMINI". Anthropic is intentionally never auto-selected without an explicit LLM_PROVIDER=ANTHROPIC variable.

    Parameters: None.

    Returns: * str | None: The normalized provider name ("GEMINI", "ANTHROPIC", "OPENROUTER", or custom), or None if no provider can be resolved.

    Raises: None.

    Example: 

    def get_llm_provider() -> str | None:
    """Determine the LLM provider from environment variables.

    Explicit LLM_PROVIDER wins; otherwise Gemini credentials select GEMINI (legacy default).
    ANTHROPIC is never auto-selected: ANTHROPIC_API_KEY is often exported globally for other
    tools (e.g. Claude Code), and a silent switch to a paid Opus run would be surprising.
    """
    provider = os.getenv("LLM_PROVIDER")
    if provider:
        return provider.strip().upper()
    if os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY"):
        return "GEMINI"
    return None

    The restriction on auto-detecting Anthropic is an intentional defensive design choice. Because developers frequently export ANTHROPIC_API_KEY globally for local developer tooling (like Claude Code), automatically falling back to Anthropic could incur unintended billing costs on premium models like Claude Opus.

    openrouter_base_url()

    Visibility: Public
    Signature: def openrouter_base_url() -> str:

    Description: Resolves the base URL for OpenRouter requests from OPENROUTER_BASE_URL or defaults to DEFAULT_OPENROUTER_BASE_URL. Strips trailing slashes and removes any trailing /v1 segment to normalize the root URL for path concatenation.

    _normalize_claude_id()

    Visibility: Private
    Signature: def _normalize_claude_id(model_name: str) -> str:

    Description: Converts diverse gateway and cloud provider Claude model identifiers into canonical, family-first IDs. Normalizes delimiters, strips leading gateway prefixes (such as anthropic/ or bedrock/...), and reorganizes version-first naming schemes (e.g., claude-4.7-opus -> claude-opus-4-7).

    Parameters: * model_name (str): Raw model identifier or path.

    Returns: * str: Canonical lowercased family-first model ID.

    Raises: None.

    Example: 

    def _normalize_claude_id(model_name: str) -> str:
    """Gateway/cloud IDs → bare family-first Claude ID: 'anthropic/claude-opus-4.7',
    'bedrock/us.anthropic.claude-opus-4-7-v1:0' and the version-first alias
    'anthropic/claude-4.7-opus-20260416' all → 'claude-opus-4-7...'."""
    name = (model_name or "").lower().replace(".", "-")
    start = name.find("claude-")
    name = name[start:] if start >= 0 else name
    match = _CLAUDE_VERSION_FIRST.match(name)
    if match:
        major, minor, family = match.groups()
        name = f"claude-{family}-{major}" + (f"-{minor}" if minor else "") + name[match.end() :]
    return name

    This helper uses the regular expression _CLAUDE_VERSION_FIRST (re.compile(r"claude-(\d+)(?:-(\d+))?-(opus|sonnet|haiku|fable|mythos)")). By reorganizing version-first identifiers into family-first forms, subsequent prefix checks (like ANTHROPIC_ADAPTIVE_PREFIXES) can match variations accurately across different naming conventions.

    Error Handling

    The module implements defensive validation patterns to catch configuration problems before inference begins:

    • SDK Version Enforcement (check_gemini_config): Compares installed google-genai versions against GEMINI_MIN_SDK (1.56.0). Outdated installations emit ERROR_GEMINI_SDK_OUTDATED and return False, preventing runtime Pydantic schema validation failures from unsupported thinking levels.
    • OpenRouter Catalog Network Resilience (openrouter_catalog): HTTP failures and malformed catalog payloads trigger a 60-second cooldown (_OPENROUTER_RETRY_COOLDOWN). Subsequent lookups return None immediately, allowing operations to proceed with fallback context lengths rather than hanging on repeated network timeouts.
    • Anthropic Authentication Verification (check_anthropic_auth): If environment variables are missing, the preflight checks for the ant CLI tool or saved JSON profiles in _anthropic_config_dir(). Subprocess execution handles OSError and subprocess.SubprocessError by emitting WARN_ANTHROPIC_AUTH_UNVERIFIED and allowing the run to proceed, letting the native SDK make the final authentication attempt.
    • Google Application Default Credentials Validation (check_gemini_config): When using Vertex AI, the module tests google.auth.default(). If credentials cannot be loaded, it catches the exception, logs the first line via ERROR_GEMINI_VERTEX_CREDENTIALS, and aborts early to prevent downstream authentication failures.
    • Context Length Fallback (get_model_context_length): If catalog lookups or provider limit queries raise unexpected errors, the exception is caught, logged via WARN_CONTEXT_LENGTH_FETCH, and safely falls back to a baseline limit of 100,000 tokens.
