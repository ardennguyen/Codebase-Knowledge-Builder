    crawl_local_files.py

    Source: utils/crawl_local_files.py

    Technical Overview

    crawl_local_files.py serves as the primary local filesystem ingestion component for the Codebase-Knowledge-Builder architecture. Operating as the local counterpart to crawl_github_files.py, this module scans a designated root directory on the host machine, normalizes directory hierarchies, evaluates path-filtering rules, and reads file content into memory. Downstream analysis nodes, including AST parsing routines and LLM-assisted knowledge extraction passes, depend on the resulting in-memory file dictionary to generate technical documentation without requiring external network access or Git credentials.

    The crawling pipeline is implemented as a single-pass traversal built upon Python's os.walk. To optimize performance across large code repositories, the traversal implements in-place directory pruning (dirs.remove()), ensuring that entire subtrees designated as ignored—such as build directories, virtual environments, or package caches—are bypassed before entering unnecessary recursion cycles. Filtering is governed hierarchically: the module dynamically identifies, parses, and caches scoping rules from both root and nested .gitignore files using pathspec, while simultaneously evaluating explicit glob patterns (include_patterns and exclude_patterns) via fnmatch. Files exceeding a configured byte size ceiling or failing UTF-8 text decoding (such as compiled binaries or proprietary formats) are recorded and excluded.

    The module integrates tightly with the runtime's central telemetry bus in utils.output. Rather than printing unformatted diagnostic text directly to stdout, the crawler emits standardized, localized event tokens (emit) along with structural counts for processed, excluded, and non-text entries. This design isolates file discovery and ingestion mechanics from presentation and report generation, maintaining structural parity with remote GitHub crawl workflows.

    Public API

    crawl_local_files()

    Visibility: Public

    Signature: def crawl_local_files( directory, include_patterns=None, exclude_patterns=None, max_file_size=None, use_relative_paths=True, ):

    Description: Recursively walks the specified local directory to collect, filter, and extract file contents into a standardized dictionary structure. The function enforces root and nested .gitignore compliance, evaluates custom glob exclusion and inclusion rules, validates file sizes against byte limits, decodes text using utf-8-sig to safely strip Byte Order Marks (BOM), and emits comprehensive progress metrics.

    Parameters:

    • directory (str): The target filesystem path pointing to the root directory to crawl.
    • include_patterns (set | None): Optional set of glob expressions (e.g., {"*.py", "*.js"}) restricting the crawler strictly to matching file paths.
    • exclude_patterns (set | None): Optional set of glob expressions (e.g., {"tests/*", "*.pyc"}) specifying directories and files to exclude.
    • max_file_size (int | None): Optional maximum file size threshold in bytes. Files exceeding this ceiling are excluded from ingestion.
    • use_relative_paths (bool): Flag indicating whether dictionary keys should be normalized relative to directory (defaults to True) or maintained as absolute/raw filesystem paths.

    Returns:

    • dict: A dictionary containing a single "files" key mapped to an inner dictionary {filepath: content}, where each path points to its decoded UTF-8 string payload.

    Raises:

    • ValueError: Raised if the target directory argument does not exist or fails os.path.isdir().

    Example:

    files_data = crawl_local_files(
    "..",
    exclude_patterns={
        "*.pyc",
        "__pycache__/*",
        ".venv/*",
        ".git/*",
        "docs/*",
        "output/*",
    },
)

    The function begins by verifying that the target filesystem path points to an accessible directory; if not, it raises a ValueError immediately. It initializes tracking counters for crawl telemetry, empty lists for skipped items, and the main files_dict container. It then inspects the crawl root for an initial .gitignore file, parses it into a pathspec.PathSpec object mapped to the directory's absolute path, and retrieves localized rejection reason strings once via utils.output.get to avoid redundant dictionary lookups throughout the traversal.

    Phase 2: Directory Traversal and Pruning

        # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        abs_root = os.path.abspath(root)

        # Check for nested .gitignore in current directory (skip root, already loaded)
        if abs_root != os.path.abspath(directory):
            nested_gi = os.path.join(root, ".gitignore")
            if os.path.exists(nested_gi):
                spec = _load_gitignore(nested_gi)
                if spec:
                    gitignore_specs[abs_root] = spec

        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            abs_d = os.path.join(abs_root, d)
            dirpath_rel = os.path.relpath(abs_d, directory)

            reason = None
            if _matches_any_gitignore(gitignore_specs, abs_d, is_dir=True):
                reason = reason_gitignore
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = reason_excluded
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                emit("CRAWL_DIR_EXCLUDED", num=entry_num, path=dirpath_rel, reason=reason)

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()

    The crawler initiates a single-pass os.walk through the filesystem hierarchy. At each traversed directory level, it detects and loads any nested .gitignore file into gitignore_specs to enforce scoped ignoring rules for child subtrees. Candidate child directories are evaluated against both loaded .gitignore specifications and user-supplied exclude_patterns. Any matched directory is pruned directly from dirs in-place using dirs.remove(d), which halts os.walk from descending into that entire filesystem subtree and conserves significant I/O and CPU cycles.

    Phase 3: File Filtering Chain

            # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            abs_filepath = os.path.abspath(filepath)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore (all levels)
            if _matches_any_gitignore(gitignore_specs, abs_filepath):
                count_excluded += 1
                emit("CRAWL_FILE_GITIGNORE", num=entry_num, path=relpath)
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=relpath)
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    emit("CRAWL_FILE_NOT_INCLUDED", num=entry_num, path=relpath)
                    continue

    For every file located within an unpruned directory, the crawler executes an ordered filtering pipeline. Files are first matched against all active .gitignore rules across all hierarchy levels via _matches_any_gitignore(). If permitted, the relative file path is checked against the set of exclude_patterns using fnmatch.fnmatch. Finally, if include_patterns were explicitly configured, the path must positively match at least one pattern, or else it is rejected and tagged with a CRAWL_FILE_NOT_INCLUDED telemetry event.

                # Check size limit

                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=relpath, size=f"{size_kb:.0f}")

                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                emit("CRAWL_FILE_PROCESSED", num=entry_num, path=relpath)
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_NOT_TEXT", num=entry_num, path=relpath)
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_ERROR", num=entry_num, path=relpath, error=e)

    Files that survive the pattern filters undergo a byte-size check if max_file_size is specified; files exceeding the limit are skipped, and their size in kilobytes is reported. Surviving files are opened using utf-8-sig encoding, ensuring UTF-8 compatibility while transparently stripping leading Byte Order Marks. If the read operation triggers a UnicodeDecodeError or ValueError (indicating a binary file), or any other filesystem I/O exception, the file is safely caught, categorized as non-text, recorded in skipped_non_text, and omitted from files_dict.

    Phase 5: Telemetry Summary and Payload Return

        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    emit("CRAWL_SUMMARY_HEADER")
    emit("CRAWL_SUMMARY_TOTAL", count=total_fetched)
    emit("CRAWL_SUMMARY_PROCESSED", count=count_processed)

    return {"files": files_dict}

    Once os.walk finishes traversing the filesystem tree, the crawler aggregates metric totals across processed, excluded, oversized, and non-text categories. It transmits structured telemetry events to utils.output.emit, itemizing skipped oversized files and unreadable binaries for pipeline audit logs. Finally, the collected in-memory dictionary containing relative paths mapped to decoded source strings is packaged into {"files": files_dict} and returned to the caller.

    Internal Helpers

    _load_gitignore()

    Visibility: Private

    Signature: def _load_gitignore(gitignore_path):

    Description: Opens a specified .gitignore file using utf-8-sig encoding and compiles its rules into a pathspec.PathSpec instance utilizing the standard gitwildmatch pattern syntax. If the file cannot be opened or parsed due to permission errors or encoding issues, a warning log is transmitted through emit_raw, and the function returns None.

    Parameters:

    • gitignore_path (str): Filesystem path pointing directly to a .gitignore file.

    Returns:

    • pathspec.PathSpec | None: A compiled pattern matcher instance if successfully parsed, or None if an exception occurred.

    Raises:

    • No exceptions are raised directly; all read and parsing errors are caught internally.

    Example:

    root_gi_path = os.path.join(directory, ".gitignore")
if os.path.exists(root_gi_path):
    spec = _load_gitignore(root_gi_path)
    if spec:
        gitignore_specs[os.path.abspath(directory)] = spec
        emit("CRAWL_GITIGNORE_LOADED", path=root_gi_path)

    def _load_gitignore(gitignore_path):
    """Load a .gitignore file and return a PathSpec, or None on failure."""
    try:
        with open(gitignore_path, encoding="utf-8-sig") as f:
            return pathspec.PathSpec.from_lines("gitwildmatch", f.readlines())
    except Exception as e:
        emit_raw("WARNING", f"Failed to load .gitignore at {gitignore_path}: {e}", dest="LOG")
        return None

    The helper encapsulates file ingestion and pattern compilation for Git ignore rules. By parsing lines using pathspec.PathSpec.from_lines("gitwildmatch", ...), it faithfully reproduces standard Git wildcard behavior (such as handling glob stars, leading slashes, and negation rules). Wrapping the entire operation in a defensive try...except block ensures that malformed or inaccessible .gitignore files log a diagnostic warning without aborting the parent crawl operation.

    _matches_any_gitignore()

    Visibility: Private

    Signature: def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False):

    Description: Determines whether an absolute filesystem path matches any active pathspec.PathSpec rule across loaded .gitignore instances. The evaluation calculates the candidate path relative to each .gitignore's containing directory, skipping specs that do not encompass the path's subtree. For directory evaluations, it ensures a trailing slash is appended to conform to Git wildcard directory syntax.

    Parameters:

    • gitignore_specs (dict): Dictionary mapping absolute directory paths to their corresponding compiled pathspec.PathSpec objects.
    • abs_path (str): The absolute path of the file or directory being evaluated.
    • is_dir (bool): Optional boolean indicating whether the target path represents a directory (defaults to False).

    Returns:

    • bool: True if the path matches at least one governing .gitignore rule; otherwise False.

    Raises:

    • No exceptions are raised.

    Example:

    if _matches_any_gitignore(gitignore_specs, abs_d, is_dir=True):
    reason = reason_gitignore

    def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False):
    """Check if a path matches ANY loaded .gitignore spec.

    Each spec is checked with the path relative to its own .gitignore directory.
    For directories, a trailing '/' is appended for proper gitignore matching.

    Args:
        gitignore_specs: dict of {abs_dir_path: pathspec.PathSpec}
        abs_path: absolute path of the file or directory to check
        is_dir: True if checking a directory
    Returns:
        True if the path matches any gitignore rule
    """
    for gi_dir, spec in gitignore_specs.items():
        rel = os.path.relpath(abs_path, gi_dir)
        # Skip if the path is not under this gitignore's scope
        if rel.startswith(".."):
            continue
        match_path = rel.replace("\\", "/")
        if is_dir:
            match_path = match_path.rstrip("/") + "/"
        if spec.match_file(match_path):
            return True
    return False

    This function performs multi-level Gitignore resolution across hierarchical scopes. When checking a path, it calculates the relative path from each cached .gitignore directory using os.path.relpath. Any relative path prefixed with .. indicates that the target path lies outside that specific ignore file's subtree and is skipped immediately. Windows backslashes are normalized to forward slashes to guarantee cross-platform consistency with POSIX gitwildmatch rules, and directories have trailing slashes appended so that rules targeting directories specifically (e.g., build/) match correctly.

    Data Structures

    Local crawler file results

    Field Type Description
    files dict[str, str] Key-value store where each key is a file path (relative to the crawled root directory when use_relative_paths=True) and each value is the raw decoded file content as a string.

}

    Gitignore specification mapping

    An internal mapping constructed dynamically during filesystem traversal to track active scoping rules across directory subtrees.

    Key Type Description
    abs_dir_path str Absolute filesystem path of the directory containing the .gitignore file.
    spec pathspec.PathSpec Compiled pattern matcher configured with the gitwildmatch syntax for that specific directory subtree.

    Error Handling

    • Root Directory Validation (ValueError): At invocation, crawl_local_files() checks os.path.isdir(directory). If the target does not exist or points to a non-directory file, a ValueError is raised immediately with the message f"Directory does not exist: {directory}".
    • Gitignore Parsing Tolerances (Exception): Inside _load_gitignore(), all filesystem I/O and syntax parsing failures are trapped by an untyped except Exception as e: block. The error is routed to logging via emit_raw("WARNING", ..., dest="LOG"), returning None so that invalid or locked ignore files do not interrupt the broader crawl.
    • Non-Text and Encoding Errors (UnicodeDecodeError, ValueError): When reading file payloads, the crawler attempts decoding using utf-8-sig. If decoding fails due to binary content, invalid UTF-8 sequences, or embedded null characters, the exception is caught, the counter count_non_text is incremented, the path is appended to skipped_non_text, and a CRAWL_FILE_NOT_TEXT event is emitted.
    • Filesystem Read Faults (Exception): Any unexpected OS-level I/O faults during file reads (such as read permission denials or broken symlinks) are caught by an untyped except Exception as e: block. The crawler increments count_non_text, records the path, and logs the diagnostic event CRAWL_FILE_ERROR with the exception object.
