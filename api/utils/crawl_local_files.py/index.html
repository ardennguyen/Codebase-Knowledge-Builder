    crawl_local_files.py

    Source: utils/crawl_local_files.py

    Technical Overview

    Following the remote repository extraction capabilities established in crawl_github_files.py, the utils/crawl_local_files.py module serves as the primary ingestion gateway for local directory trees within the documentation pipeline. It implements an in-place filesystem crawler that traverses directories, evaluates hierarchical ignore patterns, enforces safety limits on file sizes and encoding formats, and delivers a normalized dictionary of file paths mapped to their string contents. This output provides the raw text corpus consumed by downstream tokenization, chunking, and LLM processing stages.

    The module solves several operational challenges inherent to processing arbitrary local codebases: handling deeply nested .gitignore files relative to their declaring directories, preventing unbounded memory consumption when encountering binary or oversized build artifacts, and pruning directory branches early during traversal to avoid unnecessary filesystem overhead. To achieve parity with the GitHub crawler, crawl_local_files.py supports standard fnmatch inclusion and exclusion globs alongside formal Git wildcard path specifications powered by the pathspec library.

    The architectural flow is structured as an integrated single-pass traversal over the filesystem using os.walk. As the crawler descends into the tree, it dynamically registers nested .gitignore specifications, prunes subdirectories in-place before they can be traversed, filters candidate files against pattern cascades, validates byte size thresholds, and decodes content with UTF-8 byte order mark (utf-8-sig) handling. Telemetry events and real-time operational metrics are emitted throughout execution using utils/output.py.

    crawl_local_files()

    Visibility: Public
    Signature: def crawl_local_files(directory: str, include_patterns: set | None = None, exclude_patterns: set | None = None, max_file_size: int | None = None, use_relative_paths: bool = True) -> dict[str, dict[str, str]]:

    Description: Crawls a local directory tree in a single pass using os.walk, dynamically compiling nested .gitignore configurations, applying directory and file pattern matching, rejecting binary or oversized assets, and aggregating file contents into a unified dictionary structure.

    Parameters: * directory (str): System path pointing to the root directory to crawl. * include_patterns (set | None): Optional set of glob patterns (e.g., {"*.py", "*.ts"}) defining files that must be included. If provided, files not matching at least one pattern are omitted. * exclude_patterns (set | None): Optional set of glob patterns (e.g., {"tests/*", "*.lock"}) matching files or directories that must be skipped. * max_file_size (int | None): Maximum allowable file size in bytes. Files exceeding this threshold are bypassed. * use_relative_paths (bool): When True, returns dictionary keys formatted relative to directory. When False, returns absolute filesystem paths. Defaults to True.

    Returns: * dict: A dictionary containing a single key "files", mapping string file paths to their decoded text contents: {"files": {filepath: content}}.

    Raises: * ValueError: If directory does not exist or is not a valid filesystem directory.

    Phase 1: Validation and State Initialization

        if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Gitignore specs: {abs_dir_path: pathspec} ---
    gitignore_specs = {}
    root_gi_path = os.path.join(directory, ".gitignore")
    if os.path.exists(root_gi_path):
        spec = _load_gitignore(root_gi_path)
        if spec:
            gitignore_specs[os.path.abspath(directory)] = spec
            emit("CRAWL_GITIGNORE_LOADED", path=root_gi_path)

    # Translated reason strings (looked up once)
    reason_excluded = get("CRAWL_REASON_EXCLUDED")
    reason_gitignore = get("CRAWL_REASON_GITIGNORE")

    The function initiates by verifying that the supplied path exists and represents a valid directory via os.path.isdir, raising an immediate ValueError if the assertion fails. It establishes the central extraction dictionary files_dict alongside metrics counters tracking candidate entry indices, successfully ingested files, pattern exclusions, size violations, and non-text decodings.

    Before starting the directory walk, it detects whether a .gitignore exists at the root of the specified directory. If present, it compiles the rules into a pathspec.PathSpec object using _load_gitignore() and maps it to the absolute path of the target directory. Localized reason strings (reason_excluded and reason_gitignore) are retrieved once from utils.output.get to avoid redundant dictionary lookups throughout the traversal loop.

    Phase 2: Directory Walk and Nested Ignore Discovery

        # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        abs_root = os.path.abspath(root)

        # Check for nested .gitignore in current directory (skip root, already loaded)
        if abs_root != os.path.abspath(directory):
            nested_gi = os.path.join(root, ".gitignore")
            if os.path.exists(nested_gi):
                spec = _load_gitignore(nested_gi)
                if spec:
                    gitignore_specs[abs_root] = spec

    The traversal operates via Python's standard os.walk, inspecting the directory hierarchy top-down. For every directory entered, the crawler resolves the absolute root path abs_root to eliminate symlink and relative reference ambiguity.

    If the current directory is not the crawl root, the routine checks for a nested .gitignore file. If located, _load_gitignore() parses its patterns and records the resulting PathSpec into the gitignore_specs registry under abs_root. This scoping design ensures that ignore rules declared in subpackages or nested modules are discovered dynamically before processing the subdirectories or files enclosed beneath them.

    Phase 3: Directory Filtering and In-Place Branch Pruning

            # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            abs_d = os.path.join(abs_root, d)
            dirpath_rel = os.path.relpath(abs_d, directory)

            reason = None
            if _matches_any_gitignore(gitignore_specs, abs_d, is_dir=True):
                reason = reason_gitignore
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = reason_excluded
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                emit("CRAWL_DIR_EXCLUDED", num=entry_num, path=dirpath_rel, reason=reason)

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()

    Directory filtering enforces branch pruning directly within os.walk by mutating the dirs list in place. Subdirectories are sorted deterministically before evaluation. For each subdirectory d, the crawler checks if its absolute path matches any active rule in gitignore_specs via _matches_any_gitignore(..., is_dir=True).

    If not ignored by Git rules, the directory is checked against exclude_patterns. To account for user patterns containing trailing wildcard syntax like tests/* or node_modules/*, the loop strips the trailing /* suffix and evaluates both the relative path (dirpath_rel) and directory name (d) using fnmatch.fnmatch. Matching directories are registered in excluded_dirs, incrementing exclusion metrics and broadcasting a CRAWL_DIR_EXCLUDED event. Modifying dirs with dirs.remove(d) prevents os.walk from descending into the excluded subtrees entirely, significantly reducing unnecessary filesystem I/O. The surviving directories are re-sorted to preserve consistent cross-platform traversal ordering.

    Phase 4: File Exclusion and Inclusion Matching

            # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            abs_filepath = os.path.abspath(filepath)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore (all levels)
            if _matches_any_gitignore(gitignore_specs, abs_filepath):
                count_excluded += 1
                emit("CRAWL_FILE_GITIGNORE", num=entry_num, path=relpath)
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=relpath)
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    emit("CRAWL_FILE_NOT_INCLUDED", num=entry_num, path=relpath)
                    continue

    For every file in the surviving directory, the filename is sorted and resolved to its relative path or absolute path based on use_relative_paths. The candidate is subjected to a three-tier rejection filter: 1. Gitignore Evaluation: Evaluated against all applicable gitignore_specs using _matches_any_gitignore(). Matches trigger a CRAWL_FILE_GITIGNORE event and skip the file. 2. Exclusion Globs: Evaluated against the caller's exclude_patterns using fnmatch.fnmatch. Matches trigger a CRAWL_FILE_EXCLUDED event and skip the file. 3. Inclusion Globs: If include_patterns is defined, the file path must match at least one glob pattern. Failure to match triggers a CRAWL_FILE_NOT_INCLUDED event and skips the file.

    All skips increment the count_excluded metric and advance the global entry tracking counter entry_num.

    Phase 5: Size Enforcement and Text Ingestion

                # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=relpath, size=f"{size_kb:.0f}")
                continue

            # Try to read as text
            try:
                with open(filepath, encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                emit("CRAWL_FILE_PROCESSED", num=entry_num, path=relpath)
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_NOT_TEXT", num=entry_num, path=relpath)
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_ERROR", num=entry_num, path=relpath, error=e)

    Files passing the pattern filters are verified against max_file_size using os.path.getsize. If the byte size exceeds the configured ceiling, the crawler records the path in skipped_size_limit, increments count_size_limit, emits CRAWL_FILE_SIZE_LIMIT with the calculated size in kilobytes, and bypasses content extraction.

    If the size falls within acceptable limits, the module attempts to open and read the file using utf-8-sig encoding, ensuring automatic stripping of UTF-8 byte order marks. If decoding succeeds, the string content is placed into files_dict keyed by relpath, count_processed is incremented, and CRAWL_FILE_PROCESSED is emitted. If a UnicodeDecodeError or ValueError occurs (typical for binary assets, images, or compiled objects), the exception is trapped, the file is added to skipped_non_text, and CRAWL_FILE_NOT_TEXT is dispatched. Generic I/O or filesystem permission errors are caught by the broader Exception block, emitting CRAWL_FILE_ERROR without terminating the crawl.

    Phase 6: Telemetry Reporting and Result Packaging

        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    emit("CRAWL_SUMMARY_HEADER")
    emit("CRAWL_SUMMARY_TOTAL", count=total_fetched)
    emit("CRAWL_SUMMARY_PROCESSED", count=count_processed)
    if count_excluded > 0:
        emit("CRAWL_SUMMARY_EXCLUDED", count=count_excluded)
    if count_size_limit > 0:
        emit("CRAWL_SUMMARY_SIZE_LIMIT", count=count_size_limit)
        for f in skipped_size_limit:
            emit("CRAWL_SUMMARY_ITEM", name=f)
    if count_non_text > 0:
        emit("CRAWL_SUMMARY_NON_TEXT", count=count_non_text)
        for f in skipped_non_text:
            emit("CRAWL_SUMMARY_ITEM", name=f)

    return {"files": files_dict}

    Following the complete traversal of directory, the crawler calculates total inspected items by summing processed, excluded, size-limited, and non-text counts. It emits a structured sequence of telemetry summary events (CRAWL_SUMMARY_HEADER, CRAWL_SUMMARY_TOTAL, CRAWL_SUMMARY_PROCESSED, and conditional breakdown items for size-limited or non-text files). Finally, it packages and returns files_dict encapsulated under the "files" key, conforming to the unified schema expected across all ingestion handlers in the codebase.

    Internal Helpers

    _load_gitignore()

    Visibility: Internal (Module-private)
    Signature: def _load_gitignore(gitignore_path: str) -> pathspec.PathSpec | None:

    Description: Opens and parses a .gitignore file from the local filesystem, returning a compiled pathspec.PathSpec object configured with the gitwildmatch pattern syntax. If the file cannot be accessed or parsed due to I/O or syntax faults, it intercepts the exception, logs a warning message to the execution log, and returns None to prevent traversal failure.

    Parameters: * gitignore_path (str): Absolute or relative filesystem path to the target .gitignore file.

    Returns: * pathspec.PathSpec | None: A compiled PathSpec matcher representing the gitignore rules, or None if loading failed.

    Raises: * No exceptions are propagated; all file access and parsing errors are intercepted internally.

    Implementation: 

    def _load_gitignore(gitignore_path):
    """Load a .gitignore file and return a PathSpec, or None on failure."""
    try:
        with open(gitignore_path, encoding="utf-8-sig") as f:
            return pathspec.PathSpec.from_lines("gitwildmatch", f.readlines())
    except Exception as e:
        emit_raw("WARNING", f"Failed to load .gitignore at {gitignore_path}: {e}", dest="LOG")
        return None

    The function utilizes open with utf-8-sig encoding to handle ignore files that may contain Unicode characters or byte order markers. The lines read from the file are passed directly to pathspec.PathSpec.from_lines using the standard gitwildmatch pattern parser, which faithfully replicates Git's native wildcard matching rules (including prefix slashes, directory trailing slashes, and negation with !). If any error occurs—such as a FileNotFoundError, PermissionError, or file locking conflict—it catches Exception, logs the error using emit_raw(..., dest="LOG"), and safely yields None.

    Example: 

    root_gi_path = os.path.join(directory, ".gitignore")
if os.path.exists(root_gi_path):
    spec = _load_gitignore(root_gi_path)
    if spec:
        gitignore_specs[os.path.abspath(directory)] = spec
        emit("CRAWL_GITIGNORE_LOADED", path=root_gi_path)

    _matches_any_gitignore()

    Visibility: Internal (Module-private)
    Signature: def _matches_any_gitignore(gitignore_specs: dict[str, pathspec.PathSpec], abs_path: str, is_dir: bool = False) -> bool:

    Description: Evaluates whether an absolute filesystem path matches any loaded .gitignore specification within the active hierarchy. The function calculates the path relative to each ignore specification's parent directory, ensures Windows backslashes are normalized to POSIX forward slashes, appends trailing slashes for directory matching, and checks for rule inclusion.

    Parameters: * gitignore_specs (dict[str, pathspec.PathSpec]): Dictionary mapping absolute directory paths to their corresponding compiled PathSpec objects. * abs_path (str): Absolute filesystem path of the candidate file or directory being evaluated. * is_dir (bool): Boolean flag indicating whether abs_path represents a directory (True) or a file (False). Defaults to False.

    Returns: * bool: True if the path matches at least one applicable .gitignore rule; False otherwise.

    Raises: * No exceptions are raised.

    Implementation: 

    def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False):
    """Check if a path matches ANY loaded .gitignore spec.

    Each spec is checked with the path relative to its own .gitignore directory.
    For directories, a trailing '/' is appended for proper gitignore matching.

    Args:
        gitignore_specs: dict of {abs_dir_path: pathspec.PathSpec}
        abs_path: absolute path of the file or directory to check
        is_dir: True if checking a directory
    Returns:
        True if the path matches any gitignore rule
    """
    for gi_dir, spec in gitignore_specs.items():
        rel = os.path.relpath(abs_path, gi_dir)
        # Skip if the path is not under this gitignore's scope
        if rel.startswith(".."):
            continue
        match_path = rel.replace("\\", "/")
        if is_dir:
            match_path = match_path.rstrip("/") + "/"
        if spec.match_file(match_path):
            return True
    return False

    The function iterates through every registered (gi_dir, spec) pair. It computes the relative path from the .gitignore declaring directory (gi_dir) to the target candidate (abs_path) using os.path.relpath. If the resulting path begins with .., the target lies outside the scope of that specific .gitignore and evaluation for that spec is skipped.

    For targets falling within the scope, platform-specific path separators (\) are normalized to standard Unix slashes (/). If is_dir is True, any trailing slashes are stripped and a single trailing / is appended, which enables pathspec to correctly trigger directory-only ignore patterns (such as build/ or dist/). If spec.match_file(match_path) evaluates to True, the function immediately halts iteration and returns True. If no matching rules are found across all scopes, it returns False.

    Example: 

    # Matching directories during traversal:
if _matches_any_gitignore(gitignore_specs, abs_d, is_dir=True):
    reason = reason_gitignore

# Matching candidate files during processing:
if _matches_any_gitignore(gitignore_specs, abs_filepath):
    count_excluded += 1
    emit("CRAWL_FILE_GITIGNORE", num=entry_num, path=relpath)
    continue

    Crawl State and Telemetry Tracking

    Internal metrics counters and skip tracking collections maintained during the execution of crawl_local_files().

    Identifier Type Description
    entry_num int Sequential counter tracking every directory and file inspected.
    count_processed int Total count of files successfully read and stored in files_dict.
    count_excluded int Total count of directories and files skipped via .gitignore or pattern globs.
    count_size_limit int Count of files skipped due to exceeding max_file_size.
    count_non_text int Count of files skipped due to text decoding failures or I/O exceptions.
    skipped_size_limit list[str] List of relative file paths that exceeded the maximum size limit.
    skipped_non_text list[str] List of relative file paths that could not be decoded as text.

    Error Handling

    The module incorporates multi-layered defensive exception handling to guarantee that non-standard files, encoding anomalies, or permission errors do not terminate execution mid-crawl:

    1. Target Directory Validation:

    2. Prior to entering os.walk, os.path.isdir(directory) checks if the root path is accessible. An invalid or non-existent path immediately raises a descriptive ValueError.

    3. Gitignore Parsing Resilience:

    4. In _load_gitignore(), file opening and parsing operations are enclosed in a generic try...except Exception block. If a .gitignore file is locked, unreadable, or contains invalid syntax, an alert is dispatched via emit_raw("WARNING", ..., dest="LOG") and the function returns None. The crawl continues uninterrupted without the failed specification.

    5. Binary and Non-Text Asset Interception:

    6. When reading file content via open(filepath, encoding="utf-8-sig"), binary files (executables, compiled bytecode, images) or files with incompatible encodings trigger UnicodeDecodeError or ValueError. The crawler traps these exceptions, classifies the file as non-text, updates count_non_text, records the path in skipped_non_text, and emits CRAWL_FILE_NOT_TEXT.

    7. I/O and Permission Fault Containment:

    8. Any unexpected filesystem errors occurring during file access (such as PermissionError on restricted files or transient OS read locks) are intercepted by a catch-all except Exception as e clause. The crawler logs CRAWL_FILE_ERROR with the associated exception object, increments count_non_text, and proceeds to the next candidate file.
