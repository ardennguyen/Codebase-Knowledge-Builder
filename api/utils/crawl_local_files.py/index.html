    crawl_local_files.py

    Source: utils/crawl_local_files.py

    Following the remote repository ingestion mechanism provided by crawl_github_files.py, the crawl_local_files.py module provides the corresponding local filesystem ingestion engine for the Codebase-Knowledge-Builder architecture. While crawl_github_files.py manages remote GitHub REST endpoints and ephemeral SSH clones, crawl_local_files.py performs direct, high-performance, single-pass filesystem traversals of local directories.

    The primary objective of this module is to discover, filter, validate, and extract all relevant source code files from a local target workspace into an in-memory dictionary mapping relative file paths to their decoded UTF-8 text contents. It implements hierarchical .gitignore rule resolution, wildcard include/exclude pattern filtering, binary file detection, file size gating, and comprehensive crawl telemetry reporting.

    Technical Overview

    The crawl_local_files.py module provides a single public interface—crawl_local_files()—supported by internal helper functions that evaluate Git ignore specifications. The module processes local directory hierarchies with zero external network overhead while maintaining complete functional parity with the output format of crawl_github_files.py.

    Core Architectural Responsibilities

    1. Hierarchical .gitignore Resolution: Dynamically loads root-level and nested .gitignore files encountered during traversal. The module evaluates relative path boundaries to ensure nested ignore rules apply strictly within their lexical directory scope.
    2. In-Place Directory Pruning: Evaluates subdirectories against ignore rules and user-defined exclusion patterns prior to descending into them. Modifying the dirs list in-place within os.walk prevents unnecessary I/O operations and traversal of excluded subtrees such as .git, node_modules, or virtual environments.
    3. Multi-Stage File Filtering: Validates file candidates sequentially against .gitignore rules, explicit exclusion patterns (fnmatch), inclusion globs, and maximum byte size thresholds before attempting disk reads.
    4. Encoding and Binary Safety: Reads files using the utf-8-sig encoding format to handle UTF-8 Byte Order Marks transparently. Any decoding exceptions (UnicodeDecodeError, ValueError) or OS-level read faults are caught and logged, preventing binary artifacts from entering downstream LLM prompt contexts.
    5. Standardized Telemetry and Reporting: Emits localized progress events and structured summary metrics through utils.output.emit(), ensuring observable ingestion lifecycles across CLI and UI frontends.

    _load_gitignore()

    Visibility: Private / Internal Helper
    Signature: def _load_gitignore(gitignore_path)

    def _load_gitignore(gitignore_path):
    """Load a .gitignore file and return a PathSpec, or None on failure."""
    try:
        with open(gitignore_path, encoding="utf-8-sig") as f:
            return pathspec.PathSpec.from_lines("gitwildmatch", f.readlines())
    except Exception:
        return None

    Description: Opens and parses a .gitignore file from the specified local filesystem path, converting its line-delimited patterns into a compiled pathspec.PathSpec object using Git's standard gitwildmatch pattern syntax.

    The function enforces the utf-8-sig encoding scheme to safely handle ignore files created on Windows platforms that may contain leading Byte Order Marks. If the target file is missing, unreadable due to filesystem permissions, or structurally corrupted, the function catches all exceptions and returns None to allow crawler execution to continue unimpeded.

    Parameters: * gitignore_path (str): The absolute or relative filesystem path to the target .gitignore file.

    Returns: * pathspec.PathSpec | None: A compiled PathSpec instance capable of evaluating paths against the loaded Git wildcard rules, or None if the file could not be opened or parsed.

    Raises: * No exceptions are propagated. All standard I/O and parsing errors are intercepted internally.

    Example: 

    root_gi_path = os.path.join(directory, ".gitignore")
if os.path.exists(root_gi_path):
    spec = _load_gitignore(root_gi_path)
    if spec:
        gitignore_specs[os.path.abspath(directory)] = spec
        emit("CRAWL_GITIGNORE_LOADED", path=root_gi_path)

    _matches_any_gitignore()

    Visibility: Private / Internal Helper
    Signature: def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False)

    def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False):
    """Check if a path matches ANY loaded .gitignore spec.

    Each spec is checked with the path relative to its own .gitignore directory.
    For directories, a trailing '/' is appended for proper gitignore matching.

    Args:
        gitignore_specs: dict of {abs_dir_path: pathspec.PathSpec}
        abs_path: absolute path of the file or directory to check
        is_dir: True if checking a directory
    Returns:
        True if the path matches any gitignore rule
    """
    for gi_dir, spec in gitignore_specs.items():
        rel = os.path.relpath(abs_path, gi_dir)
        # Skip if the path is not under this gitignore's scope
        if rel.startswith(".."):
            continue
        match_path = rel.replace("\\", "/")
        if is_dir:
            match_path = match_path.rstrip("/") + "/"
        if spec.match_file(match_path):
            return True
    return False

    Description: Evaluates whether a given absolute filesystem path matches any active .gitignore specification within its hierarchical scope. Because a repository can contain nested .gitignore files with rules localized to specific subdirectories, this function ensures each PathSpec is evaluated only against paths that reside within that specification's root directory.

    The function calculates the relative path from the .gitignore directory (gi_dir) to the target (abs_path). If the relative path begins with .., the target is outside the lexical scope of that specific .gitignore file and is skipped.

    For targets located inside the scope: 1. Windows-style backslashes (\) are normalized to standard POSIX forward slashes (/). 2. If is_dir=True, any existing trailing slashes are stripped and a single trailing forward slash (/) is appended. This conforms to Git's wildmatch specification, where rules matching directories (such as build/ or target/) require explicit trailing slashes to trigger positive pattern matches. 3. The normalized path is evaluated against spec.match_file(). If any matching rule resolves to True, the function exits immediately and returns True.

    Parameters: * gitignore_specs (dict[str, pathspec.PathSpec]): A mapping of absolute directory paths to their corresponding compiled pathspec.PathSpec instances. * abs_path (str): The absolute filesystem path of the file or directory being evaluated. * is_dir (bool, optional): Indicates whether abs_path represents a directory (True) or a file (False). Defaults to False.

    Returns: * bool: True if the path matches at least one applicable .gitignore pattern; otherwise, False.

    Raises: * No exceptions are raised directly. Path calculations rely on standard string and os.path operations.

    Example: 

    # Directory-level ignore check during os.walk pruning
if _matches_any_gitignore(gitignore_specs, abs_d, is_dir=True):
    reason = reason_gitignore

# File-level ignore check
if _matches_any_gitignore(gitignore_specs, abs_filepath):
    count_excluded += 1
    emit("CRAWL_FILE_GITIGNORE", num=entry_num, path=relpath)
    continue

    def crawl_local_files(
    directory,
    include_patterns=None,
    exclude_patterns=None,
    max_file_size=None,
    use_relative_paths=True,
):
    """
    Crawl files in a local directory with similar interface as crawl_github_files.
    Args:
        directory (str): Path to local directory
        include_patterns (set): File patterns to include (e.g. {"*.py", "*.js"})
        exclude_patterns (set): File patterns to exclude (e.g. {"tests/*"})
        max_file_size (int): Maximum file size in bytes
        use_relative_paths (bool): Whether to use paths relative to directory

    Returns:
        dict: {"files": {filepath: content}}
    """
    if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    // ... [Counter and telemetry variable initialization] ...

    # --- Gitignore specs: {abs_dir_path: pathspec} ---
    gitignore_specs = {}
    root_gi_path = os.path.join(directory, ".gitignore")
    if os.path.exists(root_gi_path):
        spec = _load_gitignore(root_gi_path)
        if spec:
            gitignore_specs[os.path.abspath(directory)] = spec
            emit("CRAWL_GITIGNORE_LOADED", path=root_gi_path)

    # Translated reason strings (looked up once)
    reason_excluded = get("CRAWL_REASON_EXCLUDED")
    reason_gitignore = get("CRAWL_REASON_GITIGNORE")

    # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        abs_root = os.path.abspath(root)

        # Check for nested .gitignore in current directory (skip root, already loaded)
        if abs_root != os.path.abspath(directory):
            nested_gi = os.path.join(root, ".gitignore")
            if os.path.exists(nested_gi):
                spec = _load_gitignore(nested_gi)
                if spec:
                    gitignore_specs[abs_root] = spec

        // ... [Directory pruning logic] ...

        // ... [File filtering and content extraction loop] ...

    // ... [Summary telemetry emission] ...

    return {"files": files_dict}

    Description: Serves as the primary public entry point for local filesystem crawling. It traverses the specified directory, filters out irrelevant or ignored paths, verifies file sizes, reads text content, and returns a dictionary containing all extracted files.

    The internal workflow executes across four distinct phases:

    1. Validation and Scope Setup

    The function verifies that directory exists and is a valid directory via os.path.isdir(). If invalid, it raises a ValueError. It initializes tracking counters (entry_num, count_processed, count_excluded, count_size_limit, count_non_text) and collections for skipped items. It then checks for a root .gitignore file and compiles it into the gitignore_specs registry.

            # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            abs_d = os.path.join(abs_root, d)
            dirpath_rel = os.path.relpath(abs_d, directory)

            reason = None
            if _matches_any_gitignore(gitignore_specs, abs_d, is_dir=True):
                reason = reason_gitignore
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = reason_excluded
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                emit("CRAWL_DIR_EXCLUDED", num=entry_num, path=dirpath_rel, reason=reason)

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()

    2. Directory Pruning

    During each iteration of os.walk(), the function checks for nested .gitignore files and adds any newly discovered specifications to gitignore_specs.

    It evaluates each subdirectory in dirs against: * All active .gitignore specifications via _matches_any_gitignore(..., is_dir=True). * User-provided exclude_patterns, checking both the relative directory path (dirpath_rel) and the base directory name (d) against pattern.removesuffix("/*").

    Directories matching either condition are appended to excluded_dirs, logged via emit("CRAWL_DIR_EXCLUDED"), and removed in-place from dirs. This pruning step prevents os.walk from descending into those directories.

            # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            abs_filepath = os.path.abspath(filepath)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore (all levels)
            if _matches_any_gitignore(gitignore_specs, abs_filepath):
                count_excluded += 1
                emit("CRAWL_FILE_GITIGNORE", num=entry_num, path=relpath)
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=relpath)
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    emit("CRAWL_FILE_NOT_INCLUDED", num=entry_num, path=relpath)
                    continue

            # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=relpath, size=f"{size_kb:.0f}")
                continue

            # Try to read as text
            try:
                with open(filepath, encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                emit("CRAWL_FILE_PROCESSED", num=entry_num, path=relpath)
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_NOT_TEXT", num=entry_num, path=relpath)
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_ERROR", num=entry_num, path=relpath, error=e)

    3. File Processing Pipeline

    Files within retained directories are processed in sorted alphabetical order through a four-stage filter pipeline: 1. Gitignore Evaluation: Evaluated against all registered .gitignore specs. 2. Exclude Pattern Evaluation: Tested against exclude_patterns using fnmatch.fnmatch(). 3. Include Pattern Evaluation: If include_patterns is provided, the file must match at least one pattern; otherwise, it is skipped. 4. Byte Size Threshold Check: Evaluated against max_file_size via os.path.getsize(). Files exceeding the limit are skipped, and their size in kilobytes is emitted to telemetry. 5. Text Decoding and Ingestion: The file is opened using utf-8-sig. Upon successful read, the contents are stored in files_dict keyed by relpath. If decoding fails with UnicodeDecodeError or ValueError (indicating a binary file), or if an unexpected I/O error occurs, the path is appended to skipped_non_text and recorded in telemetry.

        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    emit("CRAWL_SUMMARY_HEADER")
    emit("CRAWL_SUMMARY_TOTAL", count=total_fetched)
    emit("CRAWL_SUMMARY_PROCESSED", count=count_processed)
    if count_excluded > 0:
        emit("CRAWL_SUMMARY_EXCLUDED", count=count_excluded)
    if count_size_limit > 0:
        emit("CRAWL_SUMMARY_SIZE_LIMIT", count=count_size_limit)
        for f in skipped_size_limit:
            emit("CRAWL_SUMMARY_ITEM", name=f)
    if count_non_text > 0:
        emit("CRAWL_SUMMARY_NON_TEXT", count=count_non_text)
        for f in skipped_non_text:
            emit("CRAWL_SUMMARY_ITEM", name=f)

    return {"files": files_dict}

    4. Summary Telemetry and Return

    After traversing the entire directory tree, total statistics are calculated and emitted via utils.output.emit(). The function returns a single dictionary wrapping files_dict under the "files" key, matching the schema expected by downstream pipeline nodes.

    Parameters: * directory (str): The local directory path to crawl. * include_patterns (set[str] | None, optional): A collection of glob patterns specifying which files to include (e.g., {"*.py", "*.ts"}). Defaults to None. * exclude_patterns (set[str] | None, optional): A collection of glob patterns specifying which files or directories to exclude (e.g., {"tests/*", "build/*"}). Defaults to None. * max_file_size (int | None, optional): The maximum allowed file size in bytes. Files exceeding this threshold are skipped. Defaults to None. * use_relative_paths (bool, optional): If True, keys in the returned dictionary are relative to directory. If False, absolute paths are used. Defaults to True.

    Returns: * dict[str, dict[str, str]]: A dictionary containing the "files" key mapping relative file paths to their decoded string contents: 

    {
    "files": {
        "src/index.js": "console.log('hello');",
        "utils/math.py": "def add(a, b): return a + b"
    }
}

    Raises: * ValueError: If directory does not exist or is not a valid directory.

    Internal Filter Mechanics and Edge Cases

    In-Place Directory Mutation During os.walk

    os.walk() generates directory tree entries by yielding a 3-tuple (root, dirs, files). To optimize filesystem traversal and avoid descending into large directory trees (such as node_modules, .git, or .venv), crawl_local_files() modifies the dirs list in-place:

    for d in dirs.copy():
    if d in excluded_dirs:
        dirs.remove(d)

    Iterating over dirs.copy() allows the code to safely call dirs.remove(d) without mutating the list during iteration. Because os.walk reads the remaining items in dirs to schedule future directory descents, removing an excluded folder prevents all underlying subdirectories and files from being read or traversed.

    Scoped .gitignore Resolution

    A single Git repository may contain multiple .gitignore files placed across different subdirectories:

    project_root/
├── .gitignore          (Spec A: ignores *.log)
└── packages/
    └── frontend/
        └── .gitignore  (Spec B: ignores dist/)

    crawl_local_files.py handles this hierarchy dynamically: 1. Root-level .gitignore rules are loaded into gitignore_specs prior to directory walking. 2. When os.walk() visits packages/frontend/, it detects the local .gitignore, compiles it via _load_gitignore(), and registers it under the absolute path key /path/to/packages/frontend. 3. When evaluating a file such as packages/backend/dist/bundle.js, _matches_any_gitignore() computes os.path.relpath("/path/to/packages/backend/dist/bundle.js", "/path/to/packages/frontend"), which yields ../../backend/dist/bundle.js. 4. Because the relative path starts with .., the function identifies that the file is outside Spec B's lexical directory scope and ignores Spec B, preventing nested .gitignore rules from unintentionally affecting sibling or parent directories.

    Path Normalization Across Platforms

    Windows uses backslashes (\) as filesystem separators, whereas Git wildcard rules and pathspec matchers expect POSIX forward slashes (/). In _matches_any_gitignore, every relative path undergoes slash normalization:

    match_path = rel.replace("\\", "/")
if is_dir:
    match_path = match_path.rstrip("/") + "/"

    This normalization ensures pattern matching remains consistent across Windows, macOS, and Linux environments.
