    crawl_local_files.py

    Source: utils/crawl_local_files.py

    Technical Overview

    The crawl_local_files.py module serves as the primary filesystem ingestion engine within the knowledge extraction pipeline. While its sibling component, crawl_github_files.py, provides ingestion over remote GitHub repositories via API queries or ephemeral Git clones, crawl_local_files.py executes synchronous, local directory traversals. It presents a structurally symmetric interface to downstream pipeline consumers, accepting path inclusion and exclusion rules and returning an in-memory dictionary mapping discovered file paths directly to their decoded text content.

    Operating directly on the host filesystem via Python's standard os.walk iterator, the module enforces a multi-phase pruning and filtering workflow. As it encounters directories, it dynamically locates, parses, and stacks local .gitignore files using pathspec, ensuring that scoped exclusion rules defined at any directory tier take immediate effect. Directories matching exclusion patterns or .gitignore specifications are pruned in-place from the traversal stack, avoiding costly filesystem traversal into large trees like node_modules, .git, or build outputs. Files that pass structural checks are evaluated for size thresholds, opened using utf-8-sig encoding to handle optional Byte Order Marks, and gracefully skipped if binary or corrupt.

    Throughout execution, the module integrates tightly with the runtime output bus via utils/output.py. Instead of writing directly to standard streams or raising non-critical filesystem exceptions, the crawler emits fine-grained lifecycle and diagnostic events (CRAWL_DIR_EXCLUDED, CRAWL_FILE_GITIGNORE, CRAWL_FILE_SIZE_LIMIT, CRAWL_FILE_PROCESSED). This ensures high-visibility operational metrics and seamless localization support across the document synthesis lifecycle.

    Public API

    crawl_local_files()

    Visibility: Public Signature: def crawl_local_files(directory, include_patterns=None, exclude_patterns=None, max_file_size=None, use_relative_paths=True)

    Description: Crawls a target local directory tree, applying hierarchical .gitignore rules, inclusion globs, exclusion globs, and maximum file size boundaries. Discovered readable text files are decoded and assembled into a path-to-content map. Operational metrics and skipping events are emitted directly to the logging system.

    Parameters: * directory (str): Target filesystem directory path to crawl. * include_patterns (set[str], optional): Set of Unix glob patterns that files must match to be included (e.g., {"*.py", "*.js"}). Defaults to None. * exclude_patterns (set[str], optional): Set of Unix glob patterns specifying files or directories to exclude (e.g., {"tests/*", "*.pyc"}). Defaults to None. * max_file_size (int, optional): Maximum permissible file size in bytes. Files exceeding this threshold are bypassed. Defaults to None. * use_relative_paths (bool): If True, keys in the returned dictionary are paths relative to directory; if False, keys are absolute or raw joined filesystem paths. Defaults to True.

    Returns: * dict: A dictionary containing a single key "files", mapped to a sub-dictionary of {filepath: content}.

    Raises: * ValueError: If directory does not exist or does not point to a valid directory on the host filesystem.

    The function executes across six discrete operational phases detailed below.

    Phase 1: Directory Validation and Baseline Setup

        if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Gitignore specs: {abs_dir_path: pathspec} ---
    gitignore_specs = {}
    root_gi_path = os.path.join(directory, ".gitignore")
    if os.path.exists(root_gi_path):
        spec = _load_gitignore(root_gi_path)
        if spec:
            gitignore_specs[os.path.abspath(directory)] = spec
            emit("CRAWL_GITIGNORE_LOADED", path=root_gi_path)

    # Translated reason strings (looked up once)
    reason_excluded = get("CRAWL_REASON_EXCLUDED")
    reason_gitignore = get("CRAWL_REASON_GITIGNORE")
    This phase enforces initial precondition checks by asserting that the target path resolves to an active directory via os.path.isdir. It instantiates the result payload map files_dict alongside metric counters for entries processed, excluded, bounded by file size, or flagged as non-text. The crawler initializes gitignore_specs as an empty dictionary and attempts to load an initial .gitignore at the root directory level via _load_gitignore(). If a valid root .gitignore is found, its compiled pathspec.PathSpec is bound to the directory's absolute path, and an informational event (CRAWL_GITIGNORE_LOADED) is broadcast. Localized exclusion reason tokens are queried from the output catalog once to optimize loop performance.

    Phase 2: Dynamic GitIgnore Specification Registry

        # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        abs_root = os.path.abspath(root)

        # Check for nested .gitignore in current directory (skip root, already loaded)
        if abs_root != os.path.abspath(directory):
            nested_gi = os.path.join(root, ".gitignore")
            if os.path.exists(nested_gi):
                spec = _load_gitignore(nested_gi)
                if spec:
                    gitignore_specs[abs_root] = spec
    The traversal initiates a single-pass iteration using os.walk(directory). At each directory tier, the crawler converts root to an absolute path (abs_root) and inspects whether a nested .gitignore file exists within that subdirectory. To prevent redundant I/O, the root directory is bypassed since it was parsed in Phase 1. When a nested .gitignore is found, _load_gitignore() compiles its rules into a new PathSpec and registers it in gitignore_specs keyed by abs_root. This enables downward-cascading rule scoping that mirrors standard Git behavior.

    Phase 3: Directory Traversal and In-Place Pruning

            # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            abs_d = os.path.join(abs_root, d)
            dirpath_rel = os.path.relpath(abs_d, directory)

            reason = None
            if _matches_any_gitignore(gitignore_specs, abs_d, is_dir=True):
                reason = reason_gitignore
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = reason_excluded
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                emit("CRAWL_DIR_EXCLUDED", num=entry_num, path=dirpath_rel, reason=reason)

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()
    Directory pruning prevents unnecessary filesystem I/O into unneeded directory subtrees. Each subdirectory in dirs is sorted and checked against active gitignore_specs with is_dir=True and tested against caller-specified exclude_patterns. The crawler cleans wildcards using removesuffix("/*") to test against both relative directory paths and individual segment names using fnmatch.fnmatch. If excluded, an exclusion event is emitted, and the directory name is staged in excluded_dirs. Crucially, matching directories are removed directly from dirs in-place using dirs.remove(d). This mutates the iterator list utilized by os.walk, preventing it from descending into excluded branches entirely. The remaining entries in dirs are sorted to guarantee deterministic alphabetical traversal order.

    Phase 4: Per-File Pattern Filtering

            # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            abs_filepath = os.path.abspath(filepath)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore (all levels)
            if _matches_any_gitignore(gitignore_specs, abs_filepath):
                count_excluded += 1
                emit("CRAWL_FILE_GITIGNORE", num=entry_num, path=relpath)
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=relpath)
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    emit("CRAWL_FILE_NOT_INCLUDED", num=entry_num, path=relpath)
                    continue
    In this phase, individual files within the current directory are sorted and evaluated sequentially against exclusion boundaries. A candidate file's absolute path is checked against all active gitignore_specs via _matches_any_gitignore(); if matched, count_excluded increments, a CRAWL_FILE_GITIGNORE event is emitted, and execution continues to the next candidate. Next, if exclude_patterns are provided, the file's normalized relative path is evaluated via fnmatch. Finally, if explicit include_patterns are provided, the path must match at least one inclusion rule; failure to match triggers a CRAWL_FILE_NOT_INCLUDED event and bypasses further reading.

    Phase 5: File Ingestion and Unicode Decoding

                # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=relpath, size=f"{size_kb:.0f}")
                continue

            # Try to read as text
            try:
                with open(filepath, encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                emit("CRAWL_FILE_PROCESSED", num=entry_num, path=relpath)
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_NOT_TEXT", num=entry_num, path=relpath)
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_ERROR", num=entry_num, path=relpath, error=e)
    Files passing pattern filtering are evaluated against max_file_size. If the byte size returned by os.path.getsize exceeds the threshold, the relative path is added to skipped_size_limit and skipped. For permitted files, the crawler reads the content using the utf-8-sig codec, which decodes UTF-8 while stripping BOM headers. If decoding raises UnicodeDecodeError or ValueError, the file is marked as non-text, added to skipped_non_text, and skipped. Any unexpected I/O or permission errors are trapped by the general Exception clause, which logs CRAWL_FILE_ERROR without terminating the crawl. Successfully ingested text files are stored in files_dict under relpath.

    Phase 6: Telemetry Reporting and Payload Assembly

        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    emit("CRAWL_SUMMARY_HEADER")
    emit("CRAWL_SUMMARY_TOTAL", count=total_fetched)
    emit("CRAWL_SUMMARY_PROCESSED", count=count_processed)
    if count_excluded > 0:
        emit("CRAWL_SUMMARY_EXCLUDED", count=count_excluded)
    if count_size_limit > 0:
        emit("CRAWL_SUMMARY_SIZE_LIMIT", count=count_size_limit)
        for f in skipped_size_limit:
            emit("CRAWL_SUMMARY_ITEM", name=f)
    if count_non_text > 0:
        emit("CRAWL_SUMMARY_NON_TEXT", count=count_non_text)
        for f in skipped_non_text:
            emit("CRAWL_SUMMARY_ITEM", name=f)

    return {"files": files_dict}
    Following directory traversal completion, the module compiles summary metrics over all visited entries (total_fetched = count_processed + count_excluded + count_size_limit + count_non_text). It emits structured summary headers and totals, followed by itemized listings of files skipped due to size restrictions or non-text formatting. Finally, it packages the ingested file paths and their contents into the standard dictionary schema {"files": files_dict} and returns it to the caller.

    Internal Helpers

    _load_gitignore()

    Visibility: Private Signature: def _load_gitignore(gitignore_path: str) -> Optional[pathspec.PathSpec]:

    Description: Opens a specified .gitignore file from the host filesystem, reads its pattern lines, and compiles them into a pathspec.PathSpec object using the standard Git "gitwildmatch" syntax rules. If the file cannot be opened, read, or parsed, the exception is caught and None is returned.

    Parameters: * gitignore_path (str): The filesystem path pointing to the .gitignore file.

    Returns: * Optional[pathspec.PathSpec]: A compiled path matching specification object if parsed successfully, or None on any I/O or syntax failure.

    Raises: * None. All exceptions raised during file reading or parsing are caught internally.

    Core Implementation: 

    def _load_gitignore(gitignore_path):
    """Load a .gitignore file and return a PathSpec, or None on failure."""
    try:
        with open(gitignore_path, encoding="utf-8-sig") as f:
            return pathspec.PathSpec.from_lines("gitwildmatch", f.readlines())
    except Exception:
        return None
    The helper wraps file operations in a defensive try...except block to prevent unreadable, locked, or corrupt .gitignore files from aborting the crawl. It opens the target path with utf-8-sig to strip any Byte Order Marks that may precede pattern definitions on Windows platforms. The collected lines are parsed by pathspec.PathSpec.from_lines using Git's wildmatch syntax. Any unexpected errors cause the function to return None, signaling to the caller that no rules could be loaded.

    Example:

if os.path.exists(root_gi_path):

        emit("CRAWL_GITIGNORE_LOADED", path=root_gi_path)

    _matches_any_gitignore()

    Visibility: Private Signature: def _matches_any_gitignore(gitignore_specs: dict[str, pathspec.PathSpec], abs_path: str, is_dir: bool = False) -> bool:

    Description: Determines if an absolute target path matches any compiled .gitignore specification in gitignore_specs. Because .gitignore rules apply only to files within their own directory subtree, this function calculates the relative path from each .gitignore root to the target path. It normalizes path separators to POSIX slashes and appends a trailing slash for directory checks.

    Parameters: * gitignore_specs (dict[str, pathspec.PathSpec]): Mapping of absolute directory paths to their compiled pathspec.PathSpec instances. * abs_path (str): Absolute filesystem path of the candidate file or directory to check. * is_dir (bool): Flag indicating whether abs_path represents a directory. Defaults to False.

    Returns: * bool: True if abs_path matches any active .gitignore specification within its scope; otherwise False.

    Raises: * None.

    Core Implementation: 

    def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False):
    for gi_dir, spec in gitignore_specs.items():
        rel = os.path.relpath(abs_path, gi_dir)
        # Skip if the path is not under this gitignore's scope
        if rel.startswith(".."):
            continue
        match_path = rel.replace("\\", "/")
        if is_dir:
            match_path = match_path.rstrip("/") + "/"
        if spec.match_file(match_path):
            return True
    return False
    This helper enforces directory-scoped .gitignore semantics. For every registered spec, it computes the relative path rel = os.path.relpath(abs_path, gi_dir). If rel starts with ".." (or Windows "..\\"), the candidate path resides outside that .gitignore file's subtree, and that spec is skipped. For paths within scope, Windows backslashes are replaced with POSIX forward slashes (/) to ensure cross-platform compatibility with pathspec. If is_dir is True, any trailing slash is stripped and re-appended (match_path.rstrip("/") + "/") so directory-only rules (e.g., build/) match correctly. If any specification matches, True is returned immediately.

    Error Handling

    The module employs defensive error-handling patterns to ensure that filesystem anomalies, binary payloads, and pattern syntax issues do not terminate ingestion prematurely:

    1. Precondition Directory Validation: crawl_local_files() tests the input path via os.path.isdir(directory) before beginning traversal. If the path does not exist or points to a non-directory file, it raises a ValueError: 

      if not os.path.isdir(directory):
    raise ValueError(f"Directory does not exist: {directory}")

    2. Fault-Tolerant .gitignore Loading: Inside _load_gitignore(), all filesystem access and parsing errors are intercepted via except Exception: return None. If a .gitignore cannot be read due to file permissions or invalid syntax, the crawler ignores that specific file and proceeds without aborting.

    3. Binary and Non-Text Ingestion Handling: Text decoding errors are caught explicitly when reading candidate files: 

      try:
    with open(filepath, encoding="utf-8-sig") as f:
        content = f.read()
    files_dict[relpath] = content
    count_processed += 1
    emit("CRAWL_FILE_PROCESSED", num=entry_num, path=relpath)
except (UnicodeDecodeError, ValueError):
    count_non_text += 1
    skipped_non_text.append(relpath)
    emit("CRAWL_FILE_NOT_TEXT", num=entry_num, path=relpath)
except Exception as e:
    count_non_text += 1
    skipped_non_text.append(relpath)
    emit("CRAWL_FILE_ERROR", num=entry_num, path=relpath, error=e)

    4. UnicodeDecodeError and ValueError: These indicate non-text or binary files (e.g., compiled .pyc, images, zip archives). The crawler records the path in skipped_non_text, increments count_non_text, and emits CRAWL_FILE_NOT_TEXT.
    5. Generic Exception: Catches unexpected OS-level I/O issues (e.g., filesystem locks, permission denials, broken symlinks). It logs CRAWL_FILE_ERROR with the exception object and allows the traversal to continue.
