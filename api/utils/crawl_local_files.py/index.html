    crawl_local_files.py

    Source: utils/crawl_local_files.py

    Technical Overview

    The utils/crawl_local_files.py module is the local filesystem ingestion engine for the documentation pipeline. Operating as the offline counterpart to utils/crawl_github_files.py, it traverses a specified root directory on the local filesystem, identifies and filters source code artifacts, and decodes textual file contents into an in-memory dictionary. The component is designed to handle messy real-world repositories by filtering out binary artifacts, honoring multi-level Git ignore files, enforcing strict byte-size ceilings, and matching user-supplied glob inclusions and exclusions.

    Architecturally, the module employs an inline, single-pass traversal pattern built around Python's os.walk. To avoid descending into large or ignored directory trees (such as virtual environments, cache folders, or .git internals), the module evaluates and prunes the sub-directory collection in-place during the descent. It dynamically discovers and compiles nested .gitignore files into scoping rules via the third-party pathspec library. At the file level, it applies a sequential pipeline of filter checks—Git ignore rules, glob-based exclusions, glob-based inclusions, and size boundaries—before reading file buffers using UTF-8 encoding with byte order mark handling (utf-8-sig).

    The module integrates tightly with the telemetry and localization system in utils/output.py. Every filtering decision, encoding failure, and processing milestone emits structured localization keys. This design ensures that long-running directory scans provide granular terminal and log feedback while producing a clean, normalized mapping of relative POSIX-style paths to string contents ready for downstream AST analysis and chapter generation.

    crawl_local_files()

    Visibility: Public

    Signature: 

    def crawl_local_files(
    directory,
    include_patterns=None,
    exclude_patterns=None,
    max_file_size=None,
    use_relative_paths=True,
):

    Description: Orchestrates recursive filesystem discovery, filtering, and text content loading starting from a local root directory. It mimics the output shape of crawl_github_files(), providing a uniform dictionary interface mapping file paths to their textual file contents.

    The function operates across six internal execution phases: input verification and metric initialization, root and nested .gitignore parsing, directory tree pruning, sequential file filter evaluation, file content decoding with binary fallback, and aggregated telemetry reporting.

    Phase 1: Directory Validation and Metric Initialization

        if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Gitignore specs: {abs_dir_path: pathspec} ---
    gitignore_specs = {}
    root_gi_path = os.path.join(directory, ".gitignore")
    if os.path.exists(root_gi_path):
        spec = _load_gitignore(root_gi_path)
        if spec:
            gitignore_specs[os.path.abspath(directory)] = spec
            emit("CRAWL_GITIGNORE_LOADED", path=root_gi_path)

    # Translated reason strings (looked up once)
    reason_excluded = get("CRAWL_REASON_EXCLUDED")
    reason_gitignore = get("CRAWL_REASON_GITIGNORE")
    The initial phase validates that the target path points to an accessible local directory, raising a ValueError if the path does not exist or is a plain file. It initializes counters tracking processed files, excluded patterns, size violations, and non-text binaries. It also establishes the gitignore_specs dictionary, immediately looking for and parsing a .gitignore file located at the target directory root. Localized reason strings are resolved upfront using utils.output.get() to prevent redundant dictionary lookups throughout the traversal.

    Phase 2: Dynamic Gitignore Discovery and Directory Pruning

        for root, dirs, files in os.walk(directory):
        abs_root = os.path.abspath(root)

        # Check for nested .gitignore in current directory (skip root, already loaded)
        if abs_root != os.path.abspath(directory):
            nested_gi = os.path.join(root, ".gitignore")
            if os.path.exists(nested_gi):
                spec = _load_gitignore(nested_gi)
                if spec:
                    gitignore_specs[abs_root] = spec

        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            abs_d = os.path.join(abs_root, d)
            dirpath_rel = os.path.relpath(abs_d, directory)

            reason = None
            if _matches_any_gitignore(gitignore_specs, abs_d, is_dir=True):
                reason = reason_gitignore
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = reason_excluded
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                emit("CRAWL_DIR_EXCLUDED", num=entry_num, path=dirpath_rel, reason=reason)

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()
    During traversal via os.walk, the function dynamically inspects each visited folder for sub-directory .gitignore files, compiling them and adding them to gitignore_specs keyed by their absolute folder path. It then iterates through all child directory candidates. If a directory matches any loaded Git ignore rule or matches an exclusion wildcard (after stripping /* suffixes via str.removesuffix), it is added to excluded_dirs. By mutating dirs in-place (dirs.remove(d)), os.walk is instructed not to recurse into those subtrees, saving substantial execution time. The remaining valid directories are sorted alphabetically to guarantee deterministic crawl ordering.

    Phase 3: File Exclusion and Inclusion Matching

            for filename in sorted(files):
            filepath = os.path.join(root, filename)
            abs_filepath = os.path.abspath(filepath)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore (all levels)
            if _matches_any_gitignore(gitignore_specs, abs_filepath):
                count_excluded += 1
                emit("CRAWL_FILE_GITIGNORE", num=entry_num, path=relpath)
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=relpath)
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    emit("CRAWL_FILE_NOT_INCLUDED", num=entry_num, path=relpath)
                    continue
    For each file in the current directory, the function evaluates three successive filter gates. First, _matches_any_gitignore tests whether the file is matched by any loaded .gitignore spec governing its path. Second, if exclude_patterns are provided, the relative file path is matched against the glob set using fnmatch.fnmatch. Third, if include_patterns are provided, the file must match at least one pattern; failing this test marks it as excluded. Each negative outcome increments count_excluded, emits a diagnostic event, and short-circuits further processing of that file.

    Phase 4: Size Constraints and Content Reading

                # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=relpath, size=f"{size_kb:.0f}")
                continue

            # Try to read as text
            try:
                with open(filepath, encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                emit("CRAWL_FILE_PROCESSED", num=entry_num, path=relpath)
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_NOT_TEXT", num=entry_num, path=relpath)
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_ERROR", num=entry_num, path=relpath, error=e)
    Surviving files encounter the file-size barrier. When max_file_size is specified and os.path.getsize(filepath) exceeds that limit, the file is bypassed, its path is recorded in skipped_size_limit, and an event is emitted displaying its size in kilobytes. Otherwise, the file is opened using utf-8-sig encoding to consume UTF-8 text and strip optional byte order marks. If decoding fails due to a UnicodeDecodeError or ValueError, the file is marked as a non-text binary and skipped. Any unexpected OS-level I/O failure is similarly caught, preventing a single unreadable file from crashing the entire crawler run.

    Phase 5: Telemetry Summary and Payload Return

        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    emit("CRAWL_SUMMARY_HEADER")
    emit("CRAWL_SUMMARY_TOTAL", count=total_fetched)
    emit("CRAWL_SUMMARY_PROCESSED", count=count_processed)
    if count_excluded > 0:
        emit("CRAWL_SUMMARY_EXCLUDED", count=count_excluded)
    if count_size_limit > 0:
        emit("CRAWL_SUMMARY_SIZE_LIMIT", count=count_size_limit)
        for f in skipped_size_limit:
            emit("CRAWL_SUMMARY_ITEM", name=f)
    if count_non_text > 0:
        emit("CRAWL_SUMMARY_NON_TEXT", count=count_non_text)
        for f in skipped_non_text:
            emit("CRAWL_SUMMARY_ITEM", name=f)

    return {"files": files_dict}
    Following the completion of the directory walk, the crawler tallies all categories into total_fetched and emits summary telemetry blocks through utils.output.emit. These blocks record the total number of files scanned, files successfully processed, files excluded by rules, files discarded for exceeding byte limits, and non-text files skipped. Specific file paths that were skipped for size limits or non-text encodings are itemized in the log. Finally, the ingested text files are returned within a standard dictionary wrapper under the "files" key.

    Parameters: * directory (str): Absolute or relative path to the local root directory to crawl. * include_patterns (set | None): Optional set of glob file patterns to explicitly include (e.g., {"*.py", "*.js"}). Defaults to None. * exclude_patterns (set | None): Optional set of glob file or directory patterns to omit (e.g., {"tests/*", "*.pyc"}). Defaults to None. * max_file_size (int | None): Maximum allowed file size in bytes. Files exceeding this threshold are bypassed. Defaults to None. * use_relative_paths (bool): Determines whether dictionary keys are relative to directory (True) or full filesystem paths (False). Defaults to True.

    Returns: * dict: A dictionary containing a single "files" key, mapping relative (or absolute) file path strings to their decoded UTF-8 string contents.

    Raises: * ValueError: Raised immediately if the provided directory does not exist or fails os.path.isdir().

    _load_gitignore()

    Visibility: Private

    Signature: 

    def _load_gitignore(gitignore_path):

    Description: Reads a .gitignore file from disk and parses its pattern lines into a compiled pathspec.PathSpec matcher utilizing the "gitwildmatch" pattern dialect.

    The helper opens the specified file path with utf-8-sig encoding to handle UTF-8 files with or without byte order marks. If the file cannot be found, read, or parsed, the exception is caught and logged at the WARNING level through utils.output.emit_raw(), and the function returns None. This guarantees that unreadable or corrupt .gitignore files fail gracefully without aborting the crawl process.

    Parameters: * gitignore_path (str): File path to the .gitignore configuration file.

    Returns: * pathspec.PathSpec | None: A compiled pattern specification object capable of evaluating paths against Git ignore syntax rules, or None if loading/parsing fails.

    Raises: * None. All internal exceptions are caught defensively and logged.

    Example: 

    def _load_gitignore(gitignore_path):
    """Load a .gitignore file and return a PathSpec, or None on failure."""
    try:
        with open(gitignore_path, encoding="utf-8-sig") as f:
            return pathspec.PathSpec.from_lines("gitwildmatch", f.readlines())
    except Exception as e:
        emit_raw("WARNING", f"Failed to load .gitignore at {gitignore_path}: {e}", dest="LOG")
        return None

    _matches_any_gitignore()

    Visibility: Private

    Signature: 

    def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False):

    Description: Evaluates whether a target filesystem path matches any loaded .gitignore specification in the repository hierarchy.

    Because Git repositories can place .gitignore files at multiple nested folder depths, each spec must evaluate paths relative to its own containing folder. The helper loops through all registered (gi_dir, spec) pairs. For each pair, it computes the relative path from gi_dir to abs_path. If the resulting relative path begins with ".." (meaning abs_path resides outside that .gitignore's folder scope), the spec is bypassed.

    For paths within scope, Windows backslashes (\) are normalized to POSIX forward slashes (/). If is_dir is True, a trailing slash is appended to the normalized path to ensure directory-specific Git wildcard rules (such as build/) match correctly. The helper delegates matching to spec.match_file(match_path) and returns True immediately upon the first match.

    Parameters: * gitignore_specs (dict): Mapping of {abs_dir_path: pathspec.PathSpec} containing compiled Git ignore rules keyed by directory. * abs_path (str): Absolute filesystem path to the file or directory under inspection. * is_dir (bool): Flag indicating whether abs_path represents a directory (True) or a file (False). Defaults to False.

    Returns: * bool: True if abs_path matches any active .gitignore rule within its scope, otherwise False.

    Raises: * None.

    Example: 

    def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False):
    for gi_dir, spec in gitignore_specs.items():
        rel = os.path.relpath(abs_path, gi_dir)
        # Skip if the path is not under this gitignore's scope
        if rel.startswith(".."):
            continue
        match_path = rel.replace("\\", "/")
        if is_dir:
            match_path = match_path.rstrip("/") + "/"
        if spec.match_file(match_path):
            return True
    return False

    Data Structures

    Local crawl result dictionary

    The primary payload returned by crawl_local_files(). It standardizes the local crawl output to match the dictionary format returned by the GitHub remote crawler.

    Field Type Description
    files dict[str, str] Mapping where keys are relative (or absolute) file paths and values are full textual file contents.

    Example return structure: 

    {
    "files": {
        "utils/crawl_local_files.py": "import fnmatch\nimport os\n...",
        "main.py": "def main():\n    ..."
    }
}

    Gitignore specification mapping

    An internal dictionary constructed and maintained during filesystem traversal to track active .gitignore rules across different directory hierarchy depths.

    Key Value Type Description
    abs_dir_path (str) pathspec.PathSpec The absolute path to the directory hosting the .gitignore file, mapped to its compiled PathSpec matcher instance.

    Internal crawl tracking counters

    Internal execution state maintained in local variables during crawl_local_files() to generate telemetry summaries:

    Metric Variable Type Description
    entry_num int Sequential counter tracking total directory and file candidate evaluations.
    count_processed int Count of files successfully read and added to the output mapping.
    count_excluded int Count of files and directories excluded by .gitignore rules or glob filters.
    count_size_limit int Count of files omitted due to exceeding max_file_size.
    count_non_text int Count of files skipped due to encoding decode errors or I/O failures.
    skipped_size_limit list[str] List of relative file paths that exceeded max_file_size.
    skipped_non_text list[str] List of relative file paths that failed text decoding.

    Error Handling

    The module balances strict entry validation with tolerant, fail-soft ingestion during directory traversal:

    • Entry Validation: crawl_local_files() calls os.path.isdir(directory) before starting the walk. If the path does not exist or points to a non-directory entry, it raises a ValueError(f"Directory does not exist: {directory}").
    • Gitignore Loading Failures: In _load_gitignore(), all exceptions (such as FileNotFoundError, PermissionError, or syntax parsing errors) are caught within a generic except Exception as e: block. The helper logs a warning through emit_raw("WARNING", ... dest="LOG") and returns None, allowing crawling to continue uninhibited.
    • Non-Text / Binary Detection: When opening files, the crawler wraps open(filepath, encoding="utf-8-sig") in a try...except (UnicodeDecodeError, ValueError) block. Binary files (e.g., compiled binaries, images, bytecode) trigger these exceptions and are intercepted cleanly, incrementing count_non_text, recording the path in skipped_non_text, and emitting CRAWL_FILE_NOT_TEXT.
    • I/O and Permission Safeguards: A broad except Exception as e: block wraps the file reading logic to catch OS-level access violations, locked files, or transient filesystem errors. The error is routed to emit("CRAWL_FILE_ERROR", num=entry_num, path=relpath, error=e) without breaking the traversal loop.
