    crawl_local_files.py

    Source: utils/crawl_local_files.py

    Technical Overview

    While crawl_github_files.py manages remote source code extraction via GitHub REST endpoints and shallow Git clones, crawl_local_files.py serves as the primary local ingestion engine within the Codebase-Knowledge-Builder architecture. It abstracts local filesystem discovery by exposing a unified ingestion contract that matches the output schema of the remote crawler. The module traverses physical directory hierarchies, dynamically discovers and enforces nested .gitignore boundaries, applies user-defined glob exclusion and inclusion rules, validates file payload sizes, and defensively reads text content into memory while isolating binary or corrupt artifacts.

    Under the hood, the engine relies on a single-pass traversal orchestrated via Python's os.walk(). Rather than collecting all system paths and filtering post-traversal, crawl_local_files.py intercepts directory entries in-place. By mutating the mutable dirs slice provided by os.walk(), it prunes entire unneeded directory subtrees (such as virtual environments, build targets, and metadata folders) before descending into them. File qualification is governed by an evaluation chain where paths must sequentially clear hierarchical pathspec rules, user-supplied exclude patterns via fnmatch, include filters, and file size limits before being decoded using utf-8-sig.

    All operational telemetry, filtering decisions, and ingestion summaries are dispatched through the centralized messaging system in output.py. The crawler emits structured progress events throughout traversal, tracking excluded paths, skipped binary files, and size-capped assets, culminating in a crawl summary report.

    Public API

    crawl_local_files()

    Visibility: Public
    Signature: def crawl_local_files(directory, include_patterns=None, exclude_patterns=None, max_file_size=None, use_relative_paths=True) -> dict:

    Description: Crawls a specified local directory tree, loads root and nested .gitignore configurations, dynamically prunes directories matching exclusion parameters, filters individual files through glob and size criteria, safely ingests text contents, and dispatches detailed telemetry events to stdout and log channels.

    Parameters: * directory (str): Absolute or relative filesystem path to the target directory. * include_patterns (set | None): Optional set of glob patterns (e.g., {"*.py", "*.ts"}). If supplied, only files matching at least one pattern are ingested. * exclude_patterns (set | None): Optional set of glob patterns (e.g., {"*.pyc", ".git/*"}). Paths matching any pattern are skipped. * max_file_size (int | None): Upper threshold in bytes. Files exceeding this limit are omitted from collection. * use_relative_paths (bool): When True (the default), dictionary keys represent relative paths calculated from directory; when False, full paths are retained.

    Returns: * dict: A dictionary containing an extracted file map under the "files" key: {"files": {filepath: content}}.

    Raises: * ValueError: If the target directory does not exist or fails filesystem directory validation.

    Phase 1: Input Validation and Metric Initialization

        if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []
    The routine verifies that the target path points to an accessible directory on disk. If os.path.isdir returns False, traversal aborts immediately by raising a ValueError. It then prepares the accumulator files_dict to store relative file paths and string contents, and initializes telemetry counters tracking entry sequencing, processed files, excluded paths, size violations, and non-text decode errors along with their respective tracking lists.

    Phase 2: Root Gitignore Resolution

        # --- Gitignore specs: {abs_dir_path: pathspec} ---
    gitignore_specs = {}
    root_gi_path = os.path.join(directory, ".gitignore")
    if os.path.exists(root_gi_path):
        spec = _load_gitignore(root_gi_path)
        if spec:
            gitignore_specs[os.path.abspath(directory)] = spec
            emit("CRAWL_GITIGNORE_LOADED", path=root_gi_path)

    # Translated reason strings (looked up once)
    reason_excluded = get("CRAWL_REASON_EXCLUDED")
    reason_gitignore = get("CRAWL_REASON_GITIGNORE")
    Before walking the directory tree, the crawler checks for a .gitignore file residing at the root level. If found, it delegates parsing to _load_gitignore() and registers the resulting PathSpec object mapped to the absolute root directory path within gitignore_specs. Telemetry confirms the load operation via emit("CRAWL_GITIGNORE_LOADED"), and localized reason strings for exclude and gitignore skips are cached from the translation engine via get() to prevent repeated lookups inside loop iterations.

    Phase 3: Directory Traversal and In-Place Pruning

        for root, dirs, files in os.walk(directory):
        abs_root = os.path.abspath(root)

        # Check for nested .gitignore in current directory (skip root, already loaded)
        if abs_root != os.path.abspath(directory):
            nested_gi = os.path.join(root, ".gitignore")
            if os.path.exists(nested_gi):
                spec = _load_gitignore(nested_gi)
                if spec:
                    gitignore_specs[abs_root] = spec

        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            abs_d = os.path.join(abs_root, d)
            dirpath_rel = os.path.relpath(abs_d, directory)

            reason = None
            if _matches_any_gitignore(gitignore_specs, abs_d, is_dir=True):
                reason = reason_gitignore
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = reason_excluded
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                emit("CRAWL_DIR_EXCLUDED", num=entry_num, path=dirpath_rel, reason=reason)

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()
    The crawler initiates an os.walk() traversal. If the current directory contains a nested .gitignore distinct from the root, its rules are loaded into gitignore_specs mapped to abs_root. Directory candidates in dirs are evaluated against both the aggregated gitignore specifications (flagged with is_dir=True) and glob patterns stripped of trailing /* qualifiers. Excluded directory names are accumulated into excluded_dirs, and dirs is mutated in-place via dirs.remove(d) against a shallow copy, preventing os.walk() from descending into ignored directory trees.

    Phase 4: Candidate File Filtering

            for filename in sorted(files):
            filepath = os.path.join(root, filename)
            abs_filepath = os.path.abspath(filepath)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore (all levels)
            if _matches_any_gitignore(gitignore_specs, abs_filepath):
                count_excluded += 1
                emit("CRAWL_FILE_GITIGNORE", num=entry_num, path=relpath)
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=relpath)
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    emit("CRAWL_FILE_NOT_INCLUDED", num=entry_num, path=relpath)
                    continue
    For each file in the sorted directory list, absolute and relative paths are resolved. The candidate file passes through a three-stage gating mechanism: first against all active .gitignore rules in scope via _matches_any_gitignore(), second against user-specified glob exclusion rules via fnmatch.fnmatch(), and third against glob inclusion rules. Failing any gate increments count_excluded, emits a categorized event (CRAWL_FILE_GITIGNORE, CRAWL_FILE_EXCLUDED, or CRAWL_FILE_NOT_INCLUDED), and skips remaining processing for that entry.

    Phase 5: Size Verification and Content Ingestion

                # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=relpath, size=f"{size_kb:.0f}")
                continue

            # Try to read as text
            try:
                with open(filepath, encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                emit("CRAWL_FILE_PROCESSED", num=entry_num, path=relpath)
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_NOT_TEXT", num=entry_num, path=relpath)
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                emit("CRAWL_FILE_ERROR", num=entry_num, path=relpath, error=e)
    If a file passes filtering, its size is checked using os.path.getsize(). If max_file_size is defined and exceeded, the path is tracked in skipped_size_limit and skipped. Surviving files are opened using the utf-8-sig codec to transparently strip any Byte Order Marks. If decoding fails (UnicodeDecodeError or ValueError) or an OS/file-system error occurs, the file is classified as non-text, added to skipped_non_text, and documented via CRAWL_FILE_NOT_TEXT or CRAWL_FILE_ERROR. Successful reads insert the decoded content string into files_dict under the relative path key.

    Phase 6: Traversal Summary and Telemetry

        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    emit("CRAWL_SUMMARY_HEADER")
    emit("CRAWL_SUMMARY_TOTAL", count=total_fetched)
    emit("CRAWL_SUMMARY_PROCESSED", count=count_processed)
    if count_excluded > 0:
        emit("CRAWL_SUMMARY_EXCLUDED", count=count_excluded)
    if count_size_limit > 0:
        emit("CRAWL_SUMMARY_SIZE_LIMIT", count=count_size_limit)
        for f in skipped_size_limit:
            emit("CRAWL_SUMMARY_ITEM", name=f)
    if count_non_text > 0:
        emit("CRAWL_SUMMARY_NON_TEXT", count=count_non_text)
        for f in skipped_non_text:
            emit("CRAWL_SUMMARY_ITEM", name=f)

    return {"files": files_dict}
    Upon completing traversal, aggregate statistics are calculated by summing processed, excluded, oversized, and non-text file entries. A structured summary report is dispatched through emit() calls, surfacing total entries seen, files accepted, items filtered, and enumerating oversized and non-text files. The assembled files_dict is returned wrapped in a dictionary under the "files" key.

    Internal Helpers

    _load_gitignore()

    Visibility: Private
    Signature: def _load_gitignore(gitignore_path) -> pathspec.PathSpec | None:

    Description: Safely opens and reads a .gitignore file from the local filesystem using UTF-8-SIG encoding. It compiles the lines into a pathspec.PathSpec object configured with the Git-standard "gitwildmatch" pattern syntax. If file opening or syntax parsing fails due to missing permissions, disk corruption, or format anomalies, the function intercepts the exception, logs a warning message to the "LOG" channel via emit_raw(), and returns None to allow directory traversal to continue without crashing.

    Parameters: * gitignore_path (str): Filesystem path to the .gitignore file to be compiled.

    Returns: * pathspec.PathSpec | None: A compiled pattern specification instance if successful; None on any I/O or parsing failure.

    Raises: * No exceptions are propagated. All exceptions are caught internally.

    Example: 

    # Implementation from utils/crawl_local_files.py
def _load_gitignore(gitignore_path):
    """Load a .gitignore file and return a PathSpec, or None on failure."""
    try:
        with open(gitignore_path, encoding="utf-8-sig") as f:
            return pathspec.PathSpec.from_lines("gitwildmatch", f.readlines())
    except Exception as e:
        emit_raw("WARNING", f"Failed to load .gitignore at {gitignore_path}: {e}", dest="LOG")
        return None
    Under the hood, _load_gitignore() guarantees resilient parsing of repository ignore rules. It uses utf-8-sig encoding to handle UTF-8 files with or without byte order marks, and passes the lines directly into pathspec.PathSpec.from_lines("gitwildmatch", ...). If an I/O failure or permission error occurs, the exception is caught, formatted into a warning string, and dispatched to emit_raw targeting the "LOG" stream, returning None to prevent traversal failure.

    _matches_any_gitignore()

    Visibility: Private
    Signature: def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False) -> bool:

    Description: Evaluates whether an absolute filesystem path matches any active .gitignore specification in gitignore_specs. It computes the target's relative path against each specification's parent directory, skips rules where the path lies outside the specification's tree scope (indicated by leading ..), normalizes path separators to POSIX forward slashes, and appends a trailing slash for directory entries to ensure accurate matching against gitwildmatch directory rules.

    Parameters: * gitignore_specs (dict[str, pathspec.PathSpec]): Mapping of absolute directory paths to their respective compiled PathSpec objects. * abs_path (str): Absolute filesystem path of the candidate file or directory. * is_dir (bool): Flag indicating whether abs_path represents a directory. Defaults to False.

    Returns: * bool: True if the path matches at least one governing .gitignore rule; otherwise False.

    Raises: * No exceptions are explicitly raised.

    Example: 

    # Implementation from utils/crawl_local_files.py
def _matches_any_gitignore(gitignore_specs, abs_path, is_dir=False):
    """Check if a path matches ANY loaded .gitignore spec."""
    for gi_dir, spec in gitignore_specs.items():
        rel = os.path.relpath(abs_path, gi_dir)
        # Skip if the path is not under this gitignore's scope
        if rel.startswith(".."):
            continue
        match_path = rel.replace("\\", "/")
        if is_dir:
            match_path = match_path.rstrip("/") + "/"
        if spec.match_file(match_path):
            return True
    return False
    This helper enforces nested gitignore scoping. It iterates over each registered directory gi_dir and computes os.path.relpath(abs_path, gi_dir). If the relative path starts with .., the file or directory exists outside that .gitignore's hierarchy and is skipped. Cross-platform path separators (\) are normalized to forward slashes (/), and directories have a trailing slash appended (match_path.rstrip("/") + "/") to satisfy gitwildmatch directory matching conventions. The helper returns True as soon as spec.match_file(match_path) matches.

    Telemetry Counter Metrics

    Internal state variables tracking traversal throughput and filter attrition.

    Counter Variable Type Description
    entry_num int Monotonically increasing sequence number assigned to every evaluated file and directory.
    count_processed int Total count of files successfully read and stored in files_dict.
    count_excluded int Total count of files and directories excluded via .gitignore, exclude patterns, or include patterns.
    count_size_limit int Total count of files skipped because their size exceeded max_file_size.
    count_non_text int Total count of files skipped due to decode errors (UnicodeDecodeError, ValueError) or OS I/O exceptions.
    skipped_size_limit list[str] List of relative file paths that exceeded max_file_size.
    skipped_non_text list[str] List of relative file paths that failed text decoding or file reading.

    Error Handling

    crawl_local_files.py uses defensive error handling to prevent filesystem anomalies, permission issues, or binary files from aborting traversal runs:

    1. Root Directory Verification: The function validates the input path using os.path.isdir(directory). If the path does not exist or is not a directory, a ValueError is raised immediately, stopping execution before allocating crawler state.

    2. Graceful Gitignore Fallback: In _load_gitignore(), file opening and compilation operations are wrapped in a generic try...except Exception block. If a .gitignore file cannot be read (e.g., due to permission restrictions or encoding issues), the error is intercepted, logged to the persistent log stream via emit_raw("WARNING", ..., dest="LOG"), and None is returned. Traversal continues without the failed rules.

    3. Binary and Non-UTF-8 Artifact Isolation: When reading file content, crawl_local_files uses open(filepath, encoding="utf-8-sig") inside a try...except block:

    4. UnicodeDecodeError and ValueError exceptions indicate binary data (e.g., images, binaries, bytecode) or non-UTF-8 encodings. These are caught, increment count_non_text, append the path to skipped_non_text, and trigger a CRAWL_FILE_NOT_TEXT event.

    5. Other file system errors (PermissionError, OSError, or generic Exception) are caught in a separate branch, increment count_non_text, and trigger a CRAWL_FILE_ERROR event containing the exception details. Traversal then advances to the next file without failing.

    6. Relative Path Boundary Protection: In _matches_any_gitignore(), os.path.relpath(abs_path, gi_dir) computes paths relative to each loaded ignore specification. Paths containing leading .. are skipped via if rel.startswith(".."): continue, preventing rules in subdirectories from leaking into parent or sibling directories.
