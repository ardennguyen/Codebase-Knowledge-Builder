    crawl_github_files.py

    Source: utils/crawl_github_files.py

    Technical Overview

    Following the LLM inference abstraction layer established in call_llm.py, the crawl_github_files.py module functions as the remote repository ingestion engine for the codebase analysis pipeline. It extracts source trees, verifies file properties, and loads source file contents into memory from GitHub repositories before downstream tokenization, abstraction mapping, and documentation generation take place. The module supports two primary ingestion pathways: native Git cloning over SSH for authenticated or firewalled environments, and deep API-driven tree navigation via the GitHub REST API v3 for targeted subpaths and commit-pinned trees.

    The architecture accommodates large remote repositories by implementing size-gated memory loading, rate-limit backoff handling, and filtering mechanisms. Path filtering operates across multiple tiers: standard Git exclude specifications (.gitignore parsed via pathspec), explicit inclusion globs, and targeted exclusion globs evaluated via fnmatch. When targeting subdirectories within monorepos, the crawler supports relative path re-basing so that extracted downstream node artifacts reflect module-relative hierarchies rather than top-level repository nesting.

    The module emits granular telemetry throughout its lifecycle via utils.output functions (emit, emit_raw, get), capturing progress events, directory skips, size ceiling violations, and encoding failures. Traversal results are compiled into a normalized dictionary mapping relative file paths to decoded UTF-8 string buffers, accompanied by operational metadata describing file counts and filtering configurations.

    DEFAULT_MAX_FILE_SIZE = 1_048_576  # 1 MB

    Description: Defines the default upper boundary (1 megabyte in bytes) for file buffers retrieved during crawling operations. Files exceeding this threshold are bypassed to avoid memory exhaustion during large codebase ingestions.

    In the SSH workflow, git.Repo.clone_from performs a full clone of the remote repository into a managed tempfile.TemporaryDirectory. If the cloned root contains a .gitignore file, its lines are parsed into a pathspec.PathSpec object using the gitwildmatch dialect. The code recursively walks the local directory via os.walk, pruning directory trees in-place if they match .gitignore rules or directory exclusion patterns (normalizing patterns ending in /*). For surviving files, the implementation checks pattern inclusion, enforces the max_file_size cap via os.path.getsize, and reads the content using utf-8-sig encoding to handle UTF-8 Byte Order Marks (BOM). Files failing text decoding or encountering read errors are categorized as non-text and excluded.

    def should_include_file(file_path: str, file_name: str, gitignore_spec=None) -> bool:

    Description: Evaluates whether a candidate file satisfies filtering criteria based on file name inclusion patterns, .gitignore path specifications, and explicit file exclusion globs.

        def should_include_file(file_path: str, file_name: str, gitignore_spec=None) -> bool:
        """Determine if a file should be included based on patterns"""
        # If no include patterns are specified, include all files
        if not include_patterns:
            include_file = True
        else:
            # Check if file matches any include pattern
            include_file = any(fnmatch.fnmatch(file_name, pattern) for pattern in include_patterns)

        # Check gitignore if provided
        if include_file and gitignore_spec and gitignore_spec.match_file(file_path):
            return False

        # If exclude patterns are specified, check if file should be excluded
        if exclude_patterns and include_file:
            # Exclude if file matches any exclude pattern
            exclude_file = any(fnmatch.fnmatch(file_path, pattern) for pattern in exclude_patterns)
            return not exclude_file

        return include_file

    The function executes three filtering steps. First, if include_patterns is present, file_name must match at least one glob pattern via fnmatch.fnmatch; otherwise, include_file remains True. Second, if a gitignore_spec is provided and reports a match against the relative file_path, the candidate is immediately excluded. Third, if exclude_patterns are defined, file_path is evaluated against each pattern; a positive match causes the function to reject the file.

    Parameters: * file_path (str): Relative path of the file within the repository root or target subdirectory. * file_name (str): Basename of the file. * gitignore_spec (pathspec.PathSpec, optional): Compiled PathSpec instance matching .gitignore rules.

    Returns: * bool: True if the file passes all inclusion and exclusion checks; False otherwise.

    Raises: * None.

    def fetch_branches(owner: str, repo: str) -> list[dict] | list:

    Description: Queries the GitHub REST API to retrieve branch metadata for the target repository, enabling reference resolution for multi-segment branch names.

        def fetch_branches(owner: str, repo: str):
        """Get branches of the repository"""

        url = f"https://api.github.com/repos/{owner}/{repo}/branches"
        response = requests.get(url, headers=headers, timeout=(30, 30))

        if response.status_code in (403, 429) and not token:
            raise Exception("GitHub API rate limit exceeded. Please provide a GitHub token using --token or GITHUB_TOKEN env var.")

        if response.status_code == 404:
            if not token:
                emit_raw(
                    "ERROR",
                    "Error 404: Repository not found or is private.\n"
                    "If this is a private repository, please provide a valid GitHub token via the 'token' argument or set the GITHUB_TOKEN environment variable.",
                )
            else:
                emit_raw(
                    "ERROR",
                    "Error 404: Repository not found or insufficient permissions with the provided token.\n"
                    "Please verify the repository exists and the token has access to this repository.",
                )
            return []

        if response.status_code != 200:
            emit_raw("ERROR", f"Error fetching the branches of {owner}/{repo}: {response.status_code} - {response.text}")
            return []

        return response.json()

    The function executes an HTTP GET request against /repos/{owner}/{repo}/branches with a 30-second connection and read timeout. It intercepts status codes 403 and 429, raising an explicit Exception if no API token is configured. If the repository is inaccessible (HTTP 404) or encounters unexpected error codes, diagnostic failure messages are emitted via emit_raw, and an empty list is returned to halt branch resolution.

    Parameters: * owner (str): Repository owner (organization or user account). * repo (str): Repository name.

    Returns: * list[dict] | list: A list of dictionaries representing GitHub branch descriptors if successful; otherwise, an empty list.

    Raises: * Exception: Raised when GitHub API rate limits are exceeded and no authentication token is provided.

    def fetch_contents(path: str) -> None:

    Description: Recursively queries the GitHub Contents API at the specified directory path, handles rate limiting with backoff sleep cycles, evaluates directory and file exclusions, downloads file contents, and populates the outer files dictionary.

        def fetch_contents(path):
        """Fetch contents of the repository at a specific path and commit"""
        url = f"https://api.github.com/repos/{owner}/{repo}/contents/{path}"
        params = {"ref": ref} if ref is not None else {}

        response = requests.get(url, headers=headers, params=params, timeout=(30, 30))

        if response.status_code in (403, 429) and "rate limit exceeded" in response.text.lower():
            if not token:
                raise Exception("GitHub API rate limit exceeded. Please provide a GitHub token using --token or GITHUB_TOKEN env var.")
            reset_time = int(response.headers.get("X-RateLimit-Reset", 0))
            wait_time = max(reset_time - time.time(), 0) + 1
            emit_raw("WARNING", f"Rate limit exceeded. Waiting for {wait_time:.0f} seconds...")
            time.sleep(wait_time)
            return fetch_contents(path)

        if response.status_code == 404:
            if not token:
                emit_raw(
                    "ERROR",
                    "Error 404: Repository not found or is private.\n"
                    "If this is a private repository, please provide a valid GitHub token via the 'token' argument or set the GITHUB_TOKEN environment variable.",
                )
            elif not path and ref == "main":
                emit_raw(
                    "ERROR",
                    "Error 404: Repository not found. Check if the default branch is not 'main'\n"
                    "Try adding branch name to the request i.e. python main.py --repo https://github.com/username/repo/tree/master",
                )
            else:
                emit_raw(
                    "ERROR",
                    f"Error 404: Path '{path}' not found in repository or insufficient permissions with the provided token.\n"
                    f"Please verify the token has access to this repository and the path exists.",
                )
            return None

        if response.status_code != 200:
            emit_raw("ERROR", f"Error fetching {path}: {response.status_code} - {response.text}")
            return None

        contents = response.json()

        # Handle both single file and directory responses
        if not isinstance(contents, list):
            contents = [contents]

        for item in contents:
            item_path = item["path"]

            # Calculate relative path if requested
            if use_relative_paths and specific_path:
                # Make sure the path is relative to the specified subdirectory
                if item_path.startswith(specific_path):
                    rel_path = item_path[len(specific_path) :].lstrip("/")
                else:
                    rel_path = item_path
            else:
                rel_path = item_path

            if item["type"] == "file":
                api_counters["entry"] += 1
                entry_num = api_counters["entry"]

                # Check if file should be included based on patterns
                if not should_include_file(rel_path, item["name"], gitignore_spec=gitignore_spec):
                    api_counters["excluded"] += 1
                    emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=rel_path)
                    continue

                # Check file size if available
                file_size = item.get("size", 0)
                if file_size > max_file_size:
                    api_counters["size_limit"] += 1
                    api_skipped_size.append(rel_path)
                    size_kb = file_size / 1024
                    emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=rel_path, size=f"{size_kb:.0f}")
                    continue

                # For files, get raw content
                if item.get("download_url"):
                    file_url = item["download_url"]
                    file_response = requests.get(file_url, headers=headers, timeout=(30, 30))

                    # Final size check in case content-length header is available but differs from metadata
                    content_length = int(file_response.headers.get("content-length", 0))
                    if content_length > max_file_size:
                        api_counters["size_limit"] += 1
                        api_skipped_size.append(rel_path)
                        size_kb = content_length / 1024
                        emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=rel_path, size=f"{size_kb:.0f}")
                        continue

                    if file_response.status_code == 200:
                        files[rel_path] = file_response.text
                        api_counters["processed"] += 1
                        emit("CRAWL_FILE_PROCESSED", num=entry_num, path=rel_path)
                    else:
                        api_counters["non_text"] += 1
                        api_skipped_non_text.append(rel_path)
                        emit("CRAWL_FILE_HTTP_ERROR", num=entry_num, path=rel_path, status=file_response.status_code)
                else:
                    # Alternative method if download_url is not available
                    content_response = requests.get(item["url"], headers=headers, timeout=(30, 30))
                    if content_response.status_code == 200:
                        content_data = content_response.json()
                        if content_data.get("encoding") == "base64" and "content" in content_data:
                            # Check size of base64 content before decoding
                            if len(content_data["content"]) * 0.75 > max_file_size:  # Approximate size calculation
                                estimated_size = int(len(content_data["content"]) * 0.75)
                                api_counters["size_limit"] += 1
                                api_skipped_size.append(rel_path)
                                size_kb = estimated_size / 1024
                                emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=rel_path, size=f"{size_kb:.0f}")
                                continue

                            file_content = base64.b64decode(content_data["content"]).decode("utf-8")
                            files[rel_path] = file_content
                            api_counters["processed"] += 1
                            emit("CRAWL_FILE_PROCESSED", num=entry_num, path=rel_path)
                        else:
                            api_counters["non_text"] += 1
                            api_skipped_non_text.append(rel_path)
                            emit("CRAWL_FILE_UNEXPECTED", num=entry_num, path=rel_path)
                    else:
                        api_counters["non_text"] += 1
                        api_skipped_non_text.append(rel_path)
                        emit("CRAWL_FILE_HTTP_ERROR", num=entry_num, path=rel_path, status=content_response.status_code)

            elif item["type"] == "dir":
                # Check if directory should be excluded before recursing
                dir_excluded = False
                dir_reason = None

                if gitignore_spec and gitignore_spec.match_file(rel_path):
                    dir_excluded = True
                    dir_reason = get("CRAWL_REASON_GITIGNORE")

                if not dir_excluded and exclude_patterns:
                    dir_name = item["name"]  # basename of the directory
                    for pattern in exclude_patterns:
                        dir_pattern = pattern.removesuffix("/*")
                        if (
                            fnmatch.fnmatch(item_path, dir_pattern)
                            or fnmatch.fnmatch(rel_path, dir_pattern)
                            or fnmatch.fnmatch(dir_name, dir_pattern)
                        ):
                            dir_excluded = True
                            dir_reason = get("CRAWL_REASON_EXCLUDED")
                            break

                if dir_excluded:
                    api_counters["entry"] += 1
                    api_counters["excluded"] += 1
                    emit("CRAWL_DIR_EXCLUDED", num=api_counters["entry"], path=rel_path, reason=dir_reason)
                    continue

                # Only recurse if directory is not excluded
                fetch_contents(item_path)

        return None

    The function manages the remote API traversal lifecycle. When rate limits are encountered, it reads the X-RateLimit-Reset response header, computes the required sleep interval via time.sleep(), and retries the request recursively. Directories are checked against gitignore_spec and exclude_patterns before recursive calls are scheduled. For file entries, it verifies size limits using either metadata properties, HTTP Content-Length headers, or base64 length estimates (len * 0.75), downloading text via download_url or decoding base64 payloads directly into files.

    Parameters: * path (str): Remote directory path or file path relative to the repository root.

    Returns: * None: Mutates enclosing dictionaries and counters directly.

    Raises: * Exception: Raised when an unauthenticated request encounters rate limit codes (403, 429).

    Example: 

    # Extracted from utils/crawl_github_files.py (initial API trigger)
fetch_contents(specific_path)

    Data Structures

    Crawl Result Schema (CrawlResult)

    Returned directly by crawl_github_files() upon completing crawling operations.

    Field Type Description
    files dict[str, str] Mapping where each key is a repository-relative or subpath-relative file path, and each value is the decoded UTF-8 file content.
    stats dict[str, Any] Operational statistics and configuration parameters applied during the crawling run.

    Crawl Statistics Schema (CrawlStats)

    Nested dictionary stored within the "stats" key of the return structure.

    Field Type Description
    downloaded_count int Total number of successfully retrieved and decoded text files.
    skipped_count int Number of files skipped due to filtering (initialized to 0 in return payload).
    skipped_files list List of paths skipped during ingestion.
    base_path str \| None Base path used for relative re-basing if use_relative_paths was enabled; otherwise None.
    include_patterns set[str] \| None Evaluated set of inclusion globs.
    exclude_patterns set[str] \| None Evaluated set of exclusion globs.
    source str (Optional) Present with value "ssh_clone" when the SSH ingestion path is used.
    error str (Optional) Present if an exception halted Git clone execution during SSH ingestion.

    API Metrics Schema (api_counters)

    Internal tracking state utilized during GitHub REST API traversal.

    Field Type Description
    processed int Count of files successfully fetched and written to memory.
    excluded int Count of files or directories omitted due to pattern or .gitignore matches.
    size_limit int Count of files skipped because their byte size exceeded max_file_size.
    non_text int Count of files skipped due to HTTP errors, missing content, or decoding issues.
    entry int Total count of all remote entries traversed.

    Error Handling

    Rate Limiting (HTTP 403 / 429)

    The module differentiates between authenticated and unauthenticated rate-limit violations: * When token is absent and a 403 or 429 response contains "rate limit exceeded", execution terminates by raising Exception("GitHub API rate limit exceeded. Please provide a GitHub token using --token or GITHUB_TOKEN env var."). * When token is present, the crawler extracts the epoch timestamp from response.headers["X-RateLimit-Reset"], calculates wait_time = max(reset_time - time.time(), 0) + 1, logs a warning via emit_raw("WARNING", ...), suspends execution via time.sleep(wait_time), and re-attempts the request recursively.

    Missing or Private Resources (HTTP 404)

    When queries return HTTP 404: * If unauthenticated, the crawler logs that the repository may be private or non-existent, prompting for a token. * If the root path fails and ref == "main", the crawler advises verifying the default branch (e.g., checking if the primary branch is named master). * For specific subpaths, the crawler logs that the path does not exist or lacks permissions under the active token.

    Binary and Non-Text Data Handling

    During both local SSH traversals and API base64 payload decodings, files are decoded using UTF-8 / UTF-8-SIG: * If decoding fails with UnicodeDecodeError or ValueError, the file is identified as binary or non-text. * The file is appended to skipped_non_text_list (or api_skipped_non_text), the non-text counter is incremented, and telemetry is recorded via emit("CRAWL_FILE_NOT_TEXT", ...).

    Size Limit Enforcement

    File sizes are evaluated before allocating content buffers: * In SSH mode, os.path.getsize(abs_path) is checked against max_file_size. * In API mode, item["size"], HTTP Content-Length, and estimated base64 byte sizes (len * 0.75) are validated. Files violating the threshold increment size-limit counters and trigger emit("CRAWL_FILE_SIZE_LIMIT", ...).

    SSH Git Operations

    Cloning failures via git.Repo.clone_from are caught under a broad Exception block. The module emits an error message via emit_raw("ERROR", ...) and returns an early dictionary containing empty files and the string representation of the exception under stats["error"].
