    crawl_github_files.py

    Source: utils/crawl_github_files.py

    Following the inference abstraction layer documented in call_llm.py, utils/crawl_github_files.py implements the remote repository ingestion engine for the Codebase-Knowledge-Builder system. While model inference consumes standardized text representations of source code, this module is responsible for extracting, filtering, and normalizing those source files directly from remote GitHub repositories.

    Technical Overview

    utils/crawl_github_files.py provides a dual-engine architecture for ingesting source code from GitHub repositories without requiring manual local repository configuration. It supports both public and private repositories, handling deep URL subpath specifications, specific Git commits, tree references, and branch names. The module evaluates remote repository content against inclusion patterns, exclusion lists, file size limits, and .gitignore specifications, returning a standardized in-memory dictionary mapping file paths to their UTF-8 string contents.

    The module operates across two distinct execution strategies: 1. Git over SSH Clone Engine: Triggered when a URL starts with git@ or ends with .git. The module provisions an ephemeral directory via Python's tempfile.TemporaryDirectory, performs a shallow clone using GitPython (git.Repo.clone_from), parses any top-level .gitignore via pathspec, and performs a filtered filesystem walk before releasing all disk resources. 2. GitHub REST API Engine: Utilized for standard HTTPS GitHub URLs (e.g., https://github.com/owner/repo/tree/commit/subpath). The engine parses the URL into its constituent components (owner, repository name, branch/commit ref, and subdirectory path), validates refs against the /branches and /git/trees endpoints, loads remote .gitignore definitions via Base64 decoding, and recursively traverses the directory tree using the /contents API.

    To protect the execution environment against resource exhaustion and rate degradation, the module incorporates automatic HTTP 403/429 rate-limit backoff using GitHub's X-RateLimit-Reset headers, enforces binary/non-text file detection, applies a default 1 MB per-file size ceiling, and streams execution progress events to the console via output.py.

    Phase 1: Parameter Normalization and Pattern Setup

    Normalizes string-based include and exclude patterns into uniform Python set collections to ensure consistent iteration and lookup semantics throughout the crawling lifecycle.

        # Convert single pattern to set
    if include_patterns and isinstance(include_patterns, str):

    def should_include_file(file_path: str, file_name: str, gitignore_spec=None) -> bool:
        """Determine if a file should be included based on patterns"""
        # If no include patterns are specified, include all files
        if not include_patterns:
            include_file = True
        else:
            # Check if file matches any include pattern
            include_file = any(fnmatch.fnmatch(file_name, pattern) for pattern in include_patterns)

        # Check gitignore if provided
        if include_file and gitignore_spec and gitignore_spec.match_file(file_path):
            return False

        # If exclude patterns are specified, check if file should be excluded
        if exclude_patterns and include_file:
            # Exclude if file matches any exclude pattern

It defines a nested helper closure should_include_file that encapsulates the evaluation chain: positive match against include patterns (or pass-through if unconfigured), negative check against compiled .gitignore path specifications (pathspec), and negative match against user-provided exclusion patterns.

    Phase 2: Protocol Detection and Git SSH Clone Pipeline

    Executes when the URL string satisfies SSH format heuristics (git@ prefix or .git suffix). Clones the repository into a context-managed temporary directory and walks the filesystem on disk.

        # Detect SSH URL (git@ or .git suffix)
    is_ssh_url = repo_url.startswith("git@") or repo_url.endswith(".git")

    if is_ssh_url:

        with tempfile.TemporaryDirectory() as tmpdirname:

            try:
                repo = git.Repo.clone_from(repo_url, tmpdirname)
            except Exception as e:
                emit_raw("ERROR", f"Error cloning repo: {e}")
                return {"files": {}, "stats": {"error": str(e)}}

            # Attempt to checkout specific commit/branch if in URL
            # Parse ref and subdir from SSH URL? SSH URLs don't have branch info embedded
            # So rely on default branch, or user can checkout manually later
            # Optionally, user can pass ref explicitly in future API

            # Walk directory
            files = {}

            # --- Counters ---
            count_processed = 0
            count_excluded = 0
            count_size_limit = 0
            count_non_text = 0
            skipped_size_list = []
            skipped_non_text_list = []
            entry_num = 0

            # --- Load .gitignore ---
            gitignore_path = os.path.join(tmpdirname, ".gitignore")
            gitignore_spec = None
            if os.path.exists(gitignore_path):
                try:
                    with open(gitignore_path, encoding="utf-8-sig") as f:
                        gitignore_spec = pathspec.PathSpec.from_lines("gitwildmatch", f.readlines())
                    emit("CRAWL_GITIGNORE_LOADED", path="repository")
                except Exception:
                    pass

            for root, dirs, filenames in os.walk(tmpdirname):
                # Filter directories
                excluded_dirs = set()
                for d in sorted(dirs):
                    dirpath_rel = os.path.relpath(os.path.join(root, d), tmpdirname)
                    reason = None
                    if gitignore_spec and gitignore_spec.match_file(dirpath_rel):
                        reason = get("CRAWL_REASON_GITIGNORE")
                    elif exclude_patterns:
                        for pattern in exclude_patterns:
                            dir_pattern = pattern.removesuffix("/*")
                            if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                                reason = get("CRAWL_REASON_EXCLUDED")
                                break

                    if reason:
                        excluded_dirs.add(d)
                        entry_num += 1
                        count_excluded += 1
                        emit("CRAWL_DIR_EXCLUDED", num=entry_num, path=dirpath_rel, reason=reason)

                for d in dirs.copy():
                    if d in excluded_dirs:
                        dirs.remove(d)

                # Sort remaining dirs for consistent traversal order
                dirs.sort()

                for filename in sorted(filenames):
                    abs_path = os.path.join(root, filename)
                    rel_path = os.path.relpath(abs_path, tmpdirname)
                    entry_num += 1

                    # Check include/exclude patterns
                    if not should_include_file(rel_path, filename, gitignore_spec=gitignore_spec):
                        count_excluded += 1
                        emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=rel_path)
                        continue

                    # Check file size
                    try:
                        file_size = os.path.getsize(abs_path)
                    except OSError:
                        continue

                    if file_size > max_file_size:
                        count_size_limit += 1
                        skipped_size_list.append(rel_path)
                        size_kb = file_size / 1024
                        emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=rel_path, size=f"{size_kb:.0f}")
                        continue

                    # Read content
                    try:
                        with open(abs_path, encoding="utf-8-sig") as f:
                            content = f.read()
                        files[rel_path] = content
                        count_processed += 1
                        emit("CRAWL_FILE_PROCESSED", num=entry_num, path=rel_path)
                    except (UnicodeDecodeError, ValueError):
                        count_non_text += 1
                        skipped_non_text_list.append(rel_path)
                        emit("CRAWL_FILE_NOT_TEXT", num=entry_num, path=rel_path)
                    except Exception as e:
                        count_non_text += 1
                        skipped_non_text_list.append(rel_path)
                        emit("CRAWL_FILE_ERROR", num=entry_num, path=rel_path, error=e)

    The SSH pipeline provisions a temporary folder and invokes git.Repo.clone_from. If cloning fails, it emits an error event and returns an error payload immediately. When successful, it inspects the cloned root for a .gitignore file and compiles its lines into a pathspec.PathSpec matcher using the gitwildmatch dialect. It then invokes os.walk, pruning matched directories dynamically from dirs in-place to avoid descending into excluded branches (such as .git or build outputs). Individual files are validated against the pattern matcher and checked for size via os.path.getsize. Text files are ingested with utf-8-sig encoding handling, catching UnicodeDecodeError to skip binary assets cleanly.

    Phase 3: GitHub REST API URL Parsing and Ref Resolution

    Handles standard HTTPS URLs by parsing path components into repository metadata, identifying commit hashes, branch names, and requested subdirectories.

            return "/".join(path_parts[i:])

        branch_names = (branch.get("name") for branch in branches)

        # Fetching branches was not successful
        if len(branches) == 0:
            return None

        if ref is None:

            ref = tree if check_tree(owner, repo, tree) else None

        if ref is None:
            emit_raw("ERROR", "The given path does not match with any branch and any tree in the repository.\nPlease verify the path is exists.")
            return None

        # Combine all parts after the ref as the path
        part_index = 5 if "/" in ref else 4
        specific_path = join_parts(part_index) if part_index < len(path_parts) else ""
    else:
        # Don't put the ref param in query
        # and let Github decide default branch
        ref = None
        specific_path = ""

    In the REST API branch, the function parses the URL path to isolate owner and repo. When URLs contain /tree/, the subpath must be disambiguated between complex multi-slash branch names (e.g., feature/login), commit SHAs, or Git tree objects. The code queries fetch_branches() and searches for prefix matches against existing remote branch names. If no branch matches, it falls back to validating whether the path segment represents a valid Git tree commit SHA via check_tree(). Once the ref is identified, remaining path segments are combined to form the target root specific_path.

    Phase 4: Remote .gitignore Acquisition and Spec Compilation

    Attempts to locate and retrieve the repository's root .gitignore file through the GitHub contents API before traversing code trees.

    # --- Counters ---

    api_skipped_non_text = []

    gitignore_spec = None

        pass

    Before initiating full directory crawling, the API engine performs a speculative HTTP GET request for /.gitignore pinned to the target ref. If the file exists and is encoded as base64, it decodes the payload to text and constructs a PathSpec matcher instance. If the file is missing (HTTP 404) or network errors occur, the exception is caught silently, leaving gitignore_spec as None so crawling can continue without .gitignore filtering.

    Phase 5: Recursive REST API Traversal and Content Extraction

    Recursively crawls the repository tree via GitHub's /repos/{owner}/{repo}/contents/{path} endpoint, managing rate limit backoff and extracting raw file bodies.

    The recursive fetch_contents helper queries the GitHub contents endpoint. If an HTTP 403 or 429 response indicates rate-limiting, the engine parses X-RateLimit-Reset, pauses execution with time.sleep(), and retries the request. When reading directory entries, it normalizes relative subpaths, verifies inclusion/exclusion criteria, checks the size metadata attribute against max_file_size, and retrieves file bodies. Content fetching prefers direct HTTP downloads from download_url, falling back to decoding Base64 JSON payloads from item["url"] when download_url is absent.

    Phase 6: Result Assembly and Summary Reporting

    Aggregates crawl metrics across processed files, exclusions, size limit skips, and non-text omissions, emitting structured diagnostic summaries via output.py.

    Upon completing the traversal, the function tallies cumulative statistics across all encountered items (processed, excluded, size_limit, non_text). It invokes standardized emit() telemetry events to print summary metrics and detailed lists of skipped files to the output console. Finally, it constructs and returns the structured dictionary containing the accumulated files map and metadata stats.

def should_include_file(file_path: str, file_name: str, gitignore_spec=None) -> bool:
    """Determine if a file should be included based on patterns"""
    # If no include patterns are specified, include all files
    if not include_patterns:
        include_file = True
    else:
        # Check if file matches any include pattern
        include_file = any(fnmatch.fnmatch(file_name, pattern) for pattern in include_patterns)

    # Check gitignore if provided
    if include_file and gitignore_spec and gitignore_spec.match_file(file_path):
        return False

    if exclude_patterns and include_file:

    return include_file

def fetch_branches(owner: str, repo: str):
    """Get branches of the repository"""

    url = f"https://api.github.com/repos/{owner}/{repo}/branches"
    response = requests.get(url, headers=headers, timeout=(30, 30))

    if response.status_code in (403, 429) and not token:
        raise Exception("GitHub API rate limit exceeded. Please provide a GitHub token using --token or GITHUB_TOKEN env var.")

    if response.status_code == 404:
        if not token:
            emit_raw(
                "ERROR",
                "Error 404: Repository not found or is private.\n"
                "If this is a private repository, please provide a valid GitHub token via the 'token' argument or set the GITHUB_TOKEN environment variable.",
            )
        else:
            emit_raw(
                "ERROR",
                "Error 404: Repository not found or insufficient permissions with the provided token.\n"
                "Please verify the repository exists and the token has access to this repository.",
            )
        return []

    if response.status_code != 200:
        emit_raw("ERROR", f"Error fetching the branches of {owner}/{repo}: {response.status_code} - {response.text}")
        return []

    return response.json()

    The function executes a synchronized HTTP GET request with a 30-second connect/read timeout. It intercepts HTTP 403 and 429 status codes, raising a fatal exception if unauthenticated, or reporting granular 404 diagnostics differentiating between missing public repositories and private repositories requiring a GitHub PAT.

    fetch_contents()

    Visibility: Private (Nested Helper inside crawl_github_files)
    Signature: def fetch_contents(path: str) -> None:

    Description: Recursively traverses and downloads files from the GitHub repository contents endpoint. Handles directory recursion, exclusion pruning, rate limit sleep-and-retry logic, file size checking, download URL streaming, and Base64 content decoding. Populates the outer files dictionary by side effect.

    Parameters: * path (str): Subdirectory path within the repository to fetch. Passes an empty string "" to begin traversal at the root.

    Returns: * None: Populates the outer scope files dictionary and increments api_counters directly.

    Raises: * Exception: If an unauthenticated rate limit error is encountered.

    Example: 

    # Extracted from utils/crawl_github_files.py (inside crawl_github_files)
def fetch_contents(path):
    """Fetch contents of the repository at a specific path and commit"""
    url = f"https://api.github.com/repos/{owner}/{repo}/contents/{path}"
    params = {"ref": ref} if ref is not None else {}

    response = requests.get(url, headers=headers, params=params, timeout=(30, 30))

    if response.status_code in (403, 429) and "rate limit exceeded" in response.text.lower():
        if not token:
            raise Exception("GitHub API rate limit exceeded. Please provide a GitHub token using --token or GITHUB_TOKEN env var.")
        reset_time = int(response.headers.get("X-RateLimit-Reset", 0))
        wait_time = max(reset_time - time.time(), 0) + 1
        emit_raw("WARNING", f"Rate limit exceeded. Waiting for {wait_time:.0f} seconds...")
        time.sleep(wait_time)
        return fetch_contents(path)

    if response.status_code == 404:
        # ... [Handle 404 error formatting] ...
        return None

    if response.status_code != 200:
        emit_raw("ERROR", f"Error fetching {path}: {response.status_code} - {response.text}")
        return None

    contents = response.json()
    if not isinstance(contents, list):
        contents = [contents]

    for item in contents:
        # ... [Process file downloads and directory recursion] ...
        pass
    return None

    fetch_contents manages directory recursion over the GitHub API. When encountering a directory (item["type"] == "dir"), it tests the directory against .gitignore and glob exclusion rules before making recursive calls. For files (item["type"] == "file"), it verifies size limits against item["size"], issues HTTP GET requests to download_url, checks the resulting Content-Length header, and stores decoded UTF-8 file content in the outer files mapping.

    Data Structures

    Return Schema: Repository Crawl Result

    Both the SSH clone and REST API engines return a dictionary conforming to the structural schema below.

    {
    "files": {
        "src/main.py": "import os\n...",
        "README.md": "# Project\n..."
    },
    "stats": {
        "downloaded_count": 2,
        "skipped_count": 0,
        "skipped_files": [],
        "base_path": "src",
        "include_patterns": {"*.py", "*.md"},
        "exclude_patterns": None,
        "source": "ssh_clone"  # Present only in SSH mode
    }
}

    Fields: Top-Level Mapping

    Field Type Description
    files dict[str, str] Mapping of file paths (relative to repository root or base_path) to UTF-8 file contents.
    stats dict[str, Any] Execution metadata, filter criteria, and transfer statistics.

    Fields: stats Sub-Dictionary

    Field Type Description
    downloaded_count int Total number of valid text files successfully ingested into files.
    skipped_count int Reserved counter for skipped files (defaults to 0).
    skipped_files list[str] Reserved list for skipped file paths (defaults to []).
    base_path str | None Base path offset used if use_relative_paths=True; otherwise None.
    include_patterns set[str] | None Glob pattern set applied for file inclusion.
    exclude_patterns set[str] | None Glob pattern set applied for file/directory exclusion.
    source str (Optional) Identifies the ingestion mechanism. Set to "ssh_clone" when the SSH engine is used.

    Internal State: api_counters Tracking Schema

    Used internally by the REST API crawler to aggregate telemetry across traversal steps.

    Field Type Description
    processed int Count of successfully ingested and decoded text files.
    excluded int Count of files and directories skipped due to .gitignore or exclusion patterns.
    size_limit int Count of files skipped due to exceeding max_file_size.
    non_text int Count of files skipped due to binary encoding, decoding failures, or HTTP download errors.
    entry int Total count of all evaluated filesystem entries (files and directories).

    Error Handling

    utils/crawl_github_files.py handles diverse network, transport, filesystem, and rate limit errors:

    1. GitHub API Rate Limiting (HTTP 403 / 429)

    • Unauthenticated Requests: If no token is supplied and GitHub returns an HTTP 403 or 429 containing "rate limit exceeded", execution raises an immediate Exception notifying the user that an API token is required.
    • Authenticated Requests: If an authenticated session hits a rate limit, the engine extracts the X-RateLimit-Reset Unix epoch timestamp, calculates the required sleep duration (reset_time - time.time() + 1), logs a warning event via emit_raw("WARNING", ...), sleeps using time.sleep(), and retries the request automatically.

    2. HTTP 404 Repository and Ref Resolution Diagnostics

    The engine differentiates 404 error causes based on authentication context and URL paths: * Private or Missing Repositories: Emits a targeted advisory explaining that the repository may be private (requiring a token via GITHUB_TOKEN) or does not exist. * Branch Name Heuristics: If querying root paths on default branches fails, it alerts the user to check if the repository uses an alternative default branch (such as master instead of main). * Invalid Trees: If URL path segments after /tree/ do not match any branch from /branches or commit tree from /git/trees/{tree}, it halts execution and returns None.

    3. File Size and Memory Protection

    • Files are validated against max_file_size at three distinct checkpoints:
    • REST API file metadata (item.get("size", 0)).
    • HTTP download streaming headers (Content-Length).
    • Base64 payload length heuristics (len(content) * 0.75).
    • Files exceeding the threshold increment count_size_limit / api_counters["size_limit"], are logged to the skipped lists, and trigger a CRAWL_FILE_SIZE_LIMIT event without downloading the full payload.

    4. Binary and Non-Text Ingestion Failures

    • SSH Engine: Catches UnicodeDecodeError and ValueError when opening files with utf-8-sig, logging them as non-text via CRAWL_FILE_NOT_TEXT.
    • API Engine: Validates Base64 decoding and HTTP response statuses, catching parsing errors and emitting CRAWL_FILE_HTTP_ERROR or CRAWL_FILE_UNEXPECTED.
