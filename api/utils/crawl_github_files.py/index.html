    crawl_github_files.py

    Source: utils/crawl_github_files.py

    Technical Overview

    utils/crawl_github_files.py implements the remote source code ingestion subsystem for the knowledge extraction pipeline. It provides automated facilities for retrieving, filtering, and indexing file trees from GitHub repositories. The module supports two distinct operational modes: cloning via SSH through GitPython for Git URLs ending in .git or starting with git@, and tree traversal via the GitHub REST API (v3) for standard HTTPS URLs. This architecture allows the pipeline to ingest remote repositories without requiring external git installations when operating over HTTPS, while retaining support for SSH key authentication and private network clones when required.

    The module incorporates multi-layered content filtering and defensive validation to safeguard downstream Large Language Model (LLM) processing stages. Files and directories are filtered through .gitignore specifications (using pathspec's gitwildmatch implementation) fetched either from the cloned directory or directly from the GitHub API. In addition, user-defined glob patterns (include_patterns and exclude_patterns) are evaluated using fnmatch. Binary files and unsupported encodings are filtered out during file reading, and files exceeding DEFAULT_MAX_FILE_SIZE (1 MB) are skipped to avoid memory exhaustion and token budget overrun.

    Execution telemetry is deeply integrated with the pipeline's reporting layer via utils.output. Crawl operations emit event-driven status updates, error notifications, size limit warnings, and aggregated ingestion metrics. When interacting with GitHub REST endpoints, the crawler dynamically detects rate-limiting thresholds (HTTP 403 and 429), interrogates the X-RateLimit-Reset header, and implements an exponential backoff wait state if authenticated, or raises actionable configuration exceptions when unauthenticated.

    Public API

    DEFAULT_MAX_FILE_SIZE

    Visibility: Public

    Signature: DEFAULT_MAX_FILE_SIZE = 1_048_576 # 1 MB

    Description: The fallback maximum byte threshold allowed per file during repository traversal. Any source file exceeding 1,048,576 bytes is excluded from ingestion to prevent memory bloating and pipeline stalls during tokenization and AST parsing.

    crawl_github_files()

    Visibility: Public

    Signature: def crawl_github_files( repo_url, token=None, max_file_size: int = DEFAULT_MAX_FILE_SIZE, use_relative_paths: bool = False, include_patterns: str | set[str] | None = None, exclude_patterns: str | set[str] | None = None, )

    Description: Orchestrates the retrieval of source files from a remote GitHub repository at a target branch, commit ref, or subdirectory. It routes requests through GitPython for SSH-based protocols or recursive GitHub REST API v3 queries for standard URLs. It enforces file-level exclusion patterns, applies repository .gitignore rules, discards binary payloads, and computes execution summary metrics.

    Parameters:

    • repo_url (str): Full GitHub repository URL, optionally containing commit or branch references and subdirectory paths (e.g., https://github.com/microsoft/autogen/tree/e45a15766746d95f8cfaaa705b0371267bec812e/python/packages/autogen-core/src/autogen_core) or an SSH git locator (e.g., git@github.com:owner/repo.git).
    • token (str | None): GitHub personal access token used for API authentication and rate-limit mitigation. If not passed, defaults to None and attempts fallback to unauthenticated public requests or reads from environment variables at caller sites.
    • max_file_size (int): Ceiling on ingested file sizes in bytes. Files exceeding this threshold are recorded in skipped statistics and omitted from the returned content map. Defaults to 1_048_576 (1 MB).
    • use_relative_paths (bool): When True, strips the leading target subdirectory path from the keys in the output dictionary, anchoring file paths directly to the target subfolder. Defaults to False.
    • include_patterns (str | set[str] | None): Filename glob patterns (e.g., *.py) required for inclusion. If None, all encountered files are candidates for ingestion.
    • exclude_patterns (str | set[str] | None): Path or filename glob patterns to filter out (e.g., */tests/*). Takes precedence over inclusion matches. Defaults to None.

    Returns:

    • dict: Ingestion payload containing a files dictionary mapping repository-relative file paths to UTF-8 decoded content strings, and a stats dictionary containing ingestion metrics.

    Raises:

    • ValueError: Raised when repo_url does not conform to standard GitHub repository paths (fewer than two path components representing owner and repository).
    • Exception: Raised when GitHub API rate limits are encountered on unauthenticated connections.

    def should_include_file(file_path: str, file_name: str, gitignore_spec=None) -> bool:

Any positive match against .gitignore or exclusion patterns drops the candidate file immediately.

    Phase 3: Repository Traversal and Local File Ingestion (SSH)

                # --- Load .gitignore ---
            gitignore_path = os.path.join(tmpdirname, ".gitignore")
            gitignore_spec = None
            if os.path.exists(gitignore_path):
                try:
                    with open(gitignore_path, encoding="utf-8-sig") as f:
                        gitignore_spec = pathspec.PathSpec.from_lines("gitwildmatch", f.readlines())
                    emit("CRAWL_GITIGNORE_LOADED", path="repository")
                except Exception:
                    pass

            for root, dirs, filenames in os.walk(tmpdirname):
                # Filter directories
                excluded_dirs = set()
                for d in sorted(dirs):
                    dirpath_rel = os.path.relpath(os.path.join(root, d), tmpdirname)
                    reason = None
                    if gitignore_spec and gitignore_spec.match_file(dirpath_rel):
                        reason = get("CRAWL_REASON_GITIGNORE")
                    elif exclude_patterns:
                        for pattern in exclude_patterns:
                            dir_pattern = pattern.removesuffix("/*")
                            if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                                reason = get("CRAWL_REASON_EXCLUDED")
                                break

                    if reason:
                        excluded_dirs.add(d)
                        entry_num += 1
                        count_excluded += 1
                        emit("CRAWL_DIR_EXCLUDED", num=entry_num, path=dirpath_rel, reason=reason)

                for d in dirs.copy():
                    if d in excluded_dirs:
                        dirs.remove(d)

                # Sort remaining dirs for consistent traversal order
                dirs.sort()

                for filename in sorted(filenames):
                    abs_path = os.path.join(root, filename)
                    rel_path = os.path.relpath(abs_path, tmpdirname)
                    entry_num += 1

                    # Check include/exclude patterns
                    if not should_include_file(rel_path, filename, gitignore_spec=gitignore_spec):
                        count_excluded += 1
                        emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=rel_path)
                        continue

                    # Check file size
                    try:
                        file_size = os.path.getsize(abs_path)
                    except OSError:
                        continue

                    if file_size > max_file_size:
                        count_size_limit += 1
                        skipped_size_list.append(rel_path)
                        size_kb = file_size / 1024
                        emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=rel_path, size=f"{size_kb:.0f}")
                        continue

                    # Read content
                    try:
                        with open(abs_path, encoding="utf-8-sig") as f:
                            content = f.read()
                        files[rel_path] = content
                        count_processed += 1
                        emit("CRAWL_FILE_PROCESSED", num=entry_num, path=rel_path)
                    except (UnicodeDecodeError, ValueError):
                        count_non_text += 1
                        skipped_non_text_list.append(rel_path)
                        emit("CRAWL_FILE_NOT_TEXT", num=entry_num, path=rel_path)
                    except Exception as e:
                        count_non_text += 1
                        skipped_non_text_list.append(rel_path)
                        emit("CRAWL_FILE_ERROR", num=entry_num, path=rel_path, error=e)

    The SSH execution path compiles a PathSpec model from the root .gitignore file and walks the temporary directory using os.walk. Pruning of directories occurs dynamically in-place within dirs before traversing subdirectories, avoiding unnecessary disk reads in ignored branches. Files are validated against max_file_size, and content is decoded via utf-8-sig to gracefully strip byte order marks. Binary files, decoding failures, and unexpected file-system errors are caught, counted as non-text, and emitted to telemetry channels.

            return "/".join(path_parts[i:])

        branches = fetch_branches(owner, repo)
        branch_names = (branch.get("name") for branch in branches)

        # Fetching branches was not successful
        if len(branches) == 0:

        filter_gen = (name for name in branch_names if relevant_path.startswith(name))

        # If match is not found, check for is it a tree
        if ref is None:

            ref = tree if check_tree(owner, repo, tree) else None

        # If it is neither a tree nor a branch name
        if ref is None:
            emit_raw("ERROR", "The given path does not match with any branch and any tree in the repository.\nPlease verify the path is exists.")
            return None

        # Combine all parts after the ref as the path
        part_index = 5 if "/" in ref else 4
        specific_path = join_parts(part_index) if part_index < len(path_parts) else ""
    else:
        # Don't put the ref param in query
        # and let Github decide default branch
        ref = None
        specific_path = ""

    For standard HTTPS requests, the URL is decomposed into owner, repo, git ref (commit SHA, branch, or tag), and an optional subdirectory path specific_path. When a /tree/ segment is present, the crawler fetches repository branches and disambiguates multi-slash branch names (such as feature/auth) against target directory paths using relevant_path.startswith(name). If no named branch matches, it verifies whether the identifier corresponds to a valid Git tree or commit SHA via check_tree. If verification fails, the crawler terminates with an error message; otherwise, it assigns ref and sets specific_path to index into the targeted subfolder.

    Phase 6: Recursive Contents Retrieval via REST API

        def fetch_contents(path):
        """Fetch contents of the repository at a specific path and commit"""
        url = f"https://api.github.com/repos/{owner}/{repo}/contents/{path}"
        params = {"ref": ref} if ref is not None else {}

        response = requests.get(url, headers=headers, params=params, timeout=(30, 30))

        if response.status_code in (403, 429) and "rate limit exceeded" in response.text.lower():
            if not token:
                raise Exception("GitHub API rate limit exceeded. Please provide a GitHub token using --token or GITHUB_TOKEN env var.")
            reset_time = int(response.headers.get("X-RateLimit-Reset", 0))
            wait_time = max(reset_time - time.time(), 0) + 1
            emit_raw("WARNING", f"Rate limit exceeded. Waiting for {wait_time:.0f} seconds...")
            time.sleep(wait_time)
            return fetch_contents(path)

        # ... Status code validation, directory parsing, and file content dispatch ...

    The recursive fetch_contents helper queries the GitHub contents endpoint at the specified path. It inspects response headers and status codes to detect rate limits. When a rate limit is exceeded on an authenticated connection, it sleeps until the timestamp specified in X-RateLimit-Reset and retries the request; on unauthenticated connections, it raises an exception. Received directory entries are filtered against .gitignore and exclude_patterns to prevent descending into ignored subtrees. For files, payloads are downloaded using download_url or through the REST contents API using Base64 decoding, with file size limits enforced before and after transfer.

    should_include_file()

    Visibility: Private (nested within crawl_github_files)

    Signature: def should_include_file(file_path: str, file_name: str, gitignore_spec=None) -> bool

    Description: Determines whether a given candidate file should be ingested based on glob patterns and Git wildcard specifications. The inclusion logic checks whether file_name matches any configured pattern in include_patterns. If accepted, it evaluates file_path against gitignore_spec.match_file().     Returns:

    fetch_branches()

    Visibility: Private (nested within crawl_github_files)

    Signature: def fetch_branches(owner: str, repo: str)

    Description: Queries the GitHub REST API to list all branches in the specified repository. This list is used to parse branch names that contain slashes (e.g., feature/v2) out of ambiguous URL path segments.

    Parameters:

    • owner (str): GitHub account or organization name.
    • repo (str): GitHub repository name.

    Returns:

    • list[dict]: List of branch representation dictionaries returned by the GitHub API. Returns an empty list ([]) if the repository is not found, permissions are insufficient, or a non-200 status code occurs.

    Raises:

    • Exception: Raised when GitHub API rate limits (HTTP 403 or 429) are encountered without an authentication token.

    Example:

        def fetch_branches(owner: str, repo: str):
        """Get branches of the repository"""

        url = f"https://api.github.com/repos/{owner}/{repo}/branches"
        response = requests.get(url, headers=headers, timeout=(30, 30))

        if response.status_code in (403, 429) and not token:
            raise Exception("GitHub API rate limit exceeded. Please provide a GitHub token using --token or GITHUB_TOKEN env var.")

        if response.status_code == 404:
            if not token:
                emit_raw(
                    "ERROR",
                    "Error 404: Repository not found or is private.\n"
                    "If this is a private repository, please provide a valid GitHub token via the 'token' argument or set the GITHUB_TOKEN environment variable.",
                )
            else:
                emit_raw(
                    "ERROR",
                    "Error 404: Repository not found or insufficient permissions with the provided token.\n"
                    "Please verify the repository exists and the token has access to this repository.",
                )
            return []

        if response.status_code != 200:
            emit_raw("ERROR", f"Error fetching the branches of {owner}/{repo}: {response.status_code} - {response.text}")
            return []

        return response.json()

    The function executes a synchronized HTTP GET against /repos/{owner}/{repo}/branches with a 30-second timeout. It checks for rate-limiting status codes and differentiates unauthenticated from authenticated 404 responses via emit_raw, guiding the user on how to configure access tokens when a repository cannot be reached.

    fetch_contents()

    Visibility: Private (nested within crawl_github_files)

    Signature: def fetch_contents(path)

    Description: Core recursive traversal routine for the GitHub REST API workflow. Fetches the metadata and content of files and subdirectories located at path. Handles directory pruning, rate-limit backoff, file size enforcement, and decoding of Base64 or raw payloads.

    Parameters:

    • path (str): Repository-relative subdirectory or file path to inspect.

    Returns:

    • None: Mutates the parent scope files dictionary and api_counters maps in-place.

    Raises:

    • Exception: Raised when rate limits are exceeded on unauthenticated connections.

    Phase 1: Request Dispatch and Rate Limit Handling

        def fetch_contents(path):
        """Fetch contents of the repository at a specific path and commit"""
        url = f"https://api.github.com/repos/{owner}/{repo}/contents/{path}"
        params = {"ref": ref} if ref is not None else {}

        response = requests.get(url, headers=headers, params=params, timeout=(30, 30))

        if response.status_code in (403, 429) and "rate limit exceeded" in response.text.lower():
            if not token:
                raise Exception("GitHub API rate limit exceeded. Please provide a GitHub token using --token or GITHUB_TOKEN env var.")
            reset_time = int(response.headers.get("X-RateLimit-Reset", 0))
            wait_time = max(reset_time - time.time(), 0) + 1
            emit_raw("WARNING", f"Rate limit exceeded. Waiting for {wait_time:.0f} seconds...")
            time.sleep(wait_time)
            return fetch_contents(path)

        if response.status_code == 404:
            if not token:
                emit_raw(
                    "ERROR",
                    "Error 404: Repository not found or is private.\n"
                    "If this is a private repository, please provide a valid GitHub token via the 'token' argument or set the GITHUB_TOKEN environment variable.",
                )
            elif not path and ref == "main":
                emit_raw(
                    "ERROR",
                    "Error 404: Repository not found. Check if the default branch is not 'main'\n"
                    "Try adding branch name to the request i.e. python main.py --repo https://github.com/username/repo/tree/master",
                )
            else:
                emit_raw(
                    "ERROR",
                    f"Error 404: Path '{path}' not found in repository or insufficient permissions with the provided token.\n"
                    f"Please verify the token has access to this repository and the path exists.",
                )
            return None

        if response.status_code != 200:
            emit_raw("ERROR", f"Error fetching {path}: {response.status_code} - {response.text}")
            return None

    The helper issues an HTTP GET to /contents/{path} with the active commit or branch reference in params. If a 403 or 429 status code indicates rate limiting, the function checks for a token; if missing, it terminates by raising an Exception. If a token is present, it extracts the epoch reset timestamp from X-RateLimit-Reset, sleeps for the required interval, and retries the call. 404 responses are caught and logged with troubleshooting instructions before returning None.

    Phase 2: File Ingestion and Payload Decoding

            contents = response.json()

        # Handle both single file and directory responses
        if not isinstance(contents, list):
            contents = [contents]

        for item in contents:
            item_path = item["path"]

            # Calculate relative path if requested
            if use_relative_paths and specific_path:
                # Make sure the path is relative to the specified subdirectory
                if item_path.startswith(specific_path):
                    rel_path = item_path[len(specific_path) :].lstrip("/")
                else:
                    rel_path = item_path
            else:
                rel_path = item_path

            if item["type"] == "file":
                api_counters["entry"] += 1
                entry_num = api_counters["entry"]

                # Check if file should be included based on patterns
                if not should_include_file(rel_path, item["name"], gitignore_spec=gitignore_spec):
                    api_counters["excluded"] += 1
                    emit("CRAWL_FILE_EXCLUDED", num=entry_num, path=rel_path)
                    continue

                # Check file size if available
                file_size = item.get("size", 0)
                if file_size > max_file_size:
                    api_counters["size_limit"] += 1
                    api_skipped_size.append(rel_path)
                    size_kb = file_size / 1024
                    emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=rel_path, size=f"{size_kb:.0f}")
                    continue

                # For files, get raw content
                if item.get("download_url"):
                    file_url = item["download_url"]
                    file_response = requests.get(file_url, headers=headers, timeout=(30, 30))

                    # Final size check in case content-length header is available but differs from metadata
                    content_length = int(file_response.headers.get("content-length", 0))
                    if content_length > max_file_size:
                        api_counters["size_limit"] += 1
                        api_skipped_size.append(rel_path)
                        size_kb = content_length / 1024
                        emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=rel_path, size=f"{size_kb:.0f}")
                        continue

                    if file_response.status_code == 200:
                        files[rel_path] = file_response.text
                        api_counters["processed"] += 1
                        emit("CRAWL_FILE_PROCESSED", num=entry_num, path=rel_path)
                    else:
                        api_counters["non_text"] += 1
                        api_skipped_non_text.append(rel_path)
                        emit("CRAWL_FILE_HTTP_ERROR", num=entry_num, path=rel_path, status=file_response.status_code)
                else:
                    # Alternative method if download_url is not available
                    content_response = requests.get(item["url"], headers=headers, timeout=(30, 30))
                    if content_response.status_code == 200:
                        content_data = content_response.json()
                        if content_data.get("encoding") == "base64" and "content" in content_data:
                            # Check size of base64 content before decoding
                            if len(content_data["content"]) * 0.75 > max_file_size:  # Approximate size calculation
                                estimated_size = int(len(content_data["content"]) * 0.75)
                                api_counters["size_limit"] += 1
                                api_skipped_size.append(rel_path)
                                size_kb = estimated_size / 1024
                                emit("CRAWL_FILE_SIZE_LIMIT", num=entry_num, path=rel_path, size=f"{size_kb:.0f}")
                                continue

                            file_content = base64.b64decode(content_data["content"]).decode("utf-8")
                            files[rel_path] = file_content
                            api_counters["processed"] += 1
                            emit("CRAWL_FILE_PROCESSED", num=entry_num, path=rel_path)
                        else:
                            api_counters["non_text"] += 1
                            api_skipped_non_text.append(rel_path)
                            emit("CRAWL_FILE_UNEXPECTED", num=entry_num, path=rel_path)
                    else:
                        api_counters["non_text"] += 1
                        api_skipped_non_text.append(rel_path)
                        emit("CRAWL_FILE_HTTP_ERROR", num=entry_num, path=rel_path, status=content_response.status_code)

    The response JSON array (or single dictionary) is processed sequentially. For each file item, relative paths are computed if use_relative_paths is enabled. If the item passes pattern and size checks, the file content is retrieved. If download_url is provided, a direct GET request downloads the text; otherwise, the function queries the API item URL, checks that the payload is Base64 encoded, approximates the decoded byte size (len * 0.75), and decodes the string into files[rel_path].

    Phase 3: Directory Filtering and Recursion

                elif item["type"] == "dir":
                # Check if directory should be excluded before recursing
                dir_excluded = False
                dir_reason = None

                if gitignore_spec and gitignore_spec.match_file(rel_path):
                    dir_excluded = True
                    dir_reason = get("CRAWL_REASON_GITIGNORE")

                if not dir_excluded and exclude_patterns:
                    dir_name = item["name"]  # basename of the directory
                    for pattern in exclude_patterns:
                        dir_pattern = pattern.removesuffix("/*")
                        if (
                            fnmatch.fnmatch(item_path, dir_pattern)
                            or fnmatch.fnmatch(rel_path, dir_pattern)
                            or fnmatch.fnmatch(dir_name, dir_pattern)
                        ):
                            dir_excluded = True
                            dir_reason = get("CRAWL_REASON_EXCLUDED")
                            break

                if dir_excluded:
                    api_counters["entry"] += 1
                    api_counters["excluded"] += 1
                    emit("CRAWL_DIR_EXCLUDED", num=api_counters["entry"], path=rel_path, reason=dir_reason)
                    continue

                # Only recurse if directory is not excluded
                fetch_contents(item_path)

        return None

    When an item's type is "dir", the function determines whether the directory is ignored by the compiled gitignore_spec or matches any pattern in exclude_patterns. Patterns ending with /* have that suffix stripped using .removesuffix("/*"), and are compared against the full path, relative path, and directory basename. If the directory is marked for exclusion, traversal skips the entire subtree; otherwise, it recursively invokes fetch_contents(item_path).

    Internal API Traversal Telemetry

    Internal integer tracking schema maintained in the api_counters dictionary during remote REST traversal.

    Field Type Description
    processed int Number of files retrieved and stored in files.

    Error Handling

    The module handles errors defensive at multiple layers to prevent incomplete crawls and unhandled exceptions:

    • URL Parsing Validation: The function parses repo_url using urllib.parse.urlparse. If the path segments contain fewer than two elements (owner and repo name), it raises a ValueError(f"Invalid GitHub URL: {repo_url}").
    • API Rate Limiting: REST requests check for HTTP status codes 403 and 429. If rate limits are encountered on an unauthenticated connection, the crawler raises an Exception notifying the user to set GITHUB_TOKEN. On authenticated connections, it reads the X-RateLimit-Reset header, logs a warning message, and sleeps until the limit window resets before retrying.
    • Missing or Private Repositories (HTTP 404): When handling 404 status codes, the crawler inspects the authentication state. For unauthenticated calls, it notifies the user that the repository may be private and requires a token. When a specific branch (such as main) returns 404, it suggests specifying an alternate branch (such as master).
    • SSH Clone Resilience: Failures during git.Repo.clone_from are caught within a general except Exception as e block. The error is emitted via emit_raw("ERROR", ...) and the function returns early with an empty files map and the exception string recorded under stats["error"].
    • Binary File Filtering: When reading local files in SSH mode, reading is wrapped in try...except (UnicodeDecodeError, ValueError). Non-text and binary payloads are skipped, logged via emit("CRAWL_FILE_NOT_TEXT", ...), and tracked in the skipped_non_text_list.
