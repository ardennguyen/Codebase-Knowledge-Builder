    mkdocs.py

    Source: utils/mkdocs.py

    Technical Overview

    The utils/mkdocs.py module serves as the central documentation publishing, site generation, and navigation layout engine for the Codebase Knowledge Builder pipeline. It consolidates configuration synthesis, directory-aware and LLM-assisted navigation clustering, Markdown link normalization, cross-chapter dependency indexing, and post-generation site auditing. The module bridges the gap between raw, AI-generated chapter content and a production-ready static documentation website built on Material for MkDocs. It supports both structured multi-page documentation sites (under --mkdocs) and monolithic standalone single-folder Markdown packages.

    Architecturally, the module operates during the pipeline's combination and finalization phase. For API reference documentation, it ingests verified module facts and chapter briefs, optionally prompts an LLM to organize modules into architectural tiers (roles such as types, setup, core, support, and operational), and deterministically groups files within those tiers by repository directory structure. It synthesizes a complete mkdocs.yml configuration configured with PyMDown extensions, generates client-side JavaScript overrides for Mermaid diagram pan-and-zoom interactivity, and compiles an interactive landing page featuring top-level section maps and comprehensive module dependency graphs.

    Finally, the module enforces structural integrity and cross-platform reliability across documentation pages. It normalizes all relative markdown links against filesystem depths, appends deterministic **Used by:** citation lines derived from static code facts, deletes obsolete or orphaned .md files using filesystem device-and-inode identity tracking, and executes a non-destructive verification pass via utils.chapter_check.run_chapter_check using an isolated in-memory Markdown compiler matching the generated site's configuration.

    Public API

    MERMAID_INIT_JS

    Visibility: Public

    Signature: MERMAID_INIT_JS = """..."""

    Description: JavaScript snippet embedded into docs/javascripts/mermaid-init.js. It customizes the initialization of Mermaid.js within Material for MkDocs. Material applies proprietary CSS color overrides to elements bearing the .mermaid class; this script targets .mermaid-raw (generated by pymdownx.superfences) so diagrams render using Mermaid's default styling (yellow subgraph containers and lavender nodes). In dark mode ([data-md-color-scheme="slate"]), it dynamically inserts a CSS style rule that wraps diagrams in a light background card so dark gray edge connectors remain visible. It initializes diagrams on DOM completion and suppresses uncaught rendering exceptions to prevent console noise.

    GROUPING_ATTEMPTS

    Visibility: Public

    Signature: GROUPING_ATTEMPTS = 3

    Description: The maximum number of retry attempts permitted for the group_modules LLM invocation. LLM streaming timeouts or incomplete outputs during reasoning-heavy grouping must not fail the downstream site assembly.

    GROUPING_WAIT

    Visibility: Public

    Signature: GROUPING_WAIT = 20

    Description: The backoff duration in seconds between consecutive failed grouping requests.

    SECTION_ROLES

    Visibility: Public

    Signature: SECTION_ROLES = ("types", "setup", "core", "support", "operational")

    Description: Canonical tuple defining the sequential reading order for top-level documentation sections. Navigational sections tagged with these roles are sorted deterministically so that fundamental domain vocabulary comes first, followed by setup/initialization, primary runtime engines, utility helpers, and cross-cutting operational concerns.

    Visibility: Public

    Returns:

    Example:

    # Real usage from mkdocs.py: quoting site names and nav labels

    build_chapter_filenames()

    Visibility: Public

    Signature: def build_chapter_filenames(chapter_order: list, abstractions: list, is_mkdocs: bool) -> dict:

    Description: Generates an authoritative mapping between ordered chapter indices and their final Markdown output filenames. This function is shared between chapter drafting (WriteChapters) and final document combination (CombineTutorial) to guarantee link target consistency. When is_mkdocs is true and an abstraction defines an original_path, it mirrors the repository's relative source path; otherwise, it sanitizes the abstraction name into an alphanumeric slug. For standalone output modes, it prepends zero-padded two-digit sequence numbers (NN_name.md). It prevents case-insensitive collisions and reserves index.md (and directory-level README.md) by appending incrementing numeric suffixes (e.g., _2.md).

    Parameters:

    • chapter_order (list): Ordered integer indices referencing entries in abstractions.
    • abstractions (list): Sequence of abstraction dictionaries containing names and optional original_path keys.
    • is_mkdocs (bool): Flag indicating whether MkDocs path conventions apply.

    Returns:

    • dict[int, str]: Mapping of chapter position index to relative Markdown filename.

    Example:

    # Real implementation logic from mkdocs.py
filenames = {}
used = {"index.md"}
for i, abstraction_index in enumerate(chapter_order):
    if not 0 <= abstraction_index < len(abstractions):
        continue
    abstraction = abstractions[abstraction_index]
    if is_mkdocs and abstraction.get("original_path"):
        base = abstraction["original_path"].replace(os.sep, "/")
    else:
        chapter_name = abstraction["name"].replace("\n", " ").strip()
        safe_name = "".join(c if c.isalnum() else "_" for c in chapter_name).lower()
        base = safe_name if is_mkdocs else f"{i + 1:02d}_{safe_name}"
    filename, suffix = f"{base}.md", 2
    while page_key(filename) in used:
        filename, suffix = f"{base}_{suffix}.md", suffix + 1
    used.add(page_key(filename))
    filenames[i] = filename

    split_frontmatter()

    Visibility: Public

    Signature: def split_frontmatter(text: str) -> tuple[str, bool]:

    Description: Detects and strips a leading YAML frontmatter block from a Markdown text document. It utilizes _FRONTMATTER_RE to match triple-hyphen delimiters. To ensure semantic fidelity with MkDocs, it parses the matched block using yaml.safe_load; only blocks that successfully evaluate to a Python dictionary are stripped. If the block fails YAML validation or evaluates to a scalar (such as a horizontal rule followed by text), the text remains unmutated.

    Parameters:

    • text (str): Raw Markdown source text.

    Returns:

    • tuple[str, bool]: A pair containing the remaining Markdown body string and a boolean flag indicating whether valid frontmatter was found and removed.

    Example:

    # Real implementation logic from mkdocs.py
match = _FRONTMATTER_RE.match(text)
if match:
    try:
        if isinstance(yaml.safe_load(match.group(1)), dict):
            return text[match.end() :].strip(), True
    except Exception:
        pass
return text, False

    clip_sentences()

    Visibility: Public

    Signature: def clip_sentences(text: str, limit: int) -> str:

    Description: Truncates prose text to a maximum character length while preserving whole sentences and typographic integrity. Whitespace is collapsed into single spaces. Sentences are parsed via _sentences(). If the cumulative text exceeds limit, processing breaks at the last completed sentence. If even the first sentence exceeds limit, the text is truncated at the nearest preceding whitespace boundary (or exact character count for non-spaced CJK text), unclosed inline code backticks are balanced, and an ellipsis (…) is appended.

    Parameters:

    • text (str): The prose string to clip.
    • limit (int): Maximum allowed character length.

    Returns:

    • str: Clipped string conforming to sentence or word boundaries.

    Example:

    # Real implementation logic from mkdocs.py
text = " ".join(text.split())
if len(text) <= limit:
    return text
clipped = ""
for sentence in _sentences(text):
    separator = "" if not clipped or clipped.endswith(_CJK_STOPS) else " "
    candidate = f"{clipped}{separator}{sentence}"
    if len(candidate) > limit:
        break
    clipped = candidate
if not clipped:
    clipped = text[:limit].rsplit(" ", 1)[0].rstrip(",;:—\u2013- ")
    if clipped.count("`") % 2:
        clipped += "`"
    clipped += "…"
return clipped

    table_cell_text()

    Visibility: Public

    Signature: def table_cell_text(text: str) -> str:

    Description: Escapes pipe characters (| to \|) for inclusion in Markdown table cells while preserving pipes inside inline code spans. Markdown table parsers treat pipes inside backtick code spans literally; escaping them inside code spans would corrupt type expressions like str | None. This function uses _CODE_SPAN_RE to segment the string, escaping pipes strictly within prose segments.

    Parameters:

    • text (str): The cell text to escape.

    Returns:

    • str: Table-safe escaped text string.

    Example:

    # Real implementation logic from mkdocs.py
parts, position = [], 0
for match in _CODE_SPAN_RE.finditer(text):
    parts.append(text[position : match.start()].replace("|", "\\|"))
    parts.append(match.group(0))
    position = match.end()
parts.append(text[position:].replace("|", "\\|"))
return "".join(parts)

    module_name_lookup()

    Visibility: Public

    Signature: def module_name_lookup(chapter_files: list) -> dict:

    Description: Compiles a resilient resolution dictionary mapping possible module identifiers to their canonical module_name. In LLM responses, modules may be referenced by exact module name, original repository file path, or bare filename. This helper maps exact names and original_path values unconditionally. If a basename is unique across the entire project, it also registers the bare basename as a valid lookup key.

    Parameters:

    • chapter_files (list): Sequence of chapter metadata dictionaries.

    Returns:

    • dict[str, str]: Mapping from variant name strings to canonical module_name strings.

    Example:

    # Real implementation logic from mkdocs.py
lookup = {}
basename_counts = Counter(os.path.basename(cf.get("original_path") or cf["module_name"]) for cf in chapter_files)
for cf in chapter_files:
    name = cf["module_name"]
    lookup[name] = name
    if cf.get("original_path"):
        lookup.setdefault(cf["original_path"], name)
    basename = os.path.basename(cf.get("original_path") or name)
    if basename_counts[basename] == 1:
        lookup.setdefault(basename, name)
return lookup

    verified_dependencies()

    Visibility: Public

    Signature: def verified_dependencies(module_facts: dict, chapter_files: list) -> dict:

    Description: Extracts the source-verified dependency graph from static AST/regex facts in module_facts. Edges defined in each entry's depends_on list are converted from repository file paths to canonical module names. Self-references and external targets not documented in chapter_files are filtered out.

    Parameters:

    • module_facts (dict): Fact extraction mapping keyed by original file path.
    • chapter_files (list): Sequence of chapter file dictionaries.

    Returns:

    • dict[str, list[str]]: Mapping of source module_name to a list of distinct dependency module_name values.

    Example:

    # Real implementation logic from mkdocs.py
name_of = {cf["original_path"]: cf["module_name"] for cf in chapter_files if cf.get("original_path")}
dependencies = {}
for path, entry in (module_facts or {}).items():
    source = name_of.get(path)
    targets = [name_of[edge["module"]] for edge in entry.get("depends_on", []) if edge.get("module") in name_of]
    targets = [name for name in dict.fromkeys(targets) if name != source]
    if source and targets:
        dependencies[source] = targets
return dependencies

    request_grouping()

    Visibility: Public

    Signature: def request_grouping(prompt: str, prep_res: dict, chapter_files: list) -> tuple[dict, list]:

    Description: Dispatches the group_modules prompt to the configured LLM with bounded retries. Up to GROUPING_ATTEMPTS (3) calls are attempted with a GROUPING_WAIT (20s) pause between failures. The response cache is consulted only on the initial attempt. Responses are parsed via parse_grouping_response() and sanitized through prune_sections(). Non-retryable LLMRefusalError exceptions terminate immediately without retrying, while syntax or validation failures trigger retries until the attempt threshold is exhausted.

    Parameters:

    • prompt (str): Formatted prompt text based on prompts/common/group_modules.md.
    • prep_res (dict): Pipeline execution context containing options like use_cache and thinking_level.
    • chapter_files (list): Complete list of chapter file dictionaries.

    Returns:

    • tuple[dict, list]: A 2-tuple (parsed_reply, pruned_sections).

    Raises:

    • LLMRefusalError: When the model refuses the prompt with retryable=False.
    • ValueError: If the model response yields zero valid sections after pruning.
    • Exception: The final caught error if all retry attempts are exhausted.

    Example:

    # Real implementation logic from mkdocs.py
use_cache = prep_res.get("use_cache", True)
attempt = 1
while True:
    try:
        response = call_llm(prompt, use_cache=use_cache and attempt == 1, thinking_level=prep_res.get("thinking_level"), step="group_modules")
        parsed = parse_grouping_response(response)
        sections = parsed.get("sections", parsed) if isinstance(parsed, dict) else None
        sections = prune_sections(sections, chapter_files) if isinstance(sections, list) else []
        if not sections:
            raise ValueError(get("GROUP_NO_SECTIONS"))
        return (parsed if isinstance(parsed, dict) else {}), sections
    except LLMRefusalError as e:
        if not e.retryable:
            raise
        error = e
    except Exception as e:
        error = e
    if attempt == GROUPING_ATTEMPTS:
        raise error
    emit("GROUP_RETRY", attempt=attempt, attempts=GROUPING_ATTEMPTS, error=error, wait=GROUPING_WAIT)
    time.sleep(GROUPING_WAIT)
    attempt += 1

    order_sections()

    Visibility: Public

    Signature: def order_sections(sections: list, chapter_files: list) -> list:

    Description: Orders section dictionaries into a standardized reading order. Siblings at each hierarchy level are sorted based on their role attribute using SECTION_ROLES. If any sibling at a level lacks a recognized role, the model's original ordering is preserved. Within each section, member modules are grouped by their physical directory based on first appearance, ensuring that the navigation menu, index tables, and architecture diagrams list modules in identical sequences.

    Parameters:

    • sections (list): Hierarchical list of section dictionaries.
    • chapter_files (list): List of chapter dictionaries.

    Returns:

    • list[dict]: New list of section dictionaries sorted into canonical reading order.

    Example:

    # Real implementation logic from mkdocs.py
rank = {role: index for index, role in enumerate(SECTION_ROLES)}
dir_of = {cf["module_name"]: os.path.dirname(cf.get("original_path") or "") for cf in chapter_files}

def role_rank(section):
    return rank.get(str(section.get("role", "")).strip().lower())

def ordered(level):
    level = [dict(section) for section in level]
    for section in level:
        modules = section.get("modules") or []
        dirs = list(dict.fromkeys(dir_of.get(name, "") for name in modules))
        section["modules"] = [name for dir_path in dirs for name in modules if dir_of.get(name, "") == dir_path]
        if section.get("children"):
            section["children"] = ordered(section["children"])
    if all(role_rank(section) is not None for section in level):
        level.sort(key=role_rank)
    return level

return ordered(sections)

    Visibility: Public

    Signature: def prune_stale_pages(api_docs_path, chapter_files):

    Description: Deletes orphaned Markdown files and empty directories beneath docs/api/ that do not correspond to any active chapter.     • None

def identity(path):
    st = os.stat(path)
    return st.st_dev, st.st_ino

keep = set()
for filename in ["index.md", *(cf["filename"] for cf in chapter_files)]:
    path = os.path.join(api_docs_path, filename)
    if os.path.exists(path):
        keep.add(identity(path))
for root, _dirs, files in os.walk(api_docs_path, topdown=False):
    for name in files:
        path = os.path.join(root, name)
        if name.endswith(".md") and identity(path) not in keep:
            os.remove(path)
            emit("MKDOCS_PRUNED_STALE", path=path)
    if os.path.normcase(root) != os.path.normcase(api_docs_path) and not os.listdir(root):

    Description: Determines whether a candidate text segment ends with a known whole-word abbreviation from _ABBREVIATIONS.     _section_members()

    Visibility: Private

    Signature: def _section_members(sections: list) -> list[tuple[str, list]]:

    Description: Flattens a nested section tree into a list of top-level sections paired with their recursive module members. If a module is declared across multiple sections, it is assigned strictly to the first section encountered.

    Parameters:

    • sections (list): Hierarchical section tree.

    Returns:

    • list[tuple[str, list[str]]]: Sequence of (section_name, [module_names]) tuples.

    Example:

    # Real implementation logic from mkdocs.py
owned = set()

def modules_of(section):
    found = list(section.get("modules", []))
    for child in section.get("children", []):
        found += modules_of(child)
    return found

groups = []
for section in sections:
    members = []
    for name in modules_of(section):
        if name not in owned:
            owned.add(name)
            members.append(name)
    groups.append((section["name"], members))
return groups

    Error Handling

    • LLM Grouping Failure and Refusal: In request_grouping(), invocations are trapped inside a bounded retry loop (up to 3 attempts with 20-second pauses). If an LLMRefusalError occurs with retryable=False, the exception is re-raised immediately without retrying. Other runtime or JSON parsing exceptions trigger retries. If all attempts fail, write_mkdocs_output() catches the terminal exception, emits a diagnostic log (GROUP_ERROR_FALLBACK), and falls back to deterministic filesystem directory grouping via directory_sections().
    • Empty Section Pruning: prune_sections() removes empty sections (sections where all module names are unrecognized or left empty) from the hierarchy. This prevents null nav entries (- "Name":) from being written to mkdocs.yml, which would cause mkdocs build to fail with Expected nav to be a list, got None.
    • Zero Valid Sections: If grouping parses successfully but prune_sections() eliminates all sections, request_grouping() raises a ValueError(get("GROUP_NO_SECTIONS")) to trigger retry or fallback.
    • Frontmatter Stripping Resilience: split_frontmatter() wraps YAML parsing in an exception guard. If a leading block bounded by --- fails YAML parsing (e.g., syntax errors or invalid date formats like 2024-02-30), the error is discarded and the text is preserved unmodified.
    • Missing Markdown Extensions: site_renderer() attempts to dynamically load markdown and configure the extensions declared in mkdocs.yml. If the required libraries are missing, it emits CHAPTER_CHECK_NO_RENDERER and returns None, allowing callers to skip Markdown compilation gracefully.
