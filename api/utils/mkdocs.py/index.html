    mkdocs.py

    Source: utils/mkdocs.py

    Technical Overview

    The mkdocs.py module serves as the centralized static documentation generation and artifact serialization engine for the Codebase-Knowledge-Builder architecture. It consolidates site configuration generation, navigation assembly, architecture overview diagramming, cross-chapter link normalization, and output writing. Positioned at the culmination of the documentation pipeline, this module transforms synthesized chapter payloads, extracted code facts, and LLM-derived abstractions into production-ready MkDocs Material static documentation sites or self-contained standalone Markdown bundles.

    The module operates across two distinct generation modes: --mkdocs site compilation and standalone Markdown assembly. For MkDocs generation, it crafts a full mkdocs.yml configuration configured with the Material theme, dark/light palette toggles, code copy buttons, search, and a pan-zoom extension tailored for interactive Mermaid diagrams. In api-reference mode, the module employs an LLM-assisted grouping workflow with deterministic fallbacks to cluster modules into logical reading-order tiers (types, setup, core, support, operational). It cross-references source-verified AST edges from facts.json to generate top-level architecture overview maps, complete module dependency graphs, and dedicated fan-in diagrams for shared architectural hubs.

    To guarantee rendering fidelity and factual integrity across varied CommonMark parsers, mkdocs.py incorporates an automated, render-verified markup repair pipeline. This subsystem detects and repairs malformed Markdown constructs—such as tables or lists rendered as raw prose text due to missing boundary blank lines, or un-indented nested sub-lists—by running candidate transformations through an isolated Markdown rendering engine to ensure that visible text and code blocks remain invariant. Finally, the module performs case-safe stale file pruning via filesystem device and inode tracking, normalizes all internal cross-chapter hyperlinks relative to nested directory structures, and invokes deterministic quality-assurance auditing through chapter_check.py.

    yaml_str()

    Visibility: Public

    Signature: def yaml_str(value) -> str:

    Description: Serializes any scalar value into a valid YAML string literal by leveraging json.dumps with ensure_ascii=False. Because JSON string literals represent valid YAML double-quoted scalars, this prevents structural corruption in generated YAML files (mkdocs.yml, nav_snippet.yml) when titles, labels, or paths contain special metacharacters such as colons, apostrophes, square brackets, quotes, or leading @ symbols.

    Parameters:

    • value (Any): The scalar value to serialize as a YAML string.

    Returns:

    • str: A double-quoted string literal safe for inclusion in YAML configurations.

    Example:

    # Quoting a navigation section title containing colons and brackets
label = yaml_str("Core [Service]: Accounting & Billing")
# Output: '"Core [Service]: Accounting & Billing"'

    build_mkdocs_config()

    Visibility: Public

    Signature: def build_mkdocs_config(site_name: str, nav_yaml: str, include_home: bool = True, lang_code: str = "") -> str:

    Description: Programmatically constructs the complete mkdocs.yml configuration file for the static documentation build. Configures the Material theme, syntax highlighting through pymdownx.highlight, inline code highlighting (pymdownx.inlinehilite), and custom Mermaid diagram fences (pymdownx.superfences) emitting <div class="mermaid-raw"> to isolate diagrams from Material's CSS palette overrides. It sets up the panzoom plugin for interactive diagram zooming, registers dark and light theme toggles, injects localized UI settings, and integrates the compiled navigation hierarchy.

    Parameters:

    • site_name (str): The display title of the static documentation site.
    • nav_yaml (str): Pre-formatted YAML lines containing the site navigation tree.
    • include_home (bool, optional): Whether to inject a Home entry pointing to index.md. Defaults to True.
    • lang_code (str, optional): Two-letter ISO language code for UI localization (e.g., "fr", "vi"). Defaults to "".

    Returns:

    • str: The complete text content of mkdocs.yml.

    Example:

    config = build_mkdocs_config(
    site_name="My Project — API Reference",
    nav_yaml="nav:\n  - API:\n    - api/index.md\n",
    include_home=True,
    lang_code="vi"
)

    build_chapter_filenames()

    Visibility: Public

    Signature: def build_chapter_filenames(chapter_order: list, abstractions: list, is_mkdocs: bool) -> dict:

    Description: Computes deterministic filenames for all generated documentation chapters. For MkDocs builds where abstractions provide an original_path (such as in api-reference mode), the source path is mirrored with an appended .md extension; otherwise, sanitized lowercase names are used. For standalone output modes, chapters receive a zero-padded index prefix (01_name.md). To prevent accidental page collisions on case-insensitive filesystems or overwriting generated index pages, filenames are evaluated through case-folded keys, mapping directory-level readme.md files to index.md, and appending incrementing numeric suffixes (_2.md, _3.md) when collisions occur.

    Parameters:

    • chapter_order (list): Ordered abstraction indices representing the sequence of chapters.
    • abstractions (list): List of abstraction metadata dictionaries containing name and path specifications.
    • is_mkdocs (bool): Flag indicating whether output targets an MkDocs site structure.

    Returns:

    • dict[int, str]: Mapping of chapter position index to the resolved relative output filename.

    Example:

    filenames = build_chapter_filenames(
    chapter_order=[0, 1],
    abstractions=[
        {"name": "App Flow", "original_path": "flow.py"},
        {"name": "Nodes", "original_path": "nodes.py"}
    ],
    is_mkdocs=True
)
# Result: {0: 'flow.py.md', 1: 'nodes.py.md'}

    clip_sentences()

    Visibility: Public

    Signature: def clip_sentences(text: str, limit: int) -> str:

    Description: Collapses internal whitespace and truncates prose text to a maximum character threshold while strictly preserving sentence boundaries. It iterates through extracted sentences, appending complete sentences until the limit is reached. If even the first sentence exceeds the specified character limit, the text is sliced cleanly at a preceding word boundary, trailing punctuation is stripped, unclosed code spans (backticks) are balanced, and an ellipsis (…) is appended.

    Parameters:

    • text (str): Input text to truncate.
    • limit (int): Maximum allowable character count.

    Returns:

    • str: Formatted, sentence-bounded text constrained within the specified character ceiling.

    Example:

    snippet = clip_sentences("First sentence. Second sentence goes here.", 20)
# Result: "First sentence."

      • hub_threshold: The integer threshold used to classify hub nodes (0 if no hubs were found).

    Example:

    graph_src, threshold = build_module_graph(sections, dependencies, chapter_files)

    def request_grouping(prompt: str, prep_res: dict, chapter_files: list) -> tuple[dict, list]:
    use_cache = prep_res.get("use_cache", True)
    attempt = 1
    while True:
        try:
            response = call_llm(prompt, use_cache=use_cache and attempt == 1, thinking_level=prep_res.get("thinking_level"), step="group_modules")
            parsed = parse_grouping_response(response)
            sections = parsed.get("sections", parsed) if isinstance(parsed, dict) else None
            # Drop unknown module names and the sections they leave empty (null nav entries break mkdocs build)
            sections = prune_sections(sections, chapter_files) if isinstance(sections, list) else []
            if not sections:
                raise ValueError(get("GROUP_NO_SECTIONS"))
            return (parsed if isinstance(parsed, dict) else {}), sections
        except LLMRefusalError as e:
            if not e.retryable:
                raise
            error = e
        except Exception as e:
            error = e
        if attempt == GROUPING_ATTEMPTS:
            raise error
        emit("GROUP_RETRY", attempt=attempt, attempts=GROUPING_ATTEMPTS, error=error, wait=GROUPING_WAIT)
        time.sleep(GROUPING_WAIT)
        attempt += 1

    Visibility: Public

    Signature: def normalize_chapter_links(chapter_files):

    Description: Deterministically post-processes and rewrites cross-chapter Markdown links ([text](target.md)) throughout all chapter contents. It compiles an authoritative filename lookup table, including unique basename aliases. For each link, it computes the exact relative path from the linking chapter's directory to the target chapter's directory, pinning targets with ./ when a relative path could collide with a root-level page.

    def normalize_chapter_links(chapter_files):
    filenames = [cf["filename"] for cf in chapter_files]
    filename_lookup = {fname: fname for fname in filenames}
    basename_counts = Counter(fname.rsplit("/", 1)[-1] for fname in filenames)
    for fname in filenames:
        basename = fname.rsplit("/", 1)[-1]
        if basename_counts[basename] == 1 and basename not in filename_lookup:
            filename_lookup[basename] = fname

    link_pattern = re.compile(r"\[([^\]]*)\]\(([^)#]+\.md)(#[^)]*)?\)")
    fixed_count = 0

    for cf in chapter_files:
        current_dir = os.path.dirname(cf["filename"])  # e.g. "CoreService"

        def fix_link(match, _dir=current_dir):
            nonlocal fixed_count
            text, target, anchor = match.group(1), match.group(2), match.group(3) or ""
            if target.startswith(("http://", "https://")):
                return match.group(0)
            canonical = filename_lookup.get(target)
            if not canonical:
                resolved = os.path.normpath(os.path.join(_dir, target)).replace("\\", "/")
                canonical = filename_lookup.get(resolved)
            if canonical:
                correct_rel = os.path.relpath(canonical, _dir).replace("\\", "/") if _dir else canonical
                if _dir and filename_lookup.get(correct_rel, canonical) != canonical:
                    correct_rel = f"./{correct_rel}"
                if correct_rel != target:
                    fixed_count += 1
                return f"[{text}]({correct_rel}{anchor})"
            return match.group(0)

        cf["content"] = link_pattern.sub(fix_link, cf["content"])

    if fixed_count:
        emit_raw("DEBUG", f"LINK NORMALIZATION | fixed {fixed_count} cross-chapter links", dest="LOG")

    The algorithm operates independently of chapter iteration order by indexing all known full paths before creating single-occurrence basename aliases. External URLs (http://, https://) and unresolvable targets are left unmodified. Fixed links that were altered are counted and reported to the debug logging sink via emit_raw().

    Visibility: Private

    Signature: def _repair(lines: list[str], kind: str, finding: dict) -> list[str]:

    Description: Applies a specific formatting repair transformation to a list of lines. For lists_as_text or tables_as_text, it inserts a blank line (or blockquote marker >) preceding the element. For lists_flattened, it shifts the nested list block rightward by 4 spaces past its parent item, shifting enclosed fenced code blocks as intact units while leaving lines containing literal tabs untouched.

    def _repair(lines: list[str], kind: str, finding: dict) -> list[str]:
    index = finding["line"] - 1
    if kind in ("lists_as_text", "tables_as_text"):
        if index == 0 or not lines[index - 1].strip():
            return lines
        quote = re.match(r"^(?: {0,3}> ?)+", lines[index])
        return [*lines[:index], quote.group(0).rstrip() if quote else "", *lines[index:]]
    indent = _indent_of(lines[index])
    parent = next((line for line in reversed(lines[:index]) if line.strip() and _indent_of(line) < indent), None)
    if parent is None or _indent_of(parent) + 4 <= indent:
        return lines
    end = _flattened_run(lines, index)
    if any("\t" in line[: len(line) - len(line.lstrip())] for line in lines[index:end]):
        return lines
    repaired = list(lines)
    levels = []
    fence = None
    for position in range(index, end):
        line = lines[position]
        if fence:
            if line.strip():
                repaired[position] = " " * fence[1] + line
            if fence[0].match(line):
                fence = None
            continue
        if not line.strip():
            continue
        old = _indent_of(line)
        item = _ITEM_START_RE.match(line.expandtabs(4))
        if item:
            while levels and old <= levels[-1][0]:
                levels.pop()
            new = levels[-1][1] + 4 if levels else _indent_of(parent) + 4
            spaces = len(item.group(3))
            levels.append((old, new, item.end(2) + (spaces if 1 <= spaces <= 4 else 1)))
            shift = new - old
        else:
            while levels and old < levels[-1][2]:
                levels.pop()
            shift = levels[-1][1] + 4 - levels[-1][2] if levels else 0
            opener = _FENCE_LINE_RE.match(line)
            if opener:
                fence = (re.compile(rf"^\s*{re.escape(opener.group(1)[0])}{{{len(opener.group(1))},}}\s*$"), max(shift, 0))
        if shift > 0:
            repaired[position] = " " * shift + line
    return repaired

    Error Handling

    • LLM Refusal Interception: In request_grouping(), errors from call_llm() are inspected for LLMRefusalError. If an error is flagged as non-retryable (e.retryable is False), the retry loop is bypassed and the error re-raised immediately to prevent wasting API tokens on deterministic safety rejections.
    • Bounded Grouping Retries: The LLM grouping pipeline retries transient failures (such as network drops or unparsable model outputs) up to GROUPING_ATTEMPTS (3) times with a GROUPING_WAIT (20s) delay. If all attempts are exhausted or the returned sections contain no resolvable modules, request_grouping() raises a ValueError, prompting write_mkdocs_output() to log the traceback and fall back to directory-based sections.
    • Markup Repair Safety Invariants: The repair_markup() function guards all text transformations against corruption. A repair candidate is discarded if visible non-whitespace characters change (_visible()), if dedented code blocks change (_code_blocks()), if CommonMark token readings diverge, or if previously valid markup elements regress.
    • Case-Safe Pruning: Stale file pruning in prune_stale_pages() uses filesystem device and inode numbers (os.stat(path).st_dev, st_ino) rather than filename strings. This ensures that case-only file renames on case-insensitive filesystems (such as macOS or Windows) do not delete active files.
    • Defensive Frontmatter Parsing: split_frontmatter() wraps PyYAML execution in a general exception trap. Documents containing invalid YAML syntax or invalid dates (e.g., 2024-02-30) fall back gracefully to preserving the original text rather than raising runtime errors.
    • Missing Renderer Degradation: If markdown or its third-party extensions are missing, site_renderer() emits a CHAPTER_CHECK_NO_RENDERER telemetry event and returns None. Downstream processes check for None and skip markup repairs and rendered audits without crashing.
