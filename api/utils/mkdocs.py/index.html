    mkdocs.py

    Source: utils/mkdocs.py

    Technical Overview

    Following the Large Language Model provider execution harnesses such as utils/llm_openrouter.py, the utils/mkdocs.py module acts as the downstream static site compilation, structural organization, and filesystem persistence engine of the pipeline. While the LLM inference layers generate decoupled markdown chapters and chapter-level abstractions, mkdocs.py orchestrates the conversion of these discrete text artifacts into a cohesive, production-ready static documentation website powered by MkDocs Material, or alternatively into a consolidated standalone Markdown archive.

    The module provides full lifecycle management for documentation generation. It constructs strict MkDocs configurations (mkdocs.yml) equipped with search, code copy capabilities, custom-themed Mermaid diagram renderers, and panzoom interactivity. For complex API reference projects containing numerous modules, it optionally engages an LLM-driven semantic clustering pipeline to group source files into logical sections and sub-packages. Furthermore, it enforces deterministic post-processing routines that sanitize YAML strings, normalize cross-chapter Markdown hyperlinks across nested directories, and prune stale files from previous compilation passes using filesystem inode identity matching.

    The function strips the root nav: key from the input YAML snippet to allow clean indentation nesting under the global nav: block. It configures the pymdownx.superfences extension using fence_div_format to emit <div class="mermaid-raw"> wrappers for diagrams instead of default preformatted code blocks. This naming convention explicitly bypasses Material for MkDocs' internal color scheme overrides while permitting the panzoom plugin to bind to the outer <div>.

    build_chapter_filenames()

    Visibility: Public Signature: def build_chapter_filenames(chapter_order: list, abstractions: list, is_mkdocs: bool) -> dict:

    Description: Derives a collision-resistant mapping between sequential chapter indexes and their corresponding target Markdown filenames. It ensures parity between chapter drafting nodes (which generate cross-references) and aggregation nodes (which write files to disk).

    Parameters: * chapter_order (list[int]): List of integer indices referencing entries in abstractions. * abstractions (list[dict]): List of abstraction metadata dictionaries containing module names, descriptions, and optional paths. * is_mkdocs (bool): Flag indicating whether output targets an MkDocs directory structure (mirroring source paths) or a standalone bundle (prefixing zero-padded numbers).

    Returns: * dict[int, str]: Mapping of chapter position index to relative Markdown filename (e.g., {0: "utils/files.py.md"}).

    Raises: * None. Out-of-bounds indices in chapter_order are safely bypassed.

    Example: 

    # Extracted from build_chapter_filenames implementation in utils/mkdocs.py
filenames = build_chapter_filenames(chapter_order, abstractions, is_mkdocs=True)
# Result: {0: 'index.md', 1: 'call_llm.py.md', 2: 'crawl_github_files.py.md'}

    The implementation prevents filename collisions and directory index collisions:

    def build_chapter_filenames(chapter_order: list, abstractions: list, is_mkdocs: bool) -> dict:
    def page_key(filename):
        directory, basename = posixpath.split(filename.lower())
        return posixpath.join(directory, "index.md") if basename == "readme.md" else filename.lower()

    filenames = {}
    used = {"index.md"}
    for i, abstraction_index in enumerate(chapter_order):
        if not 0 <= abstraction_index < len(abstractions):
            continue
        abstraction = abstractions[abstraction_index]
        if is_mkdocs and abstraction.get("original_path"):
            base = abstraction["original_path"].replace(os.sep, "/")
        else:
            chapter_name = abstraction["name"].replace("\n", " ").strip()
            safe_name = "".join(c if c.isalnum() else "_" for c in chapter_name).lower()
            base = safe_name if is_mkdocs else f"{i + 1:02d}_{safe_name}"
        filename, suffix = f"{base}.md", 2
        while page_key(filename) in used:
            filename, suffix = f"{base}_{suffix}.md", suffix + 1
        used.add(page_key(filename))
        filenames[i] = filename
    return filenames

    The internal page_key() helper normalizes paths to lowercase and treats any file named readme.md as equivalent to index.md, reflecting MkDocs' internal directory index convention. If an abstraction produces a filename that collides with an existing page or reserved index in a case-insensitive manner, an incrementing integer suffix (_2.md, _3.md) is appended.

    def split_frontmatter(text: str) -> tuple[str, bool]:
    match = _FRONTMATTER_RE.match(text)
    if match:
        try:
            if isinstance(yaml.safe_load(match.group(1)), dict):
                return text[match.end() :].strip(), True
        except Exception:  # like MkDocs: YAMLError, or e.g. ValueError from an impossible date (2024-02-30)
            pass
    return text, False

    The function matches against _FRONTMATTER_RE, verifying that the block is delimited by triple hyphens (---) or dots (...). A block is stripped only if yaml.safe_load successfully parses the content into a Python dict. If a file begins with horizontal rules or non-dictionary YAML, the entire text remains unaltered.

    normalize_chapter_links()

    Visibility: Public Signature: def normalize_chapter_links(chapter_files: list) -> None:

    Description: Performs deterministic cross-chapter link rewriting across all generated Markdown files. It builds a global path lookup table and updates relative link paths so that links between chapters resolve accurately regardless of directory depth.

    Parameters: * chapter_files (list[dict]): In-memory list of chapter objects containing module_name, filename, and mutable content.

    Returns: * None: Mutates the content field of entries inside chapter_files in place.

    Raises: * None.

    The function executes across two distinct logical phases:

    Phase 1: Canonical Filename Lookup and Alias Construction

        # Build lookup: every full path first (e.g. "CoreService/AccountingService.cs.md"), then a bare-basename
    # alias only for basenames that occur once and are not themselves a full path, so an alias can never
    # shadow or remove a real file (the result no longer depends on chapter order).
    filenames = [cf["filename"] for cf in chapter_files]
    filename_lookup = {fname: fname for fname in filenames}
    basename_counts = Counter(fname.rsplit("/", 1)[-1] for fname in filenames)
    for fname in filenames:
        basename = fname.rsplit("/", 1)[-1]
        if basename_counts[basename] == 1 and basename not in filename_lookup:
            filename_lookup[basename] = fname

    Phase 1 establishes a deterministic resolution map. It records every explicit full path and computes frequency counts for bare basenames using collections.Counter. Unambiguous basenames occurring exactly once are mapped as aliases pointing to the full relative path, preventing LLM-generated shorthand links from breaking while guaranteeing that identical basenames across distinct subdirectories do not accidentally collide.

    Phase 2: Link Extraction and Relative Path Rewriting

        link_pattern = re.compile(r"\[([^\]]*)\]\(([^)#]+\.md)(#[^)]*)?\)")
    fixed_count = 0

    for cf in chapter_files:
        current_dir = os.path.dirname(cf["filename"])  # e.g. "CoreService"

        def fix_link(match, _dir=current_dir):
            nonlocal fixed_count
            text, target, anchor = match.group(1), match.group(2), match.group(3) or ""
            if target.startswith(("http://", "https://")):
                return match.group(0)
            # Try resolving the target as-is (LLM copied verbatim from index)
            canonical = filename_lookup.get(target)
            if not canonical:
                # Try resolving relative to current dir
                resolved = os.path.normpath(os.path.join(_dir, target)).replace("\\", "/")
                canonical = filename_lookup.get(resolved)
            if canonical:
                correct_rel = os.path.relpath(canonical, _dir).replace("\\", "/") if _dir else canonical
                # Cached pages are normalized again on later runs, where a page-relative target that is also
                # another chapter's root-relative path would be read as that chapter: pin it with "./".
                if _dir and filename_lookup.get(correct_rel, canonical) != canonical:
                    correct_rel = f"./{correct_rel}"
                if correct_rel != target:
                    fixed_count += 1
                return f"[{text}]({correct_rel}{anchor})"
            return match.group(0)  # Unknown target — leave as-is

        cf["content"] = link_pattern.sub(fix_link, cf["content"])

    if fixed_count:
        emit_raw("DEBUG", f"LINK NORMALIZATION | fixed {fixed_count} cross-chapter links", dest="LOG")

    Phase 2 uses regular expressions to find all Markdown link targets terminating in .md (preserving optional fragment anchors). It ignores external HTTP/HTTPS protocols, resolves the destination through the lookup table or current directory context, and recalculates the relative path using os.path.relpath. It pins relative paths using ./ when ambiguity with a root-relative page would arise on subsequent passes, logging the count of modified links to the diagnostic log.

    strip_summary_header()

    Visibility: Internal Signature: def strip_summary_header(summary: str) -> str:

    Description: Strips leading chapter heading markers generated by chapter drafting stages (e.g., <Chapter> 1 — Name:).

    Parameters: * summary (str): Raw summary text associated with a chapter.

    Returns: * str: Summary text with the first header line removed.

    Raises: * None.

    def strip_summary_header(summary: str) -> str:
    """Drop the ``<Chapter> N — name:`` first line that WriteChapters puts on every chapter summary."""
    first, sep, rest = summary.partition("\n")
    if sep and _SUMMARY_HEADER_RE.match(first.strip()):
        return rest.strip()
    return summary.strip()

    The function splits the summary text across the first newline character. If the first line matches the regular expression _SUMMARY_HEADER_RE (r"^.+ \d+ — .+:$"), it discards the line and returns the remaining text. If the pattern is not matched, the original stripped text is returned.

    summary_description()

    Visibility: Internal Signature: def summary_description(summary: str, limit: int = 200) -> str:

    Description: Formats chapter summaries into single-line descriptions suitable for Markdown table cells.

    Parameters: * summary (str): Full chapter summary text. * limit (int): Maximum character length before truncation. Defaults to 200.

    Returns: * str: Cleaned, single-line description text capped at limit characters.

    Raises: * None.

    def summary_description(summary: str, limit: int = 200) -> str:
    text = _SUMMARY_LABEL_RE.sub("", strip_summary_header(summary), count=1)
    text = " ".join(text.split()).replace("|", "—")
    if len(text) > limit:
        text = text[: limit - 3].rstrip() + "..."
    return text

    The function strips the summary header via strip_summary_header() and uses _SUMMARY_LABEL_RE to remove section numbering prefixes (such as (1) **Component Scope**:, 1.     md_link_text()

    Visibility: Internal Signature: def md_link_text(text: str) -> str:

    Description: Escapes Markdown metacharacters within anchor link labels to ensure literal rendering.

    Parameters: * text (str): Target link label text.

    build_grouped_nav()

    Visibility: Internal Signature: def build_grouped_nav(sections: list, chapter_files: list, indent: int = 4) -> list[str]:

    Description: Recursively constructs MkDocs navigation YAML lines from section grouping trees, sub-grouping non-root modules by their directory paths.

    Parameters: * sections (list[dict]): Nested list of section definitions, each containing a name, a list of modules, and optional child children sections. * chapter_files (list[dict]): The set of chapter metadata objects used to resolve module locations. * indent (int): Current whitespace indentation level. Defaults to 4.

    Returns: * list[str]: Formatted lines suitable for inclusion in an MkDocs navigation configuration.

    Raises: * None.

    def build_grouped_nav(sections: list, chapter_files: list, indent: int = 4) -> list[str]:
    emit_raw("DEBUG", f"build_grouped_nav | building nav for {len(sections)} sections", dest="LOG")

    lines = []
    pad = " " * indent
    for section in sections:
        lines.append(f"{pad}- {yaml_str(section['name'])}:")
        if "children" in section:
            lines.extend(build_grouped_nav(section["children"], chapter_files, indent + 2))

        # Collect matched modules with directory info
        matched = []
        for mod_name in section.get("modules", []):
            match = next((cf for cf in chapter_files if cf["module_name"] == mod_name), None)
            if match:
                dir_path = os.path.dirname(match.get("original_path", "")) or ""
                matched.append((dir_path, mod_name, match))

        # Group by directory
        dir_groups = defaultdict(list)
        for dir_path, mod_name, match in matched:
            dir_groups[dir_path].append((mod_name, match))

        # Emit dir sub-layers for non-root dirs, flat for root files
        has_non_root = any(d for d in dir_groups)
        if has_non_root:
            for dir_path in sorted(dir_groups.keys()):
                if dir_path:
                    # Non-root: add directory sub-layer with bare module names
                    lines.append(f"{pad}  - {yaml_str(dir_path)}:")
                    for mod_name, match in dir_groups[dir_path]:
                        lines.append(f"{pad}    - {yaml_str(mod_name)}: {yaml_str('api/' + match['filename'])}")
                else:
                    # Root files: flat (no sub-layer)
                    for mod_name, match in dir_groups[dir_path]:
                        lines.append(f"{pad}  - {yaml_str(mod_name)}: {yaml_str('api/' + match['filename'])}")
        else:
            # All root files → flat list
            for _dir_path, mod_name, match in matched:
                lines.append(f"{pad}  - {yaml_str(mod_name)}: {yaml_str('api/' + match['filename'])}")

    return lines

    The function iterates over the section hierarchy, emitting section headers and recursing into children with increased indentation. For modules associated with each section, it resolves the underlying directory path (dir_path). Modules located in subdirectories are organized under directory subheadings using bare module names, while root-level files are emitted directly under the section without extra directory layers.

    prune_sections()

    Visibility: Internal Signature: def prune_sections(sections: list, chapter_files: list) -> list:

    Description: Filters out non-existent module names from section definitions and removes empty sections.

    Parameters: * sections (list[dict]): Raw section trees returned from LLM parsing. * chapter_files (list[dict]): Known chapter objects to match against.

    Returns: * list[dict]: Cleaned section hierarchy containing only valid, populated sections.

    Raises: * None.

    def prune_sections(sections: list, chapter_files: list) -> list:
    known = {cf["module_name"] for cf in chapter_files}
    pruned = []
    for section in sections:
        if not isinstance(section, dict):
            continue
        modules = [m for m in section.get("modules") or [] if isinstance(m, str) and m in known]
        children = prune_sections(section.get("children") or [], chapter_files)
        if not modules and not children:
            continue
        kept = {key: value for key, value in section.items() if key != "children"}
        kept["modules"] = modules
        if children:
            kept["children"] = children
        pruned.append(kept)
    return pruned

    The function builds a set of valid module names from chapter_files and strips unreferenced strings from modules. It then recurses into child sections. If a section contains neither modules nor child sections, it is removed to prevent empty navigation entries (such as - "Name":), which cause mkdocs build to fail with list validation errors.

    def build_index_sections(lines, sections, chapter_files, level=3, summaries=None):
    summaries = summaries or {}

    for section in sections:
        lines.append(f"{heading} {section['name']}")
        lines.append("")
        if section.get("modules"):

    prune_stale_pages()

    Visibility: Internal Signature: def prune_stale_pages(api_docs_path: str, chapter_files: list) -> None:

    Description: Deletes .md files in docs/api/ that do not correspond to any active chapter, along with any directories left empty as a result.

    Parameters: * api_docs_path (str): Absolute filesystem path to docs/api. * chapter_files (list[dict]): List of active chapter definitions.

    Returns: * None

    Raises: * OSError: If file or directory removal fails due to filesystem permissions.

    def prune_stale_pages(api_docs_path, chapter_files):
    def identity(path):
        st = os.stat(path)
        return st.st_dev, st.st_ino

    keep = set()
    for filename in ["index.md", *(cf["filename"] for cf in chapter_files)]:
        path = os.path.join(api_docs_path, filename)
        if os.path.exists(path):
            keep.add(identity(path))
    for root, _dirs, files in os.walk(api_docs_path, topdown=False):
        for name in files:
            path = os.path.join(root, name)
            if name.endswith(".md") and identity(path) not in keep:
                os.remove(path)
                emit("MKDOCS_PRUNED_STALE", path=path)
        if os.path.normcase(root) != os.path.normcase(api_docs_path) and not os.listdir(root):
            os.rmdir(root)

    The function uses the identity() closure to track files by device and inode numbers (st_dev, st_ino). This ensures that case-only filename modifications on case-insensitive filesystems (such as macOS and Windows) are handled correctly without leaving orphaned pages. It performs a bottom-up traversal using os.walk(..., topdown=False), deleting obsolete .md files and removing any directories that become empty.
