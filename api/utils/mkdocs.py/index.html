    mkdocs.py

    Source: utils/mkdocs.py

    Technical Overview

    Following the execution of provider transport adapters like llm_openrouter.py, the mkdocs.py module serves as the final site compilation, layout generation, and document export engine within the Codebase-Knowledge-Builder architecture. It consolidates site construction logic that structures raw Markdown chapters, verified source facts, and model-derived summaries into navigable documentation sites. The module supports two operational targets: a standalone bundled format (generating flat files and a unified full_content.md artifact) and an interactive MkDocs Material documentation site equipped with client-side search, dark mode toggling, Panzoom-based diagram inspection, and localized user interface elements.

    When operating in api-reference mode with six or more modules, the module coordinates an automated navigation layout pipeline. It constructs contextual prompts from project directory trees and chapter summaries, invoking language models via call_llm.py to discover structural groupings and assign semantic architectural roles (such as types, setup, core, support, and operational). Ground-truth module dependencies extracted by facts.py are merged with LLM-inferred edges to construct interactive Mermaid architecture maps and dependency graphs. These graphs isolate high-fan-in hub modules to preserve visual clarity while embedding direct references to verified facts records.

    The module also handles document integrity and filesystem synchronization. It manages cross-chapter hyperlink normalization by dynamically rewriting relative paths across arbitrary directory depths, neutralizing broken references across cached runs. It escapes Markdown table cells, sanitizes Mermaid entity labels against syntax breakages, and strips frontmatter safely across edge cases. Finally, it uses OS filesystem device and inode tracking to clean up orphaned pages and empty directories left behind by prior generations, ensuring documentation artifacts remain consistent with the active codebase state.

    Public API

    yaml_str()

    Visibility: Public
    Signature: def yaml_str(value) -> str:

    Description: Encapsulates a scalar value into a valid, double-quoted YAML string representation using JSON string serialization. Because JSON string literals are valid YAML double-quoted scalars, values containing colons, square brackets, quotes, or leading @ symbols can be injected into mkdocs.yml navigation labels or frontmatter blocks without corrupting YAML syntax.

    Parameters: * value (Any): The scalar, string, or object to serialize into a YAML-safe string.

    Returns: * str: A valid, JSON-escaped double-quoted string with whitespace trimmed.

    Example: 

    def yaml_str(value) -> str:
    """Quote a scalar for hand-built YAML (nav labels, section names, titles).

    JSON string literals are valid YAML double-quoted scalars, so names containing
    apostrophes, colons, brackets or a leading @ never break mkdocs.yml or frontmatter.
    """
    return json.dumps(str(value).strip(), ensure_ascii=False)

    The function converts the input argument to a string, strips surrounding whitespace, and delegates encoding to json.dumps with ensure_ascii=False. This guarantees that international characters (e.g., CJK ideographs, accented characters) are preserved in UTF-8 without hex-escape corruption while automatically escaping control characters and quotation marks.

    Returns: * str: The complete YAML configuration file ready to be saved as mkdocs.yml.

    Example: 

    def build_mkdocs_config(site_name: str, nav_yaml: str, include_home: bool = True, lang_code: str = "") -> str:
    # Extract nav items from nav_snippet (strip the "nav:" header line)
    nav_lines = nav_yaml.split("\n")
    nav_body = "\n".join(nav_lines[1:]) if nav_lines else ""

        f"  name: material\n"
        f"{lang_line}"
        # ...
    )

    The function splits incoming navigation strings to strip any leading nav: block indicators, realigning indentation under the primary configuration tree. It injects PyMdown's fence_div_format for Mermaid blocks, forcing Markdown parsers to output raw <div class="mermaid-raw"> containers instead of default preformatted code blocks. This container structure enables the Panzoom plugin to bind zoom events to the diagrams while preserving default SVG colors across theme switches.

    build_chapter_filenames()

    Visibility: Public
    Signature: def build_chapter_filenames(chapter_order: list, abstractions: list, is_mkdocs: bool) -> dict:

    Description: Computes a deterministic mapping between chapter execution order indices and their output Markdown filenames. It enforces collision-resistant naming across platforms by tracking case-insensitive targets, mapping mirrored source paths for API documentation, applying numbered prefixes for standalone tutorials, and ensuring filenames do not collide with index.md or directory indexes.

    Parameters: * chapter_order (list): Ordered integer indices referencing the abstractions list. * abstractions (list): List of abstraction metadata dictionaries containing name, path, and module properties. * is_mkdocs (bool): Flag indicating whether MkDocs site conventions apply (preserving subdirectories) or standalone numbering should be enforced.

    Returns: * dict: A dictionary mapping each chapter_order index i to its resolved Markdown filename string.

    Example: 

    def build_chapter_filenames(chapter_order: list, abstractions: list, is_mkdocs: bool) -> dict:
    def page_key(filename):
        directory, basename = posixpath.split(filename.lower())
        return posixpath.join(directory, "index.md") if basename == "readme.md" else filename.lower()

    filenames = {}
    used = {"index.md"}
    for i, abstraction_index in enumerate(chapter_order):
        if not 0 <= abstraction_index < len(abstractions):
            continue
        abstraction = abstractions[abstraction_index]
        if is_mkdocs and abstraction.get("original_path"):
            base = abstraction["original_path"].replace(os.sep, "/")
        else:
            chapter_name = abstraction["name"].replace("\n", " ").strip()
            safe_name = "".join(c if c.isalnum() else "_" for c in chapter_name).lower()
            base = safe_name if is_mkdocs else f"{i + 1:02d}_{safe_name}"
        filename, suffix = f"{base}.md", 2
        while page_key(filename) in used:
            filename, suffix = f"{base}_{suffix}.md", suffix + 1
        used.add(page_key(filename))
        filenames[i] = filename
    return filenames

    The function uses an internal helper page_key() to normalize paths to lowercase POSIX format, treating any file named readme.md as equivalent to its parent directory's index.md. When naming conflicts occur, it enters a while loop that appends incrementing integer suffixes (e.g., _2.md, _3.md) until a unique, unused path is established.

    split_frontmatter()

    Visibility: Public
    Signature: def split_frontmatter(text: str) -> tuple[str, bool]:

    Description: Detects, parses, and strips a leading YAML frontmatter block from Markdown text using the same matching rules as MkDocs' metadata parser.

    Parameters: * text (str): The raw document string potentially beginning with a --- block.

    Returns: * tuple[str, bool]: A 2-tuple (body, found) containing the stripped body text and a boolean indicating whether valid frontmatter was detected and removed.

    Example: 

    def split_frontmatter(text: str) -> tuple[str, bool]:
    match = _FRONTMATTER_RE.match(text)
    if match:
        try:
            if isinstance(yaml.safe_load(match.group(1)), dict):
                return text[match.end() :].strip(), True
        except Exception:  # like MkDocs: YAMLError, or e.g. ValueError from an impossible date (2024-02-30)
            pass
    return text, False

    The function matches against _FRONTMATTER_RE, extracting lines between leading triple dashes (---) and closing delimiter markers (--- or ...). It passes the matched block to yaml.safe_load. If the block parses as a valid dictionary, it trims the frontmatter from the document; otherwise, parsing exceptions like YAMLError or invalid date ValueError are suppressed, preserving the content as standard Markdown.

    clip_sentences()

    Visibility: Public
    Signature: def clip_sentences(text: str, limit: int) -> str:

    Description: Truncates prose to a specified character budget while preserving whole sentence boundaries. If even the first sentence exceeds the limit, it falls back to a clean word-boundary cut, balances any open backtick pairs, and appends an ellipsis (…).

    Parameters: * text (str): The source prose string to truncate. * limit (int): Maximum allowable character count.

    Returns: * str: Truncated, whitespace-collapsed string within the character budget.

    Example: 

    def clip_sentences(text: str, limit: int) -> str:
    text = " ".join(text.split())
    if len(text) <= limit:
        return text
    clipped = ""
    for sentence in _sentences(text):
        separator = "" if not clipped or clipped.endswith(_CJK_STOPS) else " "
        candidate = f"{clipped}{separator}{sentence}"
        if len(candidate) > limit:
            break
        clipped = candidate
    if not clipped:
        clipped = text[:limit].rsplit(" ", 1)[0].rstrip(",;:—\u2013- ")
        if clipped.count("`") % 2:
            clipped += "`"
        clipped += "…"
    return clipped

    The function collapses all internal whitespace down to single spaces. It iterates across sentences yielded by _sentences(), checking whether appending the next sentence exceeds limit. If no complete sentence fits, it slices the string at limit, finds the nearest preceding whitespace boundary via rsplit(" ", 1), balances any unclosed backticks to prevent broken code spans, and appends ….

    table_cell_text()

    Visibility: Public
    Signature: def table_cell_text(text: str) -> str:

    Description: Escapes pipe characters (|) to \| for Markdown table compatibility, while leaving pipes inside inline code spans untouched.

    Parameters: * text (str): The source text to place within a table cell.

    Returns: * str: Safely escaped table cell string.

    Example: 

    def table_cell_text(text: str) -> str:
    parts, position = [], 0
    for match in _CODE_SPAN_RE.finditer(text):
        parts.append(text[position : match.start()].replace("|", "\\|"))
        parts.append(match.group(0))
        position = match.end()
    parts.append(text[position:].replace("|", "\\|"))
    return "".join(parts)

    The function uses _CODE_SPAN_RE to iterate over backtick-delimited code segments. Plain-text segments outside code spans have all pipe characters converted to \|. The unescaped code spans (e.g., str | None) are preserved as-is, since Markdown table renderers naturally ignore pipe delimiters within backticks.

    summary_description()

    Visibility: Public
    Signature: def summary_description(summary: str, limit: int = 300) -> str:

    Description: Extracts the first point (scope and responsibility) from a 4-point chapter summary to generate concise, table-cell-safe descriptions when LLM clustering descriptions are unavailable.

    Parameters: * summary (str): The full multi-point chapter summary text. * limit (int, optional): Character threshold for the output description. Defaults to 300.

    Returns: * str: Cleaned, clipped, and pipe-escaped single-point description.

    Example: 

    def summary_description(summary: str, limit: int = 300) -> str:
    text = strip_summary_header(summary)
    points = [m for m in _POINT_PAREN_RE.finditer(text) if m.group(1) in ("1", "2")]
    if not points:
        points = [m for m in _POINT_PLAIN_RE.finditer(text) if m.group(1) in ("1", "2")]
    if points and points[0].group(1) == "1":
        end = next((m.start() for m in points[1:] if m.group(1) == "2"), len(text))
        text = text[points[0].start() : end].strip()
        first, sep, rest = text.partition("\n")
        if _SUMMARY_LABEL_RE.match(first):
            text = _SUMMARY_LABEL_RE.sub("", text, count=1)
        elif sep and rest.strip() and not _is_prose(_POINT_MARKER_RE.sub("", first, count=1)):
            text = rest
        else:
            text = _POINT_MARKER_RE.sub("", text, count=1)
    # ...
    return table_cell_text(clip_sentences(text, limit))

    The function locates section markers (1) and (2) (or plain 1. and 2.) using regular expressions, slicing out the text between them to extract point 1. It strips leading labels such as ### (1) Component Scope & Responsibility using _SUMMARY_LABEL_RE and _POINT_MARKER_RE. Finally, it passes the text through clip_sentences() and table_cell_text() to produce a safe table entry.

    md_link_text()

    Visibility: Public
    Signature: def md_link_text(text: str) -> str:

    Description: Escapes Markdown metacharacters in labels (such as _, *, [, ], \, and |) so that module names like __init__.py render as literal text rather than italics or bold formatting.

    Parameters: * text (str): Plain-text module name or label.

    def md_link_text(text: str) -> str:

    module_name_lookup()

    Visibility: Public
    Signature: def module_name_lookup(chapter_files: list) -> dict:

    Description: Generates an alias lookup map linking any plausible module identifier generated by an LLM (such as canonical module_name, original_path, or unique base filename) to its canonical module_name.

    Parameters: * chapter_files (list[dict]): List of chapter metadata dictionaries.

    Returns: * dict: A dictionary mapping aliases to canonical module_name strings.

    Example: 

    def module_name_lookup(chapter_files: list) -> dict:
    lookup = {}
    basename_counts = Counter(os.path.basename(cf.get("original_path") or cf["module_name"]) for cf in chapter_files)
    for cf in chapter_files:
        name = cf["module_name"]
        lookup[name] = name
        if cf.get("original_path"):
            lookup.setdefault(cf["original_path"], name)
        basename = os.path.basename(cf.get("original_path") or name)
        if basename_counts[basename] == 1:
            lookup.setdefault(basename, name)
    return lookup

    The function calculates basename frequencies using collections.Counter to identify unique filenames across the project. It maps module_name directly to itself, then registers original_path if present. If a basename is globally unique across the entire codebase, it is added to the dictionary as a fallback alias. This prevents ambiguity when models omit directory prefixes.

    verified_dependencies()

    Visibility: Public
    Signature: def verified_dependencies(module_facts: dict, chapter_files: list) -> dict:

    Description: Constructs a module dependency dictionary derived exclusively from source-verified citation edges in facts.json.

    Parameters: * module_facts (dict): Dictionary mapping file paths to verified fact entries. * chapter_files (list[dict]): List of chapter metadata dictionaries.

    Returns: * dict: A dictionary mapping source_module to a list of deduplicated target_module names.

    Example: 

    def verified_dependencies(module_facts: dict, chapter_files: list) -> dict:
    name_of = {cf["original_path"]: cf["module_name"] for cf in chapter_files if cf.get("original_path")}
    dependencies = {}
    for path, entry in (module_facts or {}).items():
        source = name_of.get(path)
        targets = [name_of[edge["module"]] for edge in entry.get("depends_on", []) if edge.get("module") in name_of]
        targets = [name for name in dict.fromkeys(targets) if name != source]
        if source and targets:
            dependencies[source] = targets
    return dependencies

    The function resolves paths in depends_on edge records back to canonical module names. Targets not mapped to an active chapter file are discarded, self-dependencies are filtered out, and the remaining targets are deduplicated using dict.fromkeys() to preserve discovery order.

    def order_sections(sections: list, chapter_files: list) -> list:
    rank = {role: index for index, role in enumerate(SECTION_ROLES)}
    dir_of = {cf["module_name"]: os.path.dirname(cf.get("original_path") or "") for cf in chapter_files}

    def role_rank(section):

    def ordered(level):
        level = [dict(section) for section in level]

    normalize_chapter_links()

    Visibility: Public
    Signature: def normalize_chapter_links(chapter_files):

    Description: Rewrites Markdown link targets across all chapter files so that relative links resolve correctly between chapters at different directory depths.

    Parameters: * chapter_files (list[dict]): List of chapter dictionaries containing filename and content fields.

    Returns: * None: Modifies the content field of each chapter dictionary in-place.

    Example: 

    def normalize_chapter_links(chapter_files):
    filenames = [cf["filename"] for cf in chapter_files]
    filename_lookup = {fname: fname for fname in filenames}
    basename_counts = Counter(fname.rsplit("/", 1)[-1] for fname in filenames)
    for fname in filenames:
        basename = fname.rsplit("/", 1)[-1]
        if basename_counts[basename] == 1 and basename not in filename_lookup:
            filename_lookup[basename] = fname

    link_pattern = re.compile(r"\[([^\]]*)\]\(([^)#]+\.md)(#[^)]*)?\)")
    fixed_count = 0

    for cf in chapter_files:
        current_dir = os.path.dirname(cf["filename"])

        def fix_link(match, _dir=current_dir):
            nonlocal fixed_count
            text, target, anchor = match.group(1), match.group(2), match.group(3) or ""
            if target.startswith(("http://", "https://")):
                return match.group(0)
            canonical = filename_lookup.get(target)
            if not canonical:
                resolved = os.path.normpath(os.path.join(_dir, target)).replace("\\", "/")
                canonical = filename_lookup.get(resolved)
            if canonical:
                correct_rel = os.path.relpath(canonical, _dir).replace("\\", "/") if _dir else canonical
                if _dir and filename_lookup.get(correct_rel, canonical) != canonical:
                    correct_rel = f"./{correct_rel}"
                if correct_rel != target:
                    fixed_count += 1
                return f"[{text}]({correct_rel}{anchor})"
            return match.group(0)

        cf["content"] = link_pattern.sub(fix_link, cf["content"])

    The function builds an alias lookup map across all output paths, registering unique basenames as fallback targets. It scans Markdown text using a regex that matches [text](target.md#anchor) patterns, ignoring external HTTP/HTTPS URLs. Target paths are resolved relative to the referencing chapter's parent directory via os.path.relpath. If a relative path could be misread as an unrelated root-relative file on subsequent passes, it is explicitly prefixed with ./.

    _sentences()

    Description: Generator that yields sentences from a prose block. It detects sentence endings while skipping common whole-word abbreviations (such as "e.g." or "vs.") that would otherwise cause false-positive splits.

    Parameters: * text (str): Prose text to segment.

    Yields: * str: Individual sentence strings extracted from the text.

    Signature: def _ends_with_abbreviation(piece: str) -> bool:

    Description: Checks whether a text segment ends with a recognized whole-word abbreviation from _ABBREVIATIONS (e.g., "e.g.", "i.e.", "approx.").

    The helper converts the input segment to lowercase and checks it against each abbreviation in _ABBREVIATIONS. If a match is found, it inspects the character immediately preceding the abbreviation string. If that character is empty or non-alphanumeric, the match is confirmed as a standalone abbreviation rather than a word ending (e.g., distinguishing "e.g." from "piano.").

    _section_members()

    Visibility: Private
    Signature: def _section_members(sections: list) -> list[tuple[str, list]]:

    Description: Flattens nested section trees into a list of top-level section tuples, rolling child section modules up into their parent sections and deduplicating modules so each appears only in the first section that references it.

    Parameters: * sections (list[dict]): Hierarchical section trees.

    Returns: * list[tuple[str, list]]: A list of (section_name, [module_names]) tuples for all top-level sections.

    Example: 

    def _section_members(sections: list) -> list[tuple[str, list]]:
    owned = set()

    def modules_of(section):
        found = list(section.get("modules", []))
        for child in section.get("children", []):
            found += modules_of(child)
        return found

    groups = []
    for section in sections:
        members = []
        for name in modules_of(section):
            if name not in owned:
                owned.add(name)
                members.append(name)
        groups.append((section["name"], members))
    return groups

    The function defines an inner recursive helper modules_of() that gathers all module names from a section and its nested children. The outer loop tracks claimed module names in an owned set. If a module is referenced across multiple sections, it is assigned exclusively to the first section that encountered it.

    _mermaid_label()

    Visibility: Private
    Signature: def _mermaid_label(text) -> str:

    Description: Sanitizes plain-text labels for use in quoted Mermaid diagram nodes, replacing characters that interfere with Mermaid's syntax parser with numeric entity codes.

    Parameters: * text (Any): Source label string or object.

    Returns: * str: Sanitized string safe for inclusion in Mermaid node declarations.

    Example: 

    def _mermaid_label(text) -> str:
    text = " ".join(str(text).split())
    for char, code in (("#", "#35;"), ('"', "#quot;"), ("`", "#96;"), ("<", "#lt;"), (">", "#gt;")):
        text = text.replace(char, code)
    return text

    The helper collapses all internal whitespace into single spaces. It then escapes special characters using numeric entities: # becomes #35;, " becomes #quot;, backticks become #96;, and angle brackets </> become #lt; and #gt;. Escaping # first prevents double-encoding of subsequent entity prefixes.

    Error Handling

    The module uses defensive error handling patterns to prevent invalid model responses, file system differences, or Markdown parsing anomalies from halting the documentation build:

    • LLM Grouping Failure Fallback: In write_mkdocs_output(), LLM-assisted section clustering is wrapped in a broad try-except Exception as e block. If parsing fails, an invalid schema is returned, or the network call drops, the error is logged to dest="LOG" via emit_raw() alongside a full stack trace. The pipeline then emits GROUP_ERROR_FALLBACK and falls back to the deterministic, flat navigation layout provided by prep_res["nav_snippet"].
    • Empty Section and Null Nav Guard: prune_sections() drops modules that do not match known chapters, as well as sections left with no modules or children. This prevents MkDocs from encountering null YAML navigation items (- "Section Name":), which causes mkdocs build to abort with "Expected nav to be a list, got None".
    • Safe Frontmatter Parsing: split_frontmatter() catches exceptions raised by yaml.safe_load(). If a chapter opens with a horizontal divider (---) or contains invalid frontmatter (such as an impossible date), the exception is suppressed and the content is retained as regular Markdown body text.
    • Mermaid Syntax Escaping: In _mermaid_label(), characters that conflict with Mermaid's syntax parser (#, ", `, <, >) are replaced with their corresponding numeric entity codes (#35;, #quot;, #96;, #lt;, #gt;). This prevents unescaped characters in code identifiers or comments from breaking diagram rendering.
    • Cross-Platform Inode Tracking: In prune_stale_pages(), files are tracked by their filesystem device and inode numbers (st_dev, st_ino). This ensures that case-only file renames on case-insensitive filesystems (such as macOS or Windows) do not cause active files to be mistakenly identified as stale and deleted.
