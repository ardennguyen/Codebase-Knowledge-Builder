    mkdocs.py

    Source: utils/mkdocs.py

    While previous chapters such as llm_openrouter.py and llm_gemini.py detail the transport clients and execution adapters responsible for low-level prompt dispatching, streaming aggregation, and token accounting, utils/mkdocs.py operates at the end of the documentation pipeline. Once LLM generation passes complete across codebase abstractions, this module synthesizes raw chapter markdown, structural dependency graphs, navigation hierarchies, and site configuration assets into either an interactive, searchable MkDocs Material site or a standalone Markdown publication.

    Technical Overview

    utils/mkdocs.py consolidates site layout, navigation graph synthesis, frontmatter filtering, link normalization, and filesystem operations into a centralized publishing engine. The module addresses the structural impedance mismatch between LLM-generated chapter outputs and static site generators. Large language models frequently output inconsistent cross-document relative links, include superfluous introductory headers in summary briefs, and introduce special characters that corrupt YAML configurations or Mermaid syntax. utils/mkdocs.py provides deterministic post-processing routines that sanitize these outputs, ensuring that generated sites build cleanly under mkdocs build and mkdocs serve.

    The module exposes two primary pipeline termination targets: write_mkdocs_output and write_standalone_output. In MkDocs mode, the module configures the Material for MkDocs theme, registers custom code highlighting via pymdownx, initializes interactive diagram pan/zoom capabilities, and builds dynamic landing pages. For projects operating in api-reference mode with more than five modules, the engine invokesLarge Language Models through call_llm.py using the prompts/common/group_modules.md prompt. This prompt clusters modules into functional architectural sections, derives cross-module dependency relationships, and produces system overview diagrams.

    To deliver interactive documentation, utils/mkdocs.py implements custom asset injection. Diagrams are formatted with the .mermaid-raw CSS class to bypass MkDocs Material's automatic SVG color overrides. This styling ensures that standard Mermaid themes render with light card backings on slate dark mode palettes. A client-side loader script (MERMAID_INIT_JS) manages strict-security diagram rendering and integrates with the panzoom plugin to provide full-screen zooming on complex module graphs. Finally, the filesystem synchronization engine uses operating system file identity checks (st_dev and st_ino) to detect and purge stale artifacts across case-insensitive file systems without deleting active documentation pages.

    Public API

    yaml_str()

    Visibility: Public
    Signature: def yaml_str(value) -> str:

    Description: Serializes any scalar value into a valid YAML double-quoted string literal using json.dumps(..., ensure_ascii=False). Because JSON string literals conform to YAML 1.2 double-quoted scalar specifications, this escaping prevents titles, section headings, or navigation labels containing apostrophes, colons, brackets, or leading @ symbols from breaking mkdocs.yml parsing or Markdown frontmatter.

    Parameters: * value (Any): The scalar, string, or number to quote for hand-crafted YAML documents.

    Returns: * str: A valid, JSON-escaped, double-quoted YAML string.

    Raises: * No custom exceptions raised.

    Example: 

    def yaml_str(value) -> str:
    """Quote a scalar for hand-built YAML (nav labels, section names, titles).

    JSON string literals are valid YAML double-quoted scalars, so names containing
    apostrophes, colons, brackets or a leading @ never break mkdocs.yml or frontmatter.
    """
    return json.dumps(str(value).strip(), ensure_ascii=False)

    The function converts arbitrary objects to strings, strips leading and trailing whitespace, and serializes the text with Unicode characters preserved. This approach avoids using heavier YAML serialization dependencies for single scalar interpolations within configuration strings.

    build_chapter_filenames()

    Visibility: Public
    Signature: def build_chapter_filenames(chapter_order: list, abstractions: list, is_mkdocs: bool) -> dict:

    Description: Calculates deterministic, collision-free Markdown target filenames for every chapter index in chapter_order. For MkDocs output with an original_path abstraction, it mirrors the relative source directory path. For standard standalone outputs, it uses numeric ordering prefixes (e.g., 01_setup.md). It maintains a case-insensitive registry of assigned paths, automatically appending numeric suffixes (e.g., _2.md) to resolve collisions with reserved files like index.md or existing chapters.

    Parameters: * chapter_order (list): Ordered list of integer indices referencing the abstractions array. * abstractions (list): List of abstraction metadata dictionaries containing name and optional original_path keys. * is_mkdocs (bool): True if generating paths for MkDocs mode; False for standalone prefixed mode.

    Returns: * dict: Mapping from integer chapter order positions to relative Markdown filename strings (e.g., {0: "core/engine.py.md"}).

    Raises: * No custom exceptions raised.

    Example: 

        def page_key(filename):
        directory, basename = posixpath.split(filename.lower())
        return posixpath.join(directory, "index.md") if basename == "readme.md" else filename.lower()

    filenames = {}
    used = {"index.md"}
    for i, abstraction_index in enumerate(chapter_order):
        if not 0 <= abstraction_index < len(abstractions):
            continue
        abstraction = abstractions[abstraction_index]
        if is_mkdocs and abstraction.get("original_path"):
            base = abstraction["original_path"].replace(os.sep, "/")
        else:
            chapter_name = abstraction["name"].replace("\n", " ").strip()
            safe_name = "".join(c if c.isalnum() else "_" for c in chapter_name).lower()
            base = safe_name if is_mkdocs else f"{i + 1:02d}_{safe_name}"
        filename, suffix = f"{base}.md", 2
        while page_key(filename) in used:
            filename, suffix = f"{base}_{suffix}.md", suffix + 1
        used.add(page_key(filename))
        filenames[i] = filename
    return filenames

    The internal page_key() helper normalizes paths by treating readme.md files as equivalent to index.md within their respective directories. This accounts for MkDocs building README.md as a directory index and prevents silent overwrite errors.

    split_frontmatter()

    Visibility: Public
    Signature: def split_frontmatter(text: str) -> tuple[str, bool]:

    Description: Detects and extracts leading YAML frontmatter blocks bounded by triple dashes (---). The extraction strictly parses the block using yaml.safe_load(). If the header parses into a valid YAML mapping (dict), the frontmatter is removed and the remaining body is returned. Otherwise, if parsing fails or returns a non-dictionary type (such as a bare horizontal rule), the content remains untouched.

    Parameters: * text (str): Raw Markdown source code that may contain YAML frontmatter.

    Returns: * tuple[str, bool]: A 2-tuple (body, found), where body is the stripped text and found indicates if valid frontmatter was detected and removed.

    Raises: * No custom exceptions raised.

    Example: 

    def split_frontmatter(text: str) -> tuple[str, bool]:
    match = _FRONTMATTER_RE.match(text)
    if match:
        try:
            if isinstance(yaml.safe_load(match.group(1)), dict):
                return text[match.end() :].strip(), True
        except Exception:  # like MkDocs: YAMLError, or e.g. ValueError from an impossible date (2024-02-30)
            pass
    return text, False

    The function uses defensive exception handling to catch yaml.YAMLError and parsing edge cases like invalid calendar dates in frontmatter (e.g., 2024-02-30). This mirrors MkDocs' internal YAML parser behavior.

    clip_sentences()

    Visibility: Public
    Signature: def clip_sentences(text: str, limit: int) -> str:

    Description: Truncates arbitrary text to a maximum character length while preserving whole sentence boundaries. If even the first sentence exceeds limit, the function cuts at a word boundary, balances code spans by closing dangling backticks, and appends an ellipsis (…).

    Parameters: * text (str): The source text to clip. * limit (int): The maximum character count threshold.

    Returns: * str: Cleanly truncated text ending on a whole sentence or safe word boundary.

    Raises: * No custom exceptions raised.

    Example: 

        text = " ".join(text.split())
    if len(text) <= limit:
        return text
    clipped = ""
    for sentence in _sentences(text):
        separator = "" if not clipped or clipped.endswith(_CJK_STOPS) else " "
        candidate = f"{clipped}{separator}{sentence}"
        if len(candidate) > limit:
            break
        clipped = candidate
    if not clipped:
        clipped = text[:limit].rsplit(" ", 1)[0].rstrip(",;:—\u2013- ")
        if clipped.count("`") % 2:
            clipped += "`"
        clipped += "…"
    return clipped

    The function normalizes whitespace and iterates through sentences using _sentences(). When building strings in CJK languages, it skips space separators if the previous sentence terminates with a full-width punctuation stop (。, ！, ？).

    table_cell_text()

    Visibility: Public
    Signature: def table_cell_text(text: str) -> str:

    Description: Escapes pipe characters (| to \|) so the string can be safely embedded into Markdown table cells. It skips pipes that appear inside inline code spans (e.g., `str | None`), ensuring type union signatures render correctly.

    Parameters: * text (str): Raw string intended for a Markdown table cell.

    Returns: * str: Markdown table-safe string with unescaped pipes protected.

    Raises: * No custom exceptions raised.

    Example: 

    def table_cell_text(text: str) -> str:
    parts, position = [], 0
    for match in _CODE_SPAN_RE.finditer(text):
        parts.append(text[position : match.start()].replace("|", "\\|"))
        parts.append(match.group(0))
        position = match.end()
    parts.append(text[position:].replace("|", "\\|"))
    return "".join(parts)

    By scanning the string with _CODE_SPAN_RE, the function segments prose from inline backtick blocks. Only the intervening prose regions undergo pipe replacement, leaving type annotations and code syntax unmodified.

    module_name_lookup()

    Visibility: Public
    Signature: def module_name_lookup(chapter_files: list) -> dict:

    Description: Compiles an alias resolution map that maps various naming variations an LLM might use for a module back to its canonical module_name. It indexes the exact module_name, the original_path, and—when unique across the documentation set—the bare filesystem basename.

    Parameters: * chapter_files (list): List of chapter dictionaries, where each entry contains at least a module_name and optional original_path.

    Returns: * dict: Dictionary mapping alternate aliases and basenames to canonical module name strings.

    Raises: * No custom exceptions raised.

    Example: 

    def module_name_lookup(chapter_files: list) -> dict:
    lookup = {}
    basename_counts = Counter(os.path.basename(cf.get("original_path") or cf["module_name"]) for cf in chapter_files)
    for cf in chapter_files:
        name = cf["module_name"]
        lookup[name] = name
        if cf.get("original_path"):
            lookup.setdefault(cf["original_path"], name)
        basename = os.path.basename(cf.get("original_path") or name)
        if basename_counts[basename] == 1:
            lookup.setdefault(basename, name)
    return lookup

    The function tallies basename occurrences using collections.Counter. If a basename is unique across the entire project (such as call_llm.py), it is added as a valid key pointing to its canonical module name. If multiple files share a basename (such as utils/index.ts and api/index.ts), the bare basename alias is omitted to prevent ambiguous mappings.

    build_module_graph()

    Visibility: Public
    Signature: def build_module_graph(sections: list, dependencies: dict, chapter_files: list) -> tuple[str, int]:

    Description: Generates Mermaid diagram source code for the complete module-level dependency graph in docs/api/index.md. Modules are grouped into subgraph blocks based on their top-level navigation sections. Highly connected "hub" modules—those referenced by at least max(5, total_modules // 4) other files—are styled with entryNode and have their incoming arrows replaced with an inline "used by N modules" label to prevent visual clutter.

    Parameters: * sections (list): Hierarchical list of section dictionaries. * dependencies (dict): Module-level dependency mappings. * chapter_files (list): List of all chapter metadata dictionaries.

    Returns: * tuple[str, int]: A 2-tuple (source, hub_threshold): * source: Mermaid flowchart source string (empty if unrenderable or exceeded limit). * hub_threshold: The integer threshold count used to classify modules as hubs, or 0 if no hubs exist.

    Raises: * No custom exceptions raised.

    Example: 

        if not dependencies or len(chapter_files) > _MODULE_GRAPH_MAX_MODULES:
        return "", 0
    ids = {cf["module_name"]: f"M{index}" for index, cf in enumerate(chapter_files)}
    edges = [(source, target) for source, targets in dependencies.items() for target in targets if source in ids and target in ids]
    incoming = Counter(target for _, target in edges)

    Example: 

    def prune_stale_pages(api_docs_path, chapter_files):
    def identity(path):
        st = os.stat(path)
        return st.st_dev, st.st_ino

    keep = set()
    for filename in ["index.md", *(cf["filename"] for cf in chapter_files)]:
        path = os.path.join(api_docs_path, filename)
        if os.path.exists(path):

    _sentences()

    Signature: def _sentences(text: str):

    Description: A generator that yields individual sentence slices from text. It splits sentences using terminal punctuation followed by whitespace (or CJK stop characters) while ignoring standard abbreviations to avoid broken sentence fragments.

    Parameters: * text (str): Prose text to parse into sentences.

    Yields: * str: Clean sentence slices.

    """Yield the sentences of *text*; an abbreviation such as "e.g." or "vs." does not end one."""

    def _ends_with_abbreviation(piece: str) -> bool:

    Error Handling

    LLM Grouping Failure and Fallback

    Dynamic navigation grouping in write_mkdocs_output() relies on external LLM responses that may fail due to timeouts, network errors, or malformed JSON output: 

            except Exception as e:
            emit("GROUP_ERROR_FALLBACK", error=e)
            emit_raw("ERROR", f"LLM grouping failed: {e}\n{traceback.format_exc()}", dest="LOG")
            nav_snippet = prep_res["nav_snippet"]
            sections = None
            descriptions, dependencies = {}, {}
    When an exception occurs during grouping, the module logs a diagnostic traceback and falls back to prep_res["nav_snippet"]. It clears dynamic extras and renders a standard flat landing page index table, ensuring the site build completes successfully.

    Safe Navigation Pruning

    If an LLM includes phantom modules in its response, generating a navigation entry for them could break the build: 

    def prune_sections(sections: list, chapter_files: list) -> list:
    known = {cf["module_name"] for cf in chapter_files}
// ...
        modules = [m for m in section.get("modules") or [] if isinstance(m, str) and m in known]
        children = prune_sections(section.get("children") or [], chapter_files)
        if not modules and not children:
            continue
    prune_sections() filters out module names that do not match known chapters and recursively drops any sections left without content. This prevents empty navigation entries (- "Section":) from causing mkdocs build to exit with syntax errors.

    Case-Insensitive Filesystem Stale Page Pruning

    When cleaning up stale files from previous runs, string path comparisons can fail on case-insensitive filesystems (such as macOS APFS or Windows NTFS) during case-only renames: 

        def identity(path):
        st = os.stat(path)
        return st.st_dev, st.st_ino

    keep = set()
    for filename in ["index.md", *(cf["filename"] for cf in chapter_files)]:
        path = os.path.join(api_docs_path, filename)
        if os.path.exists(path):
            keep.add(identity(path))
    prune_stale_pages() identifies files using (st_dev, st_ino) tuples. This ensures that active chapters whose case-only renames reuse an existing file system inode are not deleted by the stale file cleanup pass.
