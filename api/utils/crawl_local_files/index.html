    utils.crawl_local_files

    File Path: utils/crawl_local_files.py

    Overview

    The utils.crawl_local_files module provides local filesystem directory crawling and source ingestion capabilities for the Codebase-Knowledge-Builder pipeline. It is utilized by the FetchRepo node when local directory paths (--dir) are targeted instead of remote Git repositories.

    The module mirrors the functional interface and filtering logic of utils.crawl_github_files, enabling uniform downstream processing. It features: - Recursive directory traversal via os.walk with in-place directory pruning to avoid traversing excluded directory branches. - Automatic .gitignore pattern loading and matching using pathspec.PathSpec with gitwildmatch rules. - Glob-based include and exclude pattern filtering using fnmatch. - File size threshold validation to avoid loading large assets into memory. - Safe text decoding with utf-8-sig encoding, filtering out binary and non-text files. - Formatted ANSI terminal summary reporting with detailed metrics on processed, excluded, oversized, and unreadable files.

    Functions

    crawl_local_files()

    Visibility: Public
    Signature: def crawl_local_files(directory: str, include_patterns: set[str] | None = None, exclude_patterns: set[str] | None = None, max_file_size: int | None = None, use_relative_paths: bool = True) -> dict[str, dict[str, str]]:

    Description:
    Performs a single-pass traversal of a local directory, applying hierarchical directory pruning, .gitignore rules, inclusion/exclusion wildcard filters, file size limits, and UTF-8 encoding checks.

    Under the hood, the function performs the following steps: 1. Validation: Checks if directory exists using os.path.isdir(), raising ValueError if the directory is missing. 2. Gitignore Discovery: Checks for a .gitignore file located directly under directory. If found, parses its lines using pathspec.PathSpec.from_lines("gitwildmatch", ...) with utf-8-sig encoding. If parsing fails, logs a warning and continues without .gitignore filtering. 3. Recursive Traversal & Directory Pruning: - Walks the directory tree using os.walk(directory). - Iterates through subdirectories (dirs), calculating their relative path to directory. - Checks subdirectories against gitignore_spec and exclude_patterns (normalizing trailing /* wildcards). - Dynamically mutates dirs in-place by removing excluded directories, preventing unnecessary recursive traversal into ignored subtrees (such as node_modules, .git, or build caches). - Sorts the remaining dirs in-place for deterministic alphabetical traversal ordering. 4. File Filtering and Ingestion: - Iterates over sorted files within the current directory. - Computes relative paths if use_relative_paths=True, or absolute/verbatim paths otherwise. - Tests relpath against gitignore_spec.match_file(relpath). Skips and logs with ANSI gray if matched. - Tests relpath against exclude_patterns using fnmatch.fnmatch. Skips and logs if matched. - Tests relpath against include_patterns using fnmatch.fnmatch (if include_patterns is provided). Skips if no pattern matches. - Inspects file size via os.path.getsize(filepath). Skips and logs with ANSI red if max_file_size is exceeded. - Reads text contents using open(filepath, "r", encoding="utf-8-sig"). - Catches UnicodeDecodeError or ValueError for binary/non-text files and records them in skipped_non_text. - Successfully read files are added to files_dict[relpath]. 5. Summary Reporting: - Prints a formatted terminal summary to standard output detailing total discovered items, processed count, excluded count, oversized files, and unparseable non-text files. 6. Return: Returns a dictionary mapping the "files" key to the populated path-to-content dictionary.

    Parameters: * directory (str): Target root filesystem path to crawl. * include_patterns (set[str] | None, optional): Set of wildcard glob patterns to include (e.g., {"*.py", "*.js"}). If None or empty, all non-excluded files are considered. Defaults to None. * exclude_patterns (set[str] | None, optional): Set of wildcard glob patterns to ignore (e.g., {"tests/*", "*.log"}). Defaults to None. * max_file_size (int | None, optional): Maximum allowable file size in bytes. Files exceeding this threshold are skipped. Defaults to None. * use_relative_paths (bool, optional): Flag indicating whether the dictionary keys should be relative to directory (True) or use full filepath strings (False). Defaults to True.

    Returns: * dict[str, dict[str, str]]: A dictionary containing: - "files" (dict[str, str]): Mapping of relative (or full) file path strings to their decoded file text contents.

    Raises: * ValueError: If directory does not exist or is not a valid directory.

    Example: 

    from utils.crawl_local_files import crawl_local_files

# Crawl a local project folder ignoring caches and tests
result = crawl_local_files(
    directory="./my_project",
    include_patterns={"*.py", "*.md"},
    exclude_patterns={"tests/*", "__pycache__/*", "*.pyc"},
    max_file_size=512 * 1024,
    use_relative_paths=True
)

files = result["files"]
for path, content in files.items():
    print(f"Loaded {path} ({len(content)} characters)")
