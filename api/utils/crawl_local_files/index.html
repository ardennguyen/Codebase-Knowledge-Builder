    utils.crawl_local_files

    File Path: utils/crawl_local_files.py

    Technical Overview

    The utils.crawl_local_files module provides local filesystem traversal and content extraction capabilities for the Codebase-Knowledge-Builder system. It serves as an alternative to utils.crawl_github_files, exposing a compatible return interface ({"files": {filepath: content}}) when operating directly against a local workspace or repository instead of fetching data via the GitHub REST API.

    The module performs a single-pass traversal using os.walk, incorporating: - Rule-based directory pruning to eliminate unnecessary branches early. - .gitignore compatibility using pathspec.PathSpec (gitwildmatch syntax). - User-supplied glob inclusion and exclusion matching via fnmatch. - Maximum file size thresholds to prevent loading large binaries or assets. - UTF-8 text decoding with fallback detection to skip non-text or binary files safely. - Real-time ANSI-colored logging and crawl metrics reporting.

    flowchart TD
    Start([Start Crawl]) --> CheckDir{os.path.isdir?}
    CheckDir -- No --> RaiseErr[Raise ValueError]
    CheckDir -- Yes --> LoadGitignore[Load .gitignore if present]

    LoadGitignore --> WalkDirs[os.walk directory]

    subgraph DirFiltering[Directory Level Filter]
        WalkDirs --> MatchGitignoreDir{Gitignore match?}
        MatchGitignoreDir -- Yes --> PruneDir[Add to excluded dirs]
        MatchGitignoreDir -- No --> MatchExcludeDir{Exclude pattern match?}
        MatchExcludeDir -- Yes --> PruneDir
        MatchExcludeDir -- No --> KeepDir[Keep directory in traversal]
    end

    subgraph FileFiltering[File Level Filter]
        KeepDir --> CheckGitignoreFile{Gitignore match?}
        CheckGitignoreFile -- Yes --> SkipFile[Skip file]
        CheckGitignoreFile -- No --> CheckExcludeFile{Exclude pattern match?}
        CheckExcludeFile -- Yes --> SkipFile
        CheckExcludeFile -- No --> CheckIncludeFile{Include pattern set and no match?}
        CheckIncludeFile -- Yes --> SkipFile
        CheckIncludeFile -- No --> CheckSize{Size > max_file_size?}
        CheckSize -- Yes --> SkipSize[Log Size Limit Skip]
        CheckSize -- No --> ReadContent[Read with utf-8-sig]
    end

    ReadContent --> TextCheck{Decode Success?}
    TextCheck -- Yes --> AddDict[Store in files_dict]
    TextCheck -- No --> SkipBin[Log Non-Text Skip]

    AddDict --> Summary[Print Summary Report]
    SkipFile --> Summary
    SkipSize --> Summary
    SkipBin --> Summary
    Summary --> End([Return dict])

    Visibility: Public
    Signature: 

    def crawl_local_files(
    directory,
    include_patterns=None,
    exclude_patterns=None,
    max_file_size=None,
    use_relative_paths=True,
):

    Description: Traverses a target directory on the local filesystem, filters out ignored or irrelevant files/directories, reads matching text files, and compiles their contents into a dictionary.

    The function operates through several distinct phases: 1. Validation & Initialization: Verifies that the provided path points to a valid directory. Initializes ANSI escape codes for terminal feedback, counters for tracking scan metrics, and the output dictionary. 2. Gitignore Parsing: Detects if a .gitignore file exists in the root of the target directory. If found, reads it using utf-8-sig encoding and compiles it into a pathspec.PathSpec object using the gitwildmatch rule style. 3. Directory Pruning: While walking through the directory hierarchy with os.walk, checks each directory against the gitignore rules and exclude_patterns. Any matched directory is removed in-place from dirs to prevent os.walk from descending into its children. 4. File Filtering & Extraction: Evaluates each file against the gitignore rules, exclude_patterns, include_patterns, and max_file_size constraints. 5. Text Decoding: Attempts to read each valid file using open(filepath, "r", encoding="utf-8-sig"). Non-text files or files that raise UnicodeDecodeError or ValueError are categorized as non-text and skipped without crashing the traversal process. 6. Summary Generation: Outputs ANSI-colorized summary metrics displaying total entries examined, successfully processed files, excluded paths, size limit violations, and non-text skips.

        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- ANSI colors ---
    C_GREEN  = "\033[92m"
    C_GRAY   = "\033[90m"
    C_RED    = "\033[91m"
    C_RESET  = "\033[0m"

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Load .gitignore ---
    gitignore_path = os.path.join(directory, ".gitignore")
    gitignore_spec = None
    if os.path.exists(gitignore_path):
        try:
            with open(gitignore_path, "r", encoding="utf-8-sig") as f:
                gitignore_patterns = f.readlines()
            gitignore_spec = pathspec.PathSpec.from_lines("gitwildmatch", gitignore_patterns)
            print(f"Loaded .gitignore patterns from {gitignore_path}")
        except Exception as e:
            print(f"Warning: Could not read or parse .gitignore file {gitignore_path}: {e}")
    # ...

    The initial block handles validation and .gitignore ingestion. If directory is invalid, a ValueError is raised immediately before any state is initialized. The .gitignore loader catches general exceptions gracefully to avoid failing the crawl when .gitignore files contain unreadable characters or permissions issues.

        # ...
    # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            dirpath_rel = os.path.relpath(os.path.join(root, d), directory)

            reason = None
            if gitignore_spec and gitignore_spec.match_file(dirpath_rel):
                reason = "excluded (.gitignore)"
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern[:-2] if pattern.endswith("/*") else pattern
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = "excluded"
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {dirpath_rel}/ [{reason}]{C_RESET}")

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()
        # ...

    The directory filtering block prunes unneeded directory trees before recursing into them. Modifying dirs in-place by removing directories matching gitignore_spec or exclude_patterns prevents os.walk from traversing large subtrees (such as node_modules or .git), saving I/O overhead.

            # ...
        # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore
            if gitignore_spec and gitignore_spec.match_file(relpath):
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (.gitignore)]{C_RESET}")
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded]{C_RESET}")
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (not in include list)]{C_RESET}")
                    continue

            # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                print(f"{C_RED}  [{entry_num}] {relpath} [size limit: {size_kb:.0f}KB]{C_RESET}")
                continue

            # Try to read as text
            try:
                with open(filepath, "r", encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                print(f"{C_GREEN}  [{entry_num}] {relpath} [processed]{C_RESET}")
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: not a text file]{C_RESET}")
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: {e}]{C_RESET}")
    # ...

    The file filtering logic evaluates files individually. If an include_patterns set is provided, files not matching any pattern in the set are excluded. Size limits are checked using os.path.getsize before opening the file. File reading is wrapped in broad exception handling to trap UnicodeDecodeError and other I/O errors, ensuring that binary files or unreadable nodes do not interrupt the crawl.

        # ...
    # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    print("\n--- Crawl Summary ---")
    print(f"  Total found : {total_fetched}")
    print(f"{C_GREEN}  Processed   : {count_processed}{C_RESET}")
    if count_excluded > 0:
        print(f"{C_GRAY}  Excluded    : {count_excluded}{C_RESET}")
    if count_size_limit > 0:
        print(f"{C_RED}  Size limit  : {count_size_limit}{C_RESET}")
        for f in skipped_size_limit:
            print(f"{C_RED}    - {f}{C_RESET}")
    if count_non_text > 0:
        print(f"{C_RED}  Non-text    : {count_non_text}{C_RESET}")
        for f in skipped_non_text:
            print(f"{C_RED}    - {f}{C_RESET}")

    The summary block formats crawl statistics into a consolidated report written to stdout. Lists of files skipped due to size limits or non-text decoding errors are printed in red ANSI text.

    Parameters: * directory (str): The root path to the local directory to crawl. * include_patterns (set | None, optional): Set of file glob patterns to match against (e.g., {"*.py", "*.js"}). Defaults to None (includes all files not otherwise excluded). * exclude_patterns (set | None, optional): Set of file or directory glob patterns to ignore (e.g., {"tests/*", "*.pyc"}). Defaults to None. * max_file_size (int | None, optional): Maximum allowed file size in bytes. Files larger than this threshold are skipped. Defaults to None. * use_relative_paths (bool, optional): Whether the output dictionary keys should be relative to directory (True) or absolute/verbatim paths (False). Defaults to True.

    Returns: * dict: A dictionary containing a single key "files", mapping file paths (relative or absolute) to their string text content ({"files": {filepath: content}}).

    Raises: * ValueError: Raised if directory is not an existing directory according to os.path.isdir.
