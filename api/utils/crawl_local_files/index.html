    utils.crawl_local_files

    Original Source File: utils/crawl_local_files.py

    The utils.crawl_local_files module provides local filesystem exploration and ingestion capabilities for the knowledge base generation pipeline. It is the offline equivalent to utils.crawl_github_files, offering a unified dictionary output schema ({"files": {filepath: content}}) that downstream pipeline stages can consume interchangeably.

    Technical Overview

    The module executes a single-pass filesystem crawl using Python's standard os.walk, augmenting directory traversal with pattern-based path filtering, .gitignore rule integration via the pathspec library, file size limits, and robust text-decoding error handling (utf-8-sig).

    Key architectural behaviors include: 1. In-place Directory Pruning: Modifies os.walk directory lists in-place during traversal to avoid descending into excluded branches (e.g., .venv, .git, node_modules). 2. Gitignore Matching: Dynamically locates and parses .gitignore at the root of the targeted crawl directory using gitwildmatch path specification rules. 3. Multi-Stage File Filtering: Validates file paths sequentially against .gitignore specs, glob exclude patterns, glob include patterns, maximum byte size constraints, and text decodability. 4. ANSI Color-Coded Progress Telemetry: Outputs real-time console status logs and summarizes crawl statistics at completion.

    Module-Level Functions

    crawl_local_files()

    Visibility: Public
    Signature: def crawl_local_files(directory, include_patterns=None, exclude_patterns=None, max_file_size=None, use_relative_paths=True) -> dict

    Description: Scans a target directory on the local disk, evaluates all encountered directory trees and individual files against filtering rules, reads decodable text files into memory, and returns a dictionary mapping file paths to their textual contents.

    Parameters: * directory (str): Absolute or relative filesystem path to the target directory. * include_patterns (set | None, optional): Optional set of wildcard glob patterns (e.g., {"*.py", "*.js"}) defining files to include. Defaults to None (all decodable files included). * exclude_patterns (set | None, optional): Optional set of wildcard glob patterns (e.g., {"tests/*", "*.pyc"}) defining paths to exclude. Defaults to None. * max_file_size (int | None, optional): Maximum allowable file size in bytes. Files exceeding this threshold are skipped. Defaults to None. * use_relative_paths (bool, optional): Whether the returned dictionary keys and log entries use relative paths from directory. Defaults to True.

    Returns: * dict: A dictionary containing the processed text files: 

    {"files": {filepath: content}}

    Raises: * ValueError: Raised if directory does not exist or is not a valid directory path on the local filesystem.

    Implementation Details

    1. Directory Validation, Setup, and .gitignore Parsing
        if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- ANSI colors ---
    C_GREEN  = "\033[92m"
    C_GRAY   = "\033[90m"
    C_RED    = "\033[91m"
    C_RESET  = "\033[0m"

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Load .gitignore ---
    gitignore_path = os.path.join(directory, ".gitignore")
    gitignore_spec = None
    if os.path.exists(gitignore_path):
        try:
            with open(gitignore_path, "r", encoding="utf-8-sig") as f:
                gitignore_patterns = f.readlines()
            gitignore_spec = pathspec.PathSpec.from_lines("gitwildmatch", gitignore_patterns)
            print(f"Loaded .gitignore patterns from {gitignore_path}")
        except Exception as e:
            print(f"Warning: Could not read or parse .gitignore file {gitignore_path}: {e}")

    The function validates that the target path points to an existing directory before initializing tracking metrics and terminal styling constants. It searches for a .gitignore file located at the root of directory and compiles its patterns using pathspec.PathSpec.from_lines("gitwildmatch", ...). If the .gitignore file cannot be read or parsed, a warning is logged to standard output, and crawl operations proceed with gitignore_spec set to None.

    2. In-Place Directory Traversal and Pruning
        # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            dirpath_rel = os.path.relpath(os.path.join(root, d), directory)

            reason = None
            if gitignore_spec and gitignore_spec.match_file(dirpath_rel):
                reason = "excluded (.gitignore)"
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern[:-2] if pattern.endswith("/*") else pattern
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = "excluded"
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {dirpath_rel}/ [{reason}]{C_RESET}")

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()

    Directory filtering is performed inline on each iteration of os.walk. The code checks relative directory paths against the compiled .gitignore spec and standard wildcard exclusions. If a pattern ends with /*, the trailing characters are stripped so the directory name itself can match. Matched directories are removed directly from dirs via dirs.remove(d), which prevents os.walk from descending into child directories. The remaining directories are sorted to enforce deterministic traversal across different operating systems and filesystems.

    3. File Filtering, Decoding, and Ingestion
            # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore
            if gitignore_spec and gitignore_spec.match_file(relpath):
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (.gitignore)]{C_RESET}")
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded]{C_RESET}")
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (not in include list)]{C_RESET}")
                    continue

            # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                print(f"{C_RED}  [{entry_num}] {relpath} [size limit: {size_kb:.0f}KB]{C_RESET}")
                continue

            # Try to read as text
            try:
                with open(filepath, "r", encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                print(f"{C_GREEN}  [{entry_num}] {relpath} [processed]{C_RESET}")
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: not a text file]{C_RESET}")
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: {e}]{C_RESET}")

    Each file in the active directory is sorted and evaluated sequentially against filtering rules: 1. Matched against .gitignore rules via pathspec. 2. Matched against exclude_patterns via fnmatch. 3. Verified against include_patterns (if specified). 4. Checked against max_file_size using os.getsize(filepath).

    Files passing these filters are opened using utf-8-sig encoding (which handles UTF-8 with and without a Byte Order Mark). If reading fails with UnicodeDecodeError or ValueError, the file is flagged as non-text, recorded in skipped_non_text, and skipped without raising an unhandled exception.

    4. Crawl Summary Telemetry
        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    print(f"\n--- Crawl Summary ---")
    print(f"  Total found : {total_fetched}")
    print(f"{C_GREEN}  Processed   : {count_processed}{C_RESET}")
    if count_excluded > 0:
        print(f"{C_GRAY}  Excluded    : {count_excluded}{C_RESET}")
    if count_size_limit > 0:
        print(f"{C_RED}  Size limit  : {count_size_limit}{C_RESET}")
        for f in skipped_size_limit:
            print(f"{C_RED}    - {f}{C_RESET}")
    if count_non_text > 0:
        print(f"{C_RED}  Non-text    : {count_non_text}{C_RESET}")
        for f in skipped_non_text:
            print(f"{C_RED}    - {f}{C_RESET}")
    print(f"---------------------")

    return {"files": files_dict}

    After visiting all non-pruned paths in os.walk, the function generates a console summary detailing total entries encountered, successfully processed files, excluded paths, files exceeding the size limit, and unreadable binary or non-text files. The final payload is returned as a dictionary with the processed file map.

    Executable Entrypoint

    The module includes a standalone testing block under if __name__ == "__main__": to facilitate isolated validation of the crawler against the local parent directory.

    if __name__ == "__main__":
    print("--- Crawling parent directory ('..') ---")
    files_data = crawl_local_files(
        "..",
        exclude_patterns={
            "*.pyc",
            "__pycache__/*",
            ".venv/*",
            ".git/*",
            "docs/*",
            "output/*",
        },
    )
    print(f"Found {len(files_data['files'])} files:")
    for path in files_data["files"]:
        print(f"  {path}")

    When executed directly (python -m utils.crawl_local_files), the script targets the parent directory (..), filters out common build artifacts, cache folders, and output directories, and prints each ingested relative file path to standard output.
