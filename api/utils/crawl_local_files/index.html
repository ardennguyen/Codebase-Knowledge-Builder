    utils.crawl_local_files

    Original File Path: utils/crawl_local_files.py

    This module is the local filesystem counterpart to utils.crawl_github_files. It extracts, filters, and loads text file contents from a local directory tree into an in-memory dictionary.

    Technical Overview

    The primary responsibility of utils.crawl_local_files is to traverse a directory hierarchy on the local filesystem, evaluate files and directories against exclusion rules and ignore files, filter candidate items based on include patterns and byte size limits, and parse valid text files into memory.

    Key features and execution characteristics include: 1. .gitignore Integration: Automatically searches for a root .gitignore file within the specified directory and compiles its rules into a pathspec.PathSpec matcher using the gitwildmatch pattern grammar. 2. Directory Pruning: Inspects subdirectories during traversal and removes excluded directories from dirs in-place within os.walk, preventing recursive traversal into ignored subtrees (such as .venv, __pycache__, or .git). 3. Multi-Stage File Filtering: Filters individual files in a structured sequence: .gitignore matching, explicit exclude_patterns, positive matching against include_patterns, and maximum file size thresholds (max_file_size). 4. Encoding & Binary Safety: Reads files using utf-8-sig encoding (handling UTF-8 with or without Byte Order Mark) and traps UnicodeDecodeError, ValueError, and other I/O exceptions to skip non-text or binary files cleanly. 5. Console Progress Telemetry: Outputs formatted ANSI-colored log lines for every evaluated path along with an aggregate execution summary upon completion.

    Module-Level Functions

    crawl_local_files()

    Visibility: Public
    Signature: def crawl_local_files(directory, include_patterns=None, exclude_patterns=None, max_file_size=None, use_relative_paths=True)

    Description:
    Traverses the specified directory path using os.walk, applying exclusion and inclusion matching logic against directories and files. The function parses and enforces root .gitignore files via pathspec, enforces size limits on candidate files, reads UTF-8 text contents, and generates console output detailing the status of every file and directory encountered.

    Core Implementation:

    def crawl_local_files(
    directory,
    include_patterns=None,
    exclude_patterns=None,
    max_file_size=None,
    use_relative_paths=True,
):
    if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- ANSI colors ---
    C_GREEN = "\033[92m"
    C_GRAY = "\033[90m"
    C_RED = "\033[91m"
    C_RESET = "\033[0m"

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Load .gitignore ---
    gitignore_path = os.path.join(directory, ".gitignore")
    gitignore_spec = None
    if os.path.exists(gitignore_path):
        try:
            with open(gitignore_path, "r", encoding="utf-8-sig") as f:
                gitignore_patterns = f.readlines()
            gitignore_spec = pathspec.PathSpec.from_lines("gitwildmatch", gitignore_patterns)
            print(f"Loaded .gitignore patterns from {gitignore_path}")
        except Exception as e:
            print(f"Warning: Could not read or parse .gitignore file {gitignore_path}: {e}")

    # ... [Directory and File Filtering Logic] ...

    The function first verifies that the target directory exists and is a directory; if not, it immediately raises a ValueError. It initializes tracking counters for processed files, excluded paths, size-exceeded files, and non-text/binary files. Next, it checks for a .gitignore file located at the root of directory. If present, it loads all lines and compiles a pathspec.PathSpec instance using the gitwildmatch rule set. If reading or compiling the .gitignore fails, it logs a warning message to standard output and continues execution with gitignore_spec set to None.

    Directory Pruning Logic:

        # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            dirpath_rel = os.path.relpath(os.path.join(root, d), directory)

            reason = None
            if gitignore_spec and gitignore_spec.match_file(dirpath_rel):
                reason = "excluded (.gitignore)"
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern[:-2] if pattern.endswith("/*") else pattern
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = "excluded"
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {dirpath_rel}/ [{reason}]{C_RESET}")

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()

        # ... [File Processing Loop] ...

    During each step of os.walk, subdirectories in dirs are evaluated before entering them. For every directory name d, the relative path from directory is computed. If gitignore_spec matches the relative directory path, or if exclude_patterns match the relative directory path or folder name directly (with trailing /* wildcard suffixes stripped), the directory is added to excluded_dirs. The excluded entries are then removed in-place from dirs using dirs.remove(d). This mutates the active list used by os.walk, pruning entire directory trees from subsequent traversal and avoiding redundant filesystem operations.

    File Processing and Reading Logic:

            # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore
            if gitignore_spec and gitignore_spec.match_file(relpath):
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (.gitignore)]{C_RESET}")
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded]{C_RESET}")
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (not in include list)]{C_RESET}")
                    continue

            # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                print(f"{C_RED}  [{entry_num}] {relpath} [size limit: {size_kb:.0f}KB]{C_RESET}")
                continue

            # Try to read as text
            try:
                with open(filepath, "r", encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                print(f"{C_GREEN}  [{entry_num}] {relpath} [processed]{C_RESET}")
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: not a text file]{C_RESET}")
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: {e}]{C_RESET}")

    Files within retained directories are processed in sorted order. For each file, the path key is calculated as relative or absolute based on use_relative_paths. The file is checked against gitignore_spec, exclude_patterns, and include_patterns. If all filter checks pass, the byte size is validated against max_file_size. If valid, the file is opened with encoding="utf-8-sig". If the content fails to decode (raising UnicodeDecodeError or ValueError), the error is caught, the file is categorized as non-text, and execution continues without crashing.

    Reporting and Output Summary:

        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    print("\n--- Crawl Summary ---")
    print(f"  Total found : {total_fetched}")
    print(f"{C_GREEN}  Processed   : {count_processed}{C_RESET}")
    if count_excluded > 0:
        print(f"{C_GRAY}  Excluded    : {count_excluded}{C_RESET}")
    if count_size_limit > 0:
        print(f"{C_RED}  Size limit  : {count_size_limit}{C_RESET}")
        for f in skipped_size_limit:
            print(f"{C_RED}    - {f}{C_RESET}")
    if count_non_text > 0:
        print(f"{C_RED}  Non-text    : {count_non_text}{C_RESET}")
        for f in skipped_non_text:
            print(f"{C_RED}    - {f}{C_RESET}")
    print("---------------------")

    return {"files": files_dict}

    Once the filesystem walk is complete, the function tallies the total entries encountered and prints a summary block highlighting the count of processed, excluded, size-limited, and non-text files using ANSI color codes (C_GREEN, C_GRAY, C_RED, C_RESET). The resulting dictionary is returned in the format {"files": {filepath: content}}.

    Parameters: * directory (str): The root path to the local directory to be traversed. * include_patterns (set or None): Optional collection of glob patterns that files must match (e.g., {"*.py", "*.js"}). If None, no include filtering is applied. * exclude_patterns (set or None): Optional collection of glob patterns for files and directories to exclude (e.g., {"tests/*", "*.pyc"}). * max_file_size (int or None): Maximum allowed file size in bytes. Files exceeding this threshold are skipped. * use_relative_paths (bool): Whether the dictionary keys returned in "files" should be paths relative to directory (True) or full filesystem paths (False). Defaults to True.

    Returns: * dict: A dictionary containing a single key "files", which maps file path strings to their decoded text content strings: 

    {
    "files": {
        "utils/crawl_local_files.py": "import fnmatch...",
        "README.md": "# Project Title..."
    }
}

    Raises: * ValueError: Raised if directory does not exist or is not a valid directory (not os.path.isdir(directory)).

    Example: 

    if __name__ == "__main__":
    print("--- Crawling parent directory ('..') ---")
    files_data = crawl_local_files(
        "..",
        exclude_patterns={
            "*.pyc",
            "__pycache__/*",
            ".venv/*",
            ".git/*",
            "docs/*",
            "output/*",
        },
    )
    print(f"Found {len(files_data['files'])} files:")
    for path in files_data["files"]:
        print(f"  {path}")
