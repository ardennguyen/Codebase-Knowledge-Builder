    utils.crawl_local_files

    Original File Path: utils/crawl_local_files.py

    Technical Overview

    The utils.crawl_local_files module implements a filesystem crawler designed to traverse local directory trees, parse file contents, and collect text data into an in-memory dictionary. It serves as the local counterpart to crawl_github_files, sharing a standardized return schema ({"files": {filepath: content}}) to provide pipeline nodes with an agnostic ingestion interface.

    The crawler performs a single-pass traversal using os.walk, dynamically pruning directories in place to prevent unnecessary filesystem traversal. It applies a multi-tiered filtering pipeline in the following sequence:

    1. Gitignore Evaluation: Parses root .gitignore files using pathspec with gitwildmatch rules.
    2. Directory Exclusion Filtering: Evaluates directory paths against caller-specified glob exclusion rules and prunes matched directories from os.walk traversal.
    3. File Exclusion Filtering: Checks files against user-defined exclusion patterns using fnmatch.
    4. File Inclusion Filtering: Validates files against inclusion rules (when specified).
    5. Size Limit Checking: Rejects files exceeding byte-threshold constraints using os.path.getsize.
    6. UTF-8 Ingestion and Decoding: Attempts decoding using utf-8-sig to handle byte order marks (BOM) gracefully while filtering out non-text/binary files.

    The module provides colored terminal diagnostics using ANSI escape codes and generates an execution summary detailing processed files, exclusions, size rejections, and binary decode failures.

    Module-Level Functions

    crawl_local_files()

    Visibility: Public
    Signature: def crawl_local_files(directory, include_patterns=None, exclude_patterns=None, max_file_size=None, use_relative_paths=True) -> dict

    Description:
    Crawls a local directory tree recursively, applying exclusion rules, .gitignore wildcards, inclusion patterns, size thresholds, and text encoding checks. Extracted file contents are returned in a dictionary keyed by file path.

    Parameters: * directory (str): The path to the root directory on the local filesystem to crawl. * include_patterns (set, optional): Glob patterns defining which files to include (e.g., {"*.py", "*.js"}). Defaults to None. * exclude_patterns (set, optional): Glob patterns defining files or directories to exclude (e.g., {"tests/*", "*.pyc"}). Defaults to None. * max_file_size (int, optional): The maximum allowable file size in bytes. Files exceeding this threshold are skipped. Defaults to None. * use_relative_paths (bool, optional): When True, returned dictionary keys are formatted relative to directory. When False, keys contain the full path. Defaults to True.

    Returns: * dict: A dictionary containing a single key "files", mapping string file paths to their decoded string contents: {"files": {filepath: content}}.

    Raises: * ValueError: Raised if directory does not exist or is not a valid filesystem directory.

    def crawl_local_files(
    directory,
    include_patterns=None,
    exclude_patterns=None,
    max_file_size=None,
    use_relative_paths=True,
):
    if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- ANSI colors ---
    C_GREEN = "\033[92m"
    C_GRAY = "\033[90m"
    C_RED = "\033[91m"
    C_RESET = "\033[0m"

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Load .gitignore ---
    gitignore_path = os.path.join(directory, ".gitignore")
    gitignore_spec = None
    if os.path.exists(gitignore_path):
        try:
            with open(gitignore_path, encoding="utf-8-sig") as f:
                gitignore_patterns = f.readlines()
            gitignore_spec = pathspec.PathSpec.from_lines("gitwildmatch", gitignore_patterns)
            print(f"Loaded .gitignore patterns from {gitignore_path}")
        except Exception as e:
            print(f"Warning: Could not read or parse .gitignore file {gitignore_path}: {e}")

    # ... (directory walking and file filtering logic) ...

    The initialization block validates the existence of the target root path via os.path.isdir, raising a ValueError immediately if invalid. It initializes tracking counters for CLI reporting and attempts to discover a .gitignore file located directly within directory. When present, lines are read using utf-8-sig encoding and compiled into a pathspec.PathSpec object using the standard gitwildmatch syntax. If .gitignore reading fails, the error is caught and reported to standard output without interrupting the crawl.

        # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            dirpath_rel = os.path.relpath(os.path.join(root, d), directory)

            reason = None
            if gitignore_spec and gitignore_spec.match_file(dirpath_rel):
                reason = "excluded (.gitignore)"
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = "excluded"
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {dirpath_rel}/ [{reason}]{C_RESET}")

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()

        # ... (file filtering and ingestion logic) ...

    Directory pruning is performed inside the os.walk loop before recursing into subdirectories. Each directory name in dirs is converted to a relative path and checked against the compiled gitignore_spec and the caller's exclude_patterns. Patterns suffixed with /* are normalized using removesuffix("/*") to ensure matching on directory names and paths. Directories identified for exclusion are removed directly from dirs in place using dirs.remove(d), which instructs os.walk not to traverse into those directory branches.

            # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore
            if gitignore_spec and gitignore_spec.match_file(relpath):
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (.gitignore)]{C_RESET}")
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded]{C_RESET}")
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (not in include list)]{C_RESET}")
                    continue

            # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                print(f"{C_RED}  [{entry_num}] {relpath} [size limit: {size_kb:.0f}KB]{C_RESET}")
                continue

            # Try to read as text
            try:
                with open(filepath, encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                print(f"{C_GREEN}  [{entry_num}] {relpath} [processed]{C_RESET}")
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: not a text file]{C_RESET}")
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: {e}]{C_RESET}")

    Files within each retained directory are processed in deterministic alphabetical order (sorted(files)). The function resolves the appropriate path representation (relpath vs filepath) and evaluates the file against .gitignore rules, explicit glob exclusions (fnmatch), and inclusion constraints. If a file passes pattern checks, os.path.getsize checks against max_file_size. Files passing all filters are opened with encoding="utf-8-sig". If reading raises UnicodeDecodeError or ValueError, the file is flagged as non-text and omitted from files_dict.

        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    print("\n--- Crawl Summary ---")
    print(f"  Total found : {total_fetched}")
    print(f"{C_GREEN}  Processed   : {count_processed}{C_RESET}")
    if count_excluded > 0:
        print(f"{C_GRAY}  Excluded    : {count_excluded}{C_RESET}")
    if count_size_limit > 0:
        print(f"{C_RED}  Size limit  : {count_size_limit}{C_RESET}")
        for f in skipped_size_limit:
            print(f"{C_RED}    - {f}{C_RESET}")
    if count_non_text > 0:
        print(f"{C_RED}  Non-text    : {count_non_text}{C_RESET}")
        for f in skipped_non_text:
            print(f"{C_RED}    - {f}{C_RESET}")
    print("---------------------")

    return {"files": files_dict}

    Once the directory walk completes, summary telemetry is aggregated and output to the terminal. The summary categorizes entries into total entries discovered, successfully processed text files, excluded files and directories, files exceeding byte size limits, and skipped non-text or unreadable files. The accumulated files_dict is then packaged into the output dictionary and returned.

    Technical Details and Edge Cases

    In-Place Directory Pruning

    crawl_local_files uses Python's standard os.walk(directory) generator. To prevent walking down massive dependency trees (such as node_modules or .venv), the function mutates dirs in place using dirs.remove(d) after iterating over a snapshot copy (dirs.copy()). This prevents os.walk from descending into matching directory sub-trees, significantly reducing crawl latency and filesystem I/O.

    Path Normalization

    Directory patterns often contain trailing glob syntax such as docs/* or .git/*. The directory filtering logic applies pattern.removesuffix("/*") to normalize user-defined exclusion patterns prior to evaluating relative directory paths with fnmatch.fnmatch.

    BOM and Binary Detection

    All file read operations utilize utf-8-sig. This ensures that files generated on Windows systems containing UTF-8 Byte Order Marks (0xEF, 0xBB, 0xBF) are loaded without corrupting the initial tokens of the content string. Binary files (such as compiled binaries, images, or archives) naturally fail UTF-8 decoding and trigger UnicodeDecodeError, allowing them to be classified as non-text without requiring external MIME-type inspection libraries.
