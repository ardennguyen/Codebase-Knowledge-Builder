    utils.crawl_local_files

    Original source file: utils/crawl_local_files.py

    This module provides directory traversal and content extraction capabilities for local filesystem targets within the Codebase-Knowledge-Builder system. It scans a specified local directory tree, applies exclusion and inclusion filters (including native .gitignore pattern matching via pathspec and glob matching via fnmatch), enforces file size constraints, filters out non-text or binary assets, and reads UTF-8 encoded file content into an in-memory dictionary.

    The module provides an identical output dictionary structure ({"files": {filepath: content}}) as utils.crawl_github_files, enabling graph ingestion nodes such as those in nodes and execution graphs in flow to consume file trees uniformly regardless of whether the source repository is remote (GitHub) or local.

    Module-Level Functions

    crawl_local_files()

    Visibility: Public
    Signature: def crawl_local_files(directory, include_patterns=None, exclude_patterns=None, max_file_size=None, use_relative_paths=True)

    Description: Crawls a local directory recursively using os.walk, pruning excluded directories in-place before traversing into them. It loads .gitignore rules from the root directory using pathspec.PathSpec.from_lines("gitwildmatch", ...) and evaluates both directory names and file paths against gitignore rules, explicit exclusion patterns, and inclusion sets.

    For each qualifying file, it verifies that the file size on disk does not exceed max_file_size (if defined), then attempts to read the content using UTF-8 encoding (handling Byte Order Marks via utf-8-sig). Files triggering UnicodeDecodeError or other read errors are categorized as non-text assets and skipped. The function tracks operational metrics (processed, excluded, size limit exceeded, non-text) and prints color-coded ANSI status logs for each entry alongside a final crawl summary.

    Parameters: * directory (str): The absolute or relative path to the local root directory to scan. * include_patterns (set, optional): Glob patterns specifying files to include (e.g., {"*.py", "*.js"}). Defaults to None. * exclude_patterns (set, optional): Glob patterns specifying files or directory prefixes to skip (e.g., {"tests/*", "*.pyc"}). Defaults to None. * max_file_size (int, optional): Maximum allowable file size in bytes. Files exceeding this threshold are skipped. Defaults to None. * use_relative_paths (bool, optional): Whether the returned dictionary keys and logged paths should be relative to directory (True) or full paths (False). Defaults to True.

    Returns: * dict: A dictionary containing a single "files" key mapped to an inner dictionary of {filepath: content}, where filepath is the file path string and content is the decoded string content.

    Raises: * ValueError: Raised if the supplied directory path does not exist or is not a valid directory according to os.path.isdir().

    Implementation Logic

        if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- ANSI colors ---
    C_GREEN = "\033[92m"
    C_GRAY = "\033[90m"
    C_RED = "\033[91m"
    C_RESET = "\033[0m"

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Load .gitignore ---
    gitignore_path = os.path.join(directory, ".gitignore")
    gitignore_spec = None
    if os.path.exists(gitignore_path):
        try:
            with open(gitignore_path, encoding="utf-8-sig") as f:
                gitignore_patterns = f.readlines()
            gitignore_spec = pathspec.PathSpec.from_lines("gitwildmatch", gitignore_patterns)
            print(f"Loaded .gitignore patterns from {gitignore_path}")
        except Exception as e:
            print(f"Warning: Could not read or parse .gitignore file {gitignore_path}: {e}")

    The initial segment validates directory existence, defines ANSI escape codes (\033[92m, \033[90m, \033[91m, \033[0m) for console logging, initializes counters and failure tracking lists, and attempts to load a .gitignore file from the target directory root. If present, patterns are compiled into a pathspec.PathSpec object using the gitwildmatch dialect; parsing failures emit warnings without halting execution.

        # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            dirpath_rel = os.path.relpath(os.path.join(root, d), directory)

            reason = None
            if gitignore_spec and gitignore_spec.match_file(dirpath_rel):
                reason = "excluded (.gitignore)"
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = "excluded"
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {dirpath_rel}/ [{reason}]{C_RESET}")

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()

    Directory traversal operates via os.walk. For each step, subdirectories in dirs are evaluated against gitignore_spec and exclude_patterns. Patterns ending in /* are stripped using .removesuffix("/*") to allow directory matching on both the relative directory path and the directory basename. Matching directories are removed from dirs in-place, preventing os.walk from descending into unneeded directory trees (such as .git or node_modules).

            # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore
            if gitignore_spec and gitignore_spec.match_file(relpath):
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (.gitignore)]{C_RESET}")
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded]{C_RESET}")
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (not in include list)]{C_RESET}")
                    continue

            # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                print(f"{C_RED}  [{entry_num}] {relpath} [size limit: {size_kb:.0f}KB]{C_RESET}")
                continue

            # Try to read as text
            try:
                with open(filepath, encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                print(f"{C_GREEN}  [{entry_num}] {relpath} [processed]{C_RESET}")
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: not a text file]{C_RESET}")
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: {e}]{C_RESET}")

    Files are sorted alphabetically for deterministic iteration. Each file undergoes a four-stage filtering check: 1. .gitignore pattern matching using pathspec. 2. Explicit exclude_patterns matching using fnmatch.fnmatch. 3. Explicit include_patterns validation (if configured). 4. File size threshold verification using os.path.getsize(filepath).

    Files passing all checks are read with UTF-8 encoding. If decoding fails due to non-text or binary contents, UnicodeDecodeError and ValueError are caught, incrementing count_non_text and skipping the file without throwing unhandled exceptions.

        # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    print("\n--- Crawl Summary ---")
    print(f"  Total found : {total_fetched}")
    print(f"{C_GREEN}  Processed   : {count_processed}{C_RESET}")
    if count_excluded > 0:
        print(f"{C_GRAY}  Excluded    : {count_excluded}{C_RESET}")
    if count_size_limit > 0:
        print(f"{C_RED}  Size limit  : {count_size_limit}{C_RESET}")
        for f in skipped_size_limit:
            print(f"{C_RED}    - {f}{C_RESET}")
    if count_non_text > 0:
        print(f"{C_RED}  Non-text    : {count_non_text}{C_RESET}")
        for f in skipped_non_text:
            print(f"{C_RED}    - {f}{C_RESET}")
    print("---------------------")

    return {"files": files_dict}

    The summary block calculates total entries processed and prints categorized totals to the standard output. Files skipped due to size limits or decoding failures are enumerated individually under red ANSI formatting.
