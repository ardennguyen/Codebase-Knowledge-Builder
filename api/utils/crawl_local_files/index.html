    utils.crawl_local_files

    utils/crawl_local_files.py

    As the local filesystem counterpart to utils.crawl_github_files, this module provides directory traversal, file filtering, and content extraction capabilities for repositories stored locally on disk. It produces an output dictionary structure matching the remote GitHub crawler ({"files": {filepath: content}}), ensuring seamless interoperability across the ingestion pipeline.

    Technical Overview

    The module traverses local directories using a single-pass os.walk strategy with in-place directory pruning. During traversal, it respects git-ignore rules, glob inclusion/exclusion patterns, and file size limits, while safely extracting UTF-8 text content and discarding binary files.

    Key Capabilities

    1. .gitignore Integration: Automatically detects and compiles repository-level .gitignore files using pathspec (with gitwildmatch syntax) to prune ignored paths before traversal.
    2. Directory Pruning: Mutates dirs in-place during os.walk execution to prevent traversing into excluded directory trees (e.g., .git, virtual environments, or node_modules).
    3. Filtering Pipeline: Applies exclusion patterns, inclusion filters, and size constraints sequentially to minimize unnecessary I/O operations.
    4. Encoding & Binary Safety: Reads file contents using utf-8-sig to automatically strip byte-order marks (BOM) while capturing UnicodeDecodeError and general exceptions to skip binary assets.
    5. ANSI Console Reporting: Emits formatted, color-coded logging for each encountered item and outputs a structured summary table at the end of the crawl process.

    Module-Level Functions

    crawl_local_files()

    Visibility: Public
    Signature: def crawl_local_files(directory, include_patterns=None, exclude_patterns=None, max_file_size=None, use_relative_paths=True)

    Description:
    Crawls a local directory path, applying gitignore specifications, user-defined exclusion patterns, inclusion patterns, and file size restrictions. Files that pass all filter stages are read from disk using the utf-8-sig encoding format and stored in an internal dictionary indexed by their path.

    Parameters: * directory (str): Target root filesystem path to crawl. * include_patterns (set | None): Optional set of glob patterns indicating which files should be included (e.g., {"*.py", "*.js"}). If provided, any file not matching at least one pattern is excluded. * exclude_patterns (set | None): Optional set of glob patterns indicating files or directories to skip (e.g., {"tests/*", "*.pyc"}). * max_file_size (int | None): Maximum allowed file size in bytes. Larger files are bypassed. * use_relative_paths (bool): If True, keys in the returned dictionary are relative to directory. If False, absolute/resolved filesystem paths are retained. Default is True.

    Returns: * dict: A dictionary containing a single key "files", mapping string file paths to their read string contents: 

    {"files": {filepath: content}}

    Raises: * ValueError: Raised immediately if directory does not exist or is not recognized as a directory by os.path.isdir.

    Implementation Logic:

        if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- ANSI colors ---
    C_GREEN = "\033[92m"
    C_GRAY = "\033[90m"
    C_RED = "\033[91m"
    C_RESET = "\033[0m"

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Load .gitignore ---
    gitignore_path = os.path.join(directory, ".gitignore")
    gitignore_spec = None
    if os.path.exists(gitignore_path):
        try:
            with open(gitignore_path, encoding="utf-8-sig") as f:
                gitignore_patterns = f.readlines()
            gitignore_spec = pathspec.PathSpec.from_lines("gitwildmatch", gitignore_patterns)
            print(f"Loaded .gitignore patterns from {gitignore_path}")
        except Exception as e:
            print(f"Warning: Could not read or parse .gitignore file {gitignore_path}: {e}")
    # ...

    The function initiates by validating the directory and preparing console logging tracking variables. It looks for a top-level .gitignore file within the specified directory. When found, it parses the ignore lines into a pathspec.PathSpec object using the gitwildmatch standard. Parsing errors are caught gracefully with a warning output, allowing the crawl to proceed even if .gitignore syntax is invalid or unreadable.

        # ...
    # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            dirpath_rel = os.path.relpath(os.path.join(root, d), directory)

            reason = None
            if gitignore_spec and gitignore_spec.match_file(dirpath_rel):
                reason = "excluded (.gitignore)"
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = "excluded"
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {dirpath_rel}/ [{reason}]{C_RESET}")

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()
        # ...

    For directory pruning, os.walk is traversed top-down. Candidate directory names in dirs are evaluated against both the parsed .gitignore pattern specification and the caller-provided exclude_patterns (handling patterns with or without trailing /*). Any directory matching an exclusion rule is collected in excluded_dirs and purged in-place from dirs via dirs.remove(d). This prevents os.walk from descending into unnecessary subtrees, significantly reducing crawl time on large repositories. Remaining directories are sorted in-place to guarantee deterministic traversal order.

            # ...
        # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore
            if gitignore_spec and gitignore_spec.match_file(relpath):
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (.gitignore)]{C_RESET}")
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded]{C_RESET}")
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (not in include list)]{C_RESET}")
                    continue

            # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                print(f"{C_RED}  [{entry_num}] {relpath} [size limit: {size_kb:.0f}KB]{C_RESET}")
                continue

            # Try to read as text
            try:
                with open(filepath, encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                print(f"{C_GREEN}  [{entry_num}] {relpath} [processed]{C_RESET}")
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: not a text file]{C_RESET}")
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: {e}]{C_RESET}")
    # ...

    Files within each directory are evaluated in sorted order. For each candidate file: 1. It is matched against .gitignore using pathspec.match_file(). 2. It is checked against caller-provided exclude_patterns using fnmatch.fnmatch(). 3. If include_patterns is provided, the path must match at least one inclusion pattern; otherwise, it is skipped. 4. If max_file_size is specified and the file's disk size exceeds this threshold, the file is skipped and logged with its size in kilobytes. 5. If all checks pass, the file is opened with utf-8-sig encoding. If the file is binary or has an incompatible encoding, a UnicodeDecodeError or ValueError is caught, and the path is cataloged in skipped_non_text. Any other filesystem I/O exceptions are caught and reported as non-text errors without crashing the crawler.

        # ...
    # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    print("\n--- Crawl Summary ---")
    print(f"  Total found : {total_fetched}")
    print(f"{C_GREEN}  Processed   : {count_processed}{C_RESET}")
    if count_excluded > 0:
        print(f"{C_GRAY}  Excluded    : {count_excluded}{C_RESET}")
    if count_size_limit > 0:
        print(f"{C_RED}  Size limit  : {count_size_limit}{C_RESET}")
        for f in skipped_size_limit:
            print(f"{C_RED}    - {f}{C_RESET}")
    if count_non_text > 0:
        print(f"{C_RED}  Non-text    : {count_non_text}{C_RESET}")
        for f in skipped_non_text:
            print(f"{C_RED}    - {f}{C_RESET}")
    print("---------------------")

    return {"files": files_dict}

    Once os.walk finishes traversing the target directory tree, crawl_local_files aggregates statistics for total entries found, successfully processed files, excluded items, files exceeding the size threshold, and non-text/unreadable files. It prints this detailed breakdown to standard output and returns the final dictionary.

    Usage Example:

    # Extract from utils/crawl_local_files.py (__main__ execution block)
if __name__ == "__main__":
    print("--- Crawling parent directory ('..') ---")
    files_data = crawl_local_files(
        "..",
        exclude_patterns={
            "*.pyc",
            "__pycache__/*",
            ".venv/*",
            ".git/*",
            "docs/*",
            "output/*",
        },
    )
    print(f"Found {len(files_data['files'])} files:")
    for path in files_data["files"]:
        print(f"  {path}")
