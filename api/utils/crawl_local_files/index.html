    utils.crawl_local_files

    Source: utils/crawl_local_files.py

    Following the remote repository crawling capabilities documented in utils.crawl_github_files, the utils.crawl_local_files module provides local filesystem traversal and ingestion capabilities. It provides a drop-in local equivalent to crawl_github_files, producing an identical data contract ({"files": {filepath: content}}) to allow downstream pipeline components to ingest source code agnostic of whether the target repository is hosted remotely or stored locally.

    Technical Overview

    The primary responsibility of utils.crawl_local_files is recursively traversing a local workspace directory, filtering paths against project-defined rules, reading text content safely, and producing a unified dictionary mapping file paths to their raw string contents.

    Key architectural features include: - Gitignore Parsing: Automatically detects and loads root-level .gitignore files using pathspec.PathSpec.from_lines("gitwildmatch", ...) to honor repository-native ignore patterns. - Hierarchical Directory Pruning: Modifies directory lists in-place during os.walk to prevent recursing into excluded or git-ignored subtrees (such as node_modules, .git, or build artifact folders), reducing disk I/O. - Pattern Filtering: Applies user-supplied include_patterns and exclude_patterns through Python's standard fnmatch engine. - File Size Guardrails: Skips oversized files based on a configurable byte threshold (max_file_size). - Encoding Safety and Binary Rejection: Enforces utf-8-sig reading; files raising UnicodeDecodeError or ValueError are flagged as non-text binaries and bypassed. - Terminal Observability: Emits color-coded ANSI console logs per file and outputs a detailed execution summary upon completion.

    Processing Pipeline Workflow

    The local crawl process operates in a sequential filter pipeline per filesystem entry discovered during tree traversal:

    Module-Level Functions

    crawl_local_files()

    Visibility: Public
    Signature: def crawl_local_files(directory, include_patterns=None, exclude_patterns=None, max_file_size=None, use_relative_paths=True):

    Description: Traverses a local directory recursively, applies multi-stage filtering (.gitignore, exclusion glob patterns, inclusion glob patterns, file size limits), reads valid text files using utf-8-sig encoding, and returns a dictionary of file contents structured identically to the GitHub crawler.

    Core Implementation: Setup and .gitignore Parsing

        if not os.path.isdir(directory):
        raise ValueError(f"Directory does not exist: {directory}")

    files_dict = {}

    # --- ANSI colors ---
    C_GREEN = "\033[92m"
    C_GRAY = "\033[90m"
    C_RED = "\033[91m"
    C_RESET = "\033[0m"

    # --- Counters ---
    entry_num = 0
    count_processed = 0
    count_excluded = 0
    count_size_limit = 0
    count_non_text = 0
    skipped_size_limit = []
    skipped_non_text = []

    # --- Load .gitignore ---
    gitignore_path = os.path.join(directory, ".gitignore")
    gitignore_spec = None
    if os.path.exists(gitignore_path):
        try:
            with open(gitignore_path, encoding="utf-8-sig") as f:
                gitignore_patterns = f.readlines()
            gitignore_spec = pathspec.PathSpec.from_lines("gitwildmatch", gitignore_patterns)
            print(f"Loaded .gitignore patterns from {gitignore_path}")
        except Exception as e:
            print(f"Warning: Could not read or parse .gitignore file {gitignore_path}: {e}")

    The function verifies that the supplied path points to a valid directory, raising a ValueError if the path does not exist or is not a directory. It initializes ANSI color constants for terminal logging and metric tracking counters. It checks for a .gitignore file located directly under directory. If present, the file is parsed line-by-line using pathspec.PathSpec.from_lines configured with the standard gitwildmatch pattern grammar. If parsing fails, an error is printed, and execution continues without gitignore filtering.

    Core Implementation: Directory Pruning and File Filtering

        # --- Single-pass: walk, filter, and process inline ---
    for root, dirs, files in os.walk(directory):
        # --- Directory filtering ---
        excluded_dirs = set()
        for d in sorted(dirs):
            dirpath_rel = os.path.relpath(os.path.join(root, d), directory)

            reason = None
            if gitignore_spec and gitignore_spec.match_file(dirpath_rel):
                reason = "excluded (.gitignore)"
            elif exclude_patterns:
                for pattern in exclude_patterns:
                    dir_pattern = pattern.removesuffix("/*")
                    if fnmatch.fnmatch(dirpath_rel, dir_pattern) or fnmatch.fnmatch(d, dir_pattern):
                        reason = "excluded"
                        break

            if reason:
                excluded_dirs.add(d)
                entry_num += 1
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {dirpath_rel}/ [{reason}]{C_RESET}")

        for d in dirs.copy():
            if d in excluded_dirs:
                dirs.remove(d)

        # Sort remaining dirs for consistent traversal order
        dirs.sort()

        # --- File processing (inline, sorted) ---
        for filename in sorted(files):
            filepath = os.path.join(root, filename)
            relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
            entry_num += 1

            # Check gitignore
            if gitignore_spec and gitignore_spec.match_file(relpath):
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (.gitignore)]{C_RESET}")
                continue

            # Check exclude patterns
            excluded = False
            if exclude_patterns:
                for pattern in exclude_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        excluded = True
                        break
            if excluded:
                count_excluded += 1
                print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded]{C_RESET}")
                continue

            # Check include patterns
            if include_patterns:
                matched = False
                for pattern in include_patterns:
                    if fnmatch.fnmatch(relpath, pattern):
                        matched = True
                        break
                if not matched:
                    count_excluded += 1
                    print(f"{C_GRAY}  [{entry_num}] {relpath} [excluded (not in include list)]{C_RESET}")
                    continue

    Directory pruning is performed during os.walk by mutating the dirs list in place. When a directory matches .gitignore patterns or any pattern in exclude_patterns (with trailing /* suffixes stripped), it is added to excluded_dirs and purged from dirs. This stops os.walk from descending into those directory trees. For the remaining directories, files are evaluated sequentially against .gitignore, exclude_patterns, and include_patterns using fnmatch.fnmatch.

    Core Implementation: Content Ingestion and Summary Reporting

                # Check size limit
            if max_file_size and os.path.getsize(filepath) > max_file_size:
                count_size_limit += 1
                skipped_size_limit.append(relpath)
                size_kb = os.path.getsize(filepath) / 1024
                print(f"{C_RED}  [{entry_num}] {relpath} [size limit: {size_kb:.0f}KB]{C_RESET}")
                continue

            # Try to read as text
            try:
                with open(filepath, encoding="utf-8-sig") as f:
                    content = f.read()
                files_dict[relpath] = content
                count_processed += 1
                print(f"{C_GREEN}  [{entry_num}] {relpath} [processed]{C_RESET}")
            except (UnicodeDecodeError, ValueError):
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: not a text file]{C_RESET}")
            except Exception as e:
                count_non_text += 1
                skipped_non_text.append(relpath)
                print(f"{C_RED}  [{entry_num}] {relpath} [cannot process: {e}]{C_RESET}")

    # --- Summary ---
    total_fetched = count_processed + count_excluded + count_size_limit + count_non_text
    print("\n--- Crawl Summary ---")
    print(f"  Total found : {total_fetched}")
    print(f"{C_GREEN}  Processed   : {count_processed}{C_RESET}")
    if count_excluded > 0:
        print(f"{C_GRAY}  Excluded    : {count_excluded}{C_RESET}")
    if count_size_limit > 0:
        print(f"{C_RED}  Size limit  : {count_size_limit}{C_RESET}")
        for f in skipped_size_limit:
            print(f"{C_RED}    - {f}{C_RESET}")
    if count_non_text > 0:
        print(f"{C_RED}  Non-text    : {count_non_text}{C_RESET}")
        for f in skipped_non_text:
            print(f"{C_RED}    - {f}{C_RESET}")
    print("---------------------")

    return {"files": files_dict}

    Files that pass pattern matching are checked against max_file_size using os.path.getsize. If within limits, the file is read using utf-8-sig encoding, stripping potential UTF-8 Byte Order Marks (BOM) automatically. Binary files, encoded binaries, or unreadable assets that raise UnicodeDecodeError or ValueError are captured and tallied in count_non_text. Finally, a formatted terminal summary is printed listing total scanned items, processed counts, exclusions, and failures, returning the populated dictionary.

    Parameters: * directory (str): Path to the target root directory on the local filesystem. * include_patterns (set, optional): Glob patterns of files to include (e.g. {"*.py", "*.js"}). If None or empty, all non-excluded files are included. * exclude_patterns (set, optional): Glob patterns for files or directories to exclude (e.g. {"tests/*", "*.pyc"}). * max_file_size (int, optional): Maximum allowable file size in bytes. Files exceeding this limit are skipped. * use_relative_paths (bool, optional): Whether the output dictionary keys should be relative to directory (True, default) or absolute system paths (False).

    Returns: * dict: A dictionary containing a single "files" key whose value is a dictionary mapping relative file paths to their raw text content: {"files": {filepath: content}}.

    Raises: * ValueError: Raised when directory does not exist or fails os.path.isdir(directory).

    Detailed Implementation Mechanics

    1. Directory Tree Pruning

    When crawling large source repositories, descending into build directories (dist/, build/) or dependency trees (node_modules/, .venv/) causes performance overhead. crawl_local_files avoids this by modifying the mutable dirs list provided by os.walk(directory): 

    for d in dirs.copy():
    if d in excluded_dirs:
        dirs.remove(d)
    Removing directory names from dirs prevents os.walk from recursing into those directories.

    2. Relative Path Normalization

    File path keys stored in the output dictionary are determined by the use_relative_paths flag: 

    relpath = os.path.relpath(filepath, directory) if use_relative_paths else filepath
    When use_relative_paths=True, paths match the standard repository-relative format (e.g., src/index.js, utils/crawl_local_files.py), maintaining compatibility with downstream nodes in nodes and remote crawler outputs from utils.crawl_github_files.
