    output.py

    Source: utils/output.py

    Following the path filtering rules defined in exclude_patterns.py, utils/output.py implements the centralized messaging, internationalization (i18n), terminal formatting, and diagnostic logging subsystem for the Codebase-Knowledge-Builder engine.

    Technical Overview

    utils/output.py provides a unified output interface that abstracts terminal styling, file logging, and localized message resolution across the entire repository analysis pipeline. By decoupling message invocation from raw string literals and direct terminal input/output (I/O), the subsystem ensures that all user-facing diagnostics, operational metrics, LLM interaction alerts, and generated documentation UI strings can be dynamically translated, formatted with context-specific arguments, and routed selectively to STDOUT, dedicated log files, or internal document builders.

    The module operates around an on-disk CSV localization store (utils/strings.csv). Upon startup, strings are parsed into memory. If non-English output is requested and translations for the target language are missing or incomplete, the module automatically delegates translation to the LLM subsystem via call_llm.py, persists the translated entries back into strings.csv with a UTF-8 Byte Order Mark (BOM) for Excel compatibility, and dynamically refreshes its internal lookup table. Output calls are routed through ANSI color palettes for terminal rendering and Python's native logging framework for persistent file-based tracing.

    Public API

    init()

    Visibility: Public
    Signature: def init(language="english", use_cache=True, thinking_level=None) -> None

    Description: Initializes the output subsystem by setting active language configurations, loading localization entries from strings.csv, and initiating automated LLM-driven translation for any missing strings in the target language. This must be invoked from the entry point (such as main.py) after parsing CLI flags and before calling emit().

    Parameters: * language (str): Target language name for CLI output and generated documentation (e.g., "english", "vietnamese"). Defaults to "english". * use_cache (bool): Flag passed down to LLM calls during automated translation to enable or bypass response caching. Defaults to True. * thinking_level (str | None): Reasoning effort budget configuration passed to translation LLM calls. Defaults to None.

    Returns: * None

    Raises: * Does not raise directly; internal file errors or LLM translation failures are caught defensively, with warnings emitted to terminal and fallbacks to English.

    Example: 

    def init(language="english", use_cache=True, thinking_level=None):
    """Initialize the output system: load strings.csv, set language, auto-translate missing.

    Must be called from main() after parsing CLI arguments but before any emit() calls.

    Args:
        language: Target language name (e.g., "Vietnamese").
        use_cache: Whether LLM caching is enabled (passed to translation calls).
        thinking_level: LLM thinking level (passed to translation calls).
    """
    global _language, _lang_col, _csv_path, _use_cache, _thinking_level
    _language = language.capitalize()
    _lang_col = language.lower()
    _csv_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "strings.csv")
    _use_cache = use_cache
    _thinking_level = thinking_level
    _load_strings()
    _auto_translate()

    The function configures global module state pointers, determines the absolute path to strings.csv relative to output.py, and triggers _load_strings(). Once the baseline strings dictionary is assembled, _auto_translate() checks whether any records in the specified language column are empty, translating them as a single batch if necessary.

    emit()

    Visibility: Public
    Signature: def emit(key, suffix="", **kwargs) -> None

    Description: Emits a localized, formatted string to standard output, the log file, or both, based on the record configuration in strings.csv. Applies variable substitutions safely via _format_safe(), appends any optional suffix text (such as token metrics), and applies terminal color codes according to the message's defined LEVEL.

    Parameters: * key (str): String identifier matching a STRING_KEY entry in strings.csv (e.g., "LLM_CALL_WRITE_CHAPTER"). * suffix (str): Optional text appended directly to the formatted message before emission (useful for raw token breakdowns or latency metrics). Defaults to "". * **kwargs: Key-value pairs matching {placeholder} tags defined in the target string template.

    Returns: * None

    Raises: * Does not raise exceptions. If key is missing from _strings, a fallback message [UNKNOWN STRING: {key}] is printed directly to STDOUT.

    Example: 

    def emit(key, suffix="", **kwargs):
    """Emit a translatable string to stdout and/or log file.

    Args:
        key: String key from strings.csv (e.g., "LLM_CALL_WRITE_CHAPTER").
        suffix: Optional extra text appended after the main message (e.g., token breakdown).
        **kwargs: Variables to substitute into the string template.
    """
    entry = _strings.get(key)
    if not entry:
        # Fallback for unknown keys — print raw so nothing is silently lost
        print(f"[UNKNOWN STRING: {key}]")
        return

    text = _format_safe(entry["text"], kwargs)
    if suffix:
        text = text + suffix

    level = entry["level"]
    dest = entry["dest"]
    color = COLORS.get(level, "")
    reset = RESET if color else ""

    if dest in ("BOTH", "STDOUT"):
        print(f"{color}{text}{reset}")
    if dest in ("BOTH", "LOG"):
        _logger.log(LOG_LEVELS.get(level, logging.INFO), text)

    The function queries _strings for the metadata dictionary associated with key. If found, _format_safe() interpolates the keyword arguments into entry["text"]. The message destination (entry["dest"]) dictates whether the styled payload is printed via print() to terminal with ANSI escape codes, logged to _logger using the mapped Python log level, or dispatched to both channels simultaneously.

    emit_raw()

    Visibility: Public
    Signature: def emit_raw(level, text, dest="BOTH") -> None

    Description: Emits unmanaged, dynamically formatted text directly to terminal output or logging channels with explicit level-based ANSI color styling. Used for structural CLI output not tracked in strings.csv, such as file lists, dynamic progress tables, batch splits, and raw error messages.

    Parameters: * level (str): The severity/style level matching a key in COLORS (e.g., "PROGRESS", "SUCCESS", "WARNING", "ERROR", "INFO", "DEBUG"). * text (str): The raw text message to be emitted. * dest (str): Target destination channel. Allowed values are "BOTH", "STDOUT", or "LOG". Defaults to "BOTH".

    Returns: * None

    Raises: * Does not raise exceptions.

    Example: 

    def emit_raw(level, text, dest="BOTH"):
    """Emit a pre-formatted string with explicit level styling.

    Use for dynamic/structural output that doesn't come from strings.csv
    (e.g., numbered file lists, batch details, crawl summary tables).
    """
    color = COLORS.get(level, "")
    reset = RESET if color else ""

    if dest in ("BOTH", "STDOUT"):
        print(f"{color}{text}{reset}")
    if dest in ("BOTH", "LOG"):
        _logger.log(LOG_LEVELS.get(level, logging.INFO), text)

    emit_raw resolves ANSI styling directly from COLORS using the provided level identifier. If dest includes "STDOUT", it prints the colored message followed by an ANSI reset code. If dest includes "LOG", it resolves the corresponding logging level via LOG_LEVELS (defaulting to logging.INFO) and writes the uncolored string payload to _logger.

    get()

    Visibility: Public
    Signature: def get(key, **kwargs) -> str

    Description: Resolves and returns a localized string without writing to terminal output or active log handlers. Used primarily by documentation generator nodes to retrieve localized section headers, table titles, and UI text elements embedded into generated markdown documents.

    Parameters: * key (str): String key identifier present in strings.csv. * **kwargs: Key-value pairs for template placeholder variable substitution.

    Returns: * str: The localized text string with all {placeholder} variables substituted, or the raw key if no matching record exists in _strings.

    Raises: * Does not raise exceptions.

    Example: 

    def get(key, **kwargs):
    """Get a translated string without printing or logging.

    Use for UI strings embedded in generated markdown (index.md headings, etc.).
    Returns the raw translated text with variable substitution applied.
    """
    entry = _strings.get(key)
    if not entry:
        return key  # Fallback: return the key itself
    return _format_safe(entry["text"], kwargs)

    The function accesses _strings to retrieve the active translation entry. If the key is not present, it gracefully returns key as a fallback. When an entry is found, it evaluates entry["text"] using _format_safe with the supplied kwargs dictionary, ensuring that UI labels can incorporate dynamic runtime numbers or paths without terminal formatting artifacts.

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name="project", mode="tutorial") -> str

    Description: Configures file-based logging for the active execution run. Generates a timestamped log file inside the directory specified by the LOG_DIR environment variable (defaulting to logs/), clears any pre-existing handlers on _logger (such as logging.NullHandler), registers a UTF-8 FileHandler, and records execution metadata headers.

    Parameters: * project_name (str): Name of the analyzed repository or target project, sanitized for filesystem safety. Defaults to "project". * mode (str): Active execution mode (e.g., "tutorial", "reference"). Defaults to "tutorial".

    Returns: * str: The absolute or normalized path to the created log file on disk.

    Raises: * OSError: If the log directory cannot be created due to filesystem permissions.

    Example: 

    def configure_logging(project_name="project", mode="tutorial"):
    """Configure file-based logging for this run.

    Creates a new log file per invocation:
        logs/{project_name}_{mode}_{YYYYMMDD_HHmmss}.log

    Must be called from main() after parsing CLI arguments.
    """
    from datetime import datetime

    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    _logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
    _logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    _logger.info(f"{'=' * 80}")
    _logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    _logger.info(f"Log file: {log_file}")
    _logger.info(f"{'=' * 80}")

    return log_file

    configure_logging creates the log directory via os.makedirs(..., exist_ok=True). It sanitizes project_name by replacing non-alphanumeric characters (excluding -, _, and .) with underscores, formats the current timestamp into %Y%m%d_%H%M%S, and constructs the output file path. It flushes any pre-existing handlers on _logger, binds a logging.FileHandler using UTF-8 encoding, configures a standard timestamp-level-message formatter, and writes run-header metadata directly into the log file.

    Internal Helpers

    _format_safe()

    Visibility: Private
    Signature: def _format_safe(template: str, kwargs: dict) -> str

    Description: Safely applies standard Python string formatting (str.format(**kwargs)) against a template string. Intercepts common formatting errors (such as missing placeholder variables, unescaped curly braces, or type mismatches) and returns the unformatted template intact rather than crashing the pipeline.

    Parameters: * template (str): String containing optional {placeholder} replacement tokens. * kwargs (dict): Dictionary of keyword replacements.

    Returns: * str: The successfully interpolated string, or the raw template if a formatting exception occurs.

    Raises: * Does not raise exceptions; catches KeyError, IndexError, and ValueError.

    Example: 

    def _format_safe(template, kwargs):
    """Apply .format(**kwargs) with graceful fallback on missing keys."""
    try:
        return template.format(**kwargs)
    except (KeyError, IndexError, ValueError):
        return template

    This helper wraps template.format(**kwargs) inside a defensive try-except block. In dynamic environments where LLMs or external configurations might pass partially populated variable sets, catching KeyError (missing placeholder value), IndexError (positional token mismatch), and ValueError (invalid format specification) guarantees that logging or CLI printing will not disrupt execution.

    _load_strings()

    Visibility: Private
    Signature: def _load_strings() -> None

    Description: Reads and parses utils/strings.csv into the internal _strings dictionary using csv.DictReader with utf-8-sig encoding. Extracts string identifiers, level tags, destination channels, and resolved text content (prioritizing the active language column with automatic fallback to the english column).

    Parameters: * None (operates on module-level globals _csv_path, _lang_col, _language, and _strings).

    Returns: * None

    Raises: * Does not raise exceptions directly; missing files abort early, and CSV parsing handles BOM transparently.

    Example: 

    def _load_strings():
    """Load all strings from strings.csv."""
    global _strings
    _strings = {}

    if not _csv_path or not os.path.exists(_csv_path):
        return

    translated_count = 0
    total_count = 0

    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if not key or key.startswith("#"):
                continue

            level = row.get("LEVEL", "INFO").strip()
            dest = row.get("DEST", "BOTH").strip()

            # Priority: language column → English fallback
            text = row.get(_lang_col, "").strip()
            if text:
                translated_count += 1
            else:
                text = row.get("english", "").strip()

            total_count += 1
            _strings[key] = {"text": text, "level": level, "dest": dest}

    if _lang_col != "english" and translated_count == total_count:
        emit_raw("SUCCESS", f"[i18n] {_language} — loaded {translated_count} strings from CSV")

    The function clears _strings and iterates across all records in strings.csv. It skips empty rows and comment lines starting with #. For each valid key, it inspects the target language column (_lang_col). If a non-empty string exists, it increments translated_count; otherwise, it falls back to the value in the english column. If all keys for a non-English language are fully translated, a success message is emitted to terminal and log channels.

    _auto_translate()

    Visibility: Private
    Signature: def _auto_translate() -> None

    Description: Identifies missing translations for the active target language in strings.csv, constructs a batch translation prompt using prompts/common/translate_strings.md, calls the inference gateway via call_llm(), parses the returned JSON dictionary, writes new translations to strings.csv, and reloads the memory state.

    Phase 1: Target Language and CSV Pre-check

    def _auto_translate():
    """Auto-translate missing strings via LLM and write back into strings.csv."""
    if _lang_col == "english":
        return

    if not _csv_path or not os.path.exists(_csv_path):
        return
    Phase 1 checks whether translation is necessary. If the target language is English or if strings.csv is inaccessible, execution terminates immediately without reading records or triggering LLM calls.

    Phase 2: Missing Translation Discovery

        # Collect strings that have no translation in the target language column
    missing = {}
    is_new_column = False
    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        fieldnames = list(reader.fieldnames)
        is_new_column = _lang_col not in fieldnames
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if not key or key.startswith("#"):
                continue
            # Check if the language column exists and has a value
            lang_text = row.get(_lang_col, "").strip() if _lang_col in fieldnames else ""
            if lang_text:
                continue  # Already translated

            english_text = row.get("english", "").strip()
            if english_text:
                missing[key] = english_text

    if not missing:
        return

    # Report what we found
    if is_new_column:
        emit_raw("PROGRESS", f"[i18n] New language '{_language}' — adding column to strings.csv")
    emit_raw("PROGRESS", f"[i18n] {len(missing)} strings need translation to {_language}")
    Phase 2 parses strings.csv to detect whether the target language column exists in reader.fieldnames. It traverses every non-comment row to collect keys where the target column is missing or empty, mapping key -> english_text into the missing dictionary. If all strings are translated, the function returns. Otherwise, it emits progress messages indicating how many translations are required.

    Phase 3: Prompt Construction & LLM Request Execution

        # Batch translate via LLM
    try:
        from utils.call_llm import call_llm

        entries_json = json.dumps(missing, ensure_ascii=False, indent=2)

        # Load prompt template from prompts/common/translate_strings.md
        prompt_path = os.path.join(
            os.path.dirname(os.path.dirname(os.path.abspath(__file__))),
            "prompts",
            "common",
            "translate_strings.md",
        )
        with open(prompt_path, encoding="utf-8") as pf:
            prompt_template = pf.read()
        prompt = prompt_template.format(language=_language, entries=entries_json)

        emit_raw("PROGRESS", f"[i18n] Calling LLM to translate {len(missing)} strings...")
        response = call_llm(prompt, use_cache=_use_cache, thinking_level=_thinking_level)
    Phase 3 dynamically imports call_llm from call_llm.py (preventing circular import loops at module initialization). It formats the missing dictionary into a JSON string, loads the translation prompt template from prompts/common/translate_strings.md, and sends the prompt payload to the configured LLM provider with the caching and thinking level settings established during init().

    Phase 4: Response Parsing, CSV Persistence, and Memory Reload

            # Extract JSON from response
        json_match = re.search(r"\{[^{}]*(?:\{[^{}]*\}[^{}]*)*\}", response, re.DOTALL)
        if json_match:
            translations = json.loads(json_match.group())
            translated_count = len(translations)

            # Write translations back into strings.csv
            _write_translations_to_csv(translations)
            emit_raw("SUCCESS", f"[i18n] Translated {translated_count}/{len(missing)} strings — saved to strings.csv")

            # Reload strings from the updated CSV so all translations are active
            _load_strings()
        else:
            emit_raw("WARNING", "[i18n] LLM response did not contain valid JSON — falling back to English")

    except Exception as e:
        emit_raw("WARNING", f"[i18n] Translation failed: {e} — falling back to English")
    Phase 4 extracts the JSON translation dictionary from the model response using a regular expression. It parses the JSON payload, passes the resulting dictionary to _write_translations_to_csv(), and invokes _load_strings() to refresh in-memory strings with the new translations. If JSON extraction or inference fails, defensive exception handling logs a warning and leaves English fallbacks active.

    _write_translations_to_csv()

    Visibility: Private
    Signature: def _write_translations_to_csv(translations: dict[str, str]) -> None

    Description: Updates strings.csv on disk with newly translated strings. If the target language column does not already exist in the CSV header, it appends the new column and writes all rows with UTF-8 BOM encoding (utf-8-sig) and blank line controls.

    Parameters: * translations (dict[str, str]): Dictionary mapping STRING_KEY names to their newly translated text strings.

    Returns: * None

    Raises: * OSError: If the file cannot be written due to disk or permission constraints.

    Example: 

    def _write_translations_to_csv(translations):
    """Write LLM translations back into strings.csv, persisting them for future runs.

    If the target language column doesn't exist, it is added to the CSV.
    """
    rows = []
    fieldnames = None

    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        fieldnames = list(reader.fieldnames)
        # Add language column if it doesn't exist
        if _lang_col not in fieldnames:
            fieldnames.append(_lang_col)
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if key in translations:
                row[_lang_col] = translations[key]
            rows.append(row)

    # Write with BOM so Excel opens as UTF-8 without extra import steps
    with open(_csv_path, "w", encoding="utf-8-sig", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(rows)

    The function reads all existing rows and column headers from strings.csv. If _lang_col is not present in fieldnames, it appends the new column name to the header list. It iterates through all rows, updating the target language field for any key matching translations. Finally, it opens _csv_path with utf-8-sig encoding and newline="" to prevent blank lines on Windows platforms, re-writing the updated dataset via csv.DictWriter.

    Error Handling

    The module employs defensive error handling to prevent logging or formatting errors from halting the knowledge generation pipeline:

    • Unknown String Keys: When emit() receives a key not present in _strings, it avoids raising KeyError. Instead, it outputs [UNKNOWN STRING: {key}] to standard output to maintain pipeline progress while alerting developers to the missing entry.
    • Template Formatting Fallbacks: In _format_safe(), string interpolation errors (KeyError, IndexError, ValueError) are caught and suppressed, returning the raw template string unmodified.
    • Auto-Translation Failures: In _auto_translate(), LLM communication errors, network failures, and JSON decoding issues are wrapped in a general except Exception as e: block. The error is emitted as a WARNING via emit_raw(), and the module transparently falls back to the canonical English strings in memory without crashing the process.
    • Missing CSV File Handling: Both _load_strings() and _auto_translate() verify os.path.exists(_csv_path) before attempting file I/O, allowing the module to fail gracefully if the strings table is deleted or misplaced.
