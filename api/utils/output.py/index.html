    output.py

    Source: utils/output.py

    Technical Overview

    The utils/output.py module serves as the centralized emission, console formatting, ANSI color styling, file logging, and localization gateway for the Codebase Knowledge Builder pipeline. It replaces direct print() statements and standard library logging configurations with a deterministic output bus. Every user-facing emission is mediated through string templates loaded from a persistent tabular catalog (strings.csv), decoupling terminal presentation and localized phrasing from execution logic. In addition to console routing, the module provisions per-run timestamped log files, manages buffering for early boot events, handles encoding normalization across diverse host platforms, and routes missing translations to an LLM-assisted localization worker.

    The module routes messages through a dual-destination architecture controlled by message metadata (BOTH, STDOUT, LOG, DBOTH, DSTDOUT). Emissions tagged with debug-sensitive prefixes are dynamically gated depending on whether the global --debug flag is active: when debug mode is disabled, debug emissions are suppressed from standard output while continuing to write into the permanent file log. Before persistent file logging is initialized via configure_logging(), all log messages generated during argument validation and credential verification are buffered inside an in-memory queue (_pending_log) bounded by PENDING_LOG_MAX_LINES entries, preventing message loss during the preflight execution phase.

    To ensure non-destructive runtime localization without circular dependency chains, output.py coordinates with utils.i18n. When init() is invoked with a non-English target language, the module can trigger LLM translation passes to populate missing message keys and serialize them back into the CSV catalog. The runtime environment is safeguarded against platform-specific character encoding failures through automated stream reconfiguration, preventing UnicodeEncodeError exceptions when output streams are redirected to non-interactive pipes or files on Windows hosts.

    COLORS

    Visibility: Public

    Signature: COLORS = { "PROGRESS": "\033[96m", # Cyan — LLM calls, active steps "SUCCESS": "\033[92m", # Green — completions, cache hits

    Description: Module-level mapping linking logical message severity levels to ANSI escape sequences for 16-color/256-color compatible terminal emulators. Levels without visual tinting (INFO, FILE_WRITE, and UI) map to empty strings.

    Implementation:

    COLORS = {
    "PROGRESS": "\033[96m",  # Cyan — LLM calls, active steps
    "SUCCESS": "\033[92m",  # Green — completions, cache hits
    "WARNING": "\033[93m",  # Yellow — warnings, capacity alerts
    "ERROR": "\033[91m",  # Red — errors, failures
    "INFO": "",  # Plain — config, counts, labels
    "DEBUG": "\033[90m",  # Gray — skipped files, debug
    "FILE_WRITE": "",  # Plain — "  - Wrote {path}" messages
    "UI": "",  # N/A — used in generated docs, never printed
}

    The dictionary defines color boundaries across eight operational categories. PROGRESS applies high-intensity cyan (\033[96m) to emphasize ongoing asynchronous steps and model generation loops. SUCCESS utilizes high-intensity green (\033[92m) for completed actions and cache hits. WARNING provides high-intensity yellow (\033[93m) for retry attempts and capacity thresholds, while ERROR applies high-intensity red (\033[91m). Diagnostic statements categorized as DEBUG render in muted dark gray (\033[90m). Uncolored levels default to empty strings to avoid injecting unneeded terminal control characters.

    RESET

    Visibility: Public

    Signature: RESET = "\033[0m"

    Description: ANSI terminal escape sequence used to reset graphic rendition attributes, restoring foreground and background terminal colors back to default settings following styled console emissions.

    Implementation:

    RESET = "\033[0m"

    The sequence \033[0m is appended to all styled standard output strings whenever an associated color code is retrieved from COLORS. If the evaluated color code evaluates to an empty string, the reset token is omitted to avoid emitting unnecessary bytes to the stream.

    PENDING_LOG_MAX_LINES

    Visibility: Public

    Signature: PENDING_LOG_MAX_LINES = 5_000

    Description: Bounded capacity limit defining the maximum number of formatted log lines permitted in the pre-configuration queue _pending_log.

    Implementation:

    PENDING_LOG_MAX_LINES = 5_000

    This integer ceiling enforces memory safety during long execution sequences that emit log lines prior to calling configure_logging(). If pre-configuration log emissions exceed this threshold, the queue evicts items in FIFO order, ensuring that unconfigured CLI runs or long verification sequences cannot trigger unbounded memory growth.

    def init(language="english", use_cache=True, thinking_level=None, debug=False, auto_translate=True):
    """Initialize the output system: load strings.csv, set language, auto-translate missing.

    Must be called from main() after parsing CLI arguments but before any emit() calls.

    Args:
        language: Target language name (e.g., "Vietnamese").
        use_cache: Whether LLM caching is enabled (passed to translation calls).
        thinking_level: LLM thinking level (passed to translation calls).
        auto_translate: Translate missing strings now. main() passes False and calls
            translate_missing_strings() after argument validation and the LLM auth preflight,
            because translation is itself an LLM call.
    """
    global _language, _lang_col, _csv_path, _use_cache, _thinking_level, _debug
    _language = language.capitalize()
    _lang_col = language.lower()
    _csv_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "strings.csv")
    _use_cache = use_cache
    _thinking_level = thinking_level
    _debug = debug
    _ensure_utf8_streams()
    _load_strings()
    if auto_translate:
        _auto_translate()

    The function normalizes the input language name into two representations: a capitalized string (_language) for terminal display messages and a lowercase identifier (_lang_col) matching column headers in strings.csv. It locates the string catalog relative to the physical directory of output.py and stores inference parameters (_use_cache, _thinking_level) for runtime translation requests. Stream safety is verified by calling _ensure_utf8_streams(), which forces UTF-8 encoding on redirected I/O streams. After populating _strings via _load_strings(), it selectively invokes _auto_translate() based on the auto_translate flag.

    emit()

    Visibility: Public

    Signature: def emit(key, suffix="", **kwargs):

    Description: Resolves a localized template from the catalog by key, formats it with provided variable substitutions, and outputs the result to the console, file log, or both according to configured routing rules.

    Parameters:

    • key (str): Catalog key identifier defined in strings.csv (e.g., "LLM_CALL_WRITE_CHAPTER").
    • suffix (str): Optional string appended to the formatted text before output (e.g., token consumption statistics). Defaults to "".
    • **kwargs (Any): Keyword arguments substituted into template placeholders (e.g., chapter_num=1).

    Returns:

    • None

    Raises:

    • Does not raise exceptions; missing keys output a fallback warning string, while variable formatting errors fall back to raw template text.

    Example:

    emit("LLM_CALL_WRITE_CHAPTER", chapter_num=1, name="flow")  # Print + log

    Implementation Details:

    def emit(key, suffix="", **kwargs):
    """Emit a translatable string to stdout and/or log file.

    Args:
        key: String key from strings.csv (e.g., "LLM_CALL_WRITE_CHAPTER").
        suffix: Optional extra text appended after the main message (e.g., token breakdown).
        **kwargs: Variables to substitute into the string template.
    """
    entry = _strings.get(key)
    if not entry:
        # Fallback for unknown keys — print raw so nothing is silently lost
        print(f"[UNKNOWN STRING: {key}]")
        return

    text = _format_safe(entry["text"], kwargs)
    if suffix:
        text = text + suffix

    level = entry["level"]
    dest = entry["dest"]

    # D-prefixed destinations (DBOTH, DSTDOUT): debug-gated console output.
    # Without --debug, suppress console but always log. Preserves original color from LEVEL.
    if dest.startswith("D"):
        if _debug:
            dest = dest[1:]  # DBOTH → BOTH, DSTDOUT → STDOUT
        else:
            dest = "LOG"

    color = COLORS.get(level, "")
    reset = RESET if color else ""

    if dest in ("BOTH", "STDOUT"):
        print(f"{color}{text}{reset}")
    if dest in ("BOTH", "LOG"):
        _write_log(level, text)

    The function queries _strings for the specified key. If the key does not exist, it prints [UNKNOWN STRING: {key}] to standard output to surface missing catalog entries without crashing the application. If found, the template string is safely formatted with kwargs via _format_safe() and concatenated with any optional suffix.

    Destination routing evaluates the dest property. Destinations prefixed with "D" (such as DBOTH and DSTDOUT) are treated as debug-gated channels: if _debug is True, the "D" prefix is stripped to allow console printing; otherwise, dest is converted to "LOG" to restrict output to the log file. If the destination includes console output, the text is wrapped with ANSI codes from COLORS and RESET and printed via print(). If the destination includes file output, the message is passed to _write_log().

    Implementation Details:

    def emit_raw(level, text, dest="BOTH"):
    """Emit a pre-formatted string with explicit level styling.

    Use for dynamic/structural output that doesn't come from strings.csv
    (e.g., numbered file lists, batch details, crawl summary tables).
    """
    # DEBUG-level: suppress console unless --debug is active
    if level == "DEBUG" and not _debug:
        dest = "LOG"

    color = COLORS.get(level, "")
    reset = RESET if color else ""

    if dest in ("BOTH", "STDOUT"):
        print(f"{color}{text}{reset}")
    if dest in ("BOTH", "LOG"):
        _write_log(level, text)

    emit_raw() handles structural, non-catalog messages such as dynamic file lists, runtime ASCII banners, markdown summaries, and raw diagnostic dumps. If the provided level is "DEBUG" and global debug mode is inactive (not _debug), the destination is downgraded from "BOTH" or "STDOUT" to "LOG". Terminal colors are looked up directly from COLORS using level. When dest contains "STDOUT" or "BOTH", the colored string is printed to the terminal. When dest contains "LOG" or "BOTH", _write_log() records the message to the file log.

    def get(key, **kwargs):
    """Get a translated string without printing or logging.

    Use for UI strings embedded in generated markdown (index.md headings, etc.).

    Implementation Details:

    def configure_logging(project_name="project", mode="tutorial"):
    """Configure file-based logging for this run.

    Creates a new log file per invocation:
        logs/{project_name}_{mode}_{YYYYMMDD_HHmmss}.log

    Must be called from main() after parsing CLI arguments.
    """
    global _log_file

    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_path = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Close any existing log file
    if _log_file is not None:
        _log_file.close()

    _log_file = open(log_path, "a", encoding="utf-8")  # noqa: SIM115

    # Log run metadata at the start of every log file
    sep = "=" * 80
    emit_raw("INFO", sep, dest="LOG")
    emit_raw("INFO", f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}", dest="LOG")
    emit_raw("INFO", f"Log file: {log_path}", dest="LOG")
    if _pending_log:
        _log_file.write("".join(_pending_log))
        _log_file.flush()
        _pending_log.clear()

    return log_path

    The function resolves the output directory by reading the LOG_DIR environment variable, falling back to the local "logs" directory if unset, and creates it via os.makedirs(log_directory, exist_ok=True). The log filename follows the pattern {safe_project}_{safe_mode}_{timestamp}.log, sanitizing project_name to remove invalid filesystem characters and replacing hyphens in mode with underscores.

    If a log file is already open, it is closed before opening the new file handle in append mode ("a") with UTF-8 encoding. It then writes a delimiter banner, metadata header, and log file path via emit_raw(..., dest="LOG"). Finally, any log entries buffered in _pending_log during early application boot are written to disk, flushed immediately, and cleared from the buffer.

    Implementation:

    def _write_log(level, text):
    """Write a timestamped line to the log file (buffered until configure_logging opens it)."""
    ts = datetime.now().strftime("%Y-%m-%d %H:%M:%S,%f")[:-3]
    line = f"{ts} - {level} - {text}\n"
    if _log_file is None:
        _pending_log.append(line)
        if len(_pending_log) > PENDING_LOG_MAX_LINES:
            del _pending_log[0]
        return
    _log_file.write(line)
    _log_file.flush()

    The function builds a log record prefixed with a microsecond-precision timestamp formatted as YYYY-MM-DD HH:MM:SS,mmm alongside the severity level. Once _log_file is open, records are written immediately and flushed to disk to guarantee log durability.

    _ensure_utf8_streams()

    Signature: def _ensure_utf8_streams():

    Description: Reconfigures standard output and error streams to use UTF-8 encoding when connected to pipes or redirection sinks on operating systems with legacy ANSI code pages.

    Parameters:

    • None

    Returns:

    • None

    Raises:

    • Does not raise exceptions.

    Implementation:

    def _ensure_utf8_streams():
    """Write UTF-8 when stdout/stderr are piped or redirected.

    On Windows a redirected stream uses the ANSI code page (e.g. cp1252) and any
    non-English CLI string (Vietnamese, CJK, ...) raises UnicodeEncodeError. Interactive
    consoles already use UTF-8 (PEP 528), so only non-TTY streams are reconfigured.
    """
    for stream in (sys.stdout, sys.stderr):
        encoding = (getattr(stream, "encoding", "") or "").lower().replace("-", "")
        if hasattr(stream, "reconfigure") and encoding != "utf8" and not stream.isatty():
            stream.reconfigure(encoding="utf-8", errors="replace")

    This helper addresses platform-specific console encoding discrepancies, particularly on Windows environments where redirected streams default to non-UTF-8 character sets like cp1252. Under these code pages, non-English translations containing diacritics or CJK characters trigger fatal UnicodeEncodeError exceptions. The function inspects sys.stdout and sys.stderr; if a stream is not an interactive terminal (not stream.isatty()) and its encoding is not UTF-8, it calls stream.reconfigure(encoding="utf-8", errors="replace"). This guarantees safe streaming across pipes and redirection targets while replacing unencodable code points rather than raising errors.

    def _format_safe(template, kwargs):
    """Apply .format(**kwargs) with graceful fallback on missing keys."""
    try:

        return template

    The function executes Python's built-in str.format(**kwargs). If the substitution references an undefined key (KeyError), uses invalid positional indexes (IndexError), or encounters malformed format specifiers (ValueError), the exception is caught and the unparsed template is returned as-is. This prevents missing metadata arguments from crashing execution.

    Implementation:

    def _load_strings():
    """Load all strings from strings.csv."""
    global _strings
    _strings = {}

    if not _csv_path or not os.path.exists(_csv_path):
        return

    translated_count = 0
    total_count = 0

    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if not key or key.startswith("#"):
                continue

            level = row.get("LEVEL", "INFO").strip()
            dest = row.get("DEST", "BOTH").strip()

            # Priority: language column → English fallback
            text = row.get(_lang_col, "").strip()
            if text:
                translated_count += 1
            else:
                text = row.get("english", "").strip()

            total_count += 1
            _strings[key] = {"text": text, "level": level, "dest": dest}

    if _lang_col != "english" and translated_count == total_count:
        emit_raw("SUCCESS", f"[i18n] {_language} — loaded {translated_count} strings from CSV")

    The function reads the CSV catalog using utf-8-sig encoding to transparently handle byte-order marks. It skips empty rows and comment entries prefixed with #. For each row, it extracts STRING_KEY, LEVEL (defaulting to "INFO"), and DEST (defaulting to "BOTH").

    Text selection follows a priority hierarchy: it first checks for text under the active language column (_lang_col); if empty or missing, it falls back to the canonical "english" column. As rows are parsed, the function tracks translated_count against total_count. If a non-English language is fully translated, it emits a confirmation message via emit_raw().

    Data Structures

    Catalog Entry Mapping

    The internal _strings dictionary stores parsed string records using string keys mapped to entry dictionaries with the following structure:

    Field Type Description
    text str Localized string template, optionally including format placeholders like {name}.
    level str Message severity category used for ANSI color selection. Matches a key in COLORS.
    dest str Output destination flag controlling stream routing (BOTH, STDOUT, LOG, DBOTH, DSTDOUT). 
    # Representative entry structure inside _strings:
{
    "LLM_CALL_WRITE_CHAPTER": {
        "text": "Writing chapter {chapter_num}: {name}...",
        "level": "PROGRESS",
        "dest": "BOTH"
    }
}

    CSV Catalog Schema (strings.csv)

    strings.csv defines the persistent storage format for application messages. The file uses commas as delimiters and utf-8-sig encoding.

    Column Type Description Example
    STRING_KEY String Unique identifier used in code invocations. Rows starting with # are treated as comments. LLM_CALL_WRITE_CHAPTER
    LEVEL String Severity level controlling console color formatting. PROGRESS
    DEST String Stream destination selector (BOTH, STDOUT, LOG, DBOTH, DSTDOUT). BOTH
    english String Canonical English template text. Serves as the fallback for untranslated rows. Writing chapter {chapter_num}: {name}...
    <lang> String Dynamic language-specific columns (e.g., vietnamese, japanese) appended as new translations are generated. Đang viết chương {chapter_num}: {name}...

    Output Destination Routing Directives

    The dest attribute in catalog entries and emit_raw() calls determines how messages are routed between terminal output and persistent log files:

    Routing Identifier Target Streams Debug Behavior Description
    STDOUT Console only Standard Emits to sys.stdout with ANSI styling; bypassed by the file log.
    LOG File log only Standard Written directly to _log_file or _pending_log; bypassed by the console.
    BOTH Console and file log Standard Simultaneous emission to both terminal and file destinations.
    DSTDOUT Console only Debug-gated Downgraded to LOG when _debug is False; emitted to console when _debug is True.
    DBOTH Console and file log Debug-gated Downgraded to LOG when _debug is False; emitted to both when _debug is True.

    Error Handling

    The utils/output.py module implements defensive error handling to prevent logging or formatting errors from interrupting pipeline execution:

    • Format Substitution Fault Tolerance: _format_safe() catches KeyError, IndexError, and ValueError exceptions raised by str.format(). If an emit() or get() call receives incomplete arguments or invalid placeholders, the module returns the unformatted template string instead of raising an unhandled exception.
    • Stream Encoding Fallback: _ensure_utf8_streams() guards non-interactive and redirected streams against character encoding failures on Windows systems. If standard streams are bound to legacy code pages, the module calls stream.reconfigure(encoding="utf-8", errors="replace") to replace unencodable characters instead of throwing UnicodeEncodeError.
    • Missing Catalog Key Handling: When emit() receives an unrecognized catalog key, it avoids dropping the message by printing a fallback warning in the format [UNKNOWN STRING: {key}]. Similarly, get() returns the raw key string when a lookup fails.
    • Pre-configuration Log Buffering: Messages logged before configure_logging() completes are stored in the _pending_log queue. If log configuration is delayed or omitted, the queue is capped at PENDING_LOG_MAX_LINES (5,000 entries) using a FIFO eviction policy (del _pending_log[0]) to prevent unbounded memory growth.
    • Missing Catalog Handling: If strings.csv is missing or the path cannot be resolved, _load_strings() returns an empty catalog without raising an error. Subsequent emit() and get() calls gracefully fall back to displaying missing key warnings.
