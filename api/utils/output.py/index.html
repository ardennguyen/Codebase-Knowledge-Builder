    output.py

    Source: utils/output.py

    Following the generation and rendering mechanics documented in mkdocs.py, which orchestrates document layout, static site configurations, and navigation manifests, the utils/output.py module serves as the centralized terminal formatting, internationalization (i18n), and file logging facility across the entire repository documentation pipeline.

    Technical Overview

    utils/output.py unifies standard output (stdout) and persistent disk logging into a coordinated messaging bus. The system decouples operational messaging from hardcoded string literals across CLI tools, pipeline nodes, and file crawlers by utilizing an external CSV registry (strings.csv). Messages are assigned contextual severity levels—such as PROGRESS, SUCCESS, WARNING, ERROR, INFO, DEBUG, and FILE_WRITE—each tied to distinct ANSI terminal escape sequences. Furthermore, routing destinations (STDOUT, LOG, BOTH, DSTDOUT, DBOTH) allow fine-grained control over whether messages appear on the interactive terminal, in runtime trace logs, or both, with automatic suppression of high-verbosity debug traces unless explicitly requested.

    A core architectural feature of this module is its self-healing internationalization (i18n) subsystem. When initialized with a target language other than English, the engine inspects strings.csv for missing localized variants. If untranslated string identifiers are identified, the module leverages the Large Language Model gateway to batch-translate missing strings, persists the translated column back to strings.csv using UTF-8 with Byte Order Mark (utf-8-sig), and dynamically reloads the runtime registry without interrupting execution.

    The module manages execution logs through structured log files partitioned by project name, execution mode, and microsecond timestamps. It guarantees file pointer isolation, ensures synchronous flushing to disk via stream flushes, and captures run headers detailing pipeline invocation metadata.

    def init(language="english", use_cache=True, thinking_level=None, debug=False):
    """Initialize the output system: load strings.csv, set language, auto-translate missing.

    Must be called from main() after parsing CLI arguments but before any emit() calls.

    Args:
        language: Target language name (e.g., "Vietnamese").
        use_cache: Whether LLM caching is enabled (passed to translation calls).
        thinking_level: LLM thinking level (passed to translation calls).
    """
    global _language, _lang_col, _csv_path, _use_cache, _thinking_level, _debug
    _language = language.capitalize()
    _lang_col = language.lower()
    _csv_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "strings.csv")
    _use_cache = use_cache
    _thinking_level = thinking_level
    _debug = debug
    _load_strings()
    _auto_translate()

    The function coordinates setting several module-level variables (_language, _lang_col, _csv_path, _use_cache, _thinking_level, and _debug) before triggering sequential loading and translation pipelines. Capitalizing _language ensures consistent presentation formatting, while lowering _lang_col aligns with column headers defined in the localization schema. The file path resolution uses os.path.abspath(__file__) to avoid working-directory relative path inconsistencies.

    Implementation extract from utils/output.py: 

    def emit(key, suffix="", **kwargs):
    """Emit a translatable string to stdout and/or log file.

    Args:
        key: String key from strings.csv (e.g., "LLM_CALL_WRITE_CHAPTER").
        suffix: Optional extra text appended after the main message (e.g., token breakdown).
        **kwargs: Variables to substitute into the string template.
    """
    entry = _strings.get(key)
    if not entry:
        # Fallback for unknown keys — print raw so nothing is silently lost
        print(f"[UNKNOWN STRING: {key}]")
        return

    text = _format_safe(entry["text"], kwargs)
    if suffix:
        text = text + suffix

    level = entry["level"]
    dest = entry["dest"]

    # D-prefixed destinations (DBOTH, DSTDOUT): debug-gated console output.
    # Without --debug, suppress console but always log. Preserves original color from LEVEL.
    if dest.startswith("D"):
        if _debug:
            dest = dest[1:]  # DBOTH → BOTH, DSTDOUT → STDOUT
        else:
            dest = "LOG"

    color = COLORS.get(level, "")
    reset = RESET if color else ""

    if dest in ("BOTH", "STDOUT"):
        print(f"{color}{text}{reset}")
    if dest in ("BOTH", "LOG"):
        _write_log(level, text)

    The function incorporates debug-gating logic: when dest begins with D (such as DBOTH or DSTDOUT), standard output is suppressed unless _debug is True. In non-debug executions, the destination dynamically falls back to LOG, guaranteeing that operational telemetry remains archived in the run log without cluttering standard terminal output. Terminal colors are injected using the module's COLORS dictionary and cleanly terminated via RESET.

    def get(key, **kwargs):
    """Get a translated string without printing or logging.

    Use for UI strings embedded in generated markdown (index.md headings, etc.).
    Returns the raw translated text with variable substitution applied.

    def configure_logging(project_name="project", mode="tutorial"):
    """Configure file-based logging for this run.

    Creates a new log file per invocation:
        logs/{project_name}_{mode}_{YYYYMMDD_HHmmss}.log

    Must be called from main() after parsing CLI arguments.
    """
    global _log_file
    from datetime import datetime

    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_path = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Close any existing log file
    if _log_file is not None:
        _log_file.close()

    _log_file = open(log_path, "a", encoding="utf-8")  # noqa: SIM115

    # Log run metadata at the start of every log file
    sep = "=" * 80
    emit_raw("INFO", sep, dest="LOG")
    emit_raw("INFO", f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}", dest="LOG")
    emit_raw("INFO", f"Log file: {log_path}", dest="LOG")

    return log_path

    Sanitization filters out filesystem-incompatible characters by retaining only alphanumeric characters, dashes, underscores, and periods, replacing all other characters with underscores. The function writes a standardized header block containing an 80-character boundary separator, invocation parameters, and creation timestamps directly to the newly opened log handle using emit_raw(..., dest="LOG").

    def _write_log(level, text):
    """Write a timestamped line to the log file (no-op if logging not configured)."""
    if _log_file is None:
        return
    from datetime import datetime

    ts = datetime.now().strftime("%Y-%m-%d %H:%M:%S,%f")[:-3]

    def _format_safe(template, kwargs):
    """Apply .format(**kwargs) with graceful fallback on missing keys."""
    try:
        return template.format(**kwargs)
    except (KeyError, IndexError, ValueError):
        return template

    Implementation extract from utils/output.py: 

    def _load_strings():
    """Load all strings from strings.csv."""
    global _strings
    _strings = {}

    if not _csv_path or not os.path.exists(_csv_path):
        return

    translated_count = 0
    total_count = 0

    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if not key or key.startswith("#"):
                continue

            level = row.get("LEVEL", "INFO").strip()
            dest = row.get("DEST", "BOTH").strip()

            # Priority: language column → English fallback
            text = row.get(_lang_col, "").strip()
            if text:
                translated_count += 1
            else:
                text = row.get("english", "").strip()

            total_count += 1
            _strings[key] = {"text": text, "level": level, "dest": dest}

    if _lang_col != "english" and translated_count == total_count:
        emit_raw("SUCCESS", f"[i18n] {_language} — loaded {translated_count} strings from CSV")

    The loader respects commented rows prefixed with # to allow documentation headers directly within strings.csv. Using utf-8-sig handles Byte Order Mark prefixes seamlessly, preventing extraneous \ufeff artifacts from corrupting the first column header. When a non-English language is fully localized, a SUCCESS status confirmation is emitted.

    Phase 1: Missing Translation Detection

    Inspects strings.csv to collect all string entries lacking a localized entry under column _lang_col.

        if _lang_col == "english":
        return

    if not _csv_path or not os.path.exists(_csv_path):
        return

    # Collect strings that have no translation in the target language column
    missing = {}
    is_new_column = False
    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        fieldnames = list(reader.fieldnames)
        is_new_column = _lang_col not in fieldnames
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if not key or key.startswith("#"):
                continue
            # Check if the language column exists and has a value
            lang_text = row.get(_lang_col, "").strip() if _lang_col in fieldnames else ""
            if lang_text:
                continue  # Already translated

            english_text = row.get("english", "").strip()
            if english_text:
                missing[key] = english_text

    if not missing:
        return

    # Report what we found
    if is_new_column:
        emit_raw("PROGRESS", f"[i18n] New language '{_language}' — adding column to strings.csv")
    emit_raw("PROGRESS", f"[i18n] {len(missing)} strings need translation to {_language}")

    If the active language is English or if strings.csv is missing, the procedure terminates immediately. The reader detects whether the language requires appending a new column header (is_new_column). For each row containing a valid key and an English string, if the target language column value is empty or absent, the entry is queued into the missing dictionary mapping key to english_text. If missing is empty, execution cleanly finishes.

    Phase 2: LLM Prompt Assembly & Execution

    Serializes missing entries into formatted JSON and combines them with the translation prompt template before querying the LLM gateway.

    The module imports call_llm from call_llm.py dynamically to prevent circular dependencies during module loading. The missing dictionary is serialized via json.dumps with ensure_ascii=False to preserve Unicode characters. The module loads prompts/common/translate_strings.md, injects the target language name and entries payload into the template, and dispatches the request through the LLM gateway using the configured caching and thinking level settings.

    Phase 3: Response Extraction & CSV Persistence

    Extracts JSON from the LLM completion using regular expressions, writes the translations to disk, and refreshes the cache.

            # Extract JSON from response
        json_match = re.search(r"\{[^{}]*(?:\{[^{}]*\}[^{}]*)*\}", response, re.DOTALL)
        if json_match:
            translations = json.loads(json_match.group())
            translated_count = len(translations)

            # Write translations back into strings.csv
            _write_translations_to_csv(translations)

The JSON content is parsed via json.loads into a dictionary, passed to _write_translations_to_csv(), and activated by calling _load_strings(). If the LLM output is malformed or if an API exception occurs, the routine catches the error, emits a descriptive warning, and preserves English fallback values.

    If the target language column doesn't exist, it is added to the CSV.
    """
    rows = []
    fieldnames = None

    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        fieldnames = list(reader.fieldnames)
        # Add language column if it doesn't exist
        if _lang_col not in fieldnames:
            fieldnames.append(_lang_col)
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if key in translations:
                row[_lang_col] = translations[key]
            rows.append(row)

    # Write with BOM so Excel opens as UTF-8 without extra import steps
    with open(_csv_path, "w", encoding="utf-8-sig", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(rows)

    The writer processes rows sequentially, checking if the row key exists in translations and setting row[_lang_col] accordingly. If _lang_col represents a newly added language, it is appended to fieldnames. Writing back out with newline="" prevents blank line insertion on Windows operating systems, while encoding="utf-8-sig" ensures compatibility with external spreadsheet tools like Microsoft Excel.

    Data Structures

    ANSI Escape Sequences (COLORS)

    The module defines a static dictionary COLORS mapping severity levels to their corresponding ANSI terminal color codes:

    Severity Level ANSI Code Terminal Representation Architectural Purpose
    PROGRESS \033[96m Bright Cyan Active pipeline stages, LLM inference invocations
    SUCCESS \033[92m Bright Green Completed phases, cache hits, successful validations
    WARNING \033[93m Bright Yellow Non-fatal anomalies, capacity warnings, English fallbacks
    ERROR \033[91m Bright Red Pipeline failures, fatal errors, missing configurations
    INFO "" Standard Console Operational counts, configuration summaries, run metadata
    DEBUG \033[90m Gray Skipped files, detailed AST parses, low-level metrics
    FILE_WRITE "" Standard Console File write notifications (e.g., " - Wrote {path}")
    UI "" N/A Markdown headers and UI labels embedded into generated docs

    Module-Level State

    The module stores runtime configurations and parsed translation mappings in module-level global variables:

    Variable Name Type Initial Value Description
    _strings dict[str, dict[str, str]] {} In-memory lookup registry mapping string keys to record dictionaries
    _language str "English" Display-formatted, capitalized target language name
    _lang_col str "english" Lowercase string identifier matching CSV header columns
    _log_file Optional[io.TextIOWrapper] None Open append-mode file handle for synchronous log writing
    _csv_path Optional[str] None Absolute filesystem path to strings.csv
    _use_cache bool True Directs whether LLM caching is active during auto-translation
    _thinking_level Optional[str] None Reasoning effort budget configured for LLM operations
    _debug bool False Controls standard output gating for debug messages

    In-Memory String Entry Schema

    Each element stored within the _strings dictionary adheres to the following record schema:

    Field Type Description
    text str The resolved template string (in target language or fallback English)
    level str Message severity level key matching an entry in COLORS
    dest str Message destination directive (BOTH, STDOUT, LOG, DBOTH, DSTDOUT)

    CSV Schema (strings.csv)

    The CSV storage file backing the localization framework uses the following column schema:

    Column Header Data Type Required Description
    STRING_KEY str Yes Unique identifier for the message string (or # comment prefix)
    LEVEL str Yes Output severity categorization (PROGRESS, SUCCESS, etc.)
    DEST str Yes Destination routing rule (BOTH, STDOUT, LOG, DBOTH, DSTDOUT)
    english str Yes Baseline canonical English text template with optional {placeholders}
    <language> str No Target language translations dynamically added as extra columns

    Error Handling

    Template Interpolation Failures

    Variable substitution errors are handled defensively in _format_safe(). If a template contains named placeholders (e.g., {chapter_num}) but the caller fails to provide matching keyword arguments, standard Python string formatting raises a KeyError. Similarly, mismatched index references or malformed format specifiers raise IndexError or ValueError. _format_safe() intercepts all three exception classes and returns the unformatted template string directly:

    try:
    return template.format(**kwargs)
except (KeyError, IndexError, ValueError):
    return template

    Unregistered String Keys

    When emit() or get() is called with an unknown key, the system does not raise an exception: * emit() prints a raw fallback warning to standard output: [UNKNOWN STRING: {key}]. This ensures missing localization definitions are immediately noticeable to developers without halting the execution flow. * get() returns the raw key string as a fallback, ensuring that markdown generation pipelines continue producing output documents.

    Translation and LLM Parsing Resiliency

    During _auto_translate(), multiple failure points are intercepted: 1. Network or Inference Exceptions: The invocation to call_llm() is wrapped inside a broad try...except Exception as e block. Network disconnects, rate limits, or context exhaustion failures are caught, logged as a warning ([i18n] Translation failed: {e} — falling back to English), and execution proceeds using default English strings. 2. Malformed JSON Payload: If the LLM generates non-compliant JSON, unescaped quotes, or conversational preamble without valid JSON syntax, the regex extraction fails to match, or json.loads() fails. The module falls back cleanly with an explicit warning: [i18n] LLM response did not contain valid JSON — falling back to English.

    Debug Route Gating

    To prevent sensitive or high-frequency debug traces from cluttering user terminals while maintaining an audit trail on disk, the system applies destination routing rules: * Entries with destinations prefixed with D (such as DBOTH and DSTDOUT) are inspected against _debug. If _debug=False, the destination is coerced to LOG. * emit_raw() checks whether level == "DEBUG" and redirects dest to LOG when _debug=False.
