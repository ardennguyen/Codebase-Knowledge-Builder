    output.py

    Source: utils/output.py

    Technical Overview

    The utils/output.py module provides the centralized output, console styling, and persistent file logging infrastructure for the Codebase-Knowledge-Builder repository. It decouples the visual and structured reporting of pipeline events from operational execution logic. Instead of hardcoding log strings or print statements within workflow nodes, the entire system routes user-facing text through a centralized localization catalog (utils/strings.csv). This design supports dynamic {placeholder} token interpolation and multi-language translation.

    The module operates as a hybrid logging engine, simultaneously handling formatted console output on standard streams and raw, timestamped entries in run-specific log files. To resolve ordering constraints where telemetry and authorization events occur before CLI arguments configure the destination log file, the module maintains an in-memory pending ring buffer. When the file logger initializes, this buffer flushes all preflight events into the active file in chronological order without log loss.

    Additionally, utils/output.py safeguards against character encoding failures on Windows environments. When streams are redirected or piped, standard streams can default to legacy ANSI code pages (such as cp1252), leading to fatal encoding exceptions on non-English characters. The module detects redirected streams and transparently reconfigures standard I/O streams to UTF-8. It also bridges missing language localizations by delegating to LLM-driven translation passes, persisting discovered translations directly back to disk.

    Public API

    init()

    Visibility: Public

    Signature: def init(language="english", use_cache=True, thinking_level=None, debug=False, auto_translate=True):

    Description: Initializes the output subsystem, configuring localization targets, stream encodings, and string catalogs. It sets module-level configuration variables, validates UTF-8 streams for piped environments via _ensure_utf8_streams(), and reads the localization table from disk using _load_strings(). If auto_translate is enabled, it immediately initiates an LLM check to translate untranslated keys.

    Parameters:

    • language (str): Target language name used for display and column resolution (e.g., "english", "Vietnamese"). Defaults to "english".
    • use_cache (bool): Flag indicating whether downstream LLM caching is active during automated string translation calls. Defaults to True.
    • thinking_level (str | None): LLM thinking effort level passed through to automated translation prompts. Defaults to None.
    • debug (bool): Global switch to enable verbose debug-level console output. Defaults to False.
    • auto_translate (bool): Whether to immediately run translation for missing strings during initialization. Defaults to True.

    Returns:

    • None: Does not return a value; mutates internal module-level state.

    Raises:

    • Does not raise exceptions internally; delegates stream reconfiguration and missing file checks defensively.

    Example:

    from utils.output import init as init_output

# Initialize output with default English localization
init_output(language="english")

# Initialize output with Vietnamese localization and debug logging
init_output(
    language="Vietnamese",
    use_cache=True,
    thinking_level="low",
    debug=True,
    auto_translate=False
)

    The init function sets the internal runtime context required for all subsequent output operations across the system. It initializes display and CSV lookup names (_language and _lang_col) while establishing the filesystem path to strings.csv. Stream checking prevents non-TTY output redirection on Windows hosts from crashing on multi-byte characters. When auto_translate is deferred by callers such as main.py, initialization completes quickly without performing network I/O.

    emit()

    Visibility: Public

    Signature: def emit(key, suffix="", **kwargs):

    Description: Looks up a localized message from the internal catalog by key, formats it with provided keyword arguments, applies ANSI color coding according to its configured severity level, and routes the formatted string to stdout, the log file, or both.

    Parameters:

    • key (str): Catalog key declared in strings.csv (e.g., "LLM_CALL_WRITE_CHAPTER").
    • suffix (str): Optional additional text appended directly to the end of the formatted message prior to emission. Defaults to "".
    • **kwargs (Any): Variable keyword arguments applied to the message template via string formatting.

    Returns:

    • None: Emits output to standard streams or files.

    Raises:

    • Does not raise exceptions. If a key cannot be found, it outputs a diagnostic message [UNKNOWN STRING: {key}] to prevent silent output drops.

    Example:

    from utils.output import emit

# Emit a progress event with placeholder variables and token breakdown suffix
emit(
    "LLM_CALL_WRITE_CHAPTER",
    suffix=" (prompt=1,200, completion=850)",
    chapter_num=1,
    name="flow"
)

    The function queries _strings using the provided key. If the key is unregistered, it prints [UNKNOWN STRING: {key}] to stdout as a fallback and halts further processing. For registered keys, the string is populated via _format_safe before appending any suffix. Destination flags starting with "D" (such as "DBOTH" or "DSTDOUT") indicate debug gating: if _debug is disabled, the destination downgrades to "LOG", suppressing console noise while maintaining audit traces. ANSI escape sequences are retrieved from COLORS using the record's level and wrapped around the text when writing to console sinks.

    emit_raw()

    Visibility: Public

    Signature: def emit_raw(level, text, dest="BOTH"):

    Description: Directly routes arbitrary, uncataloged text strings through the formatting and logging pipeline using an explicit severity level and destination target.

    Parameters:

    • level (str): Severity identifier (e.g., "PROGRESS", "SUCCESS", "WARNING", "ERROR", "INFO", "DEBUG").
    • text (str): Pre-formatted string to output.
    • dest (str): Target stream selector; accepts "BOTH", "STDOUT", or "LOG". Defaults to "BOTH".

    Returns:

    • None: Renders output directly to selected destinations.

    Raises:

    • Does not raise exceptions.

    Example:

    from utils.output import emit_raw

# Output an informational banner to both console and log file
emit_raw("INFO", "Initializing codebase crawler pipeline...")

# Emit diagnostic data only to the log file
emit_raw("DEBUG", "Excluded path matched regex: tests/fixtures/*", dest="LOG")

    emit_raw bypasses the strings.csv catalog, providing a direct interface for dynamic CLI displays, generated data tables, and batch processing status counters. If level is set to "DEBUG" while _debug is inactive, dest is reassigned to "LOG" to prevent console clutter. When dest includes stdout, ANSI color codes mapped from level are applied and reset using RESET. If dest includes file logging, execution is dispatched to _write_log.

    get()

    Visibility: Public

    Signature: def get(key, **kwargs):

    Description: Resolves and returns a localized, formatted string from the catalog without sending output to standard streams or persistent log files.

    Parameters:

    • key (str): Catalog key declared in strings.csv (e.g., "UI_TUTORIAL").
    • **kwargs (Any): Named parameters to interpolate into the catalog text template.

    Returns:

    • str: The localized, interpolated string. If the key is not found in the catalog, it returns the raw key string as a fallback.

    Raises:

    • Does not raise exceptions.

    Example:

    from utils.output import get

# Retrieve a localized title for documentation generation
title = get("UI_TUTORIAL_HEADING", project_name="KnowledgeBuilder")

    get serves as the primary retrieval method for UI strings that need to be embedded directly into generated documents (e.g., Markdown headers, navigation labels, index page summaries) rather than CLI streams. If the key does not exist within the internal catalog, get falls back to returning the key name itself. When found, the raw template is processed via _format_safe with the provided keyword parameters.

    configure_logging()

    Visibility: Public

    Signature: def configure_logging(project_name="project", mode="tutorial"):

    Description: Establishes file-based logging for the active execution lifecycle. It generates the destination directory, calculates a sanitized log filename containing the project name, execution mode, and current timestamp, opens the file with UTF-8 encoding, writes run metadata, and flushes any buffered preflight log entries.

    Parameters:

    • project_name (str): Identifier of the analyzed project, used in the log filename. Defaults to "project".
    • mode (str): Execution mode identifier (e.g., "tutorial", "api-reference"). Defaults to "tutorial".

    Returns:

    • str: The absolute or normalized relative path to the newly created log file on disk.

    Raises:

    • OSError: If the logging directory cannot be created or the log file cannot be opened for writing.

    Example:

    from utils.output import configure_logging

# Configure logging for an API reference generation pass
log_file_path = configure_logging(project_name="MyLib", mode="api-reference")
print(f"Logging active at: {log_file_path}")

        global _log_file

    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_path = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Close any existing log file
    if _log_file is not None:
        _log_file.close()

    _log_file = open(log_path, "a", encoding="utf-8")  # noqa: SIM115

    # Log run metadata at the start of every log file
    sep = "=" * 80
    emit_raw("INFO", sep, dest="LOG")
    emit_raw("INFO", f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}", dest="LOG")
    emit_raw("INFO", f"Log file: {log_path}", dest="LOG")
    if _pending_log:
        _log_file.write("".join(_pending_log))
        _log_file.flush()
        _pending_log.clear()

    return log_path

    configure_logging checks the LOG_DIR environment variable, defaulting to "logs" if unset, and creates the directory using os.makedirs(..., exist_ok=True). Filename parameters are sanitized by replacing non-alphanumeric characters with underscores. If a log file handle is already open, it is closed before opening the new path in append mode with explicit UTF-8 encoding. Any log records buffered in _pending_log are written into the file and cleared.

    Internal Helpers

    _write_log()

    Visibility: Private

    Signature: def _write_log(level, text):

    Description: Formats and records a single log entry with a millisecond-precision timestamp and severity level. If file logging has not yet been initialized via configure_logging(), the formatted line is appended to _pending_log, enforcing an upper limit of PENDING_LOG_MAX_LINES. If a file handle is open, the message is written directly and flushed.

    Parameters:

    • level (str): Severity classification of the log entry (e.g., "INFO", "ERROR").
    • text (str): Text payload of the log line.

    Returns:

    • None: Writes to file or buffers in memory.

    Raises:

    • Does not raise exceptions.

    Example:

    # Internal invocation from emit or emit_raw
_write_log("INFO", "Discovered 45 source files in repository")

        ts = datetime.now().strftime("%Y-%m-%d %H:%M:%S,%f")[:-3]
    line = f"{ts} - {level} - {text}\n"
    if _log_file is None:
        _pending_log.append(line)
        if len(_pending_log) > PENDING_LOG_MAX_LINES:
            del _pending_log[0]
        return
    _log_file.write(line)
    _log_file.flush()

    _write_log formats log entries with timestamps using the format YYYY-MM-DD HH:MM:SS,mmm. When _log_file is None, entries are buffered in _pending_log. If this buffer exceeds PENDING_LOG_MAX_LINES (5,000 entries), the oldest line is dropped to prevent memory leaks during long runs without file logging. Once a file handle is available, writes are immediately followed by flush() to ensure crash-safe persistence.

    _ensure_utf8_streams()

    Visibility: Private

    Signature: def _ensure_utf8_streams():

    Description: Inspects sys.stdout and sys.stderr and reconfigures them to use UTF-8 encoding with character replacement if they are redirected or piped.

    Parameters:

    • None.

    Returns:

    • None: Mutates system stream configurations in place.

    Raises:

    • Does not raise exceptions.

    Example:

    # Internal invocation during init()
_ensure_utf8_streams()

        for stream in (sys.stdout, sys.stderr):
        encoding = (getattr(stream, "encoding", "") or "").lower().replace("-", "")
        if hasattr(stream, "reconfigure") and encoding != "utf8" and not stream.isatty():
            stream.reconfigure(encoding="utf-8", errors="replace")

    On Windows, non-interactive streams (such as subprocess pipes or redirected output files) often default to legacy code pages like CP1252. When the pipeline prints non-English characters (such as Vietnamese diacritics or CJK characters), these streams can raise unhandled UnicodeEncodeError exceptions. This helper checks whether sys.stdout or sys.stderr are non-TTY streams and calls .reconfigure(encoding="utf-8", errors="replace") to ensure safe, loss-tolerant output.

    _format_safe()

    Visibility: Private

    Signature: def _format_safe(template, kwargs):

    Description: Applies Python string interpolation using .format(**kwargs) to a template string. If keys are missing, indexes are invalid, or value errors occur, it safely falls back to returning the unformatted template string.

    Parameters:

    • template (str): Template string containing format replacement tokens.
    • kwargs (dict): Dictionary of keyword arguments to interpolate into the template.

    Returns:

    • str: The successfully formatted string, or the raw template if formatting fails.

    Raises:

    • Does not raise exceptions; absorbs KeyError, IndexError, and ValueError.

    Example:

    formatted = _format_safe("Processing step {step}: {name}", {"step": 1, "name": "Extract"})
# If kwargs is missing 'name', falls back gracefully:
fallback = _format_safe("Processing step {step}: {name}", {"step": 1})

        try:
        return template.format(**kwargs)
    except (KeyError, IndexError, ValueError):
        return template

    _format_safe protects the application from crashing due to string formatting issues. If an upstream caller fails to pass a required placeholder argument or passes mismatched formatting types, the exception is caught and the original template string is returned intact.

    _load_strings()

    Visibility: Private

    Signature: def _load_strings():

    Description: Reads and parses utils/strings.csv using utf-8-sig encoding, loading all string templates, log levels, and target destinations into the module's _strings catalog.

    Parameters:

    • None.

    Returns:

    • None: Replaces the contents of the _strings dictionary in place.

    Raises:

    • Does not raise exceptions. If the CSV path is unset or the file does not exist, it exits silently.

    Example:

    # Internal invocation during init() or post-translation reloading
_load_strings()

        global _strings
    _strings = {}

    if not _csv_path or not os.path.exists(_csv_path):
        return

    translated_count = 0
    total_count = 0

    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if not key or key.startswith("#"):
                continue

            level = row.get("LEVEL", "INFO").strip()
            dest = row.get("DEST", "BOTH").strip()

            # Priority: language column → English fallback
            text = row.get(_lang_col, "").strip()
            if text:
                translated_count += 1
            else:
                text = row.get("english", "").strip()

            total_count += 1
            _strings[key] = {"text": text, "level": level, "dest": dest}

    if _lang_col != "english" and translated_count == total_count:
        emit_raw("SUCCESS", f"[i18n] {_language} — loaded {translated_count} strings from CSV")

    _load_strings opens strings.csv using utf-8-sig encoding to handle Byte Order Marks (BOM) transparently. It iterates through each row using csv.DictReader, skipping blank lines and comment rows prefixed with #. For each entry, it attempts to extract the text from the column matching _lang_col. If the targeted language entry is empty, it falls back to the "english" column. Finally, it constructs a mapping containing the resolved text, severity level, and destination, storing it in _strings.

    Visibility: Private

    Signature: def _auto_translate():

    Description: Triggers an automated translation check for missing language strings in strings.csv by calling auto_translate from utils.i18n. If new translations are written to the CSV file, it reloads the internal string catalog.

    Parameters:

    • None.

    Returns:

    • None: Updates the on-disk CSV and internal cache if translations were added.

    Raises:

    • Does not raise exceptions directly; imports auto_translate locally to prevent circular dependencies.

    Example:

    # Internal invocation inside init() or translate_missing_strings()
_auto_translate()

        from utils.i18n import auto_translate

    if auto_translate(_lang_col, _language, _csv_path, _use_cache, _thinking_level):

    _auto_translate imports auto_translate from utils.i18n inside the function body to prevent circular imports between utils.output and utils.i18n.     Data Structures

    ANSI Terminal Color Palette (COLORS)

    A dictionary mapping log severity levels to ANSI escape codes for colored terminal output.

    Field Type Description
    "PROGRESS" str Cyan (\033[96m) for active steps, model requests, and progress tracking.
    "SUCCESS" str Green (\033[92m) for completed tasks, successful validations, and cache hits.
    "WARNING" str Yellow (\033[93m) for operational warnings, fallback events, and capacity limits.
    "ERROR" str Red (\033[91m) for task failures, API exceptions, and validation errors.
    "INFO" str Plain/Empty string ("") for standard configuration settings and statistics.
    "DEBUG" str Gray (\033[90m) for detailed trace metrics, skipped files, and diagnostic data.
    "FILE_WRITE" str Plain/Empty string ("") for file system output confirmations.
    "UI" str Plain/Empty string ("") reserved for documentation generation templates.

    Terminal Reset Escape Sequence (RESET)

    A public string constant ("\033[0m") used to reset terminal styling after printing colored ANSI sequences.

    String Catalog Entry (_strings)

    An in-memory dictionary mapping string identifiers to their localized text templates, severity levels, and output destinations.

    Field Type Description
    key str Unique string identifier from strings.csv (e.g., "LLM_CALL_WRITE_CHAPTER").
    key.text str Localized template string containing {variable} interpolation placeholders.
    key.level str Log severity classification (e.g., "PROGRESS", "INFO", "WARNING").
    key.dest str Routing destination code ("BOTH", "STDOUT", "LOG", "DBOTH", "DSTDOUT").

    CSV String Registry Schema (strings.csv)

    The structural contract for rows loaded from utils/strings.csv.

    Column Type Description
    STRING_KEY str Primary key identifier for the string template.
    LEVEL str Severity level mapped to the COLORS table. Defaults to "INFO".
    DEST str Target output stream ("BOTH", "STDOUT", "LOG", "DBOTH", "DSTDOUT"). Defaults to "BOTH".
    english str Default fallback English text containing format placeholders.
    <lang_col> str Dynamic column added per target language (e.g., vietnamese, japanese).

    Module-Level State Properties

    Internal variables maintaining the runtime configuration of the output subsystem.

    Variable Type Description
    _strings dict In-memory cache of parsed strings keyed by STRING_KEY.
    _language str Display name of the active target language (e.g., "Vietnamese").
    _lang_col str Lowercase column header name used for CSV language lookups.
    _log_file TextIOWrapper or None Open file handle for writing active log statements.
    _pending_log list[str] Memory buffer holding log statements generated prior to file logger initialization.
    PENDING_LOG_MAX_LINES int Upper boundary limit (5_000) for the preflight pending log list.
    _csv_path str or None Absolute filesystem path resolving to utils/strings.csv.
    _use_cache bool Cache retention flag passed to automated string translation passes.
    _thinking_level str or None Model reasoning effort parameter passed to automated string translation passes.
    _debug bool Flag determining whether debug statements appear on standard output.

    Error Handling

    The module uses several defensive strategies to ensure output and logging operations do not interrupt the main workflow:

    • Missing Key Fallbacks: If emit() receives an unregistered string key, it prints [UNKNOWN STRING: {key}] to stdout instead of raising a KeyError. Similarly, get() returns the bare key string if it is not present in the catalog.
    • Safe Template Formatting: In _format_safe(), string formatting errors (KeyError, IndexError, ValueError) caused by missing or invalid keyword arguments are caught, and the unformatted template string is returned as a fallback.
    • Stream Reconfiguration for Non-TTY Displays: On Windows environments, non-interactive redirected output streams can cause UnicodeEncodeError exceptions when handling non-ASCII characters. The _ensure_utf8_streams() helper reconfigures standard output and error streams to UTF-8 with character replacement (errors="replace").
    • Bounded Pending Buffer: The _pending_log buffer stores preflight events before log file paths are configured. To prevent unbounded memory growth if logging is never initialized, the buffer maintains a maximum capacity of PENDING_LOG_MAX_LINES (5,000 lines), evicting the oldest entries first.
    • Path Sanitization: configure_logging() sanitizes user-provided project and mode arguments, stripping unsafe filesystem characters before constructing the log file path.
    • Lazy Circular Dependency Management: The automated translation helper _auto_translate() imports utils.i18n.auto_translate inside the function body, avoiding circular import dependencies between the output formatting and translation subsystems.
