    output.py

    Source: utils/output.py

    Following the generation and layout assembly handled by mkdocs.py, the utils/output.py module serves as the centralized terminal presentation, telemetry broadcasting, and persistent file logging engine for the Codebase-Knowledge-Builder system. It decouples hardcoded console output and operational notifications from core pipeline logic, routing all human-facing messaging through a structured, multi-lingual localization catalog.

    Technical Overview

    utils/output.py implements a unified, level-aware messaging bus designed to handle simultaneous standard output rendering and persistent file-based audit logging. The architecture abstracts string presentation behind symbolic keys defined in an external CSV catalog (utils/strings.csv). By standardizing user messages around unique identifier keys, the system supports dynamic multi-language localization, safe variable interpolation, and centralized level styling without scattering formatting logic across workflow nodes or low-level transport adapters.

    A critical design challenge addressed by the module is managing output during early runtime initialization—specifically before command-line parsing, project directory creation, or log file configuration occurs. Standard library logging systems often drop early telemetry or require complex early-handler setups. utils/output.py solves this by introducing a bounded in-memory buffer (_pending_log) that holds preflight entries (such as credential checks, environment verification, and auto-translation records). Once configure_logging() executes, the buffered messages are atomically flushed into the newly initialized run log, ensuring continuous audit trails without data loss.

    The module also handles cross-platform encoding constraints and console routing rules. On non-interactive or redirected standard output streams (notably on Windows environments where non-UTF-8 code pages like CP-1252 would trigger UnicodeEncodeError when printing localized CJK or accented Latin text), the module safely reconfigures stdout and stderr streams to UTF-8. Message routing supports multiple destination targets (BOTH, STDOUT, LOG, and debug-gated variants DBOTH, DSTDOUT), pairing ANSI terminal color sequences with unadorned, ISO-8601-timestamped file logs.

    def init(language="english", use_cache=True, thinking_level=None, debug=False, auto_translate=True):
    global _language, _lang_col, _csv_path, _use_cache, _thinking_level, _debug
    _language = language.capitalize()
    _lang_col = language.lower()
    _csv_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "strings.csv")
    _use_cache = use_cache

Stream sanity checks (_ensure_utf8_streams) and catalog parsing (_load_strings) are executed immediately. If auto_translate is enabled, the helper immediately attempts to resolve missing localization definitions via downstream LLM integration.

    emit()

    Visibility: Public
    Signature: def emit(key: str, suffix: str = "", **kwargs) -> None

    Description: Retrieves a translatable template string from the in-memory catalog using a symbolic key, interpolates keyword variables safely, appends an optional unformatted suffix, and directs the resulting message to terminal standard output and/or the run log file according to catalog destination rules and debug switches.

    Parameters: * key (str): Identifier key matching an entry in strings.csv (e.g., "LLM_CALL_WRITE_CHAPTER"). * suffix (str): Optional string appended directly to the end of the formatted message (e.g., raw token counts or duration statistics). Defaults to "". * **kwargs: Key-value pairs for string template interpolation via Python .format() substitution.

    Returns: * None

    Raises: * No exceptions raised. If key is missing from strings.csv, prints an [UNKNOWN STRING: {key}] warning directly to standard output.

    Example: 

    # Emit a localized progress message with dynamic parameters and token breakdown
emit("LLM_CALL_WRITE_CHAPTER", suffix=" [1,420 tokens]", chapter_num=1, name="flow")


    def emit(key, suffix="", **kwargs):
    entry = _strings.get(key)
    if not entry:
        # Fallback for unknown keys — print raw so nothing is silently lost
        print(f"[UNKNOWN STRING: {key}]")
        return

    text = _format_safe(entry["text"], kwargs)
    if suffix:
        text = text + suffix

    level = entry["level"]
    dest = entry["dest"]

    # D-prefixed destinations (DBOTH, DSTDOUT): debug-gated console output.
    # Without --debug, suppress console but always log. Preserves original color from LEVEL.
    if dest.startswith("D"):
        if _debug:
            dest = dest[1:]  # DBOTH → BOTH, DSTDOUT → STDOUT
        else:
            dest = "LOG"

    color = COLORS.get(level, "")
    reset = RESET if color else ""

    if dest in ("BOTH", "STDOUT"):
        print(f"{color}{text}{reset}")
    if dest in ("BOTH", "LOG"):
        _write_log(level, text)
    The emit() function serves as the standard emission interface for all cataloged pipeline events. When invoked, it looks up the key in the module's _strings cache and passes the raw template along with kwargs to _format_safe(). If a routing destination begins with D (such as DBOTH or DSTDOUT), it checks the active _debug state: if debug mode is active, the prefix is stripped to allow console printing; otherwise, the destination is demoted to LOG to keep console output clean while preserving audit history. Terminal output applies ANSI color sequences mapped to the entry's level (COLORS.get(level)), while file logging via _write_log() records the plain message tagged with the uncolored level name.

    def emit_raw(level, text, dest="BOTH"):
    # DEBUG-level: suppress console unless --debug is active
    if level == "DEBUG" and not _debug:
        dest = "LOG"

    color = COLORS.get(level, "")
    reset = RESET if color else ""

    if dest in ("BOTH", "STDOUT"):
        print(f"{color}{text}{reset}")
    if dest in ("BOTH", "LOG"):
        _write_log(level, text)
    emit_raw() bypasses catalog lookups entirely to accommodate dynamic runtime data, such as ASCII trees, table formatting, or batch processing summaries. If the supplied level is set to "DEBUG" and global debug mode is disabled, the function diverts the destination to "LOG". This ensures verbose debugging diagnostics are persistently captured in the run log without cluttering standard output. ANSI color formatting and destination routing follow the exact same mechanics as emit().

    def get(key, **kwargs):
    entry = _strings.get(key)
    if not entry:
        return key  # Fallback: return the key itself

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name: str = "project", mode: str = "tutorial") -> str

    Description: Configures and opens a dedicated, timestamped file log on disk. Flushes any log entries accumulated in the in-memory buffer (_pending_log) prior to configuration and prints initial execution metadata headers.

    Parameters: * project_name (str): Name of the target project or repository being analyzed. Sanitized for filesystem safety. Defaults to "project". * mode (str): Operating pipeline mode (e.g., "tutorial", "api-reference"). Defaults to "tutorial".

    Returns: * str: Absolute or relative path to the newly created log file.

    Raises: * OSError: If log directory creation or file handle allocation fails due to filesystem permissions.

    Example: 

    # Initialize disk logging for a project workflow run
log_filepath = configure_logging(project_name="my_repo", mode="api-reference")
# Output: logs/my_repo_api_reference_20260330_141500.log


    def configure_logging(project_name="project", mode="tutorial"):
    global _log_file

    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_path = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Close any existing log file
    if _log_file is not None:
        _log_file.close()

    _log_file = open(log_path, "a", encoding="utf-8")  # noqa: SIM115

    # Log run metadata at the start of every log file
    sep = "=" * 80
    emit_raw("INFO", sep, dest="LOG")
    emit_raw("INFO", f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}", dest="LOG")
    emit_raw("INFO", f"Log file: {log_path}", dest="LOG")
    if _pending_log:
        _log_file.write("".join(_pending_log))
        _log_file.flush()
        _pending_log.clear()

    return log_path
    configure_logging() manages log file creation and initialization for each run. It resolves the output directory from the LOG_DIR environment variable (defaulting to logs/) and creates it if necessary using os.makedirs. Project names and modes are sanitized to alphanumeric and safe delimiter characters (-_) to prevent path traversal or filesystem errors. Any previously open file handle assigned to _log_file is closed. It then opens the target path in append mode with explicit utf-8 encoding. Initial metadata headers are logged, and all buffered log messages stored in _pending_log are written to disk and flushed before clearing the memory buffer.

    Internal Helpers

    _write_log()

    Visibility: Private
    Signature: def _write_log(level: str, text: str) -> None

    Description: Internal logging worker that formats a single log entry with a microsecond-precision timestamp and level marker. If configure_logging() has not yet been executed, the entry is queued in _pending_log (bounded to PENDING_LOG_MAX_LINES). Once configured, entries are written directly to _log_file and flushed.

    Parameters: * level (str): Log level category identifier (e.g., "PROGRESS", "ERROR", "INFO"). * text (str): Uncolored text payload of the message.

    Returns: * None

    Raises: * No exceptions raised.

    Example: 

    # Internal invocation from emit() or emit_raw()
_write_log("INFO", "Discovered 42 files matching inclusion criteria")


    def _write_log(level, text):
    """Write a timestamped line to the log file (buffered until configure_logging opens it)."""
    ts = datetime.now().strftime("%Y-%m-%d %H:%M:%S,%f")[:-3]
    line = f"{ts} - {level} - {text}\n"
    if _log_file is None:
        _pending_log.append(line)
        if len(_pending_log) > PENDING_LOG_MAX_LINES:
            del _pending_log[0]
        return
    _log_file.write(line)
    _log_file.flush()
    _write_log() handles log record serialization. Timestamps are formatted as YYYY-MM-DD HH:MM:SS,fff by truncating microsecond measurements to milliseconds. When _log_file is None, entries are appended to the _pending_log list. To prevent memory leaks during long-running workflows that do not configure logging, the list is capped at PENDING_LOG_MAX_LINES (5,000) using a FIFO eviction pattern (del _pending_log[0]). When the file is active, lines are immediately written and flushed to guarantee real-time log persistence.

    _ensure_utf8_streams()

    Visibility: Private
    Signature: def _ensure_utf8_streams() -> None

    Description: Inspects sys.stdout and sys.stderr to identify non-interactive, redirected, or piped execution environments, reconfiguring their output encodings to utf-8 when necessary.

    Parameters: * None

    Returns: * None

    Raises: * No exceptions raised.

    Example: 

    # Executed automatically during init()
_ensure_utf8_streams()


    def _ensure_utf8_streams():
    for stream in (sys.stdout, sys.stderr):
        encoding = (getattr(stream, "encoding", "") or "").lower().replace("-", "")
        if hasattr(stream, "reconfigure") and encoding != "utf8" and not stream.isatty():
            stream.reconfigure(encoding="utf-8", errors="replace")
    This utility prevents encoding crashes on Windows platforms when output is piped to another process or redirected to a file. Interactive consoles on modern Python runtimes (PEP 528) use UTF-8 by default, but redirected streams often fall back to legacy system codepages like CP-1252. If a non-TTY stream does not use UTF-8, _ensure_utf8_streams() invokes stream.reconfigure(encoding="utf-8", errors="replace"). This ensures Unicode characters (such as CJK text or accented characters) can be safely output without raising UnicodeEncodeError.

    _format_safe()

    Visibility: Private
    Signature: def _format_safe(template: str, kwargs: dict) -> str

    Description: Safely interpolates keyword variables into a template string using template.format(**kwargs), gracefully suppressing formatting errors if keys are missing or malformed.

    Parameters: * template (str): Template string containing {placeholder} tokens. * kwargs (dict): Dictionary of keyword arguments to interpolate into the template.

    Returns: * str: The formatted string, or the original unaltered template if an interpolation error occurs.

    Raises: * No exceptions raised; catches KeyError, IndexError, and ValueError.

    Example: 

    # Safely handles missing template variables without throwing exceptions
formatted = _format_safe("Processing {current} of {total}", {"current": 5})
# Returns "Processing {current} of {total}" if 'total' is missing


    def _format_safe(template, kwargs):
    """Apply .format(**kwargs) with graceful fallback on missing keys."""
    try:
        return template.format(**kwargs)
    except (KeyError, IndexError, ValueError):
        return template
    _format_safe() provides error isolation for string formatting. Dynamic templates loaded from strings.csv can contain placeholder variables (e.g., {project}, {count}). If caller invocations omit an expected keyword argument or the template contains unbalanced braces, standard .format() raises KeyError, IndexError, or ValueError. This helper traps those exceptions and returns the raw template string as a fallback, ensuring that messaging errors never interrupt core pipeline processing.

    _load_strings()

    Visibility: Private
    Signature: def _load_strings() -> None

    Description: Parses utils/strings.csv using csv.DictReader and populates the internal _strings catalog dictionary. Implements localized fallback resolution, defaulting to English values if the target language column entry is missing or empty.

    Parameters: * None

    Returns: * None

    Raises: * OSError: If the CSV file is inaccessible due to invalid permissions (file existence is checked prior to reading).

    Example: 

    # Reload the internal string cache after file modifications
_load_strings()


    def _load_strings():
    global _strings
    _strings = {}

    if not _csv_path or not os.path.exists(_csv_path):
        return

    translated_count = 0
    total_count = 0

    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if not key or key.startswith("#"):
                continue

            level = row.get("LEVEL", "INFO").strip()
            dest = row.get("DEST", "BOTH").strip()

            # Priority: language column → English fallback
            text = row.get(_lang_col, "").strip()
            if text:
                translated_count += 1
            else:
                text = row.get("english", "").strip()

            total_count += 1
            _strings[key] = {"text": text, "level": level, "dest": dest}

    if _lang_col != "english" and translated_count == total_count:
        emit_raw("SUCCESS", f"[i18n] {_language} — loaded {translated_count} strings from CSV")
    _load_strings() initializes and populates the in-memory string catalog. It opens _csv_path using utf-8-sig encoding to transparently strip any Byte Order Marks (BOM) introduced by text editors or Microsoft Excel. It iterates through each row, skipping blank lines and comment rows starting with #. For each valid key, it checks the configured language column (_lang_col); if empty, it falls back to the "english" column. Entries are stored in _strings as dictionaries containing "text", "level", and "dest". If a non-English language is fully translated, a success notification is emitted.

    _auto_translate()

    Visibility: Private
    Signature: def _auto_translate() -> None

    Description: Lazily imports utils.i18n.auto_translate to translate any missing string entries in strings.csv for the configured language, subsequently reloading the cache via _load_strings() if new translations were written.

    Parameters: * None

    Returns: * None

    Raises: * Traps errors downstream; does not propagate translation exceptions.

    Example: 

    # Internal invocation triggered by init() or translate_missing_strings()
_auto_translate()


    def _auto_translate():
    """Auto-translate missing strings via LLM and write back into strings.csv."""
    from utils.i18n import auto_translate

    if auto_translate(_lang_col, _language, _csv_path, _use_cache, _thinking_level):

    _auto_translate() integrates localization updates into the output module. To prevent circular import cycles between output.py, i18n.py, and call_llm.py, auto_translate is imported dynamically inside the function body. If auto_translate() returns True (indicating that new translations were generated and persisted to the CSV file), _auto_translate() calls _load_strings() to refresh the in-memory cache so subsequent emit() calls use the updated translations.

    Data Structures

    ANSI Color Palette (COLORS)

    Mapping of semantic output levels to their corresponding ANSI escape sequences:

    Level Key ANSI Escape Code Rendered Appearance Intended Context
    "PROGRESS" "\033[96m" Cyan LLM invocations, active pipeline steps, crawl loops
    "SUCCESS" "\033[92m" Green Successful step completions, cache hits, finish notices
    "WARNING" "\033[93m" Yellow Non-fatal alerts, context window limits, fallbacks
    "ERROR" "\033[91m" Red Fatal failures, API rejections, unhandled exceptions
    "INFO" "" Standard Console Configuration parameters, file counts, telemetry headers
    "DEBUG" "\033[90m" Gray Ignored paths, fine-grained AST parsing, debug logs
    "FILE_WRITE" "" Standard Console File serialization logs (- Wrote {path})
    "UI" "" Standard Console Markdown headers and UI labels (never styled)

    Module State Registry

    The module maintains runtime state across multiple module-level variables:

    Variable Type Default Value Description
    _strings dict[str, dict[str, str]] {} In-memory cache mapping string keys to their configuration dictionaries.
    _language str "English" Capitalized display name of active localization language.
    _lang_col str "english" Lowercase column header used for CSV lookups.
    _log_file io.TextIOWrapper or None None Open file handle pointing to the active log file on disk.
    _pending_log list[str] [] FIFO queue holding log entries generated before log file initialization.
    PENDING_LOG_MAX_LINES int 5000 Maximum capacity of _pending_log before dropping the oldest entries.
    _csv_path str or None None Absolute filesystem path resolving to utils/strings.csv.
    _use_cache bool True Global flag indicating if translation LLM calls should use caching.
    _thinking_level Any None Reasoning effort level passed to translation LLM calls.
    _debug bool False Global flag controlling verbose debug output and destination routing.

    Error Handling

    Non-Interactive Stream Transcoding

    On Windows platforms, redirected standard output streams often default to legacy single-byte codepages (e.g., CP-1252), causing UnicodeEncodeError when non-ASCII characters are encountered. The module resolves this by checking stream.isatty() in _ensure_utf8_streams() and reconfiguring non-TTY streams using stream.reconfigure(encoding="utf-8", errors="replace"). This ensures Unicode strings are safely output without raising encoding exceptions.

    Safe Template Variable Substitution

    Templates loaded from strings.csv rely on bracketed placeholders (e.g., {project_name}). The internal helper _format_safe() intercepts formatting exceptions: 

    try:
    return template.format(**kwargs)
except (KeyError, IndexError, ValueError):
    return template
    If caller invocations omit required parameters or include mismatched types, the exception is caught and the original template string is returned as a fallback. This guarantees that missing formatting variables do not cause runtime failures during output emission.

    Missing Key and Unknown Entry Fallbacks

    If an unrecognized key is passed to emit() or get(), the module falls back gracefully instead of raising exceptions: * emit() prints a raw warning: [UNKNOWN STRING: {key}]. * get() returns the raw key string, allowing document generation pipelines to continue without interruptions from missing UI labels.

    Bounded In-Memory Buffering

    Log entries generated before log file initialization are held in _pending_log. To prevent unbounded memory consumption during long-running workflows without file logging, the buffer is capped at 5,000 lines (PENDING_LOG_MAX_LINES). Once this threshold is reached, older entries are dropped using a FIFO queue strategy (del _pending_log[0]).
