    output.py

    Source: utils/output.py

    Following the baseline filesystem filtering rules established in exclude_patterns.py to discard extraneous files during codebase crawling, the Codebase-Knowledge-Builder pipeline requires a unified telemetry, logging, and user communication interface. The output.py module serves as this centralized subsystem, managing ANSI-styled terminal output, persistent file logging, multi-language internationalization (i18n), dynamic LLM-driven string translation, and UI string retrieval for generated documentation artifacts.

    Technical Overview

    The output.py module centralizes all visual presentation, diagnostic messaging, and execution tracing across the system. It replaces unmanaged print() and direct logger calls with a structured, data-driven emission pipeline backed by a CSV string registry (utils/strings.csv).

    Core Responsibilities

    1. Structured Presentation: Decouples presentation logic from operational code by enforcing level-based ANSI color styling (PROGRESS, SUCCESS, WARNING, ERROR, INFO, DEBUG, FILE_WRITE, UI).
    2. Dual-Channel Dispatch: Directs output to standard output (STDOUT), disk-based log files (LOG), or both (BOTH), respecting severity mappings to Python's standard logging library.
    3. Internationalization & Localization (i18n): Translates user-facing messages and generated document titles dynamically using language-specific columns in utils/strings.csv.
    4. Autonomous Self-Healing Translations: Detects missing string translations at runtime, constructs translation prompts for target languages, invokes the LLM via call_llm.py, parses the structured JSON response, and persists translated strings back to strings.csv with UTF-8 BOM encoding.
    5. Per-Invocation File Logging: Configures dedicated timestamped log files in a configurable directory (logs/ by default) containing execution metadata and unstyled message streams.

    Architecture & Workflows

    Initialization and Dynamic Translation Workflow

    When the system boots, init() reads strings.csv to populate the in-memory string registry. If a non-English language is requested and untranslated string entries are encountered, the module executes an automated translation and self-update cycle.

    Module-Level Constants & Global State

    COLORS

    COLORS = {
    "PROGRESS": "\033[96m",  # Cyan — LLM calls, active steps
    "SUCCESS": "\033[92m",  # Green — completions, cache hits
    "WARNING": "\033[93m",  # Yellow — warnings, capacity alerts
    "ERROR": "\033[91m",  # Red — errors, failures
    "INFO": "",  # Plain — config, counts, labels
    "DEBUG": "\033[90m",  # Gray — skipped files, debug
    "FILE_WRITE": "",  # Plain — "  - Wrote {path}" messages
    "UI": "",  # N/A — used in generated docs, never printed
}
    Type: dict[str, str]
    Defines mapping from logical message levels to standard ANSI 8-bit escape sequences for terminal styling. Levels configured with empty strings ("") render without escape codes.

    RESET

    RESET = "\033[0m"
    Type: str
    The standard ANSI escape sequence used to reset terminal text attributes and colors back to default styling after emitting a colored message.

    LOG_LEVELS

    LOG_LEVELS = {
    "PROGRESS": logging.INFO,
    "SUCCESS": logging.INFO,
    "WARNING": logging.WARNING,
    "ERROR": logging.ERROR,
    "INFO": logging.INFO,
    "DEBUG": logging.DEBUG,
    "FILE_WRITE": logging.DEBUG,
}
    Type: dict[str, int]
    Maps user-facing logical emission levels to Python standard logging severity integer constants.

    Internal Module State Variables

    • _strings: dict[str, dict[str, str]] — In-memory dictionary caching the parsed string registry. Keys are string identifiers (e.g., LLM_CALL_WRITE_CHAPTER), mapping to records containing {"text": str, "level": str, "dest": str}.
    • _language: str — Target display language capitalized for UI and logging outputs (e.g., "Vietnamese"). Defaults to "English".
    • _lang_col: str — Lowercase identifier matching CSV column header names (e.g., "vietnamese"). Defaults to "english".
    • _logger: logging.Logger — Named logger instance ("llm_logger") utilized across the application lifecycle.
    • _csv_path: str | None — Absolute filesystem path to utils/strings.csv. Initialized by init().
    • _use_cache: bool — Controls whether automated translation calls allow LLM prompt-response disk caching. Defaults to True.
    • _thinking_level: int | None — Configured LLM thinking or reasoning budget parameter forwarded to translation inference requests. Defaults to None.

    Description:

It resolves the absolute path to utils/strings.csv, sets module-level language preferences, populates the in-memory string lookup cache via _load_strings(), and triggers _auto_translate() to translate any missing localized strings via an LLM call before normal execution begins. Defaults to True. * thinking_level (int | None, optional): Reasoning/thinking budget level forwarded to the LLM backend during translation. Defaults to None.

    Returns: * None

    Raises: * Does not raise exceptions directly; translation and file I/O exceptions during initialization are intercepted, logged as warnings, and fall back to English.

    Implementation: 

    def init(language="english", use_cache=True, thinking_level=None):
    global _language, _lang_col, _csv_path, _use_cache, _thinking_level
    _language = language.capitalize()
    _lang_col = language.lower()
    _csv_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "strings.csv")
    _use_cache = use_cache
    _thinking_level = thinking_level
    _load_strings()
    _auto_translate()

    The function normalizes the input language parameter into capitalized form (_language) for human-readable logging and lowercase form (_lang_col) for column key lookups against strings.csv. It computes the absolute path to the CSV file relative to __file__, guaranteeing path consistency regardless of the current working directory. Once the internal globals are assigned, it executes a sequential load-and-translate sequence.

    emit()

    Visibility: Public
    Signature: def emit(key: str, suffix: str = "", **kwargs: Any) -> None:

    Description:
    Emits a registered, localized message template to standard output, the log file, or both. The message is resolved from the internal string table by key, interpolated safely with provided keyword arguments (**kwargs), appended with an optional unformatted suffix, and decorated with ANSI terminal color codes corresponding to its declared severity level.

    Parameters: * key (str): The unique string identifier defined in strings.csv (e.g., "LLM_CALL_WRITE_CHAPTER"). * suffix (str, optional): Additional text appended directly to the formatted message (e.g., token consumption statistics "(2,100 tokens)"). Defaults to "". * **kwargs (Any): Named replacement variables matching {placeholder} tokens in the template.

    Returns: * None

    Raises: * No exceptions raised. Unknown keys trigger an unstyled fallback warning directly to stdout ([UNKNOWN STRING: {key}]).

    Implementation: 

    def emit(key, suffix="", **kwargs):
    entry = _strings.get(key)
    if not entry:
        # Fallback for unknown keys — print raw so nothing is silently lost
        print(f"[UNKNOWN STRING: {key}]")
        return

    text = _format_safe(entry["text"], kwargs)
    if suffix:
        text = text + suffix

    level = entry["level"]
    dest = entry["dest"]
    color = COLORS.get(level, "")
    reset = RESET if color else ""

    if dest in ("BOTH", "STDOUT"):
        print(f"{color}{text}{reset}")
    if dest in ("BOTH", "LOG"):
        _logger.log(LOG_LEVELS.get(level, logging.INFO), text)

    emit() performs a defensive dictionary lookup on _strings. If the requested key is not registered, it avoids raising KeyError or crashing the caller, opting to print [UNKNOWN STRING: <key>] to ensure the diagnostic failure is immediately visible. If the entry exists, it invokes _format_safe() to replace template placeholders, appends the raw suffix, maps the entry's destination attribute (dest) against allowed output targets (BOTH, STDOUT, LOG), and routes the unstyled text to _logger.log() while routing ANSI-wrapped text to print().

    Example: 

    # Real usage from source code docstring:
emit("LLM_CALL_WRITE_CHAPTER", chapter_num=1, name="flow")

    def emit_raw(level, text, dest="BOTH"):

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name: str = "project", mode: str = "tutorial") -> str:

    Description:
    Configures dedicated file-based logging for the active execution run. It resolves the target log directory (defaulting to the LOG_DIR environment variable or "logs"), sanitizes project and mode names for filesystem safety, creates a timestamped log file ({project}_{mode}_{YYYYMMDD_HHmmss}.log), clears existing handlers from _logger, attaches a formatted logging.FileHandler using UTF-8 encoding, and writes header metadata demarcating the start of the execution run.

    Parameters: * project_name (str, optional): Name of the codebase project being processed. Non-alphanumeric characters (excluding -_..) are replaced with underscores. Defaults to "project". * mode (str, optional): Active pipeline operating mode (e.g., "tutorial", "deep-dive"). Hyphens are replaced with underscores. Defaults to "tutorial".

    Returns: * str: The absolute or relative filesystem path to the newly created log file.

    Raises: * OSError: If the target log directory cannot be created due to filesystem permissions.

    Implementation: 

    def configure_logging(project_name="project", mode="tutorial"):
    from datetime import datetime

    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    _logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
    _logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    _logger.info(f"{'=' * 80}")
    _logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    _logger.info(f"Log file: {log_file}")
    _logger.info(f"{'=' * 80}")

    return log_file

    configure_logging() isolates run logs into separate files, preventing log accumulation across multiple invocations. It replaces prior handlers on _logger (such as default stream handlers or NullHandler instances set during initial module import) with a single FileHandler configured for %(asctime)s - %(levelname)s - %(message)s. It records initialization banners containing the un-sanitized project name, mode, and execution timestamp before returning the file path.

    _format_safe()

    Visibility: Private
    Signature: def _format_safe(template: str, kwargs: dict[str, Any]) -> str:

    Description:
    Safely applies Python string formatting (str.format(**kwargs)) against a template string. If the template contains unsupplied placeholders, malformed index markers, or invalid format specifiers, it intercepts KeyError, IndexError, and ValueError and returns the unmodified template.

    Parameters: * template (str): Format string template potentially containing {key} placeholders. * kwargs (dict[str, Any]): Dictionary of substitution arguments.

    Returns: * str: The successfully formatted string, or the raw template if interpolation raised an error.

    Raises: * Intercepts all formatting exceptions (KeyError, IndexError, ValueError); never propagates errors.

    Implementation: 

    def _format_safe(template, kwargs):
    try:
        return template.format(**kwargs)
    except (KeyError, IndexError, ValueError):
        return template

    This helper protects terminal rendering and document generation pipelines from formatting failures. In scenarios where a translated string modifies placeholder variable names or an API call omits an optional format argument, standard .format() would throw a fatal exception. _format_safe() guarantees graceful fallback by returning the raw string template.

    _load_strings()

    Visibility: Private
    Signature: def _load_strings() -> None:

    Description:
    Parses utils/strings.csv into the internal _strings dictionary cache. It ignores empty lines and comment rows (lines starting with #), reads metadata columns (LEVEL, DEST), extracts the target language translation matching _lang_col, and falls back to the "english" column if the target column is missing or empty. If all strings for a non-English language are successfully resolved, it emits a confirmation message.

    Parameters: * None (operates on module-level globals _csv_path, _lang_col, _language, and _strings).

    Returns: * None

    Raises: * OSError: If the CSV file exists but cannot be read due to OS permission restrictions.

    Implementation: 

    def _load_strings():
    global _strings
    _strings = {}

    if not _csv_path or not os.path.exists(_csv_path):
        return

    translated_count = 0
    total_count = 0

    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if not key or key.startswith("#"):
                continue

            level = row.get("LEVEL", "INFO").strip()
            dest = row.get("DEST", "BOTH").strip()

            # Priority: language column → English fallback
            text = row.get(_lang_col, "").strip()
            if text:
                translated_count += 1
            else:
                text = row.get("english", "").strip()

            total_count += 1
            _strings[key] = {"text": text, "level": level, "dest": dest}

    if _lang_col != "english" and translated_count == total_count:
        emit_raw("SUCCESS", f"[i18n] {_language} — loaded {translated_count} strings from CSV")

    The function utilizes utf-8-sig encoding when reading strings.csv to strip Byte Order Marks (BOM) transparently. It tracks translated_count against total_count to determine whether all strings possess explicit translations for the requested language. If every key is translated and the selected language is not English, it emits a SUCCESS notification detailing the string count loaded.

    _auto_translate()

    Visibility: Private
    Signature: def _auto_translate() -> None:

    Description:
    Identifies untranslated strings in strings.csv for the active language, constructs an LLM prompt using prompts/common/translate_strings.md, calls call_llm() to obtain JSON-formatted translations, persists the new translations to disk via _write_translations_to_csv(), and triggers a cache reload via _load_strings().

    Parameters: * None (uses module state _lang_col, _csv_path, _language, _use_cache, _thinking_level).

    Returns: * None

    Raises: * Catches all exceptions (Exception) during LLM invocation or JSON decoding, logs a warning message using emit_raw(), and falls back to English defaults.

    Implementation: 

    def _auto_translate():
    if _lang_col == "english":
        return

    if not _csv_path or not os.path.exists(_csv_path):
        return

    # Collect strings that have no translation in the target language column
    missing = {}
    is_new_column = False
    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        fieldnames = list(reader.fieldnames)
        is_new_column = _lang_col not in fieldnames
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if not key or key.startswith("#"):
                continue
            # Check if the language column exists and has a value
            lang_text = row.get(_lang_col, "").strip() if _lang_col in fieldnames else ""
            if lang_text:
                continue  # Already translated

            english_text = row.get("english", "").strip()
            if english_text:
                missing[key] = english_text

    if not missing:
        return

    # Report what we found
    if is_new_column:
        emit_raw("PROGRESS", f"[i18n] New language '{_language}' — adding column to strings.csv")
    emit_raw("PROGRESS", f"[i18n] {len(missing)} strings need translation to {_language}")

    # Batch translate via LLM
    try:
        from utils.call_llm import call_llm

        entries_json = json.dumps(missing, ensure_ascii=False, indent=2)

        # Load prompt template from prompts/common/translate_strings.md
        prompt_path = os.path.join(
            os.path.dirname(os.path.dirname(os.path.abspath(__file__))),
            "prompts",
            "common",
            "translate_strings.md",
        )
        with open(prompt_path, encoding="utf-8") as pf:
            prompt_template = pf.read()
        prompt = prompt_template.format(language=_language, entries=entries_json)

        emit_raw("PROGRESS", f"[i18n] Calling LLM to translate {len(missing)} strings...")
        response = call_llm(prompt, use_cache=_use_cache, thinking_level=_thinking_level)

        # Extract JSON from response
        json_match = re.search(r"\{[^{}]*(?:\{[^{}]*\}[^{}]*)*\}", response, re.DOTALL)
        if json_match:
            translations = json.loads(json_match.group())
            translated_count = len(translations)

            # Write translations back into strings.csv
            _write_translations_to_csv(translations)
            emit_raw("SUCCESS", f"[i18n] Translated {translated_count}/{len(missing)} strings — saved to strings.csv")

            # Reload strings from the updated CSV so all translations are active
            _load_strings()
        else:
            emit_raw("WARNING", "[i18n] LLM response did not contain valid JSON — falling back to English")

    except Exception as e:
        emit_raw("WARNING", f"[i18n] Translation failed: {e} — falling back to English")

    The function executes lazy translation initialization. It scans strings.csv to identify keys that lack values in the target column (_lang_col). If missing entries exist, it serializes them into a JSON payload and injects them into prompts/common/translate_strings.md. It executes an inference request through call_llm.py (call_llm()), extracts the JSON payload from the LLM response using regular expression matching (re.search(r"\{[^{}]*(?:\{[^{}]*\}[^{}]*)*\}", ...)), writes the translated records back to strings.csv, and triggers _load_strings() to activate the translations immediately.

    _write_translations_to_csv()

    Visibility: Private
    Signature: def _write_translations_to_csv(translations: dict[str, str]) -> None:

    Description:
    Updates utils/strings.csv on disk with newly generated translations. If the active language column does not exist in the CSV header, it is dynamically appended. The file is rewritten with utf-8-sig encoding (including a UTF-8 BOM) to ensure compatibility when opened directly in external spreadsheet applications like Microsoft Excel.

    Parameters: * translations (dict[str, str]): Key-value dictionary where keys correspond to STRING_KEY identifiers and values contain translated strings.

    Returns: * None

    Raises: * OSError: If writing to _csv_path fails due to disk errors or file lock contentions.

    Implementation: 

    def _write_translations_to_csv(translations):
    rows = []
    fieldnames = None

    with open(_csv_path, encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        fieldnames = list(reader.fieldnames)
        # Add language column if it doesn't exist
        if _lang_col not in fieldnames:
            fieldnames.append(_lang_col)
        for row in reader:
            key = row.get("STRING_KEY", "").strip()
            if key in translations:
                row[_lang_col] = translations[key]
            rows.append(row)

    # Write with BOM so Excel opens as UTF-8 without extra import steps
    with open(_csv_path, "w", encoding="utf-8-sig", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(rows)

    The function performs an in-place migration of strings.csv. It reads existing rows into memory, appends _lang_col to fieldnames if it is a newly introduced language, merges the incoming translations dictionary into matching row objects, and writes the entire dataset back out using csv.DictWriter. Setting encoding="utf-8-sig" ensures that multi-byte non-Latin characters (e.g., Vietnamese, Japanese, Chinese) render cleanly across all text editors and spreadsheet tools without encoding corruption.

    Data Schema: strings.csv

    The strings.csv file defines the contract between string identifiers, emission levels, routing targets, and localized text.

    Column Header Type Description
    STRING_KEY str Unique uppercase identifier (e.g., CRAWL_LOCAL_START, TOKEN_BUDGET_EXCEEDED).
    LEVEL str Message category matching COLORS and LOG_LEVELS (PROGRESS, SUCCESS, WARNING, ERROR, INFO, DEBUG, FILE_WRITE, UI).
    DEST str Target output sink (STDOUT, LOG, BOTH).
    english str Baseline English text containing {placeholder} variables.
    <language> str Dynamically appended columns for target languages (e.g., vietnamese, japanese, french).
