    utils.call_llm

    File Path: utils/call_llm.py

    Technical overview and API reference for utils/call_llm.py. This module serves as the centralized Large Language Model (LLM) abstraction layer for the Codebase-Knowledge-Builder system. It manages model execution routing, persistent disk caching, granular file-based logging, dynamic context window discovery, and reasoning/thinking configurations across both Google Gemini and OpenAI-compatible inference providers (such as Ollama and OpenRouter).

    Technical Overview

    The utils.call_llm module coordinates all text generation interactions with remote and local LLM backends. It isolates upstream pipeline nodes from the complexities of vendor-specific SDKs, authorization schemes, and REST schemas.

    Key Architectural Capabilities

    1. Dual Provider Routing:
    2. Google Gemini Engine: Direct integration via the modern google-genai SDK (google.genai), supporting both API key authentication and Google Cloud Vertex AI infrastructure (GEMINI_PROJECT_ID, GEMINI_LOCATION).
    3. OpenAI-Compatible Endpoint Engine: Generic HTTP client capable of communicating with standard /v1/chat/completions REST endpoints, including local Ollama runtimes and OpenRouter proxy networks.
    4. Response Caching: Deterministic local caching using an llm_cache.json flat-file registry to eliminate redundant token consumption and expedite debugging across repetitive workflow executions.
    5. Reasoning and Extended Thinking Support: Translates abstract reasoning requests (thinking_level in low, medium, high) to underlying engine configurations:
    6. For Gemini: Sets types.ThinkingConfig(thinking_budget=...).
    7. For OpenRouter: Validates provider capabilities dynamically against the OpenRouter API and attaches reasoning: {"effort": ...} payloads.
    8. For Ollama: Injects both think and reasoning_effort parameters.
    9. Context Length Discovery: Programmatically fetches model context limits via get_model_context_length to facilitate safe token chunking and batch management upstream in token_utils.
    10. Run-Isolated Logging: Implements a two-phase logging lifecycle using Python's standard logging library. Logging is absorbed via logging.NullHandler at import time and activated per-run into timestamped files via configure_logging.

    Module-Level Variables

    • logger (logging.Logger): Dedicated logger named "llm_logger" with disabled propagation to prevent unformatted emissions to the root logger. Handlers are assigned dynamically at runtime.
    • cache_file (str): Target JSON file path for LLM prompt-response pairs ("llm_cache.json").
    • _openrouter_models_cache (Optional[List[Dict[str, Any]]]): In-memory singleton cache holding model metadata downloaded from the OpenRouter API endpoint.

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name="project", mode="tutorial") -> str:

    Description: Configures file-based logging for the active execution run. It creates a dedicated directory (defaulting to logs/ or sourced from the LOG_DIR environment variable) and initializes a logging.FileHandler using a timestamped filename format: {safe_project}_{safe_mode}_{YYYYMMDD_HHmmss}.log. Any existing handlers on logger (such as the default import-time NullHandler) are cleared prior to attaching the file handler. It writes run initialization banners containing execution metadata directly to the log file.

    Parameters: * project_name (str, optional): Identifier for the target project being analyzed. Sanitized to alphanumeric, dash, dot, and underscore characters. Defaults to "project". * mode (str, optional): Execution mode or workflow profile. Hyphens are replaced with underscores. Defaults to "tutorial".

    Returns: * str: The absolute or relative filesystem path of the initialized log file.

    Raises: * OSError: If the directory specified in LOG_DIR cannot be created.

    Implementation: 

    def configure_logging(project_name="project", mode="tutorial"):
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'=' * 80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'=' * 80}")

    return log_file

    The function provides predictable log isolation across multiple parallel or sequential pipeline invocations. It sanitizes user-supplied project names by filtering non-standard filesystem characters to prevent directory traversal or malformed file paths. The log format includes full millisecond timestamps, logging severity levels, and structured informational banners.

    def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):

    Description: Retrieves model capability metadata from OpenRouter's public model catalog endpoint (https://openrouter.ai/api/v1/models). Results are cached within the module-level _openrouter_models_cache variable to avoid redundant network round-trips across consecutive model invocations.

    Parameters: * model_id (str): The unique identifier of the target model (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict | None: The dictionary containing model metadata (such as reasoning support, pricing, and context limits), or None if the model cannot be found or the network request fails.

    Raises: * No exceptions are raised; network and parsing errors default _openrouter_models_cache to an empty list.

    Implementation: 

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function protects network latency during high-volume generation loops by using a lazy global cache pattern. It applies a 5-second connection and read timeout to ensure transient connectivity issues do not stall execution indefinitely.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Determines the maximum token context window supported by a given model and endpoint. For Google Gemini endpoints or model names containing "gemini", it defaults to 1,000,000 tokens. For OpenRouter endpoints, it queries https://openrouter.ai/api/v1/models to extract the exact context_length property. For other configurations or on failure, it falls back to a safe default of 100,000 tokens.

    Parameters: * endpoint_url (str): The base or endpoint URL configured for inference requests. * model_name (str): The name or identifier of the LLM model. * api_key (str, optional): Authorization token (reserved for future authenticated catalog endpoints). Defaults to "".

    Returns: * int: The maximum token context length supported by the model.

    Raises: * No exceptions are raised; unexpected failures emit warnings to logger and return 100000.

    Implementation: 

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This method is utilized by upstream partitioning algorithms to prevent token overflow exceptions during ingestion. By distinguishing Gemini's large-scale window from standard OpenAI/Ollama limits, callers can accurately maximize payload sizes.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Executes a chat completion request against an OpenAI-compatible HTTP REST endpoint (e.g., OpenRouter, Ollama, LocalAI). It reads runtime configurations from environment variables dynamically based on LLM_PROVIDER: * {provider}_MODEL: Model name. * {provider}_BASE_URL: Base host URL (e.g., http://localhost:11434). * {provider}_API_KEY: API key for authorization headers.

    It normalizes URLs to append /v1/chat/completions, constructs authorization and JSON payload headers, applies vendor-specific reasoning effort parameters, and executes a requests.post call with a dual timeout (10, 300) (10s connection, 300s read).

    Parameters: * prompt (str): The raw text prompt sent as a user message. * thinking_level (str | None, optional): Desired reasoning effort level (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The textual content response extracted from choices[0].message.content.

    Raises: * ValueError: If LLM_PROVIDER, {provider}_MODEL, or {provider}_BASE_URL are unset; if the server response is invalid JSON; or if the response lacks expected choices fields. * Exception: Standardized wrapping for requests.exceptions.HTTPError, requests.exceptions.ConnectionError, requests.exceptions.Timeout, and requests.exceptions.RequestException.

    Implementation: 

    def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")

    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        try:
            response_json = response.json()
        except (ValueError, requests.exceptions.JSONDecodeError):
            print(f"\033[93mWarning: Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}\033[0m")
            logger.warning(f"Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}")
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None
        response.raise_for_status()

        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        // ... error message extraction logic ...
        raise Exception(error_message) from e
    except requests.exceptions.ConnectionError as e:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
    except requests.exceptions.Timeout as e:
        raise Exception(f"Request to {provider} API timed out.") from e
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
    except ValueError as e:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e

    This method implements rigorous defensive programming patterns against non-standard REST responses. When targeting reasoning models via OpenRouter or Ollama, it automatically adjusts the request temperature to 1.0 (as required by most reasoning parsers) and injects vendor-compliant parameters (reasoning.effort or think/reasoning_effort). It checks for empty choice arrays and HTTP 200 error payloads before extracting generated content.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Executes a generative content request against the Google Gemini API using the official google-genai SDK (google.genai.Client). It authenticates via Google Cloud Vertex AI if GEMINI_PROJECT_ID is set, or via direct API key if GEMINI_API_KEY is present. It configures model parameters, calculates thinking token budgets when requested, dispatches generation via client.models.generate_content, and filters the returned candidate parts to concatenate text-only segments.

    Parameters: * prompt (str): Text prompt sent to Gemini. * thinking_level (str | None, optional): Budget level mapping for model thinking ("low" -> 1024, "medium" -> 4096, "high" -> 8192). Defaults to None.

    Returns: * str: The concatenated text output from all text candidate parts.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY are defined in the environment.

    Implementation: 

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    The function handles specific Gemini 2.0/3.0/3.7 response structures where reasoning candidates contain non-text components (such as thought_signature parts). By explicitly iterating over response.candidates[0].content.parts and selecting only non-null part.text entries, it prevents serialization warnings and runtime crashes.

    Description: The primary entry point for executing LLM queries across the entire codebase. It calculates prompt token metrics via utils.token_utils.count_tokens, checks the local disk cache, logs request parameters and prompts, delegates execution to either _call_llm_gemini or _call_llm_provider, writes fresh responses back to disk cache, and logs timing benchmarks.

    Returns: * str: The generated text response from the cache or provider.

    Raises: * Exception: Propagates any underlying network, authentication, or parsing exceptions raised by _call_llm_gemini or _call_llm_provider.

    Implementation & Actual In-Source Usage: 

    def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text
