    utils.call_llm

    File Path: utils/call_llm.py

    Technical Overview

    The utils.call_llm module provides an abstraction layer for interacting with Large Language Model (LLM) backends within the Codebase-Knowledge-Builder system. It manages model execution routing, caching, run-level logging, and token budgeting parameters across multiple provider endpoints, including Google Gemini (via Vertex AI or Gemini Developer API), OpenRouter, and Ollama (or any standard OpenAI-compatible /v1/chat/completions server).

    The module enforces standard structured generation flows by providing: 1. Dynamic Provider Resolution: Automatically inspects environment variables (LLM_PROVIDER, GEMINI_PROJECT_ID, GEMINI_API_KEY) to select between direct Google Gemini SDK calls and OpenAI-compatible HTTP requests. 2. Local Response Caching: Implements a simple disk-backed JSON cache (llm_cache.json) to prevent redundant LLM invocations during development and multi-stage workflow testing. 3. Reasoning/Thinking Budget Adaptation: Translates standardized string levels (low, medium, high) into provider-specific reasoning configurations (such as types.ThinkingConfig for Gemini or payload parameters like reasoning / think / reasoning_effort for OpenRouter and Ollama). 4. Context Length Discovery: Queries provider endpoints (such as OpenRouter's model catalog) or applies heuristic defaults to retrieve maximum context windows for prompt fitting. 5. Session-Specific File Logging: Configures decoupled file-based logging isolated from root loggers, storing complete prompts, execution timing, token statistics, and raw responses.

    Module Constants and Global State

    • logger: A logging.Logger instance named "llm_logger". At import time, logger.propagate is set to False and a logging.NullHandler is attached to prevent unconfigured root logging output until configure_logging() is explicitly invoked.
    • cache_file (str): File system path for the disk cache, hardcoded to "llm_cache.json".
    • _openrouter_models_cache (list[dict] | None): In-memory cache holding the OpenRouter /api/v1/models JSON array to eliminate repeated HTTP model lookups during context and capability discovery.

    Module-Level Functions

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name: str = "project", mode: str = "tutorial") -> str:

    Description: Configures run-specific file-based logging for the execution session. It creates the target log directory (controlled by LOG_DIR, default "logs"), sanitizes project_name and mode to guarantee filesystem safety, clears existing handlers (including NullHandler), and attaches a logging.FileHandler using UTF-8 encoding. It logs an initial banner with execution metadata and returns the resolved log file path.

    Parameters: * project_name (str): Name of the repository or project being processed. Defaults to "project". * mode (str): Operational mode of the pipeline (e.g., "tutorial", "documentation"). Defaults to "tutorial".

    Returns: * str: Absolute or relative path to the generated log file.

    Raises: * OSError: If directory creation or file initialization fails due to insufficient permissions or invalid paths.

    Example: 

    # Extracted from utils/call_llm.py configure_logging implementation
log_directory = os.getenv("LOG_DIR", "logs")
os.makedirs(log_directory, exist_ok=True)

# Sanitize project name for filesystem safety
safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
safe_mode = mode.replace("-", "_")
timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

# Remove any existing handlers (e.g., NullHandler) and add the file handler
logger.handlers.clear()
file_handler = logging.FileHandler(log_file, encoding="utf-8")
file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
logger.addHandler(file_handler)

    The function ensures that each execution session creates an isolated log file formatted as {safe_project}_{safe_mode}_{YYYYMMDD_HHmmss}.log. By clearing existing handlers before adding the new file handler, it transitions the module from its initial silent NullHandler state to active file recording without duplicate logs. The header block printed at the top of the log captures the startup parameters, ensuring traceability across multi-stage runs.

    load_cache()

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description: Reads and deserializes the JSON cache file from cache_file ("llm_cache.json"). If the file does not exist, cannot be accessed, or contains malformed JSON, it logs a warning via logger.warning and returns an empty dictionary.

    Parameters: * None.

    Returns: * dict: Mapping of prompt strings to cached LLM output strings, or an empty dictionary if loading fails.

    Raises: * None (all exceptions are trapped internally).

    Example: 

    # Extracted from utils/call_llm.py load_cache implementation
try:
    with open(cache_file) as f:
        return json.load(f)
except Exception:
    logger.warning("Failed to load cache.")
return {}

    load_cache provides resilient cache access designed to prevent disk I/O errors from breaking the pipeline. When executing in environments where llm_cache.json does not yet exist or is being accessed concurrently, any read failure gracefully falls back to returning {}. This ensures downstream callers can proceed directly to live API execution.

    save_cache()

    Visibility: Public
    Signature: def save_cache(cache: dict) -> None:

    Description: Serializes and writes the provided in-memory cache dictionary back to disk at cache_file ("llm_cache.json"). If serialization or file I/O fails, it catches the exception and logs a warning.

    Parameters: * cache (dict): The updated prompt-to-response dictionary to persist.

    Returns: * None

    Raises: * None (all exceptions are trapped internally).

    Example: 

    # Extracted from utils/call_llm.py save_cache implementation
try:
    with open(cache_file, "w") as f:
        json.dump(cache, f)
except Exception:
    logger.warning("Failed to save cache")

    The persistence strategy writes raw JSON directly to the target file. It relies on standard dictionary serialization, meaning keys must be string prompts and values must be string responses. Like load_cache(), non-fatal error handling prevents write access issues from aborting long-running generation pipelines.

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description: Resolves the active LLM backend provider name by inspecting environment variables. If LLM_PROVIDER is set, its value is returned directly. If LLM_PROVIDER is unset, it checks for the presence of GEMINI_PROJECT_ID or GEMINI_API_KEY; if either exists, it defaults the provider to "GEMINI".

    Parameters: * None.

    Returns: * str | None: The resolved provider identifier (e.g., "GEMINI", "OPENROUTER", "OLLAMA"), or None if no relevant configuration is present.

    Raises: * None.

    Example: 

    # Extracted from utils/call_llm.py get_llm_provider implementation
provider = os.getenv("LLM_PROVIDER")
if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
    provider = "GEMINI"
# if necessary, add ANTHROPIC/OPENAI
return provider

    This function implements the environment discovery precedence for the application. By falling back to "GEMINI" when Google Cloud or Gemini API credentials exist, it simplifies local setups where explicit LLM_PROVIDER definitions might be omitted.

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description: Queries the OpenRouter catalog endpoint (https://openrouter.ai/api/v1/models) to retrieve metadata for a given model ID. It caches the API response in the module-level global variable _openrouter_models_cache upon the first request to eliminate redundant HTTP overhead on subsequent lookups.

    Parameters: * model_id (str): The model identifier string to match (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict | None: The dictionary containing model specifications (including reasoning and context_length), or None if the model was not found or the network request failed.

    Raises: * None.

    Example: 

    # Extracted from utils/call_llm.py _get_openrouter_model_info implementation
global _openrouter_models_cache
if _openrouter_models_cache is None:
    try:
        resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
        _openrouter_models_cache = resp.json().get("data", [])
    except Exception:
        _openrouter_models_cache = []

return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function employs a 5-second HTTP timeout and safeguards against network errors by falling back to an empty list. It parses the OpenRouter model registry to inspect supported capabilities, such as reasoning.supported_efforts, before sending requests.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Determines the maximum context window token limit for a given endpoint and model name. If the endpoint corresponds to Google Gemini (generativelanguage.googleapis.com or gemini in model name), it returns 1,000,000. If the endpoint belongs to OpenRouter, it queries OpenRouter's model endpoint and extracts context_length. For unhandled endpoints or upon network failure, it defaults to 100,000.

    Parameters: * endpoint_url (str): Base URL or endpoint of the LLM server. * model_name (str): Target model name. * api_key (str, optional): API key for authenticated requests. Defaults to "".

    Returns: * int: The resolved context length limit in tokens.

    Raises: * None.

    Example: 

    # Extracted from utils/call_llm.py get_model_context_length implementation
default_limit = 100000
try:
    if not endpoint_url:
        return default_limit

    if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
        # Safely default to 1M tokens for Gemini models
        return 1000000

    if "openrouter.ai" in endpoint_url:
        resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
        data = resp.json().get("data", [])
        for m in data:
            if m.get("id") == model_name:
                return m.get("context_length", default_limit)
except Exception as e:
    logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

return default_limit

    This helper is used when planning context window consumption and token allocations across document crawling and prompt generation stages. It incorporates defensive parsing around remote network calls to ensure that downstream prompt construction does not fail if metadata discovery is unreachable.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches an HTTP POST request to an OpenAI-compatible /v1/chat/completions endpoint for providers configured via environment variables (such as OPENROUTER or OLLAMA). Reads {provider}_MODEL, {provider}_BASE_URL, and optionally {provider}_API_KEY. It constructs the JSON payload, applies reasoning/thinking configurations when requested, executes the HTTP request with timeout limits (10, 300), validates JSON integrity and response structures, and extracts the generated content.

    Parameters: * prompt (str): The raw text prompt to send to the model. * thinking_level (str | None, optional): Reasoning effort level (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The completion string extracted from choices[0].message.content.

    Raises: * ValueError: If LLM_PROVIDER, model, or base URL environment variables are missing; if the provider returns invalid JSON; or if the response lacks the choices key. * Exception: Wraps underlying requests.exceptions.HTTPError, requests.exceptions.ConnectionError, requests.exceptions.Timeout, or general requests.exceptions.RequestException instances with descriptive error messages.

    Example: 

    # Extracted from utils/call_llm.py _call_llm_provider implementation
# ...
payload = {
    "model": model,
    "messages": [{"role": "user", "content": prompt}],
    "temperature": 0.7,
}

if provider == "OPENROUTER" and thinking_level:
    model_info = _get_openrouter_model_info(model)
    if model_info and "reasoning" in model_info:
        supported_efforts = model_info["reasoning"].get("supported_efforts", [])
        if thinking_level.lower() in supported_efforts:
            payload["reasoning"] = {"effort": thinking_level.lower()}
            payload["temperature"] = 1.0  # Required for many reasoning models
        else:
            logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
    else:
        logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

elif provider == "OLLAMA" and thinking_level:
    # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
    payload["think"] = thinking_level.lower()
    payload["reasoning_effort"] = thinking_level.lower()
    payload["temperature"] = 1.0

try:
    response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
    # ...
    response_json = response.json()
    response.raise_for_status()

    # Defensive check: API may return 200 with error/rate-limit payload missing 'choices'
    if "choices" not in response_json or not response_json["choices"]:
        error_detail = response_json.get("error", response_json)
        logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
        raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

    return response_json["choices"][0]["message"]["content"]
except requests.exceptions.HTTPError as e:
    # ...

    The function adapts payload structures depending on the backend. When interfacing with OpenRouter, it verifies that the specified thinking_level is listed within the model's supported_efforts before modifying the payload and forcing temperature: 1.0. For Ollama, it sets both think and reasoning_effort fields to maintain compatibility across different server versions. It uses a connect/read timeout pair (10, 300) to handle extended inference times on long completions.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches generation requests to Google Gemini using the google.genai SDK. It initializes a genai.Client using Vertex AI if GEMINI_PROJECT_ID is present (with optional GEMINI_LOCATION, defaulting to "us-central1"), or via direct API key authentication if GEMINI_API_KEY is provided. If thinking_level is set, it maps "low", "medium", and "high" string values to explicit token budgets (1024, 4096, 8192) via types.ThinkingConfig. Finally, it executes client.models.generate_content and concatenates all text parts from the response candidates, filtering out non-text metadata.

    Parameters: * prompt (str): The prompt text to process. * thinking_level (str | None, optional): Reasoning level string ("low", "medium", "high"). Defaults to None.

    Returns: * str: The concatenated text content from candidate response parts, or an empty string if no candidates exist.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is defined in the execution environment.

    Example: 

    # Extracted from utils/call_llm.py _call_llm_gemini implementation
if os.getenv("GEMINI_PROJECT_ID"):
    client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
elif os.getenv("GEMINI_API_KEY"):
    client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
else:
    raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

kwargs = {"model": model, "contents": [prompt]}

if thinking_level:
    # Map string levels to budgets for the installed SDK version
    budget_map = {"low": 1024, "medium": 4096, "high": 8192}
    budget = budget_map.get(thinking_level.lower(), 4096)
    thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
    kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

response = client.models.generate_content(**kwargs)

# Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
if response.candidates and response.candidates[0].content.parts:
    text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
    return "".join(text_parts)
return ""

    This method interacts directly with the Google GenAI Python SDK. When reasoning is enabled, Gemini responses can include structured thought chunks and metadata signatures (such as thought_signature). The response parsing logic explicitly loops over response.candidates[0].content.parts and ignores non-text chunks, preventing formatting artifacts or warning messages from contaminating generated markdown output.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description: The primary entry point for executing model prompts across the entire repository. It calculates prompt token counts via utils.token_utils.count_tokens, checks the local disk cache if use_cache=True, records detailed execution logs, routes the request to either _call_llm_gemini or _call_llm_provider, measures response latency, updates the disk cache upon completion, and returns the response string.

    Parameters: * prompt (str): The full prompt text to be submitted to the model. * use_cache (bool, optional): Whether to inspect and update llm_cache.json. Defaults to True. * thinking_level (str | None, optional): Reasoning intensity ("low", "medium", "high", or None). Defaults to None.

    Returns: * str: The model-generated output text.

    Raises: * ValueError: Propagated from underlying provider methods if environment variables are missing or provider responses are malformed. * Exception: Propagated from network failures, HTTP errors, or timeout exceptions.

    Example: 

    # Extracted from utils/call_llm.py call_llm implementation
import time
from utils.token_utils import count_tokens

provider = get_llm_provider()
model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
prompt_tokens = count_tokens(prompt)

logger.info(f"{'=' * 80}")
logger.info(
    f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
)
logger.info(f"PROMPT:\n{prompt}")

# Check cache if enabled
if use_cache:
    cache = load_cache()
    if prompt in cache:
        cached_response = cache[prompt]
        logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
        logger.info(f"RESPONSE (cached):\n{cached_response}")
        logger.info("LLM CALL END | result=cache_hit")
        return cached_response

# Make the actual LLM call
start_time = time.time()
logger.info(f"API CALL | sending request to {provider}...")

if provider == "GEMINI":
    response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
    response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

elapsed = time.time() - start_time
logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
logger.info(f"RESPONSE:\n{response_text}")

# Update cache if enabled
if use_cache:
    cache = load_cache()
    cache[prompt] = response_text
    save_cache(cache)
    logger.info("CACHE WRITE | saved response to cache")

logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
return response_text

    call_llm() serves as the single interface utilized by pipeline nodes throughout the system (e.g., in nodes and flow). It standardizes timing measurements, token accounting via token_utils, debug logging, caching mechanisms, and routing behind a uniform functional interface.

    Direct Execution (__main__)

    When invoked directly as a standalone script (python -m utils.call_llm), the module executes a smoke test validating provider connectivity without using the disk cache:

    # Extracted from utils/call_llm.py __main__ block
if __name__ == "__main__":
    test_prompt = "Hello, how are you?"

    # First call - should hit the API
    print("Making call...")
    response1 = call_llm(test_prompt, use_cache=False)
    print(f"Response: {response1}")
