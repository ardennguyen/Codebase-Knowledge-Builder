    utils.call_llm

    File Path: utils/call_llm.py

    Overview

    The utils.call_llm module provides an abstraction layer for interacting with Large Language Model (LLM) APIs across multiple backend providers. It handles model routing, parameter configuration, request construction, response parsing, error mitigation, response caching, and execution logging.

    The module supports two primary pathways: 1. Google Gemini Native API (google-genai SDK): Leverages Vertex AI or direct API key authentication, supporting structured thinking budgets via ThinkingConfig for models such as gemini-3.7-flash. 2. OpenAI-Compatible Providers (OpenRouter, Ollama, etc.): Connects via HTTP REST requests to /v1/chat/completions endpoints, mapping provider-specific configuration variables and dynamically configuring reasoning effort or thinking budgets where supported.

    In addition to inference routing, utils.call_llm implements local disk caching via llm_cache.json to prevent redundant network invocations during development and multi-stage workflow execution. It also provisions an isolated logger (llm_logger) configured with a NullHandler at import time and initialized into structured per-run log files on demand.

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name: str = "project", mode: str = "tutorial") -> str:

    Description:
    Initializes file-based logging for an active execution run. It resolves the output directory from the LOG_DIR environment variable (defaulting to logs), creates the directory if absent, sanitizes the project_name string to remove filesystem-unsafe characters, replaces dashes in mode, and constructs a timestamped log path. It purges all existing handlers (including NullHandler) on logger, attaches an explicit logging.FileHandler using UTF-8 encoding, and writes initial session metadata.

    Parameters: * project_name (str, optional): The name of the project being processed, used to prefix the log file name. Defaults to "project". * mode (str, optional): The execution mode (e.g., "tutorial", "deep-dive"), used in the log file name. Defaults to "tutorial".

    Returns: * str: The absolute or relative path to the created log file (logs/{safe_project}_{safe_mode}_{YYYYMMDD_HHmmss}.log).

    Raises: * OSError: If the log directory cannot be created or the log file cannot be opened for writing.

    Example: 

    # Implementation from utils/call_llm.py
def configure_logging(project_name="project", mode="tutorial"):
    """Configure file-based logging for this run.

    Creates a new log file per invocation:
        logs/{project_name}_{mode}_{YYYYMMDD_HHmmss}.log

    Must be called from main() after parsing CLI arguments.
    """
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'=' * 80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'=' * 80}")

    return log_file

    The function provides complete separation between standard root logging and the LLM execution trace. By calling logger.handlers.clear(), it prevents duplicate log entries if configure_logging is invoked multiple times during test runs or pipeline restarts. The log format adheres to %(asctime)s - %(levelname)s - %(message)s, and the opening banner guarantees traceability for run parameters and timestamps.

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description:
    Attempts to open and deserialize the JSON cache file specified by cache_file. If the file is missing, cannot be opened, or contains corrupted JSON data, the function suppresses the exception, logs a warning message to logger, and returns an empty dictionary fallback.

    Parameters: * None.

    Returns: * dict: A dictionary mapping prompt strings to their cached LLM completion strings. Returns {} on failure or empty cache.

    Raises: * No exceptions are propagated; all file I/O and JSON parsing exceptions are trapped.

    Example: 

    # Implementation from utils/call_llm.py
def load_cache():
    try:
        with open(cache_file) as f:
            return json.load(f)
    except Exception:
        logger.warning("Failed to load cache.")
    return {}

    This helper guarantees non-blocking cache operations. If a developer runs concurrent executions or if the cache file is manually edited into an invalid syntax state, the system logs the issue via logger.warning without terminating the generation pipeline, allowing execution to proceed with direct API calls.

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description:
    Determines the active LLM backend provider based on ambient environment variables. It reads LLM_PROVIDER; if this variable is unset but either GEMINI_PROJECT_ID or GEMINI_API_KEY is present in the environment, it defaults the provider value to "GEMINI".

    Parameters: * None.

    Returns: * str | None: The identified provider name (such as "GEMINI", "OLLAMA", or "OPENROUTER"), or None if no relevant environment variables are set.

    Raises: * No exceptions raised.

    Example: 

    # Implementation from utils/call_llm.py
def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This resolution logic enables zero-config operation for Google Gemini users who only export GEMINI_API_KEY or GEMINI_PROJECT_ID in their environment or .env file. For other third-party providers like Ollama or OpenRouter, the user must explicitly declare LLM_PROVIDER=OLLAMA or LLM_PROVIDER=OPENROUTER.

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description:
    Fetches metadata for available OpenRouter models via HTTP GET to https://openrouter.ai/api/v1/models and caches the result in the module-level variable _openrouter_models_cache. It iterates through the cached model entries to locate and return the model object matching model_id.

    Parameters: * model_id (str): The unique OpenRouter model identifier (e.g., "anthropic/claude-3.7-sonnet" or "deepseek/deepseek-r1").

    Returns: * dict | None: The dictionary containing model capabilities, reasoning parameter support, pricing, and context limits, or None if the model is not found or the network request fails.

    Raises: * No exceptions are propagated; network exceptions and JSON parsing failures are trapped internally and cause _openrouter_models_cache to default to [].

    Example: 

    # Implementation from utils/call_llm.py
def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function implements lazy network initialization and memoization. On first invocation, it queries OpenRouter's endpoint with a 5-second timeout. Subsequent queries across different pipeline nodes reuse the cached payload in _openrouter_models_cache, preventing unnecessary HTTP calls and avoiding rate limits during reasoning capability checks.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description:
    Calculates or retrieves the maximum input context window size (in tokens) for a given endpoint and model identifier. If the endpoint corresponds to Gemini (or the model name includes "gemini"), it returns 1000000. If the endpoint belongs to OpenRouter, it queries the OpenRouter API to read the context_length field. If the model is not recognized or an error occurs, it falls back to a safe default of 100000.

    Parameters: * endpoint_url (str): The base URL or target API endpoint. * model_name (str): The identifier of the model being evaluated. * api_key (str, optional): The API key for authenticated lookups. Defaults to "".

    Returns: * int: The maximum token limit supported by the model context window.

    Raises: * No exceptions are propagated; errors are logged via logger.warning and fallback values are returned.

    Example: 

    # Implementation from utils/call_llm.py
def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    """
    Fetch the maximum context length of a model based on the endpoint.
    If endpoint is Gemini API, safely default to 1,000,000 tokens.
    If endpoint is openrouter.ai, make GET to /api/v1/models and extract.
    Default to 100,000.
    """
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This utility ensures downstream token-packing and prompt-chunking operations allocate context safely. By defaulting Google Gemini models to 1,000,000 tokens and checking dynamic OpenRouter context limits, it avoids context window overflow errors during large codebase crawl ingestions.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Executes an HTTP POST request against an OpenAI-compatible /v1/chat/completions API endpoint configured via environment variables. It resolves {provider}_MODEL, {provider}_BASE_URL, and {provider}_API_KEY based on LLM_PROVIDER. For OpenRouter models supporting reasoning, it validates requested thinking_level values against supported_efforts and configures payload parameters (reasoning.effort and temperature=1.0). For Ollama, it maps thinking_level to both think and reasoning_effort.

    Parameters: * prompt (str): The full text prompt to transmit to the model. * thinking_level (str | None, optional): Reasoning effort level (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The textual completion returned under choices[0].message.content.

    Raises: * ValueError: If required environment variables (LLM_PROVIDER, <provider>_MODEL, <provider>_BASE_URL) are missing, if invalid JSON is returned, or if the choices key is omitted from the response. * Exception: Wraps requests.exceptions.HTTPError, requests.exceptions.ConnectionError, requests.exceptions.Timeout, or generic requests.exceptions.RequestException with descriptive connection context.

    Example: 

    # Implementation excerpt from utils/call_llm.py
def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    // ...
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")

    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        // ...
        response.raise_for_status()
        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        // ...
        raise Exception(error_message) from e

    The function handles timeouts using a tuple (10, 300), specifying a 10-second connection timeout and a 300-second read timeout to accommodate long reasoning generation cycles. It performs defensive assertions on the status code and JSON payload structure, checking for HTTP 200 responses that wrap API error blocks missing choices.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Invokes the Google GenAI SDK (google.genai.Client) using either Vertex AI credentials (GEMINI_PROJECT_ID and GEMINI_LOCATION) or direct API key authentication (GEMINI_API_KEY). It sets the target model via GEMINI_MODEL (defaulting to gemini-3.7-flash). If thinking_level is specified, it maps the level string (low, medium, high) to an explicit token budget (1024, 4096, 8192) inside types.ThinkingConfig and passes it to types.GenerateContentConfig. Finally, it concatenates and returns all non-null text parts from the response candidates.

    Parameters: * prompt (str): The text prompt to process. * thinking_level (str | None, optional): Reasoning level string ("low", "medium", "high"). Defaults to None.

    Returns: * str: The concatenated text string generated by the Gemini model. Returns "" if no candidates or text parts exist.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment. * google.genai.errors.APIError: If the Google GenAI backend encounters quota, permission, or execution errors.

    Example: 

    # Implementation from utils/call_llm.py
def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    This method filters out non-textual parts (such as thought_signature or raw reasoning trace structures) emitted by reasoning-capable Gemini models, preventing SDK warnings or formatting artifacts in generated documentation. It dynamically handles both Google Cloud Vertex AI infrastructure deployments and standalone developer API keys.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description:
    The primary entrypoint function for executing LLM completion requests within the application. It counts prompt tokens using utils.token_utils.count_tokens, checks and reads the disk cache (llm_cache.json) when use_cache is True, dispatches the request to either _call_llm_gemini or _call_llm_provider, tracks request latency, writes new responses back to cache if enabled, and emits detailed timing and execution metrics to logger.

    Parameters: * prompt (str): The full text prompt string. * use_cache (bool, optional): Whether to inspect and write to llm_cache.json. Defaults to True. * thinking_level (str | None, optional): Optional reasoning budget identifier ("low", "medium", "high"). Defaults to None.

    Returns: * str: The textual response generated by the model or retrieved from disk cache.

    Raises: * ValueError: If provider environment configuration is missing or invalid. * Exception: If upstream API calls fail or connection errors occur.

    Example: 

    # Implementation from utils/call_llm.py
def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

    The function serves as the central orchestration point for all LLM calls in the pipeline. It ensures consistent logging of prompts, character counts, elapsed network execution time, and token usage across both cached and non-cached requests.
