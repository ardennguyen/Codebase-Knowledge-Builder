    utils.call_llm

    File Path: utils/call_llm.py

    Overview

    The utils.call_llm module provides the unified LLM execution layer for Codebase-Knowledge-Builder. It abstracts downstream model invocations across multiple providers, including native Google Gemini (via the google-genai SDK using either API keys or Google Cloud Vertex AI) and OpenAI-compatible endpoints (such as OpenRouter and local Ollama instances).

    Key responsibilities include: - Multi-provider routing based on environment configuration (GEMINI, OPENROUTER, OLLAMA). - Simple persistent prompt/response caching via llm_cache.json to prevent duplicate API queries during development and pipeline reruns. - Reasoning effort / thinking budget configuration (e.g., Gemini thinking tokens, OpenRouter reasoning effort, Ollama think parameters). - Dynamic model context window inspection via API querying or provider heuristics. - Structured file logging for all prompt and response payloads under the configured log directory.

    Constants and Module Variables

    cache_file

    • Type: str
    • Value: "llm_cache.json"
    • Description: Relative path to the local JSON file used to persist cached prompt-response pairs.

    log_directory

    • Type: str
    • Default: os.getenv("LOG_DIR", "logs")
    • Description: Destination directory where LLM interaction logs are written.

    log_file

    • Type: str
    • Description: Timestamped log filename formatted as llm_calls_YYYYMMDD.log located inside log_directory.

    logger

    • Type: logging.Logger
    • Description: Dedicated non-propagating logger named "llm_logger" configured with a file handler at logging.INFO level.

    _openrouter_models_cache

    • Type: list[dict] | None
    • Default: None
    • Description: In-memory cache holding the list of available OpenRouter models fetched dynamically from https://openrouter.ai/api/v1/models.

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description:
    Reads and deserializes the local JSON cache file specified by cache_file. If the file does not exist, cannot be accessed, or contains malformed JSON, the failure is logged as a warning and an empty dictionary is returned.

    Parameters:
    None

    Returns:
    * dict: A dictionary mapping prompt strings to cached response strings, or an empty dictionary on error.

    None* (Catches all exceptions internally and returns {}).

    Example:

    None

    Returns:

    Raises:
    None*

    Example:

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description:
    Determines the maximum input context window (in tokens) for a specified model and endpoint. Used by main and nodes to calculate safety margins and batch boundaries. - If endpoint_url matches generativelanguage.googleapis.com or model_name contains "gemini", defaults to 1,000,000 tokens. - If endpoint_url contains "openrouter.ai", fetches model details from /api/v1/models and extracts context_length. - Defaults to 100,000 tokens if unknown, empty, or if an error occurs.

    Parameters:
    * endpoint_url (str): Base URL or endpoint of the LLM provider. * model_name (str): Name or ID of the model. * api_key (str, optional): Provider API key. Defaults to "".

    Returns:
    * int: Maximum context length in tokens.

    Raises:
    None* (Catches all exceptions internally and logs a warning).

    Example: 

    from utils.call_llm import get_model_context_length

context_len = get_model_context_length("https://openrouter.ai/api/v1", "openai/gpt-4o")
# Returns context token limit integer

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str = None) -> str:

    Description:
    Executes an LLM inference call against generic OpenAI-compatible REST endpoints (such as OpenRouter or Ollama). Reads target configuration from dynamic environment variables based on LLM_PROVIDER (<provider>_MODEL, <provider>_BASE_URL, <provider>_API_KEY). Appends /v1/chat/completions to the base URL and formats the payload.

    Handles extended reasoning configuration when thinking_level is provided: - OpenRouter: Queries _get_openrouter_model_info to verify if the model supports reasoning effort and maps payload["reasoning"] = {"effort": thinking_level.lower()} with temperature 1.0. - Ollama: Populates payload["think"] and payload["reasoning_effort"] with temperature 1.0.

    Logs prompts and responses, validates JSON responses, and unwraps the text content from response_json["choices"][0]["message"]["content"].

    Parameters:
    * prompt (str): Prompt text string sent to the LLM. * thinking_level (str, optional): Reasoning effort level (e.g., "low", "medium", "high"). Defaults to None.

    Returns:
    * str: Raw text content generated by the model.

    Raises:
    * ValueError: If LLM_PROVIDER, <provider>_MODEL, or <provider>_BASE_URL are not set in the environment, or if the server response is invalid JSON. * Exception: On network connection failure, request timeout, HTTP error, or bad status codes.

    Example: 

    # Assuming LLM_PROVIDER=OPENROUTER, OPENROUTER_MODEL=..., OPENROUTER_BASE_URL=...
from utils.call_llm import _call_llm_provider

response = _call_llm_provider("Explain quicksort in Python", thinking_level="low")

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str = None) -> str:

    Description:
    Executes an inference call against Google Gemini models using the official google-genai SDK. Resolves authentication via Google Cloud Vertex AI (GEMINI_PROJECT_ID and optional GEMINI_LOCATION) or standalone API key (GEMINI_API_KEY).

    Reads the model from GEMINI_MODEL (defaulting to "gemini-3.7-flash"). When thinking_level is passed, maps the level to explicit token budgets (low -> 1024, medium -> 4096, high -> 8192) and attaches a types.ThinkingConfig(include_thoughts=True, thinking_budget=budget) to the generation config.

    Extracts and concatenates only text content parts from candidate responses to avoid including non-text metadata (such as thought signatures).

    Parameters:
    * prompt (str): Prompt text string sent to the model. * thinking_level (str, optional): Reasoning effort budget level ("low", "medium", or "high"). Defaults to None.

    Returns:
    * str: Concatenated text response generated by Gemini, or an empty string if no candidate parts are present.

    Raises:
    * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is set in the environment. * Exception: If the Gemini SDK client generation call fails.

    Example: 

    from utils.call_llm import _call_llm_gemini

response = _call_llm_gemini("Generate an architectural summary", thinking_level="medium")

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str = None) -> str:

    Description:
    The primary entry point used across pipeline nodes to query LLMs. Coordinates caching, logging, and provider delegation:

    1. Logs the prompt to the active session log file.
    2. If use_cache=True, checks llm_cache.json via load_cache. If a cached response exists for prompt, returns it immediately.
    3. If not cached, resolves the active provider via get_llm_provider.
    4. Routes the request to _call_llm_gemini if provider is "GEMINI", or _call_llm_provider for generic OpenAI-compatible endpoints.
    5. Logs the generated response.
    6. If use_cache=True, updates and writes the response back to llm_cache.json via save_cache.
    7. Returns the final generated text string.

    Parameters:
    * prompt (str): The full prompt text to send to the LLM. * use_cache (bool, optional): Flag indicating whether to check and store results in llm_cache.json. Defaults to True. * thinking_level (str, optional): Extended reasoning effort level ("low", "medium", "high"). Defaults to None.

    Returns:
    * str: Generated text response from the LLM or cache.

    Raises:
    * ValueError: If provider credentials or required endpoint environment variables are missing. * Exception: If downstream network or provider calls fail.

    Example: 

    from utils.call_llm import call_llm

prompt = "List three key principles of software engineering."
response = call_llm(prompt, use_cache=True, thinking_level="low")
print(response)
