    utils.call_llm

    Original Source File: utils/call_llm.py

    The utils.call_llm module serves as the centralized Large Language Model (LLM) interaction layer for the Codebase-Knowledge-Builder system. It provides an abstraction over multiple backend model providers, supporting the Google GenAI SDK (Vertex AI and Gemini Developer API) as well as OpenAI-compatible HTTP endpoints (such as OpenRouter and Ollama). The module also encapsulates disk-backed caching mechanisms, per-run file-based structured logging, token estimation logging via utils.token_utils, dynamic model context length resolution, and configurable reasoning/thinking effort budgets.

    Architecture and Invocation Lifecycle

    The module dispatches LLM calls through a unified entrypoint (call_llm). Depending on environment configuration, requests are routed either to Google's GenAI client library or to custom OpenAI-compatible REST endpoints, with transparent JSON caching and execution telemetry.

    subgraph ProviderRouting[Provider Routing and Execution]

        H --> H1["genai.Client(vertexai or api_key)"]
        H1 --> H2["models.generate_content(...)"]

        I --> I1{"Provider Type"}
        I1 -- OPENROUTER --> I2["Query _get_openrouter_model_info"]

    end

    subgraph Finalization[Response Handling and Persistence]
        H2 --> J["Extract text parts from candidates"]
        I4 --> K["Validate and extract choices[0]"]

        M --> N
    end

    Module-Level State and Configuration

    The module maintains module-level state for logging, disk-backed cache file reference, and memoization of remote model capabilities:

    • logger (logging.Logger): Dedicated logger instance named "llm_logger". Initialized with a logging.NullHandler and propagate = False to prevent unconfigured root logging prior to explicit configuration via configure_logging().
    • cache_file (str): File path "llm_cache.json" where prompt-response key-value pairs are stored when caching is enabled.
    • _openrouter_models_cache (list[dict] | None): In-memory cache holding metadata returned from the OpenRouter API (https://openrouter.ai/api/v1/models) to prevent redundant network requests during reasoning capability verification.

    Module-Level Functions

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name="project", mode="tutorial") -> str:

    Description:
    Configures file-based logging for an execution run. It resolves the output directory from the LOG_DIR environment variable (defaulting to "logs"), sanitizes the project and mode strings for filesystem compatibility, generates a timestamped log filename, clears pre-existing handlers (such as the default NullHandler), and attaches a logging.FileHandler with UTF-8 encoding. Initial header metadata describing the run parameters is written to the log immediately upon handler creation.

    Parameters: * project_name (str, optional): The name of the codebase or target project being processed. Defaults to "project". * mode (str, optional): The operating mode of the application (e.g., "tutorial", "deep-dive"). Defaults to "tutorial".

    Returns: * str: The absolute or relative file path to the newly configured log file.

    Raises: * OSError: If the target log directory cannot be created or the log file cannot be opened for writing.

    Example: 

    def configure_logging(project_name="project", mode="tutorial"):
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'=' * 80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'=' * 80}")

    return log_file

    configure_logging ensures isolated per-run logging across execution pipelines. Handlers attached to logger are cleared to avoid duplicate outputs across multiple pipeline invocations within the same process. Characters not matching alphanumeric tokens, hyphens, underscores, or periods are replaced with underscores to prevent directory traversal or invalid filename issues across operating systems.

    load_cache()

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description:
    Reads and deserializes the local JSON cache file designated by cache_file. If the file does not exist, cannot be read, or contains malformed JSON, the function intercepts the exception, logs a warning message to logger, and returns an empty dictionary.

    Parameters: * None.

    Returns: * dict: A dictionary mapping prompt strings to cached model completion strings.

    Raises: * None. All I/O and JSON parsing exceptions are caught internally.

    Example: 

    def load_cache():
    try:
        with open(cache_file, "r") as f:
            return json.load(f)
    except:
        logger.warning("Failed to load cache.")
    return {}

    This function implements safe fallback semantics. When cold-starting without a pre-existing cache file or when reading corrupted JSON data, execution proceeds smoothly without interrupting downstream generation nodes.

    Description:
    Serializes the provided cache dictionary to the local file designated by cache_file in JSON format. Any I/O errors encountered during the write operation are caught and recorded as warnings in the logging pipeline.

    Parameters: * cache (dict): The dictionary containing prompt-to-response mappings to persist to disk.

    Returns: * None

    Raises: * None. All filesystem and serialization exceptions are handled internally.

    Example: 

    def save_cache(cache):
    try:
        with open(cache_file, "w") as f:
            json.dump(cache, f)
    except:
        logger.warning("Failed to save cache")

    The function performs a synchronous disk write. It is invoked following successful API completions in call_llm when caching is active.

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description:
    Determines the active LLM backend provider based on ambient environment variables. It inspects LLM_PROVIDER, falling back to "GEMINI" if LLM_PROVIDER is unset but GEMINI_PROJECT_ID or GEMINI_API_KEY is present.

    Parameters: * None.

    Returns: * str | None: The identifier string of the provider (e.g., "GEMINI", "OPENROUTER", "OLLAMA"), or None if no relevant configuration is detected.

    Raises: * None.

    Example: 

    def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This helper centralizes provider resolution rules so that Google Gemini remains the default provider whenever Google credentials are present, while allowing explicit overrides via the LLM_PROVIDER environment variable.

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description:
    Retrieves capability and parameter metadata for a specified OpenRouter model identifier by querying the OpenRouter models catalog endpoint (https://openrouter.ai/api/v1/models). The response payload is cached in the module-level variable _openrouter_models_cache to avoid repeated remote API requests on subsequent lookups.

    Parameters: * model_id (str): The full identifier of the model (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict | None: The dictionary containing model metadata (such as context length and reasoning effort configurations) if found; otherwise None.

    Raises: * None. Network errors during the HTTP request are caught, resulting in an empty model cache.

    Example: 

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function applies a memoization strategy over the global _openrouter_models_cache. If network failures or timeouts occur during the request, the cache is initialized to an empty list, allowing fallback defaults to take effect downstream.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description:
    Determines the maximum token context window supported by a given model based on the endpoint URL and model name. If the endpoint corresponds to Google Gemini (generativelanguage.googleapis.com or if "gemini" is in model_name), it returns a default limit of 1,000,000 tokens. If the endpoint points to OpenRouter (openrouter.ai), it queries the OpenRouter models API to extract the exact context_length attribute. For other providers or in the event of an error, it returns a standard fallback limit of 100,000 tokens.

    Parameters: * endpoint_url (str): The base or complete endpoint URL of the model service. * model_name (str): The model identifier string. * api_key (str, optional): The API key for authenticated requests. Defaults to "".

    Returns: * int: The maximum token context length allowed for prompt construction.

    Raises: * None. Catches all exceptions internally and logs a warning message.

    Example: 

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This context discovery helper assists document ingestion and prompt construction nodes by preventing token overflow exceptions before payloads are submitted to target providers.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Executes an HTTP POST request against an OpenAI-compatible /v1/chat/completions API endpoint determined by dynamic environment variables (e.g., OLLAMA_* or OPENROUTER_*). It constructs the authorization headers, sets temperature parameters, configures reasoning/thinking effort payloads according to provider capabilities, and executes the request with strict connection and read timeouts ((10, 300)). The response is parsed to verify JSON validity and defensively checked for the existence of non-empty choices elements.

    Parameters: * prompt (str): The user prompt to send to the completion endpoint. * thinking_level (str | None, optional): Desired reasoning effort (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The completion text extracted from choices[0]["message"]["content"].

    Raises: * ValueError: If required environment variables (LLM_PROVIDER, <provider>_MODEL, <provider>_BASE_URL) are missing, if invalid JSON is returned by the provider, or if the response JSON lacks the choices key. * Exception: Wraps underlying requests.exceptions.HTTPError, requests.exceptions.ConnectionError, requests.exceptions.Timeout, or general requests.exceptions.RequestException with descriptive context.

    Example: 

    def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")

    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        # ... JSON parsing, defensive choices validation, and HTTP status verification ...
        response_json = response.json()
        response.raise_for_status()

        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        # ... Detailed error extraction ...
        raise Exception(error_message) from e

    _call_llm_provider dynamically composes request schemas based on target provider rules. When provider == "OPENROUTER" and reasoning is requested, it queries _get_openrouter_model_info() to validate that the model's reasoning.supported_efforts includes the requested level. If supported, payload["reasoning"] = {"effort": ...} is attached and temperature is shifted to 1.0 (as required by reasoning models). For OLLAMA, both think and reasoning_effort fields are injected to maintain compatibility across various Ollama server releases.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Executes a content generation request using the official google-genai SDK client (google.genai.Client). It authenticates via Vertex AI if GEMINI_PROJECT_ID is set (using GEMINI_LOCATION with a default of "us-central1"), or via Gemini Developer API key if GEMINI_API_KEY is present. When a thinking_level is specified, it maps the level string ("low", "medium", "high") to a corresponding token budget (1024, 4096, 8192) and constructs a types.GenerateContentConfig with types.ThinkingConfig(include_thoughts=True, thinking_budget=budget). The resulting content parts are filtered to concatenate only non-null text components, safely stripping thought signatures and metadata.

    Parameters: * prompt (str): The user prompt text. * thinking_level (str | None, optional): Desired thinking budget level ("low", "medium", or "high"). Defaults to None.

    Returns: * str: The concatenated text returned in the model candidate response. Returns an empty string if no candidates or text parts exist.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Example: 

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    By filtering response content parts (part.text is not None), _call_llm_gemini avoids SDK warnings when reasoning is enabled, as reasoning models (such as Gemini 2.5/3.7 with thinking enabled) include binary or non-text thought signatures in response candidate parts.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description:
    Primary public entry point for dispatching prompts to LLMs. It calculates estimated prompt token counts using utils.token_utils.count_tokens, records structured logs of the request metadata, checks and returns cached responses when use_cache is True, routes uncached requests to the configured provider implementation (_call_llm_gemini or _call_llm_provider), updates the persistent disk cache, logs request execution timings, and returns the completion text.

    Parameters: * prompt (str): The full text prompt to be submitted to the LLM. * use_cache (bool, optional): Whether to check and update the local JSON cache (llm_cache.json). Defaults to True. * thinking_level (str | None, optional): Reasoning effort level ("low", "medium", "high", or None). Defaults to None.

    Returns: * str: The completion text generated by the model.

    Raises: * ValueError: If required environment variables are absent or response schemas are invalid. * Exception: If provider API requests fail, time out, or encounter network errors.

    Example: 

    def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

    The function orchestrates logging, caching, token accounting, and provider dispatch. By importing count_tokens from utils.token_utils at runtime, it maintains token awareness in logging streams without introducing circular dependencies during initial module loading.

    Direct Module Execution

    When executed as a standalone script (__main__), the module executes a basic diagnostic call to verify provider connectivity without utilizing the response cache:

    if __name__ == "__main__":
    test_prompt = "Hello, how are you?"

    # First call - should hit the API
    print("Making call...")
    response1 = call_llm(test_prompt, use_cache=False)
    print(f"Response: {response1}")
