    utils.call_llm

    Source: utils/call_llm.py

    Technical reference for the centralized LLM invocation module in Codebase-Knowledge-Builder. This module abstracts API integrations across various LLM providers (including Google Gemini via the google-genai SDK, as well as OpenAI-compatible endpoints like OpenRouter and Ollama via HTTP requests). It provides unified caching, structured file-based logging, token count introspection, reasoning/thinking budget configurations, and model context limit detection.

    Technical Architecture and Request Lifecycle

    The utils.call_llm module coordinates model interactions by resolving configured environment variables, querying or writing to a local JSON cache file (llm_cache.json), formatting provider payloads with reasoning parameters where supported, and logging metrics.

    Module State and Global Variables

    • logger: A dedicated logging.Logger instance ("llm_logger") configured with logging.NullHandler() at import time to suppress unconfigured output until configure_logging() is invoked.
    • cache_file: String filepath pointing to "llm_cache.json" used for simple prompt-response memoization.
    • _openrouter_models_cache: Internal module-level variable used to memoize metadata retrieved from https://openrouter.ai/api/v1/models to prevent redundant network lookups for reasoning capabilities.

    Module-Level Functions

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name: str = "project", mode: str = "tutorial") -> str:

    Description: Initializes runtime file-based logging for the execution session. It creates the configured log directory (reading LOG_DIR from environment variables, defaulting to "logs"), sanitizes input project and mode identifiers to ensure filesystem compatibility, generates a timestamped log filename (<project>_<mode>_<YYYYMMDD_HHmmss>.log), removes prior handlers such as the default NullHandler, and attaches a configured logging.FileHandler with UTF-8 encoding.

    Parameters: * project_name (str, optional): Project name identifier to prefix the log filename. Defaults to "project". * mode (str, optional): Operational mode label (e.g., "tutorial") to categorize the log output. Defaults to "tutorial".

    Returns: * str: The absolute or relative file path to the initialized log file.

    Raises: * OSError: If directory creation or file handler instantiation fails due to permissions or disk errors.

    Example: 

    # Implementation from utils/call_llm.py
def configure_logging(project_name="project", mode="tutorial"):
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'=' * 80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'=' * 80}")

    return log_file

    The function guarantees clean separation between invocations by purging existing log handlers from llm_logger and writing a distinct run header block. The character replacement filter strips out special filesystem characters from the project name while transforming hyphens to underscores in the mode parameter.

    load_cache()

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description: Attempts to open and deserialize JSON content from the file defined by cache_file ("llm_cache.json"). If the file cannot be found, is unreadable, or contains malformed JSON, the function logs a warning via logger.warning() and falls back to returning an empty dictionary.

    Parameters: * None.

    Returns: * dict: Deserialized dictionary mapping cached prompts to LLM string responses.

    Raises: * None (all exceptions are trapped internally and logged).

    Example: 

    # Implementation from utils/call_llm.py
def load_cache():
    try:
        with open(cache_file) as f:
            return json.load(f)
    except Exception:
        logger.warning("Failed to load cache.")
    return {}

    This helper functions as a fault-tolerant reader. When running in environments where llm_cache.json does not yet exist on disk, it safely returns {} without interrupting the execution pipeline.

    Parameters: * cache (dict): The prompt-to-response mapping dictionary to write to disk.

    Returns: * None

    Raises: * None (exceptions are handled internally and logged).

    Example: 

    # Implementation from utils/call_llm.py
def save_cache(cache):

        with open(cache_file, "w") as f:
            json.dump(cache, f)
    except Exception:
        logger.warning("Failed to save cache")

    The function writes the dictionary in standard JSON format without formatting indents. It is typically invoked directly after receiving a successful response from a remote model invocation.

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description: Inspects process environment variables to determine the configured LLM backend. It checks LLM_PROVIDER first; if unset, it inspects whether GEMINI_PROJECT_ID or GEMINI_API_KEY are defined, defaulting to "GEMINI" if either is present.

    Parameters: * None.

    Returns: * str | None: The resolved provider string (such as "GEMINI", "OPENROUTER", "OLLAMA"), or None if no variables match.

    Raises: * None.

    Example: 

    # Implementation from utils/call_llm.py
def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This resolution logic allows backward-compatible execution where users set GEMINI_API_KEY directly without having to define LLM_PROVIDER=GEMINI explicitly.

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description: Queries OpenRouter's public models API endpoint (https://openrouter.ai/api/v1/models) to inspect model capabilities and properties (such as supported reasoning effort tiers). Results are cached in the module-level variable _openrouter_models_cache to eliminate redundant HTTP calls across multiple generations.

    Parameters: * model_id (str): The unique OpenRouter model identifier (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict | None: The model metadata dictionary matching model_id, or None if the model is not found or the HTTP request fails.

    Raises: * None (network failures and parsing errors default the internal cache to []).

    Example: 

    # Implementation from utils/call_llm.py
def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function applies a 5-second network timeout. If the request fails, _openrouter_models_cache is set to an empty list so subsequent calls within the same process do not repeatedly block execution.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Calculates or queries the maximum context window size (in tokens) for a given endpoint and model name. For Gemini endpoints or models containing "gemini", it returns a conservative limit of 1,000,000 tokens. For OpenRouter endpoints, it queries OpenRouter's /api/v1/models endpoint and parses context_length. For all other endpoints or upon network failure, it falls back to 100,000 tokens.

    Parameters: * endpoint_url (str): Base URL or full endpoint used for LLM interaction. * model_name (str): Name or identifier of the targeted model. * api_key (str, optional): Optional API key. Defaults to "".

    Returns: * int: Maximum context window limit in tokens.

    Raises: * None (internal exceptions log warnings and return default_limit).

    Example: 

    # Implementation from utils/call_llm.py
def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This context detection utility allows callers (such as token aggregation and prompt building routines in utils.token_utils) to dynamically size prompt content chunks before dispatching generation requests.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Executes a generic OpenAI-compatible chat completion request via POST /v1/chat/completions. It constructs the target URL, authorization headers, and JSON payload from environment variables ({PROVIDER}_MODEL, {PROVIDER}_BASE_URL, and {PROVIDER}_API_KEY). It dynamically injects provider-specific reasoning configuration options (such as reasoning: {effort: level} for OpenRouter models supporting reasoning, or think / reasoning_effort for Ollama models).

    Parameters: * prompt (str): The user prompt text to send to the model. * thinking_level (str | None, optional): Reasoning effort level string (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The string content extracted from choices[0].message.content in the response JSON.

    Raises: * ValueError: If LLM_PROVIDER is unset, or if provider-specific {PROVIDER}_MODEL or {PROVIDER}_BASE_URL are missing, if the server returns non-JSON responses, or if the response JSON lacks a valid choices array. * Exception: For HTTP status errors, connection failures, timeouts, or general request errors.

    Example: 

    # Core implementation extracted from utils/call_llm.py
def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")

    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    # ... requests.post execution, status code validation, and error parsing ...

    The function configures a two-stage timeout (10, 300) representing a 10-second connect timeout and a 300-second read timeout for complex completions. It implements defensive checks ensuring that 200 OK responses containing error details without a choices list fail with informative exceptions.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Invokes Google's Gemini models using the official google.genai SDK (genai.Client). It authenticates either via Vertex AI (when GEMINI_PROJECT_ID is set, with optional GEMINI_LOCATION defaulting to "us-central1") or via direct Developer API keys (GEMINI_API_KEY). When thinking_level is specified, it maps levels ("low" -> 1024, "medium" -> 4096, "high" -> 8192) to a types.ThinkingConfig instance. It filters candidate parts to extract only textual content, preventing runtime warnings from non-text parts such as thought signatures.

    Parameters: * prompt (str): The text prompt to pass as contents to generate_content. * thinking_level (str | None, optional): Reasoning level mapped to token thinking budgets ("low", "medium", or "high"). Defaults to None.

    Returns: * str: Concatenated text parts from the first candidate response, or "" if empty.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Example: 

    # Implementation from utils/call_llm.py
def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    By default, the model defaults to "gemini-3.7-flash". Part extraction explicitly iterates over response.candidates[0].content.parts filtering out None values to safely discard internal SDK thought structures and signatures while preserving all actual generation output.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description: The primary dispatch function for LLM operations across the codebase. It calculates token usage via utils.token_utils.count_tokens, checks the local cache (load_cache()) when use_cache is True, dispatches to either _call_llm_gemini or _call_llm_provider depending on get_llm_provider(), logs timing and payload metrics, updates the cache, and returns the response string.

    Parameters: * prompt (str): The full prompt string to submit to the model. * use_cache (bool, optional): Whether to check and write to llm_cache.json. Defaults to True. * thinking_level (str | None, optional): Reasoning level constraint ("low", "medium", "high"), or None. Defaults to None.

    Returns: * str: The model's generated text response.

    Raises: * ValueError: Propagated from underlying provider callers if credentials or configs are missing. * Exception: Propagated on unhandled HTTP, network, or SDK errors.

    Example: 

    # Implementation from utils/call_llm.py
def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

It encapsulates token measurement via utils.token_utils and full telemetry logging, ensuring every outgoing prompt and incoming generation is recorded with exact timestamps and durations in the session log.
