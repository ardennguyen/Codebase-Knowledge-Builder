    utils.call_llm

    File Path: utils/call_llm.py

    Following the pipeline execution nodes detailed in nodes, the utils.call_llm module provides the centralized LLM communication layer for Codebase-Knowledge-Builder. It is responsible for routing prompts to supported model backends (Google Gemini SDK or generic OpenAI-compatible REST endpoints such as OpenRouter and Ollama), managing disk-based JSON response caching, handling model context length discovery, and managing runtime file logging.

    Architectural Overview

    The module acts as a unified abstraction over multiple model providers. When a pipeline node calls call_llm(), the module evaluates the cache, determines the active provider from environment variables, configures reasoning budgets (thinking levels) if requested, executes the API call, and persists responses back to the local cache.

    flowchart TD
    A[Call: call_llm] --> B{Cache Enabled?}
    B -- Yes --> C[Check llm_cache.json]
    C -- Hit --> D[Return Cached Response]
    C -- Miss --> E[get_llm_provider]
    B -- No --> E

    E --> F{Provider?}
    F -- GEMINI --> G[_call_llm_gemini]
    F -- OPENROUTER / OLLAMA / Other --> H[_call_llm_provider]

    G --> I[Google GenAI SDK Client]
    H --> J[REST POST /v1/chat/completions]

    I --> K[Extract Text Parts]
    J --> L[Extract choices.0.message.content]

    K --> M{Cache Enabled?}
    L --> M

    M -- Yes --> N[Write llm_cache.json]
    M -- No --> O[Return Response String]
    N --> O

    logger

    • Type: logging.Logger
    • Description: Dedicated module logger instance named "llm_logger". At import time, logger.propagate is set to False and a logging.NullHandler() is attached to prevent unconfigured logging to root handlers until configure_logging() is explicitly invoked by main.

    cache_file

    • Type: str
    • Value: "llm_cache.json"
    • Description: Relative file path to the local JSON file used for prompt/response persistence across pipeline runs.

    _openrouter_models_cache

    • Type: list[dict] | None
    • Default: None
    • Description: In-memory global cache for model metadata retrieved from the OpenRouter API (https://openrouter.ai/api/v1/models) to avoid repetitive HTTP calls when checking model context windows or reasoning effort capabilities.

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name: str = "project", mode: str = "tutorial") -> str:

    Description:
    Initializes file-based execution logging for the active run. It reads the target log directory from the LOG_DIR environment variable (defaulting to "logs"), sanitizes project and mode strings for filesystem compatibility, constructs a timestamped log path, binds a logging.FileHandler with UTF-8 encoding, and writes header metadata demarcating the start of the execution session.

    def configure_logging(project_name="project", mode="tutorial"):
    """Configure file-based logging for this run.

    Creates a new log file per invocation:
        logs/{project_name}_{mode}_{YYYYMMDD_HHmmss}.log

    Must be called from main() after parsing CLI arguments.
    """
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding='utf-8')
    file_handler.setFormatter(
        logging.Formatter("%(asctime)s - %(levelname)s - %(message)s")
    )
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'='*80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'='*80}")

    return log_file

    Parameters: * project_name (str, optional): Name of the codebase project being processed. Defaults to "project". * mode (str, optional): Generation documentation mode (e.g., "tutorial", "advanced", "api-reference", "sdk"). Defaults to "tutorial".

    Returns: * str: Absolute or relative file path to the created .log file.

    Raises: * OSError: If the logging directory cannot be created or the file handler cannot open the log destination.

    Example: 

    # From main.py
configure_logging(project_name=log_project_name, mode=doc_mode)

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description:
    Queries OpenRouter's model catalog endpoint (https://openrouter.ai/api/v1/models) with a 5-second timeout and populates the module-level _openrouter_models_cache. Searches the cached list for a model matching model_id and returns its descriptor dictionary.

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    Parameters: * model_id (str): The OpenRouter model ID string (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict | None: The dictionary containing model properties (including context length and reasoning support), or None if the model is not found or the request fails.

    Raises: * None (exceptions are caught and result in an empty model cache).

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description:
    Determines the maximum context token capacity for a specified endpoint and model name. - Returns 1,000,000 tokens if the endpoint points to Google Generative Language or the model name contains "gemini". - Queries https://openrouter.ai/api/v1/models and extracts context_length if using OpenRouter. - Defaults safely to 100,000 tokens if endpoint_url is missing, unhandled, or if network requests fail.

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    """
    Fetch the maximum context length of a model based on the endpoint.
    If endpoint is Gemini API, safely default to 1,000,000 tokens.
    If endpoint is openrouter.ai, make GET to /api/v1/models and extract.
    Default to 100,000.
    """
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    Parameters: * endpoint_url (str): Base API endpoint URL. * model_name (str): Name or ID of the targeted model. * api_key (str, optional): Provider API key. Defaults to "".

    Returns: * int: Maximum context window length in tokens.

    Raises: * None (exceptions are caught and fallback to default_limit of 100,000).

    Example: 

    # From nodes.py resolve_max_tokens()
return get_model_context_length(endpoint, model_name, api_key)

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str = None) -> str:

    Description:
    Dispatches an HTTP POST request to an OpenAI-compatible REST endpoint (<BASE_URL>/v1/chat/completions) constructed dynamically from environment variables: - Provider configuration: <PROVIDER>_MODEL, <PROVIDER>_BASE_URL, and <PROVIDER>_API_KEY. - For OPENROUTER, it inspects model reasoning capabilities via _get_openrouter_model_info() and sets payload fields {"reasoning": {"effort": thinking_level.lower()}} and temperature: 1.0. - For OLLAMA, it injects {"think": thinking_level.lower(), "reasoning_effort": thinking_level.lower(), "temperature": 1.0}. - Sets request timeout to (10, 300) seconds (connect timeout 10s, read timeout 300s). - Validates the response body defensively, ensuring HTTP status is successful and the payload contains choices[0].message.content.

    def _call_llm_provider(prompt: str, thinking_level: str = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    # Read the provider-specific variables
    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

    # Validate required variables
    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"

    # Configure headers and payload based on provider
    headers = {
        "Content-Type": "application/json",
    }
    if api_key:  # Only add Authorization header if API key is provided
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {
                    "effort": thinking_level.lower()
                }
                payload["temperature"] = 1.0  # Required for many reasoning models
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        try:
            response_json = response.json() # Log the response
        except (ValueError, requests.exceptions.JSONDecodeError):
            print(f"\033[93mWarning: Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}\033[0m")
            logger.warning(f"Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}")
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}")
        response.raise_for_status()

        # Defensive check: API may return 200 with error/rate-limit payload missing 'choices'
        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        error_message = f"HTTP error occurred: {e}"
        try:
            error_details = response.json().get("error", "No additional details")
            error_message += f" (Details: {error_details})"
        except:
            pass
        raise Exception(error_message)
    except requests.exceptions.ConnectionError:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.")
    except requests.exceptions.Timeout:
        raise Exception(f"Request to {provider} API timed out.")
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}")
    except ValueError:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.")

    Parameters: * prompt (str): Prompt text sent to the model. * thinking_level (str, optional): Reasoning effort level (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: Raw text content generated by the model.

    Raises: * ValueError: If required provider environment variables are missing, the response is malformed JSON, or the response object lacks the choices attribute. * Exception: Wrapped network exceptions (HTTPError, ConnectionError, Timeout, RequestException).

    Example: 

    # Invoked internally via call_llm()
response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str = None) -> str:

    Description:
    Executes a prompt completion call against the official Google GenAI SDK (google.genai.Client). - Authenticates using either Vertex AI (GEMINI_PROJECT_ID and GEMINI_LOCATION) or Gemini Developer API (GEMINI_API_KEY). - Reads target model from GEMINI_MODEL (defaulting to "gemini-3.7-flash"). - Maps thinking_level to token budgets ("low": 1024, "medium": 4096, "high": 8192) wrapped in types.ThinkingConfig(include_thoughts=True, thinking_budget=budget). - Filters out non-text parts (such as internal thought signatures) to return clean generated markdown/YAML.

    def _call_llm_gemini(prompt: str, thinking_level: str = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(
            vertexai=True,
            project=os.getenv("GEMINI_PROJECT_ID"),
            location=os.getenv("GEMINI_LOCATION", "us-central1")
        )
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {
        "model": model,
        "contents": [prompt]
    }

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    Parameters: * prompt (str): Prompt text sent to the Gemini model. * thinking_level (str, optional): Thinking budget setting ("low", "medium", or "high"). Defaults to None.

    Returns: * str: Clean extracted response text.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY are found in the environment. * Exception: Any SDK generation exceptions raised during API communication.

    Example: 

    # Invoked internally via call_llm()
if provider == "GEMINI":
    response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str = None) -> str:

    Description:
    Primary public entry point for dispatching prompts to LLM providers. Performs end-to-end caching, logging, timing, and dispatching: 1. Inspects the active provider and model. 2. Logs execution start metadata and prompt contents. 3. If use_cache=True, checks load_cache() for a matching prompt string and returns immediately on a cache hit. 4. Routes request to _call_llm_gemini() (if provider is "GEMINI") or _call_llm_provider() for other endpoints. 5. If use_cache=True, updates llm_cache.json via save_cache(). 6. Logs completion duration and response metadata before returning.

    def call_llm(prompt: str, use_cache: bool = True, thinking_level: str = None) -> str:
    import time

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_len = len(prompt)

    logger.info(f"{'='*80}")
    logger.info(f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_chars={prompt_len:,}")
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info(f"LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info(f"CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

    Parameters: * prompt (str): Raw prompt text to submit. * use_cache (bool, optional): Whether to inspect and update llm_cache.json. Defaults to True. * thinking_level (str, optional): Reasoning effort level ("low", "medium", "high"). Defaults to None.

    Returns: * str: Model text completion response.

    Raises: * Exception: Propagates any API failure, validation error, or communication timeout.

    Example: 

    # Standalone CLI execution harness from utils/call_llm.py
if __name__ == "__main__":
    test_prompt = "Hello, how are you?"

    # First call - should hit the API
    print("Making call...")
    response1 = call_llm(test_prompt, use_cache=False)
    print(f"Response: {response1}")
