    utils.call_llm

    Source: utils/call_llm.py

    Technical and API documentation for utils/call_llm.py. This module provides the central interface for interacting with Large Language Models (LLMs) across multiple backend providers, handling environment-based provider routing, file-based response caching, per-run execution logging, model context length inspection, and reasoning/thinking effort configuration.

    Technical Overview

    utils/call_llm.py serves as the primary abstraction layer between the processing nodes of Codebase-Knowledge-Builder and downstream LLM inference providers. It decouples high-level codebase summarization and node orchestration logic from vendor-specific API structures.

    Key Architectural Capabilities

    1. Provider Agnosticism & Routing: Routes completion requests dynamically to Google Gemini (native via the official google-genai SDK with Vertex AI or API key authentication) or generic OpenAI-compatible completion endpoints (including OpenRouter and Ollama).
    2. Dynamic Reasoning / Thinking Configuration: Supports extended thinking and reasoning budgets (e.g., Gemini 3.7 Flash ThinkingConfig, OpenRouter reasoning.effort, and Ollama think / reasoning_effort payloads).
    3. Transparent Disk-Based Caching: Integrates a local JSON cache (llm_cache.json) to prevent redundant LLM invocations during iterative knowledge graph generation runs.
    4. Context Length Discovery: Provides dynamic retrieval and fallback inference for context token boundaries based on endpoint analysis or OpenRouter model catalog queries.
    5. Per-Invocation Run Logging: Implements a deferred file-logging architecture initialized with a NullHandler at import time, preventing root logger contamination until explicitly bound to a timestamped file via configure_logging().

    Module-Level State and Configuration

    The module defines global runtime variables and configuration references used across API calls and logging:

    • logger: An instance of logging.Logger named "llm_logger" configured with logger.propagate = False and an initial logging.NullHandler() to suppress logging until configure_logging() is invoked.
    • cache_file (str): File path for local response caching, defaulting to "llm_cache.json".
    • _openrouter_models_cache (list[dict] | None): An in-memory cache holding OpenRouter API model metadata fetched during runtime to prevent redundant endpoint queries.

    Module-Level Functions

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name: str = "project", mode: str = "tutorial") -> str:

    Description: Configures and initializes dedicated file-based logging for the active execution run. Creates a structured log file under logs/ formatted as {safe_project}_{safe_mode}_{timestamp}.log. Replaces existing runtime handlers (such as the import-time NullHandler) with a configured logging.FileHandler using UTF-8 encoding and writes execution metadata headers.

    Parameters: * project_name (str, optional): The name of the project codebase being processed. Defaults to "project". * mode (str, optional): The operational pipeline mode (e.g., "tutorial", "architecture"). Defaults to "tutorial".

    Returns: * str: The absolute or relative file path to the newly created log file.

    Raises: * OSError: If the target log directory cannot be created or the log file cannot be opened.

    Example: 

    def configure_logging(project_name="project", mode="tutorial"):
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'=' * 80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'=' * 80}")

    return log_file

    The function sanitizes input project names to ensure filesystem safety across operating systems by replacing non-alphanumeric characters (outside of -, _, .) with underscores. It clears prior handlers from the module's logger instance and writes a standard banner with metadata to mark the initiation of the run.

    load_cache()

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description: Reads and deserializes cached prompt-response pairs from the disk file defined by cache_file. If the file does not exist, is unreadable, or contains invalid JSON formatting, the failure is logged as a warning and an empty dictionary is returned.

    Parameters: * None.

    Returns: * dict: A dictionary mapping prompt string keys to LLM response text values.

    Raises: * No exceptions are raised; file access or parsing errors are caught and logged.

    Example: 

    def load_cache():
    try:
        with open(cache_file) as f:
            return json.load(f)
    except Exception:
        logger.warning("Failed to load cache.")
    return {}

    load_cache ensures resilient fallback behavior during local execution. When file read operations fail due to missing files or corrupted JSON contents, it defaults safely to returning {} to allow LLM processing to continue without throwing unhandled exceptions.

    save_cache()

    Visibility: Public
    Signature: def save_cache(cache: dict) -> None:

    Description: Serializes and writes the in-memory cache dictionary into cache_file formatted as JSON. Any write or filesystem failure is intercepted and recorded to the log.

    Parameters: * cache (dict): The dictionary mapping string prompts to generated text completions.

    Returns: * None

    Raises: * No exceptions are raised; I/O exceptions are caught internally.

    Example: 

    def save_cache(cache):
    try:
        with open(cache_file, "w") as f:
            json.dump(cache, f)
    except Exception:
        logger.warning("Failed to save cache")

    The function performs atomic replacement of the JSON cache content. It safeguards pipeline execution by catching broad exceptions during write attempts, logging a warning rather than interrupting pipeline processing.

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description: Determines the target LLM inference provider by inspecting environment variables. If LLM_PROVIDER is not explicitly set, it infers whether Google Gemini credentials (GEMINI_PROJECT_ID or GEMINI_API_KEY) are present and returns "GEMINI".

    Parameters: * None.

    Returns: * str | None: The provider identifier (e.g., "GEMINI", "OPENROUTER", "OLLAMA"), or None if undetermined.

    Raises: * No exceptions are raised.

    Example: 

    def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This helper centralizes provider resolution rules across the project. It ensures backward compatibility with configurations that specify Gemini credentials without explicitly assigning LLM_PROVIDER=GEMINI.

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description: Queries the OpenRouter API catalog (https://openrouter.ai/api/v1/models) to retrieve capabilities and configuration schemas for a specific model ID. Caches the API catalog list in memory (_openrouter_models_cache) to prevent repeated remote HTTP requests across invocations.

    Parameters: * model_id (str): The model identifier string (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict | None: The model descriptor dictionary if found; otherwise None.

    Raises: * No exceptions are raised; network and parsing errors default the cache to an empty list.

    Example: 

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function implements in-memory memoization using the module-level _openrouter_models_cache variable. When invoked for the first time, it issues an HTTP GET with a 5-second timeout, caching the data list and searching for the entry whose id matches model_id.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Resolves the maximum input context token limit for a given endpoint and model. Automatically assigns a 1,000,000-token limit for Gemini endpoints/models, inspects the OpenRouter API for OpenRouter endpoints, and falls back to a default limit of 100,000 tokens for other models or on error.

    Parameters: * endpoint_url (str): Base URL or complete endpoint URL of the LLM service. * model_name (str): Name or ID of the model. * api_key (str, optional): API key for authenticated queries if necessary. Defaults to "".

    Returns: * int: The maximum supported context token count.

    Raises: * No exceptions are raised; failures log a warning and return the default fallback value.

    Example: 

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This utility allows ingestion nodes in the pipeline to dynamically balance file packing and prompt chunk sizes against known context window limits. Gemini endpoints are safely credited with 1M tokens, while OpenRouter models are queried dynamically with a graceful fallback to 100,000 tokens.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches a standard OpenAI-compatible /v1/chat/completions HTTP POST request to generic LLM providers (such as Ollama or OpenRouter). Dynamically evaluates provider-specific environment variables for model names, base URLs, and API keys. Handles reasoning configuration payloads and validates response structures.

    Parameters: * prompt (str): The raw text prompt sent to the model. * thinking_level (str | None, optional): Desired reasoning effort (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The text content extracted from the first choice message in the response.

    Raises: * ValueError: If required environment variables (LLM_PROVIDER, <provider>_MODEL, <provider>_BASE_URL) are missing, if invalid JSON is returned, or if choices is missing from the response payload. * Exception: On network timeouts, connection failures, or HTTP status error codes.

    Example: 

    def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")

    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        # ... response parsing and error handling ...
        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e

    _call_llm_provider dynamically constructs the endpoint URL using ${LLM_PROVIDER}_BASE_URL and appends /v1/chat/completions. When thinking_level is requested, it configures reasoning parameters based on provider capabilities: for OpenRouter, it validates supported_efforts from model metadata; for Ollama, it sets both think and reasoning_effort. It enforces a connect timeout of 10 seconds and a read timeout of 300 seconds.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description: The primary public entry point for executing LLM completions across the codebase. Logs execution details (including token counts via token_utils), checks the local cache if enabled, dispatches the request to either Gemini or a generic provider, updates the cache upon successful completion, and records execution timing metrics.

    Parameters: * prompt (str): The textual prompt to send to the language model. * use_cache (bool, optional): Whether to inspect and update llm_cache.json. Defaults to True. * thinking_level (str | None, optional): Reasoning effort level passed to models that support extended thinking (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The model's textual completion.

    Raises: * ValueError: If provider credentials or required environment configurations are missing. * Exception: If network or API errors occur during execution.

    Example: 

    def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

    call_llm orchestrates caching, profiling, and provider dispatch. It uses count_tokens from utils.token_utils to log prompt sizes before dispatching requests. When cache hits occur, it bypasses network transmission entirely, returning cached output immediately.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Invokes the official Google GenAI SDK (google.genai). Supports authentication via Google Cloud Vertex AI (GEMINI_PROJECT_ID and GEMINI_LOCATION) or direct Gemini API keys (GEMINI_API_KEY). Manages model selection (defaulting to gemini-3.7-flash), configures ThinkingConfig token budgets when requested, and filters non-text thought signatures from candidate parts.

    Parameters: * prompt (str): The raw text prompt sent to Gemini. * thinking_level (str | None, optional): Reasoning budget setting ("low", "medium", or "high"). Defaults to None.

    Returns: * str: The concatenated text content from candidate output parts.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Example: 

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    The function handles Vertex AI initialization when GEMINI_PROJECT_ID is present, falling back to standard API key authentication via GEMINI_API_KEY. Thinking budgets map "low" to 1024 tokens, "medium" to 4096 tokens, and "high" to 8192 tokens. It iterates through response.candidates[0].content.parts to filter out non-text metadata (such as Gemini thought signatures) before returning the combined output text.
