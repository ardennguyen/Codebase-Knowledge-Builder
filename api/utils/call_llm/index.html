    utils.call_llm

    File Path: utils/call_llm.py

    Overview

    The utils.call_llm module provides unified abstraction for interacting with Large Language Model (LLM) backends within the Codebase-Knowledge-Builder pipeline. It manages:

    • Dynamic Provider Routing: Dispatches requests to native Google Gemini SDK clients (google-genai targeting Gemini API or Google Cloud Vertex AI) or generic OpenAI-compatible HTTP endpoints (such as OpenRouter or local Ollama instances).
    • Caching Layer: Persists prompt-response pairs to a local JSON file cache (llm_cache.json) to minimize redundant latency and compute costs during iterative graph execution.
    • Reasoning and Thinking Level Control: Configures reasoning parameters across different providers, such as ThinkingConfig for Google Gemini and reasoning/think payloads for OpenRouter and Ollama.
    • Dynamic Context Discovery: Queries external model catalogs (e.g., OpenRouter API) to identify maximum context window constraints or applies safety defaults for Google Gemini.
    • Isolated Run-Level Logging: Sets up dedicated run logs under a designated directory (logs/) with sanitized filenames and formatted execution metadata.

    Module Variables

    • logger: An instance of logging.Logger named "llm_logger". At import time, logger.propagate is set to False and configured with a logging.NullHandler to buffer logs until explicit configuration by configure_logging().
    • cache_file: A string constant ("llm_cache.json") defining the local cache target path.
    • _openrouter_models_cache: A module-level cache variable (list or None) storing model capability payloads fetched from https://openrouter.ai/api/v1/models.

    Module-Level Functions

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name="project", mode="tutorial") -> str:

    Description: Initializes file-based logging for the active execution run. It creates the destination directory specified by the LOG_DIR environment variable (defaulting to "logs"), sanitizes the input project_name and mode strings against invalid filesystem characters, and generates a timestamped log file. It replaces all existing logger handlers with a configured logging.FileHandler encoded in UTF-8 and writes standard run header metadata.

    Parameters: * project_name (str, optional): Identifier for the codebase/project being documented. Defaults to "project". * mode (str, optional): Processing mode identifier (e.g., "tutorial", "deep-dive"). Defaults to "tutorial".

    Returns: * str: Absolute or relative file path to the newly created log file.

    Raises: * OSError: If the directory creation fails or permissions prevent creating the log file.

    Example: 

    def configure_logging(project_name="project", mode="tutorial"):
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'=' * 80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'=' * 80}")

    return log_file

    configure_logging ensures file logging is deferred until command-line arguments are parsed in main. The sanitization step replaces non-alphanumeric and non-standard filename characters with underscores, preventing directory traversal or invalid path errors on diverse operating systems. Once instantiated, the handler isolates LLM logs from the root logger, capturing prompt transmissions, token estimates, and raw responses.

    load_cache()

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description: Reads and deserializes the JSON cache stored at cache_file (llm_cache.json). If the file is missing, unreadable, or contains corrupted JSON data, the error is logged as a warning and an empty dictionary is returned.

    Parameters: * None.

    Returns: * dict: Key-value mapping representing cached prompts (str) to completions (str). Returns {} on failure.

    Raises: * No exceptions are raised; errors are trapped internally and logged via logger.warning.

    Example: 

    def load_cache():
    try:
        with open(cache_file) as f:
            return json.load(f)
    except Exception:
        logger.warning("Failed to load cache.")
    return {}

    The function provides fault-tolerant reading of cached prompts. It wraps standard file I/O within a blanket exception guard so that missing cache files or transient file lock errors do not disrupt the execution of downstream node generation tasks in nodes.

    save_cache()

    Visibility: Public
    Signature: def save_cache(cache: dict) -> None:

    Description: Serializes and writes the provided dictionary to cache_file (llm_cache.json) in plaintext JSON format. Captures and logs any I/O errors encountered during the write operation.

    Parameters: * cache (dict): The dictionary of prompt-to-response pairs to be saved to disk.

    Returns: * None

    Raises: * No exceptions are raised; errors are trapped internally and logged via logger.warning.

    Example: 

    def save_cache(cache):
    try:
        with open(cache_file, "w") as f:
            json.dump(cache, f)
    except Exception:
        logger.warning("Failed to save cache")

    save_cache executes an atomic overwrite of the local cache file whenever an LLM invocation yields a new response. It acts synchronously within call_llm, allowing intermediate pipeline stages to preserve progress across intermittent network disconnects or process restarts.

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description: Determines which LLM provider backend to use based on environment configuration. Reads the LLM_PROVIDER environment variable. If unspecified, it inspects whether GEMINI_PROJECT_ID or GEMINI_API_KEY are defined, automatically falling back to "GEMINI".

    Parameters: * None.

    Returns: * str | None: The resolved provider name (e.g., "GEMINI", "OLLAMA", "OPENROUTER") or None if no matching configuration is found.

    Example: 

    def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This resolver allows dynamic switching across LLM providers via standard .env properties. When users only supply credentials for Vertex AI (GEMINI_PROJECT_ID) or Google AI Studio (GEMINI_API_KEY), the resolver defaults to the native Gemini provider pipeline without requiring explicit assignment of LLM_PROVIDER.

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description: Fetches capabilities and metadata for a given model ID from the OpenRouter /api/v1/models endpoint. The retrieved response array is cached in the module-level variable _openrouter_models_cache to prevent repeated HTTP lookups during subsequent invocations.

    Parameters: * model_id (str): The unique OpenRouter model identifier string (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict | None: The dictionary containing model specifications, reasoning support, and context limits, or None if not found or if the network request fails.

    Raises: * No exceptions are raised; network and JSON decoding failures default _openrouter_models_cache to [].

    Example: 

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    _get_openrouter_model_info manages global caching for model catalog lookups. It prevents duplicate network requests across multi-node execution graphs. The function inspects model entries to verify whether specific reasoning levels (low, medium, high) are supported by OpenRouter's reasoning abstraction layer.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Calculates or retrieves the maximum input context token limit for a target LLM endpoint. For Google Gemini endpoints or models containing "gemini", it safely defaults to 1,000,000 tokens. For OpenRouter endpoints, it queries the OpenRouter model registry to extract context_length. For unhandled or unreachable endpoints, it falls back to a safe baseline of 100,000 tokens.

    Parameters: * endpoint_url (str): Base URL or full endpoint URI for the target model. * model_name (str): The identifier of the model. * api_key (str, optional): Authentication key (reserved for authenticated metadata queries). Defaults to "".

    Returns: * int: Maximum context window capacity measured in tokens.

    Raises: * No exceptions are raised; network or parsing errors are caught and logged via logger.warning.

    Example: 

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    get_model_context_length provides upper-bound context metadata used during prompt construction and token-budget partitioning in token_utils. It prevents context window overflow by accurately identifying multi-million-token contexts for Gemini while respecting custom model thresholds queried from OpenRouter.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches a standard OpenAI-compatible chat completion request using requests.post to <PROVIDER>_BASE_URL/v1/chat/completions. Dynamically resolves configuration from environment variables based on LLM_PROVIDER (e.g., OLLAMA_MODEL, OLLAMA_BASE_URL, OPENROUTER_API_KEY). Supports reasoning effort configurations for OpenRouter and Ollama, handles HTTP errors, and extracts the response message content.

    Parameters: * prompt (str): Input text prompt to send to the completion model. * thinking_level (str | None, optional): Reasoning effort level (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: Raw text content returned by the LLM choice message.

    Raises: * ValueError: If required environment variables (LLM_PROVIDER, <provider>_MODEL, <provider>_BASE_URL) are missing, or if the API returns non-JSON or response payloads lacking choices. * Exception: On network timeouts, connection failures, or non-200 HTTP response codes.

    Example: 

    def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")

    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        # ... JSON parsing, status verification, error extraction ...
        response.raise_for_status()
        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e

    _call_llm_provider serves as the generic HTTP client wrapper for non-Gemini providers. It applies dual-timeout settings (10 seconds for initial connection, 300 seconds for read timeout) to accommodate extended generation times for large prompts. It handles provider-specific reasoning flags: OpenRouter uses {"reasoning": {"effort": ...}}, while Ollama uses both think and reasoning_effort payload fields to ensure compatibility across Ollama engine versions.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Invokes the Google Gemini API using the official google-genai SDK (genai.Client). Automatically configures authentication via Vertex AI (GEMINI_PROJECT_ID and GEMINI_LOCATION) or Google AI Studio API key (GEMINI_API_KEY). Maps string-based thinking levels to numeric token budgets (low = 1024, medium = 4096, high = 8192) via types.ThinkingConfig. Filters candidate content parts to return only text segments while excluding thought signatures.

    Parameters: * prompt (str): Input prompt text. * thinking_level (str | None, optional): Reasoning budget level ("low", "medium", "high"). Defaults to None.

    Returns: * str: Joined text content extracted from candidate parts. Returns "" if no candidate or text parts exist.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY are found in the environment. * Exception: Propagates any API execution errors originating from client.models.generate_content.

    Example: 

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    _call_llm_gemini encapsulates the Google GenAI SDK interface. When reasoning is requested, it translates the symbolic level (low, medium, high) into concrete token budgets (types.ThinkingConfig), enabling fine-grained control over model reasoning depth. It safely extracts text parts from response.candidates[0].content.parts, preventing non-text components (such as thought signatures) from corrupting downstream Markdown artifact generation.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description: The primary interface for dispatching LLM queries in the system. Coordinates prompt token counting via count_tokens from token_utils, executes cache lookups, routes requests to either _call_llm_gemini or _call_llm_provider, tracks execution latency, logs diagnostic details, and updates the cache upon successful completion.

    Parameters: * prompt (str): The input text or serialized prompt context to send to the language model. * use_cache (bool, optional): Whether to inspect and update the local JSON cache. Defaults to True. * thinking_level (str | None, optional): Target reasoning intensity ("low", "medium", "high", or None). Defaults to None.

    Returns: * str: Model text response output.

    Raises: * ValueError: If provider credentials or required configurations are missing. * Exception: If upstream API calls fail or return malformed outputs.

    Example: 

    def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

    call_llm serves as the centralized entry point used across processing nodes in nodes. It measures prompt token counts using token_utils and logs structured telemetry before and after execution. When use_cache=True is passed, exact prompt hits avoid network roundtrips entirely, returning the cached completion and reducing run times during pipeline testing and development.

    Direct Module Execution

    When executed directly (python -m utils.call_llm), the module executes a self-test invocation against the configured backend with cache lookup disabled:

    if __name__ == "__main__":
    test_prompt = "Hello, how are you?"

    # First call - should hit the API
    print("Making call...")
    response1 = call_llm(test_prompt, use_cache=False)
    print(f"Response: {response1}")
