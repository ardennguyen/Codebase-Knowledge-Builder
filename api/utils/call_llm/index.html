    utils.call_llm

    File Path: utils/call_llm.py

    Overview

    The utils.call_llm module serves as the primary inference dispatch interface for the Codebase-Knowledge-Builder system. It abstracts multi-provider Large Language Model (LLM) communications across Google Gemini (via the google-genai SDK with Vertex AI or standard API keys), OpenRouter, Ollama, and generic OpenAI-compatible chat completion endpoints.

    Key capabilities implemented in this module include: - Provider Routing & Auto-Detection: Dynamic resolution of execution providers based on environment configuration (GEMINI, OPENROUTER, OLLAMA, etc.). - Response Caching: Local disk caching mechanism backed by a JSON store (llm_cache.json) to minimize redundant inference latency and token consumption during iterative workflows. - Reasoning Effort Integration: Propagation of thinking budgets and reasoning configurations (e.g., Google GenAI ThinkingConfig, OpenRouter reasoning effort fields, and Ollama think/reasoning_effort payloads). - Context Length Resolution: Dynamic inspection and querying of endpoint context windows (e.g., OpenRouter /api/v1/models inspection, Gemini default ceilings). - Structured File-Based Logging: Isolated run logging via custom loggers to capture prompts, raw outputs, latency, and token metrics.

    Module-Level Variables

    • logger: An instance of logging.Logger named "llm_logger". Initialized with logging.NullHandler() at import time and set to propagate = False until explicitly bound to a destination file via configure_logging().
    • cache_file: str = "llm_cache.json". The relative path specifying the default JSON file used for prompt-response caching across pipeline executions.
    • _openrouter_models_cache: Optional[List[dict]]. In-memory global cache containing model schema and capability metadata fetched from the OpenRouter API.

    Module-Level Functions

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name="project", mode="tutorial") -> str:

    Description: Configures file-based logging for a pipeline invocation. It creates a dedicated log directory (controlled by the LOG_DIR environment variable or defaulting to logs), creates a sanitized filename incorporating the project name, execution mode, and a timestamp (%Y%m%d_%H%M%S), clears existing null/stale handlers from llm_logger, attaches a new logging.FileHandler, and records invocation start banners.

    Parameters: * project_name (str, optional): Name of the codebase or target project. Defaults to "project". * mode (str, optional): Execution mode (e.g., "tutorial", "documentation"). Defaults to "tutorial".

    Returns: * str: The absolute or relative filesystem path to the initialized log file.

    Raises: * OSError: If directory creation or file handler initialization fails due to insufficient permissions.

    Example: 

    def configure_logging(project_name="project", mode="tutorial"):
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding='utf-8')
    file_handler.setFormatter(
        logging.Formatter("%(asctime)s - %(levelname)s - %(message)s")
    )
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'='*80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'='*80}")

    return log_file

    configure_logging() isolates system runs into discrete log files to ensure debugging output does not leak across runs. Characters outside alphanumeric and basic punctuation (-, _, .) are replaced with underscores to prevent illegal filesystem paths across operating systems. The handler operates using UTF-8 encoding and formats all outputs with timestamps, log levels, and messages.

    load_cache()

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description: Loads the local LLM prompt response cache from the JSON file referenced by cache_file. If the file does not exist, is inaccessible, or contains invalid JSON data, the error is logged as a warning, and an empty dictionary is returned.

    Parameters: * None.

    Returns: * dict: A dictionary containing prompt keys mapped to previously generated LLM output strings.

    Raises: * Does not raise; internal exceptions are caught and logged to logger.warning.

    Example: 

    def load_cache():
    try:
        with open(cache_file, 'r') as f:
            return json.load(f)
    except:
        logger.warning(f"Failed to load cache.")
    return {}

    This function provides fault-tolerant reads for the key-value cache layer. Catching all exceptions ensures that corrupted cache files or missing disk assets do not halt the overarching pipeline execution, gracefully falling back to fresh LLM invocations.

    save_cache()

    Visibility: Public
    Signature: def save_cache(cache: dict) -> None:

    Description: Serializes the in-memory cache dictionary back into the local filesystem at cache_file in JSON format. Write failures are captured and recorded to the logger without terminating program execution.

    Parameters: * cache (dict): The updated dictionary containing prompt-to-response mappings.

    Returns: * None

    Raises: * Does not raise; IO and serialization exceptions are caught and logged to logger.warning.

    Example: 

    def save_cache(cache):
    try:
        with open(cache_file, 'w') as f:
            json.dump(cache, f)
    except:
        logger.warning(f"Failed to save cache")

    save_cache() ensures that successful API calls are persisted to disk immediately after generation. If the file is locked, inaccessible, or non-writable due to environment constraints, the warning is suppressed at the process boundary, preventing pipeline disruption.

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> Optional[str]:

    Description: Determines the active LLM provider strategy by inspecting configured environment variables. It prioritizes the explicit LLM_PROVIDER environment variable, but falls back to "GEMINI" if either GEMINI_PROJECT_ID or GEMINI_API_KEY is present.

    Parameters: * None.

    Returns: * Optional[str]: The provider string identifier (e.g., "GEMINI", "OPENROUTER", "OLLAMA"), or None if unconfigured.

    Raises: * None.

    Example: 

    def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This helper centralizes provider resolution across the module. It allows zero-configuration fallbacks for Google Gemini deployments where only API credentials or Vertex Project IDs are provided, while enabling alternative backends when LLM_PROVIDER is explicitly defined.

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> Optional[dict]:

    Description: Fetches and caches OpenRouter's model capability catalog by performing a GET request to https://openrouter.ai/api/v1/models. Populates the module-level _openrouter_models_cache variable to avoid redundant network lookups on subsequent calls, returning the specific model dictionary that matches model_id.

    Parameters: * model_id (str): The OpenRouter model identifier (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * Optional[dict]: The model metadata payload if found; otherwise None.

    Raises: * Does not raise; network and parsing errors result in an empty list cache.

    Example: 

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function handles capability queries when configuring advanced parameters like extended reasoning effort. A 5-second timeout prevents indefinite blocking in degraded network conditions, and network exceptions degrade gracefully by setting _openrouter_models_cache to an empty list.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Calculates or retrieves the maximum supported token context window for a given model and API endpoint. Gemini endpoints automatically resolve to a default limit of 1,000,000 tokens. OpenRouter endpoints trigger a query against /api/v1/models to obtain the declared context_length. All other endpoints or unhandled exceptions fallback to a baseline of 100,000 tokens.

    Parameters: * endpoint_url (str): The base or completion endpoint URL for the model provider. * model_name (str): Identifier of the target model. * api_key (str, optional): API credentials (currently unused in public endpoint query). Defaults to "".

    Returns: * int: The maximum token limit for prompt and completion contexts.

    Raises: * Does not raise; exceptions during HTTP queries are logged and return the default baseline.

    Example: 

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This method is critical for token budgeting and file chunking mechanisms implemented across the indexing pipeline. By identifying million-token context capabilities (standard for modern Gemini architectures), the system avoids premature text truncation while preserving safety margins for smaller local models.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str = None) -> str:

    Description: Dispatches a chat completion request to an OpenAI-compatible HTTP REST endpoint (e.g., OpenRouter, Ollama, vLLM). It dynamically resolves <PROVIDER>_MODEL, <PROVIDER>_BASE_URL, and <PROVIDER>_API_KEY from environment variables, prepares request headers and payloads, applies thinking/reasoning parameters if supported, posts the payload to {base_url}/v1/chat/completions, and extracts the completion text from the response structure.

    Parameters: * prompt (str): The prompt string to transmit to the model. * thinking_level (Optional[str], optional): Desired reasoning level (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The text generated by the model.

    Raises: * ValueError: If LLM_PROVIDER, <PROVIDER>_MODEL, or <PROVIDER>_BASE_URL are missing from the environment, if the provider returns invalid JSON, or if the choices array is missing in the payload. * Exception: On HTTP errors, network timeouts, or connection failures.

    Example: 

    def _call_llm_provider(prompt: str, thinking_level: str = None) -> str:
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")

    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")
    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        try:
            response_json = response.json()
        except (ValueError, requests.exceptions.JSONDecodeError):
            print(f"\033[93mWarning: Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}\033[0m")
            logger.warning(f"Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}")
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}")
        response.raise_for_status()

        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        error_message = f"HTTP error occurred: {e}"
        try:
            error_details = response.json().get("error", "No additional details")
            error_message += f" (Details: {error_details})"
        except:
            pass
        raise Exception(error_message)
    # ... handles ConnectionError, Timeout, RequestException, ValueError

    _call_llm_provider() handles the complexities of calling generic OpenAI-compatible completion APIs. It implements specific reasoning parameters: for OpenRouter, it checks supported_efforts before modifying temperature and payload structures; for Ollama, it sets both think and reasoning_effort properties. The HTTP request enforces a connection timeout of 10 seconds and a read timeout of 300 seconds to accommodate long generation runs.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str = None) -> str:

    Description: High-level public entry point for invoking LLMs across the entire project. Counts input prompt tokens using utils.token_utils, checks and retrieves disk cache entries if use_cache is enabled, tracks invocation latency, routes requests to _call_llm_gemini or _call_llm_provider, writes fresh responses to cache, and outputs structured execution logs.

    Parameters: * prompt (str): The full prompt text to send to the language model. * use_cache (bool, optional): Flag indicating whether to check and write to llm_cache.json. Defaults to True. * thinking_level (Optional[str], optional): Desired reasoning level (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The completion generated by the selected model provider.

    Raises: * ValueError: If required environment variables for the selected provider are not found. * Exception: If underlying API calls fail due to network, authentication, or provider-side issues.

    Example: 

    # Extraction from utils/call_llm.py test execution block
if __name__ == "__main__":
    test_prompt = "Hello, how are you?"

    # First call - should hit the API
    print("Making call...")
    response1 = call_llm(test_prompt, use_cache=False)
    print(f"Response: {response1}")

    call_llm() acts as a centralized facade, decoupling higher-level pipeline orchestration components (such as nodes and flow) from provider-specific logic. It lazily imports count_tokens from utils.token_utils to record exact prompt token metrics, measures wall-clock execution time via time.time(), and outputs structured logs for auditing and debugging.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str = None) -> str:

    Description: Direct client implementation for Google Gemini models using the google-genai SDK. Supports authentication via Vertex AI (GEMINI_PROJECT_ID and GEMINI_LOCATION) or standalone Google AI Studio keys (GEMINI_API_KEY). Maps thinking_level values ("low", "medium", "high") to token budgets (1024, 4096, 8192) wrapped inside types.ThinkingConfig, and filters out non-text response parts (such as thought_signature) to return clean text.

    Parameters: * prompt (str): The prompt string to transmit. * thinking_level (Optional[str], optional): Target thinking level for models supporting reasoning budgets. Defaults to None.

    Returns: * str: Combined text content extracted from the candidate response parts.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Example: 

    def _call_llm_gemini(prompt: str, thinking_level: str = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(
            vertexai=True,
            project=os.getenv("GEMINI_PROJECT_ID"),
            location=os.getenv("GEMINI_LOCATION", "us-central1")
        )
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {
        "model": model,
        "contents": [prompt]
    }

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    This function handles Google GenAI SDK calls and reasoning configs. It maps reasoning levels into numeric token budgets via budget_map and wraps them in types.GenerateContentConfig. When parsing response parts from response.candidates[0].content.parts, it filters out non-text parts (such as reasoning metadata and thought_signature) before returning the final concatenated string.
