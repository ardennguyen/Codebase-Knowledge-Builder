    utils.call_llm

    File Path: utils/call_llm.py

    Technical and architectural documentation for the utils/call_llm module. This module encapsulates all external Large Language Model (LLM) communications across multiple supported backends (Google Gemini API/Vertex AI, OpenRouter, and Ollama/OpenAI-compatible endpoints). It provides automated response caching, file-based structured logging, dynamic model context-length detection, and multi-tier reasoning/thinking budget configurations.

    Architectural Overview

    The utils.call_llm module serves as the central LLM execution gateway for the knowledge base generator pipeline. When nodes and workflows request LLM inference, call_llm intercepts the request to enforce caching, audit logging, token accounting via utils.token_utils, and provider-specific payload formatting.

    Module-Level Variables and State

    • logger (logging.Logger): Instance named "llm_logger" configured with logging.INFO and propagate = False. By default, it initializes with a logging.NullHandler() at module load time to absorb emissions until configure_logging() is invoked.
    • cache_file (str): File path string pointing to "llm_cache.json". Used for simple JSON-based disk caching of LLM requests and responses.
    • _openrouter_models_cache (list[dict] | None): Internal in-memory cache initialized to None. Used to avoid repeated network queries to OpenRouter's /api/v1/models endpoint when inspecting model capabilities and reasoning effort configurations.

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name="project", mode="tutorial") -> str:

    Description: Configures and attaches a file-based logger instance for an individual CLI execution run. It creates a target directory specified by the LOG_DIR environment variable (defaulting to logs), sanitizes the project name and generation mode against unwanted characters, and establishes a uniquely timestamped log file named {safe_project}_{safe_mode}_{YYYYMMDD_HHmmss}.log. Any existing handlers (such as the import-time NullHandler) are cleared from logger, and a new logging.FileHandler formatted with %(asctime)s - %(levelname)s - %(message)s is registered.

    Parameters: * project_name (str, optional): Identifier of the target repository or project. Defaults to "project". * mode (str, optional): Pipeline operation mode (e.g., "tutorial", "architecture"). Defaults to "tutorial".

    Returns: * str: The absolute or relative filesystem path of the initialized .log file.

    Raises: * OSError: If directory creation or log file access fails due to filesystem permission constraints.

    Implementation: 

    def configure_logging(project_name="project", mode="tutorial"):
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding="utf-8")
    file_handler.setFormatter(logging.Formatter("%(asctime)s - %(levelname)s - %(message)s"))
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'=' * 80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'=' * 80}")

    return log_file

    The function performs input sanitation on project_name by replacing non-alphanumeric and non-whitelisted characters (-, _, .) with underscores. It also replaces hyphens in mode with underscores. Once the FileHandler is established, the function immediately writes execution boundary headers containing metadata to verify output capture before returning the file path to the caller (such as main).

    def load_cache():
    try:
        with open(cache_file) as f:
            return json.load(f)

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description: Resolves the active LLM provider strategy from environment variables. If LLM_PROVIDER is explicitly set, its value is returned. If omitted, it falls back to checking whether GEMINI_PROJECT_ID or GEMINI_API_KEY are defined, returning "GEMINI" if either is present.

    Parameters: * None.

    Returns: * str | None: The resolved provider string (e.g., "GEMINI", "OPENROUTER", "OLLAMA"), or None if unresolvable.

    Implementation & Usage: 

    def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This function acts as the runtime provider selector for the application. It establishes Google Gemini as the implicit default when relevant API credentials exist in .env, while allowing overrides via explicit LLM_PROVIDER environment variable assignments (such as "OPENROUTER" or "OLLAMA").

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description: Queries OpenRouter's public /api/v1/models catalog to inspect capabilities, supported reasoning effort parameters, and metadata for a specific model ID. Caches the response payload in the module-level variable _openrouter_models_cache to eliminate redundant HTTP requests across calls.

    Parameters: * model_id (str): The model identifier string (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict | None: A dictionary containing model metadata if located within the catalog; otherwise, None.

    Raises: * No exceptions are raised; network and timeout errors result in populating an empty cache list and returning None.

    Implementation & Usage: 

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function optimizes network bandwidth and prevents rate limiting by fetching OpenRouter model data only on the initial call. It leverages Python's next() built-in with a generator expression to locate the model object matching model_id.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Determines the maximum token context window supported by a given endpoint and model name combination. Automatically allocates a 1,000,000-token limit for Gemini endpoints, dynamically extracts context limits from OpenRouter's model catalog for OpenRouter URLs, and defaults to 100,000 tokens for all other providers or when lookups fail.

    Parameters: * endpoint_url (str): Base URL or endpoint of the LLM provider. * model_name (str): Name or ID of the target model. * api_key (str, optional): API key parameter (optional, defaults to "").

    Returns: * int: The context length limit in tokens.

    Raises: * No exceptions are propagated; errors fall back safely to 100000.

    Implementation & Usage: 

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This helper is primarily utilized during prompt chunking, file aggregation, and token budgeting across the indexing pipeline. When operating against Gemini endpoints or models containing "gemini" in their name, it returns a 1,000,000-token window. When hitting OpenRouter endpoints, it dynamically queries the model registry to retrieve exact token limits.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches chat completion requests to OpenAI-compatible provider endpoints such as OpenRouter or Ollama. Dynamically resolves environment variables based on LLM_PROVIDER (e.g., <PROVIDER>_MODEL, <PROVIDER>_BASE_URL, <PROVIDER>_API_KEY), formats messages under the /v1/chat/completions REST specification, applies reasoning/thinking effort payloads, executes HTTP requests with robust timeout limits, and validates response schemas.

    Parameters: * prompt (str): The input user prompt text to send to the LLM. * thinking_level (str | None, optional): Reasoning intensity ("low", "medium", or "high"). Defaults to None.

    Returns: * str: The generated text response extracted from choices[0].message.content.

    Raises: * ValueError: If required environment variables (LLM_PROVIDER, <PROVIDER>_MODEL, <PROVIDER>_BASE_URL) are missing, if invalid JSON is returned, or if the choices attribute is missing from a 200 OK response. * Exception: Wrapper exception providing diagnostic context on HTTP errors, connection drops, request timeouts, or general network failures.

    Implementation & Usage: 

    def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")

    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        try:
            response_json = response.json()
        except (ValueError, requests.exceptions.JSONDecodeError):
            print(f"\033[93mWarning: Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}\033[0m")
            logger.warning(f"Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}")
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None
        response.raise_for_status()

        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        error_message = f"HTTP error occurred: {e}"
        try:
            error_details = response.json().get("error", "No additional details")
            error_message += f" (Details: {error_details})"
        except Exception:
            pass
        raise Exception(error_message) from e
    except requests.exceptions.ConnectionError as e:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
    except requests.exceptions.Timeout as e:
        raise Exception(f"Request to {provider} API timed out.") from e
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
    except ValueError as e:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e

    This function implements a generic REST integration for OpenAI-compatible LLM endpoints. It maps provider-specific reasoning flags (e.g., verifying supported_efforts via OpenRouter metadata or attaching think / reasoning_effort fields for Ollama) and automatically adjusts model temperature to 1.0 when reasoning effort is enabled. It configures a dual connection and read timeout (timeout=(10, 300)) to accommodate long generation runs and includes defensive JSON validation to catch upstream provider errors hidden within 200 OK responses.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Direct execution handler for the Google GenAI SDK (google.genai). Supports both Vertex AI authentication (via GEMINI_PROJECT_ID and GEMINI_LOCATION) and standalone Google Developer API keys (via GEMINI_API_KEY). Formats reasoning configurations by translating string levels into explicit token budgets (low: 1024, medium: 4096, high: 8192), filters non-text thought signatures from output candidate parts, and returns pure text output.

    Parameters: * prompt (str): User prompt text to execute against Gemini. * thinking_level (str | None, optional): Reasoning budget intensity ("low", "medium", "high"). Defaults to None.

    Returns: * str: The combined text generated by the model candidates, or an empty string if no content parts are returned.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY are found in the environment.

    Implementation & Usage: 

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    The function instantiates the official genai.Client, choosing Vertex AI mode when GEMINI_PROJECT_ID is set and API Key mode otherwise. When thinking_level is provided, it configures types.ThinkingConfig with explicit token budgets to ensure compatibility with models such as gemini-3.7-flash. To prevent downstream logging warnings regarding non-text internal parts (such as thought_signature), it iterates over response.candidates[0].content.parts to filter and join only valid text segments.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description: The primary public entry point for dispatching prompts to LLMs throughout the application. Handles token counting via count_tokens, logs prompt metadata and payload details, coordinates local disk cache hits and misses, measures round-trip inference latency, routes requests to _call_llm_gemini or _call_llm_provider, and stores newly generated responses in the cache.

    Parameters: * prompt (str): The complete prompt string to submit to the model. * use_cache (bool, optional): Whether to check and update the local JSON cache. Defaults to True. * thinking_level (str | None, optional): Desired reasoning level ("low", "medium", "high"), or None for standard generation. Defaults to None.

    Returns: * str: The textual response generated by the LLM (or retrieved from cache).

    Raises: * ValueError: If provider resolution fails or if underlying provider calls fail. * Exception: Any network or provider-level errors encountered during an uncached invocation.

    Implementation & Usage: 

    def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text
