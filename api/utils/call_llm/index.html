    utils.call_llm

    File Path: utils/call_llm.py

    Overview

    The utils.call_llm module provides a centralized abstraction layer for dispatching inference requests to supported Large Language Model (LLM) backends. It manages logging lifecycle configuration, disk-based response caching, context length detection, and multi-provider client dispatching.

    The module natively supports Google Gemini (via the official google-genai SDK using Vertex AI or standard API key authentication) as well as OpenAI-compatible REST endpoints such as OpenRouter and Ollama. It features specialized logic for passing extended reasoning/thinking parameters across disparate model APIs and ensures robust error handling and defensive parsing for upstream provider responses.

    Module-Level State & Variables

    • logger (logging.Logger): Module logger instance configured initially with logging.NullHandler to avoid unconfigured log emissions during import. Reconfigured via configure_logging().
    • cache_file (str): File path for local caching ("llm_cache.json").
    • _openrouter_models_cache (list[dict] | None): In-memory cache holding OpenRouter metadata fetched from https://openrouter.ai/api/v1/models to avoid redundant network round-trips when checking reasoning capability.

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name: str = "project", mode: str = "tutorial") -> str:

    Description: Initializes file-based logging for the execution session. It creates the destination directory specified by the LOG_DIR environment variable (defaulting to logs/), sanitizes the project and mode strings to avoid illegal filesystem characters, constructs a unique timestamped log file, clears existing handlers on logger, attaches a formatted logging.FileHandler, and logs initial execution metadata.

    Parameters: * project_name (str): Name of the repository or target project being analyzed. Defaults to "project". * mode (str): Operational execution mode (e.g., "tutorial", "deep-dive"). Defaults to "tutorial".

    Returns: * str: The absolute or relative file path to the newly configured log file.

    Raises: * OSError: If the target directory cannot be created or the file handler cannot open the log file path.

    Implementation: 

    def configure_logging(project_name="project", mode="tutorial"):
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding='utf-8')
    file_handler.setFormatter(
        logging.Formatter("%(asctime)s - %(levelname)s - %(message)s")
    )
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'='*80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'='*80}")

    return log_file

    This method is designed to defer logging initialization until command-line interface arguments have been parsed in the main entrypoint. By clearing logger.handlers before attaching the new FileHandler, it cleanly transitions the logger away from the initial NullHandler state.

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description: Fetches metadata for all available models from OpenRouter's /api/v1/models endpoint, caches the result in global variable _openrouter_models_cache, and looks up the dictionary matching the supplied model_id.

    Parameters: * model_id (str): The unique identifier of the target model on OpenRouter (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict | None: The model metadata dictionary if found, or None if not found or if the network request fails.

    Raises: * None. Catches all request exceptions and defaults the cache to an empty list.

    Implementation: 

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function prevents redundant external network requests during batch runs by memoizing the OpenRouter model catalog in _openrouter_models_cache. It allows callers to query model capabilities like reasoning support dynamically.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Determines the maximum token context window supported by a model based on the target API endpoint and model identifier. For Gemini endpoints or model names containing "gemini", it defaults to 1,000,000 tokens. For OpenRouter endpoints, it queries the OpenRouter API to obtain the model's configured context_length. For all other providers or on error, it defaults to 100,000 tokens.

    Parameters: * endpoint_url (str): The base URL or full endpoint of the model provider. * model_name (str): The model name or identifier string. * api_key (str, optional): API key for authentication (currently unused by the underlying probe, defaults to "").

    Returns: * int: The maximum token limit for the context window.

    Raises: * None. Catches all exceptions and falls back to default_limit (100000).

    Implementation: 

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This utility ensures downstream chunking and prompt-packing algorithms can dynamically adapt to model limits, avoiding context overflow errors during code processing.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches a chat completion request to generic OpenAI-compatible REST providers (such as OpenRouter or Ollama). It extracts model, base URL, and optional API key settings from environment variables corresponding to the active LLM_PROVIDER. Configures reasoning/thinking parameters where supported, posts payload to /v1/chat/completions, performs status and JSON validation, and returns the response message content.

    Parameters: * prompt (str): The text prompt to send to the model. * thinking_level (str | None, optional): Desired reasoning level (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The string output content from the assistant's message.

    Raises: * ValueError: If required environment variables (LLM_PROVIDER, <provider>_MODEL, <provider>_BASE_URL) are missing, if invalid JSON is returned, or if the response JSON lacks the choices key. * Exception: Wraps underlying requests.exceptions.HTTPError, requests.exceptions.ConnectionError, requests.exceptions.Timeout, or general RequestException.

    Implementation: 

    def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    # Read the provider-specific variables
    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

    # Validate required variables
    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"

    # Configure headers and payload based on provider
    headers = {
        "Content-Type": "application/json",
    }
    if api_key:  # Only add Authorization header if API key is provided
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {
                    "effort": thinking_level.lower()
                }
                payload["temperature"] = 1.0  # Required for many reasoning models
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        try:
            response_json = response.json() # Log the response
        except (ValueError, requests.exceptions.JSONDecodeError):
            print(f"\033[93mWarning: Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}\033[0m")
            logger.warning(f"Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}")
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None
        response.raise_for_status()

        # Defensive check: API may return 200 with error/rate-limit payload missing 'choices'
        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        error_message = f"HTTP error occurred: {e}"
        try:
            error_details = response.json().get("error", "No additional details")
            error_message += f" (Details: {error_details})"
        except:
            pass
        raise Exception(error_message) from e
    except requests.exceptions.ConnectionError as e:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
    except requests.exceptions.Timeout as e:
        raise Exception(f"Request to {provider} API timed out.") from e
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
    except ValueError as e:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e

    This method handles provider-specific nuances such as reasoning flags and temperature adjustments (e.g., setting temperature: 1.0 when reasoning effort is applied). It also defends against upstream API proxies that return HTTP 200 OK statuses alongside error payloads lacking choices.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Executes generation requests using Google's official genai.Client. Supports authentication via Vertex AI (GEMINI_PROJECT_ID and GEMINI_LOCATION) or direct Gemini Developer API keys (GEMINI_API_KEY). Maps thinking_level strings to explicit token budgets (low = 1024, medium = 4096, high = 8192) via types.ThinkingConfig. Concatenates text content parts from response candidates while ignoring non-text parts (such as thought signatures).

    Parameters: * prompt (str): Prompt text. * thinking_level (str | None, optional): Reasoning effort level string ("low", "medium", or "high"). Defaults to None.

    Returns: * str: Concatenated text parts of the model response.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Implementation: 

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(
            vertexai=True,
            project=os.getenv("GEMINI_PROJECT_ID"),
            location=os.getenv("GEMINI_LOCATION", "us-central1")
        )
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {
        "model": model,
        "contents": [prompt]
    }

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    The function interfaces with the google-genai SDK and handles both Vertex AI enterprise environments and direct API key usage. Filtering candidate content parts to only non-None text strings prevents runtime warnings and schema mismatches when thinking mode outputs metadata parts.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description: Primary entry point for LLM inference across the entire framework. Measures token counts via utils.token_utils, handles prompt cache lookup, dispatches calls to either _call_llm_gemini() or _call_llm_provider(), records timing metrics and logging output, updates the cache upon successful completion, and returns the response string.

    Parameters: * prompt (str): The text prompt submitted for completion. * use_cache (bool, optional): Whether to check and write to disk cache. Defaults to True. * thinking_level (str | None, optional): Reasoning level passed to downstream handlers ("low", "medium", "high"). Defaults to None.

    Returns: * str: The textual output returned by the LLM.

    Raises: * ValueError: Propagated from underlying provider callers if credentials or response schemas are invalid. * Exception: Propagated on network or provider communication failures.

    Implementation: 

    def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens
    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'='*80}")
    logger.info(f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}")
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text
