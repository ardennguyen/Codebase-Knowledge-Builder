    utils.call_llm

    File Path: utils/call_llm.py

    Overview

    The utils.call_llm module provides a centralized abstraction layer for dispatching text generation requests to Large Language Model (LLM) backends. It encapsulates client initialization, prompt payload construction, response extraction, file-based execution logging, local disk response caching, and reasoning/thinking parameter configuration across multiple supported providers.

    The module supports multiple runtime backends: 1. Google Gemini: Native Google GenAI SDK integration supporting both Vertex AI authentication (via Project ID and location) and standard API key authentication, including thinking budget controls. 2. OpenAI-Compatible Providers (e.g., Ollama, OpenRouter): Direct HTTP REST interactions with /v1/chat/completions endpoints supporting custom authentication headers, reasoning effort payloads, and dynamic model discovery.

    Module-Level Variables & State

    The module establishes global configurations, default file paths, and in-memory caches upon module load.

    • logger: A standard Python logging.Logger named "llm_logger". Initialized with a NullHandler and propagate = False to swallow logs silently until explicitly activated by configure_logging().
    • cache_file (str): File path pointing to "llm_cache.json" where prompt-response key-value mappings are persisted across invocations.
    • _openrouter_models_cache (list or None): Global in-memory cache holding metadata fetched from https://openrouter.ai/api/v1/models to minimize redundant API discovery calls during reasoning parameter validation.

    Module-Level Functions

    configure_logging()

    Visibility: Public
    Signature: def configure_logging(project_name="project", mode="tutorial") -> str:

    Description: Initializes the runtime file logging mechanism for the application execution cycle. It creates the designated target directory (resolved from the LOG_DIR environment variable, defaulting to "logs"), sanitizes input project and mode identifiers to conform to filesystem path safety requirements, constructs a timestamped log filename, removes pre-existing handlers (such as the default NullHandler), and attaches a formatted UTF-8 FileHandler. It also writes execution start headers containing run metadata directly to the newly initialized log file.

    def configure_logging(project_name="project", mode="tutorial"):
    log_directory = os.getenv("LOG_DIR", "logs")
    os.makedirs(log_directory, exist_ok=True)

    # Sanitize project name for filesystem safety
    safe_project = "".join(c if c.isalnum() or c in "-_." else "_" for c in project_name)
    safe_mode = mode.replace("-", "_")
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_directory, f"{safe_project}_{safe_mode}_{timestamp}.log")

    # Remove any existing handlers (e.g., NullHandler) and add the file handler
    logger.handlers.clear()
    file_handler = logging.FileHandler(log_file, encoding='utf-8')
    file_handler.setFormatter(
        logging.Formatter("%(asctime)s - %(levelname)s - %(message)s")
    )
    logger.addHandler(file_handler)

    # Log run metadata at the start of every log file
    logger.info(f"{'='*80}")
    logger.info(f"RUN STARTED | project={project_name} | mode={mode} | timestamp={timestamp}")
    logger.info(f"Log file: {log_file}")
    logger.info(f"{'='*80}")

    return log_file

    This function ensures that individual runs generate distinct, auditable artifacts without polluting global logger namespaces. Handlers are cleared before attaching the new FileHandler to avoid duplicate log entries if called multiple times within a process. Special characters in project_name outside of alphanumerics, hyphens, underscores, and dots are replaced with underscores to maintain valid filesystem paths across operating systems.

    Parameters: * project_name (str, optional): Identifier for the target project being analyzed. Defaults to "project". * mode (str, optional): Generation or workflow mode. Defaults to "tutorial".

    Returns: * str: The absolute or relative path to the generated log file.

    Raises: * OSError: If the directory creation fails due to filesystem permissions.

    Example: 

    # From source implementation initialization
log_file = configure_logging(project_name="my_repo", mode="developer-guide")

    load_cache()

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description: Reads and deserializes the JSON cache dictionary from the local storage file specified by cache_file. If the file does not exist, is inaccessible, or contains invalid JSON data, the error is caught, logged as a warning, and an empty dictionary is returned.

    def load_cache():
    try:
        with open(cache_file, 'r') as f:
            return json.load(f)
    except:
        logger.warning(f"Failed to load cache.")
    return {}

    This function serves as a fail-safe persistent caching layer. It catches all standard I/O and JSON parsing exceptions to guarantee that cache read failures do not interrupt core generation pipelines. When cache access fails, downstream components fall back to fresh network API calls.

    Parameters: * None.

    Returns: * dict: Deserialized dictionary mapping prompt strings to LLM response strings, or {} upon failure.

    Raises: * No exceptions raised; all errors are absorbed and logged.

    Example:

if use_cache:
    cache = load_cache()
    if prompt in cache:
        cached_response = cache[prompt]

    Description: Serializes and writes the provided dictionary into the JSON file specified by cache_file. If an I/O error or serialization issue occurs, the exception is absorbed and a warning is logged to logger.

    def save_cache(cache):

    Parameters: * cache (dict): The dictionary of cached prompt-response pairs to be written to disk.

    Returns: * None

    Raises: * No exceptions raised; all errors are caught and logged.

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str:

    Description: Determines the active LLM backend provider based on environment variables. It inspects LLM_PROVIDER, and if not explicitly configured, infers "GEMINI" if either GEMINI_PROJECT_ID or GEMINI_API_KEY exists in the runtime environment.

    def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This helper unifies provider resolution logic across the codebase. By defaulting to Gemini when Gemini-specific environment variables are present, the system minimizes configuration overhead while allowing generic providers (e.g., OLLAMA, OPENROUTER) when LLM_PROVIDER is explicitly defined.

    Parameters: * None.

    Returns: * str or None: Resolved provider name string (e.g., "GEMINI", "OPENROUTER", "OLLAMA"), or None if no relevant configuration is detected.

    Raises: * No exceptions raised.

    Example: 

    # Provider resolution inside call_llm()

model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict:

    Description: Queries the OpenRouter public API (https://openrouter.ai/api/v1/models) to fetch model capability schemas, caching the full model array into the module-level variable _openrouter_models_cache. It then searches and returns the matching dictionary entry for the specified model_id.

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function handles runtime feature detection for OpenRouter models. Network failures or invalid JSON structures fallback to an empty list, ensuring downstream parameter lookups degrade gracefully. Successive calls within the same process reuse the populated cache to prevent network overhead.

    Parameters: * model_id (str): The unique identifier of the model as registered on OpenRouter (e.g., "anthropic/claude-3.7-sonnet").

    Returns: * dict or None: The model dictionary containing capabilities, context limits, and supported reasoning parameters, or None if not found or unreachable.

    Raises: * No exceptions raised.

    Example:

if provider == "OPENROUTER" and thinking_level:
    model_info = _get_openrouter_model_info(model)
    if model_info and "reasoning" in model_info:
        supported_efforts = model_info["reasoning"].get("supported_efforts", [])

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Resolves the maximum context token window for a given endpoint and model name. Applies known heuristics (e.g., 1,000,000 tokens for Gemini endpoints and model names) or queries OpenRouter's metadata API. Returns a safe default of 100,000 tokens if specific context sizes cannot be determined.

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    """
    Fetch the maximum context length of a model based on the endpoint.
    If endpoint is Gemini API, safely default to 1,000,000 tokens.
    If endpoint is openrouter.ai, make GET to /api/v1/models and extract.
    Default to 100,000.
    """
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This helper allows prompt batching and chunking utilities to size payloads according to provider context limits. All exceptions are caught and logged as warnings, returning default_limit (100,000) on network failures or unexpected payload responses.

    Parameters: * endpoint_url (str): Base URL or full endpoint string configured for the LLM request. * model_name (str): Name or identifier of the target model. * api_key (str, optional): API key for authenticated lookups (currently optional/unused in context queries). Defaults to "".

    Returns: * int: The resolved maximum context length in tokens.

    Raises: * No exceptions raised.

    Example: 

    # Context calculation usage
max_tokens = get_model_context_length("https://openrouter.ai/api/v1", "openai/gpt-4o")

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str = None) -> str:

    Description: Executes text completion requests against OpenAI-compatible REST endpoints (such as Ollama or OpenRouter). It extracts configuration variables dynamically using <PROVIDER>_MODEL, <PROVIDER>_BASE_URL, and <PROVIDER>_API_KEY, constructs standard /v1/chat/completions JSON payloads, handles provider-specific reasoning configurations, performs HTTP POST execution with timeout thresholds, and parses message response bodies.

    def _call_llm_provider(prompt: str, thinking_level: str = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    # Read the provider-specific variables
    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

    # Validate required variables
    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"

    # Configure headers and payload based on provider
    headers = {
        "Content-Type": "application/json",
    }
    if api_key:  # Only add Authorization header if API key is provided
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {
                    "effort": thinking_level.lower()
                }
                payload["temperature"] = 1.0  # Required for many reasoning models
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    # ... HTTP POST execution, error handling, and response extraction ...
    response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
    # ... JSON verification and return ...
    return response_json["choices"][0]["message"]["content"]

    The function adapts reasoning/thinking parameters based on the provider: OpenRouter receives a structured {"reasoning": {"effort": ...}} object when validated against model metadata, while Ollama receives both think and reasoning_effort fields to accommodate varying engine versions. The HTTP client uses a connect timeout of 10 seconds and a read timeout of 300 seconds. It also implements defensive checks against HTTP 200 responses containing error bodies missing the choices attribute.

    Parameters: * prompt (str): The full user input text sent to the model. * thinking_level (str, optional): Desired reasoning level (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The generated message content text returned by the model backend.

    Raises: * ValueError: If required environment variables (LLM_PROVIDER, <PROVIDER>_MODEL, <PROVIDER>_BASE_URL) are missing, if JSON parsing fails, or if choices is missing in the returned response. * Exception: If HTTP status code errors occur, connections fail, or timeouts are encountered.

    Example: 

    # Dispatching inside call_llm()
response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str = None) -> str:

    Description: Executes inference using the official google.genai SDK. Supports both Vertex AI authentication (via GEMINI_PROJECT_ID and GEMINI_LOCATION) and Google Developer API authentication (via GEMINI_API_KEY). Maps reasoning strings to SDK-specific thinking token budgets and cleans output text parts.

    def _call_llm_gemini(prompt: str, thinking_level: str = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(
            vertexai=True,
            project=os.getenv("GEMINI_PROJECT_ID"),
            location=os.getenv("GEMINI_LOCATION", "us-central1")
        )
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {
        "model": model,
        "contents": [prompt]
    }

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    The function prioritizes Vertex AI initialization if GEMINI_PROJECT_ID is set, defaulting the region to "us-central1" unless overridden by GEMINI_LOCATION. When thinking_level is set, it maps string keys to explicit integer token budgets (low = 1024, medium = 4096, high = 8192) via types.ThinkingConfig. The response handler filters candidate parts to concatenate only valid text items, stripping out non-text structural metadata like thought_signature.

    Parameters: * prompt (str): The prompt string to be processed by Gemini. * thinking_level (str, optional): Thinking budget level descriptor ("low", "medium", "high"). Defaults to None.

    Returns: * str: The concatenated text output from the model's candidate responses, or an empty string if no candidate parts are returned.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Example: 

    # Dispatching inside call_llm()
if provider == "GEMINI":
    response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str = None) -> str:

    Description: The primary external entry point for executing LLM generations across the codebase. It orchestrates prompt token counting, execution logging, disk cache lookups, backend provider dispatching, duration timing, and cache persistence.

    def call_llm(prompt: str, use_cache: bool = True, thinking_level: str = None) -> str:
    import time

    from utils.token_utils import count_tokens
    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'='*80}")
    logger.info(f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}")
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info(f"LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info(f"CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

    The function measures prompt complexity using utils.token_utils.count_tokens before querying the cache or making outbound network calls. If use_cache is True and the prompt matches a cached entry, the cached response is returned immediately. Otherwise, execution is delegated to either _call_llm_gemini or _call_llm_provider. Successful API responses update the cache file before returning to the caller.

    Parameters: * prompt (str): The complete prompt payload sent to the model. * use_cache (bool, optional): Whether to check and write to llm_cache.json. Defaults to True. * thinking_level (str, optional): Thinking/reasoning depth control ("low", "medium", or "high"). Defaults to None.

    Returns: * str: Raw text content generated by the resolved LLM provider.

    Raises: * ValueError: If provider credentials or configuration parameters are missing or invalid. * Exception: If upstream network or provider API failures occur during uncached execution.

    Example: 

    # Standalone execution check from module entrypoint
test_prompt = "Hello, how are you?"
response1 = call_llm(test_prompt, use_cache=False)
print(f"Response: {response1}")
