    utils.token_utils

    File Path: utils/token_utils.py

    Overview

    The utils.token_utils module provides token counting estimation and command-line analytics logging across the Codebase-Knowledge-Builder pipeline. It is utilized by computational workflow nodes (such as DeterministicFileMapper and prompt-preparation stages) to track prompt sizes and monitor LLM context window utilization in real time.

    The module attempts accurate token counting using the tiktoken library with the cl100k_base encoding model. If tiktoken encounters an error or is unavailable, it seamlessly falls back to a 4-characters-per-token heuristic (len(prompt_content) // 4). It formats the resulting token statistics and prints colorized ANSI terminal output indicating the active node, token usage, maximum limit, and context percentage.

    Functions

    log_token_estimation()

    Visibility: Public
    Signature: def log_token_estimation(node_name: str, prompt_content: str, max_tokens: int) -> None:

    Description:
    Estimates the token count for a given prompt string and prints a formatted analytics line to standard output using ANSI yellow terminal styling (\033[93m).

    Under the hood: 1. Token Estimation: Attempts to load the cl100k_base tokenizer via tiktoken.get_encoding("cl100k_base") and encodes prompt_content to retrieve the exact token count. 2. Fallback Strategy: If an exception occurs during tokenizer loading or encoding, falls back to an integer division heuristic of len(prompt_content) // 4. 3. Capacity Calculation: Calculates the percentage of total capacity consumed ((token_count / max_tokens) * 100). If max_tokens is 0, defaults capacity to 0. 4. Console Output: Prints a formatted log line in the format: 

    [Token Analytics] <node_name>: <token_count> / <max_tokens> tokens (<percentage>% capacity)

    Parameters: * node_name (str): The name or identifier of the calling pipeline node (e.g., "DeterministicFileMapper", "IdentifyAbstractions"). * prompt_content (str): The full text of the prompt to be analyzed for token consumption. * max_tokens (int): The maximum context window limit configured for the target model.

    Returns: * None

    Raises: * None (Catches all exceptions internally during token encoding to execute the fallback calculation).

    Example: 

    from utils.token_utils import log_token_estimation

prompt = "Analyze the architectural structure of the following codebase..."
max_context_limit = 128000

# Logs: [Token Analytics] AbstractionMapper: 14 / 128,000 tokens (0.0% capacity)
log_token_estimation("AbstractionMapper", prompt, max_context_limit)
