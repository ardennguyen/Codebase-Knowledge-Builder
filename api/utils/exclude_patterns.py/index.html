    exclude_patterns.py

    Source: utils/exclude_patterns.py

    Technical Overview

    utils/exclude_patterns.py defines the default baseline pattern set used by filesystem and repository crawling modules across the system, including crawl_local_files.py and crawl_github_files.py. The module centralizes file and directory exclusion rules into a single immutable configuration constant, DEFAULT_EXCLUDE_PATTERNS. During repository traversal, crawlers match discovered paths against these patterns to prevent ingestion of binary assets, compiled artifacts, third-party vendor directories, lockfiles, temporary files, and sensitive credentials.

    The patterns rely on standard Unix shell-style glob syntax evaluated via fnmatch. Directory patterns terminate with a trailing wildcard suffix (/*), signaling to recursive crawlers (such as os.walk) that any directory matching the prefix should be pruned before descending into its subtree. File patterns leverage wildcard extension matching (such as *.png or *.pyc), exact basename matching (such as package-lock.json or .DS_Store), and depth-independent wildcard path prefixes (such as */.env or */id_rsa) to intercept files located at arbitrary filesystem depths.

    Excluding irrelevant content at the ingestion boundary is essential for the documentation generation pipeline. Parsing binary media files or massive dependency trees (such as node_modules or Python virtual environments) causes excessive memory consumption, decoding failures, and token limit exhaustion when payloads are sent to Large Language Models (LLMs). Furthermore, the exclusion of cryptographic keys, environment variables, and SSH credentials prevents secrets from being cached on disk or transmitted across network boundaries to LLM inference providers.

    Public API

    DEFAULT_EXCLUDE_PATTERNS

    Visibility: Public

    Signature: DEFAULT_EXCLUDE_PATTERNS = {

    Description: A module-level set of string literals containing glob patterns formatted for evaluation with fnmatch.fnmatch() or fnmatch.fnmatchcase(). The set encapsulates exclusions partitioned across seven distinct operational domains: media and static assets; build and framework distribution directories; virtual environments, dependencies, lockfiles, and secrets; language-specific compilation artifacts; operating system and version control metadata; traditional IDE settings; and modern AI assistant workspace rules.

    Parameters:

    • This constant symbol does not accept parameters.

    Returns:

    • set[str]: An unordered collection of unique glob pattern strings.

Directory prefixes such as data/*, assets/*, and public/* discard static site resources and large sample datasets that would inflate crawler payload sizes without contributing structural code logic.

    This subset captures platform-specific compilation units, runtime bytecodes, coverage reports, and mobile dependency caches. Native machine objects and libraries (*.o, *.so, *.dylib, *.dll, *.exe) and mobile package directories (ios/Pods/*, android/.gradle/*) are excluded to avoid reading unparsable binary headers.

    Phase 5: Operating System and Version Control Metadata

        # ...
    # 5. OS & Version Control
    ".git/*",
    ".github/*",
    ".svn/*",
    ".hg/*",
    ".DS_Store",
    "Thumbs.db",

    This category eliminates VCS internal object databases and operating system desktop metadata. The .git/*, .svn/*, and .hg/* directories store internal object graphs, commit indices, and packfiles that must not be crawled as project source code. Operating system desktop index files, including macOS .DS_Store and Windows Thumbs.db and desktop.ini, are filtered out to keep directory listings clean and reproducible across operating systems.

Excluding these files prevents their prompt instructions from interfering with the LLM prompts executed by this knowledge extraction pipeline.

    Data Structures

    Default exclusion pattern set

    The file defines DEFAULT_EXCLUDE_PATTERNS as a standard Python set[str]. Each element in the set represents a path or file pattern evaluated using fnmatch.fnmatch(). The set adheres to three structural conventions:

    Pattern Category Syntax Pattern Matching Behavior Target Scope
    Directory Subtree directory_name/* Trailing wildcard indicating that any directory matching the prefix should be omitted, allowing crawlers to mutate dirnames in-place and skip subtrees. Top-level or nested directories (e.g., dist/*, venv/*, node_modules/*).
    Glob Extension *.extension Suffix wildcard matching any filename with the specified file extension, regardless of directory location. Binary assets, media files, compiled bytecode, libraries (e.g., *.png, *.pyc, *.dll).
    Basename Literal filename Exact match against the file basename; applies when the filename appears in any discovered path. Environment files, lockfiles, OS files (e.g., .env, .DS_Store, package-lock.json).
    Arbitrary Depth Wildcard */pattern Wildcard prefix matching files or directories located inside any parent directory. Nested secrets and credentials (e.g., */.env, */id_rsa, */id_ed25519).

    The breakdown of patterns across the 7 functional categories defined in DEFAULT_EXCLUDE_PATTERNS is summarized below:

    Category Index Category Description Representative Entries Primary Rationale
    1 Media, Data, & Static Assets *.png, *.jpg, *.mp4, *.pdf, *.zip, assets/* Avoid binary decoding errors and unnecessary payload volume.
    2 Build, Distribution, & Caches dist/*, build/*, target/*, .next/*, *.log Eliminate minified bundles, compiler targets, and non-source logs.
    3 Environments, Lockfiles, & Secrets .env, */id_rsa, *.pem, node_modules/*, *.lock Prevent secret exfiltration and eliminate redundant lockfile token load.
    4 Language-Specific Artifacts __pycache__/*, *.class, *.so, *.dylib, ios/Pods/* Exclude compiled platform-specific binaries and runtime caches.
    5 OS & Version Control .git/*, .github/*, .svn/*, .DS_Store, Thumbs.db Skip VCS object databases and local OS file manager metadata.
    6 Classic IDEs .vscode/*, .idea/*, *.iml, .eclipse/*, .vs/* Omit developer-specific workstation and project configuration files.
    7 AI Agents & AI IDEs .cursor/*, .cursorrules, .windsurf/*, .cline/* Avoid prompt pollution or conflicting instructions from other AI agent frameworks.
