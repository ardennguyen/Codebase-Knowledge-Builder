    exclude_patterns.py

    Source: utils/exclude_patterns.py

    Following the local filesystem crawler architecture documented in crawl_local_files.py, this module provides the central repository of default file and directory ignore rules.

    Technical Overview

    utils/exclude_patterns.py defines the canonical baseline of path exclusion rules for the Codebase-Knowledge-Builder system. During repository ingestion—whether executed locally via crawl_local_files.py or remotely via crawl_github_files.py—the extraction engine traverses directory trees containing thousands of files. Without aggressive pre-filtering, large language model (LLM) context windows are rapidly exhausted by binary media, compiled bytecode, dependency trees, lockfiles, minified distribution bundles, and AI tool metadata. This module acts as the declarative filter configuration that prunes irrelevant artifacts before they reach downstream token counting and LLM inference pipelines.

    The module exports a single primary data structure: DEFAULT_EXCLUDE_PATTERNS, a Python set containing Unix shell-style glob patterns compatible with standard fnmatch matching algorithms. The patterns are systematically partitioned across seven technical domains: static assets, build distributions, dependency directories, language-specific runtime artifacts, version control systems, legacy IDE metadata, and modern AI coding assistant telemetry. Directory patterns explicitly terminate with the /* wildcard syntax, enabling crawler implementations to prune entire directory branches during traversal rather than processing child paths individually.

    Public API

    DEFAULT_EXCLUDE_PATTERNS

    Visibility: Public (Module Constant)

    Signature: 

    DEFAULT_EXCLUDE_PATTERNS: set[str]

    Description: A constant hash set containing 131 default glob patterns used to identify non-source, binary, generated, dependency, or metadata files across diverse software ecosystems. Downstream crawlers consume this set to perform pattern matching against relative directory paths and individual filenames using fnmatch.fnmatch() or directory-level prefix pruning.

    The set employs three syntactic conventions: 1. Directory subtrees (<dir>/*): Used for early pruning during filesystem walking (e.g., node_modules/*, __pycache__/*, .git/*). 2. File extensions (*.<ext>): Used for filtering binary media, compiled bytecode, libraries, and compressed archives (e.g., *.png, *.pyc, *.dll, *.zip). 3. Exact filenames (<filename>): Used for configuration files, lockfiles, and environment definitions that contain excessive or sensitive data (e.g., package-lock.json, .DS_Store, .env).

    The set structure guarantees $O(1)$ lookup complexity when checking for exact rule membership, although typical crawler usage iterates across the set to perform pattern-based wildcard matching. The declarative grouping allows engine developers to extend or prune rules without altering crawling algorithms in crawl_local_files.py or crawl_github_files.py.

    Data Structures

    Pattern Category Taxonomy

    DEFAULT_EXCLUDE_PATTERNS is structurally organized into seven domain-specific categories. The following tables document each pattern, its syntax matching type, target ecosystem, and technical rationale.

    1. Media, Data, and Static Assets

    Static binary assets, multimedia files, office documents, and compressed archives cannot be meaningfully summarized as plain text by LLMs and risk encoding corruption or token overflow.

    Pattern Match Type Target Domain Technical Rationale
    assets/* Directory Prefix Web / App Assets Static resource directory containing bundled images, fonts, and stylesheets.
    data/* Directory Prefix Datasets / Fixtures Raw application data, SQLite databases, or bulky JSON/CSV records.
    images/* Directory Prefix Graphics Storage Raster and vector images used across UI interfaces.
    public/* Directory Prefix Frontend Bundles Static web assets served directly without build transformations.
    static/* Directory Prefix Backend Frameworks Static directory convention (Django, Flask, FastAPI) for CSS/JS/images.
    temp/* Directory Prefix Temporary Files Ephemeral scratch directory for runtime file generation.
    tmp/* Directory Prefix Temporary Files Unix-style temporary directory.
    media/* Directory Prefix User Media Uploaded user content and multimedia storage.
    *.jpg, *.jpeg File Extension Raster Image Binary JPEG image format.
    *.png File Extension Raster Image Binary PNG image format.
    *.gif File Extension Raster Image Binary GIF animation format.
    *.ico File Extension Raster Image Binary favicon icon format.
    *.svg File Extension Vector Graphic XML-based vector graphics that contain high token counts with low logic value.
    *.webp File Extension Raster Image Modern compressed image format.
    *.mp4, *.webm, *.mov File Extension Video Media Binary video container formats.
    *.mp3, *.wav File Extension Audio Media Binary audio container formats.
    *.pdf File Extension Document Portable Document Format binary structure.
    *.doc, *.docx File Extension Document Microsoft Word legacy binary and OpenXML compressed archive formats.
    *.xls, *.xlsx File Extension Spreadsheet Microsoft Excel tabular sheets containing non-code binary structures.
    *.ppt, *.pptx File Extension Presentation Microsoft PowerPoint presentation files.
    *.zip, *.tar, *.gz, *.rar, *.7z File Extension Archive Compressed multi-file container archives.

    2. Build, Distribution, and Framework Caches

    Generated compiler outputs, framework intermediate bundles, log files, and test caches do not represent original source logic.

    Pattern Match Type Target Domain Technical Rationale
    dist/* Directory Prefix Build Distribution Compiled production bundles for JavaScript, Python wheels, etc.
    build/* Directory Prefix Build System Generic build target directory for C, C++, Python, and JS.
    out/* Directory Prefix Compiler Output Output directory for TypeScript, Go, and IntelliJ builds.
    output/* Directory Prefix Artifact Storage General artifact export directory.
    output-test*/* Directory Prefix Test Harness Test runner output and mock generation artifacts.
    target/* Directory Prefix Rust / Maven Rust Cargo and Java Maven build output root.
    bin/* Directory Prefix Executables Compiled binary executables and execution scripts.
    obj/* Directory Prefix C / C++ / .NET Intermediate compiled object files.
    .next/* Directory Prefix Next.js Next.js server and client bundle cache.
    .nuxt/* Directory Prefix Nuxt.js Nuxt framework cache and virtual entrypoints.
    .svelte-kit/* Directory Prefix SvelteKit SvelteKit routing manifest and build cache.
    .expo/* Directory Prefix React Native / Expo Expo mobile development tooling cache.
    docs/* Directory Prefix Documentation External documentation trees (often redundant to inline docs).
    test/*, tests/* Directory Prefix Test Suites Unit and integration test trees excluded during core architectural passes.
    examples/* Directory Prefix Examples Sample codebases and usage demonstrations.
    v1/* Directory Prefix API Versions Legacy API versions excluded to focus on active architecture.
    experimental/* Directory Prefix Prototypes Unreleased or non-production experimental spikes.
    deprecated/* Directory Prefix Legacy Code Code marked for removal.
    misc/*, legacy/* Directory Prefix Utility / Old Code Unstructured utility scripts and legacy assets.
    *.log File Extension Logging Runtime execution log traces.
    *.bak, *.tmp, *.swp File Extension Editor / Temp Backup files, temporary writes, and Vim swap files.

    3. Environments, Dependencies & Lockfiles

    Third-party dependencies and machine-generated lockfiles contain tens of thousands of lines that dilute repository-specific logic and exhaust LLM context.

    Pattern Match Type Target Domain Technical Rationale
    venv/*, .venv/*, env/* Directory Prefix Python Virtualenv Isolated Python runtime environments and site-packages.
    .env, .env.* Exact / Glob Secrets & Config Local environment variable definitions containing credentials and API keys.
    node_modules/* Directory Prefix Node.js Ecosystem NPM, Yarn, and PNPM resolved dependency trees.
    bower_components/* Directory Prefix Bower Package Manager Legacy client-side package dependencies.
    jspm_packages/* Directory Prefix JSPM SystemJS/JSPM package repository.
    vendor/* Directory Prefix Go / PHP / Ruby Vendored dependencies for Go modules, Composer, or Bundler.
    packages/* Directory Prefix Monorepos / NuGet Local monorepo dependency cache or NuGet package directory.
    *.lock File Extension General Lockfiles Generic dependency resolution lockfiles.
    package-lock.json Exact Match NPM NPM resolved dependency tree and checksum manifest.
    yarn.lock Exact Match Yarn Yarn resolved package graph.
    pnpm-lock.yaml Exact Match PNPM PNPM content-addressable storage lockfile.
    Cargo.lock Exact Match Rust / Cargo Exact crate dependency versions for Rust projects.
    Gemfile.lock Exact Match Ruby / Bundler Ruby gem dependency resolution state.
    poetry.lock Exact Match Python Poetry Poetry pinned dependency hashes and versions.
    mix.lock Exact Match Elixir / Mix Hex package lockfile for Elixir applications.
    Pipfile.lock Exact Match Pipenv JSON-formatted dependency hash lockfile for Pipenv.

    4. Language-Specific Exclusions

    Language compilers, runtime virtual machines, and testing harnesses generate intermediate binaries, bytecode, and coverage metrics that cannot be read as plain text.

    Pattern Match Type Ecosystem Technical Rationale
    __pycache__/* Directory Prefix Python CPython compiled bytecode directory.
    *.pyc, *.pyo, *.pyd File Extension Python Compiled bytecode, optimized bytecode, and C-extension DLLs.
    .pytest_cache/* Directory Prefix Python (pytest) Pytest execution cache and step failure state.
    .ruff_cache/* Directory Prefix Python (Ruff) Ruff linter file analysis cache.
    .tox/* Directory Prefix Python (Tox) Tox virtual environment test runner matrices.
    .coverage, htmlcov/* Exact / Directory Python (Coverage) SQLite coverage database and generated HTML coverage reports.
    .gradle/* Directory Prefix Java / Kotlin / Gradle Gradle daemon cache, dependency cache, and build steps.
    *.class File Extension JVM Compiled Java bytecode binaries.
    *.jar, *.war, *.ear File Extension JVM Java ARchive, Web Application, and Enterprise Application packages.
    *.nar File Extension JVM / Native Native ARchive format for JVM native bindings.
    *.o, *.obj File Extension C / C++ / Native Compiled object code prior to linking.
    *.dll, *.dylib, *.so File Extension Native Libraries Dynamically linked shared libraries (Windows, macOS, Linux).
    *.exe File Extension Executable Windows portable executable binaries.
    *.lib, *.a File Extension Static Libraries Statically linked archive libraries (Windows, Unix).
    ios/Pods/* Directory Prefix iOS (CocoaPods) Downloaded CocoaPods library source dependencies.
    android/.gradle/* Directory Prefix Android Android Studio Gradle wrapper and daemon state.
    android/app/build/* Directory Prefix Android Android application intermediate APK and AAR build assets.

    5. OS & Version Control

    Internal version control databases and operating system file managers create metadata files containing binary indices or display configurations.

    Pattern Match Type Target Domain Technical Rationale
    .git/* Directory Prefix Git Internal Git repository database (objects, refs, hooks, index).
    .github/* Directory Prefix GitHub CI/CD actions, issue templates, and repository workflows.
    .svn/* Directory Prefix Subversion Legacy SVN repository administrative directory.
    .hg/* Directory Prefix Mercurial Mercurial version control store.
    .DS_Store Exact Match macOS Finder Desktop Services Store containing folder view settings.
    Thumbs.db Exact Match Windows Explorer Thumbnail image cache for Windows folders.
    desktop.ini Exact Match Windows Explorer Custom folder layout and icon configuration file.

    6. Classic IDEs

    Integrated Development Environment project configurations, compiler workspace indices, and user-specific editor preferences.

    Pattern Match Type IDE / Tool Technical Rationale
    .vscode/* Directory Prefix Visual Studio Code Workspace launch settings, extension recommendations, and tasks.
    .idea/* Directory Prefix JetBrains IDEs IntelliJ/PyCharm workspace state, indexing cache, and project models.
    *.iml File Extension JetBrains IDEs IntelliJ module configuration XML file.
    .eclipse/* Directory Prefix Eclipse IDE Eclipse project workspace metadata.
    .settings/* Directory Prefix Eclipse IDE Eclipse project-level plugin configuration.
    .classpath, .project Exact Match Eclipse IDE Eclipse Java build path and core project descriptors.
    .vs/* Directory Prefix Visual Studio Visual Studio solution browsing databases and debug sessions.

    7. AI Agents & Modern AI IDEs

    Modern AI development environments and autonomous coding agents generate prompt scratchpads, rule configurations, indexing databases, and session logs that distract repository comprehension models.

    Pattern Match Type AI System Technical Rationale
    .cursor/* Directory Prefix Cursor IDE Cursor indexing database, project indexing state, and logs.
    .cursorrules Exact Match Cursor IDE Custom system instructions and project-level AI constraints.
    .windsurf/* Directory Prefix Windsurf IDE Codeium Windsurf project cache and execution traces.
    .windsurfrules Exact Match Windsurf IDE Windsurf agent system instructions.
    .cline/* Directory Prefix Cline Assistant Cline agent task memory, checkpoint history, and MCP settings.
    .clinerules Exact Match Cline Assistant Cline repository instruction set.
    .roo/* Directory Prefix Roo Code Roo Code agent task states and context histories.
    .roorules Exact Match Roo Code Roo Code custom rule configuration.
    .agent/*, .agents/* Directory Prefix Generic Agents Autonomous coding agent working directories and tool outputs.
    .continue/* Directory Prefix Continue.dev Continue indexing store, prompt templates, and telemetry.
    .aide/* Directory Prefix Aide IDE Aide workspace indexing and execution artifacts.
    .gemini/* Directory Prefix Gemini CLI / IDE Gemini assistant local project configuration and caches.
    .antigravity/* Directory Prefix Antigravity AI Antigravity engine workspace metadata and task traces.
    .claude/* Directory Prefix Anthropic Claude Claude Code CLI project settings and conversation logs.
    .copilot/* Directory Prefix GitHub Copilot Copilot workspace indexing state and local configuration.
