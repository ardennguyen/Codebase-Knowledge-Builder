    llm_common.py

    Source: utils/llm_common.py

    Technical Overview

    The utils/llm_common.py module serves as the foundational, provider-neutral utility library for the LLM abstraction layer in Codebase-Knowledge-Builder. It operates without importing any external model SDKs (such as Anthropic, Google GenAI, or OpenAI), relying solely on standard library primitives (contextlib, contextvars, and hashlib). This design ensures that core error representations, response boundary types, execution step context management, warning de-duplication, and token accounting are universally available to all provider drivers and downstream execution nodes without circular dependencies or vendor lock-in.

    The module manages two primary stateful subsystems across the execution lifecycle: request memoization and a multi-dimensional usage ledger. First, to avoid redundant billing and prevent wasted rate-limit quotas during retry loops, it computes SHA-256 cryptographic digests of outgoing requests and memoizes terminal refusals (LLMRefusalError). Second, it provides an in-memory accounting engine that tracks token consumption (input, output, reasoning/thinking, and prompt cache reads/writes), monetary costs, event counters, and estimation discrepancies. By leveraging Python's contextvars.ContextVar, the ledger automatically correlates per-request token usage with active pipeline steps (such as ContextRouter, IdentifyAbstractions, or CombineTutorial), even across nested calling contexts.

    Public API

    TruncatedResponse

    Visibility: Public

    Signature: class TruncatedResponse(str):

    Description: A specialized string subclass used to wrap model response texts that were cut off prematurely due to token budget caps or context window boundaries. Downstream caching systems check the truncated attribute to strictly bypass serialization to the persistent response cache, while YAML/JSON response parsers reject it to trigger retry strategies.

    Example:

    class TruncatedResponse(str):
    """Response text from a reply that was cut off; call_llm returns it but never caches it."""

    truncated = True

    The TruncatedResponse class subclasses Python's built-in str, enabling downstream functions to process its contents as ordinary text if needed while carrying the boolean attribute truncated = True. This explicit boundary flag allows orchestrators such as call_llm to distinguish complete generations from cut-off outputs without parsing stop reason metadata. Caching subsystems inspect this attribute prior to persisting payloads, ensuring partial or syntactically broken responses never pollute the response cache. Furthermore, downstream structured output validators immediately fail on encountering a TruncatedResponse, triggering retry and context recovery routines.

    LLMRefusalError

    Visibility: Public

    Signature: class LLMRefusalError(RuntimeError):

    Description: Custom exception raised when an upstream model provider (and any configured fallback models) declines to service an inference request due to safety restrictions, content moderation, recitation blocks, or policy constraints.

    Parameters:

    • model (str): Identifier of the model that issued the refusal.
    • category (str | None): Policy or safety category reported by the provider (e.g., "recitation", "safety", "content_filter").
    • provider (str): Model provider identifier, defaulting to "ANTHROPIC".
    • retryable (bool): Flag indicating whether re-sampling the prompt might succeed (True) or if the decline is deterministic (False).

    Example:

    class LLMRefusalError(RuntimeError):
    """Raised when the provider (and any configured fallback) declines a request.

    retryable=False: the same request is declined again (Claude refusal, blocked prompt,
    prohibited content) — call_llm remembers it and does not re-send it on node retries.
    retryable=True: an output-side block that a new sample can pass (Gemini RECITATION / OTHER /
    SAFETY on the candidate, OpenRouter content_filter) — node retries re-sample normally.
    """

    def __init__(self, model: str, category: str | None, provider: str = "ANTHROPIC", retryable: bool = False):
        self.model = model
        self.category = category
        self.provider = provider
        self.retryable = retryable
        super().__init__(f"{provider} model {model} declined the request (category={category or 'unknown'})")

    The constructor binds structural metadata (model, category, provider, and retryable) to the exception instance before formatting a descriptive diagnostic message for the standard RuntimeError base class. When retryable is set to False, the decline is considered deterministic (such as an outright prompt safety block), signaling to the calling orchestrator that the request should be permanently memoized in the module's refusal registry to prevent retries. Conversely, when retryable is set to True, the block occurred during output sampling (e.g., Gemini candidate recitation filters or transient moderation flags), signaling that re-submitting the prompt with another sampling attempt may succeed.

    request_key()

    Visibility: Public

    Signature: def request_key(provider: str, model: str, thinking_level: str | None, prompt: str) -> str:

    Description: Generates an isolated, deterministic SHA-256 hex digest representing a unique LLM invocation scope. Combines provider, model, thinking effort level, and prompt text.

    Parameters:

    • provider (str): The model provider identifier (e.g., "anthropic", "gemini", "openrouter").
    • model (str): The specific model name or identifier string.
    • thinking_level (str | None): The reasoning or thinking budget configuration string (e.g., "low", "high"), falling back to "default" if None.
    • prompt (str): The complete raw prompt string passed to the LLM.

    Returns:

    • str: A 64-character lowercase SHA-256 hexadecimal hash string uniquely identifying the call.

    Example:

    def request_key(provider: str, model: str, thinking_level: str | None, prompt: str) -> str:
    scope = f"{provider}|{model}|{(thinking_level or 'default').lower()}\n"
    return hashlib.sha256((scope + prompt).encode("utf-8")).hexdigest()

    The function constructs a composite scope prefix consisting of the provider, model, and normalized lowercase thinking level separated by pipe characters and terminated with a newline character. This prefix is concatenated with the complete prompt body and encoded into UTF-8 byte streams before passing into hashlib.sha256(). By incorporating the thinking level and provider alongside the raw prompt, the function guarantees cryptographic isolation across differing model configurations, preventing collision when the same prompt is evaluated under different reasoning budgets.

    remember_refusal()

    Visibility: Public

    Signature: def remember_refusal(key: str, error: LLMRefusalError) -> None:

    Description: Stores a non-retryable refusal exception in the module's internal refusal memoization table using the call's unique request key.

    Parameters:

    • key (str): Cryptographic request key generated by request_key().
    • error (LLMRefusalError): The terminal refusal exception instance to memoize.

    Returns:

    • None

    Example:

    def remember_refusal(key: str, error: LLMRefusalError) -> None:
    _refused[key] = error

    This function performs a direct assignment of the LLMRefusalError instance into the private module-level _refused dictionary keyed by the calculated hash. It serves as an in-memory write barrier during workflow retry loops, ensuring that deterministic provider rejections are cataloged once and recalled immediately on subsequent invocation attempts without repeating remote HTTP requests.

    usage_step()

    Visibility: Public

    Signature: def usage_step(step: str | None):

    Description: Context manager that binds the current execution context to a designated pipeline step identifier, attributing all token usage and counters within the block to that step.

    Parameters:

    • step (str | None): Pipeline step name (e.g., "extract_facts", "draft_chapters"). If None or empty, defaults to "other".

    Returns:

    • Generator yielding control within the context manager block.

    Example:

    @contextlib.contextmanager
def usage_step(step: str | None):
    """Attribute every record_usage / count_event inside the block to `step`."""
    token = _current_step.set(step or "other")
    try:
        yield
    finally:
        _current_step.reset(token)

    The function employs @contextlib.contextmanager to govern the lifecycle of a contextvars.ContextVar token. Upon entering the context, it sets _current_step to the provided step string (defaulting to "other") and retains the returned state token. Inside a finally block, it guarantees that _current_step.reset(token) is executed upon block exit, restoring the previous step identifier even if exceptions occur within the nested code block.

    record_usage()

    Visibility: Public

    Signature:

    def record_usage(
    provider: str,
    model: str,
    *,
    input_tokens: int = 0,
    output_tokens: int = 0,
    thinking_tokens: int = 0,
    cache_read: int = 0,
    cache_write: int = 0,
    cost: float | None = None,
    measured: bool = True,
) -> None:

    Description: Records metrics from a completed LLM request into both the provider-level and step-level usage ledgers, aggregating tokens, pricing, and measurement metadata.

    Parameters:

    • provider (str): Provider identifier (e.g., "anthropic", "gemini").
    • model (str): Name of the model executing the call.
    • input_tokens (int): Total prompt tokens counted by the provider, including cached tokens. Defaults to 0.
    • output_tokens (int): Total output tokens returned, including reasoning/thinking tokens. Defaults to 0.
    • thinking_tokens (int): Subset of output tokens dedicated to model reasoning. Defaults to 0.
    • cache_read (int): Tokens read from an existing prompt cache. Defaults to 0.
    • cache_write (int): Tokens written into the prompt cache during this request. Defaults to 0.
    • cost (float | None): Monetary cost in USD for the call. If None, marked as unpriced.
    • measured (bool): Flag indicating if the provider reported valid token metrics. Defaults to True.

    Returns:

    • None

    Example:

    def record_usage(
    provider: str,
    model: str,
    *,
    input_tokens: int = 0,
    output_tokens: int = 0,
    thinking_tokens: int = 0,
    cache_read: int = 0,
    cache_write: int = 0,
    cost: float | None = None,
    measured: bool = True,
) -> None:
    for entry in (_usage.setdefault(provider, _new_entry()), _steps.setdefault(current_step(), _new_entry())):
        if model:
            entry["models"].add(model)
        entry["calls"] += 1
        if not measured:
            entry["unmeasured_calls"] += 1
        entry["input"] += input_tokens or 0
        entry["output"] += output_tokens or 0
        entry["thinking"] += thinking_tokens or 0
        entry["cache_read"] += cache_read or 0
        entry["cache_write"] += cache_write or 0
        if cost is None:
            entry["unpriced_calls"] += 1
        else:
            entry["cost"] += cost

    This function performs dual accumulation: it resolves the ledger entry for the given provider in _usage and the entry for the active step via current_step() in _steps, initializing each via _new_entry() if absent. It updates the unique set of model names, increments the total call count, and defensively accumulates token counts using or 0 fallbacks. If measured is False, it increments unmeasured_calls, allowing subsequent telemetry audits to exclude unbilled or uninstrumented requests from token estimation comparisons. If cost is None, it tracks the occurrence under unpriced_calls; otherwise, it adds the float amount directly to cost.

    count_event()

    Visibility: Public

    Signature: def count_event(provider: str, event: str) -> None:

    Description: Increments a named operational event counter (e.g., "refusals", "fallbacks", "truncations") simultaneously for a given provider and the active execution step.

    Parameters:

    • provider (str): Provider identifier against which the event occurred.
    • event (str): The counter dictionary key to increment (must match an integer key in _new_entry()).

    Returns:

    • None

    Example:

    def count_event(provider: str, event: str) -> None:
    """Increment 'refusals' | 'fallbacks' | 'truncations' for a provider (and the current step)."""
    _usage.setdefault(provider, _new_entry())[event] += 1
    _steps.setdefault(current_step(), _new_entry())[event] += 1

    The function accesses the corresponding entry dictionaries in both _usage and _steps using .setdefault(), initializing them with _new_entry() if they do not yet exist. It then directly increments the value mapped to the string passed via the event argument. This ensures that non-fatal exceptions, provider fallback switches, and token truncation events are tracked synchronously across provider and workflow step aggregations.

    record_estimate()

    Visibility: Public

    Signature: def record_estimate(step: str, estimated_input: int, *, cache_hit: bool = False) -> None:

    Description: Records prompt token estimations and cache hit indicators for a specific pipeline step.

    Parameters:

    • step (str): The pipeline step name receiving the estimate. Defaults to "other" if empty.
    • estimated_input (int): The calculated input token count estimated prior to provider execution.
    • cache_hit (bool): Flag indicating if the request was resolved directly from the local cache. Defaults to False.

    Returns:

    • None

    Example:

    def record_estimate(step: str, estimated_input: int, *, cache_hit: bool = False) -> None:
    """Add call_llm's input estimate for a call (billed or served from the LLM cache) to a step."""
    entry = _steps.setdefault(step or "other", _new_entry())
    if cache_hit:
        entry["cache_hits"] += 1
    else:
        entry["estimated_input"] += estimated_input or 0

    The function fetches or initializes the dictionary entry for the designated step within the _steps ledger. When cache_hit is True, it increments the entry's cache_hits counter, tracking requests satisfied from the local disk cache without network transport. When cache_hit is False, it accumulates estimated_input tokens into the entry, enabling downstream reporting tools to compare upfront tokenizer estimations against actual billed tokens.

    usage_snapshot()

    Visibility: Public

    Signature: def usage_snapshot(provider: str) -> dict:

    Description: Creates a point-in-time copy of a provider's numeric usage counters, excluding non-numeric objects like sets.

    Parameters:

    • provider (str): Provider identifier to inspect.

    Returns:

    • dict: A dictionary containing copies of all metric counters for the provider, excluding the "models" key.

    Example:

    def usage_snapshot(provider: str) -> dict:
    """Copy of a provider's running totals (diff two snapshots to get one call's usage)."""
    entry = _usage.get(provider)
    return {k: v for k, v in entry.items() if k != "models"} if entry else {k: v for k, v in _new_entry().items() if k != "models"}

    The function inspects _usage for the target provider. If an entry is present, it constructs a new dictionary filtering out the "models" set; if the provider has not yet been registered, it constructs an equivalent blank template from _new_entry() with "models" omitted. This snapshot serves as an isolated baseline that can be subtracted from a subsequent snapshot to compute the exact usage delta of a single request.

    usage_delta()

    Visibility: Public

    Signature: def usage_delta(before: dict, after: dict) -> dict:

    Description: Computes the arithmetic difference between two usage snapshot dictionaries.

    Parameters:

    • before (dict): Baseline usage dictionary captured prior to an operation.
    • after (dict): Terminal usage dictionary captured after an operation.

    Returns:

    • dict: A dictionary containing the arithmetic difference (after[k] - before[k]) for every counter key.

    Example:

    def usage_delta(before: dict, after: dict) -> dict:
    return {k: after[k] - before.get(k, 0) for k in after}

    The function executes a dictionary comprehension iterating over all keys present in the after dictionary, subtracting the corresponding key's value from before (defaulting missing baseline keys to 0). This calculates the incremental token usage, cost, and event counts incurred specifically between the capture of before and after.

    get_usage_summary()

    Visibility: Public

    Signature: def get_usage_summary() -> dict:

    Description: Compiles a comprehensive usage report mapping each active provider to its normalized metrics dictionary.

    Parameters:

    • None

    Returns:

    • dict: Dictionary mapping provider strings to public ledger summaries for providers that recorded at least one call (calls > 0).

    Example:

    def get_usage_summary() -> dict:
    """{provider: totals} for every provider that made at least one call this run."""

    The function filters the _usage registry to include only providers that executed one or more calls (entry["calls"] > 0). For each qualifying provider, it passes the internal mutable entry through _public() to sanitize internal data structures (sorting model names and computing cost validity) before returning the resulting mapping to the caller.

    warn_once()

    Visibility: Public

    Signature: def warn_once(key: str, *parts) -> bool:

    Description: Thread-safe de-duplication mechanism ensuring a warning identified by a key and arbitrary message parts is emitted only once per process execution.

    Parameters:

    • key (str): Primary identifier categorizing the warning.
    • *parts (Any): Variable positional components comprising the warning identifier tuple.

    Returns:

    • bool: True if this specific warning marker is encountered for the first time during the run; False if it has already been observed.

    Example:

    def warn_once(key: str, *parts) -> bool:
    """True the first time a (key, parts) combination is seen this run."""
    marker = (key, *parts)
    if marker in _warned:
        return False
    _warned.add(marker)
    return True

    The function packs key and any trailing arguments *parts into a single immutable tuple marker. It checks whether marker exists within the module-level set _warned. If present, it immediately returns False; otherwise, it adds marker to _warned and returns True. Callers wrap logging statements in conditional checks on warn_once() to prevent repetitive warnings from flooding console logs across iterative loops.

    Internal Helpers

    _refused

    Visibility: Private

    Signature: _refused = {}

    Description: A module-level dictionary singleton mapping 64-character SHA-256 request keys (generated by request_key()) directly to their corresponding LLMRefusalError instances.

    Example:

    # Refused-request memo: a declined prompt is declined again, so PocketFlow retries
# must not re-send it (wasted rate limit, and billed partial output on mid-stream declines).
_refused = {}

    This private dictionary operates as a memoization cache for non-retryable provider declines. Because deterministic refusals will repeat if re-sent, storing the exception object allows orchestrators to bypass network dispatch on workflow retries and re-raise the original refusal immediately.

    Description: A module-level dictionary singleton mapping provider identifier strings (e.g., "anthropic", "gemini") to their respective mutable accounting entries created by _new_entry().

_usage = {}

    This private dictionary aggregates running token totals, financial costs, call volumes, and error metrics partitioned by model provider. It is updated incrementally by record_usage() and count_event(), and read during snapshot creation or summary generation.

    _steps

    Description: A module-level dictionary singleton mapping workflow step names (e.g., "extract_manifest", "draft_chapters") to their mutable accounting entries created by _new_entry().

    Example:

    _steps = {}

    Maintained in insertion order, this dictionary records token metrics, cost amounts, and cache statistics broken down by pipeline node execution steps. It mirrors the structure of _usage, allowing callers to inspect resource consumption either by model vendor or by workflow phase.

    _current_step

    Description: Context variable used to track the currently executing pipeline step identifier across synchronous and asynchronous execution boundaries.

    Example:

    By utilizing contextvars.ContextVar, the module ensures thread-safe and task-isolated step tracking. When nested functions or providers record usage, current_step() reads from this variable to attribute consumption to the enclosing workflow step without requiring parameter passing.

    _warned

    Visibility: Private

    Description: A module-level set storing composite marker tuples of previously observed warnings.

    Example:

    _new_entry()

    Visibility: Private

    Signature: def _new_entry() -> dict:

    Description: Factory function initializing a standardized ledger entry dictionary with zeroed metric counters and an empty model set.

    Returns:

    • dict: A newly allocated ledger dictionary conforming to the internal accounting schema.

    Example:

    def _new_entry() -> dict:
    return {
        "models": set(),
        "calls": 0,
        "input": 0,
        "output": 0,
        "thinking": 0,
        "cache_read": 0,
        "cache_write": 0,

    The function constructs and returns a uniform dictionary tracking fifteen individual metrics. The "models" field is initialized as a mutable Python set to collect distinct model strings encountered during execution.     _public()

    Visibility: Private

    Signature: def _public(entry: dict) -> dict:

    Description: Transforms an internal mutable ledger entry dictionary into an externally consumable dictionary representation.

    Parameters:

    • entry (dict): An internal accounting dictionary created via _new_entry().

    Returns:

    • dict: A shallow copy of entry where "models" is converted into a sorted list of strings and a "cost_known" boolean flag is appended.

    Example:

    def _public(entry: dict) -> dict:
    return dict(entry, models=sorted(entry["models"]), cost_known=entry["unpriced_calls"] == 0)

    This helper transforms internal data structures prior to exposing summaries outside the module. Specifically, it converts the mutable "models" set into a deterministic, lexicographically sorted list of strings suitable for serialization. Additionally, it computes the boolean property cost_known (evaluated as entry["unpriced_calls"] == 0), signaling to reporting tools whether the accumulated cost accurately reflects the entire call volume or if unpriced calls were present.

    Error Handling

    The module defines and relies on LLMRefusalError to manage provider declines systematically:

    • Non-Retryable Declines (retryable=False): When an upstream provider rejects a prompt deterministically (e.g., Anthropic Claude safety policy rejections, content moderation violations, or blocked system instructions), the exception is initialized with retryable=False. The orchestrator passes the call's unique hash key to remember_refusal(), which caches the exception instance in _refused. On future retries within PocketFlow or orchestrator workflows, previous_refusal() short-circuits execution before network dispatch, preventing rate-limit depletion and redundant billing for unserviceable requests.
    • Retryable Declines (retryable=True): When a decline occurs due to candidate-level or stochastic output sampling restrictions (such as Google Gemini RECITATION, OTHER, or candidate safety thresholds, and OpenRouter mid-stream content_filter responses), the exception is initialized with retryable=True. These errors are omitted from remember_refusal(), allowing retry handlers to re-sample the request with different seeds or adjusted parameters.
    • Defensive Arithmetic and Missing Keys: Functions that perform counter updates or differential calculations (record_usage(), record_estimate(), and usage_delta()) employ fallback defaulting (or 0, .get(k, 0)). This prevents KeyError or TypeError exceptions if uninitialized entries or partial dictionaries are evaluated.
