    llm_common.py

    Source: utils/llm_common.py

    Technical Overview

    Building upon the vendor-specific transport and parsing mechanics established in llm_anthropic.py, the llm_common.py module defines the shared, provider-agnostic domain layer for the entire inference pipeline. It operates as a zero-dependency foundational component that explicitly avoids importing third-party provider SDKs (anthropic, google-genai, openai). By establishing uniform domain representations for incomplete generations, provider rejections, runtime deduplication, and financial telemetry, it isolates the high-level orchestration workflows in call_llm.py from the underlying provider implementations.

    The primary architectural role of llm_common.py is to manage stateful inference invariants across multi-step execution graphs. It provides a circuit-breaking refusal memoization mechanism (_refused) that prevents wasteful network retries against models that deterministically decline prompts due to safety, moderation, or policy violations. Furthermore, it defines custom string subtype semantics (TruncatedResponse) to intercept length-truncated completions before they can contaminate the disk-backed cache in call_llm.py, while simultaneously offering a centralized session ledger (_usage) to record token volumes, thinking token allocations, prompt cache interactions, and accumulated operational costs.

    Public API

    TruncatedResponse

    Visibility: Public
    Signature: class TruncatedResponse(str):

    Description: A specialized string subclass that tags model responses truncated by output token limits or context window boundaries. It preserves standard string behavior across serialization and downstream logging operations while exposing a sentinel truncated = True attribute. Higher-level orchestration layers, specifically call_llm and parse_yaml_response, inspect this boolean attribute to bypass persistent disk caching and signal upstream node retries.

    Attributes: * truncated (bool): Sentinel flag, always set to True, identifying the output buffer as incomplete.

    Example: 

    class TruncatedResponse(str):
    """Response text from a reply that was cut off; call_llm returns it but never caches it."""

    truncated = True
    The implementation derives directly from native str without mutating base string memory layouts. Because instances pass standard string type checks throughout the Python runtime, intermediate formatters can safely inspect, print, or measure the truncated payload without raising type errors. Upstream orchestrators use getattr(response, "truncated", False) to selectively invalidate the run from the persistence cache, ensuring that defective, half-formed YAML blocks or code generations are forced through subsequent re-sampling passes.

    LLMRefusalError

    Visibility: Public
    Signature: class LLMRefusalError(RuntimeError): def __init__(self, model: str, category: str | None, provider: str = "ANTHROPIC", retryable: bool = False):

    Description: Domain exception raised when an LLM provider declines to generate a completion due to content moderation filters, safety guardrails, or recitation protections. It encapsulates the originating provider, model identifier, refusal classification category, and a criticality flag (retryable). This flag differentiates between deterministic prompt declines (such as system-level policy blocks that must never be re-sent) and stochastic candidate blocks (such as mid-generation recitation triggers that may succeed upon re-sampling).

    Parameters: * model (str): The specific model identifier that issued the refusal (e.g., "claude-3-7-sonnet-20250219"). * category (str | None): The provider's safety category code or rejection reason (e.g., "safety", "recitation", "content_filter"). * provider (str): The identifier of the rejecting vendor platform. Defaults to "ANTHROPIC". * retryable (bool): Indicates whether repeating the inference request with alternative sampling parameters could succeed. Defaults to False.

    Returns: * LLMRefusalError: Instantiated exception object with formatted diagnostic details.

    Raises: * N/A: Instantiation does not raise errors.

    Example: 

    class LLMRefusalError(RuntimeError):
    """Raised when the provider (and any configured fallback) declines a request.

    retryable=False: the same request is declined again (Claude refusal, blocked prompt,
    prohibited content) — call_llm remembers it and does not re-send it on node retries.
    retryable=True: an output-side block that a new sample can pass (Gemini RECITATION / OTHER /
    SAFETY on the candidate, OpenRouter content_filter) — node retries re-sample normally.
    """

    def __init__(self, model: str, category: str | None, provider: str = "ANTHROPIC", retryable: bool = False):
        self.model = model
        self.category = category
        self.provider = provider
        self.retryable = retryable
        super().__init__(f"{provider} model {model} declined the request (category={category or 'unknown'})")
    The constructor structures diagnostic messages uniformly across diverse provider payloads, converting ambiguous vendor error codes into a standardized runtime exception. Downstream dispatchers evaluate the instance's retryable property to modulate retry loops. If retryable evaluates to False, the refusal is committed to the module's internal lookup table, short-circuiting identical subsequent requests before invoking network sockets.

    request_key()

    Visibility: Public
    Signature: def request_key(provider: str, model: str, thinking_level: str | None, prompt: str) -> str:

    Description: Generates a deterministic SHA-256 hexadecimal hash identifying an inference request. The key is composed of a scoped header containing the provider name, the model string, and the normalized reasoning effort level, followed by the exact prompt payload. This hash serves as the primary indexing key for refusal tracking and cache deduplication.

    Parameters: * provider (str): The upstream inference provider (e.g., "ANTHROPIC", "GEMINI", "OPENROUTER"). * model (str): The target model name string. * thinking_level (str | None): The configured reasoning intensity (e.g., "low", "medium", "high"), or None if operating without reasoning tokens. * prompt (str): The complete serialized prompt string passed to the driver.

    Returns: * str: A 64-character lowercase SHA-256 hexadecimal digest representing the request signature.

    Raises: * N/A.

    Example: 

    def request_key(provider: str, model: str, thinking_level: str | None, prompt: str) -> str:
    scope = f"{provider}|{model}|{(thinking_level or 'default').lower()}\n"
    return hashlib.sha256((scope + prompt).encode("utf-8")).hexdigest()
    The implementation uses a delimiter-separated scope prefix (provider|model|thinking_level\n) to ensure that identical prompt strings routed to different models or distinct reasoning budgets yield collision-free digests. The resulting string is encoded into UTF-8 before being passed to hashlib.sha256. This mechanism provides an identical hash output across diverse operating systems and process lifecycles.

    remember_refusal()

    Visibility: Public
    Signature: def remember_refusal(key: str, error: LLMRefusalError) -> None:

    Description: Registers an encountered non-retryable LLMRefusalError into the module-level refusal registry (_refused), binding the error object to the request's deterministic SHA-256 hash.

    Parameters: * key (str): The hexadecimal request digest computed via request_key(). * error (LLMRefusalError): The refusal error instance capturing the failure context.

    Returns: * None

    Raises: * N/A.

    Example: 

    def remember_refusal(key: str, error: LLMRefusalError) -> None:
    _refused[key] = error
    This function populates the private global dictionary _refused to provide process-level memorization of declined inference attempts. When synthesis nodes attempt retries following a fatal safety refusal, registering the error through this function allows the caller to break out of cascading execution cycles immediately. The stored error retains its original stack context, failure model, and safety categories for subsequent inspection.

    previous_refusal()

    Visibility: Public
    Signature: def previous_refusal(key: str) -> LLMRefusalError | None:

    Description: Queries the module-level refusal registry for a previously recorded LLMRefusalError matching the provided request hash.

    Parameters: * key (str): The hexadecimal request digest computed via request_key().

    Returns: * LLMRefusalError | None: The cached refusal error if previously recorded; otherwise None.

    Raises: * N/A.

    Example: 

    def previous_refusal(key: str) -> LLMRefusalError | None:
    return _refused.get(key)
    The retrieval helper executes an $O(1)$ dictionary lookup against the _refused table. Orchestrators in call_llm evaluate this lookup before calculating token bounds or initiating network requests. If an error is returned, the orchestrator immediately raises the memorized exception, preventing unnecessary network traffic, API quota consumption, and unneeded billing on inputs that will reliably trigger safety filters.

    record_usage()

    Visibility: Public
    Signature: def record_usage(provider: str, model: str, *, input_tokens: int = 0, output_tokens: int = 0, thinking_tokens: int = 0, cache_read: int = 0, cache_write: int = 0, cost: float | None = None) -> None:

    Description: Records token volumes, prompt cache mechanics, and operational expenses for a completed inference call into the global usage ledger (_usage). It aggregates metrics per provider, tracks unique models utilized, and updates cost flags based on pricing availability.

    Parameters: * provider (str): The provider identifier (e.g., "GEMINI", "ANTHROPIC"). * model (str): The specific model used for the completion. * input_tokens (int): Count of prompt/input tokens processed. Defaults to 0. * output_tokens (int): Count of total output tokens generated, including thinking tokens. Defaults to 0. * thinking_tokens (int): Subset of output tokens dedicated to internal model reasoning. Defaults to 0. * cache_read (int): Count of input tokens read from the provider's prompt cache. Defaults to 0. * cache_write (int): Count of input tokens written to create new prompt cache entries. Defaults to 0. * cost (float | None): Financial cost in USD for the transaction. If passed as None, marks the provider's overall cost as uncomputable. Defaults to None.

    Returns: * None

    Raises: * N/A.

    Example: 

    def record_usage(
    provider: str,
    model: str,
    *,
    input_tokens: int = 0,
    output_tokens: int = 0,
    thinking_tokens: int = 0,
    cache_read: int = 0,
    cache_write: int = 0,
    cost: float | None = None,
) -> None:
    """Accumulate one call. `output_tokens` includes thinking; `thinking_tokens` is the reported subset.
    `cost` is USD; None means the price is unknown for this model (summary shows n/a)."""
    entry = _usage.setdefault(
        provider,
        {
            "models": set(),
            "calls": 0,
            "input": 0,
            "output": 0,
            "thinking": 0,
            "cache_read": 0,
            "cache_write": 0,
            "cost": 0.0,
            "cost_known": True,
            "refusals": 0,
            "fallbacks": 0,
            "truncations": 0,
        },
    )
    if model:
        entry["models"].add(model)
    entry["calls"] += 1
    entry["input"] += input_tokens or 0
    entry["output"] += output_tokens or 0
    entry["thinking"] += thinking_tokens or 0
    entry["cache_read"] += cache_read or 0
    entry["cache_write"] += cache_write or 0
    if cost is None:
        entry["cost_known"] = False
    else:
        entry["cost"] += cost
    The implementation uses dict.setdefault to initialize zeroed usage buckets on the first call for a given provider. Integer token metrics defensively fall back to 0 if passed falsy or None values. When tracking costs, if any call for a model lacks price metadata (cost is None), the ledger sets cost_known to False, signaling downstream reporting routines in output.py to render costs as unknown (n/a) rather than misleadingly incomplete figures.

    count_event()

    Visibility: Public
    Signature: def count_event(provider: str, event: str) -> None:

    Description: Increments discrete operational anomaly counters ("refusals", "fallbacks", or "truncations") for a specified provider entry within the global usage ledger.

    Parameters: * provider (str): The target provider key in the usage ledger. * event (str): The metric counter to increment; expected to be one of "refusals", "fallbacks", or "truncations".

    Returns: * None

    Raises: * KeyError: If event does not match an existing key in the ledger entry template.

    Example: 

    def count_event(provider: str, event: str) -> None:
    """Increment 'refusals' | 'fallbacks' | 'truncations' for a provider."""
    entry = _usage.setdefault(
        provider,
        {
            "models": set(),
            "calls": 0,
            "input": 0,
            "output": 0,
            "thinking": 0,
            "cache_read": 0,
            "cache_write": 0,
            "cost": 0.0,
            "cost_known": True,
            "refusals": 0,
            "fallbacks": 0,
            "truncations": 0,
        },
    )
    entry[event] += 1
    This function maintains parity between token volume reporting and pipeline operational health. By sharing the initialization structure with record_usage(), it allows events to be recorded before any tokens have been successfully generated—such as during immediate prompt rejections or connection fallback events. Upstream adapters call this helper whenever fallback headers are disabled, responses are truncated at context limits, or refusals are intercepted.

    get_usage_summary()

    Visibility: Public
    Signature: def get_usage_summary() -> dict:

    Description: Generates a consolidated summary of token allocations, costs, and operational events for all providers that processed at least one call during the execution run. Transforms internal sets of model names into lexicographically sorted lists.

    Parameters: * None.

    Returns: * dict: A dictionary mapping provider names to shallow-copied usage records with sorted "models" lists, omitting inactive providers.

    Raises: * N/A.

    Example: 

    def get_usage_summary() -> dict:
    """{provider: totals} for every provider that made at least one call this run."""
    return {provider: dict(entry, models=sorted(entry["models"])) for provider, entry in _usage.items() if entry["calls"]}
    The summary pipeline uses a dictionary comprehension that filters out uncalled providers (if entry["calls"]). It creates a decoupled copy of the internal accumulator using dict(entry, ...), explicitly converting the internal set of model names into a deterministically sorted list. This transformation guarantees stable rendering when generating tables or serialized CLI output summaries.

    reset_usage()

    Visibility: Public
    Signature: def reset_usage() -> None:

    Description: Resets all in-memory usage ledgers and refusal caches, returning the module to an uninitialized state. Primarily intended for automated test suites and isolated execution resets.

    Parameters: * None.

    Returns: * None

    Raises: * N/A.

    Example: 

    def reset_usage() -> None:
    _usage.clear()
    _refused.clear()
    The helper invokes .clear() on both the _usage ledger and _refused map in-place. This guarantees that subsequent pipeline executions within the same Python process boundary do not retain dirty telemetry or memorized refusals from previous test runs.

    warn_once()

    Visibility: Public
    Signature: def warn_once(key: str, *parts) -> bool:

    Description: Evaluates whether a warning signature has already been displayed during the active process run, tracking compound keys to prevent noisy CLI log duplication.

    Parameters: * key (str): The primary category or message identifier. * *parts (Any): Optional additional hashable values (such as model names or HTTP status codes) forming a composite warning key.

    Returns: * bool: True if this specific warning marker is encountered for the first time; False if it has already been registered.

    Raises: * N/A.

    Example: 

    def warn_once(key: str, *parts) -> bool:
    """True the first time a (key, parts) combination is seen this run."""
    marker = (key, *parts)
    if marker in _warned:
        return False
    _warned.add(marker)
    return True
    The helper constructs a tuple (key, *parts) to serve as a composite hash in the private _warned set. If the marker is already present, the function returns False, allowing caller logging blocks to exit early. When a new marker is encountered, it is recorded in the set and returns True, ensuring that identical warnings (e.g., deprecated parameters, unsupported reasoning flags) are emitted only once per session.

    Internal Helpers

    The utils/llm_common.py module maintains three internal, process-scoped data containers to track runtime state without exposing mutable data structures directly to external modules.

    # ---------------------------------------------------------------------------
# Refused-request memo: a declined prompt is declined again, so PocketFlow retries
# must not re-send it (wasted rate limit, and billed partial output on mid-stream declines).
# ---------------------------------------------------------------------------
_refused = {}

# ---------------------------------------------------------------------------
# Usage ledger (one per process; a run is sequential)
# ---------------------------------------------------------------------------
_usage = {}

# ---------------------------------------------------------------------------
# De-duplicated warnings
# ---------------------------------------------------------------------------
_warned = set()

    _refused

    A process-level dictionary (dict[str, LLMRefusalError]) that maps SHA-256 request signatures generated by request_key() to their corresponding LLMRefusalError instances. It acts as an in-memory cache to prevent repetitive, non-retryable API calls. External modules access this dictionary exclusively through remember_refusal(), previous_refusal(), and reset_usage().

    _usage

    A process-level dictionary (dict[str, dict[str, Any]]) that aggregates operational statistics and token accounting across all active LLM providers. Each entry stores call counts, token usage, cost data, and error metrics. State modifications and reads are restricted to record_usage(), count_event(), get_usage_summary(), and reset_usage().

    _warned

    A process-level set (set[tuple[str, ...]]) containing composite warning markers. It records unique tuples passed to warn_once() to deduplicate warning messages in CLI logs throughout the life of the process.

    Data Structures

    UsageRecord Schema

    The internal dictionary structure maintained for each provider inside the _usage ledger, and exposed in shallow-copied form via get_usage_summary().

    Field Type Description
    models set[str] (internal) / list[str] (summary) Unique model identifiers invoked for this provider during the run.
    calls int Total number of attempted inference calls dispatched.
    input int Total count of input/prompt tokens processed.
    output int Total count of output tokens generated (including thinking tokens).
    thinking int Subset of output tokens dedicated to model reasoning/thinking.
    cache_read int Prompt tokens retrieved directly from provider-side caches.
    cache_write int Prompt tokens written to create new provider-side cache entries.
    cost float Cumulative calculated cost in USD across all calls.
    cost_known bool Flag indicating whether all models used have known pricing metadata (False if any model cost was None).
    refusals int Count of declined requests encountered for this provider.
    fallbacks int Count of times the provider dropped down to secondary models or disabled fallback beta headers.
    truncations int Count of model completions cut off by context or token limits.

    RefusalMemo Schema

    The schema mapping maintained by the _refused dictionary for recording declined requests.

    Key Value Type Description
    SHA-256 digest string (64 characters) LLMRefusalError The captured refusal error instance, preserving model, category, provider, and retryability semantics.

    Error Handling

    The module provides the foundation for error handling across the system's inference layers:

    • Refusal Classification: LLMRefusalError introduces a structured categorization for declined prompts. By dividing errors into retryable=False (fatal declines, policy triggers, deterministic refusals) and retryable=True (transient safety blocks, recitation checks on output candidates), it provides the decision logic necessary for upstream graph nodes to either resample or abandon execution paths.
    • Truncation Signatures: Rather than raising an unhandled exception upon encountering context window limits or maximum token exhaustion, the module provides TruncatedResponse. This string subtype allows pipelines to inspect partial completions, bypass the disk-based cache, and trigger controlled retries via higher-level handlers (such as YAML parsers).
    • Cost Incompleteness Guard: If an invoked model does not have pricing metrics available, record_usage() flags cost_known = False. This prevents the pipeline from displaying inaccurate or partially calculated cost summaries in terminal logs.
