    llm_common.py

    Source: utils/llm_common.py

    Technical Overview

    The utils/llm_common.py module establishes a provider-neutral operational foundation and shared runtime substrate for all Large Language Model (LLM) client interactions across the codebase. It operates completely independently of vendor-specific software development kits (SDKs) such as Anthropic, Google GenAI, or OpenAI, isolating core coordination logic, accounting primitives, and operational state from third-party transport layers. By providing a decoupled core, it standardizes error semantics, truncation flagging, execution-step attribution, telemetry accumulation, and warning deduplication across disparate model backends.

    The architecture of the module centers on three primary mechanisms: a refusal memoization cache, a context-aware usage ledger, and sentinel response typing. Refusal memoization deterministically intercepts repeat requests for prompts that models have rejected on policy grounds, preventing redundant network overhead and unnecessary billing. The usage ledger leverages thread-safe and asynchronous task-safe context variables (contextvars.ContextVar) to transparently attribute prompt tokens, completion tokens, reasoning tokens, cache read/write operations, and estimated USD costs to specific workflow nodes without requiring invasive parameter passing through intermediate layers. Sentinel wrapping through TruncatedResponse enables downstream consumers to detect context window exhaustion while maintaining backward compatibility with standard string APIs.

    Public API

    TruncatedResponse

    Visibility: Public Signature: class TruncatedResponse(str):

    Description: A specialized string subclass used to represent model outputs that were abruptly terminated prior to natural completion due to maximum token boundaries or context window ceilings. Because it inherits directly from str, instances can be passed transparently through text-processing filters, regex evaluators, and string formatting routines without runtime type mismatches. However, the presence of the class attribute truncated = True allows callers such as call_llm to detect incomplete outputs, suppress local persistent caching, and signal upstream orchestrators to initiate retries or resize token allocations.

    class TruncatedResponse(str):
    """Response text from a reply that was cut off; call_llm returns it but never caches it."""

    truncated = True

    The TruncatedResponse class provides an in-band failure signaling mechanism that avoids the overhead and control-flow disruptions of exception unwinding. When an LLM provider indicates that output generation ceased because of a limit cutoff (such as stop_reason == "max_tokens"), the raw text payload is wrapped within this type. Downstream pipeline stages check getattr(response, "truncated", False) to determine whether the response is partial, ensuring that incomplete JSON or truncated YAML payloads do not corrupt persistent caches or trigger malformed parsing errors downstream.

    Visibility: Public Signature: truncated = True

    Description: A class-level boolean constant set to True on all TruncatedResponse instances, providing a direct discriminator for truncated response detection.

    LLMRefusalError

    Visibility: Public Signature: class LLMRefusalError(RuntimeError):

    Description: A specialized runtime exception indicating that a model provider declined to process or complete an inference request. The error encapsulates diagnostic metadata including the originating model name, refusal category, provider identifier, and a critical retryable boolean flag. This flag differentiates between deterministic prompt-level policy rejections (which must not be retried) and transient, sampling-dependent candidate generation blocks (which can be retried with fresh random seeds).

    class LLMRefusalError(RuntimeError):
    """Raised when the provider (and any configured fallback) declines a request.

    retryable=False: the same request is declined again (Claude refusal, blocked prompt,
    prohibited content) — call_llm remembers it and does not re-send it on node retries.
    retryable=True: an output-side block that a new sample can pass (Gemini RECITATION / OTHER /
    SAFETY on the candidate, OpenRouter content_filter) — node retries re-sample normally.
    """

    def __init__(self, model: str, category: str | None, provider: str = "ANTHROPIC", retryable: bool = False):
        self.model = model
        self.category = category
        self.provider = provider
        self.retryable = retryable
        super().__init__(f"{provider} model {model} declined the request (category={category or 'unknown'})")

    The LLMRefusalError standardizes error reporting across diverse provider rejection formats, including Anthropic refusal blocks, Google Gemini safety/recitation candidate suppressions, and OpenRouter moderation content filters. By default, retryable is set to False, signaling to callers like call_llm that the prompt itself triggered the refusal and that repeated submissions will consume rate limits without succeeding. When set to True, the calling pipeline recognizes that the refusal occurred on the generated candidate tokens rather than the input prompt, permitting standard retry mechanisms to attempt a new generation pass.

    request_key()

    Visibility: Public Signature: def request_key(provider: str, model: str, thinking_level: str | None, prompt: str) -> str:

    Description: Generates a deterministic SHA-256 hexadecimal hash string uniquely identifying an inference request configuration. The input parameters are concatenated into a structured scope string followed by the raw prompt body before hashing.

    Parameters: * provider (str): The target provider identifier (e.g., "ANTHROPIC", "GEMINI", "OPENROUTER"). * model (str): The specific model name string. * thinking_level (str | None): Normalized reasoning or thinking effort level (e.g., "low", "high"), falling back to "default" if None. * prompt (str): The complete raw prompt text sent to the model.

    Returns: * str: A 64-character lowercase SHA-256 hexadecimal hash representing the request identity.

    Raises: * No internal exceptions are raised.

    Example: 

    def request_key(provider: str, model: str, thinking_level: str | None, prompt: str) -> str:
    scope = f"{provider}|{model}|{(thinking_level or 'default').lower()}\n"
    return hashlib.sha256((scope + prompt).encode("utf-8")).hexdigest()

    The hashing routine ensures that variations in case sensitivity for thinking_level do not lead to key divergence by converting the value to lowercase. A newline character separates the prefix metadata scope from the prompt text, preventing concatenation collisions between model names and prompt prefixes. This hash serves as the uniform primary key for tracking non-retryable refusal events in the memoization table.

    remember_refusal()

    Visibility: Public Signature: def remember_refusal(key: str, error: LLMRefusalError) -> None:

    Description: Caches a deterministic refusal exception in the module-level refusal dictionary, indexed by the request's unique hash key.

    Parameters: * key (str): The SHA-256 hexadecimal digest generated by request_key(). * error (LLMRefusalError): The refusal exception instance to store for subsequent short-circuiting.

    Returns: * None: No return value.

    Raises: * No internal exceptions are raised.

    Example: 

    def remember_refusal(key: str, error: LLMRefusalError) -> None:

    This function records permanent declinations directly into the in-memory _refused registry. Once registered, any subsequent attempt by pipeline retry loops or concurrent workers to execute the exact same prompt against the same model and thinking configuration can be immediately short-circuited before reaching network sockets or incurring vendor rate-limit penalties.

    usage_step()

    Visibility: Public Signature: def usage_step(step: str | None):

    Description: A context manager that scopes LLM usage metrics to a specified logical pipeline step. It sets the execution context variable _current_step upon entering the context block and resets it to its previous token state upon exit.

    Parameters: * step (str | None): Logical identifier of the execution phase or pipeline node (e.g., "IdentifyAbstractions", "DraftChapters"). If None or empty, defaults to "other".

    Returns: * Generator context manager yielding control to the enclosing block.

    Raises: * No internal exceptions are raised; context resetting is guaranteed via a try...finally construct.

    Example: 

    @contextlib.contextmanager
def usage_step(step: str | None):
    """Attribute every record_usage / count_event inside the block to `step`."""
    token = _current_step.set(step or "other")
    try:
        yield
    finally:
        _current_step.reset(token)

    By leveraging contextvars.ContextVar, usage_step provides concurrency-safe attribution across synchronous and asynchronous execution boundaries. When nested within multiple workflows or execution blocks, the context manager preserves stack state using context tokens. Any invocation of record_usage() or count_event() within the scope of the context automatically maps token and monetary consumption directly to the designated step.

    record_usage()

    Visibility: Public Signature: def record_usage(provider: str, model: str, *, input_tokens: int = 0, output_tokens: int = 0, thinking_tokens: int = 0, cache_read: int = 0, cache_write: int = 0, cost: float | None = None, measured: bool = True) -> None:

    Description: Records metrics from a completed API invocation into the usage ledger. Updates are applied concurrently to both the provider-level bucket and the current step-level bucket.

    Parameters: * provider (str): Vendor identifier for the API provider (e.g., "ANTHROPIC", "GEMINI"). * model (str): Name of the model invoked (e.g., "claude-3-7-sonnet-20250219"). * input_tokens (int): Total prompt tokens counted by the provider, including cached tokens. Defaults to 0. * output_tokens (int): Total completion tokens generated, including reasoning tokens. Defaults to 0. * thinking_tokens (int): Subset of output tokens dedicated to internal reasoning/thinking. Defaults to 0. * cache_read (int): Number of prompt tokens served from provider-side prompt caches. Defaults to 0. * cache_write (int): Number of prompt tokens written to provider-side prompt caches. Defaults to 0. * cost (float | None): Monetary cost in USD for the transaction. If None, the call is flagged as unpriced. Defaults to None. * measured (bool): Flag indicating whether the provider reported actual token counts (True) or if usage went unmeasured/unbilled (False). Defaults to True.

    Returns: * None: No return value.

    Raises: * No internal exceptions are raised.

    Example: 

    def record_usage(
    provider: str,
    model: str,
    *,
    input_tokens: int = 0,
    output_tokens: int = 0,
    thinking_tokens: int = 0,
    cache_read: int = 0,
    cache_write: int = 0,
    cost: float | None = None,
    measured: bool = True,
) -> None:
    """Accumulate one API request. `input_tokens` = total prompt tokens (cached included);
    `output_tokens` includes thinking. `cost` is USD; None = unknown price (counted as unpriced).
    measured=False: the provider reported no usage, or the request was an unbilled decline — it counts
    as a request but is left out of estimate-vs-billed comparisons (`unmeasured_calls`)."""
    for entry in (_usage.setdefault(provider, _new_entry()), _steps.setdefault(current_step(), _new_entry())):
        if model:
            entry["models"].add(model)
        entry["calls"] += 1
        if not measured:
            entry["unmeasured_calls"] += 1
        entry["input"] += input_tokens or 0
        entry["output"] += output_tokens or 0
        entry["thinking"] += thinking_tokens or 0
        entry["cache_read"] += cache_read or 0
        entry["cache_write"] += cache_write or 0
        if cost is None:
            entry["unpriced_calls"] += 1
        else:
            entry["cost"] += cost

    The method uses a single unified loop over both the provider entry in _usage and the current step entry in _steps, guaranteeing synchronized updates across both dimensions. If the cost argument is None, the unpriced_calls counter increments while the total cost remains unchanged, indicating that cost calculation must be treated as incomplete. Unmeasured or unbilled requests (such as early refusals where no billable tokens were reported) increment unmeasured_calls, which allows auditing routines to discount those requests during token estimation discrepancy checks.

    count_event()

    Visibility: Public Signature: def count_event(provider: str, event: str) -> None:

    Description: Increments a named operational event counter across both the provider-level bucket and the currently active step bucket.

    Parameters: * provider (str): Provider identifier (e.g., "ANTHROPIC", "GEMINI"). * event (str): Specific counter attribute key to increment; expected to be one of "refusals", "fallbacks", or "truncations".

    Returns: * None: No return value.

    Raises: * KeyError: If event does not match an existing key initialized in _new_entry().

    Example: 

    def count_event(provider: str, event: str) -> None:
    """Increment 'refusals' | 'fallbacks' | 'truncations' for a provider (and the current step)."""
    _usage.setdefault(provider, _new_entry())[event] += 1
    _steps.setdefault(current_step(), _new_entry())[event] += 1

    This helper centralizes tracking for anomalous or non-standard execution paths. When an adapter catches a server-side fallback, records a refusal, or encounters an output truncation, it dispatches count_event to update diagnostic counters without altering token or pricing fields.

    record_estimate()

    Visibility: Public Signature: def record_estimate(step: str, estimated_input: int, *, cache_hit: bool = False) -> None:

    Description: Records pre-flight token estimations and local cache hits for a specific pipeline step.

    Parameters: * step (str): Logical step identifier. If empty or None, falls back to "other". * estimated_input (int): Number of input tokens estimated prior to network dispatch (e.g., via tiktoken). * cache_hit (bool): Whether the request was served directly from the persistent local cache (True) or dispatched to an API provider (False). Defaults to False.

    Returns: * None: No return value.

    Raises: * No internal exceptions are raised.

    Example: 

    def record_estimate(step: str, estimated_input: int, *, cache_hit: bool = False) -> None:
    """Add call_llm's input estimate for a call (billed or served from the LLM cache) to a step."""
    entry = _steps.setdefault(step or "other", _new_entry())
    if cache_hit:
        entry["cache_hits"] += 1
    else:
        entry["estimated_input"] += estimated_input or 0

    This function allows the pipeline to maintain accurate operational tracking even when network calls are avoided entirely due to cache hits. When cache_hit is True, the cache_hits counter increments, isolating cache performance per step. When cache_hit is False, the estimated input tokens accumulate under estimated_input, enabling telemetry summaries to compare predicted token budgets against final provider-measured tokens.

    usage_snapshot()

    Visibility: Public Signature: def usage_snapshot(provider: str) -> dict:

    Description: Creates a point-in-time copy of a provider's running metrics dictionary, excluding non-numeric collection fields like "models".

    Parameters: * provider (str): Provider identifier to snapshot.

    Returns: * dict: A dictionary containing scalar copies of all tracking fields for the provider, or an initialized zero-state dictionary if the provider has not yet been registered.

    Raises: * No internal exceptions are raised.

    Example: 

    def usage_snapshot(provider: str) -> dict:
    """Copy of a provider's running totals (diff two snapshots to get one call's usage)."""
    entry = _usage.get(provider)
    return {k: v for k, v in entry.items() if k != "models"} if entry else {k: v for k, v in _new_entry().items() if k != "models"}

    Snapshots isolate scalar accounting values before and after individual API requests. By excluding the mutable "models" set from the returned structure, the snapshot contains only numeric values that can be cleanly compared and subtracted across points in time.

    usage_delta()

    Visibility: Public Signature: def usage_delta(before: dict, after: dict) -> dict:

    Description: Computes the arithmetic difference between two usage snapshot dictionaries, producing the net usage incurred between the two snapshots.

    Parameters: * before (dict): Baseline metric dictionary captured via usage_snapshot(). * after (dict): Later metric dictionary captured via usage_snapshot().

    Returns: * dict: A dictionary containing the arithmetic difference (after[key] - before[key]) for each key present in after.

    Raises: * KeyError: If after contains keys missing from before without a fallback default (safeguarded internally via before.get(k, 0)).

    Example: 

    def usage_delta(before: dict, after: dict) -> dict:
    return {k: after[k] - before.get(k, 0) for k in after}

    The function computes delta metrics across individual API requests. Callers capture a baseline snapshot prior to dispatch, execute the LLM invocation, capture a terminal snapshot, and pass both into usage_delta(). This isolates the exact token consumption, cache activity, and monetary cost of a single call even when concurrent or background activity is present.

    get_usage_summary()

    Visibility: Public Signature: def get_usage_summary() -> dict:

    Description: Compiles a comprehensive usage report covering all providers that completed at least one API call during the current execution.

    Parameters: * None.

    Returns: * dict: A dictionary mapping provider strings to serialized public usage records formatted by _public().

    Raises: * No internal exceptions are raised.

    Example: 

    def get_usage_summary() -> dict:
    """{provider: totals} for every provider that made at least one call this run."""

    The resulting dictionary excludes providers that were registered but made zero actual API calls. The internal records are converted using _public(), which transforms internal sets into sorted lists and appends boolean completeness flags, making the output suitable for JSON serialization and diagnostic logging.

    get_step_summary()

    Visibility: Public Signature: def get_step_summary() -> dict:

    Description: Compiles an ordered dictionary of usage metrics grouped by execution step for all steps that incurred either active API calls or cache hits.

    Parameters: * None.

    Returns: * dict: A dictionary mapping step name strings to their serialized public usage records formatted by _public().

    Raises: * No internal exceptions are raised.

    Example: 

    def get_step_summary() -> dict:

    Because Python 3.7+ preserves dictionary insertion order, get_step_summary() returns steps in their exact sequence of first encounter during pipeline execution. Steps that executed entirely out of local disk cache (where calls == 0 but cache_hits > 0) are retained in the summary, ensuring visibility into all active phases of the pipeline.

    warn_once()

    Visibility: Public Signature: def warn_once(key: str, *parts) -> bool:

    Description: Evaluates whether a warning signature has already been registered during the current process run. If the signature is new, it records it and returns True; otherwise, it returns False.

    Parameters: * key (str): Primary category identifier or format template string for the warning. * *parts: Variable length positional arguments forming the unique context tuple (e.g., model name, error code).

    Returns: * bool: True if this is the first time the specific (key, *parts) marker has been encountered; False if it was previously recorded.

    Raises: * No internal exceptions are raised.

    Example: 

    def warn_once(key: str, *parts) -> bool:
    """True the first time a (key, parts) combination is seen this run."""
    marker = (key, *parts)

        return False
    _warned.add(marker)
    return True

    The function deduplicates repetitive warning logs that can occur during tight loops or extensive batch operations. By verifying warnings against the internal _warned set, callers ensure that transient conditions (such as missing pricing tables or deprecated model headers) are logged only once per run, preventing terminal log spam.

    _public()

    Visibility: Private Signature: def _public(entry: dict) -> dict:

    The helper ensures internal mutable sets are converted into deterministic, JSON-serializable sorted lists.     Error Handling

    The module provides specialized mechanisms for handling two distinct categories of model failure: policy-driven declinations and token-limit truncations.

    Policy Refusals and Memoization

    When an LLM provider explicitly rejects an inference prompt on safety, compliance, or moderation grounds, it signals that the request cannot be fulfilled under the requested parameters. The module manages this via LLMRefusalError, differentiating between two operational modes:

    1. Non-Retryable Declinations (retryable=False): Used when the refusal is triggered deterministically by the prompt content (such as Claude safety refusals or blocked input keywords). The error is cached in _refused via remember_refusal(), indexed by the SHA-256 digest from request_key(). When subsequent attempts or pipeline retry loops encounter the same prompt and parameters, previous_refusal() matches the cached entry and short-circuits execution immediately, preventing repeated rate-limit consumption and billed partial generations.
    2. Retryable Output Blocks (retryable=True): Used when the refusal is non-deterministic and triggered by the generated candidate content rather than the input prompt (such as Gemini recitation checks or dynamic safety blocks on output tokens). These errors are not stored in the memoization table, allowing downstream retry handlers to resubmit the prompt with different sampling parameters or random seeds.

    Context and Output Truncation

    When an API provider indicates that generation stopped due to context window or output token limits (e.g., stop_reason == "max_tokens"), raising an exception would disrupt operations where partial output may still be inspectable or repairable. Instead, the module returns a TruncatedResponse instance. This sentinel string allows downstream parsers to check for truncation flags, avoid caching incomplete responses in persistent disk caches, and handle retries or context expansion gracefully.
