    prompts.py

    Source: utils/prompts.py

    Technical Overview

    Operating directly downstream from telemetry logging in output.py and alongside inference routing in call_llm.py, utils/prompts.py provides the prompt templating infrastructure and defensive response parsing pipeline for the entire codebase analysis framework. Large language models (LLMs) frequently produce slightly malformed outputs—such as unquoted YAML indicator characters, unescaped colons in code signatures, incomplete fenced blocks due to context cutoffs, or non-standard index ranges. This module bridges external model inference with strict internal Python data contracts by loading prompt markdown templates, assembling dynamic inline prompts, and executing resilient, multi-tiered parsing algorithms.

    The module implements specialized parsers for critical workflow stages: index resolution (parse_file_index and parse_file_indices), module grouping (parse_grouping_response), and ground-truth fact extraction (parse_facts_response). For structured responses such as YAML, it implements strict pre-validation checks against response truncation markers (e.g., TruncatedResponse emitted by llm_common.py). If standard YAML deserialization fails, the module executes a progressive recovery pipeline—stripping invalid syntax, wrapping raw indicator values, converting plain quotes into YAML block scalar syntax (|-), and isolating broken list elements so that valid entities are salvaged while unparseable items are tallied rather than aborting the pipeline.

    Public API

    parse_file_index()

    Visibility: Public Signature: def parse_file_index(idx_value):

    Description: Extracts the first integer encountered from a loose file index representation returned by an LLM. Large language models often annotate returned index values with explanatory comments (e.g., "3 # path/to/file.py") or return range notations (e.g., "0-3"). This function strips extraneous formatting using regular expressions and returns the first integer found as a primitive int, or None if no numerical digits are present.

    Parameters: * idx_value (Any): The raw index value returned by the LLM, typically an int, str, or composite scalar.

    Returns: * int | None: The first resolved integer from the input, or None if no digits exist.

    Raises: * This function does not raise exceptions; non-digit inputs safely resolve to None.

    Example: 

    def parse_file_index(idx_value):
    """Extract the first integer from an LLM-returned file index value.

    Handles multiple formats the LLM may produce:
    - Plain int: 3
    - Annotated string: "3 # path/to/file.py"
    - Range notation: "0-3" → returns first number only (caller handles ranges)

    Returns:
        int or None if no digits found.
    """
    nums = re.findall(r"\d+", str(idx_value))
    return int(nums[0]) if nums else None
    The implementation converts idx_value to a string and searches for consecutive digit sequences using re.findall(r"\d+", str(idx_value)). If one or more digit sequences are found, the initial sequence is converted to an integer and returned. If the list is empty (such as when passed an empty string, boolean, or prose without numbers), it returns None.

    parse_file_indices()

    Visibility: Public Signature: def parse_file_indices(idx_value) -> list[int]:

    Description: Strictly parses a single entry from a file index collection returned by an LLM, expanding valid single values and ranges into a list of integers. Unlike parse_file_index(), which greedily takes the first digit run, parse_file_indices() guards against path hallucinations (e.g., extracting 2 from src/v2/api.py). It accepts non-negative integers, annotated index strings (e.g., "3 # path"), and ascending range expressions (e.g., "0-3", "4..7", "1 to 5", or expressions using en-dashes \u2013), bounded by a safety threshold of 10,000 entries.

    Parameters: * idx_value (Any): The candidate entry to evaluate, which may be a boolean, integer, string, or arbitrary object.

    Returns: * list[int]: A list of resolved integer file indices. Returns an empty list [] for negative integers, booleans, invalid ranges, or arbitrary prose.

    Raises: * This function does not raise exceptions; invalid inputs fail safely to an empty list.

    Example: 

    def parse_file_indices(idx_value) -> list[int]:
    """Strictly parse one entry of an index list the LLM returned → the indices it names.

    An int, an annotated number ("3 # path") or an ascending range ("0-3", "4..7", expanded). Anything
    else — a negative number, a path with a digit in it (src/v2/api.py), prose — names no index, instead
    of the first digit run picking an unrelated file."""
    if isinstance(idx_value, bool):
        return []
    if isinstance(idx_value, int):
        return [idx_value] if idx_value >= 0 else []
    text = str(idx_value) if isinstance(idx_value, str) else ""
    single = _INDEX_RE.match(text)
    if single:
        return [int(single.group(1))]
    span = _INDEX_RANGE_RE.match(text)
    if span and int(span.group(1)) <= int(span.group(2)) and int(span.group(2)) - int(span.group(1)) < 10000:
        return list(range(int(span.group(1)), int(span.group(2)) + 1))
    return []
    The logic begins by checking for booleans (which inherit from int in Python) and immediately returns an empty list to prevent True and False from resolving to 1 or 0. For integers, it returns a single-item list if non-negative. Strings are matched against _INDEX_RE (^\s*(\d+)\s*(?:#.*)?$) for annotated single numbers, and _INDEX_RANGE_RE (^\s*(\d+)\s*(?:-|\.\.|\u2013|to)\s*(\d+)\s*(?:#.*)?$) for range notations. When a range matches, the span is validated to ensure the start index is less than or equal to the end index and the total span is under 10,000 items, returning an expanded list via range().

    load_prompt_template()

    Visibility: Public Signature: def load_prompt_template(template_name, advanced_mode=False, mode=None):

The directory is selected based on the execution mode: advanced if advanced_mode=True, tutorial by default, or an explicit directory override passed via mode (e.g., api-reference or common). Defaults to False. * mode (str | None, optional): Explicit subdirectory name inside prompts/. Overrides advanced_mode when provided. Defaults to None.

    Returns: * str: Raw text content of the loaded prompt template file.

    Raises: * FileNotFoundError: If the targeted markdown template file does not exist. * OSError: If filesystem permissions prevent reading the file.

    Example: 

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(__file__))), "prompts", prompt_dir, f"{template_name}.md")
    with open(path, encoding="utf-8-sig") as f:
        content = f.read()
    from utils.output import emit_raw

    emit_raw("DEBUG", f"load_prompt_template | loaded '{template_name}.md' from prompts/{prompt_dir}/", dest="LOG")
    return content
    The function navigates two levels up from utils/prompts.py using os.path.dirname to locate the project root, constructing an absolute path to prompts/{prompt_dir}/{template_name}.md. It reads the entire content within a context manager using utf-8-sig. To prevent circular import loops with output.py, emit_raw is lazily imported inside the function scope to record diagnostic log entries.

    parse_yaml_response()

    Visibility: Public Signature: def parse_yaml_response(response):

    Description: Extracts and parses a YAML document embedded within Markdown triple-backtick fences (```yaml ... ```) from an LLM response string. The function first verifies that the response was not cut off by an output token ceiling by inspecting the .truncated attribute (an attribute set by TruncatedResponse instances from llm_common.py). It then isolates the content between the ```yaml opening fence and the closing ``` fence, deserializing it using yaml.safe_load.

    Parameters: * response (str | TruncatedResponse): The raw text response received from an LLM provider.

    Returns: * Any: The deserialized Python data structure (typically a dict or list).

    Raises: * ValueError: Raised if response.truncated is True, if the response does not contain the required Markdown YAML code fence delimiters, or if yaml.safe_load fails to parse the string.

    Example: 

    def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    # A reply cut off at max tokens (llm_common.TruncatedResponse) can still contain a parseable
    # fenced prefix that silently drops items — raise so the node retries instead.
    if getattr(response, "truncated", False):
        raise ValueError("LLM response was truncated before the YAML block completed")
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}") from e
    The method guards against incomplete outputs by checking getattr(response, "truncated", False). Truncated responses could otherwise yield a syntactically valid YAML subset that silently discards downstream entries. It isolates the YAML substring via successive .split() operations and safely deserializes it. If string splitting or parsing raises an exception, it wraps the failure inside a descriptive ValueError.

    parse_grouping_response()

    Visibility: Public Signature: def parse_grouping_response(response):

    Description: Parses the structured response generated by group_modules.md, extracting module groupings across three top-level keys: sections, descriptions, and dependencies. If the entire block fails standard YAML parsing, the function initiates a lenient salvage sequence. It un-backticks invalid YAML role strings (e.g., converting role: `utility` to role: utility) and splits the document into independent top-level key blocks using regex lookaheads. Each block is parsed in isolation, ensuring that a malformed description scalar does not compromise the recovered section list or dependency map.

    Parameters: * response (str | TruncatedResponse): The LLM response string containing fenced YAML with module groupings.

    Returns: * dict: A dictionary containing the recovered top-level keys, guaranteed to contain at least a valid sections list.

    Raises: * ValueError: If the response was truncated, if no ```yaml fence is present, or if the sections list cannot be recovered.

    Example: 

    def parse_grouping_response(response):
    """Parse the group_modules.md reply (sections + descriptions + dependencies).

    When the whole block is not valid YAML, each top-level block (sections:, descriptions:,
    dependencies:) is parsed on its own and the ones that parse are kept, so one malformed
    description costs neither the grouped sidebar nor the dependencies. A section role written in
    backticks (invalid YAML) is unwrapped first. Raises when sections cannot be recovered, and for
    truncated replies.
    """
    try:
        return parse_yaml_response(response)
    except ValueError:
        if getattr(response, "truncated", False) or "```yaml" not in response:
            raise
        yaml_str = response.split("```yaml", 1)[1].split("```", 1)[0]
        yaml_str = re.sub(r"(?m)^(\s*(?:-\s+)?role\s*:\s*)`([^`\n]*)`", r"\1\2", yaml_str)
        parsed = {}
        for chunk in re.split(r"(?m)^(?=(?:sections|descriptions|dependencies)\s*:)", yaml_str):
            try:
                part = yaml.safe_load(chunk)
            except Exception:
                continue
            if isinstance(part, dict):
                parsed.update(part)
        if not isinstance(parsed.get("sections"), list):
            raise ValueError("Failed to parse YAML: no sections list in the grouping reply") from None
        return parsed
    The function delegates to parse_yaml_response() initially. Upon encountering a ValueError, it checks for unrecoverable conditions (truncated flag or missing fences). If recoverable, it extracts the raw YAML substring and cleans invalid backtick syntax using re.sub(). It then segments the string with re.split(r"(?m)^(?=(?:sections|descriptions|dependencies)\s*:)", yaml_str) and parses each chunk independently via yaml.safe_load(). If the aggregated dictionary lacks a valid sections list, a terminal ValueError is raised.

    build_facts_focus_note()

    Visibility: Public Signature: def build_facts_focus_note(lines: list[tuple[int, str]], limit: int = FACTS_FOCUS_LIMIT) -> str:

    Description: Constructs a prompt instruction note for follow-up fact-extraction requests executed by extract_facts.md. When an initial extraction pass omits lines that appear to contain declarations or imports, this helper formats up to limit (defaulting to FACTS_FOCUS_LIMIT = 60) lines into a numbered context block. Lines exceeding _FOCUS_LINE_CHARS (200 characters) are trimmed with an ellipsis to prevent context window bloat while preserving line number citations.

    Parameters: * lines (list[tuple[int, str]]): A list of tuples where each element contains a 1-based line number (int) and the source code string (str). * limit (int, optional): Maximum number of lines to explicitly render in the note. Defaults to FACTS_FOCUS_LIMIT (60).

    Returns: * str: A formatted Markdown instruction block containing line citations and follow-up guidance for the LLM.

    Raises: * This function does not raise exceptions.

    Example: 

    def build_facts_focus_note(lines: list[tuple[int, str]], limit: int = FACTS_FOCUS_LIMIT) -> str:
    """The {focus_note} of an extract_facts.md follow-up: the uncovered lines a first pass left out."""

    def shown_line(text: str) -> str:
        text = text.strip()
        return text if len(text) <= _FOCUS_LINE_CHARS else text[: _FOCUS_LINE_CHARS - 3] + "..."

    shown = "\n".join(f"  {number}: {shown_line(text)}" for number, text in lines[:limit])
    more = f"\n  ... and {len(lines) - limit} more such lines" if len(lines) > limit else ""
    return (
        "FOLLOW-UP: a first pass over this file reported nothing for the lines below, which look like declarations "
        "or imports. Report ONLY the facts on these lines, with the same four lists and rules; a line that is not a "
        "declaration a reader looks up (a local variable, a statement) gets nothing.\n"
        f"Lines:\n{shown}{more}\n"
    )
    The helper defines an inner shown_line() closure that strips whitespace and truncates lines exceeding 200 characters. It formats the visible slice up to limit as indented strings (" {number}: {text}"). If the candidate list exceeds the threshold, an overflow count note ("... and N more such lines") is appended. The resulting string directs the LLM to focus strictly on those line numbers for declaration discovery.

    parse_facts_response()

    Visibility: Public Signature: def parse_facts_response(response, keys: tuple = FACTS_KEYS) -> dict:

    Phase 1: Pre-Validation and Boundary Resolution

    Validates response termination markers and locates opening/closing YAML fences.

        raise ValueError("LLM response was truncated before the YAML block completed")
    match = _FACTS_BLOCK_RE.search(response) or _FACTS_OPEN_RE.search(response)

    Phase 2: Tiered Parsing Strategy

    Executes a multi-tier deserialization ladder progressing from strict text loading to block scalar conversions and item-level salvage routines.

        data = _load_strings(yaml_str)
    except Exception:

            data = _load_strings(_block_quotes(yaml_str))

If standard loading fails, it applies _block_quotes() to rewrite plain scalars into block scalars (|-) and retries. If parsing still fails, it invokes _salvage_yaml_lists(), which breaks down broken lists item by item. Finally, it validates that data is a mapping containing at least one target key.

    Phase 3: Contract Sanitization and Metric Assembly

    Sanitizes the parsed data structures against target schema keys and calculates lost entity metrics.

    for key in keys:
        items = data.get(key)
        items = items if isinstance(items, list) else []
        result[key] = [item for item in items if isinstance(item, dict)]

    This phase iterates across expected schema keys (symbols, dependencies, config, errors by default). For each key, it normalizes None or non-list values to empty lists and filters the list to retain only valid dictionary records (isinstance(item, dict)). Any discarded items are added to the running unparsed counter, which is returned under the "unparsed" key in the result dictionary.

    Internal Helpers

    _load_strings()

    Visibility: Private Signature: def _load_strings(text: str):

    Description: Wraps yaml.load using yaml.BaseLoader. Standard YAML parsers automatically cast numeric values, version tags, and booleans (e.g., 404, 3.10, on, yes) into integers, floats, or boolean primitives. When parsing fact extractions, these tokens represent code symbols, configuration keys, or HTTP status codes that must remain exact string representations. yaml.BaseLoader guarantees that every scalar is preserved as a primitive str.

    Parameters: * text (str): The raw YAML string to deserialize.

    Returns: * Any: A deserialized data structure composed strictly of str, list, and dict types.

    Raises: * yaml.YAMLError: If the provided text contains unrecoverable YAML syntax errors.

    Example: 

    def _load_strings(text: str):
    """YAML with every scalar kept as the reply's text: 404, on, 3.10 stay strings."""
    return yaml.load(text, Loader=yaml.BaseLoader)  # BaseLoader builds only str / list / dict: safe
    The helper directly calls yaml.load(text, Loader=yaml.BaseLoader). This avoids unintended type coercion (such as converting string ports or semantic version keys into floats) while protecting against unsafe object instantiation vulnerabilities present in yaml.Loader or yaml.FullLoader.

    _quote_indicator_values()

    Visibility: Private Signature: def _quote_indicator_values(text: str) -> str:

    Description: Sanitizes unquoted YAML indicator characters appearing at the start of scalar values. LLMs frequently output code identifiers like @acme/api, #db/*, or *args without quotes. In standard YAML syntax, characters such as @, `, #, *, &, !, and % are reserved indicators representing aliases, comments, or tags. This function applies _INDICATOR_VALUE_RE across key fields (name, entry, alias, target, base, parent), wrapping bare indicator values in escaped double quotes before YAML deserialization occurs.

    Parameters: * text (str): The raw YAML string to sanitize.

    Returns: * str: The sanitized YAML string with problematic scalar values safely enclosed in double quotes.

    Raises: * This function does not raise exceptions.

    Example: 

    def _quote_indicator_values(text: str) -> str:
    return _INDICATOR_VALUE_RE.sub(lambda m: m[1] + '"' + m[2].replace("\\", "\\\\").replace('"', '\\"') + '"', text)
    The regex _INDICATOR_VALUE_RE locates lines beginning with designated keys followed by indicator symbols. The substitution callback isolates the key prefix (m[1]) and raw value (m[2]), escapes backslashes and double quotes within the value, and encloses it in double quotes ("). Valid block indicators (such as target: |-) are matched by a negative lookahead and left unquoted.

    _block_quotes()

    Visibility: Private Signature: def _block_quotes(text: str) -> str:

    Description: Transforms unquoted single-line code quotes into YAML block scalars. When LLMs output code signatures or evidence strings (e.g., signature: def run(self):), the embedded colons or trailing hashes cause standard YAML parsers to fail. This function identifies single-line signature: and evidence: declarations that are not already valid whole scalars and rewrites them into literal block scalar format (|-) with appropriate indentation.

    Parameters: * text (str): Raw YAML text containing potentially malformed code quotes.

    Returns: * str: Rewritten YAML text where plain quotes are converted to indented block scalars.

    Raises: * This function does not raise exceptions.

    Example: 

    def _block_quotes(text: str) -> str:
    return _PLAIN_QUOTE_RE.sub(lambda m: m[0] if _WHOLE_SCALAR_RE.match(m[3]) else f"{m[1]}{m[2]}: |-\n{' ' * (len(m[1]) + 2)}{m[3]}", text)
    The function scans the text using _PLAIN_QUOTE_RE. If the captured value (m[3]) matches _WHOLE_SCALAR_RE (indicating it is already an enclosed quoted string or a valid block indicator), it is left untouched. Otherwise, it generates a block indicator |-, inserts a newline, and indents the quote value by two spaces beyond the key's margin (len(m[1]) + 2).

    _salvage_yaml_lists()

    Visibility: Private Signature: def _salvage_yaml_lists(yaml_str: str, keys: tuple) -> tuple[dict, int]:

    Description: Executes fine-grained salvage operations on severely malformed YAML payloads by decomposing the document into isolated chunks and individual list items. It splits the document at top-level key boundaries (keys). If a top-level block fails to parse, it splits the list body at item bullet boundaries (-). Each item is individually parsed with _load_strings(), collecting valid dictionary items while tallying failed entries in an unparsed counter.

    Parameters: * yaml_str (str): The corrupted YAML string that failed full document parsing. * keys (tuple[str, ...]): Expected top-level keys to split and salvage (e.g., FACTS_KEYS).

    Returns: * tuple[dict, int]: A 2-tuple containing: 1. dict: A dictionary mapping recovered section keys to lists of successfully parsed dictionary items. 2. int: The count of individual list items that failed parsing.

    Raises: * This function does not raise exceptions; corrupted fragments increment the loss counter.

    Example: 

    def _salvage_yaml_lists(yaml_str: str, keys: tuple) -> tuple[dict, int]:
    """Parse each top-level key: list of a broken YAML block on its own; a list that still fails is
    parsed item by item (split at its own -  indentation) and keeps the items that parse.
    Returns (lists, number of items lost)."""
    names = "|".join(keys)
    parsed, lost = {}, 0
    for chunk in re.split(rf"(?m)^(?=(?:{names})\s*:)", yaml_str):
        head = re.match(rf"({names})\s*:", chunk)
        if not head:
            continue
        try:
            part = _load_strings(chunk)
        except Exception:
            part = None
        if isinstance(part, dict):
            parsed.update(part)
            continue
        body = chunk[head.end() :]
        first = re.search(r"(?m)^([ \t]*)- ", body)
        if not first:
            continue
        indent = first.group(1)
        items = []
        for piece in re.split(rf"(?m)^(?={re.escape(indent)}- )", body):
            if not piece.startswith(f"{indent}- "):
                continue
            text = "\n".join(line.removeprefix(indent) for line in piece.split("\n"))
            try:
                item = _load_strings(text)
            except Exception:
                lost += 1
                continue
            if isinstance(item, list) and item and isinstance(item[0], dict):
                items.append(item[0])
            else:
                lost += 1
        parsed[head.group(1)] = items
    return parsed, lost
    The helper constructs a regular expression from the provided keys tuple to split top-level sections via lookaheads. If an entire section parses as a valid dictionary, it is merged immediately into parsed. If section parsing fails, it determines the item bullet indentation (indent) and splits the section body into individual items. Each item is stripped of base indentation and parsed independently. Successfully resolved dictionary items are added to items, while invalid items increment lost.

    Error Handling

    utils/prompts.py enforces a defensive parsing philosophy: whenever an LLM response fails standard deserialization, the module uses progressive fallback strategies to salvage valid information before raising an error.

    • Truncation Pre-emption: LLM completions that reach model context ceilings (marked with truncated = True on TruncatedResponse instances from llm_common.py) can contain partially formed YAML blocks that appear syntactically valid but omit data. Both parse_yaml_response() and parse_facts_response() verify getattr(response, "truncated", False) before executing parse logic, immediately raising a ValueError so pipeline nodes retry instead of continuing with incomplete outputs.

    • Progressive YAML Recovery: When deserializing facts responses in parse_facts_response(), the system applies a three-tiered recovery ladder:

    • Strict Load: Pre-quotes indicator characters via _quote_indicator_values() and attempts standard loading via _load_strings().
    • Scalar Conversion: If strict loading fails, plain scalars in code quotes are converted to block scalars via _block_quotes().

    • Item-Level Salvage: If the block remains unparseable, _salvage_yaml_lists() segments the text into independent sections and item bullets, isolating malformed lines while capturing valid entries.

    • Non-Blocking Index Resolution: In parse_file_indices(), ambiguous or invalid inputs (such as paths containing embedded version numbers like src/v2/api.py, negative indices, or ranges exceeding 10,000 items) do not raise exceptions. They safely evaluate to empty lists ([]), preventing index extraction failures from interrupting file filtering workflows.
