    call_llm.py

    Source: utils/call_llm.py

    Technical Overview

    The utils/call_llm.py module serves as the primary LLM interaction layer and caching facade for the Codebase Knowledge Builder pipeline. It exposes a unified entry point, call_llm(), that routes prompt requests to configured LLM providers—including Anthropic Claude, Google Gemini, OpenRouter, and generic OpenAI-compatible APIs (such as local Ollama instances). The module handles provider configuration resolution, model sampling constraints, thinking/reasoning effort adjustments, token usage accounting, and cached response persistence.

    To optimize operational cost and turnaround time during iterative documentation generation, utils/call_llm.py implements an in-memory singleton cache backed by an atomic file-persisted JSON store (llm_cache_v2.json). Cache keys are calculated using SHA-256 hashes scoping the prompt against the active provider, model name, and thinking level. Responses flagged as truncated or empty are strictly excluded from the cache to prevent persistent serialization of broken generation states.

    The module also integrates tightly with pipeline tracking systems. It records pre-call token estimates, intercepts and records provider refusals to short-circuit redundant retries, snapshots ledger usage deltas before and after network operations, and surfaces real-time usage metrics and cost calculations through the unified utils.output console emission system.

    Public API

    cache_file

    Visibility: Public

    Signature: cache_file = "llm_cache_v2.json"

    Description: The file path for the active version 2 JSON response cache. Responses in this file are keyed by SHA-256 hashes generated from the provider, model, thinking level, and prompt content.

    LEGACY_CACHE_FILE

    Visibility: Public

    Signature: LEGACY_CACHE_FILE = "llm_cache.json"

    Description: Constant holding the filename of the deprecated pre-v2 cache file. This file is retained only for startup detection and cleanup checks; it is never read for responses during runtime.

    Description: Loads the disk-based JSON cache into the global singleton _cache. If _cache is already populated in memory, it is returned immediately.     • None.

    Returns:

    • dict: In-memory dictionary containing cached SHA-256 hash keys mapped to cached response strings.

    Raises:

    • Does not raise exceptions; handles FileNotFoundError, json.JSONDecodeError, and OSError internally.

    save_cache()

    Visibility: Public

    Signature: def save_cache(cache):

    Description: Updates the in-memory singleton _cache and commits the dictionary to disk. To prevent cache file corruption if the process is terminated mid-write, the data is dumped into a temporary file (llm_cache_v2.json.tmp) and then atomically moved into place using os.replace.

    Parameters:

    • cache (dict): The dictionary of hash keys mapped to response strings to persist.

    Returns:

    • None

    Raises:

    • Does not raise exceptions; catches OSError and TypeError and emits a warning message.

    cache[key] = response_text
    save_cache(cache)
    emit_raw("DEBUG", "CACHE WRITE | saved response to cache", dest="LOG")

    The function assigns the updated cache dictionary back to the global _cache variable, writes the serialized JSON output to a temporary staging file, and performs an atomic rename via os.replace to safeguard existing cache entries against unexpected pipeline termination.

    call_llm()

    Visibility: Public

    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None, step: str | None = None) -> str:

    Description: Main entry point for submitting prompt requests across the pipeline. It resolves active provider settings, computes cache keys, verifies prior refusal state, routes calls to provider implementations, calculates usage deltas, and saves valid responses to disk.

    Parameters:

    • prompt (str): The full text prompt to send to the language model.
    • use_cache (bool, optional): Whether to check and write to the local response cache. Defaults to True.
    • thinking_level (str | None, optional): Desired reasoning effort or budget (e.g., "low", "medium", "high"). Defaults to None.
    • step (str | None, optional): Node identifier used for usage ledger categorization and reporting. Defaults to None (mapped internally to "other").

    Returns:

    • str: The text response returned by the language model. May be an instance of TruncatedResponse if the model terminated due to length constraints.

    Raises:

    • LLMRefusalError: If the LLM provider explicitly rejects the request.
    • ValueError: If required environment variables are absent.
    • RuntimeError: If provider APIs return malformed responses.
    • Exception: On network timeouts, connection drops, or HTTP communication errors.

    Phase 1: Configuration and Cache Lookup

        step = step or "other"
    provider, model, _, _ = resolve_llm_settings()
    prompt_tokens = count_tokens(prompt)  # memoized: the node already counted this prompt

    emit_raw("DEBUG", f"{'=' * 80}", dest="LOG")
    emit_raw(
        "DEBUG",
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}",
        dest="LOG",
    )
    emit_raw("DEBUG", f"PROMPT:\n{prompt}", dest="LOG")

    # Check cache if enabled
    key = _cache_key(prompt, provider, model, thinking_level)
    if use_cache:
        cache = load_cache()
        if key in cache:
            cached_response = cache[key]
            emit("CACHE_HIT", chars=f"{len(cached_response):,}")
            record_estimate(step, prompt_tokens, cache_hit=True)
            emit("LLM_CALL_CACHED", step=step, estimate=f"{prompt_tokens:,}")
            emit_raw("DEBUG", f"RESPONSE (cached):\n{cached_response}", dest="LOG")
            emit_raw("DEBUG", "LLM CALL END | result=cache_hit", dest="LOG")
            return cached_response
        emit("CACHE_MISS")

    The function resolves the provider configuration using resolve_llm_settings(), calculates the prompt token count, and writes trace diagnostics to the debug log. If use_cache is enabled, it generates a hash key via _cache_key() and verifies whether a cached response exists. On a cache hit, it updates token estimates, emits cache hit notifications, logs the response, and returns the cached string immediately without invoking any external API.

    Phase 2: Refusal Checking

        # A request the provider already declined this run is declined again: do not re-send it on
    # node retries (rate limits, billed partial output). The node retry still sees the error.
    refusal_key = request_key(provider, model, thinking_level, prompt)
    refused = previous_refusal(refusal_key)
    if refused is not None:
        emit_raw("DEBUG", "LLM CALL END | result=refused_before (not re-sent)", dest="LOG")
        raise refused

    Before dispatching an outbound network request, the function generates a request identifier via request_key() and checks if this specific prompt and model configuration previously experienced a non-retryable refusal during this run. If a prior refusal exists in the memory store, it skips making duplicate network calls and immediately raises the stored LLMRefusalError.

    Phase 3: Provider Execution and Usage Accounting

        # Make the actual LLM call
    start_time = time.time()
    emit_raw("DEBUG", f"API CALL | sending request to {provider}...", dest="LOG")

    # Usage of this call = ledger delta for the provider: it includes every billed request the call
    # made (Anthropic truncation retry, resend after fallbacks were disabled), even when it raises.
    before = usage_snapshot(provider)
    returned = False
    try:
        with usage_step(step):
            if provider == "GEMINI":
                response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
            elif provider == "ANTHROPIC":
                response_text = _call_llm_anthropic(prompt, thinking_level=thinking_level)
            elif provider == "OPENROUTER":
                response_text = _call_llm_openrouter(prompt, thinking_level=thinking_level)
            else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
                response_text = _call_llm_provider(prompt, thinking_level=thinking_level)
        returned = True
    except LLMRefusalError as e:
        if not e.retryable:
            remember_refusal(refusal_key, e)
        raise
    finally:
        call_usage = usage_delta(before, usage_snapshot(provider))
        measured = call_usage["calls"] - call_usage["unmeasured_calls"]
        if measured:
            record_estimate(step, prompt_tokens * measured)
            _emit_call_usage(step, prompt_tokens, call_usage, measured)
        elif returned:  # answered, but the provider reported no usage
            emit("LLM_CALL_USAGE_MISSING", step=step, estimate=f"{prompt_tokens:,}")

    Execution snapshots the current provider token usage via usage_snapshot() and routes the call to the appropriate internal provider function inside a usage_step(step) context manager. If a non-retryable LLMRefusalError occurs, it registers the error via remember_refusal() before re-raising. In the finally block, the function computes the differential ledger delta using usage_delta(), records prompt estimates, and emits per-call token usage and cost metrics.

    Phase 4: Cache Write and Finalization

        elapsed = time.time() - start_time
    emit_raw("DEBUG", f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}", dest="LOG")
    emit_raw("DEBUG", f"RESPONSE:\n{response_text}", dest="LOG")

    # Update cache if enabled. Empty and truncated responses (llm_common.TruncatedResponse)
    # are never cached — they would be replayed on every later run.
    if use_cache and response_text and not getattr(response_text, "truncated", False):
        cache = load_cache()
        cache[key] = response_text
        save_cache(cache)
        emit_raw("DEBUG", "CACHE WRITE | saved response to cache", dest="LOG")

    emit_raw("DEBUG", f"LLM CALL END | result=success | elapsed={elapsed:.1f}s", dest="LOG")
    return response_text

    After completion of the API call, the elapsed time and response size are logged. If caching is enabled, the response text is non-empty, and the object is not marked as truncated (truncated=False), the new result is persisted to disk via save_cache(). Finally, the raw response string (or TruncatedResponse wrapper) is returned to the caller.

    _cache_key()

    Visibility: Private

    Signature: def _cache_key(prompt: str, provider: str, model: str, thinking_level: str | None) -> str:

    Description: Generates an isolated SHA-256 digest string based on the provider, model name, normalized thinking level, and prompt string. This ensures responses cached under one model or reasoning setting are never returned for a different configuration.

    Parameters:

    • prompt (str): The raw prompt input.
    • provider (str): Active provider identifier (e.g., "ANTHROPIC").
    • model (str): Configured model identifier (e.g., "claude-sonnet-5").
    • thinking_level (str | None): Reasoning effort string or None.

    Returns:

    • str: Hexadecimal digest string representing the SHA-256 hash.

    Raises:

    • None.

    Example:

    def _cache_key(prompt: str, provider: str, model: str, thinking_level: str | None) -> str:
    scope = f"{provider}|{model}|{(thinking_level or 'default').lower()}\n"
    return hashlib.sha256((scope + prompt).encode("utf-8")).hexdigest()

    The helper formats a scoping string containing the provider, model, and lowercase thinking level (defaulting to "default"), joins it with the prompt separated by a newline, encodes the concatenated string to UTF-8 bytes, and computes the hex digest via hashlib.sha256().

    _call_llm_provider()

    Visibility: Private

    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Executes calls against generic OpenAI-compatible HTTP endpoints (such as local Ollama deployments or custom inference servers). It reads endpoint URLs and API keys from environment variables, adjusts reasoning parameters, makes synchronous HTTP requests via requests.post, and parses output choices and token usage.

    Parameters:

    • prompt (str): The prompt string to submit.
    • thinking_level (str | None, optional): Reasoning effort level (e.g., "low", "medium", "high"). Defaults to None.

    Returns:

    • str: Extracted response text, wrapped in TruncatedResponse if finish_reason == "length".

    Raises:

    • ValueError: If LLM_PROVIDER, model, or base URL environment variables are unset, or if invalid JSON is returned.
    • RuntimeError: If the returned JSON response lacks the required 'choices' field.
    • Exception: On network connection failures, request timeouts, or HTTP status error codes.

    Phase 1: Environment Validation and Setup

        # Read the provider from environment variable
    provider = get_llm_provider()
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    # Read the provider-specific variables
    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

    # Validate required variables
    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"

    The function fetches the active provider name using get_llm_provider(). It constructs dynamic environment variable keys based on that provider name (e.g., OLLAMA_MODEL, OLLAMA_BASE_URL), ensures mandatory configuration values are present in the environment, and normalizes the target endpoint to end in /v1/chat/completions.

    Phase 2: Payload and Thinking Effort Assembly

        # Configure headers and payload based on provider
    headers = {
        "Content-Type": "application/json",
    }
    if api_key:  # Only add Authorization header if API key is provided
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OLLAMA" and thinking_level:
        # Ollama reasoning models accept low/medium/high; xhigh/max clamp to high.
        # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
        effort = _clamp_level(thinking_level.lower(), ["low", "medium", "high"]) or "medium"
        payload["think"] = effort
        payload["reasoning_effort"] = effort
        payload["temperature"] = 1.0

    if rejects_sampling_params(model):
        # Claude Opus 4.7+ / Opus 5.x / Sonnet 5 / Fable reject sampling parameters (400).
        payload.pop("temperature", None)

    The HTTP headers and base payload are constructed with a default temperature of 0.7. If the provider is "OLLAMA" and a thinking_level is provided, the value is clamped to "low", "medium", or "high", and applied to both think and reasoning_effort payload fields while setting temperature to 1.0. Models that reject sampling parameters (checked via rejects_sampling_params()) have their temperature field stripped to prevent 400 Bad Request responses.

    Phase 3: HTTP Dispatch and Response Validation

        try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        response.raise_for_status()  # HTTP status first: an HTML 502 page must not look like a JSON bug
        try:
            response_json = response.json()
        except (ValueError, requests.exceptions.JSONDecodeError):
            from utils.output import emit

            emit(
                "WARN_INVALID_JSON",
                status_code=response.status_code,
                preview=response.text[:200].strip(),
            )
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None

        # Defensive check: API may return 200 with error/rate-limit payload missing 'choices'
        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            from utils.output import emit

            emit("WARN_API_NO_CHOICES", detail=str(error_detail))
            raise RuntimeError(f"API response missing 'choices' key. Response: {error_detail}")

    The request is sent using requests.post with a connection timeout of 10 seconds and read timeout of 300 seconds. Status codes are checked immediately using raise_for_status(). The response body is decoded into JSON, raising an explicit ValueError if parsing fails. A defensive check verifies that the returned JSON contains a non-empty choices list; if missing, an error is logged and a RuntimeError is raised.

    Phase 4: Token Usage Accounting and Output Parsing

            usage = response_json.get("usage") or {}
        from utils.llm_common import record_usage
        from utils.token_utils import count_tokens_raw, observe_prompt_tokens

            cache_read=(usage.get("prompt_tokens_details") or {}).get("cached_tokens") or 0,
            cost=None,
            measured=bool(usage),
        )
        if usage:
            observe_prompt_tokens(provider, model, count_tokens_raw(prompt), prompt_tokens)
        choice = response_json["choices"][0]
        text = (choice.get("message") or {}).get("content") or ""
        if choice.get("finish_reason") == "length":
            from utils.llm_common import TruncatedResponse

            return TruncatedResponse(text)
        return text
    except requests.exceptions.HTTPError as e:
        error_message = f"HTTP error occurred: {e}"
        try:
            error_details = response.json().get("error", "No additional details")
            error_message += f" (Details: {error_details})"
        except Exception:
            pass
        raise Exception(error_message) from e
    except requests.exceptions.ConnectionError as e:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
    except requests.exceptions.Timeout as e:
        raise Exception(f"Request to {provider} API timed out.") from e
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
    except ValueError as e:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e

    Token metrics from the usage block are recorded via record_usage() and benchmarked via observe_prompt_tokens(). The message content is extracted from the first choice object. If the API indicates completion stopped due to max tokens (finish_reason == "length"), the text is returned as a TruncatedResponse object. The function includes structured exception handlers for HTTP, connection, timeout, and request errors, wrapping them in descriptive Exception instances.

    Visibility: Private

    Signature: def _emit_call_usage(step: str, estimate: int, usage: dict, measured: int) -> None:

    Description: Emits a formatted single-line log detailing token utilization and financial cost for a completed LLM call. Calculates percentage deviation between the estimated input tokens and actual measured billed tokens, and reports input, output, thinking, cached tokens, and total cost.

    Parameters:

    • step (str): Name of the executing workflow node.
    • estimate (int): Pre-computed token count estimate.
    • usage (dict): Usage ledger dictionary containing token metrics.
    • measured (int): Count of underlying API requests that reported measured usage.

    Returns:

    • None

    Raises:

    • None.

    Example:

    def _emit_call_usage(step: str, estimate: int, usage: dict, measured: int) -> None:
    """One console line per LLM call: billed input vs the estimate, output (thinking), cached, cost.
    `measured` = requests with provider-reported usage (the deviation is per measured request)."""
    from utils.output import emit, get
    from utils.token_utils import format_cost

    per_request = usage["input"] / measured
    deviation = f"{(per_request - estimate) / estimate:+.0%}" if estimate else get("CFG_VALUE_UNKNOWN")
    emit(
        "LLM_CALL_USAGE",
        step=step,
        input=f"{usage['input']:,}",
        estimate=f"{estimate:,}",
        deviation=deviation,
        requests=get("LLM_CALL_REQUESTS", count=measured) if measured > 1 else "",
        output=f"{usage['output']:,}",
        thinking=f"{usage['thinking']:,}",
        cached=f"{usage['cache_read']:,}",
        cost=format_cost(usage),
    )

    The helper calculates average per-request input token usage by dividing total input tokens by the number of measured requests. It calculates deviation against the initial estimate, formats numeric quantities with comma separators, and triggers the LLM_CALL_USAGE event via emit().

    Error Handling

    utils/call_llm.py standardizes provider error handling into predictable behavior:

    • Missing Configuration: If LLM_PROVIDER, <provider>_MODEL, or <provider>_BASE_URL are not defined when calling generic providers, a ValueError is raised immediately before issuing network requests.
    • Missing Dependencies: When Anthropic or Gemini providers are invoked without their corresponding SDKs installed (anthropic, google-genai), the module traps ImportError and raises an ImportError with an explicit installation message (pip install -r requirements.txt).
    • Provider Refusals: If an LLM explicitly refuses a prompt (represented by LLMRefusalError), the module catches the error, checks if it is marked as non-retryable, registers it in the refusal cache via remember_refusal(), and re-raises it. Future attempts to dispatch the identical prompt within the same session raise the cached error immediately.
    • Malformed API Responses: In _call_llm_provider(), invalid JSON payloads trigger WARN_INVALID_JSON and raise a ValueError. Responses missing the 'choices' array trigger WARN_API_NO_CHOICES and raise a RuntimeError.
    • Network & HTTP Failures: Network exceptions (requests.exceptions.HTTPError, requests.exceptions.ConnectionError, requests.exceptions.Timeout) are caught, enriched with any diagnostic error messages returned by the remote API, and wrapped in descriptive Exception instances.
    • Cache Fault Tolerance: Failures encountered while loading or saving cache files (FileNotFoundError, json.JSONDecodeError, OSError, TypeError) log warnings through emit("WARN_CACHE_LOAD_FAIL") or emit("WARN_CACHE_SAVE_FAIL") rather than aborting execution. Truncated or empty responses are ignored during cache writes.
