    call_llm.py

    Source: utils/call_llm.py

    Overview

    Following the foundational package initialization defined in __init__.py, call_llm.py serves as the primary inference client and multi-provider bridge for the Codebase-Knowledge-Builder system. It abstracts model communication across diverse backend providers—including Google Gemini (native and Vertex AI), OpenRouter, and Ollama—into a unified programmatic interface.

    The module encapsulates prompt serialization, token accounting, persistent response caching, reasoning/thinking budget control, model capability discovery, and robust error handling. Upstream orchestration components, such as nodes.py and flow.py, invoke call_llm.py to analyze codebase architectures, parse module hierarchies, synthesize documentation sections, and evaluate repository artifacts without coupling internal workflow logic to specific external APIs.

    def get_llm_provider():

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description:
    Fetches and caches model metadata from the OpenRouter public API endpoint (https://openrouter.ai/api/v1/models). The response payload is stored in the global _openrouter_models_cache variable to avoid network overhead on subsequent calls. It searches the cached model list for a model whose id attribute matches model_id.

    Parameters:
    * model_id (str): The unique identifier of the model (e.g., "anthropic/claude-3.7-sonnet" or "deepseek/deepseek-r1").

    Returns:
    * dict | None: The dictionary containing model capabilities, supported reasoning efforts, and context limits, or None if not found or if the request fails.

    Raises:
    * Does not raise exceptions; network errors and JSON parsing exceptions populate _openrouter_models_cache with an empty list.

    Implementation: 

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The function applies a short 5-second timeout to prevent blocking during network latency. The iterator next(...) searches the list of model dictionaries and returns the matching dictionary or defaults to None.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description:
    Computes or queries the maximum supported token context window for a given model and endpoint. If the endpoint corresponds to Google Generative Language or contains "gemini" in the model name, it returns 1,000,000 tokens. For OpenRouter endpoints, it queries https://openrouter.ai/api/v1/models and extracts the model's context_length field. If resolution fails or the endpoint is unrecognized, it falls back to a safe default of 100,000 tokens.

    Parameters:
    * endpoint_url (str): The base URL or target endpoint of the inference service. * model_name (str): The model name/identifier string. * api_key (str, optional): The authorization API key if required by the remote endpoint. Defaults to "".

    Returns:
    * int: The maximum token capacity for the model.

    Raises:
    * Does not raise exceptions; network or parsing errors are logged as warnings and return 100000.

    Implementation: 

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    """
    Fetch the maximum context length of a model based on the endpoint.
    If endpoint is Gemini API, safely default to 1,000,000 tokens.
    If endpoint is openrouter.ai, make GET to /api/v1/models and extract.
    Default to 100,000.
    """
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This method is utilized during repository ingestion and file crawling to prevent prompt token counts from exceeding provider limits before invoking inference.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Executes a generic HTTP request to an OpenAI-compatible /v1/chat/completions endpoint for providers such as OpenRouter or Ollama. It reads provider configuration variables dynamically (<PROVIDER>_MODEL, <PROVIDER>_BASE_URL, and <PROVIDER>_API_KEY), configures reasoning parameters based on thinking_level, posts the payload, and validates the response JSON structure.

    Parameters:
    * prompt (str): The raw text prompt to transmit to the model. * thinking_level (str | None, optional): Desired reasoning effort (e.g., "low", "medium", "high"). Defaults to None.

    Returns:
    * str: The textual completion content returned by the LLM.

    Raises:
    * ValueError: If LLM_PROVIDER, <PROVIDER>_MODEL, or <PROVIDER>_BASE_URL are missing from the environment, if the provider returns invalid JSON, or if the response lacks the expected "choices" structure. * Exception: If an HTTP error, network connection error, or timeout occurs during the request.

    Implementation (Configuration and Reasoning Payload Setup): 

        # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    # Read the provider-specific variables
    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

    # Validate required variables
    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"

    # Configure headers and payload based on provider
    headers = {
        "Content-Type": "application/json",
    }
    if api_key:  # Only add Authorization header if API key is provided
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0  # Required for many reasoning models
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    The function inspects dynamic environment variables using the resolved provider prefix. When thinking_level is provided for OpenRouter, it verifies that the model's metadata supports the requested effort level before injecting {"reasoning": {"effort": ...}} and adjusting temperature to 1.0. For Ollama, it sets both think and reasoning_effort parameters to maintain compatibility across different Ollama runtime versions.

        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))

It also performs defensive verification on the "choices" array to handle rate-limit envelopes returned with HTTP 200 status codes.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Dispatches inference requests to Google's Gemini models using the official google-genai SDK. It initializes a genai.Client using Vertex AI if GEMINI_PROJECT_ID is present, or using standard API key authentication if GEMINI_API_KEY is set. When thinking_level is configured, it maps the requested level ("low", "medium", "high") to a thinking token budget (1024, 4096, 8192) via types.ThinkingConfig. It then filters candidate content parts to aggregate only text parts, preventing warnings from non-text reasoning signatures.

    Parameters:
    * prompt (str): The raw text prompt to submit to Gemini. * thinking_level (str | None, optional): Thinking budget level ("low", "medium", or "high"). Defaults to None.

    Returns:
    * str: The concatenated text response from the model candidate, or "" if no content is returned.

    Raises:
    * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Implementation: 

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    The function supports dual-mode Google Cloud authentication: enterprise Vertex AI environments configure GEMINI_PROJECT_ID and GEMINI_LOCATION, whereas developer setups provide GEMINI_API_KEY. Filtering part.text from response.candidates[0].content.parts isolates the final synthesized markdown documentation from internal model thoughts.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description:
    The central public entry point for all LLM interactions in the codebase. It orchestrates prompt token counting via token_utils.py, structured execution logging, local disk caching via load_cache() and save_cache(), execution timing, and provider dispatch between _call_llm_gemini() and _call_llm_provider().

    Parameters:
    * prompt (str): The text prompt to be evaluated by the LLM. * use_cache (bool, optional): Whether to inspect and write to llm_cache.json. Defaults to True. * thinking_level (str | None, optional): Reasoning effort level passed to the underlying provider. Defaults to None.

    Returns:
    * str: The synthesized textual response from the model or disk cache.

    Raises:
    * ValueError: If required environment variables are absent or unparseable responses are received. * Exception: For unrecoverable network, timeout, or provider API errors.

    Implementation: 

    # By default, we use Google Gemini 3.7 flash, as it shows great performance for code understanding
def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

    call_llm uses local imports for time and count_tokens to optimize startup time. It formats comprehensive audit trails in llm_logger, tracking token usage, request duration, cache hit/miss status, and full input/output text payloads. If use_cache is enabled, repeated requests with identical prompts return immediately without incurring network latency or API consumption.

    response1 = call_llm(test_prompt, use_cache=False)
    print(f"Response: {response1}")

    Executing python -m utils.call_llm bypasses the cache (use_cache=False) and prints the raw model response to standard output, allowing developers to validate environment variable configuration and network access.
