    call_llm.py

    Source: utils/call_llm.py

    Overview

    The call_llm.py module serves as the primary Large Language Model (LLM) abstraction and routing layer for the Codebase-Knowledge-Builder system. It provides a unified, cached interface for dispatching prompts to multiple LLM backend providers, notably Google Gemini (via the google-genai SDK and Vertex AI) as well as OpenAI-compatible REST endpoints (such as OpenRouter, Ollama, or local inference servers).

    Key architectural capabilities encapsulated in this module include: - Provider Resolution and Dynamic Routing: Environment-driven provider dispatching supporting native Gemini Vertex/API integration and generic OpenAI-compatible completions endpoints. - Reasoning / Extended Thinking Support: Automated parameter adaptation for model reasoning budgets across Gemini (ThinkingConfig), OpenRouter (reasoning.effort), and Ollama (think / reasoning_effort). - Context Length Introspection: Dynamic querying of endpoint and provider model registries (such as the OpenRouter models catalog) to extract maximum input context windows. - Persistent Disk Caching: Key-value JSON caching mechanism to prevent redundant token consumption and costly round-trip API queries during repeated or exploratory indexing runs. - Resilient Request Execution & Diagnostics: Structured logging, execution timing, input token quantification via token_utils.py, and defensive error handling for malformed JSON payloads, HTTP errors, timeouts, and missing candidate parts.

    logger

    • Type: logging.Logger
    • Description: Internal module logger configured under the namespace "llm_logger". Propagate is set to False and an initial logging.NullHandler() is registered at import time to absorb logs until explicit configuration is performed by the application bootstrap in main.py.

    • Type: list[dict] | None
    • Value: None
    • Description: In-memory cache holding the list of model metadata objects fetched from OpenRouter's model catalog endpoint to prevent redundant HTTP GET requests during context calculation or capability checks.

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description:
    Determines the maximum token context length for a given model and endpoint combination. It applies provider-specific heuristic checks and dynamic catalog lookups to establish the token limit.

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    For Google Gemini models (identified via Google API domain strings or "gemini" in the model name), it returns 1,000,000 tokens. For OpenRouter endpoints, it performs a real-time GET query against /api/v1/models and extracts the context_length field for the matching model. If the endpoint is unparseable or the query fails, it logs a warning and safely returns a default fallback of 100,000 tokens.

    Parameters:
    * endpoint_url (str): Base URL or API host URL for the LLM endpoint. * model_name (str): Name or ID of the targeted model. * api_key (str, optional): API authorization key if required by the target provider. Defaults to "".

    Returns:
    * int: Maximum context window length in tokens.

    Raises:
    No exceptions are raised; internal errors default to 100000.

    Example: 

    # Usage pattern in token budgeting and context management:

    endpoint_url="https://openrouter.ai/api/v1",
    model_name="meta-llama/llama-3.3-70b-instruct"
)

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Executes a generic OpenAI-compatible completions API call via HTTP POST to {provider}_BASE_URL/v1/chat/completions. Dynamically resolves configuration using the LLM_PROVIDER environment variable to look up ${LLM_PROVIDER}_MODEL, ${LLM_PROVIDER}_BASE_URL, and ${LLM_PROVIDER}_API_KEY.

    def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")

    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0
    # ...

    The function handles advanced provider-specific features: - OpenRouter Reasoning: Validates the thinking_level against the model's supported reasoning efforts using _get_openrouter_model_info(), setting payload["reasoning"] = {"effort": thinking_level.lower()} and elevating temperature to 1.0. - Ollama Reasoning: Injects both think and reasoning_effort fields into the request payload with a 1.0 temperature. - Request and Error Handling: Dispatches HTTP POST with timeout=(10, 300) (10 seconds connect, 300 seconds read). It verifies that valid JSON was received, invokes response.raise_for_status(), checks defensively for the presence of non-empty choices array in response_json, and raises informative exceptions for network errors, timeouts, or invalid response formats.

        # ...
    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        try:
            response_json = response.json()
        except (ValueError, requests.exceptions.JSONDecodeError):
            from utils.output import emit_raw

            emit_raw(
                "WARNING",
                f"Warning: Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}",
                dest="STDOUT",
            )
            logger.warning(f"Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}")
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None
        response.raise_for_status()

        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        error_message = f"HTTP error occurred: {e}"
        try:
            error_details = response.json().get("error", "No additional details")
            error_message += f" (Details: {error_details})"
        except Exception:
            pass
        raise Exception(error_message) from e
    except requests.exceptions.ConnectionError as e:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
    except requests.exceptions.Timeout as e:
        raise Exception(f"Request to {provider} API timed out.") from e
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
    except ValueError as e:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e

    Parameters:
    * prompt (str): The input prompt text to send to the completion endpoint. * thinking_level (str | None, optional): Reasoning effort level (e.g., "low", "medium", "high"). Defaults to None.

    Returns:
    * str: The textual response content from choices[0].message.content.

    Raises:
    * ValueError: If required environment variables (LLM_PROVIDER, <provider>_MODEL, <provider>_BASE_URL) are missing, if invalid JSON is received, or if the choices key is missing in the payload. * Exception: Wrapping HTTPError, ConnectionError, Timeout, or generic RequestException instances.

    Example:

    response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Executes a content generation request using the official Google GenAI SDK (google.genai). Supports both Vertex AI authentication via GCP project settings and direct API key authentication.

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    The function executes initialization and generation according to the following rules: 1. Client Initialization: If GEMINI_PROJECT_ID is set, instantiates genai.Client(vertexai=True, project=..., location=...) defaulting GEMINI_LOCATION to "us-central1". Otherwise, uses GEMINI_API_KEY. 2. Model Selection: Defaults to gemini-3.7-flash if GEMINI_MODEL is not specified. 3. Reasoning Budgets: When thinking_level is provided, maps string labels to explicit token budgets ("low" -> 1024, "medium" -> 4096, "high" -> 8192) and wraps them in types.ThinkingConfig(include_thoughts=True, thinking_budget=budget). 4. Candidate Extraction: Iterates across response.candidates[0].content.parts, extracting only items where part.text is not None. This cleanly filters out non-text metadata (such as thought_signature structures returned by reasoning models).

    Parameters:
    * prompt (str): The input user prompt string. * thinking_level (str | None, optional): Reasoning level constraint ("low", "medium", "high"). Defaults to None.

    Returns:
    * str: Joined text content from response parts, or an empty string "" if no candidate content exists.

    Raises:
    * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment. * google.genai.errors.APIError: If the Google GenAI backend rejects the request or fails authentication.

    Example: 

    # Invoked internally from call_llm when provider is resolved to "GEMINI"
response_text = _call_llm_gemini("Explain the architecture", thinking_level="high")

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description:
    Main entry point for dispatching LLM queries within the application. Provides token counting, execution logging, disk cache integration, timing instrumentation, and provider routing.

    def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

    The execution flow consists of the following steps: 1. Dynamically imports count_tokens from token_utils.py to calculate input token load. 2. Formats and writes comprehensive debug logging headers including model, provider, thinking budget, cache status, and token metrics. 3. If use_cache is True, queries load_cache(). On a cache hit, logs the cached response and returns immediately without initiating network calls. 4. On a cache miss or if caching is disabled, measures elapsed time and dispatches to _call_llm_gemini() (if provider is "GEMINI") or _call_llm_provider() (for all other OpenAI-compatible endpoints). 5. If caching is enabled, updates the cache dictionary with the new prompt/response pair and invokes save_cache(). 6. Returns the resulting response string.

    Parameters:
    * prompt (str): The full prompt string to pass to the model. * use_cache (bool, optional): Whether to check against and write to the local cache file. Defaults to True. * thinking_level (str | None, optional): Desired reasoning effort (e.g., "low", "medium", "high"). Defaults to None.

    Returns:
    * str: Textual generation output from the selected LLM provider.

    Raises:
    * ValueError: If provider environment configuration is invalid. * Exception: If network or API failures occur during generation.

    Example: 

    # Implementation pattern extracted from utils/call_llm.py (__main__ self-test)
test_prompt = "Hello, how are you?"
response1 = call_llm(test_prompt, use_cache=False)

    response1 = call_llm(test_prompt, use_cache=False)
    emit("SELFTEST_LLM_RESPONSE", response=response1)

    When invoked as a script (python -m utils.call_llm), the module imports emit from output.py, emits a "SELFTEST_LLM_CALL" notification event, executes a live call with caching explicitly bypassed (use_cache=False), and emits the resulting output via "SELFTEST_LLM_RESPONSE".
