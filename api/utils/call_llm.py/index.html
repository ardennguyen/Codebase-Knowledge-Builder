    call_llm.py

    Source: utils/call_llm.py

    Technical Overview

    utils/call_llm.py serves as the centralized Large Language Model (LLM) execution gateway and abstraction layer for the Codebase-Knowledge-Builder repository. Every pipeline node in nodes.py and workflow driver in flow.py that requires cognitive inference—ranging from code summarization and architecture extraction to markdown documentation drafting—delegates its inference requests through this module. The module decouples high-level task orchestrators from underlying model providers, protocol specifications, telemetry capture, and caching mechanics.

    The architecture supports multiple backend inference providers through two primary execution pathways: 1. Google Gemini Client: Directly integrates with the official Google GenAI SDK (google.genai), enabling execution via Vertex AI enterprise instances (GEMINI_PROJECT_ID and GEMINI_LOCATION) or public Gemini Developer API keys (GEMINI_API_KEY). This path provides explicit support for Gemini reasoning models via token-budgeted ThinkingConfig. 2. OpenAI-Compatible Providers: Provides a unified HTTP transport layer targeting any standard /v1/chat/completions REST endpoint. This allows seamless interoperability with local model runtimes such as Ollama as well as unified cloud aggregators such as OpenRouter, complete with dynamic capability detection for reasoning efforts.

    To prevent redundant API costs, circumvent external rate limits, and provide idempotence across repeated pipeline executions, utils/call_llm.py encapsulates a persistent, two-tier cache architecture. It maintains an in-memory dictionary singleton backed by a localized JSON persistence file (llm_cache.json). The module integrates directly with utils/token_utils.py for input token measurement and utils/output.py for structured, channel-aware event telemetry.

    Public API

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description:
    Executes an inference request against the resolved LLM provider. This function orchestrates token counting, structured logging, cache retrieval, provider dispatching, execution timing, cache mutation, and response propagation.

    Phase 1: Context Setup and Diagnostic Telemetry

        provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    emit_raw("DEBUG", f"{'=' * 80}", dest="LOG")
    emit_raw(
        "DEBUG",
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}",
        dest="LOG",
    )
    emit_raw("DEBUG", f"PROMPT:\n{prompt}", dest="LOG")
    The execution begins by resolving the active backend provider via get_llm_provider() and determining the model name from environment variables (<PROVIDER>_MODEL or GEMINI_MODEL). It utilizes count_tokens from utils/token_utils.py to calculate prompt length for resource tracking. Telemetry headers, model configurations, thinking parameters, and the complete prompt text are streamed directly to debug log sinks via emit_raw from utils/output.py.

    Phase 2: Cache Evaluation and Short-Circuiting

        # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            emit("CACHE_HIT", chars=f"{len(cached_response):,}")
            emit_raw("DEBUG", f"RESPONSE (cached):\n{cached_response}", dest="LOG")
            emit_raw("DEBUG", "LLM CALL END | result=cache_hit", dest="LOG")
            return cached_response
        emit("CACHE_MISS")
    When use_cache is True, the function executes a cache lookup against the persistent storage dictionary returned by load_cache(). If an exact string match for prompt exists, an event notification (CACHE_HIT) is emitted, the cached string response is logged to debug output, and the function immediately returns without initiating network calls. If the key is not present, a CACHE_MISS event is broadcast, and execution advances to API invocation.

    Phase 3: Provider Dispatch and Execution Timing

        # Make the actual LLM call
    start_time = time.time()
    emit_raw("DEBUG", f"API CALL | sending request to {provider}...", dest="LOG")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    emit_raw("DEBUG", f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}", dest="LOG")
    emit_raw("DEBUG", f"RESPONSE:\n{response_text}", dest="LOG")
    The invocation timestamp is recorded via time.time(), and request dispatch branches conditionally. If provider evaluates to "GEMINI", execution routes to _call_llm_gemini(). For all other providers (e.g., "OPENROUTER", "OLLAMA"), execution routes to _call_llm_provider(). After synchronous response generation completes, total network duration and character volume are computed, logged, and prepared for storage.

    Phase 4: Cache Persistence and Response Propagation

        # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        emit_raw("DEBUG", "CACHE WRITE | saved response to cache", dest="LOG")

    emit_raw("DEBUG", f"LLM CALL END | result=success | elapsed={elapsed:.1f}s", dest="LOG")
    return response_text
    If caching is enabled, the new response string is associated with the raw prompt key in the in-memory cache, and save_cache() is invoked to flush the serialized state to llm_cache.json. A completion debug trace is registered with duration metrics, and the raw text response is returned to the calling node.

    Parameters: * prompt (str): The raw text prompt sent to the LLM. * use_cache (bool, optional): Flag controlling whether to check and store results in llm_cache.json. Defaults to True. * thinking_level (str | None, optional): Desired reasoning effort or budget ("low", "medium", "high"). Defaults to None.

    Returns: * str: The textual completion returned by the selected provider.

    Raises: * ValueError: If required environment variables are absent, if the API returns malformed JSON, or if the choices list is missing. * Exception: On network timeouts, connection drops, or HTTP status failures.

    Example: 

    # Self-test invocation from utils/call_llm.py
test_prompt = "Hello, how are you?"

emit("SELFTEST_LLM_CALL")
response1 = call_llm(test_prompt, use_cache=False)
emit("SELFTEST_LLM_RESPONSE", response=response1)

    load_cache()

    Visibility: Public
    Signature: def load_cache():

    Description:
    Implements an in-memory singleton pattern around the persistent cache file (llm_cache.json). On first invocation, it loads and deserializes the JSON structure into the module-level _cache variable. Subsequent calls return _cache immediately without disk I/O, preventing performance bottlenecks when large cache files (often tens or hundreds of megabytes) are accessed across hundreds of pipeline iterations.

    def load_cache():
    global _cache
    if _cache is not None:
        return _cache
    try:
        with open(cache_file) as f:
            _cache = json.load(f)
        from utils.output import emit

        emit("CACHE_LOADED", count=f"{len(_cache):,}", file=cache_file)
    except Exception:
        from utils.output import emit

        emit("WARN_CACHE_LOAD_FAIL")
        _cache = {}
    return _cache

    If the cache file is missing, corrupt, or unreadable due to filesystem permissions, the error is trapped. The function emits a WARN_CACHE_LOAD_FAIL notification through utils.output.emit and initializes _cache to an empty dictionary, ensuring pipeline continuity.

    Parameters: * None.

    Returns: * dict: In-memory dictionary mapping prompt strings to LLM response strings.

    Raises: * No exceptions are propagated; all filesystem and JSON parsing errors are caught internally.

    Example: 

    # Cache read within call_llm()
if use_cache:
    cache = load_cache()
    if prompt in cache:
        cached_response = cache[prompt]

    save_cache()

    Visibility: Public
    Signature: def save_cache(cache):

    Description:
    Flushes the modified in-memory cache dictionary back to the persistent storage file (llm_cache.json). It updates the global _cache singleton reference and serializes the complete dictionary to disk using json.dump().

    def save_cache(cache):
    global _cache
    _cache = cache
    try:
        with open(cache_file, "w") as f:
            json.dump(cache, f)
    except Exception:
        from utils.output import emit

        emit("WARN_CACHE_SAVE_FAIL")

    The function incorporates defensive exception handling. If disk write operations fail (such as during storage exhaustion or read-only filesystem mounts), the error is intercepted and a WARN_CACHE_SAVE_FAIL event is logged. The runtime state remains updated in memory even if disk synchronization fails.

    Parameters: * cache (dict): The updated dictionary mapping prompt strings to generated responses.

    Returns: * None

    Raises: * No exceptions are propagated; disk write errors are logged and safely suppressed.

    Example: 

    # Cache persistence within call_llm()
if use_cache:
    cache = load_cache()
    cache[prompt] = response_text
    save_cache(cache)

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider():

    Description:
    Determines the active LLM provider identity by reading the environment configuration. It inspects the LLM_PROVIDER environment variable. If that variable is unset, it checks for the existence of GEMINI_PROJECT_ID or GEMINI_API_KEY, defaulting to "GEMINI" if either credential exists.

    def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This resolution hierarchy allows developers to configure the tool by supplying standard Google Cloud or Gemini credentials without explicitly setting LLM_PROVIDER.

    Parameters: * None.

    Returns: * str | None: The resolved provider string (e.g., "GEMINI", "OPENROUTER", "OLLAMA"), or None if unconfigured.

    Raises: * No exceptions are raised.

    Example: 

    # Provider resolution in call_llm()
provider = get_llm_provider()
model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description:
    Queries or infers the maximum context window length (in tokens) for a designated model and endpoint combination. Pipeline chunkers and batch partitioners in utils/files.py and nodes.py rely on this value to ensure combined prompt payloads do not exceed model boundaries.

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    """
    Fetch the maximum context length of a model based on the endpoint.
    If endpoint is Gemini API, safely default to 1,000,000 tokens.
    If endpoint is openrouter.ai, make GET to /api/v1/models and extract.
    Default to 100,000.
    """
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        from utils.output import emit

        emit("WARN_CONTEXT_LENGTH_FETCH", model=model_name, endpoint=endpoint_url, error=str(e))

    return default_limit

    The function applies specific heuristics: 1. If the endpoint contains generativelanguage.googleapis.com or model_name includes "gemini", it defaults to 1,000,000 tokens. 2. If the endpoint targets openrouter.ai, it performs an HTTP GET to https://openrouter.ai/api/v1/models (with a 5-second timeout) and extracts the context_length field for the matching model ID. 3. If the endpoint is empty, unrecognized, or the network request raises an exception, it safely falls back to a default limit of 100,000 tokens while emitting WARN_CONTEXT_LENGTH_FETCH.

    Parameters: * endpoint_url (str): The base or complete URL of the API endpoint. * model_name (str): The model identifier (e.g., "gemini-3.7-flash", "anthropic/claude-3.7-sonnet"). * api_key (str, optional): API credentials if required by the target endpoint. Defaults to "".

    Returns: * int: Context length in tokens (e.g., 1000000, model-specific capacity, or default fallback 100000).

    Raises: * No exceptions are propagated; network or parsing failures trigger WARN_CONTEXT_LENGTH_FETCH and return default_limit.

    Example: 

    # Intended usage by context partitioners
context_limit = get_model_context_length(
    endpoint_url="https://openrouter.ai/api/v1",
    model_name="anthropic/claude-3.5-sonnet"
)

    Internal Helpers

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Executes inference against the Google GenAI platform using the official SDK (google.genai). It handles client instantiation (Vertex AI vs. API Key), configures reasoning budgets, transmits requests, and extracts text segments while filtering reasoning artifacts.

    Phase 1: Client Authentication and Vertex AI Resolution

        if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}
    The client detects authentication credentials from environment variables. If GEMINI_PROJECT_ID is present, it constructs a Vertex AI client using genai.Client(vertexai=True, ...) with a fallback location of "us-central1". Alternatively, if GEMINI_API_KEY is present, it initializes the developer API client. If neither credential is set, execution halts immediately with a ValueError. The target model is extracted from GEMINI_MODEL, defaulting to "gemini-3.7-flash".

    Phase 2: Thinking Budget Configuration and Generation Options

        if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        from utils.output import emit_raw

        emit_raw("DEBUG", f"Gemini thinking config | budget={budget}", dest="LOG")
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)
    When thinking_level is specified, the string level is mapped to a discrete token budget: "low" maps to 1,024 tokens, "medium" to 4,096 tokens, and "high" to 8,192 tokens (defaulting to 4,096 if unrecognized). An instance of types.ThinkingConfig is created with include_thoughts=True and assigned to types.GenerateContentConfig, configuring the Gemini 3.7 reasoning subsystem.

    Phase 3: Content Generation and Thought Signature Filtering

        response = client.models.generate_content(**kwargs)

    response_text = ""
    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        response_text = "".join(text_parts)

    if not response_text:
        from utils.output import emit_raw

        emit_raw("WARNING", "Gemini response contained no text parts", dest="LOG")

    return response_text
    The request is submitted via client.models.generate_content(**kwargs). To handle reasoning models that output internal thought chains alongside the final answer, the parser iterates through response.candidates[0].content.parts and collects only items where part.text is not None. This explicitly filters out non-text metadata (such as thought_signature), preventing SDK warnings and output pollution. If the combined text is empty, a warning is logged before returning.

    Parameters: * prompt (str): The prompt string to be processed. * thinking_level (str | None, optional): Reasoning tier ("low", "medium", "high"). Defaults to None.

    Returns: * str: The concatenated text response from Gemini.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment. * google.genai.errors.APIError: If the Google GenAI service encounters an API, quota, or authentication failure.

    Example: 

    # Internal invocation within call_llm()
if provider == "GEMINI":
    response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Executes chat completion calls against OpenAI-compatible REST APIs. It dynamically resolves provider configurations, manages HTTP headers, negotiates reasoning/thinking flags across OpenRouter and Ollama, issues the network request with socket timeouts, and parses the response payload.

    Phase 1: Environment Variable Resolution and Endpoint Formulation

        # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    # Read the provider-specific variables
    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

    # Validate required variables
    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"

    # Configure headers and payload based on provider
    headers = {
        "Content-Type": "application/json",
    }
    if api_key:  # Only add Authorization header if API key is provided
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }
    The helper determines variable names dynamically based on the active provider (e.g., OPENROUTER_MODEL, OPENROUTER_BASE_URL, OPENROUTER_API_KEY). It verifies that model and base_url are defined, raising a ValueError if either is missing. It constructs the target URL by stripping trailing slashes and appending /v1/chat/completions. Headers are initialized with Content-Type: application/json and an optional Authorization: Bearer <API_KEY> header. The default payload includes the model, messages array, and a default temperature of 0.7.

    Phase 2: Provider-Specific Reasoning and Parameter Negotiation

        if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0  # Required for many reasoning models
            else:
                from utils.output import emit

                emit("WARN_THINKING_LEVEL_INVALID", level=thinking_level, model=model, supported=str(supported_efforts))
        else:
            from utils.output import emit

            emit("WARN_THINKING_NOT_SUPPORTED", model=model)

    elif provider == "OLLAMA" and thinking_level:
        # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0
    Reasoning configuration is customized for the target provider: * OpenRouter: Calls _get_openrouter_model_info() to verify model capabilities. If the model supports reasoning, it confirms that thinking_level is in supported_efforts. If valid, it assigns payload["reasoning"] = {"effort": thinking_level.lower()} and adjusts temperature to 1.0. If unsupported or invalid, appropriate warnings (WARN_THINKING_NOT_SUPPORTED or WARN_THINKING_LEVEL_INVALID) are emitted. * Ollama: Injects both think and reasoning_effort parameters into the payload to maintain compatibility across Ollama runtime versions, setting temperature to 1.0.

    Phase 3: Network Transmission and Response Extraction

        try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        try:
            response_json = response.json()  # Log the response
        except (ValueError, requests.exceptions.JSONDecodeError):
            from utils.output import emit

            emit(
                "WARN_INVALID_JSON",
                status_code=response.status_code,
                preview=response.text[:200].strip(),
            )
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None
        response.raise_for_status()

        # Defensive check: API may return 200 with error/rate-limit payload missing 'choices'
        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            from utils.output import emit

            emit("WARN_API_NO_CHOICES", detail=str(error_detail))
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        // ... exception wrapping and details extraction ...
    except requests.exceptions.ConnectionError as e:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
    except requests.exceptions.Timeout as e:
        raise Exception(f"Request to {provider} API timed out.") from e
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
    except ValueError as e:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e
    The HTTP request is executed with a tuple timeout of (10, 300)—allowing 10 seconds for initial socket connection and up to 300 seconds for complete response generation. The response is validated through several defensive checks: 1. It validates that the response body is well-formed JSON, emitting WARN_INVALID_JSON and raising a ValueError if parsing fails. 2. It asserts response.raise_for_status() to flag HTTP 4xx/5xx responses. 3. It validates that choices is present and non-empty. This catches cases where upstream aggregators return HTTP 200 OK along with an inline JSON error object (such as rate limits). If missing, WARN_API_NO_CHOICES is emitted. 4. When validation passes, response_json["choices"][0]["message"]["content"] is returned.

    Parameters: * prompt (str): The prompt string to be transmitted in the user message payload. * thinking_level (str | None, optional): Desired reasoning level ("low", "medium", "high"). Defaults to None.

    Returns: * str: The textual content extracted from the first candidate in choices.

    Raises: * ValueError: If required environment variables are missing, response JSON is corrupt, or the choices array is absent. * Exception: Normalized wrapper around requests.exceptions.HTTPError, ConnectionError, Timeout, or generic RequestException.

    Description:
    Retrieves capabilities and metadata for a specific model from OpenRouter's /api/v1/models endpoint. To minimize redundant network requests across multiple calls, the function caches model records in the global _openrouter_models_cache variable.

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception as e:
            from utils.output import emit_raw

            emit_raw("WARNING", f"Failed to fetch OpenRouter model info: {e}", dest="LOG")
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    If the cache has not yet been populated, the helper issues an HTTP GET with a 5-second timeout. If the request succeeds, it extracts and stores the data array. If the request encounters a network error, it logs a warning via emit_raw and initializes the cache to an empty list to avoid retry loops. Finally, it uses a generator expression with next() to return the dictionary matching model_id, or None if not found.

    Notable Error Scenarios and Mitigations

    1. Persistent Cache I/O Failures: Both load_cache() and save_cache() wrap their filesystem operations in broad try...except Exception blocks. If disk reads fail, the cache defaults to an in-memory dictionary while emitting WARN_CACHE_LOAD_FAIL. If disk writes fail, WARN_CACHE_SAVE_FAIL is broadcast, but execution continues using the in-memory state.

    2. Missing Environment Credentials: If LLM_PROVIDER is not set and no Gemini keys are discovered, or if provider-specific endpoints (<PROVIDER>_BASE_URL) or models (<PROVIDER>_MODEL) are missing, explicit ValueError exceptions are raised immediately before establishing network connections.

    3. HTTP 200 OK with Embedded Error Payloads: Certain API gateways return HTTP status 200 OK with an error payload missing the expected choices key (e.g., rate limits or credit exhaustion). _call_llm_provider() guards against this by explicitly verifying "choices" in response_json and response_json["choices"]. If missing, it extracts error details, emits WARN_API_NO_CHOICES, and raises a descriptive ValueError.

    4. Malformed JSON and HTML Error Pages: When reverse proxies or edge load balancers return HTML error bodies (e.g., 502 Bad Gateway), JSON deserialization fails. The module catches (ValueError, requests.exceptions.JSONDecodeError), emits WARN_INVALID_JSON with a 200-character preview of the response body, and raises a ValueError.

    5. Socket Timeouts and Network Drops: The HTTP request utilizes a timeout tuple (10, 300). Connect timeouts trigger within 10 seconds if the host is unreachable, while generation timeouts trigger after 300 seconds. Exceptions are normalized into clear error messages (e.g., "Request to {provider} API timed out.") to assist pipeline troubleshooting.

    6. Gemini Non-Text Thought Part Filtering: Gemini reasoning models output structured parts that may include non-text candidate artifacts (such as thought signatures). _call_llm_gemini() checks part.text is not None before concatenation, preventing runtime exceptions and logging a warning if no textual content is returned.
