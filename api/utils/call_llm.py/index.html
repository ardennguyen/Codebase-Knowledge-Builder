    call_llm.py

    Source: utils/call_llm.py

    Following the structural initialization established in utils/init.py, utils/call_llm.py implements the centralized Large Language Model (LLM) execution engine for the Codebase-Knowledge-Builder system. It abstracts model interaction across distinct AI providers, unifying direct Google Gemini SDK integrations with OpenAI-compatible REST endpoints (including OpenRouter, Ollama, and local model proxies). The module encapsulates dynamic provider routing, prompt caching, reasoning/thinking budget parameterization, token counting hooks, context window resolution, and defensive error containment.

    Technical Overview

    The module serves as the primary inference gateway for workflow nodes in nodes.py. It mediates all outbound LLM traffic, decoupling higher-level pipeline orchestration from provider-specific payload schemas, authentication protocols, and error-handling semantics. The execution architecture relies on two distinct transport layers: the official Google GenAI SDK (google.genai) for native Gemini Vertex and API services, and direct HTTP transport via requests for generic OpenAI-compatible APIs (such as OpenRouter and Ollama).

    A built-in JSON file caching mechanism (llm_cache.json) intercepts duplicate inference requests. Before dispatching an expensive network operation, call_llm.py checks for identical prompt inputs, short-circuiting execution upon a cache hit. The module also manages reasoning parameters across providers, translating abstract thinking levels (low, medium, high) into concrete provider payloads—such as ThinkingConfig budgets for Gemini, reasoning effort dictionaries for OpenRouter, or think/reasoning_effort fields for Ollama.

    Public API

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description: Orchestrates the top-level execution flow for model inference. It coordinates token estimation, cache verification, dynamic provider selection, execution timing, response extraction, and cache synchronization.

    Phase 1: Provider and Token Accounting

        import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")
    The function identifies the active LLM provider via get_llm_provider() and resolves the active model identifier using environment variables. It calls count_tokens() from token_utils.py to calculate prompt complexity for observability before emitting entry log records containing execution metadata.

    Phase 2: Cache Evaluation and Short-Circuiting

        # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response
    When use_cache is True, the local cache dictionary is loaded from disk via load_cache(). If an exact string match for prompt exists in the cache, the cached response is logged and returned immediately, avoiding network latency and token consumption.

    Phase 3: LLM Provider Dispatch and Execution

        # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")
    If the prompt is not cached, the execution timer starts and request dispatch branches based on the resolved provider string. If provider == "GEMINI", the internal helper _call_llm_gemini() handles invocation; otherwise, _call_llm_provider() is called for OpenAI-compatible REST endpoints. Upon completion, elapsed wall-clock time and response sizes are recorded.

    Phase 4: Cache Update and Finalization

        # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text
    If caching is enabled, the cache dictionary is reloaded from disk to account for concurrent writes, updated with the new prompt-response pair, and committed to disk via save_cache(). Finally, the raw text response is returned to the caller.

    Parameters: * prompt (str): The complete input prompt text submitted to the language model. * use_cache (bool, optional): Flag controlling whether to read from and write to the local llm_cache.json file. Defaults to True. * thinking_level (str | None, optional): Reasoning intensity level (e.g., "low", "medium", "high"), mapped to provider-specific reasoning configurations. Defaults to None.

    Returns: * str: The text response generated by the LLM.

    Raises: * ValueError: If environment credentials or model configurations are invalid. * Exception: If network requests fail, connection timeouts occur, or invalid JSON is returned.

    Example: 

    from utils.call_llm import call_llm

response = call_llm("Explain the repository structure.", use_cache=False, thinking_level="medium")

    get_llm_provider()

    Visibility: Public
    Signature: def get_llm_provider() -> str | None:

    Description: Determines the active LLM backend provider by inspecting system environment variables. It checks for an explicit LLM_PROVIDER declaration, falling back to "GEMINI" if Google Cloud credentials (GEMINI_PROJECT_ID or GEMINI_API_KEY) are present in the runtime environment.

    def get_llm_provider():
    provider = os.getenv("LLM_PROVIDER")
    if not provider and (os.getenv("GEMINI_PROJECT_ID") or os.getenv("GEMINI_API_KEY")):
        provider = "GEMINI"
    # if necessary, add ANTHROPIC/OPENAI
    return provider

    This helper centralizes provider resolution across utility and graph components. If no explicit LLM_PROVIDER variable is exported, the presence of standard Gemini environment variables automatically configures the Gemini backend. If no compatible provider environment variables are detected, None is returned.

    Parameters: * None

    Returns: * str | None: The resolved provider string (such as "GEMINI", "OPENROUTER", or "OLLAMA"), or None if unresolvable.

    Raises: * None

    Example: 

    provider = get_llm_provider()
model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description: Resolves the maximum input context window size (in tokens) for a specified model and endpoint. It applies heuristic defaults for Gemini models, dynamically queries the OpenRouter /api/v1/models catalog when targeting OpenRouter infrastructure, and falls back to a safe default of 100,000 tokens for unrecognized endpoints.

    Phase 1: Endpoint Analysis and Heuristic Resolution

        default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000
    The function establishes a standard baseline context window of 100,000 tokens. If the endpoint contains Google Generative Language URLs or if the model name indicates a Gemini model, it allocates a 1,000,000-token limit to match standard Gemini 1.5/2.0/3.7 context architectures.

    Phase 2: Remote OpenRouter Query and Exception Fallback

            if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit
    When communicating with OpenRouter (openrouter.ai), the function executes a GET request to https://openrouter.ai/api/v1/models with a 5-second timeout. It iterates over the returned model catalog, matching model_name against the model ID to extract its official context_length. If any network, JSON decoding, or key error occurs, a warning is logged and default_limit (100,000) is returned.

    Parameters: * endpoint_url (str): Base URL or endpoint URI of the target model service. * model_name (str): Identifier of the target model (e.g., "anthropic/claude-3.7-sonnet", "gemini-3.7-flash"). * api_key (str, optional): Authorization key for protected endpoints. Defaults to "".

    Returns: * int: Maximum context window capacity in tokens.

    Raises: * None (All internal exceptions are caught, logged, and return the safe fallback limit).

    Example: 

    limit = get_model_context_length("https://openrouter.ai/api/v1", "anthropic/claude-3.7-sonnet")

    Internal Helpers

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Handles model invocation via the official Google GenAI SDK (google.genai). It configures client authentication via Vertex AI or API key credentials, maps string thinking levels to token budgets, executes generation, and extracts text segments while discarding non-text response parts.

    Phase 1: Client Initialization and Authentication Routing

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}
    The helper checks for GEMINI_PROJECT_ID to initialize a Vertex AI client instance configured with GEMINI_LOCATION (defaulting to "us-central1"). If absent, it checks for GEMINI_API_KEY to initialize a standard API key client. If neither is present, it raises a ValueError. The target model defaults to "gemini-3.7-flash".

    Phase 2: Thinking Budget Configuration

        if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)
    When thinking_level is supplied, it maps the level string ("low", "medium", "high") to token limits (1024, 4096, 8192, defaulting to 4096). It creates a types.ThinkingConfig with include_thoughts=True and wraps it in a types.GenerateContentConfig, passing it to the request keyword arguments.

    Phase 3: Model Execution and Clean Text Extraction

        response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""
    The client executes generate_content(**kwargs). To handle Gemini 2.0/3.7 responses that return multiple content parts containing reasoning blocks (thought_signature), it filters the candidates' parts, concatenating only entries where part.text is not None. If no valid candidates or parts are returned, an empty string is returned.

    Parameters: * prompt (str): The prompt payload to process. * thinking_level (str | None, optional): Reasoning configuration identifier ("low", "medium", "high"). Defaults to None.

    Returns: * str: The combined text response generated by the Gemini model.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is configured in the environment.

    Example: 

    if provider == "GEMINI":
    response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches chat completion requests to OpenAI-compatible HTTP REST APIs (such as OpenRouter or Ollama). It validates environment configurations, formats request headers, constructs payloads with provider-specific reasoning flags, executes the HTTP POST request with dual connect/read timeouts, and validates the response JSON structure.

    Phase 1: Environment Variable Resolution and Validation

    def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    # Read the provider-specific variables
    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

    # Validate required variables
    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")
    The helper reads LLM_PROVIDER and constructs dynamic environment variable keys (<PROVIDER>_MODEL, <PROVIDER>_BASE_URL, <PROVIDER>_API_KEY). It verifies that both the model and base URL are set, raising a ValueError if either variable is missing.

    Phase 2: Payload Construction and Reasoning Configuration

        # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"

    # Configure headers and payload based on provider
    headers = {
        "Content-Type": "application/json",
    }
    if api_key:  # Only add Authorization header if API key is provided
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0  # Required for many reasoning models
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0
    The endpoint URL is constructed by appending /v1/chat/completions to the base URL. If thinking_level is requested for OpenRouter, the helper checks cached model metadata via _get_openrouter_model_info(). If reasoning is supported, it injects payload["reasoning"] = {"effort": thinking_level.lower()} and adjusts the temperature to 1.0. For Ollama, it sets both payload["think"] and payload["reasoning_effort"] alongside temperature = 1.0.

    Phase 3: Network Execution, Error Interception, and Response Parsing

        try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        try:
            response_json = response.json()  # Log the response
        except (ValueError, requests.exceptions.JSONDecodeError):
            from utils.output import emit_raw

            emit_raw(
                "WARNING",
                f"Warning: Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}",
                dest="STDOUT",
            )
            logger.warning(f"Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}")
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None
        response.raise_for_status()

        # Defensive check: API may return 200 with error/rate-limit payload missing 'choices'
        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        error_message = f"HTTP error occurred: {e}"
        try:
            error_details = response.json().get("error", "No additional details")
            error_message += f" (Details: {error_details})"
        except Exception:
            pass
        raise Exception(error_message) from e
    except requests.exceptions.ConnectionError as e:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
    except requests.exceptions.Timeout as e:
        raise Exception(f"Request to {provider} API timed out.") from e
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
    except ValueError as e:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e
    The request is dispatched with a connection timeout of 10 seconds and a read timeout of 300 seconds. If parsing fails, an alert is dispatched through emit_raw() from output.py. The helper also handles edge cases where providers return an HTTP 200 status code containing rate-limit or error messages without a choices array.

    Parameters: * prompt (str): Prompt text submitted to the provider. * thinking_level (str | None, optional): Reasoning intensity string. Defaults to None.

    Returns: * str: Extracted response content from choices[0].message.content.

    Raises: * ValueError: If required environment variables are unset or the response payload is malformed. * Exception: On network connection failures, request timeouts, or HTTP status errors.

    Example: 

    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
    response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description: Retrieves model metadata from the OpenRouter catalog (https://openrouter.ai/api/v1/models). It uses a module-level cache variable _openrouter_models_cache to avoid repeated remote network lookups during a workflow run.

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    When first invoked, the helper fetches the active models catalog from OpenRouter with a 5-second timeout. If the request fails, _openrouter_models_cache is set to an empty list []. Subsequent queries filter this in-memory list by model ID.

    Parameters: * model_id (str): OpenRouter model identifier (e.g., "deepseek/deepseek-r1").

    Returns: * dict | None: The model metadata dictionary if found, or None.

    Raises: * None

    Example: 

    model_info = _get_openrouter_model_info(model)
if model_info and "reasoning" in model_info:
    supported_efforts = model_info["reasoning"].get("supported_efforts", [])

    Error Handling

    utils/call_llm.py implements defensive error-handling patterns across both transport layers:

    1. Missing Configuration Verification: Before initiating network calls, the module validates that required provider variables (LLM_PROVIDER, <PROVIDER>_MODEL, <PROVIDER>_BASE_URL, or GEMINI_PROJECT_ID/GEMINI_API_KEY) are present. Missing parameters immediately raise a descriptive ValueError.

    2. Defensive Response and Content Parsing: When communicating with generic HTTP endpoints, the module checks for non-standard failure modes:

    3. Invalid JSON Payloads: If a proxy or endpoint returns non-JSON data (e.g., HTML 502 Bad Gateway responses), the error is caught, surfaced to standard output using emit_raw() from output.py, logged to llm_logger, and re-raised as a ValueError.

    4. Missing choices Array: Some APIs return HTTP 200 OK statuses containing error or rate-limiting details in the root JSON object instead of a valid choices array. The module verifies that "choices" exists and is non-empty before indexing into choices[0].

    5. HTTP Transport Exception Wrapping: All requests.exceptions subclasses are caught and wrapped in standard Python Exception types with context-specific messages:

    6. requests.exceptions.HTTPError: Extracts nested error details from response JSON when available.
    7. requests.exceptions.ConnectionError: Returns a clear message prompting the user to check network configurations.

    8. requests.exceptions.Timeout: Flags requests exceeding the 10-second connect or 300-second read timeouts.

    9. Multi-Part Gemini Thought Segment Filtering: The Gemini SDK may return thought segments alongside generation text. In _call_llm_gemini(), the response candidate parts are filtered using [part.text for part in parts if part.text is not None] to prevent thought_signature warnings.

    10. Fault-Tolerant Cache Operations: Both load_cache() and save_cache() wrap disk I/O operations in general try...except blocks. If disk permissions or serialization fail, operations log a warning and return empty state rather than terminating the workflow.
