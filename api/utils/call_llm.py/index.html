    call_llm.py

    Source: utils/call_llm.py

    Technical Overview

    The call_llm.py module serves as the central dispatch hub for all Large Language Model (LLM) interactions within the Codebase-Knowledge-Builder architecture. It abstracts provider-specific communication protocols behind a uniform entry point, call_llm(), while managing response caching, token usage tracking, and failure handling. The module dispatches prompts dynamically across Google Gemini, Anthropic Claude, OpenRouter, and local or remote OpenAI-compatible endpoints (such as Ollama) according to configured environment variables and runtime overrides.

    A core operational feature of the module is its persistent two-tier response caching system. To eliminate unnecessary API costs and minimize pipeline latency during repeated generation runs, responses are stored in an atomic on-disk JSON database (llm_cache_v2.json). An in-memory singleton dictionary (_cache) ensures that disk I/O occurs only once during initialization and during cache persistence. Cache keys are generated via SHA-256 digests over composite tuples including the prompt body, provider name, target model, and reasoning/thinking level. Corrupt or partial cache writes are mitigated by dumping JSON content to an intermediate temporary file before atomically replacing the destination cache file.

    In addition to routing and caching, call_llm.py enforces cost and usage attribution. By interfacing with tracking ledgers in utils.llm_common and estimation utilities in utils.token_utils, every prompt request records exact token metrics, reasoning tokens, and API call costs attributed to specific pipeline execution steps. Non-retryable API refusals are memoized across invocations to prevent repetitive failures during node-level retry loops, and truncated responses resulting from token limits are flagged to prevent corrupted responses from polluting the cache.

    Public API

    cache_file

    Visibility: Public

    Signature: cache_file = "llm_cache_v2.json"

    Description: The default filename for the v2 JSON disk cache. This path stores SHA-256 hashed keys mapping to string responses, ensuring prompts are scoped to the exact provider, model, and thinking budget that generated them.

    LEGACY_CACHE_FILE

    Visibility: Public

    Signature: LEGACY_CACHE_FILE = "llm_cache.json"

    Description: The filename for pre-v2 cache files. Legacy cache files keyed directly on raw prompt text are no longer read by the v2 runtime to prevent prompt leakage and scoping collisions.

    load_cache()

    Visibility: Public

    Signature: def load_cache():

    Description: Loads and initializes the in-memory cache dictionary singleton _cache from the filesystem (llm_cache_v2.json). If the cache file does not exist, an empty dictionary is assigned. If reading fails due to OS permissions or JSON decode corruption, a warning is emitted via utils.output and an empty cache is returned to allow execution to proceed. Subsequent invocations return the in-memory singleton directly to eliminate disk I/O overhead.

    Parameters:

    • None.

    Returns:

    • dict: In-memory dictionary containing key-value cache mappings where keys are SHA-256 hashes and values are response strings.

    Raises:

    • No exceptions are raised directly; filesystem errors and JSON decoding errors are intercepted and logged.

    Example:

    cache = load_cache()
if key in cache:
    cached_response = cache[key]
    emit("CACHE_HIT", chars=f"{len(cached_response):,}")
    record_estimate(step, prompt_tokens, cache_hit=True)

    The singleton loader is invoked at the start of cache validation cycles. It prevents reparsing large multi-megabyte cache files during high-frequency graph iterations, returning the active reference immediately when _cache is populated.

    save_cache()

    Visibility: Public

    Signature: def save_cache(cache):

    Description: Persists the in-memory cache dictionary to disk using an atomic file replacement strategy. The cache object is first serialized to a temporary file (llm_cache_v2.json.tmp). Once written and flushed, os.replace atomically swaps the temporary file into the destination path (llm_cache_v2.json). This ensures that process interruptions or unexpected termination will not result in a truncated or corrupted cache file.

    Parameters:

    • cache (dict): The full cache dictionary mapping hash strings to response strings.

    Returns:

    • None

    Raises:

    • No exceptions are raised directly; OSError and TypeError events encountered during writing or renaming are caught and reported via warning logs.

    Example:

    # Write to a temp file and atomically replace, so an interrupted run never leaves a truncated cache.
tmp_path = f"{cache_file}.tmp"
try:
    with open(tmp_path, "w", encoding="utf-8") as f:
        json.dump(cache, f)
    os.replace(tmp_path, cache_file)
except (OSError, TypeError) as e:
    from utils.output import emit, emit_raw

    emit("WARN_CACHE_SAVE_FAIL")
    emit_raw("WARNING", f"Cache save error: {e}", dest="LOG")

    The function updates the global _cache reference, then serializes the dictionary to UTF-8 encoded JSON. The use of os.replace guarantees an atomic rename across POSIX and Windows filesystems, protecting pipeline progress against system crashes or forced exits.

    notice_legacy_cache()

    Visibility: Public

    Signature: def notice_legacy_cache() -> None:

    Description: Inspects the filesystem for the presence of the pre-v2 prompt cache (llm_cache.json). If found, it calculates the file size in megabytes and emits an advisory notification (CACHE_LEGACY_FOUND) prompting the user or cleanup routines to reclaim disk space, as pre-v2 cache entries are intentionally ignored by the current execution engine.

    Parameters:

    • None.

    Returns:

    • None

    Raises:

    • No exceptions are raised; missing file errors (OSError) silently terminate the routine.

    Example:

    def notice_legacy_cache() -> None:
    """Point out a leftover pre-v2 cache file: it is never read, so it only takes disk space."""
    try:
        size = os.path.getsize(LEGACY_CACHE_FILE)
    except OSError:
        return
    from utils.output import emit

    emit("CACHE_LEGACY_FOUND", file=LEGACY_CACHE_FILE, size=f"{size / 1_048_576:,.1f}", current=cache_file)

    The routine provides disk hygiene feedback during startup preflight checks. By querying file metadata via os.path.getsize, it avoids parsing legacy formats while calculating storage reclamation figures.

    call_llm()

    Visibility: Public

    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None, step: str | None = None) -> str:

    Description: The primary orchestration function for submitting prompts to LLMs. It handles configuration lookup, token estimation, cache verification, refusal deduplication, usage accounting, and provider dispatch. Execution follows five distinct operational phases.

    Phase 1: Setup and Token Estimation

    step = step or "other"
provider, model, _, _ = resolve_llm_settings()
prompt_tokens = count_tokens(prompt)  # memoized: the node already counted this prompt

emit_raw("DEBUG", f"{'=' * 80}", dest="LOG")
emit_raw(
    "DEBUG",
    f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}",
    dest="LOG",
)
emit_raw("DEBUG", f"PROMPT:\n{prompt}", dest="LOG")

    The execution step defaults to "other" if unspecified, tying accounting metrics to the pipeline phase. Active provider configurations and target models are resolved via resolve_llm_settings(), followed by memoized prompt token counting through count_tokens(). Detailed debug traces are flushed to disk logs.

    Phase 2: Cache Evaluation

    # Check cache if enabled
key = _cache_key(prompt, provider, model, thinking_level)
if use_cache:
    cache = load_cache()
    if key in cache:
        cached_response = cache[key]
        emit("CACHE_HIT", chars=f"{len(cached_response):,}")
        record_estimate(step, prompt_tokens, cache_hit=True)
        emit("LLM_CALL_CACHED", step=step, estimate=f"{prompt_tokens:,}")
        emit_raw("DEBUG", f"RESPONSE (cached):\n{cached_response}", dest="LOG")
        emit_raw("DEBUG", "LLM CALL END | result=cache_hit", dest="LOG")
        return cached_response
    emit("CACHE_MISS")

    If caching is enabled, the function computes a scoped SHA-256 digest using _cache_key(). If found in _cache, the response is immediately emitted as a cache hit, prompt token estimates are logged to the billing ledger with cache_hit=True, and the stored response text is returned without making network calls.

    Phase 3: Refusal Deduplication Check

    # A request the provider already declined this run is declined again: do not re-send it on
# node retries (rate limits, billed partial output). The node retry still sees the error.
refusal_key = request_key(provider, model, thinking_level, prompt)
refused = previous_refusal(refusal_key)
if refused is not None:
    emit_raw("DEBUG", "LLM CALL END | result=refused_before (not re-sent)", dest="LOG")
    raise refused

    Before dispatching an external network call, the function calculates a refusal key and checks previous_refusal(). If an identical request encountered a non-retryable refusal earlier in the pipeline execution (such as content filtering or policy violations), the recorded exception is re-raised immediately to prevent burning API quota.

    Phase 4: Provider Dispatch and Ledger Tracking

    # Make the actual LLM call
start_time = time.time()
emit_raw("DEBUG", f"API CALL | sending request to {provider}...", dest="LOG")

# Usage of this call = ledger delta for the provider: it includes every billed request the call
# made (Anthropic truncation retry, resend after fallbacks were disabled), even when it raises.
before = usage_snapshot(provider)
returned = False
try:
    with usage_step(step):
        if provider == "GEMINI":
            response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
        elif provider == "ANTHROPIC":
            response_text = _call_llm_anthropic(prompt, thinking_level=thinking_level)
        elif provider == "OPENROUTER":
            response_text = _call_llm_openrouter(prompt, thinking_level=thinking_level)
        else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
            response_text = _call_llm_provider(prompt, thinking_level=thinking_level)
    returned = True
except LLMRefusalError as e:
    if not e.retryable:
        remember_refusal(refusal_key, e)
    raise
finally:
    call_usage = usage_delta(before, usage_snapshot(provider))
    measured = call_usage["calls"] - call_usage["unmeasured_calls"]
    if measured:
        record_estimate(step, prompt_tokens * measured)
        _emit_call_usage(step, prompt_tokens, call_usage, measured)
    elif returned:  # answered, but the provider reported no usage
        emit("LLM_CALL_USAGE_MISSING", step=step, estimate=f"{prompt_tokens:,}")

    The function captures a ledger snapshot before routing the prompt to the provider-specific adapter. Execution is wrapped within the usage_step(step) context manager to ensure token attribution. If the call fails with a non-retryable LLMRefusalError, it is recorded in the refusal ledger. Regardless of success or failure, the finally block computes ledger deltas to account for all billed calls, including provider-level internal retries.

    Phase 5: Response Finalization and Cache Persistence

    elapsed = time.time() - start_time
emit_raw("DEBUG", f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}", dest="LOG")
emit_raw("DEBUG", f"RESPONSE:\n{response_text}", dest="LOG")

# Update cache if enabled. Empty and truncated responses (llm_common.TruncatedResponse)
# are never cached — they would be replayed on every later run.
if use_cache and response_text and not getattr(response_text, "truncated", False):
    cache = load_cache()
    cache[key] = response_text
    save_cache(cache)
    emit_raw("DEBUG", "CACHE WRITE | saved response to cache", dest="LOG")

emit_raw("DEBUG", f"LLM CALL END | result=success | elapsed={elapsed:.1f}s", dest="LOG")
return response_text

    The completed response text is logged with latency metrics. Truncated responses (TruncatedResponse) and empty replies are explicitly excluded from persistence to avoid polluting the cache with broken or partial generation states. Valid outputs are written to the in-memory cache and persisted via save_cache().

    Parameters:

    • prompt (str): The complete prompt text to submit to the model.
    • use_cache (bool, optional): Whether to check and populate the on-disk cache. Defaults to True.
    • thinking_level (str | None, optional): Desired reasoning effort (e.g., "low", "medium", "high"). Clamped or translated according to provider capabilities. Defaults to None.
    • step (str | None, optional): Identifier for the pipeline node or execution stage for usage logging and cost attribution. Defaults to None (assigned to "other").

    Returns:

    • str: The generated text response returned by the model.

    Raises:

    • LLMRefusalError: Raised when the provider refuses the prompt due to policy, safety, or non-retryable constraints.
    • ValueError: Raised if required provider configurations are missing or invalid JSON is returned.
    • RuntimeError: Raised when API responses omit required response objects.
    • ImportError: Raised if provider SDK dependencies are not installed.
    • Exception: Raised on network failures, timeouts, or HTTP status errors.

    Example:

    test_prompt = "Hello, how are you?"

emit("SELFTEST_LLM_CALL")
response1 = call_llm(test_prompt, use_cache=False)
emit("SELFTEST_LLM_RESPONSE", response=response1)

    _cache

    Visibility: Private

    Signature: _cache = None

    Description: Module-level singleton reference holding the loaded cache dictionary. When None, load_cache() populates it from disk.

    _cache_key()

    Visibility: Private

    Signature: def _cache_key(prompt: str, provider: str, model: str, thinking_level: str | None) -> str:

    Description: Constructs an immutable SHA-256 hexadecimal hash string uniquely identifying a generation request. The hash input scopes the raw prompt string by prepending the provider name, model identifier, and normalized thinking level, formatted as "{provider}|{model}|{thinking_level}\n{prompt}". This ensures identical prompts submitted to different models or reasoning budgets do not collide in the cache.

    Parameters:

    • prompt (str): The raw prompt string.
    • provider (str): The active LLM provider (e.g., "GEMINI", "ANTHROPIC").
    • model (str): The specific model name string.
    • thinking_level (str | None): The reasoning level string or None (normalized to "default").

    Returns:

    • str: A 64-character hexadecimal SHA-256 hash string.

    Raises:

    • Does not raise exceptions.

    Example:

    def _cache_key(prompt: str, provider: str, model: str, thinking_level: str | None) -> str:
    scope = f"{provider}|{model}|{(thinking_level or 'default').lower()}\n"
    return hashlib.sha256((scope + prompt).encode("utf-8")).hexdigest()

    The function normalizes the input casing of the thinking level and combines it with provider and model namespaces. UTF-8 encoding ensures deterministic hash calculation across different runtime platforms.

    _call_llm_provider()

    Visibility: Private

    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches chat completion requests to generic OpenAI-compatible REST endpoints, specifically tailored for Ollama and local runtime servers. It queries environment variables for connection endpoints, constructs JSON payloads with appropriate sampling and reasoning parameters, validates responses, tracks token counts, and checks for finish truncation.

    Phase 1: Environment Resolution and Endpoint Assembly

    # Read the provider from environment variable
provider = get_llm_provider()
if not provider:
    raise ValueError("LLM_PROVIDER environment variable is required")

# Construct the names of the other environment variables
model_var = f"{provider}_MODEL"
base_url_var = f"{provider}_BASE_URL"
api_key_var = f"{provider}_API_KEY"

# Read the provider-specific variables
model = os.environ.get(model_var)
base_url = os.environ.get(base_url_var)
api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

# Validate required variables
if not model:
    raise ValueError(f"{model_var} environment variable is required")
if not base_url:
    raise ValueError(f"{base_url_var} environment variable is required")

# Append the endpoint to the base URL
url = f"{base_url.rstrip('/')}/v1/chat/completions"

    The function identifies the provider via get_llm_provider() and constructs dynamic environment variable lookup names. It validates that both the model and base URL are present, raising a ValueError if either is missing, before constructing the standard /v1/chat/completions target URL.

    Phase 2: Payload Assembly and Reasoning Calibration

    # Configure headers and payload based on provider
headers = {
    "Content-Type": "application/json",
}
if api_key:  # Only add Authorization header if API key is provided
    headers["Authorization"] = f"Bearer {api_key}"

payload = {
    "model": model,
    "messages": [{"role": "user", "content": prompt}],
    "temperature": 0.7,
}

if provider == "OLLAMA" and thinking_level:
    # Ollama reasoning models accept low/medium/high; xhigh/max clamp to high.
    # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
    effort = _clamp_level(thinking_level.lower(), ["low", "medium", "high"]) or "medium"
    payload["think"] = effort
    payload["reasoning_effort"] = effort
    payload["temperature"] = 1.0

if rejects_sampling_params(model):
    # Claude Opus 4.7+ / Opus 5.x / Sonnet 5 / Fable reject sampling parameters (400).
    payload.pop("temperature", None)

    Headers are populated with bearer token authorization if an API key exists. For Ollama reasoning deployments, the function clamps the requested thinking level to allowed tiers (low, medium, high) and sets both think and reasoning_effort fields while resetting temperature to 1.0. If rejects_sampling_params() returns true for modern reasoning architectures, sampling parameters like temperature are removed to avoid HTTP 400 rejection.

    Phase 3: Network Execution, Error Checking, and Response Extraction

    try:
    response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
    response.raise_for_status()  # HTTP status first: an HTML 502 page must not look like a JSON bug
    try:
        response_json = response.json()
    except (ValueError, requests.exceptions.JSONDecodeError):
        from utils.output import emit

        emit(
            "WARN_INVALID_JSON",
            status_code=response.status_code,
            preview=response.text[:200].strip(),
        )
        raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None

    # Defensive check: API may return 200 with error/rate-limit payload missing 'choices'
    if "choices" not in response_json or not response_json["choices"]:
        error_detail = response_json.get("error", response_json)
        from utils.output import emit

        emit("WARN_API_NO_CHOICES", detail=str(error_detail))
        raise RuntimeError(f"API response missing 'choices' key. Response: {error_detail}")

    usage = response_json.get("usage") or {}
    from utils.llm_common import record_usage
    from utils.token_utils import count_tokens_raw, observe_prompt_tokens

    prompt_tokens = usage.get("prompt_tokens") or 0
    record_usage(
        provider,
        model,
        input_tokens=prompt_tokens,
        output_tokens=usage.get("completion_tokens") or 0,
        thinking_tokens=(usage.get("completion_tokens_details") or {}).get("reasoning_tokens") or 0,
        cache_read=(usage.get("prompt_tokens_details") or {}).get("cached_tokens") or 0,
        cost=None,
        measured=bool(usage),
    )
    if usage:
        observe_prompt_tokens(provider, model, count_tokens_raw(prompt), prompt_tokens)
    choice = response_json["choices"][0]
    text = (choice.get("message") or {}).get("content") or ""
    if choice.get("finish_reason") == "length":
        from utils.llm_common import TruncatedResponse

        return TruncatedResponse(text)
    if not text:
        from utils.output import emit

        emit("LLM_EMPTY_REPLY", provider=provider, reason=choice.get("finish_reason") or "n/a")
    return text
except requests.exceptions.HTTPError as e:
    error_message = f"HTTP error occurred: {e}"
    try:
        error_details = response.json().get("error", "No additional details")
        error_message += f" (Details: {error_details})"
    except Exception:
        pass
    raise Exception(error_message) from e
except requests.exceptions.ConnectionError as e:
    raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
except requests.exceptions.Timeout as e:
    raise Exception(f"Request to {provider} API timed out.") from e
except requests.exceptions.RequestException as e:
    raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
except ValueError as e:
    raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e

    The request is submitted via requests.post with a connection timeout of 10 seconds and read timeout of 300 seconds. HTTP errors are caught and unpacked for structured error details. Token metrics from the API payload (including prompt, completion, and reasoning tokens) are logged via record_usage(). If the generation was terminated prematurely due to token budget exhaustion (finish_reason == "length"), the output is wrapped in a TruncatedResponse instance.

    Parameters:

    • prompt (str): The prompt payload to send to the completion endpoint.
    • thinking_level (str | None, optional): Reasoning configuration effort to inject into the payload. Defaults to None.

    Returns:

    • str: The decoded completion message content, or a TruncatedResponse string wrapper if truncated.

    Raises:

    • ValueError: If required environment variables are unset or response JSON is invalid.
    • RuntimeError: If the returned JSON object lacks the 'choices' array.
    • Exception: If HTTP, connection, timeout, or parsing errors occur.

    Example:

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    try:
        from utils.llm_gemini import call_gemini

    _emit_call_usage()

    Visibility: Private

    Signature: def _emit_call_usage(step: str, estimate: int, usage: dict, measured: int) -> None:

    Description: Formats and logs a consolidated console line summarizing token consumption, cost, and deviation for an LLM call. It compares billed input tokens against initial heuristic estimates to surface token calculation drift across execution nodes.

    Parameters:

    • step (str): The execution step name or node identifier.
    • estimate (int): The estimated input token count.
    • usage (dict): The token usage ledger dictionary containing input, output, thinking, and cache statistics.
    • measured (int): Count of actual measured API requests associated with this call.

    Returns:

    • None

    Raises:

    • Does not raise exceptions.

    Example:

    def _emit_call_usage(step: str, estimate: int, usage: dict, measured: int) -> None:
    """One console line per LLM call: billed input vs the estimate, output (thinking), cached, cost.
    `measured` = requests with provider-reported usage (the deviation is per measured request)."""
    from utils.output import emit, get
    from utils.token_utils import format_cost

    per_request = usage["input"] / measured
    deviation = f"{(per_request - estimate) / estimate:+.0%}" if estimate else get("CFG_VALUE_UNKNOWN")
    emit(
        "LLM_CALL_USAGE",
        step=step,
        input=f"{usage['input']:,}",
        estimate=f"{estimate:,}",
        deviation=deviation,
        requests=get("LLM_CALL_REQUESTS", count=measured) if measured > 1 else "",
        output=f"{usage['output']:,}",
        thinking=f"{usage['thinking']:,}",
        cached=f"{usage['cache_read']:,}",
        cost=format_cost(usage),
    )

    The helper derives the average input tokens per request, computes the percentage deviation relative to the pre-call estimate, and outputs the structured LLM_CALL_USAGE notification.

    Cache Storage Format

    The persistent JSON cache stored in llm_cache_v2.json and mirrored in the _cache singleton maps SHA-256 hash keys to completion responses.

    Field / Key Type Description
    key (hashlib.sha256) str 64-character hexadecimal SHA-256 digest of {provider}\|{model}\|{thinking_level}\n{prompt}
    value str Full response string returned by the provider for the specified prompt

    Example structure:

    {

  "b84f932e19a405cde210...": "def example_function():\n    return True\n"
}

    Usage Ledger Delta Dictionary

    The usage dictionary returned by usage_delta() and processed by _emit_call_usage() tracks token volumes and financial cost across calls.

    Field Type Description
    input int Total billed prompt/input tokens across the call
    output int Total completion/output tokens generated
    thinking int Total reasoning or thought tokens generated by reasoning models
    cache_read int Prompt tokens served from provider-side prompt caching
    calls int Total number of API requests initiated during this call
    unmeasured_calls int Number of requests that did not report usage statistics
    cost float \| None Financial cost incurred in USD (or None if unknown/unpriced)

    model str Provider model name (from <PROVIDER>_MODEL)

    Error Handling

    call_llm.py standardizes error conditions across disparate HTTP and SDK client libraries:

    • Refusal Caching (LLMRefusalError): When an upstream provider raises an LLMRefusalError, the module checks e.retryable. If False, the refusal is recorded in memory via remember_refusal(). If the pipeline subsequently attempts to invoke call_llm() with an identical request key, the refusal is re-raised immediately without initiating network requests.
    • Corrupted or Truncated Responses (TruncatedResponse): Responses terminating due to length exhaustion (finish_reason == "length") are wrapped as TruncatedResponse instances. The caching logic explicitly validates getattr(response_text, "truncated", False) and skips writing them to disk to avoid caching partial generation outputs.
    • Network & HTTP Failures: Generic provider requests in _call_llm_provider() validate HTTP response codes prior to JSON decoding via response.raise_for_status(). HTML error pages (such as HTTP 502 Bad Gateway) are caught cleanly without raising misleading JSON decode errors. In addition, requests.exceptions.ConnectionError and requests.exceptions.Timeout are wrapped in user-friendly Exception messages specifying the target provider name.
    • Cache Corruption Safeguards: load_cache() intercepts json.JSONDecodeError and OSError if cache files are manually altered or corrupted, resetting the cache in memory to an empty dictionary and logging a warning. Atomic file replacement in save_cache() using temporary files (.tmp) and os.replace prevents partial file writes if execution terminates mid-dump.
