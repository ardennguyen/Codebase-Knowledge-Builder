    call_llm.py

    Source: utils/call_llm.py

    Technical Overview

    The utils/call_llm.py module serves as the centralized inference router and cache orchestrator across the Codebase-Knowledge-Builder architecture. It abstracts model provider variance by dispatching requests to Google Gemini, Anthropic Claude, OpenRouter, or generic OpenAI-compatible APIs (such as local Ollama endpoints). The module integrates persistent disk-backed caching, token usage accounting, reasoning effort clamping, and active error caching to avoid redundant API consumption when downstream workers encounter fatal model refusals.

    At its core, the execution pipeline handles configuration discovery via utils/llm_config.py, token evaluation through utils/token_utils.py, and event logging and localization through utils/output.py. The caching subsystem utilizes a scoped SHA-256 hash algorithm taking into account the provider, model, thinking level, and prompt payload. Cache reads occur lazily into an in-memory singleton, while writes use atomic file replacement semantics to ensure atomic cache persistence across multi-process or interrupted runs.

    When executed directly as a standalone script via python utils/call_llm.py, the module triggers a self-test harness. It checks LLM credentials via check_llm_auth(), evaluates the filesystem for legacy v1 cache remnants with notice_legacy_cache(), and issues a live round-trip test query ("Hello, how are you?") to verify connectivity and parsing integrity before workflow execution.

    Public API

    load_cache()

    Visibility: Public
    Signature: def load_cache() -> dict:

    Description: Loads the v2 persistent disk cache (llm_cache_v2.json) into the module-level in-memory cache singleton (_cache). If the in-memory dictionary is already initialized, it immediately returns the active reference, bypassing disk I/O. When reading from disk for the first time, it handles missing files gracefully by initializing an empty dictionary, and catches json.JSONDecodeError or OSError anomalies by emitting a warning event via utils.output.emit and resetting to an empty dictionary.

    Parameters: None.

    Returns: * dict: The global in-memory mapping of SHA-256 keys to cached string responses.

    Raises: None. Errors are trapped internally and logged via utils.output.emit_raw.

    Example: 

    def load_cache():
    global _cache
    if _cache is not None:
        return _cache
    try:
        with open(cache_file, encoding="utf-8") as f:
            _cache = json.load(f)
        from utils.output import emit

        emit("CACHE_LOADED", count=f"{len(_cache):,}", file=cache_file)
    except FileNotFoundError:
        _cache = {}
    except (json.JSONDecodeError, OSError) as e:
        from utils.output import emit, emit_raw

        emit("WARN_CACHE_LOAD_FAIL")
        emit_raw("WARNING", f"Cache load error: {e}", dest="LOG")
        _cache = {}
    return _cache
    The implementation uses a global variable _cache to ensure that files up to hundreds of megabytes in size are only parsed once during the lifecycle of the Python process. If the file is not found, _cache defaults to {} without failing, allowing subsequent saves to write a fresh cache file.

    save_cache()

    Visibility: Public
    Signature: def save_cache(cache: dict) -> None:

    Description: Commits the in-memory cache dictionary to disk. To prevent race conditions, corrupted states, or truncated cache files if the process is terminated mid-write, the function implements atomic file replacement. It writes the serialized JSON data into a temporary sibling file (llm_cache_v2.json.tmp) and executes os.replace to atomically overwrite the destination cache file.

    Parameters: * cache (dict): The updated dictionary containing key-value pairs of cache keys and string responses.

    Returns: * None

    Raises: None. Catches OSError and TypeError and emits diagnostic warnings.

    Example: 

    def save_cache(cache):
    global _cache
    _cache = cache
    # Write to a temp file and atomically replace, so an interrupted run never leaves a truncated cache.
    tmp_path = f"{cache_file}.tmp"
    try:
        with open(tmp_path, "w", encoding="utf-8") as f:
            json.dump(cache, f)
        os.replace(tmp_path, cache_file)
    except (OSError, TypeError) as e:
        from utils.output import emit, emit_raw

        emit("WARN_CACHE_SAVE_FAIL")
        emit_raw("WARNING", f"Cache save error: {e}", dest="LOG")
    The method assigns the provided dictionary directly to the module's global _cache reference before initiating disk persistence. If writing to disk fails due to disk quotas, file permission locks, or non-serializable objects, WARN_CACHE_SAVE_FAIL is emitted to the output logging system without interrupting worker execution.

    notice_legacy_cache()

    Visibility: Public
    Signature: def notice_legacy_cache() -> None:

    Description: Inspects the local working directory for the existence of the obsolete pre-v2 cache file defined by LEGACY_CACHE_FILE (llm_cache.json). The legacy format keyed entries strictly by prompt string rather than the model-scoped hash used in v2. If detected, it reads the file size and notifies the user via the CACHE_LEGACY_FOUND emission event so obsolete files can be identified and reclaimed via cleanup commands.

    Parameters: None.

    Returns: * None

    Raises: None. Catches OSError silently if the legacy file does not exist.

    Example: 

    def notice_legacy_cache() -> None:
    """Point out a leftover pre-v2 cache file: it is never read, so it only takes disk space."""
    try:
        size = os.path.getsize(LEGACY_CACHE_FILE)
    except OSError:
        return
    from utils.output import emit

    emit("CACHE_LEGACY_FOUND", file=LEGACY_CACHE_FILE, size=f"{size / 1_048_576:,.1f}", current=cache_file)
    This utility function executes during preflight routines (such as direct module execution or main entry point verification). By converting byte size to megabytes via division by 1_048_576, it yields human-readable disk consumption feedback.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description: Primary entry point for making LLM generation requests across all pipeline nodes. It resolves provider settings, counts prompt tokens, inspects cache and prior refusal records, dispatches to specific backend drivers, and conditionally updates persistent cache upon successful non-truncated completions.

    Parameters: * prompt (str): The full text prompt to submit to the language model. * use_cache (bool, optional): Whether to inspect and write to the local cache. Defaults to True. * thinking_level (str | None, optional): Desired reasoning effort (e.g., "low", "medium", "high"). Defaults to None.

    Returns: * str: The text response returned by the target LLM provider.

    Raises: * LLMRefusalError: When an LLM model refuses a prompt or policy triggers an unrecoverable decline. * ValueError: If required environment variables are absent or unparseable. * Exception: Network timeouts, HTTP errors, or backend connection failures.

    Phase 1: Configuration Resolution and Token Preflight

        from utils.output import emit, emit_raw
    from utils.token_utils import count_tokens

    provider, model, _, _ = resolve_llm_settings()
    prompt_tokens = count_tokens(prompt)

    emit_raw("DEBUG", f"{'=' * 80}", dest="LOG")
    emit_raw(
        "DEBUG",
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}",
        dest="LOG",
    )
    emit_raw("DEBUG", f"PROMPT:\n{prompt}", dest="LOG")
    The initial phase resolves the active provider name, configured model identifier, and auxiliary settings by delegating to utils/llm_config.py. The input prompt's tokens are tallied using utils/token_utils.py, and verbose diagnostics are logged to track the request lifecycle.

    Phase 2: Cache Lookup and Hit Resolution

        # Check cache if enabled
    key = _cache_key(prompt, provider, model, thinking_level)
    if use_cache:
        cache = load_cache()
        if key in cache:
            cached_response = cache[key]
            emit("CACHE_HIT", chars=f"{len(cached_response):,}")
            emit_raw("DEBUG", f"RESPONSE (cached):\n{cached_response}", dest="LOG")
            emit_raw("DEBUG", "LLM CALL END | result=cache_hit", dest="LOG")
            return cached_response
        emit("CACHE_MISS")
    If use_cache is True, the function computes the deterministic cache key via _cache_key(). It calls load_cache() to access the in-memory singleton; if a key matches, it logs a CACHE_HIT event along with response character length and immediately returns the cached text without making an external network call.

    Phase 3: Refusal Check and Short-Circuiting

        # A request the provider already declined this run is declined again: do not re-send it on
    # node retries (rate limits, billed partial output). The node retry still sees the error.
    refusal_key = request_key(provider, model, thinking_level, prompt)
    refused = previous_refusal(refusal_key)
    if refused is not None:
        emit_raw("DEBUG", "LLM CALL END | result=refused_before (not re-sent)", dest="LOG")
        raise refused
    Before reaching out to the remote provider, the function constructs a refusal key using request_key() from utils/llm_common.py. If this identical request previously failed with an unrecoverable refusal during this application run, it re-raises the recorded LLMRefusalError immediately to prevent rate limit depletion and duplicate billing.

    Phase 4: Provider Dispatch and Execution

        # Make the actual LLM call
    start_time = time.time()
    emit_raw("DEBUG", f"API CALL | sending request to {provider}...", dest="LOG")

    try:
        if provider == "GEMINI":
            response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
        elif provider == "ANTHROPIC":
            response_text = _call_llm_anthropic(prompt, thinking_level=thinking_level)
        elif provider == "OPENROUTER":
            response_text = _call_llm_openrouter(prompt, thinking_level=thinking_level)
        else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
            response_text = _call_llm_provider(prompt, thinking_level=thinking_level)
    except LLMRefusalError as e:
        if not e.retryable:
            remember_refusal(refusal_key, e)
        raise
    The dispatch branch evaluates the resolved provider string to invoke the appropriate backend wrapper. If the call raises an LLMRefusalError, the exception is inspected: non-retryable refusals are captured in memory via remember_refusal before being re-raised to the caller.

    Phase 5: Response Validation, Caching, and Telemetry

        elapsed = time.time() - start_time
    emit_raw("DEBUG", f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}", dest="LOG")
    emit_raw("DEBUG", f"RESPONSE:\n{response_text}", dest="LOG")

    # Update cache if enabled. Empty and truncated responses (llm_common.TruncatedResponse)
    # are never cached — they would be replayed on every later run.
    if use_cache and response_text and not getattr(response_text, "truncated", False):
        cache = load_cache()
        cache[key] = response_text
        save_cache(cache)
        emit_raw("DEBUG", "CACHE WRITE | saved response to cache", dest="LOG")

    emit_raw("DEBUG", f"LLM CALL END | result=success | elapsed={elapsed:.1f}s", dest="LOG")
    return response_text
    Following successful execution, elapsed wall-clock duration and response payload size are logged. If caching is enabled, the result is checked against emptiness and the truncated attribute flag (indicating an incomplete output sequence). Complete, valid responses are committed to the cache file via save_cache(), and the final text string is returned.

    Internal Helpers

    _cache_key()

    Visibility: Private
    Signature: def _cache_key(prompt: str, provider: str, model: str, thinking_level: str | None) -> str:

    Description: Constructs a SHA-256 hexadecimal hash representing the discrete configuration and payload of an LLM request. By prefixing the prompt with the provider name, model identifier, and normalized reasoning effort level, this function guarantees that responses remain isolated across different models and configurations even when prompts are identical.

    Parameters: * prompt (str): The exact input text sent to the model. * provider (str): The active provider name (e.g., "GEMINI", "ANTHROPIC", "OLLAMA"). * model (str): The target model name string. * thinking_level (str | None): The requested reasoning budget or effort level string, defaulting to "default" if None.

    Returns: * str: A 64-character hexadecimal SHA-256 digest string.

    Raises: None.

    Example: 

    def _cache_key(prompt: str, provider: str, model: str, thinking_level: str | None) -> str:
    scope = f"{provider}|{model}|{(thinking_level or 'default').lower()}\n"
    return hashlib.sha256((scope + prompt).encode("utf-8")).hexdigest()
    The scope string formats the provider, model, and normalized thinking level followed by a newline delimiter. This prefix is prepended to the raw prompt before encoding as UTF-8 bytes and hashing, preventing cache collisions across model migrations.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Implements HTTP communication with generic OpenAI-compatible chat completion endpoints (such as Ollama or custom local server deployments). It dynamically parses environment variables matching <provider>_MODEL, <provider>_BASE_URL, and <provider>_API_KEY, prepares JSON payloads with sampling parameters or reasoning effort levels, executes a POST request via requests.post, and parses output choices and token usage.

    Parameters: * prompt (str): Prompt text to be passed under a user role message. * thinking_level (str | None, optional): Reasoning effort level to inject into Ollama-compatible payloads. Defaults to None.

    Returns: * str: The extracted completion content or a TruncatedResponse wrapper if finish_reason == "length".

    Raises: * ValueError: Missing required environment variables or malformed non-JSON responses from the server. * RuntimeError: Successful HTTP responses that lack the expected choices array. * Exception: Wrapped connection errors, HTTP errors, or socket timeouts.

    Phase 1: Environment and Configuration Validation

        # Read the provider from environment variable
    provider = get_llm_provider()
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    # Read the provider-specific variables
    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

    # Validate required variables
    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"
    The method resolves the active provider name via get_llm_provider(). It looks up provider-specific variables in os.environ for the model name, base URL, and optional API key, throwing ValueError if model or base URL entries are unset, and constructs the standard /v1/chat/completions endpoint URL.

    Phase 2: Payload Construction and Reasoning Parameter Clamping

        # Configure headers and payload based on provider
    headers = {
        "Content-Type": "application/json",
    }
    if api_key:  # Only add Authorization header if API key is provided
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OLLAMA" and thinking_level:
        # Ollama reasoning models accept low/medium/high; xhigh/max clamp to high.
        # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
        effort = _clamp_level(thinking_level.lower(), ["low", "medium", "high"]) or "medium"
        payload["think"] = effort
        payload["reasoning_effort"] = effort
        payload["temperature"] = 1.0

    if rejects_sampling_params(model):
        # Claude Opus 4.7+ / Opus 5.x / Sonnet 5 / Fable reject sampling parameters (400).
        payload.pop("temperature", None)
    Headers are initialized with standard JSON content types and optional bearer authorization. The JSON body is populated with messages and a default temperature of 0.7. For Ollama reasoning models, _clamp_level normalizes the thinking level to low, medium, or high, setting both think and reasoning_effort fields while shifting temperature to 1.0. If rejects_sampling_params(model) evaluates to true, the temperature parameter is stripped completely to prevent upstream 400 Bad Request responses.

    Phase 3: HTTP Request Execution and JSON Parsing

        try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        response.raise_for_status()  # HTTP status first: an HTML 502 page must not look like a JSON bug
        try:
            response_json = response.json()
        except (ValueError, requests.exceptions.JSONDecodeError):
            from utils.output import emit

            emit(
                "WARN_INVALID_JSON",
                status_code=response.status_code,
                preview=response.text[:200].strip(),
            )
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None
// ...
    except requests.exceptions.HTTPError as e:
        error_message = f"HTTP error occurred: {e}"
        try:
            error_details = response.json().get("error", "No additional details")
            error_message += f" (Details: {error_details})"
        except Exception:
            pass
        raise Exception(error_message) from e
    except requests.exceptions.ConnectionError as e:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
    except requests.exceptions.Timeout as e:
        raise Exception(f"Request to {provider} API timed out.") from e
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
    except ValueError as e:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e
    The network request is dispatched with a connect timeout of 10 seconds and read timeout of 300 seconds. response.raise_for_status() guarantees that gateway errors (such as HTML 502 Bad Gateway responses) are captured prior to JSON parsing attempts. Exceptions are captured and mapped into clear, contextual exceptions with provider references.

    Phase 4: Response Validation, Token Usage Tracking, and Truncation Detection

            # Defensive check: API may return 200 with error/rate-limit payload missing 'choices'
        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            from utils.output import emit

            emit("WARN_API_NO_CHOICES", detail=str(error_detail))
            raise RuntimeError(f"API response missing 'choices' key. Response: {error_detail}")

        usage = response_json.get("usage") or {}
        from utils.llm_common import record_usage

        record_usage(provider, model, input_tokens=usage.get("prompt_tokens") or 0, output_tokens=usage.get("completion_tokens") or 0, cost=None)
        choice = response_json["choices"][0]
        text = (choice.get("message") or {}).get("content") or ""
        if choice.get("finish_reason") == "length":
            from utils.llm_common import TruncatedResponse

            return TruncatedResponse(text)
        return text
    The parsed response is inspected for valid completion choices. Token consumption metadata reported in the usage block is registered via record_usage(). If the choice metadata indicates finish_reason == "length", the text is wrapped in a TruncatedResponse object so downstream consumers recognize that max output token limits were hit and avoid caching partial results.

    _cache dict \| None In-memory singleton caching parsed response mappings from disk.

    Disk Cache Schema (llm_cache_v2.json)

    The v2 cache structure is serialized directly to JSON on disk and held in memory within _cache. It maps SHA-256 hash keys to response strings:

    Field / Key Type Description
    <sha256_hash> str Key generated by _cache_key(). Represents the hexadecimal hash of provider\|model\|thinking_level\n<prompt>.
    <value> str Exact string response returned by the LLM completion API.

    Example Schema Record: 

    {
  "8a2f4c9e81b6730d12e847cbb6509f7a3f81e223b5d681c20e405a7612f0e42a": "Here is the summary of the requested module..."
}

    Generic Provider JSON Request Payload

    The dictionary structure constructed inside _call_llm_provider() passed as json=payload to /v1/chat/completions:

    Field Type Description
    model str Model identifier string resolved from <provider>_MODEL.
    messages list[dict[str, str]] Message list formatted with [{"role": "user", "content": prompt}].
    temperature float (optional) Sampling temperature, set to 0.7 by default or 1.0 for reasoning models; omitted if rejects_sampling_params(model) is true.
    think str (optional) Clamped reasoning level ("low", "medium", "high") injected when provider is "OLLAMA".
    reasoning_effort str (optional) Standardized reasoning effort injected alongside think for Ollama reasoning models.

    Error Handling

    The module employs defensive handling for network instability, malformed API responses, provider rejections, and caching failures:

    1. Atomic Cache Failure Trapping: In load_cache() and save_cache(), file I/O operations are wrapped in try...except (OSError, json.JSONDecodeError, TypeError). If corrupt data is loaded or disk storage cannot be written, warning events (WARN_CACHE_LOAD_FAIL, WARN_CACHE_SAVE_FAIL) are dispatched to the logging pipeline, and execution continues without crashing the pipeline.

    2. Non-Retryable Refusal Memorization: When a provider driver raises an LLMRefusalError, the system checks e.retryable. If False, the refusal is stored in-memory using remember_refusal(refusal_key, e) from utils/llm_common.py. Subsequent calls with the identical prompt and model setup match previous_refusal(refusal_key) and immediately re-raise the error, skipping network transport.

    3. HTTP and Content Validation in Generic Provider Calls: _call_llm_provider() executes response.raise_for_status() to catch HTTP status errors before attempting JSON parsing. If the upstream provider sends non-JSON content (e.g., HTML cloud proxy error pages), requests.exceptions.JSONDecodeError triggers a WARN_INVALID_JSON emission with a 200-character preview. Furthermore, if a 200 OK response omits the choices attribute, a RuntimeError is raised after emitting WARN_API_NO_CHOICES.

    4. Truncated Response Shielding: If a generic model run stops due to context length limits (finish_reason == "length"), the returned string is wrapped in TruncatedResponse(text). call_llm() verifies getattr(response_text, "truncated", False) and suppresses cache writes for truncated responses, guaranteeing incomplete responses are never cached or replayed.
