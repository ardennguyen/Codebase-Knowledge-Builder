    call_llm.py

    Source: utils/call_llm.py

    Following the package initialization established in init.py, utils/call_llm.py provides the core model invocation layer for the Codebase-Knowledge-Builder system. It abstracts external Large Language Model (LLM) communications across multiple backend providers, manages disk-backed prompt-response caching, resolves context window limits, and normalizes reasoning and thinking parameter configurations.

    Technical Overview

    The call_llm.py module acts as the unified inference interface for all downstream pipeline nodes defined in nodes.py and orchestrated by flow.py. The application requires robust, multi-provider LLM support to generate repository summaries, system architecture diagrams, file-level explanations, and relationship matrices.

    Core Responsibilities

    1. Multi-Provider Dispatching: Supports native Google Gemini APIs (via the official google-genai SDK for both Vertex AI and direct API key authentication) and generic OpenAI-compatible HTTP endpoints (such as OpenRouter, Ollama, LocalAI, and vLLM).
    2. Deterministic Response Caching: Manages an on-disk JSON key-value store (llm_cache.json) indexed by the exact input prompt string, avoiding duplicate API calls and redundant token consumption during repeated pipeline executions.
    3. Context Length Discovery: Dynamically resolves context window capacities per model by querying remote endpoints (e.g., OpenRouter metadata APIs) or applying rule-based heuristics based on endpoint URLs and model names.
    4. Reasoning Parameter Translation: Maps abstract reasoning effort tiers (low, medium, high) to backend-specific schemas, such as Gemini's token-based thinking budget (ThinkingConfig), OpenRouter's reasoning payload (reasoning.effort), and Ollama's think/reasoning_effort payload fields.
    5. Defensive Error Handling and Logging: Provides structured logging through a dedicated "llm_logger" instance configured with a NullHandler at import time, preventing root logger pollution before runtime initialization by main.py.

    def get_llm_provider():

    _get_openrouter_model_info()

    Visibility: Private
    Signature: def _get_openrouter_model_info(model_id: str) -> dict | None:

    Description:
    Fetches and caches model metadata from OpenRouter's public endpoint (https://openrouter.ai/api/v1/models). If the module-level _openrouter_models_cache is unpopulated (None), it dispatches an HTTP GET request with a 5-second timeout and extracts the "data" array. It then performs a linear search over the cached models to return the dictionary whose "id" matches model_id.

    Parameters:
    * model_id (str): The unique model identifier string (e.g., "anthropic/claude-3.7-sonnet", "meta-llama/llama-3.3-70b-instruct").

    Returns:
    * dict | None: The model capability dictionary containing pricing, context limits, and reasoning capability objects, or None if the model ID is not found or the network request fails.

    Raises:
    * No exceptions are propagated. Network errors or invalid JSON payloads result in an empty list cache [], returning None.

    Implementation: 

    def _get_openrouter_model_info(model_id: str) -> dict:
    global _openrouter_models_cache
    if _openrouter_models_cache is None:
        try:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            _openrouter_models_cache = resp.json().get("data", [])
        except Exception:
            _openrouter_models_cache = []

    return next((m for m in _openrouter_models_cache if m.get("id") == model_id), None)

    The memoization pattern used here avoids repeated network latency when making hundreds of inference calls against OpenRouter. By storing the parsed metadata in _openrouter_models_cache, subsequent lookups for reasoning capabilities and context limits execute in memory.

    get_model_context_length()

    Visibility: Public
    Signature: def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:

    Description:
    Resolves the maximum input context window size (in tokens) for a given model and endpoint combination. It applies a hierarchical resolution strategy: 1. If endpoint_url is empty, returns the default baseline of 100,000 tokens. 2. If endpoint_url contains "generativelanguage.googleapis.com" or model_name contains "gemini" (case-insensitive), returns 1,000,000 tokens. 3. If endpoint_url contains "openrouter.ai", queries the OpenRouter /api/v1/models endpoint (with a 5-second timeout) to extract the model's exact context_length. 4. If remote queries fail or the endpoint is unknown, catches any exception, logs a warning, and falls back to 100,000 tokens.

    Parameters:
    * endpoint_url (str): The base or full URL of the model inference service. * model_name (str): The identifier of the target model (e.g., "gemini-3.7-flash", "qwen/qwen-2.5-coder-32b"). * api_key (str, optional): API authentication key (unused in the current implementation, defaults to "").

    Returns:
    * int: The maximum supported context length in tokens.

    Raises:
    * No exceptions are raised. Network or parsing failures default to 100,000.

    Implementation: 

    def get_model_context_length(endpoint_url: str, model_name: str, api_key: str = "") -> int:
    """
    Fetch the maximum context length of a model based on the endpoint.
    If endpoint is Gemini API, safely default to 1,000,000 tokens.
    If endpoint is openrouter.ai, make GET to /api/v1/models and extract.
    Default to 100,000.
    """
    default_limit = 100000
    try:
        if not endpoint_url:
            return default_limit

        if "generativelanguage.googleapis.com" in endpoint_url or "gemini" in model_name.lower():
            # Safely default to 1M tokens for Gemini models
            return 1000000

        if "openrouter.ai" in endpoint_url:
            resp = requests.get("https://openrouter.ai/api/v1/models", timeout=5)
            data = resp.json().get("data", [])
            for m in data:
                if m.get("id") == model_name:
                    return m.get("context_length", default_limit)
    except Exception as e:
        logger.warning(f"Failed to fetch context length for {model_name} at {endpoint_url}: {e}")

    return default_limit

    This context length calculation is consumed upstream by partitioning and token management routines in token_utils.py to calculate chunk sizes and prompt truncation thresholds before dispatching prompts to external LLMs.

    _call_llm_provider()

    Visibility: Private
    Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Executes an inference request against an OpenAI-compatible REST completions endpoint (e.g., OpenRouter, Ollama, vLLM). The function dynamically determines environment variable names from the LLM_PROVIDER setting (reading {provider}_MODEL, {provider}_BASE_URL, and {provider}_API_KEY), validates required configuration values, builds the request payload, adapts reasoning/thinking parameters, and sends an HTTP POST request to {base_url}/v1/chat/completions.

    Parameters:
    * prompt (str): The complete prompt string to transmit. * thinking_level (str | None, optional): Desired reasoning level (e.g., "low", "medium", "high"), or None to disable explicit reasoning configurations.

    Returns:
    * str: The textual content generated by the model extracted from response_json["choices"][0]["message"]["content"].

    Raises:
    * ValueError: If LLM_PROVIDER, {provider}_MODEL, or {provider}_BASE_URL is missing from the environment; if the provider returns invalid non-JSON content; or if an HTTP 200 response lacks the expected "choices" field. * Exception: Wraps underlying requests.exceptions.HTTPError, requests.exceptions.ConnectionError, requests.exceptions.Timeout, and requests.exceptions.RequestException errors with descriptive diagnostic messages.

    Implementation: 

    def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:
    # Read the provider from environment variable
    provider = os.environ.get("LLM_PROVIDER")
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    // ... [Read and validate {provider}_MODEL, {provider}_BASE_URL, {provider}_API_KEY] ...

    # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"

    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OPENROUTER" and thinking_level:
        model_info = _get_openrouter_model_info(model)
        if model_info and "reasoning" in model_info:
            supported_efforts = model_info["reasoning"].get("supported_efforts", [])
            if thinking_level.lower() in supported_efforts:
                payload["reasoning"] = {"effort": thinking_level.lower()}
                payload["temperature"] = 1.0  # Required for many reasoning models
            else:
                logger.warning(f"Invalid thinking level '{thinking_level}' for model {model}. Supported efforts: {supported_efforts}")
        else:
            logger.warning(f"Model {model} does not support reasoning via OpenRouter API.")

    elif provider == "OLLAMA" and thinking_level:
        payload["think"] = thinking_level.lower()
        payload["reasoning_effort"] = thinking_level.lower()
        payload["temperature"] = 1.0

    try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        try:
            response_json = response.json()
        except (ValueError, requests.exceptions.JSONDecodeError):
            from utils.output import emit_raw
            emit_raw("WARNING", f"Warning: Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}", dest="STDOUT")
            logger.warning(f"Provider returned invalid JSON. Status Code: {response.status_code}, Response Text: {response.text}")
            raise ValueError(f"Provider returned invalid JSON. Status Code: {response.status_code}") from None
        response.raise_for_status()

        if "choices" not in response_json or not response_json["choices"]:
            error_detail = response_json.get("error", response_json)
            logger.warning(f"API returned 200 but no 'choices' in response: {error_detail}")
            raise ValueError(f"API response missing 'choices' key. Response: {error_detail}")

        return response_json["choices"][0]["message"]["content"]
    except requests.exceptions.HTTPError as e:
        // ... [Format error details and wrap exception] ...
    except requests.exceptions.ConnectionError as e:
        raise Exception(f"Failed to connect to {provider} API. Check your network connection.") from e
    except requests.exceptions.Timeout as e:
        raise Exception(f"Request to {provider} API timed out.") from e
    except requests.exceptions.RequestException as e:
        raise Exception(f"An error occurred while making the request to {provider}: {e}") from e
    except ValueError as e:
        raise Exception(f"Failed to parse response as JSON from {provider}. The server might have returned an invalid response.") from e

    The function handles edge cases across third-party OpenAI-compatible endpoints: - Connection & Timeout Management: Uses a split connection/read timeout (10, 300) via requests.post(), allowing 10 seconds for initial connection negotiation and up to 300 seconds for complete token generation on long responses. - Provider-Specific Reasoning Handling: For OpenRouter, it validates requested reasoning levels against supported_efforts from metadata lookups and sets temperature: 1.0 (required by many reasoning models like OpenAI o-series or DeepSeek-R1). For Ollama, it sets both think and reasoning_effort fields to accommodate different Ollama daemon versions. - Defensive Error Handling: Detects and handles edge cases where proxy servers return an HTTP 200 OK status code with an internal JSON error object or rate-limiting message instead of a valid choices array.

    call_llm()

    Visibility: Public
    Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:

    Description:
    The primary entry point for all LLM inference in the system. It handles token tracking, cache validation, provider routing, performance timing, and cache updates: 1. Calculates prompt token length using count_tokens from token_utils.py. 2. Logs execution metadata (provider, model, thinking level, cache flag, and prompt token count). 3. When use_cache=True, checks load_cache() for an existing prompt match. On a cache hit, returns the stored response immediately. 4. On a cache miss or when caching is disabled, records the start timestamp and routes the prompt to either _call_llm_gemini() (if get_llm_provider() == "GEMINI") or _call_llm_provider() (for all other providers). 5. Logs request duration and response character counts. 6. When use_cache=True, saves the updated prompt-response pair to disk via save_cache().

    Parameters:
    * prompt (str): The full prompt text to send to the language model. * use_cache (bool, optional): Whether to check and update the local JSON cache. Defaults to True. * thinking_level (str | None, optional): Reasoning effort level ("low", "medium", "high"), or None. Defaults to None.

    Returns:
    * str: The complete string output returned by the LLM.

    Raises:
    * ValueError: If required environment variables or configuration keys are missing. * Exception: If underlying network calls, authentication, or API endpoints fail.

    Implementation: 

    # By default, we use Google Gemini 3.7 flash, as it shows great performance for code understanding
def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None) -> str:
    import time

    from utils.token_utils import count_tokens

    provider = get_llm_provider()
    model = os.environ.get(f"{provider}_MODEL", os.environ.get("GEMINI_MODEL", "unknown"))
    prompt_tokens = count_tokens(prompt)

    logger.info(f"{'=' * 80}")
    logger.info(
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}"
    )
    logger.info(f"PROMPT:\n{prompt}")

    # Check cache if enabled
    if use_cache:
        cache = load_cache()
        if prompt in cache:
            cached_response = cache[prompt]
            logger.info(f"CACHE HIT | response_chars={len(cached_response):,}")
            logger.info(f"RESPONSE (cached):\n{cached_response}")
            logger.info("LLM CALL END | result=cache_hit")
            return cached_response

    # Make the actual LLM call
    start_time = time.time()
    logger.info(f"API CALL | sending request to {provider}...")

    if provider == "GEMINI":
        response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
    else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
        response_text = _call_llm_provider(prompt, thinking_level=thinking_level)

    elapsed = time.time() - start_time
    logger.info(f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}")
    logger.info(f"RESPONSE:\n{response_text}")

    # Update cache if enabled
    if use_cache:
        cache = load_cache()
        cache[prompt] = response_text
        save_cache(cache)
        logger.info("CACHE WRITE | saved response to cache")

    logger.info(f"LLM CALL END | result=success | elapsed={elapsed:.1f}s")
    return response_text

    The function uses localized imports (import time, from utils.token_utils import count_tokens) inside the function body to reduce top-level module import overhead and prevent circular dependency cycles with modules like token_utils.py. The logging output includes clear delimiting headers ('=' * 80) and token counts to assist in debugging and tracing pipeline runs.

    _call_llm_gemini()

    Visibility: Private
    Signature: def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description:
    Dispatches inference requests directly to Google Gemini models using the official google-genai SDK (google.genai.Client). It configures authentication using one of two strategies: 1. Vertex AI Authentication: If GEMINI_PROJECT_ID is set, instantiates genai.Client(vertexai=True, project=..., location=...) using GEMINI_LOCATION (defaulting to "us-central1"). 2. Direct API Key Authentication: If GEMINI_API_KEY is set, instantiates genai.Client(api_key=...).

    If neither variable is found in the environment, it raises a ValueError. The target model is read from GEMINI_MODEL (defaulting to "gemini-3.7-flash"). When thinking_level is specified, it maps the level to a concrete token budget (low -> 1024, medium -> 4096, high -> 8192) via types.ThinkingConfig(include_thoughts=True, thinking_budget=budget) inside a types.GenerateContentConfig. Finally, it executes client.models.generate_content() and concatenates all text parts from the response candidates, safely ignoring non-text parts (such as thought_signature).

    Parameters:
    * prompt (str): The raw text prompt for the model. * thinking_level (str | None, optional): The reasoning depth ("low", "medium", "high"), or None.

    Returns:
    * str: The concatenated text output from the model's response parts.

    Raises:
    * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment. * google.genai.errors.APIError: If Google's API returns an error during content generation.

    Implementation: 

    def _call_llm_gemini(prompt: str, thinking_level: str | None = None) -> str:
    if os.getenv("GEMINI_PROJECT_ID"):
        client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=os.getenv("GEMINI_LOCATION", "us-central1"))
    elif os.getenv("GEMINI_API_KEY"):
        client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    model = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")

    kwargs = {"model": model, "contents": [prompt]}

    if thinking_level:
        # Map string levels to budgets for the installed SDK version
        budget_map = {"low": 1024, "medium": 4096, "high": 8192}
        budget = budget_map.get(thinking_level.lower(), 4096)
        thinking_config = types.ThinkingConfig(include_thoughts=True, thinking_budget=budget)
        kwargs["config"] = types.GenerateContentConfig(thinking_config=thinking_config)

    response = client.models.generate_content(**kwargs)

    # Extract only text parts to avoid "non-text parts: ['thought_signature']" warnings
    if response.candidates and response.candidates[0].content.parts:
        text_parts = [part.text for part in response.candidates[0].content.parts if part.text is not None]
        return "".join(text_parts)
    return ""

    This implementation handles the multi-part content stream returned by reasoning models such as Gemini 2.0 and Gemini 3.7 Flash Thinking. Rather than calling response.text directly (which raises library warnings when non-text artifacts like thought signatures are included), it filters response.candidates[0].content.parts to extract and join only parts where part.text is not None.

    Standalone Execution Block

    The module includes a standard __main__ guard allowing developers to test LLM connectivity and caching behavior directly from the command line without running the full pipeline:

    if __name__ == "__main__":
    test_prompt = "Hello, how are you?"

    # First call - should hit the API
    print("Making call...")
    response1 = call_llm(test_prompt, use_cache=False)
    print(f"Response: {response1}")

    Execution Mechanics

    When executed directly (python utils/call_llm.py), the script: 1. Loads environment variables from the local .env file via load_dotenv(). 2. Initializes the test prompt string "Hello, how are you?". 3. Calls call_llm() with use_cache=False, bypassing the cache to verify live API credentials, network connectivity, and model availability. 4. Outputs the returned response text directly to standard output.

    Error Handling & Resilience Matrix

    The following matrix summarizes how call_llm.py handles various runtime errors across different providers:

    Failure Mode Trigger Condition Component Handling System Impact
    Missing Cache File llm_cache.json does not exist on disk load_cache() catches exception, logs warning, returns {} Non-Fatal: Cache miss occurs; executes live API request.
    Corrupted Cache File Invalid JSON syntax in llm_cache.json load_cache() catches exception, logs warning, returns {} Non-Fatal: Disregards cache; executes live API request.
    Missing Provider Config LLM_PROVIDER not set and no Gemini keys _call_llm_provider() / _call_llm_gemini() raise ValueError Fatal: Aborts current pipeline node execution.
    Missing Base URL / Model {provider}_BASE_URL or {provider}_MODEL empty _call_llm_provider() raises descriptive ValueError Fatal: Aborts inference with explicit error.
    Invalid REST Response JSON HTTP endpoint returns non-JSON text / HTML emit_raw("WARNING", ...) and raises ValueError Fatal: Logs raw response; raises error up the stack.
    Malformed 200 OK Response API returns 200 OK but payload omits "choices" Identifies missing key, logs error_detail, raises ValueError Fatal: Prevents KeyError crashes downstream.
    HTTP Errors (4xx / 5xx) Upstream API rate limits (429) or server errors Extracts error details from JSON payload and raises Exception Fatal: Propagates structured diagnostic details.
    Network Connection / Timeout Host unreachable or execution exceeds 300s Catches ConnectionError / Timeout and wraps with context Fatal: Suggests checking connectivity / endpoint status.
    Gemini Thought Signature Gemini thinking parts present in response Filters parts for part.text is not None before joining Non-Fatal: Safely ignored; returns clean response text.
