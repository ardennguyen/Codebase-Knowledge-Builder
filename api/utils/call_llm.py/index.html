    call_llm.py

    Source: utils/call_llm.py

    Technical Overview

    As the primary invocation gateway for large language models within the Codebase-Knowledge-Builder architecture, utils/call_llm.py establishes a unified interface across diverse LLM backends. It abstracts provider-specific communication protocols, serialization quirks, and client libraries beneath a consistent, caching-aware dispatch pipeline. The module dispatches prompts to Google Gemini, Anthropic Claude, OpenRouter, or generic OpenAI-compatible HTTP endpoints (such as local Ollama instances) according to system configuration resolved at runtime.

    The module incorporates an atomic, content-addressable caching subsystem keyed on SHA-256 digests over the provider name, target model, reasoning effort, and the full prompt body. This design guarantees that identical calls avoid redundant API consumption and billing without risking disk corruption if interrupted mid-write. Surrounding each execution, call_llm.py integrates token tracking, ledger differential measurements via context managers, refusal memory caching to prevent repetitive failures during workflow node retries, and automated pruning of incompatible sampling parameters for advanced reasoning models.

    Public API

    call_llm()

    Visibility: Public Signature: def call_llm(prompt: str, use_cache: bool = True, thinking_level: str | None = None, step: str | None = None) -> str:

    Description: Dispatches a single prompt string to the currently configured LLM provider and model. Manages the lifecycle of cache lookup, refusal short-circuiting, active API dispatch, ledger delta calculation, and cache persistence. If caching is enabled and an exact key match exists, the cached response is returned immediately. Otherwise, the call executes against the provider, records token usage against the specified workflow step, validates that the output is not truncated or empty, updates persistent storage, and returns the response string.

    Phase 1: Setup and Token Estimation

        step = step or "other"
    provider, model, _, _ = resolve_llm_settings()
    prompt_tokens = count_tokens(prompt)  # memoized: the node already counted this prompt

    emit_raw("DEBUG", f"{'=' * 80}", dest="LOG")
    emit_raw(
        "DEBUG",
        f"LLM CALL START | provider={provider} | model={model} | thinking={thinking_level} | cache={'enabled' if use_cache else 'disabled'} | prompt_tokens={prompt_tokens:,}",
        dest="LOG",
    )
    emit_raw("DEBUG", f"PROMPT:\n{prompt}", dest="LOG")

    The function normalizes the workflow step to "other" if not specified and resolves the runtime provider, model identifier, and credentials through resolve_llm_settings(). It counts the prompt tokens using count_tokens(prompt)—which is typically pre-computed and memoized in token utilities—and emits structured debug logs containing the invocation metadata and raw prompt content.

    Phase 2: Cache Lookup and Hit Resolution

        # Check cache if enabled
    key = _cache_key(prompt, provider, model, thinking_level)
    if use_cache:
        cache = load_cache()
        if key in cache:
            cached_response = cache[key]
            emit("CACHE_HIT", chars=f"{len(cached_response):,}")
            record_estimate(step, prompt_tokens, cache_hit=True)
            emit("LLM_CALL_CACHED", step=step, estimate=f"{prompt_tokens:,}")
            emit_raw("DEBUG", f"RESPONSE (cached):\n{cached_response}", dest="LOG")
            emit_raw("DEBUG", "LLM CALL END | result=cache_hit", dest="LOG")
            return cached_response
        emit("CACHE_MISS")

    When caching is requested, _cache_key() hashes the provider, model, normalized thinking level, and prompt text. If a match is present within the singleton cache structure loaded by load_cache(), the system registers a cache hit event, attributes estimated prompt tokens to the current pipeline step without incurring monetary cost, logs the retrieved response, and exits early.

    Phase 3: Prior Refusal Verification

        # A request the provider already declined this run is declined again: do not re-send it on
    # node retries (rate limits, billed partial output). The node retry still sees the error.
    refusal_key = request_key(provider, model, thinking_level, prompt)
    refused = previous_refusal(refusal_key)
    if refused is not None:
        emit_raw("DEBUG", "LLM CALL END | result=refused_before (not re-sent)", dest="LOG")
        raise refused

    # Make the actual LLM call
    start_time = time.time()
    emit_raw("DEBUG", f"API CALL | sending request to {provider}...", dest="LOG")

    To prevent wasteful requests and cascading rate limits during automated graph node retries, the function computes a provider-agnostic request_key() and verifies whether this exact request has already encountered a non-retryable refusal during the current run. If a previous refusal exception exists in memory, previous_refusal() returns the stored exception, which is immediately re-raised without making an outbound network request.

    Phase 4: Provider Dispatch and Usage Metering

        # Usage of this call = ledger delta for the provider: it includes every billed request the call
    # made (Anthropic truncation retry, resend after fallbacks were disabled), even when it raises.
    before = usage_snapshot(provider)
    returned = False
    try:
        with usage_step(step):
            if provider == "GEMINI":
                response_text = _call_llm_gemini(prompt, thinking_level=thinking_level)
            elif provider == "ANTHROPIC":
                response_text = _call_llm_anthropic(prompt, thinking_level=thinking_level)
            elif provider == "OPENROUTER":
                response_text = _call_llm_openrouter(prompt, thinking_level=thinking_level)
            else:  # generic method using a URL that is OpenAI compatible API (Ollama, ...)
                response_text = _call_llm_provider(prompt, thinking_level=thinking_level)
        returned = True
    except LLMRefusalError as e:
        if not e.retryable:
            remember_refusal(refusal_key, e)
        raise
    finally:
        call_usage = usage_delta(before, usage_snapshot(provider))
        measured = call_usage["calls"] - call_usage["unmeasured_calls"]
        if measured:
            record_estimate(step, prompt_tokens * measured)
            _emit_call_usage(step, prompt_tokens, call_usage, measured)
        elif returned:  # answered, but the provider reported no usage
            emit("LLM_CALL_USAGE_MISSING", step=step, estimate=f"{prompt_tokens:,}")

    Execution snapshots the provider's token ledger prior to dispatch and wraps provider invocation inside a usage_step(step) context block. Calls branch to specialized adapters (_call_llm_gemini, _call_llm_anthropic, _call_llm_openrouter) or fall back to the generic OpenAI-compatible HTTP bridge (_call_llm_provider). If an LLMRefusalError occurs and is designated non-retryable, it is recorded in the refusal registry. In the finally block, the exact ledger difference (usage_delta) is computed to account for intermediate retries or truncated token consumption, emitting formatted billing metrics.

    Phase 5: Response Persistence and Cache Commit

        elapsed = time.time() - start_time
    emit_raw("DEBUG", f"API CALL COMPLETE | elapsed={elapsed:.1f}s | response_chars={len(response_text):,}", dest="LOG")
    emit_raw("DEBUG", f"RESPONSE:\n{response_text}", dest="LOG")

    # Update cache if enabled. Empty and truncated responses (llm_common.TruncatedResponse)
    # are never cached — they would be replayed on every later run.
    if use_cache and response_text and not getattr(response_text, "truncated", False):
        cache = load_cache()
        cache[key] = response_text
        save_cache(cache)
        emit_raw("DEBUG", "CACHE WRITE | saved response to cache", dest="LOG")

    emit_raw("DEBUG", f"LLM CALL END | result=success | elapsed={elapsed:.1f}s", dest="LOG")
    return response_text

    Following successful text retrieval, the function evaluates whether the response should be committed to disk. If use_cache is active, the response is non-empty, and the returned object is not an instance of TruncatedResponse (which indicates premature token cutoff), the cache dictionary is updated with key and serialized atomically via save_cache(). Finally, the raw text is returned to the caller.

    Parameters: * prompt (str): The complete, formatted text prompt to be evaluated by the LLM. * use_cache (bool, optional): Flag indicating whether to check local cache prior to execution and persist valid responses afterwards. Defaults to True. * thinking_level (str | None, optional): Desired reasoning effort configuration ("low", "medium", "high", "max", etc.), mapped to provider-specific thinking configurations. Defaults to None. * step (str | None, optional): Label identifying the calling workflow node (e.g., matching definitions in utils/thinking.py) used to attribute token consumption. Defaults to None (mapped to "other").

    Returns: * str: The string output received from the language model backend, or an instance of TruncatedResponse (a str subclass) if the provider ran out of generation tokens.

    Raises: * LLMRefusalError: If the provider explicitly declines generation, hits billing cutoffs, or encounters terminal rate limits. * ValueError: If required environment variables or provider configurations are missing or malformed. * ImportError: If a required vendor SDK package (such as anthropic or google-genai) is missing from the environment. * Exception: Catch-all for uncaught connection errors, HTTP errors, timeouts, or unexpected API payload structures.

    save_cache()

    Visibility: Public Signature: def save_cache(cache: dict) -> None:

    Description: Persists the provided cache dictionary to disk using an atomic file replacement strategy. The cache payload is first serialized to a temporary file (llm_cache_v2.json.tmp) and then atomically moved onto llm_cache_v2.json using os.replace. This prevents cache file corruption if the application process is terminated unexpectedly during disk writes.

    def save_cache(cache):
    global _cache
    _cache = cache
    # Write to a temp file and atomically replace, so an interrupted run never leaves a truncated cache.
    tmp_path = f"{cache_file}.tmp"
    try:
        with open(tmp_path, "w", encoding="utf-8") as f:
            json.dump(cache, f)
        os.replace(tmp_path, cache_file)
    except (OSError, TypeError) as e:
        from utils.output import emit, emit_raw

        emit("WARN_CACHE_SAVE_FAIL")
        emit_raw("WARNING", f"Cache save error: {e}", dest="LOG")

    The implementation updates the module-level _cache reference, performs a synchronous json.dump to a .tmp file, and invokes os.replace to guarantee POSIX atomic replacement semantics across platforms. File access or serialization exceptions (OSError, TypeError) are trapped and emitted via the logging system.

    Parameters: * cache (dict): The mapping of SHA-256 cache keys to cached LLM response strings.

    Returns: * None.

    Raises: * No exceptions are raised; write and serialization failures are trapped and emitted as warnings.

    Example: 

    # Extracted from call_llm() response caching in utils/call_llm.py

cache[key] = response_text
save_cache(cache)

    _cache_key()

    Visibility: Private Signature: def _cache_key(prompt: str, provider: str, model: str, thinking_level: str | None) -> str:

    Description: Computes a deterministic SHA-256 hash identifying an LLM prompt invocation. The scope string binds the provider name, model identifier, and normalized thinking level, concatenated with the prompt content.

    def _cache_key(prompt: str, provider: str, model: str, thinking_level: str | None) -> str:
    scope = f"{provider}|{model}|{(thinking_level or 'default').lower()}\n"
    return hashlib.sha256((scope + prompt).encode("utf-8")).hexdigest()

    The function guarantees strict isolation between models and reasoning modes. Even if identical prompt text is supplied, running against different providers or switching thinking effort levels will result in distinct SHA-256 hex digests.

    Parameters: * prompt (str): The exact input prompt text. * provider (str): Target provider identifier (e.g., "GEMINI", "ANTHROPIC", "OLLAMA"). * model (str): The provider-specific model name string. * thinking_level (str | None): The requested reasoning effort level, or None (mapped to "default").

    Returns: * str: A 64-character hexadecimal SHA-256 digest string.

    Raises: * No custom exceptions raised.

    Example:

    _call_llm_provider()

    Visibility: Private Signature: def _call_llm_provider(prompt: str, thinking_level: str | None = None) -> str:

    Description: Sends an HTTP POST request to an arbitrary OpenAI-compatible REST API endpoint (such as Ollama or local proxy hosts) configured via environment variables. Handles authorization headers, reasoning budget parameter adaptation, parameter stripping for models rejecting sampling flags, JSON payload parsing, defensive response structure checks, token usage telemetry registration, and HTTP transport error handling.

    Phase 1: Provider Environment Configuration and Validation

        # Read the provider from environment variable
    provider = get_llm_provider()
    if not provider:
        raise ValueError("LLM_PROVIDER environment variable is required")

    # Construct the names of the other environment variables
    model_var = f"{provider}_MODEL"
    base_url_var = f"{provider}_BASE_URL"
    api_key_var = f"{provider}_API_KEY"

    # Read the provider-specific variables
    model = os.environ.get(model_var)
    base_url = os.environ.get(base_url_var)
    api_key = os.environ.get(api_key_var, "")  # API key is optional, default to empty string

    # Validate required variables
    if not model:
        raise ValueError(f"{model_var} environment variable is required")
    if not base_url:
        raise ValueError(f"{base_url_var} environment variable is required")

    # Append the endpoint to the base URL
    url = f"{base_url.rstrip('/')}/v1/chat/completions"

    The helper derives variable names dynamically from LLM_PROVIDER (e.g., OLLAMA_MODEL, OLLAMA_BASE_URL, OLLAMA_API_KEY). It verifies that the model and base URL are defined, raises descriptive ValueError instances if missing, and appends /v1/chat/completions to the stripped base URL.

    Phase 2: Request Payload and Thinking Parameter Assembly

        # Configure headers and payload based on provider
    headers = {
        "Content-Type": "application/json",
    }
    if api_key:  # Only add Authorization header if API key is provided
        headers["Authorization"] = f"Bearer {api_key}"

    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
    }

    if provider == "OLLAMA" and thinking_level:
        # Ollama reasoning models accept low/medium/high; xhigh/max clamp to high.
        # Some Ollama SDKs / API versions look for `think`, others look for standard `reasoning_effort`
        effort = _clamp_level(thinking_level.lower(), ["low", "medium", "high"]) or "medium"
        payload["think"] = effort
        payload["reasoning_effort"] = effort
        payload["temperature"] = 1.0

    if rejects_sampling_params(model):
        # Claude Opus 4.7+ / Opus 5.x / Sonnet 5 / Fable reject sampling parameters (400).
        payload.pop("temperature", None)

    The HTTP header dictionary is populated with standard JSON content types and optional Bearer authentication. For OLLAMA with reasoning enabled, the thinking level is clamped to allowed strings (low, medium, high) using _clamp_level and mapped to both think and reasoning_effort keys while resetting temperature to 1.0. For modern models that reject sampling parameters entirely (verified via rejects_sampling_params(model)), the temperature parameter is stripped.

    Phase 3: HTTP Transmission and Error Handling

        try:
        response = requests.post(url, headers=headers, json=payload, timeout=(10, 300))
        response.raise_for_status()  # HTTP status first: an HTML 502 page must not look like a JSON bug
        try:
            response_json = response.json()
        except (ValueError, requests.exceptions.JSONDecodeError):

                "WARN_INVALID_JSON",

            raise RuntimeError(f"API response missing 'choices' key. Response: {error_detail}")

    Requests are dispatched with a connection timeout of 10 seconds and read timeout of 300 seconds. HTTP errors are caught via response.raise_for_status(). Response bodies are parsed into JSON with fallback logging if invalid payloads or HTML error pages are returned. A defensive check verifies that the returned JSON contains a non-empty choices list, guarding against providers that respond with HTTP 200 while embedding an error payload.

    Phase 4: Usage Recording and Response Parsing

            usage = response_json.get("usage") or {}

            return TruncatedResponse(text)

    except requests.exceptions.HTTPError as e:

        try:

            pass

    Extracted usage metrics (input tokens, completion tokens, reasoning tokens, and cached tokens) are fed to record_usage().     Parameters: * prompt (str): The prompt payload to send in the user message. * thinking_level (str | None, optional): Reasoning effort level string, clamped to allowed values for compatible providers. Defaults to None.

    Data Structures

    In-Memory and Persistent Cache Dictionary (llm_cache_v2.json)

    The local disk cache stored in llm_cache_v2.json and kept in memory via _cache is a key-value mapping of SHA-256 strings to model responses.

    Field Type Description
    [sha256_hash_key] str A 64-character hexadecimal SHA-256 hash computed by _cache_key().
    [value] str The complete text response generated by the LLM.

    Example shape in JSON: 

    {
  "a3b8c9d4e5f60718293a4b5c6d7e8f90123456789abcdef0123456789abcdef0": "This is a cached completion response."
}

    Cache Key Construction String

    Internal scope structure used to seed hashlib.sha256 in _cache_key().

    Segment Format Description
    provider str Name of the provider (e.g., GEMINI, ANTHROPIC, OLLAMA).
    model str Configured model identifier (e.g., gemini-2.5-flash, claude-3-7-sonnet).
    thinking_level str Lowercase thinking level, or "default" if unspecified.
    delimiter \n Newline separating scope metadata from the prompt.
    prompt str The full user prompt text.

    OpenAI-Compatible HTTP Request Payload

    The dictionary structure transmitted to generic OpenAI-compatible completion endpoints via requests.post.

    Key Type Description
    model str Model identifier string retrieved from the environment variable <PROVIDER>_MODEL.
    messages list[dict[str, str]] Message history containing a single user turn: [{"role": "user", "content": prompt}].
    temperature float Sampling temperature (0.7 by default; set to 1.0 if reasoning is enabled; stripped if model rejects sampling).
    think str (optional) Reasoning effort for Ollama servers ("low", "medium", "high").

    Provider Usage Ledger Delta Object (call_usage)

    Dictionary produced by usage_delta(before, after) representing token usage accumulated during an execution.

    Key Type Description
    calls int Total count of outbound API calls dispatched.
    unmeasured_calls int Count of outbound API calls whose provider returned no usage block.
    input int Cumulative prompt/input tokens billed.
    output int Cumulative output/completion tokens generated.
    thinking int Tokens generated as internal reasoning/thinking steps.
    cache_read int Prompt tokens satisfied by provider-side prompt caching.

    Error Handling

    The module implements defensive strategies across network transport, response parsing, and execution retries:

    • Non-Retryable Refusal Memorization: When a provider encounters a non-retryable refusal (such as credit depletion or safety blocks), an LLMRefusalError is caught, and remember_refusal(refusal_key, e) records it in memory. If graph execution retries the node, previous_refusal() intercepts the call and re-raises the error before issuing another HTTP request.
    • Corrupt Cache Resilience: When loading llm_cache_v2.json, json.JSONDecodeError and OSError exceptions are caught, an error warning is emitted, and _cache is reset to an empty dictionary, allowing execution to proceed without caching rather than crashing the pipeline.
    • Atomic Cache Writing: save_cache() writes JSON contents to f"{cache_file}.tmp" and replaces the target file via os.replace. This atomic operation avoids file truncation or corruption if the execution is interrupted.
    • Truncated Response Caching Exclusion: Empty responses or instances of TruncatedResponse (where finish_reason == "length") bypass cache persistence entirely (not getattr(response_text, "truncated", False)). This ensures incomplete generations are not saved to disk and replayed in subsequent runs.
    • Transport Normalization: In _call_llm_provider(), network errors are trapped and mapped to clear exception messages distinguishing connection failures, timeouts, invalid JSON, and HTTP status codes.
