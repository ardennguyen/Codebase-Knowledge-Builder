    facts.py

    Source: utils/facts.py

    Technical Overview

    Following the declarative filtering established in exclude_patterns.py—which prevents unwanted files from entering the pipeline—facts.py provides language-agnostic code verification. It acts as an automated ground-truth validation engine that intercepts claims made by Large Language Models (LLMs) regarding module symbols, internal and external dependencies, configuration keys, and error types, proving their existence against verbatim source text without language-specific Abstract Syntax Tree (AST) parsers.

    The module operates across two distinct verification phases: single-file fact extraction and cross-module link resolution. In the single-file phase, claims are verified against a pre-normalized SourceIndex using a tiered search hierarchy: exact collapsed line matching, whitespace-squashed multi-line span matching, and in-order identifier token sequence searching. In the cross-module phase, ModuleTable aggregates symbols across all analyzed files, resolves package boundaries and path aliases declared in project manifests, and applies the "evidence rule" to ensure claimed dependencies are explicitly named and imported by the source code.

    Public API

    split_lines()

    Visibility: Public
    Signature: def split_lines(content: str) -> list[str]:

    Description: Splits source code text into line lists matching line numbering as tracked by text editors and GitHub. It splits exclusively on carriage return (\r), line feed (\n), and CRLF combinations via _LINE_BREAK_RE, deliberately avoiding Python's built-in str.splitlines() behavior of splitting on form feeds (\f), next line characters (\x85), and Unicode line separators (U+2028). A trailing empty string produced by a terminating newline is discarded.

    Parameters: * content (str): Raw string content of the source file.

    Returns: * list[str]: Individual lines without terminal newline characters.

    Raises: * None.

    Example: 

    # Sourced from utils/facts.py
def split_lines(content: str) -> list[str]:
    """Lines as editors and GitHub number them (only CR, LF, CRLF break a line)."""
    lines = _LINE_BREAK_RE.split(content)
    return lines[:-1] if lines and lines[-1] == "" else lines

    SourceIndex

    Visibility: Public
    Signature: class SourceIndex:

    Description: High-performance text index created per file for matching LLM quotes against source text without AST parsing. It normalizes all text to Unicode NFC and prepares three distinct representations for tiered quote matching: collapsed whitespace lines with character offset accumulation, squashed text stripped of all whitespace, and inverted token frequency indices mapping words to the line numbers on which they occur.

    SourceIndex.__init__()

    Visibility: Public
    Signature: def __init__(self, content: str):

    Description: Initializes the normalized string tables and inverted indices used for multi-tier quote location.

    # Sourced from utils/facts.py
class SourceIndex:
    """One file's lines, pre-normalized for quote matching (NFC: models write precomposed letters)."""

    def __init__(self, content: str):
        self.lines = split_lines(_nfc(content))
        self.collapsed = [_collapse(line) for line in self.lines]
        # Collapsed lines joined by "\n" (never inside a collapsed line or quote, so no match spans two lines)
        self.collapsed_text = "\n".join(self.collapsed) + "\n"
        self.collapsed_offsets = list(accumulate((len(line) + 1 for line in self.collapsed), initial=0))
        squashed = [_squash(line) for line in self.lines]
        # All lines without whitespace, back to back, with each line's start offset: one str.find per quote
        self.squashed_text = "".join(squashed)
        self.offsets = list(accumulate((len(line) for line in squashed), initial=0))
        self.words = [_words(line) for line in self.lines]
        self.word_sets = [set(words) for words in self.words]
        self.word_lines = defaultdict(list)  # word → lines it occurs on, for the token fallback
        for number, words in enumerate(self.word_sets):
            for word in words:
                self.word_lines[word].append(number)
    The constructor computes prefix-sum cumulative offsets (accumulate) across both collapsed and squashed representations. This enables $O(\log N)$ binary search line mapping via bisect_right when finding character substring offsets. It also constructs word_lines, an inverted index mapping each identifier word to its list of line numbers.

    SourceIndex.locate()

    Visibility: Public
    Signature: def locate(self, quote, start: int = 0, end: int | None = None) -> list[tuple[int, int, str]]:

    Description: Locates 0-based line ranges [(first_line, last_line, how)] where a quote occurs between lines start and end. Implements three tiers of matching: 1. exact: Single-line match using whitespace-collapsed comparison via collapsed_text. 2. joined: Multi-line match across up to _WINDOW lines (or the quote's line count) using squashed_text. 3. tokens: In-order identifier token matching spanning within the window, anchored by the quote's least frequent identifier token.

    # Sourced from utils/facts.py
    def locate(self, quote, start: int = 0, end: int | None = None) -> list[tuple[int, int, str]]:
        end = len(self.lines) if end is None else min(end, len(self.lines))
        collapsed = _collapse(quote)
        if not collapsed or start >= end:
            return []
        exact = []
        pos = self.collapsed_text.find(collapsed, self.collapsed_offsets[start])
        while 0 <= pos < self.collapsed_offsets[end]:
            line = bisect_right(self.collapsed_offsets, pos) - 1
            exact.append((line, line, "exact"))
            pos = self.collapsed_text.find(collapsed, self.collapsed_offsets[line + 1])
        if exact:
            return exact
        window = max(_WINDOW, len(split_lines(str(quote))) + 1)
        squashed = _squash(quote)
        joined = []
        pos = self.squashed_text.find(squashed, self.offsets[start])
        while 0 <= pos < self.offsets[end]:
            first = bisect_right(self.offsets, pos) - 1
            last = bisect_right(self.offsets, pos + len(squashed) - 1) - 1
            if last - first < window and last < end:
                joined.append((first, last, "joined"))
            pos = self.squashed_text.find(squashed, pos + 1)
        if joined:
            return list(dict.fromkeys(joined))
        words = _words(quote)
        if len(words) < _MIN_TOKEN_QUOTE or any(word not in self.word_lines for word in words):
            return []
        rarest = min((self.word_lines[word] for word in words), key=len)
        starts = sorted({i for line in rarest for i in range(max(start, line - window + 1), min(line + 1, end))})
        found = []
        for i in starts:
            if words[0] not in self.word_sets[i]:
                continue
            last = self._words_in_order(words, i, min(i + window, end))
            if last is not None:
                found.append((i, last, "tokens"))
        return found
    The method short-circuits at the first tier that produces results. The tokens fallback prevents combinatorial search explosion by finding the rarest token in the quote via word_lines, restricting window scans exclusively around candidate lines containing that word.

    SourceIndex.excerpt()

    Visibility: Public
    Signature: def excerpt(self, first: int, last: int, quote) -> tuple[str, bool]:

    Description: Generates an excerpt of matched source text spanning at most _EXCERPT (300) characters centered around the quote citation.

    # Sourced from utils/facts.py
    def excerpt(self, first: int, last: int, quote) -> tuple[str, bool]:
        """The matched source text, at most ``_EXCERPT`` characters around the quote: ``(text, truncated)``."""
        text = self.text(first, last).strip()
        if len(text) <= _EXCERPT:
            return text, False
        flat, wanted = _collapse(text), _collapse(quote)
        pos = max(flat.find(wanted), 0)
        start = max(0, min(pos - (_EXCERPT - len(wanted)) // 2, len(flat) - _EXCERPT))
        return flat[start : start + _EXCERPT], True
    When source lines exceed 300 characters (such as minified files or long signatures), excerpt centers a 300-character window around the matched quote substring and sets the truncated flag to True.

    Phase 4: Configuration and Error Claim Matching

    Config options and error declarations require dual verification: the evidence must locate in the file, and the claimed name must be present in the matched source lines according to _names_in().

    Phase 5: Deduplication and Coverage Accounting

    # Sourced from utils/facts.py
    # One fact quoted twice (a whole signature and its first line, an import and its block) is kept once
    for key, fields in (("symbols", ("parent", "name")), ("dependencies", ("target",)), ("config", ("name",)), ("errors", ("name",))):

    Duplicate citations pointing to the same line numbers are merged. The total claimed count is adjusted for deduplicated items, and the final found score is calculated as claimed - len(rejected).

    code_view()

    Visibility: Public
    Signature: def code_view(lines: list[str]) -> list[str]:

    Description: Strips docstrings, block comments, and trailing comments while preserving original line count and indices. Agnostically strips Python triple quotes (""", '''), C-style block comments (/* ... */), and trailing line comments (#, //, --). Block string assignments like HELP = """...""" are replaced with HELP = "" to maintain syntactically valid declaration heads.

    # Sourced from utils/facts.py
def code_view(lines: list[str]) -> list[str]:
    last = {}  # closer → (line, column) of its last occurrence
    for closer in set(_BLOCK_CLOSERS.values()):
        for number in range(len(lines) - 1, -1, -1):
            column = lines[number].rfind(closer)
            if column >= 0:
                last[closer] = (number, column)
                break
    view, closing = [], None
    for number, line in enumerate(lines):
        out, position = "", 0
        if closing:
            end = line.find(closing)
            if end < 0:
                view.append("")
                continue
            position, closing = end + len(closing), None
        elif line.lstrip().startswith(("#", "//")):
            view.append(line)
            continue
        # ... token loop parsing strings and comment openers ...
        while True:
            match = _CODE_TOKEN_RE.search(line, position)
            if not match:
                out += line[position:]
                break
            token, start = match.group(), match.start()
            if token in ("#", "//", "--"):
                out += line[position:start]
                break
            closer = _BLOCK_CLOSERS.get(token)
            glob = token == "/*" and start and (line[start - 1].isalnum() or line[start - 1] in "_.*/$}")
            if not closer or glob or last.get(closer, (-1, -1)) < (number, match.end()):
                out += line[position : match.end()]
                position = match.end()
                continue
            out += line[position:start] + ('""' if closer != "*/" else " ")
            end = line.find(closer, match.end())
            if end < 0:
                closing = closer
                break
            position = end + len(closer)
        view.append(out.rstrip())
    return view
    The routine scans forward while verifying that block delimiters match closing tags located via a reverse pass (last). Delimiters inside single-line strings or wildcard glob patterns (such as lib/*.sh) are preserved.

    declaration_like()

    Visibility: Public
    Signature: def declaration_like(line: str) -> bool:

    Description: Language-agnostic heuristic checking whether a source code line appears to declare a reader-visible symbol (classes, functions, interfaces, constants, type definitions). Evaluates leading modifiers, keywords (_DECLARATION_WORDS), C-family return types, and assignment patterns.

    # Sourced from utils/facts.py
def declaration_like(line: str) -> bool:
    stripped = line.strip()
    if not stripped:
        return False
    if stripped.startswith("#"):
        return stripped.startswith(("#define ", "#macro "))
    if not (stripped[0].isalpha() or stripped[0] in "_@$"):
        return False
    unindented = line[:1] not in (" ", "\t")
    constant = _CONSTANT_RE.match(stripped)
    if constant and not re.search(r"(?:^|\s)[a-z]+\s+[a-z]+[^()\[\]{}]*\.$", constant.group(1)):
        return True
    if _SQL_CREATE_RE.match(stripped) or _EXPORTED_FUNCTION_RE.match(stripped):
        return True
    if unindented and (_C_FUNCTION_RE.match(stripped) or _SIGNATURE_RE.match(stripped)):
        return True
    modifiers, word, separator, rest = _lead(stripped)
    if word is None and modifiers and _CONSTANT_RE.match(rest):
        return True
    if word is None or word in _CONTROL_WORDS:
        return bool(modifiers) and _METHOD_RE.match(rest) is not None
    names_next = bool(separator) and not separator.strip() and bool(re.match(r"[A-Za-z_$(]", rest))
    if (word in _DECLARATION_WORDS and names_next) or (word in _NAMELESS_DECLARATIONS and separator):
        return True
    if unindented and word in _TOP_LEVEL_WORDS and names_next:
        return True
    text = f"{word}{separator}{rest}"
    if unindented and modifiers and _TYPED_VALUE_RE.match(text):
        return True
    if modifiers:
        return _METHOD_RE.match(text) is not None
    if not text.rstrip().endswith("{") or " => " in text or _METHOD_RE.match(text) is None:
        return False
    inside = text[text.find("(") + 1 : text.rfind(")")] if ")" in text else ""
    return not re.search(r"=>|->|[\"'`]|\w\s*\(", inside)
    The heuristic filters out control-flow structures, callback invocations (such as describe('x', () => {), and inline expressions, identifying lines likely to introduce named symbols.

    import_statement_like()

    Visibility: Public
    Signature: def import_statement_like(line: str) -> bool:

    Description: Determines whether a line is an import statement across various programming languages. Validates keyword-led imports (import, from, require, use), dynamic import calls, and shell source dots (. ./file.sh). Filters out prose sentences, block openers (import (), assignments (source = x), and attribute accesses (import.meta).

    # Sourced from utils/facts.py
def import_statement_like(line: str) -> bool:
    stripped = _ANNOTATIONS_RE.sub("", line.strip())  # @testable import X
    if stripped.startswith("#") and not stripped[1:2].isalpha():
        return False
    if stripped.startswith(("'", '"', "`")):
        return False
    if _IMPORT_CALL_RE.search(stripped) and not stripped.startswith(("//", "/*", "*")):
        return True
    if re.match(r"^\.\s+[\"'$./\w]", stripped):  # shell: . ./lib/env.sh
        return True
    if not _import_like(stripped):
        return False
    words = _words(stripped.lstrip("#@"))
    while words and words[0] in _MODIFIERS:
        words = words[1:]
    after = stripped.lstrip("#@").split(words[0], 1)[1].lstrip()
    if not after or after in ("(", "{", "["):
        return False
    if after[0] in _NOT_IMPORT_AFTER:
        return False
    if after[0] == "." and words[0] != "from" and after[1:2] not in ("/", "."):

    Visibility: Private
    Signature: def _resolve_relative(self, target: str, source_path: str, source_words: set) -> tuple[list[str], str] | None:

    Description: Resolves relative import targets (./x, ../x, leading dots, Rust super) against the source file's directory.

    # Sourced from utils/facts.py
    def _resolve_relative(self, target: str, source_path: str, source_words: set) -> tuple[list[str], str] | None:
        text = target.strip().strip("\"'`<>()[];,").replace("\\", "/")
        parent = re.match(r"^super(?:::(.*))?$", text)
        if parent:
            directory = posixpath.dirname(source_path)
            if _stem(source_path) in _INDEX_STEMS:
                directory = posixpath.dirname(directory)
            rest = [part for part in (parent.group(1) or "").split("::") if part and _SEGMENT_RE.match(part)]
            for size in range(len(rest), 0, -1):
                base = posixpath.join(directory, *rest[:size])
                hits = [path for path in self.paths if path != source_path and os.path.splitext(path)[0] == base]
                if len(hits) == 1:
                    return hits, "path"
            index_file = self._index_file(directory)
            return ([index_file], "package") if index_file and index_file != source_path else ([], "external")
        dots = re.match(r"^(\.+)(\w[\w.]*)$", text)
        if dots:
            text = "../" * (len(dots.group(1)) - 1) + "./" + dots.group(2).replace(".", "/")
        if not text.startswith(("./", "../")):
            return None
        base = posixpath.normpath(posixpath.join(posixpath.dirname(source_path), text))
        resolved = self._resolve_rooted(base, source_path, source_words)
        if resolved is not None:
            return resolved
        if dots:
            return [], "external"
        return None
    Handles Python relative imports (..core.engine) by converting leading dots to relative path segments before resolution.

    Visibility: Private
    Signature: def _resolve_in_package(self, package: dict, rest: list[str], source_path: str, source_words: set) -> list[str]:

    Description: Resolves sub-paths within a manifest package, checking package roots, nested subdirectories, re-exported barrel files, and owned symbols.

    # Sourced from utils/facts.py
    def _resolve_in_package(self, package: dict, rest: list[str], source_path: str, source_words: set) -> list[str]:
        directory = package["dir"]
        under = [path for path in self.paths if path != source_path and (not directory or path.startswith(directory + "/"))]
        root = self._package_root(package, under, source_path, source_words)
        if not rest:
            return root
        for size in range(len(rest), 0, -1):
            tail = rest[:size]
            for fold in (str, str.casefold):
                wanted = [fold(part) for part in tail]
                hits = [path for path in under if [fold(part) for part in self.segments[path][-len(tail) :]] == wanted]
                if len(hits) == 1:
                    return hits
                dirs = [
                    d
                    for d in self.by_dir
                    if (not directory or d == directory or d.startswith(directory + "/"))
                    and [fold(part) for part in d.split("/")[-len(tail) :]] == wanted
                ]
                if len(dirs) == 1:
                    index_file = self._index_file(dirs[0])
                    used = [
                        path
                        for path in self.by_dir[dirs[0]]
                        if path != source_path and (path == index_file or self.used_names(path, source_path, source_words))
                    ]
                    if used:
                        return used
                if hits or dirs:
                    break
        if len(rest) == 1 and len(root) == 1 and rest[0] in _words(self.contents.get(root[0], "")):
            return root
        owner = self.symbol_owner.get(rest[-1])
        return [owner] if owner in under else []

    Error Handling

    facts.py avoids raising unhandled exceptions during verification, treating extraction discrepancies as data points rather than fatal failures:

    • Unparsed LLM Responses: If an LLM response cannot be parsed as valid YAML upstream, an integer count is recorded in claims["unparsed"]. verify_file_claims() and verify_manifest_claims() convert these directly into rejected claim records ({"kind": "unparsed", "reason": "reply item that is not valid YAML"}), keeping coverage statistics balanced.
    • Corrupted or Missing Files: load_facts() handles file access and JSON parsing errors by catching (OSError, ValueError) and returning an empty dictionary ({}). Similarly, source_commit() handles Git subprocess failures by catching (OSError, subprocess.SubprocessError) and returning None.
    • Ambiguous Symbol Resolution: When a member's signature matches multiple locations in a file and parent scope boundaries cannot disambiguate them, the claim is rejected with "signature matches several lines; the parent does not tell them apart". Top-level signatures matching multiple lines are retained at their first occurrence and annotated with ambiguous_lines.
    • Atomic Persistence: save_facts() guards against corrupted state files caused by process termination during I/O by writing to a temporary file (.tmp) before calling os.replace().
