    facts.py

    Source: utils/facts.py

    Technical Overview

    The utils/facts.py module implements deterministic, language-agnostic code fact verification across the repository. In the documentation generation pipeline, Large Language Models (LLMs) inspect repository files and emit structured assertions regarding symbols, module dependencies, configuration keys, and error conditions, accompanied by line-level quote evidence. Rather than employing language-specific Abstract Syntax Tree (AST) parsers, this module verifies whether LLM claims correspond verbatim to physical source lines, resolves their line boundaries, verifies lexical enclosing structures, and tracks module dependencies across multi-package projects.

    Source files undergo text normalization and indexing via SourceIndex, which prepares Unicode NFC-normalized views, whitespace-collapsed single-line representations, fully squashed character offsets, and an inverted word-token line index. Quoted evidence is matched using a tiered search strategy: single-line collapsed string matching, multi-line squashed matching bounded by a line window, and ordered token subsequence searches. Symbols are bound to their declared parents by tracking hierarchical indentation blocks and container keywords across diverse programming language conventions.

    For cross-module analysis, ModuleTable aggregates project manifests (such as package.json, Cargo.toml, or pom.xml), directory structures, and unique symbol ownership maps. It resolves raw import strings—including relative imports, path aliases, package barrel exports, and wildcard namespaces—against actual project files. The module enforces the strict "evidence rule": a claimed dependency is accepted only if the quoted line names the target module, references a path matching the module, or uses a symbol owned exclusively by that module.

    SourceIndex

    Visibility: Public

    Signature: class SourceIndex:

    Description: An in-memory search index built for a single source file. It normalizes text via Unicode NFC, maintains whitespace-collapsed and whitespace-free ("squashed") linear buffers with line-offset indexes, and indexes word tokens in an inverted map for multi-line and token-fallback matching.

    SourceIndex.__init__()

    Visibility: Public

    Signature: def __init__(self, content: str):

    Description: Initializes the SourceIndex instance by splitting and normalizing content, calculating cumulative line offsets for exact and squashed buffers, and constructing inverted token indexes.

    Parameters:

    • content (str): Raw source file content.

    Returns:

    • None

    Example:

    def __init__(self, content: str):
    self.lines = split_lines(_nfc(content))
    self.collapsed = [_collapse(line) for line in self.lines]
    # Collapsed lines joined by "\n" (never inside a collapsed line or quote, so no match spans two lines)
    self.collapsed_text = "\n".join(self.collapsed) + "\n"
    self.collapsed_offsets = list(accumulate((len(line) + 1 for line in self.collapsed), initial=0))
    squashed = [_squash(line) for line in self.lines]
    # All lines without whitespace, back to back, with each line's start offset: one str.find per quote
    self.squashed_text = "".join(squashed)
    self.offsets = list(accumulate((len(line) for line in squashed), initial=0))
    self.words = [_words(line) for line in self.lines]
    self.word_sets = [set(words) for words in self.words]
    self.word_lines = defaultdict(list)  # word → lines it occurs on, for the token fallback
    for number, words in enumerate(self.word_sets):
        for word in words:
            self.word_lines[word].append(number)
    self._chains = None  # block_chain(), built on first use

    The constructor computes cumulative length offsets using itertools.accumulate for both the whitespace-collapsed lines buffer (collapsed_offsets) and the whitespace-removed squashed buffer (offsets). It pre-tokenizes each line into word lists and populates word_lines, mapping every token to the list of line indices where it appears. Block hierarchy chains (self._chains) are initialized as None and lazily calculated when requested.

    SourceIndex.locate()

    Visibility: Public

    Signature: def locate(self, quote, start: int = 0, end: int | None = None) -> list[tuple[int, int, str]]:

    Description: Finds 0-based line ranges matching a target quote within the line window between start and end. Executes a three-tiered fallback search: exact single-line collapsed matching, multi-line squashed matching within a sliding window, and ordered token sequence matching.

    Parameters:

    • quote (Any): The search string or object convertible to string representing the quote evidence.
    • start (int): 0-based line index at which to begin searching. Defaults to 0.
    • end (int | None): 0-based line index upper boundary. Defaults to None (searches to end of file).

    Returns:

    • list[tuple[int, int, str]]: A list of matches formatted as (first_line, last_line, match_mode), where match_mode is "exact", "joined", or "tokens".

    Example:

    end = len(self.lines) if end is None else min(end, len(self.lines))
collapsed = _collapse(quote)
if not collapsed or start >= end:
    return []
exact = []
pos = self.collapsed_text.find(collapsed, self.collapsed_offsets[start])
while 0 <= pos < self.collapsed_offsets[end]:
    line = bisect_right(self.collapsed_offsets, pos) - 1
    exact.append((line, line, "exact"))
    pos = self.collapsed_text.find(collapsed, self.collapsed_offsets[line + 1])  # next line: one hit per line
if exact:
    return exact
# ...

    The matching hierarchy begins with single-line collapsed string matching against collapsed_text. Binary search via bisect_right resolves character positions to line indices. If no exact match occurs, it searches squashed_text for joined multi-line matches spanning at most window lines. If joined matching fails, it evaluates ordered word tokens using the rarest token in word_lines as a search anchor.

    SourceIndex.excerpt()

    Visibility: Public

    Signature: def excerpt(self, first: int, last: int, quote) -> tuple[str, bool]:

    Description: Extracts a representative snippet of source code spanning lines first through last, capped at _EXCERPT (300) characters. If the snippet exceeds this threshold, it centers a 300-character window around the matched quote.

    Parameters:

    • first (int): 0-based starting line index.
    • last (int): 0-based ending line index.
    • quote (Any): The quote string to center around if truncation is required.

    Returns:

    • tuple[str, bool]: A tuple containing (excerpt_text, is_truncated).

    Example:

    def excerpt(self, first: int, last: int, quote) -> tuple[str, bool]:
    text = self.text(first, last).strip()
    if len(text) <= _EXCERPT:
        return text, False
    flat, wanted = _collapse(text), _collapse(quote)
    pos = max(flat.find(wanted), 0)
    start = max(0, min(pos - max(0, (_EXCERPT - len(wanted)) // 2), len(flat) - _EXCERPT))
    return flat[start : start + _EXCERPT], True

    The method retrieves the raw text slice between first and last. When the length is within 300 characters, it returns the text unmodified with False. For longer text, it collapses whitespace and calculates an excerpt window centered on the target quote, returning the 300-character slice marked as True for truncation.

    verify_file_claims()

    Visibility: Public

    Signature: def verify_file_claims(claims: dict, content: str) -> dict:

    Description: Audits LLM-extracted claims for a single file against its source content. Verifies symbols, dependencies, configuration keys, and errors, calculating physical 1-based line numbers, multi-line spans, excerpt strings, and error handling roles.

    Phase 1: Symbol Verification and Top-level Resolution

    index = SourceIndex(content)
result = {key: [] for key in CLAIM_KEYS}
rejected = []

unparsed = claims.get("unparsed", 0) if isinstance(claims, dict) and isinstance(claims.get("unparsed"), int) else 0

    claimed += unparsed
    rejected.extend({"kind": "unparsed", "reason": "reply item that is not valid YAML"} for _ in range(unparsed))

kept, symbol_rejects = _verify_symbols(symbols, index)

rejected += symbol_rejects

    The function constructs a SourceIndex over the file content. Any pre-flagged unparsed YAML reply items are counted toward total claims and directly appended to the rejected queue. Symbol claims are extracted and processed via _verify_symbols, which establishes parent-child relationships and checks signatures.

    Phase 2: Dependency Evidence Matching

    for item in _claim_list(claims, "dependencies"):
    claimed += 1
    target, evidence = _as_text(item.get("target")).strip(), _as_text(item.get("evidence"))
    matches = index.locate(evidence) if target else []
    if not matches:
        rejected.append({"kind": "dependency", "target": target, "evidence": evidence, "reason": "evidence not in source"})
        continue
    first, last, how = matches[0]
    text, truncated = index.excerpt(first, last, evidence)
    entry = {"target": target, "line": first + 1, **_end(first, last), "evidence": text, "match": how}

    Each dependency claim is checked by searching for its evidence quote in the SourceIndex. If the quote cannot be located in the file, the dependency claim is rejected. When located, the entry records 1-based line numbers, matching technique (exact, joined, or tokens), and excerpted evidence text.

        first, last, how, extended = matches[0]
        # ...

    Config keys and error claims are matched against the index. If an evidence quote begins a multi-line function call (such as argparse.add_argument() but the argument name appears on a subsequent line, _call_span extends the line boundary. For error claims, _error_role inspects surrounding keywords to classify the error as raised, caught, or mentioned.

    Phase 4: Fact Deduplication and Span Narrowing

    for key, fields in (("symbols", ("parent", "name")), ("dependencies", ("target",)), ("config", ("name",)), ("errors", ("name",))):
    seen, unique = set(), []
    for entry in result[key]:
        marker = (*(entry.get(field) for field in fields), entry["line"])
        if marker not in seen:
            seen.add(marker)
            unique.append(entry)
    if key in ("config", "errors"):
        narrow_first = sorted(unique, key=lambda e: e.get("end_line", e["line"]) - e["line"])
        kept_spans = []
        for entry in narrow_first:
            low, high = entry["line"], entry.get("end_line", entry["line"])
            if not any(other["name"] == entry["name"] and low <= other["line"] <= high for other in kept_spans):
                kept_spans.append(entry)
        unique = [entry for entry in unique if any(entry is other for other in kept_spans)]
    claimed -= len(result[key]) - len(unique)
    result[key] = unique
result["rejected"] = rejected
result["claimed"] = claimed
result["found"] = claimed - len(rejected)
return result

    Duplicate claims sharing identical identities and start lines are pruned. For configuration and error items where overlapping matches occur across expanded and unexpanded spans, the narrowest line span is preserved. The final dictionary reports verified claims, rejected claims with diagnostic reasons, total claimed items, and confirmed items found.

    Parameters:

    • claims (dict): Raw dictionary of claims returned by an LLM prompt.
    • content (str): Decoded source file text.

    Returns:

    • dict: Verified claims dictionary structured with keys symbols, dependencies, config, errors, rejected, claimed, and found.

    Visibility: Public

    Signature: def code_view(lines: list[str]) -> list[str]:

    Description: Returns a sanitized view of the source lines with comments, docstrings, and multi-line string literals blanked out while preserving exact line numbers and column alignments. Skips globs such as lib/*.sh and ensures block comments are correctly paired.

    Parameters:

    • lines (list[str]): List of raw source lines.

        dropped = parts[: len(parts) - size]
        alias = not re.match(r"\w", dropped[0]) and not (self.packages or self.aliases)
        return alias or declares_namespace(self.contents.get(path, ""), dropped[-1]) or bool(self.used_names(path, source_path, source_words))
    if len(parts) == 1 and not _is_relative(target):
        directory, source_dir = posixpath.dirname(path), posixpath.dirname(source_path)
        ancestor = not directory or source_dir == directory or source_dir.startswith(directory + "/")
        return ancestor or bool(self.used_names(path, source_path, source_words))
    return True

    If leading segments were discarded (e.g., matching app/utils.py for email.utils), corroboration requires a sigil alias, a matching namespace declaration in the target, or shared symbol usage. Bare single-part names matching distant directories require directory ancestry or shared symbols.

    Visibility: Private

    Signature: def _imports_target(evidence: str, target: str) -> bool:

    Description: Checks if evidence imports target via an import statement, a Go import block, a quoted specifier, or inline qualified code usage.

    Parameters:

    • evidence (str): Evidence text.

    Returns:

    Example:

    Error Handling

    The module employs defensive error isolation patterns to prevent invalid LLM inputs or missing files from interrupting the documentation generation process:

    • Unparsed Claim Recovery: Malformed JSON/YAML blocks identified during extraction passes are passed as claims["unparsed"]. verify_file_claims increments the claimed count and adds corresponding entries to rejected with descriptive reasons rather than raising exceptions.
    • Corrupted Cache Handling: In load_facts(), file read failures (OSError) or JSON decoding errors (ValueError) are caught, returning an empty dictionary ({}). Schema version mismatches are checked silently to trigger cache invalidation.
    • Atomic File Writes: save_facts() writes JSON documents to an adjacent temporary file (f"{path}.tmp") and swaps it via os.replace(). This prevents corrupted facts files if execution terminates during disk writes.
    • Subprocess Isolation: Git command execution in source_commit() uses timeout=10 and handles OSError and subprocess.SubprocessError, returning None if the local directory lacks a Git environment or fails to respond.
    • Ambiguity Rejection: In _verify_symbols() and judge_dependency(), when an identifier matches multiple candidate lines or modules without sufficient context to differentiate them, the claim is rejected with reason "signature matches several lines" or "target matches several modules".
