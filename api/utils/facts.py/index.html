    facts.py

    Source: utils/facts.py

    Technical Overview

    utils/facts.py implements a language-agnostic verification engine that validates LLM-extracted claims against actual repository source code. Documentation generation pipelines frequently ingest large language model (LLM) assertions regarding symbols, import dependencies, configuration keys, and error roles. Rather than relying on heavyweight, language-specific abstract syntax tree (AST) parsers that fail on polyglot repositories or non-standard syntax, this module adopts a deterministic textual and lexical verification strategy. A claimed fact is accepted only when its accompanying verbatim source quote can be located within the physical file—either as a single-line collapsed match, a multiline squashed string span, or an in-order identifier token sequence.

    The module operates across two distinct execution phases: per-file verification and cross-module resolution. In the per-file phase, verify_file_claims consumes raw claims, instantiates a SourceIndex to locate quotes, calculates 1-based line intervals, determines error roles (raised, caught, or mentioned), and rejects hallucinations with explanatory diagnostic strings. In the cross-module phase, ModuleTable aggregates symbols across all documented files alongside workspace manifest definitions (package.json, Cargo.toml, go.mod, etc.). It cross-references relative imports, aliased module paths, directory index conventions, and namespace declarations to resolve claimed dependency targets to real physical file paths.

    Verified facts are compiled into an immutable JSON document structure conforming to schema version 1 (facts.json). Downstream consumers—including documentation chapter generators and static quality gates like chapter_check.py—use this document to verify code citations, detect missing architectural dependencies, and prevent hallucinated symbols from appearing in published developer guides.

    split_lines()

    Visibility: Public

    Signature: def split_lines(content: str) -> list[str]:

    Description: Splits source file text into discrete lines strictly across CR (\r), LF (\n), and CRLF (\r\n) boundaries. Trailing empty lines resulting from a final newline delimiter are stripped to align 1-based line indexing with standard text editors and GitHub diff counters.

    Parameters:

    • content (str): Raw text content of a source file.

    Returns:

    • list[str]: List of lines preserving leading and trailing internal whitespace.

    Example:

    def split_lines(content: str) -> list[str]:
    """Lines as editors and GitHub number them (only CR, LF, CRLF break a line)."""
    lines = _LINE_BREAK_RE.split(content)
    return lines[:-1] if lines and lines[-1] == "" else lines

    The function relies on the precompiled regular expression _LINE_BREAK_RE = re.compile(r"\r\n|\r|\n"). Unlike Python's standard str.splitlines(), which splits on additional Unicode boundaries such as form feed (\f), vertical tab (\v), next line (\x85), line separator (\u2028), and paragraph separator (\u2029), split_lines restricts line termination to byte sequences recognized by source control and editors.

    SourceIndex

    Visibility: Public

    Signature: class SourceIndex:

    Description: In-memory text normalization and index structure for a single source file. Pre-computes normalized representations (Unicode NFC), whitespace-collapsed lines, squashed text, and word token occurrence maps to perform rapid, multi-strategy quote location.

    SourceIndex.__init__()

    Visibility: Public

    Signature: def __init__(self, content: str):

    Description: Initializes the index by calculating cumulative line offset arrays, squashed string mappings, and an inverted index of token occurrences across lines.

    Parameters:

    • content (str): Raw file text.

    Example:

        def __init__(self, content: str):
        self.lines = split_lines(_nfc(content))
        self.collapsed = [_collapse(line) for line in self.lines]
        # Collapsed lines joined by "\n" (never inside a collapsed line or quote, so no match spans two lines)
        self.collapsed_text = "\n".join(self.collapsed) + "\n"
        self.collapsed_offsets = list(accumulate((len(line) + 1 for line in self.collapsed), initial=0))
        squashed = [_squash(line) for line in self.lines]
        # All lines without whitespace, back to back, with each line's start offset: one str.find per quote
        self.squashed_text = "".join(squashed)
        self.offsets = list(accumulate((len(line) for line in squashed), initial=0))
        self.words = [_words(line) for line in self.lines]
        self.word_sets = [set(words) for words in self.words]
        self.word_lines = defaultdict(list)  # word → lines it occurs on, for the token fallback
        for number, words in enumerate(self.word_sets):
            for word in words:
                self.word_lines[word].append(number)
        self._chains = None  # block_chain(), built on first use

    The constructor converts text to Unicode NFC format so that precomposed characters emitted by LLMs match decomposed filesystem bytes. It precomputes two parallel search vectors: collapsed_text (internal whitespace collapsed to single spaces with newline separators) and squashed_text (all whitespace removed). Line offsets are maintained using itertools.accumulate, allowing string offset matches found via str.find to be mapped to 0-based line indices via binary search (bisect_right).

    SourceIndex.locate()

    Visibility: Public

    Signature: def locate(self, quote, start: int = 0, end: int | None = None) -> list[tuple[int, int, str]]:

    Description: Locates occurrences of an extracted code quote within an optional line range start to end. The search progressively executes three match strategies: exact single-line match, joined multiline squashed match, and in-order rare token fallback.

    Phase 1: Exact Collapsed Match
            end = len(self.lines) if end is None else min(end, len(self.lines))
        collapsed = _collapse(quote)
        if not collapsed or start >= end:
            return []
        exact = []
        pos = self.collapsed_text.find(collapsed, self.collapsed_offsets[start])
        while 0 <= pos < self.collapsed_offsets[end]:
            line = bisect_right(self.collapsed_offsets, pos) - 1
            exact.append((line, line, "exact"))
            pos = self.collapsed_text.find(collapsed, self.collapsed_offsets[line + 1])  # next line: one hit per line
        if exact:
            return exact

    The exact search collapses consecutive whitespace inside the search quote and searches self.collapsed_text. Because each collapsed line in the search corpus is separated by \n and _collapse strips all line breaks, an exact match is guaranteed to reside entirely on a single line. The line number is located by binary searching self.collapsed_offsets.

    Phase 2: Multiline Squashed Match
            window = max(_WINDOW, len(split_lines(str(quote))) + 1)
        squashed = _squash(quote)
        joined = []
        pos = self.squashed_text.find(squashed, self.offsets[start])
        while 0 <= pos < self.offsets[end]:
            first = bisect_right(self.offsets, pos) - 1
            last = bisect_right(self.offsets, pos + len(squashed) - 1) - 1
            if last - first < window and last < end:
                joined.append((first, last, "joined"))
            pos = self.squashed_text.find(squashed, pos + 1)
        if joined:
            return list(dict.fromkeys(joined))

    If single-line collapsed matching yields no hits, the engine strips all whitespace from both the quote and the file text. This accommodates quotes spanning line wraps, chained function calls, or multiline parameter lists. Matches are accepted only if the span between first and last line does not exceed window (derived from _WINDOW = 8 or the quote's natural line count).

    Phase 3: Rare Token Fallback Search
            words = _words(quote)
        if len(words) < _MIN_TOKEN_QUOTE or any(word not in self.word_lines for word in words):
            return []
        # Only windows around the quote's rarest word can hold all of its words
        rarest = min((self.word_lines[word] for word in words), key=len)
        starts = sorted({i for line in rarest for i in range(max(start, line - window + 1), min(line + 1, end))})
        found = []
        for i in starts:
            if words[0] not in self.word_sets[i]:
                continue
            last = self._words_in_order(words, i, min(i + window, end))
            if last is not None:
                found.append((i, last, "tokens"))
        return found

    When squashed matching fails, the method attempts to match identifier tokens in order. This handles cases where an LLM quotes a statement along with a distant keyword (such as prepending import to an item inside a Go parenthesized import block). The rarest token in the quote is identified to constrain candidate window starting positions before executing _words_in_order.

    Parameters:

    • quote (Any): The code string or expression to locate.
    • start (int, optional): 0-based lower bound line index. Defaults to 0.
    • end (int | None, optional): 0-based upper bound line index. Defaults to None.

    Returns:

    • list[tuple[int, int, str]]: Tuples of (first_line, last_line, match_kind) where match_kind is "exact", "joined", or "tokens".

    SourceIndex.excerpt()

    Visibility: Public

    Signature: def excerpt(self, first: int, last: int, quote) -> tuple[str, bool]:

    Description: Extracts a normalized snippet of source code bounded by _EXCERPT (300 characters) surrounding the matched quote within lines first through last.

    Parameters:

    • first (int): Starting 0-based line index.
    • last (int): Ending 0-based line index.
    • quote (Any): The target search quote.

    Returns:

    • tuple[str, bool]: A 2-tuple containing the extracted snippet string and a boolean flag indicating whether the text was truncated.

    Example:

        def excerpt(self, first: int, last: int, quote) -> tuple[str, bool]:
        """The matched source text, at most ``_EXCERPT`` characters around the quote: ``(text, truncated)``. A
        quote longer than the window keeps its start (a long signature keeps its keyword and name)."""
        text = self.text(first, last).strip()
        if len(text) <= _EXCERPT:
            return text, False
        flat, wanted = _collapse(text), _collapse(quote)
        pos = max(flat.find(wanted), 0)
        start = max(0, min(pos - max(0, (_EXCERPT - len(wanted)) // 2), len(flat) - _EXCERPT))
        return flat[start : start + _EXCERPT], True

    The method prevents minified or unusually dense code blocks from bloating stored verification records. If the extracted block exceeds 300 characters, it centers a 300-character window around the matched quote, preserving immediate context while marking truncated = True.

    verify_file_claims()

    Visibility: Public

    Signature: def verify_file_claims(claims: dict, content: str) -> dict:

    Description: Audits LLM-extracted claims for a single source file against its actual text. Verifies symbols, dependencies, configuration items, and error handling constructs, resolving exact 1-based source lines and rejecting ungrounded claims.

    Phase 1: Initialization and Unparsed Claims Handling

        index = SourceIndex(content)
    result = {key: [] for key in CLAIM_KEYS}
    rejected = []
    claimed = 0
    unparsed = claims.get("unparsed", 0) if isinstance(claims, dict) and isinstance(claims.get("unparsed"), int) else 0
    if unparsed:
        claimed += unparsed
        rejected.extend({"kind": "unparsed", "reason": "reply item that is not valid YAML"} for _ in range(unparsed))

    symbols = _claim_list(claims, "symbols")
    claimed += len(symbols)
    kept, symbol_rejects = _verify_symbols(symbols, index)
    result["symbols"] = kept
    rejected += symbol_rejects

    The function initializes a SourceIndex and sets up tracking accumulators. Any items flagged as unparsed YAML during upstream LLM parsing are counted toward total claims and registered directly in the rejected list. Claimed symbols are delegated to _verify_symbols for scope-aware resolution.

    Phase 2: Dependency Claim Location

        for item in _claim_list(claims, "dependencies"):
        claimed += 1
        target, evidence = _as_text(item.get("target")).strip(), _as_text(item.get("evidence"))
        matches = index.locate(evidence) if target else []
        if not matches:
            rejected.append({"kind": "dependency", "target": target, "evidence": evidence, "reason": "evidence not in source"})
            continue
        first, last, how = matches[0]
        text, truncated = index.excerpt(first, last, evidence)
        entry = {"target": target, "line": first + 1, **_end(first, last), "evidence": text, "match": how}
        result["dependencies"].append({**entry, "truncated": True} if truncated else entry)

    Dependencies are located based on their evidence string. If the evidence cannot be grounded in the source text, the dependency claim is rejected. Accepted claims record 1-based start and end lines alongside the match type.

    Phase 3: Configuration and Error Verification

        for key in ("config", "errors"):
        for item in _claim_list(claims, key):
            claimed += 1
            name, evidence = _as_text(item.get("name")).strip(), _as_text(item.get("evidence"))
            # A quote that opens a multi-line call (`parser.add_argument(`) also covers the call's lines when the
            # name is not on its own lines (`extended`)
            matches = []
            for first, last, how in index.locate(evidence) if name else []:
                if _names_in(index.text(first, last), name):
                    matches.append((first, last, how, False))
                    continue
                end = _call_span(index, first, last)
                if end > last and _names_in(index.text(first, end), name):
                    matches.append((first, end, how, True))
            if not matches:
                rejected.append({"kind": key, "name": name, "evidence": evidence, "reason": "name/evidence not in source"})
                continue
            # Of several places: the name used in code, then written as a whole string, then only mentioned in
            # prose; the quote's own lines before extended spans; for errors, raising before handling
            roles = {m: _error_role(index, m[0], m[1], name) for m in matches} if key == "errors" else {}
            matches.sort(key=lambda m: (_ROLE_RANK.get(roles.get(m), 0), _name_rank(index.text(m[0], m[1]), name), m[3]))
            first, last, how, extended = matches[0]
            text, truncated = index.excerpt(first, last, evidence)
            if extended and not _names_in(text, name):  # a long call: center the stored text on the name
                text, truncated = index.excerpt(first, last, name)
            entry = {"name": name, "line": first + 1, **_end(first, last), "evidence": text, "match": how}
            if key == "config":
                entry["kind"] = _as_text(item.get("kind")).strip() or "config"
            else:
                entry["role"] = roles[matches[0]]
            result[key].append({**entry, "truncated": True} if truncated else entry)

    Configuration items and errors undergo call-span expansion via _call_span if the item name appears within an unclosed bracket expression (such as add_argument(...)). Candidate matches are ranked by code occurrence priority, string literal priority, and error handling role (raising takes precedence over handling, which takes precedence over mention).

    Phase 4: Span Deduplication and Summary

        # One fact quoted twice (a whole signature and its first line, an import and its block) is kept once; a
    # config key or error found both on a call's line and inside its extended span keeps the narrower place
    for key, fields in (("symbols", ("parent", "name")), ("dependencies", ("target",)), ("config", ("name",)), ("errors", ("name",))):
        seen, unique = set(), []
        for entry in result[key]:
            marker = (*(entry.get(field) for field in fields), entry["line"])
            if marker not in seen:
                seen.add(marker)
                unique.append(entry)
        if key in ("config", "errors"):
            narrow_first = sorted(unique, key=lambda e: e.get("end_line", e["line"]) - e["line"])
            kept_spans = []
            for entry in narrow_first:
                low, high = entry["line"], entry.get("end_line", entry["line"])
                if not any(other["name"] == entry["name"] and low <= other["line"] <= high for other in kept_spans):
                    kept_spans.append(entry)
            unique = [entry for entry in unique if any(entry is other for other in kept_spans)]
        claimed -= len(result[key]) - len(unique)
        result[key] = unique
    result["rejected"] = rejected
    result["claimed"] = claimed
    result["found"] = claimed - len(rejected)
    return result

    The final phase removes duplicate claims where multiple quotes overlap the same identity fields and line coordinates. For configuration keys and errors, if both an extended call span and an exact inner line are captured, the narrower span is preserved.

    Parameters:

    • claims (dict): Raw claims dictionary extracted by the LLM.
    • content (str): File source text.

    Returns:

    • dict: Verified results dictionary containing symbols, dependencies, config, errors, rejected, claimed, and found.

    Signature: def code_view(lines: list[str]) -> list[str]:

    Description: Strips block comments, inline comments, and multiline docstrings while preserving line counts and line indices. Replaces non-code tokens with blank spaces or empty strings so that language-agnostic heuristics are not confused by prose or commented-out declarations.

    Parameters:

    • lines (list[str]): List of original source lines.

    Returns:

    Example:

    def code_view(lines: list[str]) -> list[str]:
    last = {}  # closer → (line, column) of its last occurrence

    Description: Verifies that a claimed dependency target string is explicitly written within the quoted evidence line, rather than being an LLM paraphrase or hallucination.

    def target_written(target: str, evidence: str) -> bool:
    text = _collapse(target.strip().strip("\"'`<>()[];,"))
    if not text:
        return False
    if re.search("[\"'`]", text) and text in _collapse(evidence):  # the whole expression copied: __DIR__ . '/src/Db.php'
        return True
    first = (_words(text) or [""])[0]
    quoted = [q for q in re.findall(r"(?=[\"'`<]([^\"'`<>\s]+)[\"'`>])", evidence) if re.search(r"[/.]", q) or (first and first in _words(q))]
    if quoted:  # whole, or the end of a path built at run time: "$(dirname "$0")/../lib/log.sh", __DIR__ . '/src/Db.php'
        bare = _bare_path(text)
        if any(_bare_path(q) == bare or q.endswith("/" + bare) for q in quoted):
            return True
        # the static part of a path built from a template: require(`./plugins/${name}`) → ./plugins
        if any(_bare_path(q).startswith(bare + "/") and re.search(r"[$#%]\{|\{\w", _bare_path(q)[len(bare) :]) for q in quoted):
            return True
    code = _without_bindings(re.sub(r"\"(?:\\.|[^\"\\])*\"|'(?:\\.|[^'\\])*'|`[^`]*`", " ", evidence))
    if quoted and not _words(code):
        return False
    wanted, have = _words(text), _words(code)
    position = 0
    for word in have:
        if position < len(wanted) and word == wanted[position]:
            position += 1
    return bool(wanted) and position == len(wanted) and not quoted

    The function handles string literals, dynamically concatenated paths (such as __DIR__ . '/src/Db.php'), and template strings (require(\./plugins/${name}`)).         if len(parts) == 1 and not _is_relative(target):
            directory, source_dir = posixpath.dirname(path), posixpath.dirname(source_path)
            ancestor = not directory or source_dir == directory or source_dir.startswith(directory + "/")
            return ancestor or bool(self.used_names(path, source_path, source_words))
        return True

    _names_path()

    Visibility: Private

    Signature: def _names_path(evidence: str, name: str, extension: str, extensions: set) -> bool:

    Description: Checks whether name appears in evidence as part of a path or qualified module reference rather than an unadorned identifier.

    Parameters:

    • evidence (str): Evidence line text.
    • name (str): Candidate module stem name.
    • extension (str): Expected file extension.
    • extensions (set): Set of all project extensions.

    Returns:

    • bool: True if name is qualified by path delimiters, quotes, or file extensions.
    def _names_path(evidence: str, name: str, extension: str, extensions: set) -> bool:
    for match in re.finditer(rf"(?<!\w){re.escape(name)}(?!\w)", evidence):
        before = evidence[match.start() - 1] if match.start() else ""
        after = evidence[match.end() :]
        written = re.match(r"\.\w+", after)
        if written and written.group() in extensions and written.group() != extension:
            continue
        if before in _QUALIFIERS or (extension and after.startswith(extension)) or (after and after[0] in _CLOSERS):
            return True
    return False

    Visibility: Private

    Description: Checks whether name appears in evidence as a distinct token rather than referring to a sibling file with a different extension (e.g., socket in socket.h does not match socket.cpp).

    Visibility: Private

    Description: Strips local alias bindings (as alias, => alias, import x = y) from an import line so that only imported modules and symbols remain.

    _imports_target()

    Visibility: Private

    Signature: def _imports_target(evidence: str, target: str) -> bool:

    Description: Checks whether evidence actively imports target via an import statement, Go block specifier, or inline qualified code reference, excluding comments and string literals.

    Parameters:

    • evidence (str): Evidence line text.
    • target (str): Import target string.

    Returns:

    • bool: True if the target is imported.
    def _imports_target(evidence: str, target: str) -> bool:
    lines = split_lines(evidence)
    quoted = re.escape(target.strip().strip("\"'`<>"))
    if any(import_statement_like(line) or _GO_BLOCK_LINE_RE.match(line) for line in lines) or re.search(rf"[\"'`<]{quoted}[\"'`>]", evidence):
        return True
    for line in lines:
        stripped = line.strip()
        if stripped.startswith(("//", "#", "/*", "*", "--", ";")):
            continue
        code = re.sub(r"\"(?:\\.|[^\"\\])*\"|'(?:\\.|[^'\\])*'|`[^`]*`", " ", line)
        if re.search(rf"(?<![\w-]){quoted}(?:::|\.)\w", code):
            return True
    return False

    Error Handling

    The module implements a non-crashing, audit-style error handling architecture. Claims that fail verification are recorded in rejected lists with explicit reasons rather than raising fatal exceptions:

    # Example of non-fatal claim rejection inside verify_file_claims()
if not matches:
    rejected.append({"kind": "dependency", "target": target, "evidence": evidence, "reason": "evidence not in source"})
    continue

    Notable error and fallback patterns across the module include:

    • File System and Deserialization Trapping: load_facts() wraps file loading in a try...except (OSError, ValueError): block, returning an empty dictionary on missing files, permission errors, or invalid JSON.
    • Subprocess Isolation: source_commit() handles subprocess invocations within a try...except (OSError, subprocess.SubprocessError): guard with a 10-second timeout, gracefully returning None if git is unavailable or the directory is not a git repository.
    • Atomic File Updates: save_facts() writes serialized JSON to a temporary file (.tmp) before calling os.replace(), preventing corrupt or partial writes if the process is terminated mid-execution.
    • Progressive Search Fallbacks: SourceIndex.locate() uses a three-tier fallback (exact single-line match, squashed multiline match, rare token-order search) to tolerate variations in LLM formatting without throwing search errors.
    • Ambiguous Resolution Handling: When an import target matches multiple internal files without corroborating context, ModuleTable.resolve() returns ([], "ambiguous"), allowing judge_dependency() to record a rejection reason ("target matches several modules") rather than picking an arbitrary file.
