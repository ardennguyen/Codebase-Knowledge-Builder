    llm_gemini.py

    Source: utils/llm_gemini.py

    Following the configuration, credential resolution, and reasoning mode negotiation established in llm_config.py, llm_gemini.py serves as the dedicated execution harness and low-level transport adapter for the Google Gemini model family. It provides exclusive integration with the official google-genai SDK, isolating all Google-specific wire protocol management, payload transformations, streaming abstractions, and error translations away from the unified dispatcher in call_llm.py.

    Technical Overview

    llm_gemini.py implements an end-to-end execution pipeline for sending prompts to Google Gemini models across both Google AI Studio and Google Cloud Vertex AI backends. The module dynamically adapts to generation paradigms across model generations, supporting Gemini 3.x models that utilize discrete categorical thinking levels (ThinkingConfig.thinking_level) and Gemini 2.5 models that operate on explicit token thinking budgets (ThinkingConfig.thinking_budget). To ensure network resilience during lengthy reasoning chains, all model interactions are executed over server-sent event streams via generate_content_stream. The module sets an overall stream execution deadline (GEMINI_TIMEOUT_SECONDS, defaulting to 1,800 seconds) and enables native transport retries for transient HTTP status codes (408, 429, 500, 502, 503, 504).

    The module enforces strict parameter cleanliness by suppressing deprecated sampling parameters (e.g., temperature) that cause runtime failures on newer Gemini reasoning checkpoints. It automatically disables automatic function calling (AutomaticFunctionCallingConfig(disable=True)) to eliminate extraneous SDK warning chatter during plain-text streaming. When an upstream model unexpectedly rejects a configured thinking regime (returning an HTTP 400 containing think), the adapter executes an automatic self-healing fallback: it records the failure, notifies the telemetry pipeline, strips the reasoning configuration, and transparently replays the request without thinking controls for the remainder of the runtime session.

    Downstream response evaluation parses candidate structures, safety flags, and stream metadata to enforce deterministic accounting and cache integrity. Token usage metrics—spanning prompt inputs, candidate outputs, internal thoughts, and context cache reads—are calculated against Google's published multi-tiered pricing schedules, including regional Vertex markups and long-context surcharges for prompts exceeding 200,000 tokens. Generations terminating with MAX_TOKENS are intercepted and packaged as non-cacheable TruncatedResponse instances, while safety interventions, content blocks, and recitation limits are translated into LLMRefusalError exceptions tagged with retryability flags.

    Description: Resolves and returns the normalized Gemini model identifier configured for the current runtime execution. The function retrieves the model name from the GEMINI_MODEL environment variable, falling back to DEFAULT_GEMINI_MODEL if undefined, and strips Google-specific resource path prefixes such as models/ or publishers/google/models/ using gemini_model_id.

    Parameters: None.

    Returns: * str: The sanitized model name suitable for SDK client invocation (e.g., "gemini-3.1-pro", "gemini-2.5-flash").

    Raises: None.

    Example: 

    def get_model() -> str:
    """GEMINI_MODEL without a 'models/' or 'publishers/google/models/' resource prefix."""
    return gemini_model_id(os.getenv("GEMINI_MODEL") or DEFAULT_GEMINI_MODEL)
    The implementation delegates directly to gemini_model_id defined in utils.llm_config. It ensures that resource qualifiers provided in environment variables or configuration files do not cause lookup failures when passed to the client SDK's underlying RPC methods.

    get_model_limits()

    Visibility: Public Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Retrieves the maximum context input token limit and output token limit for a designated Gemini model. It maintains an in-memory dictionary cache (_model_limits_cache) to prevent redundant lookups. If the model limits are not cached, it initializes defaults from GEMINI_DEFAULT_LIMITS. When operating against Google AI Studio (indicated by the absence of GEMINI_PROJECT_ID), it attempts an active API inquiry via _get_client().models.get(model=model) to inspect runtime token bounds. If Vertex AI is active or the API query raises an exception, the lookup degrades safely to static limit mappings.

    Parameters: * model (str): The normalized model identifier whose limits are being queried.

    Returns: * tuple[int, int]: A 2-tuple containing (input_token_limit, output_token_limit).

    Raises: None. Exceptions raised during API metadata calls are caught and emitted as diagnostic warnings.

    Example: 

    def get_model_limits(model: str) -> tuple[int, int]:
    """(input_token_limit, output_token_limit). AI Studio reports them via models.get; Vertex does
    not (the SDK maps no limits there), so the static Gemini 3.x / 2.5 table applies."""
    if model in _model_limits_cache:
        return _model_limits_cache[model]
    limits = GEMINI_DEFAULT_LIMITS
    if not os.getenv("GEMINI_PROJECT_ID"):
        try:
            info = _get_client().models.get(model=model)
            limits = (getattr(info, "input_token_limit", None) or limits[0], getattr(info, "output_token_limit", None) or limits[1])
            emit_raw("DEBUG", f"Gemini models.get | model={model} | input={limits[0]:,} | output={limits[1]:,}", dest="LOG")
        except Exception as e:
            emit("WARN_GEMINI_MODEL_LOOKUP", model=model, error=str(e)[:200])
    _model_limits_cache[model] = limits
    return limits
    This function utilizes an in-memory caching pattern to optimize token budgeting calls across generation phases. Because the Google Cloud Vertex AI endpoint does not expose input and output limits through the models.get SDK contract, the implementation gates the remote network call to AI Studio environments. Any network failure or unexpected payload attribute gracefully preserves the conservative default limits defined in GEMINI_DEFAULT_LIMITS.

    call_gemini()

    Visibility: Public Signature: def call_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches a single-turn completion prompt to the configured Google Gemini model, processes the resultant server-sent event stream, records usage telemetry and billing estimations, and validates completion status flags.

    Parameters: * prompt (str): The primary instruction and contextual content sent to the model. * thinking_level (str | None, optional): Desired reasoning intensity level ("minimal", "low", "medium", "high"), an explicit numeric budget string, or None to leverage model defaults.

    Returns: * str: The fully accumulated text payload returned by the model. If generation was abruptly halted by output token ceilings, returns an instance of TruncatedResponse (a str subclass).

    Raises: * LLMRefusalError: If the generation candidate or prompt was halted due to content blocking, prohibited safety categories, reciting copyrighted material, or language constraints. * genai_errors.ClientError: If a non-400 Google client error occurs or an unrecoverable API error is encountered. * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment during client initialization.

    Phase 1: Request Assembly and Configuration

        from utils.token_utils import count_tokens_raw

    model = get_model()
    raw_tokens = count_tokens_raw(prompt)
    max_output = _max_output_tokens(model, thinking_level)
    thinking, level_desc = _thinking_config(model, thinking_level)
    # No tools are passed, so automatic function calling is off (google-genai warns on streams otherwise).
    no_afc = types.AutomaticFunctionCallingConfig(disable=True)
    config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=thinking, automatic_function_calling=no_afc)
    emit_raw(
        "DEBUG",
        f"Gemini request | model={model} | {level_desc} | max_output_tokens={max_output:,} | location={gemini_location() if os.getenv('GEMINI_PROJECT_ID') else 'ai-studio'}",
        dest="LOG",
    )
    In the initial preparation phase, call_gemini measures baseline input tokens using count_tokens_raw to establish reference points for token ratios and logging. It derives the output ceiling via _max_output_tokens() and translates the requested thinking intensity into an SDK-compliant types.ThinkingConfig via _thinking_config(). To prevent unwanted console warnings emitted by google-genai when streaming responses without tool definitions, AutomaticFunctionCallingConfig(disable=True) is explicitly configured within GenerateContentConfig.

    Phase 2: Stream Execution and Self-Healing Fallback

        start = time.time()
    try:
        result = _stream(model, prompt, config)
    except genai_errors.ClientError as e:
        # A model that rejects our thinking control (unknown future model, level set changed):
        # warn once and resend without it for the rest of the run.
        if getattr(e, "code", None) == 400 and thinking is not None and "think" in str(e).lower():
            _thinking_rejected.add(model)
            emit("WARN_GEMINI_THINKING_REJECTED", model=model, error=str(e)[:200])
            config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=None, automatic_function_calling=no_afc)
            result = _stream(model, prompt, config)
        else:
            raise
    elapsed = time.time() - start
    The execution phase delegates transport consumption to the private helper _stream. If the API returns a client error (HTTP status 400) specifically citing thinking parameters—which commonly occurs when upstream Google endpoints alter accepted thinking configurations or reject thinking configurations on newly deployed snapshots—the handler catches genai_errors.ClientError. It registers the affected model in the global _thinking_rejected set, emits a diagnostic warning, constructs a revised GenerateContentConfig stripped of thinking options, and retries the generation.

    Phase 3: Telemetry, Accounting, and Debug Logging

        if result["usage"] is not None:
        _record(model, result["usage"], raw_tokens, level_desc, result["finish"], elapsed)
    else:
        record_usage("GEMINI", model, cost=None, measured=False)  # stream carried no usage_metadata
    if is_debug() and result["thoughts"]:
        emit_raw("DEBUG", f"THINKING SUMMARY:\n{result['thoughts']}", dest="LOG")
    Once the stream concludes, telemetry processing inspects the collected usage metadata. If present, it executes _record to compute financial costs, track input/output/thinking tokens, and update token calibration metrics. In scenarios where a partial or unmeasured stream omitted usage metadata, it logs an unmeasured event to ensure accounting ledgers in llm_common.py track the occurrence. If debug logging is active and the model generated internal thought summaries, they are dumped to the debug stream.

    Phase 4: Termination Reason Evaluation and Signals

        if result["block_reason"] or result["finish"] in _BLOCK_FINISH_REASONS:
        category = result["block_reason"] or result["finish"]
        # A blocked prompt repeats for the same input; a stop on the candidate may pass on resampling.
        retryable = not result["block_reason"] and result["finish"] in _RETRYABLE_FINISH_REASONS
        count_event("GEMINI", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="Gemini", model=model, category=category)
        raise LLMRefusalError(model, category, provider="GEMINI", retryable=retryable)
    if result["finish"] in _TRUNCATION_FINISH_REASONS:
        count_event("GEMINI", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="Gemini", max_tokens=f"{max_output:,}")
        return TruncatedResponse(result["text"])
    if not result["text"]:
        emit_raw("WARNING", f"Gemini response contained no text (finish_reason={result['finish'] or 'n/a'})", dest="LOG")
    return result["text"]
    The final phase evaluates stream completion codes against terminal conditions. Prompt-level blockages or policy violations (such as PROHIBITED_CONTENT or BLOCKLIST) cause an immediate LLMRefusalError with retryable=False. Candidate-level finish reasons like SAFETY or RECITATION are classified as retryable, raising LLMRefusalError with retryable=True to permit higher-level nodes to resample. If the stream ended due to MAX_TOKENS, the result is wrapped in TruncatedResponse to prevent disk caching in call_llm.py.

    Internal Helpers

    _timeout_ms()

    Visibility: Private Signature: def _timeout_ms() -> int:

    Description: Calculates the total per-request execution deadline in milliseconds for Google SDK operations. It parses the GEMINI_TIMEOUT_SECONDS environment variable (defaulting to 1,800 seconds / 30 minutes) and enforces a minimum lower bound of 30 seconds to prevent premature disconnections during extended reasoning phases.

    Parameters: None.

    Returns: * int: Total per-request timeout duration in milliseconds.

    Raises: None. Invalid numeric values fall back to the default of 1,800.0 seconds.

    Example: 

    def _timeout_ms() -> int:
    """Total per-request deadline (the SDK applies it to the whole streamed response)."""
    try:
        seconds = float(os.getenv("GEMINI_TIMEOUT_SECONDS", "1800"))
    except ValueError:
        seconds = 1800.0
    return int(max(seconds, 30.0) * 1000)
    Because the google-genai SDK interprets the configured HTTP timeout as the deadline for the entire streamed message rather than an idle read timeout, this helper guarantees that lengthy generations spanning several thousand thinking tokens do not abort midway through the stream.

    _get_client()

    Visibility: Private Signature: def _get_client():

    Description: Lazily initializes and caches a singleton instance of google.genai.Client. It evaluates the execution environment to configure either a Vertex AI client (when GEMINI_PROJECT_ID is present) or a standard Google AI Studio client (when GEMINI_API_KEY is present). It configures low-level HTTP transport parameters including overall deadlines and automated retries.

    Parameters: None.

    Returns: * genai.Client: A shared instance of the configured Google GenAI SDK client.

    Raises: * ValueError: Raised if neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is detected in the runtime environment.

    Example: 

    def _get_client():
    global _client
    if _client is None:
        http_options = types.HttpOptions(
            timeout=_timeout_ms(),  # milliseconds; with no timeout a stalled connection hangs forever
            # One SDK retry for transient errors; PocketFlow node retries (5 x 20 s) sit on top.
            retry_options=types.HttpRetryOptions(attempts=2, http_status_codes=[408, 429, 500, 502, 503, 504]),
        )
        if os.getenv("GEMINI_PROJECT_ID"):
            _client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=gemini_location(), http_options=http_options)
        elif os.getenv("GEMINI_API_KEY"):
            # vertexai=False explicitly: GOOGLE_GENAI_USE_VERTEXAI=true in the environment would otherwise
            # route the API key to Vertex AI.
            _client = genai.Client(vertexai=False, api_key=os.getenv("GEMINI_API_KEY"), http_options=http_options)
        else:
            raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    return _client
    The client instantiation explicitly overrides vertexai=False when using GEMINI_API_KEY to avoid accidental routing collisions caused by ambient GOOGLE_GENAI_USE_VERTEXAI=true environment variables. Transport options establish two automated SDK-level retry attempts covering standard transient HTTP error codes before yielding control back to application-level retry loops.

    _thinking_config()

    Visibility: Private Signature: def _thinking_config(model: str, level: str | None) -> tuple[types.ThinkingConfig | None, str]:

    Description: Constructs the appropriate types.ThinkingConfig object based on the model's architectural capabilities and the requested thinking level. It distinguishes between models utilizing discrete categorical levels (mode == "level") and models requiring integer token budgets (mode == "budget"), ensuring that incompatible options are never conflated into an invalid HTTP 400 payload.

    Parameters: * model (str): Target model name. * level (str | None): Desired reasoning intensity level or None.

    Returns: * tuple[types.ThinkingConfig | None, str]: A 2-tuple containing the constructed types.ThinkingConfig instance (or None if disabled/unsupported) and a human-readable telemetry description string.

    Raises: None.

    Example: 

    def _thinking_config(model: str, level: str | None):
    """(ThinkingConfig | None, description). Never mixes thinking_level with thinking_budget."""
    mode, spec = gemini_thinking_mode(model)
    include = True if is_debug() else None  # thought summaries only for the debug log
    if model in _thinking_rejected:
        return None, "default (thinking config rejected by model)"
    if not level:
        # Model default thinking; with --debug still ask for summaries so they can be logged.
        return (types.ThinkingConfig(include_thoughts=True) if include and mode != "none" else None), "default"
    if mode == "level":
        effective = clamp_level(level.lower(), spec) or spec[-1]
        if effective != level.lower() and warn_once("gemini_level", model, level):
            emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effective, model=model)
        return types.ThinkingConfig(thinking_level=effective, include_thoughts=include), f"thinking_level={effective}"
    if mode == "budget":
        low, high, _can_disable = spec
        budget = min(max(GEMINI_THINKING_BUDGETS.get(level.lower(), 4096), low), high)
        return types.ThinkingConfig(thinking_budget=budget, include_thoughts=include), f"thinking_budget={budget}"
    if warn_once("gemini_no_thinking", model):
        emit("WARN_THINKING_NOT_SUPPORTED", model=model)
    return None, "unsupported"
    This helper enforces strict boundary checks on reasoning controls. When mode == "level", it leverages clamp_level to map out-of-bounds user levels (such as xhigh or max) to supported values like high. In budget mode, token counts are constrained between low and high model limits. It also dynamically injects include_thoughts=True when the application is running in debug mode.

    _max_output_tokens()

    Visibility: Private Signature: def _max_output_tokens(model: str, level: str | None) -> int:

    Description: Determines the maximum permissible generation token ceiling for a given model and thinking intensity.

    Parameters: * model (str): Target model name. * level (str | None): Active thinking intensity level.

    Returns: * int: Maximum output token limit for the request.

    Raises: None.

    Example: 

    def _max_output_tokens(model: str, level: str | None) -> int:
    """Per-level budget capped by the model's output limit. Gemini documents separate input and

    Unlike architectures that dynamically contract the output budget based on prompt length, Google Gemini specifies isolated input and output token boundaries.     _price()

    Visibility: Private Signature: def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:

    Description: Calculates the estimated USD cost of an API call based on token consumption, model pricing tiers, long-context thresholds, promotional schedules, and regional hosting surcharges.

    Parameters: * model (str): Model identifier. * prompt_tokens (int): Total input tokens counted. * cached (int): Subset of input tokens served via context caching. * output_tokens (int): Total output tokens (including reasoning/thinking tokens). * today (datetime.date | None, optional): Explicit date override for testing promotional pricing expiration. Defaults to datetime.date.today().

    Returns: * float | None: Total calculated cost in USD, or None if the model does not match any prefix in the pricing schedule.

    Raises: None.

    Example: 

    def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:
    key = next((k for k in sorted(_PRICING, key=len, reverse=True) if model.lower().startswith(k)), None)
    if key is None:
        return None
    row = _PRICING[key]
    if key in _INTRO_PRICING and (today or datetime.date.today()) <= _INTRO_PRICING_UNTIL:
        row = _INTRO_PRICING[key]
    p_in, p_out, p_cache = row[3:6] if len(row) == 6 and prompt_tokens > _LONG_CONTEXT_THRESHOLD else row[:3]
    uncached = max(prompt_tokens - cached, 0)
    cost = (uncached * p_in + cached * p_cache + output_tokens * p_out) / 1_000_000
    if os.getenv("GEMINI_PROJECT_ID") and gemini_location().lower() != "global":
        cost *= _REGIONAL_UPLIFT
    return cost
    Pricing resolution uses a longest-prefix match against _PRICING. For eligible Flash models, it substitutes introductory pricing if the execution date precedes _INTRO_PRICING_UNTIL (December 31, 2026). If the prompt exceeds _LONG_CONTEXT_THRESHOLD (200,000 tokens) on tiered models like Gemini Pro, the rate switches to 6-tuple pricing coordinates. Additionally, requests routed through regional Vertex AI endpoints apply a 10% multiplier (_REGIONAL_UPLIFT).

    _record()

    Visibility: Private Signature: def _record(model: str, usage: object, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:

    Description: Extracts token counts from SDK usage metadata, invokes financial calculation helpers, dispatches metrics to the shared token ledger, updates token estimation ratios, and logs granular debugging telemetry.

    Parameters: * model (str): The active model identifier. * usage (object): The usage_metadata object returned on the generation stream. * raw_prompt_tokens (int): Baseline prompt token count computed prior to transmission. * level_desc (str): Telemetry description of active reasoning parameters. * finish (str): Stream finish reason string. * elapsed (float): Request latency in seconds.

    Returns: * None

    Raises: None.

    Example: 

    def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:
    prompt = getattr(usage, "prompt_token_count", 0) or 0
    candidates = getattr(usage, "candidates_token_count", 0) or 0
    thoughts = getattr(usage, "thoughts_token_count", 0) or 0
    cached = getattr(usage, "cached_content_token_count", 0) or 0
    output = candidates + thoughts  # thinking is billed as output
    cost = _price(model, prompt, cached, output)
    record_usage("GEMINI", model, input_tokens=prompt, output_tokens=output, thinking_tokens=thoughts, cache_read=cached, cost=cost)
    ratio = prompt / raw_prompt_tokens if raw_prompt_tokens else 0.0
    from utils.token_utils import observe_prompt_tokens

    observe_prompt_tokens("GEMINI", model, raw_prompt_tokens, prompt)  # prompt_token_count includes cached tokens
    emit_raw(
        "DEBUG",
        f"GEMINI USAGE | model={model} | {level_desc} | finish={finish or 'n/a'} | in={prompt:,} | out={candidates:,} | thinking={thoughts:,} | "
        f"cached={cached:,} | est_cost={'$' + format(cost, '.4f') if cost is not None else 'n/a'} | elapsed={elapsed:.1f}s | observed_token_ratio={ratio:.2f}",
        dest="BOTH",
    )
    This helper treats internal reasoning tokens (thoughts_token_count) as billable output tokens in accordance with Google's billing architecture. It calls record_usage in llm_common.py to register metrics in the shared step and provider ledgers. Furthermore, it dynamically imports observe_prompt_tokens from token_utils.py to continuously calibrate the runtime ratio between raw heuristic token counts and actual Gemini BPE token counts.

    def _stream(model: str, prompt: str, config) -> dict:
    """Consume generate_content_stream; returns text, thoughts, finish, block_reason, usage."""
    text, thoughts = [], []
    finish, block_reason, usage = "", "", None
    for chunk in _get_client().models.generate_content_stream(model=model, contents=[prompt], config=config):
        feedback = getattr(chunk, "prompt_feedback", None)
        if feedback is not None and getattr(feedback, "block_reason", None):
            block_reason = _name(feedback.block_reason)
        if getattr(chunk, "usage_metadata", None) is not None:
            usage = chunk.usage_metadata
        for candidate in getattr(chunk, "candidates", None) or []:
            if getattr(candidate, "finish_reason", None):
                finish = _name(candidate.finish_reason)
            content = getattr(candidate, "content", None)
            for part in (getattr(content, "parts", None) or []) if content is not None else []:
                if getattr(part, "text", None):
                    (thoughts if getattr(part, "thought", False) else text).append(part.text)
            break  # candidate_count is 1
    return {"text": "".join(text), "thoughts": "".join(thoughts), "finish": finish, "block_reason": block_reason, "usage": usage}
    The stream accumulator parses each incoming response chunk, checking for prompt-level feedback blocks before evaluating candidate parts. It routes parts marked with thought=True into a dedicated thoughts accumulator to separate internal chain-of-thought tokens from the primary response text. Candidate traversal explicitly limits inspection to the primary candidate (break), aligning with the application's single-turn contract.

    Finish Reason Taxonomies

    The module organizes Google completion codes into three distinct functional sets:

    Set Name Members Semantics / Pipeline Behavior
    _RETRYABLE_FINISH_REASONS SAFETY, RECITATION, LANGUAGE, OTHER Sampling-dependent interruptions. Raises LLMRefusalError(retryable=True) to permit retry passes.
    _BLOCK_FINISH_REASONS _RETRYABLE_FINISH_REASONS + PROHIBITED_CONTENT, BLOCKLIST, SPII, IMAGE_SAFETY, IMAGE_PROHIBITED_CONTENT, IMAGE_RECITATION, IMAGE_OTHER Absolute policy rejections. Non-retryable reasons raise LLMRefusalError(retryable=False) to prevent duplicate execution.
    _TRUNCATION_FINISH_REASONS MAX_TOKENS Token limit ceiling reached. Returns TruncatedResponse to bypass response caching in call_llm.py.

    Error Handling

    llm_gemini.py implements structured error management to handle remote API constraints, policy interventions, and network volatility:

    • Thinking Configuration Self-Healing: When invoking newer or modified model endpoints, Google may return an HTTP 400 ClientError containing "think". The adapter catches this exception during _stream(), adds the model identifier to _thinking_rejected, logs WARN_GEMINI_THINKING_REJECTED, and automatically replays the request without reasoning configurations. Subsequent calls for that model bypass thinking injection entirely.
    • Deterministic Policy Blocks vs. Sampling Rejections: The adapter categorizes refusal codes into deterministic rejections (e.g., PROHIBITED_CONTENT, BLOCKLIST, SPII, or prompt-level block_reason) versus stochastic rejections (e.g., candidate-level SAFETY, RECITATION, LANGUAGE). Stochastic rejections raise LLMRefusalError with retryable=True, allowing caller orchestrators to retry with modified parameters, whereas deterministic rejections set retryable=False to abort immediately.
    • Truncation Defense: Generations terminated due to MAX_TOKENS are intercepted and packaged within TruncatedResponse. This informs upstream cache controllers (e.g., call_llm.py) that the output is incomplete, preventing truncated content from poisoning the disk cache (llm_cache_v2.json).
    • Transport-Level Retries and Deadlines: Transport robustness is enforced via types.HttpOptions and types.HttpRetryOptions. The SDK client is configured to automatically retry transient network failures (HTTP 408, 429, 500, 502, 503, and 504) across two attempts, bound by a 30-minute default stream deadline (_timeout_ms()).
