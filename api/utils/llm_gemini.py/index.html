    llm_gemini.py

    Source: utils/llm_gemini.py

    Technical Overview

    Building upon the runtime parameters, quota boundaries, and authentication preflights established in utils/llm_config.py, this module serves as the dedicated Google Gemini provider adapter for the codebase's centralized inference gateway. It encapsulates all direct interactions with the google-genai SDK, isolating external Google Cloud and AI Studio dependencies from downstream workflow nodes. The module manages runtime execution across both Google AI Studio (authenticated via GEMINI_API_KEY) and Google Cloud Vertex AI (authenticated via GEMINI_PROJECT_ID and regional location settings), dynamically selecting transport configurations based on environment variables.

    The core execution path is designed around resilient chunked streaming through generate_content_stream. Because Google Gemini imposes a total per-request stream deadline rather than an idle read timeout, the module calculates and applies per-request deadlines (defaulting to 1,800 seconds) via SDK-level HTTP options, with automated retries for transient status codes (408, 429, 5xx). Furthermore, it features dynamic reasoning configuration: Gemini 3.x models consume reasoning levels clamped to valid model capabilities, whereas Gemini 2.5 models receive token budgets. If a model rejects thinking configuration headers with an HTTP 400 Client Error, the module dynamically records the rejection and replays the stream without thinking parameters.

    The module provides rigorous post-stream telemetry, accounting, and completion categorization. Token consumption across prompts, candidate outputs, thoughts, and cached inputs is tracked against multi-tier pricing schedules that support introductory discounts, long-context surcharges (prompts exceeding 200,000 tokens), and Vertex regional pricing uplifts. Candidate finish reasons and prompt feedback blocks are evaluated to raise structured LLMRefusalError exceptions—differentiating stochastic, retryable candidate blocks (such as SAFETY or RECITATION) from deterministic prompt violations (such as PROHIBITED_CONTENT or BLOCKLIST). Responses truncated by output token limits return TruncatedResponse instances to guarantee that incomplete outputs bypass persistent disk caches.

    Public API

    call_gemini()

    Visibility: Public

    Signature: def call_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches a single-turn completion prompt to the configured Google Gemini model over a chunked streaming transport. It orchestrates preflight sizing, thinking parameter validation, client invocation, dynamic fallback recovery, usage telemetry recording, and finish reason validation.

    Phase 1: Preflight Configuration and Prompt Sizing

        from utils.token_utils import count_tokens_raw

    model = get_model()
    raw_tokens = count_tokens_raw(prompt)
    max_output = _max_output_tokens(model, thinking_level)
    thinking, level_desc = _thinking_config(model, thinking_level)
    # No tools are passed, so automatic function calling is off (google-genai warns on streams otherwise).
    no_afc = types.AutomaticFunctionCallingConfig(disable=True)
    config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=thinking, automatic_function_calling=no_afc)
    emit_raw(
        "DEBUG",
        f"Gemini request | model={model} | {level_desc} | max_output_tokens={max_output:,} | location={gemini_location() if os.getenv('GEMINI_PROJECT_ID') else 'ai-studio'}",
        dest="LOG",
    )

    In the initial configuration phase, the target model identifier is resolved via get_model(), and the raw prompt is tokenized using count_tokens_raw() to establish baseline token metrics. The maximum allowable output tokens are resolved based on model ceilings and requested thinking levels via _max_output_tokens(). The reasoning parameters are assembled into a types.ThinkingConfig instance via _thinking_config(). Finally, automatic function calling is explicitly disabled through types.AutomaticFunctionCallingConfig(disable=True) to prevent the SDK from issuing console warnings during streaming when no tools are declared.

    Phase 2: Stream Execution and Fallback Recovery

        start = time.time()
    try:
        result = _stream(model, prompt, config)
    except genai_errors.ClientError as e:
        # A model that rejects our thinking control (unknown future model, level set changed):
        # warn once and resend without it for the rest of the run.
        if getattr(e, "code", None) == 400 and thinking is not None and "think" in str(e).lower():
            _thinking_rejected.add(model)
            emit("WARN_GEMINI_THINKING_REJECTED", model=model, error=str(e)[:200])
            config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=None, automatic_function_calling=no_afc)
            result = _stream(model, prompt, config)
        else:
            raise
    elapsed = time.time() - start

    The execution phase dispatches the streaming request via _stream() inside a monitored execution block. If Google Gemini returns an HTTP 400 ClientError indicating that the target model does not support the supplied thinking configuration parameters, the handler intercepts the exception. It logs a warning via WARN_GEMINI_THINKING_REJECTED, adds the model identifier to the module-level _thinking_rejected set to prevent future attempts during the run, constructs a new GenerateContentConfig omitting thinking_config, and replays the request. Any unhandled or non-thinking 400 errors are re-raised immediately.

    Phase 3: Telemetry and Cost Recording

        if result["usage"] is not None:
        _record(model, result["usage"], raw_tokens, level_desc, result["finish"], elapsed)
    else:
        record_usage("GEMINI", model, cost=None, measured=False)  # stream carried no usage_metadata
    if is_debug() and result["thoughts"]:
        emit_raw("DEBUG", f"THINKING SUMMARY:\n{result['thoughts']}", dest="LOG")

    Once the stream terminates, post-flight telemetry processing evaluates the accumulated usage_metadata. If usage metrics are present on the stream payload, _record() extracts prompt, candidate, thinking, and cached token totals, determines monetary cost against pricing tables, updates global usage ledgers, and logs execution benchmarks. If usage metadata was omitted by the API, record_usage() records an unmeasured event. In addition, when debug mode is enabled via is_debug(), accumulated internal thinking summaries are emitted to the debug log stream.

    Phase 4: Block, Refusal, and Truncation Post-Processing

        if result["block_reason"] or result["finish"] in _BLOCK_FINISH_REASONS:
        category = result["block_reason"] or result["finish"]
        # A blocked prompt repeats for the same input; a stop on the candidate may pass on resampling.
        retryable = not result["block_reason"] and result["finish"] in _RETRYABLE_FINISH_REASONS
        count_event("GEMINI", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="Gemini", model=model, category=category)
        raise LLMRefusalError(model, category, provider="GEMINI", retryable=retryable)
    if result["finish"] in _TRUNCATION_FINISH_REASONS:
        count_event("GEMINI", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="Gemini", max_tokens=f"{max_output:,}")
        return TruncatedResponse(result["text"])
    if not result["text"]:
        emit_raw("WARNING", f"Gemini response contained no text (finish_reason={result['finish'] or 'n/a'})", dest="LOG")
    return result["text"]

    The final phase inspects response stop conditions. If the request triggered an upstream block (via prompt_feedback.block_reason) or the candidate finish reason belongs to _BLOCK_FINISH_REASONS, the module registers a refusal event. It flags candidate sampling stops (e.g., SAFETY, RECITATION) as retryable=True while treating prompt-level violations as permanent (retryable=False), raising an LLMRefusalError. If the candidate was stopped due to token budget exhaustion (MAX_TOKENS), the text is wrapped in a TruncatedResponse to prevent caching. Otherwise, the generated completion text is returned to the caller.

    Parameters:

    • prompt (str): The input prompt string to be evaluated by the model.
    • thinking_level (str | None): Optional reasoning effort level (e.g., "low", "medium", "high") or token budget string. Defaults to None.

    Returns:

    • str: The decoded text completion, or a TruncatedResponse instance if the generation was terminated by maximum token ceilings.

    Raises:

    • LLMRefusalError: When prompt feedback or candidate finish reasons indicate content policy violations, safety blocks, or recitation filters.
    • genai_errors.ClientError: When non-thinking 4xx API errors occur during transport.
    • ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is set in the runtime environment.

    Example:

    get_model_limits()

    Visibility: Public

    Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Retrieves the maximum context input limit and maximum output token limit for a designated Gemini model. When connected via AI Studio (without GEMINI_PROJECT_ID), the limits are dynamically queried from the Gemini API via client.models.get() and cached in _model_limits_cache. When running on Vertex AI or if API lookup fails, it falls back to the static boundaries defined in GEMINI_DEFAULT_LIMITS.

    def get_model_limits(model: str) -> tuple[int, int]:
    """(input_token_limit, output_token_limit). AI Studio reports them via models.get; Vertex does
    not (the SDK maps no limits there), so the static Gemini 3.x / 2.5 table applies."""
    if model in _model_limits_cache:
        return _model_limits_cache[model]
    limits = GEMINI_DEFAULT_LIMITS
    if not os.getenv("GEMINI_PROJECT_ID"):
        try:
            info = _get_client().models.get(model=model)
            limits = (getattr(info, "input_token_limit", None) or limits[0], getattr(info, "output_token_limit", None) or limits[1])
            emit_raw("DEBUG", f"Gemini models.get | model={model} | input={limits[0]:,} | output={limits[1]:,}", dest="LOG")
        except Exception as e:
            emit("WARN_GEMINI_MODEL_LOOKUP", model=model, error=str(e)[:200])
    _model_limits_cache[model] = limits
    return limits

    The function checks the module-level dictionary _model_limits_cache to bypass repeated network queries. If uncached, it establishes defaults from GEMINI_DEFAULT_LIMITS (typically (1_048_576, 65_536)). If Vertex AI is not in use, it invokes _get_client().models.get(model=model) to inspect remote metadata. Any network or lookup failures trigger a WARN_GEMINI_MODEL_LOOKUP warning and default boundaries are safely preserved.

    Parameters:

    • model (str): The normalized model identifier string.

    Returns:

    • tuple[int, int]: A two-element tuple containing (input_token_limit, output_token_limit).

    Raises:

    • None.

    Example:

    # Call site within _max_output_tokens()
_input_limit, output_limit = get_model_limits(model)
return gemini_output_budget(level, output_limit)

    _timeout_ms()

    Visibility: Private

    Signature: def _timeout_ms() -> int:

    Description: Computes the total request deadline in milliseconds from the GEMINI_TIMEOUT_SECONDS environment variable. The value represents the deadline for the entire streamed response rather than an idle read timeout. It enforces a lower bound of 30.0 seconds and defaults to 1,800.0 seconds if parsing fails or the variable is omitted.

    def _timeout_ms() -> int:
    """Total per-request deadline (the SDK applies it to the whole streamed response)."""
    try:
        seconds = float(os.getenv("GEMINI_TIMEOUT_SECONDS", "1800"))
    except ValueError:
        seconds = 1800.0
    return int(max(seconds, 30.0) * 1000)

    The implementation reads GEMINI_TIMEOUT_SECONDS, safely handling non-numeric configurations by reverting to 1,800.0 seconds. It calculates milliseconds using int(max(seconds, 30.0) * 1000), ensuring that connections do not hang indefinitely while preventing aggressive timeouts during extended reasoning phases.

    • None.

    Returns:

    • int: The request timeout deadline in milliseconds.

    Raises:

    • None.

    _get_client()

    Visibility: Private

    Signature: def _get_client():

    Description: Lazily initializes and returns the singleton genai.Client instance stored in the module-level _client variable. It configures transport deadlines and automatic HTTP retry policies, selecting either Vertex AI mode or AI Studio mode based on the presence of GEMINI_PROJECT_ID or GEMINI_API_KEY.

    def _get_client():
    global _client
    if _client is None:
        http_options = types.HttpOptions(
            timeout=_timeout_ms(),  # milliseconds; with no timeout a stalled connection hangs forever
            # One SDK retry for transient errors; PocketFlow node retries (5 x 20 s) sit on top.
            retry_options=types.HttpRetryOptions(attempts=2, http_status_codes=[408, 429, 500, 502, 503, 504]),
        )
        if os.getenv("GEMINI_PROJECT_ID"):
            _client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=gemini_location(), http_options=http_options)
        elif os.getenv("GEMINI_API_KEY"):
            # vertexai=False explicitly: GOOGLE_GENAI_USE_VERTEXAI=true in the environment would otherwise
            # route the API key to Vertex AI.
            _client = genai.Client(vertexai=False, api_key=os.getenv("GEMINI_API_KEY"), http_options=http_options)
        else:
            raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    return _client

    The function checks if _client is already cached. If uninitialized, it constructs a types.HttpOptions instance specifying total request timeouts and an HTTP retry policy covering status codes [408, 429, 500, 502, 503, 504]. If GEMINI_PROJECT_ID is defined, it instantiates genai.Client(vertexai=True, ...) using the location resolved by gemini_location(). Otherwise, if GEMINI_API_KEY is present, it explicitly forces vertexai=False to prevent ambient Google Cloud environment variables from misrouting traffic.

    Parameters:

    • None.

    Returns:

    • genai.Client: The initialized Google GenAI SDK client.

    Raises:

    • ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is configured in the environment.

    Example:

    _thinking_config()

    Visibility: Private

    Signature: def _thinking_config(model: str, level: str | None):

    Description: Constructs the appropriate types.ThinkingConfig object and a human-readable telemetry description string based on model capabilities. It guarantees that thinking_level and thinking_budget parameters are never simultaneously transmitted, clamps levels to model allowances, and formats debug thought summary requests.

    def _thinking_config(model: str, level: str | None):
    """(ThinkingConfig | None, description). Never mixes thinking_level with thinking_budget."""
    mode, spec = gemini_thinking_mode(model)
    include = True if is_debug() else None  # thought summaries only for the debug log
    if model in _thinking_rejected:
        return None, "default (thinking config rejected by model)"
    if not level:
        # Model default thinking; with --debug still ask for summaries so they can be logged.
        return (types.ThinkingConfig(include_thoughts=True) if include and mode != "none" else None), "default"
    if mode == "level":
        effective = clamp_level(level.lower(), spec) or spec[-1]
        if effective != level.lower() and warn_once("gemini_level", model, level):
            emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effective, model=model)
        return types.ThinkingConfig(thinking_level=effective, include_thoughts=include), f"thinking_level={effective}"
    if mode == "budget":
        low, high, _can_disable = spec
        budget = min(max(GEMINI_THINKING_BUDGETS.get(level.lower(), 4096), low), high)
        return types.ThinkingConfig(thinking_budget=budget, include_thoughts=include), f"thinking_budget={budget}"
    if warn_once("gemini_no_thinking", model):
        emit("WARN_THINKING_NOT_SUPPORTED", model=model)
    return None, "unsupported"

    The function calls gemini_thinking_mode(model) to determine whether the model uses discrete levels ("level"), numeric token budgets ("budget"), or does not support reasoning ("none"). If the model previously returned an HTTP 400 error, it returns early with None. For level-based models, it invokes clamp_level() against the allowed set and emits WARN_THINKING_LEVEL_CLAMPED if adjustments were necessary. For budget-based models, it clamps predefined budget lookups between lower and upper token boundaries.

    • model (str): The target model identifier.
    • level (str | None): The requested reasoning effort string or None.

    Returns:

    • tuple[types.ThinkingConfig | None, str]: A tuple containing the initialized SDK thinking configuration (or None) and a telemetry description string.

    Raises:

    • None.

    Example:

    _price()

    Visibility: Private

    Signature: def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:

    Description: Estimates the monetary cost in USD for a given Gemini invocation. It evaluates model prefixes against pricing schedules, accounts for introductory pricing windows, computes tiered rates for long-context prompts, and applies regional Vertex AI surcharges.

    def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:
    key = next((k for k in sorted(_PRICING, key=len, reverse=True) if model.lower().startswith(k)), None)
    if key is None:
        return None
    row = _PRICING[key]
    if key in _INTRO_PRICING and (today or datetime.date.today()) <= _INTRO_PRICING_UNTIL:
        row = _INTRO_PRICING[key]
    p_in, p_out, p_cache = row[3:6] if len(row) == 6 and prompt_tokens > _LONG_CONTEXT_THRESHOLD else row[:3]
    uncached = max(prompt_tokens - cached, 0)
    cost = (uncached * p_in + cached * p_cache + output_tokens * p_out) / 1_000_000
    if os.getenv("GEMINI_PROJECT_ID") and gemini_location().lower() != "global":
        cost *= _REGIONAL_UPLIFT
    return cost

    The function matches the model against _PRICING keys using longest-prefix matching. If the model falls under active introductory rates in _INTRO_PRICING (valid through _INTRO_PRICING_UNTIL), those rates supersede standard tiers. If prompt tokens exceed _LONG_CONTEXT_THRESHOLD (200,000 tokens) and the pricing entry defines a 6-element tuple, long-context rates are applied. The cost is calculated per million tokens across uncached prompts, cached prompts, and combined output tokens. Finally, if the request is routed through Vertex AI outside the "global" region, a 10% uplift (_REGIONAL_UPLIFT = 1.10) is applied.

    Parameters:

    • model (str): The model identifier.
    • prompt_tokens (int): Total prompt tokens reported by usage metadata.
    • cached (int): Tokens read from explicit cache layers.
    • output_tokens (int): Combined candidate and thinking tokens.
    • today (datetime.date | None): Optional date override for introductory pricing evaluation. Defaults to datetime.date.today().

    Returns:

    • float | None: The estimated USD cost, or None if the model pricing is unmapped.

    Raises:

    • None.

    Example:

    # Call site inside _record()
cost = _price(model, prompt, cached, output)

    _record()

    Visibility: Private

    Signature: def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:

    Description: Extracts token counts from SDK usage metadata, calculates USD cost, registers execution metrics in the central ledger, and calibrates local prompt tokenizer scaling ratios.

    def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:
    prompt = getattr(usage, "prompt_token_count", 0) or 0
    candidates = getattr(usage, "candidates_token_count", 0) or 0
    thoughts = getattr(usage, "thoughts_token_count", 0) or 0
    cached = getattr(usage, "cached_content_token_count", 0) or 0
    output = candidates + thoughts  # thinking is billed as output
    cost = _price(model, prompt, cached, output)
    record_usage("GEMINI", model, input_tokens=prompt, output_tokens=output, thinking_tokens=thoughts, cache_read=cached, cost=cost)
    ratio = prompt / raw_prompt_tokens if raw_prompt_tokens else 0.0
    from utils.token_utils import observe_prompt_tokens

    observe_prompt_tokens("GEMINI", model, raw_prompt_tokens, prompt)  # prompt_token_count includes cached tokens
    emit_raw(
        "DEBUG",
        f"GEMINI USAGE | model={model} | {level_desc} | finish={finish or 'n/a'} | in={prompt:,} | out={candidates:,} | thinking={thoughts:,} | "
        f"cached={cached:,} | est_cost={'$' + format(cost, '.4f') if cost is not None else 'n/a'} | elapsed={elapsed:.1f}s | observed_token_ratio={ratio:.2f}",
        dest="BOTH",
    )

    The function reads prompt_token_count, candidates_token_count, thoughts_token_count, and cached_content_token_count from the usage_metadata object. Thinking tokens are combined with candidate tokens into output, reflecting Google's billing architecture. It calls record_usage() from utils.llm_common, invokes observe_prompt_tokens() from utils.token_utils to calibrate estimation ratios against actual token counts, and outputs formatted execution metrics via emit_raw().

    _stream()

    Visibility: Private

    Signature: def _stream(model: str, prompt: str, config) -> dict:

    Description: Consumes the generator returned by generate_content_stream(), iterating over all stream chunks to concatenate completion text and reasoning thought parts while capturing finish reasons, prompt feedback blocks, and usage metadata.

    def _stream(model: str, prompt: str, config) -> dict:
    """Consume generate_content_stream; returns text, thoughts, finish, block_reason, usage."""
    text, thoughts = [], []
    finish, block_reason, usage = "", "", None
    for chunk in _get_client().models.generate_content_stream(model=model, contents=[prompt], config=config):
        feedback = getattr(chunk, "prompt_feedback", None)
        if feedback is not None and getattr(feedback, "block_reason", None):
            block_reason = _name(feedback.block_reason)
        if getattr(chunk, "usage_metadata", None) is not None:
            usage = chunk.usage_metadata
        for candidate in getattr(chunk, "candidates", None) or []:
            if getattr(candidate, "finish_reason", None):
                finish = _name(candidate.finish_reason)
            content = getattr(candidate, "content", None)
            for part in (getattr(content, "parts", None) or []) if content is not None else []:
                if getattr(part, "text", None):
                    (thoughts if getattr(part, "thought", False) else text).append(part.text)
            break  # candidate_count is 1
    return {"text": "".join(text), "thoughts": "".join(thoughts), "finish": finish, "block_reason": block_reason, "usage": usage}

    The function dispatches _get_client().models.generate_content_stream(). For each streamed chunk, it inspects prompt_feedback for safety blocks, records incoming usage_metadata, and traverses candidate content parts. Content parts tagged with thought=True are routed into thoughts, while standard content parts append to text. The function returns an aggregated dictionary once the stream concludes.

    Parameters:

    • model (str): The target model identifier.
    • prompt (str): The raw text prompt.
    • config (types.GenerateContentConfig): The fully populated configuration instance.

    Returns:

    • dict: A dictionary containing aggregated response text, thought strings, finish reason, block reason, and usage metadata. See Stream Result Dictionary for schema details.

    Raises:

    • genai_errors.ClientError: If the Google GenAI backend rejects the request payload or stream.

    Example:

    Error Handling

    The module implements defensive error handling to classify network, validation, and content policy failures:

    • Authentication Validation: In _get_client(), if neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment, execution halts immediately by raising a ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment").
    • Dynamic Thinking Fallback: When _stream() encounters a google.genai.errors.ClientError with HTTP status code 400 whose message references thinking configuration, call_gemini() intercepts the exception. It adds the model name to _thinking_rejected, emits WARN_GEMINI_THINKING_REJECTED, strips thinking_config, and replays the request without raising an exception to the caller.
    • Content Refusal and Policy Blocks: In call_gemini(), if result["block_reason"] is non-empty or result["finish"] appears in _BLOCK_FINISH_REASONS, the module registers an event via count_event("GEMINI", "refusals") and raises an LLMRefusalError. It evaluates retryable status: candidate stops (SAFETY, RECITATION, LANGUAGE, OTHER) set retryable=True to allow caller resampling, whereas prompt-level blocks (PROHIBITED_CONTENT, BLOCKLIST, SPII) set retryable=False.
    • Truncation Safeguards: If a candidate terminates with MAX_TOKENS, it is registered via count_event("GEMINI", "truncations") and wrapped in TruncatedResponse. This prevents callers (such as call_llm) from committing partial responses to persistent SHA-256 disk caches.
    • Stream Deadlines and Transport Retries: Transient HTTP status codes (408, 429, 500, 502, 503, 504) trigger automatic client-side retries governed by types.HttpRetryOptions(attempts=2). Stalled streaming connections are terminated according to _timeout_ms().
