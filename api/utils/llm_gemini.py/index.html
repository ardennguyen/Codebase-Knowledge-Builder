    llm_gemini.py

    Source: utils/llm_gemini.py

    Building directly upon the model limits, configuration schemas, and reasoning budget helpers established in llm_config.py, utils/llm_gemini.py implements the concrete runtime client adapter for Google Gemini models.

    Technical Overview

    The utils/llm_gemini.py module serves as the dedicated provider adapter for Google Gemini language models within the Codebase-Knowledge-Builder architecture. It isolates all interactions with the official google-genai SDK, ensuring that vendor-specific connection options, payload formats, error hierarchies, and streaming protocols do not leak into high-level pipeline nodes or the generic dispatch interface in call_llm.py. The adapter supports both Google AI Studio (authenticated via GEMINI_API_KEY) and Google Cloud Vertex AI (authenticated via GEMINI_PROJECT_ID and GEMINI_LOCATION), standardizing them behind a unified execution flow.

    Architecturally, the module is engineered around streamed generation using client.models.generate_content_stream. Because Google's SDK treats request timeouts as an end-to-end deadline spanning the entire generation lifecycle rather than an idle socket timeout, the adapter enforces a configurable per-request deadline (defaulting to 1,800 seconds) to accommodate extensive reasoning traces produced by Gemini 3.x and Gemini 2.5 thinking models. It disables Automatic Function Calling (AFC) to eliminate unnecessary SDK warnings on text-only streams, negotiates thinking configurations based on whether a model expects discrete reasoning levels or numeric token budgets, and dynamically tracks models that reject thinking parameters to execute zero-downtime retries.

    The module also integrates runtime usage accounting, real-time token calibration, and strict finish-reason evaluation. As responses stream in, candidate parts are aggregated into plain text and thought summaries, while metadata blocks are parsed for input, output, thinking, and cached token metrics. If generation stops due to token budget exhaustion (MAX_TOKENS), the text is wrapped in a TruncatedResponse to prevent persistent disk caching. If generation is halted by safety filters, recitation blockers, or policy terms, the adapter categorizes the rejection into deterministic or sampling-dependent classifications and raises an LLMRefusalError.

    Public API

    get_model()

    Visibility: Public Signature: def get_model() -> str:

    Description: Resolves and returns the canonical Gemini model identifier configured for the current runtime. It inspects the GEMINI_MODEL environment variable, falling back to DEFAULT_GEMINI_MODEL when unset, and strips resource naming prefixes such as models/ or publishers/google/models/ via gemini_model_id.

    Parameters: None.

    Returns: * str: Clean model identifier string suitable for passing to the google-genai SDK (e.g., "gemini-3.8-flash").

    Raises: None.

    Example: 

    def get_model() -> str:
    """GEMINI_MODEL without a 'models/' or 'publishers/google/models/' resource prefix."""
    return gemini_model_id(os.getenv("GEMINI_MODEL") or DEFAULT_GEMINI_MODEL)

    The function provides an idempotent resolution helper used by both internal streaming routines and external orchestrators. By delegating prefix normalization to gemini_model_id, it prevents routing errors caused by inconsistent model formats across Google AI Studio and Google Cloud Vertex AI configurations.

    get_model_limits()

    Visibility: Public Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Retrieves the maximum context input token limit and output token limit for a specified model. Results are memoized in the module-level _model_limits_cache dictionary. For AI Studio environments, it queries client.models.get(model=model) over the network to inspect live metadata, falling back to GEMINI_DEFAULT_LIMITS if the lookup fails. For Vertex AI environments, it skips the network call and immediately uses static fallbacks because the Vertex endpoint does not populate limit properties on model metadata objects.

    Parameters: * model (str): The normalized model identifier string to look up.

    Returns: * tuple[int, int]: A 2-tuple containing (input_token_limit, output_token_limit) measured in tokens.

    Raises: None. Network exceptions during metadata retrieval are trapped, logged as warnings via emit("WARN_GEMINI_MODEL_LOOKUP", ...), and resolved using fallback limits.

    Example: 

    def get_model_limits(model: str) -> tuple[int, int]:
    """(input_token_limit, output_token_limit). AI Studio reports them via models.get; Vertex does
    not (the SDK maps no limits there), so the static Gemini 3.x / 2.5 table applies."""
    if model in _model_limits_cache:
        return _model_limits_cache[model]
    limits = GEMINI_DEFAULT_LIMITS
    if not os.getenv("GEMINI_PROJECT_ID"):
        try:
            info = _get_client().models.get(model=model)
            limits = (getattr(info, "input_token_limit", None) or limits[0], getattr(info, "output_token_limit", None) or limits[1])
            emit_raw("DEBUG", f"Gemini models.get | model={model} | input={limits[0]:,} | output={limits[1]:,}", dest="LOG")
        except Exception as e:
            emit("WARN_GEMINI_MODEL_LOOKUP", model=model, error=str(e)[:200])
    _model_limits_cache[model] = limits
    return limits

    This helper guarantees that subsequent token budgeting calculations never block on repeated network roundtrips. By detecting Vertex AI via os.getenv("GEMINI_PROJECT_ID"), it avoids issuing unsupported SDK calls while ensuring fallback values conform to standard Gemini 2.5 and 3.x specifications (1,048,576 context tokens and 65,536 output tokens).

    call_gemini()

    Visibility: Public Signature: def call_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches a single-turn prompt string to Google Gemini using streaming transport, monitors execution progress, tracks token usage and financial cost, handles model parameter fallbacks, and returns the generated content. If the response is interrupted by token caps, it returns a TruncatedResponse; if blocked by safety or policy constraints, it raises an LLMRefusalError.

    Parameters: * prompt (str): The complete, formatted prompt string to send to the model. * thinking_level (str | None, optional): Desired reasoning effort level (e.g., "low", "medium", "high"). Defaults to None, which activates model defaults.

    Returns: * str: The decoded response text. If the generation finished due to MAX_TOKENS, the string is wrapped as an instance of TruncatedResponse.

    Raises: * LLMRefusalError: Raised when the request is refused or blocked by candidate safety ratings, recitation filters, or prompt content policies. * genai_errors.ClientError: Raised on client errors from the Google GenAI SDK (status codes other than recoverable 400 thinking mismatches). * ValueError: Raised if neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Phase 1: Request Configuration and Budgeting

        from utils.token_utils import count_tokens_raw

    model = get_model()
    raw_tokens = count_tokens_raw(prompt)
    max_output = _max_output_tokens(model, thinking_level)
    thinking, level_desc = _thinking_config(model, thinking_level)
    # No tools are passed, so automatic function calling is off (google-genai warns on streams otherwise).
    no_afc = types.AutomaticFunctionCallingConfig(disable=True)
    config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=thinking, automatic_function_calling=no_afc)
    emit_raw(
        "DEBUG",
        f"Gemini request | model={model} | {level_desc} | max_output_tokens={max_output:,} | location={gemini_location() if os.getenv('GEMINI_PROJECT_ID') else 'ai-studio'}",
        dest="LOG",
    )

    The initial phase resolves the active model name and measures prompt length using count_tokens_raw. It computes the maximum allowable output tokens via _max_output_tokens and creates the ThinkingConfig object via _thinking_config. Automatic function calling is explicitly disabled using AutomaticFunctionCallingConfig(disable=True) to suppress SDK console warnings on streamed connections. These settings are packaged into an immutable types.GenerateContentConfig instance and logged for debugging.

    Phase 2: Stream Execution and Fallback Recovery

        start = time.time()
    try:
        result = _stream(model, prompt, config)
    except genai_errors.ClientError as e:
        # A model that rejects our thinking control (unknown future model, level set changed):
        # warn once and resend without it for the rest of the run.
        if getattr(e, "code", None) == 400 and thinking is not None and "think" in str(e).lower():
            _thinking_rejected.add(model)
            emit("WARN_GEMINI_THINKING_REJECTED", model=model, error=str(e)[:200])
            config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=None, automatic_function_calling=no_afc)
            result = _stream(model, prompt, config)
        else:
            raise
    elapsed = time.time() - start

    The execution phase records a timestamp and delegates HTTP stream consumption to _stream. If the underlying API returns an HTTP 400 ClientError containing error text related to thinking parameters, the adapter intercepts the exception. It adds the offending model to the _thinking_rejected blacklist, issues a warning through emit("WARN_GEMINI_THINKING_REJECTED", ...), rebuilds the configuration payload with thinking_config=None, and immediately re-executes the streaming request to achieve graceful recovery without failing the pipeline step.

    Phase 3: Telemetry and Cost Accounting

        if result["usage"] is not None:
        _record(model, result["usage"], raw_tokens, level_desc, result["finish"], elapsed)
    else:
        record_usage("GEMINI", model, cost=None, measured=False)  # stream carried no usage_metadata
    if is_debug() and result["thoughts"]:
        emit_raw("DEBUG", f"THINKING SUMMARY:\n{result['thoughts']}", dest="LOG")

    Upon stream completion, this phase verifies whether metadata usage figures accompanied the response. If present, it dispatches the usage object to _record to compute costs, calculate empirical token-expansion ratios, and record metrics in the runtime ledger. If the stream completed without metadata, it registers an unmeasured usage event with measured=False. When running under debug mode (is_debug()), thought summaries accumulated from model reasoning segments are emitted directly to application logs.

    Phase 4: Output Classification and Error Enforcement

        if result["block_reason"] or result["finish"] in _BLOCK_FINISH_REASONS:
        category = result["block_reason"] or result["finish"]
        # A blocked prompt repeats for the same input; a stop on the candidate may pass on resampling.
        retryable = not result["block_reason"] and result["finish"] in _RETRYABLE_FINISH_REASONS
        count_event("GEMINI", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="Gemini", model=model, category=category)
        raise LLMRefusalError(model, category, provider="GEMINI", retryable=retryable)
    if result["finish"] in _TRUNCATION_FINISH_REASONS:
        count_event("GEMINI", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="Gemini", max_tokens=f"{max_output:,}")
        return TruncatedResponse(result["text"])
    if not result["text"]:
        emit_raw("WARNING", f"Gemini response contained no text (finish_reason={result['finish'] or 'n/a'})", dest="LOG")
    return result["text"]

    The final phase evaluates candidate termination states. If either prompt feedback flags a block_reason or the candidate finishes with a status matching _BLOCK_FINISH_REASONS, the function registers a refusal event and raises LLMRefusalError, setting retryable=True only for candidate-level sampling interruptions like SAFETY or RECITATION. If the generation was halted due to reaching output token bounds (MAX_TOKENS), it increments truncation counters and returns a TruncatedResponse. Otherwise, it returns the accumulated plaintext response string.

    Internal Helpers

    _timeout_ms()

    Visibility: Private Signature: def _timeout_ms() -> int:

    Description: Calculates the client timeout deadline in milliseconds by reading the GEMINI_TIMEOUT_SECONDS environment variable. The value is clamped to a minimum floor of 30.0 seconds to prevent premature disconnections, then multiplied by 1,000.

    Parameters: None.

    Returns: * int: Timeout deadline in milliseconds (defaults to 1_800_000 ms when the variable is missing or invalid).

    Raises: None. Non-numeric values fall back safely to 1,800.0 seconds via internal try/except ValueError handling.

    Example: 

    def _timeout_ms() -> int:
    """Total per-request deadline (the SDK applies it to the whole streamed response)."""
    try:
        seconds = float(os.getenv("GEMINI_TIMEOUT_SECONDS", "1800"))
    except ValueError:
        seconds = 1800.0
    return int(max(seconds, 30.0) * 1000)

    The Google GenAI SDK applies this timeout across the full lifespan of the streaming iterator rather than resetting an idle timer on chunk receipt. Clamping the timeout to at least 30 seconds ensures the client survives prolonged cold-start initialization or deep reasoning traces without aborting prematurely.

    _get_client()

    Visibility: Private Signature: def _get_client():

    Description: Instantiates or returns the cached singleton genai.Client instance stored in the module-level _client variable. It configures underlying HTTP transport parameters, including timeout deadlines and automated retry rules for transient HTTP status codes.

    Parameters: None.

    Returns: * genai.Client: Initialized and authenticated Google GenAI client object.

    Raises: * ValueError: Raised when neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is configured in the environment.

    Example: 

    def _get_client():
    global _client
    if _client is None:
        http_options = types.HttpOptions(
            timeout=_timeout_ms(),  # milliseconds; with no timeout a stalled connection hangs forever
            # One SDK retry for transient errors; PocketFlow node retries (5 x 20 s) sit on top.
            retry_options=types.HttpRetryOptions(attempts=2, http_status_codes=[408, 429, 500, 502, 503, 504]),
        )
        if os.getenv("GEMINI_PROJECT_ID"):
            _client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=gemini_location(), http_options=http_options)
        elif os.getenv("GEMINI_API_KEY"):
            # vertexai=False explicitly: GOOGLE_GENAI_USE_VERTEXAI=true in the environment would otherwise
            # route the API key to Vertex AI.
            _client = genai.Client(vertexai=False, api_key=os.getenv("GEMINI_API_KEY"), http_options=http_options)
        else:
            raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    return _client

    This factory implements lazy client construction with explicit routing isolation. By explicitly setting vertexai=False when using GEMINI_API_KEY, it prevents ambient GOOGLE_GENAI_USE_VERTEXAI=true environment variables from incorrectly redirecting API key credentials to Google Cloud Vertex endpoints. Furthermore, HttpRetryOptions enables one low-level retry across transient gateway errors (408, 429, 500, 502, 503, 504) beneath the application-level pipeline retries.

    _thinking_config()

    Visibility: Private Signature: def _thinking_config(model: str, level: str | None):

    Description: Resolves and constructs the appropriate types.ThinkingConfig instance and its human-readable diagnostic description for a given model and reasoning tier. It enforces the constraint that thinking_level (used by Gemini 3.x) and thinking_budget (used by Gemini 2.5) must never be sent simultaneously in the same request payload.

    Parameters: * model (str): The target model identifier string. * level (str | None): Requested reasoning effort level string (e.g., "low", "medium", "high"), or None for default model behavior.

    Returns: * tuple[types.ThinkingConfig | None, str]: A 2-tuple containing the constructed configuration object (or None) and a diagnostic label string describing the effective mode.

    Raises: None. Unsupported or rejected levels emit warnings and fall back gracefully.

    Example: 

    def _thinking_config(model: str, level: str | None):
    """(ThinkingConfig | None, description). Never mixes thinking_level with thinking_budget."""
    mode, spec = gemini_thinking_mode(model)
    include = True if is_debug() else None  # thought summaries only for the debug log
    if model in _thinking_rejected:
        return None, "default (thinking config rejected by model)"
    if not level:
        # Model default thinking; with --debug still ask for summaries so they can be logged.
        return (types.ThinkingConfig(include_thoughts=True) if include and mode != "none" else None), "default"
    if mode == "level":
        effective = clamp_level(level.lower(), spec) or spec[-1]
        if effective != level.lower() and warn_once("gemini_level", model, level):
            emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effective, model=model)
        return types.ThinkingConfig(thinking_level=effective, include_thoughts=include), f"thinking_level={effective}"
    if mode == "budget":
        low, high, _can_disable = spec
        budget = min(max(GEMINI_THINKING_BUDGETS.get(level.lower(), 4096), low), high)
        return types.ThinkingConfig(thinking_budget=budget, include_thoughts=include), f"thinking_budget={budget}"
    if warn_once("gemini_no_thinking", model):
        emit("WARN_THINKING_NOT_SUPPORTED", model=model)
    return None, "unsupported"

    The function inspects gemini_thinking_mode(model) from llm_config.py to branch between categorical levels and token budgets. If the model was previously marked as rejecting thinking controls in _thinking_rejected, it returns None. For categorical models, it invokes clamp_level from thinking.py to ensure the requested tier falls within the model's allowed enum values (e.g., re-mapping "xhigh" to "high"). Thought inclusion (include_thoughts=True) is gated exclusively on debug mode (is_debug()) to conserve log volume during production runs.

    _max_output_tokens()

    Visibility: Private Signature: def _max_output_tokens(model: str, level: str | None) -> int:

    Description: Calculates the upper limit of output tokens to request for a given model and thinking level. It retrieves the model's static or dynamic output token ceiling and computes the budget via gemini_output_budget.

    Parameters: * model (str): Target model identifier string. * level (str | None): Desired thinking level string.

    Returns: * int: The maximum number of tokens the model is permitted to generate.

    Raises: None.

    Example: 

    def _max_output_tokens(model: str, level: str | None) -> int:
    """Per-level budget capped by the model's output limit. Gemini documents separate input and
    output limits, so output is not reduced for large prompts (input_token_budget still reserves it)."""
    _input_limit, output_limit = get_model_limits(model)
    return gemini_output_budget(level, output_limit)

    Because Gemini architectures maintain separate, non-overlapping allocations for input context and output generation, the output reservation does not need to scale down as prompt sizes grow. Instead, it delegates to gemini_output_budget from llm_config.py, ensuring output reservations leave ample headroom for internal reasoning tokens, which Google bills as output tokens.

    _price()

    Visibility: Private Signature: def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:

    Description: Computes the estimated monetary cost in US Dollars for a completed Gemini request based on token consumption, model prefix matching, prompt caching tiers, promotional discounts, and regional Vertex AI uplifts.

    Parameters: * model (str): The model name used during the API call. * prompt_tokens (int): Total count of input prompt tokens (including cached tokens). * cached (int): Count of input tokens read from the server-side context cache. * output_tokens (int): Total count of generated output and thinking tokens. * today (datetime.date | None, optional): Reference date used for evaluating promotional introductory pricing expiration. Defaults to None (resolving to datetime.date.today()).

    Returns: * float | None: Calculated total cost in USD, or None if the model does not match any entry in _PRICING.

    Raises: None.

    Example: 

    def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:
    key = next((k for k in sorted(_PRICING, key=len, reverse=True) if model.lower().startswith(k)), None)
    if key is None:
        return None
    row = _PRICING[key]
    if key in _INTRO_PRICING and (today or datetime.date.today()) <= _INTRO_PRICING_UNTIL:
        row = _INTRO_PRICING[key]
    p_in, p_out, p_cache = row[3:6] if len(row) == 6 and prompt_tokens > _LONG_CONTEXT_THRESHOLD else row[:3]
    uncached = max(prompt_tokens - cached, 0)
    cost = (uncached * p_in + cached * p_cache + output_tokens * p_out) / 1_000_000
    if os.getenv("GEMINI_PROJECT_ID") and gemini_location().lower() != "global":
        cost *= _REGIONAL_UPLIFT
    return cost

    The pricing algorithm matches the target model against _PRICING keys sorted by length in descending order, ensuring specific identifiers (e.g., "gemini-3.8-flash-cyber") take precedence over generic prefixes (e.g., "gemini-3.8-flash"). It checks introductory price tables valid through December 31, 2026, selects higher rate tiers for prompts exceeding the 200,000-token _LONG_CONTEXT_THRESHOLD, deducts cached tokens from standard input billing, and applies a 10% surcharge (_REGIONAL_UPLIFT = 1.10) for non-global Vertex AI deployments.

    _record()

    Visibility: Private Signature: def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:

    Description: Extracts token usage metrics from an SDK UsageMetadata object, updates the central usage ledger via record_usage, calibrates the local tokenizer ratio via observe_prompt_tokens, and emits diagnostic telemetry to application logs and console outputs.

    Parameters: * model (str): Identifier of the executed model. * usage (Any): The usage_metadata object returned on the generation stream chunk. * raw_prompt_tokens (int): Token count estimated locally before dispatch using tiktoken. * level_desc (str): Text description of the thinking level configuration applied to the request. * finish (str): Normalized finish reason token string. * elapsed (float): Total wall-clock execution duration in seconds.

    Returns: None.

    Raises: None.

    Example: 

    def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:
    prompt = getattr(usage, "prompt_token_count", 0) or 0
    candidates = getattr(usage, "candidates_token_count", 0) or 0
    thoughts = getattr(usage, "thoughts_token_count", 0) or 0
    cached = getattr(usage, "cached_content_token_count", 0) or 0
    output = candidates + thoughts  # thinking is billed as output
    cost = _price(model, prompt, cached, output)
    record_usage("GEMINI", model, input_tokens=prompt, output_tokens=output, thinking_tokens=thoughts, cache_read=cached, cost=cost)
    ratio = prompt / raw_prompt_tokens if raw_prompt_tokens else 0.0
    from utils.token_utils import observe_prompt_tokens

    observe_prompt_tokens("GEMINI", model, raw_prompt_tokens, prompt)  # prompt_token_count includes cached tokens
    emit_raw(
        "DEBUG",
        f"GEMINI USAGE | model={model} | {level_desc} | finish={finish or 'n/a'} | in={prompt:,} | out={candidates:,} | thinking={thoughts:,} | "
        f"cached={cached:,} | est_cost={'$' + format(cost, '.4f') if cost is not None else 'n/a'} | elapsed={elapsed:.1f}s | observed_token_ratio={ratio:.2f}",
        dest="BOTH",
    )

    Thinking tokens are combined with standard candidate tokens because Google bills model reasoning at standard output token rates. The observed ratio between raw tiktoken prompt counts and actual API-reported prompt tokens is passed to observe_prompt_tokens in token_utils.py, allowing the system to refine future budgeting calculations dynamically throughout the pipeline run.

    _stream()

    Visibility: Private Signature: def _stream(model: str, prompt: str, config) -> dict:

    Description: Consumes the generator returned by client.models.generate_content_stream. It iterates through streaming chunks to assemble response text, collect thought segments, extract usage metadata, and record termination or block reasons.

    Parameters: * model (str): The model identifier string. * prompt (str): The prompt payload to send in the contents list. * config (types.GenerateContentConfig): Fully populated SDK configuration object.

    Returns: * dict: A dictionary containing assembled content and stream metadata with the keys "text", "thoughts", "finish", "block_reason", and "usage".

    Raises: * genai_errors.ClientError: Propagates API-level client exceptions encountered during stream consumption.

    Example: 

    def _stream(model: str, prompt: str, config) -> dict:
    """Consume generate_content_stream; returns text, thoughts, finish, block_reason, usage."""
    text, thoughts = [], []
    finish, block_reason, usage = "", "", None
    for chunk in _get_client().models.generate_content_stream(model=model, contents=[prompt], config=config):
        feedback = getattr(chunk, "prompt_feedback", None)
        if feedback is not None and getattr(feedback, "block_reason", None):
            block_reason = _name(feedback.block_reason)
        if getattr(chunk, "usage_metadata", None) is not None:
            usage = chunk.usage_metadata
        for candidate in getattr(chunk, "candidates", None) or []:
            if getattr(candidate, "finish_reason", None):
                finish = _name(candidate.finish_reason)
            content = getattr(candidate, "content", None)
            for part in (getattr(content, "parts", None) or []) if content is not None else []:
                if getattr(part, "text", None):
                    (thoughts if getattr(part, "thought", False) else text).append(part.text)
            break  # candidate_count is 1
    return {"text": "".join(text), "thoughts": "".join(thoughts), "finish": finish, "block_reason": block_reason, "usage": usage}

    The function handles multiple candidate parts per chunk, inspecting the boolean part.thought attribute to separate internal reasoning traces from deliverable output text. Because requests configure a single candidate (candidate_count=1), the candidate loop breaks after the primary index. Metadata updates overwrite local variables so that the final chunk retains cumulative usage_metadata and final termination statuses.

    Error Handling

    The module implements a tiered error management strategy distinguishing between credential misconfigurations, transient transport errors, vendor parameter mismatches, content safety rejections, and output truncations:

    • Credential Preflight Verification: _get_client() asserts the presence of either GEMINI_PROJECT_ID or GEMINI_API_KEY. If neither is detected, it raises a ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment"), halting initialization before network requests occur.
    • Transport and Gateway Retries: Transient HTTP failures (status codes 408, 429, 500, 502, 503, and 504) are intercepted directly at the transport layer via types.HttpRetryOptions(attempts=2). This provides a transparent retry underneath pipeline retry mechanisms.
    • Thinking Configuration Fallback: If an unlisted or updated Gemini model rejects thinking configuration options with an HTTP 400 genai_errors.ClientError containing "think" in the message body, call_gemini() captures the error. It memoizes the failure in _thinking_rejected, emits WARN_GEMINI_THINKING_REJECTED, strips thinking_config, and re-issues the request immediately.
    • Refusal and Policy Enforcement: When the API refuses a prompt or candidate due to safety checks, recitation blocks, or prohibited content, call_gemini() raises an LLMRefusalError. It classifies the error as retryable=True for non-deterministic sampling stops (SAFETY, RECITATION, LANGUAGE, OTHER) and retryable=False for deterministic prompt violations (PROHIBITED_CONTENT, BLOCKLIST, SPII).
    • Output Truncation Wrapping: Reaching output token ceilings (finish_reason == "MAX_TOKENS") is treated as a non-fatal truncation. The adapter logs WARN_LLM_TRUNCATED, records truncation metrics via count_event("GEMINI", "truncations"), and returns the accumulated text wrapped in a TruncatedResponse instance, preventing caching engines in call_llm.py from storing incomplete output.
