    llm_gemini.py

    Source: utils/llm_gemini.py

    Technical Overview

    Building upon the configuration abstractions and provider capability mappings established in utils/llm_config.py, utils/llm_gemini.py provides the dedicated, low-level execution engine for Google Gemini models within the pipeline. It acts as the sole driver importing the official google-genai SDK, isolating external Google Cloud and AI Studio dependencies from the remainder of the architecture. The module encapsulates authentication resolution, thinking mode negotiation, response streaming, finish reason analysis, token accounting, and financial modeling for both Gemini 2.5 and Gemini 3.x architectures.

    The module interfaces with Google's inference infrastructure through two distinct deployment topologies: Google AI Studio (authenticated via GEMINI_API_KEY) and Google Cloud Vertex AI (authenticated via environment credentials alongside GEMINI_PROJECT_ID and GEMINI_LOCATION). All generations are executed through chunked streaming (generate_content_stream), ensuring long-form documentation synthesis does not encounter transport-layer HTTP timeouts. Furthermore, the engine manages model-specific reasoning controls—translating abstract thinking tiers into discrete reasoning levels on Gemini 3.x or explicit token budgets on Gemini 2.5—while automatically executing a graceful degradation fallback when encountering unexpected provider-side schema rejections.

    Public API

    get_model()

    Visibility: Public

    Signature: def get_model() -> str:

    Description: Resolves and sanitizes the configured Gemini model name from the runtime environment. It reads the GEMINI_MODEL environment variable, falls back to DEFAULT_GEMINI_MODEL if unset, and strips any Google Cloud resource prefixes (such as models/ or publishers/google/models/) via gemini_model_id() to ensure compatibility across both Vertex AI and AI Studio endpoints.

    Parameters:

    This function takes no parameters.

    Returns:

    • str: The normalized model identifier string (e.g., "gemini-3.7-flash").

    Raises:

    This function does not raise exceptions internally.

    Example:

    # Extracted from utils/llm_gemini.py call_gemini()
model = get_model()
raw_tokens = count_tokens_raw(prompt)
max_output = _max_output_tokens(model, thinking_level)

    The function queries os.getenv("GEMINI_MODEL") and passes the value through the canonical normalization logic in utils.llm_config.gemini_model_id. Downstream callers receive a uniform string identifier that can be used directly in API client routing and pricing lookup tables.

    get_model_limits()

    Visibility: Public

    Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Retrieves the maximum input and output token boundaries for a given Gemini model. If using AI Studio credentials, it queries the Google GenAI SDK's client.models.get() endpoint dynamically to inspect remote limits and caches the result. When running against Google Cloud Vertex AI (where the SDK does not map token limits) or when network lookups fail, it falls back to the static boundaries defined in GEMINI_DEFAULT_LIMITS.

    Parameters:

    • model (str): The normalized model identifier string.

    Returns:

    • tuple[int, int]: A 2-tuple structured as (input_token_limit, output_token_limit).

    Raises:

    This function traps all exceptions internally and logs a warning via emit("WARN_GEMINI_MODEL_LOOKUP"), returning default fallback limits instead of raising.

    Example:

    # Extracted from utils/llm_gemini.py get_model_limits() implementation
if model in _model_limits_cache:
    return _model_limits_cache[model]
limits = GEMINI_DEFAULT_LIMITS
if not os.getenv("GEMINI_PROJECT_ID"):
    try:
        info = _get_client().models.get(model=model)
        limits = (
            getattr(info, "input_token_limit", None) or limits[0],
            getattr(info, "output_token_limit", None) or limits[1],
        )
        emit_raw(
            "DEBUG",
            f"Gemini models.get | model={model} | input={limits[0]:,} | output={limits[1]:,}",
            dest="LOG",
        )
    except Exception as e:
        emit("WARN_GEMINI_MODEL_LOOKUP", model=model, error=str(e)[:200])
_model_limits_cache[model] = limits
return limits

    The function checks an in-memory memoization dictionary (_model_limits_cache) to avoid redundant metadata round-trips. When dynamic lookup succeeds on AI Studio, it preserves any missing remote fields by falling back on the corresponding element in GEMINI_DEFAULT_LIMITS. Vertex AI invocations bypass dynamic lookups entirely because the Vertex API does not publish token boundary attributes on model descriptor objects.

    call_gemini()

    Visibility: Public

    Signature: def call_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: The primary entry point for executing single-turn prompt completions against Google Gemini models. It orchestrates prompt token counting, output budgeting, reasoning configuration, streaming consumption, automated failure recovery, telemetry recording, and termination classification.

    Parameters:

    • prompt (str): The complete, formatted prompt string to send to the model.
    • thinking_level (str | None, optional): The requested reasoning effort tier (e.g., "low", "medium", "high", or None to adopt model defaults). Defaults to None.

    Returns:

    • str: The generated text response. If the response was truncated due to output token exhaustion, an instance of TruncatedResponse (a specialized str subclass) is returned.

    Raises:

    • LLMRefusalError: Raised when the prompt is blocked by content policy or when the candidate output triggers safety, blocklist, recitation, or language filters.
    • genai_errors.ClientError: Raised if the Google GenAI SDK encounters unhandled client-side or HTTP protocol errors not covered by the thinking recovery fallback.
    • ValueError: Raised if neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Phase 1: Parameter Assembly and Configuration

    from utils.token_utils import count_tokens_raw

model = get_model()
raw_tokens = count_tokens_raw(prompt)
max_output = _max_output_tokens(model, thinking_level)
thinking, level_desc = _thinking_config(model, thinking_level)
# No tools are passed, so automatic function calling is off (google-genai warns on streams otherwise).
no_afc = types.AutomaticFunctionCallingConfig(disable=True)
config = types.GenerateContentConfig(
    max_output_tokens=max_output,
    thinking_config=thinking,
    automatic_function_calling=no_afc,
)
emit_raw(
    "DEBUG",
    f"Gemini request | model={model} | {level_desc} | max_output_tokens={max_output:,} | location={gemini_location() if os.getenv('GEMINI_PROJECT_ID') else 'ai-studio'}",
    dest="LOG",
)

    In the initialization phase, the model identifier is normalized and the raw prompt is tokenized using count_tokens_raw(). The maximum allowable output token ceiling is computed via _max_output_tokens(), which harmonizes caller-requested reasoning allocations with the model's hard output limits. The thinking configuration is resolved into an SDK-compatible types.ThinkingConfig instance. Automatic function calling is explicitly disabled via types.AutomaticFunctionCallingConfig(disable=True) to prevent the SDK from emitting runtime warnings when processing chunked streams without tool declarations.

    Phase 2: Stream Execution and Fallback Recovery

    start = time.time()
try:
    result = _stream(model, prompt, config)
except genai_errors.ClientError as e:
    # A model that rejects our thinking control (unknown future model, level set changed):
    # warn once and resend without it for the rest of the run.
    if getattr(e, "code", None) == 400 and thinking is not None and "think" in str(e).lower():
        _thinking_rejected.add(model)
        emit("WARN_GEMINI_THINKING_REJECTED", model=model, error=str(e)[:200])
        config = types.GenerateContentConfig(
            max_output_tokens=max_output,
            thinking_config=None,
            automatic_function_calling=no_afc,
        )
        result = _stream(model, prompt, config)
    else:
        raise
elapsed = time.time() - start

    The execution phase dispatches the prompt through _stream(). If the remote endpoint returns an HTTP 400 client error caused by an incompatible or deprecated thinking specification, the exception handler catches the genai_errors.ClientError. It verifies the status code and error message, caches the model in the module-level _thinking_rejected set to prevent future incompatible requests, strips the thinking configuration from types.GenerateContentConfig, and immediately retries the generation. Unrelated errors are re-raised without modification.

    Phase 3: Telemetry Accounting and Token Ratio Observation

    if result["usage"] is not None:
    _record(model, result["usage"], raw_tokens, level_desc, result["finish"], elapsed)
else:
    record_usage("GEMINI", model, cost=None, measured=False)  # stream carried no usage_metadata
if is_debug() and result["thoughts"]:
    emit_raw("DEBUG", f"THINKING SUMMARY:\n{result['thoughts']}", dest="LOG")

    Once the stream is completely consumed, the response payload is evaluated for telemetry metadata. If usage_metadata was returned by the SDK, _record() extracts token counts across prompt input, candidate output, reasoning/thought tokens, and cached prompt reads, computes estimated billing, and passes prompt statistics to observe_prompt_tokens(). If usage metadata was absent from the stream chunks, the module records an unmeasured fallback event via record_usage(). When debug mode is active, extracted model thought summaries are directed to the execution log.

    Phase 4: Safety, Refusal, and Truncation Evaluation

    if result["block_reason"] or result["finish"] in _BLOCK_FINISH_REASONS:
    category = result["block_reason"] or result["finish"]
    # A blocked prompt repeats for the same input; a stop on the candidate may pass on resampling.
    retryable = not result["block_reason"] and result["finish"] in _RETRYABLE_FINISH_REASONS
    count_event("GEMINI", "refusals")
    emit(
        "WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL",
        provider="Gemini",
        model=model,
        category=category,
    )
    raise LLMRefusalError(model, category, provider="GEMINI", retryable=retryable)
if result["finish"] in _TRUNCATION_FINISH_REASONS:
    count_event("GEMINI", "truncations")
    emit("WARN_LLM_TRUNCATED", provider="Gemini", max_tokens=f"{max_output:,}")
    return TruncatedResponse(result["text"])
if not result["text"]:
    emit_raw("WARNING", f"Gemini response contained no text (finish_reason={result['finish'] or 'n/a'})", dest="LOG")
return result["text"]

    The final phase examines prompt feedback and candidate finish reasons. If a prompt-level block reason exists or the candidate finished with a refusal code, the system differentiates between deterministic policy blocks (non-retryable) and candidate-level safety/recitation/sampling stops (retryable=True), recording telemetry and raising an LLMRefusalError. If the generation was halted due to reaching MAX_TOKENS, it logs a truncation warning and wraps the output string in a TruncatedResponse to prevent downstream nodes from caching partial completions. If completed normally, the text is returned as a standard string.

    Internal Helpers

    _timeout_ms()

    Visibility: Private

    Signature: def _timeout_ms() -> int:

    Description: Calculates the total per-request HTTP timeout in milliseconds. It reads GEMINI_TIMEOUT_SECONDS from the environment, enforces a minimum baseline of 30.0 seconds to prevent premature disconnections, and converts the resulting floating-point value to an integer millisecond representation.

    Parameters:

    This helper takes no parameters.

    Returns:

    • int: Total request timeout in milliseconds.

    Raises:

    This helper does not raise exceptions; invalid numeric formats fall back to 1,800 seconds (1,800,000 ms).

    Example:

    # Extracted from utils/llm_gemini.py _timeout_ms() implementation
try:
    seconds = float(os.getenv("GEMINI_TIMEOUT_SECONDS", "1800"))
except ValueError:
    seconds = 1800.0
return int(max(seconds, 30.0) * 1000)

    The function provides an operational guard for streaming invocations. Because the Google GenAI SDK applies this timeout across the lifetime of the entire response stream rather than as an idle read timeout, prolonged generations with extended reasoning budgets require deadlines that span several minutes.

    _get_client()

    Visibility: Private

    Signature: def _get_client():

    Description: Lazily constructs and caches the global google.genai.Client singleton (_client). It configures transport-level retry policies and determines whether to initialize the client for Google Cloud Vertex AI or Google AI Studio based on ambient environment variables.

    Parameters:

    This helper takes no parameters.

    Returns:

    • google.genai.Client: An initialized, authenticated Google GenAI client instance.

    Raises:

    • ValueError: Raised if neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is configured in the environment.

    Example:

    # Extracted from utils/llm_gemini.py _get_client() implementation
global _client
if _client is None:
    http_options = types.HttpOptions(
        timeout=_timeout_ms(),  # milliseconds; with no timeout a stalled connection hangs forever
        # One SDK retry for transient errors; PocketFlow node retries (5 x 20 s) sit on top.
        retry_options=types.HttpRetryOptions(attempts=2, http_status_codes=[408, 429, 500, 502, 503, 504]),
    )
    if os.getenv("GEMINI_PROJECT_ID"):
        _client = genai.Client(
            vertexai=True,
            project=os.getenv("GEMINI_PROJECT_ID"),
            location=gemini_location(),
            http_options=http_options,
        )
    elif os.getenv("GEMINI_API_KEY"):
        _client = genai.Client(
            vertexai=False,
            api_key=os.getenv("GEMINI_API_KEY"),
            http_options=http_options,
        )
    else:
        raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
return _client

    The helper sets up types.HttpRetryOptions to automatically retry transient HTTP 408, 429, 500, 502, 503, and 504 status codes up to two attempts at the network layer. When authenticating via GEMINI_API_KEY, it explicitly passes vertexai=False to prevent the SDK from inadvertently redirecting API key credentials to Vertex AI if GOOGLE_GENAI_USE_VERTEXAI=true is set elsewhere in the environment.

    _thinking_config()

    Visibility: Private

    Signature: def _thinking_config(model: str, level: str | None):

    Description: Resolves the appropriate google.genai.types.ThinkingConfig object and human-readable diagnostic description based on the target model's architecture. It enforces mutual exclusivity between Gemini 3.x thinking levels and Gemini 2.5 thinking budgets.

    Parameters:

    • model (str): The normalized model identifier string.
    • level (str | None): The requested reasoning effort tier, or None.

    Returns:

    • tuple[types.ThinkingConfig | None, str]: A 2-tuple containing the configured ThinkingConfig instance (or None) and a diagnostic label string (e.g., "thinking_level=high", "thinking_budget=4096", "default").

    Raises:

    This helper does not raise exceptions. It emits warnings if thinking levels are clamped or unsupported.

    Example:

    # Extracted from utils/llm_gemini.py _thinking_config() implementation
mode, spec = gemini_thinking_mode(model)
include = True if is_debug() else None  # thought summaries only for the debug log
if model in _thinking_rejected:
    return None, "default (thinking config rejected by model)"
if not level:
    return (types.ThinkingConfig(include_thoughts=True) if include and mode != "none" else None), "default"
if mode == "level":
    effective = clamp_level(level.lower(), spec) or spec[-1]
    if effective != level.lower() and warn_once("gemini_level", model, level):
        emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effective, model=model)
    return types.ThinkingConfig(thinking_level=effective, include_thoughts=include), f"thinking_level={effective}"
if mode == "budget":
    low, high, _can_disable = spec
    budget = min(max(GEMINI_THINKING_BUDGETS.get(level.lower(), 4096), low), high)
    return types.ThinkingConfig(thinking_budget=budget, include_thoughts=include), f"thinking_budget={budget}"
if warn_once("gemini_no_thinking", model):
    emit("WARN_THINKING_NOT_SUPPORTED", model=model)
return None, "unsupported"

    The function calls gemini_thinking_mode(model) from utils.llm_config to identify whether the target architecture expects a categorical reasoning level (mode == "level"), an integer token budget (mode == "budget"), or does not support reasoning (mode == "none"). If the model has previously returned an HTTP 400 error against thinking configurations, it bypasses configuration immediately. When debug mode is active, it sets include_thoughts=True so internal reasoning thoughts can be captured in diagnostics.

    _max_output_tokens()

    Visibility: Private

    Signature: def _max_output_tokens(model: str, level: str | None) -> int:

    Description: Computes the output token reservation for a request. It determines the target output budget based on the active reasoning level and caps the calculation by the physical model limit retrieved from get_model_limits().

    Parameters:

    • model (str): The normalized model identifier string.
    • level (str | None): The requested reasoning effort tier, or None.

    Returns:

    • int: The maximum allowed output token budget.

    Raises:

    This helper does not raise exceptions internally.

    Example:

    # Extracted from utils/llm_gemini.py _max_output_tokens() implementation
_input_limit, output_limit = get_model_limits(model)
return gemini_output_budget(level, output_limit)

    Because Google Gemini documents separate, non-shared context windows for input and output, output allocations are not diminished by oversized input prompts. The helper delegates directly to gemini_output_budget() in utils.llm_config to resolve the budget against the model's reported output_limit.

    _price()

    Visibility: Private

    Signature: def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:

    Description: Calculates the estimated monetary cost (in USD) of an inference request based on Google's published multi-tier pricing schedules, introductory rate periods, regional Vertex AI surcharges, and long-context prompt thresholds.

    Parameters:

    • model (str): The model identifier.
    • prompt_tokens (int): Total prompt token count (including cached tokens).
    • cached (int): Number of prompt tokens served from context cache.
    • output_tokens (int): Total output tokens generated (candidate tokens plus thinking tokens).
    • today (datetime.date | None, optional): Override date used for introductory pricing evaluation. Defaults to None (which uses datetime.date.today()).

    Returns:

    • float | None: Estimated cost in USD, or None if the model has no pricing entry in _PRICING.

    Raises:

    This helper does not raise exceptions.

    Example:

    # Extracted from utils/llm_gemini.py _price() implementation
key = next((k for k in sorted(_PRICING, key=len, reverse=True) if model.lower().startswith(k)), None)
if key is None:
    return None
row = _PRICING[key]
if key in _INTRO_PRICING and (today or datetime.date.today()) <= _INTRO_PRICING_UNTIL:
    row = _INTRO_PRICING[key]
p_in, p_out, p_cache = row[3:6] if len(row) == 6 and prompt_tokens > _LONG_CONTEXT_THRESHOLD else row[:3]
uncached = max(prompt_tokens - cached, 0)
cost = (uncached * p_in + cached * p_cache + output_tokens * p_out) / 1_000_000
if os.getenv("GEMINI_PROJECT_ID") and gemini_location().lower() != "global":
    cost *= _REGIONAL_UPLIFT
return cost

    Pricing lookups match model names against the keys in _PRICING using longest-prefix matching. If the model qualifies for introductory rates prior to _INTRO_PRICING_UNTIL, _INTRO_PRICING overrides standard rates. If the prompt exceeds _LONG_CONTEXT_THRESHOLD (200,000 tokens) and the model specifies a 6-tuple rate schedule, tier-two pricing is applied. Finally, if executed on Vertex AI outside the global region, a 10% regional uplift (_REGIONAL_UPLIFT) is applied.

    _record()

    Visibility: Private

    Signature: def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:

    Description: Parses the SDK usage_metadata object, bills output and reasoning tokens, records usage metrics into the centralized accounting ledger, updates runtime token calibration ratios, and emits execution telemetry.

    Parameters:

    • model (str): The model identifier.
    • usage (Any): The usage_metadata object returned on the generation stream chunk.
    • raw_prompt_tokens (int): The tiktoken-derived baseline token count for the prompt.
    • level_desc (str): Diagnostic description of the applied thinking configuration.
    • finish (str): Candidate finish reason string.
    • elapsed (float): Generation elapsed time in seconds.

    Returns:

    • None: This helper returns nothing.

    Raises:

    This helper does not raise exceptions.

    Example:

    # Extracted from utils/llm_gemini.py _record() implementation
prompt = getattr(usage, "prompt_token_count", 0) or 0
candidates = getattr(usage, "candidates_token_count", 0) or 0
thoughts = getattr(usage, "thoughts_token_count", 0) or 0
cached = getattr(usage, "cached_content_token_count", 0) or 0
output = candidates + thoughts  # thinking is billed as output
cost = _price(model, prompt, cached, output)
record_usage(
    "GEMINI",
    model,
    input_tokens=prompt,
    output_tokens=output,
    thinking_tokens=thoughts,
    cache_read=cached,
    cost=cost,
)
ratio = prompt / raw_prompt_tokens if raw_prompt_tokens else 0.0
from utils.token_utils import observe_prompt_tokens

observe_prompt_tokens("GEMINI", model, raw_prompt_tokens, prompt)  # prompt_token_count includes cached tokens
emit_raw(
    "DEBUG",
    f"GEMINI USAGE | model={model} | {level_desc} | finish={finish or 'n/a'} | in={prompt:,} | out={candidates:,} | thinking={thoughts:,} | "
    f"cached={cached:,} | est_cost={'$' + format(cost, '.4f') if cost is not None else 'n/a'} | elapsed={elapsed:.1f}s | observed_token_ratio={ratio:.2f}",
    dest="BOTH",
)

    The function treats reasoning thoughts as billable output tokens by calculating output = candidates + thoughts. It logs the measured consumption into utils.llm_common.record_usage and invokes utils.token_utils.observe_prompt_tokens to continuously refine the runtime BPE-to-Gemini token multiplier ratio.

    _stream()

    Visibility: Private

    Signature: def _stream(model: str, prompt: str, config) -> dict:

    Description: Consumes the chunked response generator produced by client.models.generate_content_stream(). It aggregates output text, isolates thinking thoughts, captures prompt feedback block reasons, records candidate finish reasons, and preserves usage metadata.

    Parameters:

    • model (str): The model identifier.
    • prompt (str): The prompt string.
    • config (types.GenerateContentConfig): The request generation configuration.

    Returns:

    • dict: An aggregated stream result dictionary containing text, thoughts, finish, block_reason, and usage.

    Raises:

    • genai_errors.ClientError: Raised if the stream encounters Google GenAI client errors.
    • Exception: Raised on connection interruptions or SDK stream failures.

    Example:

    # Extracted from utils/llm_gemini.py _stream() implementation
text, thoughts = [], []
finish, block_reason, usage = "", "", None
for chunk in _get_client().models.generate_content_stream(model=model, contents=[prompt], config=config):
    feedback = getattr(chunk, "prompt_feedback", None)
    if feedback is not None and getattr(feedback, "block_reason", None):
        block_reason = _name(feedback.block_reason)
    if getattr(chunk, "usage_metadata", None) is not None:
        usage = chunk.usage_metadata
    for candidate in getattr(chunk, "candidates", None) or []:
        if getattr(candidate, "finish_reason", None):
            finish = _name(candidate.finish_reason)
        content = getattr(candidate, "content", None)
        for part in (getattr(content, "parts", None) or []) if content is not None else []:
            if getattr(part, "text", None):
                (thoughts if getattr(part, "thought", False) else text).append(part.text)
        break  # candidate_count is 1
return {
    "text": "".join(text),
    "thoughts": "".join(thoughts),
    "finish": finish,
    "block_reason": block_reason,
    "usage": usage,
}

    The helper iterates over stream chunks yielded by the Google GenAI SDK. For each candidate part, it checks the boolean part.thought flag; if true, the text segment is accumulated into the thoughts buffer, otherwise it is appended to the text buffer. The loop breaks after evaluating the primary candidate (candidate_count == 1).

    Error Handling

    The module implements a tiered error management strategy designed to differentiate transient network faults, non-retryable input policy violations, sampling-dependent candidate stops, and provider-side schema rejections:

    • Authentication Validation: In _get_client(), the absence of both GEMINI_PROJECT_ID and GEMINI_API_KEY immediately raises a ValueError, failing fast before any network requests are dispatched.
    • Transient Network Resilience: _get_client() configures the SDK's internal HttpRetryOptions to automatically retry transient HTTP 408, 429, 500, 502, 503, and 504 responses up to 2 attempts, complementing upstream pipeline workflow retries.
    • Dynamic Thinking Fallback: In call_gemini(), if a model returns an HTTP 400 genai_errors.ClientError referencing "think", the system identifies that the remote endpoint does not accept the supplied thinking parameters. It registers the model in _thinking_rejected, emits WARN_GEMINI_THINKING_REJECTED, strips the thinking configuration from types.GenerateContentConfig, and re-dispatches the stream.
    • Refusal Bifurcation: In call_gemini(), candidate and prompt blocks are checked against _BLOCK_FINISH_REASONS. Prompt-level blocks and policy list violations raise non-retryable LLMRefusalError(retryable=False), preventing pipeline retry loops from re-sending doomed prompts. Stochastic candidate stops (such as "SAFETY" or "RECITATION") raise LLMRefusalError(retryable=True) to permit upstream workflow nodes to re-attempt inference.
    • Truncation Trapping: In call_gemini(), responses terminating with finish_reason == "MAX_TOKENS" emit WARN_LLM_TRUNCATED and return a TruncatedResponse wrapper. This signals callers (such as utils.call_llm) to discard partial payloads and prevent truncated JSON or Markdown from polluting disk caches.
