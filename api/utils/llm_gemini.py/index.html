    llm_gemini.py

    Source: utils/llm_gemini.py

    Technical Overview

    Building upon the configuration, endpoint routing, and token reserve parameters established in utils/llm_config.py, this module provides the concrete Google Gemini provider implementation using the official google-genai SDK. It encapsulates all vendor-specific communication with Gemini models (Gemini 3.x and 2.5), handling request serialization, streaming transport, thought summary extraction, dynamic thinking parameter negotiation, and fine-grained token cost accounting. By centralizing the google-genai import within this module, the wider architecture avoids hard dependencies on Google's client libraries when other model providers are active.

    The module interfaces with either Google AI Studio (authenticated via GEMINI_API_KEY) or Vertex AI (authenticated via GEMINI_PROJECT_ID and GEMINI_LOCATION). All completions are executed over HTTP streaming connections (generate_content_stream), which avoids premature read timeouts on extended reasoning responses that can stretch up to 1,800 seconds. Transport-level transient errors (such as HTTP 408, 429, 500, 502, 503, and 504) are automatically retried by the SDK via HttpRetryOptions and monitored through an intercepted tenacity logger that emits real-time status notices without interrupting execution.

    To guarantee downstream cache integrity and prevent retry storms, llm_gemini.py performs rigorous finish reason analysis. Deterministic policy violations, blocklists, and safety filters map directly to utils/llm_common.py's LLMRefusalError, distinguishing between unretryable prompt blocks and retryable candidate stops. When generation limits truncate an output, the module returns a specialized TruncatedResponse instance that prevents partial answers from being committed to persistent disk caches. Additionally, real-time pricing calculations incorporate long-context tiers (>200K tokens), promotional introductory windows, and Vertex AI regional surcharges, directly feeding the system-wide usage ledger.

    Public API

    get_model()

    Visibility: Public

    Signature: def get_model() -> str:

    Description: Resolves the active Gemini model identifier by querying the GEMINI_MODEL environment variable. If the variable is unset or empty, it falls back to DEFAULT_GEMINI_MODEL from utils.llm_config. The resolved name is passed through gemini_model_id() to strip extraneous provider prefixes such as models/ or publishers/google/models/.

    Returns:

    • str: The normalized Gemini model identifier (e.g., "gemini-3.7-flash").

    Example:

    model = get_model()
raw_tokens = count_tokens_raw(prompt)
max_output = _max_output_tokens(model, thinking_level)

    The function reads environment configuration once per invocation, stripping resource prefixes dynamically. It ensures that downstream pricing lookups, token limit checks, and client calls receive an identifier that matches Google API conventions.

    get_model_limits()

    Visibility: Public

    Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Retrieves the context window and output token capacities for a specified Gemini model as an (input_token_limit, output_token_limit) tuple. When running against Google AI Studio (i.e., when GEMINI_PROJECT_ID is not set), the function queries the live API via client.models.get(model=model) to inspect real-time server limits, falling back to static constants in GEMINI_DEFAULT_LIMITS if the remote call fails. For Vertex AI deployments, where the SDK does not populate dynamic token limits, it bypasses the network call and returns static limits directly. Successful lookups are cached in the module-level _model_limits_cache dictionary to prevent redundant network round-trips.

    Parameters:

    • model (str): The normalized Gemini model identifier.

    Returns:

    • tuple[int, int]: A 2-tuple containing the maximum input tokens and maximum output tokens.

    Example:

    def get_model_limits(model: str) -> tuple[int, int]:
    """(input_token_limit, output_token_limit). AI Studio reports them via models.get; Vertex does
    not (the SDK maps no limits there), so the static Gemini 3.x / 2.5 table applies."""
    if model in _model_limits_cache:
        return _model_limits_cache[model]
    global _sdk_retries
    limits = GEMINI_DEFAULT_LIMITS
    if not os.getenv("GEMINI_PROJECT_ID"):
        try:
            _sdk_retries = 0
            info = _get_client().models.get(model=model)
            limits = (getattr(info, "input_token_limit", None) or limits[0], getattr(info, "output_token_limit", None) or limits[1])
            emit_raw("DEBUG", f"Gemini models.get | model={model} | input={limits[0]:,} | output={limits[1]:,}", dest="LOG")
        except Exception as e:
            emit("WARN_GEMINI_MODEL_LOOKUP", model=model, error=str(e)[:200])
    _model_limits_cache[model] = limits
    return limits

    The function implements in-memory memoization through _model_limits_cache. If an unexpected exception occurs while querying AI Studio, the error is truncated to 200 characters and emitted as a warning diagnostic, allowing the fallback tuple to preserve operational continuity.

    call_gemini()

    Visibility: Public

    Signature: def call_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: The primary public entry point for executing completions against Google Gemini models. Orchestrates token pre-estimation, output token reservation, thinking configuration formatting, streaming consumption, error handling, usage accounting, and refusal evaluation.

    Parameters:

    • prompt (str): The raw text prompt submitted to the model.
    • thinking_level (str | None, optional): Desired reasoning effort (e.g., "low", "medium", "high"). Defaults to None, which uses the model's native default behavior.

    Returns:

    • str: The generated text response, or an instance of TruncatedResponse (a str subclass) if generation hit output limits.

    Raises:

    • LLMRefusalError: Raised when the model rejects the request due to policy blocks, safety filters, or terms recitation.
    • google.genai.errors.ClientError: Raised if the API rejects the request with an unhandled 4xx error.
    • ValueError: Raised if neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Phase 1: Request Configuration and Parameter Budgeting

    emit_raw(
        "DEBUG",
        f"Gemini request | model={model} | {level_desc} | max_output_tokens={max_output:,} | location={gemini_location() if os.getenv('GEMINI_PROJECT_ID') else 'ai-studio'}",
        dest="LOG",
    )

    The execution begins by resolving the target model and counting raw prompt tokens via count_tokens_raw(). It calculates the maximum permitted output budget via _max_output_tokens() and constructs a types.ThinkingConfig object tailored to the model's architecture. Because no tool definitions are provided, automatic function calling is explicitly disabled to suppress SDK runtime warnings during streaming.

    Phase 2: Stream Execution with Fallback Recovery

        start = time.time()
    try:
        result = _stream(model, prompt, config)
    except genai_errors.ClientError as e:
        # A model that rejects our thinking control (unknown future model, level set changed):
        # warn once and resend without it for the rest of the run.
        if getattr(e, "code", None) == 400 and thinking is not None and "think" in str(e).lower():
            _thinking_rejected.add(model)
            emit("WARN_GEMINI_THINKING_REJECTED", model=model, error=str(e)[:200])
            config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=None, automatic_function_calling=no_afc)
            result = _stream(model, prompt, config)
        else:
            raise
    elapsed = time.time() - start

    The function executes the streaming completion wrapped inside an exception guard. If Google's API returns an HTTP 400 ClientError indicating that the model rejected the specified ThinkingConfig, the module registers the model into _thinking_rejected. It then strips the thinking configuration from GenerateContentConfig and immediately retries the request once, ensuring continuity on unmapped models.

    Phase 3: Telemetry, Accounting, and Debug Output

        if result["usage"] is not None:
        _record(model, result["usage"], raw_tokens, level_desc, result["finish"], elapsed)
    else:
        record_usage("GEMINI", model, cost=None, measured=False)  # stream carried no usage_metadata
    if is_debug() and result["thoughts"]:
        emit_raw("DEBUG", f"THINKING SUMMARY:\n{result['thoughts']}", dest="LOG")

    Once the stream is completely consumed, the function evaluates the captured usage_metadata. If usage metrics are available, _record() calculates pricing tiers, records ledger statistics via record_usage(), and updates token calibration ratios. If thought summaries were returned and debug logging is active, the reasoning content is emitted directly to the local diagnostic log file.

    Phase 4: Candidate Inspection and Refusal/Truncation Handling

        if result["block_reason"] or result["finish"] in _BLOCK_FINISH_REASONS:
        category = result["block_reason"] or result["finish"]
        # A blocked prompt repeats for the same input; a stop on the candidate may pass on resampling.
        retryable = not result["block_reason"] and result["finish"] in _RETRYABLE_FINISH_REASONS
        count_event("GEMINI", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="Gemini", model=model, category=category)
        raise LLMRefusalError(model, category, provider="GEMINI", retryable=retryable)
    if result["finish"] in _TRUNCATION_FINISH_REASONS:
        count_event("GEMINI", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="Gemini", max_tokens=f"{max_output:,}")

    if not result["text"]:

    return result["text"]

    The final phase inspects prompt block reasons and candidate finish reasons. If the request was halted by safety or policy filters, it classifies whether the refusal is deterministic (prompt-level violation) or retryable (sampling-dependent candidate stop) and raises LLMRefusalError. If the generation was halted due to MAX_TOKENS, it logs a truncation warning and wraps the text in TruncatedResponse to prevent disk caching before returning the result.

    Internal Helpers

    _timeout_ms()

    Visibility: Private

    Signature: def _timeout_ms() -> int:

    Description: Parses the GEMINI_TIMEOUT_SECONDS environment variable to determine the global per-request deadline in milliseconds. Enforces a lower bound of 30.0 seconds to prevent premature disconnections, defaulting to 1,800 seconds (30 minutes) if the variable is missing or malformed.

    Returns:

    • int: Total request timeout in milliseconds for types.HttpOptions.

    Example:

    def _timeout_ms() -> int:
    """Total per-request deadline (the SDK applies it to the whole streamed response)."""
    try:
        seconds = float(os.getenv("GEMINI_TIMEOUT_SECONDS", "1800"))
    except ValueError:
        seconds = 1800.0
    return int(max(seconds, 30.0) * 1000)

    Because the google-genai SDK applies timeouts across the entire duration of a streamed response rather than as an idle socket timeout, extended reasoning sequences require generous deadlines. Parsing failures gracefully fall back to the 1,800.0-second default.

    _sdk_retry_record()

    Visibility: Private

    Signature: def _sdk_retry_record(record) -> None:

    Description: Log record interceptor attached to the google_genai._api_client logger via open_sdk_logger. Matches tenacity retry log lines emitted before sleeping, extracts the planned wait time and underlying exception cause, increments the internal _sdk_retries counter, and broadcasts an LLM_HTTP_RETRY telemetry event.

    Parameters:

    • record (logging.LogRecord): The standard Python logging record intercepted from the SDK HTTP transport layer.

    Example:

    def _sdk_retry_record(record) -> None:
    """Reads the SDK's own retry record (tenacity's before-sleep line on ``google_genai._api_client``, through
    ``open_sdk_logger``: ``Retrying … in T seconds as it raised ServerError: 503 …``) into ``LLM_HTTP_RETRY``."""
    global _sdk_retries
    match = _TENACITY_RETRY_RE.match(record.getMessage())
    if match:
        _sdk_retries += 1
        emit(
            "LLM_HTTP_RETRY",
            provider="Gemini",
            attempt=_sdk_retries,
            attempts=_SDK_ATTEMPTS,
            error=brief(match.group("cause")),
            wait=match.group("wait"),
        )

    The helper uses regular expression matching via _TENACITY_RETRY_RE to extract structured details from unstructured SDK logs. It transforms obscure transport logs into structured CLI notifications, informing users of transient network backoffs without interrupting node operations.

    _get_client()

    Visibility: Private

    Signature: def _get_client():

    Description: Lazily constructs and returns a singleton instance of google.genai.Client. Configures HttpOptions with the timeout from _timeout_ms() and registers automatic SDK retry attempts for HTTP status codes 408, 429, 500, 502, 503, and 504. Dynamically routes between Vertex AI and AI Studio based on the presence of GEMINI_PROJECT_ID.

    Returns:

    • genai.Client: Configured Google GenAI client instance.

    Raises:

    • ValueError: Raised if neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Example:

    def _get_client():
    global _client
    if _client is None:
        http_options = types.HttpOptions(
            timeout=_timeout_ms(),  # milliseconds; with no timeout a stalled connection hangs forever
            # SDK retries for transient errors (announced: _sdk_retry_record); PocketFlow node retries (5 x 20 s) sit on top.
            retry_options=types.HttpRetryOptions(attempts=_SDK_ATTEMPTS, http_status_codes=[408, 429, 500, 502, 503, 504]),
        )
        open_sdk_logger("google_genai._api_client", logging.INFO, _sdk_retry_record)
        if os.getenv("GEMINI_PROJECT_ID"):
            _client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=gemini_location(), http_options=http_options)
        elif os.getenv("GEMINI_API_KEY"):
            # vertexai=False explicitly: GOOGLE_GENAI_USE_VERTEXAI=true in the environment would otherwise
            # route the API key to Vertex AI.
            _client = genai.Client(vertexai=False, api_key=os.getenv("GEMINI_API_KEY"), http_options=http_options)
        else:
            raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    return _client

    When authenticating via GEMINI_API_KEY, the client explicitly sets vertexai=False. This prevents ambient environment variables like GOOGLE_GENAI_USE_VERTEXAI=true from misrouting consumer API keys to Google Cloud Vertex endpoints.

    _thinking_config()

    Visibility: Private

    Signature: def _thinking_config(model: str, level: str | None):

    Description: Translates an abstract thinking level into a concrete types.ThinkingConfig instance and descriptive telemetry string. Respects model-specific reasoning modes ("level" vs "budget" vs "none"), clamps requested levels to allowed boundaries, and requests thought summaries only when debug mode is enabled.

    Parameters:

    • model (str): The normalized model identifier.
    • level (str | None): The requested thinking effort level or budget string.

    Returns:

    • tuple[types.ThinkingConfig | None, str]: A tuple containing the initialized configuration (or None) and a telemetry description string.

    Example:

    def _thinking_config(model: str, level: str | None):
    """(ThinkingConfig | None, description). Never mixes thinking_level with thinking_budget."""
    mode, spec = gemini_thinking_mode(model)
    include = True if is_debug() else None  # thought summaries only for the debug log
    if model in _thinking_rejected:
        return None, "default (thinking config rejected by model)"
    if not level:
        # Model default thinking; with --debug still ask for summaries so they can be logged.
        return (types.ThinkingConfig(include_thoughts=True) if include and mode != "none" else None), "default"
    if mode == "level":
        effective = clamp_level(level.lower(), spec) or spec[-1]
        if effective != level.lower() and warn_once("gemini_level", model, level):
            emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effective, model=model)
        return types.ThinkingConfig(thinking_level=effective, include_thoughts=include), f"thinking_level={effective}"
    if mode == "budget":
        low, high, _can_disable = spec
        budget = min(max(GEMINI_THINKING_BUDGETS.get(level.lower(), 4096), low), high)
        return types.ThinkingConfig(thinking_budget=budget, include_thoughts=include), f"thinking_budget={budget}"
    if warn_once("gemini_no_thinking", model):
        emit("WARN_THINKING_NOT_SUPPORTED", model=model)
    return None, "unsupported"

    The function guarantees that thinking_level and thinking_budget are never combined in the same configuration, preventing HTTP 400 parameter rejections. If the model was previously flagged in _thinking_rejected, it returns None immediately to suppress reasoning parameters.

    _price()

    Visibility: Private

    Signature: def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:

    Description: Calculates the estimated cost of an inference call in US dollars based on published per-million-token rate cards. Evaluates prefix matches against _PRICING, applies temporary introductory pricing from _INTRO_PRICING when eligible, switches to tiered long-context pricing (>200K tokens) when applicable, and applies a 10% uplift for regional Vertex AI deployments.

    Parameters:

    • model (str): Normalized model name.
    • prompt_tokens (int): Total prompt tokens (including cached tokens).
    • cached (int): Subset of prompt tokens retrieved from context cache.
    • output_tokens (int): Generated tokens (including thought tokens).
    • today (datetime.date | None, optional): Override date for promotional price verification. Defaults to datetime.date.today().

    Returns:

    • float | None: Total cost in USD, or None if the model has no pricing entry.

    Example:

    def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:
    key = next((k for k in sorted(_PRICING, key=len, reverse=True) if model.lower().startswith(k)), None)
    if key is None:
        return None
    row = _PRICING[key]
    if key in _INTRO_PRICING and (today or datetime.date.today()) <= _INTRO_PRICING_UNTIL:
        row = _INTRO_PRICING[key]
    p_in, p_out, p_cache = row[3:6] if len(row) == 6 and prompt_tokens > _LONG_CONTEXT_THRESHOLD else row[:3]
    uncached = max(prompt_tokens - cached, 0)
    cost = (uncached * p_in + cached * p_cache + output_tokens * p_out) / 1_000_000
    if os.getenv("GEMINI_PROJECT_ID") and gemini_location().lower() != "global":
        cost *= _REGIONAL_UPLIFT
    return cost

    The function matches model names by longest prefix to prevent generic identifiers from masking specialized variants (e.g., matching "gemini-3.8-flash-cyber" before "gemini-3.8-flash"). Uncached input tokens are separated from cached tokens so that discounted cache-read rates are applied accurately.

    _record()

    Visibility: Private

    Signature: def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:

    Description: Extracts token usage metrics from the SDK's usage_metadata, records metrics in the global ledger via record_usage(), calibrates prompt tokenizer ratios via observe_prompt_tokens(), and emits structured usage logs to console and log sinks.

    Parameters:

    • model (str): Model identifier.
    • usage (types.GenerateContentResponseUsageMetadata): Usage metadata object returned by the Gemini API.
    • raw_prompt_tokens (int): Estimated prompt tokens calculated locally before the call.
    • level_desc (str): Human-readable thinking level description.
    • finish (str): Candidate finish reason.
    • elapsed (float): Execution duration in seconds.

    Example:

    def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:
    prompt = getattr(usage, "prompt_token_count", 0) or 0
    candidates = getattr(usage, "candidates_token_count", 0) or 0
    thoughts = getattr(usage, "thoughts_token_count", 0) or 0
    cached = getattr(usage, "cached_content_token_count", 0) or 0
    output = candidates + thoughts  # thinking is billed as output
    cost = _price(model, prompt, cached, output)
    record_usage("GEMINI", model, input_tokens=prompt, output_tokens=output, thinking_tokens=thoughts, cache_read=cached, cost=cost)
    ratio = prompt / raw_prompt_tokens if raw_prompt_tokens else 0.0
    from utils.token_utils import observe_prompt_tokens

    observe_prompt_tokens("GEMINI", model, raw_prompt_tokens, prompt)  # prompt_token_count includes cached tokens
    emit_raw(
        "DEBUG",
        f"GEMINI USAGE | model={model} | {level_desc} | finish={finish or 'n/a'} | in={prompt:,} | out={candidates:,} | thinking={thoughts:,} | "
        f"cached={cached:,} | est_cost={'$' + format(cost, '.4f') if cost is not None else 'n/a'} | elapsed={elapsed:.1f}s | observed_token_ratio={ratio:.2f}",
        dest="BOTH",
    )

    The helper accounts for thinking tokens under total output, matching Google's billing architecture where generated thoughts are billed at candidate token rates. It lazily imports observe_prompt_tokens() to avoid circular dependencies with utils.token_utils.

    Signature: def _stream(model: str, prompt: str, config) -> dict:

    • prompt (str): Prompt string.
    • config (types.GenerateContentConfig): Fully populated generation configuration.

    Returns:

    Example:

    def _stream(model: str, prompt: str, config) -> dict:
    """Consume generate_content_stream; returns text, thoughts, finish, block_reason, usage."""
    global _sdk_retries
    text, thoughts = [], []
    finish, block_reason, usage = "", "", None
    _sdk_retries = 0  # _sdk_retry_record counts this request's retries
    for chunk in _get_client().models.generate_content_stream(model=model, contents=[prompt], config=config):
        feedback = getattr(chunk, "prompt_feedback", None)
        if feedback is not None and getattr(feedback, "block_reason", None):
            block_reason = _name(feedback.block_reason)
        if getattr(chunk, "usage_metadata", None) is not None:
            usage = chunk.usage_metadata
        for candidate in getattr(chunk, "candidates", None) or []:
            if getattr(candidate, "finish_reason", None):
                finish = _name(candidate.finish_reason)
            content = getattr(candidate, "content", None)
            for part in (getattr(content, "parts", None) or []) if content is not None else []:
                if getattr(part, "text", None):
                    (thoughts if getattr(part, "thought", False) else text).append(part.text)
            break  # candidate_count is 1
    return {"text": "".join(text), "thoughts": "".join(thoughts), "finish": finish, "block_reason": block_reason, "usage": usage}

    The generator iterates through incoming chunks, resetting _sdk_retries at the start of each request. It inspects candidate parts, routing content tagged with part.thought == True to the thoughts buffer and standard text to the output text buffer.

    Data Structures

    Stream Extraction Payload

    The dictionary returned by the internal _stream() helper contains the parsed components of the response stream.

    Field Type Description
    text str Complete aggregated completion text generated across all candidates.
    thoughts str Aggregated reasoning thoughts captured when include_thoughts is enabled.
    finish str Normalized candidate finish reason (e.g., "STOP", "MAX_TOKENS", "SAFETY").
    block_reason str Normalized prompt block reason from prompt_feedback (e.g., "PROHIBITED_CONTENT").
    usage types.GenerateContentResponseUsageMetadata \| None Google GenAI SDK token usage object, or None if the stream omitted metadata.

    Module Constants

    The module declares internal lookup tables and sets to govern pricing, retries, and finish reason categorization.

    Constant Type Description
    _RETRYABLE_FINISH_REASONS set[str] Candidate finish reasons ({"SAFETY", "RECITATION", "LANGUAGE", "OTHER"}) that may pass upon resampling.
    _BLOCK_FINISH_REASONS set[str] Union of retryable finish reasons and deterministic prompt blocks ({"PROHIBITED_CONTENT", "BLOCKLIST", ...}).
    _TRUNCATION_FINISH_REASONS set[str] Set containing finish reasons indicating output token exhaustion ({"MAX_TOKENS"}).
    _PRICING dict[str, tuple[float, ...]] Standard rates in USD per million tokens: (input, output, cached [, long_input, long_output, long_cached]).
    _INTRO_PRICING dict[str, tuple[float, float, float]] Promotional rates for Gemini 3.6-3.8 Flash through December 31, 2026.
    _INTRO_PRICING_UNTIL datetime.date Expiration date for introductory pricing (datetime.date(2026, 12, 31)).
    _REGIONAL_UPLIFT float Multiplier (1.10) applied to base pricing for Vertex AI regional deployments.
    _LONG_CONTEXT_THRESHOLD int Token threshold (200_000) triggering long-context pricing rates.
    _SDK_ATTEMPTS int Maximum internal retry attempts (2) executed by HttpRetryOptions for transient errors.
    _TENACITY_RETRY_RE re.Pattern Compiled regex parsing wait durations and exception causes from tenacity retry logs.

    Error Handling

    The module maps error states into structured exceptions and signals to maintain resilience across pipelines:

    Thinking Parameter Rejection Recovery

    Certain experimental or unmapped Gemini models reject explicit reasoning configurations with an HTTP 400 ClientError. The module catches this condition dynamically in call_gemini():

        except genai_errors.ClientError as e:
        # A model that rejects our thinking control (unknown future model, level set changed):
        # warn once and resend without it for the rest of the run.
        if getattr(e, "code", None) == 400 and thinking is not None and "think" in str(e).lower():
            _thinking_rejected.add(model)
            emit("WARN_GEMINI_THINKING_REJECTED", model=model, error=str(e)[:200])
            config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=None, automatic_function_calling=no_afc)
            result = _stream(model, prompt, config)
        else:
            raise

    When this error occurs, the model identifier is added to _thinking_rejected. The request is re-executed without ThinkingConfig, and subsequent calls for that model skip thinking configurations automatically.

    Policy Blocks vs. Sample Refusals

    Finish reasons and prompt feedback block reasons are evaluated to determine whether an error can be retried:

        if result["block_reason"] or result["finish"] in _BLOCK_FINISH_REASONS:
        category = result["block_reason"] or result["finish"]
        # A blocked prompt repeats for the same input; a stop on the candidate may pass on resampling.
        retryable = not result["block_reason"] and result["finish"] in _RETRYABLE_FINISH_REASONS
        count_event("GEMINI", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="Gemini", model=model, category=category)
        raise LLMRefusalError(model, category, provider="GEMINI", retryable=retryable)

    If block_reason is set, the prompt itself triggered an unretryable block (such as PROHIBITED_CONTENT or BLOCKLIST), setting retryable=False to halt caller retries. If the refusal occurred on the generated candidate (such as SAFETY or RECITATION), retryable is set to True, allowing caller retry loops to resample with a different seed.

    Truncation Handling

    When generation stops due to output token constraints (finish == "MAX_TOKENS"), returning raw strings would risk saving cut-off responses into persistent caches. The module intercepts this condition:

        if result["finish"] in _TRUNCATION_FINISH_REASONS:
        count_event("GEMINI", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="Gemini", max_tokens=f"{max_output:,}")
        return TruncatedResponse(result["text"])

    Wrapping the result in TruncatedResponse signals to upstream cache orchestrators (such as utils.call_llm) that the output was truncated and must not be committed to disk.
