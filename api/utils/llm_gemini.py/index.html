    llm_gemini.py

    Source: utils/llm_gemini.py

    Following the runtime configuration resolution and model capability negotiation established in llm_config.py, llm_gemini.py acts as the dedicated low-level driver for Google Gemini models. It encapsulates all communication with Google's generative AI infrastructure, handling authentication, request construction, streaming generation, thinking parameter calibration, finish reason classification, and token usage accounting.

    Technical Overview

    The llm_gemini.py module serves as the native integration driver for Google Gemini models (Gemini 3.1+ with Gemini 2.5 fallback architectures) within the repository synthesis pipeline. It directly imports the official google-genai SDK and provides a self-contained execution boundary for all Google-specific API interactions. The module isolates upstream orchestration components—such as call_llm.py—from the complexities of Google API authentication modes, deprecations across Gemini generations, and vendor-specific streaming protocols.

    Architecturally, the driver manages authentication across both Google AI Studio (API key) and Google Cloud Vertex AI (Project ID and Location). It enforces strict parameter isolation across model families. For Gemini 3.x architectures, reasoning capabilities are configured via ThinkingConfig.thinking_level, clamped to per-model supported tiers. For Gemini 2.5 models, reasoning uses an explicit integer thinking_budget. The driver ensures that these mutually exclusive fields are never submitted within the same payload, which would trigger an immediate HTTP 400 Bad Request. Furthermore, the module omits deprecated sampling parameters (such as temperature and top_p) to guarantee compatibility across Vertex AI endpoints.

    Inference execution relies entirely on generate_content_stream to prevent HTTP transport drops during extended reasoning sessions. The driver inspects the streaming chunks in real time, assembling raw completion tokens alongside internal reasoning thoughts (include_thoughts). It parses granular completion metadata, routing safety stops or content policy rejections to llm_common.py's LLMRefusalError, length limits to TruncatedResponse, and successful text completions to the caller while updating centralized financial and token telemetry ledgers.

    Public API

    get_model()

    Visibility: Public Signature: def get_model() -> str:

    Description: Resolves and returns the normalized Gemini model identifier configured for the current runtime. It inspects the GEMINI_MODEL environment variable, falling back to DEFAULT_GEMINI_MODEL (from utils.llm_config) if unset. The raw model string is stripped of leading resource path prefixes such as models/ or publishers/google/models/ via gemini_model_id to ensure compatibility with both AI Studio and Vertex AI SDK client calls.

    Parameters: None.

    Returns: * str: The sanitized model name (e.g., "gemini-3.7-flash").

    Raises: None.

    Example: 

    def get_model() -> str:
    """GEMINI_MODEL without a 'models/' or 'publishers/google/models/' resource prefix."""
    return gemini_model_id(os.getenv("GEMINI_MODEL") or DEFAULT_GEMINI_MODEL)

    The get_model function acts as the single entry point for model name normalization within the driver. Upstream dispatchers and internal helper functions use this sanitized ID to ensure cache consistency, pricing lookups, and SDK request formatting without redundant regex parsing.

    get_model_limits()

    Visibility: Public Signature: def get_model_limits(model: str) -> tuple[int, int]:

    Description: Retrieves the maximum input and output token boundaries for a given Gemini model identifier. The function implements an in-memory caching mechanism via _model_limits_cache to minimize network overhead. When querying Google AI Studio (when GEMINI_PROJECT_ID is absent), the function attempts to fetch dynamic limits via client.models.get(model=model). If Vertex AI is active, or if the API query fails, the function falls back to static defaults defined in GEMINI_DEFAULT_LIMITS (from utils.llm_config).

    Parameters: * model (str): The normalized model identifier string.

    Returns: * tuple[int, int]: A 2-element tuple representing (input_token_limit, output_token_limit).

    Raises: None (internal exceptions during lookup are trapped, logged as warnings via emit(), and resolved to default limits).

    Example: 

    def get_model_limits(model: str) -> tuple[int, int]:
    """(input_token_limit, output_token_limit). AI Studio reports them via models.get; Vertex does
    not (the SDK maps no limits there), so the static Gemini 3.x / 2.5 table applies."""
    if model in _model_limits_cache:
        return _model_limits_cache[model]
    limits = GEMINI_DEFAULT_LIMITS
    if not os.getenv("GEMINI_PROJECT_ID"):
        try:
            info = _get_client().models.get(model=model)
            limits = (getattr(info, "input_token_limit", None) or limits[0], getattr(info, "output_token_limit", None) or limits[1])
            emit_raw("DEBUG", f"Gemini models.get | model={model} | input={limits[0]:,} | output={limits[1]:,}", dest="LOG")
        except Exception as e:
            emit("WARN_GEMINI_MODEL_LOOKUP", model=model, error=str(e)[:200])
    _model_limits_cache[model] = limits
    return limits

    The implementation prevents repetitive remote lookups by memoizing results in _model_limits_cache. When running against Vertex AI endpoints, Google does not expose token ceilings via the standard models.get endpoint; the driver handles this discrepancy by bypassing the network lookup entirely and applying local static limits.

    call_gemini()

    Visibility: Public Signature: def call_gemini(prompt: str, thinking_level: str | None = None) -> str:

    Description: Dispatches a single-turn completion request to Google Gemini using streaming transport and returns the synthesized response text. It coordinates token estimation, thinking parameter selection, function calling suppression, stream processing, error recovery, operational logging, and finish reason classification.

    Because this function implements the central workflow of the module, its internal logic is broken down into four distinct execution phases:

    Phase 1: Configuration Preparation and Model Parameter Resolution

        from utils.token_utils import count_tokens_raw

    model = get_model()
    raw_tokens = count_tokens_raw(prompt)
    max_output = _max_output_tokens(model, thinking_level)
    thinking, level_desc = _thinking_config(model, thinking_level)
    # No tools are passed, so automatic function calling is off (google-genai warns on streams otherwise).
    no_afc = types.AutomaticFunctionCallingConfig(disable=True)
    config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=thinking, automatic_function_calling=no_afc)
    emit_raw(
        "DEBUG",
        f"Gemini request | model={model} | {level_desc} | max_output_tokens={max_output:,} | location={gemini_location() if os.getenv('GEMINI_PROJECT_ID') else 'ai-studio'}",
        dest="LOG",
    )

    The initial phase resolves the model ID and calculates the baseline token count of the prompt using count_tokens_raw. It determines the output token ceiling by invoking _max_output_tokens and configures the reasoning behavior using _thinking_config. Automatic function calling is explicitly disabled using types.AutomaticFunctionCallingConfig(disable=True) to prevent the SDK from emitting runtime stream warnings when no tool schemas are supplied.

    Phase 2: Stream Execution and Dynamic Thinking Fallback

        start = time.time()
    try:
        result = _stream(model, prompt, config)
    except genai_errors.ClientError as e:
        # A model that rejects our thinking control (unknown future model, level set changed):
        # warn once and resend without it for the rest of the run.
        if getattr(e, "code", None) == 400 and thinking is not None and "think" in str(e).lower():
            _thinking_rejected.add(model)
            emit("WARN_GEMINI_THINKING_REJECTED", model=model, error=str(e)[:200])
            config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=None, automatic_function_calling=no_afc)
            result = _stream(model, prompt, config)
        else:
            raise
    elapsed = time.time() - start

    Execution delegates to the private _stream helper inside a timed block. If the endpoint rejects the thinking parameter by returning an HTTP 400 ClientError containing the string "think", the driver catches the exception, registers the model into _thinking_rejected to bypass thinking parameters on future calls, emits a warning, strips thinking_config, and immediately retries the request.

    Phase 3: Telemetry Recording and Thought Logging

        if result["usage"] is not None:
        _record(model, result["usage"], raw_tokens, level_desc, result["finish"], elapsed)
    else:
        record_usage("GEMINI", model, cost=None)
    if is_debug() and result["thoughts"]:
        emit_raw("DEBUG", f"THINKING SUMMARY:\n{result['thoughts']}", dest="LOG")

    Once the stream completes, telemetry is written to the global usage ledger via _record(). If the response omitted usage metadata, record_usage() is called with cost=None to mark cost tracking as unverified. When CLI debugging is enabled via is_debug(), extracted reasoning traces (result["thoughts"]) are written to the persistent log file.

    Phase 4: Block and Truncation Post-Processing

        if result["block_reason"] or result["finish"] in _BLOCK_FINISH_REASONS:
        category = result["block_reason"] or result["finish"]
        # A blocked prompt repeats for the same input; a stop on the candidate may pass on resampling.
        retryable = not result["block_reason"] and result["finish"] in _RETRYABLE_FINISH_REASONS
        count_event("GEMINI", "refusals")
        emit("WARN_LLM_BLOCKED_RETRYABLE" if retryable else "WARN_LLM_REFUSAL", provider="Gemini", model=model, category=category)
        raise LLMRefusalError(model, category, provider="GEMINI", retryable=retryable)
    if result["finish"] in _TRUNCATION_FINISH_REASONS:
        count_event("GEMINI", "truncations")
        emit("WARN_LLM_TRUNCATED", provider="Gemini", max_tokens=f"{max_output:,}")
        return TruncatedResponse(result["text"])
    if not result["text"]:
        emit_raw("WARNING", f"Gemini response contained no text (finish_reason={result['finish'] or 'n/a'})", dest="LOG")
    return result["text"]

    The final phase inspects candidate finish states and prompt feedback blocks. If the request was halted by safety mechanisms, terms-of-service violations, or content blocks (_BLOCK_FINISH_REASONS), it increments the refusal counter, logs a warning, and raises LLMRefusalError. It differentiates between permanent prompt refusals (retryable=False) and transient candidate stops (retryable=True). If the generation was halted due to context or budget exhaustion (MAX_TOKENS), it logs the truncation and returns a TruncatedResponse instance. Otherwise, it returns the generated text.

    Parameters: * prompt (str): The full text prompt to be completed by the model. * thinking_level (str | None, optional): The requested reasoning intensity ("low", "medium", "high", etc.), or None to adopt the model default.

    Returns: * str: The generated completion text, or an instance of TruncatedResponse (which subclasses str) if generation exceeded output token limits.

    Raises: * LLMRefusalError: If the prompt or generated response was blocked by safety filters, recitation checks, or policy restrictions. * google.genai.errors.ClientError: For unhandled 4xx client errors that are not related to thinking parameter rejection. * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Example: 

    # Real usage pattern from utils/call_llm.py delegating to call_gemini
from utils.llm_gemini import call_gemini

response_text = call_gemini(
    prompt="Generate an architecture summary for the authentication subsystem.",
    thinking_level="high",
)

    Internal Helpers

    _timeout_ms()

    Visibility: Private Signature: def _timeout_ms() -> int:

    Description: Parses the GEMINI_TIMEOUT_SECONDS environment variable to compute the global request timeout in milliseconds for the google-genai SDK. Because the SDK applies this deadline to the entire streamed response rather than individual socket read intervals, the timeout must accommodate extended reasoning cycles. The value is clamped to a minimum of 30.0 seconds (30,000 ms), defaulting to 1,800.0 seconds (1,800,000 ms or 30 minutes).

    Parameters: None.

    Returns: * int: Total per-request deadline in milliseconds.

    Raises: None.

    Example: 

    def _timeout_ms() -> int:
    """Total per-request deadline (the SDK applies it to the whole streamed response)."""
    try:
        seconds = float(os.getenv("GEMINI_TIMEOUT_SECONDS", "1800"))
    except ValueError:
        seconds = 1800.0
    return int(max(seconds, 30.0) * 1000)

    The function incorporates defensive parsing of the environment variable. If an invalid or non-numeric string is configured, the ValueError exception handler reverts the value to the 1,800-second baseline. Clamping with max(seconds, 30.0) guarantees that aggressive user configurations do not drop connections during standard network handshakes.

    _get_client()

    Visibility: Private Signature: def _get_client():

    Description: Initializes and returns the process-wide google.genai.Client singleton. The client is configured with HTTP deadline options derived from _timeout_ms() and automated retry parameters (HttpRetryOptions) for status codes 408, 429, 500, 502, 503, and 504. The helper evaluates the execution environment to configure either Vertex AI (via GEMINI_PROJECT_ID and gemini_location()) or Google AI Studio (via GEMINI_API_KEY). When using AI Studio, vertexai=False is passed explicitly to prevent ambient environment variables such as GOOGLE_GENAI_USE_VERTEXAI from rerouting requests.

    Parameters: None.

    Returns: * genai.Client: The configured Google GenAI client instance.

    Raises: * ValueError: If neither GEMINI_PROJECT_ID nor GEMINI_API_KEY is present in the environment.

    Example: 

    def _get_client():
    global _client
    if _client is None:
        http_options = types.HttpOptions(
            timeout=_timeout_ms(),  # milliseconds; with no timeout a stalled connection hangs forever
            # One SDK retry for transient errors; PocketFlow node retries (5 x 20 s) sit on top.
            retry_options=types.HttpRetryOptions(attempts=2, http_status_codes=[408, 429, 500, 502, 503, 504]),
        )
        if os.getenv("GEMINI_PROJECT_ID"):
            _client = genai.Client(vertexai=True, project=os.getenv("GEMINI_PROJECT_ID"), location=gemini_location(), http_options=http_options)
        elif os.getenv("GEMINI_API_KEY"):
            # vertexai=False explicitly: GOOGLE_GENAI_USE_VERTEXAI=true in the environment would otherwise
            # route the API key to Vertex AI.
            _client = genai.Client(vertexai=False, api_key=os.getenv("GEMINI_API_KEY"), http_options=http_options)
        else:
            raise ValueError("Either GEMINI_PROJECT_ID or GEMINI_API_KEY must be set in the environment")
    return _client

    This helper manages client lifecycle state through the global _client reference. The SDK's built-in HTTP retry policy is constrained to two attempts, operating underneath the higher-level workflow retry loops in the pipeline's execution graph.

    _thinking_config()

    Visibility: Private Signature: def _thinking_config(model: str, level: str | None) -> tuple[types.ThinkingConfig | None, str]:

    Description: Constructs the vendor-specific reasoning configuration object (types.ThinkingConfig) based on the target model's supported mode ("level" vs "budget"). If the model previously rejected thinking parameters (tracked in _thinking_rejected), the function bypasses configuration and returns None. For Gemini 3.x models (mode == "level"), it clamps the requested level to the model's supported enumeration via clamp_level, warning the user via warn_once if clamping occurs. For Gemini 2.5 models (mode == "budget"), it clamps the budget to the allowed integer range. The two modes are never mixed.

    Parameters: * model (str): Normalized Gemini model name. * level (str | None): Desired reasoning intensity level.

    Returns: * tuple[types.ThinkingConfig | None, str]: A tuple containing the initialized SDK thinking configuration (or None) and a human-readable telemetry description string.

    Raises: None.

    Example: 

    def _thinking_config(model: str, level: str | None):
    """(ThinkingConfig | None, description). Never mixes thinking_level with thinking_budget."""
    mode, spec = gemini_thinking_mode(model)
    include = True if is_debug() else None  # thought summaries only for the debug log
    if model in _thinking_rejected:
        return None, "default (thinking config rejected by model)"
    if not level:
        # Model default thinking; with --debug still ask for summaries so they can be logged.
        return (types.ThinkingConfig(include_thoughts=True) if include and mode != "none" else None), "default"
    if mode == "level":
        effective = clamp_level(level.lower(), spec) or spec[-1]
        if effective != level.lower() and warn_once("gemini_level", model, level):
            emit("WARN_THINKING_LEVEL_CLAMPED", level=level, effective=effective, model=model)
        return types.ThinkingConfig(thinking_level=effective, include_thoughts=include), f"thinking_level={effective}"
    if mode == "budget":
        low, high, _can_disable = spec
        budget = min(max(GEMINI_THINKING_BUDGETS.get(level.lower(), 4096), low), high)
        return types.ThinkingConfig(thinking_budget=budget, include_thoughts=include), f"thinking_budget={budget}"
    if warn_once("gemini_no_thinking", model):
        emit("WARN_THINKING_NOT_SUPPORTED", model=model)
    return None, "unsupported"

    The function coordinates with utils.llm_config.gemini_thinking_mode to determine whether the target model supports categorical thinking levels or integer token budgets. The include_thoughts flag is enabled only when debug logging is active (is_debug()), avoiding transport overhead and log bloat during standard execution.

    _max_output_tokens()

    Visibility: Private Signature: def _max_output_tokens(model: str, level: str | None) -> int:

    Description: Resolves the maximum generation limit for output tokens based on the active model and reasoning intensity. It retrieves the model's static or queried token limit using get_model_limits(), and delegates budget calculation to gemini_output_budget from utils.llm_config. Because Google Gemini maintains separate input and output token quotas, the output budget is not dynamically reduced for large prompts.

    Parameters: * model (str): Normalized model name. * level (str | None): Desired thinking level string.

    Returns: * int: The maximum allowed output tokens for the completion request.

    Raises: None.

    Example: 

    def _max_output_tokens(model: str, level: str | None) -> int:
    """Per-level budget capped by the model's output limit. Gemini documents separate input and
    output limits, so output is not reduced for large prompts (input_token_budget still reserves it)."""
    _input_limit, output_limit = get_model_limits(model)
    return gemini_output_budget(level, output_limit)

    This helper ensures that downstream requests do not exceed the architectural limits of the model while allocating sufficient headroom for internal reasoning steps, which share the max_output_tokens allocation on Gemini 3.x and 2.5 architectures.

    _name()

    Visibility: Private Signature: def _name(value) -> str:

    Description: Normalizes enum members, status objects, or dynamic error types into a standardized uppercase string. In the google-genai SDK, unexpected or newly introduced finish reasons may arrive as raw strings or dynamically generated enum instances. This helper safely extracts the .name attribute if present, splits by dot notation, and transforms the resulting identifier to uppercase.

    Parameters: * value (Any): An enum instance, string, or arbitrary object representing a finish or block reason.

    Returns: * str: Standardized uppercase string identifier.

    Raises: None.

    Example: 

    def _name(value) -> str:
    """Enum → 'NAME' (unknown enum members arrive as dynamic values; compare by name)."""
    return (getattr(value, "name", None) or str(value or "")).split(".")[-1].upper()

    By decoupling finish reason evaluation from static SDK enum classes, _name prevents AttributeError exceptions when newer API releases introduce unmapped finish conditions.

    _price()

    Visibility: Private Signature: def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:

    Description: Calculates the estimated financial cost (in USD) for an inference request based on token consumption, prompt caching, long-context thresholds, promotional pricing calendars, and deployment locations. It performs a longest-prefix match against the _PRICING table. If the model qualifies for introductory rates (_INTRO_PRICING) and the current date is before _INTRO_PRICING_UNTIL (December 31, 2026), discounted rates are applied. If the input exceeds _LONG_CONTEXT_THRESHOLD (200,000 tokens) and the model defines dual-tier pricing, Tier-2 rates are evaluated. Finally, a 10% regional uplift (_REGIONAL_UPLIFT = 1.10) is applied if the request was routed through Vertex AI outside the global region.

    Parameters: * model (str): Target model name. * prompt_tokens (int): Total input prompt tokens. * cached (int): Tokens read from explicit or implicit prompt context caches. * output_tokens (int): Total output tokens (including reasoning tokens). * today (datetime.date | None, optional): Explicit date override used for testing pricing cutoffs. Defaults to datetime.date.today().

    Returns: * float | None: Estimated cost in USD, or None if the model pricing is unmapped.

    Raises: None.

    Example: 

    def _price(model: str, prompt_tokens: int, cached: int, output_tokens: int, today: datetime.date | None = None) -> float | None:
    key = next((k for k in sorted(_PRICING, key=len, reverse=True) if model.lower().startswith(k)), None)
    if key is None:
        return None
    row = _PRICING[key]
    if key in _INTRO_PRICING and (today or datetime.date.today()) <= _INTRO_PRICING_UNTIL:
        row = _INTRO_PRICING[key]
    p_in, p_out, p_cache = row[3:6] if len(row) == 6 and prompt_tokens > _LONG_CONTEXT_THRESHOLD else row[:3]
    uncached = max(prompt_tokens - cached, 0)
    cost = (uncached * p_in + cached * p_cache + output_tokens * p_out) / 1_000_000
    if os.getenv("GEMINI_PROJECT_ID") and gemini_location().lower() != "global":
        cost *= _REGIONAL_UPLIFT
    return cost

    The algorithm splits input tokens into cached and uncached portions, applying differential rates to each. If a model identifier does not match any prefix in _PRICING, the function safely returns None, signaling downstream telemetry engines that costs could not be computed.

    _record()

    Visibility: Private Signature: def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:

    Description: Extracts token metrics from the SDK's usage_metadata object, invokes _price() to estimate request expense, and writes operational metrics into the centralized session ledger using record_usage(). It calculates the observed tokenization ratio between Gemini's native tokenizer and the pipeline's offline estimator (raw_prompt_tokens), outputting detailed diagnostics to the debug log.

    Parameters: * model (str): The model identifier. * usage (types.GenerateContentResponseUsageMetadata): The usage container returned in the final stream chunk. * raw_prompt_tokens (int): The offline baseline token count computed prior to transmission. * level_desc (str): Telemetry description of the applied thinking configuration. * finish (str): Resolved finish reason identifier. * elapsed (float): Request duration in seconds.

    Returns: None.

    Raises: None.

    Example: 

    def _record(model: str, usage, raw_prompt_tokens: int, level_desc: str, finish: str, elapsed: float) -> None:
    prompt = getattr(usage, "prompt_token_count", 0) or 0
    candidates = getattr(usage, "candidates_token_count", 0) or 0
    thoughts = getattr(usage, "thoughts_token_count", 0) or 0
    cached = getattr(usage, "cached_content_token_count", 0) or 0
    output = candidates + thoughts  # thinking is billed as output
    cost = _price(model, prompt, cached, output)
    record_usage("GEMINI", model, input_tokens=prompt, output_tokens=output, thinking_tokens=thoughts, cache_read=cached, cost=cost)
    ratio = prompt / raw_prompt_tokens if raw_prompt_tokens else 0.0
    emit_raw(
        "DEBUG",
        f"GEMINI USAGE | model={model} | {level_desc} | finish={finish or 'n/a'} | in={prompt:,} | out={candidates:,} | thinking={thoughts:,} | "
        f"cached={cached:,} | est_cost={'$' + format(cost, '.4f') if cost is not None else 'n/a'} | elapsed={elapsed:.1f}s | observed_token_ratio={ratio:.2f}",
        dest="LOG",
    )

    The function handles reasoning tokens by consolidating candidate tokens and thought tokens into total output volume, matching Google's billing architecture. The ratio of actual prompt tokens to raw offline estimates is tracked to assist in calibrating tokenizer multiplier settings.

    _stream()

    Visibility: Private Signature: def _stream(model: str, prompt: str, config: types.GenerateContentConfig) -> dict:

    Description: Consumes the generator returned by client.models.generate_content_stream. It iterates through streaming response chunks, accumulating text content, separating internal thoughts from candidate output, capturing prompt blocks, monitoring finish reasons, and saving the final usage metadata.

    Parameters: * model (str): Target model identifier. * prompt (str): Raw prompt text. * config (types.GenerateContentConfig): Fully populated generation configuration schema.

    Returns: * dict: An aggregation dictionary containing: * "text" (str): Concatenated output text. * "thoughts" (str): Concatenated thinking traces. * "finish" (str): Uppercase finish reason. * "block_reason" (str): Uppercase prompt block reason. * "usage" (types.GenerateContentResponseUsageMetadata | None): Token usage metadata.

    Raises: * google.genai.errors.ClientError: If network or authentication errors occur during stream consumption.

    Example: 

    def _stream(model: str, prompt: str, config) -> dict:
    """Consume generate_content_stream; returns text, thoughts, finish, block_reason, usage."""
    text, thoughts = [], []
    finish, block_reason, usage = "", "", None
    for chunk in _get_client().models.generate_content_stream(model=model, contents=[prompt], config=config):
        feedback = getattr(chunk, "prompt_feedback", None)
        if feedback is not None and getattr(feedback, "block_reason", None):
            block_reason = _name(feedback.block_reason)
        if getattr(chunk, "usage_metadata", None) is not None:
            usage = chunk.usage_metadata
        for candidate in getattr(chunk, "candidates", None) or []:
            if getattr(candidate, "finish_reason", None):
                finish = _name(candidate.finish_reason)
            content = getattr(candidate, "content", None)
            for part in (getattr(content, "parts", None) or []) if content is not None else []:
                if getattr(part, "text", None):
                    (thoughts if getattr(part, "thought", False) else text).append(part.text)
            break  # candidate_count is 1
    return {"text": "".join(text), "thoughts": "".join(thoughts), "finish": finish, "block_reason": block_reason, "usage": usage}

    The streaming loop evaluates candidate parts individually, appending content to thoughts if part.thought evaluates to True, and to text otherwise. It restricts candidate parsing to the first candidate (candidate_count is 1), matching the single-turn design of the pipeline.

    Error Handling

    Thinking Parameter Rejection Recovery

    Certain experimental or future Gemini models may reject structured reasoning configurations via HTTP 400 Client Errors. The module catches these errors dynamically during stream execution:

        except genai_errors.ClientError as e:
        # A model that rejects our thinking control (unknown future model, level set changed):
        # warn once and resend without it for the rest of the run.
        if getattr(e, "code", None) == 400 and thinking is not None and "think" in str(e).lower():
            _thinking_rejected.add(model)
            emit("WARN_GEMINI_THINKING_REJECTED", model=model, error=str(e)[:200])
            config = types.GenerateContentConfig(max_output_tokens=max_output, thinking_config=None, automatic_function_calling=no_afc)
            result = _stream(model, prompt, config)
        else:
            raise

    When an HTTP 400 error occurs and the error payload contains the substring "think", the model is permanently added to the _thinking_rejected set. The current request is immediately re-executed with thinking_config=None, ensuring the pipeline continues without failing the active workflow step.

    Safety Refusals and Policy Blocks

    The driver standardizes vendor-specific safety classifications into LLMRefusalError (defined in utils.llm_common). It categorizes finish states into two distinct groups:

    1. Deterministic Refusals (retryable=False): Blocks triggered on the prompt itself (via block_reason) or finish reasons matching explicit policy violations:
    2. PROHIBITED_CONTENT, BLOCKLIST, SPII

    3. IMAGE_SAFETY, IMAGE_PROHIBITED_CONTENT, IMAGE_RECITATION, IMAGE_OTHER These errors indicate content that Google's filters will deterministically decline for the same input. They are not retried.

    4. Retryable Refusals (retryable=True): Blocks occurring on candidate generation where alternate sampling trajectories might succeed:

    5. SAFETY, RECITATION, LANGUAGE, OTHER These errors are flagged with retryable=True, allowing upstream execution graphs to attempt re-generation with altered sampling conditions.

    Response Truncation

    When generation terminates due to output budget limits, the SDK emits a finish_reason of MAX_TOKENS. The driver records the event using count_event("GEMINI", "truncations") and wraps the accumulated text in a TruncatedResponse instance. Upstream caching layers (in call_llm.py) identify this type and bypass disk caching to ensure partial outputs are not permanently stored.
