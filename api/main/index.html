    main

    Source: main.py

    The main.py module serves as the primary command-line interface (CLI) entry point and runtime orchestrator for the Codebase-Knowledge-Builder framework. It is responsible for parsing command-line flags, initializing environment configurations, defining baseline file inclusion/exclusion glob patterns, constructing the execution context dictionary (shared), configuring per-run structured logging, dynamically determining model context boundaries, and triggering the underlying processing pipeline constructed in flow.

    Architecture & Execution Lifecycle

    When invoked from the command line, main.py bootstraps the generation pipeline through distinct validation, setup, execution, and cleanup phases.

    Module-Level Functions

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description:
    Configures the command-line argument parser, validates input parameters, prepares execution context state, detects LLM provider configuration, instantiates the processing pipeline flow, executes it synchronously, and handles optional post-execution artifact teardown.

    Under the hood, main() performs the following sequential actions: 1. Argument Parsing: Uses argparse.ArgumentParser to define and parse inputs, enforcing mutual exclusivity between --repo and --dir. 2. Flag Harmonization & Validation: - Resolves documentation generation modes (--advanced backwards-compatibility alias vs. --mode). - Validates that --incremental mode is only active when --mode api-reference is set, automatically disabling it with a terminal warning if mismatched. - Handles cache invalidation for --force-rebuild by computing the cache manifest path (.doc_cache_manifest.json) and deleting it if found. 3. State Initialization (shared): Assembles the core mutable state dictionary that flows between all nodes in the pipeline (see flow and nodes). 4. LLM Provider Detection & Logging Setup: Inspects environment variables (LLM_PROVIDER, GEMINI_PROJECT_ID, GEMINI_API_KEY) to determine model endpoints, queries the dynamic token limit via get_model_context_length from utils.call_llm, and initializes per-run logging via configure_logging. 5. Flow Execution: Invokes create_tutorial_flow() from flow and triggers tutorial_flow.run(shared). 6. Teardown: If --cleanup was specified, purges llm_cache.json and the runtime log directory.

    Parameters:
    None (Reads directly from sys.argv and system environment variables).

    Returns:
    * None

    Raises:
    * SystemExit: Raised by argparse.ArgumentParser on parameter syntax errors, missing mandatory arguments, or when --help is invoked. * Exception: Propagates pipeline errors originating during flow execution in nodes or LLM calls in utils.call_llm.

    Implementation Details & Excerpts

    1. Argument Parsing & Mode Resolution
        parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Create mutually exclusive group for source
    source_group = parser.add_mutually_exclusive_group(required=True)
    source_group.add_argument("--repo", help="URL of the public GitHub repository.")
    source_group.add_argument("--dir", help="Path to local directory.")

    parser.add_argument("-n", "--name", help="Project name (optional, derived from repo/directory if omitted).")
    parser.add_argument("-t", "--token", help="GitHub personal access token (optional, reads from GITHUB_TOKEN env var if not provided).")
    parser.add_argument("-o", "--output", default="output", help="Base directory for output (default: ./output).")
    parser.add_argument("-i", "--include", nargs="+", help="Files to include (e.g., '*.py' '*.js'). Defaults to '*' (all files).")
    parser.add_argument(
        "-e",
        "--exclude",
        nargs="+",
        help="Files to exclude. Custom patterns are automatically merged with a massive global exclusion list (build caches, node_modules, binaries, media, AI environments) AND your repository's native .gitignore rules.",
    )
    parser.add_argument("-s", "--max-size", type=int, default=200000, help="Maximum file size in bytes (default: 200000, about 200KB).")
    parser.add_argument("--language", default="english", help="Language for the generated tutorial (default: english)")
    parser.add_argument("--no-cache", action="store_true", help="Disable LLM response caching (default: caching enabled)")
    parser.add_argument("--cleanup", action="store_true", help="Clean up logs and cache JSON at the end of the script (default: No)")
    parser.add_argument("--max-abstractions", type=int, default=10, help="Maximum number of abstractions to identify (default: 10)")
    parser.add_argument(

        help="Thinking effort level for native Gemini, OpenRouter, and Ollama reasoning models (e.g., low, medium, high). Leave empty to use model defaults.",
    )
    parser.add_argument(
        "--max-tokens", type=int, default=None, help="Maximum number of tokens for the context window (default: fetched dynamically)."

    # --- Documentation Mode & Generation Styles ---
    parser.add_argument(
        "--mode",

        default="tutorial",
        help="Documentation style (tutorial, advanced, api-reference, sdk). (default: tutorial)",
    )
    parser.add_argument("--advanced", action="store_true", help="Legacy flag: equivalent to --mode advanced")
    parser.add_argument("--mkdocs", action="store_true", help="Format output for MkDocs Material (adds YAML frontmatter & nav snippet)")
    parser.add_argument(
        "--incremental", action="store_true", help="Enable MD5 incremental caching to skip unchanged modules (Only supported in --mode api-reference)"
    )
    parser.add_argument(
        "--force-rebuild", action="store_true", help="Clear incremental cache and regenerate all chapters from scratch (use with --incremental)"
    )

    parser.add_argument("--batch", type=int, default=50, help="Maximum files per batch when using map-reduce mode (default: 50)")
    parser.add_argument("--force-batch", action="store_true", help="Force map-reduce mode regardless of context size")
    parser.add_argument("--debug", action="store_true", help="Enable verbose debug output")

    args = parser.parse_args()

    The argument parser establishes strict exclusivity between remote GitHub repositories (--repo) and local directory analysis (--dir). It configures documentation generation styling (tutorial, advanced, api-reference, sdk), MkDocs integration compatibility flags, batching parameters for large codebases exceeding single-prompt context limits, reasoning effort indicators (--thinking-level), and MD5 incremental caching parameters.

    2. Incremental Constraint Enforcement & Force Rebuild
        # Resolve mode (backward compatibility for --advanced)
    doc_mode = "advanced" if args.advanced else args.mode

    # Enforce incremental cache constraints
    if args.incremental and doc_mode != "api-reference":
        print(
            "\n\033[93m[Warning] --incremental caching is only effective in 'api-reference' mode due to stable 1:1 file mapping. Disabling incremental cache for this run.\033[0m\n"
        )
        args.incremental = False

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        project_name = args.name
        if not project_name:
            # Derive project name the same way FetchRepo does
            if args.dir:
                project_name = os.path.basename(os.path.abspath(args.dir))
            elif args.repo:
                project_name = args.repo.rstrip("/").split("/")[-1]
        if project_name:
            output_base = args.output or "output"
            manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
            if os.path.exists(manifest_path):
                os.remove(manifest_path)
                print(f"\033[93m[Force Rebuild] Deleted cache manifest: {manifest_path}\033[0m")
            else:
                print(f"\033[93m[Force Rebuild] No cache manifest found at {manifest_path} — all chapters will be generated fresh.\033[0m")
    elif args.force_rebuild and not args.incremental:
        print("\033[93m[Warning] --force-rebuild has no effect without --incremental. Ignoring.\033[0m")

    Because incremental MD5 generation relies on a 1:1 mapping between source files and output Markdown documentation (a feature unique to api-reference mode), main() guards against invalid configurations by disabling incremental caching if requested under holistic modes like tutorial or advanced. When --force-rebuild is supplied alongside --incremental, the manifest .doc_cache_manifest.json located within the target output directory is detected and unlinked, guaranteeing that stale hashes are discarded.

    3. Shared Context Assembly
        # Prepare shared store to be passed between nodes
    shared = {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Add include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Add language for multi-language support
        "language": args.language,
        # Add use_cache flag (inverse of no-cache flag)
        "use_cache": not args.no_cache,
        # Add max_abstraction_num parameter
        "max_abstraction_num": args.max_abstractions,
        # Add thinking_level for LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Add max tokens override
        "max_tokens": args.max_tokens,
        # Added mode, mkdocs, and incremental
        "mode": doc_mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": doc_mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs will be populated by the nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    The shared dictionary is initialized as the centralized blackboard state for the PocketFlow engine. It captures input flags, normalizes include/exclude pattern sets (combining user exclusions with DEFAULT_EXCLUDE_PATTERNS), and pre-allocates intermediate data slots (files, abstractions, relationships, chapter_order, chapters) that pipeline nodes populate downstream.

    4. Provider Resolution, Logging, & Execution
        # Get LLM configuration for display
    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    from utils.call_llm import configure_logging, get_model_context_length

    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)

    # Derive project name for logging (before flow runs, which may override shared["project_name"])
    if args.name:
        log_project_name = args.name
    elif args.dir:
        log_project_name = os.path.basename(os.path.normpath(args.dir))
    elif args.repo:
        log_project_name = args.repo.rstrip("/").split("/")[-1]
    else:
        log_project_name = "project"

    # Configure per-run logging: logs/{project}_{mode}_{datetime}.log
    log_file = configure_logging(project_name=log_project_name, mode=doc_mode)

    # ... Display configuration print blocks ...

    # Create the flow instance
    tutorial_flow = create_tutorial_flow()

    # Run the flow
    tutorial_flow.run(shared)

    The resolution block checks environment variables to determine which provider backend is configured (such as OpenAI-compatible endpoints or Google Gemini). It then queries get_model_context_length from utils.call_llm to dynamically compute model window capacities for chunking decisions. Logging is initialized via configure_logging to write to a timestamped file under the configured log directory. Finally, create_tutorial_flow is called to instantiate the workflow, followed by tutorial_flow.run(shared) to synchronously execute the node graph.

    5. Post-Run Cleanup Logic
        # Cleanup logs and cache if requested
    if args.cleanup:
        print("\nCleaning up cache and logs...")
        cache_path = "llm_cache.json"
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                print(f" - Removed {cache_path}")
            except Exception as e:
                print(f" - Failed to remove {cache_path}: {e}")

        log_dir = os.environ.get("LOG_DIR", "logs")
        if os.path.exists(log_dir) and os.path.isdir(log_dir):
            import shutil

            try:
                shutil.rmtree(log_dir)
                print(f" - Removed {log_dir} directory")
            except Exception as e:
                print(f" - Failed to remove {log_dir}: {e}")

    If the --cleanup flag is passed, this block executes after pipeline completion. It attempts to remove local ephemeral files created during LLM invocations (llm_cache.json) and recursively deletes the run log directory (defaulting to logs/ or the path specified by LOG_DIR), catching and reporting any filesystem I/O exceptions without crashing the main process.

    Execution Entrypoint

    The file concludes with the standard Python execution guard:

    if __name__ == "__main__":
    main()

    When main.py is executed directly from a shell (e.g., python main.py --dir . --mode api-reference), main() is invoked to parse arguments and run the application.
