    main

    Original File Path: main.py

    Overview

    The main.py script serves as the primary command-line interface (CLI) and execution entry point for the Codebase-Knowledge-Builder system. It coordinates configuration ingestion, environment bootstrapping, validation of execution flags, shared pipeline state initialization, and execution of the underlying workflow graph created via flow.

    At a high level, main.py handles: 1. Environment Setup & Flag Parsing: Ingests .env configuration using dotenv and parses CLI flags via argparse, supporting input sources (GitHub repository URL or local directory path), filtering patterns, target natural languages, LLM provider settings, batch sizes, and documentation generation modes (tutorial, advanced, api-reference, sdk). 2. Exclusion Pattern Aggregation: Merges custom user exclusion rules with a default blacklist covering media, binaries, package locks, build artifacts, IDE configs, virtual environments, and AI agent artifacts. 3. Cache & Incremental State Validation: Enforces compatibility constraints (e.g., restricting --incremental caching strictly to --mode api-reference) and invalidates cache manifests when --force-rebuild is triggered. 4. Shared State Store Construction: Initializes the shared dictionary that serves as the central context container passed across nodes in the flow engine. 5. Runtime Telemetry & Logging Setup: Detects configured LLM providers (OPENROUTER, GEMINI, etc.), resolves model context lengths dynamically via utils.call_llm, configures per-run logging, displays runtime configuration diagnostics, and executes the pipeline flow. 6. Teardown & Cleanup: Optionally purges llm_cache.json and runtime log directories upon execution completion if --cleanup is asserted.

    Module-Level Constants

    DEFAULT_INCLUDE_PATTERNS

    • Type: set[str]
    • Value: {"*"}
    • Description: The default wildcard matching rule applied when no specific --include patterns are passed via the command line. Matches all discovered files in the target repository or directory.

    DEFAULT_EXCLUDE_PATTERNS

    • Type: set[str]
    • Description: A comprehensive blacklist of glob patterns ignored during codebase crawling. It prevents unnecessary token consumption, context pollution, and LLM processing bottlenecks by filtering out 7 distinct categories of files:
    • Media, Data, and Static Assets: Images (*.jpg, *.png, *.svg), audio/video (*.mp4, *.wav), documents (*.pdf, *.docx, *.xlsx), archives (*.zip, *.tar.gz), and asset directories (assets/*, data/*, public/*, static/*, temp/*).
    • Build, Distribution, and Framework Caches: Compiled outputs and framework artifacts (dist/*, build/*, target/*, bin/*, .next/*, .nuxt/*, .svelte-kit/*, docs/*, test/*, tests/*, examples/*, *.log, *.tmp).
    • Environments, Dependencies & Lockfiles: Package directories (node_modules/*, vendor/*, venv/*, .venv/*), environment variables (.env*), and package manager lockfiles (package-lock.json, yarn.lock, pnpm-lock.yaml, Cargo.lock, Gemfile.lock, poetry.lock, Pipfile.lock).
    • Language-Specific Exclusions: Python byte code and caches (__pycache__/*, *.pyc, .pytest_cache/*, htmlcov/*), Java class files (.gradle/*, *.class, *.jar), compiled native objects (*.o, *.obj, *.dll, *.so, *.dylib), and mobile pods/gradle caches (ios/Pods/*, android/.gradle/*).
    • OS & Version Control: Git and VCS metadata (.git/*, .github/*, .svn/*, .hg/*) and OS desktop files (.DS_Store, Thumbs.db).
    • Classic IDEs: IDE configuration directories (.vscode/*, .idea/*, *.iml, .eclipse/*, .vs/*).
    • AI Agents & Modern AI IDEs: Metadata generated by AI development environments (.cursor/*, .cursorrules, .windsurf/*, .cline/*, .roo/*, .agent/*, .continue/*, .gemini/*, .claude/*, .copilot/*).

    Module-Level Functions

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description: The primary runtime function of main.py. It reads CLI parameters, configures environment bindings, establishes shared state variables, validates configuration combinations, prints diagnostic information, executes the workflow graph using flow.create_tutorial_flow, and handles post-run artifact cleanup.

    Parameters: None (reads directly from sys.argv via argparse.ArgumentParser).

    Returns: * None

    Raises: * SystemExit: Raised implicitly by argparse.ArgumentParser if mutually exclusive arguments are missing, invalid combinations are passed, or --help is invoked. * Exception: Propagates any unhandled runtime exceptions emitted during flow execution in tutorial_flow.run(shared) or file removal operations during cleanup.

    def main():
    parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Create mutually exclusive group for source
    source_group = parser.add_mutually_exclusive_group(required=True)
    source_group.add_argument("--repo", help="URL of the public GitHub repository.")
    source_group.add_argument("--dir", help="Path to local directory.")

    parser.add_argument("-n", "--name", help="Project name (optional, derived from repo/directory if omitted).")
    parser.add_argument("-t", "--token", help="GitHub personal access token (optional, reads from GITHUB_TOKEN env var if not provided).")
    parser.add_argument("-o", "--output", default="output", help="Base directory for output (default: ./output).")
    parser.add_argument("-i", "--include", nargs="+", help="Files to include (e.g., '*.py' '*.js'). Defaults to '*' (all files).")
    parser.add_argument("-e", "--exclude", nargs="+", help="Files to exclude. Custom patterns are automatically merged with a massive global exclusion list (build caches, node_modules, binaries, media, AI environments) AND your repository's native .gitignore rules.")
    parser.add_argument("-s", "--max-size", type=int, default=200000, help="Maximum file size in bytes (default: 200000, about 200KB).")
    # Add language parameter for multi-language support
    parser.add_argument("--language", default="english", help="Language for the generated tutorial (default: english)")
    # Add use_cache parameter to control LLM caching
    parser.add_argument("--no-cache", action="store_true", help="Disable LLM response caching (default: caching enabled)")
    # Add cleanup parameter
    parser.add_argument("--cleanup", action="store_true", help="Clean up logs and cache JSON at the end of the script (default: No)")
    # Add max_abstraction_num parameter to control the number of abstractions
    parser.add_argument("--max-abstractions", type=int, default=10, help="Maximum number of abstractions to identify (default: 10)")
    # Add thinking_level parameter for LLM reasoning capabilities
    parser.add_argument("--thinking-level", default=None, help="Thinking effort level for OpenRouter models (e.g., low, medium, high). Default is auto.")
    # Add max-tokens parameter
    parser.add_argument("--max-tokens", type=int, default=None, help="Maximum number of tokens for the context window (default: fetched dynamically).")

    # --- Documentation Mode & Generation Styles ---
    parser.add_argument("--mode", choices=["tutorial", "advanced", "api-reference", "sdk"], default="tutorial", help="Documentation style (tutorial, advanced, api-reference, sdk). (default: tutorial)")
    parser.add_argument("--advanced", action="store_true", help="Legacy flag: equivalent to --mode advanced")
    parser.add_argument("--mkdocs", action="store_true", help="Format output for MkDocs Material (adds YAML frontmatter & nav snippet)")
    parser.add_argument("--incremental", action="store_true", help="Enable MD5 incremental caching to skip unchanged modules (Only supported in --mode api-reference)")
    parser.add_argument("--force-rebuild", action="store_true", help="Clear incremental cache and regenerate all chapters from scratch (use with --incremental)")

    # Add batching parameters
    parser.add_argument("--batch", type=int, default=50, help="Max files per batch in map-reduce mode")
    parser.add_argument("--force-batch", action="store_true", help="Force map-reduce mode regardless of context size")
    # Debug mode
    parser.add_argument("--debug", action="store_true", help="Enable verbose debug output")

    args = parser.parse_args()
    # ...

    The CLI parsing logic establishes mandatory input mutual exclusivity: the user must supply either a remote target (--repo) or a local filesystem path (--dir). It configures documentation generation modes and optional behaviors such as batching thresholds, maximum file size cutoffs (defaulting to 200,000 bytes / ~200 KB), token context window limits, LLM thinking level parameters, and MkDocs-compatible output formatting.

    Incremental Cache and Mode Resolution Logic

        # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get('GITHUB_TOKEN')
        if not github_token:
            print("Warning: No GitHub token provided. You might hit rate limits for public repositories.")

    # Resolve mode (backward compatibility for --advanced)
    doc_mode = "advanced" if args.advanced else args.mode

    # Enforce incremental cache constraints
    if args.incremental and doc_mode != "api-reference":
        print("\n\033[93m[Warning] --incremental caching is only effective in 'api-reference' mode due to stable 1:1 file mapping. Disabling incremental cache for this run.\033[0m\n")
        args.incremental = False

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        project_name = args.name
        if not project_name:
            # Derive project name the same way FetchRepo does
            if args.dir:
                project_name = os.path.basename(os.path.abspath(args.dir))
            elif args.repo:
                project_name = args.repo.rstrip("/").split("/")[-1]
        if project_name:
            output_base = args.output or "output"
            manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
            if os.path.exists(manifest_path):
                os.remove(manifest_path)
                print(f"\033[93m[Force Rebuild] Deleted cache manifest: {manifest_path}\033[0m")
            else:
                print(f"\033[93m[Force Rebuild] No cache manifest found at {manifest_path} — all chapters will be generated fresh.\033[0m")
    elif args.force_rebuild and not args.incremental:
        print("\033[93m[Warning] --force-rebuild has no effect without --incremental. Ignoring.\033[0m")

    This section reconciles legacy flags (such as --advanced) into unified mode descriptors and enforces operational constraints on incremental caching. Because incremental documentation generation relies on a deterministic 1:1 relationship between source files and documentation output chapters, --incremental is constrained strictly to --mode api-reference. If --force-rebuild is supplied alongside incremental caching, main() locates and deletes the project's .doc_cache_manifest.json file to ensure clean, end-to-end regeneration.

    Shared State Construction

        # Prepare shared store to be passed between nodes
    shared = {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name, # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output, # Base directory for CombineTutorial output

        # Add include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,

        # Add language for multi-language support
        "language": args.language,

        # Add use_cache flag (inverse of no-cache flag)
        "use_cache": not args.no_cache,

        # Add max_abstraction_num parameter
        "max_abstraction_num": args.max_abstractions,

        # Add thinking_level for LLM reasoning capabilities
        "thinking_level": args.thinking_level,

        # Add max tokens override
        "max_tokens": args.max_tokens,

        # Added mode, mkdocs, and incremental
        "mode": doc_mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": doc_mode == "advanced",

        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,

        # Debug mode
        "debug": args.debug,

        # Outputs will be populated by the nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None
    }

    The shared dictionary represents the shared pipeline state passed to each node executed by flow.create_tutorial_flow. Keys initialized here provide configuration parameters (e.g., include_patterns, exclude_patterns, max_file_size, batch_size, use_cache) and output slots (files, abstractions, relationships, chapter_order, chapters, final_output_dir) that downstream nodes in nodes populate incrementally.

    LLM Telemetry, Logging, and Flow Execution

        # Get LLM configuration for display
    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    from utils.call_llm import configure_logging, get_model_context_length
    context_length = args.max_tokens if args.max_tokens else get_model_context_length(endpoint_url, model_name, api_key)

    # Derive project name for logging (before flow runs, which may override shared["project_name"])
    if args.name:
        log_project_name = args.name
    elif args.dir:
        log_project_name = os.path.basename(os.path.normpath(args.dir))
    elif args.repo:
        log_project_name = args.repo.rstrip("/").split("/")[-1]
    else:
        log_project_name = "project"

    # Configure per-run logging: logs/{project}_{mode}_{datetime}.log
    log_file = configure_logging(project_name=log_project_name, mode=doc_mode)
    # ...
    # Create the flow instance
    tutorial_flow = create_tutorial_flow()

    # Run the flow
    tutorial_flow.run(shared)

    The telemetry routines identify the configured LLM backend by inspecting environment variables (e.g., LLM_PROVIDER, <PROVIDER>_MODEL, <PROVIDER>_BASE_URL, and <PROVIDER>_API_KEY, falling back to GEMINI defaults if unspecified). It derives the context window using get_model_context_length from utils.call_llm unless explicitly overridden by --max-tokens. It then initializes run-level log handlers using configure_logging, outputs a formatted diagnostics table to standard output, instantiates the execution graph via create_tutorial_flow(), and invokes .run(shared).

    Teardown and Resource Cleanup

        # Cleanup logs and cache if requested
    if args.cleanup:
        print("\nCleaning up cache and logs...")
        cache_path = "llm_cache.json"
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                print(f" - Removed {cache_path}")
            except Exception as e:
                print(f" - Failed to remove {cache_path}: {e}")

        log_dir = os.environ.get("LOG_DIR", "logs")
        if os.path.exists(log_dir) and os.path.isdir(log_dir):
            import shutil
            try:
                shutil.rmtree(log_dir)
                print(f" - Removed {log_dir} directory")
            except Exception as e:
                print(f" - Failed to remove {log_dir}: {e}")

    When --cleanup is supplied, post-execution teardown executes after tutorial_flow.run(shared) finishes. It checks for the existence of llm_cache.json and the logging directory resolved from $LOG_DIR (defaulting to ./logs), attempting file removal and directory tree deletion using os.remove and shutil.rmtree. Any file system deletion errors are captured and reported without aborting process termination.

    Example Usage

    The following snippets illustrate CLI invocation patterns parsed and executed by main():

    # 1. Generate an architectural tutorial from a local directory
python main.py --dir /path/to/my-project --mode tutorial --language english

# 2. Generate a 1:1 API Reference for a GitHub repo with incremental caching enabled
python main.py --repo https://github.com/org/repo --mode api-reference --incremental --mkdocs

# 3. Force rebuild an incremental API reference documentation suite
python main.py --dir ./my-sdk --mode api-reference --incremental --force-rebuild

# 4. Run large codebase documentation with MapReduce batching and custom reasoning depth
python main.py --dir ./large-repo --batch 30 --force-batch --thinking-level high --cleanup
