    main

    Original Source File: main.py

    Technical Overview

    The main.py module serves as the primary command-line interface (CLI) entry point for the Codebase-Knowledge-Builder engine. It orchestrates user input ingestion, parses repository metadata and processing flags, establishes global exclusion and inclusion rules, configures runtime logging, and initializes the shared execution context passed across the entire pipeline.

    The module operates as the control plane for documentation generation: 1. CLI Ingestion and Parsing: Validates mutually exclusive input sources (remote GitHub repository URLs versus local filesystem directories) and normalizes configuration options such as model context length, token limits, AI reasoning depth, batch size, and output formatting. 2. Exclusion Filtering Baseline: Defines the system-wide static blacklist DEFAULT_EXCLUDE_PATTERNS, covering media assets, build artifacts, package-manager lockfiles, virtual environments, language compilation caches, operating system metadata, and AI IDE artifacts. 3. Environment & Provider Introspection: Resolves AI provider credentials and model hyperparameters from environment variables (.env) or explicit CLI flags, dynamically computing context window capacities via utils.call_llm. 4. Pipeline Lifecycle Orchestration: Instantiates the complete node execution graph via flow.create_tutorial_flow, provisions the shared state dictionary, triggers execution, and performs post-run log and cache cleanup if requested.

    Module-Level Constants

    DEFAULT_INCLUDE_PATTERNS

    • Type: set[str]
    • Value: {"*"}
    • Description: Baseline file inclusion pattern matching all files encountered during repository crawling unless filtered out by exclusion rules.

    DEFAULT_EXCLUDE_PATTERNS

    • Type: set[str]
    • Description: Exhaustive set of glob patterns automatically ignored during repository traversal across local and remote sources. Categorized into seven distinct domains:
    • Media, Data, and Static Assets: Binary image files (.png, .jpg, .ico, .webp), audio/video files (.mp4, .mp3, .wav), document containers (.pdf, .docx, .xlsx), archives (.zip, .tar, .gz), and raw directories (assets/*, static/*, temp/*).
    • Build, Distribution, and Framework Caches: Compiled frontend/backend output directories (dist/*, build/*, out/*, .next/*, .nuxt/*, .svelte-kit/*), documentation/example directories (docs/*, test/*, tests/*, examples/*), and temporary editor swap files (*.swp, *.bak, *.log).
    • Environments, Dependencies, and Lockfiles: Virtual environments (.venv/*, env/*), environment files (.env*), third-party dependency vendor trees (node_modules/*, vendor/*, packages/*), and package lockfiles (package-lock.json, yarn.lock, pnpm-lock.yaml, Cargo.lock, poetry.lock).
    • Language-Specific Exclusions: Python byte code (__pycache__/*, *.pyc), test coverage artifacts (.pytest_cache/*, .coverage, htmlcov/*), Java/JVM artifacts (*.class, *.jar, *.war), native C/C++ compiled binaries (*.o, *.obj, *.dll, *.dylib, *.so), and mobile build trees (ios/Pods/*, android/.gradle/*).
    • OS & Version Control: VCS control directories (.git/*, .github/*, .svn/*, .hg/*) and OS-specific metadata files (.DS_Store, Thumbs.db, desktop.ini).
    • Classic IDEs: IDE workspace configuration folders (.vscode/*, .idea/*, .eclipse/*, *.iml).
    • AI Agents & Modern AI IDEs: Metadata and rule configurations from AI code assistants and agents (.cursor/*, .cursorrules, .windsurf/*, .windsurfrules, .cline/*, .clinerules, .roo/*, .agent/*, .continue/*, .gemini/*, .claude/*, .copilot/*).

    Module-Level Functions

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description:
    Parses command-line arguments, validates execution parameters, configures LLM runtime options, prepares the global state dictionary, and dispatches the execution graph through create_tutorial_flow.

    The function enforces key constraints: * Requires either --repo or --dir via a mutually exclusive argument group. * Validates incremental caching: if --incremental is supplied with a mode other than api-reference, the flag is automatically disabled because non-reference modes lack deterministic 1:1 file-to-chapter mapping. * Processes --force-rebuild when running in incremental mode by locating and removing the .doc_cache_manifest.json file before the pipeline executes. * Identifies the active LLM provider (evaluating LLM_PROVIDER, GEMINI_PROJECT_ID, or GEMINI_API_KEY) and fetches the context window limit dynamically via get_model_context_length from utils.call_llm if --max-tokens is not explicitly provided. * Constructs the shared dictionary containing runtime arguments, inclusion/exclusion rules, and placeholders for downstream pipeline nodes to populate. * Executes the flow and handles teardown of logs and cache files when --cleanup is enabled.

    Parameters:
    * None (reads from sys.argv via argparse.ArgumentParser).

    Returns:
    * None

    Raises:
    * SystemExit: Raised by argparse.ArgumentParser if required CLI arguments are missing or invalid options are passed.

    Example:

def main():
    parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Create mutually exclusive group for source
    source_group = parser.add_mutually_exclusive_group(required=True)
    source_group.add_argument("--repo", help="URL of the public GitHub repository.")
    source_group.add_argument("--dir", help="Path to local directory.")

    parser.add_argument("-n", "--name", help="Project name (optional, derived from repo/directory if omitted).")
    parser.add_argument("-t", "--token", help="GitHub personal access token (optional, reads from GITHUB_TOKEN env var if not provided).")
    parser.add_argument("-o", "--output", default="output", help="Base directory for output (default: ./output).")
    parser.add_argument("-i", "--include", nargs="+", help="Files to include (e.g., '*.py' '*.js'). Defaults to '*' (all files).")
    parser.add_argument(
        "-e",
        "--exclude",
        nargs="+",
        help="Files to exclude. Custom patterns are automatically merged with a massive global exclusion list (build caches, node_modules, binaries, media, AI environments) AND your repository's native .gitignore rules.",
    )
    parser.add_argument("-s", "--max-size", type=int, default=200000, help="Maximum file size in bytes (default: 200000, about 200KB).")
    parser.add_argument("--language", default="english", help="Language for the generated tutorial (default: english)")
    parser.add_argument("--no-cache", action="store_true", help="Disable LLM response caching (default: caching enabled)")
    parser.add_argument("--cleanup", action="store_true", help="Clean up logs and cache JSON at the end of the script (default: No)")
    parser.add_argument("--max-abstractions", type=int, default=10, help="Maximum number of abstractions to identify (default: 10)")
    parser.add_argument(
        "--thinking-level", default=None, help="Thinking effort level for OpenRouter models (e.g., low, medium, high). Default is auto."
    )
    parser.add_argument(
        "--max-tokens", type=int, default=None, help="Maximum number of tokens for the context window (default: fetched dynamically)."
    )

    # --- Documentation Mode & Generation Styles ---
    parser.add_argument(
        "--mode",
        choices=["tutorial", "advanced", "api-reference", "sdk"],
        default="tutorial",
        help="Documentation style (tutorial, advanced, api-reference, sdk). (default: tutorial)",

    parser.add_argument("--advanced", action="store_true", help="Legacy flag: equivalent to --mode advanced")
    parser.add_argument("--mkdocs", action="store_true", help="Format output for MkDocs Material (adds YAML frontmatter & nav snippet)")
    parser.add_argument(
        "--incremental", action="store_true", help="Enable MD5 incremental caching to skip unchanged modules (Only supported in --mode api-reference)"

    )

    parser.add_argument("--debug", action="store_true", help="Enable verbose debug output")

    The argument parser establishes the structural constraints of the CLI application. The mutually exclusive group guarantees that the pipeline processes either a remote repository or a local directory path per run. Default values prevent uninitialized configuration states, setting sane defaults such as a 200KB per-file cutoff (--max-size) and standard English documentation generation.

    # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get("GITHUB_TOKEN")
        if not github_token:
            print("Warning: No GitHub token provided. You might hit rate limits for public repositories.")

    # Resolve mode (backward compatibility for --advanced)
    doc_mode = "advanced" if args.advanced else args.mode

    # Enforce incremental cache constraints
    if args.incremental and doc_mode != "api-reference":
        print(
            "\n\033[93m[Warning] --incremental caching is only effective in 'api-reference' mode due to stable 1:1 file mapping. Disabling incremental cache for this run.\033[0m\n"
        )
        args.incremental = False

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        project_name = args.name
        if not project_name:
            # Derive project name the same way FetchRepo does
            if args.dir:
                project_name = os.path.basename(os.path.abspath(args.dir))
            elif args.repo:
                project_name = args.repo.rstrip("/").split("/")[-1]
        if project_name:
            output_base = args.output or "output"
            manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
            if os.path.exists(manifest_path):
                os.remove(manifest_path)
                print(f"\033[93m[Force Rebuild] Deleted cache manifest: {manifest_path}\033[0m")
            else:
                print(f"\033[93m[Force Rebuild] No cache manifest found at {manifest_path} — all chapters will be generated fresh.\033[0m")
    elif args.force_rebuild and not args.incremental:
        print("\033[93m[Warning] --force-rebuild has no effect without --incremental. Ignoring.\033[0m")

    This section reconciles input flags and verifies cache consistency. When --incremental is specified without api-reference mode, main() issues a warning and disables incremental mode to prevent corrupted partial builds. When --force-rebuild is active alongside --incremental, the function derives the target project name from either the directory name or the repository URL and deletes .doc_cache_manifest.json from the output directory.

        # Debug mode

    The shared dictionary acts as the centralized data store transferred between pipeline nodes in flow.py. User-specified exclusion patterns are merged with DEFAULT_EXCLUDE_PATTERNS using a set union, ensuring default filters are always preserved. Output collections (files, abstractions, relationships, chapter_order, chapters, final_output_dir) are initialized as empty structures ready for mutation by pipeline nodes.
