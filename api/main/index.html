    main

    Original File Path: main.py

    This page documents the CLI entry point module main.py for the Codebase-Knowledge-Builder system. This module parses command-line arguments, configures environment variables and execution flags, establishes global pattern-matching defaults, initializes LLM provider settings, validates execution parameters (including incremental cache consistency and mode overrides), and initiates pipeline execution by passing the shared state dictionary to the flow graph defined in flow.

    Architectural Role and Workflow Overview

    The main.py script serves as the CLI orchestrator. It sits outside the pipeline node execution graph and acts as the bootstrap interface:

    1. Environment Setup & Defaults: Loads environment variables using python-dotenv and defines default file matching sets (DEFAULT_INCLUDE_PATTERNS, DEFAULT_EXCLUDE_PATTERNS).
    2. CLI Argument Parsing: Extracts user inputs for source targets (--repo or --dir), documentation modes (tutorial, advanced, api-reference, sdk), token overrides, abstraction limits, output formatting (--mkdocs), and cache behaviors (--incremental, --force-rebuild, --no-cache).
    3. Validation & State Initialization: Normalizes legacy parameters (such as translating --advanced to --mode advanced), validates incremental cache constraints, resets caching manifests when --force-rebuild is supplied, sets up per-run file logging via utils.call_llm, and constructs the shared dictionary.
    4. Execution & Teardown: Creates the pipeline flow by calling create_tutorial_flow() from flow, invokes tutorial_flow.run(shared), and performs optional filesystem teardown (--cleanup) for LLM cache and log files.

    Module Constants

    DEFAULT_INCLUDE_PATTERNS

    • Type: set[str]
    • Value: {"*"}
    • Description: Default wildcard match pattern applied when no explicit inclusion flags (-i or --include) are supplied via CLI arguments.

    DEFAULT_EXCLUDE_PATTERNS

    • Type: set[str]
    • Description: Global exclusion set comprising standard file matching globs, dependency folders, artifact caches, and non-source directories that are skipped across crawling operations. It includes:

    Module-Level Functions

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description: Executes the command-line interface lifecycle for Codebase-Knowledge-Builder. It performs the following technical operations: 1. Instantiates argparse.ArgumentParser with a mutually exclusive source constraint (--repo or --dir) and CLI parameters configuring documentation style, output destination, token caps, LLM thinking parameters, batch size, and file filters. 2. Resolves documentation modes, mapping legacy --advanced boolean switches to advanced mode. 3. Enforces cache consistency by ensuring --incremental is active only when --mode is set to api-reference (where stable 1:1 file-to-chapter mapping exists). 4. Handles --force-rebuild operations by locating and deleting the existing .doc_cache_manifest.json file in the project's target output directory. 5. Assembles the shared pipeline execution state dictionary (shared) containing parsed arguments, merged exclusion pattern sets (DEFAULT_EXCLUDE_PATTERNS | args.exclude), include pattern sets, batch settings, and output receptacles. 6. Inspects environment variables (LLM_PROVIDER, GEMINI_PROJECT_ID, GEMINI_API_KEY) to identify provider metadata, and derives context limits via get_model_context_length. 7. Configures run-specific log files through configure_logging(project_name=..., mode=...). 8. Calls create_tutorial_flow() to build the pipeline graph, triggers execution with tutorial_flow.run(shared), and cleans up transient cache (llm_cache.json) or log directories if --cleanup is flagged.

    Parameters: * None (Reads arguments directly from sys.argv).

    Returns: * None

    Raises: * SystemExit: Raised by argparse when CLI arguments fail validation or --help is requested. * Exception: Any uncaught exceptions propagated during node execution inside tutorial_flow.run(shared).

    Core Implementation Logic: Argument Parsing & Validation

        parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Create mutually exclusive group for source
    source_group = parser.add_mutually_exclusive_group(required=True)
    source_group.add_argument("--repo", help="URL of the public GitHub repository.")
    source_group.add_argument("--dir", help="Path to local directory.")

    parser.add_argument("-n", "--name", help="Project name (optional, derived from repo/directory if omitted).")
    parser.add_argument("-t", "--token", help="GitHub personal access token (optional, reads from GITHUB_TOKEN env var if not provided).")
    parser.add_argument("-o", "--output", default="output", help="Base directory for output (default: ./output).")
    parser.add_argument("-i", "--include", nargs="+", help="Files to include (e.g., '*.py' '*.js'). Defaults to '*' (all files).")
    parser.add_argument("-e", "--exclude", nargs="+", help="Files to exclude. Custom patterns are automatically merged with a massive global exclusion list (build caches, node_modules, binaries, media, AI environments) AND your repository's native .gitignore rules.")
    parser.add_argument("-s", "--max-size", type=int, default=200000, help="Maximum file size in bytes (default: 200000, about 200KB).")
    # Add language parameter for multi-language support
    parser.add_argument("--language", default="english", help="Language for the generated tutorial (default: english)")
    # Add use_cache parameter to control LLM caching
    parser.add_argument("--no-cache", action="store_true", help="Disable LLM response caching (default: caching enabled)")
    # Add cleanup parameter
    parser.add_argument("--cleanup", action="store_true", help="Clean up logs and cache JSON at the end of the script (default: No)")
    # Add max_abstraction_num parameter to control the number of abstractions
    parser.add_argument("--max-abstractions", type=int, default=10, help="Maximum number of abstractions to identify (default: 10)")
    # Add thinking_level parameter for LLM reasoning capabilities
    parser.add_argument("--thinking-level", default=None, help="Thinking effort level for OpenRouter models (e.g., low, medium, high). Default is auto.")
    # Add max_tokens parameter
    parser.add_argument("--max-tokens", type=int, default=None, help="Maximum number of tokens for the context window (default: fetched dynamically).")

    # --- Documentation Mode & Generation Styles ---
    parser.add_argument("--mode", choices=["tutorial", "advanced", "api-reference", "sdk"], default="tutorial", help="Documentation style (tutorial, advanced, api-reference, sdk). (default: tutorial)")
    parser.add_argument("--advanced", action="store_true", help="Legacy flag: equivalent to --mode advanced")
    parser.add_argument("--mkdocs", action="store_true", help="Format output for MkDocs Material (adds YAML frontmatter & nav snippet)")
    parser.add_argument("--incremental", action="store_true", help="Enable MD5 incremental caching to skip unchanged modules (Only supported in --mode api-reference)")
    parser.add_argument("--force-rebuild", action="store_true", help="Clear incremental cache and regenerate all chapters from scratch (use with --incremental)")

    # Add batching parameters
    parser.add_argument("--batch", type=int, default=50, help="Max files per batch in map-reduce mode")
    parser.add_argument("--force-batch", action="store_true", help="Force map-reduce mode regardless of context size")
    # Debug mode
    parser.add_argument("--debug", action="store_true", help="Enable verbose debug output")

    args = parser.parse_args()

    The CLI configuration establishes mutually exclusive ingestion pathways for remote Git repositories (--repo) versus local filesystem paths (--dir). It registers flags controlling batch processing boundaries, inclusion/exclusion rules, context token overrides, and output generation modes. Flag parameters are parsed into an argparse.Namespace instance, establishing the input criteria required for downstream execution stages.

    Core Implementation Logic: Incremental Caching & Force Rebuild

        # Resolve mode (backward compatibility for --advanced)
    doc_mode = "advanced" if args.advanced else args.mode

    # Enforce incremental cache constraints
    if args.incremental and doc_mode != "api-reference":
        print("\n\033[93m[Warning] --incremental caching is only effective in 'api-reference' mode due to stable 1:1 file mapping. Disabling incremental cache for this run.\033[0m\n")
        args.incremental = False

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        project_name = args.name
        if not project_name:
            # Derive project name the same way FetchRepo does
            if args.dir:
                project_name = os.path.basename(os.path.abspath(args.dir))
            elif args.repo:
                project_name = args.repo.rstrip("/").split("/")[-1]
        if project_name:
            output_base = args.output or "output"
            manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
            if os.path.exists(manifest_path):
                os.remove(manifest_path)
                print(f"\033[93m[Force Rebuild] Deleted cache manifest: {manifest_path}\033[0m")
            else:
                print(f"\033[93m[Force Rebuild] No cache manifest found at {manifest_path} — all chapters will be generated fresh.\033[0m")
    elif args.force_rebuild and not args.incremental:
        print("\033[93m[Warning] --force-rebuild has no effect without --incremental. Ignoring.\033[0m")

    The incremental caching logic ensures structural integrity across documentation generations. Because non-API reference modes (e.g., tutorial, advanced) produce non-deterministic or aggregated multi-file conceptual structures, incremental caching is restricted strictly to api-reference mode. If --force-rebuild is active alongside incremental caching, the function precomputes the target project directory and deletes .doc_cache_manifest.json prior to pipeline instantiation, ensuring all module chapters are regenerated from scratch.

    Core Implementation Logic: Context Assembly & Flow Execution

        # Prepare shared store to be passed between nodes
    shared = {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name, # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output, # Base directory for CombineTutorial output

        # Add include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,

        # Add language for multi-language support
        "language": args.language,

        # Add use_cache flag (inverse of no-cache flag)
        "use_cache": not args.no_cache,

        # Add max_abstraction_num parameter
        "max_abstraction_num": args.max_abstractions,

        # Add thinking_level for LLM reasoning capabilities
        "thinking_level": args.thinking_level,

        # Add max tokens override
        "max_tokens": args.max_tokens,

        # Added mode, mkdocs, and incremental
        "mode": doc_mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": doc_mode == "advanced",

        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,

        # Debug mode
        "debug": args.debug,

        # Outputs will be populated by the nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None
    }
// ...
    # Create the flow instance
    tutorial_flow = create_tutorial_flow()

    # Run the flow
    tutorial_flow.run(shared)

    The dictionary instantiated in this block forms the mutable state container transferred between pipeline nodes (such as repository fetching, abstraction parsing, chapter generation, and documentation compilation). Default exclusion sets are combined using set union operations with any user-provided --exclude arguments. Once configured and logged, execution is handed off synchronously to tutorial_flow.run(shared) via flow.

    Core Implementation Logic: Cache & Log Teardown

        # Cleanup logs and cache if requested
    if args.cleanup:
        print("\nCleaning up cache and logs...")
        cache_path = "llm_cache.json"
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                print(f" - Removed {cache_path}")
            except Exception as e:
                print(f" - Failed to remove {cache_path}: {e}")

        log_dir = os.environ.get("LOG_DIR", "logs")
        if os.path.exists(log_dir) and os.path.isdir(log_dir):
            import shutil
            try:
                shutil.rmtree(log_dir)
                print(f" - Removed {log_dir} directory")
            except Exception as e:
                print(f" - Failed to remove {log_dir}: {e}")

    When the --cleanup flag is passed, the teardown block executes immediately following the completion of tutorial_flow.run(shared). It attempts to remove local cache artifacts (llm_cache.json) and recursively delete the active log folder (defaulting to ./logs or as defined by LOG_DIR), capturing and logging any standard I/O or filesystem permission exceptions.

    Shared Context Schema

    The shared dictionary initialized in main.py is the state repository passed across all graph nodes in nodes. The schema structure initialized by main.py is documented below:

    Field Name Type Initial Value Description
    repo_url str \| None args.repo GitHub repository URL for remote crawling.
    local_dir str \| None args.dir Target directory path for local crawling.
    project_name str \| None args.name Custom project identifier; derived if None.
    github_token str \| None args.token or env GitHub Personal Access Token for remote API calls.
    output_dir str args.output ("output") Base target directory for documentation output.
    include_patterns set[str] set(args.include) or {"*"} Set of inclusion glob patterns.
    exclude_patterns set[str] DEFAULT_EXCLUDE_PATTERNS \| set(args.exclude) Merged set of global exclusion globs.
    max_file_size int args.max_size (200000) Byte size limit for parsed source files.
    language str args.language ("english") Natural language for generated documentation.
    use_cache bool not args.no_cache Toggle for caching LLM responses locally.
    max_abstraction_num int args.max_abstractions (10) Maximum abstractions to extract in tutorial modes.
    thinking_level str \| None args.thinking_level Reasoning effort level passed to compatible LLMs.
    max_tokens int \| None args.max_tokens Token limit context window override.
    mode str doc_mode ("tutorial") Output documentation mode (tutorial, advanced, etc.).
    mkdocs bool args.mkdocs If True, formats output for MkDocs Material.
    incremental bool args.incremental Enables MD5 cache comparisons for api-reference.
    advanced_mode bool doc_mode == "advanced" Convenience flag for advanced mode pipelines.
    batch_size int args.batch (50) File count threshold for map-reduce chunking.
    force_batch bool args.force_batch Forces chunked batch processing regardless of token limits.
    debug bool args.debug Verbose debug flag.
    files list [] Populated by crawling nodes with file payloads.
    abstractions list [] Populated with discovered abstraction models.
    relationships dict {} Populated with abstraction cross-references.
    chapter_order list [] Populated with ordered chapter identifiers.
    chapters list [] Populated with generated chapter markdown contents.
    final_output_dir str \| None None Path to the final generated output directory.
