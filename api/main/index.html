    main

    main.py

    Technical Overview

    main.py is the primary entry point and command-line interface (CLI) for the Codebase-Knowledge-Builder application. It coordinates the end-to-end execution lifecycle for converting codebases (either remote GitHub repositories or local directories) into structured architectural tutorials, advanced developer guides, API references, or SDK documentation suites.

    The script performs the following core responsibilities: 1. Environment Initialization: Loads environment variables from .env files via dotenv.load_dotenv() to configure LLM API keys and service endpoints. 2. CLI Parameter Parsing & Validation: Configures and evaluates command-line arguments using argparse, enforcing mutual exclusivity between repository URLs (--repo) and local directories (--dir), while applying validation rules (such as restricting --incremental caching strictly to --mode api-reference). 3. Exclusion & Inclusion Pattern Aggregation: Merges custom user pattern filters with comprehensive built-in defaults that encompass binaries, dependencies, build caches, test suites, IDE artifacts, and AI agent configuration files. 4. Shared State Construction: Builds the central mutable shared state dictionary containing runtime settings, file filters, documentation modes, and output buffers passed across all workflow nodes. 5. LLM & Logging Diagnostics: Queries model endpoint metadata and context window limits via get_model_context_length, configures per-run logging via configure_logging, and outputs execution summaries to stdout. 6. Pipeline Dispatch & Post-Processing: Invokes create_tutorial_flow() from flow, executes the sequential processing graph with tutorial_flow.run(shared), and handles optional post-run cache or log teardown if --cleanup is specified.

    Module-Level Constants

    DEFAULT_INCLUDE_PATTERNS

    • Type: set[str]
    • Value: {"*"}
    • Description: The default glob pattern set used when the user does not specify explicit inclusion rules via -i or --include. It matches all discovered files in the target directory tree.

    DEFAULT_EXCLUDE_PATTERNS

    • Type: set[str]
    • Description: A comprehensive set of glob patterns automatically ignored during repository traversal. When custom exclude patterns are provided via -e or --exclude, they are combined with this set via set union. It prevents non-source assets, build artifacts, environments, and tool caches from polluting LLM context windows.

    The patterns are grouped internally into 7 distinct categories: 1. Media, Data, and Static Assets: Binary media files, document formats, archives, and web assets (e.g., assets/*, data/*, *.png, *.mp4, *.pdf, *.zip, *.tar). 2. Build, Distribution, and Framework Caches: Compiler and framework output directories (e.g., dist/*, build/*, target/*, .next/*, .nuxt/*, *.log, *.tmp). 3. Environments, Dependencies & Lockfiles: Package managers, virtual environments, and lockfiles (e.g., venv/*, .venv/*, node_modules/*, vendor/*, package-lock.json, Cargo.lock, poetry.lock). 4. Language-Specific Exclusions: Bytecode, compiled binaries, and test coverage outputs across Python, Java/JVM, and C/C++ (e.g., __pycache__/*, *.pyc, *.class, *.jar, *.o, *.so, *.dylib, ios/Pods/*, android/.gradle/*). 5. OS & Version Control: System metadata and VCS internals (e.g., .git/*, .github/*, .DS_Store, Thumbs.db). 6. Classic IDEs: Workspace settings for development environments (e.g., .vscode/*, .idea/*, *.iml, .vs/*). 7. AI Agents & Modern AI IDEs: Context files, rulesets, and scratchpads generated by coding assistants (e.g., .cursor/*, .cursorrules, .windsurf/*, .cline/*, .roo/*, .agent/*, .continue/*, .claude/*, .copilot/*).

    Module-Level Functions

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description:
    Serves as the master CLI execution function. It configures the argparse.ArgumentParser instance with all operational flags, validates arguments, resolves project metadata, constructs the shared state dictionary, configures diagnostic logging, executes the pipeline flow graph, and executes optional teardown operations.

    Parameters:
    * None (reads from sys.argv and system environment variables).

    Returns:
    * None

    Raises:
    * SystemExit: Raised by argparse upon missing required arguments (--repo or --dir), invalid command syntax, or when invoked with --help. * Exception: Any uncaught exceptions propagated during node execution inside tutorial_flow.run(shared).

    Core Implementation Breakdown

    1. CLI Parsing & Mutually Exclusive Source Selection

    def main():
    parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Create mutually exclusive group for source
    source_group = parser.add_mutually_exclusive_group(required=True)
    source_group.add_argument("--repo", help="URL of the public GitHub repository.")
    source_group.add_argument("--dir", help="Path to local directory.")

    parser.add_argument("-n", "--name", help="Project name (optional, derived from repo/directory if omitted).")
    parser.add_argument("-t", "--token", help="GitHub personal access token (optional, reads from GITHUB_TOKEN env var if not provided).")
    parser.add_argument("-o", "--output", default="output", help="Base directory for output (default: ./output).")
    parser.add_argument("-i", "--include", nargs="+", help="Files to include (e.g., '*.py' '*.js'). Defaults to '*' (all files).")
    parser.add_argument(
        "-e",
        "--exclude",
        nargs="+",
        help="Files to exclude. Custom patterns are automatically merged with a massive global exclusion list (build caches, node_modules, binaries, media, AI environments) AND your repository's native .gitignore rules.",
    )
    parser.add_argument("-s", "--max-size", type=int, default=200000, help="Maximum file size in bytes (default: 200000, about 200KB).")
    # ...

    The CLI entry initializes an argparse.ArgumentParser configured with a required mutually exclusive group for input target resolution: either --repo (for remote GitHub repositories) or --dir (for local file system paths). File traversal options allow setting base directories, file size ceilings in bytes (defaulting to 200,000 bytes / ~200 KB), and glob-based inclusion/exclusion lists.

    2. Pipeline Configuration, Mode Resolution & Incremental Flags

        # ...
    # Add language parameter for multi-language support
    parser.add_argument("--language", default="english", help="Language for the generated tutorial (default: english)")
    # Add use_cache parameter to control LLM caching
    parser.add_argument("--no-cache", action="store_true", help="Disable LLM response caching (default: caching enabled)")
    # Add cleanup parameter
    parser.add_argument("--cleanup", action="store_true", help="Clean up logs and cache JSON at the end of the script (default: No)")
    # Add max_abstraction_num parameter to control the number of abstractions
    parser.add_argument("--max-abstractions", type=int, default=10, help="Maximum number of abstractions to identify (default: 10)")
    # Add thinking_level parameter for LLM reasoning capabilities
    parser.add_argument(
        "--thinking-level", default=None, help="Thinking effort level for OpenRouter models (e.g., low, medium, high). Default is auto."
    )
    # Add max_tokens parameter
    parser.add_argument(
        "--max-tokens", type=int, default=None, help="Maximum number of tokens for the context window (default: fetched dynamically)."
    )

    # --- Documentation Mode & Generation Styles ---
    parser.add_argument(
        "--mode",
        choices=["tutorial", "advanced", "api-reference", "sdk"],
        default="tutorial",
        help="Documentation style (tutorial, advanced, api-reference, sdk). (default: tutorial)",
    )
    parser.add_argument("--advanced", action="store_true", help="Legacy flag: equivalent to --mode advanced")
    parser.add_argument("--mkdocs", action="store_true", help="Format output for MkDocs Material (adds YAML frontmatter & nav snippet)")
    parser.add_argument(
        "--incremental", action="store_true", help="Enable MD5 incremental caching to skip unchanged modules (Only supported in --mode api-reference)"
    )
    parser.add_argument(
        "--force-rebuild", action="store_true", help="Clear incremental cache and regenerate all chapters from scratch (use with --incremental)"
    )

    # Add batching parameters
    parser.add_argument("--batch", type=int, default=50, help="Max files per batch in map-reduce mode")
    parser.add_argument("--force-batch", action="store_true", help="Force map-reduce mode regardless of context size")
    # Debug mode
    parser.add_argument("--debug", action="store_true", help="Enable verbose debug output")

    args = parser.parse_args()
    # ...

    The argument parser establishes flags governing documentation style and processing behavior. Documentation modes include tutorial, advanced, api-reference, and sdk, supported by a legacy compatibility alias --advanced. Flags like --mkdocs alter document output structures for static documentation site generators. Granular parameters govern batch size for map-reduce flows, context token limits, LLM reasoning effort levels, cache invalidation, and incremental rebuild toggling.

    3. Validation, Auth Discovery, and Cache Manifest Management

        # ...
    # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get("GITHUB_TOKEN")
        if not github_token:
            print("Warning: No GitHub token provided. You might hit rate limits for public repositories.")

    # Resolve mode (backward compatibility for --advanced)
    doc_mode = "advanced" if args.advanced else args.mode

    # Enforce incremental cache constraints
    if args.incremental and doc_mode != "api-reference":
        print(
            "\n\033[93m[Warning] --incremental caching is only effective in 'api-reference' mode due to stable 1:1 file mapping. Disabling incremental cache for this run.\033[0m\n"
        )
        args.incremental = False

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        project_name = args.name
        if not project_name:
            # Derive project name the same way FetchRepo does
            if args.dir:
                project_name = os.path.basename(os.path.abspath(args.dir))
            elif args.repo:
                project_name = args.repo.rstrip("/").split("/")[-1]
        if project_name:
            output_base = args.output or "output"
            manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
            if os.path.exists(manifest_path):
                os.remove(manifest_path)
                print(f"\033[93m[Force Rebuild] Deleted cache manifest: {manifest_path}\033[0m")
            else:
                print(f"\033[93m[Force Rebuild] No cache manifest found at {manifest_path} — all chapters will be generated fresh.\033[0m")
    elif args.force_rebuild and not args.incremental:
        print("\033[93m[Warning] --force-rebuild has no effect without --incremental. Ignoring.\033[0m")
    # ...

    Post-parsing validation extracts GitHub personal access tokens from --token or the GITHUB_TOKEN environment variable. Mode resolution reconciles legacy --advanced flags. Incremental caching (--incremental) is strictly validated: because only api-reference mode guarantees stable 1:1 module-to-chapter file mapping, incremental generation is disabled with a warning in other modes. If --force-rebuild is supplied alongside --incremental, the runtime derives the output path and removes .doc_cache_manifest.json to invalidate cached module hashes.

    4. Shared State Store Construction

        # ...
    # Prepare shared store to be passed between nodes
    shared = {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Add include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Add language for multi-language support
        "language": args.language,
        # Add use_cache flag (inverse of no-cache flag)
        "use_cache": not args.no_cache,
        # Add max_abstraction_num parameter
        "max_abstraction_num": args.max_abstractions,
        # Add thinking_level for LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Add max tokens override
        "max_tokens": args.max_tokens,
        # Added mode, mkdocs, and incremental
        "mode": doc_mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": doc_mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs will be populated by the nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }
    # ...

    The shared dictionary acts as the blackboard state passed between pipeline nodes. It encapsulates user preferences, pattern sets, authentication secrets, batch configuration, and placeholder collections (files, abstractions, relationships, chapter_order, chapters) that nodes incrementally populate and mutate during execution.

    5. LLM Diagnostics, Logging, Execution & Post-Run Teardown

        # ...
    # Get LLM configuration for display
    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    from utils.call_llm import configure_logging, get_model_context_length

    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)

    # Derive project name for logging (before flow runs, which may override shared["project_name"])
    if args.name:
        log_project_name = args.name
    elif args.dir:
        log_project_name = os.path.basename(os.path.normpath(args.dir))
    elif args.repo:
        log_project_name = args.repo.rstrip("/").split("/")[-1]
    else:
        log_project_name = "project"

    # Configure per-run logging: logs/{project}_{mode}_{datetime}.log
    log_file = configure_logging(project_name=log_project_name, mode=doc_mode)

    # Display configuration
    print(f"Starting tutorial generation for: {args.repo or args.dir} in {args.language.capitalize()} language")
    print("--- Configuration ---")
    print(f"AI Provider    : {provider}")
    print(f"AI Endpoint    : {endpoint_url}")
    print(f"AI Model       : {model_name}")
    print(f"Context Length : {context_length:,} tokens")
    print(f"Thinking Level : {args.thinking_level or 'None'}")
    print(f"Batch Size     : {args.batch} files/batch")
    print(f"Force Batch    : {'Enabled' if args.force_batch else 'Disabled'}")
    print(f"Output Mode    : {doc_mode}")
    print(f"MkDocs Output  : {'Enabled' if args.mkdocs else 'Disabled'}")
    print(f"Incremental    : {'Enabled' if args.incremental else 'Disabled'}")
    if args.incremental:
        print(f"Force Rebuild  : {'Enabled' if args.force_rebuild else 'Disabled'}")
    if doc_mode == "api-reference":
        print("Max Abstractions: Ignored (api-reference uses 1:1 file mapping)")
    else:
        print(f"Max Abstractions: {args.max_abstractions}")
    print(f"LLM Caching    : {'Disabled' if args.no_cache else 'Enabled'}")
    if args.debug:
        print("Debug Mode     : Enabled")
    print(f"Log File       : {log_file}")
    print("---------------------")

    # Create the flow instance
    tutorial_flow = create_tutorial_flow()

    # Run the flow
    tutorial_flow.run(shared)

    # Cleanup logs and cache if requested
    if args.cleanup:
        print("\nCleaning up cache and logs...")
        cache_path = "llm_cache.json"
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                print(f" - Removed {cache_path}")
            except Exception as e:
                print(f" - Failed to remove {cache_path}: {e}")

        log_dir = os.environ.get("LOG_DIR", "logs")
        if os.path.exists(log_dir) and os.path.isdir(log_dir):
            import shutil

            try:
                shutil.rmtree(log_dir)
                print(f" - Removed {log_dir} directory")
            except Exception as e:
                print(f" - Failed to remove {log_dir}: {e}")

    The final phase resolves AI provider configuration from environment variables (checking LLM_PROVIDER or falling back to Google Gemini credentials). It queries utils.call_llm to dynamically compute context lengths via get_model_context_length and set up isolated run logging via configure_logging. After printing the execution banner, it instantiates and executes the flow pipeline created by create_tutorial_flow(). If --cleanup was passed, it removes llm_cache.json and the logs/ directory.

    Shared State Dictionary Schema

    The table below describes the keys initialized within the shared dictionary by main.py and consumed or mutated across downstream nodes:

    Key Type Initial Value Mutated By / Role
    repo_url str \| None args.repo Read by FetchRepo to clone remote Git repositories.
    local_dir str \| None args.dir Read by FetchRepo to index local directories.
    project_name str \| None args.name Derived by FetchRepo if initially None.
    github_token str \| None github_token Used by FetchRepo for authenticated GitHub API calls.
    output_dir str args.output ("output") Base target directory for documentation generation.
    include_patterns set[str] set(args.include) or {"*"} Filter for file inclusion during crawling.
    exclude_patterns set[str] Merged DEFAULT_EXCLUDE_PATTERNS Filter for ignoring paths during crawling.
    max_file_size int args.max_size (200000) Byte ceiling for scanned source files.
    language str args.language ("english") Target natural language for generated documentation.
    use_cache bool not args.no_cache Dictates if LLM queries use llm_cache.json.
    max_abstraction_num int args.max_abstractions (10) Limit on concept extraction in IdentifyAbstractions.
    thinking_level str \| None args.thinking_level Reasoning effort parameter for supported LLMs.
    max_tokens int \| None args.max_tokens Manual override for model context window limits.
    mode str doc_mode "tutorial", "advanced", "api-reference", or "sdk".
    mkdocs bool args.mkdocs Controls frontmatter and MkDocs navigation generation.
    incremental bool args.incremental Enables MD5 cache comparisons in api-reference mode.
    advanced_mode bool doc_mode == "advanced" Boolean convenience flag for advanced chapter prompt formatting.
    batch_size int args.batch (50) File count threshold per map batch.
    force_batch bool args.force_batch Forces map-reduce chunking regardless of model context length.
    debug bool args.debug Toggles verbose diagnostic logging.
    files list [] Populated by FetchRepo with discovered file metadata.
    abstractions list [] Populated by IdentifyAbstractions or api-reference mapping.
    relationships dict {} Populated by IdentifyAbstractions with component dependency graphs.
    chapter_order list [] Populated by OrderTutorial or file topological ordering.
    chapters list [] Populated by WriteChapters with generated Markdown content.
    final_output_dir str \| None None Set by CombineTutorial to the finalized output directory path.
