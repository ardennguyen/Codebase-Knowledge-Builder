    main

    File Path: main.py

    Overview

    The main module serves as the command-line interface (CLI) entry point and execution harness for Codebase-Knowledge-Builder. It orchestrates environment loading, command-line argument parsing, default file filter configuration, LLM provider context detection, runtime logging setup, and invocation of the computational graph constructed in flow.

    The script initializes the shared context data structure passed to all downstream processing nodes in the DAG, executes the pipeline via tutorial_flow.run(shared), and handles optional post-execution artifact cleanup.

    Module Constants

    DEFAULT_INCLUDE_PATTERNS

    • Type: set[str]
    • Value: {"*"}
    • Description: The default glob pattern applied to codebase scanning when no explicit --include patterns are provided via the CLI. Ensures all files are processed by default.

    DEFAULT_EXCLUDE_PATTERNS

    Module-Level Functions

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description:
    Executes the primary CLI application logic. It parses arguments, resolves target repository/directory settings, dynamically inspects environment variables for provider configuration, configures logging via utils.call_llm, builds the shared flow context dictionary, runs the workflow DAG generated by flow, and performs cleanup if requested.

    Core Implementation:

    def main():
    parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Create mutually exclusive group for source
    source_group = parser.add_mutually_exclusive_group(required=True)
    source_group.add_argument("--repo", help="URL of the public GitHub repository.")
    source_group.add_argument("--dir", help="Path to local directory.")

    # ... [Argument parsing configuration] ...

    args = parser.parse_args()

    # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get('GITHUB_TOKEN')
        if not github_token:
            print("Warning: No GitHub token provided. You might hit rate limits for public repositories.")

    # Resolve mode (backward compatibility for --advanced)
    doc_mode = "advanced" if args.advanced else args.mode

    # Enforce incremental cache constraints
    if args.incremental and doc_mode != "api-reference":
        print("\n\033[93m[Warning] --incremental caching is only effective in 'api-reference' mode due to stable 1:1 file mapping. Disabling incremental cache for this run.\033[0m\n")
        args.incremental = False

    # Prepare shared store to be passed between nodes
    shared = {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,
        "github_token": github_token,
        "output_dir": args.output,
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        "language": args.language,
        "use_cache": not args.no_cache,
        "max_abstraction_num": args.max_abstractions,
        "thinking_level": args.thinking_level,
        "max_tokens": args.max_tokens,
        "mode": doc_mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": doc_mode == "advanced",
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        "debug": args.debug,
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None
    }

    # ... [LLM config & context length resolution] ...

    # Create the flow instance
    tutorial_flow = create_tutorial_flow()

    # Run the flow
    tutorial_flow.run(shared)

    # Cleanup logs and cache if requested
    if args.cleanup:
        # ... [Cleanup implementation] ...

    CLI Arguments Reference:

    Argument Type Default Description
    --repo str None URL of the public GitHub repository (mutually exclusive with --dir).
    --dir str None Local directory path (mutually exclusive with --repo).
    -n, --name str None Project name override (derived from path/URL if omitted).
    -t, --token str None GitHub Personal Access Token (falls back to GITHUB_TOKEN environment variable).
    -o, --output str "output" Base output directory path.
    -i, --include list[str] ["*"] File patterns to include.
    -e, --exclude list[str] None File patterns to exclude (merged into DEFAULT_EXCLUDE_PATTERNS).
    -s, --max-size int 200000 Maximum file size in bytes (200 KB default).
    --language str "english" Target language for the output tutorial/documentation.
    --no-cache bool False Disables prompt/response caching for LLM invocations.
    --cleanup bool False Deletes llm_cache.json and the logs/ directory upon completion.
    --max-abstractions int 10 Maximum number of architectural abstractions to extract.
    --thinking-level str None Thinking effort for reasoning models (low, medium, high).
    --max-tokens int None Manual override for model context window length.
    --mode str "tutorial" Generation style (tutorial, advanced, api-reference, sdk).
    --advanced bool False Legacy flag equivalent to --mode advanced.
    --mkdocs bool False Formats output with YAML frontmatter and generates an mkdocs.yml navigation snippet.
    --incremental bool False Enables MD5 file hashing cache to skip unchanged files in api-reference mode.
    --batch int 50 Maximum number of files per batch in map-reduce abstraction extraction.
    --force-batch bool False Forces map-reduce execution regardless of context window availability.
    --debug bool False Enables verbose debug logs across all execution nodes.

    Detailed Execution Flow

                      +-------------------+
                  |   CLI Execution   |
                  +---------+---------+
                            |
                            v
               +----------------------------+
               | Parse Args & Load .env     |
               +-------------+--------------+
                             |
                             v
               +----------------------------+
               | Mode / Flag Sanitization   |
               | (e.g. check incremental)   |
               +-------------+--------------+
                             |
                             v
               +----------------------------+
               | Initialize Shared Context  |
               +-------------+--------------+
                             |
                             v
               +----------------------------+
               | Provider & Context Length  |
               | Discovery via call_llm     |
               +-------------+--------------+
                             |
                             v
               +----------------------------+
               | Configure Logging          |
               +-------------+--------------+
                             |
                             v
               +----------------------------+
               | create_tutorial_flow()     |
               +-------------+--------------+
                             |
                             v
               +----------------------------+
               | flow.run(shared)           |
               +-------------+--------------+
                             |
                             v
               +----------------------------+
               | Cleanup Logs/Cache if set  |
               +----------------------------+
    1. Environment Initialization: Invokes dotenv.load_dotenv() to import environment configurations from .env.
    2. CLI Parsing & Validation:
    3. Validates that either --repo or --dir is provided.
    4. Normalizes legacy --advanced to doc_mode = "advanced".
    5. Validates --incremental usage: if mode != "api-reference", issues a warning and disables the flag.
    6. Shared Context Population: Builds the dictionary containing execution parameters, custom/default include-exclude patterns, batch thresholds, and storage keys for pipeline nodes (nodes).
    7. Provider & Context Resolution: Inspects provider environment variables (LLM_PROVIDER, GEMINI_PROJECT_ID, GEMINI_API_KEY) and queries get_model_context_length from utils.call_llm to determine token limits.
    8. Logging Initialization: Calls configure_logging(project_name=log_project_name, mode=doc_mode) from utils.call_llm to set up per-run log files in logs/{project}_{mode}_{datetime}.log.
    9. Flow Pipeline Execution: Calls create_tutorial_flow() from flow and triggers execution via tutorial_flow.run(shared).
    10. Post-Run Cleanup: If --cleanup is specified, deletes llm_cache.json and purges the LOG_DIR directory via shutil.rmtree.
