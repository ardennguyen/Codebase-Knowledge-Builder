    main

    File Path: main.py

    Overview

    The main module serves as the primary command-line interface (CLI) entry point for the Codebase-Knowledge-Builder tool. It parses user arguments, configures runtime environment variables, initializes glob-matching filters, establishes LLM endpoint and context parameters, and constructs the shared memory dictionary passed to the computational workflow managed by create_tutorial_flow.

    It is responsible for: - Command-line argument parsing and flag validation. - Setting default inclusion and comprehensive exclusion glob patterns for file crawling. - Determining documentation formats (tutorial, advanced, api-reference, sdk), MkDocs Material compatibility, and incremental cache handling. - Resolving model configurations via environment variables (LLM_PROVIDER, API keys, base URLs). - Executing the pipeline and performing post-execution cleanup of caches and log files if requested.

    Constants and Module Variables

    DEFAULT_INCLUDE_PATTERNS

    • Type: set[str]
    • Value: {"*"}
    • Description: Default set of wildcard patterns specifying that all files are eligible for scanning unless excluded.

    DEFAULT_EXCLUDE_PATTERNS

    • Type: set[str]
    • Description: Comprehensive set of wildcard glob patterns excluded by default from the repository traversal. Covers:
    • Media, Data, and Static Assets (assets/*, *.png, *.pdf, *.zip, etc.)
    • Build, Distribution, and Framework Caches (dist/*, build/*, .next/*, docs/*, test/*, etc.)
    • Environments, Dependencies & Lockfiles (venv/*, node_modules/*, *.lock, etc.)
    • Language-Specific Exclusions (__pycache__/*, *.pyc, *.class, *.o, ios/Pods/*, etc.)
    • OS & Version Control (.git/*, .DS_Store, etc.)
    • Classic IDEs (.vscode/*, .idea/*, etc.)
    • AI Agents & Modern AI IDEs (.cursor/*, .windsurf/*, .cline/*, .gemini/*, etc.)

    Functions

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description:
    Parses CLI arguments using argparse.ArgumentParser, processes environment variables loaded from .env, initializes the shared context store, and invokes the flow execution engine.

    Under the hood, the function performs the following steps: 1. Argument Parsing: Defines and processes arguments including source target (--repo or --dir), project metadata (-n, --name), access tokens (-t, --token), filtering options (-i, -e, -s), LLM parameters (--language, --no-cache, --max-abstractions, --thinking-level, --max-tokens), documentation modes (--mode, --advanced, --mkdocs, --incremental), and batch/debug flags (--batch, --force-batch, --debug, --cleanup). 2. Mode & Cache Resolution: - Backward compatibility: Maps --advanced to --mode advanced. - Incremental caching constraint: Enforces that --incremental is only active when --mode is set to api-reference. Otherwise, issues a warning and disables the flag. 3. Shared Context Assembly: Builds the shared dictionary containing all runtime parameters and initializes placeholder structures (files, abstractions, relationships, chapter_order, chapters, final_output_dir). 4. Provider & Context Resolution: Inspects environment variables (LLM_PROVIDER, GEMINI_PROJECT_ID, GEMINI_API_KEY) to identify the active model and endpoint, calling get_model_context_length from utils.call_llm to calculate max context window size if not explicitly overridden. 5. Flow Execution: Calls create_tutorial_flow() to instantiate the DAG and runs it with tutorial_flow.run(shared). 6. Cleanup: If --cleanup is specified, removes llm_cache.json and deletes the directory pointed to by LOG_DIR (default: logs).

    Parameters:
    None (Reads directly from sys.argv and system environment variables).

    Returns:
    * None

    Raises:
    * SystemExit: Raised by argparse if mandatory arguments are missing or invalid arguments are passed. * Exception: Logs errors if post-run file or directory deletion fails during cleanup.

    Example: 

    # Generate API Reference documentation for a local directory
python main.py --dir ./my_project --mode api-reference --mkdocs --incremental

# Generate a standard tutorial from a GitHub repository
python main.py --repo https://github.com/octocat/Hello-World --language english --max-abstractions 5
