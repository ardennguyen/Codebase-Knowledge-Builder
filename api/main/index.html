    main

    Source File: main.py

    Technical and architectural reference documentation for the entrypoint module main.py in Codebase-Knowledge-Builder.

    Overview

    The main.py module serves as the command-line interface (CLI) entry point and execution orchestrator for the Codebase-Knowledge-Builder documentation pipeline. It coordinates repository ingestion, configuration normalization, environment variable parsing, runtime state creation, and the invocation of the primary execution graph created by flow.

    Core Responsibilities

    1. CLI Parsing & Parameter Normalization: Parses command-line flags and arguments across ingestion targets (--repo, --dir), documentation styles (--mode), processing thresholds (--max-size, --max-tokens, --batch), and target languages (--language).
    2. Environment & Provider Detection: Reads .env configuration via dotenv, detects configured Large Language Model (LLM) providers (such as Gemini or OpenRouter configurations), and queries dynamic context lengths using helper utilities from utils.call_llm.
    3. Cache Manifest Management: Implements cache invalidation rules for incremental builds (--incremental, --force-rebuild) within API reference generation mode.
    4. Shared State Construction: Constructs the centralized runtime dictionary (shared) passed across every node in the execution graph.
    5. Execution Lifecycle Management: Dispatches execution to the compiled Flow graph and runs post-execution filesystem cleanup (e.g., pruning local cache files or temporary run logs) if requested.

    Module-Level Functions

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description:
    Initializes CLI argument definitions, enforces mutually exclusive constraints between local directories and remote GitHub URLs, validates configuration flags, populates the execution dictionary shared, configures runtime logging, dispatches execution to create_tutorial_flow().run(shared), and executes post-run file pruning if cleanup is requested.

    Parameters:
    None (parses arguments directly from sys.argv).

    Returns:
    * None

    Raises:
    * SystemExit: Raised by argparse.ArgumentParser upon parameter validation failures, missing required mutually exclusive source groups, or when invoking --help. * Exception: Propagates pipeline errors from tutorial_flow.run(shared) during code extraction, abstraction identification, LLM query generation, or file writing.

    CLI Argument Schema: | Argument | Type | Default | Description | | :--- | :--- | :--- | :--- | | --repo | str | None | URL of the public GitHub repository. Mutually exclusive with --dir. | | --dir | str | None | Path to a local directory. Mutually exclusive with --repo. | | -n, --name | str | None | Project name. If omitted, derived from --dir or --repo. | | -t, --token | str | None | GitHub Personal Access Token (defaults to GITHUB_TOKEN environment variable). | | -o, --output | str | "output" | Root output directory path. | | -i, --include | list[str] | None | Glob inclusion patterns (defaults to {"*"}). | | -e, --exclude | list[str] | None | Glob exclusion patterns merged with DEFAULT_EXCLUDE_PATTERNS. | | -s, --max-size | int | 200000 | Maximum file size in bytes (approx. 200 KB). | | --language | str | "english" | Target language for the generated documentation. | | --no-cache | bool | False | Disables disk caching for LLM responses. | | --cleanup | bool | False | Deletes llm_cache.json and the logs directory upon completion. | | --max-abstractions | int | 10 | Abstraction limit for tutorial and advanced modes. | | --thinking-level | str | None | Thinking/reasoning level for supported reasoning models. | | --max-tokens | int | None | Hard override for model context window limits. | | --mode | str | "tutorial" | Documentation generation mode (tutorial, advanced, api-reference, sdk). | | --advanced | bool | False | Legacy boolean flag equivalent to --mode advanced. | | --mkdocs | bool | False | Emits MkDocs Material YAML frontmatter and navigation snippets. | | --incremental | bool | False | Enables MD5 hash-based incremental caching (API-reference mode only). | | --force-rebuild | bool | False | Removes .doc_cache_manifest.json before execution. | | --batch | int | 50 | Maximum files per batch during map-reduce processing. | | --force-batch | bool | False | Forces map-reduce execution regardless of context window sizing. | | --debug | bool | False | Enables verbose debug output. |

    CLI Argument Parsing Implementation

        parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Create mutually exclusive group for source
    source_group = parser.add_mutually_exclusive_group(required=True)
    source_group.add_argument("--repo", help="URL of the public GitHub repository.")
    source_group.add_argument("--dir", help="Path to local directory.")

    parser.add_argument("-n", "--name", help="Project name (optional, derived from repo/directory if omitted).")
    parser.add_argument("-t", "--token", help="GitHub personal access token (optional, reads from GITHUB_TOKEN env var if not provided).")
    parser.add_argument("-o", "--output", default="output", help="Base directory for output (default: ./output).")
    parser.add_argument("-i", "--include", nargs="+", help="Files to include (e.g., '*.py' '*.js'). Defaults to '*' (all files).")
    parser.add_argument(
        "-e",
        "--exclude",
        nargs="+",
        help="Files to exclude. Custom patterns are automatically merged with a massive global exclusion list (build caches, node_modules, binaries, media, AI environments) AND your repository's native .gitignore rules.",
    )
    # ... additional arguments configured
    args = parser.parse_args()

    The method configures the argument parser using standard library argparse, enforcing that exactly one source (--repo or --dir) is provided via add_mutually_exclusive_group(required=True). Custom exclusions provided through -e/--exclude accept variable arguments (nargs="+"), which are subsequently combined via set union with DEFAULT_EXCLUDE_PATTERNS.

    Incremental Cache & Force Rebuild Handling

        # Resolve mode (backward compatibility for --advanced)
    doc_mode = "advanced" if args.advanced else args.mode

    # Enforce incremental cache constraints
    if args.incremental and doc_mode != "api-reference":
        print(
            "\n\033[93m[Warning] --incremental caching is only effective in 'api-reference' mode due to stable 1:1 file mapping. Disabling incremental cache for this run.\033[0m\n"
        )
        args.incremental = False

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        project_name = args.name
        if not project_name:
            # Derive project name the same way FetchRepo does
            if args.dir:
                project_name = os.path.basename(os.path.abspath(args.dir))
            elif args.repo:
                project_name = args.repo.rstrip("/").split("/")[-1]
        if project_name:
            output_base = args.output or "output"
            manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
            if os.path.exists(manifest_path):
                os.remove(manifest_path)
                print(f"\033[93m[Force Rebuild] Deleted cache manifest: {manifest_path}\033[0m")
            else:
                print(f"\033[93m[Force Rebuild] No cache manifest found at {manifest_path} — all chapters will be generated fresh.\033[0m")
    elif args.force_rebuild and not args.incremental:
        print("\033[93m[Warning] --force-rebuild has no effect without --incremental. Ignoring.\033[0m")

    The incremental caching subsystem relies on deterministic 1:1 file-to-chapter mappings. When --incremental is requested outside of api-reference mode, main() disables the flag and issues a console warning. When --force-rebuild is active alongside --incremental, main() derives the project name from the target path or URL, locates .doc_cache_manifest.json inside the output directory, and deletes it before flow execution starts.

    Shared Context Dictionary Initialization

        # Prepare shared store to be passed between nodes
    shared = {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Add include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Add language for multi-language support
        "language": args.language,
        # Add use_cache flag (inverse of no-cache flag)
        "use_cache": not args.no_cache,
        # Add max_abstraction_num parameter
        "max_abstraction_num": args.max_abstractions,
        # Add thinking_level for LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Add max tokens override
        "max_tokens": args.max_tokens,
        # Added mode, mkdocs, and incremental
        "mode": doc_mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": doc_mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs will be populated by the nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    The shared dictionary serves as the central data contract between pipeline nodes. It includes runtime configuration flags, resolved pattern sets, and empty placeholders (files, abstractions, relationships, chapter_order, chapters, final_output_dir) populated downstream by nodes such as FetchRepo, IdentifyAbstractions, and WriteChapters.

    Flow Dispatch & Post-Run Teardown

        # Create the flow instance
    tutorial_flow = create_tutorial_flow()

    # Run the flow
    tutorial_flow.run(shared)

    # Cleanup logs and cache if requested
    if args.cleanup:
        print("\nCleaning up cache and logs...")
        cache_path = "llm_cache.json"
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                print(f" - Removed {cache_path}")
            except Exception as e:
                print(f" - Failed to remove {cache_path}: {e}")

        log_dir = os.environ.get("LOG_DIR", "logs")
        if os.path.exists(log_dir) and os.path.isdir(log_dir):
            import shutil

            try:
                shutil.rmtree(log_dir)
                print(f" - Removed {log_dir} directory")
            except Exception as e:
                print(f" - Failed to remove {log_dir}: {e}")

    Execution is triggered by instantiating the pipeline graph via create_tutorial_flow() and passing shared into tutorial_flow.run(). If --cleanup is specified, main() attempts to delete the local llm_cache.json file and recursively removes the log directory resolved from os.environ.get("LOG_DIR", "logs").
