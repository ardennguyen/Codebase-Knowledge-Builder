    Chapter Index

    Application Setup

    Chapter Description
    main.py Serves as the primary CLI entry point that parses runtime arguments, verifies LLM credentials, and initializes the execution state. It builds the SharedStore and triggers the PocketFlow DAG within a protected telemetry lifecycle.

    Pipeline Orchestration

    Chapter Description
    nodes.py Implements the discrete computation graph nodes that execute ingestion, context window budgeting, abstraction discovery, fact extraction, and chapter drafting. Each node follows PocketFlow's three-phase prep, exec, and post lifecycle.
    flow.py Constructs the declarative execution Directed Acyclic Graph using pocketflow.Flow via create_tutorial_flow(). It wires nodes with sequential and conditional transitions across single-pass, MapReduce, and deterministic topologies.

    LLM Gateway & Providers

    Chapter Description
    call_llm.py Acts as the centralized LLM dispatch gateway routing prompts to Anthropic, Gemini, OpenRouter, or OpenAI-compatible backends via call_llm(). It implements SHA-256 content-addressable response caching, refusal short-circuiting, and token usage accounting.
    llm_config.py Centralizes configuration, credential preflight checks, and context window limits across supported model providers via resolve_llm_settings(). It acts as the single source of truth for reasoning capabilities, endpoint targets, and output token reserves.
    thinking.py Defines standardized reasoning effort levels and resolves per-node thinking plans across LLM providers via build_thinking_plan(). It normalizes profiles and maps abstract effort tiers to provider-specific parameters using clamp_level().
    token_utils.py Calculates token counts, safe input budgets, and dynamic tokenizer calibration ratios using BPE tokenization and provider feedback. It exposes count_tokens() and input_token_budget() while caching token operations in an LRU memory buffer.
    llm_common.py Provides provider-neutral accounting primitives, refusal memoization, and custom signals like TruncatedResponse and LLMRefusalError. It tracks workflow step metrics using Python's contextvars to ensure asynchronous and thread-safe usage aggregation.
    llm_anthropic.py Executes Claude model invocations using client-side streaming through call_anthropic() and manages Anthropic-specific reasoning effort parameters. It handles transient truncation recovery through ceiling escalation and models generation costs.
    llm_gemini.py Adapts Google Gemini models across AI Studio and Vertex AI backends through call_gemini(). It manages streaming communication, translates thinking configurations, calculates generation costs, and converts truncated completions into TruncatedResponse instances.
    llm_openrouter.py Dispatches completions to OpenRouter endpoints via SSE streaming in call_openrouter(). It dynamically adapts reasoning budgets, performs bounded HTTP retries for transient errors, and updates shared token ledger metrics.

    Repository Ingestion

    Chapter Description
    crawl_local_files.py Traverses local directory hierarchies using os.walk to extract source code into in-memory string buffers via crawl_local_files(). It evaluates hierarchical .gitignore rules and excludes unwanted paths to maintain parity with remote crawls.
    crawl_github_files.py Retrieves remote repository source trees using Git-over-SSH cloning or GitHub REST API traversals via crawl_github_files(). It applies size thresholds, .gitignore matching, and rate-limit backoffs to yield normalized file buffers.
    files.py Generates indexed directory tree representations from file collections and retrieves selective file slices by index. It provides deterministic formatting via build_directory_tree() and bounds retrieval via get_content_for_indices() for token-efficient prompts.
    exclude_patterns.py Defines the centralized glob exclusion catalog in DEFAULT_EXCLUDE_PATTERNS to filter non-essential files, compilation artifacts, and sensitive credentials. It prevents context overflow and secret leakage across remote and local file crawlers.

    Fact Verification & Publishing

    Chapter Description
    facts.py Provides an AST-independent verification engine auditing LLM-extracted code assertions against verbatim source code via SourceIndex and ModuleTable. It verifies entity citations, manifest boundaries, and cross-module dependencies to prevent hallucinations.
    prompts.py Loads Markdown prompt templates and parses model responses containing YAML, facts, and file index ranges into structured dictionaries. It employs progressive degradation and safe loading to salvage malformed or truncated LLM completions.
    mkdocs.py Compiles Markdown chapters, verified source facts, and Mermaid dependency diagrams into standalone documentation or complete MkDocs Material sites. Entry points write_mkdocs_output() and write_standalone_output() handle navigation pruning, link normalization, and stale page deletion.

    Operational Infrastructure

    Chapter Description
    output.py Manages console output, ANSI styling, and timestamped file logging through emit(), emit_raw(), and configure_logging(). It routes messages through localized string catalogs and ensures UTF-8 stream compatibility across operating systems.
    i18n.py Manages user interface localization by detecting missing translations in strings.csv and auto-generating them with LLMs via auto_translate(). It safely persists localized catalogs using UTF-8-SIG encoding.
