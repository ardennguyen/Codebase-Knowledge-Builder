    Chapter Index

    Project root

    Chapter Description
    flow.py flow.py serves as the declarative orchestration module that constructs the executable Directed Acyclic Graph (DAG) for the documentation generation pipeline using the PocketFlow framework.
    main.py main.py serves as the centralized CLI entry point, execution harness, and configuration coordinator for the Codebase-Knowledge-Builder system. It manages the full lifecycle of repository ingestion, preflight environment validation, LLM reasoning budget resolution, and workflow invocation.

    utils

    Chapter Description
    call_llm.py * call_llm.py functions as the centralized entry point and dispatch router for all Large Language Model interactions across the Codebase-Knowledge-Builder architecture.
    chapter_check.py chapter_check.py functions as a deterministic, non-LLM quality assurance gate deployed at the conclusion of the documentation generation pipeline.
    crawl_github_files.py The crawl_github_files.py module serves as the repository ingestion component of the Codebase-Knowledge-Builder pipeline. Its primary objective is to traverse remote GitHub repositories and ingest source code into an in-memory dictionary mapping file paths to UTF-8 decoded strings.
    crawl_local_files.py * crawl_local_files.py serves as the primary local filesystem ingestion component for the Codebase-Knowledge-Builder architecture, functioning as the offline counterpart to crawl_github_files.py.
    exclude_patterns.py * The chapter covers utils/exclude_patterns.py, which provides the centralized exclusion rules used during filesystem and repository crawling operations across the codebase.
    facts.py * The facts.py module implements deterministic, language-agnostic code fact verification to audit Large Language Model (LLM) assertions against repository source files during documentation generation.
    files.py utils/files.py serves as a lightweight, in-memory file organization and selective content retrieval utility within the Codebase-Knowledge-Builder pipeline.
    i18n.py utils/i18n.py serves as the automated internationalization and UI string translation subsystem for the repository. It scans the localized string registry (strings.csv), identifies missing translations for specified target languages, and coordinates batch translation requests via an LLM.
    llm_anthropic.py * llm_anthropic.py serves as the native Anthropic Claude provider adapter within the Codebase-Knowledge-Builder architecture, isolating vendor-specific SDK calls, request serialization, and streaming transport logic.
    llm_common.py utils/llm_common.py serves as the provider-neutral foundational utility module for all Large Language Model interactions across the system.
    llm_config.py llm_config.py acts as the single source of truth for Large Language Model provider resolution, endpoint routing, context-window planning, and credential preflight verification.
    llm_gemini.py This module serves as the concrete provider adapter for Google Gemini models (Gemini 3.x and 2.5), encapsulating all vendor-specific interactions through the official google-genai SDK.
    llm_openrouter.py The llm_openrouter.py module serves as the specialized OpenRouter provider adapter within the system's call_llm dispatch architecture.
    mkdocs.py The mkdocs.py module serves as the centralized static documentation generation and artifact serialization engine at the culmination of the documentation pipeline.
    output.py > This page could not be generated in this run. It will be regenerated on the next run.
    prompts.py utils/prompts.py acts as the centralized prompt template loader, dynamic context builder, and fault-tolerant response deserialization engine for the codebase knowledge generation pipeline.
    thinking.py utils/thinking.py serves as the reasoning effort orchestration and budget planning engine for the codebase knowledge generation pipeline.
    token_utils.py utils/token_utils.py provides the token counting, context window headroom budgeting, prompt sizing, and dynamic token calibration infrastructure for the codebase knowledge generation pipeline.
