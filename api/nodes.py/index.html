    nodes.py

    Source: nodes.py

    Following the orchestration mechanics defined in flow.py and the runtime bootstrapping established in main.py, nodes.py implements the discrete computational units and LLM transformation stages for the Codebase-Knowledge-Builder pipeline. It houses all node definitions conforming to the pocketflow computation model (Node and BatchNode subclasses), executing operations spanning file ingestion, token capacity evaluation, structural abstraction extraction, relationship mapping, pedagogical ordering, parallel chapter drafting, and multi-format static documentation site assembly.

    Architecture Overview

    Every computational unit in nodes.py inherits from either pocketflow.Node (for sequential, single-payload execution) or pocketflow.BatchNode (for parallelized or itemized batch processing). Execution strictly adheres to a three-phase lifecycle: 1. prep(shared): Reads dependencies and parameters from the centralized shared blackboard state, resolves configurations, calculates token budgets, and formats prompt parameters or batch items. 2. exec(prep_res): Performs the core computational or generative work. For LLM nodes, this phase tracks token usage via token_utils.py, queries Large Language Models via call_llm.py, and validates/parses structured YAML responses. 3. post(shared, prep_res, exec_res): Mutates the centralized shared dictionary with validated execution artifacts, tracks progression via output.py, and emits routing action keys to drive DAG edge transitions.

    build_directory_tree()

    Visibility: Public
    Signature: def build_directory_tree(files_data: list[tuple[str, str]]) -> str:

    Description: Constructs a compact, human- and LLM-readable hierarchical directory tree string from a collection of file tuples containing paths and contents. Files are grouped by parent directory, sorted lexicographically, and tagged with their zero-based global integer index ((idx:N)). This representation provides structural context within LLM prompts across routing, abstraction mapping, and navigation synthesis stages.

    Parameters: * files_data (list[tuple[str, str]]): List of (file_path, file_content) tuples representing all crawled source files.

    Returns: * str: Formatted directory tree text where directories end with / and child files are indented with their index tags.

    Raises: * None.

    Example: 

    def build_directory_tree(files_data):
    from collections import defaultdict

    dir_files = defaultdict(list)
    for i, (path, _content) in enumerate(files_data):
        dirname = os.path.dirname(path) or "."
        basename = os.path.basename(path)
        dir_files[dirname].append(f"{basename} (idx:{i})")

    lines = []
    for dirname in sorted(dir_files.keys()):
        lines.append(f"{dirname}/")
        lines.extend(f"  {fname}" for fname in sorted(dir_files[dirname]))
    return "\n".join(lines)

    The function iterates over the input list of file tuples, extracting the directory and base filename for each entry. If a file resides at the root level, os.path.dirname(path) evaluates to an empty string, which is normalized to ".". File entries are appended to a defaultdict(list) using the format {basename} (idx:{i}). Once grouped, directory names are sorted alphabetically, their headers formatted with trailing slashes, and their corresponding child entries sorted and indented with two spaces before being joined into a newline-delimited string.

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:

This key schema aligns with the file reference format expected by downstream prompt templates, ensuring deterministic index extraction during LLM inference.

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> dict | list:

    Description: Extracts and deserializes YAML data fenced inside Markdown code blocks from raw LLM text responses. It isolates text enclosed between ```yaml and ``` boundaries and executes safe YAML parsing via yaml.safe_load().

    Parameters: * response (str): Raw text response returned by the LLM inference provider.

    Returns: * dict | list: Parsed Python data structure corresponding to the YAML schema emitted by the model.

    Raises: * ValueError: If ```yaml delimiters are missing, the fence closing is absent, or yaml.safe_load() encounters a syntax error.

    Example: 

    def parse_yaml_response(response):
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}") from e

    This parsing utility expects the model output to contain a fenced YAML block. It performs a two-stage string partition: splitting on "```yaml" to bypass preamble text, and splitting the second segment on "```" to discard trailing explanations. The extracted substring is passed to yaml.safe_load(). Any IndexError (due to missing code fences) or yaml.YAMLError is trapped and re-raised as a standardized ValueError, triggering node retry mechanics.

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> Callable[[str], int]:

    Description: Instantiates and returns a token-counting callable backed by tiktoken's cl100k_base BPE tokenizer. If initialization fails or the tokenizer cannot be loaded, it returns a heuristic fallback function calculating len(text) // 4.

    Parameters: * None.

    Returns: * Callable[[str], int]: A synchronous function accepting a string and returning its estimated token count.

    Raises: * None.

    Example: 

    def create_token_counter():
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    The function attempts to retrieve the cl100k_base BPE encoding. When successful, the returned lambda configures disallowed_special=() to treat special tokens (such as <|endoftext|>) as plain text, preventing runtime exceptions when processing source code containing model control tokens. If tiktoken is unavailable or encounters an initialization error, the fallback lambda provides an approximate calculation based on the standard English ratio of four characters per token.

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Determines the maximum context length available for LLM inference. It first checks for an explicit max_tokens value in the shared dictionary. If not specified, it inspects environment variables (LLM_PROVIDER, endpoint, model, and API keys) and delegates to get_model_context_length() from call_llm.py to discover the model's context window.

    Parameters: * shared (dict): The central runtime state dictionary.

    Returns: * int: Context window ceiling in tokens.

    Raises: * None.

    Example: 

    def resolve_max_tokens(shared):
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    The resolution logic prioritizes user CLI configuration stored in shared["max_tokens"]. When missing, it evaluates the active LLM_PROVIDER environment variable. For Google Gemini (or when unset), it targets standard Gemini defaults (gemini-3.7-flash). For other providers (e.g., OpenRouter, OpenAI, Ollama), it constructs dynamic environment lookup keys ({PROVIDER}_BASE_URL, {PROVIDER}_MODEL, {PROVIDER}_API_KEY) and queries get_model_context_length() for dynamic remote context discovery.

    Visibility: Public
    Signature: def prep(self, shared: dict) -> dict:

    Description: Reads target paths, repository URLs, credentials, and filtering rules from the shared store. If project_name is absent, it infers the project name from the Git repository URL or local directory path.

    Parameters: * shared (dict): Shared state containing repo_url, local_dir, project_name, include_patterns, exclude_patterns, max_file_size, and optional github_token.

    Returns: * dict: Parameter dictionary packaged for exec().

    Raises: * None.

    Example: 

    def prep(self, shared):
    repo_url = shared.get("repo_url")
    local_dir = shared.get("local_dir")
    project_name = shared.get("project_name")

    if not project_name:
        if repo_url:
            project_name = repo_url.split("/")[-1].replace(".git", "")
        else:
            project_name = os.path.basename(os.path.abspath(local_dir))
        shared["project_name"] = project_name

    include_patterns = shared["include_patterns"]
    exclude_patterns = shared["exclude_patterns"]
    max_file_size = shared["max_file_size"]

    return {
        "repo_url": repo_url,
        "local_dir": local_dir,
        "token": shared.get("github_token"),
        "include_patterns": include_patterns,
        "exclude_patterns": exclude_patterns,
        "max_file_size": max_file_size,
        "use_relative_paths": True,
    }

    The method inspects repo_url and local_dir to determine whether a project name was provided. If project_name is missing, it extracts the trailing slug from the Git URL (stripping .git) or takes the base folder name of the resolved absolute local directory, writing the result back to shared["project_name"]. It then packages crawler arguments into a configuration payload for execution.

    FetchRepo.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: dict) -> list[tuple[str, str]]:

    Description: Executes repository crawling. If repo_url is populated, it calls crawl_github_files(); otherwise, it executes crawl_local_files(). It converts the returned file dictionary into a sorted list of (path, content) tuples, raising an error if no matching files are discovered.

    Parameters: * prep_res (dict): Crawler configuration dictionary prepared by prep().

    Returns: * list[tuple[str, str]]: Collection of (relative_path, source_code) tuples.

    Raises: * ValueError: If crawling yields zero matching files after applying inclusion/exclusion rules.

    Example: 

    def exec(self, prep_res):
    source = prep_res["repo_url"] or prep_res["local_dir"]
    llm_logger.info(f"NODE EXEC | node=FetchRepo | action=crawl_files | source={source}")

    if prep_res["repo_url"]:
        emit("CRAWL_REPOSITORY", url=prep_res["repo_url"])
        result = crawl_github_files(
            repo_url=prep_res["repo_url"],
            token=prep_res["token"],
            include_patterns=prep_res["include_patterns"],
            exclude_patterns=prep_res["exclude_patterns"],
            max_file_size=prep_res["max_file_size"],
            use_relative_paths=prep_res["use_relative_paths"],
        )
    else:
        emit("CRAWL_DIRECTORY", path=prep_res["local_dir"])
        result = crawl_local_files(
            directory=prep_res["local_dir"],
            include_patterns=prep_res["include_patterns"],
            exclude_patterns=prep_res["exclude_patterns"],
            max_file_size=prep_res["max_file_size"],
            use_relative_paths=prep_res["use_relative_paths"],
        )

    files_list = list(result.get("files", {}).items())
    if len(files_list) == 0:
        raise ValueError("No matching files found. Check your directory and include/exclude patterns.")

    llm_logger.info(f"NODE COMPLETE | node=FetchRepo | files_found={len(files_list)}")
    return files_list

    The crawler dispatch routes between remote and local crawlers based on the presence of repo_url. Ingested file maps ({path: content}) are transformed via items() into a list of tuples. If the resulting file list is empty, a ValueError is raised to halt the pipeline before token allocation occurs.

    Class: ContextRouter

    Inheritance: pocketflow.Node $\to$ ContextRouter

    Description: The context evaluation and dynamic branching router of the pipeline. It computes prompt overhead, measures file token consumption against the active model's context window, enforces safety limits (95% of ceiling minus prompt overhead), and decides whether the repository can be processed in a single prompt ("direct"), requires MapReduce batching ("batch"), or must follow 1-to-1 file mapping ("deterministic").

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Calculates prompt overhead across templates, generates the directory tree, measures total source code tokens, calculates the effective token limit, and resolves the routing path.

    Parameters: * shared (dict): Central state store.

    Returns: * tuple: Routing descriptor tuple passed to exec(). Returns 8-element tuples containing the selected route string ("deterministic", "direct", or "batch"), file data, effective limits, batch sizing, token maps, token counting callable, directory tree, and debug flags.

    Raises: * None.

    Example: 

    def prep(self, shared):
    files_data = shared["files"]
    max_tokens = resolve_max_tokens(shared)
    shared["max_tokens"] = max_tokens
    count_tokens = create_token_counter()

    # Calculate worst-case prompt overhead
    prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
    max_template_tokens = 0
    for subdir in ["tutorial", "advanced", "api-reference", "sdk"]:
        for template_name in ["map_abstractions.md", "identify_abstractions.md", "draft_chapters.md"]:
            template_path = os.path.join(prompt_dir, subdir, template_name)
            if os.path.exists(template_path):
                with open(template_path, encoding="utf-8-sig") as f:
                    max_template_tokens = max(max_template_tokens, count_tokens(f.read()))

    directory_tree = build_directory_tree(files_data)
    tree_tokens = count_tokens(directory_tree)
    chapter_listing_estimate = "\n".join(f"{i + 1}. {os.path.basename(path)} (doc: {path}.md)" for i, (path, _) in enumerate(files_data))
    listing_tokens = count_tokens(chapter_listing_estimate)

    prompt_overhead = max_template_tokens + tree_tokens + listing_tokens
    # ... Token measurement & effective limit logic ...
    safety_limit = int(max_tokens * 0.95)
    effective_limit = safety_limit - prompt_overhead
    # ... Route resolution ...

    prep() calculates worst-case prompt overhead across all mode directories (tutorial, advanced, api-reference, sdk) and key templates. It adds token counts for the directory tree and estimated chapter listing, establishing a safety_limit at 95% of max_tokens. The effective_limit is computed by subtracting prompt overhead from safety_limit. If mode == "api-reference", it routes immediately to "deterministic". Otherwise, it compares total_tokens against effective_limit and evaluates force_batch to choose between "direct" and "batch".

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]:

    Description: Executes routing logic. For "direct" or "deterministic" paths, it returns the route identifier string. For "batch", it groups files by directory, packs them into token-bounded batches that never cross directory boundaries without exceeding effective_limit or batch_size, and returns the batch structure.

    Parameters: * prep_res (tuple): 8-element routing tuple from prep().

    Returns: * str | list[list[tuple[int, str, str]]]: Either "direct", "deterministic", or a list of batches containing (index, path, content) tuples.

    Raises: * None.

    Example: 

    def exec(self, prep_res):
    route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
    llm_logger.info(
        f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}"
    )

    if route == "direct":
        return "direct"
    if route == "deterministic":
        return "deterministic"

    dir_groups = defaultdict(list)
    for i, (path, content) in enumerate(files_data):
        dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

    batches = []
    for dirname in sorted(dir_groups.keys()):
        current_batch = []
        current_tokens = 0
        for i, path, content, tokens in dir_groups[dirname]:
            if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                batches.append(current_batch)
                current_batch = []
                current_tokens = 0
            current_batch.append((i, path, content))
            current_tokens += tokens
        if current_batch:
            batches.append(current_batch)

    self._directory_tree = directory_tree
    return batches

    When batching is required, files are partitioned into dir_groups by directory to preserve lexical locality. The function iterates through sorted directories, accumulating files into current_batch until adding another file would exceed either effective_limit in tokens or batch_size in item count. It flushes remaining files per directory and stores _directory_tree on the node instance for downstream post-processing.

    ContextRouter.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: str | list) -> str:

    Description: Stores batch lists in shared["file_batches"] and caches shared["directory_tree"]. Emits the action string ("direct", "deterministic", or "batch") to direct conditional edge execution in the pocketflow DAG.

    Parameters: * shared (dict): Central state store. * prep_res (tuple): Tuple from prep(). * exec_res (str | list): Execution result from exec().

    Returns: * str: Dynamic action string ("direct", "deterministic", or "batch").

    Raises: * None.

    Example: 

    def post(self, shared, prep_res, exec_res):
    if exec_res == "direct":
        return "direct"
    if exec_res == "deterministic":
        return "deterministic"
    shared["file_batches"] = exec_res

    The method matches the return value from exec(). For branching actions "direct" and "deterministic", it returns them immediately to trigger the corresponding DAG edges configured in flow.py. For batch routing, it writes exec_res to shared["file_batches"], ensures shared["directory_tree"] is saved, and returns "batch".

    Class: DeterministicFileMapper

    DeterministicFileMapper.prep()

                included_indices.add(idx)

            for idx, path, file_content, tokens in remaining_files:

                    included_files.append((idx, path, None, 0))
                    continue

                    included_files.append((idx, path, file_content, tokens))
                    total_unused -= tokens
                    included_indices.add(idx)
                else:
                    still_remaining.append((idx, path, file_content, tokens))
            abstr_results[i] = (included_files, still_remaining, 0)
