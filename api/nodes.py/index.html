    nodes.py

    Source: nodes.py

    Following the orchestration harness established in main.py and graph structures configured in flow.py, nodes.py defines the core functional processing units of the Codebase-Knowledge-Builder documentation pipeline. It implements concrete subclasses of PocketFlow's Node and BatchNode abstractions to handle filesystem crawling, LLM prompt generation, contextual token-budgeted routing, hierarchical abstraction identification, relationship extraction, chapter authoring, and final static site artifact generation.

    The module manages mutable state across a shared dictionary (shared), coordinating interactions with external LLMs via utils/call_llm.py, token accounting through utils/token_utils.py, prompt templating via utils/prompts.py, and localized CLI event broadcasting via utils/output.py.

    Pipeline Architecture & Class Hierarchy

    The execution pipeline transitions raw repository files into structured documentation chapters through two distinct graph pathways (direct analysis vs. map-reduce batching) or a deterministic mapping pathway for API references.

    Module-Level Functions

    build_directory_tree()

    Visibility: Public
    Signature: def build_directory_tree(files_data: list[tuple[str, str]]) -> str:

    Description: Constructs a compact, human-readable directory tree representation from a collection of (path, content) file tuples. Files are grouped by directory, indexed by their integer position in the original dataset, and formatted with indented basename listings.

    Parameters: * files_data (list[tuple[str, str]]): List of tuples where index 0 is the file path string and index 1 is the file content string.

    Returns: * str: Hierarchically formatted directory tree string.

    Raises: * None.

    Example: 

    def build_directory_tree(files_data):
    from collections import defaultdict

    dir_files = defaultdict(list)
    for i, (path, _content) in enumerate(files_data):
        dirname = os.path.dirname(path) or "."
        basename = os.path.basename(path)
        dir_files[dirname].append(f"{basename} (idx:{i})")

    lines = []
    for dirname in sorted(dir_files.keys()):
        lines.append(f"{dirname}/")
        lines.extend(f"  {fname}" for fname in sorted(dir_files[dirname]))
    return "\n".join(lines)

    build_directory_tree indexes each file by its enumeration sequence to allow LLM prompts to reference code modules by integer indices rather than lengthy paths. It processes path strings through os.path.dirname and os.path.basename, aggregating files into an in-memory dictionary grouped by directory. Directories and their respective file basenames are sorted lexicographically to ensure deterministic LLM prompt construction across platforms.

    Parameters: * files_data (list[tuple[str, str]]): Ordered list of (path, content) tuples representing repository files. * indices (list[int]): Target integer indices to extract.

    def get_content_for_indices(files_data, indices):
    content_map = {}

It performs defensive boundary checks (0 <= i < len(files_data)) to prevent IndexError exceptions when handling LLM-generated index lists. Keys are constructed using the format f"{i} # {path}" to preserve positional and structural context within downstream prompt interpolations.

    Description: Parses and loads structured YAML content enclosed within markdown ```yaml code fences from an LLM response string.

    Parameters: * response (str): Raw LLM response text containing fenced YAML data.

    Returns: * dict | list: Parsed Python data structure (dictionary or list).

    Example: 

    def parse_yaml_response(response):
    try:

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> collections.abc.Callable[[str], int]:

    Description: Factory function returning a token counting callable. It attempts to load OpenAI's cl100k_base encoding via tiktoken and falls back to a character-based heuristic (len(text) // 4) on failure.

    Parameters: * None.

    Returns: * Callable[[str], int]: A function accepting text and returning estimated token counts.

    Raises: * None.

    Example: 

    def create_token_counter():
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    create_token_counter provides resilient token estimation across execution environments. When tiktoken is installed and encoding dictionaries are accessible, it executes exact tokenization with disallowed_special=() to allow special tokens without raising errors. If network or binary dependencies fail, it gracefully degrades to a 4-character-per-token approximation.

    Visibility: Public

    Description: Resolves the maximum allowable token budget from the pipeline's shared state or dynamically inspects provider environment variables to query the model context length.

    Parameters: * shared (dict): Pipeline blackboard state dictionary.

    def resolve_max_tokens(shared):
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")

    DeterministicFileMapper.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple[str, bool, str | None, int]) -> list[int]:

    Description: Calls the LLM to filter non-code files and parses the returned YAML list of valid integer file indices.

    Parameters: * prep_res (tuple): Prepared execution parameters (prompt, use_cache, thinking_level, max_tokens).

    Returns: * list[int]: Parsed list of valid integer file indices.

    Raises: * Exception: Captures, emits diagnostics, logs stack traces, and re-raises any LLM or parsing errors.

    Example: 

        def exec(self, prep_res):
        try:
            prompt, use_cache, thinking_level, max_tokens = prep_res
            emit("LLM_CALL_FILTER_FILES")
            log_token_estimation(self.__class__.__name__, prompt, max_tokens)
            response = call_llm(prompt, use_cache=(use_cache and self.cur_retry == 0), thinking_level=thinking_level)
            valid_indices = parse_yaml_response(response)
            if not isinstance(valid_indices, list):
                valid_indices = []
            return [int(idx) for idx in valid_indices]
        except Exception as e:
            emit("NODE_RETRY_ERROR", class_name=self.__class__.__name__, error=e)
            llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
            raise e

    exec logs token estimation diagnostics and invokes call_llm. It forces a live LLM query on retries (use_cache and self.cur_retry == 0), extracts the YAML indices via parse_yaml_response, and casts all list elements to standard integers.

    DeterministicFileMapper.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list[int]) -> str:

    Description: Constructs 1:1 module abstractions for valid code files, orders chapters deepest-directory-first to process leaf dependencies before orchestrators, and populates shared pipeline collections.

    Parameters: * shared (dict): Shared state dictionary mutated with "abstractions", "chapter_order", and "relationships". * prep_res (tuple): Output from prep(). * exec_res (list[int]): List of valid file indices from exec().

    Returns: * str: Route transition string "default".

    Example: 

        def post(self, shared, prep_res, exec_res):
        import os

        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, _content) in enumerate(files):
            if idx not in valid_indices:
                emit("SKIP_NON_CODE_FILE", path=file_path)
                continue

            clean_name = os.path.basename(file_path)

            modules.append(
                {"name": clean_name, "description": f"Internal API reference for `{file_path}`", "files": [idx], "original_path": file_path}
            )
            chapter_order.append(len(modules) - 1)

        shared["abstractions"] = modules
        shared["chapter_order"] = sorted(
            chapter_order,
            key=lambda idx: (
                -modules[idx]["original_path"].count("/") - modules[idx]["original_path"].count(os.sep),
                modules[idx]["original_path"].lower(),
            ),
        )
        shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
        emit("DONE_DETERMINISTIC_MAPPER", count=len(modules))
        return "default"

    post filters the initial files by valid_indices, creating distinct module abstraction dictionaries containing "name", "description", "files", and "original_path". It sorts chapter_order using directory depth (counting / and os.sep delimiters) and alphabetical path sorting. This ordering guarantees that leaf modules are summarized first so their context can propagate to downstream chapters.

    ContextRouter

    ContextRouter analyzes repository size, calculates prompt template overhead, computes token limits, and routes execution between direct single-prompt analysis, directory-grouped map-reduce batching, or deterministic mapping.

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Calculates prompt template overhead, tokenizes all file entries, computes effective token budgets, and returns routing configurations.

    Parameters: * shared (dict): Pipeline shared store containing "files", "mode", "force_batch", "batch_size", and token parameters.

    Returns: * tuple: 8-element configuration tuple (route, files_data, effective_limit, batch_size, file_token_map, count_tokens, directory_tree, debug).

        directory_tree = build_directory_tree(files_data)
        tree_tokens = count_tokens(directory_tree)
        # ... [omitted chapter listing calculation] ...
        safety_limit = int(max_tokens * 0.95)
        effective_limit = safety_limit - prompt_overhead

        if shared.get("mode", "tutorial") == "api-reference":

        if total_tokens > effective_limit or force_batch:

    prep evaluates worst-case template token overhead across all prompt files (identify_abstractions.md, map_abstractions.md, draft_chapters.md) and calculates directory tree token footprints. It establishes a safety limit of 95% of max_tokens minus overhead to determine the effective_limit. If the operating mode is "api-reference", it routes immediately to "deterministic"; otherwise, it branches between "batch" and "direct" based on whether cumulative token counts exceed effective_limit.

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]:

    Description: Executes directory-aware batch partitioning without mixing directories across batches when in "batch" mode, or returns the bypass string ("direct" or "deterministic").

    Parameters: * prep_res (tuple): Configuration tuple from prep().

    Returns: * str | list[list[tuple[int, str, str]]]: Either "direct", "deterministic", or a list of batches containing (index, path, content) file tuples.

    Example: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
        llm_logger.info(
            f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}"
        )

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        dir_groups = defaultdict(list)
        for i, path, content in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            if current_batch:
                batches.append(current_batch)

        self._directory_tree = directory_tree
        return batches

    exec groups files strictly by their directory hierarchy to preserve contextual cohesion within prompt batches. When a batch approaches effective_limit or reaches batch_size, it finalizes the batch and starts a new one, ensuring files from different directories are never co-located within the same batch. The generated directory tree is cached on the instance (self._directory_tree) for consumption in post().

    Description: Writes partitioned batches and directory tree metadata to the shared store and returns the target graph edge name.

    Parameters: * shared (dict): Shared state store mutated with "file_batches" and "directory_tree". * prep_res (tuple): Configuration tuple from prep(). * exec_res (str | list): Output result from exec().

    WriteChapters

    WriteChapters is a BatchNode that writes individual documentation chapters sequentially or concurrently. It maintains an incremental disk-based MD5 cache and uses brief technical chapter summaries to propagate cross-chapter context without causing token context blowups.

After generating the chapter, it calls build_chapter_summary_prompt to produce a 3–5 sentence summary that is appended to self.chapter_summaries for subsequent chapters.
