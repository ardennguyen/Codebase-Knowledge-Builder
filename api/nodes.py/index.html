    nodes.py

    Source: nodes.py

    Technical Overview

    Building upon the runtime initialization and configuration reconciliation established in main.py, nodes.py provides the complete operational catalog of computational processing nodes powering the pipeline. Within the graph topology defined by flow.py, each node inherits from PocketFlow's Node or BatchNode base classes and implements the standardized three-phase lifecycle: prep(), exec(), and post(). The file bridges repository file trees, context window capacity calculations, multi-provider LLM prompt pipelines, and static documentation generation.

    The module manages execution across three distinct architectural branches: a direct route for codebases fitting inside a single model context window, a batch route leveraging MapReduce abstraction clustering for mid-sized to large codebases, and a deterministic route dedicated to per-file API reference documentation. Throughout this pipeline, nodes.py dynamically computes token overhead, redistributes token budgets across architectural abstractions using a two-pass algorithm, isolates network retries via execution decorators, and maintains an incremental MD5 manifest cache to prevent redundant LLM generation across repeated runs.

    Public API

    safe_exec()

    Visibility: Public Signature: def safe_exec(func)

    Description: A higher-order decorator designed to standardize error trapping across node execution phases. It wraps a node's exec() implementation in a defensive try...except block, emitting diagnostic signals and logging tracebacks to disk before re-raising the exception to allow PocketFlow's retry engine to engage.

    Parameters: * func (Callable): The instance method (typically Node.exec) being decorated.

    Returns: * Callable: A wrapped method preserving original metadata via functools.wraps.

    Raises: * Exception: Any exception raised by the wrapped method is re-raised after logging.

    Example: 

    def safe_exec(func):
    """Decorator that wraps Node.exec() with standardized error handling.

    On exception: emits NODE_RETRY_ERROR, logs traceback, and re-raises.
    Eliminates the identical try/except pattern duplicated across all nodes.
    """

    @wraps(func)
    def wrapper(self, *args, **kwargs):
        try:
            return func(self, *args, **kwargs)
        except Exception as e:
            emit("NODE_RETRY_ERROR", class_name=self.__class__.__name__, error=e)
            emit_raw("ERROR", f"[Node {self.__class__.__name__}] Error: {e}\n{traceback.format_exc()}", dest="LOG")
            raise

    return wrapper
    The decorator intercepts unhandled runtime exceptions within exec() and routes structured error telemetry to the UI bus through emit("NODE_RETRY_ERROR", ...) from utils/output.py. Simultaneously, it captures the full microsecond-stamped stack trace and dispatches it directly to disk logs via emit_raw(..., dest="LOG"). Because the original exception is re-raised, upstream framework retry loops defined on the PocketFlow nodes can manage backoff cycles without swallowing critical faults.

    ContextRouter

    Visibility: Public Signature: class ContextRouter(Node)

    Description: The analytical capacity gating node. It models the total token expenditure of the repository against the active provider's context ceiling and reasoning allocations to select between "direct", "batch", or "deterministic" execution topologies.

    ContextRouter.prep()

    Visibility: Public Signature: def prep(self, shared) -> tuple

    Description: Computes prompt template token overheads, file content volumes, and reasoning safety margins to route the pipeline.

    API Reference Mode Bypass

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)

        shared["max_tokens"] = max_tokens
        directory_tree = build_directory_tree(files_data)

        # ...
    When operating in api-reference mode, architectural abstraction discovery is unnecessary because each source file maps directly to an independent documentation page. The method constructs the structural directory tree using build_directory_tree() from utils/files.py and immediately returns the "deterministic" route.

    Prompt Overhead Calculation

            # ...
        # --- Calculate prompt overhead FIRST ---
        # 1. Prompt templates: check both IA/MA (for batching) and WC (for chapter writing)
        #    Use the largest template across all modes as worst-case estimate
        prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
        max_template_tokens = 0
        for subdir in ["tutorial", "advanced", "api-reference", "sdk"]:
            for template_name in ["map_abstractions.md", "identify_abstractions.md", "draft_chapters.md"]:
                template_path = os.path.join(prompt_dir, subdir, template_name)
                if os.path.exists(template_path):
                    with open(template_path, encoding="utf-8-sig") as f:
                        t = count_tokens(f.read())
                    max_template_tokens = max(max_template_tokens, t)

        # 2. Directory tree (shared across IA, MA, and WC prompts)
        tree_tokens = count_tokens(directory_tree)

        # 3. Chapter listing estimate (used in WC draft_chapters prompts)
        #    Format: "N. basename (doc: path.md)" per file
        chapter_listing_estimate = "\n".join(f"{i + 1}. {os.path.basename(path)} (doc: {path}.md)" for i, (path, _) in enumerate(files_data))
        listing_tokens = count_tokens(chapter_listing_estimate)

        prompt_overhead = max_template_tokens + tree_tokens + listing_tokens
        emit(
            "CAPACITY_PROMPT_OVERHEAD",
            total=f"{prompt_overhead:,}",
            template=f"{max_template_tokens:,}",
            tree=f"{tree_tokens:,}",
            listing=f"{listing_tokens:,}",
        )
        # ...
    To prevent context overflow, the method calculates the worst-case prompt overhead by scanning all prompt templates across all modes, evaluating the directory tree token size, and projecting the chapter listing length. This overhead is summed and logged before file content is evaluated.

    Token Capacity Budgeting and Route Determination

            # ...
        # --- Count file content tokens (batch-encoded; memoized for the nodes that re-count entries) ---
        file_token_map = count_tokens_many([f"--- File Index {i}: {path} ---\n{content}\n\n" for i, (path, content) in enumerate(files_data)])
        total_tokens = sum(file_token_map)

        # --- Effective limit = context minus output reserve minus overhead ---
        # Reserve output for whichever consumer of this budget thinks more: IdentifyAbstractions
        # (direct route) or MapAbstractions (each batch is packed to effective_limit).
        safety_limit = min(
            input_token_budget(max_tokens, resolve_thinking_level(shared, "identify_abstractions")),
            input_token_budget(max_tokens, resolve_thinking_level(shared, "map_abstractions")),
        )
        effective_limit = safety_limit - prompt_overhead
        force_batch = shared.get("force_batch", False)

        if total_tokens > effective_limit and force_batch:
            emit(
                "CAPACITY_EXCEEDS_FORCE",
                tokens=f"{total_tokens:,}",
                limit=f"{effective_limit:,}",
                safety=f"{safety_limit:,}",
                overhead=f"{prompt_overhead:,}",
            )
        elif total_tokens > effective_limit:
            emit(
                "CAPACITY_EXCEEDS",
                tokens=f"{total_tokens:,}",
                limit=f"{effective_limit:,}",
                safety=f"{safety_limit:,}",
                overhead=f"{prompt_overhead:,}",
            )
        elif force_batch:
            emit(
                "CAPACITY_FITS_FORCE",
                tokens=f"{total_tokens:,}",
                limit=f"{effective_limit:,}",
                safety=f"{safety_limit:,}",
                overhead=f"{prompt_overhead:,}",
            )
        else:
            emit(
                "CAPACITY_FITS", tokens=f"{total_tokens:,}", limit=f"{effective_limit:,}", safety=f"{safety_limit:,}", overhead=f"{prompt_overhead:,}"
            )
            return ("direct", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree)

        return (
            "batch",
            files_data,
            effective_limit,
            shared.get("batch_size", 50),
            file_token_map,
            count_tokens,
            directory_tree,
        )
    The node batch-encodes all source file entries via count_tokens_many() from utils/token_utils.py. It calculates safety_limit by deducting reasoning allocations (via resolve_thinking_level() from utils/thinking.py and input_token_budget()) for both identify_abstractions and map_abstractions. If the codebase exceeds the resulting effective_limit or if force_batch is set, the node routes to "batch"; otherwise, it selects "direct".

    ContextRouter.exec()

    Visibility: Public Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]

    Description: Partitions files into directory-aligned, token-bounded batches if routing to "batch", or returns the routing action string directly.

    Direct Route Short-Circuit

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, _directory_tree = prep_res
        emit_raw(
            "DEBUG",
            f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}",
            dest="LOG",
        )

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"
        # ...
    For non-batch pathways, the execution phase acts as a pure pass-through, propagating the string signal ("direct" or "deterministic") directly to PocketFlow's conditional branching mechanism.

    Directory-Preserving Batch Partitioning

            # ...
        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            # Flush remaining files in this directory
            if current_batch:
                batches.append(current_batch)

        batch_word = "batch" if len(batches) == 1 else "batches"
        emit("CAPACITY_SPLIT", count=len(batches), word=batch_word)
        emit_raw("DEBUG", f"NODE COMPLETE | node=ContextRouter | route={route} | batches={len(batches)}", dest="LOG")

        # Debug: show detailed batch info
        for idx, batch in enumerate(batches):
            content_tokens = sum(file_token_map[i] for i, p, _c in batch)
            emit("CAPACITY_BATCH_DEBUG", index=idx, file_count=len(batch), tokens=f"{content_tokens:,}", limit=f"{effective_limit:,}")
            for i, p, _c in batch:
                emit("BATCH_FILE_ITEM", index=i, path=p)

        return batches
    When batching is required, files are grouped by their containing directory using os.path.dirname. The algorithm iterates through sorted directories, packing files into the active batch until either effective_limit or batch_size is reached. Crucially, directories are never mixed within a single batch, preserving structural cohesion for the downstream LLM prompts.

    ContextRouter.post()

    Visibility: Public Signature: def post(self, shared, prep_res, exec_res) -> str

    Description: Stores the cached directory tree and batches in shared, returning the action string that controls graph routing.

    Parameters: * shared (dict): Shared blackboard dictionary. * prep_res (tuple): The 7-tuple produced during prep(). * exec_res (str | list): The routing string or list of batch chunks.

    Returns: * str: Action token ("direct", "deterministic", or "batch").

    Raises: * None.

    Example: 

        def post(self, shared, prep_res, exec_res):
        emit_raw("DEBUG", f"ContextRouter post | route={'batch' if isinstance(exec_res, list) else exec_res}", dest="LOG")
        # Store the directory tree built during prep() for EVERY route: draft_chapters and
        # group_modules prompts read shared["directory_tree"] on direct/deterministic routes too.
        shared["directory_tree"] = prep_res[-1]
        if exec_res == "direct":
            return "direct"
        if exec_res == "deterministic":
            return "deterministic"
        shared["file_batches"] = exec_res
        return "batch"
    The hook guarantees that shared["directory_tree"] is saved across all execution branches so downstream prompt builders can inject the global codebase structure. If a list of batches was generated, it is stored in shared["file_batches"], and "batch" is returned to drive the flow.

        # Uses LLM-generated technical summaries (3-5 sentences each) instead of
        # full chapter dumps (which caused O(n²) token explosion).

            # is counted once (memoized), and the joined text is never re-counted: its size is the sum
            # of the parts plus the separators, which keeps this step linear in the chapter count.

                running_tokens += summary_tokens

        is_mkdocs = prep_res["is_mkdocs"]
        chapter_files = prep_res["chapter_files"]
        ui = prep_res["ui"]

        emit_raw(
            "DEBUG",
            f"NODE EXEC | node=CombineTutorial | action=write_output | output={output_path} | chapters={len(chapter_files)} | mkdocs={is_mkdocs}",
            dest="LOG",
        )
        emit("COMBINE_WRITING_OUTPUT", path=output_path)
        os.makedirs(output_path, exist_ok=True)

        if is_mkdocs:
            write_mkdocs_output(output_path, prep_res, chapter_files)
        else:
            write_standalone_output(output_path, prep_res, chapter_files, ui)

        emit_raw(
            "DEBUG",
            f"NODE COMPLETE | node=CombineTutorial | output={output_path} | files_written={len(chapter_files) + 1}",
            dest="LOG",
        )
        return output_path  # Return the final path
    The method ensures the output directory exists via os.makedirs(output_path, exist_ok=True). It delegates static site structure generation to write_mkdocs_output() or Markdown generation to write_standalone_output() from utils/mkdocs.py.

    Visibility: Public Signature: def post(self, shared, prep_res, exec_res)

    Description: Persists the final output directory path to shared["final_output_dir"] and atomically writes the incremental manifest .doc_cache_manifest.json using a temporary file and POSIX replace.

    Parameters: * shared (dict): Shared blackboard state. * prep_res (dict): Context dictionary from prep(). * exec_res (str): Destination path returned by exec().

    Returns: * None.

    Raises: * None.

    Example: 

        def post(self, shared, prep_res, exec_res):
        shared["final_output_dir"] = exec_res  # Store the output path

        # Save the incremental manifest only now that the pages it describes are on disk: saved earlier,
        # an interrupted run left new hashes next to old pages, which later runs served as cache hits.
        manifest = shared.get("pending_manifest")
        if shared.get("incremental") and manifest is not None:
            manifest_path = os.path.join(exec_res, ".doc_cache_manifest.json")
            tmp_path = f"{manifest_path}.tmp"
            with open(tmp_path, "w", encoding="utf-8") as f:
                json.dump(manifest, f, indent=2)
            os.replace(tmp_path, manifest_path)

        emit("GEN_COMPLETE", path=exec_res)
    To prevent cache corruption from process terminations, the method defers writing .doc_cache_manifest.json until all generated files are safely on disk. It serializes the manifest to a .tmp file and performs an atomic os.replace(), guaranteeing that cache hits in subsequent runs reflect complete, uncorrupted files.

    IdentifyAbstractions.prep.<locals>.create_llm_context()

    Visibility: Private (nested closure inside IdentifyAbstractions.prep) Signature: def create_llm_context(files_data: list[tuple[str, str]]) -> tuple[str, int]

    Description: Iterates through source file tuples and concatenates them into an indexed context string, calculating token counts and halting if the input exceeds the provider's token budget.

    Parameters: * files_data (list[tuple[str, str]]): List of (file_path, content) pairs.

    Returns: * tuple[str, int]: A 2-tuple containing the combined context string and the total token count.

    Raises: * None.

    Example: 

            def create_llm_context(files_data):
            # Retrieve max tokens limit
            max_tokens = resolve_max_tokens(shared)

            safety_limit = input_token_budget(max_tokens, thinking_level)

            context = ""
            current_tokens = 0

            for i, (path, content) in enumerate(files_data):
                entry = f"--- File Index {i}: {path} ---\n{content}\n\n"

                entry_tokens = count_tokens(entry)

                if current_tokens + entry_tokens > safety_limit:
                    emit("WARN_CONTEXT_TRUNCATED", index=i, path=path, limit=safety_limit)
                    break

                context += entry
                current_tokens += entry_tokens

            # Entries end on a blank line, so the joined context counts as the sum of its entries
            # (measured: identical) — no need to re-encode the whole codebase once more.
            return context, current_tokens
    The helper computes the exact safety boundary using input_token_budget() from utils/token_utils.py. If adding a file would push the context beyond safety_limit, it emits a WARN_CONTEXT_TRUNCATED event and breaks early.

    Error Handling

    Node Execution Failures and Traceback Capture

    All primary node execution phases (exec()) are decorated with @safe_exec. When an unhandled exception occurs: 1. An event NODE_RETRY_ERROR is emitted to the UI system with the active class name and exception details. 2. An error entry containing the full formatted Python traceback is dispatched to the disk log via emit_raw("ERROR", ..., dest="LOG"). 3. The exception is re-raised, allowing PocketFlow's retry policy (max_retries=5, wait=20 configured in flow.py) to manage backoff and retry cycles.

    Resilient Chapter Drafting Fallback

    During documentation drafting, network dropouts, provider refusals, or persistent rate limits could abort a long multi-chapter run. WriteChapters implements exec_fallback(item, exc): * It generates a stub Markdown document indicating temporary unavailability (get("UI_CHAPTER_UNAVAILABLE")). * It sets hash: None, which excludes the stub from .doc_cache_manifest.json and forces regeneration on the next run. * It appends a placeholder summary to self.chapter_summaries, preserving chapter index alignment across the documentation suite.

    Defensive Model Output Validation

    Because Large Language Models can produce invalid YAML structures or omit required attributes: * Deserialization is wrapped with parse_yaml_response(), which explicitly verifies response completion and checks for TruncatedResponse sentinels from utils/llm_common.py. * Numeric indices are parsed using regular expressions (re.findall(r"\d+", ...)) and validated against upper bounds (0 <= idx < num_abstractions), dropping malformed references with WARN_PARSE_INDEX or WARN_PARSE_RELATIONSHIP alerts rather than crashing the node.

    Atomic Manifest Serialization

    To prevent manifest corruption from process interruptions: * In CombineTutorial.post(), .doc_cache_manifest.json is written only after all generated chapter files exist on disk. * Content is written to a temporary sibling file (.doc_cache_manifest.json.tmp) and atomically moved using os.replace(), ensuring that subsequent incremental runs never read incomplete or corrupted manifests.
