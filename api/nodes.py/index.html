    Technical Overview

    Following the CLI intake and parameter orchestration established in main.py and the Directed Acyclic Graph (DAG) construction defined in flow.py, nodes.py provides the operational execution engine of the documentation pipeline. It defines all ten processing node classes that inherit from PocketFlow's Node and BatchNode base classes. Each node implements the canonical three-stage lifecycle—prep() for shared-state extraction and prompt preparation, exec() for LLM inference or I/O processing, and post() for mutating the centralized shared dictionary.

    The module is responsible for bridging low-level filesystem ingestion with high-level cognitive synthesis. It dynamically chooses between direct single-prompt synthesis, batch map-reduce partitioning, and 1:1 deterministic file mapping based on codebase size and token constraints. To maintain high synthesis fidelity within model context boundaries, the nodes implement dynamic token budgeting algorithms, two-pass greedy file allocation, sliding-window summaries of preceding chapters, and incremental MD5 disk caching.

    Public API

    DeterministicFileMapper

    Visibility: Public
    Signature: class DeterministicFileMapper(Node):

    A specialized Node subclass that implements a non-clustering, 1:1 file-to-chapter documentation strategy. Operating primarily in api-reference mode, it bypasses architectural clustering and instead filters candidate files through an LLM before mapping each retained file directly into an isolated chapter module. Chapters are ordered deterministically by filesystem hierarchy depth (leaf files first) to guarantee that utility dependency summaries are available before orchestrating modules are analyzed.

    prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple[str, bool, str | None, int]:

    Description: Extracts the candidate file listing from shared["files"], formats each entry with its integer index and path, and generates a negative-filtering prompt via build_code_file_filter_prompt(). Returns prompt parameters and inference flags for execution.

    Parameters: * shared (dict): Central blackboard state store containing "files", "project_name", and execution options.

    Returns: * tuple[str, bool, str | None, int]: A 4-element tuple comprising (prompt, use_cache, thinking_level, max_tokens).

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        project_name = shared["project_name"]

        file_listing = "\n".join([f"{i} # {path}" for i, (path, _) in enumerate(files_data)])

        prompt = build_code_file_filter_prompt(project_name, file_listing)
        emit_raw("DEBUG", f"DeterministicFileMapper prep | {len(files_data)} candidate files for filtering", dest="LOG")
        return prompt, shared.get("use_cache", True), shared.get("thinking_level", None), shared.get("max_tokens", 100000)
    The method retrieves the list of (path, content) tuples from shared["files"]. It projects this list into a newline-separated manifest where each line pairs the index with the path formatted as {index} # {path}. It then delegates to build_code_file_filter_prompt() to construct the instruction set asking the LLM to discard build artifacts, package manifests, or non-code files.

    exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> list[int]:

    Description: Dispatches the filtering prompt to the LLM execution gateway, verifies response token boundaries, parses the returned YAML array of integer indices, and falls back to an empty list on malformed output.

    Parameters: * prep_res (tuple): The 4-element tuple returned by prep().

    Returns: * list[int]: List of integer indices corresponding to retained, valid source code files.

    Raises: * Exception: Re-raises any trapped exception after logging telemetry and triggering pocketflow node retry policies.

    Example: 

        def exec(self, prep_res):
        try:
            prompt, use_cache, thinking_level, max_tokens = prep_res
            emit("LLM_CALL_FILTER_FILES")
            log_token_estimation(self.__class__.__name__, prompt, max_tokens)
            response = call_llm(prompt, use_cache=(use_cache and self.cur_retry == 0), thinking_level=thinking_level)
            valid_indices = parse_yaml_response(response)
            if not isinstance(valid_indices, list):
                valid_indices = []
            return [int(idx) for idx in valid_indices]
        except Exception as e:
            emit("NODE_RETRY_ERROR", class_name=self.__class__.__name__, error=e)
            emit_raw("ERROR", f"[Node {self.__class__.__name__}] Error: {e}\n{traceback.format_exc()}", dest="LOG")
            raise e
    The method logs diagnostic token estimation before calling call_llm(). The use_cache parameter is conditioned on self.cur_retry == 0, ensuring that any automatic retry bypasses stale cached completions. The YAML response is deserialized into native Python objects via parse_yaml_response() and normalized into a typed list[int].

    post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list[int]) -> str:

    Description: Constructs 1:1 module definitions for all retained file indices, computes directory-depth traversal ordering, initializes synthetic relationship structures, and registers the abstractions in shared.

    Parameters: * shared (dict): The central state store to be mutated. * prep_res (tuple): The parameters emitted from prep(). * exec_res (list[int]): The list of validated integer file indices.

    Returns: * str: The PocketFlow action string "default".

    Example: 

        def post(self, shared, prep_res, exec_res):
        import os

        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, _content) in enumerate(files):
            if idx not in valid_indices:
                emit("SKIP_NON_CODE_FILE", path=file_path)
                continue

            clean_name = os.path.basename(file_path)

            modules.append(
                {"name": clean_name, "description": f"Internal API reference for `{file_path}`", "files": [idx], "original_path": file_path}
            )
            chapter_order.append(len(modules) - 1)

        shared["abstractions"] = modules
        # Sort chapter order by directory depth (deepest first, then alphabetical).
        # This ensures utility/leaf files are processed before orchestration files,
        # so their summaries are available as cross-chapter context.
        # Works universally across all languages (Python, C#, C++, Java, etc.).
        shared["chapter_order"] = sorted(
            chapter_order,
            key=lambda idx: (
                -modules[idx]["original_path"].count("/") - modules[idx]["original_path"].count(os.sep),
                modules[idx]["original_path"].lower(),
            ),
        )
        shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
        emit("DONE_DETERMINISTIC_MAPPER", count=len(modules))
        return "default"
    The method builds an abstraction dictionary for every index retained by the LLM filter. Crucially, shared["chapter_order"] is sorted using a lambda key that calculates negative slash and separator counts (-path.count("/") - path.count(os.sep)). This ensures leaf modules residing deep in the directory tree (such as utilities and data models) appear first in the order. When WriteChapters runs sequentially, summaries of leaf files are synthesized and placed in the context window before high-level orchestrators are drafted.

    ContextRouter

    Visibility: Public
    Signature: class ContextRouter(Node):

    A routing and context-budgeting node that inspects total codebase volume against the LLM's configured context window. It decides whether the pipeline can analyze all source code in a single prompt ("direct"), must split the files into coherent directory-level partitions ("batch"), or must follow a 1:1 file reference mapping ("deterministic").

    prep()

    This method evaluates token headroom across four sequential phases:

    1. Prompt Overhead Calculation

            # --- Calculate prompt overhead FIRST ---
        # 1. Prompt templates: check both IA/MA (for batching) and WC (for chapter writing)
        #    Use the largest template across all modes as worst-case estimate
        prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
        max_template_tokens = 0
        for subdir in ["tutorial", "advanced", "api-reference", "sdk"]:
            for template_name in ["map_abstractions.md", "identify_abstractions.md", "draft_chapters.md"]:
                template_path = os.path.join(prompt_dir, subdir, template_name)
                if os.path.exists(template_path):
                    with open(template_path, encoding="utf-8-sig") as f:
                        t = count_tokens(f.read())
                    max_template_tokens = max(max_template_tokens, t)
    The node reads prompt markdown files across all documentation modes ("tutorial", "advanced", "api-reference", "sdk") to establish the worst-case template footprint (max_template_tokens). This ensures that context estimations reflect the largest possible instruction payload.

    2. Structural Metadata Overhead

            # 2. Directory tree (shared across IA, MA, and WC prompts)
        directory_tree = build_directory_tree(files_data)
        tree_tokens = count_tokens(directory_tree)

        # 3. Chapter listing estimate (used in WC draft_chapters prompts)
        #    Format: "N. basename (doc: path.md)" per file
        chapter_listing_estimate = "\n".join(f"{i + 1}. {os.path.basename(path)} (doc: {path}.md)" for i, (path, _) in enumerate(files_data))
        listing_tokens = count_tokens(chapter_listing_estimate)

        prompt_overhead = max_template_tokens + tree_tokens + listing_tokens
        emit(
            "CAPACITY_PROMPT_OVERHEAD",
            total=f"{prompt_overhead:,}",
            template=f"{max_template_tokens:,}",
            tree=f"{tree_tokens:,}",
            listing=f"{listing_tokens:,}",
        )
    The method computes the token volume of the rendered directory tree using build_directory_tree() and constructs an estimated flat chapter listing. The sum of template tokens, tree tokens, and listing tokens constitutes the immutable prompt overhead (prompt_overhead).

    3. Codebase Token Aggregation

            # --- Count file content tokens ---
        total_tokens = 0
        file_token_map = []
        for i, (path, content) in enumerate(files_data):
            entry = f"--- File Index {i}: {path} ---\n{content}\n\n"
            tokens = count_tokens(entry)
            total_tokens += tokens
            file_token_map.append(tokens)

        # --- Effective limit = safety margin minus overhead ---
        safety_limit = int(max_tokens * 0.95)
        effective_limit = safety_limit - prompt_overhead
        force_batch = shared.get("force_batch", False)
    Each file entry is formatted with boundary headers, and its token cost is pre-computed and stored in file_token_map. The effective token limit is calculated by taking 95% of max_tokens (to maintain provider safety margins) and subtracting the calculated prompt_overhead.

    4. Routing Decision Logic

            if shared.get("mode", "tutorial") == "api-reference":
            emit("CAPACITY_API_REF_MODE")
            return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree)

        if total_tokens > effective_limit and force_batch:
            emit(
                "CAPACITY_EXCEEDS_FORCE",
                tokens=f"{total_tokens:,}",
                limit=f"{effective_limit:,}",
                safety=f"{safety_limit:,}",
                overhead=f"{prompt_overhead:,}",
            )
        elif total_tokens > effective_limit:
            emit(
                "CAPACITY_EXCEEDS",
                tokens=f"{total_tokens:,}",
                limit=f"{effective_limit:,}",
                safety=f"{safety_limit:,}",
                overhead=f"{prompt_overhead:,}",
            )
        elif force_batch:
            emit(
                "CAPACITY_FITS_FORCE",
                tokens=f"{total_tokens:,}",
                limit=f"{effective_limit:,}",
                safety=f"{safety_limit:,}",
                overhead=f"{prompt_overhead:,}",
            )
        else:
            emit(
                "CAPACITY_FITS", tokens=f"{total_tokens:,}", limit=f"{effective_limit:,}", safety=f"{safety_limit:,}", overhead=f"{prompt_overhead:,}"
            )
            return ("direct", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree)

        return (
            "batch",
            files_data,
            effective_limit,
            shared.get("batch_size", 50),
            file_token_map,
            count_tokens,
            directory_tree,
        )
    If mode is configured as "api-reference", the route immediately resolves to "deterministic". Otherwise, if total_tokens fits within effective_limit and force_batch is False, the route resolves to "direct". In all other circumstances (context overflow or manual batch enforcement), it routes to "batch".

    exec()

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree = prep_res
        emit_raw(
            "DEBUG",
            f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}",
            dest="LOG",
        )

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            # Flush remaining files in this directory
            if current_batch:
                batches.append(current_batch)

        batch_word = "batch" if len(batches) == 1 else "batches"
        emit("CAPACITY_SPLIT", count=len(batches), word=batch_word)
        emit_raw("DEBUG", f"NODE COMPLETE | node=ContextRouter | route={route} | batches={len(batches)}", dest="LOG")

        # Debug: show detailed batch info
        for idx, batch in enumerate(batches):
            content_tokens = sum(file_token_map[i] for i, p, _c in batch)
            emit("CAPACITY_BATCH_DEBUG", index=idx, file_count=len(batch), tokens=f"{content_tokens:,}", limit=f"{effective_limit:,}")
            for i, p, _c in batch:
                emit("BATCH_FILE_ITEM", index=i, path=p)

        # Store directory tree for later use
        self._directory_tree = directory_tree

        return batches
    When handling a "batch" decision, exec() groups candidate files by directory name (dir_groups). It aggregates files into discrete batches without mixing directories across batch boundaries. A new batch is initialized whenever adding a file would cause total batch tokens to exceed effective_limit or exceed the configured batch_size. The resulting partitions are stored as a list of batches.

    post()

        def post(self, shared, prep_res, exec_res):
        emit_raw("DEBUG", f"ContextRouter post | route={'batch' if isinstance(exec_res, list) else exec_res}", dest="LOG")
        if exec_res == "direct":
            return "direct"
        if exec_res == "deterministic":
            return "deterministic"
        shared["file_batches"] = exec_res
        # Reuse directory tree built during prep()
        shared["directory_tree"] = getattr(self, "_directory_tree", build_directory_tree(shared["files"]))
        return "batch"
    The method inspects the execution result. If "direct" or "deterministic", it emits that action token directly to drive conditional PocketFlow branch transitions. If batches were compiled, it saves them to shared["file_batches"], preserves the rendered directory_tree, and returns the "batch" action string.

    MapAbstractions

    Visibility: Public
    Signature: class MapAbstractions(BatchNode):

    A BatchNode subclass that executes across each file batch produced by ContextRouter. It analyzes file clusters independently to discover localized architectural abstractions, emitting partial abstraction definitions that are subsequently merged by ReduceAbstractions.

    prep()

        def prep(self, shared):
        return [
            {
                "batch_index": i,
                "files": batch,
                "project_name": shared["project_name"],
                "language": shared.get("language", "english"),
                "use_cache": shared.get("use_cache", True),
                "thinking_level": shared.get("thinking_level", None),
                "advanced_mode": shared.get("advanced_mode", False),
                "max_tokens": shared.get("max_tokens", 100000),
                "directory_tree": shared.get("directory_tree", ""),
                "mode": shared.get("mode", "tutorial"),
            }
            for i, batch in enumerate(shared["file_batches"])
        ]
    The method iterates over shared["file_batches"], yielding a standalone parameter payload for every batch partition. Each item contains the batch index, the constituent file tuples, target language instructions, and global context boundaries.

    exec()

        def exec(self, item):
        batch_index = item["batch_index"]
        files = item["files"]
        emit("LLM_CALL_MAP_ABSTRACTIONS", batch_index=batch_index, file_count=len(files))

        context = ""
        for i, path, content in files:
            context += f"--- File Index {i}: {path} ---\n{content}\n\n"

        prompt_template = load_prompt_template("map_abstractions", mode=item.get("mode", "tutorial"))

        language = item.get("language", "english")
        language_instruction = f"Output language MUST be entirely in {language.capitalize()}. " if language.lower() != "english" else ""
        name_lang_hint = f" (in {language.capitalize()})" if language.lower() != "english" else ""
        desc_lang_hint = f" (in {language.capitalize()})" if language.lower() != "english" else ""

        prompt = prompt_template.format(
            project_name=item["project_name"],
            context=context,
            language_instruction=language_instruction,
            name_lang_hint=name_lang_hint,
            desc_lang_hint=desc_lang_hint,
            directory_tree=item.get("directory_tree", "Not available"),
        )

        token_usage = {
            "file_content": count_tokens(context),
            "directory_tree": count_tokens(item.get("directory_tree", "")),
        }
        token_usage["overhead"] = count_tokens(prompt) - sum(token_usage.values())
        log_token_estimation(self.__class__.__name__, prompt, item["max_tokens"], token_usage=token_usage)
        for i, path, _content in files:
            emit("BATCH_FILE_ITEM", index=i, path=path)
        response = call_llm(prompt, use_cache=(item["use_cache"] and self.cur_retry == 0), thinking_level=item["thinking_level"])

        abstractions = parse_yaml_response(response)

        validated_abstractions = []
        if isinstance(abstractions, list):
            for obj in abstractions:
                if isinstance(obj, dict) and "name" in obj and "description" in obj and "file_indices" in obj:
                    import re

                    validated_indices = []
                    for idx_entry in obj["file_indices"]:
                        nums = re.findall(r"\d+", str(idx_entry))
                        if nums:
                            validated_indices.append(int(nums[0]))
                    if validated_indices:
                        validated_abstractions.append(
                            {"name": obj["name"], "description": obj["description"], "files": sorted(set(validated_indices))}
                        )
        return validated_abstractions
    For each batch, the method constructs a formatted file context string, loads the mode-specific map_abstractions.md template via load_prompt_template(), and invokes the LLM. It parses the resulting YAML completion, extracts digits from the file_indices array via regular expressions, and constructs validated abstraction dictionaries containing "name", "description", and "files".

    post()

        def post(self, shared, prep_res, exec_res_list):
        all_abstractions = []
        for batch_abs in exec_res_list:
            all_abstractions.extend(batch_abs)
        emit_raw("DEBUG", f"MapAbstractions post | collected {len(all_abstractions)} partial abstractions", dest="LOG")
        shared["mapped_abstractions"] = all_abstractions
    Merges the partial abstraction lists returned by all parallel or sequential batch executions into a single flat list, storing the consolidated result in shared["mapped_abstractions"].

    ReduceAbstractions

    Visibility: Public
    Signature: class ReduceAbstractions(Node):

    The reduction component of the Map-Reduce discovery track. It ingests the uncurated list of partial abstractions generated across all file batches and dispatches a synthesis prompt to consolidate, deduplicate, and prune them into a cohesive system-wide architecture.

    prep()

        def prep(self, shared):
        return (
            shared["mapped_abstractions"],
            shared["project_name"],
            shared.get("language", "english"),
            shared.get("use_cache", True),
            shared.get("max_abstraction_num", 10),
            shared.get("thinking_level", None),
            shared.get("advanced_mode", False),
            shared.get("max_tokens", 100000),
            shared.get("mode", "tutorial"),
        )
    Extracts mapped_abstractions, project metadata, target language flags, and the max_abstraction_num budget limit (defaulting to 10) from the shared store.

    exec()

    Internal Helpers

    create_llm_context(files_data)

    Visibility: Private (Nested Helper inside IdentifyAbstractions.prep)
    Signature: def create_llm_context(files_data: list[tuple[str, str]]) -> str:

    Description: Dynamically constructs a string of formatted source file contents while enforcing token limits. It inspects the total token ceiling via resolve_max_tokens() and greedily appends files until reaching a 95% safety margin. If adding a file would exceed this safety ceiling, the loop breaks and emits a context truncation warning.

    Parameters: * files_data (list[tuple[str, str]]): Ordered list of (relative_path, content) tuples.

    Returns: * str: Formatted multiline context string containing bounded file blocks.

    Example: 

            # Helper to create context from files, respecting limits (basic example)
        def create_llm_context(files_data):
            # Retrieve max tokens limit
            max_tokens = resolve_max_tokens(shared)

            safety_limit = int(max_tokens * 0.95)

            context = ""
            current_tokens = 0

            for i, (path, content) in enumerate(files_data):
                entry = f"--- File Index {i}: {path} ---\n{content}\n\n"

                entry_tokens = count_tokens(entry)

                if current_tokens + entry_tokens > safety_limit:
                    emit("WARN_CONTEXT_TRUNCATED", index=i, path=path, limit=safety_limit)
                    break

                context += entry
                current_tokens += entry_tokens

            return context
    The helper computes the token weight of each file block formatted as --- File Index {i}: {path} ---\n{content}\n\n. Token volumes are tracked via count_tokens(). If adding the current block causes current_tokens to exceed int(max_tokens * 0.95), the loop logs an observability event and halts accumulation, ensuring the subsequent prompt does not breach model context boundaries.

    Error Handling

    Stale Cache Bypassing on Retry

    All nodes executing LLM inference (DeterministicFileMapper, IdentifyAbstractions, MapAbstractions, ReduceAbstractions, AnalyzeRelationships, OrderChapters, WriteChapters) enforce a cache bypass guard when recovering from failures: 

    response = call_llm(prompt, use_cache=(use_cache and self.cur_retry == 0), thinking_level=thinking_level)
    When self.cur_retry > 0, use_cache evaluates to False. This forces call_llm() to bypass stale local cache entries on disk and query the upstream API for a clean response.

    YAML Fence Parsing and Extraction Resilience

    The module protects against unstructured model hallucinations through defensive regex and type assertions: * Index List Normalization: In DeterministicFileMapper, IdentifyAbstractions, and ReduceAbstractions, raw outputs are verified with isinstance(data, list). String entries containing comments (such as "4 # utils/files.py") or hyphenated ranges ("2-5") are sanitized using re.findall(r"\d+", ...). * Chapter Order Permutation Verification: In OrderChapters, the response must contain an exact permutation of all abstraction indices. If the LLM generates duplicates, out-of-range integers, or omits indices, a ValueError is explicitly raised to trigger PocketFlow's node retry mechanism.
