    nodes.py

    Source: nodes.py

    Following the runtime configuration and CLI orchestration established in main.py and the workflow graph definition in flow.py, nodes.py provides the concrete execution nodes that power the Codebase-Knowledge-Builder pipeline.

    Technical Overview

    nodes.py defines the discrete computational and inference units orchestrated by the PocketFlow DAG framework. Each node implements a three-stage lifecycle contract: prep() (state extraction, parameter validation, and prompt preparation), exec() (external I/O, LLM inference, and data transformation), and post() (state mutation and downstream routing). Together, these nodes translate raw codebase files into structured, publication-ready technical documentation.

    The module supports three distinct execution pathways dynamically governed by repository size and operational mode: 1. Deterministic Path: Used in api-reference mode, bypassing clustering heuristics in favor of a 1:1 mapping from filtered source files to documentation chapters. 2. Direct Path: Used for codebases that fit within the LLM context window safety budget, identifying architectural abstractions and relationships in a single inference pass. 3. Batch (Map-Reduce) Path: Used for massive repositories, chunking files along directory boundaries to map local abstractions across parallel sub-batches before reducing them into a unified architectural hierarchy.

    Downstream from abstraction discovery, the pipeline determines chapter ordering, drafts narrative content using rolling cross-chapter technical summaries to eliminate token explosion ($O(n^2)$ context accumulation), generates Mermaid dependency diagrams, and compiles standalone Markdown files or complete MkDocs static documentation sites.

    Public API

    build_directory_tree()

    Visibility: Public
    Signature: def build_directory_tree(files_data: list[tuple[str, str]]) -> str

    Description: Constructs a compact, hierarchical text representation of the codebase directory structure from a collection of relative path and file content tuples. It groups filenames under sorted directory headings and tags each file with its numeric index (idx:N). This provides LLM prompts with structural spatial context while minimizing token overhead.

    Parameters: * files_data (list[tuple[str, str]]): List of tuples containing (relative_path, file_content).

    Returns: * str: Newline-delimited directory tree string with directory paths and indented indexed filenames.

    Example: 

    dir_files = defaultdict(list)
for i, (path, _content) in enumerate(files_data):
    dirname = os.path.dirname(path) or "."
    basename = os.path.basename(path)
    dir_files[dirname].append(f"{basename} (idx:{i})")

lines = []
for dirname in sorted(dir_files.keys()):
    lines.append(f"{dirname}/")
    lines.extend(f"  {fname}" for fname in sorted(dir_files[dirname]))
return "\n".join(lines)

    The function iterates over all files, normalizes empty directory names to ".", and sorts directories and filenames alphabetically. It is invoked across ContextRouter, IdentifyAbstractions, MapAbstractions, and CombineTutorial to provide layout context to the model.

    FetchRepo

    Visibility: Public
    Base Class: pocketflow.Node

    Description: The entry node of the workflow DAG. It normalizes repository source identifiers, resolves include/exclude patterns, and crawls either a local directory or remote GitHub repository to ingest raw source files into memory.

    FetchRepo.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> dict

    Description: Extracts crawling configurations and credentials from the shared state store, automatically deriving the project name from the repository URL or local directory if not explicitly configured.

    Parameters: * shared (dict): The global workflow blackboard state.

    Returns: * dict: Prepared parameters for repository extraction.

    Example: 

    repo_url = shared.get("repo_url")
local_dir = shared.get("local_dir")
project_name = shared.get("project_name")

if not project_name:
    # Basic name derivation from URL or directory
    if repo_url:
        project_name = repo_url.split("/")[-1].replace(".git", "")
    else:
        project_name = os.path.basename(os.path.abspath(local_dir))
    shared["project_name"] = project_name

# Get file patterns directly from shared
include_patterns = shared["include_patterns"]
exclude_patterns = shared["exclude_patterns"]
max_file_size = shared["max_file_size"]

return {
    "repo_url": repo_url,
    "local_dir": local_dir,
    "token": shared.get("github_token"),
    "include_patterns": include_patterns,
    "exclude_patterns": exclude_patterns,
    "max_file_size": max_file_size,
    "use_relative_paths": True,
}

    The method ensures project_name is set on shared and packages filtering criteria into a dictionary payload for execution.

    FetchRepo.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: dict) -> list[tuple[str, str]]

    Description: Dispatches crawling operations to utils/crawl_github_files.py or utils/crawl_local_files.py based on whether repo_url is provided. Transforms the dictionary mapping of {path: content} into an ordered list of (path, content) tuples.

    Parameters: * prep_res (dict): Parameter payload produced by prep().

    Returns: * list[tuple[str, str]]: Collection of indexed file path and content tuples.

    Raises: * ValueError: If no matching files are discovered after applying exclusion and inclusion filters.

    Example: 

    source = prep_res["repo_url"] or prep_res["local_dir"]
llm_logger.info(f"NODE EXEC | node=FetchRepo | action=crawl_files | source={source}")

if prep_res["repo_url"]:
    emit("CRAWL_REPOSITORY", url=prep_res["repo_url"])
    result = crawl_github_files(
        repo_url=prep_res["repo_url"],
        token=prep_res["token"],
        include_patterns=prep_res["include_patterns"],
        exclude_patterns=prep_res["exclude_patterns"],
        max_file_size=prep_res["max_file_size"],
        use_relative_paths=prep_res["use_relative_paths"],
    )
else:
    emit("CRAWL_DIRECTORY", path=prep_res["local_dir"])
    result = crawl_local_files(
        directory=prep_res["local_dir"],
        include_patterns=prep_res["include_patterns"],
        exclude_patterns=prep_res["exclude_patterns"],
        max_file_size=prep_res["max_file_size"],
        use_relative_paths=prep_res["use_relative_paths"],
    )

files_list = list(result.get("files", {}).items())
if len(files_list) == 0:
    raise ValueError("No matching files found. Check your directory and include/exclude patterns.")
return files_list

    ContextRouter

    Visibility: Public
    Base Class: pocketflow.Node

    Description: Evaluates the total token payload of the codebase against model context limits, accounting for prompt template and directory tree overhead. Dynamically routes execution along deterministic, direct, or batch pathways, splitting files into directory-isolated batches when chunking is required.

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple

    This method executes in four logical phases to determine token budgeting and routing pathways.

    Phase 1: Context Limit and Overhead Resolution

    files_data = shared["files"]
max_tokens = resolve_max_tokens(shared)
shared["max_tokens"] = max_tokens

count_tokens = create_token_counter()

prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
max_template_tokens = 0
for subdir in ["tutorial", "advanced", "api-reference", "sdk"]:
    for template_name in ["map_abstractions.md", "identify_abstractions.md", "draft_chapters.md"]:
        template_path = os.path.join(prompt_dir, subdir, template_name)
        if os.path.exists(template_path):
            with open(template_path, encoding="utf-8-sig") as f:
                t = count_tokens(f.read())
            max_template_tokens = max(max_template_tokens, t)

directory_tree = build_directory_tree(files_data)
tree_tokens = count_tokens(directory_tree)

chapter_listing_estimate = "\n".join(f"{i + 1}. {os.path.basename(path)} (doc: {path}.md)" for i, (path, _) in enumerate(files_data))
listing_tokens = count_tokens(chapter_listing_estimate)

prompt_overhead = max_template_tokens + tree_tokens + listing_tokens
    This phase inspects the available prompt templates across modes, calculating the worst-case token size for templates, directory tree representations, and chapter listings to derive prompt_overhead.

    Phase 2: File Token Enumeration

    total_tokens = 0
file_token_map = []
for i, (path, content) in enumerate(files_data):
    entry = f"--- File Index {i}: {path} ---\n{content}\n\n"
    tokens = count_tokens(entry)
    total_tokens += tokens
    file_token_map.append(tokens)
    Each file is formatted with its index header, measured for token count, and appended to an in-memory token map.

    Phase 3: Capacity Calculation and Route Determination

    safety_limit = int(max_tokens * 0.95)
effective_limit = safety_limit - prompt_overhead
force_batch = shared.get("force_batch", False)

if shared.get("mode", "tutorial") == "api-reference":
    emit("CAPACITY_API_REF_MODE")
    return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

if total_tokens > effective_limit and force_batch:
    emit("CAPACITY_EXCEEDS_FORCE", tokens=f"{total_tokens:,}", limit=f"{effective_limit:,}", safety=f"{safety_limit:,}", overhead=f"{prompt_overhead:,}")
elif total_tokens > effective_limit:
    emit("CAPACITY_EXCEEDS", tokens=f"{total_tokens:,}", limit=f"{effective_limit:,}", safety=f"{safety_limit:,}", overhead=f"{prompt_overhead:,}")
elif force_batch:
    emit("CAPACITY_FITS_FORCE", tokens=f"{total_tokens:,}", limit=f"{effective_limit:,}", safety=f"{safety_limit:,}", overhead=f"{prompt_overhead:,}")
else:
    emit("CAPACITY_FITS", tokens=f"{total_tokens:,}", limit=f"{effective_limit:,}", safety=f"{safety_limit:,}", overhead=f"{prompt_overhead:,}")
    return ("direct", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

return (
    "batch",
    files_data,
    effective_limit,
    shared.get("batch_size", 50),
    file_token_map,
    count_tokens,
    directory_tree,
    shared.get("debug", False),
)
    The effective token limit is calculated by subtracting overhead from 95% of the model capacity (safety_limit). The router immediately yields "deterministic" for API reference mode, "direct" if the entire codebase fits within the effective limit, or "batch" if token capacity is exceeded or forced.

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]

    Description: Handles pass-through for "direct" and "deterministic" routes, or groups files into directory-isolated batches for the "batch" route to ensure related files are processed within the same batch.

    Parameters: * prep_res (tuple): The routing configuration and token metadata tuple generated in prep().

    Returns: * str | list[list[tuple[int, str, str]]]: Either the route string ("direct", "deterministic") or a nested list of batches containing (index, path, content) tuples.

    Example: 

    route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
if route in ("direct", "deterministic"):
    return route

dir_groups = defaultdict(list)
for i, (path, content) in enumerate(files_data):
    dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

batches = []
for dirname in sorted(dir_groups.keys()):
    current_batch = []
    current_tokens = 0
    for i, path, content, tokens in dir_groups[dirname]:
        if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
            batches.append(current_batch)
            current_batch = []
            current_tokens = 0
        current_batch.append((i, path, content))
        current_tokens += tokens
    if current_batch:
        batches.append(current_batch)

self._directory_tree = directory_tree
return batches

    The algorithm iterates through directory buckets, appending files to current_batch until the addition of the next file would exceed effective_limit or batch_size. It flushes directory batches before moving to the next directory, ensuring files from different directories are never mixed in a single batch.

    ContextRouter.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: Any) -> str

    Description: Persists file batches and directory trees to shared if batch routing was selected, and returns the routing string ("direct", "deterministic", or "batch") to direct DAG execution.

    Example: 

    def post(self, shared, prep_res, exec_res):
    if exec_res == "direct":
        return "direct"
    if exec_res == "deterministic":
        return "deterministic"
    shared["file_batches"] = exec_res
    shared["directory_tree"] = getattr(self, "_directory_tree", build_directory_tree(shared["files"]))
    return "batch"

    DeterministicFileMapper

    Visibility: Public
    Base Class: pocketflow.Node

    Description: Operates in api-reference mode. Prompts the LLM to filter out non-code assets and maps each valid source file 1:1 to an abstraction module. It orders chapters by directory depth (leaf/utility files first) so upstream dependencies are documented before downstream consumers.

    DeterministicFileMapper.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple[str, bool, str | None, int]

    Description: Builds a file-filtering prompt using utils/prompts.py and retrieves caching, reasoning, and token configurations from shared.

    Example: 

    def prep(self, shared):
    files_data = shared["files"]
    project_name = shared["project_name"]

    file_listing = "\n".join([f"{i} # {path}" for i, (path, _) in enumerate(files_data)])

    prompt = build_code_file_filter_prompt(project_name, file_listing)
    return prompt, shared.get("use_cache", True), shared.get("thinking_level", None), shared.get("max_tokens", 100000)

    DeterministicFileMapper.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> list[int]

    Description: Calls the LLM to filter files, parses the resulting YAML response into a list of valid file indices, and catches exceptions with diagnostic logging and retry triggers.

    Parameters: * prep_res (tuple): Prepared parameters (prompt, use_cache, thinking_level, max_tokens).

    Returns: * list[int]: Verified numeric file indices containing relevant code.

    Raises: * Exception: Rethrows any LLM inference or parsing exception to trigger PocketFlow node retries.

    Example: 

    def exec(self, prep_res):
    try:
        prompt, use_cache, thinking_level, max_tokens = prep_res
        emit("LLM_CALL_FILTER_FILES")
        log_token_estimation(self.__class__.__name__, prompt, max_tokens)
        response = call_llm(prompt, use_cache=(use_cache and self.cur_retry == 0), thinking_level=thinking_level)
        valid_indices = parse_yaml_response(response)
        if not isinstance(valid_indices, list):
            valid_indices = []
        return [int(idx) for idx in valid_indices]
    except Exception as e:
        emit("NODE_RETRY_ERROR", class_name=self.__class__.__name__, error=e)
        llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
        raise e

    DeterministicFileMapper.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list[int]) -> str

    Description: Instantiates a 1:1 abstraction dictionary for every valid file index, sorts chapters by directory nesting depth in reverse order, sets a stub relationship payload, and returns "default".

    Example: 

    files = shared.get("files", [])
valid_indices = set(exec_res)
modules = []
chapter_order = []

for idx, (file_path, _content) in enumerate(files):
    if idx not in valid_indices:
        emit("SKIP_NON_CODE_FILE", path=file_path)
        continue

    clean_name = os.path.basename(file_path)
    modules.append(
        {"name": clean_name, "description": f"Internal API reference for `{file_path}`", "files": [idx], "original_path": file_path}
    )
    chapter_order.append(len(modules) - 1)

shared["abstractions"] = modules
shared["chapter_order"] = sorted(
    chapter_order,
    key=lambda idx: (
        -modules[idx]["original_path"].count("/") - modules[idx]["original_path"].count(os.sep),
        modules[idx]["original_path"].lower(),
    ),
)
shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
emit("DONE_DETERMINISTIC_MAPPER", count=len(modules))
return "default"

    The reverse directory depth sort (-count('/') - count(os.sep)) ensures utility and leaf modules are documented first. This enables their generated summaries to be included in the context when drafting subsequent orchestration chapters.

    IdentifyAbstractions

    Visibility: Public
    Base Class: pocketflow.Node

    Description: Executes direct single-pass abstraction discovery when repository token counts fall within context window limits. Prompts the LLM to identify high-level conceptual components, their descriptions, and their associated file indices.

    IdentifyAbstractions.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple

    Description: Prepares the full codebase context, truncating gracefully if the token limit is exceeded, and packages project configuration parameters into an 11-element tuple.

    Parameters: * shared (dict): The global workflow state.

    Returns: * tuple: (context, directory_tree, total_files_count, project_name, language, use_cache, max_abstraction_num, thinking_level, advanced_mode, max_tokens, mode).

    Example: 

    def prep(self, shared):
    files_data = shared["files"]
    project_name = shared["project_name"]
    language = shared.get("language", "english")
    use_cache = shared.get("use_cache", True)
    max_abstraction_num = shared.get("max_abstraction_num", 10)
    thinking_level = shared.get("thinking_level", None)

    def create_llm_context(files_data):
        max_tokens = resolve_max_tokens(shared)
        safety_limit = int(max_tokens * 0.95)
        count_tokens = create_token_counter()
        context = ""
        current_tokens = 0
        for i, (path, content) in enumerate(files_data):
            entry = f"--- File Index {i}: {path} ---\n{content}\n\n"
            entry_tokens = count_tokens(entry)
            if current_tokens + entry_tokens > safety_limit:
                emit("WARN_CONTEXT_TRUNCATED", index=i, path=path, limit=safety_limit)
                break
            context += entry
            current_tokens += entry_tokens
        return context

    context = create_llm_context(files_data)
    directory_tree = build_directory_tree(files_data)
    return (
        context,
        directory_tree,
        len(files_data),
        project_name,
        language,
        use_cache,
        max_abstraction_num,
        thinking_level,
        shared.get("advanced_mode", False),
        shared.get("max_tokens", 100000),
        shared.get("mode", "tutorial"),
    )

    The nested create_llm_context() helper accumulates file entries up to the safety limit. If the content exceeds this threshold, it emits a WARN_CONTEXT_TRUNCATED diagnostic and stops appending files.

    IdentifyAbstractions.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> list[dict[str, Any]]

    Description: Formats the abstraction prompt with target language instructions, dispatches inference through call_llm(), parses the YAML response, and validates each abstraction object and its file index ranges.

    Parameters: * prep_res (tuple): 11-element parameter tuple from prep().

    Returns: * list[dict[str, Any]]: List of abstraction dictionaries containing name, description, and files (sorted list of unique integer indices).

    Raises: * ValueError: If the response fails schema validation (missing keys, non-string names, or invalid structure).

    Example: 

    # Validation of abstraction indices
validated_indices = []
for idx_entry in item["file_indices"]:
    try:
        idx_str = str(idx_entry).split("#")[0].strip()
        if "-" in idx_str:
            parts = idx_str.split("-")
            if len(parts) == 2:
                start_idx = int(re.findall(r"\d+", parts[0])[0])
                end_idx = int(re.findall(r"\d+", parts[1])[0])
                validated_indices.extend(idx for idx in range(start_idx, end_idx + 1) if 0 <= idx < total_files_count)
                continue
        nums = re.findall(r"\d+", idx_str)
        if nums:
            idx = int(nums[0])
            if 0 <= idx < total_files_count:
                validated_indices.append(idx)
    except (ValueError, TypeError, IndexError):
        emit("WARN_PARSE_INDEX", entry=idx_entry, name=item["name"])

    AnalyzeRelationships.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple

    This method builds a budget-aware context through a two-pass allocation algorithm.

    Phase 1: Budget Initialization and File Sizing

    sized = []
    for idx in abstr["files"]:
        if 0 <= idx < len(files_data):
            path, file_content = files_data[idx]
            entry = f"\\n--- File: {idx} # {path} ---\\n{file_content}\\n"
            sized.append((idx, path, file_content, estimate_tokens(entry)))
    sized.sort(key=lambda x: x[3], reverse=True)
    abstr_file_data.append(sized)
    The algorithm calculates the available token budget and computes the exact token weight of every file associated with each abstraction, sorting them by size in descending order.

    Phase 2: Two-Pass Fair Allocation and Unused Budget Redistribution

    per_abstr_budget = total_budget // max(num_abstractions, 1)
included_indices = set()
abstr_results = []

for _i, sized in enumerate(abstr_file_data):
    budget = per_abstr_budget
    included_files = []
    remaining_files = []
    for idx, path, file_content, tokens in sized:
        if idx in included_indices:
            included_files.append((idx, path, None, 0))
            continue
        if tokens <= budget:
            included_files.append((idx, path, file_content, tokens))
            budget -= tokens
            included_indices.add(idx)
        else:
            remaining_files.append((idx, path, file_content, tokens))
    abstr_results.append((included_files, remaining_files, budget))

total_unused = sum(r[2] for r in abstr_results)
if total_unused > 0:
    for i, (included_files, remaining_files, _unused) in enumerate(abstr_results):
        if not remaining_files or total_unused <= 0:
            continue
        still_remaining = []
        for idx, path, file_content, tokens in remaining_files:
            if idx in included_indices:
                included_files.append((idx, path, None, 0))
                continue
            if tokens <= total_unused:
                included_files.append((idx, path, file_content, tokens))
                total_unused -= tokens
                included_indices.add(idx)
            else:
                still_remaining.append((idx, path, file_content, tokens))
        abstr_results[i] = (included_files, still_remaining, 0)
    Pass 1 assigns an equal share (per_abstr_budget) to each abstraction. Pass 2 redistributes leftover tokens (total_unused) to abstractions with files that exceeded their initial allotment, ensuring full file contexts are included wherever capacity permits.

    sections = parsed.get("sections", parsed) if isinstance(parsed, dict) else None
    if sections:
        grouped_modules = collect_all_modules(sections)
        ungrouped = [cf["module_name"] for cf in chapter_files if cf["module_name"] not in grouped_modules]
        if ungrouped:
            sections.append({"name": "Other", "modules": ungrouped})
        nav_lines = build_grouped_nav(sections, chapter_files, indent=4)
        nav_lines.insert(0, "    - api/index.md")
        nav_snippet = f"nav:\n  - {nav_label}:\n" + "\n".join(nav_lines)

    The method calls build_mkdocs_config() and build_mermaid_init_js() from utils/prompts.py to generate static site assets, writing each file to disk with directory safety checks (os.makedirs).

    Error Handling

    The nodes in nodes.py use defensive validation, structured exception propagation, and non-blocking recovery patterns:

    1. LLM Node Retry Propagation: All node exec() methods wrap model calls in try...except blocks. If an error occurs, the node emits a localized NODE_RETRY_ERROR diagnostic, logs the stack trace to llm_logger, and re-raises the exception. This triggers PocketFlow's built-in retry mechanism (up to 5 retries with exponential backoff). 

      except Exception as e:
    emit("NODE_RETRY_ERROR", class_name=self.__class__.__name__, error=e)
    llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
    raise e

    2. YAML Extraction and Parsing Resilience: parse_yaml_response() extracts content between ```yaml and ``` fences. If an LLM omits fences, generates invalid YAML, or truncates its response, the parser raises a ValueError indicating the failure, causing the node to retry.

    3. Index Boundary and Syntax Sanitization: Nodes that parse index references (IdentifyAbstractions, AnalyzeRelationships, OrderChapters) account for common LLM output variations, including range syntax ("2-5"), comment strings ("3 # auth.py"), and non-numeric characters using regex (re.findall(r"\d+", ...)). Indices that fall outside valid array bounds are dropped with a WARN_INVALID_RELATIONSHIP warning rather than raising fatal index errors.

    4. Context Window Safety Margins: ContextRouter, IdentifyAbstractions, and AnalyzeRelationships enforce a safety_limit set to 95% of maximum model tokens. If input sizes exceed this limit, prompts are truncated cleanly at file boundaries accompanied by a WARN_CONTEXT_TRUNCATED diagnostic.

    5. Navigation Grouping Fallback: In CombineTutorial, if LLM-assisted navigation grouping fails during API reference compilation, the error is caught, logged via llm_logger.warning(), and the node falls back to the deterministic, directory-based navigation structure prepared during prep().
