    flow

    File Path: flow.py

    Overview

    The flow module defines the core directed acyclic graph (DAG) workflow for the Codebase-Knowledge-Builder using the pocketflow framework. It configures and links all execution nodes responsible for repository fetching, context routing, abstraction mapping, chapter sequencing, content writing, and tutorial synthesis.

    Depending on the context routing strategy selected during execution (direct, batch, or deterministic), the workflow dynamically branches to process codebase contexts of varying sizes before converging to write chapters and assemble the final tutorial.

    Functions

    create_tutorial_flow()

    Visibility: Public
    Signature: def create_tutorial_flow() -> Flow:

    Description:
    Instantiates and configures the pocketflow.Flow computational graph for the tutorial generation pipeline. It initializes all workflow nodes with operational parameters (such as max_retries=5 and wait=20 seconds for LLM-bound operations) and sets up the node routing topology:

    1. Initialization: Creates instances of FetchRepo, ContextRouter, MapAbstractions, ReduceAbstractions, IdentifyAbstractions, AnalyzeRelationships, OrderChapters, WriteChapters, CombineTutorial, and DeterministicFileMapper.
    2. Repository Fetch & Routing: Connects FetchRepo to ContextRouter.
    3. Branching Paths:
    4. "direct" route: Routes to IdentifyAbstractions for codebases fitting in single-prompt contexts.
    5. "batch" route: Routes to MapAbstractions followed by ReduceAbstractions for larger multi-batch codebases.
    6. "deterministic" route: Routes to DeterministicFileMapper for file-by-file deterministic chapter mappings.
    7. Synthesis & Convergence:
    8. Connects IdentifyAbstractions and ReduceAbstractions into AnalyzeRelationships.
    9. Connects AnalyzeRelationships to OrderChapters, which leads into WriteChapters.
    10. Connects DeterministicFileMapper directly into WriteChapters.
    11. Routes WriteChapters into CombineTutorial for the final markdown aggregation.

    Parameters:
    None

    Returns:
    * Flow: An initialized pocketflow.Flow pipeline with FetchRepo configured as the entry point node (start).

    Raises:
    None directly raised during declaration.*

    Example: 

    from flow import create_tutorial_flow

# Instantiate the pipeline
tutorial_flow = create_tutorial_flow()

# Execute the flow with shared context dictionary
shared_context = {
    "repo_path": "https://github.com/example/repo",
    "output_dir": "./output"
}
tutorial_flow.run(shared_context)
