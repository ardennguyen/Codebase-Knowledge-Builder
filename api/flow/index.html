    flow

    File Path: flow.py

    Overview

    The flow.py module defines the workflow orchestration layer of the Codebase-Knowledge-Builder system. It constructs a declarative directed acyclic graph (DAG) using the pocketflow framework to automate the end-to-end extraction, analysis, structuring, and synthesis of codebase documentation and tutorials.

    The module provides a single factory function, create_tutorial_flow(), which initializes pipeline execution nodes defined in nodes and wires them together with deterministic and conditional branching edges. The pipeline dynamically routes execution based on repository token limits and processing strategies, handling three distinct architectural workflows:

    1. Direct Path: For smaller codebases that fit within standard context windows, routing directly to single-pass abstraction identification.
    2. Batch (Map-Reduce) Path: For large repositories that exceed token limits, breaking files into chunks, mapping abstractions in parallel/batches, and reducing them into a unified concept list.
    3. Deterministic Path: For structured 1:1 file-to-chapter generation, bypassing dynamic concept discovery to build dedicated documentation chapters per source file.

    Module-Level Functions

    create_tutorial_flow()

    Visibility: Public
    Signature: def create_tutorial_flow() -> Flow

    Description:
    Instantiates and interconnects all execution nodes required to process a codebase into a cohesive multi-chapter tutorial. Nodes interacting with external Large Language Model (LLM) APIs are configured with exponential backoff and retry parameters (max_retries=5, wait=20) to ensure network resilience and handle API rate limits.

    The pipeline defines directional connections using pocketflow's overloaded shift (>>) and minus (-) operators: * >> establishes an unconditional sequential transition between two nodes. * - "action" >> establishes a conditional transition triggered when the upstream node returns a specific routing action string ("direct", "batch", or "deterministic").

    Parameters:
    * None.

    Returns:
    * Flow: An initialized pocketflow.Flow instance configured with FetchRepo as its root entry node (start=fetch_repo).

    Raises:
    * Does not raise exceptions during graph construction. Runtime exceptions during flow execution are managed by individual node retry policies and PocketFlow's execution runner.

    Example: 

    def create_tutorial_flow():
    fetch_repo = FetchRepo()
    context_router = ContextRouter()
    map_abstractions = MapAbstractions(max_retries=5, wait=20)
    reduce_abstractions = ReduceAbstractions(max_retries=5, wait=20)
    identify_abstractions = IdentifyAbstractions(max_retries=5, wait=20)
    analyze_relationships = AnalyzeRelationships(max_retries=5, wait=20)
    order_chapters = OrderChapters(max_retries=5, wait=20)
    write_chapters = WriteChapters(max_retries=5, wait=20)
    combine_tutorial = CombineTutorial()
    deterministic_mapper = DeterministicFileMapper(max_retries=5, wait=20)

    fetch_repo >> context_router

    context_router - "direct" >> identify_abstractions
    context_router - "batch" >> map_abstractions
    context_router - "deterministic" >> deterministic_mapper

    map_abstractions >> reduce_abstractions

    identify_abstractions >> analyze_relationships
    reduce_abstractions >> analyze_relationships

    analyze_relationships >> order_chapters
    order_chapters >> write_chapters

    deterministic_mapper >> write_chapters

    write_chapters >> combine_tutorial

    return Flow(start=fetch_repo)

    The function begins by instantiating the ingestion nodes: FetchRepo, which retrieves the target repository files (from either local storage or GitHub), and ContextRouter, which calculates total token volume to determine the processing strategy. It configures LLM-dependent nodes (MapAbstractions, ReduceAbstractions, IdentifyAbstractions, AnalyzeRelationships, OrderChapters, WriteChapters, DeterministicFileMapper) with a 5-retry limit and a 20-second wait interval between retries.

    Next, it defines the routing branches using PocketFlow's syntax. ContextRouter evaluates the token context size and emits an action: * If "direct" is emitted, control transitions to IdentifyAbstractions, extracting high-level system components in a single prompt. * If "batch" is emitted, control transitions to MapAbstractions, which analyzes file subsets independently before forwarding results to ReduceAbstractions to synthesize overlapping abstractions. * If "deterministic" is emitted, control routes to DeterministicFileMapper to generate fixed chapter definitions mapping 1:1 with files in the codebase.

    Following abstraction resolution, both the direct and batch branches converge at AnalyzeRelationships to generate cross-component dependency diagrams, followed by OrderChapters to sequence chapters pedagogically. Both the ordered dynamic chapters and deterministic file chapters flow into WriteChapters to draft full Markdown tutorials. Finally, WriteChapters streams its outputs into CombineTutorial, which assembles the complete index, navigations, and output documents.

    Detailed Node Configuration and Roles

    Node Instance Class Type Retry Config Execution Role Upstream Dependency
    fetch_repo FetchRepo Default Fetches codebase files from GitHub or local disk. Pipeline Entrypoint
    context_router ContextRouter Default Computes total token count; routes to dynamic or deterministic pipelines. fetch_repo
    identify_abstractions IdentifyAbstractions retries=5, wait=20s Discovers abstractions directly from small repositories. context_router ("direct")
    map_abstractions MapAbstractions retries=5, wait=20s Discovers abstractions across chunked file batches. context_router ("batch")
    reduce_abstractions ReduceAbstractions retries=5, wait=20s Merges chunked abstraction sets into a consolidated list. map_abstractions
    deterministic_mapper DeterministicFileMapper retries=5, wait=20s Constructs fixed 1:1 file-to-chapter outlines. context_router ("deterministic")
    analyze_relationships AnalyzeRelationships retries=5, wait=20s Maps interactions and dependencies among identified abstractions. identify_abstractions or reduce_abstractions
    order_chapters OrderChapters retries=5, wait=20s Determines pedagogical chapter sequence for tutorials. analyze_relationships
    write_chapters WriteChapters retries=5, wait=20s Writes comprehensive technical chapters in Markdown. order_chapters or deterministic_mapper
    combine_tutorial CombineTutorial Default Compiles chapters into final tutorial documents and saves them to disk. write_chapters
