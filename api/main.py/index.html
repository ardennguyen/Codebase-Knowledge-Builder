    main.py

    Source: main.py

    Technical Overview

    Building upon the declarative workflow definitions in flow.py, main.py serves as the primary command-line interface (CLI) entry point and operational coordinator for the Codebase-Knowledge-Builder system. It manages the runtime initialization sequence, command-line parameter parsing, environment variable loading via dotenv, and pre-flight validation. Before any network requests or file crawling operations begin, the module enforces configuration consistency across language model providers, reasoning effort profiles, file filtering patterns, and output modes.

    The execution lifecycle transitions through distinct operational phases: parsing arguments, resolving reasoning plans, initializing internationalized diagnostic outputs, validating credentials, preparing execution state, invoking the workflow graph, and executing guaranteed teardown. The module instantiates a shared state dictionary (shared_store) and passes it into the PocketFlow graph returned by create_tutorial_flow(). A centralized try...finally block ensures that cumulative token consumption ledgers, estimated dollar costs, and log handles are flushed and emitted even when an unhandled exception or user interrupt terminates the pipeline prematurely.

    Additionally, main.py provides standalone maintenance routines. When invoked with --cleanup, it purges persistent LLM response caches, token calibration data, and log directories from disk. The following diagram illustrates the complete control flow, validation gates, and execution boundaries managed by main.py.

    def parse_arguments():
    """Parse and return command-line arguments."""
    parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Source: --repo or --dir (mutually exclusive but not required if --cleanup is used)
    source_group = parser.add_mutually_exclusive_group()
    source_group.add_argument("--repo", help="URL of the public GitHub repository.")
    source_group.add_argument("--dir", help="Path to local directory.")
    parser.add_argument("--cleanup", action="store_true", help="Clean up logs and cache files. Can be used standalone or after a run.")

    parser.add_argument("-n", "--name", help="Project name (optional, derived from repo/directory if omitted).")
    parser.add_argument("-t", "--token", help="GitHub personal access token (optional, reads from GITHUB_TOKEN env var if not provided).")
    parser.add_argument("-o", "--output", default="output", help="Base directory for output (default: ./output).")
    parser.add_argument("-i", "--include", nargs="+", help="Files to include (e.g., '*.py' '*.js'). Defaults to '*' (all files).")
    parser.add_argument(
        "-e",
        "--exclude",
        nargs="+",
        help="Files to exclude. Custom patterns are automatically merged with a massive global exclusion list (build caches, node_modules, binaries, media, AI environments) AND your repository's native .gitignore rules.",
    )
    # ...
    parser.add_argument("--batch", type=int, default=50, help="Maximum files per batch when using map-reduce mode (default: 50).")
    parser.add_argument("--force-batch", action="store_true", help="Force map-reduce mode regardless of context size.")
    parser.add_argument("--debug", action="store_true", help="Enable verbose debug output.")

    return parser, parser.parse_args()

    The function establishes validation invariants across mutually exclusive groups and typed converters. Ingestion targets --repo and --dir are configured inside a mutually exclusive group, though neither is marked mandatory at the parser level to allow standalone --cleanup invocations. Specialized converters like _thinking_level_arg are attached to individual arguments to intercept and normalize values before they enter the runtime pipeline.

    resolve_mode_and_project(args)

    Visibility: Public Signature: def resolve_mode_and_project(args):

    Description: Resolves documentation generation modes and derives canonical project names. It maintains backward compatibility with the legacy --advanced flag, issuing a localized warning if both --advanced and an explicit --mode are specified. If the user omits an explicit project name (-n/--name), the function extracts the basename of the local directory path or derives the repository slug from a GitHub URL (stripping trailing .git extensions). If no source is specified, it defaults to "project".

    Parameters: * args (argparse.Namespace): Parsed command-line arguments.

    Returns: * tuple[str, str]: A 2-tuple containing the resolved documentation mode ("tutorial", "advanced", "api-reference", or "sdk") and the resolved project name string.

    Example: 

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1].removesuffix(".git")
        else:
            project_name = "project"
    return mode, project_name

    The resolution logic prioritizes explicit command-line input while ensuring deterministic fallbacks. For local directories, os.path.abspath normalizes relative paths before extracting the final path segment via os.path.basename. For remote URLs, trailing slashes are trimmed, and URL segments are split to isolate the Git repository slug. This ensures that downstream file paths, log files, and cache manifests use consistent identifiers.

    build_shared_store(args, github_token, mode, thinking_plan, project_name)

    Visibility: Public Signature: def build_shared_store(args, github_token, mode, thinking_plan, project_name):

    Description: Assembles and returns the initial state dictionary passed to the PocketFlow workflow engine. It consolidates inputs from the parsed CLI namespace, environment-resolved credentials, normalized file inclusion/exclusion sets, reasoning effort plans, and runtime mode flags. It also initializes placeholder containers (files, abstractions, relationships, chapter_order, chapters) that downstream pipeline nodes populate as processing progresses.

    Parameters: * args (argparse.Namespace): Parsed CLI arguments from parse_arguments(). * github_token (str | None): Authenticated GitHub personal access token, if resolved. * mode (str): Resolved documentation mode string. * thinking_plan (dict[str, str | None]): Mapping of pipeline node keys to normalized thinking effort levels. * project_name (str): Canonical project name resolved via resolve_mode_and_project().

    Returns: * dict: The shared store dictionary containing configuration options and empty output slots.

    Example: 

    def build_shared_store(args, github_token, mode, thinking_plan, project_name):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": project_name,  # Resolved once in main so logs, --force-rebuild and output agree
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities: global level (legacy) + per-node plan (utils/thinking.py)
        "thinking_level": args.thinking_level,
        "thinking_plan": thinking_plan,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    The resulting dictionary serves as the single source of truth across all PocketFlow graph operations. File exclusion patterns merge user-provided sequences directly with DEFAULT_EXCLUDE_PATTERNS using set union semantics, ensuring standard build caches, virtual environments, binary files, and media directories are excluded by default. Output slots are initialized to empty collections to allow pipeline nodes to inspect state without encountering KeyError exceptions.

    detect_llm_config(args)

    Visibility: Public Signature: def detect_llm_config(args):

    Description: Discovers active LLM provider configurations, models, base endpoints, credentials, and context window limits. It invokes resolve_llm_settings() from utils.llm_config to read environment settings, then determines the token context ceiling by prioritizing the explicit --max-tokens CLI parameter over the model context length returned by get_model_context_length().

    Parameters: * args (argparse.Namespace): Parsed CLI arguments containing optional context token overrides.

    Returns: * tuple[str, str, str, str, int]: A 5-tuple consisting of (provider, model_name, endpoint_url, api_key, context_length).

    Example: 

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.llm_config import get_model_context_length

    provider, model_name, endpoint_url, api_key = resolve_llm_settings()
    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length

    This function links static CLI parameters with dynamic environment configuration. By deferring the import of get_model_context_length, the module minimizes startup overhead when running standalone commands like --cleanup. If --max-tokens is set, dynamic remote inspection of model limits is skipped, which helps when operating in air-gapped environments or behind custom proxy configurations.

    resolve_thinking_plan(args)

    Visibility: Public Signature: def resolve_thinking_plan(args):

    Description: Compiles a per-node thinking plan dictionary without triggering side effects or console emissions. It resolves the documentation mode, parses command-line overrides via parse_overrides(), and identifies the active thinking profile using resolve_profile_name(). If a global --thinking-level is set, the profile is labeled "global". The function then calls build_thinking_plan() to compute the final mapping of node keys to thinking effort levels.

    Parameters: * args (argparse.Namespace): Parsed CLI arguments containing thinking flags (--thinking-level, --thinking-profile, --thinking-override, --mode, --advanced).

    Returns: * tuple[str, dict[str, str | None], list[str]]: A 3-tuple containing the resolved profile name (str), the compiled node-to-effort dictionary (dict[str, str | None]), and a list of any invalid override strings encountered (list[str]).

    Example: 

    def resolve_thinking_plan(args):
    """Build the per-node thinking plan from --thinking-override / --thinking-level / --thinking-profile.

    Pure (no emit): runs before init_output(). Validation messages come from _validate_thinking_args().

    Returns:
        tuple[str, dict, list[str]]: (resolved profile name, {node_key: level | None}, invalid override strings)
    """
    mode = "advanced" if args.advanced else args.mode
    overrides, invalid = parse_overrides(args.thinking_override)
    profile = "global" if args.thinking_level else resolve_profile_name(args.thinking_profile, resolve_llm_settings()[0])
    return profile, build_thinking_plan(profile, mode, args.thinking_level, overrides), invalid

    The function remains purely computational with no side effects. This design ensures it can run before utils.output.init() is called, which is necessary because the output subsystem's automated translation routine uses the reasoning effort assigned to translate_strings in the returned plan. Any malformed overrides collected in the invalid list are passed to _validate_thinking_args() for formatted error reporting once the logging system is ready.

If --repo is targeted, it reads the access token from -t/--token or the GITHUB_TOKEN environment variable, logging a warning if neither is found.     Internal Helpers

    _thinking_level_arg(value)

    Visibility: Private Signature: def _thinking_level_arg(value):

    Description: Custom validator and type converter for the --thinking-level argument in argparse. It strips leading and trailing whitespace and converts inputs to lowercase. Empty strings or "default" map to None, indicating the provider's default reasoning level should be used. If the value is not in THINKING_LEVELS, it raises an argparse.ArgumentTypeError.

    Parameters: * value (str): Raw string value passed on the command line.

    Returns: * str | None: Validated thinking level string from THINKING_LEVELS, or None if default behavior was selected.

    Raises: * argparse.ArgumentTypeError: If the input does not match "default", an empty string, or an allowed value in THINKING_LEVELS.

    Example: 

    def _thinking_level_arg(value):
    """argparse type for --thinking-level: a level from THINKING_LEVELS; '' or 'default' → None (model default)."""
    level = value.strip().lower()
    if level in ("", "default"):
        return None
    if level not in THINKING_LEVELS:
        raise argparse.ArgumentTypeError(f"invalid choice: {value!r} (choose from {', '.join(THINKING_LEVELS)}, default)")
    return level

    This helper standardizes command-line values before they enter the argument namespace. By mapping empty strings and "default" directly to None, it unifies the handling of model-native default reasoning configurations across Anthropic Claude, Google Gemini, and OpenRouter backends.

    _check_quoting_errors(parser, args)

    Visibility: Private Signature: def _check_quoting_errors(parser, args):

    Description: Detects shell quoting errors where values passed to -e/--exclude or -i/--include accidentally swallow subsequent command-line flags. When glob patterns are misquoted in shells (for example, --exclude "dist/* "src/*" --language Vietnamese), unescaped quotes can cause the shell to treat subsequent flags as part of the pattern string. This function extracts all valid option flags directly from the ArgumentParser instance and checks if any pattern contains an embedded flag string. If a collision is detected, it emits an ERROR_QUOTING diagnostic and exits immediately with status code 1.

    Parameters: * parser (argparse.ArgumentParser): The argument parser instance containing all registered option flags. * args (argparse.Namespace): Parsed command-line arguments containing exclude and include pattern lists.

    Returns: * None

    Raises: * SystemExit: Terminated with status 1 if a swallowed flag is found inside a pattern.

    Example: 

    def _check_quoting_errors(parser, args):
    """Detect shell quoting errors where --exclude/--include values accidentally swallowed other CLI flags.

    When users misquote patterns (e.g., --exclude "autogen/* "SmartFO/*" --language Vietnamese),
    the shell merges subsequent flags into the pattern value. This silently causes ALL following
    arguments to be ignored. We detect this by checking if any pattern value contains a known
    CLI flag string, which no legitimate file/directory pattern would ever contain.

    Flags are extracted dynamically from the argparse parser — no hardcoded list to maintain.
    """
    # Extract all registered flags (both --long and -short) from the parser
    known_flags = set()
    for action in parser._actions:
        for opt in action.option_strings:
            known_flags.add(opt)

    for pattern_list, flag_name in [(args.exclude, "--exclude"), (args.include, "--include")]:
        if not pattern_list:
            continue
        for pattern in pattern_list:
            for known_flag in known_flags:
                if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
                    emit(
                        "ERROR_QUOTING",
                        flag=flag_name,
                        pattern=pattern[:120],
                        embedded=known_flag,
                    )
                    sys.exit(1)

    This safety check dynamically inspects the parser's registered option_strings to discover flags without requiring a hardcoded list. By checking for space-delimited flag occurrences or trailing flag suffixes within individual pattern elements, it detects swallowed CLI parameters early and prevents silent misconfigurations during crawling operations.

    def _validate_thinking_args(args, invalid_overrides):
    """Report malformed --thinking-override values (fatal), overrides for nodes the mode never runs,
    and --thinking-level/--thinking-profile conflicts."""
    if invalid_overrides:
        emit("ERROR_THINKING_OVERRIDE", value=", ".join(invalid_overrides), nodes=", ".join(NODE_KEYS), levels=", ".join(THINKING_LEVELS))

        emit("WARN_THINKING_LEVEL_OVERRIDES_PROFILE", level=args.thinking_level, profile=args.thinking_profile)

    The function runs after output logging is initialized, allowing validation diagnostics to be recorded in persistent log files. It inspects the active mode's registered node sequence via MODE_NODES[mode] to warn users when they override reasoning effort on nodes that will never execute in the selected documentation mode.

    Error Handling

    Command-Line Quoting Error Trapping

    The _check_quoting_errors() helper mitigates a common shell mistake where missing or unescaped quotes in -e/--exclude or -i/--include patterns cause the shell to treat subsequent CLI flags as glob strings. Because the parser's registered option_strings are dynamically extracted from parser._actions, any occurrence of a known flag string (e.g., " --language") within a pattern triggers an immediate error emission via ERROR_QUOTING and exits execution with code 1:

    for pattern_list, flag_name in [(args.exclude, "--exclude"), (args.include, "--include")]:
    if not pattern_list:
        continue
    for pattern in pattern_list:
        for known_flag in known_flags:
            if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
                emit(
                    "ERROR_QUOTING",
                    flag=flag_name,
                    pattern=pattern[:120],
                    embedded=known_flag,
                )
                sys.exit(1)

    Fail-Fast Provider Authentication Verification

    To prevent unnecessary file crawling or token budgeting work when credentials are invalid, main() calls check_llm_auth() before starting ingestion:

    # Fail fast (with setup instructions) before crawling if the configured provider cannot authenticate
if not check_llm_auth():
    sys.exit(1)

    If the active provider's API key, project identity, or SDK installation is missing, check_llm_auth() emits provider-specific setup instructions and returns False, causing main() to exit immediately with status 1.

    Defensive Argument Validation

    The _validate_thinking_args() helper guards against invalid thinking level overrides before pipeline execution begins: * Malformed Overrides: If parse_overrides() flags syntax issues (e.g., missing = separators or invalid levels), the function emits ERROR_THINKING_OVERRIDE listing all valid nodes and thinking tiers, then exits with code 1. * Inactive Node Warnings: If an override targets a node not used by the selected documentation mode (such as specifying reduce_abstractions=high in api-reference mode), the function logs WARN_THINKING_OVERRIDE_UNUSED with the list of active nodes for that mode. * Conflicting Settings: If both a global --thinking-level and a non-default --thinking-profile are specified, it logs WARN_THINKING_LEVEL_OVERRIDES_PROFILE to explain that the global level takes precedence.

    Guaranteed Telemetry and Teardown

    Workflow execution and post-run cleanup are wrapped in a comprehensive try...finally block inside main(). This guarantees that usage reporting and logging teardown run even if the pipeline encounters network errors or keyboard interrupts:

    try:
    tutorial_flow.run(shared)

    # Cleanup after run if requested
    if args.cleanup:
        _run_cleanup()
finally:
    from utils.output import shutdown

    # Report spend even when the run fails — failed runs are often the expensive ones.
    try:
        _emit_usage_summary()
    except Exception as e:
        emit_raw("WARNING", f"Usage summary failed: {e}", dest="LOG")
    shutdown()

    If _emit_usage_summary() fails due to an unexpected accounting error, the exception is caught and recorded to the log file via emit_raw, allowing shutdown() to proceed and cleanly close all stream handlers.
