    main.py

    Source: main.py

    This module serves as the primary Command-Line Interface (CLI) bootstrap, configuration parser, and runtime orchestrator for the Codebase-Knowledge-Builder documentation pipeline. While flow.py defines the directed acyclic graph (DAG) structure and node lifecycles under the PocketFlow framework, main.py initializes the execution environment, parses and validates user-supplied flags, resolves environment-based LLM configurations, constructs the global shared store, and executes the compiled pipeline.

    Technical Overview

    main.py provides an end-to-end operational harness for processing either remote GitHub repositories or local directory structures into structured technical documentation. Its execution lifecycle consists of several distinct stages:

    1. Environment & Argument Parsing: Reads local environment variables via python-dotenv, parses CLI flags via argparse.ArgumentParser, and sets up global terminal output strategies via utils.output.init.
    2. Mode & Entity Resolution: Normalizes documentation generation styles (e.g., resolving legacy --advanced flags into explicit --mode styles such as tutorial, advanced, api-reference, or sdk) and derives project identifiers from repository URLs or local filesystem paths.
    3. LLM Provider & Context Discovery: Inspects runtime environment variables (LLM_PROVIDER, GEMINI_*, etc.) and determines the target LLM provider, base endpoint, model name, and context window token constraints via utils.call_llm.get_model_context_length.
    4. Validation & State Initialization: Enforces business constraints (such as restricting --incremental caching and --force-rebuild operations to api-reference mode) and initializes the shared memory dictionary (shared) used across all PocketFlow nodes.
    5. Flow Execution & Cleanup: Configures file and console logging via utils.output.configure_logging, triggers flow.create_tutorial_flow().run(shared), and executes optional cache and log purges when --cleanup is invoked.

    parse_arguments()

    Visibility: Public
    Signature: def parse_arguments() -> tuple[argparse.ArgumentParser, argparse.Namespace]:

    Description:
    Constructs and configures the CLI argument parser using Python's standard argparse module. Defines mutually exclusive source groups (--repo and --dir), output paths, inclusion/exclusion rules, context window token budgets, thinking effort parameters, generation modes, and execution flags. Returns both the parser instance (used for raising standard CLI validation errors) and the parsed Namespace object.

    Parameters:
    * None.

    Returns:
    * tuple[argparse.ArgumentParser, argparse.Namespace]: A 2-tuple containing the configured ArgumentParser instance and the resulting parsed Namespace containing all CLI options.

    Raises:
    * SystemExit: Automatically triggered by argparse if unrecognized flags are passed or --help is requested.

    Example: 

    # From main.py: main()
parser, args = parse_arguments()
init_output(
    language=args.language,
    use_cache=not args.no_cache,
    thinking_level=args.thinking_level,
)

    The parse_arguments() function configures CLI parameters across functional groups: source location (--repo, --dir), runtime maintenance (--cleanup), metadata overrides (--name, --token, --output), filtering constraints (--include, --exclude, --max-size), LLM generation behaviors (--language, --no-cache, --max-abstractions, --thinking-level, --max-tokens), documentation modes (--mode, --advanced, --mkdocs, --incremental, --force-rebuild), and execution controls (--batch, --force-batch, --debug). Mutually exclusive groups ensure users cannot pass both a remote repository URL and a local directory path simultaneously, maintaining deterministic ingest boundaries.

    resolve_mode_and_project()

    Visibility: Public
    Signature: def resolve_mode_and_project(args: argparse.Namespace) -> tuple[str, str]:

    Description:
    Resolves the active documentation mode and extracts a normalized project name. If the legacy --advanced flag is detected, it overrides the default tutorial mode (emitting a warning if an explicit conflicting --mode was passed). If no explicit project name is supplied via -n/--name, the function derives the project name from the base directory name of --dir or the final path segment of --repo.

    Parameters:
    * args (argparse.Namespace): The parsed CLI arguments namespace.

    Returns:
    * tuple[str, str]: A 2-tuple of (mode, project_name).

    Raises:
    * None internally.

    Example: 

    # From main.py: resolve_mode_and_project implementation
def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1]
        else:
            project_name = "project"
    return mode, project_name

    resolve_mode_and_project provides backward compatibility for legacy workflows while standardizing project naming across varied input sources. When --advanced is active alongside a conflicting --mode argument (such as --mode api-reference), the function invokes emit("WARN_ADVANCED_OVERRIDES_MODE") to alert the user before forcing the mode string to "advanced". If the project name is omitted, it parses local directory paths via os.path.abspath to resolve relative references (like .), strips trailing slashes from GitHub URLs to extract repository identifiers cleanly, or defaults to the fallback string "project".

    build_shared_store()

    Visibility: Public
    Signature: def build_shared_store(args: argparse.Namespace, github_token: str | None, mode: str) -> dict[str, Any]:

    Description:
    Constructs the central shared state dictionary passed between PocketFlow nodes throughout the pipeline lifecycle. It combines CLI flags, merges custom exclusion patterns with utils.exclude_patterns.DEFAULT_EXCLUDE_PATTERNS, inverts cache control flags, sets generation constraints, and allocates empty collection slots (files, abstractions, relationships, chapter_order, chapters) to be populated by downstream processing nodes.

    Parameters:
    * args (argparse.Namespace): The parsed command-line arguments. * github_token (str | None): The resolved GitHub Personal Access Token, or None if unauthenticated/local. * mode (str): The resolved documentation mode string.

    Returns:
    * dict[str, Any]: The shared dictionary containing all configuration parameters and mutable state containers for the execution graph.

    Raises:
    * None internally.

    Example: 

    # From main.py: build_shared_store implementation
def build_shared_store(args, github_token, mode):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    The dictionary returned by build_shared_store serves as the sole shared state across all PocketFlow nodes in nodes.py. It unions any user-provided --exclude arguments with the built-in DEFAULT_EXCLUDE_PATTERNS set, ensuring standard build directories, binaries, and virtual environments are excluded regardless of CLI input. It also maps flags such as --no-cache to positive boolean flags (use_cache: not args.no_cache) and creates empty mutable structures for intermediate artifacts such as extracted file representations and abstract semantic models.

    detect_llm_config()

    Visibility: Public
    Signature: def detect_llm_config(args: argparse.Namespace) -> tuple[str, str, str, str, int]:

    Description:
    Introspects the execution environment to identify the active LLM provider, target model name, base API endpoint URL, and credentials. If LLM_PROVIDER is set, it dynamically resolves provider-prefixed environment variables (e.g., OPENROUTER_MODEL, OPENROUTER_BASE_URL, OPENROUTER_API_KEY). If unset, it falls back to Gemini detection via GEMINI_PROJECT_ID or GEMINI_API_KEY. Finally, it determines the maximum context window length by either honoring --max-tokens or invoking get_model_context_length from utils.call_llm.

    Parameters:
    * args (argparse.Namespace): The parsed command-line arguments (used to check for explicit max_tokens overrides).

    Returns:
    * tuple[str, str, str, str, int]: A 5-tuple containing (provider, model_name, endpoint_url, api_key, context_length).

    Raises:
    * None internally; unresolvable configurations return placeholder "unknown" values and fallback token lengths.

    Example: 

    # From main.py: detect_llm_config implementation
def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.call_llm import get_model_context_length

    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length

    detect_llm_config implements provider detection logic that supports both OpenAI-compatible endpoints and Google AI / Vertex AI infrastructure. When LLM_PROVIDER is specified (e.g., OLLAMA or OPENROUTER), it extracts the associated environment variables based on that prefix. When no generic provider is declared, it inspects Gemini-specific environment variables, defaulting to gemini-3.7-flash and Google's endpoint. The context length calculation defers to args.max_tokens when explicitly set by the user, bypassing network lookups in get_model_context_length.

    display_config()

    Visibility: Public
    Signature: def display_config(args: argparse.Namespace, mode: str, provider: str, model_name: str, endpoint_url: str, context_length: int, log_file: str) -> None:

    Description:
    Formats and emits the active runtime configuration to the console using the localized emit and get functions from utils.output. Displays details including the repository/directory target, AI provider, endpoint, model name, context window token limit, thinking effort level, batch size, output mode, MkDocs integration status, incremental caching status, and log file destination.

    Parameters:
    * args (argparse.Namespace): The parsed CLI arguments namespace. * mode (str): The resolved documentation mode string. * provider (str): The detected LLM provider name. * model_name (str): The active LLM model identifier. * endpoint_url (str): The active LLM endpoint URL. * context_length (int): The maximum context window size in tokens. * log_file (str): The absolute or relative path to the active execution log file.

    Returns:
    * None.

    Raises:
    * None internally.

    Example: 

    # From main.py: display_config implementation
def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))
    else:
        emit("CFG_MAX_ABSTRACTIONS", value=str(args.max_abstractions))
    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block

    display_config standardizes user-facing startup diagnostics by routing all terminal output through the localization template engine in utils.output. It handles mode-specific discrepancies—such as reflecting that max_abstractions is dynamically computed from discovered code modules when running in api-reference mode rather than fixed to a numeric limit. It also formats boolean parameters (such as force_batch, mkdocs, and incremental) into localized Enabled/Disabled strings retrieved via get("CFG_VALUE_ENABLED") and get("CFG_VALUE_DISABLED").

    _run_cleanup()

    Visibility: Private
    Signature: def _run_cleanup() -> None:

    Description:
    Performs filesystem cleanup operations by deleting persisted LLM disk cache files and clearing the runtime log directory. Iterates through known cache paths (llm_cache.json) and removes the directory indicated by the LOG_DIR environment variable (defaulting to ./logs). Emits detailed event logs tracking each deleted artifact and catches filesystem errors to prevent cleanup failures from raising unhandled exceptions.

    Parameters:
    * None.

    Returns:
    * None.

    Raises:
    * Catches all Exception instances during file unlinking and directory tree removal, routing error descriptions through emit("CLEANUP_FAILED", ...).

    Example: 

    # From main.py: _run_cleanup implementation
def _run_cleanup():
    """Clean up cache files and log directory."""
    import shutil

    emit("CLEANUP_START")

    for cache_path in ["llm_cache.json"]:
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                emit("CLEANUP_REMOVED", path=cache_path)
            except Exception as e:
                emit("CLEANUP_FAILED", path=cache_path, error=e)

    log_dir = os.environ.get("LOG_DIR", "logs")
    if os.path.exists(log_dir) and os.path.isdir(log_dir):
        try:
            shutil.rmtree(log_dir)
            emit("CLEANUP_REMOVED_DIR", path=log_dir)
        except Exception as e:
            emit("CLEANUP_FAILED", path=log_dir, error=e)

    _run_cleanup manages filesystem maintenance tasks when invoked via --cleanup (either standalone or as a post-generation step). It targets the persistent cache file (llm_cache.json) generated by utils.call_llm and uses shutil.rmtree to remove accumulated pipeline execution logs. All file deletion operations are wrapped in try/except blocks to guard against permission issues or file lock contention on Windows environments, emitting localized notifications for each outcome.

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description:
    The primary entry point and orchestrator for the application. Coordinates argument parsing, output subsystem initialization, source verification, token resolution, mode normalization, constraint validation, shared memory initialization, LLM detection, logging configuration, diagnostic display, PocketFlow graph instantiation, pipeline execution, and post-execution cleanup.

    Parameters:
    * None.

    Returns:
    * None.

    Raises:
    * SystemExit: Exits with status 1 if --force-rebuild is supplied without --incremental, or via parser.error() if neither --repo, --dir, nor --cleanup is provided.

    Example: 

    # From main.py: main implementation
def main():
    parser, args = parse_arguments()
    init_output(
        language=args.language,
        use_cache=not args.no_cache,
        thinking_level=args.thinking_level,
    )

    # Handle standalone --cleanup (no --dir or --repo)
    if args.cleanup and not args.dir and not args.repo:
        _run_cleanup()
        return

    # Require --dir or --repo for generation
    if not args.dir and not args.repo:
        parser.error("one of the arguments --repo --dir --cleanup is required")

    // ... [Token resolution, mode checks, and store creation]

    shared = build_shared_store(args, github_token, mode)
    provider, model_name, endpoint_url, _, context_length = detect_llm_config(args)
    log_file = configure_logging(project_name=project_name, mode=mode)
    display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file)

    # Create and run the flow
    tutorial_flow = create_tutorial_flow()
    tutorial_flow.run(shared)

    # Cleanup after run if requested
    if args.cleanup:
        _run_cleanup()

    The main() function contains the execution rules for running the pipeline:

    1. Standalone Maintenance: Checks if --cleanup was passed without repository or directory sources; if so, it purges cache and log files and terminates immediately.
    2. Authentication Handling: Inspects -t/--token and the GITHUB_TOKEN environment variable. Emits warnings if a remote repository lacks a token (which may lead to GitHub API rate limits) or if a token was supplied for a local directory analysis.
    3. Incremental Cache Enforcement: Verifies that --incremental is only used with mode == "api-reference", falling back to non-incremental execution with a warning otherwise. If --force-rebuild is enabled, it deletes the incremental cache manifest (.doc_cache_manifest.json) from the output directory before triggering the flow.
    4. Execution & Teardown: Instantiates the flow graph via create_tutorial_flow() and invokes its .run(shared) method. If --cleanup was passed alongside generation arguments, it executes _run_cleanup() after the flow completes.
