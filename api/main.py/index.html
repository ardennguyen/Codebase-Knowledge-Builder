    main.py

    Source: main.py

    Following the workflow DAG configuration and node connectivity patterns established in flow.py, the main.py module serves as the primary command-line interface (CLI) entry point and system lifecycle orchestrator for the Codebase-Knowledge-Builder architecture. It exposes an executable command-line contract, parses and normalizes user runtime parameters, manages environment variable loading, validates option compatibility, constructs the centralized execution state, and drives the pipeline graph through its full execution lifecycle to final resource teardown.

    The module operates as the boundary adapter between the external operating environment and internal workflow engines. Upon execution, it initializes system-wide terminal telemetry, loads runtime secrets from .env files, detects underlying Large Language Model (LLM) provider infrastructure, inspects and enforces context window token ceilings, and builds the primary SharedStoreContext dictionary that is passed across PocketFlow execution nodes. Furthermore, main.py provides operational self-healing mechanisms, including automated shell-quoting corruption detection to intercept malformed CLI inputs, standalone file system and log cleanup routines, and persistent logging configuration.

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description: Acts as the master orchestrator and runtime lifecycle manager for the entire application. It executes in five distinct operational phases: parsing arguments and bootstrapping the localized output system; validating ingestion targets and standalone maintenance tasks; resolving project naming and enforcing caching invariants; assembling the PocketFlow shared state and initializing logging; and dispatching the directed acyclic graph (DAG) inside a try...finally block to ensure all file sinks and stream buffers are flushed via shutdown().

        debug=args.debug,

It then invokes init_output() from utils/output.py to set up localized string tables, cache states, reasoning effort levels, and terminal debugging output. Next, it passes the parser and namespace to _check_quoting_errors() to catch CLI quoting corruptions before they propagate. If the invocation specifies the --cleanup flag without a repository URL or local directory, it executes _run_cleanup() and terminates the process immediately.

Lastly, it turns off --force-batch with a warning if api-reference mode is active, as that mode uses a deterministic file mapping pipeline instead of map-reduce batching.

    resolve_mode_and_project()

    Visibility: Public
    Signature: def resolve_mode_and_project(args: argparse.Namespace) -> tuple[str, str]:

    Description: Normalizes the documentation generation mode and derives the target project name. It resolves the legacy --advanced flag against --mode, issuing a warning via WARN_ADVANCED_OVERRIDES_MODE if an explicit --mode was specified alongside --advanced. It then derives a project name if none was passed via -n/--name, extracting the directory basename from os.path.abspath(args.dir) for local directories, parsing the trailing URI segment for remote git repositories, or falling back to "project".

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1]
        else:
            project_name = "project"
    return mode, project_name
    The function checks args.advanced first to support backward compatibility. When set, it overrides args.mode with "advanced", alerting the user if they also passed a conflicting --mode. Project name derivation handles trailing slashes in remote URLs using .rstrip("/").split("/")[-1], while local directory paths are normalized with os.path.abspath before extracting os.path.basename.

    Parameters: * args (argparse.Namespace): The parsed command-line argument namespace.

    Returns: * tuple[str, str]: A 2-tuple containing the resolved documentation mode (e.g., "tutorial", "advanced", "api-reference", "sdk") and the resolved project_name.

    Raises: * None.

    Example: 

    mode, project_name = resolve_mode_and_project(args)

    build_shared_store()

    Visibility: Public
    Signature: def build_shared_store(args: argparse.Namespace, github_token: str | None, mode: str) -> dict[str, any]:

    Description: Assembles the central state dictionary shared between PocketFlow nodes. It maps parsed command-line arguments to internal configuration keys, merges user-defined file inclusion and exclusion patterns with system defaults, sets operational flags, and initializes empty collection containers (files, abstractions, relationships, chapter_order, chapters) that downstream pipeline nodes populate during execution.

    def build_shared_store(args, github_token, mode):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }
    The constructor performs pattern set arithmetic, joining user exclusion lists with DEFAULT_EXCLUDE_PATTERNS from utils/exclude_patterns.py using .union(). If --include is omitted, it falls back to DEFAULT_INCLUDE_PATTERNS ({"*"}). It inverts --no-cache into the boolean use_cache, sets advanced_mode to True when mode == "advanced", and pre-allocates empty data structures so pipeline nodes can safely mutate store keys without raising KeyError exceptions.

    Parameters: * args (argparse.Namespace): Parsed command-line argument values. * github_token (str | None): The resolved GitHub personal access token, or None if unauthenticated. * mode (str): The documentation generation mode resolved by resolve_mode_and_project().

    Returns: * dict[str, any]: The initialized PocketFlow shared store dictionary.

    Raises: * None.

    Example: 

    shared = build_shared_store(args, github_token, mode)

    detect_llm_config()

    Visibility: Public
    Signature: def detect_llm_config(args: argparse.Namespace) -> tuple[str, str, str, str, int]:

    Description: Inspects runtime environment variables to detect active LLM provider configurations and determine context window capacity ceilings. It checks LLM_PROVIDER first, dynamically resolving model names, API endpoints, and authentication keys using the {provider}_* naming convention. If LLM_PROVIDER is missing, it falls back to Google Gemini if either GEMINI_PROJECT_ID or GEMINI_API_KEY is present. If no recognized provider is found, it defaults to "UNKNOWN". Finally, it sets the context ceiling, using args.max_tokens if explicitly passed, or querying get_model_context_length() from utils/llm_config.py.

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.llm_config import get_model_context_length

    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length
    The function uses a lazy import of get_model_context_length to prevent circular dependencies during module loading. It queries environment variables using standard fallback patterns, defaulting Gemini endpoints to generativelanguage.googleapis.com and models to gemini-3.7-flash. When evaluating token ceilings, args.max_tokens takes precedence over catalog lookups, giving users manual control over context windows when using undocumented or local models.

    Parameters: * args (argparse.Namespace): Command-line arguments containing potential token ceiling overrides (args.max_tokens).

    Returns: * tuple[str, str, str, str, int]: A 5-tuple containing: 1. provider (str): Resolved provider name (e.g., "OPENROUTER", "GEMINI", "UNKNOWN"). 2. model_name (str): Configured model identifier string. 3. endpoint_url (str): Model provider API endpoint base URL. 4. api_key (str): API key used for upstream authentication. 5. context_length (int): Maximum context window size in tokens.

    Raises: * None.

    Example: 

    provider, model_name, endpoint_url, _, context_length = detect_llm_config(args)

    display_config()

    Visibility: Public
    Signature: def display_config(args: argparse.Namespace, mode: str, provider: str, model_name: str, endpoint_url: str, context_length: int, log_file: str) -> None:

    Description: Emits a formatted summary of the active runtime configuration to the console before pipeline execution begins. It uses emit() and get() from utils/output.py to format and output configuration parameters, applying localization keys for settings such as enabled/disabled states and documentation modes.

    def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))
    else:
        emit("CFG_MAX_ABSTRACTIONS", value=str(args.max_abstractions))
    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block
    The output format presents configuration values consistently using localized string templates. Numbers such as context_length are formatted with thousands separators ({context_length:,}), while boolean states are resolved using localized label keys (CFG_VALUE_ENABLED, CFG_VALUE_DISABLED). If mode is set to "api-reference", abstraction limits are overridden with the localized CFG_VALUE_API_REF_MAX message, reflecting that abstraction discovery is bypassed in that mode.

    Internal Helpers

    _check_quoting_errors()

    Visibility: Private
    Signature: def _check_quoting_errors(parser: argparse.ArgumentParser, args: argparse.Namespace) -> None:

    Description: Identifies shell quoting errors where malformed user input caused --exclude or --include arguments to swallow subsequent CLI flags. This occurs when quotes are misplaced (such as --exclude "dir/* "other/*" --language Vietnamese), causing the shell to group following options into pattern values and leading argparse to silently ignore intended settings. The function extracts registered CLI flags dynamically from parser._actions and checks whether pattern strings contain embedded option flags, calling sys.exit(1) with diagnostic context if corruption is detected.

    def _check_quoting_errors(parser, args):
    """Detect shell quoting errors where --exclude/--include values accidentally swallowed other CLI flags.

    When users misquote patterns (e.g., --exclude "autogen/* "SmartFO/*" --language Vietnamese),
    the shell merges subsequent flags into the pattern value. This silently causes ALL following
    arguments to be ignored. We detect this by checking if any pattern value contains a known
    CLI flag string, which no legitimate file/directory pattern would ever contain.

    Flags are extracted dynamically from the argparse parser — no hardcoded list to maintain.
    """
    # Extract all registered flags (both --long and -short) from the parser
    known_flags = set()
    for action in parser._actions:
        for opt in action.option_strings:
            known_flags.add(opt)

    for pattern_list, flag_name in [(args.exclude, "--exclude"), (args.include, "--include")]:
        if not pattern_list:
            continue
        for pattern in pattern_list:
            for known_flag in known_flags:
                if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
                    emit(
                        "ERROR_QUOTING",
                        flag=flag_name,
                        pattern=pattern[:120],
                        embedded=known_flag,
                    )
                    sys.exit(1)
    The validation iterates over all registered option strings in the parser, constructing a lookup set without needing hardcoded flag names. It examines each pattern in args.exclude and args.include, checking for boundary-delimited substrings matching " {known_flag} " or trailing patterns ending with " {known_flag}". If an embedded flag is identified, it emits the localized ERROR_QUOTING template—truncating patterns to 120 characters to preserve terminal formatting—and calls sys.exit(1).

    Parameters: * parser (argparse.ArgumentParser): The argument parser instance containing registered actions. * args (argparse.Namespace): The parsed arguments containing exclude and include lists.

    Returns: * None.

    Raises: * SystemExit: Exits with status code 1 if an embedded flag is detected inside any pattern string.

    Example: 

    # Invocation inside main() prior to executing any pipeline operations:
_check_quoting_errors(parser, args)

    _run_cleanup()

    Visibility: Private
    Signature: def _run_cleanup() -> None:

    Description: Cleans up disk state by removing persistent LLM cache files and clearing session log directories. It deletes the root llm_cache.json file if present, and removes the log directory specified by the LOG_DIR environment variable (defaulting to "logs"). Deletion attempts are wrapped in exception handlers, emitting status telemetry on success and capturing errors via CLEANUP_FAILED without terminating execution.

    def _run_cleanup():
    """Clean up cache files and log directory."""
    emit("CLEANUP_START")

    for cache_path in ["llm_cache.json"]:
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                emit("CLEANUP_REMOVED", path=cache_path)
            except Exception as e:
                emit("CLEANUP_FAILED", path=cache_path, error=e)

    log_dir = os.environ.get("LOG_DIR", "logs")
    if os.path.exists(log_dir) and os.path.isdir(log_dir):
        try:
            shutil.rmtree(log_dir)
            emit("CLEANUP_REMOVED_DIR", path=log_dir)
        except Exception as e:
            emit("CLEANUP_FAILED", path=log_dir, error=e)
    The cleanup routine uses os.remove for files and shutil.rmtree for directory trees. Status updates are routed through the localized emit logger, tracking progress via CLEANUP_START, CLEANUP_REMOVED, and CLEANUP_REMOVED_DIR. Any encountered file system or OS errors are caught and logged under CLEANUP_FAILED, preventing I/O issues from breaking pipeline runs.

    Parameters: * None.

    Returns: * None.

    Raises: * None. All internal I/O and file system exceptions are caught and reported via emit("CLEANUP_FAILED", ...).

    Example: 

    # Standalone execution or post-pipeline cleanup:
if args.cleanup:
    _run_cleanup()

    Error Handling

    Shell Quoting Corruption Check

    Because command shells merge adjacent parameters when quotes are misplaced (for example, --exclude "src/* "test/*" --language ja), subsequent flags can be inadvertently swallowed into string values. main.py detects this via _check_quoting_errors() by scanning input patterns for embedded CLI flags registered in parser._actions. If detected, it emits ERROR_QUOTING with diagnostic context and terminates execution immediately:

    for pattern in pattern_list:
    for known_flag in known_flags:
        if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
            emit(
                "ERROR_QUOTING",
                flag=flag_name,
                pattern=pattern[:120],
                embedded=known_flag,
            )
            sys.exit(1)

    Mutually Exclusive and Required Input Verification

    The command-line parser enforces input target requirements through a mutually exclusive group for --repo and --dir. In addition, main() checks that either a repository, directory, or the --cleanup flag is present, halting execution with an argparse.ArgumentError if no target is specified:

    if not args.dir and not args.repo:
    parser.error("one of the arguments --repo --dir --cleanup is required")

    Mode and Cache Invariant Enforcement

    The module validates documentation generation modes against unsupported flag combinations, preventing execution halts deeper in the pipeline: 1. Incremental Cache Mode Enforcement: Incremental processing is restricted to api-reference mode. If --incremental is passed with other modes, the module emits WARN_INCREMENTAL_API_ONLY and disables the flag. 2. Forced Rebuild Validation: Setting --force-rebuild without --incremental triggers ERROR_FORCE_REBUILD_NO_INCREMENTAL, terminating the process with sys.exit(1). 3. Batching Mode Conflicts: If --force-batch is supplied in api-reference mode, the module emits WARN_FORCE_BATCH_API_REF and resets the flag to False, as API reference mode uses deterministic mapping rather than map-reduce batching.

    GitHub Credential Fallbacks

    When generating documentation for remote repositories without authentication, the module emits a warning rather than failing immediately, allowing public repositories to be fetched within default unauthenticated rate limits:

    if args.repo:
    github_token = args.token or os.environ.get("GITHUB_TOKEN")
    if not github_token:
        emit("WARN_NO_GITHUB_TOKEN")
elif args.token:
    emit("WARN_TOKEN_NO_REPO")

    Non-Fatal Maintenance Operations

    The _run_cleanup() routine wraps all disk operations in broad exception handlers. If file permission issues or missing paths occur while deleting llm_cache.json or removing the directory specified by LOG_DIR, the error is intercepted and reported via CLEANUP_FAILED, allowing the pipeline to proceed without crashing:

    try:
    shutil.rmtree(log_dir)
    emit("CLEANUP_REMOVED_DIR", path=log_dir)
except Exception as e:
    emit("CLEANUP_FAILED", path=log_dir, error=e)

    Teardown and Resource Cleanup Guarantee

    To prevent dangling file descriptors, unbuffered log losses, or hanging network streams, pipeline execution is wrapped in a try...finally block that invokes shutdown() from utils/output.py during process termination:

    try:
    tutorial_flow.run(shared)
    if args.cleanup:
        _run_cleanup()
finally:
    from utils.output import shutdown

    shutdown()
