    main.py

    Source: main.py

    Following the orchestration architecture established in flow.py, which constructs the PocketFlow Directed Acyclic Graph (DAG) and defines the execution nodes, main.py serves as the primary Command-Line Interface (CLI) entry point and runtime lifecycle manager for the Codebase-Knowledge-Builder system. It coordinates environment initialization, argument parsing, LLM configuration discovery, diagnostic telemetry setup, and workflow execution.

    Technical Overview

    main.py acts as the operational nexus that translates high-level user intentions into execution payloads consumed by the underlying PocketFlow workflow engine. Upon invocation, the module loads local environment variables via python-dotenv, parses CLI options through argparse, and initializes the internationalization and logging subsystems via utils.output. It handles validation for mutually exclusive inputs, ensures compatibility across diverse documentation modes (tutorial, advanced, api-reference, and sdk), and reconciles user-provided file inclusion/exclusion rules with the baseline rulesets defined in utils.exclude_patterns.

    Beyond parameter normalization, main.py executes environment introspection to detect configured LLM backends (such as direct Google Gemini API connections or OpenAI-compatible gateways like OpenRouter and Ollama). It queries context window limits dynamically, constructs the initial centralized shared store dictionary, and configures rotating file logs tailored to the target project. Once execution parameters are validated and logged to the console, it invokes create_tutorial_flow() from flow.py and starts the workflow. It also manages maintenance tasks, such as clearing local LLM response caches and deleting temporary log directories.

    resolve_mode_and_project()

    Visibility: Public
    Signature: def resolve_mode_and_project(args: argparse.Namespace) -> tuple[str, str]:

    Description: Resolves precedence rules between the modern --mode option and the legacy --advanced boolean flag. It derives the canonical project name from local directory paths, remote GitHub URLs, or explicit --name CLI overrides.

    Parameters: * args (argparse.Namespace): The parsed command-line arguments.

    Returns: * tuple[str, str]: A two-element tuple containing the resolved documentation mode string (e.g., "advanced", "api-reference") and the resolved project name string.

    Raises: * None.

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1]
        else:
            project_name = "project"
    return mode, project_name
    The function prioritizes the --advanced flag when set, issuing a warning via emit() if a non-default --mode was also provided. For project naming, it falls back to the absolute directory basename for local targets (args.dir) or the trailing path component of remote Git repositories (args.repo), defaulting to "project" if no source paths can be resolved.

    Example: 

    # Invocation inside main()
mode, project_name = resolve_mode_and_project(args)

    def build_shared_store(args, github_token, mode):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

It merges custom --exclude patterns with the global DEFAULT_EXCLUDE_PATTERNS set, handles include sets with DEFAULT_INCLUDE_PATTERNS, inverts --no-cache into the boolean flag use_cache, and sets initial empty containers for downstream intermediate data.

    detect_llm_config()

    Visibility: Public
    Signature: def detect_llm_config(args: argparse.Namespace) -> tuple[str, str, str, str, int]:

    Description: Inspects environment variables to determine the active LLM provider, target model name, base API endpoint URL, and authentication key. It dynamically queries context window capacities using utils.call_llm.get_model_context_length unless explicitly overridden via the --max-tokens CLI option.

    Parameters: * args (argparse.Namespace): The parsed CLI arguments namespace (checked for max_tokens overrides).

    Returns: * tuple[str, str, str, str, int]: A 5-tuple formatted as (provider, model_name, endpoint_url, api_key, context_length).

    Raises: * None.

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.call_llm import get_model_context_length

    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length
    The detection algorithm reads LLM_PROVIDER to dynamically build environment variable lookup keys ({provider}_MODEL, {provider}_BASE_URL, {provider}_API_KEY). If LLM_PROVIDER is unset, it falls back to checking for Gemini configurations (GEMINI_PROJECT_ID or GEMINI_API_KEY), defaulting to gemini-3.7-flash. If neither is detected, it returns placeholder unknown entries. Finally, it calculates context_length by using args.max_tokens or querying get_model_context_length.

    Example: 

    # Invocation inside main()
provider, model_name, endpoint_url, _, context_length = detect_llm_config(args)

    Visibility: Public
    Signature: def display_config(args: argparse.Namespace, mode: str, provider: str, model_name: str, endpoint_url: str, context_length: int, log_file: str | None) -> None:

    Description: Renders the complete runtime configuration parameters to the console using the messaging interface in utils.output. It provides visual confirmation of active endpoints, models, token limits, modes, batch sizes, caching states, and active log paths.

    Parameters: * args (argparse.Namespace): Parsed CLI arguments namespace. * mode (str): Resolved documentation mode. * provider (str): Name of the detected LLM provider. * model_name (str): Name of the target LLM model. * endpoint_url (str): Base URL or host domain of the inference endpoint. * context_length (int): Maximum context window size in tokens. * log_file (str | None): Relative path to the active log file on disk.

    Returns: * None

    Raises: * None.

    def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))
    else:
        emit("CFG_MAX_ABSTRACTIONS", value=str(args.max_abstractions))
    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block
    The helper renders configuration properties using localized message keys via emit() and get() from utils.output. It dynamically adjusts display values for boolean toggles (_enabled / _disabled), handles conditional outputs (such as displaying FORCE_REBUILD only when incremental mode is enabled), and prints a blank terminal line to cleanly separate configuration headers from subsequent execution logs.

    Internal Helpers

    _run_cleanup()

    Visibility: Private
    Signature: def _run_cleanup() -> None:

    Description: Performs filesystem maintenance by deleting cached inference responses (llm_cache.json) and removing active log directories defined by the LOG_DIR environment variable (defaulting to ./logs). File operations are wrapped in defensive exception handling to prevent unexpected crashes from halting maintenance.

    Parameters: * None.

    Returns: * None

    Raises: * None. File system errors (OSError, PermissionError) are caught internally and reported via emit("CLEANUP_FAILED", ...).

    def _run_cleanup():
    """Clean up cache files and log directory."""
    import shutil

    emit("CLEANUP_START")

    for cache_path in ["llm_cache.json"]:
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                emit("CLEANUP_REMOVED", path=cache_path)
            except Exception as e:
                emit("CLEANUP_FAILED", path=cache_path, error=e)

    log_dir = os.environ.get("LOG_DIR", "logs")
    if os.path.exists(log_dir) and os.path.isdir(log_dir):
        try:
            shutil.rmtree(log_dir)
            emit("CLEANUP_REMOVED_DIR", path=log_dir)
        except Exception as e:
            emit("CLEANUP_FAILED", path=log_dir, error=e)
    The helper imports shutil locally to perform recursive directory tree removals. It iterates over known cache file paths (such as llm_cache.json), unlinking them with os.remove(), and checks LOG_DIR to purge existing logging directories using shutil.rmtree(). All file operations are isolated with try/except blocks, emitting progress and error telemetry without interrupting execution.

    Example: 

    # Standalone execution inside main()
if args.cleanup and not args.dir and not args.repo:
    _run_cleanup()
    return

    Error Handling

    main.py applies defensive input validation and error handling strategies across the CLI lifecycle:

    • Source Mutually Exclusive Bounds: Enforced via argparse.add_mutually_exclusive_group(). If both --repo and --dir are supplied, the parser rejects execution immediately. If neither is supplied and --cleanup is not set, parser.error() terminates execution with a localized error message.
    • Mode & Incremental Compatibility: Incremental caching is strictly restricted to api-reference mode. If --incremental is specified with other modes, emit("WARN_INCREMENTAL_API_ONLY") warns the user and resets args.incremental = False. If --force-rebuild is passed without --incremental, the program halts with sys.exit(1) after emitting ERROR_FORCE_REBUILD_NO_INCREMENTAL.
    • API Reference Mode Invariants: In api-reference mode, force_batch is disabled with WARN_FORCE_BATCH_API_REF, and non-default abstraction limits trigger WARN_MAX_ABS_API_REF because API reference documentation relies on 1:1 file mappings rather than dynamic abstraction limits.
    • Fault-Tolerant File Cleanup: The _run_cleanup() helper isolates file unlinking (os.remove) and directory tree deletions (shutil.rmtree) within try...except Exception blocks, dispatching CLEANUP_FAILED telemetry rather than crashing if file locks or permission errors occur.
