    main.py

    Source: main.py

    Following the orchestration graph definitions established in flow.py, main.py serves as the primary Command-Line Interface (CLI) entry point and operational runtime orchestrator for the Codebase-Knowledge-Builder application. It initializes the environment, parses user inputs and execution flags, resolves provider-specific Large Language Model (LLM) configurations, dynamically constructs the central shared state dictionary (shared), configures logging sinks and localized telemetry, and instantiates the PocketFlow execution pipeline.

    The module coordinates pre-flight operations such as validating source repository targets (remote GitHub repositories vs. local directories), enforcing cache constraints for incremental builds, deleting stale cache manifests during forced rebuilds, and executing standalone or post-run disk cleanups.

    DEFAULT_INCLUDE_PATTERNS

    • Type: set[str]
    • Value: {"*"}
    • Description: The default glob pattern applied during filesystem and remote repository crawls when no explicit --include patterns are provided via the command line. Matches all discovered candidate source files.

    Module-Level Functions

    parse_arguments()

    Visibility: Public
    Signature: def parse_arguments() -> tuple[argparse.ArgumentParser, argparse.Namespace]:

    Description: Configures and executes the command-line interface specification using Python's argparse standard library. Defines mutually exclusive input sources (--repo vs. --dir), operational flags for cache invalidation, output path definitions, filtering glob arrays, reasoning effort controls, context-window overrides, batch execution limits, and documentation style presets.

    Parameters: * None.

    Returns: * tuple[argparse.ArgumentParser, argparse.Namespace]: A two-element tuple containing the active ArgumentParser instance (used for programmatic error dispatching via parser.error()) and the parsed Namespace containing all flag attributes.

    Raises: * SystemExit: Implicitly raised by argparse if unrecognized flags are supplied or if CLI help (-h, --help) is requested.

    Example: 

    def parse_arguments():
    """Parse and return command-line arguments."""
    parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Source: --repo or --dir (mutually exclusive but not required if --cleanup is used)
    source_group = parser.add_mutually_exclusive_group()
    source_group.add_argument("--repo", help="URL of the public GitHub repository.")
    source_group.add_argument("--dir", help="Path to local directory.")
    parser.add_argument("--cleanup", action="store_true", help="Clean up logs and cache files. Can be used standalone or after a run.")

    parser.add_argument("-n", "--name", help="Project name (optional, derived from repo/directory if omitted).")
    parser.add_argument("-t", "--token", help="GitHub personal access token (optional, reads from GITHUB_TOKEN env var if not provided).")
    parser.add_argument("-o", "--output", default="output", help="Base directory for output (default: ./output).")
    parser.add_argument("-i", "--include", nargs="+", help="Files to include (e.g., '*.py' '*.js'). Defaults to '*' (all files).")
    parser.add_argument(
        "-e",
        "--exclude",
        nargs="+",
        help="Files to exclude. Custom patterns are automatically merged with a massive global exclusion list (build caches, node_modules, binaries, media, AI environments) AND your repository's native .gitignore rules.",
    )
    parser.add_argument("-s", "--max-size", type=int, default=200000, help="Maximum file size in bytes (default: 200000, about 200KB).")
    # Add language parameter for multi-language support
    parser.add_argument("--language", default="english", help="Language for the generated tutorial (default: english).")
    # Add use_cache parameter to control LLM caching
    parser.add_argument("--no-cache", action="store_true", help="Disable LLM response caching (default: caching enabled).")
    # Add max_abstraction_num parameter to control the number of abstractions
    parser.add_argument("--max-abstractions", type=int, default=10, help="Maximum number of abstractions to identify (default: 10).")
    # Add thinking_level parameter for LLM reasoning capabilities
    parser.add_argument(
        "--thinking-level",
        default=None,
        help="Thinking effort level for native Gemini, OpenRouter, and Ollama reasoning models (e.g., low, medium, high). Leave empty to use model defaults.",
    )
    # Add max_tokens parameter
    parser.add_argument(
        "--max-tokens", type=int, default=None, help="Maximum number of tokens for the context window (default: fetched dynamically)."
    )

    # --- Documentation Mode & Generation Styles ---
    parser.add_argument(
        "--mode",
        choices=["tutorial", "advanced", "api-reference", "sdk"],
        default="tutorial",
        help="Documentation style (tutorial, advanced, api-reference, sdk). (default: tutorial).",
    )
    parser.add_argument("--advanced", action="store_true", help="Legacy flag: equivalent to --mode advanced.")
    parser.add_argument("--mkdocs", action="store_true", help="Format output for MkDocs Material (adds YAML frontmatter & nav snippet).")
    parser.add_argument(
        "--incremental",
        action="store_true",
        help="Enable MD5 incremental caching to skip unchanged modules (Only supported in --mode api-reference).",
    )
    parser.add_argument(
        "--force-rebuild", action="store_true", help="Clear incremental cache and regenerate all chapters from scratch (use with --incremental)."
    )

    # Add batching parameters
    parser.add_argument("--batch", type=int, default=50, help="Maximum files per batch when using map-reduce mode (default: 50).")
    parser.add_argument("--force-batch", action="store_true", help="Force map-reduce mode regardless of context size.")
    # Debug mode
    parser.add_argument("--debug", action="store_true", help="Enable verbose debug output.")

    return parser, parser.parse_args()

    The parse_arguments() function establishes a unified CLI contract for the entire documentation generator. By structuring --repo and --dir into a mutually exclusive group, it guarantees that downstream ingestion routines never encounter conflicting input source instructions. It provisions multi-type flags such as nargs="+" for --include and --exclude lists, handles backward-compatibility switches like --advanced, and accepts operational tuning parameters including --batch size and --thinking-level. Returning both the parser and the resolved namespace allows the main() orchestrator to trigger formatted validation aborts when required options are omitted.

    resolve_mode_and_project()

    Visibility: Public
    Signature: def resolve_mode_and_project(args: argparse.Namespace) -> tuple[str, str]:

    Description: Resolves the operational documentation generation mode and infers a fallback project name when the user omits the -n/--name parameter. Reconciles legacy --advanced boolean switches with the current --mode selection and extracts target folder or repository names from paths or URLs.

    Parameters: * args (argparse.Namespace): The parsed command-line arguments.

    Returns: * tuple[str, str]: A tuple of (mode, project_name) where mode is one of "tutorial", "advanced", "api-reference", or "sdk", and project_name is a sanitized string identifier.

    Raises: * None.

    Example: 

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    mode = "advanced" if args.advanced else args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1]
        else:
            project_name = "project"
    return mode, project_name

    resolve_mode_and_project() prioritizes explicit CLI arguments while implementing robust fallback heuristics. If --advanced is passed, it overrides args.mode to preserve backwards compatibility with earlier pipeline versions. When deriving project_name, the function handles both absolute/relative local paths via os.path.abspath and remote URLs by stripping trailing slashes and splitting path delimiters. In edge cases where neither a repository nor a directory is provided (e.g., during invocation with --cleanup), it falls back to the generic label "project".

    build_shared_store()

    Visibility: Public
    Signature: def build_shared_store(args: argparse.Namespace, github_token: str | None, mode: str) -> dict[str, any]:

    Description: Instantiates the central dictionary store passed across all PocketFlow pipeline nodes. Maps CLI flags to store keys, compiles default and user-supplied inclusion/exclusion file patterns into native Python sets, and initializes downstream output accumulator containers.

    Parameters: * args (argparse.Namespace): Parsed CLI argument namespace. * github_token (str | None): Authenticated GitHub personal access token, if resolved. * mode (str): The active documentation generation mode resolved by resolve_mode_and_project().

    Returns: * dict[str, any]: The initialized PocketFlow shared store containing execution metadata, crawler filtering rules, LLM parameters, and empty list/dict slots for pipeline artifacts.

    Raises: * None.

    Example: 

    def build_shared_store(args, github_token, mode):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    The build_shared_store() function acts as the state factory for the entire PocketFlow orchestration lifecycle. It merges the immutable static set DEFAULT_EXCLUDE_PATTERNS with custom exclusions provided via --exclude to ensure security filters and build-artifact ignores cannot be bypassed. Furthermore, it defines mutable placeholder collections (files, abstractions, relationships, chapter_order, chapters) which downstream nodes in nodes.py sequentially mutate throughout execution.

    detect_llm_config()

    Visibility: Public
    Signature: def detect_llm_config(args: argparse.Namespace) -> tuple[str, str, str, str, int]:

    Description: Inspects runtime environment variables to determine the active LLM provider, target model name, base API endpoint URL, authentication keys, and token context length. Dynamically queries remote model metadata if token limits are not manually specified on the command line.

    Parameters: * args (argparse.Namespace): Parsed CLI arguments containing potential context window overrides (args.max_tokens).

    Returns: * tuple[str, str, str, str, int]: A 5-tuple structured as (provider, model_name, endpoint_url, api_key, context_length).

    Raises: * None. (Internal network or lookup exceptions in get_model_context_length are handled within utils/call_llm.py).

    Example: 

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.call_llm import get_model_context_length

    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length

    detect_llm_config() implements dynamic multi-provider environment introspection. It first checks for a generic LLM_PROVIDER environment variable (such as OPENROUTER or OLLAMA) and extracts the corresponding parameterized variables ({PROVIDER}_MODEL, {PROVIDER}_BASE_URL, {PROVIDER}_API_KEY). If LLM_PROVIDER is unset, it falls back to checking for Google Gemini configurations (GEMINI_PROJECT_ID or GEMINI_API_KEY), defaulting to gemini-3.7-flash. If --max-tokens was not passed via CLI, it delegates to get_model_context_length() from utils/call_llm.py to discover the model's active context window dynamically.

    display_config()

    Visibility: Public
    Signature: def display_config(args: argparse.Namespace, mode: str, provider: str, model_name: str, endpoint_url: str, context_length: int, log_file: str) -> None:

    Description: Formats and outputs the complete operational configuration banner to standard output. Uses localized translation templates from utils/output.py to display inference provider parameters, model boundaries, caching statuses, documentation modes, and output log file locations.

    Parameters: * args (argparse.Namespace): Parsed CLI argument namespace. * mode (str): Resolved documentation mode string. * provider (str): Resolved LLM provider identifier. * model_name (str): Target LLM model name. * endpoint_url (str): Inference API base endpoint URL. * context_length (int): Maximum context token window length. * log_file (str): Relative or absolute filesystem path to the active timestamped log file.

    Returns: * None

    Raises: * None.

    Example: 

    def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))
    else:
        emit("CFG_MAX_ABSTRACTIONS", value=str(args.max_abstractions))
    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block

    The display_config() function structures terminal output into a standardized, localized telemetry block prior to graph execution. It uses emit() and get() from utils/output.py to render status variables (such as enabled/disabled indicators) mapped to the selected --language. It also formats numeric token thresholds with comma thousands-separators (f"{context_length:,}") and conditionally reports mode-specific parameters such as incremental rebuild settings and API reference abstraction overrides.

    _run_cleanup()

    Visibility: Protected (Internal)
    Signature: def _run_cleanup() -> None:

    Description: Executes filesystem cleanup routines to remove persistent LLM response caches (llm_cache.json) and purge the runtime log output directory defined by the LOG_DIR environment variable (defaulting to ./logs). Emits telemetry events detailing successful removals or caught I/O exceptions.

    Parameters: * None.

    Returns: * None

    Raises: * None. (All internal OSError and file I/O exceptions are captured and reported via emit("CLEANUP_FAILED", ...)).

    Example: 

    def _run_cleanup():
    """Clean up cache files and log directory."""
    import shutil

    emit("CLEANUP_START")

    for cache_path in ["llm_cache.json"]:
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                emit("CLEANUP_REMOVED", path=cache_path)
            except Exception as e:
                emit("CLEANUP_FAILED", path=cache_path, error=e)

    log_dir = os.environ.get("LOG_DIR", "logs")
    if os.path.exists(log_dir) and os.path.isdir(log_dir):
        try:
            shutil.rmtree(log_dir)
            emit("CLEANUP_REMOVED_DIR", path=log_dir)
        except Exception as e:
            emit("CLEANUP_FAILED", path=log_dir, error=e)

    _run_cleanup() provides disk sanitation capabilities without terminating the host process on failure. It iterates over known disk cache paths (such as llm_cache.json) and attempts deletion via os.remove(). It then resolves the active logging directory from LOG_DIR and recursively purges it using shutil.rmtree(). Any encountered filesystem errors (such as file locking or permission errors) are caught cleanly and routed through the telemetry system with structured error messages.

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description: Primary execution driver for the application. Coordinates the entire workflow lifecycle: argument parsing, environment variable loading via dotenv, i18n subsystem initialization, source target validation, token verification, cache constraint validation, shared store instantiation, logging setup, PocketFlow DAG execution, and post-execution cleanup.

    Parameters: * None.

    Returns: * None

    Raises: * SystemExit: Triggered via parser.error() if neither --repo, --dir, nor --cleanup is supplied.

    Example: 

    def main():
    parser, args = parse_arguments()
    init_output(
        language=args.language,
        use_cache=not args.no_cache,
        thinking_level=args.thinking_level,
    )

    # Handle standalone --cleanup (no --dir or --repo)
    if args.cleanup and not args.dir and not args.repo:
        _run_cleanup()
        return

    # Require --dir or --repo for generation
    if not args.dir and not args.repo:
        parser.error("one of the arguments --repo --dir --cleanup is required")

    # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get("GITHUB_TOKEN")
        if not github_token:
            emit("WARN_NO_GITHUB_TOKEN")

    mode, project_name = resolve_mode_and_project(args)

    # Enforce incremental cache constraints
    if args.incremental and mode != "api-reference":
        emit("WARN_INCREMENTAL_API_ONLY")
        args.incremental = False

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        output_base = args.output or "output"
        manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
        if os.path.exists(manifest_path):
            os.remove(manifest_path)
            emit("FORCE_REBUILD_DELETED", path=manifest_path)
        else:
            emit("FORCE_REBUILD_NO_MANIFEST", path=manifest_path)
    elif args.force_rebuild and not args.incremental:
        emit("WARN_FORCE_REBUILD_NO_INCREMENTAL")

    shared = build_shared_store(args, github_token, mode)
    provider, model_name, endpoint_url, _, context_length = detect_llm_config(args)
    log_file = configure_logging(project_name=project_name, mode=mode)
    display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file)

    # Create and run the flow
    tutorial_flow = create_tutorial_flow()
    tutorial_flow.run(shared)

    # Cleanup after run if requested
    if args.cleanup:
        _run_cleanup()

    main() encapsulates the operational lifecycle of the codebase analysis pipeline. It evaluates operational prerequisites before workflow execution, enforcing that --incremental mode is restricted exclusively to --mode api-reference and managing the deletion of .doc_cache_manifest.json when --force-rebuild is specified. After constructing the shared data store and configuring output logs, it builds the PocketFlow graph using create_tutorial_flow() and triggers execution via tutorial_flow.run(shared). If --cleanup was passed alongside generation flags, it executes _run_cleanup() as a final teardown step after workflow completion.
