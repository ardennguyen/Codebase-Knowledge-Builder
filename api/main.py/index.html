    main.py

    Source: main.py

    Technical Overview

    Following the execution graph abstractions established in flow.py, main.py serves as the centralized command-line interface (CLI) entry point and runtime orchestrator for the Codebase-Knowledge-Builder system. The module initializes the application runtime by loading environment variables via python-dotenv, parsing CLI options, validating argument syntax against shell quoting hazards, and setting up internationalized logging and console telemetry. It unifies input parameters across remote GitHub repositories and local file directories into a standardized execution context.

    Architecturally, main.py acts as the bridge between external user input and the internal execution pipeline. It inspects local environment variables to detect active LLM provider configurations (such as Gemini, OpenRouter, or Ollama), queries remote context capacities, and sets up a shared runtime store dictionary. This dictionary is subsequently injected into the PocketFlow Directed Acyclic Graph (DAG) constructed by create_tutorial_flow(). In addition to managing the lifecycle of the primary documentation generation workflow, main.py provides independent maintenance utilities for purging local inference caches and file logger directories.

    parse_arguments()

    Visibility: Public
    Signature: def parse_arguments() -> tuple[argparse.ArgumentParser, argparse.Namespace]:

    Description: Configures and executes the command-line interface argument parser using Python's argparse standard library. The parser establishes mutually exclusive target sources (--repo vs --dir), standalone maintenance routines (--cleanup), output destination controls, pattern-based inclusion and exclusion filters, token and abstraction budgets, LLM reasoning parameters, generation modes, and MkDocs integration flags.

    Parameters: * None.

    Returns: * tuple[argparse.ArgumentParser, argparse.Namespace]: A two-element tuple containing the configured ArgumentParser instance (retained for contextual error reporting) and the parsed Namespace containing all CLI arguments.

    Raises: * SystemExit: Automatically invoked by argparse if unrecognized parameters are provided or if --help is passed.

    Example: 

    parser, args = parse_arguments()
init_output(
    language=args.language,
    use_cache=not args.no_cache,
    thinking_level=args.thinking_level,
)

    The function groups input sources using parser.add_mutually_exclusive_group() to ensure that remote ingestion and local filesystem crawls are never triggered simultaneously. Argument defaults are calibrated to production thresholds, setting the base output directory to "output", the maximum single-file processing ceiling to 200,000 bytes (approx. 200 KB), the abstraction ceiling to 10, the Map-Reduce batch size to 50 files, and the default documentation mode to "tutorial".

    mode, project_name = resolve_mode_and_project(args)

# Enforce incremental cache constraints
if args.incremental and mode != "api-reference":
    emit("WARN_INCREMENTAL_API_ONLY")

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1]
        else:
            project_name = "project"
    return mode, project_name

    The resolution logic prioritizes explicit naming passed via -n/--name. If absent, local targets evaluate os.path.abspath(args.dir) to retrieve the trailing folder name using os.path.basename. For remote targets, trailing slashes are stripped before extracting the terminal URI segment. If neither source yields an identity, the system falls back to "project".

    def build_shared_store(args, github_token, mode):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    The construction of the shared store guarantees that exclusion rules combine the 96 baseline patterns from utils/exclude_patterns.py with any custom globs passed via the CLI using set unions. Downstream pipeline artifacts—including raw file dictionaries, extracted abstraction structures, relationship graphs, and final chapter lists—are allocated empty list and dictionary containers to prevent KeyError exceptions in intermediate PocketFlow nodes.

    detect_llm_config()

    Visibility: Public
    Signature: def detect_llm_config(args: argparse.Namespace) -> tuple[str, str, str, str, int]:

    Description: Discovers active LLM provider configurations by inspecting environment variables and querying model context windows. It resolves provider names, target model identifiers, HTTP/REST base endpoints, and authentication keys. If no explicit provider is declared, it falls back to inspecting Google Gemini credentials. Finally, it calculates available context lengths dynamically or uses CLI token overrides.

    Parameters: * args (argparse.Namespace): The parsed CLI arguments namespace (inspected for --max-tokens).

    Returns: * tuple[str, str, str, str, int]: A 5-element tuple containing (provider, model_name, endpoint_url, api_key, context_length).

    Raises: * No exceptions raised directly; network anomalies during dynamic capacity lookups are captured within get_model_context_length().

    Example: 

    provider, model_name, endpoint_url, _, context_length = detect_llm_config(args)


    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.call_llm import get_model_context_length

    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length

    The function reads the generic LLM_PROVIDER environment variable to dynamically construct provider-prefixed environment queries (e.g., OPENROUTER_MODEL, OPENROUTER_BASE_URL, OPENROUTER_API_KEY). If LLM_PROVIDER is missing, it evaluates the presence of GEMINI_PROJECT_ID or GEMINI_API_KEY to apply Google Gemini defaults (gemini-3.7-flash). If user overrides (--max-tokens) are omitted, the function queries utils/call_llm.py to discover context window limits via remote endpoints or local heuristics.

    def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))
    else:
        emit("CFG_MAX_ABSTRACTIONS", value=str(args.max_abstractions))
    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block

    The function consumes localized string keys via emit() and get() from utils/output.py. It displays conditional metadata depending on the active mode; for example, it masks max_abstractions with localized informational tokens (CFG_VALUE_API_REF_MAX) when running in api-reference mode, as file-to-chapter allocation is deterministic in that mode.

    _check_quoting_errors()

    Visibility: Private
    Signature: def _check_quoting_errors(parser: argparse.ArgumentParser, args: argparse.Namespace) -> None:

    Description: Guards against a common CLI failure mode where unescaped spaces or misquoted glob patterns cause the user's shell to merge downstream flags into --include or --exclude pattern arguments. This function dynamically inspects all registered option strings in the parser and checks whether any parsed filter pattern contains an embedded CLI flag.

    Parameters: * parser (argparse.ArgumentParser): The active parser instance containing registered option strings. * args (argparse.Namespace): The parsed arguments namespace containing pattern lists.

    Returns: * None

    Raises: * SystemExit: Exits with code 1 if an embedded flag is detected within any pattern string.

    Example: 

    parser, args = parse_arguments()
init_output(
    language=args.language,
    use_cache=not args.no_cache,
    thinking_level=args.thinking_level,
)
_check_quoting_errors(parser, args)


    def _check_quoting_errors(parser, args):
    """Detect shell quoting errors where --exclude/--include values accidentally swallowed other CLI flags.

    When users misquote patterns (e.g., --exclude "autogen/* "SmartFO/*" --language Vietnamese),
    the shell merges subsequent flags into the pattern value. This silently causes ALL following
    arguments to be ignored. We detect this by checking if any pattern value contains a known
    CLI flag string, which no legitimate file/directory pattern would ever contain.

    Flags are extracted dynamically from the argparse parser — no hardcoded list to maintain.
    """
    # Extract all registered flags (both --long and -short) from the parser
    known_flags = set()
    for action in parser._actions:
        for opt in action.option_strings:
            known_flags.add(opt)

    for pattern_list, flag_name in [(args.exclude, "--exclude"), (args.include, "--include")]:
        if not pattern_list:
            continue
        for pattern in pattern_list:
            for known_flag in known_flags:
                if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
                    emit(
                        "ERROR_QUOTING",
                        flag=flag_name,
                        pattern=pattern[:120],
                        embedded=known_flag,
                    )
                    sys.exit(1)

    The dynamic extraction of registered flags from parser._actions eliminates the need to maintain a separate hardcoded list of CLI options. The validation logic checks if a known flag string is surrounded by spaces or appears at the end of a pattern string, safely distinguishing between accidental flag swallows and valid filenames.

    _run_cleanup()

    Visibility: Private
    Signature: def _run_cleanup() -> None:

    Description: Removes transient execution artifacts, specifically the local LLM response cache file (llm_cache.json) and the run log directory (configured via LOG_DIR, defaulting to logs).

    Parameters: * None.

    Returns: * None

    Raises: * No exceptions raised. File system exceptions during deletion are intercepted and routed to the UI via emit("CLEANUP_FAILED").

    Example: 

    # Handle standalone --cleanup (no --dir or --repo)

    def _run_cleanup():
    """Clean up cache files and log directory."""
    import shutil

    emit("CLEANUP_START")

    for cache_path in ["llm_cache.json"]:
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                emit("CLEANUP_REMOVED", path=cache_path)
            except Exception as e:
                emit("CLEANUP_FAILED", path=cache_path, error=e)

    log_dir = os.environ.get("LOG_DIR", "logs")
    if os.path.exists(log_dir) and os.path.isdir(log_dir):
        try:
            shutil.rmtree(log_dir)
            emit("CLEANUP_REMOVED_DIR", path=log_dir)
        except Exception as e:
            emit("CLEANUP_FAILED", path=log_dir, error=e)

    The cleanup implementation relies on defensive filesystem calls. Deletions check for path existence prior to unlinking, and use shutil.rmtree to recursively remove the log directory. Any operating system errors (such as file lock contention or permission restrictions) are trapped in generic except Exception blocks, ensuring that failures to clean temporary files do not trigger unhandled tracebacks.

    Data Structures

    PocketFlow Shared Store Schema

    The primary runtime data structure constructed by build_shared_store() and passed through the execution DAG:

    Key Type Description Example Value
    repo_url str \| None Remote GitHub repository URL "https://github.com/org/repo"
    local_dir str \| None Local directory path "/path/to/codebase"
    project_name str \| None Derived or explicit project identifier "my-project"
    github_token str \| None Authenticated GitHub access token "ghp_1234567890abcdef"
    output_dir str Base destination directory for generated artifacts "output"

    Error Handling

    main.py enforces CLI validation and defensive error handling across several boundaries:

    • Shell Quoting Errors:
      When users miss quotes in pattern arguments (e.g., --exclude "autogen/* "SmartFO/*" --language Vietnamese), the shell can swallow downstream flags into the pattern string. _check_quoting_errors() detects this by checking if any pattern string contains a known CLI flag preceded by a space. When found, it emits an ERROR_QUOTING diagnostic and exits with status code 1.

    • Mutual Requirement Guardrails:
      Target arguments use a mutually exclusive group for --repo and --dir. If neither is provided and --cleanup is not specified, parser.error() terminates execution with a standard CLI usage message.

    • Mode and Feature Incompatibilities:
      Incremental caching (--incremental) is restricted to --mode api-reference. If passed with other modes, a warning is logged via emit("WARN_INCREMENTAL_API_ONLY") and args.incremental is forced to False. Passing --force-rebuild without --incremental triggers ERROR_FORCE_REBUILD_NO_INCREMENTAL and terminates with status code 1. In api-reference mode, batching overrides (--force-batch) and custom abstraction limits (--max-abstractions) are automatically overridden with warnings.

    • Cleanup Fault Tolerance:
      The _run_cleanup() helper isolates file and directory deletions in try-except blocks. If file locks or permission issues prevent deleting llm_cache.json or the log directory, the error is reported via emit("CLEANUP_FAILED") without crashing the application.

    • LLM Provider Fallbacks:
      If the primary LLM_PROVIDER environment variable is not declared, detect_llm_config() checks for GEMINI_PROJECT_ID or GEMINI_API_KEY before falling back to UNKNOWN. This allows Gemini users to run the pipeline without explicitly configuring provider names.
