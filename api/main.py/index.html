    main.py

    Source: main.py

    Following the orchestration architecture established in flow.py, main.py serves as the primary Command-Line Interface (CLI) application entry point and runtime bootstrap engine for the Codebase-Knowledge-Builder system. It coordinates the end-to-end execution lifecycle: parsing CLI arguments, initializing internationalized terminal telemetry, dynamically inspecting model capabilities, managing incremental caching states, populating the shared runtime state bus, and invoking the executable directed acyclic graph (DAG) compiled by create_tutorial_flow().

    Technical Overview

    main.py encapsulates the application lifecycle and bridges operating system shell environments with internal execution nodes. Its primary responsibilities include:

    1. CLI Ingestion & Validation: Exposing a comprehensive suite of command-line flags via argparse, enforcing mutual exclusivity rules (e.g., --repo vs. --dir), validating documentation styles (tutorial, advanced, api-reference, sdk), and handling utility triggers (such as --cleanup or --force-rebuild).
    2. Telemetry & Localization Bootstrapping: Invoking utils.output.init() to configure runtime language localization, ANSI terminal palettes, and LLM reasoning configurations before emitting initial status events.
    3. LLM Runtime Environment Introspection: Inspecting active provider configurations (GEMINI, OPENROUTER, OLLAMA, or generic OpenAI-compatible REST endpoints), resolving API credentials, determining upstream context window limits, and applying token overrides.
    4. Shared State Store Construction: Assembling the centralized shared dictionary—the unified mutable state bus consumed and updated across all PocketFlow nodes defined in nodes.py.
    5. Incremental Cache Lifecycle Management: Managing .doc_cache_manifest.json invalidation on --force-rebuild and executing disk cleanup of local caches (llm_cache.json) and session logs (logs/).
    6. Graph Instantiation & Execution: Calling create_tutorial_flow() from flow.py and triggering synchronous graph execution via tutorial_flow.run(shared).

    resolve_mode_and_project()

    Visibility: Public
    Signature: def resolve_mode_and_project(args: argparse.Namespace) -> tuple[str, str]:

    Description:
    Resolves the active documentation mode (translating the legacy --advanced boolean flag into the "advanced" mode string if set) and derives the project name if omitted by the user.

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    mode = "advanced" if args.advanced else args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1]
        else:
            project_name = "project"
    return mode, project_name

    The resolution logic prioritizes backwards compatibility by mapping the legacy --advanced switch to mode = "advanced". If --name is not provided, the function inspects the input source: for local directories (--dir), it extracts the basename of the resolved absolute path; for remote Git URLs (--repo), it strips trailing slashes and extracts the trailing path segment (e.g., https://github.com/org/repo resolves to repo). If neither source is supplied, it falls back to "project".

    Parameters: * args (argparse.Namespace): Parsed CLI command-line arguments.

    Returns: * tuple[str, str]: A tuple containing (mode, project_name).

    Raises: * None.

    Example: 

    mode, project_name = resolve_mode_and_project(args)

# Enforce incremental cache constraints

    Description:
    Constructs the central shared state dictionary passed between all PocketFlow execution nodes. It merges command-line inputs, API credentials, and default exclusion patterns with downstream output slots.

    def build_shared_store(args, github_token, mode):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    This function creates the central communication channel for the pipeline. It merges custom user exclusions (--exclude) with DEFAULT_EXCLUDE_PATTERNS from utils/exclude_patterns.py using set union operations. Output containers (files, abstractions, relationships, chapter_order, chapters, and final_output_dir) are initialized to empty collections or None, ready for mutation by pipeline nodes like FetchRepo, ContextRouter, and WriteChapters.

    detect_llm_config()

    Visibility: Public
    Signature: def detect_llm_config(args: argparse.Namespace) -> tuple[str, str, str, str, int]:

    Description:
    Inspects the process runtime environment to identify the active LLM provider, target model name, API endpoint URL, and authentication credentials. It computes the active context window length by checking for a --max-tokens CLI override or querying get_model_context_length() from utils/call_llm.py.

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.call_llm import get_model_context_length

    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length

    The configuration detector checks LLM_PROVIDER in os.environ. When present, it dynamically constructs provider-prefixed environment keys ({PROVIDER}_MODEL, {PROVIDER}_BASE_URL, {PROVIDER}_API_KEY). If LLM_PROVIDER is unset, it checks for GEMINI_PROJECT_ID or GEMINI_API_KEY to default to Google Gemini (gemini-3.7-flash at generativelanguage.googleapis.com). If no recognized credentials exist, it defaults to "UNKNOWN". Finally, it evaluates context window capacity: if --max-tokens was supplied via CLI, it takes precedence; otherwise, get_model_context_length() queries remote endpoint capabilities or internal fallback tables.

    Parameters: * args (argparse.Namespace): Parsed CLI command-line arguments (evaluating args.max_tokens).

    Returns: * tuple[str, str, str, str, int]: A 5-tuple containing (provider, model_name, endpoint_url, api_key, context_length).

    Raises: * None (absorbs missing environment keys and returns fallback strings).

    Example:

    def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))

    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block

    _run_cleanup()

    Visibility: Private
    Signature: def _run_cleanup() -> None:

    Description:
    Executes cleanup of disk caches and diagnostic logs. It deletes llm_cache.json and removes the entire runtime log directory defined by LOG_DIR (defaulting to ./logs).

    def _run_cleanup():
    """Clean up cache files and log directory."""
    import shutil

    emit("CLEANUP_START")

    for cache_path in ["llm_cache.json"]:
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                emit("CLEANUP_REMOVED", path=cache_path)
            except Exception as e:
                emit("CLEANUP_FAILED", path=cache_path, error=e)

    log_dir = os.environ.get("LOG_DIR", "logs")
    if os.path.exists(log_dir) and os.path.isdir(log_dir):
        try:
            shutil.rmtree(log_dir)
            emit("CLEANUP_REMOVED_DIR", path=log_dir)
        except Exception as e:
            emit("CLEANUP_FAILED", path=log_dir, error=e)

    This function handles maintenance tasks triggered by the --cleanup flag (executed either standalone or as a post-generation step). It iterates through known cache files (llm_cache.json), safely deleting them while intercepting and logging file system exceptions. It then queries LOG_DIR from the environment (defaulting to "logs"), recursively purging the entire directory tree via shutil.rmtree(). All operations emit structured events (CLEANUP_START, CLEANUP_REMOVED, CLEANUP_REMOVED_DIR, CLEANUP_FAILED) through the telemetry system.

    Parameters: * None.

    Returns: * None

    Raises: * None (all OSError and file system exceptions are caught and logged via emit("CLEANUP_FAILED", ...)).

    Example:

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description:
    The central orchestration loop of the application. It bootstraps the CLI runtime, loads environment variables, sets up telemetry and logging, validates source paths and cache constraints, constructs the shared state store, triggers the execution flow, and runs optional cleanup routines.

    def main():
    parser, args = parse_arguments()
    init_output(
        language=args.language,
        use_cache=not args.no_cache,
        thinking_level=args.thinking_level,
    )

    # Handle standalone --cleanup (no --dir or --repo)
    if args.cleanup and not args.dir and not args.repo:
        _run_cleanup()
        return

    # Require --dir or --repo for generation
    if not args.dir and not args.repo:
        parser.error("one of the arguments --repo --dir --cleanup is required")

    # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get("GITHUB_TOKEN")
        if not github_token:
            emit("WARN_NO_GITHUB_TOKEN")

    mode, project_name = resolve_mode_and_project(args)

    # Enforce incremental cache constraints
    if args.incremental and mode != "api-reference":
        emit("WARN_INCREMENTAL_API_ONLY")
        args.incremental = False

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        output_base = args.output or "output"
        manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
        if os.path.exists(manifest_path):
            os.remove(manifest_path)
            emit("FORCE_REBUILD_DELETED", path=manifest_path)
        else:
            emit("FORCE_REBUILD_NO_MANIFEST", path=manifest_path)
    elif args.force_rebuild and not args.incremental:
        emit("WARN_FORCE_REBUILD_NO_INCREMENTAL")

    shared = build_shared_store(args, github_token, mode)
    provider, model_name, endpoint_url, _, context_length = detect_llm_config(args)
    log_file = configure_logging(project_name=project_name, mode=mode)
    display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file)

    # Create and run the flow
    tutorial_flow = create_tutorial_flow()
    tutorial_flow.run(shared)

    # Cleanup after run if requested
    if args.cleanup:
        _run_cleanup()

    main() enforces the top-level execution lifecycle. It starts by initializing the internationalized output engine via init_output(). If a standalone --cleanup run is detected, it runs _run_cleanup() and exits early. Otherwise, it verifies that either --dir or --repo was supplied, raising a parser error if both are missing. For remote repositories, it checks for GitHub authentication credentials, warning the user via WARN_NO_GITHUB_TOKEN if rate limits may apply.

    It then enforces mode rules: --incremental mode is restricted to api-reference documentation styles (downgrading and warning the user if set otherwise). When --force-rebuild is active alongside --incremental, it deletes .doc_cache_manifest.json from the output directory to force complete regeneration. Once state validation finishes, it constructs the shared dictionary, detects LLM provider settings, initializes timestamped file logging via configure_logging(), and prints the configuration summary. Finally, it compiles and runs the PocketFlow DAG via tutorial_flow.run(shared), followed by post-run cleanup if requested.

    Parameters: * None.

    Returns: * None

    Raises: * SystemExit: Triggered via parser.error() if neither --dir, --repo, nor standalone --cleanup is provided.

    Example: 

    if __name__ == "__main__":
    main()

    Detailed Shared Store Contract

    The shared dictionary constructed by build_shared_store() serves as the core state bus across the pipeline. The table below details all keys, data types, and the nodes responsible for reading and writing them:

    Key Name Data Type Originating / Mutating Node Consuming Nodes Description
    repo_url str | None main.py FetchRepo Remote GitHub repository URL.
    local_dir str | None main.py FetchRepo Host filesystem directory path.
