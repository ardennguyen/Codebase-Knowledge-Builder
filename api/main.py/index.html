    main.py

    Source: main.py

    Technical Overview

    Building upon the pipeline topologies established in flow.py, main.py serves as the primary command-line interface (CLI) entry point and runtime orchestrator for the Codebase-Knowledge-Builder application. It encapsulates the complete lifecycle of documentation generation, starting with environment variable ingestion via dotenv, command-line argument parsing, and defensive validation of user inputs. The module coordinates fail-fast authentication checks against configured Large Language Model (LLM) providers before allocating system resources or initiating repository extraction.

    Architecturally, main.py resolves execution parameters—such as operational documentation styles, reasoning profiles, token context ceilings, and file exclusion filters—and packages them into a centralized, mutable dictionary known as the shared store. It initializes the centralized logging and console formatting bus, detects provider-specific model metadata, and binds runtime states to the Directed Acyclic Graph (DAG) constructed by flow.create_tutorial_flow. In addition to managing pipeline initiation, the module ensures robust finalization by executing post-run cleanup routines and emitting multi-provider token usage ledgers and cost analytics even when upstream node executions fail.

    resolve_mode_and_project(args)

    Visibility: Public

    Signature: def resolve_mode_and_project(args):

    Description: Normalizes the active documentation mode and extracts a default project identifier if one was not explicitly supplied via CLI flags. Resolves backward compatibility for the legacy --advanced boolean switch against modern --mode options and strips trailing .git extensions or directory path prefixes.

    Parameters:

    • args (argparse.Namespace): Parsed CLI options containing mode, advanced, name, dir, and repo.

    Returns:

    • tuple[str, str]: A 2-tuple of (mode, project_name) where mode is one of "tutorial", "advanced", "api-reference", or "sdk", and project_name is a sanitized string.

    Example:

    mode, project_name = resolve_mode_and_project(args)

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1].removesuffix(".git")
        else:
            project_name = "project"
    return mode, project_name

    This function performs resolution precedence between the legacy --advanced switch and the newer multi-mode --mode flag, emitting an alert via emit() if both are supplied concurrently. If no explicit project name is provided via -n / --name, the function derives the identifier by taking the directory name of --dir or the final path segment of --repo, removing .git suffixes where present.

    Parameters:

    • args (argparse.Namespace): The parsed command-line argument object.
    • github_token (str | None): GitHub Personal Access Token resolved from CLI or environment variables.
    • mode (str): Resolved documentation mode string.
    • thinking_plan (dict[str, str | None]): Mapping of node identifier strings to their allocated thinking effort levels.
    • project_name (str): Derived or explicitly specified project name.

    Returns:

    • dict[str, Any]: The initialized shared store dictionary containing configuration options, exclusion sets, and mutable output slots.

    Example:

    shared = build_shared_store(args, github_token, mode, thinking_plan, project_name)

    def build_shared_store(args, github_token, mode, thinking_plan, project_name):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": project_name,  # Resolved once in main so logs, --force-rebuild and output agree
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities: global level (legacy) + per-node plan (utils/thinking.py)
        "thinking_level": args.thinking_level,
        "thinking_plan": thinking_plan,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    The returned dictionary acts as the single source of truth across the entire lifecycle of the DAG execution. It combines user-specified exclusion rules with DEFAULT_EXCLUDE_PATTERNS imported from utils/exclude_patterns.py, sets up boolean switches for caching (use_cache = not args.no_cache), and primes list and dictionary containers (files, abstractions, relationships, chapters) that will be mutated by subsequent processing nodes.

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.llm_config import get_model_context_length

    resolve_thinking_plan(args)

    Visibility: Public

    Signature: def resolve_thinking_plan(args):

    Description: Pure function that reconciles reasoning configurations across global CLI overrides, named thinking profiles, and per-node overrides into a comprehensive thinking schedule dictionary. Because it executes prior to localization catalogue initialization (init_output()), it avoids console side effects and defers argument validation messaging to _validate_thinking_args.

    Parameters:

    • args (argparse.Namespace): Parsed CLI arguments containing advanced, mode, thinking_override, thinking_level, and thinking_profile.

    Returns:

    • tuple[str, dict[str, str | None], list[str]]: A 3-tuple comprising:
      1. Resolved profile name string (e.g., "balanced", "global", "off").
      2. Dictionary mapping each pipeline node identifier to its resolved effort string or None.
      3. List of unrecognized or malformed per-node override strings.

    Example:

    thinking_profile, thinking_plan, invalid_overrides = resolve_thinking_plan(args)

    def resolve_thinking_plan(args):
    """Build the per-node thinking plan from --thinking-override / --thinking-level / --thinking-profile.

    Pure (no emit): runs before init_output(). Validation messages come from _validate_thinking_args().

    Returns:
        tuple[str, dict, list[str]]: (resolved profile name, {node_key: level | None}, invalid override strings)
    """
    mode = "advanced" if args.advanced else args.mode
    overrides, invalid = parse_overrides(args.thinking_override)
    profile = "global" if args.thinking_level else resolve_profile_name(args.thinking_profile, resolve_llm_settings()[0])
    return profile, build_thinking_plan(profile, mode, args.thinking_level, overrides), invalid

    By leveraging functions imported from utils/thinking.py, this method establishes strict precedence: individual --thinking-override flags take priority over global --thinking-level values, which in turn supersede baseline --thinking-profile defaults. It determines whether a provider natively supports reasoning, generating a granular execution map passed to both UI emission and downstream generation nodes.

    Parameters:

    Returns:

    • None

    Phase 1: CLI Parsing and Pre-Initialization

        parser, args = parse_arguments()
    # Resolved silently before init_output(): string translation itself uses the plan's translate_strings level.

The localization catalog in init_output is initialized with dynamic string translation disabled (auto_translate=False) to ensure that preflight checks and argument parsing complete without invoking LLM inference endpoints prematurely. Immediate calls to _check_quoting_errors and _validate_thinking_args guard against corrupted command-line invocations.

    Phase 2: Argument Validation and Standalone Cleanup

        # Handle standalone --cleanup (no --dir or --repo)
    if args.cleanup and not args.dir and not args.repo:
        _run_cleanup()
        return

    # Require --dir or --repo for generation
    if not args.dir and not args.repo:
        parser.error("one of the arguments --repo --dir --cleanup is required")

    # Fail fast (with setup instructions) before crawling if the configured provider cannot authenticate
    if not check_llm_auth():

    translate_missing_strings()
    notice_legacy_cache()

    In this phase, main() checks if the invocation is a standalone maintenance operation (--cleanup). If not, it enforces that either a remote repository (--repo) or local directory (--dir) was provided. It then evaluates check_llm_auth() from utils/llm_config.py, failing fast with system exit code 1 if credentials or required SDK dependencies are missing. Once authenticated, any untranslated UI strings are synchronized via translate_missing_strings(), and legacy cache warnings are checked.

    Phase 3: Token Resolution and Cache Setup

        # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get("GITHUB_TOKEN")
        if not github_token:
            emit("WARN_NO_GITHUB_TOKEN")
    elif args.token:
        emit("WARN_TOKEN_NO_REPO")

    mode, project_name = resolve_mode_and_project(args)

    # Enforce incremental cache constraints
    if args.incremental and mode != "api-reference":
        emit("WARN_INCREMENTAL_API_ONLY")
        args.incremental = False

    # --force-rebuild requires --incremental
    if args.force_rebuild and not args.incremental:
        emit("ERROR_FORCE_REBUILD_NO_INCREMENTAL")
        sys.exit(1)

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        output_base = args.output or "output"
        manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
        if os.path.exists(manifest_path):
            os.remove(manifest_path)
            emit("FORCE_REBUILD_DELETED", path=manifest_path)
        else:
            emit("FORCE_REBUILD_NO_MANIFEST", path=manifest_path)
        # The verified-facts cache (ExtractFacts) lives in facts.json: docs/api/ under --mkdocs, else next to the pages

    _check_quoting_errors(parser, args)

    Visibility: Private

    Signature: def _check_quoting_errors(parser, args):

    Description: Defensive shell syntax validator that inspects pattern values under --exclude and --include for swallowed CLI options. Detects scenarios where unescaped shell quotes cause subsequent flags (e.g., --language, --dir) to be merged into pattern strings, terminating the program before silent execution errors occur.

    Parameters:

    • parser (argparse.ArgumentParser): The argument parser instance used to extract registered option strings.
    • args (argparse.Namespace): Parsed CLI argument values.

    Returns:

    • None

    Raises:

    • SystemExit: Halts execution via sys.exit(1) if any pattern string contains a known CLI option flag.

    Example:

    _check_quoting_errors(parser, args)

    def _check_quoting_errors(parser, args):
    """Detect shell quoting errors where --exclude/--include values accidentally swallowed other CLI flags.

    When users misquote patterns (e.g., --exclude "autogen/* "SmartFO/*" --language Vietnamese),
    the shell merges subsequent flags into the pattern value. This silently causes ALL following
    arguments to be ignored. We detect this by checking if any pattern value contains a known
    CLI flag string, which no legitimate file/directory pattern would ever contain.

    Flags are extracted dynamically from the argparse parser — no hardcoded list to maintain.
    """
    # Extract all registered flags (both --long and -short) from the parser
    known_flags = set()
    for action in parser._actions:
        for opt in action.option_strings:
            known_flags.add(opt)

    for pattern_list, flag_name in [(args.exclude, "--exclude"), (args.include, "--include")]:
        if not pattern_list:
            continue
        for pattern in pattern_list:
            for known_flag in known_flags:
                if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
                    emit(
                        "ERROR_QUOTING",
                        flag=flag_name,
                        pattern=pattern[:120],
                        embedded=known_flag,
                    )
                    sys.exit(1)

    This helper protects against a common shell quoting bug where a missing closing quote on glob arguments causes the shell interpreter to absorb adjacent command-line flags into the glob string. It dynamically inspects all registered option strings across parser._actions without requiring hardcoded flag registries. If an embedded flag pattern is found, it reports an ERROR_QUOTING diagnostic and exits immediately.

    Error Handling

    The module implements defensive validation patterns to catch configuration problems and missing credentials before executing long-running workflows:

    • Custom CLI Type Validation: The _thinking_level_arg helper converts unrecognized --thinking-level strings into argparse.ArgumentTypeError, triggering standard CLI usage output and halting execution.
    • Shell Quoting Inspection: The _check_quoting_errors function dynamically checks parsed --include and --exclude patterns against registered option flags. If a flag is embedded within a pattern, it emits an ERROR_QUOTING diagnostic and exits with code 1.
    • Reasoning Plan Validation: _validate_thinking_args inspects the results of resolve_thinking_plan. If malformed override tokens are present, it emits an ERROR_THINKING_OVERRIDE listing valid node keys and thinking tiers, exiting with code 1.
    • Preflight Authentication Failure: Prior to file crawling, main() invokes check_llm_auth(). If the provider's API key is missing or the client SDK fails initialization, the program exits with code 1.
    • Flag Incompatibility Checks: Contradictory flag combinations—such as combining --force-rebuild without --incremental, or applying --incremental to modes other than api-reference—are caught and either normalized with warnings or terminated with errors.
    • Resilient Teardown: The core workflow is wrapped in a try...finally block inside main(). This guarantees that _emit_usage_summary() and output.shutdown() execute to flush logs and report token usage even when pipeline nodes raise unhandled exceptions.
