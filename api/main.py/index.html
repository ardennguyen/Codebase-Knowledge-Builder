    main.py

    Source: main.py

    Following the orchestration framework detailed in flow.py—which compiles repository ingestion, abstraction modeling, fact auditing, and chapter composition into a Directed Acyclic Graph (DAG)—the main.py module serves as the command-line interface (CLI) entry point and system bootstrapper for the entire Codebase-Knowledge-Builder application. It translates raw shell arguments, environment variables, and provider settings into the runtime state required by the downstream graph pipeline.

    Technical Overview

    main.py provides the operational boundary between external execution environments (such as terminal shells, automation scripts, and CI/CD containers) and internal graph-processing pipelines. It orchestrates preflight validation, runtime configuration detection, subsystem initialization, credential verification, and graceful shutdown handling. By decoupling CLI option parsing from pipeline execution, main.py ensures that all external options—ranging from repository targets and include/exclude globs to reasoning token budgets and incremental cache policies—are fully validated and normalized before any compute-intensive or billable model inference tasks execute.

    The module manages critical pre-flight operations that prevent silent failures and resource waste. It inspects CLI input strings for accidental shell quoting issues that could inadvertently swallow options, resolves documentation generation modes (tutorial, advanced, api-reference, sdk), detects and binds LLM provider credentials via utils/llm_config.py, and builds the per-node reasoning plan via utils/thinking.py. Furthermore, it configures centralized logging and terminal telemetry via utils/output.py, synchronizes localization catalogs via utils/i18n.py, and manages incremental cache invalidations alongside ground-truth fact stores via utils/facts.py.

    At runtime, main.py packages all validated parameters, target specifications, pattern sets, and empty workflow accumulator slots into a single shared dictionary (shared). It then initializes the PocketFlow graph using create_tutorial_flow() from flow.py and triggers execution. Regardless of whether the execution succeeds, fails, or is interrupted, a robust try...finally block guarantees that full token usage ledgers, cost approximations, and diagnostic logs are emitted before resources are released via shutdown().

    parse_arguments()

    Visibility: Public
    Signature: def parse_arguments() -> tuple[argparse.ArgumentParser, argparse.Namespace]:

    Description: Configures and executes the command-line argument parser for the application. It establishes mutually exclusive ingestion source groups (--repo vs. --dir), configures target output directories, sets path inclusion and exclusion globs, specifies file size thresholds, and sets localized generation languages. Additionally, it binds complex LLM execution flags such as thinking effort levels, reasoning profiles, per-node overrides, context token ceilings, batching thresholds, and documentation generation modes (tutorial, advanced, api-reference, sdk).

    def parse_arguments():
    """Parse and return command-line arguments."""
    parser = argparse.ArgumentParser(description="Generate a tutorial for a GitHub codebase or local directory.")

    # Source: --repo or --dir (mutually exclusive but not required if --cleanup is used)

    source_group.add_argument("--repo", help="URL of the public GitHub repository.")

    parser.add_argument("-i", "--include", nargs="+", help="Files to include (e.g., '*.py' '*.js'). Defaults to '*' (all files).")
    parser.add_argument(
        "-e",
        "--exclude",
        nargs="+",
        help="Files to exclude. Custom patterns are automatically merged with a massive global exclusion list (build caches, node_modules, binaries, media, AI environments) AND your repository's native .gitignore rules.",
    )
    parser.add_argument("-s", "--max-size", type=int, default=200000, help="Maximum file size in bytes (default: 200000, about 200KB).")
    # Add language parameter for multi-language support
    parser.add_argument("--language", default="english", help="Language for the generated tutorial (default: english).")
    # Add use_cache parameter to control LLM caching
    parser.add_argument("--no-cache", action="store_true", help="Disable LLM response caching (default: caching enabled).")
    # Add max_abstraction_num parameter to control the number of abstractions
    parser.add_argument("--max-abstractions", type=int, default=10, help="Maximum number of abstractions to identify (default: 10).")
    # Add thinking_level parameter for LLM reasoning capabilities

        "--thinking-profile",
        default="auto",
        type=str.lower,
        choices=THINKING_PROFILES,
        help="Per-node thinking effort profile (default: auto = balanced on ANTHROPIC, GEMINI and OPENROUTER, off elsewhere). "
        "economy/balanced/quality/max give reasoning-heavy nodes (abstractions, relationships) more effort than "
        "mechanical ones (summaries, translation), adjusted per --mode. off = model defaults.",
    )
    parser.add_argument(
        "--thinking-override",
        nargs="+",
        metavar="NODE=LEVEL",
        help=f"Per-node thinking level overrides, highest precedence (e.g., write_chapters=high identify_abstractions=xhigh). NODE: {', '.join(NODE_KEYS)}.",
    )
    # Add max_tokens parameter
    parser.add_argument(
        "--max-tokens", type=int, default=None, help="Maximum number of tokens for the context window (default: fetched dynamically)."
    )

    # --- Documentation Mode & Generation Styles ---
    parser.add_argument(
        "--mode",
        choices=["tutorial", "advanced", "api-reference", "sdk"],
        default="tutorial",
        help="Documentation style (tutorial, advanced, api-reference, sdk). (default: tutorial).",
    )
    parser.add_argument("--advanced", action="store_true", help="Legacy flag: equivalent to --mode advanced.")
    parser.add_argument("--mkdocs", action="store_true", help="Format output for MkDocs Material (adds YAML frontmatter & nav snippet).")
    parser.add_argument(

    The argument parser establishes the complete operational parameters of the system. Mutually exclusive groups guarantee that a run targets either a remote GitHub URL or a local directory path, while permitting standalone invocations of --cleanup. Advanced flags like --thinking-level, --thinking-profile, and --thinking-override delegate parsing and type coercion to helper utilities like _thinking_level_arg and utils/thinking.py. The parser also handles backwards compatibility via --advanced (which maps to --mode advanced) and enforces constraints around API reference generation features, including --incremental and --force-rebuild.

    resolve_mode_and_project()

    Visibility: Public
    Signature: def resolve_mode_and_project(args: argparse.Namespace) -> tuple[str, str]:

    Description: Resolves conflicts between legacy flags and explicit generation modes, and deterministically derives the project name from repository URLs or local filesystem paths when omitted by the user.

    Parameters: * args (argparse.Namespace): Parsed command-line arguments containing options such as advanced, mode, name, dir, and repo.

    Returns: * tuple[str, str]: A 2-tuple containing the normalized generation mode string (mode) and the resolved project identifier (project_name).

    Example: 

    mode, project_name = resolve_mode_and_project(args)
# mode -> "advanced", project_name -> "my-repo"


    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1].removesuffix(".git")
        else:
            project_name = "project"
    return mode, project_name

    This function resolves the documentation generation style. If the user passes the legacy --advanced flag while simultaneously specifying a non-default --mode (e.g., api-reference), it warns the user via emit() and overrides the mode to advanced. If the project name is not explicitly passed via -n/--name, it safely parses local absolute paths via os.path.basename(os.path.abspath(args.dir)) or extracts the trailing URL component from git targets, stripping trailing slashes and the .git suffix. If no source target is supplied, it falls back to "project".

    Parameters: * args (argparse.Namespace): Parsed CLI argument values. * github_token (str | None): Authenticated GitHub personal access token, if resolved. * mode (str): Resolved documentation generation mode. * thinking_plan (dict[str, str | None]): Mapping of workflow node keys to reasoning effort tiers. * project_name (str): Resolved project identifier.

    def build_shared_store(args, github_token, mode, thinking_plan, project_name):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": project_name,  # Resolved once in main so logs, --force-rebuild and output agree
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities: global level (legacy) + per-node plan (utils/thinking.py)
        "thinking_level": args.thinking_level,
        "thinking_plan": thinking_plan,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    The shared store functions as the central communication bus across the Directed Acyclic Graph instantiated by create_tutorial_flow(). File exclusion patterns are computed by taking the union of the built-in DEFAULT_EXCLUDE_PATTERNS from utils/exclude_patterns.py and any user-provided exclusion globs passed via CLI flags. Empty output slots (files, abstractions, relationships, chapter_order, chapters, and final_output_dir) are initialized as mutable data structures, allowing nodes in nodes.py to inspect and populate results as execution moves through the graph.

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.llm_config import get_model_context_length

    provider, model_name, endpoint_url, api_key = resolve_llm_settings()
    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length

    This helper wraps resolve_llm_settings() from utils/llm_config.py. If the user explicitly provided --max-tokens on the command line, that integer takes precedence. Otherwise, it delegates context resolution to get_model_context_length(), which queries provider endpoints or applies static fallback defaults. This ensures that downstream batching decisions in ContextRouter have an accurate token budget to evaluate against repository size.

    Parameters: * args (argparse.Namespace): Parsed command-line arguments containing options such as thinking_override, thinking_level, thinking_profile, and mode flags.

    Returns: * tuple[str, dict[str, str | None], list[str]]: A 3-tuple containing: 1. The resolved profile name (str). 2. The thinking plan mapping node names to reasoning tiers (dict[str, str | None]). 3. A list of any invalid override tokens detected (list[str]).

    def resolve_thinking_plan(args):
    """Build the per-node thinking plan from --thinking-override / --thinking-level / --thinking-profile.

    Pure (no emit): runs before init_output(). Validation messages come from _validate_thinking_args().

    Returns:
        tuple[str, dict, list[str]]: (resolved profile name, {node_key: level | None}, invalid override strings)
    """
    mode = "advanced" if args.advanced else args.mode
    overrides, invalid = parse_overrides(args.thinking_override)
    profile = "global" if args.thinking_level else resolve_profile_name(args.thinking_profile, resolve_llm_settings()[0])
    return profile, build_thinking_plan(profile, mode, args.thinking_level, overrides), invalid

    This function computes the reasoning configuration before logging is initialized. It isolates parsing logic from the terminal emission system to avoid circular dependencies during startup. By obtaining the resolved level for translate_strings early, the application can initialize the output subsystem using the correct reasoning tier for automated translation calls in utils/i18n.py.

    def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file, thinking_profile, thinking_plan):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_THINKING_PROFILE", value=thinking_profile)
    if any(thinking_plan.values()):
        emit("CFG_THINKING_PLAN", value=describe_plan(thinking_plan, mode))
    emit("CFG_THINKING_SUPPORT", value=describe_thinking_support(provider, model_name))
    emit("CFG_TOKEN_RATIO", value=describe_token_ratio())
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))
    else:
        emit("CFG_MAX_ABSTRACTIONS", value=str(args.max_abstractions))
    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block

    The configuration banner outputs localized diagnostic information via emit() and get() from utils/output.py. It displays runtime provider characteristics, formatted context lengths, thinking profile settings, and dynamic token ratio estimates calculated by utils/token_utils.py. It also dynamically formats parameter values based on the active mode (for example, showing CFG_VALUE_API_REF_MAX when --mode api-reference is set, since abstraction limits are bypassed during deterministic module mapping).

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description: The primary entry point and orchestrator for the Codebase-Knowledge-Builder runtime. It coordinates argument parsing, shell quoting validation, output subsystem initialization, provider credential checks, cache and fact pruning, shared store setup, graph execution, and final telemetry reporting.

    Phase 1: Argument Parsing and Preflight Reasoning Setup

        parser, args = parse_arguments()

    )

    _validate_thinking_args(args, invalid_overrides)
    The application first parses command-line arguments and constructs the thinking plan. It initializes the output subsystem with auto_translate=False to defer model inference until authentication credentials have been verified. Next, it evaluates user inputs using _check_quoting_errors() to prevent shell quoting bugs from swallowing flags, and validates thinking arguments using _validate_thinking_args().

    Phase 2: Standalone Cleanup and Ingestion Target Validation

        # Handle standalone --cleanup (no --dir or --repo)
    if args.cleanup and not args.dir and not args.repo:
        _run_cleanup()
        return

    # Require --dir or --repo for generation
    if not args.dir and not args.repo:
        parser.error("one of the arguments --repo --dir --cleanup is required")

    # Fail fast (with setup instructions) before crawling if the configured provider cannot authenticate
    if not check_llm_auth():
        sys.exit(1)
    translate_missing_strings()
    notice_legacy_cache()
    The orchestrator checks if --cleanup was invoked without a target repository or directory; if so, it triggers cache and log removal via _run_cleanup() and terminates immediately. For documentation runs, it verifies that either --dir or --repo was supplied. Before initiating repository crawling, it calls check_llm_auth() to verify provider credentials and fails fast if authentication is invalid. Once verified, it translates missing UI strings via translate_missing_strings() and warns about any deprecated cache files via notice_legacy_cache().

    Phase 3: Token Resolution and Mode Normalization

        # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get("GITHUB_TOKEN")
        if not github_token:
            emit("WARN_NO_GITHUB_TOKEN")
    elif args.token:
        emit("WARN_TOKEN_NO_REPO")

    mode, project_name = resolve_mode_and_project(args)

    # Enforce incremental cache constraints
    if args.incremental and mode != "api-reference":
        emit("WARN_INCREMENTAL_API_ONLY")
        args.incremental = False

    # --force-rebuild requires --incremental
    if args.force_rebuild and not args.incremental:
        emit("ERROR_FORCE_REBUILD_NO_INCREMENTAL")
        sys.exit(1)

    def _thinking_level_arg(value):

    _check_quoting_errors()

    Visibility: Private
    Signature: def _check_quoting_errors(parser: argparse.ArgumentParser, args: argparse.Namespace) -> None:

    Description: Scans pattern arguments (--exclude and --include) to detect shell quoting mistakes where whitespace or quote issues caused subsequent CLI options to be merged into pattern strings.

    Parameters: * parser (argparse.ArgumentParser): The parser instance, used to dynamically introspect registered flag strings. * args (argparse.Namespace): Parsed CLI arguments containing include and exclude pattern lists.

    Returns: * None

    Raises: * SystemExit: Exits with status code 1 via sys.exit(1) if a quoting error is detected.

    Example: 

    _check_quoting_errors(parser, args)


    def _check_quoting_errors(parser, args):
    """Detect shell quoting errors where --exclude/--include values accidentally swallowed other CLI flags.

    When users misquote patterns (e.g., --exclude "autogen/* "SmartFO/*" --language Vietnamese),
    the shell merges subsequent flags into the pattern value. This silently causes ALL following
    arguments to be ignored. We detect this by checking if any pattern value contains a known
    CLI flag string, which no legitimate file/directory pattern would ever contain.

    Flags are extracted dynamically from the argparse parser — no hardcoded list to maintain.
    """
    # Extract all registered flags (both --long and -short) from the parser
    known_flags = set()
    for action in parser._actions:
        for opt in action.option_strings:
            known_flags.add(opt)

    for pattern_list, flag_name in [(args.exclude, "--exclude"), (args.include, "--include")]:
        if not pattern_list:
            continue
        for pattern in pattern_list:
            for known_flag in known_flags:
                if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
                    emit(
                        "ERROR_QUOTING",
                        flag=flag_name,
                        pattern=pattern[:120],
                        embedded=known_flag,
                    )
                    sys.exit(1)

    Shell misquoting is a common source of user error in CLI tools that accept multiple arguments. For instance, inputting --exclude "target/* "src/*" --language Vietnamese can cause the shell to treat --language and Vietnamese as part of the --exclude pattern rather than distinct options. To prevent the application from silently ignoring flags, this function extracts all valid option strings from the ArgumentParser instance and checks if any pattern contains an embedded flag surrounded by spaces or at the end of the string. If a match is found, it emits ERROR_QUOTING with the offending pattern snippet and terminates execution.

    Error Handling

    main.py applies defensive validation patterns at startup to intercept misconfigurations before expensive model calls or disk operations occur:

    • Quoting Error Interception (_check_quoting_errors): Catches shell quoting mistakes in pattern lists (such as --exclude "dir/* "other/*"). It inspects pattern values for registered CLI option strings and terminates execution with an ERROR_QUOTING message, preventing subsequent flags from being silently ignored.
    • Fail-Fast Authentication (check_llm_auth): Calls check_llm_auth() to verify provider credentials and reachability before crawling files. If authentication fails, the process terminates immediately with exit code 1 rather than failing mid-pipeline during chapter generation.
    • Thinking Validation and Sanitization (_validate_thinking_args): Rejects malformed per-node override strings via _validate_thinking_args(), displaying supported nodes (NODE_KEYS) and reasoning tiers (THINKING_LEVELS). It also warns if overrides target nodes that are not used by the selected --mode, or if a global --thinking-level conflicts with a --thinking-profile.
    • Incremental Cache Consistency: Restricts --incremental caching to --mode api-reference. If passed with other modes, it logs a warning (WARN_INCREMENTAL_API_ONLY) and disables the flag. It also verifies that --force-rebuild is only used alongside --incremental, exiting with an error if used independently.
    • Safe Cleanup Exception Handling (_run_cleanup): Catches and logs filesystem errors using CLEANUP_FAILED when removing cache files or log folders, allowing cleanup to proceed through remaining files rather than failing on the first error.
    • Guaranteed Teardown Telemetry (main try...finally): Wraps flow execution in a try...finally block. Regardless of whether the pipeline completes successfully, fails with an unhandled exception, or is canceled via keyboard interrupt, _emit_usage_summary() outputs token consumption metrics and costs before shutdown() releases log file handles.
