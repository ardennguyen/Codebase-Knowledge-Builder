    main.py

    Source: main.py

    Technical Overview

    Building upon the orchestration pipeline defined in flow.py, which coordinates PocketFlow nodes and directs workflow branches across execution modes, main.py serves as the primary executable entry point and CLI orchestration harness for the entire Codebase-Knowledge-Builder application. While flow.py models the abstract computation graph and execution dependencies, main.py grounds this topology in a concrete runtime context by parsing command-line parameters, discovering provider credentials, configuring logging and localization subsystems, and constructing the unified shared state store passed through the graph.

    The module encapsulates operational concerns including argument parsing, shell-escaping defect detection, documentation mode resolution, LLM environment introspection, incremental caching integrity checks, and post-execution cleanup routines. By abstracting these CLI and environment configurations, main.py ensures that whether an operator is targeting a remote public GitHub repository or a local filesystem directory, all configuration parameters—such as token budgets, exclusion globs, thinking budgets, and MkDocs site specifications—are normalized into the canonical shape expected by downstream nodes.

    The module operates as a deterministic bootstrap pipeline consisting of five distinct operational phases: CLI specification and parsing, quoting error validation, runtime environment and cache constraint resolution, unified shared state store construction, and PocketFlow graph execution.     Visibility: Public
    Signature: def parse_arguments() -> tuple[argparse.ArgumentParser, argparse.Namespace]:

    Description: Constructs the command-line interface specification using Python's standard argparse module, registering all mutually exclusive source groups, operational mode switches, token limits, exclusion patterns, and debugging parameters. It returns both the instantiated ArgumentParser instance and the resulting parsed Namespace. This dual return allows downstream components, specifically _check_quoting_errors, to inspect configured option strings dynamically directly from the parser actions without maintaining hardcoded flag lists.

    Parameters: * None.

    Returns: * tuple[argparse.ArgumentParser, argparse.Namespace]: A 2-tuple containing the configured argparse.ArgumentParser instance and the populated argparse.Namespace object containing parsed CLI values.

    Raises: * SystemExit: Automatically triggered by argparse if unrecognized arguments are passed or if required argument groups fail validation.

    resolve_mode_and_project()

    Visibility: Public
    Signature: def resolve_mode_and_project(args: argparse.Namespace) -> tuple[str, str]:

    Description: Normalizes the operational documentation mode and derives the target project name from CLI arguments and environment variables. If the legacy --advanced boolean flag is passed, it forces the mode to "advanced", issuing a warning if the operator simultaneously specified a non-tutorial --mode. If the operator does not supply an explicit project name via -n/--name, the function dynamically computes it by taking the trailing path component of --dir or the final segment of the repository URL --repo.

    Parameters: * args (argparse.Namespace): Parsed CLI command-line options.

    Returns: * tuple[str, str]: A 2-tuple containing the resolved documentation mode string (e.g., "tutorial", "advanced", "api-reference", "sdk") and the resolved project name string.

    Raises: * No exceptions raised directly; warnings are emitted via emit("WARN_ADVANCED_OVERRIDES_MODE").

    Implementation: 

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1]
        else:
            project_name = "project"
    return mode, project_name
    The resolution logic prioritizes explicit legacy flags before falling back to the designated args.mode. For project name resolution, the function normalizes filesystem directories using os.path.abspath() prior to invoking os.path.basename(), preventing empty string names when trailing directory slashes are provided on Unix systems. For remote repositories, trailing slashes are stripped via .rstrip("/") before extracting the final path token. If neither source is configured (for example, during standalone execution), it safely defaults to "project".

    def build_shared_store(args, github_token, mode):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": args.name,  # Can be None, FetchRepo will derive it
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities
        "thinking_level": args.thinking_level,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }
    The state constructor handles the union of custom exclude patterns with the global DEFAULT_EXCLUDE_PATTERNS constant imported from utils/exclude_patterns.py. The use_cache boolean is set to the logical inverse of args.no_cache. Crucially, output fields such as files, abstractions, and chapters are initialized as empty lists or dictionaries, providing deterministic mutation targets for FetchRepo, IdentifyAbstractions, OrderChapters, and WriteChapters in nodes.py.

    detect_llm_config()

    Visibility: Public
    Signature: def detect_llm_config(args: argparse.Namespace) -> tuple[str, str, str, str, int]:

    Description: Inspects runtime environment variables to determine the active LLM provider, target model name, API endpoint URL, authentication key, and model context length ceiling. If an explicit provider is declared via LLM_PROVIDER, it pulls provider-prefixed environment variables (such as {provider}_MODEL and {provider}_BASE_URL). If unset, it inspects Gemini-specific environment variables (GEMINI_PROJECT_ID or GEMINI_API_KEY) as a standard default fallback. When no explicit --max-tokens flag is passed via CLI, it invokes get_model_context_length from utils/call_llm.py to dynamically compute or query the model context ceiling.

    Parameters: * args (argparse.Namespace): Parsed command-line arguments (used to check args.max_tokens).

    Returns: * tuple[str, str, str, str, int]: A 5-tuple consisting of: 1. provider (str): The resolved provider key (e.g., "OPENROUTER", "GEMINI", "UNKNOWN"). 2. model_name (str): The target model identifier string. 3. endpoint_url (str): The API base endpoint URL. 4. api_key (str): The resolved API key string. 5. context_length (int): The maximum context window token limit.

    Raises: * No exceptions raised directly. Network or parsing failures during context retrieval degrade to default integer token limits.

    Implementation: 

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.call_llm import get_model_context_length

    provider = os.environ.get("LLM_PROVIDER")
    if provider:
        model_name = os.environ.get(f"{provider}_MODEL", "unknown")
        endpoint_url = os.environ.get(f"{provider}_BASE_URL", "unknown")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    else:
        # Fallback to Gemini if neither provider is explicitly set but it's used
        if os.environ.get("GEMINI_PROJECT_ID") or os.environ.get("GEMINI_API_KEY"):
            provider = "GEMINI"
            model_name = os.environ.get("GEMINI_MODEL", "gemini-3.7-flash")
            endpoint_url = "generativelanguage.googleapis.com"
            api_key = os.environ.get("GEMINI_API_KEY", "")
        else:
            provider = "UNKNOWN"
            model_name = "unknown"
            endpoint_url = "unknown"
            api_key = ""

    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length
    The helper relies on a late local import (from utils.call_llm import get_model_context_length) to avoid cyclic initialization issues during module load time. When evaluating context_length, args.max_tokens takes absolute precedence; if omitted, the remote model context boundary is evaluated through OpenRouter metadata endpoints or static heuristic tables mapped inside utils/call_llm.py.

    Description: Formats and outputs the complete operational configuration summary banner to the console before graph execution begins.     Returns: * None: Outputs formatted diagnostics directly to the operational log/console via emit().

    Raises: * No exceptions raised directly.

    Implementation: 

    def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))
    else:
        emit("CFG_MAX_ABSTRACTIONS", value=str(args.max_abstractions))
    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block
    The routine bridges the CLI parameters with the centralized localization framework in utils/output.py. Rather than printing hardcoded English strings to standard out, it dispatches internationalized tokens (START_GENERATION, CFG_HEADER, CFG_AI_PROVIDER, etc.) through emit(). It dynamically pulls localized representations for boolean statuses (CFG_VALUE_ENABLED vs CFG_VALUE_DISABLED) and accommodates special mode configurations, such as overriding numeric abstraction counts with dynamic indicators in API reference mode.

    main()

    Visibility: Public
    Signature: def main() -> None:

    Description: The top-level workflow orchestrator of the application. It parses input flags, validates shell quoting integrity, checks source target prerequisites, handles standalone cache cleanup, normalizes modes, enforces incremental compilation rules, initializes logging, builds the shared dictionary, creates the tutorial flow graph via flow.py, and triggers execution.

    Parameters: * None.

    Returns: * None.

    Raises: * SystemExit: Raised on quoting validation failure, missing source flags, or incompatible incremental rebuild configurations.

    Phase 1: CLI Intake, Output Initialization, and Quoting Validation

    def main():
    parser, args = parse_arguments()
    init_output(

        use_cache=not args.no_cache,
        thinking_level=args.thinking_level,
        debug=args.debug,
    )
    _check_quoting_errors(parser, args)

    # Handle standalone --cleanup (no --dir or --repo)
    if args.cleanup and not args.dir and not args.repo:
        _run_cleanup()
        return

    # Require --dir or --repo for generation
    if not args.dir and not args.repo:
        parser.error("one of the arguments --repo --dir --cleanup is required")
    # ...
    Phase 1 parses CLI arguments, boots the output rendering system via init_output(), and checks for shell quoting errors using _check_quoting_errors(). It then inspects standalone commands: if --cleanup is invoked without a codebase source (--dir or --repo), it executes _run_cleanup() and terminates immediately without raising an error. If neither a source directory nor a repository is supplied for a generation run, it halts with parser.error().

    Phase 2: Credentials and Mode Verification

        # ...
    # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get("GITHUB_TOKEN")
        if not github_token:
            emit("WARN_NO_GITHUB_TOKEN")

        emit("WARN_TOKEN_NO_REPO")

    mode, project_name = resolve_mode_and_project(args)

    if args.incremental and mode != "api-reference":
        emit("WARN_INCREMENTAL_API_ONLY")
        args.incremental = False

    # --force-rebuild requires --incremental
    if args.force_rebuild and not args.incremental:
        emit("ERROR_FORCE_REBUILD_NO_INCREMENTAL")
        sys.exit(1)
    # ...
    Phase 2 resolves authentication credentials and validates mode constraints. For GitHub repository targets, it checks the CLI argument -t/--token before falling back to the GITHUB_TOKEN environment variable, emitting a warning if no token is available for remote crawling. It resolves the operational mode and project name, then enforces incremental caching rules: --incremental is deactivated with a warning if used outside api-reference mode, and --force-rebuild triggers an immediate exit if invoked without --incremental.

    Internal Helpers

    _check_quoting_errors()

    Visibility: Private
    Signature: def _check_quoting_errors(parser: argparse.ArgumentParser, args: argparse.Namespace) -> None:

    Description: Detects shell quoting errors where values passed to multi-argument options (specifically --exclude and --include) accidentally absorb subsequent CLI flags. When an operator misquotes an argument string (such as --exclude "autogen/* "SmartFO/*" --language Vietnamese), Unix shells group all trailing flags into the pattern string, silently ignoring those CLI flags. This function extracts all registered flag options dynamically from parser._actions and checks if any pattern contains an embedded flag string. If a shell quoting error is detected, it emits an ERROR_QUOTING message and exits immediately.

    Parameters: * parser (argparse.ArgumentParser): The active CLI parser instance, used to dynamically discover registered flags. * args (argparse.Namespace): Parsed CLI arguments containing pattern lists to evaluate.

    Returns: * None.

    Raises: * SystemExit: Exits with status code 1 if an embedded flag is detected within any pattern string.

    Implementation: 

    def _check_quoting_errors(parser, args):
    """Detect shell quoting errors where --exclude/--include values accidentally swallowed other CLI flags.

    When users misquote patterns (e.g., --exclude "autogen/* "SmartFO/*" --language Vietnamese),
    the shell merges subsequent flags into the pattern value. This silently causes ALL following
    arguments to be ignored. We detect this by checking if any pattern value contains a known
    CLI flag string, which no legitimate file/directory pattern would ever contain.

    Flags are extracted dynamically from the argparse parser — no hardcoded list to maintain.
    """
    # Extract all registered flags (both --long and -short) from the parser
    known_flags = set()
    for action in parser._actions:
        for opt in action.option_strings:
            known_flags.add(opt)

    for pattern_list, flag_name in [(args.exclude, "--exclude"), (args.include, "--include")]:
        if not pattern_list:
            continue
        for pattern in pattern_list:
            for known_flag in known_flags:
                if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
                    emit(
                        "ERROR_QUOTING",
                        flag=flag_name,
                        pattern=pattern[:120],
                        embedded=known_flag,
                    )
                    sys.exit(1)
    The helper inspects all action.option_strings registered across the parser, discovering both short (-o) and long (--output) flags without maintaining a hardcoded list. It evaluates candidate patterns in both args.exclude and args.include. By checking for patterns containing " {flag} " (a flag surrounded by spaces) or ending with " {flag}", it catches swallowed arguments while avoiding false positives on file paths that might contain flag substrings without whitespace boundaries.

    Example: 

    # Invocation inside main() directly after argument parsing
parser, args = parse_arguments()
init_output(...)
_check_quoting_errors(parser, args)

    _run_cleanup()

    Visibility: Private
    Signature: def _run_cleanup() -> None:

    Description: Cleans up transient cache files and execution logs generated by the application. It deletes the persistent LLM disk cache (llm_cache.json) and removes the logging directory configured in LOG_DIR (defaulting to ./logs) using shutil.rmtree(). Deletion events, directories removed, and filesystem errors are reported via emit().

    Parameters: * None.

    Returns: * None.

    Raises: * No exceptions raised. Filesystem exceptions during deletion are caught and reported via emit("CLEANUP_FAILED", ...).

    Implementation: 

    def _run_cleanup():
    """Clean up cache files and log directory."""
    import shutil

    emit("CLEANUP_START")

    for cache_path in ["llm_cache.json"]:
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                emit("CLEANUP_REMOVED", path=cache_path)
            except Exception as e:
                emit("CLEANUP_FAILED", path=cache_path, error=e)

    log_dir = os.environ.get("LOG_DIR", "logs")
    if os.path.exists(log_dir) and os.path.isdir(log_dir):
        try:
            shutil.rmtree(log_dir)
            emit("CLEANUP_REMOVED_DIR", path=log_dir)
        except Exception as e:
            emit("CLEANUP_FAILED", path=log_dir, error=e)
    The cleanup routine uses dynamic scoped imports (import shutil) to manage directory removal without adding unnecessary top-level dependencies. It wraps filesystem deletions in try...except Exception blocks, ensuring that locked files or permission issues do not crash the application or prevent subsequent cleanup steps from executing.

    Example: 

    # Standalone cleanup path inside main()
if args.cleanup and not args.dir and not args.repo:
    _run_cleanup()
    return

    When operators misquote arguments containing wildcards (for instance, --exclude "vendor/* "src/*"), shells absorb subsequent CLI flags into the pattern string, silently dropping configuration flags. The _check_quoting_errors() function intercepts this by checking patterns against all registered parser options. When a pattern contains an embedded flag token, it aborts immediately:

    Mutually Exclusive Sources and Mandatory Intake Validation

    main.py uses parser.add_mutually_exclusive_group() to prevent specifying both --repo and --dir in a single run. If neither source is supplied, it checks for standalone --cleanup; if that flag is also absent, it calls parser.error(): 

    if not args.dir and not args.repo:
    parser.error("one of the arguments --repo --dir --cleanup is required")

    Incremental Cache Integrity Rules

    To prevent inconsistent build states, main.py enforces constraints around incremental cache flags: 1. --incremental is supported only in api-reference mode. If specified with other modes, it is disabled and a warning is emitted: 

    if args.incremental and mode != "api-reference":
    emit("WARN_INCREMENTAL_API_ONLY")
    args.incremental = False
    2. --force-rebuild requires --incremental. If used without --incremental, the program emits an error and exits: 
    if args.force_rebuild and not args.incremental:
    emit("ERROR_FORCE_REBUILD_NO_INCREMENTAL")
    sys.exit(1)

    Non-Fatal Cleanup Trapping

    Filesystem failures during cache purging or directory removal in _run_cleanup() are caught via except Exception as e and logged using emit("CLEANUP_FAILED", ...). This ensures transient file locks do not crash the application during teardown:
