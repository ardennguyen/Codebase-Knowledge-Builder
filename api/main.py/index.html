    main.py

    Source: main.py

    Building directly upon the declarative DAG workflow established in flow.py, main.py serves as the centralized command-line interface (CLI) entry point and execution harness for the Codebase-Knowledge-Builder application. It coordinates the end-to-end lifecycle of repository ingestion, preflight environment validation, LLM parameter resolution, and pipeline execution. The module interprets user flags, builds the underlying shared data store, evaluates reasoning budgets across pipeline stages, and invokes the PocketFlow DAG engine while enforcing strict exception safety and operational telemetry reporting.

    Architecturally, the entry script acts as an operational bridge between raw operating system environments and downstream analytical nodes. It performs proactive validation gates prior to crawling or invoking external APIs: evaluating CLI quoting semantics to prevent accidental flag swallowing, auditing model authentication credentials, verifying reasoning configuration boundaries, and enforcing cache consistency for incremental builds. Furthermore, through an encompassing execution wrapper, the module guarantees that multi-provider token usage summaries, refusal telemetry, and estimated financial costs are recorded and flushed to persistent logs even when upstream processes fail or abort unexpectedly.

    Public API

    DEFAULT_INCLUDE_PATTERNS

    Visibility: Public

    Signature: DEFAULT_INCLUDE_PATTERNS = {"*"}

    Description: Module-level constant defining the baseline file inclusion set applied when the user omits explicit -i or --include command-line filters. By default, it matches all repository paths, delegating path filtering to the crawler exclusion rules and native .gitignore specifications.

    Example:

    # Default file patterns
DEFAULT_INCLUDE_PATTERNS = {"*"}

    This default set guarantees that crawling subsystems inspect every path discovered during directory traversal or Git tree queries unless restricted by explicit patterns. When passed to the shared state dictionary, it is converted into a native Python set to enable fast inclusion membership tests against discovered relative file paths.

    resolve_mode_and_project()

    Visibility: Public

    Signature: def resolve_mode_and_project(args):

    Description: Normalizes the active documentation mode and derives the project identifier from command-line arguments. It handles legacy overrides where --advanced takes precedence over --mode, emits diagnostic warnings when mutually conflicting mode flags are detected, and falls back to inspecting directory basenames or sanitized Git repository URLs when a project name is not explicitly passed.

    Parameters:

    • args (argparse.Namespace): Parsed command-line options containing attributes advanced, mode, name, dir, and repo.

    Returns:

    • tuple[str, str]: A two-element tuple containing (mode, project_name).

    Example:

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1].removesuffix(".git")
        else:
            project_name = "project"
    return mode, project_name

    This routine guarantees that downstream filesystem paths, log file names, cache keys, and documentation titles share an identical, normalized project identifier. If a local directory is targeted, os.path.abspath ensures relative paths like . or .. resolve to the actual folder name rather than dot tokens.

    build_shared_store()

    Visibility: Public

    Signature: def build_shared_store(args, github_token, mode, thinking_plan, project_name):

    Description: Assembles the central shared state dictionary (shared) utilized by all PocketFlow workflow nodes across the pipeline. It merges CLI flags, default file inclusion patterns, and centralized exclusion lists, while initializing placeholder data structures for populated abstractions, relationships, file contents, and compiled chapters.

    Parameters:

    • args (argparse.Namespace): Parsed command-line arguments.
    • github_token (str | None): Validated GitHub personal access token, if resolved.
    • mode (str): Resolved documentation mode string.
    • thinking_plan (dict[str, str | None]): Mapping of node keys to their computed reasoning effort levels.
    • project_name (str): Normalized name of the target project.

    Returns:

    • dict: The initial shared store populated with runtime parameters, configuration sets, and empty output collections.

    Example:

    def build_shared_store(args, github_token, mode, thinking_plan, project_name):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": project_name,  # Resolved once in main so logs, --force-rebuild and output agree
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities: global level (legacy) + per-node plan (utils/thinking.py)
        "thinking_level": args.thinking_level,
        "thinking_plan": thinking_plan,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    The resulting dictionary acts as the thread-safe context object passed to pocketflow.Flow.run(). By merging DEFAULT_EXCLUDE_PATTERNS from utils/exclude_patterns.py with custom --exclude rules at initialization time, it guarantees that node implementations never crawl or process unwanted paths.

    detect_llm_config()

    Visibility: Public

    Signature: def detect_llm_config(args):

    Description: Discovers active LLM credentials, provider identifiers, model names, API endpoints, and effective context window limits. It delegates provider resolution to utils/llm_config.py and determines the maximum context length, prioritizing user CLI overrides before querying provider catalog defaults or dynamic endpoints.

    Parameters:

    • args (argparse.Namespace): Parsed command-line arguments containing the optional max_tokens override.

    Returns:

    • tuple: A five-element tuple structured as (provider, model_name, endpoint_url, api_key, context_length).

    Example:

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.llm_config import get_model_context_length

    provider, model_name, endpoint_url, api_key = resolve_llm_settings()
    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length

    This function ensures early inspection of context size constraints before initiating repository crawls. Lazy-importing get_model_context_length prevents circular import issues and delays network catalog queries until runtime arguments have been verified.

    resolve_thinking_plan()

    Visibility: Public

    Signature: def resolve_thinking_plan(args):

    Description: Computes the per-node reasoning effort plan without triggering console emissions or side effects. It parses user-defined overrides, determines whether to apply a global effort override or an automated provider profile, and invokes the budget compiler in utils/thinking.py.

    Parameters:

    • args (argparse.Namespace): Parsed CLI arguments containing advanced, mode, thinking_override, thinking_level, and thinking_profile.

    Returns:

    • tuple[str, dict, list[str]]: A three-element tuple comprising:
      1. profile (str): Resolved profile name (e.g., "balanced", "global", "off").
      2. thinking_plan (dict[str, str | None]): Map associating each pipeline node key with its calculated effort level.
      3. invalid (list[str]): List of malformed override string tokens detected during parsing.

    Example:

    def resolve_thinking_plan(args):
    """Build the per-node thinking plan from --thinking-override / --thinking-level / --thinking-profile.

    Pure (no emit): runs before init_output(). Validation messages come from _validate_thinking_args().

    Returns:
        tuple[str, dict, list[str]]: (resolved profile name, {node_key: level | None}, invalid override strings)
    """
    mode = "advanced" if args.advanced else args.mode
    overrides, invalid = parse_overrides(args.thinking_override)
    profile = "global" if args.thinking_level else resolve_profile_name(args.thinking_profile, resolve_llm_settings()[0])
    return profile, build_thinking_plan(profile, mode, args.thinking_level, overrides), invalid

    By remaining purely computational, this function can execute before init_output() is configured. This ordering allows the string translation engine within init_output() to consume its assigned thinking level directly from the compiled plan.

    display_config()

    Visibility: Public

    Signature: def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file, thinking_profile, thinking_plan):

    Description: Emits a formatted overview of the operational configuration to standard output and log files via the internationalized messaging subsystem. It prints provider metadata, context boundaries, token ratios, batch limits, reasoning plans, and output modes.

    Parameters:

    • args (argparse.Namespace): Parsed CLI options.

    • model_name (str): Name of the target model.

    • context_length (int): Maximum context token limit.
    • log_file (str): Path to the active persistent session log file.
    • thinking_profile (str): Active reasoning profile name.
    • thinking_plan (dict[str, str | None]): Per-node reasoning effort allocation dictionary.

    Returns:

    None.

    Example:

    def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file, thinking_profile, thinking_plan):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_THINKING_PROFILE", value=thinking_profile)
    if any(thinking_plan.values()):
        emit("CFG_THINKING_PLAN", value=describe_plan(thinking_plan, mode))
    emit("CFG_THINKING_SUPPORT", value=describe_thinking_support(provider, model_name))
    emit("CFG_TOKEN_RATIO", value=describe_token_ratio())
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))
    else:
        emit("CFG_MAX_ABSTRACTIONS", value=str(args.max_abstractions))
    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block

    The function queries localized string templates via get() and dispatches formatted events via emit(). This decouples terminal rendering and internationalization from the underlying CLI state while providing a clear audit trail in the log file before execution begins.

    main()

    Visibility: Public

    Signature: def main():

    Description: The primary application orchestrator. Coordinates the execution pipeline through preflight argument validation, environment auditing, output and logging initialization, cache invalidation, workflow DAG construction, and exception-safe teardown.

    Parameters:

    None.

    Returns:

    None.

    Raises:

    • SystemExit: Raised under explicit terminal validation failures (e.g., quoting errors, invalid thinking overrides, failed LLM authentication, or conflicting rebuild flags).

    Phase 1: Preflight Setup and Thinking Plan Resolution

        parser, args = parse_arguments()
    # Resolved silently before init_output(): string translation itself uses the plan's translate_strings level.
    thinking_profile, thinking_plan, invalid_overrides = resolve_thinking_plan(args)
    # Translation of missing strings is an LLM call: deferred until arguments and credentials are checked.
    init_output(
        language=args.language,
        use_cache=not args.no_cache,
        thinking_level=thinking_plan["translate_strings"],
        debug=args.debug,
        auto_translate=False,
    )

    The initial phase parses arguments and computes the reasoning plan in memory before configuring output handlers. It initializes utils.output with auto_translate=False, which defers LLM translation network calls until arguments and provider credentials have been verified.

    Phase 2: Argument Validation and Cleanup Interception

        _check_quoting_errors(parser, args)
    _validate_thinking_args(args, invalid_overrides)

    # Handle standalone --cleanup (no --dir or --repo)
    if args.cleanup and not args.dir and not args.repo:
        _run_cleanup()
        return

    # Require --dir or --repo for generation
    if not args.dir and not args.repo:
        parser.error("one of the arguments --repo --dir --cleanup is required")

    The second phase evaluates argument validity by inspecting pattern inputs for shell quoting mistakes and validating thinking override strings. If --cleanup is specified without repository or directory targets, it executes disk cleanup immediately and terminates early. Otherwise, it verifies that at least one source target (--dir or --repo) is present.

    Phase 3: Authentication Gate and Localization Synchronization

        # Fail fast (with setup instructions) before crawling if the configured provider cannot authenticate
    if not check_llm_auth():
        sys.exit(1)
    translate_missing_strings()
    notice_legacy_cache()

    # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get("GITHUB_TOKEN")
        if not github_token:
            emit("WARN_NO_GITHUB_TOKEN")
    elif args.token:
        emit("WARN_TOKEN_NO_REPO")

    The third phase audits LLM provider connectivity and credentials via check_llm_auth(), halting execution before attempting disk scans if credentials are missing or invalid. Once verified, it executes missing UI translations via translate_missing_strings(), inspects legacy disk cache files, and resolves GitHub authentication tokens.

    Phase 4: Mode Constraints and Incremental Cache Purging

        mode, project_name = resolve_mode_and_project(args)

    # Enforce incremental cache constraints
    if args.incremental and mode != "api-reference":
        emit("WARN_INCREMENTAL_API_ONLY")
        args.incremental = False

    # --force-rebuild requires --incremental
    if args.force_rebuild and not args.incremental:
        emit("ERROR_FORCE_REBUILD_NO_INCREMENTAL")
        sys.exit(1)

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        output_base = args.output or "output"
        manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
        if os.path.exists(manifest_path):
            os.remove(manifest_path)
            emit("FORCE_REBUILD_DELETED", path=manifest_path)
        else:
            emit("FORCE_REBUILD_NO_MANIFEST", path=manifest_path)
        # The verified-facts cache (ExtractFacts) lives in facts.json: docs/api/ under --mkdocs, else next to the pages
        for facts_file in (facts_path(output_base, project_name, True), facts_path(output_base, project_name, False)):
            if os.path.exists(facts_file):
                os.remove(facts_file)
                emit("FORCE_REBUILD_DELETED_FACTS", path=facts_file)

    # Warn about args ignored in api-reference mode
    if mode == "api-reference" and args.force_batch:
        emit("WARN_FORCE_BATCH_API_REF")
        args.force_batch = False

    The fourth phase normalizes generation modes and enforces incremental caching constraints. Because MD5 incremental compilation is restricted to api-reference mode, invalid combinations emit warnings or exit.     _thinking_level_arg()

    Visibility: Private

    Signature: def _thinking_level_arg(value):

    Description: Custom validator callable passed as the type= converter for the --thinking-level argument in argparse. Normalizes empty input or string "default" to None (representing the model's native default behavior) and validates that non-empty values exist within THINKING_LEVELS.

    Parameters:

    • value (str): Raw string value supplied on the command line.

    Returns:

    • str | None: Validated thinking level string or None if defaulting.

    Raises:

    • argparse.ArgumentTypeError: Raised if the argument string does not match any recognized level in THINKING_LEVELS or "default".

    Example:

    def _thinking_level_arg(value):
    """argparse type for --thinking-level: a level from THINKING_LEVELS; '' or 'default' → None (model default)."""
    level = value.strip().lower()
    if level in ("", "default"):
        return None
    if level not in THINKING_LEVELS:
        raise argparse.ArgumentTypeError(f"invalid choice: {value!r} (choose from {', '.join(THINKING_LEVELS)}, default)")
    return level

    This helper ensures input sanitization at CLI parsing time, preventing malformed thinking level strings from propagating deeper into provider adapters or plan builders.

    _check_quoting_errors()

    Visibility: Private

    Signature: def _check_quoting_errors(parser, args):

    Description: Scans parsed glob patterns within --include and --exclude lists to detect shell quoting mistakes. When users accidentally misquote arguments (e.g., missing a closing quote), the shell merges subsequent flags into the pattern string, silently discarding them. This function inspects pattern strings for embedded CLI flag tokens, emitting an error and halting execution if found.

    Parameters:

    • parser (argparse.ArgumentParser): The configured argument parser used to dynamically extract all valid flag strings.
    • args (argparse.Namespace): The parsed arguments namespace containing include and exclude pattern lists.

    Returns:

    None.

    Raises:

    • SystemExit: Exits with status code 1 if an embedded flag is detected inside any include or exclude pattern string.

    Example:

    def _check_quoting_errors(parser, args):
    """Detect shell quoting errors where --exclude/--include values accidentally swallowed other CLI flags."""
    # Extract all registered flags (both --long and -short) from the parser
    known_flags = set()
    for action in parser._actions:
        for opt in action.option_strings:
            known_flags.add(opt)

    for pattern_list, flag_name in [(args.exclude, "--exclude"), (args.include, "--include")]:
        if not pattern_list:
            continue
        for pattern in pattern_list:
            for known_flag in known_flags:
                if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
                    emit(
                        "ERROR_QUOTING",
                        flag=flag_name,
                        pattern=pattern[:120],
                        embedded=known_flag,
                    )
                    sys.exit(1)

    By extracting option strings directly from parser._actions, this function automatically stays synchronized with all registered CLI flags without maintaining a duplicate hardcoded list.

    Parameters:

    Example:

    def _validate_thinking_args(args, invalid_overrides):
    """Report malformed --thinking-override values (fatal), overrides for nodes the mode never runs,
    and --thinking-level/--thinking-profile conflicts."""
    if invalid_overrides:
        emit("ERROR_THINKING_OVERRIDE", value=", ".join(invalid_overrides), nodes=", ".join(NODE_KEYS), levels=", ".join(THINKING_LEVELS))
        sys.exit(1)

    _run_cleanup()

    Visibility: Private

    Signature: def _run_cleanup():

    Description: Deletes persistent cache files, temporary files, dynamic token calibration records, and log directories from disk. Catches filesystem exceptions on individual path deletions to ensure cleanup continues across remaining targets.

    Parameters:

    None.

    Returns:

    None.

    Example:

    def _run_cleanup():
    """Clean up cache files and log directory."""
    emit("CLEANUP_START")

    for cache_path in [cache_file, f"{cache_file}.tmp", LEGACY_CACHE_FILE, TOKEN_CALIBRATION_FILE, f"{TOKEN_CALIBRATION_FILE}.tmp"]:
        if os.path.exists(cache_path):
            try:
                os.remove(cache_path)
                emit("CLEANUP_REMOVED", path=cache_path)
            except Exception as e:
                emit("CLEANUP_FAILED", path=cache_path, error=e)

    log_dir = os.environ.get("LOG_DIR", "logs")
    if os.path.exists(log_dir) and os.path.isdir(log_dir):
        try:
            shutil.rmtree(log_dir)
            emit("CLEANUP_REMOVED_DIR", path=log_dir)
        except Exception as e:
            emit("CLEANUP_FAILED", path=log_dir, error=e)

    The cleanup targets include the active LLM cache file, atomic .tmp swap files, legacy cache files, and the token_calibration.json ratio file. The target log folder is resolved via the LOG_DIR environment variable, defaulting to logs/.

    Error Handling

    main.py applies defensive validation checks, fail-fast authentication guards, and exception-safe execution wrappers across its lifecycle:

    • Argument Parsing Validation: The internal helper _thinking_level_arg raises argparse.ArgumentTypeError when an unrecognized effort level is supplied to --thinking-level. This halts CLI processing immediately and displays valid choices (minimal, low, medium, high, xhigh, max, or default).
    • Shell Quoting Anomaly Detection: _check_quoting_errors catches cases where unclosed shell quotes in --include or --exclude cause subsequent flags to be treated as pattern values. When detected, it emits an ERROR_QUOTING diagnostic and exits with code 1, preventing silent configuration loss.
    • Thinking Configuration Validation: _validate_thinking_args detects malformed NODE=LEVEL strings and exits with code 1. It also issues warnings for overrides assigned to nodes that the selected mode never runs, and when a global level flag overrides an explicit thinking profile.
    • Preflight Authentication Gate: check_llm_auth() verifies that required API credentials and provider endpoints are reachable before attempting filesystem traversal or crawling. If verification fails, the process exits with code 1.
    • Incremental Configuration Constraints: The script ensures that --incremental is only used with --mode api-reference, automatically disabling the flag and emitting a warning otherwise. If --force-rebuild is supplied without --incremental, it emits ERROR_FORCE_REBUILD_NO_INCREMENTAL and terminates with code 1.
    • Resilient Cache Deletion: _run_cleanup wraps individual os.remove and shutil.rmtree calls in try...except blocks, ensuring that an error deleting one cache or temporary file does not halt the cleanup of others.
    • Guaranteed Telemetry and Teardown: Flow execution inside main() is wrapped in a try...finally block. If the workflow succeeds, fails, or is cancelled, _emit_usage_summary() formats and records multi-provider token usage, cost calculations, and refusals. The summary emission itself is protected by an inner try...except to ensure shutdown() is always called to flush logs.
