    main.py

    Source: main.py

    Technical Overview

    Building directly upon the pipeline execution DAG configured in flow.py, main.py serves as the centralized command-line interface (CLI) entry point and runtime orchestrator for the Codebase-Knowledge-Builder system. The module initializes runtime environments, parses user arguments, validates environment configurations and credentials, constructs the shared execution context, and triggers the PocketFlow graph. Additionally, it handles diagnostic telemetry reporting, incremental cache invalidation, and filesystem cleanup operations across both local and remote execution targets.

    The architecture follows a strict phased lifecycle: bootstrap and preflight parsing, authentication verification, shared store compilation, flow execution, and telemetry emission. Configuration management integrates environment variables sourced via python-dotenv with explicit CLI overrides. Before initiating network crawling or code parsing, main.py executes preflight checks—such as validating LLM credentials with utils.llm_config.check_llm_auth and detecting shell quotation errors—ensuring the application fails fast before consuming API credits or allocating memory.

    During execution, main.py compiles a mutable dictionary (shared) containing parsed repository metadata, filtering criteria, and reasoning budgets. It then instantiates the execution graph via create_tutorial_flow() and invokes its .run() method. A guaranteed finally block ensures that regardless of whether the execution succeeds, encounters an internal pipeline error, or is cancelled, session telemetry—including token counts, model calls, and financial expenditures across all active LLM providers—is calculated and emitted to the console and log files prior to process exit.

If the user did not supply an explicit project name via -n/--name, it derives a deterministic name from the local directory basename or the trailing segment of the remote Git repository URL.

    Parameters: * args (argparse.Namespace): The parsed CLI arguments namespace.

    Returns: * tuple[str, str]: A tuple of (mode, project_name).

    Raises: None.

    Example:

    def resolve_mode_and_project(args):
    """Resolve documentation mode (handling --advanced legacy flag) and derive project name.

    Returns:
        tuple[str, str]: (mode, project_name)
    """
    if args.advanced:
        if args.mode != "tutorial":  # User explicitly set --mode AND --advanced
            emit("WARN_ADVANCED_OVERRIDES_MODE", mode=args.mode)
        mode = "advanced"
    else:
        mode = args.mode
    project_name = args.name
    if not project_name:
        if args.dir:
            project_name = os.path.basename(os.path.abspath(args.dir))
        elif args.repo:
            project_name = args.repo.rstrip("/").split("/")[-1].removesuffix(".git")
        else:
            project_name = "project"
    return mode, project_name

    resolve_mode_and_project reconciles configuration precedence between legacy and current operational flags. If --advanced is set alongside an explicit non-tutorial --mode, it warns the user and forces the mode to "advanced". For automatic project name inference, trailing slashes and .git suffixes are stripped from repository URLs, and local directory paths are resolved to their absolute directory name. If neither input target is provided, it falls back to "project".

    def build_shared_store(args, github_token, mode, thinking_plan, project_name):
    """Construct the shared store dictionary passed between PocketFlow nodes.

    Returns:
        dict: The shared store with all CLI args, patterns, and empty output slots.
    """
    return {
        "repo_url": args.repo,
        "local_dir": args.dir,
        "project_name": project_name,  # Resolved once in main so logs, --force-rebuild and output agree
        "github_token": github_token,
        "output_dir": args.output,  # Base directory for CombineTutorial output
        # Include/exclude patterns and max file size
        "include_patterns": set(args.include) if args.include else DEFAULT_INCLUDE_PATTERNS,
        "exclude_patterns": DEFAULT_EXCLUDE_PATTERNS.union(set(args.exclude)) if args.exclude else DEFAULT_EXCLUDE_PATTERNS,
        "max_file_size": args.max_size,
        # Language for multi-language support
        "language": args.language,
        # Cache flag (inverse of no-cache)
        "use_cache": not args.no_cache,
        # Max abstractions
        "max_abstraction_num": args.max_abstractions,
        # LLM reasoning capabilities: global level (legacy) + per-node plan (utils/thinking.py)
        "thinking_level": args.thinking_level,
        "thinking_plan": thinking_plan,
        # Max tokens override
        "max_tokens": args.max_tokens,
        # Mode, mkdocs, and incremental
        "mode": mode,
        "mkdocs": args.mkdocs,
        "incremental": args.incremental,
        "advanced_mode": mode == "advanced",
        # Batching settings
        "batch_size": args.batch,
        "force_batch": args.force_batch,
        # Debug mode
        "debug": args.debug,
        # Outputs populated by downstream nodes
        "files": [],
        "abstractions": [],
        "relationships": {},
        "chapter_order": [],
        "chapters": [],
        "final_output_dir": None,
    }

    This constructor consolidates CLI parameters into a centralized data structure. Inclusion patterns default to DEFAULT_INCLUDE_PATTERNS ({"*"}), while exclusion patterns merge user-provided globs with DEFAULT_EXCLUDE_PATTERNS from utils/exclude_patterns.py. Downstream nodes mutate this dictionary in place during pipeline execution.

    def detect_llm_config(args):
    """Detect LLM provider, model, endpoint, and context length from environment.

    Returns:
        tuple: (provider, model_name, endpoint_url, api_key, context_length)
    """
    from utils.llm_config import get_model_context_length

    provider, model_name, endpoint_url, api_key = resolve_llm_settings()
    context_length = args.max_tokens or get_model_context_length(endpoint_url, model_name, api_key)
    return provider, model_name, endpoint_url, api_key, context_length

    detect_llm_config provides runtime environment detection for downstream logging and context sizing. It defers the import of get_model_context_length from utils/llm_config.py to keep CLI startup overhead minimal. If the user explicitly provided --max-tokens, that value takes precedence over dynamic network lookups or static fallback tables.

    resolve_thinking_plan()

    Returns: * tuple[str, dict[str, str | None], list[str]]: A 3-tuple containing: 1. Resolved profile name (str). 2. Per-node thinking plan mapping each node key to an effort level or None (dict[str, str | None]). 3. List of malformed override token strings (list[str]).

    Raises: None.

    Example:

    def resolve_thinking_plan(args):
    """Build the per-node thinking plan from --thinking-override / --thinking-level / --thinking-profile.

    Pure (no emit): runs before init_output(). Validation messages come from _validate_thinking_args().

    Returns:
        tuple[str, dict, list[str]]: (resolved profile name, {node_key: level | None}, invalid override strings)
    """
    mode = "advanced" if args.advanced else args.mode
    overrides, invalid = parse_overrides(args.thinking_override)
    profile = "global" if args.thinking_level else resolve_profile_name(args.thinking_profile, resolve_llm_settings()[0])
    return profile, build_thinking_plan(profile, mode, args.thinking_level, overrides), invalid

    This function implements the cognitive allocation precedence hierarchy defined in utils/thinking.py. If a global --thinking-level is explicitly provided, the profile is designated as "global". Otherwise, it maps the provider and profile argument into a concrete profile name, subsequently compiling site-specific cognitive assignments across all DAG execution nodes.

    def display_config(args, mode, provider, model_name, endpoint_url, context_length, log_file, thinking_profile, thinking_plan):
    """Emit all configuration values to the console."""
    emit("START_GENERATION", source=args.repo or args.dir, language=args.language.capitalize())
    emit("CFG_HEADER")
    emit("CFG_AI_PROVIDER", value=provider)
    emit("CFG_AI_ENDPOINT", value=endpoint_url)
    emit("CFG_AI_MODEL", value=model_name)
    emit("CFG_CONTEXT_LENGTH", value=f"{context_length:,}")
    emit("CFG_THINKING_LEVEL", value=args.thinking_level or "None")
    emit("CFG_THINKING_PROFILE", value=thinking_profile)
    if any(thinking_plan.values()):
        emit("CFG_THINKING_PLAN", value=describe_plan(thinking_plan, mode))
    emit("CFG_THINKING_SUPPORT", value=describe_thinking_support(provider, model_name))
    emit("CFG_BATCH_SIZE", value=f"{args.batch}")
    _enabled = get("CFG_VALUE_ENABLED")
    _disabled = get("CFG_VALUE_DISABLED")
    emit("CFG_FORCE_BATCH", value=_enabled if args.force_batch else _disabled)
    emit("CFG_OUTPUT_MODE", value=mode)
    emit("CFG_MKDOCS", value=_enabled if args.mkdocs else _disabled)
    emit("CFG_INCREMENTAL", value=_enabled if args.incremental else _disabled)
    if args.incremental:
        emit("CFG_FORCE_REBUILD", value=_enabled if args.force_rebuild else _disabled)
    if mode == "api-reference":
        emit("CFG_MAX_ABSTRACTIONS", value=get("CFG_VALUE_API_REF_MAX"))
    else:
        emit("CFG_MAX_ABSTRACTIONS", value=str(args.max_abstractions))
    emit("CFG_LLM_CACHING", value=_disabled if args.no_cache else _enabled)
    if args.debug:
        emit("CFG_DEBUG_MODE")
    emit("CFG_LOG_FILE", value=log_file)
    print()  # Blank line after config block

    display_config standardizes operational logging across all execution modes. It uses get from utils/output.py to retrieve localized string representations of "enabled" and "disabled". When reasoning is configured, it renders a summary string derived from describe_plan, ensuring users can review the cognitive budget allocated to each stage before pipeline execution begins.

    main()

    Visibility: Public Signature: def main() -> None:

    Description: Main entry point that coordinates the application's runtime lifecycle. It executes preflight argument validation, sets up logging, validates authentication, prepares incremental caches, constructs the shared execution context, and runs the PocketFlow DAG. It also guarantees final telemetry accounting and log flushing via a finally block.

    Parameters: None.

    Returns: * None

    Raises: * SystemExit: Raised on invalid arguments, authentication failure, or quoting syntax issues.

    The execution logic is organized into five sequential phases:

    Phase 1: CLI Parsing and Output Initialization

        parser, args = parse_arguments()
    # Resolved silently before init_output(): string translation itself uses the plan's translate_strings level.
    thinking_profile, thinking_plan, invalid_overrides = resolve_thinking_plan(args)
    # Translation of missing strings is an LLM call: deferred until arguments and credentials are checked.
    init_output(
        language=args.language,
        use_cache=not args.no_cache,
        thinking_level=thinking_plan["translate_strings"],
        debug=args.debug,
        auto_translate=False,
    )
    _check_quoting_errors(parser, args)
    _validate_thinking_args(args, invalid_overrides)
    Phase 1 parses CLI input, resolves the reasoning plan silently, and initializes the output system (init_output). Automatic string translation is deferred (auto_translate=False) until authentication is verified. It then runs validation checks for shell quoting anomalies and invalid thinking flags.

    Phase 2: Argument Validation and Preflight Checks

        // ...
    # Handle standalone --cleanup (no --dir or --repo)
    if args.cleanup and not args.dir and not args.repo:
        _run_cleanup()
        return

    # Require --dir or --repo for generation
    if not args.dir and not args.repo:
        parser.error("one of the arguments --repo --dir --cleanup is required")

    # Fail fast (with setup instructions) before crawling if the configured provider cannot authenticate
    if not check_llm_auth():
        sys.exit(1)
    translate_missing_strings()
    notice_legacy_cache()

    # Get GitHub token from argument or environment variable if using repo
    github_token = None
    if args.repo:
        github_token = args.token or os.environ.get("GITHUB_TOKEN")
        if not github_token:
            emit("WARN_NO_GITHUB_TOKEN")
    elif args.token:
        emit("WARN_TOKEN_NO_REPO")
    Phase 2 verifies operational modes. If --cleanup is called without a target, it purges cache directories and exits cleanly. For documentation runs, it requires either --dir or --repo. It runs a fail-fast preflight check using check_llm_auth(), halting execution if credentials are missing or invalid. Once verified, it translates missing UI strings and inspects the filesystem for legacy cache artifacts via notice_legacy_cache().

    Phase 3: Mode Resolution and Incremental Cache Handling

        // ...
    mode, project_name = resolve_mode_and_project(args)

    # Enforce incremental cache constraints
    if args.incremental and mode != "api-reference":
        emit("WARN_INCREMENTAL_API_ONLY")
        args.incremental = False

    # --force-rebuild requires --incremental
    if args.force_rebuild and not args.incremental:
        emit("ERROR_FORCE_REBUILD_NO_INCREMENTAL")
        sys.exit(1)

    # Handle --force-rebuild: delete the cache manifest to force fresh generation
    if args.force_rebuild and args.incremental:
        output_base = args.output or "output"
        manifest_path = os.path.join(output_base, project_name, ".doc_cache_manifest.json")
        if os.path.exists(manifest_path):
            os.remove(manifest_path)
            emit("FORCE_REBUILD_DELETED", path=manifest_path)
        else:
            emit("FORCE_REBUILD_NO_MANIFEST", path=manifest_path)

    # Warn about args ignored in api-reference mode

    def _check_quoting_errors(parser, args):
    """Detect shell quoting errors where --exclude/--include values accidentally swallowed other CLI flags.

    When users misquote patterns (e.g., --exclude "autogen/* "SmartFO/*" --language Vietnamese),
    the shell merges subsequent flags into the pattern value. This silently causes ALL following
    arguments to be ignored. We detect this by checking if any pattern value contains a known
    CLI flag string, which no legitimate file/directory pattern would ever contain.

    Flags are extracted dynamically from the argparse parser — no hardcoded list to maintain.
    """
    # Extract all registered flags (both --long and -short) from the parser
    known_flags = set()
    for action in parser._actions:
        for opt in action.option_strings:
            known_flags.add(opt)

    for pattern_list, flag_name in [(args.exclude, "--exclude"), (args.include, "--include")]:
        if not pattern_list:
            continue
        for pattern in pattern_list:
            for known_flag in known_flags:
                if f" {known_flag} " in pattern or (f" {known_flag}" in pattern and pattern.endswith(known_flag)):
                    emit(
                        "ERROR_QUOTING",
                        flag=flag_name,
                        pattern=pattern[:120],
                        embedded=known_flag,
                    )
                    sys.exit(1)

    This defensive helper guards against quoting errors in multi-value CLI arguments. When shell quotes are mismatched, Unix and Windows shells treat following flags as literal string arguments to preceding options, causing arguments like --language or --mode to be silently skipped. Inspecting parser._actions avoids hardcoding flag names while catching syntax errors before file crawling begins.

    def _validate_thinking_args(args, invalid_overrides):
    """Report malformed --thinking-override values (fatal), overrides for nodes the mode never runs,
    and --thinking-level/--thinking-profile conflicts."""
    if invalid_overrides:

    def _run_cleanup():

    emit("CLEANUP_START")

    Error Handling

    main.py incorporates several error handling patterns:

    1. Defensive Shell Quoting Interception: When shell quotes are mismatched in multi-argument flags (e.g., passing --exclude "dist/* "src/*" --mode api-reference), shells often merge following arguments into the string literal. The _check_quoting_errors helper scans pattern elements against all valid flags dynamically retrieved from parser._actions. If an embedded flag is found, it terminates early via sys.exit(1) and emits an ERROR_QUOTING message with the affected text.
    2. Fail-Fast Credential Verification: Before initiating disk traversal or remote Git cloning, main() calls check_llm_auth(). If dependencies or authentication keys for the active provider are missing, the process terminates immediately (sys.exit(1)), preventing runs from failing midway through execution.
    3. Cognitive Override Validation: The _validate_thinking_args function checks all --thinking-override inputs against known node keys and effort levels. Invalid syntax triggers an immediate ERROR_THINKING_OVERRIDE error and exits, while unused overrides produce non-fatal WARN_THINKING_OVERRIDE_UNUSED warnings.
    4. Incremental Cache Constraint Checks: The --incremental flag is restricted to --mode api-reference. If passed in other modes, it is disabled with a WARN_INCREMENTAL_API_ONLY warning. If --force-rebuild is used without --incremental, the application raises an ERROR_FORCE_REBUILD_NO_INCREMENTAL error and exits.
    5. Guaranteed Teardown Telemetry: A top-level try...finally block wraps DAG execution (tutorial_flow.run(shared)). Even if an unhandled exception or process termination occurs, the finally block calls _emit_usage_summary() to output accumulated token counts and financial costs, followed by shutdown() to flush active file handlers.
