    nodes

    Source: nodes.py

    Technical overview and implementation reference for the core pipeline nodes in Codebase-Knowledge-Builder. This module implements the processing stages for repository ingestion, abstraction identification, map-reduce decomposition, relationship analysis, chapter drafting, and documentation generation built on top of the PocketFlow framework (pocketflow.Node and pocketflow.BatchNode).

    The module interfaces directly with utility modules including LLM calling infrastructure (utils.call_llm), repository scrapers (utils.crawl_github_files, utils.crawl_local_files), prompt formatters (utils.prompts), and token calculation helpers (utils.token_utils).

    get_content_for_indices()

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list[tuple[str, str]], indices: list[int]) -> dict[str, str]:

    Description: Helper function to retrieve file paths and contents from the ingested repository file list based on specified numeric indices. Constructs an associative map where each key is formatted as "{index} # {path}" to provide contextual metadata to the LLM.

    Parameters: * files_data (list[tuple[str, str]]): List of tuples containing (file_path, file_content). * indices (list[int]): List of target file indices to extract.

    Returns: * dict[str, str]: Mapping of index/path identifier strings to file content bodies.

    Example: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = content  # Use index + path as key for context
    return content_map

    The function filters out invalid indices that are out of bounds (0 <= i < len(files_data)). It serves as the primary extraction utility when bundling file context for LLM prompt construction in downstream generation nodes like WriteChapters.

    load_prompt_template()

    Visibility: Public
    Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str | None = None) -> str:

    Description: Loads a Markdown prompt template from the filesystem located in the prompts/ subdirectories. Resolves the directory based on explicit execution mode (mode) or fallback boolean flags (advanced_mode).

    Parameters: * template_name (str): Base filename of the prompt template (without .md). * advanced_mode (bool): Legacy flag selecting between advanced and tutorial directories. Defaults to False. * mode (str | None): Target prompt subdirectory (e.g., tutorial, advanced, api-reference, sdk). Overrides advanced_mode if provided.

    Returns: * str: Raw template content read using utf-8-sig encoding.

    Raises: * FileNotFoundError: If the constructed prompt path does not exist on disk.

    Example: 

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts", prompt_dir, f"{template_name}.md")
    with open(path, encoding="utf-8-sig") as f:
        return f.read()

    The function resolves relative paths relative to the nodes.py module directory. It utilizes utf-8-sig encoding to handle Byte Order Marks (BOM) gracefully when loading Markdown templates from various platforms.

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> Any:

    Description: Parses structured YAML payloads returned from LLM completions. Isolates text enclosed within triple-backtick ```yaml blocks and loads the data into native Python dictionaries and lists.

    Parameters: * response (str): Raw completion text received from the language model.

    Returns: * Any: Deserialized Python data structures (typically dict or list).

    Raises: * ValueError: If the response does not contain valid YAML fences or if yaml.safe_load fails to parse the extracted substring.

    Example: 

    def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}") from e

    This helper standardizes LLM response consumption across all nodes. If the model fails to output strict Markdown code fences or includes malformed syntax, the method raises a ValueError, which triggers PocketFlow's internal node retry mechanics.

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> Callable[[str], int]:

    Description: Constructs a tokenizer closure for accurate token estimation using the tiktoken library under the cl100k_base encoding. Provides an automated character-count heuristic fallback (len(text) // 4) if tiktoken fails or is unavailable.

    Returns: * Callable[[str], int]: A callable function taking a string and returning its estimated token count.

    Example: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    The returned closure disables special token validation (disallowed_special=()) so that raw source code strings containing control tokens (e.g., <|endoftext|>) can be tokenized without throwing exceptions.

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Determines the maximum context window token limit for the active LLM provider. Checks the shared workflow state first, and falls back to inspecting environment variables (LLM_PROVIDER, GEMINI_MODEL, ${PROVIDER}_BASE_URL, ${PROVIDER}_MODEL) via utils.call_llm.get_model_context_length().

    Parameters: * shared (dict): Shared state dictionary across the PocketFlow graph.

    Returns: * int: Maximum context window capacity in tokens.

    Example: 

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    This function ensures dynamic context bounds calculation. If not overridden manually via configuration, it defaults to querying the metadata context limit for models like Google Gemini or OpenAI-compatible custom endpoints via utils.call_llm.

    Description: Prepares parameter payload for file crawling by extracting paths, GitHub tokens, file size limits, and include/exclude patterns from the shared dictionary. Derives the project name if not already provided.

        def prep(self, shared):
        repo_url = shared.get("repo_url")
        local_dir = shared.get("local_dir")
        project_name = shared.get("project_name")

        if not project_name:

            "exclude_patterns": exclude_patterns,
            "max_file_size": max_file_size,

        }

    The method normalizes repo paths and ensures shared["project_name"] is populated prior to crawler execution. It preserves pattern configuration arrays for directory traversal filtering.

        def exec(self, prep_res):

    Class ContextRouter

    Inherits from: pocketflow.Node

    Analyzes total codebase token counts against model capacity and routing requirements, directing flow execution to direct discovery (direct), map-reduce batching (batch), or 1-to-1 API reference documentation (deterministic).

    ContextRouter._build_directory_tree()

    Visibility: Protected (Static)
    Signature: def _build_directory_tree(files_data: list[tuple[str, str]]) -> str:

    Description: Constructs a compact textual directory tree representation showing relative folder groupings and file indices.

    Parameters: * files_data (list[tuple[str, str]]): List of (path, content) tuples.

    Returns: * str: Formatted directory hierarchy listing paths and their index mappings.

    Example: 

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict

        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            lines.extend(f"  {fname}" for fname in sorted(dir_files[dirname]))
        return "\n".join(lines)

    The static helper groups files by their parent directory using a defaultdict and appends formatted lines for each directory and contained file, preserving file index tracking.

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Measures prompt overhead, calculates safety thresholds (95% of model max tokens), tokenizes all repository files, and determines the execution routing strategy.

    Parameters: * shared (dict): Shared state containing configuration options and files.

    Returns: * tuple: Routing descriptor tuple passed directly to exec().

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)

        shared["max_tokens"] = max_tokens

        # --- Token estimation setup ---
        count_tokens = create_token_counter()

        # --- Calculate prompt overhead FIRST ---
        # 1. Prompt template (measure both, use the larger)
        prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
        max_template_tokens = 0
        for subdir in ["tutorial", "advanced"]:
            template_path = os.path.join(prompt_dir, subdir, "map_abstractions.md")
            if os.path.exists(template_path):
                with open(template_path, encoding="utf-8-sig") as f:
                    t = count_tokens(f.read())
                max_template_tokens = max(max_template_tokens, t)

        # 2. Directory tree (built from all files, shared across batches)
        directory_tree = self._build_directory_tree(files_data)
        tree_tokens = count_tokens(directory_tree)

        # 3. File listing index (e.g. "- 0 # main.py\n- 1 # nodes.py\n...")
        file_listing_str = "\n".join(f"- {i} # {path}" for i, (path, _) in enumerate(files_data))
        listing_tokens = count_tokens(file_listing_str)

        prompt_overhead = max_template_tokens + tree_tokens + listing_tokens
        // ...
        # --- Count file content tokens ---
        total_tokens = 0
        file_token_map = []
        for i, (path, content) in enumerate(files_data):
            entry = f"--- File Index {i}: {path} ---\n{content}\n\n"
            tokens = count_tokens(entry)
            total_tokens += tokens
            file_token_map.append(tokens)

        # --- Effective limit = safety margin minus overhead ---
        safety_limit = int(max_tokens * 0.95)
        effective_limit = safety_limit - prompt_overhead
        force_batch = shared.get("force_batch", False)

        if shared.get("mode", "tutorial") == "api-reference":
            return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

        if total_tokens > effective_limit or force_batch:
            return ("batch", files_data, effective_limit, shared.get("batch_size", 50), file_token_map, count_tokens, directory_tree, shared.get("debug", False))

        return ("direct", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

    The method accurately accounts for template and directory overhead before deciding if the codebase fits within context limits. If api-reference mode is set, it routes to deterministic mapping regardless of token sizes.

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]:

    Description: Processes the routing strategy. For direct and deterministic routes, it returns the string identifier. For batch routes, it partitions repository files into coherent, directory-preserving batches respecting effective_limit and batch_size.

    Parameters: * prep_res (tuple): Prepared context and file metrics.

    Returns: * str | list[list[tuple[int, str, str]]]: Execution route name or partitioned file batches.

    Example: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
        llm_logger.info(
            f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}"
        )

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            if current_batch:
                batches.append(current_batch)

        self._directory_tree = directory_tree
        return batches

    The batching algorithm organizes files by directory to maintain architectural context and ensures no batch exceeds token capacity or file count caps. Batches are kept strictly isolated by directory boundaries.

    ContextRouter.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: Any) -> str:

    Description: Updates shared memory with generated file batches and directory trees, returning the branch target action name for PocketFlow graph routing.

    Parameters: * shared (dict): Shared state store. * prep_res (tuple): Route metadata. * exec_res (Any): Route execution outputs.

    Returns: * str: Route action ("direct", "deterministic", or "batch").

    Example: 

        def post(self, shared, prep_res, exec_res):

            return "direct"

            return "deterministic"

    Class DeterministicFileMapper

    Inherits from: pocketflow.Node

    Filters non-code files using an LLM classifier and maps remaining code files 1-to-1 to independent documentation modules for exhaustive API reference generation.

    DeterministicFileMapper.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple[str, str | None, int]:

    Description: Constructs an LLM prompt via build_code_file_filter_prompt() using the complete file listing to identify valid source code files.

    Parameters: * shared (dict): Shared workflow state.

    Returns: * tuple[str, str | None, int]: Tuple containing (prompt, thinking_level, max_tokens).

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        project_name = shared["project_name"]

        file_listing = "\n".join([f"{i} # {path}" for i, (path, _) in enumerate(files_data)])

        prompt = build_code_file_filter_prompt(project_name, file_listing)
        return prompt, shared.get("thinking_level", None), shared.get("max_tokens", 100000)

    DeterministicFileMapper.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple[str, str | None, int]) -> list[int]:

    Description: Invokes the LLM to filter non-code files and parses the response YAML into a list of valid file index integers.

    Parameters: * prep_res (tuple): Prompt, thinking level, and max token limits.

    Returns: * list[int]: Valid numeric file indices corresponding to source code files.

    Example: 

        def exec(self, prep_res):
        try:
            prompt, thinking_level, max_tokens = prep_res
            log_token_estimation(self.__class__.__name__, prompt, max_tokens)
            print("Smartly filtering non-code files using LLM...")
            response = call_llm(prompt, use_cache=True, thinking_level=thinking_level)
            valid_indices = parse_yaml_response(response)
            if not isinstance(valid_indices, list):
                valid_indices = []
            return [int(idx) for idx in valid_indices]
        except Exception as e:
            print(f"\033[93m[Node {self.__class__.__name__} Retry Triggered] Error: {e}\033[0m")
            llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
            raise e

    DeterministicFileMapper.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list[int]) -> str:

    Description: Converts each validated file index into a standalone module definition with a clean dotted module name, sets linear chapter ordering, and assigns dummy relationships.

    Parameters: * shared (dict): Shared store. * prep_res (tuple): Prep data. * exec_res (list[int]): Filtered file indices.

    Returns: * str: "default" action branch.

    Example: 

        def post(self, shared, prep_res, exec_res):
        import os

        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, _content) in enumerate(files):
            if idx not in valid_indices:
                print(f"  - Skipping non-code file: {file_path}")
                continue

            clean_name = os.path.splitext(file_path)[0].replace(os.sep, ".").replace("/", ".")

            modules.append(
                {"name": clean_name, "description": f"Internal API reference for `{file_path}`", "files": [idx], "original_path": file_path}
            )
            chapter_order.append(len(modules) - 1)

        shared["abstractions"] = modules
        shared["chapter_order"] = chapter_order
        shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
        print(f"\033[92m[DeterministicFileMapper] Mapped {len(modules)} ACTUAL code files for exhaustive documentation.\033[0m")
        return "default"

    The post-hook initializes shared["abstractions"] and shared["chapter_order"] such that downstream nodes process each individual source file independently without conceptual clustering.

    Class MapAbstractions

    Inherits from: pocketflow.BatchNode

    Executes the Map phase of the Map-Reduce pipeline. Evaluates partitioned file batches concurrently to identify local abstractions and architectural concepts.

    MapAbstractions.prep()

    AnalyzeRelationships.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Implements a two-pass token allocation algorithm across abstractions to distribute the prompt budget evenly for file snippet inclusion without starvation.

    Parameters: * shared (dict): Shared state store.

    Returns: * tuple: Prepared relationship prompt inputs.

    Example: 

        def prep(self, shared):
        abstractions = shared["abstractions"]
        files_data = shared["files"]
        project_name = shared["project_name"]
        language = shared.get("language", "english")
        use_cache = shared.get("use_cache", True)
        thinking_level = shared.get("thinking_level", None)

        // ... [Context header initialization] ...
        max_tokens = shared.get("max_tokens", 100000)
        safety_limit = int(max_tokens * 0.95)
        prompt_overhead = 2000

        estimate_tokens = create_token_counter()
        current_tokens = estimate_tokens(context)
        total_budget = safety_limit - current_tokens - prompt_overhead
        num_abstractions = len(abstractions)

        # Pre-compute file token sizes for all abstractions
        abstr_file_data = []
        for abstr in abstractions:
            sized = []
            for idx in abstr["files"]:
                if 0 <= idx < len(files_data):
                    path, file_content = files_data[idx]
                    entry = f"\\n--- File: {idx} # {path} ---\\n{file_content}\\n"
                    sized.append((idx, path, file_content, estimate_tokens(entry)))
            sized.sort(key=lambda x: x[3], reverse=True)
            abstr_file_data.append(sized)

        # Pass 1: give each abstraction an equal share, track unused
        per_abstr_budget = total_budget // max(num_abstractions, 1)
        included_indices = set()
        abstr_results = []

        for _i, sized in enumerate(abstr_file_data):
            budget = per_abstr_budget
            included_files = []
            remaining_files = []
            for idx, path, file_content, tokens in sized:
                if idx in included_indices:
                    included_files.append((idx, path, None, 0))
                    continue
                if tokens <= budget:
                    included_files.append((idx, path, file_content, tokens))
                    budget -= tokens
                    included_indices.add(idx)
                else:
                    remaining_files.append((idx, path, file_content, tokens))
            abstr_results.append((included_files, remaining_files, budget))

        # Pass 2: redistribute unused budget to abstractions with remaining files
        total_unused = sum(r[2] for r in abstr_results)
        if total_unused > 0:
            for i, (included_files, remaining_files, _unused) in enumerate(abstr_results):
                if not remaining_files or total_unused <= 0:
                    continue
                still_remaining = []
                for idx, path, file_content, tokens in remaining_files:
                    if idx in included_indices:
                        included_files.append((idx, path, None, 0))
                        continue
                    if tokens <= total_unused:
                        included_files.append((idx, path, file_content, tokens))
                        total_unused -= tokens
                        included_indices.add(idx)
                    else:
                        still_remaining.append((idx, path, file_content, tokens))
                abstr_results[i] = (included_files, still_remaining, 0)
        // ...
        return (context, "\n".join(abstraction_info_for_prompt), num_abstractions, project_name, language, use_cache, thinking_level, shared.get("advanced_mode", False), shared.get("max_tokens", 100000), shared.get("mode", "tutorial"))

    The algorithm prevents early abstractions from consuming the entire context window. Pass 1 divides the token budget equally; Pass 2 collects unspent tokens and allocates them to larger abstractions that still have pending files.

                    except Exception as e:
                        print(f"Warning: Failed to read manifest cache: {e}")

            # Cross-chapter summary prevents O(n^2) token explosion
            previous_chapters_summary = "" if doc_mode == "api-reference" else "\n---\n".join(self.chapter_summaries)

            prompt_template = load_prompt_template("draft_chapters", mode=doc_mode)
            prompt = prompt_template.format(
                language_instruction=language_instruction,
                project_name=project_name,
                abstraction_name=abstraction_name,
                chapter_num=chapter_num,
                concept_details_note=concept_details_note,

                structure_note=structure_note,
                full_chapter_listing=item["full_chapter_listing"],
                prev_summary_note=prev_summary_note,
                previous_chapters_summary=previous_chapters_summary or "This is the first chapter.",
                file_context_str=file_context_str or "No specific code snippets provided for this abstraction.",
                language=language.capitalize(),
                instruction_lang_note=instruction_lang_note,
                link_lang_note=link_lang_note,
                code_comment_note=code_comment_note,
                mermaid_lang_note=mermaid_lang_note,
                tone_note=tone_note,
            )
            // ...
            chapter_content = call_llm(prompt, use_cache=(use_cache and self.cur_retry == 0), thinking_level=thinking_level)
            self.chapters_written_so_far.append(chapter_content)

            # Generate LLM summary for cross-chapter context (skip for api-reference)
            if doc_mode != "api-reference":
                summary_prompt = build_chapter_summary_prompt(chapter_num, abstraction_name, chapter_content, language)
                chapter_summary = call_llm(summary_prompt, use_cache=True, thinking_level=None)
                self.chapter_summaries.append(f"Chapter {chapter_num} — {abstraction_name.strip()}:\n{chapter_summary}")

            return {"content": chapter_content, "hash": current_hash, "name": abstraction_name}

    def _build_index_sections(lines, sections, chapter_files, level=3):
        """Recursively build index.md sections with module tables."""
        heading = "#" * level
        for section in sections:
            lines.append(f"{heading} {section['name']}")
            lines.append("")
            if section.get("modules"):
                lines.append("| Module | Description |")
                lines.append("|--------|-------------|")
                for mod_name in section["modules"]:
                    match = next((cf for cf in chapter_files if cf["module_name"] == mod_name), None)
                    if match:
                        display = mod_name.split(".")[-1] if "." in mod_name else mod_name
                        desc = match["description"]
                        if desc.startswith("Internal API reference"):
                            content_lines = match["content"].strip().split("\n")
                            for cl in content_lines:
                                cs = cl.strip()
                                if cs and not cs.startswith(("---", "#", "```", "title:", "sidebar_position:")):
                                    desc = cs[:120]
                                    break
                        lines.append(f"| [{display}](api/{match['filename']}) | {desc} |")
                lines.append("")
            for child in section.get("children", []):
                CombineTutorial._build_index_sections(lines, [child], chapter_files, level + 1)
