    nodes

    Original source file: nodes.py

    Overview

    The nodes.py module defines the discrete execution units (nodes) comprising the documentation generation pipelines in Codebase-Knowledge-Builder. Built on top of the PocketFlow framework (Node and BatchNode base classes), each node implements a strict three-phase lifecycle: 1. prep(shared): Extracts, transforms, and validates necessary data from the pipeline's shared dictionary state, pre-allocating token budgets or structuring batch payloads. 2. exec(prep_res): Executes core computational logic or orchestrates LLM interactions (via utils.call_llm) without mutating shared state directly. 3. post(shared, prep_res, exec_res): Writes computed results back to the shared dictionary and returns routing actions to control downstream graph transitions.

    The module supports multiple documentation operational modes (tutorial, advanced, sdk, and api-reference), handling dynamic context routing, token estimation, Map-Reduce abstractions for large repositories, LLM-based architectural relationship extraction, chapter sequencing, incremental caching, and Markdown/MkDocs documentation generation.

    Module-Level Functions

    get_content_for_indices()

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list, indices: list) -> dict:

    Description: Resolves raw file contents from a list of indexed file tuples (path, content) given a list of integer indices. It constructs a dictionary keyed by formatted index comments ("{i} # {path}"), allowing downstream LLM prompts to reference code files with clear provenance.

    Parameters: * files_data (list): List of tuples containing (file_path, file_content). * indices (list): List of integer indices to extract.

    Returns: * dict: Mapping of string keys ("{index} # {path}") to file content strings.

    Raises: None. Bounds checking is applied internally (0 <= i < len(files_data)).

    Example: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = content  # Use index + path as key for context
    return content_map

    This helper function acts as an index-to-content resolver for nodes that map abstract architectural components to their underlying source files (such as WriteChapters). By formatting dictionary keys with # {path}, it embeds human-readable path identifiers into context blocks passed to LLMs while preserving zero-based index mapping. Any out-of-bounds index requests are safely skipped, avoiding index errors when mapping partial or filtered codebases.

    load_prompt_template()

    Visibility: Public
    Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str = None) -> str:

    Description: Loads the raw Markdown prompt template file from the prompts/ directory tree based on the active operational mode (tutorial, advanced, sdk, or api-reference).

    Parameters: * template_name (str): Base name of the prompt Markdown file (without .md). * advanced_mode (bool, optional): Legacy flag determining if advanced or tutorial folder is used when mode is None. Defaults to False. * mode (str, optional): Specific mode folder name under prompts/. Defaults to None.

    Returns: * str: Raw template content string loaded with UTF-8-SIG encoding.

    Raises: * FileNotFoundError: If the constructed template path does not exist on disk.

    Example: 

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts", prompt_dir, f"{template_name}.md")
    with open(path, encoding="utf-8-sig") as f:
        return f.read()

    This function resolves dynamic prompt templates from the file system relative to nodes.py. When mode is explicitly provided, it directly selects the subdirectory corresponding to that mode; otherwise, it falls back to checking the boolean advanced_mode parameter. Files are loaded with utf-8-sig encoding to handle potential byte-order marks transparently.

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> any:

    Description: Extracts and safely parses structured YAML text blocks enclosed within standard Markdown triple backtick blocks (```yaml) from an LLM response string.

    Parameters: * response (str): Raw string returned by the LLM call.

    Returns: * any: Parsed YAML data structures (typically list or dict).

    Raises: * ValueError: If the string does not contain a ```yaml fenced block or if yaml.safe_load fails to parse the extracted content.

    Example: 

    def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}") from e

    LLM prompts in this framework mandate structured responses within fenced ```yaml blocks. This helper isolates the substring between the opening ```yaml tag and the closing ``` delimiter, applying yaml.safe_load. If the LLM generates malformed YAML, omit delimiters, or encounters syntax errors, the function wraps the underlying parser exception inside a descriptive ValueError to trigger upstream node retry mechanisms.

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> callable:

    Description: Instantiates and returns a token counter callable using OpenAI's tiktoken library with the cl100k_base encoding, falling back to a character heuristic (len(text) // 4) if tiktoken fails.

    Parameters: None.

    Returns: * callable: A function (str) -> int that accepts text and returns estimated token count.

    Raises: None.

    Example: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    This factory creates a fast token estimator for pre-flight context budgeting across nodes. By passing disallowed_special=() to tiktoken.encode, the tokenizer safely encodes special tokens (such as <|endoftext|>) appearing inside raw source code files as ordinary text tokens. If encoding fails due to missing environment bindings or encoding errors, the closure degrades gracefully to the standard 4-characters-per-token heuristic.

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Determines the maximum context token window for the configured LLM provider and model. Checks shared["max_tokens"] first, and if not present, inspects environment variables and queries provider metadata via utils.call_llm.get_model_context_length.

    Parameters: * shared (dict): The pipeline shared state dictionary.

    Returns: * int: The maximum allowed context length in tokens.

    Raises: None.

    Example: 

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    This function centrally resolves model context capacities across different LLM backends. If an explicit limit is present in the pipeline's shared configuration, it takes precedence. Otherwise, it detects whether Gemini or an alternative OpenAI-compatible provider (such as Anthropic, DeepSeek, or a local endpoint) is active, extracts connection environment variables, and queries get_model_context_length() to obtain the upper bound for prompt budgeting.

    Class DeterministicFileMapper

    Inherits from: pocketflow.Node
    Description: Node used in api-reference mode to bypass high-level abstraction discovery and instead map every valid source code file into a 1:1 chapter/module reference page. It uses an LLM to filter out non-code assets (such as lockfiles or configs).

    DeterministicFileMapper.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Formats all ingested files into an indexed listing and constructs a filtering prompt via utils.prompts.build_code_file_filter_prompt.

    Parameters: * shared (dict): Pipeline shared store containing files and project_name.

    Returns: * tuple: (prompt: str, thinking_level: any, max_tokens: int).

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        project_name = shared["project_name"]

        file_listing = "\n".join([f"{i} # {path}" for i, (path, _) in enumerate(files_data)])

        prompt = build_code_file_filter_prompt(project_name, file_listing)
        return prompt, shared.get("thinking_level", None), shared.get("max_tokens", 100000)

    The prep method extracts the list of (path, content) tuples from shared["files"] and creates an enumerated string where each entry contains the file index and file path. It formats these into the code filter prompt using build_code_file_filter_prompt, passing the prompt, configured thinking level, and maximum tokens to the execution stage.

    DeterministicFileMapper.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> list:

    Description: Dispatches the filtering prompt to the LLM and parses the YAML response containing the list of integer indices corresponding to actual code files.

    Parameters: * prep_res (tuple): (prompt, thinking_level, max_tokens).

    Returns: * list: List of valid integer file indices (List[int]).

    Raises: * Exception: Propagates any LLM execution or parsing failure to trigger PocketFlow node retries.

    Example: 

        def exec(self, prep_res):
        try:
            prompt, thinking_level, max_tokens = prep_res
            log_token_estimation(self.__class__.__name__, prompt, max_tokens)
            print("Smartly filtering non-code files using LLM...")
            response = call_llm(prompt, use_cache=True, thinking_level=thinking_level)
            valid_indices = parse_yaml_response(response)
            if not isinstance(valid_indices, list):
                valid_indices = []
            return [int(idx) for idx in valid_indices]
        except Exception as e:
            print(f"\033[93m[Node {self.__class__.__name__} Retry Triggered] Error: {e}\033[0m")
            llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
            raise e

    exec records token estimation telemetry via utils.token_utils.log_token_estimation before calling utils.call_llm.call_llm with caching enabled. The returned YAML string is parsed into a list of indices. If an error occurs, the exception is logged to llm_logger and re-raised to allow PocketFlow's retry mechanism to handle intermittent network or formatting errors.

    DeterministicFileMapper.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list) -> str:

    Description: Iterates over all files, skips non-code files, creates 1:1 abstraction records for each valid file, and populates shared["abstractions"], shared["chapter_order"], and shared["relationships"].

    Parameters: * shared (dict): Pipeline shared state. * prep_res (tuple): Execution preparation artifacts. * exec_res (list): List of valid file indices.

    Returns: * str: "default" routing action.

    Example: 

        def post(self, shared, prep_res, exec_res):
        import os

        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, _content) in enumerate(files):
            if idx not in valid_indices:
                print(f"  - Skipping non-code file: {file_path}")
                continue

            clean_name = os.path.splitext(file_path)[0].replace(os.sep, ".").replace("/", ".")

            modules.append(
                {"name": clean_name, "description": f"Internal API reference for `{file_path}`", "files": [idx], "original_path": file_path}
            )
            chapter_order.append(len(modules) - 1)

        shared["abstractions"] = modules
        shared["chapter_order"] = chapter_order
        shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
        print(f"\033[92m[DeterministicFileMapper] Mapped {len(modules)} ACTUAL code files for exhaustive documentation.\033[0m")
        return "default"

    The post step converts each retained code file into a dot-separated module identifier (e.g., utils/call_llm.py becomes utils.call_llm). It constructs a 1:1 mapping entry with original path tracking and sets up sequential chapter ordering. It also initializes an empty relationship dictionary, ensuring all downstream nodes receive consistent data structures.

    Class ContextRouter

    Inherits from: pocketflow.Node
    Description: Inspects total repository file size and token overhead against the model's effective context limit. Routes execution to "deterministic" (for api-reference mode), "direct" (single-prompt abstraction discovery), or "batch" (directory-preserving Map-Reduce chunking).

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Computes prompt overhead (template tokens, directory tree tokens, listing tokens) and file content tokens. Calculates effective token limit (95% of max_tokens - overhead) and determines the appropriate route.

    Parameters: * shared (dict): Pipeline shared store.

    Returns: * tuple: Route tuple containing (route, files_data, effective_limit, batch_size, file_token_map, count_tokens, directory_tree, debug).

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)

        shared["max_tokens"] = max_tokens

        # --- Token estimation setup ---
        count_tokens = create_token_counter()

        # --- Calculate prompt overhead FIRST ---
        // ... prompt overhead calculation: template, directory tree, file listing ...
        prompt_overhead = max_template_tokens + tree_tokens + listing_tokens

        # --- Effective limit = safety margin minus overhead ---
        safety_limit = int(max_tokens * 0.95)
        effective_limit = safety_limit - prompt_overhead
        force_batch = shared.get("force_batch", False)

        if shared.get("mode", "tutorial") == "api-reference":
            return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

        if total_tokens > effective_limit or force_batch:
            return (
                "batch", files_data, effective_limit, shared.get("batch_size", 50),
                file_token_map, count_tokens, directory_tree, shared.get("debug", False),
            )
        else:
            return ("direct", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

    prep computes the prompt overhead by measuring the template size across tutorial and advanced folders, generating a directory tree, and indexing all files. A 5% safety margin is deducted from max_tokens before subtracting overhead to establish the effective_limit. If the total tokens exceed this limit or force_batch is active, the node selects the "batch" route; if the mode is api-reference, it returns "deterministic"; otherwise, it returns "direct".

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> Union[str, list]:

    Description: If routed to "batch", groups files by directory and splits them into token-aware and count-aware chunks without mixing directories across batches.

    Parameters: * prep_res (tuple): Output tuple from prep.

    Returns: * Union[str, list]: "direct", "deterministic", or a list of batches List[List[Tuple[int, str, str]]].

    Example: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
        llm_logger.info(
            f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}"
        )

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            if current_batch:
                batches.append(current_batch)

        self._directory_tree = directory_tree
        return batches

    For "direct" and "deterministic" routes, exec acts as a pass-through. For batching, it organizes files by directory using defaultdict(list). It iterates through each directory's files, packing them into batches that strictly respect both effective_limit token budgets and batch_size item ceilings. Batches never mix files from different parent directories, preserving local architectural coherence.

    ContextRouter.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: Union[str, list]) -> str:

    Description: Writes the generated file batches and directory tree into shared memory and returns the routing branch key.

    Parameters: * shared (dict): Shared state dictionary. * prep_res (tuple): Data returned from prep. * exec_res (Union[str, list]): Result from exec.

    Returns: * str: Route string ("direct", "deterministic", or "batch").

    Example: 

        def post(self, shared, prep_res, exec_res):
        if exec_res == "direct":
            return "direct"
        if exec_res == "deterministic":
            return "deterministic"
        shared["file_batches"] = exec_res
        # Reuse directory tree built during prep()
        shared["directory_tree"] = getattr(self, "_directory_tree", self._build_directory_tree(shared["files"]))
        return "batch"

    The post method assigns execution results according to the chosen route. When running in "batch" mode, it saves file_batches and the generated directory_tree into the shared state dictionary and returns "batch" to instruct PocketFlow to trigger the MapAbstractions batch node.

    ContextRouter._build_directory_tree()

    Visibility: Protected (Static)
    Signature: def _build_directory_tree(files_data: list) -> str:

    Description: Generates a compact plaintext tree representation of the codebase hierarchy, noting file indices alongside filenames.

    Parameters: * files_data (list): List of (path, content) tuples.

    Returns: * str: Formatted directory tree string.

    Example: 

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict

        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            lines.extend(f"  {fname}" for fname in sorted(dir_files[dirname]))
        return "\n".join(lines)

    This static method aggregates all repository file paths by their directory names. It sorts directories and files alphabetically, appending the integer index (idx:{i}) to each file entry. This provides the LLM with a concise structural map of the entire project repository within minimal token overhead.

    Class MapAbstractions

    Inherits from: pocketflow.BatchNode
    Description: Runs parallel or sequential batch analysis over file chunks created by ContextRouter. It prompts the LLM to identify high-level abstractions within each batch.

        def prep(self, shared):
        return [

    MapAbstractions.exec()

    Visibility: Public
    Signature: def exec(self, item: dict) -> list:

    Description: Formats batch file contents and directory context into the map_abstractions prompt, calls the LLM, and parses/validates the returned YAML abstraction entries.

    Parameters: * item (dict): Batch item parameters from prep().

    Returns: * list: List of validated abstraction dictionaries ([{"name": str, "description": str, "files": List[int]}]).

    Example: 

        def exec(self, item):
        batch_index = item["batch_index"]
        files = item["files"]
        print(f"Mapping abstractions for batch {batch_index} ({len(files)} files)...")

        context = ""
        file_listing_for_prompt = []
        for i, path, content in files:
            context += f"--- File Index {i}: {path} ---\n{content}\n\n"
            file_listing_for_prompt.append(f"- {i} # {path}")

        file_listing = "\n".join(file_listing_for_prompt)
        prompt_template = load_prompt_template("map_abstractions", mode=item.get("mode", "tutorial"))

        // ... language hints and prompt formatting ...
        response = call_llm(prompt, use_cache=(item["use_cache"] and self.cur_retry == 0), thinking_level=item["thinking_level"])
        abstractions = parse_yaml_response(response)

        validated_abstractions = []
        if isinstance(abstractions, list):
            for obj in abstractions:
                if isinstance(obj, dict) and "name" in obj and "description" in obj and "file_indices" in obj:
                    import re
                    validated_indices = []
                    for idx_entry in obj["file_indices"]:
                        nums = re.findall(r"\d+", str(idx_entry))
                        if nums:
                            validated_indices.append(int(nums[0]))
                    if validated_indices:
                        validated_abstractions.append(
                            {"name": obj["name"], "description": obj["description"], "files": sorted(set(validated_indices))}
                        )

    exec implements two key optimizations: 1. Incremental Caching: When incremental=True, it hashes file_context_str using MD5 and checks .doc_cache_manifest.json.         def post(self, shared, prep_res, exec_res_list):
        import json
        import os

        shared["chapters"] = [res["content"] for res in exec_res_list]

        if shared.get("incremental"):
            output_dir = os.path.join(shared.get("output_dir", "output"), shared.get("project_name"))
            os.makedirs(output_dir, exist_ok=True)
            manifest_path = os.path.join(output_dir, ".doc_cache_manifest.json")

            manifest = {}
            if os.path.exists(manifest_path):
                try:
                    with open(manifest_path, encoding="utf-8") as f:
                        manifest = json.load(f)
                except Exception:
                    pass

            for res in exec_res_list:
                if res.get("hash") and res.get("name"):
                    manifest[res["name"]] = res["hash"]

            with open(manifest_path, "w", encoding="utf-8") as f:
                json.dump(manifest, f, indent=2)

        del self.chapters_written_so_far
        del self.chapter_summaries
        print(f"Finished writing {len(exec_res_list)} chapters.")

    post extracts chapter Markdown strings into shared["chapters"]. If incremental mode is active, it merges the current run's content hashes into .doc_cache_manifest.json and writes the manifest to disk. Finally, it cleans up temporary instance variables (chapters_written_so_far and chapter_summaries) to free memory.
