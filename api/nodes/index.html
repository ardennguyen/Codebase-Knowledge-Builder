    nodes

    nodes.py

    Technical overview and reference for the core pipeline nodes in Codebase-Knowledge-Builder. This module implements the processing stages for repository analysis, abstraction mapping, relationship extraction, chapter sequencing, content drafting, and output rendering using PocketFlow nodes (Node and BatchNode).

    The pipeline supports both tutorial generation and direct API reference generation. It includes dynamic routing based on context size, token budgeting, multi-pass reduction, LLM-based file filtering, incremental caching, and export to both standard Markdown and MkDocs formats.

    flowchart TD
    subgraph Ingestion
        FR[FetchRepo] --> CR[ContextRouter]
    end

    subgraph Routing
        CR -->|direct| IA[IdentifyAbstractions]
        CR -->|batch| MA[MapAbstractions]
        CR -->|deterministic| DFM[DeterministicFileMapper]
    end

    subgraph AbstractionReduction [Abstraction Reduction]
        MA --> RA[ReduceAbstractions]
    end

    subgraph Synthesis
        IA --> AR[AnalyzeRelationships]
        RA --> AR
        DFM --> WC[WriteChapters]
        AR --> OC[OrderChapters]
        OC --> WC
        WC --> CT[CombineTutorial]
    end

    Module-Level Functions

    get_content_for_indices()

    Visibility: Public
    Signature: def get_content_for_indices(files_data, indices) -> dict:

    Description: Extracts file content for a sequence of numeric file indices and maps them into a dictionary keyed by formatted index-and-path strings. This keyed representation provides clear file identification context within prompt structures.

    Parameters: * files_data (list): List of (path, content) tuples representing all crawled files. * indices (list): Collection of integer indices pointing to specific entries in files_data.

    Returns: * dict: Mapping where keys are formatted as "{i} # {path}" and values are the corresponding string contents.

    Raises: * None. Out-of-bounds indices are ignored via internal bounds check 0 <= i < len(files_data).

    Example: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = content  # Use index + path as key for context
    return content_map

    The function iterates over the requested list of indices and performs bounds checking against the files_data sequence. For each valid index, it constructs a descriptive key combining the numeric index and the original file path. Invalid or out-of-range indices are silently omitted, ensuring prompts do not receive dangling references or trigger index errors during processing.

    load_prompt_template()

    Visibility: Public
    Signature: def load_prompt_template(template_name, advanced_mode=False, mode=None) -> str:

    Description: Resolves and loads prompt template markdown files from the filesystem relative to the prompts/ subdirectories (tutorial, advanced, api-reference, etc.).

    Parameters: * template_name (str): Base filename of the prompt markdown template (without .md). * advanced_mode (bool): Fallback flag used if mode is None. Selects between "advanced" and "tutorial". Defaults to False. * mode (str, optional): Specific mode folder override (e.g., "tutorial", "advanced", "api-reference"). Defaults to None.

    Returns: * str: Raw text content of the loaded markdown prompt template.

    Raises: * FileNotFoundError: If the constructed template path does not exist on disk. * OSError: If the file cannot be opened or read.

    Example: 

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts", prompt_dir, f"{template_name}.md")
    with open(path, "r", encoding="utf-8-sig") as f:
        return f.read()

    This helper handles path resolution across different execution contexts by referencing the absolute directory of nodes.py. It prioritizes the explicit mode parameter, falling back to the legacy advanced_mode boolean toggle if mode is not supplied. The file is opened with utf-8-sig encoding to automatically handle byte order marks present in cross-platform template assets.

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> Any:

    Description: Parses LLM markdown outputs containing code blocks delimited by ```yaml and deserializes the enclosed payload into Python data structures.

    Parameters: * response (str): Raw text output returned from an LLM call.

    Returns: * Any: Deserialized YAML content (typically a dict or list).

    Raises: * ValueError: Raised when the output cannot be split on ```yaml or if yaml.safe_load fails to parse the string.

    Example: 

    def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}") from e

    The function extracts structured data from LLM responses by finding the first ```yaml delimiter and reading up to the subsequent closing ``` code fence. It strips extraneous leading or trailing whitespace before passing the block to yaml.safe_load. Any failure during slicing or YAML parsing is wrapped and raised as a ValueError with contextual diagnostics.

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> Callable[[str], int]:

    Description: Factory function that creates a token counting callable using tiktoken with the cl100k_base encoding, falling back to a character heuristic if tiktoken fails.

    Parameters: * None.

    Returns: * Callable[[str], int]: A function that accepts a string and returns an integer representing the token count.

    Raises: * None. Handles missing dependencies or encoding errors internally by providing a fallback lambda.

    Example: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    This factory provides a unified token counting interface across all pipeline nodes. It attempts to load the cl100k_base byte-pair encoding from tiktoken, disabling special token checks to prevent syntax errors on raw code strings. If tiktoken initialization fails, it returns a 4-characters-per-token heuristic function (len(text) // 4).

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Determines the maximum context length for LLM interactions. It checks the shared pipeline dictionary first and falls back to inspecting active environment variables and querying model metadata.

    Parameters: * shared (dict): Shared state dictionary passed across pipeline nodes.

    Returns: * int: Maximum context window length in tokens.

    Raises: * None. Defaults to standard provider context limits via get_model_context_length().

    Example: 

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    The resolution checks for an explicit max_tokens configuration in the shared dictionary. If not found, it inspects LLM_PROVIDER environment variables to determine the provider endpoint, target model name, and API key. It passes these values to get_model_context_length() from utils.call_llm to dynamically look up the model's token limit.

    DeterministicFileMapper

    Visibility: Public
    Inherits from: pocketflow.Node

    Filters non-code files and maps each remaining source file directly into an individual documentation abstraction for deterministic API reference generation.

    flowchart TD
    Prep[DeterministicFileMapper.prep] --> Exec[DeterministicFileMapper.exec]
    Exec --> Post[DeterministicFileMapper.post]
    Prep -.->|Prompt + Config| Exec
    Exec -.->|Valid File Indices| Post
    Post -.->|Shared Abstractions| NextNode[WriteChapters]

    DeterministicFileMapper.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Prepares the filtering prompt by listing all crawled files and combining them with project metadata for LLM evaluation.

    Parameters: * shared (dict): Shared pipeline state containing files and project_name.

    Returns: * tuple: (prompt: str, thinking_level: Optional[int], max_tokens: int).

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        project_name = shared["project_name"]

        file_listing = "\n".join([f"{i} # {path}" for i, (path, _) in enumerate(files_data)])

        prompt = build_code_file_filter_prompt(project_name, file_listing)
        return prompt, shared.get("thinking_level", None), shared.get("max_tokens", 100000)

    prep indexes all crawled files stored in shared["files"] into formatted strings ("{index} # {path}"). It invokes build_code_file_filter_prompt() from utils.prompts to generate the prompt that requests file classification from the model.

    DeterministicFileMapper.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> list[int]:

    Description: Dispatches the filtering prompt to the LLM, logs token metrics, and parses the returned YAML list of valid source code indices.

    Parameters: * prep_res (tuple): Unpacked tuple from prep() containing (prompt, thinking_level, max_tokens).

    Returns: * list[int]: Parsed list of validated file index integers.

    Raises: * Exception: Logs and re-raises any error occurring during LLM execution or parsing.

    Example: 

        def exec(self, prep_res):
        try:
            prompt, thinking_level, max_tokens = prep_res
            log_token_estimation(self.__class__.__name__, prompt, max_tokens)
            print("Smartly filtering non-code files using LLM...")
            response = call_llm(prompt, use_cache=True, thinking_level=thinking_level)
            valid_indices = parse_yaml_response(response)
            if not isinstance(valid_indices, list):
                valid_indices = []
            return [int(idx) for idx in valid_indices]
        except Exception as e:
            print(f"\033[93m[Node {self.__class__.__name__} Retry Triggered] Error: {e}\033[0m")
            llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
            raise e

    exec logs estimated token usage using utils.token_utils before calling utils.call_llm with response caching enabled. The returned YAML payload is extracted and coerced into integer file indices, skipping non-code assets like assets, configuration files, or logs.

    DeterministicFileMapper.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list[int]) -> str:

    Description: Constructs deterministic module records for all retained code files, populates chapter order and placeholder relationships in shared state, and routes to "default".

    Parameters: * shared (dict): Shared pipeline state dictionary. * prep_res (tuple): Output from prep(). * exec_res (list[int]): List of integer indices from exec().

    Returns: * str: Action "default" to transition to the next pipeline node.

    Example: 

        def post(self, shared, prep_res, exec_res):
        import os

        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, content) in enumerate(files):
            if idx not in valid_indices:
                print(f"  - Skipping non-code file: {file_path}")
                continue

            clean_name = os.path.splitext(file_path)[0].replace(os.sep, ".").replace("/", ".")

            modules.append(
                {"name": clean_name, "description": f"Internal API reference for `{file_path}`", "files": [idx], "original_path": file_path}
            )
            chapter_order.append(len(modules) - 1)

        shared["abstractions"] = modules
        shared["chapter_order"] = chapter_order
        shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
        print(f"\033[92m[DeterministicFileMapper] Mapped {len(modules)} ACTUAL code files for exhaustive documentation.\033[0m")
        return "default"

    The method iterates over all candidate files, skipping indices not present in valid_indices. For each retained file, it normalizes the path into a dotted module name, sets up an abstraction entry referencing the single file, builds sequential chapter ordering, and initializes static relationship metadata.

    ContextRouter

    Visibility: Public
    Inherits from: pocketflow.Node

    Calculates prompt and file token overhead, partitions large repositories into token-bounded batches grouped by directory structure, and selects the processing route ("direct", "batch", or "deterministic").

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Computes token usage across prompt templates, directory trees, and source files, compares total volume against context limits, and decides the routing strategy.

    Parameters: * shared (dict): Shared pipeline state containing files, max_tokens, mode, and optional flags.

    Returns: * tuple: Route metadata containing (route_type, files_data, effective_limit, batch_size, file_token_map, count_tokens, directory_tree, debug).

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)
        shared["max_tokens"] = max_tokens
        count_tokens = create_token_counter()
        // ... Template token overhead and directory tree calculation ...
        total_tokens = 0
        file_token_map = []
        for i, (path, content) in enumerate(files_data):
            entry = f"--- File Index {i}: {path} ---\n{content}\n\n"
            tokens = count_tokens(entry)
            total_tokens += tokens
            file_token_map.append(tokens)

        safety_limit = int(max_tokens * 0.95)
        effective_limit = safety_limit - prompt_overhead
        force_batch = shared.get("force_batch", False)

        if shared.get("mode", "tutorial") == "api-reference":
            return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)
        if total_tokens > effective_limit or force_batch:
            return ("batch", files_data, effective_limit, shared.get("batch_size", 50), file_token_map, count_tokens, directory_tree, shared.get("debug", False))
        return ("direct", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

    prep measures prompt overhead (the larger of tutorial or advanced template sizes plus the directory tree token weight). It computes exact token counts for each individual file entry and applies a 95% safety margin on max_tokens. If the repository fits within the effective limit and force_batch is false, it routes to "direct"; otherwise, it routes to "batch" or "deterministic".

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> Union[str, list]:

    Description: If batching is required, groups files by directory and splits them into token-bounded batches that do not mix directories.

    Parameters: * prep_res (tuple): Tuple from prep() containing routing and token information.

    Returns: * Union[str, list]: The string "direct" or "deterministic", or a list of batches where each batch is a list of (index, path, content) tuples.

    Example: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
        if route in ("direct", "deterministic"):
            return route

        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0
            for i, path, content, tokens in dir_groups[dirname]:
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0
                current_batch.append((i, path, content))
                current_tokens += tokens
            if current_batch:
                batches.append(current_batch)

        self._directory_tree = directory_tree
        return batches

    When batching, files are grouped by their parent directory path. The method iterates through each directory group in sorted order, accumulating files into a batch until adding another file would exceed either effective_limit tokens or batch_size files. Batches never mix files from different directories, maintaining structural coherence.

    ContextRouter.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: Union[str, list]) -> str:

    Description: Persists calculated batches and the global directory tree string into shared, returning the active route name.

    Parameters: * shared (dict): Shared pipeline state dictionary. * prep_res (tuple): Output tuple from prep(). * exec_res (Union[str, list]): String route name or list of generated batches from exec().

    Returns: * str: Route action ("direct", "deterministic", or "batch").

    Example: 

        def post(self, shared, prep_res, exec_res):
        if exec_res == "direct":
            return "direct"
        if exec_res == "deterministic":
            return "deterministic"
        shared["file_batches"] = exec_res
        # Reuse directory tree built during prep()
        shared["directory_tree"] = getattr(self, "_directory_tree", self._build_directory_tree(shared["files"]))
        return "batch"

    The method passes "direct" or "deterministic" straight through to trigger corresponding branch transitions in the flow. For "batch" execution, it populates shared["file_batches"] with the partitioned file lists and caches the pre-built directory_tree string in shared.

    ContextRouter._build_directory_tree()

    Visibility: Private
    Signature: def _build_directory_tree(files_data: list) -> str:

    Description: Generates an indented, compact text representation of the directory hierarchy annotated with file indices.

    Parameters: * files_data (list): List of (path, content) tuples representing all files.

    Returns: * str: Formatted multi-line string representing the directory tree.

    Example: 

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict

        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            for fname in sorted(dir_files[dirname]):
                lines.append(f"  {fname}")
        return "\n".join(lines)

    This static helper builds a directory map from file paths. It groups basenames under sorted directory keys and formats them with two-space indentation, appending (idx:N) next to each file.

    MapAbstractions.exec()

    Visibility: Public
    Signature: def exec(self, item: dict) -> list[dict]:

    Description: Formats prompt context for a single batch, calls the LLM to extract partial abstractions, and validates file index boundaries.

    Parameters: * item (dict): Batch configuration dictionary prepared by prep().

    Returns: * list[dict]: List of validated abstraction dictionaries with name, description, and sorted unique files indices.

    Example: 

        def exec(self, item):
        batch_index = item["batch_index"]
        files = item["files"]
        // ... build context and format prompt template ...
        response = call_llm(prompt, use_cache=(item["use_cache"] and self.cur_retry == 0), thinking_level=item["thinking_level"])
        abstractions = parse_yaml_response(response)

        validated_abstractions = []
        if isinstance(abstractions, list):
            for obj in abstractions:
                if isinstance(obj, dict) and "name" in obj and "description" in obj and "file_indices" in obj:
                    import re
                    validated_indices = []
                    for idx_entry in obj["file_indices"]:
                        nums = re.findall(r"\d+", str(idx_entry))
                        if nums:
                            validated_indices.append(int(nums[0]))
                    if validated_indices:
                        validated_abstractions.append(
                            {"name": obj["name"], "description": obj["description"], "files": sorted(list(set(validated_indices)))}
                        )
        return validated_abstractions

    exec formats the batch's files into prompt context and loads the map_abstractions template. After receiving the LLM response, it parses the YAML payload and validates each abstraction object. Regular expressions extract integer file indices, deduplicating and sorting them into the final files field.

    ReduceAbstractions.exec()

    AnalyzeRelationships

    Visibility: Public
    Inherits from: pocketflow.Node

    Extracts architectural relationships, dependencies, and data flows between discovered abstractions using a two-pass token redistribution algorithm.

    flowchart TD
    Init[Calculate Total Token Budget] --> Pass1[Pass 1: Allocate Equal Budget per Abstraction]
    Pass1 --> Check[Check for Unused Budget]
    Check -->|Unused tokens remain| Pass2[Pass 2: Redistribute to Deficit Abstractions]
    Check -->|No unused tokens| Context[Construct Context with File Snippets]
    Pass2 --> Context
    Context --> Exec[AnalyzeRelationships.exec - LLM Analysis]

    AnalyzeRelationships.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Constructs relationship context using a two-pass token redistribution algorithm that budgets file snippets evenly across abstractions and reallocates leftover capacity.

    Parameters: * shared (dict): Shared pipeline state containing abstractions, files, and token settings.

    Returns: * tuple: Context string, abstraction listings, and execution parameters.

    Example: 

        def prep(self, shared):
        // ... build initial abstraction listing ...
        max_tokens = shared.get("max_tokens", 100000)
        safety_limit = int(max_tokens * 0.95)
        prompt_overhead = 2000
        total_budget = safety_limit - estimate_tokens(context) - prompt_overhead
        num_abstractions = len(abstractions)

        per_abstr_budget = total_budget // max(num_abstractions, 1)
        included_indices = set()
        abstr_results = []

        # Pass 1: Allocate equal share
        for i, sized in enumerate(abstr_file_data):
            budget = per_abstr_budget
            included_files, remaining_files = [], []
            for idx, path, file_content, tokens in sized:
                if idx in included_indices:
                    included_files.append((idx, path, None, 0))
                    continue
                if tokens <= budget:
                    included_files.append((idx, path, file_content, tokens))
                    budget -= tokens
                    included_indices.add(idx)
                else:
                    remaining_files.append((idx, path, file_content, tokens))
            abstr_results.append((included_files, remaining_files, budget))

        # Pass 2: Redistribute unused budget
        total_unused = sum(r[2] for r in abstr_results)
        if total_unused > 0:
            for i, (included_files, remaining_files, _unused) in enumerate(abstr_results):
                if not remaining_files or total_unused <= 0:
                    continue
                still_remaining = []
                for idx, path, file_content, tokens in remaining_files:
                    if idx in included_indices:
                        included_files.append((idx, path, None, 0))
                        continue
                    if tokens <= total_unused:
                        included_files.append((idx, path, file_content, tokens))
                        total_unused -= tokens
                        included_indices.add(idx)
                    else:
                        still_remaining.append((idx, path, file_content, tokens))
                abstr_results[i] = (included_files, still_remaining, 0)
        // ... build context string from abstr_results ...
        return (context, "\n".join(abstraction_info_for_prompt), num_abstractions, project_name, language, use_cache, thinking_level, shared.get("advanced_mode", False), shared.get("max_tokens", 100000), shared.get("mode", "tutorial"))

    To prevent early abstractions from starving later ones, prep splits available context tokens evenly across all abstractions in Pass 1, prioritizing the largest files within each abstraction. In Pass 2, unused token budget from smaller abstractions is redistributed to abstractions with remaining unallocated files. Duplicate files across abstractions are referenced by name rather than re-injected.

For non-API modes, it then invokes build_chapter_summary_prompt() to generate a concise summary appended to self.chapter_summaries for subsequent chapters.

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: list, exec_res_list: list) -> None:

    Description: Stores generated chapter texts into shared["chapters"], writes .doc_cache_manifest.json if incremental mode is active, and cleans up instance state.

    Parameters: * shared (dict): Shared pipeline state dictionary. * prep_res (list): List of items prepared by prep(). * exec_res_list (list): List of result dictionaries from all batch executions.

    Returns: * None

    Example: 

        def post(self, shared, prep_res, exec_res_list):
        import json
        import os

        # exec_res_list contains dicts with content and hashes
        shared["chapters"] = [res["content"] for res in exec_res_list]

        # Save MD5 incremental manifest if enabled
        if shared.get("incremental"):
            output_dir = os.path.join(shared.get("output_dir", "output"), shared.get("project_name"))
            os.makedirs(output_dir, exist_ok=True)
            manifest_path = os.path.join(output_dir, ".doc_cache_manifest.json")

            manifest = {}
            if os.path.exists(manifest_path):
                try:
                    with open(manifest_path, "r", encoding="utf-8") as f:
                        manifest = json.load(f)
                except Exception:
                    pass

            for res in exec_res_list:
                if res.get("hash") and res.get("name"):
                    manifest[res["name"]] = res["hash"]

            with open(manifest_path, "w", encoding="utf-8") as f:
                json.dump(manifest, f, indent=2)

        del self.chapters_written_so_far
        del self.chapter_summaries
        print(f"Finished writing {len(exec_res_list)} chapters.")

    The method extracts the content strings from all batch results into shared["chapters"]. If incremental is enabled, it updates the .doc_cache_manifest.json file with the new abstraction hashes. Finally, it deletes temporary instance attributes to free memory.
