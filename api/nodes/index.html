    nodes

    Original Source File: nodes.py

    The nodes.py module defines the execution units for the Codebase-Knowledge-Builder pipeline using the pocketflow framework (Node and BatchNode abstractions). It manages repository ingestion, token capacity calculation, context routing, LLM-driven architectural discovery (direct, map-reduce, and deterministic file mapping), relational dependency mapping, chapter sequencing, chapter generation with incremental hash-based caching, and final MkDocs or Markdown compilation.

    Architecture and Node Flow

    The pipeline executes as a directed graph where nodes communicate state by mutating a centralized shared dictionary. Depending on repository size, token capacity, and operational mode (tutorial, advanced, sdk, or api-reference), processing routes dynamically through direct single-prompt analysis, chunked map-reduce analysis, or deterministic file-by-file mapping.

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list[tuple[str, str]], indices: list[int]) -> dict[str, str]:

    Description: Retrieves file path keys and source code contents from a global indexed file list given a list of target integer indices. It constructs a lookup map where the key is formatted as "{index} # {path}" to provide surrounding context to the language model.

    Parameters: * files_data (list[tuple[str, str]]): Sequence of (path, content) tuples representing all crawled source files. * indices (list[int]): List of integer indices to extract.

    Returns: * dict[str, str]: Mapping of formatted file index headers to raw file content strings.

    Raises: * None (out-of-bounds indices are ignored via boundary checks).

    Example: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = content  # Use index + path as key for context
    return content_map

    The function iterates over the target index list and verifies that each index falls within 0 <= i < len(files_data). If valid, it extracts the tuple and populates the dictionary with a composite key consisting of the integer index and file path. This helper guarantees safe access to repository content during chapter compilation and abstraction analysis without raising indexing exceptions.

    def parse_yaml_response(response):

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> Callable[[str], int]:

    Description: Constructs a token-counting closure using tiktoken's cl100k_base encoding model, falling back to a character heuristic calculation (len(text) // 4) if tiktoken or the encoding dictionary is unavailable.

    Parameters: * None.

    Returns: * Callable[[str], int]: A callable function accepting a string and returning its estimated token count.

    Raises: * None.

    Example: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    The returned closure evaluates arbitrary strings while disabling special token syntax checking (disallowed_special=()), preventing tokenizer exceptions when analyzing raw source files containing syntax that resembles special tokens. If the encoding initialization fails, the function falls back to a 4-character-per-token heuristic.

    Class: ContextRouter

    ContextRouter calculates token overhead across prompts, directory listings, and raw file contents to decide whether to process files directly (direct), via batching (batch), or through deterministic mapping (deterministic).

    Visibility: Private (Static)
    Signature: def _build_directory_tree(files_data: list[tuple[str, str]]) -> str:

    Description: Generates an indented ASCII/text directory hierarchy of files annotated with their global integer indices.

    Parameters: * files_data (list[tuple[str, str]]): List of (path, content) tuples.

    Returns: * str: Formatted directory tree string.

    Example: 

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict

        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            lines.extend(f"  {fname}" for fname in sorted(dir_files[dirname]))
        return "\n".join(lines)

    The method groups files by their parent directory path using a defaultdict(list). It sorts directories alphabetically and lists contained filenames along with their global index identifiers (e.g., nodes.py (idx:2)).

    exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]:

    Description: Partitions files into directory-isolated batches when the batch route is selected, ensuring individual batches do not cross directory boundaries or exceed token and size limits.

    Parameters: * prep_res (tuple): Unpacked parameter tuple from prep().

    Returns: * str | list[list[tuple[int, str, str]]]: "direct", "deterministic", or a list of file batches where each batch contains (index, path, content) items.

    Example: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
        llm_logger.info(
            f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}"
        )

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            # Flush remaining files in this directory
            if current_batch:
                batches.append(current_batch)

        batch_word = "batch" if len(batches) == 1 else "batches"
        print(f"\033[93m[Capacity] Split into {len(batches)} {batch_word}.\033[0m")
        llm_logger.info(f"NODE COMPLETE | node=ContextRouter | route={route} | batches={len(batches)}")

        // ... [debug logging] ...
        self._directory_tree = directory_tree
        return batches

    When batching is required, files are grouped by their directory (os.path.dirname). The method iterates through directories in sorted order and creates new batches whenever adding a file would exceed either effective_limit or batch_size. This ensures batches maintain directory coherence.

    post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list[int]) -> str:

    Description: Builds 1:1 abstraction dictionaries for each valid code file, assigns the default chapter order, and updates shared["abstractions"].

    Parameters: * shared (dict): Shared pipeline state. * prep_res (tuple): Data from prep(). * exec_res (list[int]): List of valid file indices from exec().

    Returns: * str: Action return value "default".

    Example: 

        def post(self, shared, prep_res, exec_res):
        import os

        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, _content) in enumerate(files):
            if idx not in valid_indices:
                print(f"  - Skipping non-code file: {file_path}")
                continue

            )
            chapter_order.append(len(modules) - 1)

        shared["abstractions"] = modules
