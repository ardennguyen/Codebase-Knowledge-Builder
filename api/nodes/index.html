    Original File Path: nodes.py

    Technical Overview

    The nodes.py module serves as the primary execution engine for Codebase-Knowledge-Builder. Built on top of the PocketFlow framework (Node and BatchNode), it defines the graph computation stages required to crawl a codebase, filter code files, analyze architectural abstractions, extract module relationships, determine logical chapter sequences, write comprehensive documentation chapters, and assemble the final output (either as a traditional markdown book or as an MkDocs Material documentation site).

    The module supports two primary generation strategies: 1. Direct / LLM-Assisted Pipeline: Analyzes codebase topology, clusters abstractions, discovers relationships, sequences chapters, and generates tutorial/advanced documentation with cross-chapter summarization. 2. Deterministic API-Reference Pipeline: Employs an LLM-filtered deterministic mapper to produce exhaustive 1:1 API documentation for every actual code file, bypassing abstraction discovery and generating structured hierarchical navigation trees.

    The workflow supports token-aware batching (via utils.token_utils and utils.call_llm), multi-language generation, and incremental MD5 content caching to prevent redundant LLM invocations.

    get_content_for_indices()

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list, indices: list) -> dict:

    Description: Resolves file index references into a structured dictionary mapping index keys (formatted as "{index} # {path}") to file text contents. This mapping provides contextual anchors for LLM prompts when referencing files across abstractions.

    Parameters: * files_data (list[tuple[str, str]]): List of tuples containing relative file paths and file content strings. * indices (list[int]): List of integer indices corresponding to items in files_data.

    Returns: * dict[str, str]: Mapping of index-annotated path keys to file content strings.

    Raises: * None. Out-of-bounds indices are ignored via boundary verification (0 <= i < len(files_data)).

    Example: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = content  # Use index + path as key for context
    return content_map

    The function iterates over the target file indices, bounds-checking each index against files_data. Valid files are injected into the returned dictionary with key format f"{i} # {path}". This specific key format matches the syntax expected by the prompt templates loaded via utils.prompts.

    load_prompt_template()

    Visibility: Public
    Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str = None) -> str:

    Description: Reads Markdown prompt template files stored within the package's prompts/ directory. It selects the subdirectory based on explicit mode configuration or fallback flags, handling UTF-8-SIG encoded files cleanly.

    Parameters: * template_name (str): Base name of the prompt template file (without .md extension). * advanced_mode (bool): Fallback flag used to choose between "advanced" and "tutorial" when mode is None. Defaults to False. * mode (str | None): Specific prompt mode subdirectory (e.g., "tutorial", "advanced", "api-reference", "common"). Defaults to None.

    Returns: * str: Raw template content read from disk.

    Raises: * FileNotFoundError: If the constructed path does not exist. * IOError: If the file cannot be read.

    Example: 

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts", prompt_dir, f"{template_name}.md")
    with open(path, encoding="utf-8-sig") as f:
        return f.read()

    The function resolves relative path coordinates against __file__, resolving the target subdirectory dynamically. The utf-8-sig encoding ensures seamless handling of Byte Order Marks (BOM) when reading templates across different operating systems.

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> dict | list:

    Description: Parses structured YAML payloads returned from LLM completions that are enclosed in markdown triple-backtick code fences (```yaml).

    Parameters: * response (str): Raw text response generated by the LLM.

    Returns: * dict | list: Parsed Python data structure returned by yaml.safe_load.

    Raises: * ValueError: If the YAML fence is missing or if yaml.safe_load fails to parse the extracted block.

    Example: 

    def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}") from e

    The parsing strategy splits the string strictly around the ```yaml marker and terminates at the subsequent closing ``` fence. It trims excess whitespace and processes the payload safely using yaml.safe_load(). Any parse error or fence-split failure wraps into a descriptive ValueError to trigger upstream node retries.

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> Callable[[str], int]:

    Description: Factory function providing a callable token counter. It initializes tiktoken with the cl100k_base encoding (OpenAI standard) and falls back to a 4-characters-per-token heuristic if tiktoken fails or is unavailable.

    Returns: * Callable[[str], int]: A lambda function accepting a string and returning estimated token length.

    Example: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    Under normal operation, the returned lambda executes len(enc.encode(text, disallowed_special=())) to disable special token validation exceptions. If encoding resolution raises any exception, it falls back gracefully to len(text) // 4.

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Resolves the effective maximum context window for the current execution run. It prioritizes explicit limits configured in shared["max_tokens"], falling back to provider inspection via environment variables.

    Parameters: * shared (dict): PocketFlow shared memory dictionary.

    Returns: * int: Context length limit in tokens.

    Example: 

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    If max_tokens is not directly provided in shared, the function inspects LLM_PROVIDER. If set to GEMINI (or omitted), it evaluates defaults for Google Gemini endpoints. For generic OpenAI-compatible providers, it constructs base URL, model name, and API key environment variable lookups and delegates context window detection to get_model_context_length from utils.call_llm.

    Visibility: Public
    Signature: def prep(self, shared: dict) -> dict:

    Description: Extracts repository coordinates (repo_url, local_dir), project name, pattern filters (include_patterns, exclude_patterns), and maximum file size constraints from shared. Derives the project name if absent.

    Parameters: * shared (dict): Shared state store.

    Returns: * dict: Prepared parameter dictionary for file crawling.

    Example: 

        def prep(self, shared):
        repo_url = shared.get("repo_url")
        local_dir = shared.get("local_dir")
        project_name = shared.get("project_name")

        if not project_name:
            # Basic name derivation from URL or directory
            if repo_url:
                project_name = repo_url.split("/")[-1].replace(".git", "")
            else:
                project_name = os.path.basename(os.path.abspath(local_dir))

        exclude_patterns = shared["exclude_patterns"]
        max_file_size = shared["max_file_size"]

        return {
            "repo_url": repo_url,
            "local_dir": local_dir,
            "token": shared.get("github_token"),
            "include_patterns": include_patterns,
            "exclude_patterns": exclude_patterns,
            "max_file_size": max_file_size,
            "use_relative_paths": True,
        }

    The method sanitizes project identification by stripping .git from remote URLs or resolving directory basenames locally. It packages include/exclude glob rules and relative path configurations for exec().

    FetchRepo.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: dict) -> list[tuple[str, str]]:

    Description: Executes either utils.crawl_github_files or utils.crawl_local_files based on the presence of repo_url. Transforms output dictionary mappings into [(path, content), ...] tuples.

    Parameters: * prep_res (dict): Crawler parameters from prep().

    Returns: * list[tuple[str, str]]: List of 2-element tuples containing relative file paths and string contents.

        def exec(self, prep_res):
        source = prep_res["repo_url"] or prep_res["local_dir"]
        llm_logger.info(f"NODE EXEC | node=FetchRepo | action=crawl_files | source={source}")

        if prep_res["repo_url"]:
            print(f"Crawling repository: {prep_res['repo_url']}...")
            result = crawl_github_files(
                repo_url=prep_res["repo_url"],
                token=prep_res["token"],
                include_patterns=prep_res["include_patterns"],
                exclude_patterns=prep_res["exclude_patterns"],
                max_file_size=prep_res["max_file_size"],
                use_relative_paths=prep_res["use_relative_paths"],
            )
        else:
            print(f"Crawling directory: {prep_res['local_dir']}...")

            result = crawl_local_files(
                directory=prep_res["local_dir"],
                include_patterns=prep_res["include_patterns"],
                exclude_patterns=prep_res["exclude_patterns"],
                max_file_size=prep_res["max_file_size"],
                use_relative_paths=prep_res["use_relative_paths"],
            )

        # Convert dict to list of tuples: [(path, content), ...]
        files_list = list(result.get("files", {}).items())
        if len(files_list) == 0:
            raise ValueError("No matching files found. Check your directory and include/exclude patterns.")

        llm_logger.info(f"NODE COMPLETE | node=FetchRepo | files_found={len(files_list)}")
        return files_list

    The method branches execution dynamically to either GitHub API crawling or local filesystem traversal. Output dictionaries are converted to list tuples. An explicit ValueError guard aborts the pipeline early if filtering yielded an empty file set.

    Class: ContextRouter

    ContextRouter analyzes total prompt overhead, file token counts, and documentation mode to choose between direct, batch (map-reduce), and deterministic pipelines.

    ContextRouter._build_directory_tree()

    Visibility: Private (Static)
    Signature: def _build_directory_tree(files_data: list[tuple[str, str]]) -> str:

    Description: Constructs a compact text-based representation of the directory structure annotated with index numbers for each file.

    Parameters: * files_data (list[tuple[str, str]]): List of (path, content) tuples.

    Returns: * str: Formatted directory tree string.

    Example: 

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict

        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            lines.extend(f"  {fname}" for fname in sorted(dir_files[dirname]))
        return "\n".join(lines)

    The helper groups files under their containing folder path using defaultdict(list). It sorts directories alphabetically and formats the tree with leading indents and file index tags (basename (idx:0)).

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Calculates token overhead (prompt templates, directory tree, file index listings), estimates total file tokens, determines safety margins (95% of max context), and decides the execution route (deterministic, direct, or batch).

    Parameters: * shared (dict): Shared state store.

    Returns: * tuple: Prepared routing tuple including route key, file data, limits, and batch parameters.

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)

        shared["max_tokens"] = max_tokens

        # --- Token estimation setup ---
        count_tokens = create_token_counter()

        // ... [measures template, directory tree, and listing tokens to compute prompt_overhead]

        # --- Count file content tokens ---
        total_tokens = 0
        file_token_map = []
        for i, (path, content) in enumerate(files_data):
            entry = f"--- File Index {i}: {path} ---\n{content}\n\n"
            tokens = count_tokens(entry)
            total_tokens += tokens
            file_token_map.append(tokens)

        # --- Effective limit = safety margin minus overhead ---
        safety_limit = int(max_tokens * 0.95)
        effective_limit = safety_limit - prompt_overhead
        force_batch = shared.get("force_batch", False)

        if shared.get("mode", "tutorial") == "api-reference":
            print("\033[92m[Capacity] api-reference mode active. Bypassing LLM discovery and routing to DeterministicFileMapper.\033[0m")
            return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

        if total_tokens > effective_limit and force_batch:
            // ... [logs capacity warnings]
        // ... [checks total_tokens <= effective_limit and returns ("direct", ...) or ("batch", ...)]

    prep() calculates prompt overhead by measuring template sizes across tutorial and advanced folders and adding the directory tree and file index sizes. If mode is api-reference, it immediately selects deterministic. Otherwise, if total file tokens exceed effective_limit or force_batch is set, it selects batch; otherwise, it routes to direct.

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]:

    Description: If routed as direct or deterministic, returns the route string. If batch, groups files by directory and splits them into token-budgeted, non-mixing directory batches.

    Parameters: * prep_res (tuple): Unpacked parameter tuple from prep().

    Returns: * str | list[list[tuple[int, str, str]]]: Routing string or list of file batches.

    Example: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
        llm_logger.info(
            f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}"
        )

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            # Flush remaining files in this directory
            if current_batch:
                batches.append(current_batch)
        // ... [logs debug batch info and saves directory tree]
        return batches

    The batching algorithm organizes files by directory to preserve lexical and architectural cohesion. It prevents mixing files from different directories in the same batch, splitting a directory into sub-batches only when token counts exceed effective_limit or file count exceeds batch_size.

    DeterministicFileMapper.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list[int]) -> str:

    Description: Converts valid code file indices into 1:1 module records. Injects shared["abstractions"], shared["chapter_order"], and synthetic shared["relationships"] directly into state, routing to "default".

    Parameters: * shared (dict): Shared state store. * prep_res (tuple): Result from prep(). * exec_res (list[int]): Valid code indices from exec().

    Returns: * str: Returns "default".

    Example: 

        def post(self, shared, prep_res, exec_res):
        import os

        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, _content) in enumerate(files):
            if idx not in valid_indices:
                print(f"  - Skipping non-code file: {file_path}")
                continue

            clean_name = os.path.splitext(file_path)[0].replace(os.sep, ".").replace("/", ".")

            modules.append(
                {"name": clean_name, "description": f"Internal API reference for `{file_path}`", "files": [idx], "original_path": file_path}
            )
            chapter_order.append(len(modules) - 1)

        shared["abstractions"] = modules
        shared["chapter_order"] = chapter_order
        shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
        print(f"\033[92m[DeterministicFileMapper] Mapped {len(modules)} ACTUAL code files for exhaustive documentation.\033[0m")
        return "default"

    The method normalizes each file's relative path into a dot-separated module identifier (e.g., utils/call_llm.py becomes utils.call_llm). Each abstraction points to a single file index via files: [idx], and chapter_order is assigned linearly.

    AnalyzeRelationships.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Distributes available context tokens evenly across identified abstractions in Pass 1, redistributes unused token budget to larger abstractions in Pass 2, and inlines file snippets without exceeding context limits.

    Parameters: * shared (dict): Shared state store.

    Returns: * tuple: Relationship prompt parameters and budgeted code contexts.

    Example: 

        def prep(self, shared):
        abstractions = shared["abstractions"]
        files_data = shared["files"]
        project_name = shared["project_name"]
        language = shared.get("language", "english")
        use_cache = shared.get("use_cache", True)
        thinking_level = shared.get("thinking_level", None)

        // ... [initializes context with abstraction descriptions and token metrics]
        # Pre-compute file token sizes for all abstractions
        abstr_file_data = []
        for abstr in abstractions:
            sized = []
            for idx in abstr["files"]:
                if 0 <= idx < len(files_data):
                    path, file_content = files_data[idx]
                    entry = f"\n--- File: {idx} # {path} ---\n{file_content}\n"
                    sized.append((idx, path, file_content, estimate_tokens(entry)))
            sized.sort(key=lambda x: x[3], reverse=True)
            abstr_file_data.append(sized)

        # Two-pass allocation:
        per_abstr_budget = total_budget // max(num_abstractions, 1)
        included_indices = set()
        abstr_results = []

        for _i, sized in enumerate(abstr_file_data):
            budget = per_abstr_budget
            included_files = []
            remaining_files = []
            for idx, path, file_content, tokens in sized:
                if idx in included_indices:
                    included_files.append((idx, path, None, 0))
                    continue
                if tokens <= budget:
                    included_files.append((idx, path, file_content, tokens))
                    budget -= tokens
                    included_indices.add(idx)
                else:
                    remaining_files.append((idx, path, file_content, tokens))
            abstr_results.append((included_files, remaining_files, budget))

        # Pass 2: redistribute unused budget to abstractions with remaining files
        total_unused = sum(r[2] for r in abstr_results)
        if total_unused > 0:
            for i, (included_files, remaining_files, _unused) in enumerate(abstr_results):
                if not remaining_files or total_unused <= 0:
                    continue
                still_remaining = []
                for idx, path, file_content, tokens in remaining_files:
                    if idx in included_indices:
                        included_files.append((idx, path, None, 0))
                        continue
                    if tokens <= total_unused:
                        included_files.append((idx, path, file_content, tokens))
                        total_unused -= tokens
                        included_indices.add(idx)
                    else:
                        still_remaining.append((idx, path, file_content, tokens))
                abstr_results[i] = (included_files, still_remaining, 0)
        // ... [formats context strings and returns prep tuple]

    The budgeting algorithm prevents late-stage starvation by allocating total_budget // num_abstractions to each abstraction in Pass 1. Files already included in prior abstractions are deduplicated. In Pass 2, any unspent token balance is pooled and used to include remaining files from larger abstractions.

                manifest_path = os.path.join(output_dir, project_name, ".doc_cache_manifest.json")
                if os.path.exists(manifest_path):
                    with open(manifest_path, encoding="utf-8") as f:
                        manifest = json.load(f)
                    if manifest.get(abstraction_name) == current_hash:
                        // ... [loads cached markdown and appends to context summaries]
                        return {"content": clean_content, "hash": current_hash, "name": abstraction_name}

            // ... [formats draft_chapters.md and invokes call_llm]
            chapter_content = call_llm(prompt, use_cache=(use_cache and self.cur_retry == 0), thinking_level=thinking_level)
            self.chapters_written_so_far.append(chapter_content)

            # Generate LLM summary for cross-chapter context (skip for api-reference)
            if doc_mode != "api-reference":
                summary_prompt = build_chapter_summary_prompt(chapter_num, abstraction_name, chapter_content, language)
                chapter_summary = call_llm(summary_prompt, use_cache=True, thinking_level=None)
                self.chapter_summaries.append(f"Chapter {chapter_num} — {abstraction_name.strip()}:\n{chapter_summary}")

            return {"content": chapter_content, "hash": current_hash, "name": abstraction_name}
        except Exception as e:
            llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
            raise e

    The method uses condensed 3-5 sentence LLM-generated summaries rather than full chapter dumps for cross-chapter context, avoiding $O(N^2)$ token explosion across chapters.

        @staticmethod
    def _build_index_sections(lines, sections, chapter_files, level=3):
        """Recursively build index.md sections with module tables."""
        heading = "#" * level
        for section in sections:
            lines.append(f"{heading} {section['name']}")
            lines.append("")
            if section.get("modules"):
                lines.append("| Module | Description |")
                lines.append("|--------|-------------|")
                for mod_name in section["modules"]:
                    match = next((cf for cf in chapter_files if cf["module_name"] == mod_name), None)
                    if match:
                        display = mod_name.split(".")[-1] if "." in mod_name else mod_name
                        desc = match["description"]
                        if desc.startswith("Internal API reference"):
                            content_lines = match["content"].strip().split("\n")
                            for cl in content_lines:
                                cs = cl.strip()
                                if cs and not cs.startswith(("---", "#", "```", "title:", "sidebar_position:")):
                                    desc = cs[:120]
                                    break
                        lines.append(f"| [{display}](api/{match['filename']}) | {desc} |")
                lines.append("")
            for child in section.get("children", []):
                CombineTutorial._build_index_sections(lines, [child], chapter_files, level + 1)

    The method renders hierarchical section headers and markdown tables. If module descriptions contain placeholder text (such as "Internal API reference for..."), it extracts the first non-empty paragraph from the generated chapter markdown.
