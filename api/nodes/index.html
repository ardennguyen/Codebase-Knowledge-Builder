    nodes

    Original Source File: nodes.py

    Technical documentation and internal engineering reference for nodes.py. This module defines the pipeline nodes, execution lifecycle stages, token estimation routines, and graph abstractions powering the Codebase-Knowledge-Builder engine.

    Overview

    The nodes.py module defines the operational logic executed within the pocketflow orchestration graph. It encapsulates file discovery, LLM context limit resolution, batching, architectural abstraction extraction, relational synthesis, chapter dependency ordering, draft generation (with cross-chapter summarization and incremental hashing), and site documentation output formatting (standard Markdown and MkDocs layouts).

    The pipeline switches execution paths dynamically based on token volume, user parameters, and execution modes (tutorial, advanced, and api-reference).

    Description: Constructs an index-keyed dictionary containing file paths and source contents corresponding to a provided sequence of integer file indices. Keys are structured as "{index} # {path}" to preserve positional context during LLM prompt generation.

    Parameters: * files_data (list): List of (path, content) tuples representing all crawled source files. * indices (list): List of integer indices indicating which files to extract.

    Returns: * dict: Map of formatted index-path identifier keys to file content strings.

    Raises: * None. Out-of-bounds indices are ignored via bounds checking (0 <= i < len(files_data)).

    Implementation: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = (
                content  # Use index + path as key for context
            )
    return content_map

    The function iterates over the supplied indices sequence and safely validates index boundaries against files_data. If an index is valid, it retrieves the corresponding (path, content) tuple and assigns the content string into the content_map with an LLM-friendly comment label formatted as "{i} # {path}". If an index falls outside the boundary array, it is silently bypassed.

    create_token_counter()

    Visibility: Public Helper
    Signature: def create_token_counter() -> callable:

    Description: Constructs a token counting callable. Attempts initialization of OpenAI's cl100k_base encoding using tiktoken. If initialization fails, it returns a character-division heuristic fallback (len(text) // 4).

    Returns: * callable: A function (str) -> int accepting a string and returning token counts.

    Raises: * None.

    Implementation: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    This factory routine initializes tiktoken.get_encoding("cl100k_base"). The returned closure disables special token restrictions via disallowed_special=(), allowing arbitrary source code and comment syntax to be tokenized safely. If tiktoken fails to load, the function returns a fallback lambda calculating string length divided by 4.

    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Determines the maximum context length token budget available for LLM interactions. It checks the shared memory state first, falling back to querying provider context limits via environment configuration and utils.call_llm.

    Parameters: * shared (dict): Shared pipeline memory dictionary.

    Returns: * int: Context token limit for the active LLM provider.

    Implementation: 

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    The function checks if max_tokens is explicitly set in shared. When absent, it inspects LLM_PROVIDER. If set to GEMINI (or omitted), it defaults to Google Gemini endpoints and reads GEMINI_MODEL and GEMINI_API_KEY. For other providers (e.g., OPENAI, ANTHROPIC, OLLAMA), it constructs environment variable names using the provider prefix to retrieve the base URL, model name, and API credentials before invoking get_model_context_length().

    ContextRouter._build_directory_tree()

    Visibility: Private / Static
    Signature: def _build_directory_tree(files_data: list) -> str:

    Description: Generates an indented ASCII/textual tree representation of all repository files annotated with their global integer indices.

    Parameters: * files_data (list): Sequence of (path, content) tuples.

    Returns: * str: Formatted directory tree string.

    Implementation: 

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict
        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            for fname in sorted(dir_files[dirname]):
                lines.append(f"  {fname}")
        return "\n".join(lines)

    The helper groups basenames by their directory path using a defaultdict(list). It sorts the directories alphabetically, indenting files beneath each directory line along with their index tags (e.g., call_llm.py (idx:4)).

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Measures prompt overhead (prompt templates and directory tree tokens) and compares total source token size against effective model limits (95% safety margin minus prompt overhead). Decides whether to use direct or batched mapping.

    Parameters: * shared (dict): Shared pipeline state store.

    Returns: * tuple: Routing parameters tuple containing route indicator string ("deterministic", "direct", or "batch"), files_data, effective_limit, batch_size, token maps, counter functions, and directory tree text.

    Implementation: 

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)

        shared["max_tokens"] = max_tokens

        # --- Token estimation setup ---
        count_tokens = create_token_counter()

        # --- Calculate prompt overhead FIRST ---
        # 1. Prompt template (measure both, use the larger)
        prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
        max_template_tokens = 0
        for subdir in ["tutorial", "advanced"]:
            template_path = os.path.join(prompt_dir, subdir, "map_abstractions.md")
            if os.path.exists(template_path):
                with open(template_path, "r", encoding="utf-8-sig") as f:
                    t = count_tokens(f.read())
                max_template_tokens = max(max_template_tokens, t)

        # 2. Directory tree (built from all files, shared across batches)
        directory_tree = self._build_directory_tree(files_data)
        tree_tokens = count_tokens(directory_tree)

        prompt_overhead = max_template_tokens + tree_tokens
        print(f"\033[93m[ContextRouter] Prompt overhead: ~{prompt_overhead:,} tokens "
              f"(template: {max_template_tokens:,}, dir tree: {tree_tokens:,})\033[0m")

        # --- Count file content tokens ---
        total_tokens = 0
        file_token_map = []
        for i, (path, content) in enumerate(files_data):
            entry = f"--- File Index {i}: {path} ---\n{content}\n\n"
            tokens = count_tokens(entry)
            total_tokens += tokens
            file_token_map.append(tokens)

        safety_limit = int(max_tokens * 0.95)
        effective_limit = safety_limit - prompt_overhead
        force_batch = shared.get("force_batch", False)

        if shared.get("mode", "tutorial") == "api-reference":
            print(f"\033[92m[ContextRouter] api-reference mode active. Bypassing LLM discovery and routing to DeterministicFileMapper.\033[0m")
            return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50),
                    None, None, directory_tree, False)

        if total_tokens > effective_limit and force_batch:
            // ... [console print logic]
        elif total_tokens > effective_limit:
            // ... [console print logic]
        elif force_batch:
            // ... [console print logic]
        else:
            print(f"\033[92m[ContextRouter] File content ({total_tokens:,} tokens) fits in effective limit "
                  f"({effective_limit:,} = {safety_limit:,} - {prompt_overhead:,} overhead). "
                  f"Proceeding normally.\033[0m")
            return ("direct", files_data, effective_limit, shared.get("batch_size", 50),
                    None, None, directory_tree, False)

        return ("batch", files_data, effective_limit, shared.get("batch_size", 50),

If mode equals "api-reference", it routes to "deterministic".     ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple]]:

    Description: Handles routing branches. For "batch" routes, partitions files into token-bounded batches grouped by directory structure without mixing directory boundaries.

    Parameters: * prep_res (tuple): Execution configuration returned by prep().

    Returns: * str | list: Returns "direct" or "deterministic" for non-batch routes, or a list of batches where each batch contains (index, path, content) tuples.

    Implementation: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, count_tokens, directory_tree, debug = prep_res
        llm_logger.info(f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}")

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            # Flush remaining files in this directory
            if current_batch:
                batches.append(current_batch)

        batch_word = "batch" if len(batches) == 1 else "batches"
        print(f"\033[93m[ContextRouter] Split into {len(batches)} {batch_word}.\033[0m")
        llm_logger.info(f"NODE COMPLETE | node=ContextRouter | route={route} | batches={len(batches)}")

        // ... [debug logging logic]

        # Store directory tree for later use
        self._directory_tree = directory_tree

        return batches

    For batch processing, files are grouped by their parent directory paths. The method creates cohesive file batches ensuring that files from different directories are not blended in the same batch. If adding a file exceeds either the effective_limit or batch_size, the active batch is flushed and a new batch is created.

    Description: Allocates available token capacity across all abstractions using a two-pass budget distribution algorithm. Large files take precedence within an abstraction's share, and unused token budgets from smaller abstractions roll over to larger ones.

        def prep(self, shared):
        abstractions = shared["abstractions"]
        files_data = shared["files"]
        project_name = shared["project_name"]
        language = shared.get("language", "english")
        use_cache = shared.get("use_cache", True)
        thinking_level = shared.get("thinking_level", None)

        num_abstractions = len(abstractions)
        context = "Identified Abstractions:\n"
        all_relevant_indices = set()
        abstraction_info_for_prompt = []
        for i, abstr in enumerate(abstractions):
            file_indices_str = ", ".join(map(str, abstr["files"]))
            info_line = f"- Index {i}: {abstr['name']} (Relevant file indices: [{file_indices_str}])\n  Description: {abstr['description']}"
            context += info_line + "\n"
            abstraction_info_for_prompt.append(f"{i} # {abstr['name']}")
            all_relevant_indices.update(abstr["files"])

        context += "\nRelevant File Snippets (per abstraction, budget-aware):\n"
        max_tokens = shared.get("max_tokens", 100000)
        safety_limit = int(max_tokens * 0.95)
        prompt_overhead = 2000

        estimate_tokens = create_token_counter()
        current_tokens = estimate_tokens(context)
        total_budget = safety_limit - current_tokens - prompt_overhead

        # Pre-compute file token sizes for all abstractions
        abstr_file_data = []
        for abstr in abstractions:
            sized = []
            for idx in abstr["files"]:
                if 0 <= idx < len(files_data):
                    path, file_content = files_data[idx]
                    entry = f"\n--- File: {idx} # {path} ---\n{file_content}\n"
                    sized.append((idx, path, file_content, estimate_tokens(entry)))
            sized.sort(key=lambda x: x[3], reverse=True)
            abstr_file_data.append(sized)

        # Two-pass allocation:
        per_abstr_budget = total_budget // max(num_abstractions, 1)
        included_indices = set()
        abstr_results = []

        for i, sized in enumerate(abstr_file_data):
            budget = per_abstr_budget
            included_files, remaining_files = [], []
            for idx, path, file_content, tokens in sized:
                if idx in included_indices:
                    included_files.append((idx, path, None, 0))
                    continue
                if tokens <= budget:
                    included_files.append((idx, path, file_content, tokens))
                    budget -= tokens
                    included_indices.add(idx)
                else:
                    remaining_files.append((idx, path, file_content, tokens))
            abstr_results.append((included_files, remaining_files, budget))

        # Pass 2: redistribute unused budget to abstractions with remaining files
        total_unused = sum(r[2] for r in abstr_results)
        if total_unused > 0:
            for i, (included_files, remaining_files, _unused) in enumerate(abstr_results):
                if not remaining_files or total_unused <= 0:
                    continue
                still_remaining = []
                for idx, path, file_content, tokens in remaining_files:
                    if idx in included_indices:
                        included_files.append((idx, path, None, 0))
                        continue
                    if tokens <= total_unused:
                        included_files.append((idx, path, file_content, tokens))
                        total_unused -= tokens
                        included_indices.add(idx)
                    else:
                        still_remaining.append((idx, path, file_content, tokens))
                abstr_results[i] = (included_files, still_remaining, 0)

        // ... [assembles formatted context string from abstr_results]

                language, use_cache, thinking_level, shared.get("advanced_mode", False),
                shared.get("max_tokens", 100000), shared.get("mode", "tutorial"))
