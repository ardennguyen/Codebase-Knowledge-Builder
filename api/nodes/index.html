    nodes

    Source: nodes.py

    The nodes.py module defines the operational workflow units used in the documentation generation pipeline. Built on top of the pocketflow framework (Node and BatchNode base classes), each node implements a three-phase lifecycle: prep() to validate and prepare state from the shared store, exec() to execute the core processing or LLM invocations, and post() to mutate the shared dictionary and route the execution flow.

    The pipeline automates repository crawling, token capacity management, map-reduce abstraction extraction, topological architectural analysis, incremental chapter writing, and site assembly (supporting both standalone Markdown bundles and formatted MkDocs structures with Mermaid visualizations).

    Module-Level Functions

    get_content_for_indices()

    Visibility: Public Signature: def get_content_for_indices(files_data: list, indices: list) -> dict:

    Description: Resolves file indices to their corresponding file paths and textual content from the crawler file payload, generating a keyed map where keys retain both the file index and relative path.

    Parameters: * files_data (list): List of tuples containing (path, content). * indices (list): List of integer indices corresponding to target files.

    Returns: * dict: Mapping formatted as {"{index} # {path}": content} for each valid index within bounds.

    Raises: * None. Out-of-bounds indices are ignored.

    Example: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = content  # Use index + path as key for context
    return content_map

    This helper function extracts file snippets corresponding to specific abstraction requirements. By encoding both the index and file path directly into the dictionary key (f"{i} # {path}"), it maintains provenance information across LLM prompt contexts. It skips negative indices or indices beyond the bounds of files_data, preventing index errors during batch processing.

    load_prompt_template()

    Visibility: Public Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str = None) -> str:

    Description: Resolves and reads Markdown prompt templates from the local prompts/ directory based on the execution mode (tutorial, advanced, api-reference, etc.).

    Parameters: * template_name (str): Base name of the prompt template file (without .md). * advanced_mode (bool, optional): Legacy flag indicating whether to use the advanced/ prompt directory. Defaults to False. * mode (str, optional): Specific prompt directory mode name. Overrides advanced_mode. Defaults to None.

    Returns: * str: UTF-8 decoded content of the prompt template file.

    Raises: * FileNotFoundError: If the constructed path does not exist on disk. * OSError: If reading the file fails.

    Example: 

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts", prompt_dir, f"{template_name}.md")
    with open(path, encoding="utf-8-sig") as f:
        return f.read()

    This function resolves prompt template paths relative to the nodes.py script location. It uses utf-8-sig encoding to handle Byte Order Marks (BOM) when reading prompt markdown templates across different platforms. The directory resolution prioritizes explicit mode strings over the legacy boolean advanced_mode parameter.

    parse_yaml_response()

    Visibility: Public Signature: def parse_yaml_response(response: str) -> Any:

    Description: Extracts fenced YAML blocks (```yaml ... ```) from raw LLM string responses and deserializes them into Python objects using PyYAML.

    Parameters: * response (str): Raw text response returned by an LLM completion.

    Returns: * Any: Deserialized Python data structures (typically list or dict).

    Raises: * ValueError: If the response does not contain valid ```yaml fences or if yaml.safe_load fails.

    Example: 

    def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}") from e

    parse_yaml_response enforces structured output extraction from LLM completions. It isolates text delimited by ```yaml and ``` code fences, ignoring any introductory or concluding conversational prose emitted by the model. If no YAML block is found or if parsing fails, it raises a ValueError with the underlying exception context attached.

    create_token_counter()

    Visibility: Public Signature: def create_token_counter() -> Callable[[str], int]:

    Description: Constructs a token-counting closure using tiktoken's cl100k_base encoding, falling back to a character heuristic (len(text) // 4) if initialization fails.

    Parameters: * None.

    Returns: * Callable[[str], int]: A callable that accepts a string and returns an estimated token count.

    Raises: * None.

    Example: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    This factory function provides a fallback mechanism for token counting across nodes. It configures tiktoken with disallowed_special=() to ensure arbitrary code inputs containing special tokens (such as <|endoftext|>) are encoded as literal strings without throwing exceptions. If tiktoken fails or is unavailable, the function falls back to a standard 4-character-per-token heuristic.

    resolve_max_tokens()

    Visibility: Public Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Determines the maximum context token limit by inspecting the shared state or querying provider environment variables via utils.call_llm.

    Parameters: * shared (dict): The shared execution state dictionary.

    Returns: * int: Maximum context window length in tokens.

    Raises: * None.

    Example: 

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    resolve_max_tokens establishes the token boundary for context routing. It first checks for an explicit max_tokens override in shared. If omitted, it identifies the configured provider (GEMINI, OPENAI, ANTHROPIC, etc.) and retrieves the default context window through get_model_context_length(), ensuring prompts do not exceed upstream model limits.

    Class: FetchRepo

    Inherits from: pocketflow.Node

    FetchRepo is the ingestion node responsible for collecting files from a remote GitHub repository or local directory path.

    FetchRepo.prep()

    Visibility: Public Signature: def prep(self, shared: dict) -> dict:

    Description: Validates repository paths, derives missing project names, and aggregates file filtering parameters.

    Parameters: * shared (dict): Shared state containing repo_url, local_dir, project_name, include_patterns, exclude_patterns, max_file_size, and optional github_token.

    Returns: * dict: Prepared parameter dictionary for file crawling execution.

    Raises: * None.

    Example: 

    def prep(self, shared):
    repo_url = shared.get("repo_url")
    local_dir = shared.get("local_dir")
    project_name = shared.get("project_name")

    if not project_name:
        # Basic name derivation from URL or directory
        if repo_url:
            project_name = repo_url.split("/")[-1].replace(".git", "")
        else:
            project_name = os.path.basename(os.path.abspath(local_dir))
        shared["project_name"] = project_name

    # Get file patterns directly from shared
    include_patterns = shared["include_patterns"]
    exclude_patterns = shared["exclude_patterns"]
    max_file_size = shared["max_file_size"]

    return {
        "repo_url": repo_url,
        "local_dir": local_dir,
        "token": shared.get("github_token"),
        "include_patterns": include_patterns,
        "exclude_patterns": exclude_patterns,
        "max_file_size": max_file_size,
        "use_relative_paths": True,
    }

    prep resolves repository parameters prior to execution. If project_name is missing from shared, it derives one from the Git remote URL or directory path and updates shared["project_name"]. It gathers path inclusion/exclusion patterns and file size thresholds to configure the crawler.

    FetchRepo.exec()

    Visibility: Public Signature: def exec(self, prep_res: dict) -> list[tuple[str, str]]:

    Description: Executes file crawling against GitHub via utils.crawl_github_files or local directories via utils.crawl_local_files.

    Parameters: * prep_res (dict): Crawler parameters produced by prep().

    Returns: * list[tuple[str, str]]: List of (relative_path, file_content) tuples.

    Raises: * ValueError: If no files match the inclusion/exclusion filters.

    Example: 

    def exec(self, prep_res):
    source = prep_res["repo_url"] or prep_res["local_dir"]
    llm_logger.info(f"NODE EXEC | node=FetchRepo | action=crawl_files | source={source}")

    if prep_res["repo_url"]:
        print(f"Crawling repository: {prep_res['repo_url']}...")
        result = crawl_github_files(
            repo_url=prep_res["repo_url"],
            token=prep_res["token"],
            include_patterns=prep_res["include_patterns"],
            exclude_patterns=prep_res["exclude_patterns"],
            max_file_size=prep_res["max_file_size"],
            use_relative_paths=prep_res["use_relative_paths"],
        )
    else:
        print(f"Crawling directory: {prep_res['local_dir']}...")

        result = crawl_local_files(
            directory=prep_res["local_dir"],
            include_patterns=prep_res["include_patterns"],
            exclude_patterns=prep_res["exclude_patterns"],
            max_file_size=prep_res["max_file_size"],
            use_relative_paths=prep_res["use_relative_paths"],
        )

    # Convert dict to list of tuples: [(path, content), ...]
    files_list = list(result.get("files", {}).items())
    if len(files_list) == 0:
        raise ValueError("No matching files found. Check your directory and include/exclude patterns.")

    llm_logger.info(f"NODE COMPLETE | node=FetchRepo | files_found={len(files_list)}")
    return files_list

    exec calls the appropriate crawler based on whether a remote repository URL or local directory path was provided. It transforms the crawler's dictionary output into an ordered list of (path, content) tuples. If no files match the criteria, it raises a ValueError to halt the pipeline before LLM operations begin.

    Class: ContextRouter

    Inherits from: pocketflow.Node

    ContextRouter analyzes total repository token size, directory depth, and prompt overhead to route processing to the appropriate pipeline branch: direct, batch (map-reduce), or deterministic.

    ContextRouter._build_directory_tree()

    Visibility: Protected (Static) Signature: def _build_directory_tree(files_data: list[tuple[str, str]]) -> str:

    Description: Builds a compact textual representation of the project's directory hierarchy annotated with file indices.

    Parameters: * files_data (list[tuple[str, str]]): List of (path, content) tuples.

    Returns: * str: Formatted directory tree string.

    Raises: * None.

    Example: 

    @staticmethod
def _build_directory_tree(files_data):
    """Build a compact directory tree string from the list of (path, content) tuples."""
    from collections import defaultdict

    dir_files = defaultdict(list)
    for i, (path, _content) in enumerate(files_data):
        dirname = os.path.dirname(path) or "."
        basename = os.path.basename(path)
        dir_files[dirname].append(f"{basename} (idx:{i})")

    lines = []
    for dirname in sorted(dir_files.keys()):
        lines.append(f"{dirname}/")
        lines.extend(f"  {fname}" for fname in sorted(dir_files[dirname]))
    return "\n".join(lines)

    This method groups files by their parent directory and formats them into a deterministic directory tree listing. Each entry includes the file's index (e.g., nodes.py (idx:1)), providing the LLM with structural context and stable index references during abstraction identification.

    ContextRouter.prep()

    Visibility: Public Signature: def prep(self, shared: dict) -> tuple:

    Description: Evaluates file token footprints against the effective context window (model capacity minus prompt templates and directory trees) to select an execution route.

    Parameters: * shared (dict): Shared state dictionary.

    Returns: * tuple: Execution parameters including route name ("direct", "batch", or "deterministic"), file data, token limits, and directory trees.

    Raises: * None.

    Example: 

    def prep(self, shared):
    files_data = shared["files"]
    max_tokens = resolve_max_tokens(shared)

    shared["max_tokens"] = max_tokens

    # --- Token estimation setup ---
    count_tokens = create_token_counter()

    // ... [Template token measurement and directory tree formatting] ...

    # --- Count file content tokens ---
    total_tokens = 0
    file_token_map = []
    for i, (path, content) in enumerate(files_data):
        entry = f"--- File Index {i}: {path} ---\n{content}\n\n"
        tokens = count_tokens(entry)
        total_tokens += tokens
        file_token_map.append(tokens)

    # --- Effective limit = safety margin minus overhead ---
    safety_limit = int(max_tokens * 0.95)
    effective_limit = safety_limit - prompt_overhead
    force_batch = shared.get("force_batch", False)

    if shared.get("mode", "tutorial") == "api-reference":
        print("\033[92m[Capacity] api-reference mode active. Bypassing LLM discovery and routing to DeterministicFileMapper.\033[0m")
        return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

    if total_tokens > effective_limit and force_batch:
        // ... [Log and route to batch] ...
    elif total_tokens > effective_limit:
        // ... [Log and route to batch] ...
    elif force_batch:
        // ... [Log and route to batch] ...
    else:
        return ("direct", files_data, effective_limit, shared.get("batch_size", 50), None, None, directory_tree, False)

    return (
        "batch",
        files_data,
        effective_limit,
        shared.get("batch_size", 50),
        file_token_map,
        count_tokens,
        directory_tree,
        shared.get("debug", False),
    )

    prep calculates the prompt overhead by measuring template sizes, the generated directory tree, and the file listing. It subtracts this overhead from a 95% safety margin of the context limit to establish an effective_limit. If the documentation mode is api-reference, it routes directly to deterministic. Otherwise, it routes to batch if content exceeds the limit (or if --force-batch is set), and direct if all files fit into a single prompt.

    ContextRouter.exec()

    Visibility: Public Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]:

    Description: Partitions files into directory-isolated, token-aware batches if batch routing was selected.

    Parameters: * prep_res (tuple): Unpacked configuration and token metrics from prep().

    Returns: * str: Route identifier if "direct" or "deterministic". * list[list[tuple[int, str, str]]]: Nested list of batches containing (index, path, content) tuples if "batch".

    Raises: * None.

    Example: 

    def exec(self, prep_res):
    route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
    llm_logger.info(
        f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}"
    )

    if route == "direct":
        return "direct"
    if route == "deterministic":
        return "deterministic"

    # Group by directory for coherence, with pre-computed tokens
    dir_groups = defaultdict(list)
    for i, (path, content) in enumerate(files_data):
        dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

    # Build token-aware batches (never mix directories)
    batches = []
    for dirname in sorted(dir_groups.keys()):
        current_batch = []
        current_tokens = 0

        for i, path, content, tokens in dir_groups[dirname]:
            # Start new batch if adding this file would exceed effective limit or file count cap
            if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                batches.append(current_batch)
                current_batch = []
                current_tokens = 0

            current_batch.append((i, path, content))
            current_tokens += tokens

        # Flush remaining files in this directory
        if current_batch:
            batches.append(current_batch)

    self._directory_tree = directory_tree
    return batches

    For batch routing, exec groups files by directory so related modules remain together in the same prompt context. It creates batches that respect both the file count ceiling (batch_size) and the calculated effective_limit token budget. Files from different directories are not mixed within a batch, maintaining context isolation.

    ContextRouter.post()

    Visibility: Public Signature: def post(self, shared: dict, prep_res: tuple, exec_res: Any) -> str:

    Description: Saves file batches and directory trees to shared memory and returns the chosen routing action.

    Parameters: * shared (dict): Shared state dictionary. * prep_res (tuple): Intermediate state from prep(). * exec_res (Any): Return value from exec().

    Returns: * str: Route action ("direct", "deterministic", or "batch").

    Raises: * None.

    Example: 

    def post(self, shared, prep_res, exec_res):
    if exec_res == "direct":
        return "direct"
    if exec_res == "deterministic":
        return "deterministic"
    shared["file_batches"] = exec_res
    # Reuse directory tree built during prep()
    shared["directory_tree"] = getattr(self, "_directory_tree", self._build_directory_tree(shared["files"]))

    post forwards "direct" or "deterministic" return values directly to the PocketFlow flow engine. For "batch", it stores the generated batches in shared["file_batches"] and saves the directory tree structure to shared["directory_tree"] before returning "batch" to trigger batch processing.

    Class: DeterministicFileMapper

    Inherits from: pocketflow.Node

    DeterministicFileMapper performs code file filtering for API reference documentation, mapping code files to distinct modules without LLM abstraction discovery.

    DeterministicFileMapper.prep()

    Visibility: Public Signature: def prep(self, shared: dict) -> tuple[str, str | None, int]:

    Description: Constructs a file filtering prompt via utils.prompts to identify executable code files and filter out non-code assets.

    Parameters: * shared (dict): Shared execution store.

    Returns: * tuple[str, str | None, int]: Tuple containing (prompt, thinking_level, max_tokens).

    Raises: * None.

    Example: 

    def prep(self, shared):
    files_data = shared["files"]
    project_name = shared["project_name"]

    file_listing = "\n".join([f"{i} # {path}" for i, (path, _) in enumerate(files_data)])

    prompt = build_code_file_filter_prompt(project_name, file_listing)
    return prompt, shared.get("thinking_level", None), shared.get("max_tokens", 100000)

    prep formats the file index list into a code-file filter prompt using build_code_file_filter_prompt(). This prepares the LLM to inspect file paths and extensions and return the indices of files that contain source code.

    DeterministicFileMapper.exec()

    Visibility: Public Signature: def exec(self, prep_res: tuple[str, str | None, int]) -> list[int]:

    Description: Calls the LLM to filter the file list and parses the resulting YAML response into a list of valid file indices.

    Parameters: * prep_res (tuple): Prompt, thinking level, and token limits from prep().

    Returns: * list[int]: Integer indices of valid source code files.

    Raises: * Exception: Rethrows any LLM or YAML parsing errors to trigger PocketFlow node retry mechanisms.

    Example: 

    def exec(self, prep_res):
    try:
        prompt, thinking_level, max_tokens = prep_res
        log_token_estimation(self.__class__.__name__, prompt, max_tokens)
        print("Smartly filtering non-code files using LLM...")
        response = call_llm(prompt, use_cache=True, thinking_level=thinking_level)
        valid_indices = parse_yaml_response(response)
        if not isinstance(valid_indices, list):
            valid_indices = []
        return [int(idx) for idx in valid_indices]
    except Exception as e:
        print(f"\033[93m[Node {self.__class__.__name__} Retry Triggered] Error: {e}\033[0m")
        llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
        raise e

    exec sends the filter prompt to the LLM via call_llm() with caching enabled. It parses the returned YAML array of indices using parse_yaml_response(), verifies the output is a valid list of integers, logs errors via llm_logger, and raises exceptions on failure to allow the PocketFlow framework to retry.

    DeterministicFileMapper.post()

    Visibility: Public Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list[int]) -> str:

    Description: Maps validated code files directly into individual abstraction definitions and writes them to shared state.

    Parameters: * shared (dict): Shared execution store. * prep_res (tuple): Execution configuration. * exec_res (list[int]): List of valid file indices.

    Returns: * str: Routing action "default".

    Raises: * None.

    Example: 

    def post(self, shared, prep_res, exec_res):
    import os

    files = shared.get("files", [])
    valid_indices = set(exec_res)
    modules = []
    chapter_order = []

    for idx, (file_path, _content) in enumerate(files):
        if idx not in valid_indices:
            print(f"  - Skipping non-code file: {file_path}")
            continue

        clean_name = os.path.splitext(file_path)[0].replace(os.sep, ".").replace("/", ".")

        modules.append(
            {"name": clean_name, "description": f"Internal API reference for `{file_path}`", "files": [idx], "original_path": file_path}
        )
        chapter_order.append(len(modules) - 1)

    shared["abstractions"] = modules
    shared["chapter_order"] = chapter_order
    shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
    print(f"\033[92m[DeterministicFileMapper] Mapped {len(modules)} ACTUAL code files for exhaustive documentation.\033[0m")
    return "default"

It builds a linear chapter_order, creates a stub relationships object, and writes these to shared["abstractions"] and shared["chapter_order"].     def post(self, shared, prep_res, exec_res_list):
    import json
    import os

    # exec_res_list contains dicts with content and hashes
    shared["chapters"] = [res["content"] for res in exec_res_list]

    # Save MD5 incremental manifest if enabled
    if shared.get("incremental"):
        output_dir = os.path.join(shared.get("output_dir", "output"), shared.get("project_name"))
        os.makedirs(output_dir, exist_ok=True)
        manifest_path = os.path.join(output_dir, ".doc_cache_manifest.json")

        manifest = {}
        if os.path.exists(manifest_path):
            try:
                with open(manifest_path, encoding="utf-8") as f:
                    manifest = json.load(f)
            except Exception:
                pass

        for res in exec_res_list:
            if res.get("hash") and res.get("name"):
                manifest[res["name"]] = res["hash"]

        with open(manifest_path, "w", encoding="utf-8") as f:
            json.dump(manifest, f, indent=2)

    shared["chapter_summaries"] = list(self.chapter_summaries)

    del self.chapters_written_so_far
    del self.chapter_summaries
    print(f"Finished writing {len(exec_res_list)} chapters.")

    @staticmethod
def _build_index_sections(lines, sections, chapter_files, level=3):
    """Recursively build index.md sections with module tables."""
    heading = "#" * level
    for section in sections:
        lines.append(f"{heading} {section['name']}")
        lines.append("")
        if section.get("modules"):
            lines.append("| Module | Description |")
            lines.append("|--------|-------------|")
            for mod_name in section["modules"]:
                match = next((cf for cf in chapter_files if cf["module_name"] == mod_name), None)
                if match:
                    display = mod_name.split(".")[-1] if "." in mod_name else mod_name
                    # Use description, but if it's the generic mapper description, extract from content
                    desc = match["description"]
                    if desc.startswith("Internal API reference"):
                        content_lines = match["content"].strip().split("\n")
                        for cl in content_lines:
                            cs = cl.strip()
                            if cs and not cs.startswith(("---", "#", "```", "title:", "sidebar_position:")):
                                desc = cs[:120]
                                break
                    lines.append(f"| [{display}](api/{match['filename']}) | {desc} |")
            lines.append("")
        for child in section.get("children", []):
            CombineTutorial._build_index_sections(lines, [child], chapter_files, level + 1)
