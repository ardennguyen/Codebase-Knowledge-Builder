    nodes

    Source File: nodes.py

    Overview

    The nodes.py module serves as the primary execution engine for the Codebase-Knowledge-Builder pipeline. Built on the pocketflow framework using Node and BatchNode abstractions, this module defines all lifecycle stages responsible for ingesting codebase files, managing context windows, discovering architectural abstractions, analyzing inter-module relationships, ordering documentation sequences, drafting chapter contents, and assembling structured outputs (such as standalone Markdown tutorials or complete MkDocs documentation sites).

    The nodes coordinate data transformations across a shared memory dictionary (shared), implementing fallback routines, token estimation safeguards, caching layers, and LLM-driven structured extraction.

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list[tuple[str, str]], indices: list[int]) -> dict[str, str]:

    Description: Constructs a mapping of file index and path to file content for a specified list of file indices. This helper provides subset extraction of repository contents when preparing prompt payloads for specific abstraction groups.

    Parameters: * files_data (list[tuple[str, str]]): List of tuples containing (file_path, file_content). * indices (list[int]): List of integer indices to extract.

    Returns: * dict[str, str]: Dictionary where keys are formatted as "{index} # {path}" and values are the corresponding string contents.

    Raises: * None. Out-of-bounds indices are ignored via boundary validation.

    Example: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]

    return content_map

    get_content_for_indices() extracts targeted code context from the global repository file cache. By validating that index i satisfies 0 <= i < len(files_data), the function prevents index out-of-range errors during partial context injection. The resulting dictionary key structure "{index} # {path}" preserves indexing metadata within Markdown code fences for LLM consumption.

    Visibility: Public
    Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str | None = None) -> str:

    Description: Loads a Markdown prompt template from the local prompts/ subdirectories. It resolves directory routing based on explicit execution modes (tutorial, advanced, api-reference, etc.) or legacy boolean flags.

    Parameters: * template_name (str): Base name of the prompt Markdown template file (without .md). * advanced_mode (bool, optional): Legacy flag selecting "advanced" vs "tutorial". Defaults to False. * mode (str | None, optional): Explicit subdirectory mode name. Defaults to None.

    def load_prompt_template(template_name, advanced_mode=False, mode=None):

    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> Callable[[str], int]:

    Description: Instantiates a token counting function using tiktoken's cl100k_base encoding. If tiktoken fails or encounters initialization errors, it provides a character-length fallback heuristic (len(text) // 4).

    Parameters: * None.

    Returns: * Callable[[str], int]: A callable function that accepts a string and returns the estimated token count.

    Raises: * None.

    Example: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    create_token_counter() provides robust token estimation across varying runtime environments. By passing disallowed_special=() to the tokenizer, special tokens (such as prompt formatting tags) do not trigger encoding exceptions during estimation. When native tokenization libraries are unavailable or raise exceptions, the fallback heuristic ensures continuous execution.

    Description: Determines the maximum context token window for the active LLM provider. It inspects the shared state dictionary first, falling back to dynamic context length lookup via utils.call_llm using environment variables.

    Parameters: * shared (dict): Shared execution context containing pipeline configuration.

    Returns: * int: Maximum context window capacity in tokens.

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")

        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")

    resolve_max_tokens() resolves context constraints across multiple supported LLM providers. If max_tokens is not explicitly set in shared, it inspects LLM_PROVIDER environment flags to select the appropriate endpoint and model configuration, querying get_model_context_length() to dynamically adapt token budget constraints.

    Class DeterministicFileMapper

    Inherits from: pocketflow.Node

    DeterministicFileMapper handles 1:1 file-to-module mapping in api-reference mode. Instead of clustering files into conceptual abstractions, it uses an LLM filter to exclude non-code artifacts and directly maps each source file to an independent documentation unit.

    Visibility: Public

    Description: Formats the file list and constructs the code file filtering prompt using utils.prompts.

    Parameters: * shared (dict): Pipeline shared state containing files, project_name, thinking_level, and max_tokens.

    Returns: * tuple[str, int | None, int]: A tuple containing (prompt, thinking_level, max_tokens).

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        project_name = shared["project_name"]

        file_listing = "\n".join([f"{i} # {path}" for i, (path, _) in enumerate(files_data)])

        return prompt, shared.get("thinking_level", None), shared.get("max_tokens", 100000)

    DeterministicFileMapper.prep() aggregates file index metadata across all ingested files into an enumerated listing ({i} # {path}). It feeds this listing into build_code_file_filter_prompt() to ask the LLM to identify which indices represent actual program code versus auxiliary data files.

    Description: Converts validated file indices into individual module records and populates the shared dictionary with synthetic abstraction definitions and linear chapter ordering.

        modules = []

For each valid code file, it computes a normalized dotted module name (e.g., utils/call_llm.py becomes utils.call_llm), initializes an individual abstraction dictionary, and appends a sequential index into chapter_order.

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Measures token sizes across all prompt components (templates, directory trees, file listings, and source file content), calculates safety margins, and determines the execution route.

    Parameters: * shared (dict): Shared pipeline state.

    Returns: * tuple: Route configuration tuple containing routing keys, file records, limits, batch sizing parameters, and directory tree structures.

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)

        shared["max_tokens"] = max_tokens

        # --- Token estimation setup ---
        count_tokens = create_token_counter()

        # --- Calculate prompt overhead FIRST ---
        # 1. Prompt template (measure both, use the larger)
        prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
        max_template_tokens = 0
        for subdir in ["tutorial", "advanced"]:
            template_path = os.path.join(prompt_dir, subdir, "map_abstractions.md")
            if os.path.exists(template_path):
                with open(template_path, encoding="utf-8-sig") as f:
                    t = count_tokens(f.read())
                max_template_tokens = max(max_template_tokens, t)

        # 2. Directory tree (built from all files, shared across batches)
        directory_tree = self._build_directory_tree(files_data)
        tree_tokens = count_tokens(directory_tree)

        # 3. File listing index (e.g. "- 0 # main.py\n- 1 # nodes.py\n...")
        file_listing_str = "\n".join(f"- {i} # {path}" for i, (path, _) in enumerate(files_data))
        listing_tokens = count_tokens(file_listing_str)

        prompt_overhead = max_template_tokens + tree_tokens + listing_tokens
        // ... Calculates file token counts and sets safety limit at 95% of max_tokens ...

    ContextRouter.prep() establishes token budgets before LLM invocation. It calculates total prompt overhead by measuring template tokens, tree structure tokens, and file listing index strings. The effective context limit is calculated by taking 95% of max_tokens and subtracting the prompt overhead. If the mode is "api-reference", it routes to "deterministic". If content exceeds effective_limit or force_batch is set, it selects "batch"; otherwise, it selects "direct".

    ContextRouter._build_directory_tree()

    Visibility: Private / Static
    Signature: def _build_directory_tree(files_data: list[tuple[str, str]]) -> str:

    Description: Constructs a compact text-based directory tree with annotated file indices from the list of ingested (path, content) tuples.

    Parameters: * files_data (list[tuple[str, str]]): List of file tuples.

    Returns: * str: Formatted multi-line string representing the directory tree hierarchy.

    Example: 

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict

        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            lines.extend(f"  {fname}" for fname in sorted(dir_files[dirname]))
        return "\n".join(lines)

    _build_directory_tree() organizes files by their parent directories. It formats each directory path followed by indented file listings containing base names and their corresponding index numbers (e.g., nodes.py (idx:1)).

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]:

    Description: Executes routing logic. For "direct" or "deterministic" paths, it returns the route identifier immediately. For "batch" routing, it partitions files into directory-aware, token-bounded batches.

    Parameters: * prep_res (tuple): Prepared execution tuple containing routing choices, file data, limits, batch size, and debug flags.

    Returns: * str | list[list[tuple[int, str, str]]]: Routing string ("direct" or "deterministic") or a list of file batches.

    Example: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
        llm_logger.info(
            f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}"
        )

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            # Flush remaining files in this directory
            if current_batch:
                batches.append(current_batch)
        // ... Logs batch counts and debug info ...
        return batches

    ContextRouter.exec() segments repositories that exceed context limits into isolated batches. It groups files by directory so related modules remain together during mapping. It iterates through each directory group, adding files to the active batch until adding another file would exceed effective_limit or batch_size. It then closes the batch and starts a new one, ensuring directories are never mixed across batch boundaries.

        def post(self, shared, prep_res, exec_res_list):
        import json
        import os

        # exec_res_list contains dicts with content and hashes

        # Save MD5 incremental manifest if enabled
        if shared.get("incremental"):
            output_dir = os.path.join(shared.get("output_dir", "output"), shared.get("project_name"))
            os.makedirs(output_dir, exist_ok=True)
            manifest_path = os.path.join(output_dir, ".doc_cache_manifest.json")

            manifest = {}
            if os.path.exists(manifest_path):
                try:
                    with open(manifest_path, encoding="utf-8") as f:
                        manifest = json.load(f)
                except Exception:
                    pass

                if res.get("hash") and res.get("name"):
                    manifest[res["name"]] = res["hash"]

        shared["chapter_summaries"] = list(self.chapter_summaries)

        # Clean up the temporary instance variables
        del self.chapters_written_so_far
        del self.chapter_summaries
        print(f"Finished writing {len(exec_res_list)} chapters.")
