    nodes

    Original File Path: nodes.py

    Technical Overview

    The nodes.py module defines the execution nodes that form the core transformation pipeline of Codebase-Knowledge-Builder. Built on top of the pocketflow framework (Node and BatchNode abstractions), these classes implement a map-reduce pipeline that ingests source repositories, filters non-code assets, identifies domain abstractions via Large Language Models (LLMs), discovers cross-module relationships, orders chapters logically, and synthesizes structured tutorials or API documentation (including MkDocs outputs).

    The lifecycle of each node follows PocketFlow's three-phase execution model: 1. prep(shared): Extracts and formats necessary inputs from the shared state dictionary into immutable argument bundles. 2. exec(prep_res) / exec(item): Performs isolated computation, file parsing, token estimation, and LLM inference. 3. post(shared, prep_res, exec_res): Validates results, transforms data, updates the shared memory dictionary, and returns the next execution action/route.

    Module-Level Functions

    get_content_for_indices()

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list, indices: list) -> dict:

    Description: Extracts file contents from a master list of (path, content) tuples for a specific subset of numerical indices. Keys in the returned dictionary are formatted as "{index} # {path}" to provide LLM context identifying the file's index and path simultaneously.

    Parameters: * files_data (list): List of tuples where each element is (path, content). * indices (list): Collection of integer indices indicating which files to extract.

    Returns: * dict: Mapping of formatted index-path strings to file contents.

    Raises: * None. Out-of-bounds indices are ignored via boundary checks (0 <= i < len(files_data)).

    Example: 

    # Implementation from nodes.py
def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = (
                content  # Use index + path as key for context
            )
    return content_map

    The function iterates over the requested index list and safely resolves each entry against the files_data collection. By using {i} # {path} as dictionary keys, downstream nodes can construct prompt payloads where the language model retains visibility into both the positional offset and directory path of each relevant file.

    load_prompt_template()

    Visibility: Public
    Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str = None) -> str:

    Description: Loads a prompt Markdown template from the disk under the prompts/ directory relative to the current file. It resolves the directory by prioritizing explicit mode overrides (mode), falling back to "advanced" if advanced_mode is enabled, or defaulting to "tutorial".

    Parameters: * template_name (str): Base name of the template file (without .md). * advanced_mode (bool, optional): Flag indicating whether to use advanced prompts when mode is unspecified. Defaults to False. * mode (str, optional): Specific subfolder name under prompts/ (e.g., "tutorial", "advanced", "api-reference"). Defaults to None.

    Returns: * str: Raw template contents read using utf-8-sig encoding.

    Raises: * FileNotFoundError: If the constructed template path does not exist on disk. * IOError: If read operations fail.

    Example: 

    # Implementation from nodes.py
def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                        "prompts", prompt_dir, f"{template_name}.md")
    with open(path, "r", encoding="utf-8-sig") as f:
        return f.read()

    The function resolves relative paths by determining the absolute directory containing nodes.py via __file__. It applies utf-8-sig encoding to handle potential byte order marks (BOM) in custom prompt files gracefully, returning raw template strings ready for .format() interpolation.

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> object:

    Description: Extracts and parses a YAML block from an LLM response string. It identifies content wrapped in yaml ... code fences and deserializes it into Python native structures using PyYAML's yaml.safe_load.

    Parameters: * response (str): Raw LLM textual response expected to contain a fenced YAML block.

    Returns: * object: Parsed YAML structure (list, dict, etc.).

    Raises: * ValueError: If code fences are missing or if YAML parsing fails.

    Example: 

    # Implementation from nodes.py
def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}")

    This helper handles structured output extraction across all nodes communicating with the LLM. It splits on yaml` and delimiters, trims whitespace, and calls yaml.safe_load. If the LLM generates malformed YAML or fails to include code blocks, the helper raises a ValueError with descriptive debugging context.

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> callable:

    Description: Factory function returning a token counting callable. It attempts to load tiktoken with the cl100k_base encoding (used by modern OpenAI and compatible models). If tiktoken fails or is unavailable, it returns a fallback lambda calculating heuristic token length (len(text) // 4).

    Parameters: * None.

    Returns: * callable: A function accepting text: str and returning token count as int.

    Raises: * None. Catches internal exceptions during tokenizer initialization.

    Example: 

    # Implementation from nodes.py
def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    The token counter enables offline context sizing across routing and prompt generation stages. Disabling special tokens (disallowed_special=()) prevents exceptions when source code contains syntax resembling tokenizer control sequences.

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Determines the maximum token limit for the current execution run. If max_tokens is explicitly set in shared, that value is returned. Otherwise, it inspects environment variables (LLM_PROVIDER, GEMINI_MODEL, GEMINI_API_KEY, etc.) and calls get_model_context_length to query provider defaults dynamically.

    Parameters: * shared (dict): Shared pipeline state dictionary.

    Returns: * int: Resolved token limit for prompt budgets.

    Raises: * None. Falls back through provider-specific environment variables.

    Example: 

    # Implementation from nodes.py
def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    This helper standardizes context limit resolution across ContextRouter and IdentifyAbstractions. When explicit limits are absent, it infers configuration defaults from active provider credentials in utils.call_llm.

    Class: FetchRepo

    Visibility: Public
    Base Class: pocketflow.Node

    FetchRepo is responsible for ingesting files from either a remote GitHub repository or a local filesystem path. It normalizes paths, filters files using glob inclusion/exclusion patterns, and enforces maximum file size thresholds.

    FetchRepo.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> dict:

    Description: Reads target repository paths, tokens, file patterns, and size constraints from shared. If project_name is missing, it derives a name from the URL or folder name.

    Parameters: * shared (dict): Shared state dictionary containing crawling parameters.

    Returns: * dict: Parameter dictionary for exec().

    Example: 

    # Implementation from nodes.py
def prep(self, shared):
    repo_url = shared.get("repo_url")
    local_dir = shared.get("local_dir")
    project_name = shared.get("project_name")

    if not project_name:
        # Basic name derivation from URL or directory
        if repo_url:
            project_name = repo_url.split("/")[-1].replace(".git", "")
        else:
            project_name = os.path.basename(os.path.abspath(local_dir))
        shared["project_name"] = project_name

    # Get file patterns directly from shared
    include_patterns = shared["include_patterns"]
    exclude_patterns = shared["exclude_patterns"]
    max_file_size = shared["max_file_size"]

    return {
        "repo_url": repo_url,
        "local_dir": local_dir,
        "token": shared.get("github_token"),
        "include_patterns": include_patterns,
        "exclude_patterns": exclude_patterns,
        "max_file_size": max_file_size,
        "use_relative_paths": True,
    }

    The method parses the input target and sets default project naming metadata. It packages all pattern criteria needed by local or remote crawling routines into an isolated bundle for exec().

    FetchRepo.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: dict) -> list:

    Description: Executes crawling using crawl_github_files or crawl_local_files based on whether repo_url is populated. Converts the returned file map into a deterministic list of (path, content) tuples.

    Parameters: * prep_res (dict): Crawl configuration emitted by prep().

    Returns: * list: List of (str, str) tuples representing (relative_path, file_content).

    Raises: * ValueError: If no files match the inclusion/exclusion criteria.

    Example: 

    # Implementation from nodes.py
def exec(self, prep_res):
    source = prep_res["repo_url"] or prep_res["local_dir"]
    llm_logger.info(f"NODE EXEC | node=FetchRepo | action=crawl_files | source={source}")

    if prep_res["repo_url"]:
        print(f"Crawling repository: {prep_res['repo_url']}...")
        result = crawl_github_files(
            repo_url=prep_res["repo_url"],
            token=prep_res["token"],
            include_patterns=prep_res["include_patterns"],
            exclude_patterns=prep_res["exclude_patterns"],
            max_file_size=prep_res["max_file_size"],
            use_relative_paths=prep_res["use_relative_paths"],
        )
    else:
        print(f"Crawling directory: {prep_res['local_dir']}...")

        result = crawl_local_files(
            directory=prep_res["local_dir"],
            include_patterns=prep_res["include_patterns"],
            exclude_patterns=prep_res["exclude_patterns"],
            max_file_size=prep_res["max_file_size"],
            use_relative_paths=prep_res["use_relative_paths"]
        )

    # Convert dict to list of tuples: [(path, content), ...]
    files_list = list(result.get("files", {}).items())
    if len(files_list) == 0:
        raise ValueError("No matching files found. Check your directory and include/exclude patterns.")

    llm_logger.info(f"NODE COMPLETE | node=FetchRepo | files_found={len(files_list)}")
    return files_list

    The method routes between GitHub API crawling and local filesystem walking. It enforces validation to ensure downstream pipeline stages receive a non-empty list of source files.

    Class: ContextRouter

    Visibility: Public
    Base Class: pocketflow.Node

    ContextRouter analyzes total token requirements against model context limits to select an execution strategy: - "deterministic": Used when mode == "api-reference" to document every code file independently. - "direct": Used when all files fit comfortably within a single context window. - "batch": Partitions files into directory-isolated token batches for Map-Reduce processing.

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Computes total token volume for all files, calculates prompt template overhead, and determines the effective context limit with a 95% safety margin.

    Parameters: * shared (dict): Pipeline shared state.

    Returns: * tuple: Route decision ("deterministic", "direct", or "batch"), file data, effective token limits, batch sizing, token mapping, token counting function, directory tree string, and debug flags.

    Example: 

    # Implementation from nodes.py
def prep(self, shared):
    files_data = shared["files"]
    max_tokens = resolve_max_tokens(shared)

    shared["max_tokens"] = max_tokens

    # --- Token estimation setup ---
    count_tokens = create_token_counter()

    # --- Calculate prompt overhead FIRST ---
    prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
    max_template_tokens = 0
    for subdir in ["tutorial", "advanced"]:
        template_path = os.path.join(prompt_dir, subdir, "map_abstractions.md")
        if os.path.exists(template_path):
            with open(template_path, "r", encoding="utf-8-sig") as f:
                t = count_tokens(f.read())
            max_template_tokens = max(max_template_tokens, t)

    directory_tree = self._build_directory_tree(files_data)
    tree_tokens = count_tokens(directory_tree)

    prompt_overhead = max_template_tokens + tree_tokens
    # ...
    safety_limit = int(max_tokens * 0.95)
    effective_limit = safety_limit - prompt_overhead
    force_batch = shared.get("force_batch", False)

    if shared.get("mode", "tutorial") == "api-reference":
        return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50),
                None, None, directory_tree, False)

    if total_tokens > effective_limit or force_batch:
        return ("batch", files_data, effective_limit, shared.get("batch_size", 50),
                file_token_map, count_tokens, directory_tree, shared.get("debug", False))
    else:
        return ("direct", files_data, effective_limit, shared.get("batch_size", 50),
                None, None, directory_tree, False)

    The method measures prompt template sizes and directory tree overhead before calculating the effective limit (safety_limit - prompt_overhead). If total file tokens exceed this threshold, or if --force-batch is requested, it configures Map-Reduce batching.

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> Union[str, list]:

    Description: Constructs directory-coherent batches of files when the route is "batch". Files within the same directory are grouped together and chunked such that neither the token limit nor file count cap (batch_size) is exceeded.

    Parameters: * prep_res (tuple): Unpacked configuration from prep().

    Returns: * str: "direct" or "deterministic" if routed directly. * list: List of batches (where each batch is a list of (index, path, content) tuples).

    Example: 

    # Implementation from nodes.py
def exec(self, prep_res):
    route, files_data, effective_limit, batch_size, file_token_map, count_tokens, directory_tree, debug = prep_res
    llm_logger.info(f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}")

    if route == "direct":
        return "direct"
    if route == "deterministic":
        return "deterministic"

    dir_groups = defaultdict(list)
    for i, (path, content) in enumerate(files_data):
        dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

    batches = []
    for dirname in sorted(dir_groups.keys()):
        current_batch = []
        current_tokens = 0

        for i, path, content, tokens in dir_groups[dirname]:
            if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                batches.append(current_batch)
                current_batch = []
                current_tokens = 0

            current_batch.append((i, path, content))
            current_tokens += tokens

        if current_batch:
            batches.append(current_batch)

    self._directory_tree = directory_tree
    return batches

    The partitioning algorithm ensures batches never mix files across different directories, maintaining structural coherence during Map operations. When a directory's files exceed the token budget or batch count, it splits the directory across multiple contiguous batches.

    ContextRouter._build_directory_tree()

    Visibility: Protected (Static)
    Signature: def _build_directory_tree(files_data: list) -> str:

    Description: Generates an indented, human-readable directory hierarchy string displaying filenames alongside their numeric indices.

    Parameters: * files_data (list): List of (path, content) tuples.

    Returns: * str: Indented directory tree representation.

    Example: 

    # Implementation from nodes.py
@staticmethod
def _build_directory_tree(files_data):
    """Build a compact directory tree string from the list of (path, content) tuples."""
    from collections import defaultdict
    dir_files = defaultdict(list)
    for i, (path, _content) in enumerate(files_data):
        dirname = os.path.dirname(path) or "."
        basename = os.path.basename(path)
        dir_files[dirname].append(f"{basename} (idx:{i})")

    lines = []
    for dirname in sorted(dir_files.keys()):
        lines.append(f"{dirname}/")
        for fname in sorted(dir_files[dirname]):
            lines.append(f"  {fname}")
    return "\n".join(lines)

    This static helper builds a concise structural overview of the repository. Including the file index (idx:{i}) in tree leaves helps the LLM link structural hierarchies with file index references in prompt contexts.

    Class: DeterministicFileMapper

    Visibility: Public
    Base Class: pocketflow.Node

    DeterministicFileMapper handles documentation workflows where each source code file corresponds directly to a single standalone documentation page (api-reference mode). It queries an LLM filter prompt to remove non-code assets (e.g., lockfiles, raw configurations) and creates 1:1 module abstraction definitions.

    DeterministicFileMapper.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Formats the master file listing and builds a code-filtering prompt using build_code_file_filter_prompt.

    Parameters: * shared (dict): Pipeline shared state.

    Returns: * tuple: (prompt: str, thinking_level: object, max_tokens: int)

    Example: 

    # Implementation from nodes.py
def prep(self, shared):
    files_data = shared["files"]
    project_name = shared["project_name"]

    file_listing = "\n".join([f"{i} # {path}" for i, (path, _) in enumerate(files_data)])

    The method formats all crawled file paths with their respective indices and passes them to build_code_file_filter_prompt (from utils.prompts) to construct the classification query.

    DeterministicFileMapper.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> list:

    Description: Invokes the LLM to filter out non-code assets and parses the returned YAML list of valid code file indices.

    Parameters: * prep_res (tuple): (prompt, thinking_level, max_tokens)

    Returns: * list: List of valid integer file indices.

    Raises: * Exception: Rethrows any LLM invocation or parsing failures after logging.

    Example: 

    # Implementation from nodes.py
def exec(self, prep_res):
    try:
        prompt, thinking_level, max_tokens = prep_res
        log_token_estimation(self.__class__.__name__, prompt, max_tokens)
        print(f"Smartly filtering non-code files using LLM...")
        response = call_llm(prompt, use_cache=True, thinking_level=thinking_level)
        valid_indices = parse_yaml_response(response)
        if not isinstance(valid_indices, list):
            valid_indices = []
        return [int(idx) for idx in valid_indices]
    except Exception as e:
        print(f"\033[93m[Node {self.__class__.__name__} Retry Triggered] Error: {e}\033[0m")
        llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
        raise e

    This method calls call_llm with response caching enabled. It parses the resulting YAML response to extract an array of integer indices representing genuine source code files.

    DeterministicFileMapper.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list) -> str:

    Description: Maps each valid code file index into an abstraction dictionary with a 1:1 relationship, establishes linear chapter ordering, and populates baseline relationship structures in shared.

    Parameters: * shared (dict): Pipeline shared state. * prep_res (tuple): Prepared arguments from prep(). * exec_res (list): List of verified code indices.

    Returns: * str: "default"

    Example: 

    # Implementation from nodes.py
def post(self, shared, prep_res, exec_res):
    import os
    files = shared.get("files", [])
    valid_indices = set(exec_res)
    modules = []
    chapter_order = []

    for idx, (file_path, content) in enumerate(files):
        if idx not in valid_indices:
            print(f"  - Skipping non-code file: {file_path}")
            continue

        clean_name = os.path.splitext(file_path)[0].replace(os.sep, ".").replace("/", ".")

        modules.append({
            "name": clean_name,
            "description": f"Internal API reference for `{file_path}`",
            "files": [idx],
            "original_path": file_path
        })
        chapter_order.append(len(modules) - 1)

    shared["abstractions"] = modules
    shared["chapter_order"] = chapter_order
    shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
    print(f"\033[92m[DeterministicFileMapper] Mapped {len(modules)} ACTUAL code files for exhaustive documentation.\033[0m")
    return "default"

    AnalyzeRelationships.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Computes token budgets across abstractions using a two-pass allocation algorithm: - Pass 1: Allocates an equal share of the token budget to each abstraction and tracks unused headroom. - Pass 2: Redistributes unused budget from smaller abstractions to larger abstractions with remaining files.

    Parameters: * shared (dict): Pipeline shared state.

    Returns: * tuple: Context string with budget-allocated snippets, abstraction listings, abstraction count, project name, language, cache settings, thinking level, advanced mode, max tokens, and mode.

    Example: 

    # Implementation from nodes.py
def prep(self, shared):
    abstractions = shared["abstractions"]
    files_data = shared["files"]
    # ...
    # Two-pass allocation:
    # Pass 1: give each abstraction an equal share, track unused
    per_abstr_budget = total_budget // max(num_abstractions, 1)
    included_indices = set()
    abstr_results = []

    for i, sized in enumerate(abstr_file_data):
        budget = per_abstr_budget
        included_files = []
        remaining_files = []
        for idx, path, file_content, tokens in sized:
            if idx in included_indices:
                included_files.append((idx, path, None, 0))
                continue
            if tokens <= budget:
                included_files.append((idx, path, file_content, tokens))
                budget -= tokens
                included_indices.add(idx)
            else:
                remaining_files.append((idx, path, file_content, tokens))
        abstr_results.append((included_files, remaining_files, budget))

    # Pass 2: redistribute unused budget to abstractions with remaining files
    total_unused = sum(r[2] for r in abstr_results)
    if total_unused > 0:
        for i, (included_files, remaining_files, _unused) in enumerate(abstr_results):
            if not remaining_files or total_unused <= 0:
                continue
            still_remaining = []
            for idx, path, file_content, tokens in remaining_files:
                if idx in included_indices:
                    included_files.append((idx, path, None, 0))
                    continue
                if tokens <= total_unused:
                    included_files.append((idx, path, file_content, tokens))
                    total_unused -= tokens
                    included_indices.add(idx)
                else:
                    still_remaining.append((idx, path, file_content, tokens))
            abstr_results[i] = (included_files, still_remaining, 0)
    # ...

    The two-pass allocator prevents context window exhaustion while maximizing code visibility. Abstractions that do not fully consume their initial budget yield remaining tokens back to the pool, allowing complex abstractions to include additional source files.

            chapter_summary = call_llm(summary_prompt, use_cache=True, thinking_level=None)
            self.chapter_summaries.append(f"Chapter {chapter_num} — {abstraction_name.strip()}:\n{chapter_summary}")

        return {"content": chapter_content, "hash": current_hash, "name": abstraction_name}
    except Exception as e:
        llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
        raise e

    The method maintains cross-chapter coherence by passing rolling 3–5 sentence summaries instead of full chapter text, preventing context token limits from exploding across large documentation sets. It also supports incremental builds by comparing MD5 hashes of related file snippets against .doc_cache_manifest.json.

def post(self, shared, prep_res, exec_res_list):
    import os, json
    shared["chapters"] = [res["content"] for res in exec_res_list]

    # Save MD5 incremental manifest if enabled
    if shared.get("incremental"):
        output_dir = os.path.join(shared.get("output_dir", "output"), shared.get("project_name"))
        os.makedirs(output_dir, exist_ok=True)
        manifest_path = os.path.join(output_dir, ".doc_cache_manifest.json")

        manifest = {}
        if os.path.exists(manifest_path):
            try:
                with open(manifest_path, "r", encoding="utf-8") as f:
                    manifest = json.load(f)
            except Exception:
                pass

        for res in exec_res_list:
            if res.get("hash") and res.get("name"):
                manifest[res["name"]] = res["hash"]

        with open(manifest_path, "w", encoding="utf-8") as f:
            json.dump(manifest, f, indent=2)

    # Clean up temporary instance variables
    del self.chapters_written_so_far
    del self.chapter_summaries
