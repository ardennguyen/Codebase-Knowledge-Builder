    nodes

    File Path: nodes.py

    Overview

    The nodes module defines all atomic processing units and computational nodes used across the pocketflow DAG pipeline in Codebase-Knowledge-Builder. These nodes handle repository ingestion, token estimation, structural abstraction extraction, relationship synthesis, chapter generation, and file assembly.

    The module implements standard Node and BatchNode abstractions from the pocketflow framework, encapsulating standard three-stage execution workflows (prep, exec, and post) for both linear and map-reduce documentation strategies.

    Functions

    get_content_for_indices()

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list[tuple[str, str]], indices: list[int]) -> dict[str, str]:

    Description:
    Retrieves file contents for a specific subset of index pointers from a master files list. Formats output keys using a compound index-and-path format (e.g., "0 # src/core.py") to preserve identification context during LLM prompt construction.

    Parameters: * files_data (list[tuple[str, str]]): List of tuples containing (file_path, file_content). * indices (list[int]): List of integer indices to extract.

    Returns: * dict[str, str]: Mapping of index-path descriptor strings to raw file contents.

    Raises: * None (Silently bounds-checks indices).

    Example: 

    files = [("src/main.py", "print('hello')"), ("README.md", "# Readme")]
content_map = get_content_for_indices(files, [0])
# Returns: {"0 # src/main.py": "print('hello')"}

    load_prompt_template()

    Visibility: Public
    Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str | None = None) -> str:

    Description:
    Loads a prompt markdown template file from the prompts/ directory. It selects the subdirectory based on mode (e.g., "tutorial", "advanced", "api-reference") or defaults to inspecting the advanced_mode boolean flag if mode is None. The file is read using utf-8-sig encoding to handle BOM characters safely.

    Parameters: * template_name (str): Base filename of the template without extension. * advanced_mode (bool): Legacy boolean fallback indicating whether to load from prompts/advanced. Defaults to False. * mode (str | None): Documentation mode corresponding to a prompt subdirectory. Defaults to None.

    Returns: * str: Raw template contents read from disk.

    Raises: * FileNotFoundError: If the targeted prompt template file does not exist. * IOError: If an error occurs reading the template file.

    Example: 

    template = load_prompt_template("draft_chapters", mode="api-reference")

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> dict | list:

    Description:
    Parses structured YAML data generated by LLMs wrapped inside ```yaml code fences. Extracts the substring between the opening delimiter and closing delimiter and applies yaml.safe_load.

    Parameters: * response (str): Raw text response returned by the LLM.

    Returns: * dict | list: Parsed Python object (dictionary or list) from the YAML block.

    Raises: * ValueError: If code fences are missing, the response is malformed, or YAML parsing fails.

    Example: 

    llm_output = "Here is the result:\n```yaml\n- 0\n- 1\n```"
parsed = parse_yaml_response(llm_output)
# Returns: [0, 1]

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> callable:

    Description:
    Initializes and returns a callable token-counting function. Attempts to instantiate tiktoken.get_encoding("cl100k_base"). If tiktoken fails or is unavailable, falls back to an integer character-division heuristic (len(text) // 4).

    Parameters: * None

    Returns: * callable: A function (text: str) -> int that returns the estimated token count for any given string.

    Raises: * None

    Example: 

    counter = create_token_counter()
tokens = counter("Hello, world!")

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description:
    Resolves the maximum context token limit for the active LLM. If max_tokens is explicitly defined in the shared state, that value is returned. Otherwise, detects environment variables (LLM_PROVIDER, GEMINI_PROJECT_ID, GEMINI_API_KEY, or custom provider endpoints) and queries get_model_context_length from utils.call_llm.

    Parameters: * shared (dict): Shared state dictionary from the execution pipeline.

    Returns: * int: Maximum context length in tokens supported by the model configuration.

    Raises: * None

    Example: 

    max_tokens = resolve_max_tokens({"max_tokens": 128000})
