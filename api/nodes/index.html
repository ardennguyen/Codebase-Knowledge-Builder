    nodes

    nodes.py

    Technical reference and implementation specification for nodes.py. This module defines the core execution units—subclassed from pocketflow.Node and pocketflow.BatchNode—that orchestrate the codebase knowledge extraction, abstraction identification, architectural relationship mapping, chapter drafting, and documentation synthesis pipeline.

    Architectural Overview

    nodes.py contains the computational graph components for analyzing repositories (local directories or remote Git repositories) and synthesizing multi-chapter technical tutorials or API references. Each PocketFlow node implements a three-stage lifecycle contract: 1. prep(shared): Extracts, formats, and token-budgets the parameters and prompts required from the shared state store. 2. exec(prep_res): Executes side effects, I/O, crawls, or LLM invocations using caching, error tracing, and retry triggers. 3. post(shared, prep_res, exec_res): Validates, transforms, and mutates execution outputs back into the shared state store, determining subsequent graph flow transitions.

    Module-Level Functions

    get_content_for_indices()

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list, indices: list) -> dict:

    Description: Constructs an index-mapped dictionary containing file paths and source contents corresponding to a target list of positional indices from files_data. Each key is formatted as "{index} # {path}" to provide contextual metadata to LLM prompt renderers.

    Parameters: * files_data (list): List of tuples (path, content) representing repository files. * indices (list): Target zero-based integer indices to retrieve.

    Returns: * dict: Mapping of formatted key "{i} # {path}" to the raw string content of each matched file.

    Example: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = (
                content  # Use index + path as key for context
            )
    return content_map

    The function iterates over the supplied indices and validates bounding conditions against len(files_data). If an index is within valid range boundaries, the file content is mapped under the composite key string "{i} # {path}". This structured key pattern acts as a disambiguation mechanism for LLM prompts when referencing file numbers and paths simultaneously. Out-of-bounds indices are ignored.

    load_prompt_template()

    Visibility: Public
    Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str = None) -> str:

    Description: Resolves and loads Markdown-based prompt template files from the local filesystem under the prompts/ directory tree. It prioritizes direct mode arguments (e.g., api-reference, tutorial, advanced) before falling back to boolean advanced_mode checks.

    Parameters: * template_name (str): Base filename of the template (without .md extension). * advanced_mode (bool, optional): Legacy flag selecting between advanced and tutorial directories when mode is None. Defaults to False. * mode (str, optional): Specific subdirectory name inside prompts/. Defaults to None.

    Returns: * str: Raw template content read with utf-8-sig encoding.

    Raises: * FileNotFoundError: If the constructed prompt path does not exist on disk. * IOError: If reading the prompt file fails.

    Example: 

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                        "prompts", prompt_dir, f"{template_name}.md")
    with open(path, "r", encoding="utf-8-sig") as f:
        return f.read()

    The function computes the absolute directory path relative to nodes.py and opens the file with UTF-8 byte order mark handling (utf-8-sig). This ensures cross-platform compatibility when loading prompt assets created across different operating systems or editors.

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> object:

    Description: Extracts fenced YAML blocks from raw LLM text outputs delimited by ```yaml and ````, then safely parses them into Python data structures usingyaml.safe_load`.

    Parameters: * response (str): Raw LLM response string containing embedded YAML blocks.

    Returns: * object: Deserialized Python data structure (typically a list or dict).

    Raises: * ValueError: If markdown code block delimiters are missing or if yaml.safe_load fails to parse the string.

    Example: 

    def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}")

    This helper targets responses wrapped in standard markdown YAML blocks. It performs string segmentations using split("```yaml")[1].split("```")[0] to isolate the structural definition from any conversational text returned by the model.

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> callable:

    Description: Instantiates and returns a token estimation callable using tiktoken's cl100k_base encoding scheme, falling back to character-length heuristic division (len(text) // 4) if tiktoken initialization fails.

    Parameters: * None

    Returns: * callable: A function accepting a string text and returning an integer token count.

    Example: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    The returned closure disables special token validation (disallowed_special=()) to prevent exceptions when processing arbitrary raw source code containing token-like syntax. If tiktoken encounters missing model encodings or binary incompatibilities, it falls back to standard 4-characters-per-token heuristic estimation.

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Resolves the maximum model context token ceiling by checking the shared dictionary or querying provider environment variables to detect runtime model configurations via utils.call_llm.

    Parameters: * shared (dict): The global pipeline shared memory store.

    Returns: * int: Maximum context length supported for the active LLM provider/model configuration.

    Example: 

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    The function checks for an explicit max_tokens configuration in the shared state. If missing, it inspects LLM_PROVIDER, sets default Gemini parameters or resolves base URLs, model identifiers, and API keys for third-party providers, and queries get_model_context_length from utils.call_llm.

    FetchRepo.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> dict:

    Description: Extracts repository crawler settings from shared, automatically inferring the project name from the URL or directory base name if not explicitly provided.

    Parameters: * shared (dict): Pipeline shared store containing repository targets, file patterns, and size limits.

    Returns: * dict: Normalized parameter dictionary containing crawling filters, authorization tokens, and paths.

    Example: 

        def prep(self, shared):
        repo_url = shared.get("repo_url")
        local_dir = shared.get("local_dir")
        project_name = shared.get("project_name")

        if not project_name:
            # Basic name derivation from URL or directory
            if repo_url:
                project_name = repo_url.split("/")[-1].replace(".git", "")
            else:
                project_name = os.path.basename(os.path.abspath(local_dir))
            shared["project_name"] = project_name

        # Get file patterns directly from shared
        include_patterns = shared["include_patterns"]
        exclude_patterns = shared["exclude_patterns"]
        max_file_size = shared["max_file_size"]

        return {
            "repo_url": repo_url,
            "local_dir": local_dir,
            "token": shared.get("github_token"),
            "include_patterns": include_patterns,
            "exclude_patterns": exclude_patterns,
            "max_file_size": max_file_size,
            "use_relative_paths": True,
        }

    This method parses the target URL or path and derives a normalized project_name when one is not already stored in shared. It aggregates include/exclude filter patterns and maximum file size constraints, packaging them into an execution parameter map.

    FetchRepo.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: dict) -> list:

    Description: Executes repository crawling by calling utils.crawl_github_files for remote Git URLs or utils.crawl_local_files for local paths.

    Parameters: * prep_res (dict): Preprocessed parameters from FetchRepo.prep().

    Returns: * list: List of (path, content) tuples representing all crawled source files.

    Raises: * ValueError: If no matching files are discovered based on the configured patterns.

    Example: 

        def exec(self, prep_res):
        source = prep_res["repo_url"] or prep_res["local_dir"]
        llm_logger.info(f"NODE EXEC | node=FetchRepo | action=crawl_files | source={source}")

        if prep_res["repo_url"]:
            print(f"Crawling repository: {prep_res['repo_url']}...")
            result = crawl_github_files(
                repo_url=prep_res["repo_url"],
                token=prep_res["token"],
                include_patterns=prep_res["include_patterns"],
                exclude_patterns=prep_res["exclude_patterns"],
                max_file_size=prep_res["max_file_size"],
                use_relative_paths=prep_res["use_relative_paths"],
            )
        else:
            print(f"Crawling directory: {prep_res['local_dir']}...")

            result = crawl_local_files(
                directory=prep_res["local_dir"],
                include_patterns=prep_res["include_patterns"],
                exclude_patterns=prep_res["exclude_patterns"],
                max_file_size=prep_res["max_file_size"],
                use_relative_paths=prep_res["use_relative_paths"]
            )

        # Convert dict to list of tuples: [(path, content), ...]
        files_list = list(result.get("files", {}).items())
        if len(files_list) == 0:
            raise ValueError("No matching files found. Check your directory and include/exclude patterns.")

        llm_logger.info(f"NODE COMPLETE | node=FetchRepo | files_found={len(files_list)}")
        return files_list

    The method branches based on whether repo_url is defined. It invokes the corresponding crawl utility, normalizes the resulting dictionary mapping of file paths and file contents into a list of tuples, logs telemetry, and asserts that at least one file was found.

    ContextRouter

    Visibility: Public
    Base Class: pocketflow.Node

    Calculates token budgets, analyzes total codebase size, formats directory trees, and routes execution down one of three strategies: * deterministic: Dedicated 1:1 API reference generation. * direct: Single-pass LLM abstraction mapping when context fits safely within context limits. * batch: Map-reduce token-aware partitioning when codebase size exceeds single-context limits.

    ContextRouter._build_directory_tree()

    Visibility: Protected (Static)
    Signature: def _build_directory_tree(files_data: list) -> str:

    Description: Generates an indented, compact text representation of the codebase's directory structure, indexing every file with its positional index.

    Parameters: * files_data (list): List of (path, content) tuples.

    Returns: * str: Indented directory tree with format dirname/\n filename (idx:N).

    Example: 

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict
        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            for fname in sorted(dir_files[dirname]):
                lines.append(f"  {fname}")
        return "\n".join(lines)

    The method groups paths by parent directory name, sorts directory keys lexicographically, and renders a clean indented hierarchy. Attaching positional index markers (idx:N) to each filename allows the LLM to cross-reference entries in subsequent prompt contexts.

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Calculates prompt template overhead, estimates file token usage, measures tree size, applies safety margins (95% ceiling), and resolves the pipeline routing strategy (deterministic, direct, or batch).

    Parameters: * shared (dict): Pipeline shared store.

    Returns: * tuple: Contains routing directive, file data, computed token limits, batch sizes, token maps, token counting closures, directory trees, and debug flags.

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)

        shared["max_tokens"] = max_tokens

        # --- Token estimation setup ---
        count_tokens = create_token_counter()

        # --- Calculate prompt overhead FIRST ---
        # 1. Prompt template (measure both, use the larger)
        prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
        max_template_tokens = 0
        for subdir in ["tutorial", "advanced"]:
            template_path = os.path.join(prompt_dir, subdir, "map_abstractions.md")
            if os.path.exists(template_path):
                with open(template_path, "r", encoding="utf-8-sig") as f:
                    t = count_tokens(f.read())
                max_template_tokens = max(max_template_tokens, t)

        # 2. Directory tree (built from all files, shared across batches)
        directory_tree = self._build_directory_tree(files_data)
        tree_tokens = count_tokens(directory_tree)

        prompt_overhead = max_template_tokens + tree_tokens
        // ... (computes file_token_map, effective_limit = safety_limit - prompt_overhead)

        if shared.get("mode", "tutorial") == "api-reference":
            return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50),
                    None, None, directory_tree, False)

        if total_tokens > effective_limit or force_batch:
            return ("batch", files_data, effective_limit, shared.get("batch_size", 50),
                    file_token_map, count_tokens, directory_tree, shared.get("debug", False))
        else:
            return ("direct", files_data, effective_limit, shared.get("batch_size", 50),
                    None, None, directory_tree, False)

    prep() dynamically calculates overhead by tokenizing prompt templates and directory trees across modes. An effective token limit is calculated using (max_tokens * 0.95) - prompt_overhead. If total codebase tokens fit within this boundary, direct routing is selected; if exceeded (or if force_batch is set), batch map-reduce partitioning is triggered. If api-reference mode is set, it selects deterministic.

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list:

    Description: Performs token-aware batch grouping without mixing directory boundaries when in batch mode, or returns the passthrough route strings direct and deterministic.

    Parameters: * prep_res (tuple): The parameters resolved during prep().

    Returns: * str | list: The route name ("direct", "deterministic") or a list of file batches [[(idx, path, content), ...], ...].

    Example: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, count_tokens, directory_tree, debug = prep_res
        llm_logger.info(f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}")

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            # Flush remaining files in this directory
            if current_batch:
                batches.append(current_batch)

        self._directory_tree = directory_tree
        return batches

    When building batches, the algorithm enforces directory isolation—files in the same directory are kept together until either the cumulative token weight reaches effective_limit or file count reaches batch_size. It caches the directory tree on the instance attribute self._directory_tree for post-processing.

    ContextRouter.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: str | list) -> str:

    Description: Writes file_batches and directory_tree to shared if batched, and returns the routing transition key for the execution graph.

    Parameters: * shared (dict): Shared state store. * prep_res (tuple): Prepared execution tuple. * exec_res (str | list): Result from exec().

    Returns: * str: Graph routing action ("direct", "deterministic", or "batch").

    Example: 

        def post(self, shared, prep_res, exec_res):
        if exec_res == "direct":
            return "direct"
        if exec_res == "deterministic":
            return "deterministic"
        shared["file_batches"] = exec_res
        # Reuse directory tree built during prep()
        shared["directory_tree"] = getattr(self, "_directory_tree", self._build_directory_tree(shared["files"]))
        return "batch"

    DeterministicFileMapper

    Visibility: Public
    Base Class: pocketflow.Node

    Filters non-code files via an LLM classification prompt and performs a 1:1 mapping of source files to documentation chapters for exhaustive API documentation.

    DeterministicFileMapper.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Formats an indexed file inventory listing and builds a code filtering prompt via build_code_file_filter_prompt from utils.prompts.

    Parameters: * shared (dict): Pipeline shared store.

    Returns: * tuple: (prompt, thinking_level, max_tokens)

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        project_name = shared["project_name"]

        file_listing = "\n".join([f"{i} # {path}" for i, (path, _) in enumerate(files_data)])

        prompt = build_code_file_filter_prompt(project_name, file_listing)

    DeterministicFileMapper.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> list:

    Description: Invokes the LLM to identify valid code files from the listing, parses the returned YAML array of integer indices, and logs token usage estimates.

    Parameters: * prep_res (tuple): Formatted prompt, thinking level, and max token parameters.

    Returns: * list: List of integer file indices classified as valid source code files.

    Example: 

        def exec(self, prep_res):
        try:
            prompt, thinking_level, max_tokens = prep_res
            log_token_estimation(self.__class__.__name__, prompt, max_tokens)
            print(f"Smartly filtering non-code files using LLM...")
            response = call_llm(prompt, use_cache=True, thinking_level=thinking_level)
            valid_indices = parse_yaml_response(response)
            if not isinstance(valid_indices, list):
                valid_indices = []
            return [int(idx) for idx in valid_indices]
        except Exception as e:
            print(f"\033[93m[Node {self.__class__.__name__} Retry Triggered] Error: {e}\033[0m")
            llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
            raise e

    DeterministicFileMapper.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list) -> str:

    Description: Transforms every validated code file into an abstraction module with normalized dotted module names, setting abstractions, chapter_order, and synthetic relationships metadata directly in shared.

    Parameters: * shared (dict): Pipeline shared store. * prep_res (tuple): Prepared execution tuple. * exec_res (list): List of valid file indices.

    Returns: * str: "default" transition string.

    Example: 

        def post(self, shared, prep_res, exec_res):
        import os
        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, content) in enumerate(files):
            if idx not in valid_indices:
                print(f"  - Skipping non-code file: {file_path}")
                continue

            clean_name = os.path.splitext(file_path)[0].replace(os.sep, ".").replace("/", ".")

            modules.append({
                "name": clean_name,
                "description": f"Internal API reference for `{file_path}`",
                "files": [idx],
                "original_path": file_path
            })
            chapter_order.append(len(modules) - 1)

        shared["abstractions"] = modules
        shared["chapter_order"] = chapter_order

                    // ... (loads cached file directly if hash matches)

            previous_chapters_summary = "" if doc_mode == "api-reference" else "\n---\n".join(self.chapter_summaries)
            prompt_template = load_prompt_template("draft_chapters", mode=doc_mode)
            // ... (formats prompt and logs token diagnostics)
            chapter_content = call_llm(prompt, use_cache=(use_cache and self.cur_retry == 0), thinking_level=thinking_level)

            // ... (ensures correct '# Chapter N: ...' header)
            self.chapters_written_so_far.append(chapter_content)

            if doc_mode != "api-reference":
                summary_prompt = build_chapter_summary_prompt(chapter_num, abstraction_name, chapter_content, language)
                chapter_summary = call_llm(summary_prompt, use_cache=True, thinking_level=None)
                self.chapter_summaries.append(f"Chapter {chapter_num} — {abstraction_name.strip()}:\n{chapter_summary}")

            return {"content": chapter_content, "hash": current_hash, "name": abstraction_name}
        except Exception as e:
            llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
            raise e

    WriteChapters.exec() implements two key optimization techniques: 1. Incremental Caching: Computes an MD5 checksum of the input source files. If the hash matches the project's .doc_cache_manifest.json, the LLM call is bypassed and existing chapter files are reused. 2. Rolling Chapter Summarization: Instead of concatenating full chapter text into subsequent prompts (which leads to $O(n^2)$ token explosion), it generates a compact 3–5 sentence technical summary using build_chapter_summary_prompt from utils.prompts. This summary is appended to self.chapter_summaries for subsequent chapters.

    WriteChapters.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: list, exec_res_list: list) -> None:

    Description: Persists all generated chapter Markdown strings into shared["chapters"], updates .doc_cache_manifest.json on disk when incremental caching is active, and tears down temporary instance state variables.

    Parameters: * shared (dict): Shared pipeline state. * prep_res (list): List of prepared batch items. * exec_res_list (list): List of return dictionaries from exec().

    Example: 

        def post(self, shared, prep_res, exec_res_list):
        import os, json
        shared["chapters"] = [res["content"] for res in exec_res_list]

        # Save MD5 incremental manifest if enabled
        if shared.get("incremental"):
            output_dir = os.path.join(shared.get("output_dir", "output"), shared.get("project_name"))
            os.makedirs(output_dir, exist_ok=True)
            manifest_path = os.path.join(output_dir, ".doc_cache_manifest.json")

            manifest = {}
            if os.path.exists(manifest_path):
                try:
                    with open(manifest_path, "r", encoding="utf-8") as f:
                        manifest = json.load(f)
                except Exception:
                    pass

            for res in exec_res_list:
                if res.get("hash") and res.get("name"):
                    manifest[res["name"]] = res["hash"]

            with open(manifest_path, "w", encoding="utf-8") as f:
                json.dump(manifest, f, indent=2)

        # Clean up the temporary instance variables
        del self.chapters_written_so_far
        del self.chapter_summaries

    CombineTutorial.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: dict) -> str:

    Description: Writes all documentation files to disk. In standard mode, outputs index.md, individual numbered chapter files (NN_chapter_name.md), and an aggregated full_content.md with an anchor-linked Table of Contents. In MkDocs mode, builds mkdocs.yml, docs/index.md, docs/nav_snippet.yml, and docs/api/*.md.

    Parameters: * prep_res (dict): Output configurations prepared in prep().

    Returns: * str: Absolute path to the output directory.

    Raises: * IOError: If disk writes fail.

    Example: 

        def exec(self, prep_res):
        try:
            output_path = prep_res["output_path"]
            is_mkdocs = prep_res["is_mkdocs"]
            chapter_files = prep_res["chapter_files"]
            ui = prep_res["ui"]

            os.makedirs(output_path, exist_ok=True)
            if is_mkdocs:
                nav_snippet = prep_res["nav_snippet"]
                project_name = prep_res["project_name"]
                doc_mode = prep_res["doc_mode"]
                api_docs_path = os.path.join(output_path, "docs", "api")
                os.makedirs(api_docs_path, exist_ok=True)

                site_title = f"{project_name} — Documentation"
                mkdocs_config = build_mkdocs_config(site_title, nav_snippet)
                with open(os.path.join(output_path, "mkdocs.yml"), "w", encoding="utf-8") as f:
                    f.write(mkdocs_config)

                with open(os.path.join(output_path, "docs", "index.md"), "w", encoding="utf-8") as f:
                    f.write(f"# {site_title}\n\nGenerated documentation for **{project_name}**.\n")

                for chapter_info in chapter_files:
                    chapter_filepath = os.path.join(api_docs_path, chapter_info["filename"])
                    os.makedirs(os.path.dirname(chapter_filepath), exist_ok=True)
                    with open(chapter_filepath, "w", encoding="utf-8") as f:
                        f.write(chapter_info["content"])
            else:
                // ... (writes index.md and individual chapter files)
                toc_lines = [f"# {ui['toc']}\n"]
                full_content_lines = []
                for i, chapter_info in enumerate(chapter_files):
                    content = chapter_info["content"]
                    toc_lines.append(f"- [Chapter {i+1}](#chapter-{i+1})")
                    full_content_lines.append(f'<a id="chapter-{i+1}"></a>\n{content}\n---\n')

                full_content = "\n".join(toc_lines) + "\n\n" + "\n".join(full_content_lines)
                with open(os.path.join(output_path, "full_content.md"), "w", encoding="utf-8") as f:
                    f.write(full_content)

            return output_path
        except Exception as e:
            llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
            raise e
