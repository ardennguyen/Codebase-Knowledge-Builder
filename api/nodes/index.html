    nodes

    Original source file: nodes.py

    Technical documentation and internal engineering reference for nodes.py. This module defines the foundational pipeline processing units (subclasses of PocketFlow's Node and BatchNode) and supporting utilities that drive repository ingestion, token-budget context routing, code filtering, abstraction identification, relationship analysis, chapter ordering, drafting, and documentation synthesis within Codebase-Knowledge-Builder.

    Technical Overview

    nodes.py constitutes the computational core of the pipeline. It implements execution logic for:

    1. Repository & Directory Parsing: Ingesting code assets from local paths or remote GitHub repositories (FetchRepo).
    2. Context Routing & Token Budgeting: Calculating model context limits and dynamically switching between direct monolithic execution, map-reduce batching, and deterministic API indexing based on token availability (ContextRouter, DeterministicFileMapper).
    3. Abstraction & Architectural Mapping: Extracting structural components across the codebase via single-pass or map-reduce approaches (MapAbstractions, ReduceAbstractions, IdentifyAbstractions).
    4. Relationship Synthesis & Chapter Sequencing: Determining semantic relationships, system architecture graphs, and pedagogical chapter ordering (AnalyzeRelationships, OrderChapters).
    5. Chapter Content Generation & Caching: Drafting markdown documentation for each module with incremental MD5-based disk caching and rolling cross-chapter context summaries (WriteChapters).
    6. Artifact Assembly: Compiling final Markdown files, generating Mermaid system diagrams, configuring navigation, and emitting optional MkDocs Material structures (CombineTutorial).

    Node Execution & Branching Flow

    flowchart TD
    Start([Pipeline Start]) --> FetchRepo

    Module-Level Functions

    get_content_for_indices()

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list, indices: list) -> dict:

    Description: Extracts file contents from the master files_data collection for a given set of file indices. Keys are formatted as "{index} # {path}" to provide contextual metadata alongside the content payload when feeding prompt templates.

    Parameters: * files_data (list): List of tuples where each tuple contains (path, content). * indices (list): Target integer indices to extract.

    Returns: * dict: Map of formatted file keys ("{index} # {path}") to raw file contents.

    Raises: * None explicitly; out-of-bound indices are safely filtered via boundary checks (0 <= i < len(files_data)).

    Example: 

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = (
                content  # Use index + path as key for context
            )
    return content_map

    The function iterates over the target index list, verifying that every index exists within the bounds of files_data. If valid, it indexes the tuple and assigns the content string to a formatted key containing both index and file path. This structured key helps the LLM link file contents with reference index numbers across subsequent pipeline steps.

    load_prompt_template()

    Visibility: Public
    Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str = None) -> str:

    Description: Reads a prompt Markdown template from the prompts/ directory. It selects the subdirectory based on mode (e.g., "tutorial", "advanced", "api-reference", "sdk") or falls back to the boolean advanced_mode parameter.

    Parameters: * template_name (str): Base filename of the prompt template (without .md). * advanced_mode (bool): Legacy fallback switch (True selects "advanced", False selects "tutorial"). Default is False. * mode (str, optional): Specific prompt subdirectory name. Overrides advanced_mode if provided.

    Returns: * str: Raw text content of the Markdown prompt template.

    Raises: * FileNotFoundError: If the constructed path does not exist on disk. * OSError: If file reading fails.

    Example: 

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                        "prompts", prompt_dir, f"{template_name}.md")
    with open(path, "r", encoding="utf-8-sig") as f:
        return f.read()

    The function resolves the target file path relative to nodes.py. If mode is explicitly passed, it is used directly as the subdirectory name; otherwise, it resolves to "advanced" or "tutorial" based on advanced_mode. Files are opened with utf-8-sig encoding to handle potential byte-order marks gracefully.

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> dict | list:

    Description: Extracts and deserializes YAML structures embedded within LLM markdown responses enclosed inside ```yaml code fences.

    Parameters: * response (str): Raw string response returned by the LLM.

    Returns: * dict | list: Parsed Python data structure corresponding to the YAML content.

    Raises: * ValueError: If extraction or yaml.safe_load fails.

    Example: 

    def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}") from e

    This helper handles structured output parsing across all LLM-driven nodes. It isolates the text between the first ```yaml marker and its closing ``` boundary. If the markdown format is violated or the enclosed YAML contains syntax errors, it catches the exception and raises a descriptive ValueError.

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> callable:

    Description: Factory function returning a token counting callable. It initializes tiktoken with the cl100k_base encoding, falling back to a character estimation heuristic (len(text) // 4) if tiktoken fails or is unavailable.

    Parameters: * None.

    Returns: * callable: A function accepting a string and returning an integer token count.

    Raises: * None.

    Example: 

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    Under standard execution, the returned lambda uses tiktoken with disallowed_special=() so all tokens (including control sequences) are counted accurately without raising encoding errors. In constrained environments or if encoding initialization fails, the fallback lambda provides an estimate based on average token length.

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description: Determines the maximum context window token threshold. It checks the pipeline's shared dictionary first, and if unset, inspects environment variables (LLM_PROVIDER, endpoint, model, and API keys) to dynamically query the provider via get_model_context_length.

    Parameters: * shared (dict): Pipeline shared state dictionary.

    Returns: * int: Total context window size in tokens.

    Raises: * None (propagates exceptions raised by get_model_context_length if network or config resolution fails).

    Example: 

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    The resolver prioritizes explicit pipeline configuration from shared["max_tokens"]. If missing, it inspects LLM_PROVIDER environment variables, setting up the default Gemini endpoint or dynamically constructing the keys for alternate providers before querying get_model_context_length.

    Inherits from: pocketflow.Node

    Filters non-code files from the crawled repository and constructs a deterministic 1:1 documentation plan where each code file is documented as an independent module abstraction.

    Description: Reads file paths and project metadata from shared. Formats a file listing string and constructs the LLM prompt via build_code_file_filter_prompt.

    Parameters: * shared (dict): Shared pipeline state containing files, project_name, thinking_level, and max_tokens.

        def prep(self, shared):

    DeterministicFileMapper.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> list[int]:

    Description: Executes the LLM request to classify which file indices contain genuine source code. Parses the YAML response into an index list.

    Parameters: * prep_res (tuple): (prompt, thinking_level, max_tokens).

    Returns: * list[int]: List of integer indices corresponding to valid code files.

    Raises: * Exception: Re-raises errors encountered during logging, model calls, or YAML parsing to trigger PocketFlow node retries.

    Example: 

        def exec(self, prep_res):
        try:
            prompt, thinking_level, max_tokens = prep_res
            log_token_estimation(self.__class__.__name__, prompt, max_tokens)
            print("Smartly filtering non-code files using LLM...")
            response = call_llm(prompt, use_cache=True, thinking_level=thinking_level)
            valid_indices = parse_yaml_response(response)
            if not isinstance(valid_indices, list):
                valid_indices = []
            return [int(idx) for idx in valid_indices]
        except Exception as e:
            print(f"\033[93m[Node {self.__class__.__name__} Retry Triggered] Error: {e}\033[0m")
            llm_logger.error(f"[Node {self.__class__.__name__}] Error: {e}", exc_info=True)
            raise e

    exec records token usage estimates via log_token_estimation, calls call_llm with caching enabled, and decodes the result via parse_yaml_response. Any non-list output defaults to an empty list before casting valid entries to integers.

    DeterministicFileMapper.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: list[int]) -> str:

    Description: Generates the 1:1 abstraction catalog and sequential chapter order from the filtered file indices, updating shared state.

    Parameters: * shared (dict): Shared pipeline state. * prep_res (tuple): The parameters passed into exec. * exec_res (list[int]): List of valid file indices.

    Returns: * str: "default" routing action.

    Example: 

        def post(self, shared, prep_res, exec_res):
        import os
        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, content) in enumerate(files):
            if idx not in valid_indices:
                print(f"  - Skipping non-code file: {file_path}")
                continue

            clean_name = os.path.splitext(file_path)[0].replace(os.sep, ".").replace("/", ".")

            modules.append({
                "name": clean_name,
                "description": f"Internal API reference for `{file_path}`",
                "files": [idx],
                "original_path": file_path
            })
            chapter_order.append(len(modules) - 1)

        shared["abstractions"] = modules
        shared["chapter_order"] = chapter_order
        shared["relationships"] = {"summary": "Deterministic Internal API Reference.", "details": []}
        print(f"\033[92m[DeterministicFileMapper] Mapped {len(modules)} ACTUAL code files for exhaustive documentation.\033[0m")
        return "default"

    The method iterates over shared["files"], filtering out indices excluded by the LLM. For each retained file, it normalizes path separators into dot-notation module identifiers (e.g., utils.token_utils), assigns a 1:1 abstraction descriptor, and sets up linear indexing in shared["chapter_order"].

    ContextRouter

    Inherits from: pocketflow.Node

    Inspects total file token sizes, accounts for prompt template overhead, and routes pipeline execution to "deterministic", "direct", or "batch" mode.

    ContextRouter._build_directory_tree()

    Visibility: Protected (Static)
    Signature: def _build_directory_tree(files_data: list) -> str:

    Description: Assembles a directory tree representation showing all file names alongside their index numbers.

    Parameters: * files_data (list): List of (path, content) tuples.

    Returns: * str: Formatted directory tree string.

    Example: 

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict
        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            for fname in sorted(dir_files[dirname]):
                lines.append(f"  {fname}")
        return "\n".join(lines)

    This helper groups file paths by directory using defaultdict(list). It sorts directories and file names alphabetically, appending formatted lines with indentation to render a hierarchical representation of the codebase.

    ContextRouter.prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description: Calculates token overhead for templates and directory trees, measures file token consumption against a 95% model safety margin, and determines the routing strategy.

    Parameters: * shared (dict): Shared pipeline state.

    Returns: * tuple: Package containing the route choice ("deterministic", "direct", or "batch"), file collections, effective limits, batch size, token maps, token counting helper, directory tree, and debug flags.

    Example: 

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)
        shared["max_tokens"] = max_tokens

        count_tokens = create_token_counter()
        # ... prompt overhead calculation ...
        safety_limit = int(max_tokens * 0.95)
        effective_limit = safety_limit - prompt_overhead
        force_batch = shared.get("force_batch", False)

        if shared.get("mode", "tutorial") == "api-reference":
            return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50),
                    None, None, directory_tree, False)

        if total_tokens > effective_limit or force_batch:
            # ... log warnings ...
            return ("batch", files_data, effective_limit, shared.get("batch_size", 50),
                    file_token_map, count_tokens, directory_tree, shared.get("debug", False))
        else:
            return ("direct", files_data, effective_limit, shared.get("batch_size", 50),
                    None, None, directory_tree, False)

    prep evaluates the total token cost of all files plus prompt overhead against effective_limit (max_tokens * 0.95 - prompt_overhead). If mode equals "api-reference", it routes to "deterministic". Otherwise, if total tokens exceed effective_limit or force_batch is set, it selects "batch" mode; otherwise, it chooses "direct".

    ContextRouter.exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple]]:

    Description: If routed to "batch", partitions files into directory-coherent groups that fit within effective_limit and batch_size. For "direct" or "deterministic", it returns the route identifier as a pass-through string.

    Parameters: * prep_res (tuple): Output tuple from prep.

    Returns: * str | list[list[tuple]]: Route string ("direct" or "deterministic") or a list of file batches where each batch contains [(index, path, content), ...].

    Example: 

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, _count_tokens, directory_tree, debug = prep_res
        llm_logger.info(f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}")

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            if current_batch:
                batches.append(current_batch)

        self._directory_tree = directory_tree
        return batches

    When building batches, exec groups files by directory to maintain semantic coherence. It iterates through directory groups, appending files to current_batch until adding another file would exceed effective_limit or batch_size. It flushes remaining files into batches before moving to the next directory.

    ContextRouter.post()

    Visibility: Public
    Signature: def post(self, shared: dict, prep_res: tuple, exec_res: str | list) -> str:

    Description: Stores generated file batches and the directory tree in shared, returning the active route name for downstream PocketFlow flow branching.

    Parameters: * shared (dict): Shared pipeline state. * prep_res (tuple): Pre-execution parameters. * exec_res (str | list): Output from exec.

    Returns: * str: Route action string ("direct", "deterministic", or "batch").

        def post(self, shared, prep_res, exec_res):

    MapAbstractions.exec()

    Visibility: Public
    Signature: def exec(self, item: dict) -> list[dict]:

    Description: Renders the map_abstractions template for a single batch, queries the LLM, and parses/validates the returned abstraction dictionaries.

    Parameters: * item (dict): Batch configuration payload generated in prep.

    Returns: * list[dict]: Validated abstraction dictionaries containing name, description, and files (a list of file indices).

    Example: 

        def exec(self, item):
        batch_index = item["batch_index"]
        files = item["files"]
        # ... construct context and prompt ...
        response = call_llm(prompt, use_cache=(item["use_cache"] and self.cur_retry == 0), thinking_level=item["thinking_level"])

        abstractions = parse_yaml_response(response)

        validated_abstractions = []
        if isinstance(abstractions, list):
            for obj in abstractions:
                if isinstance(obj, dict) and "name" in obj and "description" in obj and "file_indices" in obj:
                    import re
                    validated_indices = []
                    for idx_entry in obj["file_indices"]:
                        nums = re.findall(r'\d+', str(idx_entry))
                        if nums:
                            validated_indices.append(int(nums[0]))
                    if validated_indices:
                        validated_abstractions.append({
                            "name": obj["name"],
                            "description": obj["description"],
                            "files": sorted(list(set(validated_indices)))
                        })
        return validated_abstractions

    The method builds a prompt containing the batch's file contents, directory tree, and localized language instructions. It invokes call_llm, parses the response with parse_yaml_response, extracts integer file indices using regular expressions, and filters out malformed abstractions.

    prep generates a Mermaid dependency diagram from relationships["details"]. It selects the appropriate UI string translations for the target language (supporting English, Vietnamese, Chinese, Japanese, Korean, French, Spanish, German, Portuguese, Russian, Thai, and Indonesian). For MkDocs sites, it builds navigation items with YAML frontmatter; for standalone mode, it constructs a main index.md linking to all chapters and full_content.md.

In standalone mode, it writes index.md, individual numbered chapter files, and the combined full_content.md with table-of-contents anchor tags.
