    nodes

    File Path: nodes.py

    Following the orchestration graph defined in flow and initialized via main, nodes.py contains the concrete implementation of all computational nodes and execution units in Codebase-Knowledge-Builder.

    Overview

    The nodes module defines all pipeline operations using the pocketflow framework (Node and BatchNode base classes). These nodes handle source repository discovery, context token calculation, batch slicing, high-level abstraction extraction, architectural relationship mapping, chapter sequence planning, draft authoring, incremental MD5 hashing, and final documentation synthesis.

    get_content_for_indices()

    Visibility: Public
    Signature: def get_content_for_indices(files_data: list[tuple[str, str]], indices: list[int]) -> dict[str, str]:

    Description:
    Extracts and formats file paths and contents from a list of (path, content) tuples according to a specified sequence of numeric indices. It validates index bounds to avoid IndexError exceptions and builds a dictionary where each key contains the composite identifier f"{i} # {path}" and the value corresponds to the raw file content.

    def get_content_for_indices(files_data, indices):
    content_map = {}
    for i in indices:
        if 0 <= i < len(files_data):
            path, content = files_data[i]
            content_map[f"{i} # {path}"] = (
                content  # Use index + path as key for context
            )
    return content_map

    This helper isolates contextual code snippets required when drafting chapters or analyzing relationships for a specific abstraction. By constructing keys with both index and file path, downstream LLM prompts retain explicit trace identifiers back to the project directory structure. Any index outside the valid range of files_data is safely ignored without halting execution.

    Parameters: * files_data (list[tuple[str, str]]): The master list of crawled repository files containing relative paths and file text. * indices (list[int]): List of integer indices corresponding to selected files in files_data.

    Returns: * dict[str, str]: Mapping of index-path descriptor strings to their respective file contents.

    Raises: * None directly raised.

    Example: 

    # Sourced from WriteChapters.prep()

related_files_content_map = get_content_for_indices(
    files_data, related_file_indices
)

    load_prompt_template()

    Visibility: Public
    Signature: def load_prompt_template(template_name: str, advanced_mode: bool = False, mode: str | None = None) -> str:

    Description:
    Locates and reads a Markdown prompt template from the prompts/ directory tree. It resolves the directory target using the provided mode string, falling back to legacy boolean flags (advanced vs. tutorial) when mode is None. The template file is loaded using UTF-8 with BOM signature handling (utf-8-sig).

    def load_prompt_template(template_name, advanced_mode=False, mode=None):
    """Load a prompt template file from the prompts/ directory."""
    if mode is None:
        prompt_dir = "advanced" if advanced_mode else "tutorial"
    else:
        prompt_dir = mode

    path = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                        "prompts", prompt_dir, f"{template_name}.md")
    with open(path, "r", encoding="utf-8-sig") as f:
        return f.read()

    This helper standardizes prompt retrieval across all nodes. It constructs absolute paths relative to nodes.py to ensure consistent template access regardless of the current working directory. The utf-8-sig encoding transparently strips byte-order marks that could otherwise corrupt formatted LLM instructions.

    Parameters: * template_name (str): Base filename of the prompt template (omitting the .md extension). * advanced_mode (bool): Legacy flag selecting "advanced" or "tutorial" subdirectories when mode is omitted. Default is False. * mode (str | None): Explicit directory subfolder under prompts/ (e.g., "tutorial", "advanced", "api-reference", "sdk"). Default is None.

    Returns: * str: Raw template text with placeholder formatting keys.

    Raises: * FileNotFoundError: If the requested template file does not exist in the resolved directory. * OSError: If the template file cannot be accessed or read.

    Example: 

    # Sourced from MapAbstractions.exec()
prompt_template = load_prompt_template("map_abstractions", mode=item.get("mode", "tutorial"))

    parse_yaml_response()

    Visibility: Public
    Signature: def parse_yaml_response(response: str) -> Any:

    Description:
    Parses YAML data structures enclosed in ```yaml markdown code fences returned by LLM responses. It extracts the raw string between opening and closing delimiters and invokes yaml.safe_load.

    def parse_yaml_response(response):
    """Extract and parse YAML from an LLM response fenced in ```yaml blocks."""
    try:
        yaml_str = response.strip().split("```yaml")[1].split("```")[0].strip()
        return yaml.safe_load(yaml_str)
    except Exception as e:
        raise ValueError(f"Failed to parse YAML: {e}")

    This function enforces structured extraction from LLM completions. It isolates the first YAML block enclosed within markdown backticks, strips leading and trailing whitespace, and executes a safe load. If markdown fences are missing or malformed, the resulting indexing or parser errors are caught and re-raised as a descriptive ValueError to trigger retry mechanisms in PocketFlow nodes.

    Parameters: * response (str): The raw text response received from an LLM invocation.

    Returns: * Any: The parsed Python data structure (typically a dict or list).

    Raises: * ValueError: Raised if ```yaml fences are absent or if the content cannot be decoded by yaml.safe_load.

    create_token_counter()

    Visibility: Public
    Signature: def create_token_counter() -> Callable[[str], int]:

    Description:
    Constructs a token counting function utilizing the cl100k_base encoding from tiktoken. If the tokenizer initialization encounters an environment or runtime failure, it gracefully falls back to a heuristic character-length estimator (len(text) // 4).

    def create_token_counter():
    """Create a token counting function using tiktoken with char-count fallback."""
    try:
        enc = tiktoken.get_encoding("cl100k_base")
        return lambda text: len(enc.encode(text, disallowed_special=()))
    except Exception:
        return lambda text: len(text) // 4

    This factory returns an anonymous callable configured to tokenize text while disabling special token handling (disallowed_special=()). This allows arbitrary code files containing special tokens (such as <|endoftext|>) to be evaluated without raising exceptions. In constrained execution environments where tiktoken byte-pair encodings are unavailable, the character integer division heuristic ensures uninterrupted batch and context calculation.

    Parameters: * None

    Returns: * Callable[[str], int]: A callable function accepting a string and returning the token count.

    Raises: * None directly raised.

    Example: 

    # Sourced from ContextRouter.prep()
count_tokens = create_token_counter()
entry_tokens = count_tokens(entry)

    resolve_max_tokens()

    Visibility: Public
    Signature: def resolve_max_tokens(shared: dict) -> int:

    Description:
    Resolves the maximum allowable model context length. It first inspects the shared dictionary for explicit overrides. If absent, it detects provider settings from environment variables (LLM_PROVIDER, GEMINI_PROJECT_ID, GEMINI_API_KEY, or custom provider endpoints) and queries get_model_context_length from utils.call_llm.

    def resolve_max_tokens(shared):
    """Resolve max_tokens from shared store or auto-detect from provider env vars."""
    max_tokens = shared.get("max_tokens")
    if max_tokens is not None:
        return max_tokens
    provider = os.environ.get("LLM_PROVIDER")
    if provider == "GEMINI" or not provider:
        endpoint = "https://generativelanguage.googleapis.com"
        model_name = os.getenv("GEMINI_MODEL", "gemini-3.7-flash")
        api_key = os.getenv("GEMINI_API_KEY", "")
    else:
        endpoint = os.environ.get(f"{provider}_BASE_URL", "")
        model_name = os.environ.get(f"{provider}_MODEL", "")
        api_key = os.environ.get(f"{provider}_API_KEY", "")
    return get_model_context_length(endpoint, model_name, api_key)

    The function checks if max_tokens is explicitly defined in the flow's shared storage. If not, it defaults to the Gemini platform or parses dynamic provider variables according to the active LLM_PROVIDER environment configuration. It delegates the final context length discovery to get_model_context_length(), returning a safe integer limit for prompt assembly.

    Parameters: * shared (dict): The shared workflow context dictionary.

    Returns: * int: Maximum context window token capacity for the configured LLM.

    Raises: * None directly raised.

    Example: 

    # Sourced from ContextRouter.prep()
max_tokens = resolve_max_tokens(shared)
shared["max_tokens"] = max_tokens

        def post(self, shared, prep_res, exec_res):
        import os
        files = shared.get("files", [])
        valid_indices = set(exec_res)
        modules = []
        chapter_order = []

        for idx, (file_path, content) in enumerate(files):

    prep()

    Visibility: Public
    Signature: def prep(self, shared: dict) -> tuple:

    Description:
    Calculates token budgets, measures directory tree and prompt overhead, scans all source file tokens, and selects the routing path.

        def prep(self, shared):
        files_data = shared["files"]
        max_tokens = resolve_max_tokens(shared)

        shared["max_tokens"] = max_tokens

        # --- Token estimation setup ---
        count_tokens = create_token_counter()

        # --- Calculate prompt overhead FIRST ---
        # 1. Prompt template (measure both, use the larger)
        prompt_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "prompts")
        max_template_tokens = 0
        for subdir in ["tutorial", "advanced"]:
            template_path = os.path.join(prompt_dir, subdir, "map_abstractions.md")
            if os.path.exists(template_path):
                with open(template_path, "r", encoding="utf-8-sig") as f:
                    t = count_tokens(f.read())
                max_template_tokens = max(max_template_tokens, t)

        # 2. Directory tree (built from all files, shared across batches)
        directory_tree = self._build_directory_tree(files_data)
        tree_tokens = count_tokens(directory_tree)

        prompt_overhead = max_template_tokens + tree_tokens
        print(f"\033[93m[ContextRouter] Prompt overhead: ~{prompt_overhead:,} tokens "
              f"(template: {max_template_tokens:,}, dir tree: {tree_tokens:,})\033[0m")

        # --- Count file content tokens ---
        total_tokens = 0
        file_token_map = []
        for i, (path, content) in enumerate(files_data):
            entry = f"--- File Index {i}: {path} ---\n{content}\n\n"
            tokens = count_tokens(entry)
            total_tokens += tokens
            file_token_map.append(tokens)

        # --- Effective limit = safety margin minus overhead ---
        safety_limit = int(max_tokens * 0.95)
        effective_limit = safety_limit - prompt_overhead
        force_batch = shared.get("force_batch", False)

        if shared.get("mode", "tutorial") == "api-reference":
            print(f"\033[92m[ContextRouter] api-reference mode active. Bypassing LLM discovery and routing to DeterministicFileMapper.\033[0m")
            return ("deterministic", files_data, effective_limit, shared.get("batch_size", 50),
                    None, None, directory_tree, False)

        if total_tokens > effective_limit and force_batch:
            # ... [Batch logs] ...
        elif total_tokens > effective_limit:
            # ... [Batch logs] ...
        elif force_batch:
            # ... [Batch logs] ...
        else:
            print(f"\033[92m[ContextRouter] File content ({total_tokens:,} tokens) fits in effective limit "
                  f"({effective_limit:,} = {safety_limit:,} - {prompt_overhead:,} overhead). "
                  f"Proceeding normally.\033[0m")
            return ("direct", files_data, effective_limit, shared.get("batch_size", 50),
                    None, None, directory_tree, False)

        return ("batch", files_data, effective_limit, shared.get("batch_size", 50),
                file_token_map, count_tokens, directory_tree, shared.get("debug", False))

    This method first computes the static overhead consumed by prompt templates and the complete directory tree. It calculates the cumulative token count of all file snippets using create_token_counter(). A safety limit (95% of model context) is reduced by the prompt overhead to determine the effective_limit. If the codebase exceeds this threshold or if force_batch is set, it selects "batch"; if running in api-reference mode, it selects "deterministic"; otherwise, it returns "direct".

    Parameters: * shared (dict): Shared pipeline context store.

    Returns: * tuple: Tuple containing the chosen route name, file data, calculated effective limits, batch thresholds, token mapping arrays, directory tree text, and debug flags.

    Raises: * None directly raised.

    exec()

    Visibility: Public
    Signature: def exec(self, prep_res: tuple) -> str | list[list[tuple[int, str, str]]]:

    Description:
    Executes routing decisions. For "direct" and "deterministic" routes, it returns the route name. For "batch" routes, it splits files into directory-coherent, token-bounded batches.

        def exec(self, prep_res):
        route, files_data, effective_limit, batch_size, file_token_map, count_tokens, directory_tree, debug = prep_res
        llm_logger.info(f"NODE EXEC | node=ContextRouter | action=route_decision | route={route} | files={len(files_data)} | effective_limit={effective_limit:,}")

        if route == "direct":
            return "direct"
        if route == "deterministic":
            return "deterministic"

        # Group by directory for coherence, with pre-computed tokens
        dir_groups = defaultdict(list)
        for i, (path, content) in enumerate(files_data):
            dir_groups[os.path.dirname(path)].append((i, path, content, file_token_map[i]))

        # Build token-aware batches (never mix directories)
        batches = []
        for dirname in sorted(dir_groups.keys()):
            current_batch = []
            current_tokens = 0

            for i, path, content, tokens in dir_groups[dirname]:
                # Start new batch if adding this file would exceed effective limit or file count cap
                if current_batch and (current_tokens + tokens > effective_limit or len(current_batch) >= batch_size):
                    batches.append(current_batch)
                    current_batch = []
                    current_tokens = 0

                current_batch.append((i, path, content))
                current_tokens += tokens

            # Flush remaining files in this directory
            if current_batch:
                batches.append(current_batch)

        batch_word = "batch" if len(batches) == 1 else "batches"
        print(f"\033[93m[ContextRouter] Split into {len(batches)} {batch_word}.\033[0m")
        llm_logger.info(f"NODE COMPLETE | node=ContextRouter | route={route} | batches={len(batches)}")
        # ... [Optional debug printing] ...
        self._directory_tree = directory_tree

        return batches

    When batching, files are grouped by their parent directory (os.path.dirname) to keep related modules together. The algorithm iterates through directory groups, appending (index, path, content) tuples into current_batch until the cumulative tokens exceed effective_limit or the batch size reaches batch_size. Files from different directories are never mixed within the same batch.

    Parameters: * prep_res (tuple): Output tuple from prep().

    Returns: * str | list[list[tuple[int, str, str]]]: The string "direct", "deterministic", or a list of file batches.

    Raises: * None directly raised.

    _build_directory_tree()

    Visibility: Private / Static
    Signature: def _build_directory_tree(files_data: list[tuple[str, str]]) -> str:

    Description:
    Generates an ASCII-formatted directory tree showing file paths along with their internal index mappings.

        @staticmethod
    def _build_directory_tree(files_data):
        """Build a compact directory tree string from the list of (path, content) tuples."""
        from collections import defaultdict
        dir_files = defaultdict(list)
        for i, (path, _content) in enumerate(files_data):
            dirname = os.path.dirname(path) or "."
            basename = os.path.basename(path)
            dir_files[dirname].append(f"{basename} (idx:{i})")

        lines = []
        for dirname in sorted(dir_files.keys()):
            lines.append(f"{dirname}/")
            for fname in sorted(dir_files[dirname]):
                lines.append(f"  {fname}")
        return "\n".join(lines)

    This helper formats repository paths into a structural directory tree. Files are grouped under their directory names, sorted alphabetically, and tagged with their corresponding index (idx:{i}). This tree gives the LLM full visibility into codebase structure even during partial-batch analysis.

    Parameters: * files_data (list[tuple[str, str]]): List of file tuples (path, content).

    Returns: * str: Multiline directory tree visualization.

    Raises: * None directly raised.

            if is_mkdocs:
                nav_snippet = prep_res["nav_snippet"]
                api_docs_path = os.path.join(output_path, "docs", "api")

                nav_filepath = os.path.join(output_path, "docs", "nav_snippet.yml")
                with open(nav_filepath, "w", encoding="utf-8") as f:

                print(f"  - Wrote {nav_filepath}")

                # Write module API pages
                for chapter_info in chapter_files:
                    chapter_filepath = os.path.join(api_docs_path, chapter_info["filename"])
                    os.makedirs(os.path.dirname(chapter_filepath), exist_ok=True)
                    with open(chapter_filepath, "w", encoding="utf-8") as f:
                        f.write(chapter_info["content"])
                    print(f"  - Wrote {chapter_filepath}")
            else:
                index_content = prep_res["index_content"]

                # Write index.md
                index_filepath = os.path.join(output_path, "index.md")
                with open(index_filepath, "w", encoding="utf-8") as f:
                    f.write(index_content)
                print(f"  - Wrote {index_filepath}")

                # Write chapter files
                for chapter_info in chapter_files:
                    chapter_filepath = os.path.join(output_path, chapter_info["filename"])
                    with open(chapter_filepath, "w", encoding="utf-8") as f:
                        f.write(chapter_info["content"])
                    print(f"  - Wrote {chapter_filepath}")

                # Create full_content.md
                toc_lines = [f"# {ui['toc']}\n"]
                full_content_lines = []

                for i, chapter_info in enumerate(chapter_files):
                    content = chapter_info["content"]
                    title_line = content.split('\n', 1)[0]
                    title = title_line[2:].strip() if title_line.startswith('# ') else f"{ui['chapter']} {i+1}"

                    toc_lines.append(f"- [{title}](#chapter-{i+1})")
                    full_content_lines.append(f'<a id="chapter-{i+1}"></a>\n')
                    full_content_lines.append(content)
                    full_content_lines.append('\n---\n')

                full_content = "\n".join(toc_lines) + "\n\n" + "\n".join(full_content_lines)
                full_content_filepath = os.path.join(output_path, "full_content.md")
                with open(full_content_filepath, "w", encoding="utf-8") as f:
                    f.write(full_content)
                print(f"  - Wrote {full_content_filepath}")
