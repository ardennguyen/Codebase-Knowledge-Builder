    flow.py

    Source: flow.py

    Following the token accounting and context-window capacity validation utilities documented in utils/token_utils.py, the flow.py module defines the core execution graph and orchestration topology for the Codebase-Knowledge-Builder pipeline. It assembles discrete functional and LLM-driven execution nodes into a unified Directed Acyclic Graph (DAG) using the pocketflow framework.

    Technical Overview

    The flow.py module serves as the central orchestration definition layer of the application. It decouples the definition of individual processing tasks—implemented in nodes.py—from the pipeline's topological execution flow, branching logic, and error recovery policies.

    The primary responsibility of flow.py is to instantiate all workflow nodes with appropriate fault-tolerance configurations (such as retry budgets and backoff durations) and link them using PocketFlow's graph-composition syntax (>> and - "action" >>). The resulting execution graph dynamically routes execution based on repository scale, structural complexity, and token budgets.

    Core Responsibilities

    1. Topological Pipeline Construction: Defines the dependency hierarchy between repository fetching, architectural abstraction discovery, dependency relationship analysis, chapter sequencing, markdown content generation, and final static site asset compilation.
    2. Conditional Context Routing: Establishes three distinct analysis pipelines through the ContextRouter decision node:
    3. Direct Pathway ("direct"): Routes small-to-medium repositories directly through single-pass structural analysis (IdentifyAbstractions).
    4. Batch Map-Reduce Pathway ("batch"): Splits large repositories across segmented batches (MapAbstractions) and merges the intermediate findings into a cohesive architectural model (ReduceAbstractions).
    5. Deterministic Pathway ("deterministic"): Bypasses generative abstraction modeling in favor of deterministic directory/file-level grouping (DeterministicFileMapper) when requested by user configuration.
    6. Resilience Policy Enforcement: Configures rate-limit and transient failure recovery across all network-bound and generative inference stages by attaching a 5-retry maximum with 20-second exponential/linear wait intervals (max_retries=5, wait=20).

    Module-Level Functions

    create_tutorial_flow()

    Visibility: Public
    Signature: def create_tutorial_flow() -> Flow:

    Description:
    Instantiates all concrete pipeline nodes from nodes.py, applies node-specific retry and backoff parameters, connects nodes via directed transition edges and conditional action branches, and wraps the resulting graph in a PocketFlow Flow instance starting at FetchRepo.

    Parameters:
    * None.

    Returns:
    * pocketflow.Flow: An executable workflow graph with FetchRepo designated as the root entry point.

    Raises:
    * None internally; node validation or dependency misconfigurations are propagated during graph instantiation or runtime invocation.

    Implementation: 

    def create_tutorial_flow():
    fetch_repo = FetchRepo()
    context_router = ContextRouter()
    map_abstractions = MapAbstractions(max_retries=5, wait=20)
    reduce_abstractions = ReduceAbstractions(max_retries=5, wait=20)
    identify_abstractions = IdentifyAbstractions(max_retries=5, wait=20)
    analyze_relationships = AnalyzeRelationships(max_retries=5, wait=20)
    order_chapters = OrderChapters(max_retries=5, wait=20)
    write_chapters = WriteChapters(max_retries=5, wait=20)
    combine_tutorial = CombineTutorial()
    deterministic_mapper = DeterministicFileMapper(max_retries=5, wait=20)

    fetch_repo >> context_router

    context_router - "direct" >> identify_abstractions
    context_router - "batch" >> map_abstractions
    context_router - "deterministic" >> deterministic_mapper

    map_abstractions >> reduce_abstractions

    identify_abstractions >> analyze_relationships
    reduce_abstractions >> analyze_relationships

    analyze_relationships >> order_chapters
    order_chapters >> write_chapters

    deterministic_mapper >> write_chapters

    write_chapters >> combine_tutorial

    return Flow(start=fetch_repo)

    The create_tutorial_flow() function configures ten distinct node instances. Local computational nodes that execute deterministic file-system I/O or in-memory dictionary aggregation (FetchRepo and CombineTutorial) are instantiated with default retry parameters since they do not execute remote API calls. All other nodes—which interact with backend LLM inference endpoints via utils/call_llm.py—receive max_retries=5 and wait=20 to protect the pipeline against transient provider errors, network timeouts, and HTTP 429 rate limits.

    The graph construction syntax uses overloaded bitwise right-shift operators (>>) provided by PocketFlow to establish sequential execution dependencies. For conditional branching, the subtraction operator paired with an action string (- "action" >>) creates guarded transitions from ContextRouter.

    The direct and batch branches converge at AnalyzeRelationships, which unifies single-pass and map-reduced abstractions before proceeding to OrderChapters. The deterministic branch completely bypasses relationship analysis and chapter ordering, connecting directly into WriteChapters. Finally, all generation branches converge at CombineTutorial to produce the index files, table of contents, and MkDocs static site structure.

    1. The Direct Pathway ("direct")

    • Trigger Condition: Ingested codebase token count fits comfortably within the LLM's single-prompt context window (calculated using utils/token_utils.py).
    • Execution Flow: FetchRepo $\rightarrow$ ContextRouter $\rightarrow$ IdentifyAbstractions $\rightarrow$ AnalyzeRelationships $\rightarrow$ OrderChapters $\rightarrow$ WriteChapters $\rightarrow$ CombineTutorial.
    • Behavior: Evaluates all codebase files concurrently, allowing the model to detect holistic architecture and cross-cutting concerns in a single LLM call.

    2. The Batch Map-Reduce Pathway ("batch")

    • Trigger Condition: Total token volume exceeds single-pass context limits, requiring chunked analysis.
    • Execution Flow: FetchRepo $\rightarrow$ ContextRouter $\rightarrow$ MapAbstractions $\rightarrow$ ReduceAbstractions $\rightarrow$ AnalyzeRelationships $\rightarrow$ OrderChapters $\rightarrow$ WriteChapters $\rightarrow$ CombineTutorial.
    • Behavior: MapAbstractions chunks files across multiple prompt payloads, extracting local structural abstractions per batch. ReduceAbstractions performs deduplication, hierarchical clustering, and structural merging to produce a single consolidated abstraction schema.

    3. The Deterministic Pathway ("deterministic")

    • Trigger Condition: Configured via workflow parameters to map files directly to documentation chapters based on directory structure or pre-filtered indices without generative concept clustering.
    • Execution Flow: FetchRepo $\rightarrow$ ContextRouter $\rightarrow$ DeterministicFileMapper $\rightarrow$ WriteChapters $\rightarrow$ CombineTutorial.
    • Behavior: Skips AnalyzeRelationships and OrderChapters. File groupings and module boundaries are determined programmatically, after which WriteChapters generates documentation chapters directly.

    Resilience and Fault-Tolerance Configuration

    Nodes that invoke remote inference APIs inherit from PocketFlow's retry-capable base node classes. In flow.py, these nodes are parameterized uniformly:

    Node Class Configured max_retries Configured wait (seconds) Operational Rationale
    FetchRepo Default (0) Default (0) Executes local disk traversal or deterministic Git/REST cloning via utils/crawl_local_files.py or utils/crawl_github_files.py.
    ContextRouter Default (0) Default (0) In-memory token evaluation and branch routing; no I/O or network dependencies.
    MapAbstractions 5 20 Handles high-volume parallel batch requests against LLM endpoints; prone to rate-limiting (HTTP 429).
    ReduceAbstractions 5 20 Synthesizes large intermediate JSON schemas into unified models; protects against context limits or schema generation failures.
    IdentifyAbstractions 5 20 Processes full repository contexts; guards against timeouts during large single-prompt analysis.
    AnalyzeRelationships 5 20 Performs deep dependency graph and call-hierarchy synthesis; susceptible to context saturation.
    OrderChapters 5 20 Generates logical pedagogical sequences; retried on malformed JSON or formatting errors.
    DeterministicFileMapper 5 20 Validates file maps against LLM-filtered inclusion rules using prompts from utils/prompts.py.
    WriteChapters 5 20 Generates comprehensive chapter markdown content sequentially; high token output with potential for model timeouts.
    CombineTutorial Default (0) Default (0) Final deterministic filesystem serialization and MkDocs static configuration writing via utils/output.py.
